## 欽定四庫全書總目 卷四十一　經部四十一　小學類二

<!-- 册1 葉3324：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷四十一  
<span style="margin-left: 1em">經部四十一</span>  
<span style="margin-left: 2em">小學類二</span>  
急就章四卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">漢史游撰漢書藝文志註稱游爲元帝時黄門令</span>  
<span style="margin-left: 2em">葢宦官也其始末則不可考矣是書漢志但作急</span>  
<span style="margin-left: 2em">就一篇而小學類末之敘錄則稱史游作急就篇</span>  
<span style="margin-left: 2em">故晉夏侯湛抵疑稱鄉曲之徒一介之士曾諷急</span>  
<span style="margin-left: 2em">就通甲子北齊書稱李<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）">九歲入學書急就篇或</span>  
<!-- 册1 葉3325b　Page:文淵閣四庫全書_0001冊.djvu/881 -->
<span style="margin-left: 2em">有篇字或無篇字初無一定隋志作急就章一卷</span>  
<span style="margin-left: 2em">魏書崔浩傳亦稱人多托寫急就章是改篇爲章</span>  
<span style="margin-left: 2em">在魏以後然考張懷瓘書斷曰章草者漢黃門令</span>  
<span style="margin-left: 2em">史游所作也王愔云<sub class="note-yuan">案此葢引王愔文字志之語</sub>漢元帝時史</span>  
<span style="margin-left: 2em">游作急就章解散隷體漢俗簡惰漸以行之是也</span>  
<span style="margin-left: 2em">然則所謂章草者正因游作是書以所變草法書</span>  
<span style="margin-left: 2em">之後人以其出於急就章遂名章草耳今本每節</span>  
<span style="margin-left: 2em">之首俱有章第幾字知急就章乃其本名或稱急</span>  
<span style="margin-left: 2em">就篇或但稱急就乃偶然異文也其書自始至終</span>  
<!-- 册1 葉3328a　Page:文淵閣四庫全書_0001冊.djvu/882 -->
<span style="margin-left: 2em">無一複字文詞雅奥亦非𫎇求諸書所可及玉臺</span>  
<span style="margin-left: 2em">新詠載梁蕭子顯烏栖曲有帬邊雜佩琥珀龍句</span>  
<span style="margin-left: 2em">馮氏校本改龍爲紅今檢此書有繫臂琅玕虎魄</span>  
<span style="margin-left: 2em">龍句乃知子顯實用此語馮氏不知而誤改之則</span>  
<span style="margin-left: 2em">遺文𤨏事亦頗賴以有徵不僅爲童𫎇識字之用</span>  
<span style="margin-left: 2em">矣舊有曹壽崔浩劉芳顔之推注今皆不傳惟顔</span>  
<span style="margin-left: 2em">師古注一卷存王應麟又補注之𨤲爲四卷師古</span>  
<span style="margin-left: 2em">本比皇象碑多六十三字而少齊國山陽兩章止</span>  
<span style="margin-left: 2em">三十二章應麟藝文志考證標眞定常山至高邑</span>  
<!-- 册1 葉3328b　Page:文淵閣四庫全書_0001冊.djvu/882 -->
<span style="margin-left: 2em">句以爲此二章起於東漢最爲精確其注亦考證</span>  
<span style="margin-left: 2em">典核足補師古之闕别有黃庭堅本李燾本朱子</span>  
<span style="margin-left: 2em">越中本字句小有異同應麟所註多從顔本葢以</span>  
<span style="margin-left: 2em">其考證精深較他家爲可據焉</span>  
說文解字三十卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">漢許愼撰愼字叔重汝南人官至太尉南閣祭酒</span>  
<span style="margin-left: 2em">是書成於和帝永元十二年凡十四篇合目錄一</span>  
<span style="margin-left: 2em">篇爲十五篇分五百四十部爲文九千三百五十</span>  
<span style="margin-left: 2em">三重文一千一百六十三註十三萬三千四百四</span>  
<!-- 册1 葉3329a　Page:文淵閣四庫全書_0001冊.djvu/882 -->
<span style="margin-left: 2em">十字推究六書之義分部類從至爲精密而訓詁</span>  
<span style="margin-left: 2em">簡質猝不易通又音韻改移古今異讀諧聲諸字</span>  
<span style="margin-left: 2em">亦每難明故傳本往往訛異宋雍熙三年詔徐<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）"></span>  
<span style="margin-left: 2em">葛湍王惟恭句中正等重加刊定凡字爲說文注</span>  
<span style="margin-left: 2em">義序例所載而諸部不見者悉爲補錄又有經典</span>  
<span style="margin-left: 2em">相承時俗要用而說文不載者亦皆増加别題之</span>  
<span style="margin-left: 2em">曰新附字其本有正體而俗書訛變者則辨於註</span>  
<span style="margin-left: 2em">中其違戻六書者則别載卷末或註義末備更爲</span>  
<span style="margin-left: 2em">補釋亦題臣<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）">等按以别之音切則一以孫愐唐</span>  
<!-- 册1 葉3329b　Page:文淵閣四庫全書_0001冊.djvu/882 -->
<span style="margin-left: 2em">韻爲定以篇帙繁重每卷各分上下卽今所行毛</span>  
<span style="margin-left: 2em">晉刋本是也明萬厯中宮氏刻李燾說文五音韻</span>  
<span style="margin-left: 2em">譜陳大科序之誤以爲卽<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）">校本陳啟元作毛詩</span>  
<span style="margin-left: 2em">稽古編顧炎武作日知錄並沿其謬豈毛氏所刊</span>  
<span style="margin-left: 1em">國初猶未盛行歟書中古文籀文李燾據唐林罕之</span>  
<span style="margin-left: 2em">說以爲晉㡉令呂忱所増考愼自序云今序篆文</span>  
<span style="margin-left: 2em">合以古籀其語甚明所記重文之數亦復相應又</span>  
<span style="margin-left: 2em">法書要錄載後魏江式論書表曰晉世義陽王典</span>  
<span style="margin-left: 2em">祠令任城呂忱表上字林六卷尋其况趣附託許</span>  
<!-- 册1 葉3332a　Page:文淵閣四庫全書_0001冊.djvu/883 -->
<span style="margin-left: 2em">愼說文而按偶章隠别古籀奇惑之字文得正隷</span>  
<span style="margin-left: 2em">不差篆意則忱書並不用古籀亦有顯證如罕之</span>  
<span style="margin-left: 2em">所云呂忱字林多補許愼遺闕者特廣說文未收</span>  
<span style="margin-left: 2em">字耳其書今雖不傳然如廣韻一東部炯字谾字</span>  
<span style="margin-left: 2em">四江部噥字之類云出字林者皆說文所無亦大</span>  
<span style="margin-left: 2em">畧可見燾以說文古籀爲忱所増誤之甚矣自魏</span>  
<span style="margin-left: 2em">晉以來言小學者皆祖愼至李陽氷始曲相排斥</span>  
<span style="margin-left: 2em">未協至公然愼書以小篆爲宗至於隷書行書草</span>  
<span style="margin-left: 2em">書則各爲一體孶生轉變時有異同不悉以小篆</span>  
<!-- 册1 葉3332b　Page:文淵閣四庫全書_0001冊.djvu/883 -->
<span style="margin-left: 2em">相律故顔元孫干祿字書曰自改篆行隷漸失其</span>  
<span style="margin-left: 2em">眞若總據說文便下筆多礙當去泰去甚使輕重</span>  
<span style="margin-left: 2em">各宜徐<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）">進說文表亦曰高文大冊則宜以篆籀</span>  
<span style="margin-left: 2em">著之金石至於常行簡牘則草隷足矣二人皆精</span>  
<span style="margin-left: 2em">通小學而持論如是明黃諫作从古正文一切以</span>  
<span style="margin-left: 2em">篆改隷豈識六書之㫖哉至其所引五經文字與</span>  
<span style="margin-left: 2em">今本多不相同或往往自相違異顧炎武日知錄</span>  
<span style="margin-left: 2em">嘗摭其汜下作江有汜洍下又作江有洍卺下作</span>  
<span style="margin-left: 2em">赤舄卺卺掔下又作赤舄掔掔是所云詩用毛氏</span>  
<!-- 册1 葉3333a　Page:文淵閣四庫全書_0001冊.djvu/883 -->
<span style="margin-left: 2em">者亦與今本不同盖雖一家之學而宗派旣别亦</span>  
<span style="margin-left: 2em">各不相合好奇者或據之以改經則謬戾殊甚能</span>  
<span style="margin-left: 2em">通其意而又能不泥其迹庻乎爲善讀說文矣</span>  
<span style="margin-left: 4em">案愼序自稱易孟氏書孔氏詩毛氏禮周官</span>  
<span style="margin-left: 4em">春秋左傳論語孝經皆古文考劉知幾史通</span>  
<span style="margin-left: 4em">稱古文尙書得之壁中博士孔安國以校伏</span>  
<span style="margin-left: 4em">生所誦増多二十五篇<sub class="note-yuan">案此亦據梅賾古文而言實則孔氏原本</sub></span>  
<span style="margin-left: 4em"><sub class="note-yuan">僅増多十六篇</sub>更以隷古字寫之編爲四十六卷司</span>  
<span style="margin-left: 4em">馬遷屢采其事故遷多有古說至於後漢孔</span>  
<!-- 册1 葉3333b　Page:文淵閣四庫全書_0001冊.djvu/883 -->
<span style="margin-left: 4em">氏之本遂絶其有見於經典者諸儒皆謂之</span>  
<span style="margin-left: 4em">逸書是孔氏壁中之書愼不得見說文末載</span>  
<span style="margin-left: 4em">愼子冲上書稱愼古學受之賈逵而後漢書</span>  
<span style="margin-left: 4em">儒林傳又稱扶風杜林傳古文尙書林同郡</span>  
<span style="margin-left: 4em">賈逵爲之作訓馬融作傳鄭元註解由是古</span>  
<span style="margin-left: 4em">文尙書遂顯於世是愼所謂孔氏書者卽杜</span>  
<span style="margin-left: 4em">林之本顧隋志稱杜林古文尙書所傳僅二</span>  
<span style="margin-left: 4em">十九篇又雜以今文非孔舊本<sub class="note-yuan">案古文除去無師說者十</sub></span>  
<span style="margin-left: 4em"><sub class="note-yuan">六篇正得伏生二十九篇之數非雜以今文隋志此文亦據梅賾古文未及與漢書互校</sub></span>  
<!-- 册1 葉3336a　Page:文淵閣四庫全書_0001冊.djvu/884 -->
<span style="margin-left: 4em">自餘絶無師說陸德明經典釋呅採馬融注</span>  
<span style="margin-left: 4em">甚多皆今文尙書無古文一語卽說文註中</span>  
<span style="margin-left: 4em">所引亦皆在今文二十八篇之中朱彞尊經</span>  
<span style="margin-left: 4em">義考辨之甚明<sub class="note-yuan">案彞尊又謂惟若藥不瞑<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3392.svg?width=24" alt="四庫全書僻字第3392號（眩）" title="四庫全書僻字第3392號（眩）">一句出古文說命殆因孟子</sub></span>  
<span style="margin-left: 4em"><sub class="note-yuan">所引而及之然此句乃徐鍇說文繫傳之語非許愼之原注彞尊偶爾誤觀移甲爲乙故</sub></span>  
<span style="margin-left: 4em"><sub class="note-yuan">今不取其說</sub>則愼所謂孔氏本者非今五十八篇</span>  
<span style="margin-left: 4em">本矣以意推求漢書藝文志稱劉向以中古</span>  
<span style="margin-left: 4em">文校歐陽大小夏侯三家經文酒誥脫簡一</span>  
<span style="margin-left: 4em">召誥脫簡一文字異者七百有餘脫字數十</span>  
<!-- 册1 葉3336b　Page:文淵閣四庫全書_0001冊.djvu/884 -->
<span style="margin-left: 4em">云云所謂中古文卽孔氏所上之古文存於</span>  
<span style="margin-left: 4em">中秘者是三家之本立在博士者皆經劉向</span>  
<span style="margin-left: 4em">以古文勘定改其訛脫其書已皆與古文同</span>  
<span style="margin-left: 4em">儒者據其訓詁言之則曰大小夏侯歐陽尙</span>  
<span style="margin-left: 4em">書據其經文則亦可曰孔氏古文尙書第三</span>  
<span style="margin-left: 4em">家解說只有伏生二十八篇遞相授受餘所</span>  
<span style="margin-left: 4em">増十六篇不能詮釋遂置不言故馬融書序</span>  
<span style="margin-left: 4em">稱十六篇絶無師說也<sub class="note-yuan">案融序今不傳此語見孔頴達尙書正義</sub></span>  
<span style="margin-left: 4em"><small>中</small>使賈陸所傳杜林之本卽今五十八篇之</span>  
<!-- 册1 葉3337a　Page:文淵閣四庫全書_0001冊.djvu/884 -->
<span style="margin-left: 4em">本則融嘗因之作傳矣安有是語哉又後漢</span>  
<span style="margin-left: 4em">書杜林傳稱林前於西州得漆書古文尙書</span>  
<span style="margin-left: 4em">嘗寶愛之雖遭艱困握持不離身云云是林</span>  
<span style="margin-left: 4em">所傳者乃古文字體故謂之漆書是必劉向</span>  
<span style="margin-left: 4em">校正三家之時隨二十八篇傳出以字非隷</span>  
<span style="margin-left: 4em">古世不行用林偶得之以授逵逵得之以授</span>  
<span style="margin-left: 4em">愼故愼稱爲孔氏本而亦止二十八篇非愼</span>  
<span style="margin-left: 4em">見安國舊本也論尙書者惟說文此句最爲</span>  
<span style="margin-left: 4em">疑竇閻若璩尙書古文疏證牽於此句遂誤</span>  
<!-- 册1 葉3337b　Page:文淵閣四庫全書_0001冊.djvu/884 -->
<span style="margin-left: 4em">以馬鄭所註爲孔氏原本亦千慮之一失故</span>  
<span style="margin-left: 4em">附考其源流如此</span>  
說文繫傳四十卷<sub class="note-yuan">兵部侍郎紀昀家藏本</sub>  
<span style="margin-left: 2em">南唐徐鍇撰鍇字楚金廣陵人官至右内史舍人</span>  
<span style="margin-left: 2em">宋兵下江南卒於圍城之中事迹具南唐書本傳</span>  
<span style="margin-left: 2em">是書凡八篇首通釋三十卷以許愼說文解字十</span>  
<span style="margin-left: 2em">五篇篇析爲二凡鍇所發明及徵引經傳者悉加</span>  
<span style="margin-left: 2em">臣鍇日及臣鍇按字以别之繼以部敘二卷通論</span>  
<span style="margin-left: 2em">三卷祛妄類聚錯綜疑義系述各一卷祛妄斥李</span>

<span style="margin-left: 2em">陽氷臆說疑義舉說文偏旁所有而闕其字及篆</span>
