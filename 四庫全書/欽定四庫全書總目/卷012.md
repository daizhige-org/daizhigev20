## 欽定四庫全書總目 卷十二　經部十二　書類二

欽定四庫全書總目卷十二  
<span style="margin-left: 1em">經部十二</span>  
<span style="margin-left: 2em">書類二</span>  
讀書叢說六卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">元許謙撰謙字益之金華人延祐中以講學名一</span>  
<span style="margin-left: 2em">時儒者所稱白雲先生是也事迹具无史儒學傳</span>  
<span style="margin-left: 2em">自蔡沈書集傳出解經者大抵樂其簡易不復㕘</span>  
<span style="margin-left: 2em">考諸書謙獨博覈事實不株守一家故稱叢說如</span>  
<span style="margin-left: 2em">蔡氏釋堯典本張子天左旋處其中者順之少遲</span>  
<!-- 册1 葉1077b　Page:文淵閣四庫全書_0001冊.djvu/319 -->
<span style="margin-left: 2em">則反右之說不知左旋者東西旋右旋者南北旋</span>  
<span style="margin-left: 2em">截然殊致非以遲而成右也日東出西没隨大氣</span>  
<span style="margin-left: 2em">而左以成晝夜非日之自行其自行則冬至後由</span>  
<span style="margin-left: 2em">南斂北夏至後由北發南以成寒暑月之隨大氣</span>  
<span style="margin-left: 2em">而左及其自行亦如之謙雖不能盡攻其失然七</span>  
<span style="margin-left: 2em">政疑一條謂七政與天同西行恐錯亂紛雜泛然</span>  
<span style="margin-left: 2em">無統可謂不苟同矣舊說洛誥我乃卜澗水東𤄊</span>  
<span style="margin-left: 2em">水西爲王城據召誥洛誥周公皆乙卯至洛在召</span>  
<span style="margin-left: 2em">公得卜經營攻位五日位成之後是王城無庸再</span>  
<!-- 册1 葉1080a　Page:文淵閣四庫全書_0001冊.djvu/320 -->
<span style="margin-left: 2em">卜謙謂此時王城巳定但卜處殷民之地故先河</span>  
<span style="margin-left: 2em">朔黎水以近殷舊都民遷之便次及澗東𤄊西次</span>  
<span style="margin-left: 2em">及𤄊東皆以洛與此地相對定墨而皆惟洛食𤄊</span>  
<span style="margin-left: 2em">澗流至洛所經巳遠不知周公所卜者何處又呂</span>  
<span style="margin-left: 2em">刑稱惟作五虐之刑曰法稱爰始淫爲劓刵㭬黥</span>  
<span style="margin-left: 2em">舊說以爲其刑造自有苗謙謂苗乃專以刑爲治</span>  
<span style="margin-left: 2em">國之法乃始過用其刑非創造刑也如此之類亦</span>  
<span style="margin-left: 2em">頗不爲習聞所囿至於說六律五聲漫錄律呂新</span>  
<span style="margin-left: 2em">書說唐虞之修五禮漫錄周公大宗伯之文說酒</span>  
<!-- 册1 葉1080b　Page:文淵閣四庫全書_0001冊.djvu/320 -->
<span style="margin-left: 2em">誥太史內史漫錄周公太宰六典八灋八則八柄</span>  
<span style="margin-left: 2em">之文殊屬泛衍書內載其師金履祥說爲多卷首</span>  
<span style="margin-left: 2em">書紀年一篇卽據履祥通鑑前編起算其間得失</span>  
<span style="margin-left: 2em">雜出亦不盡<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">然宋末元初說經者多尚虛談而</span>  
<span style="margin-left: 2em">謙於詩考名物於書考典制猶有先儒篤實之遺</span>  
<span style="margin-left: 2em">是足貴也其書與詩名物鈔四書叢說並刋於至</span>  
<span style="margin-left: 2em">正六年其板久佚此本爲浙江吳玉墀家所藏其</span>  
<span style="margin-left: 2em">第二卷中脫四頁第三卷中脫兩頁第五卷第六</span>  
<span style="margin-left: 2em">巻各脫四頁勘騐别本亦皆相同今亦無從校補</span>  
<!-- 册1 葉1081a　Page:文淵閣四庫全書_0001冊.djvu/320 -->
<span style="margin-left: 2em">姑仍其舊焉</span>  
書纂言四卷<sub class="note-yuan">內府藏本</sub>  
<span style="margin-left: 2em">元吳澄撰澄有易纂言巳著錄是編其書解也古</span>  
<span style="margin-left: 2em">文尚書自貞觀勅作正義以後終唐世無異說宋</span>  
<span style="margin-left: 2em">吳棫作書埤傳始稍稍掊擊朱子語錄亦疑其僞</span>  
<span style="margin-left: 2em">然言性言心言學之語宋人據以立教者其端皆</span>  
<span style="margin-left: 2em">發自古文故亦無肯輕議者其考定今文古文自</span>  
<span style="margin-left: 2em">陳振孫尚書說始其分編今文古文自趙孟頫書</span>  
<span style="margin-left: 2em">古今文集注始其專釋今文則自澄此書始自序</span>  
<!-- 册1 葉1081b　Page:文淵閣四庫全書_0001冊.djvu/320 -->
<span style="margin-left: 2em">謂晉世晩出之書别見於後然此四卷以外實未</span>  
<span style="margin-left: 2em">釋古文一篇朱彝尊經義考以爲權詞其說是也</span>  
<span style="margin-left: 2em">考漢代治尚書者伏生今文傳爲大小夏侯歐陽</span>  
<span style="margin-left: 2em">三家孔安國古文别傳都尉朝庸生胡常自爲一</span>  
<span style="margin-left: 2em">派是今文古文本各爲師說澄專釋今文尚爲有</span>  
<span style="margin-left: 2em">合於古義非王柏詩疑舉厯代相傳之古經肆意</span>  
<span style="margin-left: 2em">刋削者比惟其顚倒錯簡皆以意自爲且不明言</span>  
<span style="margin-left: 2em">所以改竄之故與所作易纂言體例迥殊是則不</span>  
<span style="margin-left: 2em">可以爲訓讀者取所長而無效所短可矣</span>  
<!-- 册1 葉1084a　Page:文淵閣四庫全書_0001冊.djvu/321 -->
尚書集傳纂疏六卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">元陳櫟撰櫟字壽翁號定宇休寧人宋亡之後隱</span>  
<span style="margin-left: 2em">居三十八年至延祐甲寅年六十三復出應試中</span>  
<span style="margin-left: 2em">浙江鄉試以病不及㑹試越二年上書干執政不</span>  
<span style="margin-left: 2em">報遂終於家年八十有三事迹具元史儒學傳董</span>  
<span style="margin-left: 2em">鼎書傳纂註所稱新安陳氏卽其人也是編以疏</span>  
<span style="margin-left: 2em">通蔡傳之意故命曰疏以纂輯諸家之說故命曰</span>  
<span style="margin-left: 2em">纂又以蔡傳本出朱子指授故第一卷特標朱子</span>  
<span style="margin-left: 2em">訂正之目每條之下必以朱子之說冠於諸家之</span>  
<!-- 册1 葉1084b　Page:文淵閣四庫全書_0001冊.djvu/321 -->
<span style="margin-left: 2em">前間附巳意則題曰愚謂以別之考櫟別有書說</span>  
<span style="margin-left: 2em">折衷成於此書之前今巳散佚惟其序尚載定宇</span>  
<span style="margin-left: 2em">集中稱朱子說書通其可通不强通其所難通而</span>  
<span style="margin-left: 2em">蔡氏於難通罕闕焉宗師說者固多異之者亦不</span>  
<span style="margin-left: 2em">少子因訓子遂掇朱子大旨及諸家之得經本義</span>  
<span style="margin-left: 2em">者句釋於下異同之說低一字折衷之則櫟之說</span>  
<span style="margin-left: 2em">書亦未嘗株守蔡傳而是書之作乃於蔡傳有所</span>  
<span style="margin-left: 2em">增補無所駁正與其舊說迥殊自序稱聖朝科舉</span>  
<span style="margin-left: 2em">興行諸經四書一是以朱子爲宗書宗蔡傳固亦</span>  
<!-- 册1 葉1085a　Page:文淵閣四庫全書_0001冊.djvu/321 -->
<span style="margin-left: 2em">宜然云云葢延祐設科以後功令如此故不敢有</span>  
<span style="margin-left: 2em">所出入也</span>  
尚書輯錄纂註六卷<sub class="note-yuan">內府藏本</sub>  
<span style="margin-left: 2em">元董鼎撰鼎字季亨鄱陽人朱子之學授於黃𠏉</span>  
<span style="margin-left: 2em">鼎族兄夢程嘗從𠏉游鼎又從夢程聞緒論故自</span>  
<span style="margin-left: 2em">敘謂得朱子之再傳是編雖以蔡沈集傳爲宗而</span>  
<span style="margin-left: 2em">集傳之後續以朱子語錄及他書所載朱子語謂</span>  
<span style="margin-left: 2em">之輯錄又采諸說之相發明者附列於末謂之纂</span>  
<span style="margin-left: 2em">註自序稱集傳旣爲朱子所訂定則與自著無異</span>  
<!-- 册1 葉1085b　Page:文淵閣四庫全書_0001冊.djvu/321 -->
<span style="margin-left: 2em">又稱薈萃成朱子之一經則仍以朱子爲主也考</span>  
<span style="margin-left: 2em">蔡沈書集傳序惟稱二典三謨嘗經先生㸃定故</span>  
<span style="margin-left: 2em">陳櫟作書集傳纂疏惟虞書首標朱子而夏書以</span>  
<span style="margin-left: 2em">下則不然其凡例曰首卷有朱子訂定四字不忘</span>  
<span style="margin-left: 2em">本也自二卷起去四字紀實也吳澄作是書序亦</span>  
<span style="margin-left: 2em">稱朱子訂定蔡傳僅至百官若帝之初而止此書</span>  
<span style="margin-left: 2em">大禹謨正月朔旦條下鼎併附注其說是鼎於此</span>  
<span style="margin-left: 2em">書源委本自分明其稱集傳爲朱子所訂定似未</span>  
<span style="margin-left: 2em">免假借然澄序又稱集傳自周書洪範後浸覺疎</span>  
<!-- 册1 葉1088a　Page:文淵閣四庫全書_0001冊.djvu/322 -->
<span style="margin-left: 2em">脫師說甚明而不用者有焉疑其著述未竟而人</span>  
<span style="margin-left: 2em">爲增補或草稿初成而未及修改所舉金縢召誥</span>  
<span style="margin-left: 2em">洛誥諸條皆顯相舛異又稱鼎作是書有同有異</span>  
<span style="margin-left: 2em">俱有所裨如解西伯戡黎則從吳棫解多士則從</span>  
<span style="margin-left: 2em">陳櫟解金縢則兼存鄭孔二義不以蔡傳之從鄭</span>  
<span style="margin-left: 2em">爲然云云然則鼎於集傳葢不免有所未愜恐人</span>  
<span style="margin-left: 2em">以源出朱子爲疑故特引朱子之說補其闕失其</span>  
<span style="margin-left: 2em">舉集傳歸之朱子猶曰以朱翼朱則不以異蔡爲</span>  
<span style="margin-left: 2em">嫌耳非其考之不審也</span>  
<!-- 册1 葉1088b　Page:文淵閣四庫全書_0001冊.djvu/322 -->
尚書通考十卷<sub class="note-yuan">江西巡撫採進本</sub>  
<span style="margin-left: 2em">元黃鎭成撰鎭成字元鎭邵武人以薦授江南儒</span>  
<span style="margin-left: 2em">學提舉未上而卒其書徵引舊說以考四代之名</span>  
<span style="margin-left: 2em">物典章亦間附以論斷頗爲詳備其中如論閏月</span>  
<span style="margin-left: 2em">而牽及後代司天之書論律而旁引京房之法論</span>  
<span style="margin-left: 2em">樂而臚陳自漢至宋之樂名皆與經義無關失之</span>  
<span style="margin-left: 2em">汎濫其他四仲五品五教九疇六府三事之類皆</span>  
<span style="margin-left: 2em">經有明文而複登圖譜别無發明亦爲冗瑣又全</span>  
<span style="margin-left: 2em">書皆數典之文而曰若稽古一條獨參訓詁尤爲</span>  
<!-- 册1 葉1089a　Page:文淵閣四庫全書_0001冊.djvu/322 -->
<span style="margin-left: 2em">例不純似乎隨筆記錄之稿未經刋潤成書者然</span>  
<span style="margin-left: 2em">書本以道政事而儒者以大經大法爲麤迹類引</span>  
<span style="margin-left: 2em">之而言心王應麟困學紀聞曰仲虺之誥言仁之</span>  
<span style="margin-left: 2em">始也湯誥言性之始也太甲言誠之始也說命言</span>  
<span style="margin-left: 2em">學之始也然則刪書錄此四篇果僅因此四語乎</span>  
<span style="margin-left: 2em">鎭成此編雖頗嫌蕪雜然猶爲以實用求書不以</span>  
<span style="margin-left: 2em">空言求書者其自序有曰求帝王之心易考帝王</span>  
<span style="margin-left: 2em">之事難可謂知說經難易之故矣</span>  
書蔡傳旁通六卷<sub class="note-yuan">兩江總督採進本</sub>  
<!-- 册1 葉1089b　Page:文淵閣四庫全書_0001冊.djvu/322 -->
<span style="margin-left: 2em">元陳師凱撰師凱家彭蠡故自題曰東滙澤其始</span>  
<span style="margin-left: 2em">末則不可得詳此書成於至治辛酉以鄱陽董鼎</span>  
<span style="margin-left: 2em">尚書輯錄纂注本以羽翼蔡傳然多採先儒問答</span>  
<span style="margin-left: 2em">斷以巳意大抵辨論義理而於天文地理律厯禮</span>  
<span style="margin-left: 2em">樂兵刑龜策河圖洛書道德性命官職封建之屬</span>  
<span style="margin-left: 2em">皆在所畧遇傳文片言之賾隻字之隱讀者不免</span>  
<span style="margin-left: 2em">囁嚅齟齬因作是編於名物度數蔡傳所稱引而</span>  
<span style="margin-left: 2em">未詳者一一博引繁稱析其端委其蔡傳岐誤之</span>  
<span style="margin-left: 2em">處則不復糾正葢如孔頴達諸經正義主於發揮</span>  
<!-- 册1 葉1092a　Page:文淵閣四庫全書_0001冊.djvu/323 -->
<span style="margin-left: 2em">註文不主於攻駁註文也然不能以回䕶註文之</span>  
<span style="margin-left: 2em">故廢孔氏之疏則亦不能以回䕶蔡傳之故廢師</span>  
<span style="margin-left: 2em">凱之書矣知其有所遷就而節取所長可也</span>  
讀書管見二卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">元王充耘撰黃虞稷千頃堂書目稱充耘字與耕</span>  
<span style="margin-left: 2em">而原序及梅鶚跋並稱耕野疑虞稷誤也吉水人</span>  
<span style="margin-left: 2em">元統甲戌進士授承務郞同知永新州事後棄官</span>  
<span style="margin-left: 2em">養母著書授徒因成是編所說與蔡氏多異同其</span>  
<span style="margin-left: 2em">中如謂堯典乃舜典之緣起本爲一篇故曰虞書</span>

<span style="margin-left: 2em">謂九族旣睦旣當訓盡謂象以典刑爲各象其罪</span>

<span style="margin-left: 2em">亦未能條分縷析以抉其罅漏明梅鷟始參考諸</span>  
<span style="margin-left: 2em">書証其剽剟而見聞較狹蒐采未周至若璩乃引</span>  
<!-- 册1 葉1128a　Page:文淵閣四庫全書_0001冊.djvu/332 -->
<span style="margin-left: 2em">經據古一一陳其矛盾之故古文之僞乃大明所</span>  
<span style="margin-left: 2em">列一百二十八條毛奇齡作古文尚書寃詞百計</span>  
<span style="margin-left: 2em">相軋終不能以强詞奪正理則有據之言先立於</span>  
<span style="margin-left: 2em">不可敗也其書初成四卷餘姚黃宗羲序之其後</span>  
<span style="margin-left: 2em">四卷又所次第續成若璩没後傳寫佚其第三卷</span>  
<span style="margin-left: 2em">其二卷第二十八條二十九條三十條七卷第一</span>  
<span style="margin-left: 2em">百二條一百八條一百九條一百十條八卷第一</span>  
<span style="margin-left: 2em">百二十二條至一百二十七條皆有錄無書編次</span>  
<span style="margin-left: 2em">先後亦未歸條理葢猶草創之本其中偶爾未核</span>  
<!-- 册1 葉1128b　Page:文淵閣四庫全書_0001冊.djvu/332 -->
<span style="margin-left: 2em">者如據正義所載鄭元書序注謂馬鄭所傳與孔</span>  
<span style="margin-left: 2em">傳篇目不符其說最<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">至謂馬鄭注本亡於永嘉</span>  
<span style="margin-left: 2em">之亂則殊不然考二家之本隋志尚皆著錄稱所</span>  
<span style="margin-left: 2em">注凡二十九篇經典釋文備引之亦止二十九篇</span>  
<span style="margin-left: 2em">葢去其無師說者十六篇止得二十九篇與伏生</span>  
<span style="margin-left: 2em">數合非別有一本注孔氏書也若璩誤以鄭逸者</span>  
<span style="margin-left: 2em">卽爲所注之逸篇不免千慮之一失又史記漢書</span>  
<span style="margin-left: 2em">但有安國上古文尚書之說並無受詔作傳之事</span>  
<span style="margin-left: 2em">此僞本鑿空之顯證亦辨僞本者至要之肯綮乃</span>  
<!-- 册1 葉1129a　Page:文淵閣四庫全書_0001冊.djvu/332 -->
<span style="margin-left: 2em">置而未言亦稍疎畧其他諸條之後往往衍及旁</span>  
<span style="margin-left: 2em">文動盈卷帙葢慮所著潛邱剳記或不傳故附見</span>  
<span style="margin-left: 2em">於此究爲支蔓又前卷所論後卷往往自駁而不</span>  
<span style="margin-left: 2em">肯刪其前說雖仿鄭元注禮先用魯詩後不追改</span>  
<span style="margin-left: 2em">之意於體例亦究屬未安然反復釐剔以祛千古</span>  
<span style="margin-left: 2em">之大疑考證之學則固未之或先矣</span>

<span style="margin-left: 1em">國朝毛奇齡撰奇齡有仲氏易巳著錄其學淹貫羣</span>  
<span style="margin-left: 2em">書而好爲駁辨以求勝凡他人所巳言者必力反</span>

<span style="margin-left: 2em">其詞故儀禮十七篇古無異議惟章如愚山堂考</span>  
<span style="margin-left: 2em">索載樂史有五可疑之言後儒亦無信之者奇齡</span>  
<span style="margin-left: 2em">獨拾其緒論詆爲戰國之僞書古文尚書自吳棫</span>  
<span style="margin-left: 2em">朱子以來皆疑其僞及閻若璩作古文尚書疏証</span>  
<span style="margin-left: 2em">奇齡又力辨以爲眞知孔安國傳中有安國以後</span>  
<span style="margin-left: 2em">地名必不可掩於是別遁其詞摭隋書經籍志之</span>  
<span style="margin-left: 2em">文以爲梅賾所上者乃孔傳而非古文尚書其古</span>  
<span style="margin-left: 2em">文尚書本傳習人間而賈馬諸儒未之見其目一</span>  
<span style="margin-left: 2em">曰總論二曰今文尚書三曰古文尚書四曰古文</span>

<span style="margin-left: 2em">之寃始於朱氏五曰古文之寃成於吳氏<sub class="note-yuan">案吳棫書裨傳</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">在朱子稍前故朱子語錄述棫說當云始於吳氏成於朱氏此二目殊爲顚倒附識於此</sub>六曰</span>  
<span style="margin-left: 2em">書篇題之寃七曰書序之寃八曰書小序之寃九</span>  
<span style="margin-left: 2em">曰書詞之寃十曰書字之寃考隋書經籍志云晉</span>  
<span style="margin-left: 2em">世秘府存有古文尚書經文今無有傳者及永嘉</span>  
<span style="margin-left: 2em">之亂歐陽大小夏侯尚書並亡至東晉豫章內史</span>  
<span style="margin-left: 2em">梅賾始得安國之傳奏之其敘述偶未分明故爲</span>  
<span style="margin-left: 2em">奇齡所假借然隋志作於尚書正義之後其時古</span>  
<span style="margin-left: 2em">文方盛行而云無有傳者知東晉古文非指今本</span>

<span style="margin-left: 2em">且先云古文不傳而後云始得安國之傳知今本</span>  
<span style="margin-left: 2em">古文與安國傳俱出非卽東晉之古文奇齡安得</span>  
<span style="margin-left: 2em">離析其文以就巳說乎至若璩所引馬融書序云</span>  
<span style="margin-left: 2em">逸十六篇絶無師說又引鄭元所注十六篇之名</span>  
<span style="margin-left: 2em">爲舜典汨作九共大禹謨益稷五子之歌允征湯</span>  
<span style="margin-left: 2em">誥咸有一德典寶伊訓肆命原命武成旅獒冏命</span>  
<span style="margin-left: 2em">明與古文二十五篇截然不同奇齡不以今本不</span>  
<span style="margin-left: 2em">合馬鄭爲僞作古文之徵反以馬鄭不合今本爲</span>  
<span style="margin-left: 2em">未見古文之徵亦頗巧於顚倒然考僞孔傳序未</span>

<span style="margin-left: 2em">志著錄賈逵嘗校理秘書不應不見又司馬遷爲</span>  
<span style="margin-left: 2em">安國弟子劉歆嘗校七畧班固亦爲蘭臺令史典</span>  
<span style="margin-left: 2em">校藝文而遷史記儒林傳云孔氏有古文尚書安</span>  
<span style="margin-left: 2em">國以今文讀之逸書得多十餘篇歆移太常博士</span>

<span style="margin-left: 2em">奇齡所藉口者不過以隋志稱馬鄭所注二十九</span>

<span style="margin-left: 2em">孔氏之書奇齡舍史記漢書不據而據唐人之誤</span>
