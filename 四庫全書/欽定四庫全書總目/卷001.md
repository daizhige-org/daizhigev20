<span style="margin-left: 2em">經禀聖裁<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2618.svg?width=24" alt="四庫全書僻字第2618號（⿱乖一）" title="四庫全書僻字第2618號（⿱乖一）">型萬世删定之㫖如日中天無所容</span>

<span style="margin-left: 2em">二千年儒者沿波學凡六變其初專門授受遞禀</span>  
<span style="margin-left: 2em">師承非惟詁訓相傳莫敢同異卽篇章字句亦恪</span>  
<span style="margin-left: 2em">守所聞其學篤實謹嚴及其𡚁也拘王弼王肅稍</span>  
<span style="margin-left: 2em">持異議流風所扇或信或疑越孔賈啖趙以及北</span>  
<span style="margin-left: 2em">宋孫復劉敞等各自論說不相統攝及其𡚁也雜</span>

<span style="margin-left: 2em">洛閩繼起道學大昌擺落漢唐獨研義理凡經師</span>  
<span style="margin-left: 2em">舊說俱排斥以爲不足信其學務別是非及其𡚁</span>  
<span style="margin-left: 2em">也悍<sub class="note-yuan">如王柏吳澄攻駁經文動輒删改之類</sub>學脈旁分攀緣日衆驅</span>  
<span style="margin-left: 2em">除異已務定一尊自宋末以逮明初其學見異不</span>  
<span style="margin-left: 2em">遷及其𡚁也黨<sub class="note-yuan">如論語集註誤引包咸夏瑚商璉之說張存中四書通證卽闕此一</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">條以諱其誤又如王柏删國風三十二篇許謙疑之吳師道反以爲非之類</sub>主持太過</span>  
<span style="margin-left: 2em">勢有所偏才辨聰明激而橫决自明正德嘉靖以</span>  
<span style="margin-left: 2em">後其學各抒心得及其𡚁也肆<sub class="note-yuan">如王守仁之末派皆以狂禪解經之</sub></span>  
<span style="margin-left: 2em"><small>類</small>空談臆斷考證必疎於是博雅之儒引古義以</span>  
<!-- 册1 葉216a　Page:文淵閣四庫全書_0001冊.djvu/104 -->
<span style="margin-left: 2em">抵其隙</span>  
<span style="margin-left: 1em">國初諸家其學徵實不誣及其獘也瑣<sub class="note-yuan">如一字音訓動辨數百言</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">之類</sub>要其歸宿則不過漢學宋學兩家互爲勝<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3688.svg?width=24" alt="四庫全書僻字第3688號（負）" title="四庫全書僻字第3688號（負）">夫</span>  
<span style="margin-left: 2em">漢學具有根柢講學者以淺陋輕之不足服漢儒</span>  
<span style="margin-left: 2em">也宋學具有精微讀書者以空疎薄之亦不足服</span>  
<span style="margin-left: 2em">宋儒也消融門戸之見而各取所長則私心祛而</span>  
<span style="margin-left: 2em">公理出公理出而經義明矣葢經者非他卽天下</span>  
<span style="margin-left: 2em">之公理而巳今叅稽衆說務取持平各明去取之</span>  
<span style="margin-left: 2em">故分爲十類曰易曰書曰詩曰禮曰春秋曰孝經</span>  
<!-- 册1 葉216b　Page:文淵閣四庫全書_0001冊.djvu/104 -->
<span style="margin-left: 2em">曰五經總義曰四書曰樂曰小學</span>  
<span style="margin-left: 1em">經部一</span>  
<span style="margin-left: 2em">易類一</span>  
<span style="margin-left: 3em">聖人覺世牖民大抵因事以寓教詩寓於風謡</span>  
<span style="margin-left: 3em">禮寓於節文尚書春秋寓於史而易則寓於卜</span>  
<span style="margin-left: 3em">筮故易之爲書推天道以明人事者也左傳所</span>  
<span style="margin-left: 3em">記諸占葢猶太卜之遺法漢儒言象數去古未</span>  
<span style="margin-left: 3em">遠也一變而爲京焦入於禨祥再變而爲陳邵</span>  
<span style="margin-left: 3em">務窮造化易遂不切於民用王弼盡黜象數說</span>  
<!-- 册1 葉217a　Page:文淵閣四庫全書_0001冊.djvu/104 -->
<span style="margin-left: 3em">以老莊一變而胡瑗程子始闡明儒理再變而</span>  
<span style="margin-left: 3em">李光楊萬里又㕘證史事易遂日啓其論端此</span>  
<span style="margin-left: 3em">兩派六宗巳互相攻駁又易道廣大無所不包</span>  
<span style="margin-left: 3em">旁及天文地理樂律兵法韻學算術以逮方外</span>  
<span style="margin-left: 3em">之爐火皆可援易以爲說而好異者又援以人</span>  
<span style="margin-left: 3em">易故易說愈繁夫六十四卦大象皆有君子以</span>  
<span style="margin-left: 3em">字其爻象則多戒占者聖人之情見乎詞矣其</span>  
<span style="margin-left: 3em">餘皆易之一端非其本也今㕘校諸家以因象</span>  
<span style="margin-left: 3em">立教者爲宗而其他易外別傳者亦兼收以盡</span>  
<!-- 册1 葉217b　Page:文淵閣四庫全書_0001冊.djvu/104 -->
<span style="margin-left: 3em">其變各爲條論具列於左</span>  
子夏易傳十一卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">舊本題卜子夏撰按說易之家最古者莫若是書</span>  
<span style="margin-left: 2em">其僞中生僞至一至再而未巳者亦莫若是書唐</span>  
<span style="margin-left: 2em">會要載開元七年詔子夏易傳近無習者令儒官</span>  
<span style="margin-left: 2em">詳定劉知幾議曰漢志易有十三家而無子夏作</span>  
<span style="margin-left: 2em">傳者至梁阮氏七錄始有子夏易六卷或云韓嬰</span>  
<span style="margin-left: 2em">作或云丁寛作然據漢書韓易十二篇丁易八篇</span>  
<span style="margin-left: 2em">求其符合事殊隳刺必欲行用深以爲疑司馬貞</span>  
<!-- 册1 葉220a　Page:文淵閣四庫全書_0001冊.djvu/105 -->
<span style="margin-left: 2em">議亦曰按劉向七畧有子夏易傳但此書不行巳</span>  
<span style="margin-left: 2em">久今所存多失眞本荀朂中經簿云子夏傳四卷</span>  
<span style="margin-left: 2em">或云丁寛是先達疑非子夏矣又隋書經籍志云</span>  
<span style="margin-left: 2em">子夏傳殘缺梁六卷今二卷知其書錯謬多矣又</span>  
<span style="margin-left: 2em">王儉七志引劉向七畧云易傳子夏韓氏嬰也今</span>  
<span style="margin-left: 2em">題不稱韓氏而載薛虞記其質粗畧㫖趣非遠無</span>  
<span style="margin-left: 2em">益後學云云是唐以前所謂子夏傳巳爲僞本晁</span>  
<span style="margin-left: 2em">說之傳易堂記又稱今號爲子夏傳者乃唐張弧</span>  
<span style="margin-left: 2em">之易<sub class="note-yuan">按弧唐末爲大理寺評事有素履子別著錄</sub>是唐時又一僞本並</span>  
<!-- 册1 葉220b　Page:文淵閣四庫全書_0001冊.djvu/105 -->
<span style="margin-left: 2em">行故宋國史志以假託子夏易傳與眞子夏易傳</span>  
<span style="margin-left: 2em">兩列其目而崇文總目亦稱此書篇第畧依王氏</span>  
<span style="margin-left: 2em">决非卜子夏之文也朱彝尊經義考證以陸德明</span>  
<span style="margin-left: 2em">經典釋文李鼎祚周易集解王應麟困學紀聞所</span>  
<span style="margin-left: 2em">引皆今本所無德明鼎祚猶曰在張弧以前應麟</span>  
<span style="margin-left: 2em">乃南宋末人何以當日所見與今本又異然則今</span>  
<span style="margin-left: 2em">本又出僞託不但非子夏書亦並非張弧書矣流</span>  
<span style="margin-left: 2em">傳旣久姑存以備一家云爾</span>  
<span style="margin-left: 4em">謹按唐徐堅初學記以太宗御製升列歴代</span>  
<!-- 册1 葉221a　Page:文淵閣四庫全書_0001冊.djvu/105 -->
<span style="margin-left: 4em">之前葢臣子尊君之大義焦竑國史經籍志</span>  
<span style="margin-left: 4em">朱彝尊經義考並踵前規<small>臣</small>等編摩四庫初</span>

<span style="margin-left: 1em">國朝著述之首俾尊卑有序而時代不淆</span>  
聖度謙冲酌中立憲實爲千古之大公謹恪遵  
<!-- 册1 葉221b　Page:文淵閣四庫全書_0001冊.djvu/105 -->
彝訓仍託始於子夏易傳並發凡於此著四庫之通例  
<span style="margin-left: 4em">焉</span>  
<span style="margin-left: 4em">又案託名之書有知其贋作之人者有不知</span>  
<span style="margin-left: 4em">其贋作之人者不能一一歸其時代故漢書</span>  
<span style="margin-left: 4em">藝文志仍從其所託之時代爲次今亦悉從</span>  
<span style="margin-left: 4em">其例</span>  
周易鄭康成注一卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">宋王應麟編應麟字伯厚慶元人自署浚儀葢其</span>  
<span style="margin-left: 2em">祖籍也淳祐元年進士寶祐四年復中博學鴻詞</span>  
<!-- 册1 葉224a　Page:文淵閣四庫全書_0001冊.djvu/106 -->
<span style="margin-left: 2em">科官至禮部尚書兼給事中事迹具宋史儒林傳</span>  
<span style="margin-left: 2em">案隋志載鄭元周易注九卷又稱鄭元王弼二注</span>  
<span style="margin-left: 2em">梁陳列於國學齊代惟傳鄭義至隋王注盛行鄭</span>  
<span style="margin-left: 2em">學寖微然新唐書著錄十卷是唐時其書猶在故</span>  
<span style="margin-left: 2em">李鼎祚集解多引之宋崇文總目惟載一卷所存</span>  
<span style="margin-left: 2em">者僅文言序卦說卦雜卦四篇餘皆散佚至中興</span>  
<span style="margin-left: 2em">書目始不著錄<sub class="note-yuan">案中興書目今不傳此據馮椅易學所引</sub>則亡於南北</span>  
<span style="margin-left: 2em">宋之間故晁說之朱震尚能見其遺文而淳熙以</span>  
<span style="margin-left: 2em">後諸儒卽罕所稱引也應麟始旁摭諸書裒爲此</span>  
<!-- 册1 葉224b　Page:文淵閣四庫全書_0001冊.djvu/106 -->
<span style="margin-left: 2em">帙經文異字亦皆並存其無經文可綴者則總錄</span>  
<span style="margin-left: 2em">末簡又以元注多言互體並取左傳禮記周禮正</span>  
<span style="margin-left: 2em">義中論互體者八條以類附焉考元初從第五元</span>  
<span style="margin-left: 2em">先受京氏易又從馬融受費氏易故其學出入於</span>  
<span style="margin-left: 2em">兩家然要其大㫖費義居多實爲傳易之正脈齊</span>  
<span style="margin-left: 2em">陸澄與王儉書曰王弼注易元學之所宗今若崇</span>  
<span style="margin-left: 2em">儒鄭注不可廢其論最篤唐初詔修正義仍黜鄭</span>  
<span style="margin-left: 2em">崇王非達識也應麟能於散佚之餘蒐羅放失以</span>  
<span style="margin-left: 2em">存漢易之一綫可謂篤志遺經研心古義者矣近</span>  
<!-- 册1 葉225a　Page:文淵閣四庫全書_0001冊.djvu/106 -->
<span style="margin-left: 2em">時惠棟別有考訂之本體例較密然經營剏始實</span>  
<span style="margin-left: 2em">自應麟其捃拾之勞亦不可冺今並著於錄所以</span>  
<span style="margin-left: 2em">兩存其功也</span>  
<span style="margin-left: 4em">謹按前代遺書後人重編者如有所竄改增</span>  
<span style="margin-left: 4em">益則從重編之時代曾子子思子之類是也</span>  
<span style="margin-left: 4em">如全輯舊文則仍從原書之時代故此書雖</span>  
<span style="margin-left: 4em">宋人所輯而列於漢代之次後皆倣此</span>  
新本鄭氏周易三卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 1em">國朝惠棟編棟字定宇長洲人初王應麟輯鄭元易</span>  
<!-- 册1 葉225b　Page:文淵閣四庫全書_0001冊.djvu/106 -->
<span style="margin-left: 2em">注一卷其後人附刻玉海之末雖殘章斷句尚頗</span>  
<span style="margin-left: 2em">見漢學之崖畧於經籍頗爲有功然皆不著所出</span>  
<span style="margin-left: 2em">之書又次序先後間與經文不應亦有遺漏未載</span>  
<span style="margin-left: 2em">者棟因其舊本重爲補正凡應麟書所巳載者一</span>  
<span style="margin-left: 2em">一考求原本注其出自某書明其信而有徵極爲</span>  
<span style="margin-left: 2em">詳核其次序先後亦悉從經文釐定復搜採羣籍</span>  
<span style="margin-left: 2em">上經補二十八條下經補十六條繫辭傳補十四</span>  
<span style="margin-left: 2em">條說卦傳補二十二條序卦傳補七條雜卦傳補</span>  
<span style="margin-left: 2em">五條移應麟所附易贊一篇於卷端刪去所引諸</span>  
<!-- 册1 葉228a　Page:文淵閣四庫全書_0001冊.djvu/107 -->
<span style="margin-left: 2em">經正義論互卦者八條而别據元周禮太師注作</span>  
<span style="margin-left: 2em">十二月爻辰圖據元月令注作爻辰所値二十八</span>  
<span style="margin-left: 2em">宿圖附於卷末以駁朱震漢上易傳之誤雖因人</span>  
<span style="margin-left: 2em">成事而考核精密實勝原書應麟固鄭氏之功臣</span>  
<span style="margin-left: 2em">棟之是編亦可謂王氏之功臣矣</span>  
陸氏易解一卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">明姚士粦所輯吳陸績周易注也吳志載績所著</span>  
<span style="margin-left: 2em">有易注不言卷數隋書經籍志有陸績周易注十</span>  
<span style="margin-left: 2em">五卷經典釋文序錄作陸績周易述十三卷會通</span>
