<span style="margin-left: 1em">史部三十一</span>  
<span style="margin-left: 2em">地理𩔖存目四</span>  
河源記一巻<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">元潘昻霄撰昻霄字景樑號蒼崖濟南人官至翰</span>  
<span style="margin-left: 2em">林侍讀學士諡文僖是書紀世祖至元十七年遣</span>  
<span style="margin-left: 2em">篤什西溯河源至星宿海事末有元統中柯九思</span>  
<span style="margin-left: 2em">跋元史巳全錄其文此其别行之本也河源遠隔</span>  
<span style="margin-left: 2em">窮荒前志傳聞率皆瞽說惟篤什嘗親厯其地故</span>  
<!-- 册2 葉2305b　Page:文淵閣四庫全書_0002冊.djvu/581 -->
<span style="margin-left: 2em">昻霄以聞於其弟庫克楚<sub class="note-yuan">原作濶濶出今改正</sub>者記爲是編</span>  
<span style="margin-left: 2em">自詫爲古所未睹迨我</span>  
皇上神武遠揚平定西域揆度水脉規量地形又知篤  
<span style="margin-left: 2em">什所言仍多疎漏巳重爲考定勒在鴻編川以祛</span>  
<span style="margin-left: 2em">萬古之疑而訂百世之謬昻霄是記竟以故紙置</span>  
<span style="margin-left: 2em">之可矣</span>  
浙西水利議答十卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">一名水利文集元任仁發撰仁發松江人仕至都</span>  
<span style="margin-left: 2em">水少監明梁惟樞内閣書目云大德間都水少監</span>  
<!-- 册2 葉2308a　Page:文淵閣四庫全書_0002冊.djvu/582 -->
<span style="margin-left: 2em">任仁發以吳松江故道陻塞震澤汎濫爲浙西害</span>  
<span style="margin-left: 2em">乃上疏條利病疏導之法凡十卷前有仁發自序</span>  
<span style="margin-left: 2em">又有許約趙某二跋末附宋郟亶及其子喬水利</span>  
<span style="margin-left: 2em">議約跋稱歲甲辰中書以其議上聞命中書省平</span>  
<span style="margin-left: 2em">章政事董是役由是震澤無壅與三江之𫝑接復</span>  
<span style="margin-left: 2em">朝於海趙某跋稱是錄所載其要有三一曰濬江</span>  
<span style="margin-left: 2em">河以洩水二曰築堤岸以障水三曰置牐竇以限</span>  
<span style="margin-left: 2em">水云</span>  
海道經一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<!-- 册2 葉2308b　Page:文淵閣四庫全書_0002冊.djvu/582 -->
<span style="margin-left: 2em">不著撰人名氏惟書中揚子江一條自稱其名曰</span>  
<span style="margin-left: 2em">璚其姓則不可考前有明嘉靖中應良序疑爲元</span>  
<span style="margin-left: 2em">初人所撰而後人增修之今觀書末附朱晞顔鯨</span>  
<span style="margin-left: 2em">背吟三十三首晞顔爲元人則此書亦出元人可</span>  
<span style="margin-left: 2em">知矣其書言海路要害及占風雨潮汐諸事大抵</span>  
<span style="margin-left: 2em">皆爲海運而作其後歌訣與今人所說亦同然未</span>  
<span style="margin-left: 2em">免失之於太簡</span>  
海道經一卷<sub class="note-yuan">戸部尚書王際華家藏本</sub>  
<span style="margin-left: 2em">不著撰人名氏紀海運道里之數自南京厯劉家</span>

<span style="margin-left: 2em">占虹占霧占電占海占潮各門蓋航海以風色爲</span>

<span style="margin-left: 2em">雖不文而語頗可據考海運惟元代有之則亦元</span>  
<span style="margin-left: 2em">人書也後有海道指南圖乃龍江至<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">沽針路嘉</span>  
<span style="margin-left: 2em">靖中袁褧以二本㕘校刻入所編金聲玉振集復</span>  
<span style="margin-left: 2em">錄元延祐間海道都漕運萬戸府海運則例圖至</span>  
<span style="margin-left: 2em">正間周伯琦供祀記二碑附於其末</span>  
<!-- 册2 葉2309b　Page:文淵閣四庫全書_0002冊.djvu/582 -->
治河總考四卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明車璽撰璽宛平人成化戊戌進士官至河南按</span>  
<span style="margin-left: 2em">察司僉事是編考厯代治河之事以時代先後爲</span>  
<span style="margin-left: 2em">次始周定王終明嘉靖十七年又以禹貢史記河</span>  
<span style="margin-left: 2em">渠書漢書溝洫志元史河源附錄宋濓治河議河</span>  
<span style="margin-left: 2em">南總志諸條列後其標題又稱山東兖州府同知</span>  
<span style="margin-left: 2em">陳銘續編前後無序跋不知孰爲璽之原書孰爲</span>  
<span style="margin-left: 2em">銘之所補體例參差刊刻拙陋蓋當時書帕本也</span>  
漕河圖志三卷<sub class="note-yuan">浙江鄭大節家藏本</sub>  
<!-- 册2 葉2312a　Page:文淵閣四庫全書_0002冊.djvu/583 -->
<span style="margin-left: 2em">明王瓊撰瓊有晉溪奏議巳著錄先是成化間三</span>  
<span style="margin-left: 2em">原王恕作漕河通志十四卷宏治九年瓊以工部</span>  
<span style="margin-left: 2em">郞中管理河道乃因恕之書而增損之首載漕河</span>  
<span style="margin-left: 2em">圖次紀河之脉絡源委及古今變遷修治經費以</span>  
<span style="margin-left: 2em">逮奏議碑記罔不具悉明史本傳稱瓊出治漕河</span>  
<span style="margin-left: 2em">三年臚其事爲志繼任者按稽之不爽毫髪由是</span>  
<span style="margin-left: 2em">以敏練稱蓋其書之切於實用如此惜原本八卷</span>  
<span style="margin-left: 2em">此本止存三卷非完帙矣</span>  
間水集三卷<sub class="note-yuan">浙江鄭大節家藏本</sub>  
<!-- 册2 葉2312b　Page:文淵閣四庫全書_0002冊.djvu/583 -->

<span style="margin-left: 2em">徙天和以右副都御史總理河道乃疏汴河自朱</span>  
<span style="margin-left: 2em">仙鎭至沛縣飛雲橋又疏山東七十二泉自鳬尼</span>  
<span style="margin-left: 2em">諸山達南旺河役夫二萬不三月訖工詔加工部</span>  
<span style="margin-left: 2em">侍郞此書蓋據其按視所至形勢利害及處置事</span>  
<span style="margin-left: 2em">宜詳述之以示後人一卷末有治河本末一篇爲</span>  
<span style="margin-left: 2em">工部都水郞中郾城楊旦所作以紀天和之績後</span>  
<span style="margin-left: 2em">四卷則皆其前後奏議之文也</span>  
通惠河志二卷附錄一卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<!-- 册2 葉2313a　Page:文淵閣四庫全書_0002冊.djvu/583 -->
<span style="margin-left: 2em">明吳仲撰仲字亞甫武進人正德丁丑進士官至</span>

<span style="margin-left: 2em">明初湮廢糧皆由陸以運費重民勞仲以御史巡</span>  
<span style="margin-left: 2em">按<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">隸疏請重濬不數月工成遂至今爲永利其</span>  
<span style="margin-left: 2em">事詳見明史後仲外調處州時恐久而其法寖弛</span>  
<span style="margin-left: 2em">故於舟中撰此書奏進得㫖刊行上卷載閘壩建</span>  
<span style="margin-left: 2em">置開濬事宜而冠以源委圖說中卷及附錄皆諸</span>  
<span style="margin-left: 2em">司奏疏下卷皆碑記詩章也</span>  
三吳水利論一卷<sub class="note-yuan">戸部尚書王際華家藏本</sub>  
<!-- 册2 葉2313b　Page:文淵閣四庫全書_0002冊.djvu/583 -->
<span style="margin-left: 2em">明伍餘福撰餘福有陜西志巳著錄是書凡分八</span>  
<span style="margin-left: 2em">篇一論五堰二論九陽江三論夾苧干四論荊溪</span>  
<span style="margin-left: 2em">五論百瀆六論七十三漊七論長橋百洞八論震</span>  
<span style="margin-left: 2em">澤皆吳中水利要害大㫖本宋單鍔所論而推廣</span>  
<span style="margin-left: 2em">之</span>  
新河初議一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>

<!-- 册2 葉2316a　Page:文淵閣四庫全書_0002冊.djvu/584 -->

<span style="margin-left: 2em">情形因上疏與應期議合興役<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2618.svg?width=24" alt="四庫全書僻字第2618號（⿱乖一）" title="四庫全書僻字第2618號（⿱乖一）">成爲言者所沮</span>

<span style="margin-left: 2em">人嘉靖癸未進士官山東巡察海運副使初元時</span>
