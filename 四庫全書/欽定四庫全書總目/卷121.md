## 欽定四庫全書總目 卷一百二十一　子部三十一　雜家類五

<!-- 册3 葉2452：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷一百二十一  
<span style="margin-left: 1em">子部三十一</span>  
<span style="margin-left: 2em">雜家𩔖五</span>  
曲洧舊聞十卷<sub class="note-yuan">浙江汪汝瑮家藏本</sub>  
<span style="margin-left: 2em">宋朱弁撰弁字少張朱子之從父也事迹具宋史</span>  
<span style="margin-left: 2em">本傳文獻通攷載弁曲洧舊聞一卷襍書一卷骩</span>  
<span style="margin-left: 2em">骳說一卷此本獨曲洧舊聞已十卷然此本從宋</span>  
<span style="margin-left: 2em">槧影鈔毎卷末皆有臨安府太廟前尹家書籍舖</span>  
<span style="margin-left: 2em">刋字又惇字避光宗諱皆缺筆葢南宋舊刋不應</span>  
<!-- 册3 葉2453b　Page:文淵閣四庫全書_0003冊.djvu/618 -->
<span style="margin-left: 2em">有誤必通攷訛十卷爲一卷也案弁以建炎丁未</span>  
<span style="margin-left: 2em">使金被留越十七年乃歸而書中有臘月八日淸</span>  
<span style="margin-left: 2em">凉山見佛光事云嵗在甲寅又記秘魔崖事其地</span>  
<span style="margin-left: 2em">在燕京又記其友述定光佛語云俘囚十年則書</span>  
<span style="margin-left: 2em">當作於留金時然皆追述北宋遺事無一語及金</span>  
<span style="margin-left: 2em">故曰舊聞通考列之小說家今考其書惟神怪諧</span>  
<span style="margin-left: 2em">謔數條不脫小說之體其餘則多記當時祖宗盛</span>  
<span style="margin-left: 2em">德及諸名臣言行而於王安石之變法蔡京之紹</span>  
<span style="margin-left: 2em">述分朋角立之故言之尤詳葢意在申明北宋一</span>  
<!-- 册3 葉2456a　Page:文淵閣四庫全書_0003冊.djvu/619 -->
<span style="margin-left: 2em">代興衰治亂之由深於史事有補實非小說家流</span>  
<span style="margin-left: 2em">也惟其中間及詩話文評及諸考證不名一格不</span>  
<span style="margin-left: 2em">可目以襍史故今改入之襍家𩔖焉</span>  
元城語錄三卷附行録一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">元城語錄三卷宋馬永卿編永卿字大年揚州人</span>  
<span style="margin-left: 2em">流寓鉛山據廣信府志知其嘗登大觀三年進士</span>  
<span style="margin-left: 2em">據所作嬾眞子知嘗官江都丞浙川令夏縣令又</span>  
<span style="margin-left: 2em">稱嘗官關中則不知何官矣徽宗初劉安世與蘇</span>  
<span style="margin-left: 2em">軾同北歸大觀中寄居永城永卿方爲主簿受學</span>  
<!-- 册3 葉2456b　Page:文淵閣四庫全書_0003冊.djvu/619 -->
<span style="margin-left: 2em">於安世因撰集其語爲此書安世之學出於司馬</span>  
<span style="margin-left: 2em">光故多有光之遺說惟光有疑孟而安世則篤信</span>  
<span style="margin-left: 2em">之亦足見君子之交不爲苟同矣其中藝祖製薰</span>  
<span style="margin-left: 2em">籠一事周必大玉堂襍記謂其以元豐後之官制</span>  
<span style="margin-left: 2em">加之藝袓之時失於附會然安世非妄語者或記</span>  
<span style="margin-left: 2em">憶偶未<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">耳李心傳道命錄又論其記程子諫折</span>  
<span style="margin-left: 2em">柳事爲虛謂程子除說書在三月四月二日方再</span>  
<span style="margin-left: 2em">具辭免四月上旬非發生之時云云然四月上旬</span>  
<span style="margin-left: 2em">與三月相去幾何執此以斷必無方春萬物發生</span>  
<!-- 册3 葉2457a　Page:文淵閣四庫全書_0003冊.djvu/619 -->
<span style="margin-left: 2em">不可𢦤折之語則强辨非正理矣安世風裁嶽嶽</span>  
<span style="margin-left: 2em">氣節震動天下朱子作名臣言行錄於王安石呂</span>  
<span style="margin-left: 2em">惠卿皆有所節取乃獨不錄安世董復亨繁露園</span>  
<span style="margin-left: 2em">集有是書序曰朱文公名臣言行錄不載先生殊</span>  
<span style="margin-left: 2em">不可解及閱宋史然後知文公所以不錄先生者</span>  
<span style="margin-left: 2em">大都有三葢先生嘗上疏論程正叔且與蘇文忠</span>  
<span style="margin-left: 2em">交好又好談禪文公左袒正叔不與文忠至禪則</span>  
<span style="margin-left: 2em">又心薄力拒者以故不錄其說不爲無因是亦識</span>  
<span style="margin-left: 2em">微之論然道命錄備載孔平仲諸人彈論程子疏</span>  
<!-- 册3 葉2457b　Page:文淵閣四庫全書_0003冊.djvu/619 -->
<span style="margin-left: 2em">議以示譏貶獨不載安世之疏不過於孔平仲條</span>  
<span style="margin-left: 2em">下附論其不知伊川而已葢亦知安世之人品世</span>  
<span style="margin-left: 2em">所共信不可動摇未敢醜詆之也近時有安邱劉</span>  
<span style="margin-left: 2em">源淥者作冷語三卷掇拾伊洛之糟粕乃以衞道</span>  
<span style="margin-left: 2em">爲名肆言排擊指安世爲邪人謂其罪甚於章惇</span>  
<span style="margin-left: 2em">邢恕豈非但有朋黨之見絶無是非之心者歟要</span>  
<span style="margin-left: 2em">之安世心事如青天白日非源淥一人所能障蔽</span>  
<span style="margin-left: 2em">衆目也行錄一卷明崔銑所續編大名兵備副使</span>  
<span style="margin-left: 2em">於文熙又補綴其文舊本附語錄之末今亦並存</span>  
<!-- 册3 葉2460a　Page:文淵閣四庫全書_0003冊.djvu/620 -->
<span style="margin-left: 2em">之庶讀者知安世之行益知證安世之言焉至語</span>  
<span style="margin-left: 2em">錄之中時有似渉於禪者此在程門高弟游楊吕</span>  
<span style="margin-left: 2em">謝之徒朱子亦譏其有此獘是不必獨爲安世責</span>  
<span style="margin-left: 2em">亦不必更爲安世諱矣</span>  
嬾眞子五卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋馬永卿撰是編乃其雜記之書然亦多述劉安</span>  
<span style="margin-left: 2em">世語又開卷冠以司馬光事書中亦多稱光蓋其</span>  
<span style="margin-left: 2em">淵源所自岀也宋史藝文志著錄晁陳二家書目</span>  
<span style="margin-left: 2em">乃皆不載然袁文爲建災紹興間人王楙爲慶元</span>  
<!-- 册3 葉2460b　Page:文淵閣四庫全書_0003冊.djvu/620 -->
<span style="margin-left: 2em">嘉泰間人費袞爲紹熙開禧間人文甕牖閒評駁</span>  
<span style="margin-left: 2em">其中印文五字一條楙野客叢書駁其中承露<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3615.svg?width=24" alt="四庫全書僻字第3615號（囊）" title="四庫全書僻字第3615號（囊）"></span>  
<span style="margin-left: 2em">一條袞梁溪漫志駁其漢太公無名母媪無姓一</span>  
<span style="margin-left: 2em">條是其書未嘗不行於世特二家偶遺之耳其書</span>  
<span style="margin-left: 2em">末稱紹興六年蓋成於南渡以後中間頗及雜事</span>  
<span style="margin-left: 2em">而考證之文爲多如據漢書王嘉封事謂書無教</span>  
<span style="margin-left: 2em">逸欲有<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3771.svg?width=24" alt="四庫全書僻字第3771號（邦）" title="四庫全書僻字第3771號（邦）">教當作敖謂陶潛游斜川詩開嵗倐五</span>  
<span style="margin-left: 2em">十當作五日與殷晉安别詩本十韻傳本誤脫一</span>  
<span style="margin-left: 2em">韻東坡亦誤和九韻謂杜甫詩虬鬚十八九字岀</span>  
<!-- 册3 葉2461a　Page:文淵閣四庫全書_0003冊.djvu/620 -->
<span style="margin-left: 2em">漢書丙吉傳謂韓愈感二鳥賦序貞元十一年誤</span>  
<span style="margin-left: 2em">作十五年又考正曹成王碑衍文訛字及箋釋句</span>  
<span style="margin-left: 2em">讀謂前漢百官表少府之遵官據唐百官志當作</span>  
<span style="margin-left: 2em">導官謂成元英莊子疏不知其時已有縣令誤讀</span>  
<span style="margin-left: 2em">縣爲懸解爲高名令聞謂古者席面之賔乃稱客</span>  
<span style="margin-left: 2em">列座之賔皆稱旅引左傳爲證謂二十八宿中亢</span>  
<span style="margin-left: 2em">氐觜三星韻略皆誤音謂賜酺始趙武靈王謂河</span>  
<span style="margin-left: 2em">鼓之河當作何謂唐中興頌復復指期復復字本</span>  
<span style="margin-left: 2em">漢書匡衡傳皆引据<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">鑿不同臆說其謂離騷正</span>  
<!-- 册3 葉2461b　Page:文淵閣四庫全書_0003冊.djvu/620 -->
<span style="margin-left: 2em">則靈均乃小名小字雖無所考亦足以備一解惟</span>  
<span style="margin-left: 2em">頗參襍以二氏至謂韓愈亦深明佛理是亦安世</span>  
<span style="margin-left: 2em">之學喜談禪悅之餘𣲖存而不論可矣</span>  
春渚紀聞十卷<sub class="note-yuan">江西巡撫採進本</sub>  
<span style="margin-left: 2em">宋何薳撰薳浦城人自號韓靑老農其書分襍記</span>  
<span style="margin-left: 2em">五卷東坡事實一卷詩詞事畧一卷雜書琴事附</span>  
<span style="margin-left: 2em">墨說一卷記研一卷記丹藥一卷明陳繼儒秘笈</span>  
<span style="margin-left: 2em">所刋僅前五卷乃姚士粦得於沈虎臣者後毛晉</span>  
<span style="margin-left: 2em">得舊本補其脫遺始爲完書卽此本也薳父曰去</span>  
<!-- 册3 葉2464a　Page:文淵閣四庫全書_0003冊.djvu/621 -->
<span style="margin-left: 2em">非嘗以蘇軾薦得官故記軾事特詳其雜記多引</span>  
<span style="margin-left: 2em">仙<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">報應兼及𤨏事如稱劉仲甫奕棋無敵又記</span>  
<span style="margin-left: 2em">祝不疑勝之兩條自相矛盾殊爲不檢又蔡絛鐵</span>  
<span style="margin-left: 2em">圍山叢談稱前以奕勝仲甫者爲王憨子後以奕</span>  
<span style="margin-left: 2em">勝仲甫者爲晉士明與祝不疑之說亦不合殆傳</span>  
<span style="margin-left: 2em">聞異詞歟張有爲張先之孫所作復古編今尙有</span>  
<span style="margin-left: 2em">傳本而此書乃作章有則或傳寫之訛非薳之舊</span>  
<span style="margin-left: 2em">也</span>  
石林燕語十卷<sub class="note-yuan">永樂大典本</sub>  
<!-- 册3 葉2464b　Page:文淵閣四庫全書_0003冊.djvu/621 -->
<span style="margin-left: 2em">宋葉夢得撰夢得有春秋傳已著錄夢得爲紹聖</span>  
<span style="margin-left: 2em">舊人徽宗時嘗司綸誥於朝章國典夙所究心故</span>  
<span style="margin-left: 2em">是書纂述舊聞皆有關當時掌故於官制科目言</span>  
<span style="margin-left: 2em">之尤詳頗足以補史傳之闕與宋敏求春明退朝</span>  
<span style="margin-left: 2em">錄徐度却掃編可相表裏陳振孫書錄解題謂其</span>  
<span style="margin-left: 2em">書成於宣和五年然其中論館伴金使一條稱建</span>  
<span style="margin-left: 2em">炎三年又論宰相一條謂自元祐五年至今紹興</span>  
<span style="margin-left: 2em">六年則書成於南渡之後振孫之說未核矣惟夢</span>  
<span style="margin-left: 2em">得當南北宋間戈甲倥偬圖籍散佚或有記憶失</span>  
<!-- 册3 葉2465a　Page:文淵閣四庫全書_0003冊.djvu/621 -->
<span style="margin-left: 2em">眞考據未詳之處故汪應辰嘗作石林燕語辨而</span>  
<span style="margin-left: 2em">成都宇文紹奕<sub class="note-yuan">案維奕始末無考嘉定中有樞密使宇文紹節疑其昆弟</sub>亦作</span>  
<span style="margin-left: 2em">考異以糾之應辰之書陳振孫已稱未見葢宋末</span>  
<span style="margin-left: 2em">傳本卽稀僅儒學警悟<sub class="note-yuan">案儒學警悟亦南宋之書不著撰人姓氏</sub>間引</span>  
<span style="margin-left: 2em">數條與紹奕考異同散見永樂大典中然寥寥無</span>  
<span style="margin-left: 2em">幾難以成編惟紹奕之書尙可裒集謹蒐采考校</span>  
<span style="margin-left: 2em">各附夢得書本條之下雖其間傳聞年月之訛繕</span>  
<span style="margin-left: 2em">寫字畫之誤一一毛舉或不免有意吹求頗𩔖劉</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3271.svg?width=24" alt="四庫全書僻字第3271號（炫）" title="四庫全書僻字第3271號（炫）">之規杜預吳縝之糾歐陽修而援引舊文辨駁</span>  
<!-- 册3 葉2465b　Page:文淵閣四庫全書_0003冊.djvu/621 -->
<span style="margin-left: 2em">詳<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">者十之八九是一朝故事得夢得之書而梗</span>  
<span style="margin-left: 2em">槩俱存得紹奕之書而考證益宻二書相輔而行</span>  
<span style="margin-left: 2em">於史學彌爲有裨矣又夢得之書宋槧罕覯前明</span>  
<span style="margin-left: 2em">有大字刋本摹印亦稀世行毛晉津逮秘書所載</span>  
<span style="margin-left: 2em">脫悞頗多而商維濬稗海所載蹖駁尤甚今併叅</span>  
<span style="margin-left: 2em">驗諸本以永樂大典所載詳爲勘校訂訛補闕以</span>  
<span style="margin-left: 2em">歸完善凡所𨤲正各附案語於下方用正俗刻之</span>  
<span style="margin-left: 2em">訛庶幾稍還舊觀不失其眞焉</span>
