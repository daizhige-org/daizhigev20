## 欽定四庫全書總目 卷一百四十三　子部五十三　小說家類存目一

<!-- 册3 葉4064：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷一百四十三  
<span style="margin-left: 1em">子部五十三</span>  
<span style="margin-left: 2em">小說家𩔖存目一</span>  
燕丹子三卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">不著撰人名氏所載皆燕太子丹事漢志法家有</span>  
<span style="margin-left: 2em">燕十事十篇注曰不知作者雜家有荆軻論五篇</span>  
<span style="margin-left: 2em">注曰司馬相如等論荆軻事無燕丹子之名至隋</span>  
<span style="margin-left: 2em">書經籍志始著錄於小說家唐李善注文選始援</span>  
<span style="margin-left: 2em">引其文是其書在唐以前又史記刺客列傳曰世</span>  
<!-- 册3 葉4065b　Page:文淵閣四庫全書_0003冊.djvu/1021 -->
<span style="margin-left: 2em">言荆軻其稱太子之命天雨粟馬生角也太過其</span>  
<span style="margin-left: 2em">文見此書中而裴駰集解不引此書司馬貞索隱</span>  
<span style="margin-left: 2em">曰風俗通及諭衡皆有此說仍云廐門木象生肉</span>  
<span style="margin-left: 2em">足也亦不引此書註家引書以在前者爲據知此</span>  
<span style="margin-left: 2em">書在應劭王充後矣史記正義引田光論夏扶宋</span>  
<span style="margin-left: 2em">意秦舞陽事又引秦王乞聽琴事均作燕太子索</span>  
<span style="margin-left: 2em">隱引進金丸膾馬肝等事亦作燕太子殆傳寫異</span>  
<span style="margin-left: 2em">文歟宋志尚著於錄至明遂佚故馬驌作驛史稱</span>  
<span style="margin-left: 2em">魯連子燕丹子之𩔖或眞或僞今皆亡其所輯秦</span>  
<!-- 册3 葉4068a　Page:文淵閣四庫全書_0003冊.djvu/1022 -->
<span style="margin-left: 2em">事引燕太子凡十條大抵本之文選注太平御覽</span>  
<span style="margin-left: 2em">諸書字句亦頗多舛異今檢永樂大典載有全本</span>  
<span style="margin-left: 2em">葢明初尚存然其文實割裂諸書燕丹荆軻事雜</span>  
<span style="margin-left: 2em">綴而成其可信者已見史記其他多鄙誕不可信</span>  
<span style="margin-left: 2em">殊無足採謹仰遵</span>  
聖訓附存其目隋志作一卷唐志宋志及文獻通考並  
<span style="margin-left: 2em">作三卷永樂大典所載併爲一卷而實作三篇故</span>  
<span style="margin-left: 2em">今仍以三卷著錄焉</span>  
漢襍事秘辛一卷<sub class="note-yuan">内府藏本</sub>  
<!-- 册3 葉4068b　Page:文淵閣四庫全書_0003冊.djvu/1022 -->
<span style="margin-left: 2em">不著撰人名氏楊愼序稱得於安寧土知州萬氏</span>  
<span style="margin-left: 2em">沈德符敝帚軒剩語曰卽愼所僞作也叙漢桓帝</span>  
<span style="margin-left: 2em">懿德皇后被選及冊立之事其與史舛謬之處明</span>  
<span style="margin-left: 2em">胡震亨姚士粦二䟦辨之甚詳其文淫豔亦𩔖傳</span>  
<span style="margin-left: 2em">奇漢人無是體裁也</span>  
飛燕外傳一卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">舊本題漢伶元撰末有元自敘稱字子于潞水人</span>  
<span style="margin-left: 2em">由司空小吏厯三署刺守州郡爲淮南相其妾樊</span>  
<span style="margin-left: 2em">通德爲樊嬺弟子不周之子能道飛燕姊弟故事</span>  
<!-- 册3 葉4069a　Page:文淵閣四庫全書_0003冊.djvu/1022 -->
<span style="margin-left: 2em">於是撰趙后别傳其文纎靡不類西漢人語序末</span>  
<span style="margin-left: 2em">又稱元爲河東都尉時辱班彪之從父躅故彪續</span>  
<span style="margin-left: 2em">史記不見收錄其文不相屬亦不𩔖元所自言後</span>  
<span style="margin-left: 2em">又載桓譚語一則言更始二年劉恭得其書於茂</span>  
<span style="margin-left: 2em">陵卞理建武二年賈子翊以示譚所稱埋藏之金</span>  
<span style="margin-left: 2em">縢漆匱者似不應如此之珍貴又載荀朂校書奏</span>  
<span style="margin-left: 2em">一篇中經簿所錄今不可考然所校他書無載朂</span>  
<span style="margin-left: 2em">奏者何獨此書有之又首尾僅六十字亦無此體</span>  
<span style="margin-left: 2em">大抵皆出於依託且閨幃媟䙝之狀嬺雖親狎無</span>  
<!-- 册3 葉4069b　Page:文淵閣四庫全書_0003冊.djvu/1022 -->
<span style="margin-left: 2em">目擊理卽萬一竊得之亦無娓娓爲通德縷陳理</span>  
<span style="margin-left: 2em">其僞妄殆不疑也晁公武頗信之陳振孫雖有或</span>  
<span style="margin-left: 2em">云僞書之說而又云通德擁髻等事文士多用而</span>  
<span style="margin-left: 2em">禍水滅火之語司馬公載之通鑑夫文士引用不</span>  
<span style="margin-left: 2em">爲典據采淖方成語以入史自是通鑑之失乃援</span>  
<span style="margin-left: 2em">以證實是書紕繆殊甚且禍水滅火其語亦有可</span>  
<span style="margin-left: 2em">疑考王懋竑白田襍著有漢火德考曰漢初用赤</span>  
<span style="margin-left: 2em">帝子之祥旗幟尚赤而自有天下後仍襲秦舊故</span>  
<span style="margin-left: 2em">張蒼以爲水德孝文帝時公孫臣言當改用士德</span>  
<!-- 册3 葉4072a　Page:文淵閣四庫全書_0003冊.djvu/1023 -->
<span style="margin-left: 2em">色尚黃其事未行至孝武帝改正朔色尚黃印章</span>  
<span style="margin-left: 2em">以五字則用公孫臣之說也王莽簒位自以黃帝</span>  
<span style="margin-left: 2em">之後當爲士德而用劉歆之說盡改從前相承之</span>  
<span style="margin-left: 2em">序以漢爲火德後漢重圖䜟以赤伏符之文改用</span>  
<span style="margin-left: 2em">火德班固作志遂以著之高帝紀而後漢人作飛</span>  
<span style="margin-left: 2em">燕外傳<sub class="note-yuan">案懋竑此語尚以此傳爲眞出伶元葢未詳考</sub>有禍水滅火之語</span>  
<span style="margin-left: 2em">不知前漢自王莽劉歆以前未有以漢爲火德者</span>  
<span style="margin-left: 2em">葢其誤也云云據此則班固在莽歆之後沿誤尙</span>  
<span style="margin-left: 2em">爲有因淖方成在莽歆之前安得預有滅火之說</span>  
<!-- 册3 葉4072b　Page:文淵閣四庫全書_0003冊.djvu/1023 -->
<span style="margin-left: 2em">其爲後人依託卽此二語亦可以見安得以通鑑</span>  
<span style="margin-left: 2em">誤引遂指爲眞古書哉</span>  
<span style="margin-left: 4em">案此書記飛燕姊妹始末實傳記之𩔖然純</span>  
<span style="margin-left: 4em">爲小說家言不可入之於史部與漢武内傳</span>  
<span style="margin-left: 4em">諸書同一例也</span>  
大業拾遺記二卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">一名南部煙花錄舊本題唐顔師古撰末有䟦語</span>  
<span style="margin-left: 2em">稱會昌中沙門志徹得之瓦棺寺閣乃隋書遺稿</span>  
<span style="margin-left: 2em">云云王得臣麈史稱其極惡可疑姚寛西溪叢語</span>  
<!-- 册3 葉4073a　Page:文淵閣四庫全書_0003冊.djvu/1023 -->
<span style="margin-left: 2em">亦曰南部煙花錄文極俚俗又載陳後主詩云夕</span>  
<span style="margin-left: 2em">陽如有意偏傍小窻明此乃唐人方域詩六朝語</span>  
<span style="margin-left: 2em">不如此唐藝文志所載煙花錄記幸廣陵事此本</span>  
<span style="margin-left: 2em">巳亡故流俗僞作此書云云然則此亦僞本矣今</span>  
<span style="margin-left: 2em">觀下卷記幸月觀時與蕭后夜話有儂家事一切</span>  
<span style="margin-left: 2em">巳託楊素了之語是時素死久矣師古豈踈謬至</span>  
<span style="margin-left: 2em">此乎其中載煬帝諸作及虞世南贈袁寳兒作明</span>  
<span style="margin-left: 2em">代輯六朝詩者往往采掇皆不考之過也</span>  
海山記一卷迷樓記一卷開河記一卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<!-- 册3 葉4073b　Page:文淵閣四庫全書_0003冊.djvu/1023 -->
<span style="margin-left: 2em">三書並載明吳琯古今逸史中不著撰人名氏海</span>  
<span style="margin-left: 2em">山記述隋煬帝西苑事所錄煬帝諸歌其調乃唐</span>  
<span style="margin-left: 2em">李德裕所作望江南調段安節樂府襍錄述其緣</span>  
<span style="margin-left: 2em">起甚詳大業中安有是體考劉斧靑𤨏高議後集</span>  
<span style="margin-left: 2em">載有此記分上下二篇其文較詳葢宋人所依託</span>  
<span style="margin-left: 2em">此本刪併爲一卷益僞中之僞矣迷樓記亦見靑</span>  
<span style="margin-left: 2em">𤨏高議載煬帝幸江都唐帝入京見迷樓云云竟</span>  
<span style="margin-left: 2em">以迷樓爲在長安乖謬殊甚開河記述麻叔謀開</span>  
<span style="margin-left: 2em">汴河事詞尤鄙俚皆近於委巷之傳奇同出依託</span>  
<!-- 册3 葉4076a　Page:文淵閣四庫全書_0003冊.djvu/1024 -->
<span style="margin-left: 2em">不足道也</span>  
續世說十卷<sub class="note-yuan">兵部侍郞紀昀家藏本</sub>  
<span style="margin-left: 2em">舊本題唐隴西李垕撰前有俞安期序稱其書出</span>  
<span style="margin-left: 2em">自梁谿安茂<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">以宋本翻雕未及印行而没後三</span>  
<span style="margin-left: 2em">年安期復得焦竑藏本更爲校正成完書又稱其</span>  
<span style="margin-left: 2em">書唐志不經見通考所列續世說載宋至五代事</span>  
<span style="margin-left: 2em">者又孔平仲所撰實非此書何良俊撰語林文徴</span>  
<span style="margin-left: 2em">明爲作序王世貞又刪語林補世說皆不言曾見</span>  
<span style="margin-left: 2em">此書疑其贋作而終以宋本𥿄墨古闇中闕宋諱</span>  
<!-- 册3 葉4076b　Page:文淵閣四庫全書_0003冊.djvu/1024 -->
<span style="margin-left: 2em">爲據今考其書惟取李延壽南北二史所載碎事</span>  
<span style="margin-left: 2em">依世說門目編之而增以博洽介潔兵策驍勇游</span>  
<span style="margin-left: 2em">戲釋教言驗志怪感動癡弄凶悖十一門别無異</span>  
<span style="margin-left: 2em">聞可資考據葢卽安期輩依託爲之詭言宋本其</span>  
<span style="margin-left: 2em">序中所設之疑正以防後人之攻詰明代僞書往</span>  
<span style="margin-left: 2em">往如是所謂欲葢而彌彰也</span>  
丁晉公談錄一卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">不著撰人名氏皆述丁謂所談當代故事晁公武</span>  
<span style="margin-left: 2em">讀書志以其出於洪州潘延之家疑卽延之所作</span>  
<!-- 册3 葉4077a　Page:文淵閣四庫全書_0003冊.djvu/1024 -->
<span style="margin-left: 2em">延之謂甥也今觀所記謂事皆溢美而敘澶淵之</span>  
<span style="margin-left: 2em">事歸之天象一字不及冦凖又載凖挾嫌私改馮</span>  
<span style="margin-left: 2em">拯轉官文字事皆顚倒是非有乖公論卽未必延</span>  
<span style="margin-left: 2em">之所作其出於謂之餘黨更無疑義也然稱謂籌</span>  
<span style="margin-left: 2em">畫軍糈決眞宗東封之行以爲美談則欲譽其才</span>  
<span style="margin-left: 2em">適彰其附合時局小人之情狀終有不能自掩者</span>  
<span style="margin-left: 2em">矣</span>  
殘本唐語林二卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">不著撰人名氏以永樂大典所載考之卽王讜之</span>  
<!-- 册3 葉4077b　Page:文淵閣四庫全書_0003冊.djvu/1024 -->
<span style="margin-left: 2em">書佚其八卷耳前有明嘉靖間桐城齊之鸞序亦</span>  
<span style="margin-left: 2em">稱所得非善本今已採掇永樂大典重爲補綴成</span>  
<span style="margin-left: 2em">帙别著於錄此殘缺之本已爲土苴以其爲讜之</span>  
<span style="margin-left: 2em">原書久行於世故仍附存其目焉</span>  
昨夢錄一卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">宋康與之撰與之字伯可又字叔聞號退軒滑州</span>  
<span style="margin-left: 2em">人故自署曰箕山此書末有小傳乃稱爲嘉禾人</span>  
<span style="margin-left: 2em">葢南渡後流寓也建炎初上中興十策爲汪伯彦</span>  
<span style="margin-left: 2em">黃潛善所抑不得用及秦檜當國乃附合求進擢</span>  
<!-- 册3 葉4080a　Page:文淵閣四庫全書_0003冊.djvu/1025 -->
<span style="margin-left: 2em">爲臺郞後遂專以歌詞供奉厠身優伶之班大爲</span>  
<span style="margin-left: 2em">士論所不齒所撰頤菴樂府五卷爲談藝者所輕</span>  
<span style="margin-left: 2em">世不甚傳今亦未見其本其僅存者惟是編皆追</span>  
<span style="margin-left: 2em">述北宋軼聞以生於滑臺目覩汴都之盛故以昨</span>  
<span style="margin-left: 2em">夢爲名所記黃河捲掃事竹牛角事老君廟畫壁</span>  
<span style="margin-left: 2em">事亦可資考證其西北邊城貯猛火油事遼史先</span>  
<span style="margin-left: 2em">有是說然疑皆傳聞附會終遼宋之世均未聞用</span>  
<span style="margin-left: 2em">此油火攻致勝且所産之地在高麗東高麗去中</span>  
<span style="margin-left: 2em">國至近亦不聞産此異物也至開封尹李倫被攝</span>  
<!-- 册3 葉4080b　Page:文淵閣四庫全書_0003冊.djvu/1025 -->
<span style="margin-left: 2em">事連篇累牘殆如傳奇又唐人小說之末流益無</span>  
<span style="margin-left: 2em">取矣</span>
