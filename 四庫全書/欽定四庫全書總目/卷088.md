## 欽定四庫全書總目 卷八十八　史部四十四　史評類

<!-- 册2 葉3228a　Page:文淵閣四庫全書_0002冊.djvu/812 -->
欽定四庫全書總目卷八十八  
<span style="margin-left: 1em">史部四十四</span>  
<span style="margin-left: 2em">史評𩔖</span>  
<span style="margin-left: 3em">春秋筆削議而不辨其後三傳異詞史記亦自</span>  
<span style="margin-left: 3em">爲序贊以著本旨而先黃老後六經退處士進</span>  
<span style="margin-left: 3em">姦雄班固復異議焉此史論所以繁也其中考</span>  
<span style="margin-left: 3em">辨史體如劉知幾倪思諸書非博覽精思不能</span>  
<span style="margin-left: 3em">成帙故作者差稀至於品隲舊聞抨彈往迹則</span>  
<span style="margin-left: 3em">纔繙史畧卽可成文此是彼非互滋簧鼓故其</span>  
<!-- 册2 葉3228b　Page:文淵閣四庫全書_0002冊.djvu/812 -->
<span style="margin-left: 3em">書動至汗牛又文士立言務求相勝或至鑿空</span>  
<span style="margin-left: 3em">生義僻謬不情如胡寅讀史管見譏晉元帝不</span>  
<span style="margin-left: 3em">復牛姓者更往往而有故瑕纇叢生亦惟此一</span>  
<span style="margin-left: 3em">𩔖爲甚我</span>  
皇上綜括古今折衷衆論  
欽定評鑑闡要及全韻詩昭示來兹日月著明爝火可  
<span style="margin-left: 3em">息百家讕語原可無存以古來著錄舊有此門</span>  
<span style="margin-left: 3em">擇其篤實近理者酌錄數家用備體裁云爾</span>  
史通二十卷<sub class="note-yuan">内府藏本</sub>  
<!-- 册2 葉3229a　Page:文淵閣四庫全書_0002冊.djvu/812 -->
<span style="margin-left: 2em">唐劉子元撰子元本名知幾避明皇嫌名以字行</span>  
<span style="margin-left: 2em">彭城人弱冠擢進士第調𫉬嘉尉遷鳳閣舍人兼</span>  
<span style="margin-left: 2em">修國史中宗時擢太子率更令累遷秘書監太子</span>  
<span style="margin-left: 2em">左庶子崇文館學士開元初官至左散騎常侍後</span>  
<span style="margin-left: 2em">坐事貶安州別駕卒於官事迹具唐書本傳此書</span>  
<span style="margin-left: 2em">成於景龍四年凡内篇十卷三十九篇外篇十卷</span>  
<span style="margin-left: 2em">十三篇葢其官秘書監時與蕭至忠宗楚客等爭</span>  
<span style="margin-left: 2em">論史事不合發憤而著書者也其内篇體統紕繆</span>  
<span style="margin-left: 2em">弛張三篇有錄無書考本傳巳稱著史通四十九</span>  
<!-- 册2 葉3229b　Page:文淵閣四庫全書_0002冊.djvu/812 -->
<span style="margin-left: 2em">篇則三篇之亡在修唐書以前矣内篇皆論史家</span>  
<span style="margin-left: 2em">體例辨別是非外篇則述史籍源流及雜評古人</span>  
<span style="margin-left: 2em">得失文或與内篇重出又或牴牾觀開卷六家篇</span>  
<span style="margin-left: 2em">首稱自古帝王文籍外篇言之備矣是先有外篇</span>  
<span style="margin-left: 2em">乃擷其精華以成内篇故刪除有所未盡也子元</span>  
<span style="margin-left: 2em">於史學最深又領史職幾三十年更厯書局亦最</span>  
<span style="margin-left: 2em">久其貫穿今古洞悉利病實非後人之所及而性</span>  
<span style="margin-left: 2em">本過剛詞復有激詆詞太甚或悍然不顧其安疑</span>  
<span style="margin-left: 2em">經惑古諸篇世所共詬不待言矣卽如六家篇議</span>  
<!-- 册2 葉3232a　Page:文淵閣四庫全書_0002冊.djvu/813 -->
<span style="margin-left: 2em">尙書爲例不純載言篇譏左氏不遵古法人物篇</span>  
<span style="margin-left: 2em">譏尙書不載八元八愷寒浞飛廉惡來閎夭散宜</span>  
<span style="margin-left: 2em">生譏春秋不載由余百里奚范蠡文種曹沬公儀</span>  
<span style="margin-left: 2em">休𡩋戚穰苴亦殊謬妄至於史家書法在褒貶不</span>  
<span style="margin-left: 2em">在名號昏暴如幽厲不能削其王號也而稱謂篇</span>  
<span style="margin-left: 2em">謂晉康穆以下諸帝皆當削其廟號朱雲之折檻</span>  
<span style="margin-left: 2em">張綱之埋輪<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">節凛然而言語篇斥爲小辨史不</span>  
<span style="margin-left: 2em">當書蘧瑗位列大夫未嘗栖隱而品藻篇謂高士</span>  
<span style="margin-left: 2em">傳漏載其名孔子門人欲尊有若事出孟子定不</span>  
<!-- 册2 葉3232b　Page:文淵閣四庫全書_0002冊.djvu/813 -->
<span style="margin-left: 2em">虛誣而鑒識篇以史記載此一事其鄙陋甚於褚</span>  
<span style="margin-left: 2em">少孫皆任意抑揚偏駁殊甚其他如雜說篇指趙</span>  
<span style="margin-left: 2em">盾魚飧不爲菲食議公羊之誣并州竹馬非其士</span>  
<span style="margin-left: 2em">產議東觀漢記之謬亦多瑣屑支離且周禮太史</span>  
<span style="margin-left: 2em">掌國之六典小史掌<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3771.svg?width=24" alt="四庫全書僻字第3771號（邦）" title="四庫全書僻字第3771號（邦）">國之志則史官兼司掌故</span>  
<span style="margin-left: 2em">古之制也子元之意惟以褒貶爲宗餘事皆視爲</span>  
<span style="margin-left: 2em">枝贅故表厯書志兩篇於班馬以來之舊例一一</span>  
<span style="margin-left: 2em">排斥多欲刪除尤乖古法餘如譏後漢書之採雜</span>  
<span style="margin-left: 2em">說而自據竹書紀年山海經譏漢書五行志之舛</span>  
<!-- 册2 葉3233a　Page:文淵閣四庫全書_0002冊.djvu/813 -->
<span style="margin-left: 2em">誤而自以元暉之科錄爲魏濟陰王暉業作以後</span>  
<span style="margin-left: 2em">漢書劉虞傅爲在三國志中小小踈漏更所不免</span>  
<span style="margin-left: 2em">然其縷析條分如別白黑一經抉摘雖馬遷班固</span>  
<span style="margin-left: 2em">幾無詞以自解亦可云載筆之法家著書之監史</span>  
<span style="margin-left: 2em">矣自明以來註本凡三四家而訛脫竄亂均如一</span>  
<span style="margin-left: 2em">轍此本爲</span>  
<span style="margin-left: 1em">内府所藏舊刻未有注文視諸家猶爲近古其中㸃</span>  
<span style="margin-left: 2em">煩一篇諸本並佚其朱㸃此本亦同無可校補姑</span>  
<span style="margin-left: 2em">仍之焉</span>  
<!-- 册2 葉3233b　Page:文淵閣四庫全書_0002冊.djvu/813 -->
史通通釋二十卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 1em">國朝浦起龍撰起龍字二田無錫人雍正甲辰進士</span>  
<span style="margin-left: 2em">官蘇州府敎授史通註本舊有郭延年王維儉二</span>  
<span style="margin-left: 2em">家近時又有黃叔琳註補郭王之所闕遞相增損</span>  
<span style="margin-left: 2em">互有短長起龍是註又在黃註稍後故亦採用黃</span>  
<span style="margin-left: 2em">註數條然頗糾彈其踈舛其中如曲筆篇稱秦人</span>  
<span style="margin-left: 2em">不死驗符生之厚誣蜀老猶存知葛亮之多枉三</span>  
<span style="margin-left: 2em">家皆不註起龍亦僅引困學紀聞謂王應麟不知</span>  
<span style="margin-left: 2em">所出定爲無考而不知秦人事出洛陽伽藍記蜀</span>  
<!-- 册2 葉3236a　Page:文淵閣四庫全書_0002冊.djvu/814 -->
<span style="margin-left: 2em">老事出魏書毛修之傳又如闌單失力但引盧照</span>  
<span style="margin-left: 2em">鄰賦旁証而不知淸異錄實有訓釋不煩假偕小</span>  
<span style="margin-left: 2em">小踈漏亦不能無然大致引據詳明足稱該洽惟</span>  
<span style="margin-left: 2em">疑經惑古諸篇更助頽波殊爲好異又輕於改竄</span>  
<span style="margin-left: 2em">古書往往失其本旨如六家篇尙書條中語無可</span>  
<span style="margin-left: 2em">述四字之下若此二字之上顯有脫句而改此字</span>  
<span style="margin-left: 2em">爲止字更臆增一有字又如列傳篇項王立傳而</span>  
<span style="margin-left: 2em">以本紀爲名句立字不誤而乃臆改爲宜字此𩔖</span>  
<span style="margin-left: 2em">至多皆矢詳愼至於句解章評參差連寫如坊刻</span>  
<!-- 册2 葉3236b　Page:文淵閣四庫全書_0002冊.djvu/814 -->
<span style="margin-left: 2em">古文之式於註書體例亦乖使其一評一註釐爲</span>  
<span style="margin-left: 2em">二書則庶乎離之雙美矣</span>  
唐鑑二十四卷<sub class="note-yuan">副都御史黄登賢家藏本</sub>  
<span style="margin-left: 2em">宋范祖禹撰呂祖謙註祖禹字淳父華陽人嘉祐</span>  
<span style="margin-left: 2em">八年進士厯官龍圖閣學士出知陜州事蹟附載</span>  
<span style="margin-left: 2em">宋史范鎭傳祖謙有古周易巳著錄初治平中司</span>  
<span style="margin-left: 2em">馬光奉詔修通鑑祖禹爲編修官分掌唐史以其</span>  
<span style="margin-left: 2em">所自得者著成此書上自高祖下迄昭宣撮取大</span>  
<span style="margin-left: 2em">綱繫以論斷爲卷十二元祐初表上於朝結銜稱</span>  
<!-- 册2 葉3237a　Page:文淵閣四庫全書_0002冊.djvu/814 -->
<span style="margin-left: 2em">著作佐郎葢進書時所居官也後祖謙爲作註乃</span>  
<span style="margin-left: 2em">分爲二十四卷蔡絛鐵圍山叢談曰祖禹子温遊</span>  
<span style="margin-left: 2em">大相國寺諸貴璫見之皆指目曰此唐鑑之子葢</span>  
<span style="margin-left: 2em">不知祖禹爲誰獨習聞有唐鑑也則是書爲當世</span>  
<span style="margin-left: 2em">所重可知矣張端義貴耳集亦記高宗與講官言</span>  
<span style="margin-left: 2em">讀資治通鑑知司馬光有宰相度量讀唐鑑知范</span>  
<span style="margin-left: 2em">祖禹有臺諫手段惟朱子語錄謂其議論弱又有</span>  
<span style="margin-left: 2em">不相應處然通鑑以武后紀年祖禹獨川沈旣濟</span>  
<span style="margin-left: 2em">之說取武后臨朝二十一年繫之中宗白謂比春</span>  
<!-- 册2 葉3237b　Page:文淵閣四庫全書_0002冊.djvu/814 -->
<span style="margin-left: 2em">秋公在乾侯之義且曰雖得罪君子亦所不辭後</span>  
<span style="margin-left: 2em">朱子作通鑑綱目書帝在房州實仍其例王懋竑</span>  
<span style="margin-left: 2em">白田雜著亦曰范淳父唐鑑言有治人無治法朱</span>  
<span style="margin-left: 2em">子嘗鄙其論以爲苟簡而晩年作社倉記則亟稱</span>  
<span style="margin-left: 2em">之以爲不易之論而自述前言之誤葢其經厯旣</span>  
<span style="margin-left: 2em">多故前後所言有不同者讀者宜詳考焉未可執</span>  
<span style="margin-left: 2em">一說以爲定也然則朱子語錄之所載未可據以</span>  
<span style="margin-left: 2em">斷此書矣</span>  
唐史論斷三卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<!-- 册2 葉3240a　Page:文淵閣四庫全書_0002冊.djvu/815 -->
<span style="margin-left: 2em">宋孫甫撰甫字之翰陽翟人舉進士厯官右正言</span>  
<span style="margin-left: 2em">遷天章閣待制河北轉運使兼侍讀事蹟具宋史</span>  
<span style="margin-left: 2em">本傳陳振孫書錄解題稱甫以劉昫唐書煩冗遺</span>  
<span style="margin-left: 2em">畧多失體法乃改用編年體創始於康定元年蕆</span>  
<span style="margin-left: 2em">事於嘉祐元年勒成唐紀七十五卷其間善惡分</span>  
<span style="margin-left: 2em">明可爲龜鑑者各繫以論凡九十二篇甫没後唐</span>  
<span style="margin-left: 2em">紀宣取留禁中其從子察嘗錄副本遺司馬光世</span>  
<span style="margin-left: 2em">亦罕見惟論斷獨傳紹興二十七年嘗鋟板於劒</span>  
<span style="margin-left: 2em">州後蜀板不存端平乙未黃準復刻於東陽宋史</span>  
<!-- 册2 葉3240b　Page:文淵閣四庫全書_0002冊.djvu/815 -->
<span style="margin-left: 2em">藝文志作二卷文獻通考作十卷此本僅三卷葢</span>  
<span style="margin-left: 2em">本從唐紀鈔出別行非其舊帙故卷數多寡隨意</span>  
<span style="margin-left: 2em">分合實無二本也前爲自序一篇末附司馬光跋</span>  
<span style="margin-left: 2em">曾鞏歐陽修所作墓志行狀蘇軾答李廌書張敦</span>  
<span style="margin-left: 2em">頤後序皆推重是書甚至朱子亦稱其議論勝唐</span>  
<span style="margin-left: 2em">鑑云</span>  
唐書直筆四卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">宋吕夏<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">撰夏<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">字縉叔泉州晉江人舉進士爲</span>  
<span style="margin-left: 2em">江寧尉厯官宣德郞守秘書丞以預修唐書告成</span>  
<!-- 册2 葉3241a　Page:文淵閣四庫全書_0002冊.djvu/815 -->
