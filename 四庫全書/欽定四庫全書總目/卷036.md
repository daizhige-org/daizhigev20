## 欽定四庫全書總目 卷三十六　經部三十六　四書類二

<!-- 册1 葉2905a　Page:文淵閣四庫全書_0001冊.djvu/776 -->
欽定四庫全書總目卷三十六  
<span style="margin-left: 1em">經部三十六</span>  
<span style="margin-left: 2em">四書類二</span>  
四書集義精要二十八卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">元劉因撰因字夢吉號靜修容城人世祖至元十</span>  
<span style="margin-left: 2em">九年徵授承德郎右贊善大夫未幾辭歸再以集</span>  
<span style="margin-left: 2em">賢學士徵不起事迹具元史本傳朱子爲四書集</span>  
<span style="margin-left: 2em">注凡諸人問答與集注有異同者不及訂歸於一</span>  
<span style="margin-left: 2em">而卒後盧孝孫取語類文集所說輯爲四書集義</span>  
<!-- 册1 葉2905b　Page:文淵閣四庫全書_0001冊.djvu/776 -->
<span style="margin-left: 2em">凡一百卷讀者頗病其繁冗因乃擇其指要刪其</span>  
<span style="margin-left: 2em">複雜勒成是書張萱内閣書目作三十五卷一齋</span>  
<span style="margin-left: 2em">書目則作三十卷考蘇天爵作因墓誌亦稱是書</span>  
<span style="margin-left: 2em">三十卷則萱所記誤矣此本僅存二十八卷至孟</span>  
<span style="margin-left: 2em">子滕文公上篇而止其後並久缺佚巳非完帙然</span>  
<span style="margin-left: 2em">朱彞尊經義考注云未見則流傳頗罕亦元人遺</span>  
<span style="margin-left: 2em">笈之僅存者不以殘缺病也其書芟削浮詞標舉</span>  
<span style="margin-left: 2em">要領使朱子之說不惑於多岐蘇天爵以簡嚴粹</span>  
<span style="margin-left: 2em">精稱之良非虛美葢因潛心義理所得頗深故去</span>  
<!-- 册1 葉2908a　Page:文淵閣四庫全書_0001冊.djvu/777 -->
<span style="margin-left: 2em">取分明如別白黑較徒博尊朱之名不問巳定未</span>  
<span style="margin-left: 2em">定之說片言隻字無不奉若球圖者固不同矣</span>  
四書辨疑十五巷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">不著撰人名氏書中稱自宋氏播遷江表南北分</span>  
<span style="margin-left: 2em">隔纔百五六十年經書文字已有不同則元初人</span>  
<span style="margin-left: 2em">所撰矣蘇天爵安熙行狀云國初有傳朱子四書</span>  
<span style="margin-left: 2em">集注至北方者滹南王公雅以辨博自<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3688.svg?width=24" alt="四庫全書僻字第3688號（負）" title="四庫全書僻字第3688號（負）">爲說非</span>  
<span style="margin-left: 2em">之趙郡陳氏獨喜其說增多至若干言是書多引</span>  
<span style="margin-left: 2em">王若虛說殆寧晉陳天祥書也朱彞尊經義考曰</span>  
<!-- 册1 葉2908b　Page:文淵閣四庫全書_0001冊.djvu/777 -->
<span style="margin-left: 2em">四書辨疑元人凡有四家雲峯胡氏偃師陳氏黄</span>  
<span style="margin-left: 2em">巖陳成甫氏孟長文氏成甫長文並浙人雲峯一</span>  
<span style="margin-left: 2em">宗朱子其爲偃師陳氏之書無疑所說當矣其曰</span>  
<span style="margin-left: 2em">偃師者元史稱天祥因兄祐仕河南自寧晉家洛</span>  
<span style="margin-left: 2em">陽嘗居偃師南山故也天爵又謂安熙爲書以辨</span>  
<span style="margin-left: 2em">之其後天祥深悔而焚其書今此本具存或天爵</span>  
<span style="margin-left: 2em">欲ခ大其師學所言未足據也凡大學十五條論</span>  
<span style="margin-left: 2em">語一百七十三條孟子一百七十四條中庸十三</span>  
<span style="margin-left: 2em">條其中如駁湯盤非沐浴之盤謂盤乃淺器難容</span>  
<!-- 册1 葉2909a　Page:文淵閣四庫全書_0001冊.djvu/777 -->
<span style="margin-left: 2em">沐浴是未考禮䘮大記鄭注有盤長二尺深三尺</span>  
<span style="margin-left: 2em">之文頗爲踈舛又多移易經文以就己說亦未見</span>  
<span style="margin-left: 2em">必然然亦多平心剖析各明一義非苟爲門戸之</span>  
<span style="margin-left: 2em">爭說春秋者三傳並存說詩者四家互異古來訓</span>  
<span style="margin-left: 2em">詁原不專主一人各尊所聞各行所知固不妨存</span>  
<span style="margin-left: 2em">此一家之書以資參考也</span>  
讀四書叢說四卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">元許謙撰謙有詩集傳名物鈔已著錄案元史本</span>  
<span style="margin-left: 2em">傳謙讀四書章句集注有叢說二十卷謂學者曰</span>  
<!-- 册1 葉2909b　Page:文淵閣四庫全書_0001冊.djvu/777 -->
<span style="margin-left: 2em">學以聖人爲凖的然必得聖人之心而後可學聖</span>  
<span style="margin-left: 2em">人之事聖賢之心具在四書而四書之義備於朱</span>  
<span style="margin-left: 2em">子顧辭約意廣讀者安可易心求之乎黃溍作謙</span>  
<span style="margin-left: 2em">墓誌亦稱是書敦繹義理惟務平實所載卷數與</span>  
<span style="margin-left: 2em">本傳相同明錢溥秘閣書目尚有四書叢說四冊</span>  
<span style="margin-left: 2em">至朱彞尊經義考則但據一齋書目編入其名而</span>  
<span style="margin-left: 2em">註云未見葢久在若存若亡間矣此本凡大學一</span>  
<span style="margin-left: 2em">卷中庸一卷孟子二卷中庸闕其半論語則已全</span>  
<span style="margin-left: 2em">闕亦非完書然約計所存猶有十之五六卽益以</span>  
<!-- 册1 葉2912a　Page:文淵閣四庫全書_0001冊.djvu/778 -->
<span style="margin-left: 2em">所闕之帙亦不能足原目二十卷之數殆後來已</span>  
<span style="margin-left: 2em">有所合併歟書中發揮義理皆言簡義該或有難</span>  
<span style="margin-left: 2em">曉則爲圖以明之務使無所疑滯而後巳其於訓</span>  
<span style="margin-left: 2em">詁名物亦頗考証有足補章句所未備於朱子一</span>  
<span style="margin-left: 2em">家之學可謂有所發明矣</span>  
四書通二十六卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">元胡炳文撰炳文有周易本義通釋已著錄是編</span>  
<span style="margin-left: 2em">以趙順孫四書纂疏吳眞子四書集成皆闡朱子</span>  
<span style="margin-left: 2em">之緖論而尚有與朱子相戾者因重爲刊削附以</span>  
<!-- 册1 葉2912b　Page:文淵閣四庫全書_0001冊.djvu/778 -->
<span style="margin-left: 2em">己說以成此書凡朱子以前之說嫌於補朱子之</span>  
<span style="margin-left: 2em">遺皆斥不錄故所取於纂疏集成者僅十四家二</span>  
<span style="margin-left: 2em">書之外又增入四十五家則皆恪守考亭之學者</span>  
<span style="margin-left: 2em">也大扺合於經義與否非其所論惟以合於註意</span>  
<span style="margin-left: 2em">與否定其是非雖堅持門戸未免偏主一家然觀</span>  
<span style="margin-left: 2em">其凡例於顔淵好學章哀樂哀懼一字之筆誤亦</span>  
<span style="margin-left: 2em">必辨明於爲政以德章初本作行道而有得於身</span>  
<span style="margin-left: 2em">祝洙本作行道而肓得於心改本又作得於心而</span>  
<span style="margin-left: 2em">不失刊本先後之差亦悉加考正其於一家之學</span>  
<!-- 册1 葉2913a　Page:文淵閣四庫全書_0001冊.djvu/778 -->
<span style="margin-left: 2em">用心亦勤且密矣章句集註所引凡五十四家今</span>  
<span style="margin-left: 2em">多不甚可考蔡模集疏間有所註亦不甚詳是書</span>  
<span style="margin-left: 2em">尚一一載其名字頗足以資訂證然如集註以有</span>  
<span style="margin-left: 2em">婦人焉爲邑姜所引劉侍讀曰者卽劉敞七經小</span>  
<span style="margin-left: 2em">傳之說也炳文獨遺漏不載葢敞在北宋閉戸窮</span>  
<span style="margin-left: 2em">經不入伊洛之派講學之家惡其不相攀附遂無</span>  
<span style="margin-left: 2em">復道其姓名者故朱子雖引之而炳文不知其誰</span>  
<span style="margin-left: 2em">也是亦各尊所聞之一騐矣</span>  
四書通證六卷<sub class="note-yuan">兩江總督採進本</sub>  
<!-- 册1 葉2913b　Page:文淵閣四庫全書_0001冊.djvu/778 -->
<span style="margin-left: 2em">元張存中撰存中字德庸新安人初胡炳文作四</span>  
<span style="margin-left: 2em">書通詳義理而略名物存中因排纂舊說成此書</span>  
<span style="margin-left: 2em">以附其後故名曰四書通證炳文爲之序稱北方</span>  
<span style="margin-left: 2em">杜緱山有語孟旁通平水薛壽之有四書引証<sub class="note-yuan">案杜</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">緱山名瑛金人薛壽之名引年元初人</sub>皆失之太繁存中能刪冗從</span>  
<span style="margin-left: 2em">簡去非取是又曰學者於余之通知四書用意之</span>  
<span style="margin-left: 2em">深於通證知四書用事之審推之甚至今核其書</span>  
<span style="margin-left: 2em">引經數典字字必著所出而論語夏曰瑚商曰璉</span>  
<span style="margin-left: 2em">一條承包氏之誤者乃不引禮記以証之又時見</span>  
<!-- 册1 葉2916a　Page:文淵閣四庫全書_0001冊.djvu/779 -->
<span style="margin-left: 2em">曰會衆頫曰同與周禮本文小異葢宋代諱殷故</span>  
<span style="margin-left: 2em">改殷爲衆乃但引周禮於下而不辨其何以不同</span>  
<span style="margin-left: 2em">皆不免有所回䕶不知朱子之學在明聖道之正</span>  
<span style="margin-left: 2em">傳區區訓詁之間固不必爲之諱也孟子與楚將</span>  
<span style="margin-left: 2em">昭陽戰亡其七邑一條存中謂史記作八邑未詳</span>  
<span style="margin-left: 2em">孰是不知司馬貞史記索隱明注史記古本作七</span>  
<span style="margin-left: 2em">邑是朱子稱七邑乃據古本原非謬誤存中持疑</span>  
<span style="margin-left: 2em">不决亦失於考核又如三讓引吳越春秋泛及雜</span>  
<span style="margin-left: 2em">說而於厯代史事毎多置正史而引通鑑亦非根</span>  
<!-- 册1 葉2916b　Page:文淵閣四庫全書_0001冊.djvu/779 -->
<span style="margin-left: 2em">本之學然大槪徴引詳明於人人習讀不察者一</span>  
<span style="margin-left: 2em">一具標出處可省檢閱之煩於學者亦不爲無補</span>  
<span style="margin-left: 2em">矣</span>  
四書疑節十二卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">元袁俊翁撰俊翁字敏齋袁州人前有黎立武李</span>  
<span style="margin-left: 2em">應星序又有彭元龍序二篇應星元龍序皆稱俊</span>  
<span style="margin-left: 2em">翁獨立武序作雋翁葢傳寫字異也其仕履無可</span>  
<span style="margin-left: 2em">考立武序稱以重吾榜應星序亦稱奕奕魁文知</span>  
<span style="margin-left: 2em">嘗首舉於鄉矣立武應星序及元龍前一序並側</span>  
<!-- 册1 葉2917a　Page:文淵閣四庫全書_0001冊.djvu/779 -->
<span style="margin-left: 2em">注經史疑義字元龍後一序又側注四書經疑字</span>  
<span style="margin-left: 2em">而卷首標題則作待問集四書疑節互相㕘錯考</span>  
<span style="margin-left: 2em">俊翁題詞稱科目以四書設疑以經史發策因取</span>  
<span style="margin-left: 2em">四書經史門分而類析之葢待問集者其總名經</span>  
<span style="margin-left: 2em">史疑義四書經疑其中之子部今經史疑義已佚</span>  
<span style="margin-left: 2em">故序與書兩不相應也惟疑節之名不甚可解卷</span>  
<span style="margin-left: 2em">首有溪山家塾刋行字或重刻時有所刪節故改</span>  
<span style="margin-left: 2em">題曰節歟朱彞尊經義考中載之註曰未見此本</span>  
<span style="margin-left: 2em">猶從元板傳鈔其例以四書之文互相㕘對爲題</span>  
<!-- 册1 葉2917b　Page:文淵閣四庫全書_0001冊.djvu/779 -->
<span style="margin-left: 2em">或似異而實同或似同而實異或闡義理或用考</span>  
<span style="margin-left: 2em">証皆標問於前列答於後葢當時之體如是雖亦</span>  
<span style="margin-left: 2em">科舉之學然非融貫經義昭晰無疑則格閡不能</span>  
<span style="margin-left: 2em">下一語非猶夫明人科舉之學也</span>  
四書經疑貫通八卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">元王充耘撰充耘有讀書管見已著錄是編黃虞</span>  
<span style="margin-left: 2em">稷千頃堂書目謂其已佚此本爲明范欽天一閣</span>  
<span style="margin-left: 2em">舊抄尚首尾完具惟第二卷中脫一頁第八卷中</span>  
<span style="margin-left: 2em">脫一頁無從校補則亦僅存之笈矣其書以四書</span>  
<!-- 册1 葉2920a　Page:文淵閣四庫全書_0001冊.djvu/780 -->
<span style="margin-left: 2em">同異參互比較各設問答以明之葢延祐科舉經</span>  
<span style="margin-left: 2em">義之外有經疑此與袁俊翁書皆程試之式也其</span>  
<span style="margin-left: 2em">間辨別疑似頗有發明非經義之循題衍說可以</span>  
<span style="margin-left: 2em">影響揣摩者比故有元一代士猶篤志於研經明</span>  
<span style="margin-left: 2em">洪武三年初行科舉其四書疑問以大學古之欲</span>  
<span style="margin-left: 2em">明明德於天下者二節與孟子道在邇而求諸遠</span>  
<span style="margin-left: 2em">一節合爲一題問二書所言平天下大指同異<sub class="note-yuan">案此</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">題見曰知錄</sub>葢猶沿元制至十七年改定格式而經疑</span>  
<span style="margin-left: 2em">之法遂廢錄此二書猶可以見宋元以來明經取</span>  
<!-- 册1 葉2920b　Page:文淵閣四庫全書_0001冊.djvu/780 -->
<span style="margin-left: 2em">士之舊制也</span>  
四書纂箋二十八卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">元詹道傳撰道傳臨川人其始末未詳是書略仿</span>
