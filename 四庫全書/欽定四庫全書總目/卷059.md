欽定四庫全書總目卷五十九  
<span style="margin-left: 1em">史部十五</span>  
<span style="margin-left: 2em">傳記類存目一</span>  
孔子世家補十二卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋歐陽士秀撰士秀廬陵人仕履未詳是書成於</span>  
<span style="margin-left: 2em">淳祐辛亥大抵據皇極經世以駁史記孔子世家</span>  
<span style="margin-left: 2em">之訛然邵子精於數學不聞精於史學所書先聖</span>  
<span style="margin-left: 2em">事迹亦未必盡<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">自序又稱慮夫事之精粗隱顯</span>  
<span style="margin-left: 2em">大小本末錯糅其間而不易見則著年表以提其</span>  
<!-- 册2 葉1225b　Page:文淵閣四庫全書_0002冊.djvu/311 -->
<span style="margin-left: 2em">綱列世本以類其族且綴弟子年名於其終於以</span>  
<span style="margin-left: 2em">稽其是非用決羣疑而祛已惑今考永樂大典所</span>  
<span style="margin-left: 2em">載並無所謂年表世本弟子年名者則已非完書</span>  
<span style="margin-left: 2em">矣</span>  
孔氏實錄一卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">不著撰人名氏末一條云大𫎇古國領中書省耶</span>  
<span style="margin-left: 2em">律楚材奏准皇帝聖㫖於南京特取襲封孔元措</span>  
<span style="margin-left: 2em">令赴闕里奉祀<sub class="note-yuan">案元厝以金承安二年襲封衍聖公</sub>此書或卽元措</span>  
<span style="margin-left: 2em">等所撰歟首錄厯代褒崇之典凡碑文詔㫖皆載</span>  
<!-- 册2 葉1228a　Page:文淵閣四庫全書_0002冊.djvu/312 -->
<span style="margin-left: 2em">其畧末載孔氏鄉官甚詳然敘次頗無體例如首</span>  
<span style="margin-left: 2em">載聖母顏氏及聖配亓官氏而孔子以上厯世之</span>  
<span style="margin-left: 2em">事獨不一敘疑或傳寫佚脫非完帙也考明文淵</span>  
<span style="margin-left: 2em">閣書目有孔子實錄一册永樂大典所載則作孔</span>  
<span style="margin-left: 2em">氏未詳孰是然文淵閣書目傳寫多誤未足盡據</span>  
<span style="margin-left: 2em">今仍從永樂大典之名著於錄焉</span>  
孔子論語年譜一卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">舊本題元程復心撰復心字子見婺源人皇慶癸</span>  
<span style="margin-left: 2em">丑江浙行省以所撰四書纂釋進於朝授徽州路</span>  
<!-- 册2 葉1228b　Page:文淵閣四庫全書_0002冊.djvu/312 -->
<span style="margin-left: 2em">教授致仕給半俸終其身是編以論語各章分隸</span>  
<span style="margin-left: 2em">於孔子年譜之内而又雜采左傳諸事附會之如</span>  
<span style="margin-left: 2em">云九歲見季札觀樂於魯三十五歲從昭公出亡</span>  
<span style="margin-left: 2em">留齊七年此因旁文而牽合孔子者也又云五十</span>  
<span style="margin-left: 2em">三歲孔子聘於齊執圭鞠躬如也云云此因論語</span>  
<span style="margin-left: 2em">而妄生旁文者也又云六十三歲阨於陳蔡不得</span>  
<span style="margin-left: 2em">已浮海至楚曰道不行乘桴浮於海云云陳蔡之</span>  
<span style="margin-left: 2em">間何由浮海郢都又豈海道可通尤夢藝之語可</span>  
<span style="margin-left: 2em">資笑噱者矣至所分隸之論語以子釣而不綱章</span>  
<!-- 册2 葉1229a　Page:文淵閣四庫全書_0002冊.djvu/312 -->
<span style="margin-left: 2em">爲三十一歲以子以四教章子所雅言章子罕言</span>  
<span style="margin-left: 2em">章子不語章自行束脩以上章爲三十四歲以八</span>  
<span style="margin-left: 2em">佾雍徹諸章爲三十五歲以君子食無求飽章爲</span>  
<span style="margin-left: 2em">四十三歲道千乘之國章爲四十八歲之類不可</span>  
<span style="margin-left: 2em">殫數均不知其何所據而云然復心師朱洪範友</span>  
<span style="margin-left: 2em">胡炳文實屬講學之家原不究心於考證然不應</span>  
<span style="margin-left: 2em">繆妄至於如是考篇末辨季本聖蹟圖考之妄本</span>  
<span style="margin-left: 2em">王守仁之弟子元人何自見其書殆明季妄人所</span>  
<span style="margin-left: 2em">爲而傳錄者僞題復心之名歟</span>  
<!-- 册2 葉1229b　Page:文淵閣四庫全書_0002冊.djvu/312 -->
孟子年譜一卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">舊本題元程復心撰復心旣作論語年譜更取孟</span>  
<span style="margin-left: 2em">子七篇爲編年其以某章爲某年之言繆妄與孔</span>  
<span style="margin-left: 2em">子年譜相等其謂孟子鄒人乃陬邑非鄒國也語</span>  
<span style="margin-left: 2em">極辯而不<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">亦好異之談蓋與孔子年譜一手所</span>  
<span style="margin-left: 2em">僞撰也考朱彞尊經義考載譚貞默孟子編年畧</span>  
<span style="margin-left: 2em">一卷今未見其書然彞尊所載貞默自述一篇則</span>  
<span style="margin-left: 2em">與此書之自述不異一字疑<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">以貞默之書詭題</span>  
<span style="margin-left: 2em">元人耳僞妄甚矣</span>  
<!-- 册2 葉1232a　Page:文淵閣四庫全書_0002冊.djvu/313 -->
闕里志二十四卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">明陳鎬撰孔允植重纂鎬㑹稽人成化丁未進士</span>  
<span style="margin-left: 2em">官至右副都御史巡撫湖廣允植孔子六十五世</span>  
<span style="margin-left: 2em">孫襲封衍聖公闕里向無志乘僅有孔庭纂要祖</span>  
<span style="margin-left: 2em">庭廣記諸書宏治甲子重修闕里</span>  
<span style="margin-left: 1em">孔廟成李東陽承命致祭時鎬爲提學副使因屬之</span>  
<span style="margin-left: 2em">編次成志崇禎中允植重加訂補是爲今本以圖</span>  
<span style="margin-left: 2em">像禮樂世家事蹟祀典人物林廟山川古蹟恩典</span>  
<span style="margin-left: 2em">弟子譔述藝文分類排纂而編次冗雜頗無體例</span>  
<!-- 册2 葉1232b　Page:文淵閣四庫全書_0002冊.djvu/313 -->
<span style="margin-left: 2em">如厯代誥敕御製文贊不入追崇恩典志而另爲</span>  
<span style="margin-left: 2em">提綱碑記本藝文中一類乃別增譔述一門均爲</span>  
<span style="margin-left: 2em">繁複</span>  
孔顏孟三氏志六卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明劉濬編濬永嘉人成化中官鄒縣教諭鄒孟子</span>  
<span style="margin-left: 2em">所生也孟廟在焉濬因考證孔顏孟三氏世系以</span>  
<span style="margin-left: 2em">及褒崇諸典彚輯成書先以地圖次以氏系年譜</span>  
<span style="margin-left: 2em">次以廟制次以誌事附述聖於卷後而前列提綱</span>  
<span style="margin-left: 2em">一卷則壬子四月紫陽楊奂所述東遊記也壬子</span>  
<!-- 册2 葉1233a　Page:文淵閣四庫全書_0002冊.djvu/313 -->
<span style="margin-left: 2em">爲元憲宗二年而濬於壬子下註云元憲宗淳祐</span>  
<span style="margin-left: 2em">十二年紀年旣誤而又以宋理宗年號移之於元</span>  
<span style="margin-left: 2em">殊爲疎舛卽此一端其他可槩見矣</span>  
孔孟事蹟圖譜四卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">明季本撰本有易學四同已著錄是編前說後譜</span>  
<span style="margin-left: 2em">於孔孟事實頗有考核如云孔子未嘗至楚見昭</span>  
<span style="margin-left: 2em">王孟子先至齊而後梁此一二條皆有所見然其</span>  
<span style="margin-left: 2em">餘大抵習聞者多</span>  
素王記事<sub class="note-yuan">無卷數　浙江朱彞尊家曝書亭藏本</sub>  
<!-- 册2 葉1233b　Page:文淵閣四庫全書_0002冊.djvu/313 -->
<span style="margin-left: 2em">舊本卷首題明浙江嚴州府通判太原傳汝楫校</span>  
<span style="margin-left: 2em">正則非汝楫所撰卷末楊奂東遊記之首又題河</span>  
<span style="margin-left: 2em">南開封府知府西蜀黃濬輯錄則似爲濬之所撰</span>  
<span style="margin-left: 2em">然不列名於書首而綴於書後體例叢脞殊不可</span>  
<span style="margin-left: 2em">曉其書則摭拾闕里志爲之亦茫然無緖葢當時</span>  
<span style="margin-left: 2em">書帕之本本不以著書爲事者也<sub class="note-yuan">案顧炎武日知錄曰昔時人覲</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">之官其餽遺一書一帕謂之書帕又曰厯官任滿必刻一書以充餽遺此亦甚雅而鹵莽就工殊不</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">堪讀陸深金臺紀聞亦稱有司刻書祗以供餽贐之用其不工反出坊本下今藏書家以書帕本爲</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">最下葢由於此</sub></span>  
<!-- 册2 葉1236a　Page:文淵閣四庫全書_0002冊.djvu/314 -->
夷齊錄五卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明張玭撰玭字席玉石州人嘉靖乙未進士官至</span>  
<span style="margin-left: 2em">南京戸部右侍郎永平府城西十八里<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2854.svg?width=24" alt="四庫全書僻字第2854號（孤）" title="四庫全書僻字第2854號（孤）">竹故城</span>  
<span style="margin-left: 2em">有淸德廟以祀夷齊玭守永平時因蒐輯厯代祀</span>  
<span style="margin-left: 2em">典諸家藝文編爲一帙據目錄原本有圖此本無</span>  
<span style="margin-left: 2em">之葢爲傳寫者所佚矣</span>  
孔聖全書三十五卷<sub class="note-yuan">衍聖公孔昭煥家藏本</sub>  
<span style="margin-left: 2em">明蔡復賞編復賞巴陵人卷端自題恩貢出身南</span>  
<span style="margin-left: 2em">京戸部修職郎不知其爲何官也前有自序稱是</span>  
<!-- 册2 葉1236b　Page:文淵閣四庫全書_0002冊.djvu/314 -->
<span style="margin-left: 2em">書始成就正於兵部侍郎姜廷頤廷頤廼次爲六</span>  
<span style="margin-left: 2em">卷上卷曰經書中卷曰子史下卷曰雜說首卷曰</span>  
<span style="margin-left: 2em">帝王崇重盛典尾卷曰經術經理世務六卷内復</span>  
<span style="margin-left: 2em">條分爲四十卷云云案序稱上中下卷首尾卷秖</span>  
<span style="margin-left: 2em">有五卷不應稱六卷又書三十五卷與四十卷之</span>  
<span style="margin-left: 2em">數亦不合其間鄙俚荒唐龎雜割裂鬼神怪誕之</span>  
<span style="margin-left: 2em">語優伶褻諢之詞無不載入謂之侮聖人可也</span>  
尊聖集四卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明陳堯道編堯道里籍未詳嘉靖末官大埔縣教</span>  
<!-- 册2 葉1237a　Page:文淵閣四庫全書_0002冊.djvu/314 -->
<span style="margin-left: 2em">諭是書分圖像世家事蹟遺澤制敕譔述封事七</span>  
<span style="margin-left: 2em">門多勦襲祖庭纂要諸書無所考證</span>  
仲志五卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">明劉天和撰天和字飬和麻城人正德戊辰進士</span>  
<span style="margin-left: 2em">官至兵部尙書提督團營諡莊襄事迹具明史本</span>  
<span style="margin-left: 2em">傳是編乃天和官總督河道都御史時以濟寧仲</span>  
<span style="margin-left: 2em">家淺有先賢仲子祠故志其建置之由而并及其</span>  
<span style="margin-left: 2em">生平行事大畧名之曰令名志崇禎中仲子裔孫</span>  
<span style="margin-left: 2em">於陛等復增損舊本易以今名又繪像列圖於卷</span>  
<!-- 册2 葉1237b　Page:文淵閣四庫全書_0002冊.djvu/314 -->
<span style="margin-left: 2em">首殊不雅馴</span>

<span style="margin-left: 2em">明張雲漢撰雲漢字倬侯宿州人是編兼及閔子</span>  
<span style="margin-left: 2em">後裔之事故曰世譜首姓氏次里居次特傳列傳</span>  
<span style="margin-left: 2em">次祀典次修葺次官生次世系次遷徙次復業次</span>

夷齊考疑四卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<!-- 册2 葉1240a　Page:文淵閣四庫全書_0002冊.djvu/315 -->
<span style="margin-left: 2em">明胡其久撰其久崇德人隆慶丁卯舉人官龍南</span>  
<span style="margin-left: 2em">知縣是編以好事者所傳夷齊世系名字皆據韓</span>  
<span style="margin-left: 2em">詩外傳吕氏春秋而附㑹之並以叩馬耻粟等事</span>
