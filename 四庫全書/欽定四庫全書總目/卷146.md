## 欽定四庫全書總目 卷一百四十六　子部五十六　道家類

<!-- 册3 葉4296：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷一百四十六  
<span style="margin-left: 1em">子部五十六</span>  
<span style="margin-left: 2em">道家𩔖</span>  
<span style="margin-left: 3em">後世神怪之迹多附於道家道家亦自矜其異</span>  
<span style="margin-left: 3em">如神仙傳道教靈驗記是也要其本始則主於</span>  
<span style="margin-left: 3em">淸淨自持而濟以堅忍之力以柔制剛以退爲</span>  
<span style="margin-left: 3em">進故申子韓子流爲刑名之學而陰符經可通</span>  
<span style="margin-left: 3em">於兵其後長生之說與神仙家合爲一而服餌</span>  
<span style="margin-left: 3em">導引入之房中一家近於神仙者亦入之鴻寳</span>  
<!-- 册3 葉4297b　Page:文淵閣四庫全書_0003冊.djvu/1079 -->
<span style="margin-left: 3em">有書燒煉入之張魯立教符籙入之北魏㓂謙</span>  
<span style="margin-left: 3em">之等又以齋醮章呪入之世所傳述大抵多後</span>  
<span style="margin-left: 3em">附之文非其本㫖彼教自不能别今亦無事於</span>  
<span style="margin-left: 2em">區分然觀其遺書源流遷變之故尙一　一可稽</span>  
<span style="margin-left: 3em">也</span>  
陰符經解一卷<sub class="note-yuan">浙江鮑士㳟家藏本</sub>  
<span style="margin-left: 2em">舊本題黄帝撰太公范蠡<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">谷子張良諸葛亮李</span>  
<span style="margin-left: 2em">筌六家注崇文總目云陰符經叙一卷不詳何代</span>  
<span style="margin-left: 2em">人叙集太公以後爲陰符經注者凡六家并以惠</span>  
<!-- 册3 葉4300a　Page:文淵閣四庫全書_0003冊.djvu/1080 -->
<span style="margin-left: 2em">光嗣等傳附之葢卽此書而佚其傳也晁公武讀</span>  
<span style="margin-left: 2em">書志引黄庭堅跋稱陰符糅雜兵家語又妄托子</span>  
<span style="margin-left: 2em">房孔明諸賢訓註則是書之註以此本爲最古矣</span>  
<span style="margin-left: 2em">案隋書經籍志有太公陰符鈐錄一卷又周書陰</span>  
<span style="margin-left: 2em">符九卷皆不云黄帝集仙傳始稱唐李筌於嵩山</span>  
<span style="margin-left: 2em">虎口巖石室得此書題曰大魏眞君二年七月七</span>  
<span style="margin-left: 2em">日道士㓂謙之藏之名山用傳同好巳糜爛筌鈔</span>  
<span style="margin-left: 2em">讀數千徧竟不曉其義後於驪山逢老母乃傳授</span>  
<span style="margin-left: 2em">微㫖爲之作註其說怪誕不足信胡應麟筆叢乃</span>  
<!-- 册3 葉4300b　Page:文淵閣四庫全書_0003冊.djvu/1080 -->
<span style="margin-left: 2em">謂蘇秦所讀卽此書故書非僞而托於黄帝則李</span>  
<span style="margin-left: 2em">筌之僞考戰國䇿載蘇秦發篋得太公陰符具有</span>  
<span style="margin-left: 2em">明文又厯代史志皆以周書陰符著錄兵家而黄</span>  
<span style="margin-left: 2em">帝陰符入道家亦足爲判然兩書之證應麟假借</span>  
<span style="margin-left: 2em">牽合殊爲未<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">至所云唐永徽初褚遂良嘗寫一</span>  
<span style="margin-left: 2em">百本者考文徵明停雲館帖所刻遂良小字陰符</span>  
<span style="margin-left: 2em">經卷末實有此文然遂良此帖自米芾書史寳章</span>  
<span style="margin-left: 2em">待訪錄宣和書譜卽不著錄諸家鑒藏亦從不及</span>  
<span style="margin-left: 2em">其名明之中葉忽出於徵明之家石刻之眞僞尙</span>  
<!-- 册3 葉4301a　Page:文淵閣四庫全書_0003冊.djvu/1080 -->
<span style="margin-left: 2em">不可定又烏可據以定書之眞僞乎特以書雖晚</span>  
<span style="margin-left: 2em">出而深有理致故文士多爲註釋今亦錄而存之</span>  
<span style="margin-left: 2em">耳註中别有稱尹曰者不知何人卷首有序一篇</span>  
<span style="margin-left: 2em">不署名氏亦不署年月中有泄天機者沉三刼語</span>  
<span style="margin-left: 2em">葢麤野道流之鄙談無足深詰惟晁公武讀書志</span>  
<span style="margin-left: 2em">中所引筌註今不見於此本或傳寫有所竄亂又</span>  
<span style="margin-left: 2em">非筌之原本歟</span>  
陰符經考異一卷<sub class="note-yuan">江西廵撫採進本</sub>  
<span style="margin-left: 2em">宋朱子撰陰符經出於唐李筌晁公武讀書志引</span>  
<!-- 册3 葉4301b　Page:文淵閣四庫全書_0003冊.djvu/1080 -->
<span style="margin-left: 2em">黄庭堅跋定爲筌所僞托朱子語錄亦以爲然然</span>  
<span style="margin-left: 2em">以其時有精語非深於道者不能作故爲考定其</span>  
<span style="margin-left: 2em">文其定人以愚虞聖而下一百十四字皆爲經文</span>  
<span style="margin-left: 2em">葢用褚氏張氏二注本也語錄載閭邱次孟論陰</span>  
<span style="margin-left: 2em">符經自然之道靜數語雖六經之言無以加朱子</span>  
<span style="margin-left: 2em">謂閭邱此等見處儘得而楊道夫以爲陰符經無</span>  
<span style="margin-left: 2em">此語葢道夫所見乃驪山老母註本以我以時物</span>  
<span style="margin-left: 2em">文理哲爲書之末句故疑其語不見於本經也書</span>  
<span style="margin-left: 2em">中有黄瑞節附錄徵引亦頗賅備考吉安府志瑞</span>  
<!-- 册3 葉4304a　Page:文淵閣四庫全書_0003冊.djvu/1081 -->
<span style="margin-left: 2em">節字觀樂安福人舉鄕試授泰和州學正元季棄</span>  
<span style="margin-left: 2em">官隱居嘗輯太極圖通書西銘易學啟𫎇家禮律</span>  
<span style="margin-left: 2em">吕精義皇極經世諸書并加釋註名曰諸子成書</span>  
<span style="margin-left: 2em">此及參同契葢亦其中之二種志葢以其學渉道</span>  
<span style="margin-left: 2em">家故諱而不載云</span>  
陰符經講義四卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">宋夏元鼎撰元鼎字宗禹自號雲<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2895.svg?width=24" alt="四庫全書僻字第2895號（峯）" title="四庫全書僻字第2895號（峯）">散人永嘉人</span>  
<span style="margin-left: 2em">是編以丹法釋陰符之㫖卷末附内外三闗圖日</span>  
<span style="margin-left: 2em">月聖功圖竒器萬象圖三教歸一圖先天後天圖</span>  
<!-- 册3 葉4304b　Page:文淵閣四庫全書_0003冊.djvu/1081 -->
<span style="margin-left: 2em">上下鵲橋圖七十二候圖五行生成圖各繫以說</span>  
<span style="margin-left: 2em">案漢志道家神仙家截然兩派陰符三百八十四</span>  
<span style="margin-left: 2em">字本李筌自撰而自注之筌注不言爐火則爲道</span>  
<span style="margin-left: 2em">家之言而非神仙家言可知後人注筌之書乃不</span>  
<span style="margin-left: 2em">用筌之自註郢書燕說殆𩔖鑿空然參同契不言</span>  
<span style="margin-left: 2em">易陳摶引以言易遂自爲一家陰符經不言丹此</span>  
<span style="margin-left: 2em">書引以言丹亦遂自爲一家遞相傳授而不能廢</span>  
<span style="margin-left: 2em">故今於陰符一書錄六家之註以存其初義復錄</span>  
<span style="margin-left: 2em">此書以備其旁支所謂從同同也其餘<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2973.svg?width=24" alt="四庫全書僻字第2973號（衍）" title="四庫全書僻字第2973號（衍）">此兩派</span>  
<!-- 册3 葉4305a　Page:文淵閣四庫全書_0003冊.djvu/1081 -->
<span style="margin-left: 2em">者則不更錄焉二氏之書姑存崖畧而巳不必一</span>  
<span style="margin-left: 2em">一窮其說也是書前有寳慶二年樓昉序稱元鼎</span>  
<span style="margin-left: 2em">少從永嘉諸老遊好觀陰符未盡解後遇至人於</span>  
<span style="margin-left: 2em">祝融<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2895.svg?width=24" alt="四庫全書僻字第2895號（峯）" title="四庫全書僻字第2895號（峯）">頂若有所授者復取陰符讀之章斷句析</span>  
<span style="margin-left: 2em">援筆立成若有神物陰來相助云云葢方術家務</span>  
<span style="margin-left: 2em">神其說徃徃如是末又有寳慶丙戌留元剛雲<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2895.svg?width=24" alt="四庫全書僻字第2895號（峯）" title="四庫全書僻字第2895號（峯）"></span>  
<span style="margin-left: 2em">入藥鏡箋序一篇及元鼎自記自亭二篇寳慶丁</span>  
<span style="margin-left: 2em">亥王九萬後序一篇俞琰席上腐談稱元鼎註陰</span>  
<span style="margin-left: 2em">符藥鏡悟眞三書眞西山爲之序與諸序所言悉</span>  
<!-- 册3 葉4305b　Page:文淵閣四庫全書_0003冊.djvu/1081 -->
<span style="margin-left: 2em">合今未見其入藥鏡悟眞篇二註而此本已無德</span>  
<span style="margin-left: 2em">秀序殆傳寫佚之然德秀西山文集亦不載其文</span>  
<span style="margin-left: 2em">則莫喻何故矣</span>  
老子注二卷<sub class="note-yuan">江蘇廵撫採進本</sub>  
<span style="margin-left: 2em">舊本題河上公撰晁公武讀書志曰太史公謂河</span>  
<span style="margin-left: 2em">上丈人通老子再傳而至葢公葢公卽齊相曹參</span>  
<span style="margin-left: 2em">師也而葛洪謂河上公者莫知其姓名漢孝文時</span>  
<span style="margin-left: 2em">居河之濵侍郞裴楷言其通老子孝文詣問之卽</span>  
<span style="margin-left: 2em">授素書道經兩說不同當從太史公云云案晁氏</span>  
<!-- 册3 葉4308a　Page:文淵閣四庫全書_0003冊.djvu/1082 -->
<span style="margin-left: 2em">所引乃史記樂毅列傳贊之文叙述源流甚悉然</span>  
<span style="margin-left: 2em">隋志道家載老子道德經二卷漢文帝時河上公</span>  
<span style="margin-left: 2em">注又載梁有戰國時河上丈人注老子經二卷亡</span>  
<span style="margin-left: 2em">則兩河上公各一人兩老子注各一書戰國時河</span>  
<span style="margin-left: 2em">上公書在隋已亡今所傳者實漢河上公書耳明</span>  
<span style="margin-left: 2em">朱東光刻是書題曰秦人葢未詳考惟是文帝駕</span>  
<span style="margin-left: 2em">臨河上親受其書無不入秘府之理何以劉向七</span>  
<span style="margin-left: 2em">畧載注老子者三家獨不列其名且孔穎逹禮記</span>  
<span style="margin-left: 2em">正義稱馬融爲周禮註欲省學者兩讀故具載本</span>  
<!-- 册3 葉4308b　Page:文淵閣四庫全書_0003冊.djvu/1082 -->
<span style="margin-left: 2em">文後漢以來始就經爲注何以是書作於西漢注</span>  
<span style="margin-left: 2em">已散入各句下唐書劉子元傳稱老子無河上公</span>  
<span style="margin-left: 2em">注欲廢之而立王弼前此陸德明作經典釋文雖</span>  
<span style="margin-left: 2em">叙錄之中亦採葛洪神仙傳之說頗失辨正而所</span>  
<span style="margin-left: 2em">釋之本則不用此注而用王弼注二人皆一代通</span>  
<span style="margin-left: 2em">儒必非無據詳其詞㫖不𩔖漢人殆道流之所依</span>  
<span style="margin-left: 2em">託歟相傳已久所言亦頗有發明姑存以備一家</span>  
<span style="margin-left: 2em">可耳</span>  
道德指歸論六卷<sub class="note-yuan">江蘇廵撫採進本</sub>  
<!-- 册3 葉4309a　Page:文淵閣四庫全書_0003冊.djvu/1082 -->
<span style="margin-left: 2em">舊本題漢嚴遵撰隋志著錄十一卷晁公武讀書</span>  
<span style="margin-left: 2em">志曰唐志有嚴遵指歸四十卷馮廓注指歸十三</span>  
<span style="margin-left: 2em">卷今考新舊唐書均載嚴遵老子指歸十四卷馮</span>  
<span style="margin-left: 2em">廓老子指歸十三卷無嚴遵書四十卷之說疑公</span>  
<span style="margin-left: 2em">武所記爲傳寫誤倒其文也此本爲胡震亨秘冊</span>  
<span style="margin-left: 2em">函所刋後以板歸毛晉編入津逮秘書止存六卷</span>  
<span style="margin-left: 2em">錢曾讀書敏求記云曾得錢叔寳鈔本自七卷至</span>  
<span style="margin-left: 2em">十三卷前有總序後有人之饑也至信言不實四</span>  
<span style="margin-left: 2em">章今皆失去又引谷神子序云道德指歸論陳隋</span>  
<!-- 册3 葉4309b　Page:文淵閣四庫全書_0003冊.djvu/1082 -->
<span style="margin-left: 2em">之間已逸其半今所存者止論德篇近代嘉興刻</span>  
<span style="margin-left: 2em">本列卷一之卷六與序文大相逕庭云云此本亦</span>  
<span style="margin-left: 2em">題卷一之卷六然則震亨所刻卽據嘉興本也曹</span>  
<span style="margin-left: 2em">學佺作元羽外編序稱近刻嚴君平道德指歸論</span>  
<span style="margin-left: 2em">乃吳中所僞作今按通考引晁氏之言<sub class="note-yuan">案此條通考所引與</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">今本讀書志不同</sub>稱其章句頗與諸本不同如以曲則全</span>  
<span style="margin-left: 2em">章末十七字爲次章首之𩔖則是書原有經文陸</span>  
<span style="margin-left: 2em">游集有是書跋稱爲道德經指歸古文亦以經文</span>  
<span style="margin-left: 2em">爲言此本乃不載經文體例互異又谷神子註本</span>  
<!-- 册3 葉4312a　Page:文淵閣四庫全書_0003冊.djvu/1083 -->
<span style="margin-left: 2em">晁氏尙著錄十三卷不云佚闕此本載谷神子序</span>  
<span style="margin-left: 2em">乃云陳隋之間已逸其半今所存者止論德篇因</span>
