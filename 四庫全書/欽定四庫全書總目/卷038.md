## 欽定四庫全書總目 卷三十八　經部三十八　樂類

<!-- 册1 葉3104：整葉圖版，無文字記錄 -->
<!-- 册1 葉3105a　Page:文淵閣四庫全書_0001冊.djvu/826 -->
欽定四庫全書總目卷三十八  
<span style="margin-left: 1em">經部三十八</span>  
<span style="margin-left: 2em">樂類</span>  
<span style="margin-left: 3em">沈約稱樂經亡於秦考諸古籍惟禮記經解有</span>  
<span style="margin-left: 3em">樂教之文伏生尚書大傳引辟雝舟張四語亦</span>  
<span style="margin-left: 3em">謂之樂然他書均不云有樂經<sub class="note-yuan">隋志樂經四卷葢王莽元始三</sub></span>  
<span style="margin-left: 3em"><sub class="note-yuan">年所立賈公彦考工記磬氏疏所稱樂日當卽莽書非古樂經也</sub>大抵樂之綱</span>  
<span style="margin-left: 3em">目具於禮其歌詞具於詩其鏗鏘鼓舞則傳在</span>  
<span style="margin-left: 3em">伶官漢初制氏所記葢其遺譜非別有一經爲</span>  
<!-- 册1 葉3105b　Page:文淵閣四庫全書_0001冊.djvu/826 -->
<span style="margin-left: 3em">聖人手定也特以宣豫導和感神人而通天地</span>  
<span style="margin-left: 3em">厥用至大厥義至精故尊其教得配于經而後</span>  
<span style="margin-left: 3em">代鐘律之書亦遂得著錄於經部不與藝術同</span>  
<span style="margin-left: 3em">科顧自漢氏以來兼陳雅俗艶歌側調並隷雲</span>  
<span style="margin-left: 3em">韶於是諸史所登雖細至筝琶亦附於經末循</span>  
<span style="margin-left: 3em">是以往將小說稗官未嘗不記言記事亦附之</span>  
<span style="margin-left: 3em">書與春秋乎悖理傷教於斯爲甚今區别諸書</span>  
<span style="margin-left: 3em">惟以辨律吕明雅樂者仍列於經其謳歌末技</span>  
<span style="margin-left: 3em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3500.svg?width=24" alt="四庫全書僻字第3500號（「絃」字少最後一點）" title="四庫全書僻字第3500號（「絃」字少最後一點）">管繁聲均退列雜藝詞曲兩類中用以見大</span>  
<!-- 册1 葉3108a　Page:文淵閣四庫全書_0001冊.djvu/827 -->
<span style="margin-left: 3em">樂元音道侔天地非鄭聲所得而奸也</span>  
皇祐新樂圖記三卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">宋阮逸胡瑗奉勅撰仁宗景祐三年二月以李照</span>  
<span style="margin-left: 2em">樂穿鑿特詔較定鐘律依周禮及厯代史志立議</span>  
<span style="margin-left: 2em">範金至皇祐五年樂成奏上此其圖記也舊本從</span>  
<span style="margin-left: 2em">明文淵閣錄出後有宋陳振孫嘉定己亥䟦云借</span>  
<span style="margin-left: 2em">虎邱寺本錄葢當時所賜藏之名山者又有元天</span>  
<span style="margin-left: 2em">厯二年吳壽民䟦明萬厯三十九年趙開美䟦敘</span>  
<span style="margin-left: 2em">此書原委頗詳考初置局時逸瑗與房庶等皆驛</span>  
<!-- 册1 葉3108b　Page:文淵閣四庫全書_0001冊.djvu/827 -->
<span style="margin-left: 2em">召預議詔命諸家各作鐘律以獻而持論互異司</span>  
<span style="margin-left: 2em">馬光主逸瑗之說范鎭則主庶之說往反爭議卒</span>  
<span style="margin-left: 2em">不能以相一其往返書牘具光傳家集中而鎭所</span>  
<span style="margin-left: 2em">作東齋記事亦畧存其槩大抵逸瑗以爲黃鐘之</span>  
<span style="margin-left: 2em">管積八百一十分容一千二百黍又以九章圜田</span>  
<span style="margin-left: 2em">算法計之黃鐘管每長一分積九分容十三黍三</span>  
<span style="margin-left: 2em">分黍之一空徑三分四釐六毫圍十分三釐八毫</span>  
<span style="margin-left: 2em">圍徑用徑三圍九古率而改圍九分爲九方分則</span>  
<span style="margin-left: 2em">遷就之術也司馬光曰古律已亡非黍無以見度</span>  
<!-- 册1 葉3109a　Page:文淵閣四庫全書_0001冊.djvu/827 -->
<span style="margin-left: 2em">非度無以見律律不生於度與黍將何從生非謂</span>  
<span style="margin-left: 2em">太古以來律必生於度也特以近世古律不存故</span>  
<span style="margin-left: 2em">返從度法求之耳其論最明范鎭譏其以度起律</span>  
<span style="margin-left: 2em">誠爲過當然鎭以秬黍律尺龠鬴斛算數權衡鐘</span>  
<span style="margin-left: 2em">聲十者必相合而不相戾然後爲得亦不爲無見</span>  
<span style="margin-left: 2em">也以律起度與以度起律源流本無異同而二家</span>  
<span style="margin-left: 2em">算術不精逸瑗等得之於橫黍而失之於圍徑又</span>  
<span style="margin-left: 2em">以大黍累尺小黍實管自相乖反至庶以千二百</span>  
<span style="margin-left: 2em">黍實之管中隨其長短斷之以爲九寸之管取三</span>  
<!-- 册1 葉3109b　Page:文淵閣四庫全書_0001冊.djvu/827 -->
<span style="margin-left: 2em">分以度空徑則空徑不生於黍而别有一物爲度</span>  
<span style="margin-left: 2em">以起分竟不必實黍於管未見其爲通論也是書</span>  
<span style="margin-left: 2em">上卷具載律吕黍尺四量權衡之法皆以橫黍起</span>  
<span style="margin-left: 2em">度故樂聲失之於髙中下二卷考定鐘磬晉鼓及</span>  
<span style="margin-left: 2em">三牲鼎鸞刀制度則精核可取云</span>  
樂書二百卷<sub class="note-yuan">福建巡撫採進本</sub>  
<span style="margin-left: 2em">宋陳暘撰暘字晉叔閩淸人紹聖中登制科官禮</span>  
<span style="margin-left: 2em">部侍郞事迹具宋史本傳此書乃建中靖國間暘</span>  
<span style="margin-left: 2em">爲秘書省正字時所進自第一卷至九十五卷引</span>  
<!-- 册1 葉3112a　Page:文淵閣四庫全書_0001冊.djvu/828 -->
<span style="margin-left: 2em">三禮詩書春秋周易孝經論語孟子之言各爲之</span>  
<span style="margin-left: 2em">訓義其第九十六卷至二百卷則專論律吕本義</span>  
<span style="margin-left: 2em">樂器樂章及五禮之用樂者爲樂圖論引據浩博</span>  
<span style="margin-left: 2em">辨論亦極精審視其兄祥道禮書殆相伯仲第禮</span>  
<span style="margin-left: 2em">書所載祗詳於三代器數是書則又推其律吕本</span>  
<span style="margin-left: 2em">原及後世雅俗諸部故陳振孫書錄解題謂樂書</span>  
<span style="margin-left: 2em">博則博矣未能免於蕪穢也然暘書包括厯代總</span>  
<span style="margin-left: 2em">述前聞旣欲備悉源流自不得不兼陳正變使振</span>  
<span style="margin-left: 2em">孫操筆而修史將舉古來秕政亂法一切刪之不</span>  
<!-- 册1 葉3112b　Page:文淵閣四庫全書_0001冊.djvu/828 -->
<span style="margin-left: 2em">載乎此南宋人迂謬之見不足據也其中惟辨二</span>  
<span style="margin-left: 2em">變四淸二條實爲紕繆自古論四淸者以民臣相</span>  
<span style="margin-left: 2em">避以爲尊卑立說本屬附㑹暘則曰黃鐘至夾鐘</span>  
<span style="margin-left: 2em">四淸聲以附正聲之次其意葢爲夷則至應鐘四</span>  
<span style="margin-left: 2em">宫而設旣謂黃鐘至夾鐘爲淸又謂爲夷則至應</span>  
<span style="margin-left: 2em">鐘而設是兩四淸也不知每均必具五聲夷則一</span>  
<span style="margin-left: 2em">均以夷南無應爲次而闕角聲必須黃鐘淸爲角</span>  
<span style="margin-left: 2em">南吕一均以南無應爲次而闕羽角二聲必須黃</span>  
<span style="margin-left: 2em">淸爲羽大淸爲角以調而論則謂夷南無應四律</span>  
<!-- 册1 葉3113a　Page:文淵閣四庫全書_0001冊.djvu/828 -->
<span style="margin-left: 2em">以聲而言則爲黃大太夾四淸非有二也其不用</span>  
<span style="margin-left: 2em">正聲而用淸聲者樂之髙下以漸無驟髙驟下之</span>  
<span style="margin-left: 2em">理以夷則一均言之如用夷有無應四正律則其</span>  
<span style="margin-left: 2em">聲以次而髙而忽用黃鐘正律雖同在一均而髙</span>  
<span style="margin-left: 2em">下不協故必以黃淸協之也暘引李照十二鐘之</span>  
<span style="margin-left: 2em">說殊爲舛誤又論二變曰五聲者樂之指拇也二</span>  
<span style="margin-left: 2em">變者五聲之駢枝也五聲可益爲七音則五星五</span>  
<span style="margin-left: 2em">行五常亦可益而七之乎二變之說始於尚書而</span>  
<span style="margin-left: 2em">蔓衍於左傳國語書傳漢志是不知書之在治忽</span>  
<!-- 册1 葉3113b　Page:文淵閣四庫全書_0001冊.djvu/828 -->
<span style="margin-left: 2em">有五聲而無七始國語之七同有四宫而無徵也</span>  
<span style="margin-left: 2em">左氏爲七音之說葢八音耳八音以土爲主而七</span>  
<span style="margin-left: 2em">音非土不和故書之益稷禮之樂記其言八者皆</span>  
<span style="margin-left: 2em">虛其一猶大衍虛其一也云云不知二變之生由</span>  
<span style="margin-left: 2em">於高下之次蔡元定相去二律則音節遠之說最</span>  
<span style="margin-left: 2em">有根據若不究其理之所由然而但以數相較則</span>  
<span style="margin-left: 2em">七較之五而多其二者將十二較之五而亦多其</span>  
<span style="margin-left: 2em">七是音不得有其七而律亦不得有其十二乎且</span>  
<span style="margin-left: 2em">五聲二變有管律<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3500.svg?width=24" alt="四庫全書僻字第3500號（「絃」字少最後一點）" title="四庫全書僻字第3500號（「絃」字少最後一點）">度之不同半太蔟與正黃鐘</span>  
<!-- 册1 葉3116a　Page:文淵閣四庫全書_0001冊.djvu/829 -->
<span style="margin-left: 2em">應半夾鐘與正大吕應此理尤爲暘所不知也至</span>  
<span style="margin-left: 2em">以七音爲八音虛土而言尤爲牽强矣又其釋周</span>  
<span style="margin-left: 2em">官三宫之樂以圜黃太姑爲宫之旋而在天者故</span>  
<span style="margin-left: 2em">其合别而爲四函太姑南爲宫之旋而在地者故</span>  
<span style="margin-left: 2em">其合降而爲三黃大太應爲宫之旋而在人者故</span>  
<span style="margin-left: 2em">其合降而爲二若然則天宫用八律地宫用六律</span>  
<span style="margin-left: 2em">人宫用四律以多少爲差别也而圜丘樂六變方</span>  
<span style="margin-left: 2em">丘樂八變宗廟樂九變又何以解耶凡此之類皆</span>  
<span style="margin-left: 2em">不可據爲典要然唐以來樂書無傳北宋樂書惟</span>  
<!-- 册1 葉3116b　Page:文淵閣四庫全書_0001冊.djvu/829 -->
<span style="margin-left: 2em">皇祐新樂圖記及此書存耳遺文緖論條理可徴</span>  
<span style="margin-left: 2em">又安可以一眚廢耶</span>  
律吕新書二卷<sub class="note-yuan">編修李潢家藏本</sub>  
<span style="margin-left: 2em">宋蔡元定撰元定字季通建陽人慶元中坐黨禁</span>  
<span style="margin-left: 2em">流道州卒事迹具宋史道學傳朱子稱其律書法</span>  
<span style="margin-left: 2em">度甚精近世諸儒皆莫能及又云季通理㑹樂律</span>  
<span style="margin-left: 2em">大段有心力看得許多書及爲是書作序又曰黃</span>  
<span style="margin-left: 2em">鐘圍徑之數則漢斛之積分可考寸以九分爲法</span>  
<span style="margin-left: 2em">則淮南太史小司馬之說可推五聲二變之數變</span>  
<!-- 册1 葉3117a　Page:文淵閣四庫全書_0001冊.djvu/829 -->
<span style="margin-left: 2em">律半聲之例則杜氏之通典具焉變宫變徴之不</span>  
<span style="margin-left: 2em">得爲調則孔氏之禮疏固亦可見至於先求聲氣</span>  
<span style="margin-left: 2em">之元而因律以生尺則尤所謂卓然者而亦班班</span>  
<span style="margin-left: 2em">雜見於兩漢之制蔡邕之說與夫國朝會要以及</span>  
<span style="margin-left: 2em">程子張子之言葢是書實朱蔡師弟子相與共成</span>  
<span style="margin-left: 2em">之者故獨見許如此書分二卷一爲律吕本原凡</span>  
<span style="margin-left: 2em">十三篇黃鐘第一黃鐘之實第二黃鐘生十一律</span>  
<span style="margin-left: 2em">第三十二律之實第四變律第五律生五聲圖第</span>  
<span style="margin-left: 2em">六變聲第七八十四聲圖第八六十調圖第九候</span>  
<!-- 册1 葉3117b　Page:文淵閣四庫全書_0001冊.djvu/829 -->
<span style="margin-left: 2em">氣第十審度第十一嘉量第十二謹權衡第十三</span>  
<span style="margin-left: 2em">其一卷爲律吕證辨凡十篇造律第一律長短圍</span>  
<span style="margin-left: 2em">徑之數第二黃鐘之實第三三分損益上下相生</span>  
<span style="margin-left: 2em">第四和聲第五五聲大小之次第六變官變徴第</span>  
<span style="margin-left: 2em">七六十調第八候氣第九度量權衡第十今考元</span>  
<span style="margin-left: 2em">定之說多截竹以擬黃鐘之管皆卽以其長權爲</span>  
<span style="margin-left: 2em">九寸而度其圍徑如黃鐘之法更迭以吹則中聲</span>  
<span style="margin-left: 2em">可得淺深以列則中氣可驗是截管之法必本之</span>  
<span style="margin-left: 2em">候氣也而候氣之說最爲荒渺後漢晉隋志所載</span>  
<!-- 册1 葉3120a　Page:文淵閣四庫全書_0001冊.djvu/830 -->
<span style="margin-left: 2em">又各異同旣云以木爲案加律其上又云埋之上</span>  
<span style="margin-left: 2em">與地平又云置於案上而以土埋之上平於地此</span>  
<span style="margin-left: 2em">置律有淺深髙下之不一也旣云以葭莩灰抑其</span>  
<span style="margin-left: 2em">内端氣至者灰去又云以竹莩灰實律以羅縠覆</span>  
<span style="margin-left: 2em">律口氣至吹灰動縠有小動大動不動三說又云</span>  
<span style="margin-left: 2em">灰飛動素散出於外而氣應有早晚灰飛有多少</span>  
<span style="margin-left: 2em">其說又不一也然則候氣旣不足憑人聲又無左</span>  
<span style="margin-left: 2em">驗是蔡氏所謂聲氣之元者亦徒爲美聽而已非</span>
