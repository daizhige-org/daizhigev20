## 欽定四庫全書總目 卷一百八十八　集部四十一　總集類三

<!-- 册5 葉192：整葉圖版，無文字記錄 -->
<!-- 册5 葉193a　Page:文淵閣四庫全書_0005冊.djvu/53 -->
欽定四庫全書總目卷一百八十八  
<span style="margin-left: 1em">集部四十一</span>  
<span style="margin-left: 2em">總集類三</span>  
中州集十卷附中州樂府一卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">金元好問編好問有續夷堅志巳著錄是集錄金</span>  
<span style="margin-left: 2em">一代之詩首錄顯宗二首章宗一首不入卷數其</span>  
<span style="margin-left: 2em">餘分爲十集以十干紀之辛集目錄旁注別起二</span>  
<span style="margin-left: 2em">字其人亦復始於金初似乎七卷以前爲正集七</span>  
<span style="margin-left: 2em">卷以後爲續集也壬集自馬舜之下別標諸相一</span>  
<!-- 册5 葉193b　Page:文淵閣四庫全書_0005冊.djvu/53 -->
<span style="margin-left: 2em">門列劉豫等十六人狀元一門列鄭子聃等八人</span>  
<span style="margin-left: 2em">異人一門列王中立等四人隠德一門列薛繼先</span>  
<span style="margin-left: 2em">宋可張潛曹珏四人詩而獨標繼先名疑傳寫訛</span>  
<span style="margin-left: 2em">脱癸集列知已三人曰辛愿李汾李獻甫南冠五</span>  
<span style="margin-left: 2em">人曰司馬朴滕茂實何宏中姚孝錫朱弁而附見</span>  
<span style="margin-left: 2em">宋遺民趙滋及好問父兄詩於末前有好問自叙</span>  
<span style="margin-left: 2em">稱魏道明作百家詩畧商衡爲附益之好問又增</span>  
<span style="margin-left: 2em">以巳之所錄以成是編序作於癸巳葢哀宗天興</span>  
<span style="margin-left: 2em">二年也其例毎人各爲小傳詳具始未兼評其詩</span>  
<!-- 册5 葉196a　Page:文淵閣四庫全書_0005冊.djvu/54 -->
<span style="margin-left: 2em">或一傳而附見數人如乙集張子羽下附載僧可</span>  
<span style="margin-left: 2em">道鮮于可高鵾王景徽吳演之類或附載他文如</span>  
<span style="margin-left: 2em">丙集党懷英下附載誅永蹈詔書之類或兼及他</span>  
<span style="margin-left: 2em">事如乙集祝簡下附載所論王洙不注杜詩之類</span>  
<span style="margin-left: 2em">大致主於借詩以存史故旁見側出不主一格至</span>  
<span style="margin-left: 2em">壬集賈益謙條下述其言世宗大定三十年中能</span>  
<span style="margin-left: 2em">𭧂海陵蟄惡者得美仕史官修實錄誣其淫毒狠</span>  
<span style="margin-left: 2em">鷙遺𦤀無窮自今觀之百無一信又稱衛王勤儉</span>  
<span style="margin-left: 2em">愼惜名器較其行事中材不能及者多如斯之類</span>  
<!-- 册5 葉196b　Page:文淵閣四庫全書_0005冊.djvu/54 -->
<span style="margin-left: 2em">尤足存一代之公論王士禎池北偶談嘗論其記</span>  
<span style="margin-left: 2em">蔡松年事不免曲筆然亦白璧之瑕不足以累全</span>  
<span style="margin-left: 2em">體矣惟大書劉豫國號年號頗<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2615.svg?width=24" alt="四庫全書僻字第2615號（垂）" title="四庫全書僻字第2615號（垂）">史法然豫之立</span>  
<span style="margin-left: 2em">國實金朝所命好問金之臣子宜有内詞固不得</span>  
<span style="margin-left: 2em">而擅削之亦未可以是爲咎也其選錄諸詩頗極</span>  
<span style="margin-left: 2em">精審實在宋末江湖諸𣲖之上故卷末自題有若</span>  
<span style="margin-left: 2em">從華實評詩品未便吳儂得錦袍及北人不拾江</span>  
<span style="margin-left: 2em">西唾末要曾郎借齒牙句士禎亦深不滿之殆以</span>  
<span style="margin-left: 2em">門戸不同歟後附中州樂府一卷與此集皆毛晉</span>  
<!-- 册5 葉197a　Page:文淵閣四庫全書_0005冊.djvu/54 -->
<span style="margin-left: 2em">所刋卷末各有晉跋稱初刻中州集佚其樂府後</span>  
<span style="margin-left: 2em">得陸深家所藏樂府乃足成之今考集中小傳皆</span>  
<span style="margin-left: 2em">兼評其樂府是樂府與中州集合爲一編之明証</span>  
<span style="margin-left: 2em">今亦仍舊本錄之不别入詞曲類焉</span>  
唐詩鼓吹十卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">不著編輯者名氏據趙孟頫序稱爲金元好問所</span>  
<span style="margin-left: 2em">編其門人中書左丞郝天挺所註</span>  
<span style="margin-left: 1em">國朝常熟陸貽典題詞則據金史隠逸傳謂天挺乃</span>  
<span style="margin-left: 2em">好問之師非其門人又早衰厭科舉不復充賦亦</span>  
<!-- 册5 葉197b　Page:文淵閣四庫全書_0005冊.djvu/54 -->
<span style="margin-left: 2em">非中書左丞頗以爲疑按王士禎池北偶談曰金</span>  
<span style="margin-left: 2em">元間有兩郝天挺一爲元遺山之師一爲遺山弟</span>  
<span style="margin-left: 2em">子考元史郝經傳云其先潞州人徙澤州之陵川</span>  
<span style="margin-left: 2em">祖天挺字晉<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">元裕之嘗從之學裕之謂經曰汝</span>  
<span style="margin-left: 2em">貌類祖才器非常者是也其一字繼先出於多羅</span>  
<span style="margin-left: 2em"><sub class="note-yuan">原作朶魯今改正</sub>别族父哈賞巴圖爾<sub class="note-yuan">原作和上㧞都魯今改正</sub>元太</span>  
<span style="margin-left: 2em">宗世多著武功天挺英爽剛<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">有志畧受業於遺</span>  
<span style="margin-left: 2em">山元好問累官河南行省平章事追封冀國公諡</span>  
<span style="margin-left: 2em">文定爲皇慶名臣當修雲南實錄五卷又註唐詩</span>  
<!-- 册5 葉200a　Page:文淵閣四庫全書_0005冊.djvu/55 -->
<span style="margin-left: 2em">鼓吹集十卷近常熟刻鼓吹集乃以爲隠逸傳之</span>  
<span style="margin-left: 2em">晉<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">而致疑於趙文敏之序稱尙書左丞又於尙</span>  
<span style="margin-left: 2em">書左丞上妄加金字誤甚云云然則貽典等所考</span>  
<span style="margin-left: 2em">知其一而不知其二矣是集所錄皆唐人七言律</span>  
<span style="margin-left: 2em">詩凡九十六家共五百九十六首作者各題其名</span>  
<span style="margin-left: 2em">惟柳宗元杜牧題其字未喻何故第四卷中宋邕</span>  
<span style="margin-left: 2em">詩十一首天挺註以爲實出曹唐集中題作宋邕</span>  
<span style="margin-left: 2em">當必有據然第八卷中胡宿詩二十三首今並見</span>  
<span style="margin-left: 2em">文恭集中實爲宋詩誤入則亦不免小有疎舛顧</span>  
<!-- 册5 葉200b　Page:文淵閣四庫全書_0005冊.djvu/55 -->
<span style="margin-left: 2em">其書與方回瀛奎律髓同出元初而去取謹嚴軌</span>  
<span style="margin-left: 2em">轍歸一大抵遒健宏敞無宋末江湖四靈𤨏碎寒</span>  
<span style="margin-left: 2em">儉之習實出方書之上天挺之註雖頗簡畧而但</span>  
<span style="margin-left: 2em">釋出典尙不渉於穿鑿亦不似明廖文炳等所觧</span>  
<span style="margin-left: 2em">横生枝節庸而至於妄也據都卬三餘贅筆此書</span>  
<span style="margin-left: 2em">至大戊申江浙儒司刋本舊有姚燧武一昌二序</span>  
<span style="margin-left: 2em">此本佚之又載燧序謂宋高宗嘗纂唐宋軼事爲</span>  
<span style="margin-left: 2em">幽閒鼓吹故好問本之按三都二京五經鼓吹其</span>  
<span style="margin-left: 2em">語見於世説好問立名當由於此燧所觧不免附</span>  
<!-- 册5 葉201a　Page:文淵閣四庫全書_0005冊.djvu/55 -->
<span style="margin-left: 2em">會其文也</span>  
二妙集八卷<sub class="note-yuan">江蘇廵撫採進本</sub>  
<span style="margin-left: 2em">金叚克已叚成已兄弟詩集也克已字復之號遯</span>  
<span style="margin-left: 2em">庵成已字誠之號菊軒稷山人克已金末嘗舉進</span>  
<span style="margin-left: 2em">士入元不仕成已登正大閒進士授宜陽主簿元</span>  
<span style="margin-left: 2em">初起爲平陽府儒學提舉堅拒不赴兄弟並以節</span>  
<span style="margin-left: 2em">終初克已成已均早以文章擅名金尙書趙秉文</span>  
<span style="margin-left: 2em">嘗目之曰二妙故其合編詩集卽以爲名㤗定間</span>  
<span style="margin-left: 2em">克已之孫輔官吏部侍郎以示吳澄始序而傳之</span>  
<!-- 册5 葉201b　Page:文淵閣四庫全書_0005冊.djvu/55 -->
<span style="margin-left: 2em">朱彛尊曝書亭書目於二妙集下乃題作叚鏞叚</span>  
<span style="margin-left: 2em">鐸撰考虞集所作叚氏世德碑鏞鐸實克已成已</span>  
<span style="margin-left: 2em">之五世祖鐸官至防禦使未嘗有集行世彛尊葢</span>  
<span style="margin-left: 2em">偶悞也集凡詩六卷樂府二卷大抵骨力堅勁意</span>  
<span style="margin-left: 2em">致蒼凉値故都傾覆之餘悵懷今昔流露於不自</span>  
<span style="margin-left: 2em">知吳澄序言其有感於興亡之會故陶之逹杜之</span>  
<span style="margin-left: 2em">憂其詩兼而有之所評良允房祺編河汾諸老詩</span>  
<span style="margin-left: 2em">八卷皆金之遺民從元好問遊者克已兄弟與焉</span>  
<span style="margin-left: 2em">而好問編中州集金源一代作者畢備乃獨無二</span>  
<!-- 册5 葉204a　Page:文淵閣四庫全書_0005冊.djvu/56 -->
<span style="margin-left: 2em">人之詩葢好問編中州集時爲金哀宗天興二年</span>  
<span style="margin-left: 2em">癸巳方遭逄離亂留𣻉聊城自序稱據商衡百家</span>  
<span style="margin-left: 2em">詩畧及所記憶者錄之必偶未得二人之作是以</span>  
<span style="margin-left: 2em">不載故又稱嗣有所得當以甲乙次第之非削而</span>  
<span style="margin-left: 2em">不錄也河汾諸老詩集所載尙有克已楸花詩一</span>  
<span style="margin-left: 2em">首成己蘇氏承顔堂等詩七首皆不在此集中疑</span>  
<span style="margin-left: 2em">當時所自刪削又此集成巳冬夜無寐一首中秋</span>  
<span style="margin-left: 2em">二首雲中暮雨一首河汾諸老詩集皆題爲克已</span>  
<span style="margin-left: 2em">作此集出自叚氏家藏編次必無舛錯當屬房祺</span>  
<!-- 册5 葉204b　Page:文淵閣四庫全書_0005冊.djvu/56 -->
<span style="margin-left: 2em">誤收今姑各仍其舊而特識其同異於此焉</span>  
谷音二卷<sub class="note-yuan">江蘇廵撫採進本</sub>  
<span style="margin-left: 2em">元杜本編本有淸江碧嶂集巳著錄是編末有張</span>  
<span style="margin-left: 2em">榘䟦稱右詩一卷凡二十三人無名者四人共一</span>  
<span style="margin-left: 2em">百首明毛晉跋則稱谷音二卷宋末逸民詩也凡</span>  
<span style="margin-left: 2em">二十有九人詩百篇此本上卷凡十人詩五十首</span>  
<span style="margin-left: 2em">下卷凡十五人無名者五人詩五十一首當爲三</span>  
<span style="margin-left: 2em">十人詩一百一首與二跋皆不合其𨤲爲二卷亦</span>  
<span style="margin-left: 2em">不知始自何人也毎人各載小傳惟柯芝柯茂謙</span>  
<!-- 册5 葉205a　Page:文淵閣四庫全書_0005冊.djvu/56 -->
<span style="margin-left: 2em">父子共一傳楊應登楊零祖孫共一傳凡小傳二</span>  
<span style="margin-left: 2em">十有八其間如王澮程自修冉琇元吉孟鯁皆金</span>  
<span style="margin-left: 2em">元間人張璜以牙兵戰没汪涯以不草露布爲賈</span>  
<span style="margin-left: 2em">似道所殺毛晉以爲皆宋逸民亦約畧大槩言之</span>  
<span style="margin-left: 2em">耳本所著淸江碧嶂集詞意粗淺不稱其名而是</span>  
<span style="margin-left: 2em">集所錄乃皆古<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">悲凉風格遒上無宋末江湖齷</span>  
<span style="margin-left: 2em">齪之習其人又皆仗節守義之士足爲詩重王士</span>  
<span style="margin-left: 2em">禎論詩絶句曰誰嗣篋中冰雪句谷音一卷獨錚</span>  
<span style="margin-left: 2em">錚其品題當矣</span>  
<!-- 册5 葉205b　Page:文淵閣四庫全書_0005冊.djvu/56 -->
河汾諸老詩集八卷<sub class="note-yuan">安徽廵撫採進本</sub>  
<span style="margin-left: 2em">元房祺編祺平陽人據高昂霄跋稱祺爲大同路</span>  
<span style="margin-left: 2em">儒學教授而祺作後序自稱横汾隠者豈罷官後</span>  
<span style="margin-left: 2em">乃編斯集𫆀所編凡麻革張宇陳賡陳颺房皥叚</span>  
<span style="margin-left: 2em">克己叚成已曹之謙八人之詩人各一卷皆金之</span>  
<span style="margin-left: 2em">遺老從元好問游者曹之謙本大同人以流寓河</span>  
<span style="margin-left: 2em">汾遂營邱墓故總以河汾諸老題焉祺後序稱好</span>  
<span style="margin-left: 2em">問有專集行世故不錄其詩然叚氏兄弟亦自有</span>  
<span style="margin-left: 2em">二妙集乃其孫輔所編葢二妙集出於泰定中祺</span>  
<!-- 册5 葉208a　Page:文淵閣四庫全書_0005冊.djvu/57 -->
<span style="margin-left: 2em">爲此集時尙未輯成故其詩仍得錄入也其書成</span>  
<span style="margin-left: 2em">於大德間皇慶癸丑高昂霄爲鋟板明宏治十一</span>  
<span style="margin-left: 2em">年御史沁水李叔淵復授開封同知謝景星刋行</span>
