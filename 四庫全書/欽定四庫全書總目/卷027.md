## 欽定四庫全書總目 卷二十七　經部二十七　春秋類二

<!-- 册1 葉2168a　Page:文淵閣四庫全書_0001冊.djvu/592 -->
欽定四庫全書總目卷二十七  
<span style="margin-left: 1em">經部二十七</span>  
<span style="margin-left: 2em">春秋類二</span>  
春秋經解十二卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋崔子方撰子方涪陵人字彦直號西疇居士晁</span>  
<span style="margin-left: 2em">說之集又稱其字伯直葢有二字也朱彝尊經義</span>  
<span style="margin-left: 2em">考稱其嘗知滁州曾子開爲作茶仙亭記經解諸</span>  
<span style="margin-left: 2em">書皆罷官後所作考子方宋史無傳惟李心傳建</span>  
<span style="margin-left: 2em">炎以來繫年要錄稱其於紹聖間三上疏乞置春</span>  
<!-- 册1 葉2168b　Page:文淵閣四庫全書_0001冊.djvu/592 -->
<span style="margin-left: 2em">秋博士不報乃隱居眞州六合縣杜門著書者三</span>  
<span style="margin-left: 2em">十餘年陳振孫書錄解題所載大畧相同朱震進</span>  
<span style="margin-left: 2em">書劄子亦稱爲東川布衣彝尊之說不知何據惟</span>  
<span style="margin-left: 2em">永樂大典引儀眞志一條云子方與蘇黃游嘗爲</span>  
<span style="margin-left: 2em">知滁州曾子開作茶仙亭記刻石醉翁亭側黃庭</span>  
<span style="margin-left: 2em">堅稱爲六合佳士殆彝尊誤記是事故云然歟考</span>  
<span style="margin-left: 2em">子方著是書時王安石之說方盛行故不能表見</span>  
<span style="margin-left: 2em">於世至南渡以後其書始顯王應麟玉海載建炎</span>  
<span style="margin-left: 2em">二年六月江端友請下湖州取崔子方所著春秋</span>  
<!-- 册1 葉2169a　Page:文淵閣四庫全書_0001冊.djvu/592 -->
<span style="margin-left: 2em">傳藏秘書紹興六年八月子方之孫若上之是時</span>  
<span style="margin-left: 2em">朱震爲翰林學士亦有劄子上請當時葢甚重其</span>  
<span style="margin-left: 2em">書矣子方自序云聖人欲以繩當世之是非著來</span>  
<span style="margin-left: 2em">世之懲勸故辭之難明者著例以見之例不可盡</span>  
<span style="margin-left: 2em">故有日月之例有變例愼思精考若網在綱又後</span>  
<span style="margin-left: 2em">序一篇具述其疏解之宗㫖大抵推本經義於三</span>  
<span style="margin-left: 2em">傳多所糾正如以晉文圍鄭謂討其不會翟泉以</span>  
<span style="margin-left: 2em">郕伯來奔爲見迫於齊以齊侯滅萊不書名辨禮</span>  
<span style="margin-left: 2em">記諸侯滅同姓名之誤類皆諸家所未發雖其中</span>  
<!-- 册1 葉2169b　Page:文淵閣四庫全書_0001冊.djvu/592 -->
<span style="margin-left: 2em">過泥日月之例持論不無偏駁而條其長義實足</span>  
<span style="margin-left: 2em">自成一家所撰凡經解本例例要三書通志堂經</span>  
<span style="margin-left: 2em">解刊本僅有本例今從永樂大典裒輯成編各還</span>  
<span style="margin-left: 2em">其舊自僖公十四年秋至三十二年襄公十六年</span>  
<span style="margin-left: 2em">夏至三十一年永樂大典並闕則取黃震日抄所</span>  
<span style="margin-left: 2em">引及本例補之其他本例所釋有引伸此書所未</span>  
<span style="margin-left: 2em">發或與此書小有異同者並節取附錄而卷袠書</span>  
<span style="margin-left: 2em">名則並遵宋史至子方原書經文已不可見今以</span>  
<span style="margin-left: 2em">所解參證知大畧皆從左氏而亦間有從公穀者</span>  
<!-- 册1 葉2172a　Page:文淵閣四庫全書_0001冊.djvu/593 -->
<span style="margin-left: 2em">故與胡安國春秋傳或有異同以非宏㫖之所繋</span>  
<span style="margin-left: 2em">今亦各隨原文錄之焉</span>  
春秋本例二十卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋崔子方撰是書大㫖以爲聖人之書編年以爲</span>  
<span style="margin-left: 2em">體舉時以爲名著日月以爲例而日月之例又其</span>  
<span style="margin-left: 2em">本故曰本例凡一十六門皆以日月時推之而分</span>  
<span style="margin-left: 2em">著例變例二則州分部居自成條理考公羊穀梁</span>  
<span style="margin-left: 2em">二傳專以日月爲例固有穿鑿破碎之病然經書</span>  
<span style="margin-left: 2em">公子益師卒左傳稱公不與小殮故不書日則日</span>  
<!-- 册1 葉2172b　Page:文淵閣四庫全書_0001冊.djvu/593 -->
<span style="margin-left: 2em">月爲例已在二傳之前疑其時去聖未遠必有所</span>  
<span style="margin-left: 2em">受但予奪筆削寓義宏深日月特其中之一例故</span>  
<span style="margin-left: 2em">一家所說時亦有合而推之以槩全經則支離轇</span>  
<span style="margin-left: 2em">轕而不可以盡通至於必不可通於是乎委曲遷</span>  
<span style="margin-left: 2em">就而變例生焉此非以日月爲例之過而全以日</span>  
<span style="margin-left: 2em">月爲例之過也亦猶易中有互體未嘗非取象之</span>  
<span style="margin-left: 2em">一義故繫辭稱雜物撰德辨是與非則非其中爻</span>  
<span style="margin-left: 2em">不備然使必卦卦以互體求象則牽合穿鑿其說</span>  
<span style="margin-left: 2em">遂至於難通王弼註易一掃互體啖助趙匡說春</span>  
<!-- 册1 葉2173a　Page:文淵閣四庫全書_0001冊.djvu/593 -->
<span style="margin-left: 2em">秋亦一掃諸例而空之豈非有激而然乎子方此</span>  
<span style="margin-left: 2em">書陳振孫書錄解題稱其學辨正三傳之是非而</span>  
<span style="margin-left: 2em">專以日月爲例則正𮛫其失而不悟所論甚允然</span>  
<span style="margin-left: 2em">依據舊傳雖嫌墨守要猶愈於放言高論逞私臆</span>  
<span style="margin-left: 2em">而亂聖經說春秋者古來有此一家今亦未能遽</span>  
<span style="margin-left: 2em">廢焉</span>  
春秋例要一卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋崔子方撰考宋史藝文志載子方春秋經解十</span>  
<span style="margin-left: 2em">二卷本例例要二十卷以本例例要統爲卷數知</span>  
<!-- 册1 葉2173b　Page:文淵閣四庫全書_0001冊.djvu/593 -->
<span style="margin-left: 2em">子方所著原本此書與本例合併爲一矣朱彝尊</span>  
<span style="margin-left: 2em">經義考稱本例例要二十卷並存亦未爲分析今</span>  
<span style="margin-left: 2em">通志堂所刋之本例則析目錄別爲一卷以足二</span>  
<span style="margin-left: 2em">十卷之數而例要闕焉葢傳寫者佚其例要一卷</span>  
<span style="margin-left: 2em">後來遂誤以本例目錄爲例要而不知其别有一</span>  
<span style="margin-left: 2em">篇彝尊所見當卽此本故誤註爲並存也今考永</span>  
<span style="margin-left: 2em">樂大典尚多載其原文雖分析爲數十百條繫於</span>  
<span style="margin-left: 2em">各字之下而尋其端緒尚可相屬較通志堂本所</span>  
<span style="margin-left: 2em">載目錄一字不同灼然知通志堂本爲不全之帙</span>  
<!-- 册1 葉2176a　Page:文淵閣四庫全書_0001冊.djvu/594 -->
<span style="margin-left: 2em">謹編綴前後畧依本例次序排纂成編以還子方</span>  
<span style="margin-left: 2em">所著三書之舊焉</span>  
春秋五禮例宗七卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">宋張大亨撰大亨字嘉父湖州人登元豐乙丑乙</span>  
<span style="margin-left: 2em">科何薳春渚紀聞王明淸玉照新志並載其嘗官</span>  
<span style="margin-left: 2em">司勳員外郞以王國侍讀侍講官名與朝廷相紊</span>  
<span style="margin-left: 2em">奏請改正事陳振孫書錄解題則稱爲直秘閣吳</span>  
<span style="margin-left: 2em">興張大亨撰葢舉其所終之官也考左傳發凡杜</span>  
<span style="margin-left: 2em">預謂皆周公禮典韓起見易象春秋亦謂周禮在</span>  
<!-- 册1 葉2176b　Page:文淵閣四庫全書_0001冊.djvu/594 -->
<span style="margin-left: 2em">魯孫復作春秋尊王發微葉夢得譏其不深於禮</span>  
<span style="margin-left: 2em">學故其言多自牴牾葢禮與春秋本相表裏大亨</span>  
<span style="margin-left: 2em">是編以杜預釋例與經踳駁兼不能賅盡陸淳所</span>  
<span style="margin-left: 2em">集啖趙春秋纂例亦支離失眞因取春秋事蹟分</span>  
<span style="margin-left: 2em">吉凶軍賓嘉五禮依類別記各爲總論義例賅貫</span>  
<span style="margin-left: 2em">而無諸家拘例之失振孫稱其詳洽殆非溢美吳</span>  
<span style="margin-left: 2em">澄春秋纂言分列五禮多與此書相出入朱𢑴尊</span>  
<span style="margin-left: 2em">經義考載此書十卷注曰存而諸家寫本皆佚其</span>  
<span style="margin-left: 2em">軍禮三卷然永樂大典凡引此書皆吉凶嘉賓四</span>  
<!-- 册1 葉2177a　Page:文淵閣四庫全書_0001冊.djvu/594 -->
<span style="margin-left: 2em">禮之文軍禮絶無一字則此三卷之佚久矣𢑴尊</span>  
<span style="margin-left: 2em">偶未核檢也</span>  
春秋通訓六卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋張大亨撰是書自序謂少聞春秋於趙郡和仲</span>  
<span style="margin-left: 2em">先生考宋蘇軾年譜軾本字和仲又蘇泃族譜稱</span>  
<span style="margin-left: 2em">爲唐相蘇頲之裔孫系出趙郡今所傳軾題烟江</span>  
<span style="margin-left: 2em">疊嶂圖詩石刻末亦有趙郡蘇氏印然則趙郡和</span>  
<span style="margin-left: 2em">仲先生卽軾也蘇籀雙溪集載大亨以春秋義問</span>  
<span style="margin-left: 2em">軾軾答書云春秋儒者本務然此書有妙用學者</span>  
<!-- 册1 葉2177b　Page:文淵閣四庫全書_0001冊.djvu/594 -->
<span style="margin-left: 2em">罕能領會多求之繩約中乃近法家者流苛細繳</span>  
<span style="margin-left: 2em">繞竟亦何用惟左丘明識其用終不肯盡言微見</span>  
<span style="margin-left: 2em">端兆欲使學者自求之云云與大亨所序亦合葢</span>  
<span style="margin-left: 2em">其學出於蘇氏故議論宗㫖亦近之陳振孫書錄</span>  
<span style="margin-left: 2em">解題及宋史藝文志並作十六卷朱𢑴尊經義考</span>  
<span style="margin-left: 2em">云已佚此本載永樂大典中十二公各自爲卷而</span>  
<span style="margin-left: 2em">隱公莊公襄公昭公又自分上下卷與十六卷之</span>  
<span style="margin-left: 2em">數合然毎卷篇頁無多病其繁碎今併爲六卷以</span>  
<span style="margin-left: 2em">便省覽其文則無所佚脫也</span>  
<!-- 册1 葉2180a　Page:文淵閣四庫全書_0001冊.djvu/595 -->
春秋傳二十卷<sub class="note-yuan">浙江朱𢑴尊家曝書亭藏本</sub>  
<span style="margin-left: 2em">宋葉夢得撰夢得字少藴號石林吳縣人紹聖四</span>  
<span style="margin-left: 2em">年進士南渡後官至崇信軍節度使事蹟具宋史</span>  
<span style="margin-left: 2em">文苑傳夢得以孫復春秋尊王發微主於廢傳以</span>  
<span style="margin-left: 2em">從經蘇轍春秋集解主於從左氏而廢公羊穀梁</span>  
<span style="margin-left: 2em">皆不免有𡚁故是書參考三傳以求經不得於事</span>  
<span style="margin-left: 2em">則考於義不得於義則考於事更相發明頗爲精</span>  
<span style="margin-left: 2em">核開禧中其孫筠刋於南劍州眞德秀䟦之稱其</span>  
<span style="margin-left: 2em">闢邪說黜異端有補世教不淺宋史藝文志又載</span>  
<!-- 册1 葉2180b　Page:文淵閣四庫全書_0001冊.djvu/595 -->
<span style="margin-left: 2em">夢得別有春秋考三十卷讞三十卷指要總例二</span>  
<span style="margin-left: 2em">卷石林春秋八卷今讞考二書散見永樂大典中</span>  
<span style="margin-left: 2em">尚可得其大槩餘皆散佚惟此傳猶爲完書南窻</span>  
<span style="margin-left: 2em">記事載夢得爲春秋書其別有四解釋音義曰傳</span>  
<span style="margin-left: 2em">訂正事實曰考掊擊三傳曰讞編列凡例曰例嘗</span>  
<span style="margin-left: 2em">語徐惇濟曰吾之爲此名前古所未見也惇濟曰</span>  
<span style="margin-left: 2em">吳程秉著書三萬餘言曰周易摘尚書駁論語弼</span>  
<span style="margin-left: 2em">得無近是乎云云案此傳不專釋音義其說已非</span>  
<span style="margin-left: 2em">至於以一字名書古人多有卽以春秋而論傳爲</span>  
<!-- 册1 葉2181a　Page:文淵閣四庫全書_0001冊.djvu/595 -->
<span style="margin-left: 2em">通名不必言矣如漢志所載鐸氏張氏皆有春秋</span>  
<span style="margin-left: 2em">微公羊傳疏有閔因春秋序後漢書有鄭衆春秋</span>  
<span style="margin-left: 2em">刪隋志有何休春秋議崔靈恩春秋序孫炎併先</span>  
<span style="margin-left: 2em">有春秋例夢得博洽安得不見乃以爲古無此名</span>  
<span style="margin-left: 2em">必非事實且宋志載夢得春秋指要總例亦不名</span>  
<span style="margin-left: 2em">曰春秋例殆小說附會之詞不足據也</span>  
春秋考十六卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋葉夢得撰是書於寧宗開禧中與春秋傳春秋</span>  
<span style="margin-left: 2em">讞同刻於南劍州元程端學作春秋三傳辨疑多</span>  
<!-- 册1 葉2181b　Page:文淵閣四庫全書_0001冊.djvu/595 -->
<span style="margin-left: 2em">引其說則當時猶有傳本自明以來藏書家皆不</span>  
<span style="margin-left: 2em">著錄故朱𢑴尊經義考注曰已佚惟永樂大典頗</span>  
<span style="margin-left: 2em">載其文以次檢校尚可得什之八九今排比綴輯</span>  
<span style="margin-left: 2em">復勒成書其書大㫖在申明所以攻排三傳者實</span>  
<span style="margin-left: 2em">本周之法度制作以爲斷初非有所臆測於其間</span>  
<span style="margin-left: 2em">故所言皆論次周典以求合於春秋之法其文辨</span>
