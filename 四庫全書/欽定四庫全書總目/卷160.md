<span style="margin-left: 1em">集部十三</span>  
<span style="margin-left: 2em">别集𩔖十三</span>  
乾道稿一卷淳熙稿二十卷章泉稿五卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋趙蕃撰蕃字昌父號章泉先世鄭州人建炎初</span>  
<span style="margin-left: 2em">其曾祖暘官於信州因家焉蕃以暘致仕恩補官</span>  
<span style="margin-left: 2em">後終於<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">祕閣始受學劉淸之年至五十乃問學</span>  
<span style="margin-left: 2em">於朱子朱子文集與蕃尺牘凡六首蕃與朱子往</span>  
<span style="margin-left: 2em">還詩及他作之稱述朱子者二十餘首朱子答徐</span>  
<!-- 册4 葉1001b　Page:文淵閣四庫全書_0004冊.djvu/255 -->
<span style="margin-left: 2em">斯遠書有云昌父志操文詞皆非流輩所及且欲</span>  
<span style="margin-left: 2em">其刋落枝葉就日用間深察義理之本然庶幾有</span>  
<span style="margin-left: 2em">所據依以造實地不但爲騷人墨客而巳所以援</span>  
<span style="margin-left: 2em">引之者甚力然蕃本詞人晚乃講學其究也仍以</span>  
<span style="margin-left: 2em">詩傳與澗泉韓淲有二泉先生之稱淲集久佚今</span>  
<span style="margin-left: 2em">從永樂大典裒輯巳别著錄蕃集世亦無傳而永</span>  
<span style="margin-left: 2em">樂大典所收頗富并爲採掇編次依舊本標題釐</span>  
<span style="margin-left: 2em">爲乾道稿一卷淳熙稿二十卷章泉稿五卷共二</span>  
<span style="margin-left: 2em">十六卷而以蕃本傳及劉宰所作墓表附錄於後</span>  
<!-- 册4 葉1004a　Page:文淵閣四庫全書_0004冊.djvu/256 -->
<span style="margin-left: 2em">初蕃爲太和簿時受知於楊萬里萬里贈詩有云</span>  
<span style="margin-left: 2em">西昌主簿如禪僧日餐秋菊嚼春冰又云勸渠未</span>  
<span style="margin-left: 2em">要思舊隱且與西昌作好春又贊其寫眞云貌恭</span>  
<span style="margin-left: 2em">氣和無月下推敲之勢神淸骨聳非山頭瘦苦之</span>  
<span style="margin-left: 2em">容一笑詩成萬象春風劉克莊跋亦云近歲詩人</span>  
<span style="margin-left: 2em">惟趙章泉五言有陶阮意詩人玉屑載蕃論詩一</span>  
<span style="margin-left: 2em">則以陳后山寄外舅詩爲全篇之似杜者後戴式</span>  
<span style="margin-left: 2em">之思家用陳韻又全篇之似陳者觀其持論其詩</span>  
<span style="margin-left: 2em">學淵源亦可槪見矣又張端義貴耳集稱蕃與周</span>  
<!-- 册4 葉1004b　Page:文淵閣四庫全書_0004冊.djvu/256 -->
<span style="margin-left: 2em">必大同里必大當軸所任但一酒官五十年不調</span>  
<span style="margin-left: 2em"><sub class="note-yuan">案五十年疑當爲十五年之訛</sub>壽九十餘公朝尊老以秘閣正郞</span>  
<span style="margin-left: 2em">聘之不至則蕃之恬淡自守人品本高宜其詩之</span>  
<span style="margin-left: 2em">無俗韻也</span>  
雙溪集二十七卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">宋王炎撰炎字晦叔婺源人乾道五年進士官至</span>  
<span style="margin-left: 2em">軍器少監與淳熙中觀文殿大學士王炎名姓偶</span>  
<span style="margin-left: 2em">同非一人也所著有讀易筆記尚書小傳禮記論</span>  
<span style="margin-left: 2em">語孝經老子解春秋衍義象數稽疑禹貢辨考工</span>  
<!-- 册4 葉1005a　Page:文淵閣四庫全書_0004冊.djvu/256 -->
<span style="margin-left: 2em">記鄉飮酒義諸經考疑編年通紀紀年提要天對</span>  
<span style="margin-left: 2em">解韓柳辨證傷寒論總題曰雙溪𩔖稿今巳無傳</span>  
<span style="margin-left: 2em">惟詩文集僅存世所行者凡二本一本爲康熙中</span>  
<span style="margin-left: 2em">其族孫祺等所刋凡十二卷一卽此本乃明萬厯</span>  
<span style="margin-left: 2em">丙申尙寶司丞王鏻得沈一貫家舊本爲校正開</span>  
<span style="margin-left: 2em">雕者也凡賦樂府一卷詩詞九卷文十七卷炎初</span>  
<span style="margin-left: 2em">與朱子相契朱子集中和炎寄弟詩有祇今心事</span>  
<span style="margin-left: 2em">同千里靜對簞瓢獨喟然之句炎亦多與朱子往</span>  
<span style="margin-left: 2em">還之作其交誼頗篤及朱子爲待制侍經筵寧宗</span>  
<!-- 册4 葉1005b　Page:文淵閣四庫全書_0004冊.djvu/256 -->
<span style="margin-left: 2em">方諒闇擇日開講炎貽書朱子論其非禮而朱子</span>  
<span style="margin-left: 2em">集中無答書葢是時韓𠈁冑趙汝愚釁隙方開汝</span>  
<span style="margin-left: 2em">愚援道學諸人以自助<sub class="note-yuan">語詳齊東野語</sub>𠈁冑之黨眈眈側</span>  
<span style="margin-left: 2em">目朱子急欲寧宗親近士大夫故不拘喪禮汲汲</span>  
<span style="margin-left: 2em">以講學爲先實一時權宜之計迨一經攻駁難以</span>  
<span style="margin-left: 2em">置詞遂付之於不論豈非所持者正雖朱子亦不</span>  
<span style="margin-left: 2em">能與之爭歟其詩文博雅精深亦具有根柢程敏</span>  
<span style="margin-left: 2em">政輯新安文獻志所採最多其所未採諸篇議論</span>  
<span style="margin-left: 2em">醇正引據典<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">者尙不可悉數葢學有本原則詞</span>  
<!-- 册4 葉1008a　Page:文淵閣四庫全書_0004冊.djvu/257 -->
<span style="margin-left: 2em">無鄙誕較以語錄爲詩文者固有蹈空徴實之别</span>  
<span style="margin-left: 2em">矣</span>  
止堂集二十卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋彭龜年撰龜年字子壽淸江人乾道五年進士</span>  
<span style="margin-left: 2em">厯官煥章閣待制知江陵府遷湖北安撫使坐事</span>  
<span style="margin-left: 2em">落職尋復官以寶謨閣待制致仕卒諡忠肅事蹟</span>  
<span style="margin-left: 2em">具宋史本傳龜年官右史時面折廷諍劘切人主</span>  
<span style="margin-left: 2em">有古<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">臣之風集中所存奏疏劄子尙五十五篇</span>  
<span style="margin-left: 2em">敷陳明<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">多關於國家大計其論光宗不朝重華</span>  
<!-- 册4 葉1008b　Page:文淵閣四庫全書_0004冊.djvu/257 -->
<span style="margin-left: 2em">宫疏凡三四上至於伏地叩額血漬甃甓光宗亦</span>  
<span style="margin-left: 2em">爲之感動又嘗事寧宗於藩邸有舊學之恩卽位</span>  
<span style="margin-left: 2em">後數進讜言拳拳懇到因風雷示變極陳小人之</span>  
<span style="margin-left: 2em">竊權及朱子以論韓𠈁冑被絀龜年又上疏請與</span>  
<span style="margin-left: 2em">同斥今諸疏並在集中其嚴氣正性凛然猶可想</span>  
<span style="margin-left: 2em">見史稱其學識正大議論簡<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">善惡是非辨析甚</span>  
<span style="margin-left: 2em">嚴故生平雖不以文章名而懇惻之忱與剛勁之</span>  
<span style="margin-left: 2em">氣浩然<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">達語不求工而自工固非鞶帨爲文者</span>  
<span style="margin-left: 2em">所得絜其長短也宋史藝文志載其集四十七卷</span>  
<!-- 册4 葉1009a　Page:文淵閣四庫全書_0004冊.djvu/257 -->
<span style="margin-left: 2em">世久失傳今從永樂大典所載益以厯代名臣奏</span>  
<span style="margin-left: 2em">議所錄共得文二百二十三首詩二百二十首依</span>  
<span style="margin-left: 2em">𩔖編次釐爲二十卷雖得諸殘缺之餘而其一生</span>  
<span style="margin-left: 2em">建白史所未盡載者巳畧具於是傳龜年之文益</span>  
<span style="margin-left: 2em">足傳龜年之人矣</span>  
緣督集二十卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋曾丰撰丰字幼度樂安人乾道五年進士官至</span>  
<span style="margin-left: 2em">知德慶府事眞德秀幼嘗受學於丰及執政奏取</span>  
<span style="margin-left: 2em">其集入崇文四部當時嘗板行於世歲久不傳元</span>  
<!-- 册4 葉1009b　Page:文淵閣四庫全書_0004冊.djvu/257 -->
<span style="margin-left: 2em">元統間丰五世孫德安購其遺集得四十卷翰林</span>  
<span style="margin-left: 2em">學士虞集爲之敘謂其氣剛而義嚴辭<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">而理勝</span>  
<span style="margin-left: 2em">有得於易之奇詩之葩其文今見道園學古錄中</span>  
<span style="margin-left: 2em">然當時欲授梓不果至明嘉靖間詹事講始選錄</span>  
<span style="margin-left: 2em">十有二卷刻於宣城卷末有萬錡後序稱摘其尤</span>  
<span style="margin-left: 2em">者存之今觀所分諸體如五言排律𩔖中惟有排</span>  
<span style="margin-left: 2em">律一二首餘皆五言古詩七言排律𩔖中皆七言</span>  
<span style="margin-left: 2em">古詩無一首爲律是古今體且不能辨其去取乖</span>  
<span style="margin-left: 2em">謬大槪可知葢事講從羅洪先游日以討論心學</span>  
<!-- 册4 葉1012a　Page:文淵閣四庫全書_0004冊.djvu/258 -->
<span style="margin-left: 2em">爲事文章一道非所深研遂使丰之菁華反因此</span>  
<span style="margin-left: 2em">選而散佚殊堪惋惜惟永樂大典編自明初尙見</span>  
<span style="margin-left: 2em">丰之原集其所收錄較刋本多至數倍今據以增</span>  
<span style="margin-left: 2em">補乃裒然幾還舊觀佚而復存亦云幸矣丰仕蹟</span>  
<span style="margin-left: 2em">不顯頗以著述自<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3688.svg?width=24" alt="四庫全書僻字第3688號（負）" title="四庫全書僻字第3688號（負）">集中如六經論之𩔖根柢深</span>  
<span style="margin-left: 2em">𮟏得馬鄭諸儒所未發其他詩文雖間有好奇之</span>  
<span style="margin-left: 2em">癖要皆有物之言非膚淺者所可企及亦南宋一</span>  
<span style="margin-left: 2em">作者也丰晚年築室自號曰撙齋故是編一名撙</span>  
<span style="margin-left: 2em">齋集見於宋史藝文志今從虞集所序仍以緣督</span>  
<!-- 册4 葉1012b　Page:文淵閣四庫全書_0004冊.djvu/258 -->
<span style="margin-left: 2em">爲名集序稱凡四十卷而宋志乃作十四卷葢刋</span>  
<span style="margin-left: 2em">刻傳寫誤倒其文今原目不可復睹謹據所存各</span>  
<span style="margin-left: 2em">體以𩔖區分共釐爲二十卷</span>  
象山集二十八卷外集四卷附語錄四卷<sub class="note-yuan">大理寺卿陸錫熊家藏本</sub>  
<span style="margin-left: 2em">宋陸九淵撰九淵字子靜金谿人乾道八年進士</span>  
<span style="margin-left: 2em">紹熙初官至奉議郞知荆門軍卒於官事迹具宋</span>  
<span style="margin-left: 2em">史本傳據九淵年譜集爲其子持之所編其門人</span>  
<span style="margin-left: 2em">袁燮刋於江西提舉倉司者凡三十二卷宋史藝</span>  
<span style="margin-left: 2em">文志文獻通考並作象山集二十八卷外集四卷</span>  
<!-- 册4 葉1013a　Page:文淵閣四庫全書_0004冊.djvu/258 -->
<span style="margin-left: 2em">總而計之與燮所刋本卷數相符獨年譜稱持之</span>  
<span style="margin-left: 2em">所編外集爲六卷殆傳寫訛四爲六歟此本前有</span>  
<span style="margin-left: 2em">燮序又有楊簡序燮序作於嘉定五年簡序作於</span>  
<span style="margin-left: 2em">開禧元年在燮序前七年而列於燮後葢刋板之</span>  
<span style="margin-left: 2em">時以新序弁首故翻刻者仍之又有嘉定庚辰吳</span>  
<span style="margin-left: 2em">杰跋稱是集爲建安陳氏所刋而年譜未載此本</span>  
<span style="margin-left: 2em">豈持之偶未見歟前十七卷皆書十八卷爲表奏</span>  
<span style="margin-left: 2em">十九卷爲記二十卷爲序贈二十一卷至二十四</span>  
<span style="margin-left: 2em">卷爲雜著二十五卷爲詩二十六卷爲祭文二十</span>  
<!-- 册4 葉1013b　Page:文淵閣四庫全書_0004冊.djvu/258 -->
<span style="margin-left: 2em">七卷二十八卷爲墓誌墓碣墓表外集四卷皆程</span>  
<span style="margin-left: 2em">試之文末爲諡議行狀則吳杰所續入也其語錄</span>  
<span style="margin-left: 2em">四卷本於集外别行正德辛巳撫州守李茂元重</span>  
<span style="margin-left: 2em">刻是集乃并附集末以成陸氏全書其說與集中</span>  
<span style="margin-left: 2em">論學諸書互相發明合而觀之益足勘證今亦仍</span>
