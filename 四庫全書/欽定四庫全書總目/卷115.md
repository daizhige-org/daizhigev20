## 欽定四庫全書總目 卷一百十五　子部二十五　譜錄類

<!-- 册3 葉1936：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷一百十五  
<span style="margin-left: 1em">子部二十五</span>  
<span style="margin-left: 2em">譜錄類</span>  
<span style="margin-left: 3em">劉向七畧門目孔多後併爲四部大綱定矣中</span>  
<span style="margin-left: 3em">間子目逓有增減亦不甚相遠然古人學問各</span>  
<span style="margin-left: 3em">守專門其著述具有源流易於配隸六朝以後</span>  
<span style="margin-left: 3em">作者漸出新裁體倒多由創造古來舊目遂不</span>  
<span style="margin-left: 3em">能該附贅懸疣往往牽强隋志譜系本陳族姓</span>  
<span style="margin-left: 3em">而末載竹譜錢譜錢圖唐志農家本言種植而</span>  
<!-- 册3 葉1937b　Page:文淵閣四庫全書_0003冊.djvu/489 -->
<span style="margin-left: 3em">雜列錢譜相鶴經相馬經鷙擊錄相具經文獻</span>  
<span style="margin-left: 3em">通考亦以香譜入農家是皆明知其不安而限</span>  
<span style="margin-left: 3em">於無類可歸又復窮而不變故支離顚舛遂至</span>  
<span style="margin-left: 3em">於斯惟尤袤遂初堂書目創立譜錄一門於是</span>  
<span style="margin-left: 3em">别類殊名咸歸統攝此亦變而能通矣今用其</span>  
<span style="margin-left: 3em">例以收諸雜書之無可繫屬者門目旣繁檢尋</span>  
<span style="margin-left: 3em">頗病於𤨏碎故諸物以類相從不更以時代次</span>  
<span style="margin-left: 3em">焉</span>  
古今刀劍錄一卷<sub class="note-yuan">兩江總督採進本</sub>  
<!-- 册3 葉1940a　Page:文淵閣四庫全書_0003冊.djvu/490 -->
<span style="margin-left: 2em">梁陶宏景撰宏景字通明丹陽秣陵人齊初爲奉</span>  
<span style="margin-left: 2em">朝請永明十年上表辭祿止於句曲山梁大同六</span>  
<span style="margin-left: 2em">年卒贈中散大夫諡貞白先生事蹟具梁書處士</span>  
<span style="margin-left: 2em">傅是書所記帝王刀劍自夏啓至梁武帝凡四十</span>  
<span style="margin-left: 2em">事諸國刀劍自劉淵至赫連勃勃凡十八事吳將</span>  
<span style="margin-left: 2em">刀周瑜以下凡十事魏將刀鍾會以下凡六事然</span>  
<span style="margin-left: 2em">關張諸葛亮黃忠皆蜀將不應附入吳將中疑傳</span>  
<span style="margin-left: 2em">寫誤佚蜀將刀標題三字又董卓袁紹不應附魏</span>  
<span style="margin-left: 2em">亦不應在鄧艾郭淮之間均爲顚舛至宏景生於</span>  
<!-- 册3 葉1940b　Page:文淵閣四庫全書_0003冊.djvu/490 -->
<span style="margin-left: 2em">宋代齊高帝作相時已引爲諸王侍讀而書中乃</span>  
<span style="margin-left: 2em">稱順帝凖爲楊玉所弑不應以身厯之事謬誤至</span>  
<span style="margin-left: 2em">此且宏景先武帝卒而帝王刀劍一條乃預著武</span>  
<span style="margin-left: 2em">帝諡號並直斥其名尤乖事理疑其書已爲後人</span>  
<span style="margin-left: 2em">竄亂非宏景本文矣然考唐李綽尚書故實引古</span>  
<span style="margin-left: 2em">今刀劍錄云自古好刀劍多投伊水中以禳膝人</span>  
<span style="margin-left: 2em">之妖與此本所記漢章帝鑄劍一條雖文字小有</span>  
<span style="margin-left: 2em">同異而大畧相合則其來已久不盡出後人贋造</span>  
<span style="margin-left: 2em">或亦張華博物志之流眞僞叅半歟</span>  
<!-- 册3 葉1941a　Page:文淵閣四庫全書_0003冊.djvu/490 -->
鼎錄一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">舊本題梁虞荔撰考陳書列傳荔字山披會稽餘</span>  
<span style="margin-left: 2em">姚人釋褐爲梁西中郞行叅軍遷中書舍人侯景</span>  
<span style="margin-left: 2em">亂歸郷里陳初召爲太子中庶子領大著作東陽</span>  
<span style="margin-left: 2em">揚州二州大中正贈侍中諡曰德是荔當爲陳人</span>  
<span style="margin-left: 2em">稱梁者誤也其書不見於本傳唐志始著錄然書</span>  
<span style="margin-left: 2em">中有陳宣帝於太極殿鑄鼎之文荔卒於陳文帝</span>  
<span style="margin-left: 2em">天嘉二年下距臨海王光大二年宣帝嗣位時首</span>  
<span style="margin-left: 2em">尾七年安得預稱諡號其爲後人所攙入無疑又</span>  
<!-- 册3 葉1941b　Page:文淵閣四庫全書_0003冊.djvu/490 -->
<span style="margin-left: 2em">卷首序文乃紀夏鼎應在黃帝條後亦必無識者</span>  
<span style="margin-left: 2em">以原書無序移掇其文葢流傳旣久屢經竄亂眞</span>  
<span style="margin-left: 2em">僞已不可辨特以其舊帙存之耳又按晁公武讀</span>  
<span style="margin-left: 2em">書志別出吳協鼎錄一條通考與此書兩收之然</span>  
<span style="margin-left: 2em">其書他無所見疑吳字近虞協字近荔傳寫舛訛</span>  
<span style="margin-left: 2em">因而誤分爲二也</span>  
嘯堂集古錄二卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">宋王俅撰俅字子弁一作球字夔玉米芾畫史又</span>  
<span style="margin-left: 2em">作夔石未詳孰是陳振孫書錄解題謂李邴序祗</span>  
<!-- 册3 葉1944a　Page:文淵閣四庫全書_0003冊.djvu/491 -->
<span style="margin-left: 2em">稱故人長孺之子未詳其爲何王氏攷邴序稱與</span>  
<span style="margin-left: 2em">長孺同鄉關邴籍濟州任城則俅爲齊人可知是</span>  
<span style="margin-left: 2em">編錄古尊彛敦卣之屬自商迄漢凡數百種摹其</span>  
<span style="margin-left: 2em">欵識各以今文釋之中有古印章數十其一曰夏</span>  
<span style="margin-left: 2em">禹吾邱衍學古編謂係漢巫厭水災法印世俗傳</span>  
<span style="margin-left: 2em">有渡水佩禹字法此印乃漢篆故知之衍精於鑒</span>  
<span style="margin-left: 2em">古當得其實衍又謂滕公墓銘鬱鬱作兩字書與</span>  
<span style="margin-left: 2em">古法叠字止作二小畫者不同灼知其僞則是書</span>  
<span style="margin-left: 2em">固眞贋襍糅然所採摭尚足資考鑒不能以一二</span>  
<!-- 册3 葉1944b　Page:文淵閣四庫全書_0003冊.djvu/491 -->
<span style="margin-left: 2em">疵累廢之葢居千百年下而辨别千百年上之遺</span>  
<span style="margin-left: 2em">器其物或眞或不眞其說亦或確或不確自考古</span>  
<span style="margin-left: 2em">圖以下大勢類然亦不但此書也</span>  
考古圖十卷續考古圖五卷釋文一卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋吕大臨撰大臨字與叔藍田人元祐中官袐書</span>  
<span style="margin-left: 2em">省正字事蹟附載宋史吕大防傳案陳振孫書錄</span>  
<span style="margin-left: 2em">解題載大臨考古圖十卷錢曾讀書敏求記則稱</span>  
<span style="margin-left: 2em">十卷之外尚有續考五卷釋文一卷乃北宋鏤板</span>  
<span style="margin-left: 2em">得於無錫顧宸家後歸泰興季振宜又歸崑山徐</span>  
<!-- 册3 葉1945a　Page:文淵閣四庫全書_0003冊.djvu/491 -->
<span style="margin-left: 2em">乾學曾復從乾學借鈔其圖亦令良工繪畫不失</span>  
<span style="margin-left: 2em">毫髪紙墨更精於槧本云云此本勘騐印記卽曾</span>  
<span style="margin-left: 2em">所手錄以較世所行本卷一多孔文父飲鼎圖一</span>  
<span style="margin-left: 2em">銘十四字說五十一字卷三邢敦圖多一葢圖卷</span>  
<span style="margin-left: 2em">四開封劉氏小方壺圖乃祕閣方文方壺圖祕閣</span>  
<span style="margin-left: 2em">方文方壺圖乃開封劉氏小方壺圖今本互相顚</span>  
<span style="margin-left: 2em">例卷六目錄多標題盤匝盂弩戈削一行卷八多</span>  
<span style="margin-left: 2em">玉鹿盧劍具圖三說一百一十五字又多白玉雲</span>  
<span style="margin-left: 2em">鉤玉環玉玦圖各一卷九多京兆田氏鹿盧鐙圖</span>  
<!-- 册3 葉1945b　Page:文淵閣四庫全書_0003冊.djvu/491 -->
<span style="margin-left: 2em">一說四十七字又犀鐙第二圖與今本逈别又内</span>  
<span style="margin-left: 2em">藏環耳鼒多一葢圖卷十新平張氏連環鼎壺無</span>  
<span style="margin-left: 2em">右所從得及度量銘識皆闕失無可考惟様存於</span>  
<span style="margin-left: 2em">此二十字又多廬江李氏鐎斗圖一又獸鑪第二</span>  
<span style="margin-left: 2em">圖後多說三十五字又卷末多卭州天寧寺僧捧</span>  
<span style="margin-left: 2em">勑佩圖二說四十六字卷首大臨自序本題曰後</span>  
<span style="margin-left: 2em">記附載卷末其餘字句行欵之異同不可縷舉而</span>  
<span style="margin-left: 2em">參騐文義皆以此本爲長續圖卷一二十器卷二</span>  
<span style="margin-left: 2em">二十二器卷三二寸六器卷四二十器卷五十二</span>  
<!-- 册3 葉1948a　Page:文淵閣四庫全書_0003冊.djvu/492 -->
<span style="margin-left: 2em">器先後不以類從葢隨見隨錄故第五卷所載獨</span>  
<span style="margin-left: 2em">少或有銘而不摹其文有文而不釋其讀者其收</span>  
<span style="margin-left: 2em">藏名姓皆載圖說之首云右某人所得與前圖註</span>  
<span style="margin-left: 2em">姓名於標目下者例亦小殊釋文一卷前有大臨</span>  
<span style="margin-left: 2em">題詞取銘識古字以廣韻四聲部分編之其有所</span>  
<span style="margin-left: 2em">異同者則各爲訓釋考證疑字象形字無所從之</span>  
<span style="margin-left: 2em">字則附於卷末大臨圖成於元祐壬申在宣和博</span>  
<span style="margin-left: 2em">古圖之前而體例謹嚴有疑則闕不似博古圖之</span>  
<span style="margin-left: 2em">附會古人動成舛謬其𨚕敦一條胡安國註春秋</span>  
<!-- 册3 葉1948b　Page:文淵閣四庫全書_0003冊.djvu/492 -->
<span style="margin-left: 2em">成周宣榭火乃引之詁經足知其說之可據吾邱</span>  
<span style="margin-left: 2em">衍學古編稱此圖有黑白兩様<sub class="note-yuan">案黑字白字皆指所刻欵識</sub>黑</span>  
<span style="margin-left: 2em">字者後有韻圖欠璊玉璏白字者博山鑪上雞畫</span>  
<span style="margin-left: 2em">作人手此本銘文作白字然博山鑪圖無所謂人</span>  
<span style="margin-left: 2em">手亦無所謂雞其釋文一卷依韻排次當卽衍所</span>  
<span style="margin-left: 2em">謂韻圖然八卷實有廬江李氏璊玉璏知衍所見</span>  
<span style="margin-left: 2em">之本亦不及此本之完善錢曾稱爲縹囊異物洵</span>  
<span style="margin-left: 2em">不虛矣惟續圖五卷書錄解題所不載學古編亦</span>  
<span style="margin-left: 2em">未言及其中第二卷引吕與叔云云又引考古圖</span>  
<!-- 册3 葉1949a　Page:文淵閣四庫全書_0003冊.djvu/492 -->
<span style="margin-left: 2em">云云第三卷有紹興壬午所得之器云云則其書</span>  
<span style="margin-left: 2em">在紹興三十二年之後與大臨遠不相及葢南宋</span>  
<span style="margin-left: 2em">人續大臨之書而佚其名氏錢曾併以爲大臨作</span>  
<span style="margin-left: 2em">葢考之未審也其釋文所舉諸器皆在前十卷中</span>  
<span style="margin-left: 2em">所釋榭字析字之類亦多與圖說相合惟弡字圖</span>  
<span style="margin-left: 2em">說釋爲張與歐陽修集古錄同而釋文則從闕疑</span>  
<span style="margin-left: 2em">稍相牴牾或大臨削改未竟偶爾駁文歟至其題</span>  
<span style="margin-left: 2em">詞稱古器銘識不獨與小篆有異有同一器同一</span>  
<span style="margin-left: 2em">字而筆畫多寡偏旁位置不一者如伯百父敦之</span>  
<!-- 册3 葉1949b　Page:文淵閣四庫全書_0003冊.djvu/492 -->
<span style="margin-left: 2em">百字寳字蘄字叔高父簋之簋字晉鼎之作字其</span>  
<span style="margin-left: 2em">異器者如彛尊壽萬等字器器筆畫皆有小異知</span>  
<span style="margin-left: 2em">古字未必同文至秦始就一律故非小篆所能該</span>  
<span style="margin-left: 2em">亦通論也</span>  
宣和博古圖三十卷<sub class="note-yuan">大理寺卿陸錫熊家藏本</sub>  
<span style="margin-left: 2em">按晁公武讀書志稱宣和博古圖爲王楚撰而錢</span>  
<span style="margin-left: 2em">曾讀書敏求記稱元至大中重刻博古圖凡臣王</span>  
<span style="margin-left: 2em">黼撰云云都爲削去殆以人廢書則是書實王黼</span>  
<span style="margin-left: 2em">撰楚字爲傳寫之訛矣曾又稱博古圖成於宣和</span>  
<!-- 册3 葉1952a　Page:文淵閣四庫全書_0003冊.djvu/493 -->
<span style="margin-left: 2em">年間而謂之重修者葢以採取黃長睿博古圖說</span>  
<span style="margin-left: 2em">在前也考陳振孫書錄解題曰博古圖說十一卷</span>  
<span style="margin-left: 2em">秘書郞昭武黃伯思長睿撰凡諸器五十九品其</span>  
<span style="margin-left: 2em">數五百二十七印章十七品其數四十五長睿没</span>  
<span style="margin-left: 2em">於政和八年其後修博古圖頗采用之而亦有删</span>  
<span style="margin-left: 2em">改云云錢曾所說良信然考蔡絛鐵圍山叢談曰</span>  
<span style="margin-left: 2em">李公麟字伯時最善畫性喜古取生平所得及其</span>  
<span style="margin-left: 2em">聞睹者作爲圖狀而名之曰考古圖及大觀初乃</span>  
<span style="margin-left: 2em">倣公麟之考古作宣和殿博古圖則此書踵李公</span>  
<!-- 册3 葉1952b　Page:文淵閣四庫全書_0003冊.djvu/493 -->
