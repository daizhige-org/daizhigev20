## 欽定四庫全書總目 卷七　經部七　易類存目一

<!-- 册1 葉640：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷七  
<span style="margin-left: 1em">經部七</span>  
<span style="margin-left: 2em">易類存目一</span>  
關氏易傳一卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">舊本題北魏關朗撰唐趙㽔注朗字子明河東人</span>  
<span style="margin-left: 2em">㽔字大賔梓州鹽亭人<sub class="note-yuan">詳見子部雜家類長短經條下</sub>是書隋志</span>  
<span style="margin-left: 2em">唐志皆不著錄晁公武讀書志謂李淑邯鄲圖書</span>  
<span style="margin-left: 2em">志始有之中興書目亦載其名云阮逸詮次刋正</span>  
<span style="margin-left: 2em">陳師道後山談叢何薳春渚紀聞及邵博聞見後</span>  
<!-- 册1 葉641b　Page:文淵閣四庫全書_0001冊.djvu/210 -->
<span style="margin-left: 2em">錄皆云阮逸嘗以僞撰之稿示蘇洵則出自逸手</span>  
<span style="margin-left: 2em">更無疑義逸與李淑同爲神宗時人故李氏書目</span>  
<span style="margin-left: 2em">始有也吳萊集有此書後序乃據文中子之說力</span>  
<span style="margin-left: 2em">辨其眞文士好奇未之深考耳</span>  
方舟易學二卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">宋李石撰石字知幾資陽人陸游老學庵筆記載</span>  
<span style="margin-left: 2em">其本名知幾後感夢兆改名石而以知幾爲字宋</span>  
<span style="margin-left: 2em">史不爲立傳資州志載其舉進士高第紹興末以</span>  
<span style="margin-left: 2em">薦任太學博士黜成都學官乾道中再入爲郞後</span>  
<!-- 册1 葉644a　Page:文淵閣四庫全書_0001冊.djvu/211 -->
<span style="margin-left: 2em">歴知合州黎州眉州皆以論罷終成都轉運判官</span>  
<span style="margin-left: 2em">鄧椿畫繼亦載其少<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3688.svg?width=24" alt="四庫全書僻字第3688號（負）" title="四庫全書僻字第3688號（負）">才名旣登第以趙逵薦任</span>  
<span style="margin-left: 2em">太學博士今倅成都葢椿與石同時猶及見其居</span>  
<span style="margin-left: 2em">官也是書專論互體每卦標兩互卦之名而以爻</span>  
<span style="margin-left: 2em">辭證之考漢儒說易多主象占後孟喜焦贛京房</span>  
<span style="margin-left: 2em">流爲災變鄭元又配以爻辰固不免有所附會自</span>  
<span style="margin-left: 2em">王弼埽滌舊文併謂互體卦變皆無足取於是棄</span>  
<span style="margin-left: 2em">象不論夫納甲五行本非易義所重棄之可也若</span>  
<span style="margin-left: 2em">互卦及動爻之變其說見於繫辭其法見於左傳</span>  
<!-- 册1 葉644b　Page:文淵閣四庫全書_0001冊.djvu/211 -->
<span style="margin-left: 2em">歴代諸儒相承有自槩從排斥未免偏涉虛無故</span>  
<span style="margin-left: 2em">石此書專闢王弼之學其上卷詳言互體之義下</span>  
<span style="margin-left: 2em">卷曰象統日明閏象統但存一序其說未竟明閏</span>  
<span style="margin-left: 2em">以六十四卦分月以明置閏之法也朱彝尊經義</span>  
<span style="margin-left: 2em">考曰方舟集止存二卷崑山徐秉義家藏有易互</span>  
<span style="margin-left: 2em">體例卷首不著撰人名氏但題門人劉伯熊編此</span>  
<span style="margin-left: 2em">本卷首有竹垞二字小印豈其書後歸彝尊歟攷</span>  
<span style="margin-left: 2em">書錄解題載李石方舟集五十卷後集二十卷而</span>  
<span style="margin-left: 2em">永樂大典所載左氏君子例詩如例詩補遺及此</span>  
<!-- 册1 葉645a　Page:文淵閣四庫全書_0001冊.djvu/211 -->
<span style="margin-left: 2em">書皆題曰李石方舟集則是四書皆其集中所載</span>  
<span style="margin-left: 2em">徐氏惟得其兩卷故卷端無姓名耳今方舟集已</span>  
<span style="margin-left: 2em">於永樂大典中裒輯成帙此四書亦仍其舊例併</span>  
<span style="margin-left: 2em">入集中故不復重錄而附存其目於此焉</span>  
周易繫辭精義二卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">舊本題宋吕祖謙撰祖謙有古周易已著錄初程</span>  
<span style="margin-left: 2em">子作易傳不及繫辭此書似集諸家之說補其所</span>  
<span style="margin-left: 2em">缺然去取未爲精審陳振孫書錄解題引館閣書</span>  
<span style="margin-left: 2em">目以是書爲託祖謙之名殆必有據也</span>  
<!-- 册1 葉645b　Page:文淵閣四庫全書_0001冊.djvu/211 -->
東萊易說二卷<sub class="note-yuan">江西巡撫採進本</sub>  
<span style="margin-left: 2em">舊本題宋吕祖謙撰朱彝尊經義考亦列其名今</span>  
<span style="margin-left: 2em">勘驗其文實吕喬年所編麗澤論說集錄之前二</span>  
<span style="margin-left: 2em">卷書賈抄出以售僞非祖謙所自著也</span>  
周易輯說明解四卷<sub class="note-yuan">江西巡撫採進本</sub>  
<span style="margin-left: 2em">舊本題宋馮椅撰椅有厚齋易學已著錄此其别</span>  
<span style="margin-left: 2em">行之僞本也案椅原書宋史藝文志作五十卷此</span>  
<span style="margin-left: 2em">本卷數懸殊其不合者一又朱彝尊經義考載中</span>  
<span style="margin-left: 2em">興藝文志云馮椅爲輯注輯傳外傳以程沙隨朱</span>  
<!-- 册1 葉648a　Page:文淵閣四庫全書_0001冊.djvu/212 -->
<span style="margin-left: 2em">文公雖本古易爲注猶未及盡正孔傳名義乃改</span>  
<span style="margin-left: 2em">彖曰象曰爲贊曰又改繫辭上下爲說卦上中以</span>  
<span style="margin-left: 2em">隋經籍志有說卦三篇也此本仍作彖曰象曰不</span>  
<span style="margin-left: 2em">作贊曰繫辭傳亦仍分上下不作說卦上下其不</span>  
<span style="margin-left: 2em">合者二胡一桂易本義附錄纂疏曰馮厚齋講明</span>  
<span style="margin-left: 2em">夷六五箕子之明夷云箕字蜀本作其字此繼統</span>  
<span style="margin-left: 2em">而當明揚之時之象其指大君當明揚之時而傳</span>  
<span style="margin-left: 2em">之子則其子亦爲明夷矣又謂文王作爻辭移置</span>  
<span style="margin-left: 2em">君象於上六以初登于天後入于地况明夷之主</span>  
<!-- 册1 葉648b　Page:文淵閣四庫全書_0001冊.djvu/212 -->
<span style="margin-left: 2em">六五在下而承之明夷之主之子之象也子繼明</span>  
<span style="margin-left: 2em">夷之治利在於貞明不可以復夷也後世以其爲</span>  
<span style="margin-left: 2em">箕遂傅會於文王與紂事甚至以爻辭爲周公作</span>  
<span style="margin-left: 2em">而非文王葢箕子之囚在文王羑里之後方演易</span>  
<span style="margin-left: 2em">時箕子之明未夷也李隆山深然其說云云此本</span>  
<span style="margin-left: 2em">解明夷六五上六二爻仍用舊說未嘗改箕子爲</span>  
<span style="margin-left: 2em">其字其不合者三至其各卦講解多沿襲本義與</span>  
<span style="margin-left: 2em">永樂大典所載椅說全殊其爲僞託更無疑義今</span>  
<span style="margin-left: 2em">椅之全書業已重編成帙此本已可不存以外間</span>  
<!-- 册1 葉649a　Page:文淵閣四庫全書_0001冊.djvu/212 -->
<span style="margin-left: 2em">傳寫已久恐其亂眞故存其目而論之焉</span>  
水村易鏡一卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">宋林光世撰光世字逢聖莆田人館閣續錄載其</span>  
<span style="margin-left: 2em">淳祐十一年以易學召赴闕充秘書省檢校文字</span>  
<span style="margin-left: 2em">十二年教授常州文字職事如舊寶祐二年補迪</span>  
<span style="margin-left: 2em">功郞添差江西提舉司事辦公事閩書則謂淮東</span>  
<span style="margin-left: 2em">漕臣黃漢章上所著易鏡由布衣召爲史館檢閱</span>  
<span style="margin-left: 2em">遷校勘改京秩自將作出知潮州開慶元年召爲</span>  
<span style="margin-left: 2em">都官郞中入爲司農少<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">兼史館官階頗有異同</span>  
<!-- 册1 葉649b　Page:文淵閣四庫全書_0001冊.djvu/212 -->
<span style="margin-left: 2em">又稱其景定二年賜進士出身在都官郞中後二</span>  
<span style="margin-left: 2em">年均未詳孰是也是書序稱丙午葢成於理宗淳</span>  
<span style="margin-left: 2em">祐六年大㫖據繫辭之語謂諸儒詁易獨遺仰觀</span>  
<span style="margin-left: 2em">俯察之義因居海上測驗天文悟天澤火雷風水</span>  
<span style="margin-left: 2em">山地八宫之星皆自然有六十四卦遂以星配卦</span>  
<span style="margin-left: 2em">先取繫辭所列自離至夬十三卦推闡其㫖以發</span>  
<span style="margin-left: 2em">大凡所列星圖穿鑿附會自古說易之家未有紕</span>  
<span style="margin-left: 2em">繆至此者夫庖犧仰觀天文亦揆其盈虛消息之</span>  
<span style="margin-left: 2em">運耳何嘗準列宿畫卦哉後永豐陳圖作周易起</span>  
<!-- 册1 葉652a　Page:文淵閣四庫全書_0001冊.djvu/213 -->
<span style="margin-left: 2em">元又以名山大川分配六十四卦謂之察於地理</span>  
<span style="margin-left: 2em">充乎其類殆不至以鳥獸配卦不止矣</span>  
易序叢書十卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">舊本題宋趙汝楳撰汝楳有周易輯聞六卷易雅</span>  
<span style="margin-left: 2em">一卷筮宗三卷總謂之易序叢書已著於錄此本</span>  
<span style="margin-left: 2em">亦分十卷卷各爲目惟首二卷爲易雅筮宗自第</span>  
<span style="margin-left: 2em">三卷至七卷則言兵法所載營陳隊伍圖法甚備</span>  
<span style="margin-left: 2em">皆與易絶不相涉惟第八卷六日七分論及第九</span>  
<span style="margin-left: 2em">卷十卷辨方納甲二篇尚頗存漢學之舊然文字</span>  
<!-- 册1 葉652b　Page:文淵閣四庫全書_0001冊.djvu/213 -->
<span style="margin-left: 2em">亦多脫誤疑好事者偶得其殘本不知完帙尚存</span>  
<span style="margin-left: 2em">雜鈔他書以足十卷之數也卷首有董其昌名印</span>  
<span style="margin-left: 2em">則其來已久殆明人所雜編歟</span>  
周易上下經解殘本四卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">宋丁易東撰易東有易象義已著錄此卽易象義</span>  
<span style="margin-left: 2em">殘本傳鈔者改其名也十翼惟存彖傳象傳其餘</span>  
<span style="margin-left: 2em">皆佚上經自乾卦至泰卦僅有一頁尤爲殘缺惟</span>  
<span style="margin-left: 2em">下經晉大壯暌蹇中孚五卦爲永樂大典所佚者</span>  
<span style="margin-left: 2em">此本獨完今已採掇補錄而别存其目於此俾世</span>  
<!-- 册1 葉653a　Page:文淵閣四庫全書_0001冊.djvu/213 -->
<span style="margin-left: 2em">知與易象義非兩書焉</span>  
大易衍說<sub class="note-yuan">無卷數　安徽巡撫採進本</sub>  
<span style="margin-left: 2em">舊本題元李簡撰簡有學易記已著錄是編卽以</span>  
<span style="margin-left: 2em">學易記序冠於卷首而書則絶不相同核其文義</span>  
<span style="margin-left: 2em">與今村塾講章相類朱彛尊經義考亦未載其名</span>  
<span style="margin-left: 2em">葢書肆僞託之本也</span>  
大易法象通贊七卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">元鄭滁孫撰滁孫字景歐處州人宋景定間進士</span>  
<span style="margin-left: 2em">嘗知温州樂淸縣遷宗正丞禮部郞官入元以薦</span>  
<!-- 册1 葉653b　Page:文淵閣四庫全書_0001冊.djvu/213 -->
<span style="margin-left: 2em">召授集賢直學士事蹟具元史儒學傳此書首爲</span>  
<span style="margin-left: 2em">諸圖次以中天述考述衍等說終以甲辰乙巳丙</span>  
<span style="margin-left: 2em">午三年所作習坎書院旅語其中天圖後署曰至</span>  
<span style="margin-left: 2em">元三十年十一月吉日宣召赴闕儒人臣鄭滁孫</span>  
<span style="margin-left: 2em">葢卽其被薦時所進也其序自言年踰五十探索</span>  
<span style="margin-left: 2em">先天圖忽得中天元景云云案中天之說始見於</span>  
<span style="margin-left: 2em">干寶周禮註朱元昇衍之爲三易備遺然滁孫所</span>  
<span style="margin-left: 2em">謂中天元景與干寶之說又異大㫖謂中天卽天</span>  
<span style="margin-left: 2em">也由其運用合一居中故曰中天由其在生兩之</span>  
<!-- 册1 葉656a　Page:文淵閣四庫全書_0001冊.djvu/214 -->
<span style="margin-left: 2em">後用九之前故曰中天其象藏於互體而義發見</span>  
<span style="margin-left: 2em">於文王周公孔子之辭其說大抵皆幽渺恍惚不</span>  
<span style="margin-left: 2em">可究詰計滁孫登第自宋景定至元世祖至元中</span>  
<span style="margin-left: 2em">當已五六十歲而此書之成在成宗之末又在進</span>  
<span style="margin-left: 2em">圖後十餘年逮至嘉興温州升席說經年巳耄耋</span>  
<span style="margin-left: 2em">矣其始終敷析者皆一中天之義又刪周易繫辭</span>  
<span style="margin-left: 2em">傳以遷就巳說而牽合諸經以證之支離曼衍終</span>  
<span style="margin-left: 2em">無歸宿自來以奇偶推易者病於穿鑿以老莊談</span>  
<span style="margin-left: 2em">易者病於虛無此書更以穿鑿之數附會於虛無</span>  
<!-- 册1 葉656b　Page:文淵閣四庫全書_0001冊.djvu/214 -->
