## 欽定四庫全書總目 卷一百五十六　集部九　別集類九

<!-- 册4 葉713a　Page:文淵閣四庫全書_0004冊.djvu/183 -->
欽定四庫全書總目卷一百五十六  
<span style="margin-left: 1em">集部九</span>  
<span style="margin-left: 2em">别集類九</span>  
宗忠簡集八卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">宋宗澤撰澤事蹟具宋史本傳是編自一卷至六</span>  
<span style="margin-left: 2em">卷皆劄子狀疏詩文雜體七卷八卷爲遺事附錄</span>  
<span style="margin-left: 2em">皆後人紀澤事實及誥勅銘記之類也澤<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2854.svg?width=24" alt="四庫全書僻字第2854號（孤）" title="四庫全書僻字第2854號（孤）">忠耿</span>  
<span style="margin-left: 2em">耿精貫三光其奏劄規畫時𫝑詳明懇切當時狃</span>  
<span style="margin-left: 2em">於和議不用其言亦竟無收拾其文者至寧宗嘉</span>  
<!-- 册4 葉713b　Page:文淵閣四庫全書_0004冊.djvu/183 -->
<span style="margin-left: 2em">定間四明樓昉乃綴輯散佚以成是集然陳振孫</span>  
<span style="margin-left: 2em">書錄解題竟不著錄是宋末巳不甚行葢理宗以</span>  
<span style="margin-left: 2em">後天下趨朝廷風㫖道學日興談心性者謂之眞</span>  
<span style="margin-left: 2em">儒講事功者謂之雜霸人情所競在彼而不在此</span>  
<span style="margin-left: 2em">其沉晦不彰固其所也明崇禎間熊人霖始據舊</span>  
<span style="margin-left: 2em">本重刋</span>  
<span style="margin-left: 1em">國朝義烏縣知縣王庭曾又重爲編定增入諫止割</span>  
<span style="margin-left: 2em">地一疏而以樓昉原序及明初方孝孺序弁於篇</span>  
<span style="margin-left: 2em">首考史稱澤力請高宗還汴疏凡二十八上本傳</span>  
<!-- 册4 葉716a　Page:文淵閣四庫全書_0004冊.djvu/184 -->
<span style="margin-left: 2em">不盡錄其文今集中所載僅十八篇猶佚其十則</span>  
<span style="margin-left: 2em">其散亡已多矣</span>  
龜山集四十二卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">宋楊時撰時事蹟具宋史道學傳是集凡書奏表</span>  
<span style="margin-left: 2em">劄講義經解史論啟記序䟦各一卷語錄四卷答</span>  
<span style="margin-left: 2em">問二卷辨二卷書七卷雜著一卷哀辭祭文一卷</span>  
<span style="margin-left: 2em">狀述一卷誌銘八卷詩五卷時受蔡京之薦雖朱</span>  
<span style="margin-left: 2em">子亦不能無疑然葉夢得爲蔡京門客南渡後作</span>  
<span style="margin-left: 2em">避暑錄話石林詩話諸書尚袒䕶熙寧紹聖之局</span>  
<!-- 册4 葉716b　Page:文淵閣四庫全書_0004冊.djvu/184 -->
<span style="margin-left: 2em">時於蔡京旣敗以後卽力持公論集中載上欽宗</span>  
<span style="margin-left: 2em">第七疏詆京與王黼之亂政而請罷王安石配享</span>  
<span style="margin-left: 2em">則尚非始終黨附者比又於靖康被兵之時首以</span>  
<span style="margin-left: 2em">誠意進言雖未免少迂而其他排和議爭三鎭請</span>  
<span style="margin-left: 2em">一統帥罷奄寺守城以及茶務鹽法轉般糴買坑</span>  
<span style="margin-left: 2em">冶盜賊邊防軍制諸議皆於時𫝑安危言之鑿鑿</span>  
<span style="margin-left: 2em">亦尚非空談性命不達世變之論葢瑕瑜並見通</span>  
<span style="margin-left: 2em">蔽互形過譽過毁皆講學家門戸之私不足據也</span>  
<span style="margin-left: 2em">時受學程子傳之沙縣羅從彥再傳爲延平李侗</span>  
<!-- 册4 葉717a　Page:文淵閣四庫全書_0004冊.djvu/184 -->
<span style="margin-left: 2em">三傳而及朱子開閩中道學之脈其東林書院存</span>  
<span style="margin-left: 2em">於無錫又爲明季講授之宗本不以文章見重而</span>  
<span style="margin-left: 2em">篤實質樸要不失爲儒者之言舊板散佚明宏治</span>  
<span style="margin-left: 2em">壬戌將樂知縣李熙重刋併爲十六卷後常州東</span>  
<span style="margin-left: 2em">林書院刋本分爲三十六卷宜興刋本又併爲三</span>  
<span style="margin-left: 2em">十五卷萬厯辛卯將樂知縣林熙春重刋定爲四</span>  
<span style="margin-left: 2em">十二卷此本爲順治庚寅時裔孫令聞所刋其卷</span>  
<span style="margin-left: 2em">帙一仍熙春之舊云</span>  
<span style="margin-left: 3em">案時卒於高宗建炎四年其入南宋曰淺故舊</span>  
<!-- 册4 葉717b　Page:文淵閣四庫全書_0004冊.djvu/184 -->
<span style="margin-left: 3em">皆繫之北宋末然南宋一代之儒風與一代之</span>  
<span style="margin-left: 3em">朝論實皆傳時之緒餘故編錄南宋諸集冠以</span>  
<span style="margin-left: 3em">宗澤著其說不用而偏安之局遂成次之以時</span>  
<span style="margin-left: 3em">著其說一行而講學之風遂熾觀於二集以考</span>  
<span style="margin-left: 3em">驗當年之時𫝑可以見世變之大凡矣</span>  
梁溪集一百八十卷附錄六卷<sub class="note-yuan">編修汪如藻家藏本</sub>  
<span style="margin-left: 2em">宋李綱撰綱有建炎時政記巳著錄是集首載宋</span>  
<span style="margin-left: 2em">少保觀文殿大學士陳俊卿序謂綱少子秀之裒</span>  
<span style="margin-left: 2em">集其表章奏劄八十卷而詩文不與焉晁公武讀</span>  
<!-- 册4 葉720a　Page:文淵閣四庫全書_0004冊.djvu/185 -->
<span style="margin-left: 2em">書志則作一百五十卷陳振孫書錄解題則作一</span>  
<span style="margin-left: 2em">百二十卷葢後人續以詩文合編互有分併巳非</span>  
<span style="margin-left: 2em">復秀之之舊本此本賦四卷詩二十八卷雜文一</span>  
<span style="margin-left: 2em">百三十八卷而以靖康傳信錄三卷建炎進退志</span>  
<span style="margin-left: 2em">四卷建炎時政記三卷俱編入集中又以年譜行</span>  
<span style="margin-left: 2em">狀之類六卷附焉與晁陳二家所錄均爲不合又</span>  
<span style="margin-left: 2em">非宋本之舊矣綱人品經濟炳然史冊固不待言</span>  
<span style="margin-left: 2em">卽以其詩文而言亦雄深雅健磊落光明非尋常</span>  
<span style="margin-left: 2em">文士所及徒以喜談佛理故南宋諸儒不肯稱之</span>  
<!-- 册4 葉720b　Page:文淵閣四庫全書_0004冊.djvu/185 -->
<span style="margin-left: 2em">然如顔眞卿精忠勁節與日月爭光固不能以書</span>  
<span style="margin-left: 2em">西京多寶塔碑作撫州麻姑壇記遂減其文章之</span>  
<span style="margin-left: 2em">價也集中有補宋璟梅花賦自序謂璟賦巳佚擬</span>  
<span style="margin-left: 2em">而作之其文甚明元劉壎隱居通議所載璟賦二</span>  
<span style="margin-left: 2em">篇皆屬僞本明田藝蘅留靑曰札乃稱得元鮮于</span>  
<span style="margin-left: 2em">樞手書璟賦急錄傳之樞之眞蹟旋燬核其文句</span>  
<span style="margin-left: 2em">大抵㸃竄綱賦十同七八其爲依託顯然然亦見</span>  
<span style="margin-left: 2em">綱之賦格置於唐人之中可以亂眞矣</span>  
初寮集八卷<sub class="note-yuan">永樂大典本</sub>  
<!-- 册4 葉721a　Page:文淵閣四庫全書_0004冊.djvu/185 -->
<span style="margin-left: 2em">宋王安中撰安中字履道中山曲陽人登進士第</span>  
<span style="margin-left: 2em">累擢尚書左丞出知燕山府除大名尹兼北京留</span>  
<span style="margin-left: 2em">守司公事靖康初安置象州紹興初復左中大夫</span>  
<span style="margin-left: 2em">卒事蹟具宋史本傳安中以詞藻擅名而行誼甚</span>  
<span style="margin-left: 2em">爲紕繆陳振孫書錄解題稱其少時嘗師事蘇軾</span>  
<span style="margin-left: 2em">於定武未卒業而軾去會晁說之爲無極令復往</span>  
<span style="margin-left: 2em">執弟子禮說之朂以爲學當愼初之旨因築室榜</span>  
<span style="margin-left: 2em">曰初寮其聞見議論得於說之爲多及後貴顯遂</span>  
<span style="margin-left: 2em">諱晁學但稱成州使君四丈無復先生之號今考</span>  
<!-- 册4 葉721b　Page:文淵閣四庫全書_0004冊.djvu/185 -->
<span style="margin-left: 2em">集中多直呼說之爲晁以道與振孫言相合其佻</span>  
<span style="margin-left: 2em">薄已可槪見曾敏行獨醒雜志稱安中初學東坡</span>  
<span style="margin-left: 2em">書崇觀宣政間頗更少習南渡以來復還其舊其</span>  
<span style="margin-left: 2em">隨時局爲翻覆亦爲灼然史稱其以作瑞應表受</span>  
<span style="margin-left: 2em">知徽宗考蔡絛鐵圍山叢談實由謟事梁師成以</span>  
<span style="margin-left: 2em">進幼老春秋又稱其交結蔡攸引入禁中則奔競</span>  
<span style="margin-left: 2em">無恥更爲小人之尤史又稱其附和童貫王黼贊</span>  
<span style="margin-left: 2em">成復燕之議又身自請行規措失當招納叛亡挑</span>  
<span style="margin-left: 2em">釁强鄰禍貽宗社則誤國之罪尤爲深重然其詩</span>  
<!-- 册4 葉724a　Page:文淵閣四庫全書_0004冊.djvu/186 -->
<span style="margin-left: 2em">文豐潤凝重頗不𩔖其爲人四六諸作尤爲雅麗</span>  
<span style="margin-left: 2em">史稱徽宗嘗宴睿謨殿安中賦百韻詩紀事令大</span>  
<span style="margin-left: 2em">書殿屏仍以副本分賜侍臣王明淸揮麈後錄載</span>  
<span style="margin-left: 2em">其詩周煇淸波雜志又補載其序皆盛相推挹張</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3771.svg?width=24" alt="四庫全書僻字第3771號（邦）" title="四庫全書僻字第3771號（邦）">基墨莊漫錄又載其立春帖子稱以才華淸麗</span>  
<span style="margin-left: 2em">其人雖至不足道而文章富贍要有未可盡冺者</span>  
<span style="margin-left: 2em">錄而傳之亦不以人廢言之義也其集見於本傳</span>  
<span style="margin-left: 2em">者七十六卷晁公武讀書志止作十卷趙希弁附</span>  
<span style="margin-left: 2em">志則作前集四十卷又内外制二十六卷與史傳</span>  
<!-- 册4 葉724b　Page:文淵閣四庫全書_0004冊.djvu/186 -->
<span style="margin-left: 2em">目次相符自明以來久佚不見今從永樂大典採</span>  
<span style="margin-left: 2em">掇裒次尚得詩文數百篇周必大序稱安中送其</span>  
<span style="margin-left: 2em">曾大父詩不論與汝小一月政自容君數百人句</span>  
<span style="margin-left: 2em">又楊萬里誠齋詩話稱安中行余深少宰制仰惟</span>  
<span style="margin-left: 2em">前代守文爲難相我受民非賢不乂句又在象州</span>  
<span style="margin-left: 2em">思鄉作文有萬里邱墳草木牛羊之踐履百年鄉</span>  
<span style="margin-left: 2em">社室家風雨之飄搖等句今俱不見於集中是其</span>  
<span style="margin-left: 2em">散佚甚多然蒐羅什一猶可考見崖畧謹𨤲爲八</span>  
<span style="margin-left: 2em">卷而仍以李邴周必大周紫芝序三篇冠之卷首</span>  
<!-- 册4 葉725a　Page:文淵閣四庫全書_0004冊.djvu/186 -->
<span style="margin-left: 2em">以存其舊焉</span>  
橫塘集二十卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋許景衡撰景衡字少伊温州瑞安人登元祐九</span>  
<span style="margin-left: 2em">年進士宣和中召爲監察御史遷殿中侍御史欽</span>  
<span style="margin-left: 2em">宗卽位以左正言召累遷中書舍人高宗朝至尚</span>  
<span style="margin-left: 2em">書右丞罷爲資政殿大學士提舉洞霄宫卒諡忠</span>  
<span style="margin-left: 2em">簡事蹟具宋史本傳景衡雖源出洛學而立身剛</span>  
<span style="margin-left: 2em">直不與賈易諸人囂爭門戸其文章坦白光明粹</span>  
<span style="margin-left: 2em">然一出於正在徽宗時卽極言財力匱乏請罷花</span>  
<!-- 册4 葉725b　Page:文淵閣四庫全書_0004冊.djvu/186 -->
<span style="margin-left: 2em">石綱運爲王黼所中而去及從高宗在揚州又與</span>  
<span style="margin-left: 2em">黃潛善不協借渡江之議斥逐而死雖阨於權倖</span>  
<span style="margin-left: 2em">屢起屢躓而終始不撓今集中所存奏議如論童</span>  
<span style="margin-left: 2em">貫誤國辨宗澤無過論王安石當自便乞寛恤東</span>  
<span style="margin-left: 2em">南諸劄子皆誠意懇摯剴切詳明其他亦多關係</span>  
<span style="margin-left: 2em">國家大計雖當時不能盡用其說而史稱旣沒之</span>  
<span style="margin-left: 2em">後高宗毎念其遇事敢言追思不置亦足見其忠</span>  
<span style="margin-left: 2em">愛之忱有以感孚於平素也至其詩篇乃吐言淸</span>  
<span style="margin-left: 2em">拔不露伉厲之氣如玉樽浮蟻一樣白靑眼與山</span>  
<!-- 册4 葉728a　Page:文淵閣四庫全書_0004冊.djvu/187 -->
<span style="margin-left: 2em">相對橫諸句殊饒風調胡仔漁隱叢話謂冦凖詩</span>  
<span style="margin-left: 2em">含思凄婉富於音情殊不𩔖其爲人今景衡亦然</span>  
<span style="margin-left: 2em">葢詩本性情義存比興固不必定爲濂洛風雅之</span>  
<span style="margin-left: 2em">派而後謂之正人也宋史藝文志載橫塘集三十</span>  
<span style="margin-left: 2em">卷書錄解題亦同自明以來傳本久絶今從永樂</span>  
<span style="margin-left: 2em">大典中採掇裒緝以次排纂𨤲爲二十卷朱子語</span>  
<span style="margin-left: 2em">錄嘗稱陳少陽事其詳見許右丞哀詞中今巳不</span>
