## 欽定四庫全書總目 卷一百四十八　集部一　楚辭類、楚辭類存目、別集類一

<!-- 册4 葉4：整葉圖版，無文字記錄 -->
<!-- 册4 葉5a　Page:文淵閣四庫全書_0004冊.djvu/6 -->
欽定四庫全書總目巻一百四十八  
<span style="margin-left: 1em">集部總敘</span>  
<span style="margin-left: 2em">集部之目楚辭最古别集次之總集次之詩文評</span>  
<span style="margin-left: 2em">又晩出詞曲則其閏餘也古人不以文章名故秦</span>  
<span style="margin-left: 2em">以前書無稱屈原宋玉工賦者洎乎漢代始有詞</span>  
<span style="margin-left: 2em">人迹其著作率由追錄故武帝命所忠求相如遺</span>  
<span style="margin-left: 2em">書魏文帝亦詔天下上孔融文章至於六朝始自</span>  
<span style="margin-left: 2em">編次唐末又刋板印行<sub class="note-yuan">事見貫休磾月集序</sub>夫自編則多所</span>  
<span style="margin-left: 2em">愛惜刋板則易於流傳四部之書别集最襍茲其</span>  
<!-- 册4 葉5b　Page:文淵閣四庫全書_0004冊.djvu/6 -->
<span style="margin-left: 2em">故歟然典冊高文淸詞麗句亦未嘗不高標獨秀</span>  
<span style="margin-left: 2em">挺出鄧林此在翦刈巵言别裁僞體不必以猥濫</span>  
<span style="margin-left: 2em">病也總集之作多由論定而蘭亭金谷悉觴咏於</span>  
<span style="margin-left: 2em">一時下及漢上題襟松陵倡和丹陽集惟錄鄕人</span>  
<span style="margin-left: 2em">篋中集則附登乃弟雖去取僉孚衆議而履霜有</span>  
<span style="margin-left: 2em">漸巳爲詩社標榜之先驅其聲氣攀援甚於别集</span>  
<span style="margin-left: 2em">要之浮華易歇公論終明巋然而獨存者文選玉</span>  
<span style="margin-left: 2em">臺新詠以下數十家耳詩文評之作著於齊梁觀</span>  
<span style="margin-left: 2em">同一八病四聲也鍾嶸以求譽不遂巧致譏排劉</span>  
<!-- 册4 葉8a　Page:文淵閣四庫全書_0004冊.djvu/7 -->
<span style="margin-left: 2em">勰以知遇獨深繼爲推闡詞場恩怨亘古如斯冷</span>  
<span style="margin-left: 2em">齋曲附乎豫章石林隠排乎元祐黨人餘釁報及</span>  
<span style="margin-left: 2em">文章又其巳事矣固宜别白存之各核其實至於</span>  
<span style="margin-left: 2em">𠋣聲末技分派詩歌其間周柳蘇辛亦遞爭軌轍</span>  
<span style="margin-left: 2em">然其得其失不足重輕姑附存以備一格而巳大</span>  
<span style="margin-left: 2em">抵門戸搆爭之見莫甚於講學而論文次之講學</span>  
<span style="margin-left: 2em">者聚黨分朋徃徃禍延宗社操觚之士筆舌相攻</span>  
<span style="margin-left: 2em">則未有亂及國事者蓋講學者必辨是非辨是非</span>  
<span style="margin-left: 2em">必及時政其事與權𫝑相連故其患大文人詞翰</span>  
<!-- 册4 葉8b　Page:文淵閣四庫全書_0004冊.djvu/7 -->
<span style="margin-left: 2em">所爭者名譽而巳與朝廷無預故其患小也然如</span>  
<span style="margin-left: 2em">艾南英以排斥王李之故至以嚴嵩爲察相而以</span>  
<span style="margin-left: 2em">殺楊繼盛爲稍過當豈其捫心淸夜果自謂然亦</span>  
<span style="margin-left: 2em">朋黨旣分𫝑不兩立故决裂名教而不辭耳至錢</span>  
<span style="margin-left: 2em">謙益列朝詩集更顚倒賢姦<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">良冺絶其貽害人</span>  
<span style="margin-left: 2em">心風俗者又豈尠哉今掃除畛域一凖至公明以</span>  
<span style="margin-left: 2em">來諸派之中各取其所長而不回䕶其所短蓋有</span>  
<span style="margin-left: 2em">世道之防焉不僅爲文體計也</span>  
<span style="margin-left: 1em">集部一</span>  
<!-- 册4 葉9a　Page:文淵閣四庫全書_0004冊.djvu/7 -->
<span style="margin-left: 2em">楚辭類</span>  
<span style="margin-left: 3em">裒屈宋諸賦定名楚辭自劉向始也後人或謂</span>  
<span style="margin-left: 3em">之騷故劉勰品論楚辭以辨騷標目考史遷稱</span>  
<span style="margin-left: 3em">屈原放逐乃著離騷葢舉其最著一篇九歌以</span>  
<span style="margin-left: 3em">下均襲騷名則非事實矣隋志集部以楚辭别</span>  
<span style="margin-left: 3em">爲一門厯代因之葢漢魏以下賦體旣變無全</span>  
<span style="margin-left: 3em">集皆作此體者他集不與楚辭𩔖楚辭亦不與</span>  
<span style="margin-left: 3em">他集類體例旣異理不得不分著也楊穆有九</span>  
<span style="margin-left: 3em">悼一卷至宋巳佚晁補之朱子皆嘗續編然補</span>  
<!-- 册4 葉9b　Page:文淵閣四庫全書_0004冊.djvu/7 -->
<span style="margin-left: 3em">之書亦不傳僅朱子書附刻集註後今所傳者</span>  
<span style="margin-left: 3em">大抵註與音耳註家由東漢至宋遞相補苴無</span>  
<span style="margin-left: 3em">大異詞迨於近世始多别解割裂補綴言人人</span>  
<span style="margin-left: 3em">殊錯簡說經之術蔓延及於詞賦矣今並刋除</span>  
<span style="margin-left: 3em">杜竄亂古書之漸也</span>  
楚辭章句十七卷<sub class="note-yuan">兵部侍郞紀昀家藏本</sub>  
<span style="margin-left: 2em">漢王逸撰逸字叔師南郡宜城人順帝時官至侍</span>  
<span style="margin-left: 2em">中事迹具後漢書文苑傳舊本題校書郞中葢據</span>  
<span style="margin-left: 2em">其註是書時所居官也初劉向裒集屈原離騷九</span>  
<!-- 册4 葉12a　Page:文淵閣四庫全書_0004冊.djvu/8 -->
<span style="margin-left: 2em">歌天問九章遠遊卜居漁父宋玉九辨招魂景差</span>  
<span style="margin-left: 2em">大招而以賈誼惜誓淮南小山招隠士東方朔七</span>  
<span style="margin-left: 2em">諫嚴忌哀時命王褒九懷及向所作九嘆共爲楚</span>  
<span style="margin-left: 2em">辭十六篇是爲總集之祖逸又益以巳作九思與</span>  
<span style="margin-left: 2em">班固二叙爲十七巻而各爲之注其九思之註洪</span>  
<span style="margin-left: 2em">興祖疑其子延壽所爲然漢書地理志藝文志卽</span>  
<span style="margin-left: 2em">有自註事在逸前謝靈運作山居賦亦自註之安</span>  
<span style="margin-left: 2em">知非用逸例𫆀舊說無文未可遽疑爲延壽作也</span>  
<span style="margin-left: 2em">陳振孫書錄解題載有古文楚辭釋文一卷其篇</span>  
<!-- 册4 葉12b　Page:文淵閣四庫全書_0004冊.djvu/8 -->
<span style="margin-left: 2em">第首離騷次九辨九歌天問九章遠遊卜居漁父</span>  
<span style="margin-left: 2em">招隠士招魂九懷七諫九歎哀時命惜誓大招九</span>  
<span style="margin-left: 2em">思迥與今本不同興祖據逸九章註中稱皆解於</span>  
<span style="margin-left: 2em">九辨中知古本九辨在前九章在後振孫又引朱</span>  
<span style="margin-left: 2em">子之言據天聖十年陳說之序謂舊本篇第混併</span>  
<span style="margin-left: 2em">乃考其人之先後重定其篇第知今本爲說之所</span>  
<span style="margin-left: 2em">改則自宋以來巳非逸之舊本又黄伯思東觀餘</span>  
<span style="margin-left: 2em">論謂逸註楚辭序皆在後如法言舊本之例不知</span>  
<span style="margin-left: 2em">何人移於前則不但篇第非舊併其序亦非舊矣</span>  
<!-- 册4 葉13a　Page:文淵閣四庫全書_0004冊.djvu/8 -->
<span style="margin-left: 2em">然洪興祖考異於離騷經下註曰釋文第一無經</span>  
<span style="margin-left: 2em">字而逸註明云離别也騷愁也經徑也則逸所註</span>  
<span style="margin-left: 2em">本<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">有經字與釋文本不同必謂釋文爲舊本亦</span>  
<span style="margin-left: 2em">未可信姑存其說可也逸註雖不甚詳核而去古</span>  
<span style="margin-left: 2em">未遠多傳先儒之訓詁故李善註文選全用其文</span>  
<span style="margin-left: 2em">抽思以下諸篇註中徃徃隔句用韻如哀憤結縎</span>  
<span style="margin-left: 2em">慮煩𡨚也哀悲太息損肺肝也心中結屈如連環</span>  
<span style="margin-left: 2em">也之𩔖不一而足葢仿周易𧰼傳之體亦足以考</span>  
<span style="margin-left: 2em">證漢人之韻而吳棫以來談古韻者皆未徵引是</span>  
<!-- 册4 葉13b　Page:文淵閣四庫全書_0004冊.djvu/8 -->
<span style="margin-left: 2em">尤宜表而出之矣</span>  
楚辭補註十七卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋洪興祖撰興祖字慶善陸游渭南集有興祖手</span>  
<span style="margin-left: 2em">帖跋稱爲洪成季慶善未之詳也丹陽人政和中</span>  
<span style="margin-left: 2em">登上舍第南渡後召試授秘書省正字厯官提<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）"></span>  
<span style="margin-left: 2em">江東刑獄知眞州饒州後忤秦檜編管昭州卒事</span>  
<span style="margin-left: 2em">迹具宋史儒林傳周麟之海陵集有興祖贈<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">敷</span>  
<span style="margin-left: 2em">文閣制極褒其編纂之功葢檜死乃昭雪也案陳</span>  
<span style="margin-left: 2em">振孫書錄解題列補註楚詞十七巻考異一巻稱</span>  
<!-- 册4 葉16a　Page:文淵閣四庫全書_0004冊.djvu/9 -->
<span style="margin-left: 2em">興祖少時從柳展如得東坡手校十卷凡諸本異</span>  
<span style="margin-left: 2em">同皆兩出之後又得洪玉父而下本十四五家叅</span>  
<span style="margin-left: 2em">校遂爲定本始補王逸章句之未備者成書又得</span>  
<span style="margin-left: 2em">姚廷輝本作考異附古本釋文之後又得歐陽永</span>  
<span style="margin-left: 2em">叔孫莘老蘇子容本於闗子東葉少恊校正以補</span>  
<span style="margin-left: 2em">考異之遺云云則舊本兼載釋文而考異一卷附</span>  
<span style="margin-left: 2em">之在補註十七卷之外此本毎巻之末有汲古後</span>  
<span style="margin-left: 2em">人毛表字奏叔依古本是正印記而考異巳散入</span>  
<span style="margin-left: 2em">各句下未知誰所竄亂也又目錄後有興祖附記</span>  
<!-- 册4 葉16b　Page:文淵閣四庫全書_0004冊.djvu/9 -->
<span style="margin-left: 2em">稱鮑欽止云辨騷非楚辭本書不當錄班固二序</span>  
<span style="margin-left: 2em">舊在九歎之後今附於第一通之末云云此本離</span>  
<span style="margin-left: 2em">騷之末有班固二序與所記合而劉勰辨騷一篇</span>  
<span style="margin-left: 2em">仍列序後亦不詳其何故豈但言其不當錄而未</span>  
<span style="margin-left: 2em">敢遽刪歟漢人注書大抵簡質又徃徃舉其訓詁</span>  
<span style="margin-left: 2em">而不備列其考據興祖是編列逸註於前而一一</span>  
<span style="margin-left: 2em">疏通證明補註於後於逸註多所闡𤼵又皆以補</span>  
<span style="margin-left: 2em">日二字别之使與原文不亂亦異乎明代諸人妄</span>  
<span style="margin-left: 2em">改古書恣情損益於楚辭諸註之中特爲善本故</span>  
<!-- 册4 葉17a　Page:文淵閣四庫全書_0004冊.djvu/9 -->
<span style="margin-left: 2em">陳振孫稱其用力之勤而朱子作集註亦多取其</span>  
<span style="margin-left: 2em">說云</span>  
楚辭集註八卷辨證二卷後語六卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋朱子撰以後漢王逸章句及洪興祖補註二書</span>  
<span style="margin-left: 2em">詳於訓詁未得意㫖乃𭬚括舊編定爲此本以屈</span>  
<span style="margin-left: 2em">原所著二十五篇爲離騷宋玉以下十六篇爲續</span>  
<span style="margin-left: 2em">離騷隨文詮釋毎章各繫以興比賦字如毛詩傳</span>  
<span style="margin-left: 2em">例其訂正舊註之謬誤者别爲辨證二巻附焉自</span>  
<span style="margin-left: 2em">爲之序又刋定晁補之續楚辭變離騷二書錄荀</span>  
<!-- 册4 葉17b　Page:文淵閣四庫全書_0004冊.djvu/9 -->
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">至吕大臨凡五十二篇爲楚辭後語亦自爲之</span>  
<span style="margin-left: 2em">序楚辭舊本有東方朔七諫王褒九懷劉向九歎</span>  
<span style="margin-left: 2em">王逸九思晁本刪九思一篇是編并削七諫九懷</span>  
<span style="margin-left: 2em">九歎三篇益以賈誼二賦陳振孫書錄解題謂以</span>  
<span style="margin-left: 2em">七諫以下詞意平緩意不深切如無病而呻吟者</span>  
<span style="margin-left: 2em">也晁氏續離騷凡二十巻變楚辭亦二十卷後語</span>  
<span style="margin-left: 2em">刪爲六卷去取特嚴而揚雄反騷爲舊錄所不取</span>  
<span style="margin-left: 2em">者乃反收入自序謂欲因反騷而著蘇氏洪氏之</span>  
<span style="margin-left: 2em">貶詞以明天下之大戒也周密齊東野語記紹熙</span>  
<!-- 册4 葉20a　Page:文淵閣四庫全書_0004冊.djvu/10 -->
