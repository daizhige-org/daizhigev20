## 欽定四庫全書總目 卷六十六　史部二十二　載記類、載記類存目

<!-- 册2 葉1692：整葉圖版，無文字記錄 -->

欽定四庫全書總目巻六十六  
<span style="margin-left: 1em">史部二十二</span>  
<span style="margin-left: 2em">載記類</span>  
<span style="margin-left: 3em">五馬南浮中原雲擾偏方割據各設史官其事</span>  
<span style="margin-left: 3em">迹亦不容泯滅故阮孝緒作七錄僞史立焉隋</span>  
<span style="margin-left: 3em">志改稱霸史文獻通考則兼用二名然年祀綿</span>  
<span style="margin-left: 3em">邈文籍散佚當時僭撰久巳無存存於今者大</span>  
<span style="margin-left: 3em">抵後人追記而巳曰霸曰僞皆非其實也案後</span>  
<span style="margin-left: 3em">漢書班固傳稱撰平林新市公孫述事爲載記</span>  
<!-- 册2 葉1693b　Page:文淵閣四庫全書_0002冊.djvu/428 -->
<span style="margin-left: 3em">史通亦稱平林下江諸人東觀列爲載記又晉</span>  
<span style="margin-left: 3em">書附叙十六國亦云載記是實立乎中朝以叙</span>  
<span style="margin-left: 3em">述列國之名今採錄吳越春秋以下述偏方僭</span>  
<span style="margin-left: 3em">亂遺迹者準東觀漢記晉書之例總題曰載記</span>  
<span style="margin-left: 3em">於義爲允惟越史略一書爲其國所自作僭號</span>  
<span style="margin-left: 3em">紀年眞爲僞史然外方私記不過附存巳聲罪</span>  
<span style="margin-left: 3em">示誅足昭名分固無庸爲此數巻别區門目焉</span>  
吳越春秋十巻<sub class="note-yuan">兵部侍郞紀昀家藏本</sub>  
<span style="margin-left: 2em">漢趙煜撰煜山陰人見後漢書儒林傳是書前有</span>  
<!-- 册2 葉1696a　Page:文淵閣四庫全書_0002冊.djvu/429 -->
<span style="margin-left: 2em">舊序稱隋唐經籍志皆云十二巻今存者十巻殆</span>  
<span style="margin-left: 2em">非全書又云楊方撰吳越春秋削繁五巻皇甫遵</span>  
<span style="margin-left: 2em">撰吳越春秋傳十巻此二書今人罕見獨煜書行</span>  
<span style="margin-left: 2em">於世史記注有徐廣所引吳越春秋語而索隱以</span>  
<span style="margin-left: 2em">爲今無此語他如文選注引季札見遺金事吳地</span>  
<span style="margin-left: 2em">記載闔閭時夷亭事及水經注嘗載越事數條類</span>  
<span style="margin-left: 2em">皆援据吳越春秋今煜本咸無其文云云攷證頗</span>  
<span style="margin-left: 2em">爲詳悉然不著名姓漢魏叢書所載合十巻爲六</span>  
<span style="margin-left: 2em">巻而削去此序併注亦不題撰人彌失其初此本</span>  
<!-- 册2 葉1696b　Page:文淵閣四庫全書_0002冊.djvu/429 -->
<span style="margin-left: 2em">爲元大德十年丙午所刊後有題識云前文林郞</span>  
<span style="margin-left: 2em">國子監書庫官徐天祐音注然後知注中稱徐天</span>  
<span style="margin-left: 2em">祐曰者卽注者之自名非援引他書之語惟其後</span>  
<span style="margin-left: 2em">又列紹興路儒學學錄留堅學正陳昺伯敎授梁</span>  
<span style="margin-left: 2em">相正議大夫紹興路總管提調學校官劉克昌四</span>  
<span style="margin-left: 2em">人不知序出誰手耳煜所述雖稍傷曼衍而詞頗</span>  
<span style="margin-left: 2em">豐蔚其中如伍尚占甲子之日時加於已范蠡占</span>  
<span style="margin-left: 2em">戊寅之日時加日出有螣蛇靑龍之語文種占陰</span>  
<span style="margin-left: 2em">畫六陽畫三有元武天空天關天梁天一神光諸</span>  
<!-- 册2 葉1697a　Page:文淵閣四庫全書_0002冊.djvu/429 -->
<span style="margin-left: 2em">神名皆非三代卜筮之法未免多所附會至於處</span>  
<span style="margin-left: 2em">女試劔老人化猿公孫聖三呼三應之類尤近小</span>  
<span style="margin-left: 2em">說家言然自是漢晉間稗官襍記之體徐天祐以</span>  
<span style="margin-left: 2em">爲不類漢文是以馬班史法求之非其倫也天祐</span>  
<span style="margin-left: 2em">注於事迹異同頗有考證其中如季孫使越子期</span>  
<span style="margin-left: 2em">私與吳爲市之類雖猶有未及詳辨者而原書失</span>  
<span style="margin-left: 2em">實之處能糾正者爲多其旁核衆說不徇本書猶</span>  
<span style="margin-left: 2em">有劉孝標注世說新語之遺意焉</span>  
越絶書十五巻<sub class="note-yuan">兵部侍郞紀昀家藏本</sub>  
<!-- 册2 葉1697b　Page:文淵閣四庫全書_0002冊.djvu/429 -->
<span style="margin-left: 2em">不著撰人名氏書中吳地傳稱勾踐徙瑯琊到建</span>  
<span style="margin-left: 2em">武二十八年凡五百六十七年則後漢初人也書</span>  
<span style="margin-left: 2em">末叙外傳記以廋詞隱其姓名其云以去爲姓得</span>  
<span style="margin-left: 2em">衣乃成是袁字也厥名有米覆之以庚是康字也</span>  
<span style="margin-left: 2em">禹來東征死葬其疆是會稽人也又云文詞屬定</span>  
<span style="margin-left: 2em">自於邦賢以口爲姓承之以天是吳字也楚相屈</span>  
<span style="margin-left: 2em">原與之同名是平字也然則此書爲會稽袁康所</span>  
<span style="margin-left: 2em">作同郡吳平所定也王充論衡按書篇曰東番鄒</span>  
<span style="margin-left: 2em">伯奇臨淮袁太伯袁文術會稽吳君高周長生之</span>  
<!-- 册2 葉1700a　Page:文淵閣四庫全書_0002冊.djvu/430 -->
<span style="margin-left: 2em">輩位雖不至公卿誠能知之囊橐文雅之英雄也</span>  
<span style="margin-left: 2em">觀伯奇之元思太伯之易童句<sub class="note-yuan">案童疑作章</sub>文術之咸</span>  
<span style="margin-left: 2em">銘君高之越紐錄長生之洞厯劉子政揚子雲不</span>  
<span style="margin-left: 2em">能過也所謂吳君高殆卽平字所謂越紐錄殆卽</span>  
<span style="margin-left: 2em">此書歟楊愼丹鉛錄胡侍珍珠船田藝衡留靑日</span>  
<span style="margin-left: 2em">札皆有是說核其文義一一脗合隋唐志皆云子</span>  
<span style="margin-left: 2em">貢作非其實矣其文縱橫曼衍與吳越春秋相類</span>  
<span style="margin-left: 2em">而博麗奥衍則過之中如計倪内經軍氣之類多</span>  
<span style="margin-left: 2em">襍術數家言皆漢人專門之學非後來所能依託</span>  
<!-- 册2 葉1700b　Page:文淵閣四庫全書_0002冊.djvu/430 -->
<span style="margin-left: 2em">也此本與吳越春秋皆大德丙午紹興路所刊巻</span>  
<span style="margin-left: 2em">末一䟦諸本所無惟申明復仇之義不著姓名詳</span>  
<span style="margin-left: 2em">其詞意或南宋人所題耶鄭明選秕言稱文選七</span>  
<span style="margin-left: 2em">命注引越絶書大翼一艘十丈中翼九丈六尺小</span>  
<span style="margin-left: 2em">翼九丈又稱王鏊震澤長語引越絶書風起震方</span>  
<span style="margin-left: 2em">云云謂今本皆無此語疑更有全書惜未之見案</span>  
<span style="margin-left: 2em">崇文總目稱越絶書舊有内記八外傳十七今文</span>  
<span style="margin-left: 2em">題闕舛裁二十篇是此書在北宋之初巳佚五篇</span>  
<span style="margin-left: 2em">選注所引葢佚篇之文王鏊所稱亦他書所引佚</span>  
<!-- 册2 葉1701a　Page:文淵閣四庫全書_0002冊.djvu/430 -->
<span style="margin-left: 2em">篇之文以爲此本之外更有全書則明選誤矣别</span>  
<span style="margin-left: 2em">有續越絶書二巻上巻曰内傳本事吳内傳德序</span>  
<span style="margin-left: 2em">記子游内經外傳越絶後語西施鄭旦外傳下巻</span>  
<span style="margin-left: 2em">曰越外傳襍事别傳變越上别傳變越下經内雅</span>  
<span style="margin-left: 2em">琴考序傳後記朱<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">尊經義考謂爲錢𠷓僞撰詭</span>  
<span style="margin-left: 2em">云得之石匣中𠷓與<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">尊友善所言當實今未見</span>  
<span style="margin-left: 2em">傳本其僞妄亦不待辨以其續此書而作又卽托</span>  
<span style="margin-left: 2em">於撰此書之人恐其幸而或傳久且亂眞又恐其</span>  
<span style="margin-left: 2em">或不能傳而好異者耳聞其說且疑此書之眞有</span>  
<!-- 册2 葉1701b　Page:文淵閣四庫全書_0002冊.djvu/430 -->
<span style="margin-left: 2em">續編故附訂其僞於此釋來者之惑焉</span>  
華陽國志十二巻附錄一巻<sub class="note-yuan">浙江汪啓淑家藏本</sub>  
<span style="margin-left: 2em">晉常璩撰璩字道將江原人李𫝑時官至散騎常</span>  
<span style="margin-left: 2em">侍晉書載勸𫝑降桓温者卽璩葢亦譙周之流也</span>  
<span style="margin-left: 2em">隋書經籍志霸史類中載璩撰漢之書十巻華陽</span>  
<span style="margin-left: 2em">國志十二巻漢之書唐志尚著錄今巳久佚惟華</span>  
<span style="margin-left: 2em">陽國志存巻數與隋志舊唐志相合新唐志作十</span>  
<span style="margin-left: 2em">三巻疑傳寫誤也其書所述始於開闢終於永和</span>  
<span style="margin-left: 2em">三年首爲巴志次漢中志次蜀志次南中志次公</span>  
<!-- 册2 葉1704a　Page:文淵閣四庫全書_0002冊.djvu/431 -->
<span style="margin-left: 2em">孫劉二牧志次劉先主志次劉後主志次大同志</span>  
<span style="margin-left: 2em">大同者紀漢晉平蜀之後事也次李特雄期壽𫝑</span>  
<span style="margin-left: 2em">志次先賢士女總讚論次後賢志次序志次三州</span>  
<span style="margin-left: 2em">士女目錄宋元豐中吕大防嘗刻於成都大防自</span>  
<span style="margin-left: 2em">爲之序又有嘉泰甲子李𡉙序稱吕刻刓缺觀者</span>  
<span style="margin-left: 2em">莫曉所謂嘗博訪善本以證其誤而莫之或得因</span>  
<span style="margin-left: 2em">摭兩漢史陳壽蜀書益部耆舊傳互相叅訂以决</span>  
<span style="margin-left: 2em">所疑凡一事而前後失序本末舛迕者則考正之</span>  
<span style="margin-left: 2em">一意而詞旨重複句讀錯襍者則刊而去之又第</span>  
<!-- 册2 葉1704b　Page:文淵閣四庫全書_0002冊.djvu/431 -->
<span style="margin-left: 2em">九巻末有𡉙附記稱李𫝑志傳寫脫漏續成以補</span>  
<span style="margin-left: 2em">其闕則是書又於殘缺之餘李𡉙爲之補綴竄易</span>  
<span style="margin-left: 2em">非盡璩之舊矣𡉙刻本世亦不傳今所傳者惟影</span>  
<span style="margin-left: 2em">寫本又有何鏜漢魏叢書吳琯古今逸史及明何</span>  
<span style="margin-left: 2em">宇度所刊三本何吳二家之本多張佳允所補江</span>  
<span style="margin-left: 2em">原常氏士女志一巻而佚去蜀中士女以下至犍</span>  
<span style="margin-left: 2em">爲士女共二巻葢𡉙本第十巻分上中下鏜等僅</span>  
<span style="margin-left: 2em">刻其下巻也又惟後賢志中二十人有讚其餘並</span>  
<span style="margin-left: 2em">缺𡉙本則蜀郡廣漢犍爲漢中梓潼士女一百九</span>  
<!-- 册2 葉1705a　Page:文淵閣四庫全書_0002冊.djvu/431 -->
<span style="margin-left: 2em">十四人各有讚宇度本亦同葢明人刻書好以意</span>  
<span style="margin-left: 2em">爲刊削新本旣行舊本漸冺原書遂不可覿宇度</span>  
<span style="margin-left: 2em">之本從𡉙本錄出此二巻偶存亦天幸也惟𡉙本</span>  
<span style="margin-left: 2em">以序志置於末而宇度本升於簡端考𡉙序稱首</span>  
<span style="margin-left: 2em">述巴中南中之風土次列公孫述劉二牧蜀二主</span>  
<span style="margin-left: 2em">之興廢及晉太康之混一以迄於特雄壽𫝑之僭</span>  
<span style="margin-left: 2em">竊以西漢以來先後賢人梁益寧三州士女總讚</span>  
<span style="margin-left: 2em">序志終焉則序志本在後宇度不知古例始誤移</span>  
<span style="margin-left: 2em">之又總讚相續成文𡉙序亦與序志並稱宜别爲</span>  
<!-- 册2 葉1705b　Page:文淵閣四庫全書_0002冊.djvu/431 -->
<span style="margin-left: 2em">一篇而𡉙本亦割冠各傳之首殊不可解殆如毛</span>  
<span style="margin-left: 2em">公之移詩序李鼎祚之分序卦傳乎今姑從𡉙本</span>  
<span style="margin-left: 2em">錄之而附著其改竄之非如右其張佳允所續常</span>  
<span style="margin-left: 2em">氏士女十九人亦併從何鏜吳琯二本錄入以補</span>  
<span style="margin-left: 2em">璩之遺焉</span>  
鄴中記一巻<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">謹案鄴中記舊有二本其一本二巻見隋書經籍</span>  
<span style="margin-left: 2em">志稱晉國子助教陸<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2908.svg?width=24" alt="四庫全書僻字第2908號（⿰嵗羽 -- 翽）" title="四庫全書僻字第2908號（⿰嵗羽 -- 翽）">撰其一本一巻見陳振孫</span>  
<span style="margin-left: 2em">書錄解題稱不知撰人名氏又稱唐志有鄴都故</span>  
<!-- 册2 葉1708a　Page:文淵閣四庫全書_0002冊.djvu/432 -->
<span style="margin-left: 2em">事二巻肅代時馬温撰今書多引之是以爲肅代</span>  
<span style="margin-left: 2em">後人作矣今考是書所記有北齊高歡高洋二事</span>  
<span style="margin-left: 2em">上距東晉之末已一百三四十年又寒食一條引</span>
