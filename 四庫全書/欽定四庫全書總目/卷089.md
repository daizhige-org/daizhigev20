## 欽定四庫全書總目 卷八十九　史部四十五　史評類存目一

<!-- 册2 葉3288：整葉圖版，無文字記錄 -->
<!-- 册2 葉3289a　Page:文淵閣四庫全書_0002冊.djvu/827 -->
欽定四庫全書總目卷八十九  
<span style="margin-left: 1em">史部四十五</span>  
<span style="margin-left: 2em">史評類存目一</span>  
史通會要三卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">明陸深撰深有南巡日錄巳著錄深嘗以唐劉知</span>  
<span style="margin-left: 2em">幾史通刋本多誤爲校定之凡補殘刓謬若干言</span>  
<span style="margin-left: 2em">又以其因習上篇缺佚乃訂正曲筆鑒識二篇錯</span>  
<span style="margin-left: 2em">簡類爲一篇以還之復采其中精粹者别纂爲會</span>  
<span style="margin-left: 2em">要三卷而陮以後人論史之語時亦以巳見叅之</span>  
<!-- 册2 葉3289b　Page:文淵閣四庫全書_0002冊.djvu/827 -->
<span style="margin-left: 2em">深集中别載史通二跋大畧言知幾是非任情往</span>  
<span style="margin-left: 2em">往捃摭賢聖是其所短至於評隲文體亦可謂當</span>  
<span style="margin-left: 2em">又言知幾嘗謂國史叙事以簡爲主而其書之冗</span>  
<span style="margin-left: 2em">長乃不少觀其議論可以見其去取之旨矣</span>  
史通評釋二十卷<sub class="note-yuan">編修勵守謙家藏本</sub>  
<span style="margin-left: 2em">明李維楨評郭孔延附評併釋維楨字本寧京山</span>  
<span style="margin-left: 2em">人隆慶戊辰進士官至南京禮部尚書事迹具明</span>  
<span style="margin-left: 2em">史文苑傳孔延始末未詳史通舊刻傳世者稀故</span>  
<span style="margin-left: 2em">永樂大典綱羅繁富而獨遺是書其後有蜀本吳</span>  
<!-- 册2 葉3292a　Page:文淵閣四庫全書_0002冊.djvu/828 -->
<span style="margin-left: 2em">本文句脫畧互有異同萬厯中復有張氏刻本增</span>  
<span style="margin-left: 2em">七百三十餘字刪六十餘字復於曲筆因習二篇</span>  
<span style="margin-left: 2em">補其殘缺遂爲完書不知其所增益果據何本然</span>  
<span style="margin-left: 2em">自是以後皆以張本爲祖矣維楨因張氏之本畧</span>  
<span style="margin-left: 2em">爲評論孔延因續爲評釋雜引諸書以證之凡每</span>  
<span style="margin-left: 2em">篇之末標評曰字者皆維楨語標附評字者則孔</span>  
<span style="margin-left: 2em">延所補也維楨所評不出明人游談之習無足置</span>  
<span style="margin-left: 2em">論孔延所釋較有引據而所徴故事率不著其出</span>  
<span style="margin-left: 2em">典亦頗有舛漏故王維儉以下註史通者數家皆</span>  
<!-- 册2 葉3292b　Page:文淵閣四庫全書_0002冊.djvu/828 -->
<span style="margin-left: 2em">嫌其未愜多所紏正焉</span>  
史通訓故二十卷<sub class="note-yuan">編修勵守謙家藏本</sub>  
<span style="margin-left: 2em">明王維儉撰維儉字損仲祥符人萬厯乙未進士</span>  
<span style="margin-left: 2em">官至山東巡撫事迹具明史文苑傳是編因郭孔</span>  
<span style="margin-left: 2em">延所釋重爲𨤲正又以華亭張之象藏本叅校刋</span>  
<span style="margin-left: 2em">定卷端有維儉題識稱除增因習一篇及更定直</span>  
<span style="margin-left: 2em">書曲筆二篇外共校正一千一百四十二字然以</span>  
<span style="margin-left: 2em">二本相校惟曲筆篇增入一百一十九字其因習</span>  
<span style="margin-left: 2em">直書二篇並與郭本相同無增入之語不知何以</span>  
<!-- 册2 葉3293a　Page:文淵閣四庫全書_0002冊.djvu/828 -->
<span style="margin-left: 2em">云然也孔延注本漏畧實甚維儉所補引證較詳</span>  
<span style="margin-left: 2em">然黃叔琳浦起龍續注是書尙多所駁正蓋劉知</span>  
<span style="margin-left: 2em">幾博極史籍於斯事爲耑門又唐以前書今不盡</span>  
<span style="margin-left: 2em">見後人捃摭殘賸比附推求實非一二人之耳目</span>  
<span style="margin-left: 2em">所能徧考輾轉相承乃能賅備固亦勢所必然耳</span>  
史通訓故補二十卷<sub class="note-yuan">編修勵守謙家藏本</sub>  
<span style="margin-left: 1em">國朝黃叔琳撰叔琳有研北易抄巳著錄是書補王</span>  
<span style="margin-left: 2em">維儉註所未及與浦起龍史通通釋同時而成而</span>  
<span style="margin-left: 2em">此本之出畧前故起龍亦問摭用所稱北平本者</span>  
<!-- 册2 葉3293b　Page:文淵閣四庫全書_0002冊.djvu/828 -->
<span style="margin-left: 2em">卽此書也浦本註釋較精核而失之於好改原文</span>  
<span style="margin-left: 2em">又評註夾襍儼如坊刻古文之例是其所短此本</span>  
<span style="margin-left: 2em">註釋不及起龍而不甚改竄猶屬謹嚴其圈㸃批</span>  
<span style="margin-left: 2em">語不出時文之式則與起龍畧同惟起龍於知幾</span>  
<span style="margin-left: 2em">原書多所𮞉䕶卽疑惑古經之𩔖亦不以爲非此</span>  
<span style="margin-left: 2em">書頗有紏正差爲勝之耳</span>  
四明尊堯集十一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">宋陳瓘撰瓘有了翁易說巳著録是書書錄解題</span>  
<span style="margin-left: 2em">著錄止一卷此本十一卷乃後人并其原表序跋</span>  
<!-- 册2 葉3296a　Page:文淵閣四庫全書_0002冊.djvu/829 -->
<span style="margin-left: 2em">合而編之者也瓘以紹聖史官專據王安石日錄</span>  
<span style="margin-left: 2em">改修神宗實錄變亂是非不可傳信因作是書以</span>  
<span style="margin-left: 2em">辨其妄其初竄廉州時所著名合浦尊堯集但著</span>  
<span style="margin-left: 2em">十論猶未直攻安石及北歸後乃改作此書分爲</span>  
<span style="margin-left: 2em">八門曰聖訓論道獻替理財邊機論兵處巳寓言</span>  
<span style="margin-left: 2em">始力斥王安石之誣皆摘實錄原文而各著駁論</span>  
<span style="margin-left: 2em">其下共六十五條坐此羈管台州其總論中所云</span>  
<span style="margin-left: 2em">安石退居鍾山著此訕書以授蔡卞卞當元祐之</span>  
<span style="margin-left: 2em">時增損潤色九年筆削云云大抵主於掊擊卞故</span>  
<!-- 册2 葉3296b　Page:文淵閣四庫全書_0002冊.djvu/829 -->
<span style="margin-left: 2em">史稱京卞兄弟最所忌恨得禍最酷然朱子尙病</span>  
<span style="margin-left: 2em">其有所避就未能直中安石隱微云</span>  
讀史管見三十卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋胡寅撰寅字明仲號致堂崇安人官至禮部侍</span>  
<span style="margin-left: 2em">郞諡文忠事蹟具宋史本傳是編乃其謫居之時</span>  
<span style="margin-left: 2em">讀司馬光資治通鑑而作前有嘉定丙寅其猶子</span>  
<span style="margin-left: 2em">大壯序稱書成於紹興乙亥又稱其父安國受知</span>  
<span style="margin-left: 2em">高宗奉詔修春秋傳宏綱大義日月著明二百四</span>  
<span style="margin-left: 2em">十二年之後至於五代司馬光所述資治通鑑事</span>  
<!-- 册2 葉3297a　Page:文淵閣四庫全書_0002冊.djvu/829 -->
<span style="margin-left: 2em">雖備而立義少實因用春秋經旨尙論詳評云云</span>  
<span style="margin-left: 2em">案胡安國之傳春秋於筆削大旨雖有發明而亦</span>  
<span style="margin-left: 2em">頗傷於深刻是以</span>  
欽定春秋傳說彚纂於其巳甚之詞多加駁正以持褒貶  
<span style="margin-left: 2em">之平寅作是書因其父說彌用嚴苛大抵其論人</span>  
<span style="margin-left: 2em">也人人責以孔顔思孟其論事也事事繩以虞夏</span>  
<span style="margin-left: 2em">商周名爲存天理遏人欲崇王道賤霸功而不近</span>  
<span style="margin-left: 2em">人情不揆事勢卒至於窒礙而難行王應麟通鑑</span>  
<span style="margin-left: 2em">問答謂但就一事詆斥不究其事之始終誠篤論</span>  
<!-- 册2 葉3297b　Page:文淵閣四庫全書_0002冊.djvu/829 -->
<span style="margin-left: 2em">也又多假借論端自申巳說凡所論是非往往枝</span>  
<span style="margin-left: 2em">蔓於本事之外趙與旹賓退錄曰胡致堂著讀史</span>  
<span style="margin-left: 2em">管見主於譏議秦會之開卷可見也如桑維翰雖</span>  
<span style="margin-left: 2em">因契丹而相其意特欲興晉而巳固無挾敵以自</span>  
<span style="margin-left: 2em">重劫國以盗權之意猶足爲賢尤爲深切致堂本</span>  
<span style="margin-left: 2em">文定從子其生也父母欲不舉文定夫人舉而子</span>  
<span style="margin-left: 2em">之及貴遭本生之喪士論有非之者<sub class="note-yuan">案寅以不持本生之服遭</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">劾見宋史本傳其自辨之書則見所撰斐然集中</sub>攷漢宣帝立皇考廟晉</span>  
<span style="margin-left: 2em">出帝封宋王敬儒兩章專以自解而於漢哀帝立</span>  
<!-- 册2 葉3300a　Page:文淵閣四庫全書_0002冊.djvu/830 -->
<span style="margin-left: 2em">定陶後一節直謂爲人後者不顧私親安而行之</span>  
<span style="margin-left: 2em">猶天性也吁甚矣首卷論豫讓報仇曰無所爲而</span>  
<span style="margin-left: 2em">爲善雖大學之道不是過若致堂者其亦有所爲</span>  
<span style="margin-left: 2em">而著書者歟則在當時論者亦有異同者矣至</span>  
<span style="margin-left: 1em">國朝朱直作史論初集專駁是書其間詆訶之詞雖</span>  
<span style="margin-left: 2em">不免於過當然亦寅之好爲高論有以激之至於</span>  
<span style="margin-left: 2em">出爾反爾也</span>  
三國紀年一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">宋陳亮撰亮字同甫婺州永康人紹熙四年進士</span>  
<!-- 册2 葉3300b　Page:文淵閣四庫全書_0002冊.djvu/830 -->
<span style="margin-left: 2em">第一官至建康軍節度判官事迹具宋史本傳是</span>  
<span style="margin-left: 2em">書大旨主於右蜀而貶魏吳名爲紀年實史家論</span>  
<span style="margin-left: 2em">斷之體巳載亮所著龍川集中此其别行之本也</span>  
議史摘要四卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">舊本題曰新刋祖謙吕先生議史摘要又題曰議</span>  
<span style="margin-left: 2em">史摘粹一書之中其名巳自相矛盾今檢其文卽</span>  
<span style="margin-left: 2em">吕祖謙左氏博議但增以註釋耳然註釋亦極淺</span>  
<span style="margin-left: 2em">陋惟板式頗舊蓋元明間麻沙書坊所僞刻也</span>  
三國六朝五代紀年總辨二十八卷<sub class="note-yuan">江蘇蔣曾瑩家藏本</sub>  
<!-- 册2 葉3301a　Page:文淵閣四庫全書_0002冊.djvu/830 -->
<span style="margin-left: 2em">不著撰人名氏惟前有開禧丁卯吳奐然序稱魏</span>  
<span style="margin-left: 2em">君仲舉比求到永嘉朱先生三國六朝五代紀年</span>  
<span style="margin-left: 2em">總辨循通鑑按前史而爲之辨論詞語警㧞侍郞</span>  
<span style="margin-left: 2em">葉公正則亦稱此書事理融會今昔貫通云云案</span>  
<span style="margin-left: 2em">文獻通考載紀年統論一卷紀年備遺一百卷永</span>  
<span style="margin-left: 2em">嘉朱黼撰引陳振孫書錄解題謂其起陶唐終顯</span>  
<span style="margin-left: 2em">德與此本不符又載葉適序稱其書三千餘篇述</span>  
<span style="margin-left: 2em">吕武王莾曹丕朱温皆削其紀年今此本三國始</span>  
<span style="margin-left: 2em">於漢昭烈帝章武元年不列曹丕五代始於唐天</span>  
<!-- 册2 葉3301b　Page:文淵閣四庫全書_0002冊.djvu/830 -->
<span style="margin-left: 2em">祐四年迄十九年下接後唐同光元年不列朱温</span>  
<span style="margin-left: 2em">其例又復相合考魏仲舉乃建陽書賈今所傳五</span>  
<span style="margin-left: 2em">百家註韓柳文集卽出其家蓋以刋書射利者又</span>  
<span style="margin-left: 2em">吳奐然序首以用兵立言中復有靈旗北指諸君</span>  
<span style="margin-left: 2em">封侯之秋語蓋開禧丁卯正韓𠈁胄肇釁敗盟之</span>  
<span style="margin-left: 2em">時時方競講北征故仲舉於紀年備遺之中摘刋</span>  
<span style="margin-left: 2em">割據戰伐之二十八卷以備程試答䇿之用觀序</span>  
<span style="margin-left: 2em">末有上可發前人未盡之藴下可以爲學者進取</span>  
<span style="margin-left: 2em">之階語則書肆之曲投時局以求速售其大㫖了</span>  
<!-- 册2 葉3304a　Page:文淵閣四庫全書_0002冊.djvu/831 -->
<span style="margin-left: 2em">然著矣卷端冠以三國兩晉南北朝五代世系與</span>  
<span style="margin-left: 2em">地理攻守之圖又甲子紀元總要一卷於曹丕朱</span>  
<span style="margin-left: 2em">温皆紀其年號與本書乖剌知亦仲舉所加非黼</span>  
<span style="margin-left: 2em">之舊也案平陽縣志黼字文昭隱居南蕩山終於</span>  
<span style="margin-left: 2em">布衣嘗受業陳傅良之門傅良喜議論有止齋論</span>  
<span style="margin-left: 2em">祖一書爲當時舉子所重故黼亦研心史事以作</span>  
<span style="margin-left: 2em">是編其原書雖不可盡睹然二十八卷中大抵憤</span>  
<span style="margin-left: 2em">南渡之積弱違心立論强作大言謂南可併北北</span>  
<span style="margin-left: 2em">不可以併南𠈁胄輕舉攻金浮動者譁然和之卒</span>

<span style="margin-left: 2em">召敗衂未必非黼等偏僻之說有以熒惑衆聽矣</span>
