<span style="margin-left: 1em">集部二十八</span>

明宣宗詩文一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">按明史藝文志載宣宗文集四十四卷今未見傳</span>  
<span style="margin-left: 2em">本此冊僅廣寒殿記一卷玉𬖂花賦一首詩歌詞</span>  
<span style="margin-left: 2em">曲三十九首非其全帙也朱<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">尊明詩綜所錄宣</span>  
<span style="margin-left: 2em">宗詩多此冊所未載意者<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">尊尙及見其集歟</span>  
御製回文詩一卷<sub class="note-yuan">左都御史張若溎家藏本</sub>  
<!-- 册4 葉2581b　Page:文淵閣四庫全書_0004冊.djvu/650 -->
<span style="margin-left: 2em">案此集載朱當㴐所輯國朝典故中惟題曰御製</span>  
<span style="margin-left: 2em">不著朝代明史藝文志不著錄不知何帝所作其</span>  
<span style="margin-left: 2em">詩以春夏秋冬四景爲題有龍文連環八卦諸體</span>  
<span style="margin-left: 2em">凡二十八首葢偶然游戲之作流傳於外與他書</span>  
<span style="margin-left: 2em">宣示頒賜見諸國史者有殊故史不載也</span>  
元宫詞一卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">不著撰人名氏前有自序稱永樂元年欽賜余家</span>  
<span style="margin-left: 2em">一老嫗年七十矣乃元宫之乳姆女知宫中事爲</span>  
<span style="margin-left: 2em">最悉間嘗細訪之一一備陳其事故余詩中所錄</span>  
<!-- 册4 葉2584a　Page:文淵閣四庫全書_0004冊.djvu/651 -->
<span style="margin-left: 2em">皆元宫之實事云云末題永樂四年夏四月朔日</span>  
<span style="margin-left: 2em">蘭雪軒製後有毛晉跋亦不知爲何許人案朱<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）"></span>  
<span style="margin-left: 2em">尊靜志居詩話曰元宫詞百首宛平劉效祖序稱</span>  
<span style="margin-left: 2em">周恭王所撰考定王以洪武十四年之國洪熙元</span>  
<span style="margin-left: 2em">年薨序題永樂四年則爲定王無疑矣定王名橚</span>  
<span style="margin-left: 2em">太祖第五子也明史周王橚傳用<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">尊之說葢以</span>  
<span style="margin-left: 2em">所考爲允矣詩凡一百首其中如東風吹綻牡丹</span>  
<span style="margin-left: 2em">芽一首燈月交光照綺羅一首玉京涼早是初秋</span>  
<span style="margin-left: 2em">一首深宫春暖日初長一首二十餘年備掖庭一</span>  
<!-- 册4 葉2584b　Page:文淵閣四庫全書_0004冊.djvu/651 -->
<span style="margin-left: 2em">首月明深院有霜華一首珊瑚枕冷象牙床一首</span>  
<span style="margin-left: 2em">金鴨燒殘午夜香一首惻惻輕寒透鳯幃一首憔</span>  
<span style="margin-left: 2em">悴花容只自知一首小樓春淺杏花寒一首御溝</span>  
<span style="margin-left: 2em">春水碧如天一首燕子泥香紅杏雨一首春情只</span>  
<span style="margin-left: 2em">在兩眉尖一首白露横空殿宇涼一首纎纎初月</span>  
<span style="margin-left: 2em">鵞黄嫩一首夢覺銀臺畫燭殘一首曉燈垂熖落</span>  
<span style="margin-left: 2em">銀釭一首尋常宫怨之詞殆居五分之一非惟語</span>  
<span style="margin-left: 2em">意重複且厯代可以通用不必定屬於元頗爲冗</span>  
<span style="margin-left: 2em">泛其他切元事者皆無註釋後人亦不盡解不及</span>  
<!-- 册4 葉2585a　Page:文淵閣四庫全書_0004冊.djvu/651 -->
<span style="margin-left: 2em">楊允孚灤京雜詠多矣</span>  
楓林集十卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">明朱升撰升有周易旁註巳著錄是編前八卷皆</span>  
<span style="margin-left: 2em">詩文而以官誥及太祖手勅編入第一卷首與升</span>  
<span style="margin-left: 2em">文相連殊爲非體第九卷載徽州府志本傳一首</span>  
<span style="margin-left: 2em">廖道南所撰詩贊一首並翼運節畧十餘則第十</span>  
<span style="margin-left: 2em">卷爲附錄皆當時投贈詩文也升於明興之初叅</span>  
<span style="margin-left: 2em">贊帷幄兼知制誥一切典制多出其手與陶安宋</span>  
<span style="margin-left: 2em">濓等名望相埓陳敬則明廷雜記嘗稱其李善長</span>  
<!-- 册4 葉2585b　Page:文淵閣四庫全書_0004冊.djvu/651 -->
<span style="margin-left: 2em">徐逹常遇春劉基四誥惜明文衡未及收入明史</span>  
<span style="margin-left: 2em">本傳載太祖大封功臣制詞多升撰時稱典核葢</span>  
<span style="margin-left: 2em">據是文然統觀全集文章乃非所長詩學擊壤集</span>  
<span style="margin-left: 2em">而不成頗近鄙俚故朱<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">尊明詩綜絶不登其一</span>  
<span style="margin-left: 2em">字況升身本元臣曾膺爵祿而賀平浙東賦序肆</span>  
<span style="margin-left: 2em">言醜詆毫無故君舊國之思是尤不可爲訓也</span>  
槎翁集八卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">明劉崧撰崧有槎翁詩集巳著錄是編乃其文集</span>  
<span style="margin-left: 2em">羅允升所校正而吉安知府徐士元爲之刋板其</span>  
<!-- 册4 葉2588a　Page:文淵閣四庫全書_0004冊.djvu/652 -->
<span style="margin-left: 2em">文頗傷流易殊不及其詩</span>  
野莊集六卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">明王鈍撰鈍字士魯太康人元至正丙午進士洪</span>  
<span style="margin-left: 2em">武初徵授禮部主事厯官浙江布政使建文中召</span>  
<span style="margin-left: 2em">爲戸部尙書燕王簒位仍故官後以布政使勒致</span>  
<span style="margin-left: 2em">仕事迹具明史本傳是集凡詩二卷文四卷皆未</span>  
<span style="margin-left: 2em">能入格前有王崇慶序謂嘉靖中其後裔曰朝獻</span>  
<span style="margin-left: 2em">者始謀梓之葢集中多稱建文爲今上皇帝故靖</span>  
<span style="margin-left: 2em">難後懼觸語禁久而不敢出也</span>  
<!-- 册4 葉2588b　Page:文淵閣四庫全書_0004冊.djvu/652 -->
滄浪櫂歌一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明陶宗儀撰宗儀有國風尊經巳著錄是編詩詞</span>  
<span style="margin-left: 2em">合爲一卷前有正德丁丑松江唐錦序稱其集不</span>  
<span style="margin-left: 2em">傳惟得此一卷爲宗儀所自編今考其中詩詞皆</span>  
<span style="margin-left: 2em">巳載南村集中惟題卞莊子刺虎圖七言古詩一</span>  
<span style="margin-left: 2em">首題岳王廟七言長律十四韻一首爲南村集所</span>  
<span style="margin-left: 2em">未載耳又對月七言律詩甘㫖未能娛綵侍句南</span>  
<span style="margin-left: 2em">村集作娛綵服疑此本爲悞南浦詞序中一水並</span>  
<span style="margin-left: 2em">九山南過村外以入於海句南村集作一水兼九</span>  
<!-- 册4 葉2589a　Page:文淵閣四庫全書_0004冊.djvu/652 -->
<span style="margin-left: 2em">山則南村集誤也</span>  
危學士全集十四卷<sub class="note-yuan">江西廵撫採進本</sub>  
<span style="margin-left: 2em">明危素撰素有草廬年譜巳著錄其原集本五十</span>  
<span style="margin-left: 2em">卷世久無傳明歸有光得其手藁因編爲說學齋</span>  
<span style="margin-left: 2em">藁凡一百三十餘篇又所作詩名雲林集乃納新</span>  
<span style="margin-left: 2em">所編此本文十三卷詩一卷乃其鄕人取二集彚</span>  
<span style="margin-left: 2em">輯而成雖名全集實非原本故今仍錄說學齋稿</span>  
<span style="margin-left: 2em">雲林集以存其舊此本則附存目焉</span>  
元釋集一卷<sub class="note-yuan">編修汪如藻家藏本</sub>  
<!-- 册4 葉2589b　Page:文淵閣四庫全書_0004冊.djvu/652 -->
<span style="margin-left: 2em">明釋克新撰克新姓余氏字仲銘自號江左外史</span>  
<span style="margin-left: 2em">又稱爲雪廬和尙鄱陽人元末住嘉興水西寺洪</span>  
<span style="margin-left: 2em">武初召至南京嘗奉詔徃西域招諭吐番所著有</span>  
<span style="margin-left: 2em">雪廬南詢藁此本别題元釋集僅古今體詩六十</span>  
<span style="margin-left: 2em">餘首考賴良大雅集載有克新詩四首而此本皆</span>  
<span style="margin-left: 2em">無之葢後人於雪廬集中摘錄抄存非其全稿也</span>  
愛禮集十卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">明劉駟撰駟字宗道龍谿人洪武初徴秀才入試</span>  
<span style="margin-left: 2em">者八千人駟爲第一授都御史尋坐事徙滇卒門</span>  
<!-- 册4 葉2592a　Page:文淵閣四庫全書_0004冊.djvu/653 -->
<span style="margin-left: 2em">人私諡愛禮先生故以名集凡文三卷詩二卷中</span>  
<span style="margin-left: 2em">庸說一卷書啟三卷附錄一卷駟宗陳淳之學詩</span>  
<span style="margin-left: 2em">文多渉性理畧似語錄之體中庸說乃講授口義</span>  
<span style="margin-left: 2em">亦無所發明集爲宏治六年浙江叅政林進<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">所</span>  
<span style="margin-left: 2em">刋附錄愼獨翁行狀紀駟父寳與駟平生行實頗</span>  
<span style="margin-left: 2em">具乃其門人漳州陳拯所述又附趙先生書一首</span>  
<span style="margin-left: 2em">則駟之師趙彦進也</span>  
坦齋文集二卷<sub class="note-yuan">江蘇廵撫採進本</sub>  
<span style="margin-left: 2em">明劉三吾撰三吾字如孫自號坦坦翁茶陵人洪</span>  
<!-- 册4 葉2592b　Page:文淵閣四庫全書_0004冊.djvu/653 -->
<span style="margin-left: 2em">武中官翰林學士事迹具明史本傳案鄭曉雷禮</span>  
<span style="margin-left: 2em">王世貞並謂三吾於洪武三十年以罪誅死蔣一</span>  
<span style="margin-left: 2em">葵又謂三吾以作大誥漏言賜死明史則稱以考</span>  
<span style="margin-left: 2em">試不實戍邊建文初召還今集中有<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2706.svg?width=24" alt="四庫全書僻字第2706號（勅）" title="四庫全書僻字第2706號（勅）">下御製大</span>  
<span style="margin-left: 2em">明一統賦實建文時所撰與史相合是曉等所載</span>  
<span style="margin-left: 2em">皆不確知其集在明代不甚傳故以曉等熟於掌</span>  
<span style="margin-left: 2em">故者亦未之見矣此本乃成化中桐江俞藎官茶</span>  
<span style="margin-left: 2em">陵時所刋萬厯戊寅茶陵知州韓城賈緣又重刋</span>  
<span style="margin-left: 2em">之三吾於洪武中典司文章頗被恩遇然其文鈎</span>

<span style="margin-left: 2em">𣗥而淺近未能凌轢一時也</span>  
一齋集十六卷<sub class="note-yuan">福建廵撫採進本</sub>  
<span style="margin-left: 2em">明朱善撰善有詩解頤巳著錄是集首載聶<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）">所</span>  
<span style="margin-left: 2em">作墓誌稱名善繼然集中自稱曰朱善而詩經解</span>  
<span style="margin-left: 2em">頤亦題曰朱善則繼字殆刋本誤也是編前集十</span>  
<span style="margin-left: 2em">卷後集五卷又廣遊集一卷附刊於後善以文章</span>  
<span style="margin-left: 2em">爲明太祖所知然核其品第究不能與宋濓諸人</span>  
<span style="margin-left: 2em">雁行</span>  
甘白集六卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<!-- 册4 葉2593b　Page:文淵閣四庫全書_0004冊.djvu/653 -->
<span style="margin-left: 2em">明張適撰適字子宣蘇州人明初以儒士徵授水</span>  
<span style="margin-left: 2em">部郞中旋放歸見集中所作其妻沈氏壙志而其</span>  
<span style="margin-left: 2em">祭西平侯文則自署雲南滇池漁課司大使是洪</span>  
<span style="margin-left: 2em">武末又嘗官雲南故集中毎自稱滇池老漁也集</span>  
<span style="margin-left: 2em">爲正統丁卯其子收所編文體修潔而未造深厚</span>  
<span style="margin-left: 2em">如在嘉隆以後則爲雅音在元明之間則未能與</span>  
<span style="margin-left: 2em">諸家壁壘相當也</span>  
秫坡詩稿七卷附錄一卷<sub class="note-yuan">浙江孫仰曾家藏本</sub>  
<span style="margin-left: 2em">明黎貞撰貞字彦晦秫坡其自號也新會人洪武</span>
