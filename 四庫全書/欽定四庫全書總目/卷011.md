## 欽定四庫全書總目 卷十一　經部十一　書類一

<!-- 册1 葉1012a　Page:文淵閣四庫全書_0001冊.djvu/303 -->
欽定四庫全書總目卷十一  
<span style="margin-left: 1em">經部十一</span>  
<span style="margin-left: 2em">書類一</span>  
<span style="margin-left: 3em">書以道政事儒者不能異說也小序之依託五</span>  
<span style="margin-left: 3em">行傳之附會久論定矣然諸家聚訟猶有四端</span>  
<span style="margin-left: 3em">曰今文古文曰錯簡曰禹貢山水曰洪範疇數</span>  
<span style="margin-left: 3em">夫古文之辨至閻若璩始明朱彜尊謂是書久</span>  
<span style="margin-left: 3em">頒於學官其言多綴輯逸經成文無悖於理汾</span>  
<span style="margin-left: 3em">陰漢鼎良亦善喻吳澄舉而刪之非可行之道</span>  
<!-- 册1 葉1012b　Page:文淵閣四庫全書_0001冊.djvu/303 -->
<span style="margin-left: 3em">也禹迹大抵在中原而論者多當南渡昔疎今</span>  
<span style="margin-left: 3em">密其𫝑則然然尺短寸長互相補苴固宜兼收</span>  
<span style="margin-left: 3em">並蓄以證同異若夫劉向記酒誥召誥脫簡僅</span>  
<span style="margin-left: 3em">三而諸儒動稱數十班固索洪範於洛書諸儒</span>  
<span style="margin-left: 3em">併及河圖支離轇轕淆經義矣故王柏書疑蔡</span>  
<span style="margin-left: 3em">沈皇極數之類非解經之正軌者咸無取焉</span>  
尚書正義二十卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">舊本題漢孔安國傳其書至晉豫章内史梅賾始</span>  
<span style="margin-left: 2em">奏於朝唐貞觀十六年孔頴達等爲之疏永徽四</span>  
<!-- 册1 葉1013a　Page:文淵閣四庫全書_0001冊.djvu/303 -->
<span style="margin-left: 2em">年長孫無忌等又加刋定孔傳之依託自朱子以</span>  
<span style="margin-left: 2em">來遞有論辨至</span>  
<span style="margin-left: 1em">國朝閻若璩作尚書古文疏證其事愈明其灼然可</span>  
<span style="margin-left: 2em">據者梅鷟尚書考異攻其註禹貢𤄊水出河南北</span>  
<span style="margin-left: 2em">山一條積石山在金城西南羌中一條地名皆在</span>  
<span style="margin-left: 2em">安國後朱彜尊經義考攻其註書序東海駒驪扶</span>  
<span style="margin-left: 2em">餘馯貊之屬一條謂駒驪王朱𫎇至漢元帝建昭</span>  
<span style="margin-left: 2em">二年始建國安國武帝時人亦不及見若璩則攻</span>  
<span style="margin-left: 2em">其註泰誓雖有周親不如仁人與所註論語相反</span>  
<!-- 册1 葉1013b　Page:文淵閣四庫全書_0001冊.djvu/303 -->
<span style="margin-left: 2em">又安國傳有湯誓而註論語予小子履一節乃以</span>  
<span style="margin-left: 2em">爲墨子所引湯誓之文<sub class="note-yuan">案安國論語注今佚此條乃何晏集解所引</sub>皆</span>  
<span style="margin-left: 2em">證佐分明更無疑義至若璩謂定從孔傳以孔頴</span>  
<span style="margin-left: 2em">達之故則不盡然考漢書藝文志敘古文尚書但</span>  
<span style="margin-left: 2em">稱安國獻之遭巫蠱事未立於學官不云作傳而</span>  
<span style="margin-left: 2em">經典釋文敘錄乃稱藝文志云安國獻尚書傳遭</span>  
<span style="margin-left: 2em">巫蠱事未立於學官始增入一傳字以證實其事</span>  
<span style="margin-left: 2em">又稱今以孔氏爲正則定從孔傳者乃陸德明非</span>  
<span style="margin-left: 2em">自頴達惟德明於舜典下註云孔氏傳亡舜典一</span>  
<!-- 册1 葉1016a　Page:文淵閣四庫全書_0001冊.djvu/304 -->
<span style="margin-left: 2em">篇時以王肅注頗類孔氏故取王注從愼徽五典</span>  
<span style="margin-left: 2em">以下爲舜典以續孔傳又云曰若稽古帝舜曰重</span>  
<span style="margin-left: 2em">華協于帝十二字是姚方興所上孔氏傳本無阮</span>  
<span style="margin-left: 2em">孝緒七錄亦云方興本或此下更有濬哲文明温</span>  
<span style="margin-left: 2em">恭允塞元德升聞乃命以位凡二十八字異聊出</span>  
<span style="margin-left: 2em">之於王注無施也則開皇中雖增入此文尚未增</span>  
<span style="margin-left: 2em">入孔傳中故德明云爾今本二十八字當爲頴達</span>  
<span style="margin-left: 2em">增入耳梅賾之時去古未遠其傳實據王肅之注</span>  
<span style="margin-left: 2em">而附益以舊訓故釋文稱王肅亦注今文所解大</span>  
<!-- 册1 葉1016b　Page:文淵閣四庫全書_0001冊.djvu/304 -->
<span style="margin-left: 2em">與古文相類或肅私見孔傳而秘之乎此雖以末</span>  
<span style="margin-left: 2em">爲本未免倒置亦足見其根據古義非盡無稽矣</span>  
<span style="margin-left: 2em">頴達之疏晁公武讀書志謂因梁費甝疏廣之然</span>  
<span style="margin-left: 2em">頴達原序稱爲正義者蔡大寶巢猗費甝顧彪劉</span>  
<span style="margin-left: 2em">焯劉<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3271.svg?width=24" alt="四庫全書僻字第3271號（炫）" title="四庫全書僻字第3271號（炫）">六家而以劉焯劉<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3271.svg?width=24" alt="四庫全書僻字第3271號（炫）" title="四庫全書僻字第3271號（炫）">最爲詳雅其書實因</span>  
<span style="margin-left: 2em">二劉非因費氏公武或以經典釋文所列義疏僅</span>  
<span style="margin-left: 2em">甝一家故云然與朱子語錄謂五經疏周禮最好</span>  
<span style="margin-left: 2em">詩禮記次之易書爲下其言良允然名物訓故究</span>  
<span style="margin-left: 2em">賴之以有考亦何可輕也</span>  
<!-- 册1 葉1017a　Page:文淵閣四庫全書_0001冊.djvu/304 -->
洪範口義二卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋胡瑗撰瑗有周易口義巳著錄是書文獻通考</span>  
<span style="margin-left: 2em">作洪範解朱彞尊經義考註云未見今其文散見</span>  
<span style="margin-left: 2em">永樂大典中尙可排纂成書周易口義出倪天隱</span>  
<span style="margin-left: 2em">之手舊有明文晁公武讀書志謂此書亦瑗門人</span>  
<span style="margin-left: 2em">編錄故無詮次首尾蓋二書同名口義故以例推</span>  
<span style="margin-left: 2em">其爲瑗所自著與否固無顯證至其說之存於經</span>  
<span style="margin-left: 2em">文各句下者皆先後貫徹條理整齊非雜記語錄</span>  
<span style="margin-left: 2em">之比與公武所說不符豈原書本無次第修永樂</span>  
<!-- 册1 葉1017b　Page:文淵閣四庫全書_0001冊.djvu/304 -->
<span style="margin-left: 2em">大典者爲散附經文之下轉排比順序歟抑或公</span>  
<span style="margin-left: 2em">武所見又別一本也洪範以五事配庶徵本經文</span>  
<span style="margin-left: 2em">所有伏生大傳以下逮京房劉向諸人遽以陰陽</span>  
<span style="margin-left: 2em">災異附合其文劉知幾排之詳矣宋儒又流爲象</span>  
<span style="margin-left: 2em">數之學惟圖書同異之是辨經義愈不能明瑗生</span>  
<span style="margin-left: 2em">於北宋盛時學問最爲篤實故其說惟發明天人</span>  
<span style="margin-left: 2em">合一之旨不務新奇如謂天錫洪範爲錫自帝堯</span>  
<span style="margin-left: 2em">不取神龜負文之瑞謂五行次第爲箕子所陳不</span>  
<span style="margin-left: 2em">辨洛書本文之多寡謂五福六極之應通於四海</span>  
<!-- 册1 葉1020a　Page:文淵閣四庫全書_0001冊.djvu/305 -->
<span style="margin-left: 2em">不當指一身而言俱駁正註疏自抒心得又詳引</span>  
<span style="margin-left: 2em">周官之法推演八政以經註經特爲精<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">其要皆</span>  
<span style="margin-left: 2em">歸於建中出治定皇極爲九疇之本辭雖平近而</span>  
<span style="margin-left: 2em">深得聖人立訓之要非䜟緯術數者流所可同日</span>  
<span style="margin-left: 2em">語也宋史本作一卷今校定字句析爲二卷</span>  
<span style="margin-left: 4em">案朱彞尊經義考凡訓釋一篇者悉彚載各</span>  
<span style="margin-left: 4em">經之末不與訓釋全經者敘時代先後然隋</span>  
<span style="margin-left: 4em">志載繫詞註洪範五行傳月令章句中庸講</span>  
<span style="margin-left: 4em">疏固雜置各經中也今從古例不復別編後</span>  
<!-- 册1 葉1020b　Page:文淵閣四庫全書_0001冊.djvu/305 -->
<span style="margin-left: 4em">均倣此</span>  
東坡書傳十三卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋蘇軾撰軾有東坡易傳巳著錄是書宋志作十</span>  
<span style="margin-left: 2em">三卷與今本同萬卷堂書目作二十卷疑其傳寫</span>  
<span style="margin-left: 2em">誤也晁公武讀書志稱熙寧以後專用王氏之說</span>  
<span style="margin-left: 2em">進退多士此書駁異其說爲多今新經尙書義不</span>  
<span style="margin-left: 2em">傳不能盡考其同異但就其書而論則軾究心經</span>  
<span style="margin-left: 2em">世之學明於事勢又長於議論於治亂興亡披抉</span>  
<span style="margin-left: 2em">明暢較他經獨爲擅長其釋禹貢三江定爲南江</span>  
<!-- 册1 葉1021a　Page:文淵閣四庫全書_0001冊.djvu/305 -->
<span style="margin-left: 2em">中江北江本諸鄭康成遠有端緒惟未嘗詳審經</span>  
<span style="margin-left: 2em">文考覈水道而附益以味别之說遂以啟後人之</span>  
<span style="margin-left: 2em">議至於以羲和曠職爲貳於羿而忠於夏則林之</span>  
<span style="margin-left: 2em">奇宗之以康王之誥服冕爲非禮引左傳叔向之</span>  
<span style="margin-left: 2em">言爲證則蔡沈取之朱子語錄亦稱其解吕刑篇</span>  
<span style="margin-left: 2em">以王享國百年耄作一句荒度作刑作一句甚合</span>  
<span style="margin-left: 2em">於理後與蔡沈帖雖有蘇氏失之簡之語然語錄</span>  
<span style="margin-left: 2em">又稱或問諸家書解誰最好莫是東坡曰然又問</span>  
<span style="margin-left: 2em">但若失之太簡曰亦有只須如此解者則又未嘗</span>  
<!-- 册1 葉1021b　Page:文淵閣四庫全書_0001冊.djvu/305 -->
<span style="margin-left: 2em">以簡爲病洛閩諸儒以程子之故與蘇氏如水火</span>  
<span style="margin-left: 2em">惟於此書有取焉則其書可知矣</span>  
尚書全解四十卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋林之奇撰之奇字少頴號拙齋侯官人官至宗</span>  
<span style="margin-left: 2em">正丞事蹟具宋史儒林傳之奇辭祿家居博考諸</span>  
<span style="margin-left: 2em">儒之說以成是書宋志作五十八卷此本僅標題</span>  
<span style="margin-left: 2em">四十卷考其孫畊後序稱脫稿之初爲門人吕祖</span>  
<span style="margin-left: 2em">謙持去諸生傳錄僅十得二三書肆急於鋟梓遂</span>  
<span style="margin-left: 2em">訛以傳訛至淳祐辛丑畊從陳元鳳得宇文氏所</span>  
<!-- 册1 葉1024a　Page:文淵閣四庫全書_0001冊.djvu/306 -->
<span style="margin-left: 2em">傳書說拾遺手稿一册乃康誥至君陳之文乙巳</span>  
<span style="margin-left: 2em">得建安余氏所刻完本始知麻沙所刻自洛誥以</span>  
<span style="margin-left: 2em">下皆僞續又得葉眞所藏林李二先生書解叅校</span>  
<span style="margin-left: 2em">證騐釐爲四十卷然則宋志所載乃麻沙僞本之</span>  
<span style="margin-left: 2em">卷數朱子所謂洛誥以後非林氏解者此本則畊</span>  
<span style="margin-left: 2em">所重編朱子未見夏僎作尚書解時亦未見故所</span>  
<span style="margin-left: 2em">引之奇之說亦至洛誥止也然畊旣稱之奇初稿</span>  
<span style="margin-left: 2em">爲吕祖謙持去則祖謙必見完書何以東萊書說</span>  
<span style="margin-left: 2em">始於洛誥以下云續之奇之書毋乃畊又有所增</span>  
<!-- 册1 葉1024b　Page:文淵閣四庫全書_0001冊.djvu/306 -->
<span style="margin-left: 2em">修託之乃祖歟自宋迨明流傳旣久又佚其三十</span>  
<span style="margin-left: 2em">四卷多方一篇通志堂刋九經解竭力購之弗能</span>  
<span style="margin-left: 2em">補也惟永樂大典修自明初其時猶見舊刻故所</span>  
<span style="margin-left: 2em">載之奇書解此篇獨存今錄而補之乃得復還舊</span>  
<span style="margin-left: 2em">觀之奇是書頗多異說如以陽鳥爲地名三俊爲</span>  
<span style="margin-left: 2em">常伯常任準人皆未嘗依傍前人至其辨析異同</span>  
<span style="margin-left: 2em">貫串史事覃思積悟實卓然成一家言雖眞贗錯</span>  
<span style="margin-left: 2em">雜不可廢也屢經散佚而卒能完善亦其精神刻</span>  
<span style="margin-left: 2em">摯有足以自傳者矣前有自序一篇述尚書始末</span>  
<!-- 册1 葉1025a　Page:文淵閣四庫全書_0001冊.djvu/306 -->
<span style="margin-left: 2em">甚詳然舛誤特甚漢書藝文志明云古文尚書孔</span>  
<span style="margin-left: 2em">安國獻之遭巫蠱不列於學官而用僞孔傳序藏</span>  
<span style="margin-left: 2em">於家之說併謂劉歆未見儒林傳明言伏生壁藏</span>  
<span style="margin-left: 2em">其書漢興亡數十篇獨得二十九篇而用衛宏古</span>  
<span style="margin-left: 2em">文尚書序使女傳言之說併謂齊語難曉尤其致</span>  
<span style="margin-left: 2em">謬之大綱閻若璩諸人巳有明辨兹不具論焉</span>  
禹貢指南四卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋毛晃撰晃宋史無傳其始末未詳世傳其增註</span>  
<span style="margin-left: 2em">禮部韻畧於紹興三十二年表進自署曰衢州免</span>
