## 欽定四庫全書總目 卷四十二　經部四十二　小學類三

<!-- 册1 葉3452：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷四十二  
<span style="margin-left: 1em">經部四十二</span>  
<span style="margin-left: 2em">小學類三</span>  
廣韻五卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">不著撰人名氏考世行廣韻凡二本一爲宋陳彭</span>  
<span style="margin-left: 2em">年邱雍等所重修一爲此本前有孫愐唐韻序注</span>  
<span style="margin-left: 2em">文比重修本頗簡朱彛尊作重修本序謂明代内</span>  
<span style="margin-left: 2em">府刊板中涓欲均其字數取而刪之然永樂大典</span>  
<span style="margin-left: 2em">引此本皆曰陸法言廣韻引重修本皆曰宋重修</span>  
<!-- 册1 葉3453b　Page:文淵閣四庫全書_0001冊.djvu/913 -->
<span style="margin-left: 2em">廣韻世尚有麻沙小字一本舆明内府板同題曰</span>  
<span style="margin-left: 2em">乙未歲明德堂刊内匡字紐下十二字皆闕一筆</span>  
<span style="margin-left: 2em">避太祖諱其他宋諱則不避邵長衡古今韻畧指</span>  
<span style="margin-left: 2em">爲宋槧雖未必然而平聲東字注中引東不訾事</span>  
<span style="margin-left: 2em">重修本作舜七友此本訛作舜之後熊忠韻會舉</span>  
<span style="margin-left: 2em">要已引此本則當爲元刻矣非明中涓所刪也又</span>  
<span style="margin-left: 2em">宋人諱殷故重修本改二十一殷爲欣此尚作殷</span>  
<span style="margin-left: 2em">知非作於宋代且唐人諸集以殷韻字少難於成</span>  
<span style="margin-left: 2em">詩間或附入眞諄臻韻如杜甫東山草堂詩李商</span>  
<!-- 册1 葉3456a　Page:文淵閣四庫全書_0001冊.djvu/914 -->
<span style="margin-left: 2em">隱五松驛詩不一而足說文所載唐韻翻切殷字</span>  
<span style="margin-left: 2em">作於身切欣字作許巾切亦借眞韻中字取音並</span>  
<span style="margin-left: 2em">無一字通文此本注殷獨用重修本始註欣與文</span>  
<span style="margin-left: 2em">通尤<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">非宋韻之一徵考唐志宋志皆載陸法言</span>  
<span style="margin-left: 2em">廣韻五卷則法言切韻亦兼廣韻之名又孫愐以</span>  
<span style="margin-left: 2em">後陳彭年等以前修廣韻者尚有嚴寶文裴務齊</span>  
<span style="margin-left: 2em">陳道固三家重修本中皆列其名氏郭忠恕佩觿</span>  
<span style="margin-left: 2em">上篇尚引裴務齊切韻序辨其老考二字左回右</span>  
<span style="margin-left: 2em">轉之訛知三家之書宋初尚存此本葢卽三家之</span>  
<!-- 册1 葉3456b　Page:文淵閣四庫全書_0001冊.djvu/914 -->
<span style="margin-left: 2em">一故彭年等所定之本不曰新修而曰重修明先</span>  
<span style="margin-left: 2em">有此廣韻又景德四年勅牒稱舊本注解未備明</span>  
<span style="margin-left: 2em">先有此注文簡約之廣韻也彛尊精於考証乃以</span>  
<span style="margin-left: 2em">此本爲在後不免千慮之一失矣惟新舊廣韻皆</span>  
<span style="margin-left: 2em">在集韻之前而上去二聲乃皆用集韻移併之部</span>  
<span style="margin-left: 2em">分不人二聲又不從集韻移併疑賈昌朝奏併十</span>  
<span style="margin-left: 2em">三部以後校刻廣韻者以儼豏檻釅陷鑑六部字</span>  
<span style="margin-left: 2em">數太窄改從集韻以便用咸銜嚴業洽狎六部字</span>  
<span style="margin-left: 2em">數稍寛則仍其舊而未改觀徐鍇說文韻譜上聲</span>  
<!-- 册1 葉3457a　Page:文淵閣四庫全書_0001冊.djvu/914 -->
<span style="margin-left: 2em">以湛檻儼相次去聲以陷鑑醶相次則唐人舊第</span>  
<span style="margin-left: 2em">可知也此於四聲次序前後乖違殊非體例以宋</span>  
<span style="margin-left: 2em">槧如是今姑仍舊本錄之而附訂其誤如右</span>  
重修廣韻五卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">宋陳彭年邱雍等奉勅撰初隋陸法言以吕靜等</span>  
<span style="margin-left: 2em">六家韻書各有乖互因與劉臻顔之推魏淵盧思</span>  
<span style="margin-left: 2em">道李若蕭該辛德源薛道衡八人撰爲切韻五卷</span>  
<span style="margin-left: 2em">書成於仁壽元年唐儀鳯二年長孫訥言爲之註</span>  
<span style="margin-left: 2em">後郭知元關亮薛峋王仁煦祝尚邱遞有增加天</span>  
<!-- 册1 葉3457b　Page:文淵閣四庫全書_0001冊.djvu/914 -->
<span style="margin-left: 2em">寶十載陳州司法孫愐重爲刊定改名唐韻後嚴</span>  
<span style="margin-left: 2em">寶文裴務齊陳道固又各有添字宋景德四年以</span>  
<span style="margin-left: 2em">舊本偏旁差訛傳寫漏落又注解未備乃命重修</span>  
<span style="margin-left: 2em">大中祥符四年書成賜名大宋重修廣韻卽是書</span>  
<span style="margin-left: 2em">也舊本不題撰人以丁度集韻考之知爲彭年雍</span>  
<span style="margin-left: 2em">等爾其書二百六韻仍陸氏之舊所收凡二萬六</span>  
<span style="margin-left: 2em">千一百九十四字考唐封演聞見記載陸法言韻</span>  
<span style="margin-left: 2em">凡一萬二千一百五十八字則所增凡一萬四千</span>  
<span style="margin-left: 2em">三十六字矣此本爲蘇州張士俊從宋槧翻雕中</span>  
<!-- 册1 葉3460a　Page:文淵閣四庫全書_0001冊.djvu/915 -->
<span style="margin-left: 2em">間巳缺欽宗諱葢建炎以後重刊朱彞尊序之力</span>  
<span style="margin-left: 2em">斥劉淵韻合殷於文合隱於吻合焮於問之非然</span>  
<span style="margin-left: 2em">此本實合殷隱焮於文吻問彞尊未及檢也註文</span>  
<span style="margin-left: 2em">凡一十九萬一千六百九十二字較舊本爲詳而</span>  
<span style="margin-left: 2em">冗漫頗甚如公字之下載姓氏至千餘言殊乏翦</span>  
<span style="margin-left: 2em">裁東字之下稱東宫得臣爲齊大夫亦多紕繆考</span>  
<span style="margin-left: 2em">孫愐唐韻序稱異聞奇怪傳說姓氏原田土地物</span>  
<span style="margin-left: 2em">産山河草木禽獸蟲魚備載其間巳極蔓引彭年</span>  
<span style="margin-left: 2em">等又從而益之宜爲丁度之所譏潘耒序乃以註</span>  
<!-- 册1 葉3460b　Page:文淵閣四庫全書_0001冊.djvu/915 -->
<span style="margin-left: 2em">文繁複爲可貴是將以韻書爲類書也著書各有</span>  
<span style="margin-left: 2em">體例豈可以便於剽剟遂推爲善本哉流傳旣久</span>  
<span style="margin-left: 2em">存以備韻書之源流可矣</span>  
集韻十卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">舊本題宋丁度等奉勅撰前有韻例稱景祐四年</span>  
<span style="margin-left: 2em">太常博士直史館宋祁太常丞直史館鄭戬等建</span>  
<span style="margin-left: 2em">言陳彭年邱雍等所定廣韻多用舊文繁畧失當</span>  
<span style="margin-left: 2em">因詔祁戩與國子監直講賈昌朝王洙同加修定</span>  
<span style="margin-left: 2em">刑部郎中知制誥丁度禮部員外郎知制誥李淑</span>  
<!-- 册1 葉3461a　Page:文淵閣四庫全書_0001冊.djvu/915 -->
<span style="margin-left: 2em">爲之典領晁公武讀書志亦同然考司馬光切韻</span>  
<span style="margin-left: 2em">指掌圖序稱仁宗皇帝詔翰林學士丁公度李公</span>  
<span style="margin-left: 2em">淑增崇韻學自許叔重而降凡數十家總爲集韻</span>  
<span style="margin-left: 2em">而以賈公昌朝王公洙爲之屬治平四年余得㫖</span>  
<span style="margin-left: 2em">繼纂其職書成上之有詔頒焉嘗因討宪之暇科</span>  
<span style="margin-left: 2em">别淸濁爲二十圖云云則此書奏於英宗時非仁</span>  
<span style="margin-left: 2em">宗時成於司馬光之手非盡出丁度等也其書凡</span>  
<span style="margin-left: 2em">平聲四卷上聲去聲入聲各二卷共五萬三千五</span>  
<span style="margin-left: 2em">百二十五字視廣韻增二萬七千三百三十二字</span>  
<!-- 册1 葉3461b　Page:文淵閣四庫全書_0001冊.djvu/915 -->
<span style="margin-left: 2em"><sub class="note-yuan">案廣韻凡二萬六千一百九十四字應增二萬七千三百三十一字於數乃合原本悞以二萬爲一</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">萬今改正</sub>熊忠韻會舉要稱舊韻但作平聲一二三四</span>  
<span style="margin-left: 2em">集韻乃改爲上下平今檢其篇目乃舊韻作上下</span>  
<span style="margin-left: 2em">平此書改爲平聲一二三四忠之所言殊爲倒置</span>  
<span style="margin-left: 2em">惟廣韻所注通用獨用封演見聞記稱爲唐許敬</span>  
<span style="margin-left: 2em">宗定者改併移易其舊部則實自此書始東齋紀</span>  
<span style="margin-left: 2em">事稱景祐初以崇政殿說書賈昌朝言詔度等改</span>  
<span style="margin-left: 2em">定韻窄者十三處許令附近通用是其事也今以</span>  
<span style="margin-left: 2em">廣韻互校平聲併殷於文併嚴於鹽添併凡於咸</span>  
<!-- 册1 葉3464a　Page:文淵閣四庫全書_0001冊.djvu/916 -->
<span style="margin-left: 2em">銜上聲併隱於吻去聲併廢於墜代併焮於問入</span>  
<span style="margin-left: 2em">聲併迄於物併業於葉帖凡得九韻不足十三然</span>  
<span style="margin-left: 2em">廣韻平聲鹽添咸銜嚴凡與入聲葉帖洽狎業乏</span>  
<span style="margin-left: 2em">皆與本書部分相應而與集韻互異惟上聲併儼</span>  
<span style="margin-left: 2em">於琰忝併范於豏檻去聲併釅於豔㮇併梵於陷</span>  
<span style="margin-left: 2em">鑑皆與本書部分不應而乃與集韻相同知此四</span>  
<span style="margin-left: 2em">韻亦集韻所併而重刊廣韻者誤據集韻以校之</span>  
<span style="margin-left: 2em">遂移其舊第耳其駁廣韻注凡姓望之出廣陳名</span>  
<span style="margin-left: 2em">系旣乖字訓復類譜牒誠爲允協至謂兼載他切</span>  
<!-- 册1 葉3464b　Page:文淵閣四庫全書_0001冊.djvu/916 -->
<span style="margin-left: 2em">徒釀細文因併刪其字下之互注則音義俱别與</span>  
<span style="margin-left: 2em">義同音異之字難以遽明殊爲省所不當省又韻</span>  
<span style="margin-left: 2em">主審音不主辨體乃篆籀兼登雅俗並列重文複</span>  
<span style="margin-left: 2em">見有類字書亦爲繁所不當繁其於廣韻葢亦互</span>  
<span style="margin-left: 2em">有得失故至今二書並行莫能偏廢焉</span>  
切韻指掌圖二卷附檢例一卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋司馬光撰其檢例一卷則邵光祖所補正光有</span>  
<span style="margin-left: 2em">温公易說巳著錄光祖字宏道自稱洛邑人其始</span>  
<span style="margin-left: 2em">末未詳考江南通志儒林傳載元邵光祖字宏道</span>  
<!-- 册1 葉3465a　Page:文淵閣四庫全書_0001冊.djvu/916 -->
<span style="margin-left: 2em">吳人研精經傳講習<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2618.svg?width=24" alt="四庫全書僻字第2618號（⿱乖一）" title="四庫全書僻字第2618號（⿱乖一）">三十年通三經所著有尚</span>  
<span style="margin-left: 2em">書集義當卽其人洛邑或其祖籍歟據王行後序</span>  
<span style="margin-left: 2em">作於洪武二十三年稱其殁巳數年則元之遺民</span>  
<span style="margin-left: 2em">入明尚在也光書以三十六字母科别清濁爲二</span>  
<span style="margin-left: 2em">十圖首獨韻次開合韻毎類之中又以四等字多</span>  
<span style="margin-left: 2em">寡爲次故高爲獨韻之首干官爲開合韻之首舊</span>  
<span style="margin-left: 2em">有檢例一卷光祖以爲全背圖㫖斷非光作因自</span>  
<span style="margin-left: 2em">撰爲檢圖之例附於其後考光自序實因集韻而</span>  
<span style="margin-left: 2em">成是圖光祖乃云廣韻凡二萬五千三百字其中</span>  
<!-- 册1 葉3465b　Page:文淵閣四庫全書_0001冊.djvu/916 -->
<span style="margin-left: 2em">有切韻者三千八百九十文正取其三千一百三</span>  
<span style="margin-left: 2em">十定爲二十圖餘七百六十字應檢而不在圖者</span>  
<span style="margin-left: 2em">則以在圖同母同音之字備用而求其音則是據</span>  
<span style="margin-left: 2em">廣韻也然光祖據光之圖以作例則其例仍與圖</span>  
<span style="margin-left: 2em">合所註七百六十字之代字及字母亦足補原圖</span>  
<span style="margin-left: 2em">所未備光例旣佚卽代以光祖之例亦無不可矣</span>  
<span style="margin-left: 2em">光書反切之法據嘉定癸亥董南一序云遞用則</span>  
<span style="margin-left: 2em">名音和傍求則名類隔同歸一母則爲雙聲同出</span>  
<span style="margin-left: 2em">一韻則爲叠韻同韻而分兩切者謂之憑切同音</span>  
<!-- 册1 葉3468a　Page:文淵閣四庫全書_0001冊.djvu/917 -->
<span style="margin-left: 2em">而分兩韻者謂之憑韻無字則<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）">窠以足之謂之</span>  
<span style="margin-left: 2em">寄聲韻闕則引鄰以寓之謂之寄韻所謂雙聲叠</span>  
<span style="margin-left: 2em">韻諸法與今世所傳劉鑑指南諸門法並同惟音</span>  
<span style="margin-left: 2em">和類隔二門則大相懸絶檢例云取同音同母同</span>  
<span style="margin-left: 2em">韻同等四者皆同謂之音和取唇重唇輕舌頭舌</span>  
<span style="margin-left: 2em">上齒頭正齒三音中淸濁同者謂之類隔是音和</span>
