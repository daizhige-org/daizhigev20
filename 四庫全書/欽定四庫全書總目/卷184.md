<span style="margin-left: 2em">別集類存目十一</span>  
湖海集十三卷<sub class="note-yuan">山東巡撫採進本</sub>  
<span style="margin-left: 1em">國朝孔尙任撰尙任有節序同風錄已著錄尙任官</span>  
<span style="margin-left: 2em">國子監博士時隨侍郞孫在豐在淮揚疏濬海口</span>  
<span style="margin-left: 2em">因輯其入淮以後詩文自編此集故以湖海爲名</span>  
幸ခ草三卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝黃百家撰百家有體獨私抄巴著錄是集凡雜</span>  
<!-- 册4 葉3656b　Page:文淵閣四庫全書_0004冊.djvu/919 -->
<span style="margin-left: 2em">文二十篇其序盧氏春秋三傳纂凡謂春秋之本</span>  
<span style="margin-left: 2em">㫖皆顯以示人無暗藏機括使人如猜謎射覆者</span>  
<span style="margin-left: 2em">深得聖人作春秋之意其王劉異同序亦深見兩</span>  
<span style="margin-left: 2em">家之閫奥大致頗肖其父但蒼老不及耳書首題</span>  
<span style="margin-left: 2em">曰學箕五稿則卷帙尙多此其稿中之一種耳</span>

<span style="margin-left: 1em">國朝高岑撰岑字峴亭商邱人官豐城縣知縣其詩</span>  
<span style="margin-left: 2em">每卷各爲集名終之以和月泉吟社田園雜興六</span>  
<span style="margin-left: 2em">十首岑爲吏部尙書宋犖外孫故其詩法亦本於</span>  
<!-- 册4 葉3657a　Page:文淵閣四庫全書_0004冊.djvu/919 -->
<span style="margin-left: 2em">犖與宋至緯蕭草堂集體格相近所謂酷似其舅</span>  
<span style="margin-left: 2em">者也</span>

<span style="margin-left: 1em">國朝孫元衡撰元衡字湘南桐城人康熙中官至東</span>  
<span style="margin-left: 2em">昌府知府是集皆其爲臺灣同知時所作以地有</span>  
<span style="margin-left: 2em">赤嵌城故以爲名多紀海外風土物產頗逞才氣</span>

四香樓集四卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<!-- 册4 葉3657b　Page:文淵閣四庫全書_0004冊.djvu/919 -->
<span style="margin-left: 1em">國朝范讚撰讚字武功婁縣人其詩源出晩唐而㕘</span>  
<span style="margin-left: 2em">以南宋如蜂憎綠蟻晴偷蜜燕覓靑蟲晝哺雛一</span>  
<span style="margin-left: 2em">潭水聚三更月四野山圍小閣燈三秋樹老蟬聲</span>  
<span style="margin-left: 2em">盡八月江寒雁影遲蟬聲送過秋多少鶴夢憑他</span>  
<span style="margin-left: 2em">夜短長之類皆綽有思致而格調未高前有海寧</span>  
<span style="margin-left: 2em">陳元龍序稱其長堪輿學蓋嘗館於元龍家相傳</span>  
<span style="margin-left: 2em">格致鏡原卽其所纂亦博洽之士也</span>  
釀川集十三卷<sub class="note-yuan">浙江巡撫採進本</sub>

<!-- 册4 葉3660a　Page:文淵閣四庫全書_0004冊.djvu/920 -->

<span style="margin-left: 2em">詩亦喜飮指邑中所謂沈釀川者自號因以名集</span>  
<span style="margin-left: 2em">其文頗有法律詞亦修整惟歌詩稍嫌故縱或不</span>  
<span style="margin-left: 2em">甚入律云</span>

<span style="margin-left: 1em">國朝陶季撰季原名澂字季深後以一字爲字又以</span>  
<span style="margin-left: 2em">字行寳應人王士禎漁洋詩話記其與萊陽董樵</span>  
<span style="margin-left: 2em">同以一字爲字因而賦詩定交者是也平生足跡</span>  
<span style="margin-left: 2em">半天下詩多於舟車得之因名舟車集其詩多才</span>  
<!-- 册4 葉3660b　Page:文淵閣四庫全書_0004冊.djvu/920 -->
<span style="margin-left: 2em">鋒踔厲風發泉湧不爲邊幅所窘然有警句亦有</span>  
<span style="margin-left: 2em">率句有健句亦有弱句蓋跌宕有餘而陶鍊未至</span>  
<span style="margin-left: 2em">者也</span>  
燕堂詩鈔八卷<sub class="note-yuan">戸部尙書王際華家藏本</sub>  
<span style="margin-left: 1em">國朝朱徑撰徑字恭亭寳應人喬萊之壻也是集爲</span>  
<span style="margin-left: 2em">徑所自編自康熙丙寅至己卯凡十四年之詩緣</span>  
<span style="margin-left: 2em">情綺靡頗有格韻特少作居多尙未能盡謝鉛華</span>  
<span style="margin-left: 2em">耳</span>  
鈍齋文鈔七卷<sub class="note-yuan">江西巡撫採進本</sub>  
<!-- 册4 葉3661a　Page:文淵閣四庫全書_0004冊.djvu/920 -->
<span style="margin-left: 1em">國朝楊兆嶦撰兆嶦字又平瑞金人是集前有自序</span>  
<span style="margin-left: 2em">謂著文三百餘首汰其三之二授諸梓則兆嶦所</span>  
<span style="margin-left: 2em">自定也張尙瑗序稱其文似歸有光使汰其冗句</span>  
<span style="margin-left: 2em">俗字固亦近之矣</span>  
集古梅花詩<sub class="note-yuan">無巻數　浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝張吳曼撰吳曼字也倩上海人居吳淞江上其</span>  
<span style="margin-left: 2em">地多梅因爲集句賦咏凡和中峰禪師韻者一百</span>  
<span style="margin-left: 2em">首和陳涉江韻者三十首自和者十首又一百首</span>  
<span style="margin-left: 2em">則吳曼以同里沈球本有是體爲繼作而合刻之</span>  
<!-- 册4 葉3661b　Page:文淵閣四庫全書_0004冊.djvu/920 -->
<span style="margin-left: 2em">者又一百首則吳曼六十生日其仲兄文<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">取十</span>  
<span style="margin-left: 2em">月先聞嶺上梅句集古爲壽吳曼因續爲之者末</span>  
<span style="margin-left: 2em">附集唐梅歌一首乃七十六歲所作殆終身詠此</span>  
<span style="margin-left: 2em">一花也</span>

<span style="margin-left: 2em">尙書元正子以父蔭官順天府通判是編凡趨庭</span>  
<span style="margin-left: 2em">集二卷壯圖集三卷小草集三卷棄擔集七卷起</span>

<span style="margin-left: 2em">集之正色講學者又殊</span>  
觀樹堂詩集十四卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝朱璋撰璋字鹿田錢塘人由舉人官至澤州府</span>  
<span style="margin-left: 2em">知府其詩爲叱馭集一卷入蜀時作也問絹集一</span>  
<!-- 册4 葉3664b　Page:文淵閣四庫全書_0004冊.djvu/921 -->
<span style="margin-left: 2em">卷白舫集二卷古㕔集四卷皆令江油時作也冬</span>  
<span style="margin-left: 2em">秀亭集四卷官澤州時作也剡曲集一卷則天台</span>  
<span style="margin-left: 2em">紀遊詩也一半勾留集一卷則憂歸居杭詩也</span>  
恕谷後集十卷續刻三卷<sub class="note-yuan"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">隸總督採進本</sub>  
<span style="margin-left: 1em">國朝李塨撰塨有周易傳注已著錄是集所作古文</span>

<span style="margin-left: 2em">集者自康熙癸未以前俱置之而惟存其後焉者</span>

<span style="margin-left: 2em">繩改本也恕谷初學八大家崑繩言當宗秦漢章</span>

<span style="margin-left: 2em">法訂此恕谷後謂唐宋不如秦漢秦漢不如六經</span>

<span style="margin-left: 2em">源字也嘗撰文章練要分六宗百家談古文之法</span>  
<span style="margin-left: 2em">後與塨同師顔元塨遂從學古文盡棄其少作後</span>  
<span style="margin-left: 2em">集之名蓋别其前之所棄也今觀其文根柢仍出</span>  
<span style="margin-left: 2em">八家但開合斷續不主故常異乎明以來學歐曾</span>  
<span style="margin-left: 2em">者惟以紆餘曼衍爲長耳遽曰秦漢曰六經溢其</span>

<span style="margin-left: 2em">主亦具有根柢然<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3688.svg?width=24" alt="四庫全書僻字第3688號（負）" title="四庫全書僻字第3688號（負）">氣求勝其文或失之麤豪少</span>

<span style="margin-left: 2em">古人淳穆之氣其持論又自命太高自信太果幾</span>

<span style="margin-left: 2em">結滌滯之功若專服久服則又生他疾耳</span>

<span style="margin-left: 2em">錄其文頗條暢詩則淺弱集後舊附陶詩箋註五</span>  
<span style="margin-left: 2em">卷邇言六卷又考定石經大學經傳解一卷今各</span>  
<span style="margin-left: 2em">分著於錄俾從其類</span>  
在陸草堂集六卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 1em">國朝儲欣撰欣有春秋指掌已著錄欣以制藝名於</span>  
<span style="margin-left: 2em">時而古文亦謹潔明暢有唐宋家法大致於蘇軾</span>  
<span style="margin-left: 2em">爲近所作蜀山東坡書院記宗㫖可槪見也其中</span>

<span style="margin-left: 2em">辨不取帝蜀之說亦不免失之好辨也</span>

<span style="margin-left: 2em">序稱其入巧極天工錯顔光敏序稱其七古似靑</span>  
<span style="margin-left: 2em">蓮長吉近體不專一家而各盡其妙今觀所作大</span>  
<span style="margin-left: 2em">抵以才思擅長品格故未能超詣雪美人七律二</span>  
<span style="margin-left: 2em">首世所艷稱實則小巧也</span>
