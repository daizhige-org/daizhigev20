## 欽定四庫全書總目 卷一百七十四　集部二十七　別集類存目一

欽定四庫全書總目卷一百七十四  
<span style="margin-left: 1em">集部二十七</span>  
<span style="margin-left: 2em">別集𩔖存目一</span>  
董子文集一卷<sub class="note-yuan">編修朱筠家藏本</sub>  
<span style="margin-left: 2em">漢董仲舒撰仲舒有春秋繁露巳著錄隋書經籍</span>  
<span style="margin-left: 2em">志載仲舒集一卷又註曰梁二卷亡舊唐書經籍</span>  
<span style="margin-left: 2em">志新唐書藝文誌俱仍載二卷宋史藝文志又作</span>  
<span style="margin-left: 2em">一卷後兩本並佚明正德己亥巡按御史盧雍行</span>  
<span style="margin-left: 2em">部至景州爲仲舒故里因修復廣川書院祀仲舒</span>  
<!-- 册4 葉2417b　Page:文淵閣四庫全書_0004冊.djvu/609 -->
<span style="margin-left: 2em">並裒其逸文以成是集然自採錄本傳外僅益以</span>  
<span style="margin-left: 2em">西京雜記古文苑所載數篇不及張溥百三家集</span>  
<span style="margin-left: 2em">之完備故僅存其目於此焉</span>  
諸葛丞相集四卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 1em">國朝朱璘編璘字靑巖常熟人官至南陽府知府是</span>  
<span style="margin-left: 2em">編首卷所錄諸葛亮遺文一卷陳壽所上目錄皆</span>  
<span style="margin-left: 2em">不載蓋摭拾三國志注及諸𩔖書而成其黃陵廟</span>  
<span style="margin-left: 2em">記明楊時偉作諸葛書嘗以摭用蘇軾大江東去</span>  
<span style="margin-left: 2em">詞語駁辨其僞今考陸游入蜀記作於乾道六年</span>  
<!-- 册4 葉2420a　Page:文淵閣四庫全書_0004冊.djvu/610 -->
<span style="margin-left: 2em">記黃牛廟事引古諺及李白歐陽修詩張詠贊甚</span>  
<span style="margin-left: 2em">詳獨一字不及亮記袁說友所刻成都文𩔖作於</span>  
<span style="margin-left: 2em">慶元五年亦無此文然則贋托之本出於南宋以</span>  
<span style="margin-left: 2em">後明甚璘乃仍然載入絶無考訂至心書五十條</span>  
<span style="margin-left: 2em">顯然僞托亦取以苟充卷帙且武侯十六䇿其僞</span>  
<span style="margin-left: 2em">與心書同晁氏讀書志著錄則猶出宋人之手旣</span>  
<span style="margin-left: 2em">取心書又不取是䇿何也二卷以下皆爲附錄所</span>  
<span style="margin-left: 2em">列八陣圖及分野諸條猥雜尤甚末一卷全爲璘</span>  
<span style="margin-left: 2em">及其子瑞圖詩文是非刻亮集乃刻璘家集矣</span>  
<!-- 册4 葉2420b　Page:文淵閣四庫全書_0004冊.djvu/610 -->
陶詩析義二卷<sub class="note-yuan">福建巡撫採進本</sub>  
<span style="margin-left: 2em">明黃文煥撰文煥有詩經考巳著錄崇禎中文煥</span>  
<span style="margin-left: 2em">以召試擢翰林㑹其鄉人黃道周以論楊嗣昌陳</span>  
<span style="margin-left: 2em">新甲逮問詞連文煥同下詔獄獄中箋註楚詞聽</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">八卷並著此書自序所謂首夏之廿五日襆被</span>  
<span style="margin-left: 2em">就白雲者是也其析義之例有三一曰練句練章</span>  
<span style="margin-left: 2em">不專平淡一曰憂時念亂不徒隱逸一曰理學標</span>  
<span style="margin-left: 2em">宗聖賢自任每首附批句下而又總論於篇末陶</span>  
<span style="margin-left: 2em">詩之妙所謂𭔃至味於淡泊發纎穠於簡古其神</span>  
<!-- 册4 葉2421a　Page:文淵閣四庫全書_0004冊.djvu/610 -->
<span style="margin-left: 2em">理在筆墨之外可以涵泳與化而不可一字一句</span>  
<span style="margin-left: 2em">求之於町畦之内如伯英逸少之跡不可鈎摹以</span>  
<span style="margin-left: 2em">波磔襄陽雲林之畫不可比量以形𧰼文煥遭逢</span>  
<span style="margin-left: 2em">世難借以寓意則可必謂得陶之精微則不然也</span>  
<span style="margin-left: 2em">別本或作四卷又附以文煥自作赭留集一卷雖</span>  
<span style="margin-left: 2em">意求附驥而事𩔖續貂今析出別著於錄焉</span>  
陶詩箋五卷<sub class="note-yuan">戸部尙書王際華家藏本</sub>  
<span style="margin-left: 1em">國朝邱嘉穗撰嘉穗有考定石經大學經傳解巳著</span>  
<span style="margin-left: 2em">錄是編乃所註陶潛集摸索語氣全𩔖時文批語</span>  
<!-- 册4 葉2421b　Page:文淵閣四庫全書_0004冊.djvu/610 -->
<span style="margin-left: 2em">其力辨潛不信佛爲能崇正學遠異端尤爲拘滯</span>  
<span style="margin-left: 2em">潛之可重在於人品志節其不入白蓮社特蕭散</span>  
<span style="margin-left: 2em">性成不耐禪儀拘束非有儒佛門戸在其意中也</span>  
<span style="margin-left: 2em">嘉穗刻意講學故以潛不入慧遠之社爲千古第</span>  
<span style="margin-left: 2em">一大事不知唐以前人正不以是論賢否耳</span>  
陶詩彚註四卷<sub class="note-yuan">江蘇周厚堉家藏本</sub>  
<span style="margin-left: 1em">國朝吳瞻泰撰瞻泰字東巖歙縣人是編成於康熙</span>  
<span style="margin-left: 2em">乙酉首卷載宋吳仁傑王質二家年譜末卷附詩</span>  
<span style="margin-left: 2em">話百餘條其詩註則採宋湯漢元劉履明何孟春</span>  
<!-- 册4 葉2424a　Page:文淵閣四庫全書_0004冊.djvu/611 -->
<span style="margin-left: 2em">張爾躬黃文煥諸家之說履未嘗註陶詩蓋自其</span>  
<span style="margin-left: 2em">文選補遺摭出也其中如辨辛丑嵗遊斜川詩之</span>  
<span style="margin-left: 2em">開嵗倐五日亦仍舊註未爲特解辨讀山海經詩</span>  
<span style="margin-left: 2em">之形天無千嵗句則持疑於曾季貍周必大二家</span>  
<span style="margin-left: 2em">之說不能遽斷案精衛本屬銜𡨚故借以寓忠臣</span>  
<span style="margin-left: 2em">志士之報復若形天爭帝不成本屬亂賊化形而</span>  
<span style="margin-left: 2em">舞仍爲妖魄正可爲卓莽之流逆常干紀之比山</span>  
<span style="margin-left: 2em">海經之文班班可考潛何取而反尙其猛志耶瞻</span>  
<span style="margin-left: 2em">泰不考其本而徒爭於字形疑似之間未爲得也</span>  
<!-- 册4 葉2424b　Page:文淵閣四庫全書_0004冊.djvu/611 -->
<span style="margin-left: 2em">又贈長沙公族祖一首吳仁傑張縯往復考證終</span>  
<span style="margin-left: 2em">爲世系不合惟楊時偉所訂陶集謂序首長沙公</span>  
<span style="margin-left: 2em">於余爲族當讀一句祖同出大司馬當讀一句其</span>  
<span style="margin-left: 2em">題中族祖二字乃後人誤讀序文祖字爲句因而</span>  
<span style="margin-left: 2em">妄增詩題其說頗<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">而瞻泰不引豈偶未見其本</span>  
<span style="margin-left: 2em">乎集中歸田園詩末首據遯齋閒覽定爲江淹詩</span>  
<span style="margin-left: 2em">有文選可證問來使詩題一首據七修𩔖稿定爲</span>  
<span style="margin-left: 2em">蘇舜欽詩有蘇子美集可證其四時一章但據許</span>  
<span style="margin-left: 2em">顗彦周詩話定爲顧愷之詩而愷之詩於古書别</span>  
<!-- 册4 葉2425a　Page:文淵閣四庫全書_0004冊.djvu/611 -->
<span style="margin-left: 2em">無所見似尙當存疑末可遽刪也讀史述九章舊</span>  
<span style="margin-left: 2em">本不入詩集瞻泰以其爲四言韻語移於卷末然</span>  
<span style="margin-left: 2em">畫扇諸贊亦四言韻語何獨舍彼取此乎</span>  
漫叟拾遺一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">是編選錄唐元結之文不著編輯者名氏卷末有</span>  
<span style="margin-left: 2em">竹岡居士䟦云元次山全集廣南近已重刻湛甘</span>  
<span style="margin-left: 2em">泉太史序之詳矣兹復何言顧此數篇於警䇿人</span>  
<span style="margin-left: 2em">心感激時事頗切故别錄之非有所去取也末署</span>  
<span style="margin-left: 2em">戊寅冬季不著年號以湛若水官翰林年月計之</span>  
<!-- 册4 葉2425b　Page:文淵閣四庫全書_0004冊.djvu/611 -->
<span style="margin-left: 2em">蓋正德十三年也</span>  
李詩鈔述註十六卷<sub class="note-yuan">福建巡撫採進本</sub>  
<span style="margin-left: 2em">明林兆珂撰兆珂有詩經多識編巳著錄兆珂守</span>  
<span style="margin-left: 2em">衡州時曾刻杜詩鈔述註兹其守安慶時所刋以</span>  
<span style="margin-left: 2em">白遊跡多在皖猶在衡刻甫詩意也其書亦分體</span>  
<span style="margin-left: 2em">選鈔每篇首箋故實終加闡發亦頗以考訂爲事</span>  
<span style="margin-left: 2em">欲突過蕭士贇張齊賢舊本然其中有本詩誤者</span>  
<span style="margin-left: 2em">如王昭君詩一上玉闗道玉闗與西域相通非漢</span>  
<span style="margin-left: 2em">與匈奴往來之道懐子房詩我來圯橋上東楚謂</span>  
<!-- 册4 葉2428a　Page:文淵閣四庫全書_0004冊.djvu/612 -->
<span style="margin-left: 2em">橋爲圯不應於圯下加橋字有傳寫誤者如擬古</span>  
<span style="margin-left: 2em">因之𭔃金徽據漢書和帝紀唐書地理志金徽當</span>  
<span style="margin-left: 2em">作金微乃山名聽新鶯百囀歌還過茝石聽新鶯</span>  
<span style="margin-left: 2em">据西都賦茝石當作茝若乃殿名今註内皆未辨</span>  
<span style="margin-left: 2em">及至於詩之必須註而後明者如擬古之蒼然五</span>  
<span style="margin-left: 2em">情𤍠乃用爾雅春蒼天郭註萬物蒼蒼然生語言</span>  
<span style="margin-left: 2em">五情蒼然而生也開元寺贈衡嶽僧之五峯秀眞</span>  
<span style="margin-left: 2em">骨乃用傳燈錄慧可大師一日頭痛其頂骨如五</span>  
<span style="margin-left: 2em">峯秀出事今註内亦未證明文義便不可曉凡此</span>  
<!-- 册4 葉2428b　Page:文淵閣四庫全書_0004冊.djvu/612 -->
<span style="margin-left: 2em">不一而足尙未可謂之善本也</span>  
杜律註二卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">舊本題元虞集撰集有平猺記巳著錄是編所註</span>  
<span style="margin-left: 2em">杜詩凡七言近體一百四十九首卷首楊士竒序</span>  
<span style="margin-left: 2em">稱其解題桃樹一篇瞭然於仁民愛物之旨深得</span>  
<span style="margin-left: 2em">杜意必伯生所爲然歐陽元撰集墓碑不載其有</span>  
<span style="margin-left: 2em">此書觀其詞意亦皆淺近考元趙汸學詩於集而</span>  
<span style="margin-left: 2em">所註杜詩乃無一語及其師董文玉爲趙註作序</span>  
<span style="margin-left: 2em">亦疑虞註之非眞然不云實出誰手案曹安讕言</span>  
<!-- 册4 葉2429a　Page:文淵閣四庫全書_0004冊.djvu/612 -->
<span style="margin-left: 2em">長語稱元進士臨川張伯成著杜詩演義曾昻夫</span>  
<span style="margin-left: 2em">作傳有此名又有刋板惜其少傳往往誤以爲虞</span>  
<span style="margin-left: 2em">伯生李東陽懷𪋤堂詩話亦云徐竹軒以道嘗謂</span>  
<span style="margin-left: 2em">子曰杜律非虞伯生註宣德初巳有刋本乃張姓</span>  
<span style="margin-left: 2em">某人註渠所親見合二家之言觀之則此註實出</span>  
<span style="margin-left: 2em">張伯成手特後人假集之名以行耳王士禎池北</span>  
<span style="margin-left: 2em">偶談謂伯成名性江西金谿人嘗註尙書補傳吳</span>  
<span style="margin-left: 2em">伯慶有輓詩云箋疏定令傳杜律誌銘誰與繼唐</span>  
<span style="margin-left: 2em">碑此尤可爲明徵也</span>  
<!-- 册4 葉2429b　Page:文淵閣四庫全書_0004冊.djvu/612 -->
讀杜愚得十八卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">明單復撰復字陽元會稽人千頃堂書目作嵊縣</span>  
<span style="margin-left: 2em">人洪武中爲漢陽河泊官又云一名復亨舉懷才</span>  
<span style="margin-left: 2em">抱德科授漢陽知縣傳聞異詞未詳孰是是編前</span>  
<span style="margin-left: 2em">有宣德九年黄淮序稱楊士竒得其本於湖湘以</span>  
<span style="margin-left: 2em">授江陰朱善慶兄弟刻之考黃伯思東觀餘論稱</span>  
<span style="margin-left: 2em">嘗撰杜詩編年集則編年實始自伯思其本今巳</span>  
<span style="margin-left: 2em">不傳後魯訔黃鶴諸家穿鑿字句鈎稽嵗月率多</span>  
<span style="margin-left: 2em">未安是編冠以新定年譜亦未免附會其箋釋典</span>  
<!-- 册4 葉2432a　Page:文淵閣四庫全書_0004冊.djvu/613 -->
<span style="margin-left: 2em">故皆剽掇千家註無所考證註後櫽括大意畧爲</span>  
<span style="margin-left: 2em">訓解亦循文敷衍無所發明至每篇彷詩傳之例</span>  
<span style="margin-left: 2em">註興也賦也比也字尤多所牽合矣</span>  
杜詩通十六卷本義四卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">明張綖註綖字世文千頃堂書目作字世昌疑傳</span>
