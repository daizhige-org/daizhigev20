## 欽定四庫全書總目 卷一百六十一　集部十四　別集類十四

欽定四庫全書總目卷一百六十一  
<span style="margin-left: 1em">集部十四</span>  
<span style="margin-left: 2em">别集類十四</span>  
石屏集六卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">宋戴復古撰復古字式之天台人嘗登陸游之門</span>  
<span style="margin-left: 2em">以詩鳴江湖間所居有石屏山因以爲號遂以名</span>  
<span style="margin-left: 2em">集卷首載其父敏詩十首葢復古幼<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2854.svg?width=24" alt="四庫全書僻字第2854號（孤）" title="四庫全書僻字第2854號（孤）">勉承家學</span>  
<span style="margin-left: 2em">因搜訪其先人遺稿以冠已集昔黃庭堅山谷集</span>  
<span style="margin-left: 2em">後附刻其父伐檀詩王楙野客叢書後附刻其父</span>  
<!-- 册4 葉1081b　Page:文淵閣四庫全書_0004冊.djvu/275 -->
<span style="margin-left: 2em">野老紀聞復古以父詩爲數無多不成卷帙特升</span>  
<span style="margin-left: 2em">弁於簡端例雖小變理乃較協矣復古詩筆俊爽</span>  
<span style="margin-left: 2em">極爲作者所推姚鏞跋其詩稱其天然不費斧鑿</span>  
<span style="margin-left: 2em">處大似高三十五輩晚唐諸子當讓一而方回跋</span>  
<span style="margin-left: 2em">其詩亦稱其淸健輕快自成一家雖皆不免稍過</span>  
<span style="margin-left: 2em">其實要其精思研刻實自能獨闢町畦瞿佑歸田</span>  
<span style="margin-left: 2em">詩話載復古嘗見夕照映山得句云夕陽山外山</span>  
<span style="margin-left: 2em">自以爲奇欲以塵世夢中夢對之而不愜意後行</span>  
<span style="margin-left: 2em">村中春雨方霽行潦縱橫得春水渡傍渡句以對</span>  
<!-- 册4 葉1084a　Page:文淵閣四庫全書_0004冊.djvu/276 -->
<span style="margin-left: 2em">上下始稱其苦心搜索卽此可見一端至集中嚴</span>  
<span style="margin-left: 2em">子陵釣臺詩所作平生誤識劉文叔惹起虛名滿</span>  
<span style="margin-left: 2em">世間者趙與虤娛書堂詩話極賞其新意可喜而</span>  
<span style="margin-left: 2em">羅大經鶴林玉露又深以其議論爲不然葢意取</span>  
<span style="margin-left: 2em">翻新轉致失之輕佻集中殊非上乘與虤所云固</span>  
<span style="margin-left: 2em">未足爲定評矣</span>  
蓮峯集十卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋史堯弼撰堯弼字唐英眉州人其仕履不見於</span>  
<span style="margin-left: 2em">史傳焦竑國史經籍志載堯弼蓮峯集三十卷而</span>  
<!-- 册4 葉1084b　Page:文淵閣四庫全書_0004冊.djvu/276 -->
<span style="margin-left: 2em">世間亦無傳本故錄宋詩者多不能舉其姓名惟</span>  
<span style="margin-left: 2em">永樂大典載有是集原序二篇其一作於乾道丙</span>  
<span style="margin-left: 2em">戌自署曰省齋不知何人其一爲任淸全序作於</span>  
<span style="margin-left: 2em">嘉定癸酉稱堯弼童丱卽迥出不凡少以古樂府</span>  
<span style="margin-left: 2em">洪範等論往見張浚浚謂其大𩔖東坡留館於潭</span>  
<span style="margin-left: 2em">與張栻遊每開以正大之學歲丁丑偕其弟堯文</span>  
<span style="margin-left: 2em">登第云云而亦不言其所終考周密浩然齋雅談</span>  
<span style="margin-left: 2em">云李燾十八歲爲眉州解魁時第二人史堯弼方</span>  
<span style="margin-left: 2em">十四歲人疑其文未工赴鹿鳴宴猶著粉紅袴命</span>  
<!-- 册4 葉1085a　Page:文淵閣四庫全書_0004冊.djvu/276 -->
<span style="margin-left: 2em">分韻賦詩堯弼得建字援筆立成云四歲尙少房</span>  
<span style="margin-left: 2em">元齡七步未饒曹子建後爲張魏公客不幸早世</span>  
<span style="margin-left: 2em">云云其所記與任淸全序相合又江湖續集載張</span>  
<span style="margin-left: 2em">煒題蓮峯集詩一首亦有句云一梗江湖客三朝</span>  
<span style="margin-left: 2em">忠義家以諸書叅互考證葢堯弼登第後未授官</span>  
<span style="margin-left: 2em">而卒也堯弼天姿卓絶其詩縱橫排宕擺脫恒蹊</span>  
<span style="margin-left: 2em">其論䇿諸篇明白曉暢瀾翻不窮亦有不可羈勒</span>  
<span style="margin-left: 2em">之氣大抵有其鄉蘇氏之遺風惟其夏綠霜凋故</span>  
<span style="margin-left: 2em">不能如李燾之著書傳後然就其文章而論要亦</span>  
<!-- 册4 葉1085b　Page:文淵閣四庫全書_0004冊.djvu/276 -->
<span style="margin-left: 2em">不失爲才士任淸全序乃因集中有論學之作遂</span>  
<span style="margin-left: 2em">以張栻少年自得爲堯弼磨礲浸灌之功欲援而</span>  
<span style="margin-left: 2em">入於道學則門戸標榜之習轉不足以見堯弼矣</span>  
<span style="margin-left: 2em">其文在宋巳多散落是集乃其從孫師道所重刻</span>  
<span style="margin-left: 2em">今亦不可復覩謹從永樂大典中掇拾裒輯釐爲</span>  
<span style="margin-left: 2em">十卷著之於錄俾懷才賫志之士無聲塵翳如之</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3004.svg?width=24" alt="四庫全書僻字第3004號（慨）" title="四庫全書僻字第3004號（慨）">焉</span>  
江湖長翁文集四十卷<sub class="note-yuan">山東巡撫採進本</sub>  
<span style="margin-left: 2em">宋陳造撰造字唐<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">高郵人淳熙二年進士官至</span>  
<!-- 册4 葉1088a　Page:文淵閣四庫全書_0004冊.djvu/277 -->
<span style="margin-left: 2em">淮南西路安撫司叅議遭宋不競事多齟齬自以</span>  
<span style="margin-left: 2em">爲無補於世置江湖乃宜遂號江湖長翁旣不竟</span>  
<span style="margin-left: 2em">其用故無所表見而宋史亦不爲立傳惟元申屠</span>  
<span style="margin-left: 2em">駉爲作墓誌稱其於誨誘則良師於撫字則循吏</span>  
<span style="margin-left: 2em">身篤操修道兼體用雖金石之文稱述例多溢量</span>  
<span style="margin-left: 2em">亦未必純搆虛詞也集中罪言一篇葢仿杜牧而</span>  
<span style="margin-left: 2em">作不免紙上談兵徒爲豪語其文則恢奇排奡要</span>  
<span style="margin-left: 2em">亦陳亮劉過之流其他劄子諸篇多剴切敷陳當</span>  
<span style="margin-left: 2em">於事理記序各體錘字鍊詞稍傷眞氣而皆謹嚴</span>  
<!-- 册4 葉1088b　Page:文淵閣四庫全書_0004冊.djvu/277 -->
<span style="margin-left: 2em">有法在南宋諸作者中亦鐵中錚錚者矣至易說</span>  
<span style="margin-left: 2em">一卷始於无妄終於比凡十五篇疑其未完之書</span>  
<span style="margin-left: 2em">中多以史證經與楊萬里誠齋易說李光讀易詳</span>  
<span style="margin-left: 2em">說相𩔖殆爲時事而發托之詁經歟其集久無刻</span>  
<span style="margin-left: 2em">本明崇禎中李之藻以淮南自秦觀而後惟造有</span>  
<span style="margin-left: 2em">名於時始與觀集同刻之於高郵云</span>  
燭湖集二十卷附編二卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋孫應時撰應時字季和自號燭湖居士餘姚人</span>  
<span style="margin-left: 2em">登淳熙乙未進士初尉黃巖遷海陵丞再遷遂安</span>  
<!-- 册4 葉1089a　Page:文淵閣四庫全書_0004冊.djvu/277 -->
<span style="margin-left: 2em">令改知常熟縣以倉粟流欠貶秩移判邵武軍未</span>  
<span style="margin-left: 2em">上而卒考楊簡作應時壙志及張淏會稽續志均</span>  
<span style="margin-left: 2em">稱其紹熙初嘗應蜀帥邱崈辟預料吳曦逆謀白</span>  
<span style="margin-left: 2em">崈以別將領其軍後曦以叛誅其言果驗時應時</span>  
<span style="margin-left: 2em">已殁三省奏官其子祖開葢亦智畧之士又史彌</span>  
<span style="margin-left: 2em">遠受業於應時集中與彌遠諸書皆深相規戒迨</span>  
<span style="margin-left: 2em">彌遠柄國獨超然自遠無所假借甘淪一倅而終</span>  
<span style="margin-left: 2em">其人品尤不可及矣宋史藝文志載燭湖集十卷</span>  
<span style="margin-left: 2em">據應時詩中自序葢嘗應劉克莊之求手編其稿</span>  
<!-- 册4 葉1089b　Page:文淵閣四庫全書_0004冊.djvu/277 -->
<span style="margin-left: 2em">爲五十卷集末有其姪祖祐跋稱悚水司馬述先</span>  
<span style="margin-left: 2em">以十卷付梓後付以問思錄五十條通鑑摘義三</span>  
<span style="margin-left: 2em">十條總名之曰經史說又附雪齋父子倡和詩及</span>  
<span style="margin-left: 2em">雪齋行狀墓銘楊簡所撰壙記會稽續志小傳子</span>  
<span style="margin-left: 2em">祖開補官省劄等篇是十卷爲祖祐所編非其舊</span>  
<span style="margin-left: 2em">本也年遠散佚久無傳本故厲鶚作宋詩紀事僅</span>  
<span style="margin-left: 2em">於吳禮部詩話王應麟困學紀聞黃宗羲姚江逸</span>  
<span style="margin-left: 2em">詩内採掇數篇寥寥不備兹從永樂大典所載排</span>  
<span style="margin-left: 2em">纂成編惟經史說殘缺特甚僅存一篇其餘則約</span>  
<!-- 册4 葉1092a　Page:文淵閣四庫全書_0004冊.djvu/278 -->
<span style="margin-left: 2em">畧篇數殆已十得八九以卷帙繁重分二十卷仍</span>  
<span style="margin-left: 2em">附編其父介及其兄應求應符詩並錄應時父子</span>  
<span style="margin-left: 2em">誌傳行狀子祖開補官省劄諸篇爲上下二卷應</span>  
<span style="margin-left: 2em">求字伯起嘗登鄉薦應符字仲潛所著有厯代帝</span>  
<span style="margin-left: 2em">王纂要二卷初學須知五卷載於陳振孫書錄解</span>  
<span style="margin-left: 2em">題今並未見云</span>  
昌谷集二十二卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋曹彥約撰彥約有經幄管見已著錄是編稱昌</span>  
<span style="margin-left: 2em">谷集者考集中有與劉後溪書謂世爲都昌村落</span>  
<!-- 册4 葉1092b　Page:文淵閣四庫全書_0004冊.djvu/278 -->
<span style="margin-left: 2em">人後遷於城下昌谷巷則其所居地名也彥約初</span>  
<span style="margin-left: 2em">游朱子之門其後厯任州郡却敵平宼獨卓有實</span>  
<span style="margin-left: 2em">用故宋史本傳稱其可以建立事功及入侍講筵</span>  
<span style="margin-left: 2em">亦能殫心啓沃其經幄管見一書敷陳祖訓規箴</span>  
<span style="margin-left: 2em">時政尙厯厯可稽文集乃湮没不顯宋史藝文志</span>  
<span style="margin-left: 2em">亦不著錄惟焦竑國史經籍志有昌谷小集二十</span>  
<span style="margin-left: 2em">卷錢溥秘閣書目亦有曹文簡公集十五冊然亦</span>  
<span style="margin-left: 2em">久無傳本厲鶚宋詩紀事蒐羅繁富絶不及其姓</span>  
<span style="margin-left: 2em">名則無徵久矣今考永樂大典載彥約詩文頗多</span>  
<!-- 册4 葉1093a　Page:文淵閣四庫全書_0004冊.djvu/278 -->
<span style="margin-left: 2em">核其篇目如本傳所稱爲利路轉運判官時所作</span>  
<span style="margin-left: 2em">病夫議爲兵部侍郞時所上薦李心傳劄子俱不</span>  
<span style="margin-left: 2em">載其中知已未免於佚缺然其餘諸作世所不傳</span>  
<span style="margin-left: 2em">者爲數尙夥謹𩔖次排纂釐爲二十二卷其間奏</span>  
<span style="margin-left: 2em">議大都通達政體可見施行所論兵事利害尤<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）"></span>  
<span style="margin-left: 2em">鑿有識不同摭拾游談其應詔陳言二封事乃慶</span>  
<span style="margin-left: 2em">元寶慶問先後所上於當日苟且玩愒之弊反覆</span>  
<span style="margin-left: 2em">致意切中窽要亦可徵其鯁<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">之槪惟儷詞韻語</span>  
<span style="margin-left: 2em">稍傷質樸然不事修飾而自能詞達理明要非學</span>  
<!-- 册4 葉1093b　Page:文淵閣四庫全書_0004冊.djvu/278 -->
<span style="margin-left: 2em">有原本者不能也</span>  
省齋集十卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋廖行之撰行之字天民其先延平人五季時徙</span>  
<span style="margin-left: 2em">於衡州登淳熙甲辰進士嘗官岳州巴陵尉以親</span>  
<span style="margin-left: 2em">老丐飬而歸注授寧鄉主簿未赴據田奇所作行</span>  
<span style="margin-left: 2em">狀稱其生平内行修飭留心經濟入仕亦多著循</span>  
<span style="margin-left: 2em">績然名位不昌故姓字不著於史傳其所著作諸</span>  
<span style="margin-left: 2em">家亦罕著錄是集乃其子謙所刋原本十卷今從</span>  
<span style="margin-left: 2em">永樂大典中採掇裒輯篇帙頗夥似當日全部收</span>  
<!-- 册4 葉1096a　Page:文淵閣四庫全書_0004冊.djvu/279 -->
