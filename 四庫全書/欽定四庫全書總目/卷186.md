## 欽定四庫全書總目 卷一百八十六　集部三十九　總集類一

欽定四庫全書總目卷一百八十六  
<span style="margin-left: 1em">集部三十九</span>  
<span style="margin-left: 2em">總集類一</span>  
<span style="margin-left: 3em">文集日興散無統紀於是總集作焉一則網羅</span>  
<span style="margin-left: 3em">放佚使零章殘什並有所歸一則刪汰繁蕪使</span>  
<span style="margin-left: 3em">莠稗咸除菁華畢出是固文章之衡鑒著作之</span>  
<span style="margin-left: 3em">淵藪矣三百篇旣列爲經王逸所衰又僅楚詞</span>  
<span style="margin-left: 3em">一家故體例所成以摯虞流別爲始其書雖佚</span>  
<span style="margin-left: 3em">其論尚散見藝文類聚中葢分體編錄者也文</span>  
<!-- 册5 葉5b　Page:文淵閣四庫全書_0005冊.djvu/6 -->
<span style="margin-left: 3em">選而下互有得失至宋眞德秀文章正宗始別</span>  
<span style="margin-left: 3em">出談理一派而總集遂判兩途然文質相扶理</span>  
<span style="margin-left: 3em">無偏廢各明一義未害同歸惟末學循聲主持</span>  
<span style="margin-left: 3em">過當使方言俚語俱入詞章麗製鴻篇横遭嗤</span>  
<span style="margin-left: 3em">㸃是則併德秀本旨失之耳今一一别裁務歸</span>  
<span style="margin-left: 3em">中道至明萬厯以後儈魁漁利坊刻彌增剽竊</span>  
<span style="margin-left: 3em">陳因動成巨帙併無門徑之可言姑存其目爲</span>  
<span style="margin-left: 3em">冗濫之戒而巳</span>  
文選註六十卷<sub class="note-yuan">内府藏本</sub>  
<!-- 册5 葉8a　Page:文淵閣四庫全書_0005冊.djvu/7 -->
<span style="margin-left: 2em">按文選舊本三十卷梁昭明太子蕭統撰唐文林</span>  
<span style="margin-left: 2em">郎守太子右内率府録事叅軍事崇賢館直學士</span>  
<span style="margin-left: 2em">江都李善爲之註始每卷各分爲二新唐書李邕</span>  
<span style="margin-left: 2em">傳稱其父善始註文選釋事而忘義書成以問邕</span>  
<span style="margin-left: 2em">邕意欲有所更善因令補益之邕乃附事見義故</span>  
<span style="margin-left: 2em">兩書並行今本事義兼釋似爲邕所改定然傳稱</span>  
<span style="margin-left: 2em">善註文選在顯慶中與今本所載進表題顯慶三</span>  
<span style="margin-left: 2em">年者合而舊唐書邕傳稱天寳五載坐柳勣事杖</span>  
<span style="margin-left: 2em">殺年七十餘上距顯慶三年凡八十九年是時邕</span>  
<!-- 册5 葉8b　Page:文淵閣四庫全書_0005冊.djvu/7 -->
<span style="margin-left: 2em">尚未生安得有助善註書之事且自天寳五載上</span>  
<span style="margin-left: 2em">推七十餘年當在高宗總章咸亨間而舊書稱善</span>  
<span style="margin-left: 2em">文選之學受之曹憲計在隋末年巳弱冠至生邕</span>  
<span style="margin-left: 2em">之時當七十餘嵗亦決無伏生之壽待其長而著</span>  
<span style="margin-left: 2em">書考李匡乂資暇録曰李氏文選有初註成者有</span>  
<span style="margin-left: 2em">覆註有三註四註者當時旋被傳寫其絶筆之本</span>  
<span style="margin-left: 2em">皆釋音訓義註解甚多是善書定本本事義兼釋</span>  
<span style="margin-left: 2em">不由於邕匡乂唐人時代相近其言當必有徵知</span>  
<span style="margin-left: 2em">新唐書喜采小說未詳考也其書自南宋以來皆</span>  
<!-- 册5 葉9a　Page:文淵閣四庫全書_0005冊.djvu/7 -->
<span style="margin-left: 2em">與五臣註合刊名曰六臣註文選而善註單行之</span>  
<span style="margin-left: 2em">本世遂罕傳此本爲毛晉所刻雖稱從宋本校正</span>  
<span style="margin-left: 2em">今考其第二十五卷陸雲贈兄機詩註中有向曰</span>  
<span style="margin-left: 2em">一條濟曰一條又贈張士然詩註中有翰曰銑曰</span>  
<span style="margin-left: 2em">濟曰向曰各一條殆因六臣之本削去五臣獨留</span>  
<span style="margin-left: 2em">善註故刊除不盡未必眞見單行本也他如班固</span>  
<span style="margin-left: 2em">兩都賦誤以註列目錄下左思三都賦善明稱劉</span>  
<span style="margin-left: 2em">逵註蜀都吳都張載註魏都乃三篇俱題劉淵林</span>  
<span style="margin-left: 2em">字又如楚詞用王逸註子虛上林賦用郭璞註兩</span>  
<!-- 册5 葉9b　Page:文淵閣四庫全書_0005冊.djvu/7 -->
<span style="margin-left: 2em">京賦用薛綜註思元賦用舊註魯靈光殿賦用張</span>  
<span style="margin-left: 2em">載註詠懷詩用顔延年沈約註射雉賦用徐爰註</span>  
<span style="margin-left: 2em">皆題本名而補註則別稱善曰於薛綜條下發例</span>  
<span style="margin-left: 2em">甚明乃於揚雄羽獵賦用顔師古註之𩔖則竟漏</span>  
<span style="margin-left: 2em">本名於班固幽通賦用曹大家註之類則散標句</span>  
<span style="margin-left: 2em">下又文選之例於作者皆書其字而杜預春秋傳</span>  
<span style="margin-left: 2em">序則獨題名豈非從六臣本中摘出善註以意排</span>  
<span style="margin-left: 2em">纂故體例互殊歟至二十七卷末附載樂府君子</span>  
<span style="margin-left: 2em">行一篇註曰李善本古詞只三首無此一篇五臣</span>  
<!-- 册5 葉12a　Page:文淵閣四庫全書_0005冊.djvu/8 -->
<span style="margin-left: 2em">本有今附於後其非善原書尤爲顯證以是例之</span>  
<span style="margin-left: 2em">其孔安國尚書序杜預春秋傳序二篇僅列原文</span>  
<span style="margin-left: 2em">絶無一字之註疑亦從五臣本勦入非其舊矣惟</span>  
<span style="margin-left: 2em">是此本之外更無別本故仍而錄之而附著其舛</span>  
<span style="margin-left: 2em">互如右</span>  
六臣註文選六十卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">按唐顯慶中李善受曹憲文選之學爲之作註至</span>  
<span style="margin-left: 2em">開元六年工部侍郞吕延祚復集衢州常山縣尉</span>  
<span style="margin-left: 2em">吕延濟都水使者劉承祖之子良處士張詵吕向</span>  
<!-- 册5 葉12b　Page:文淵閣四庫全書_0005冊.djvu/8 -->
<span style="margin-left: 2em">李周翰五人共爲之註表進於朝其詆善之短則</span>  
<span style="margin-left: 2em">曰忽發章句是徵載籍述作之由何嘗措翰使復</span>  
<span style="margin-left: 2em">精核註引則䧟於末學質訪旨趣則巋然舊文祗</span>  
<span style="margin-left: 2em">謂攪心胡爲析理其述五臣之長則曰相與三復</span>  
<span style="margin-left: 2em">乃詞周知祕旨一貫於理沓測澄懷目無全文心</span>  
<span style="margin-left: 2em">無留意作者爲志森然可觀觀其所言頗欲排突</span>  
<span style="margin-left: 2em">前人高自位置書首進表之末載高力士所宣口</span>  
<span style="margin-left: 2em">勅亦有此書甚好之語然唐李匡乂作資暇集備</span>  
<span style="margin-left: 2em">摘其竊據善註巧爲顚倒條分縷析言之甚詳又</span>  
<!-- 册5 葉13a　Page:文淵閣四庫全書_0005冊.djvu/8 -->
<span style="margin-left: 2em">姚寛西溪叢語詆其註揚雄解嘲不知伯夷太公</span>  
<span style="margin-left: 2em">爲二老反駁善註之誤王楙野客叢書詆其誤叙</span>  
<span style="margin-left: 2em">王暕世系以覽後爲祥後以曇首之曾孫爲曇首</span>  
<span style="margin-left: 2em">之子明田汝成重刊文選其子萟衡又摘所註西</span>  
<span style="margin-left: 2em">都賦之龍興虎視東都之乾符坤珍東京賦之巨</span>  
<span style="margin-left: 2em">滑間亹蕪城賦之袤廣三墳諸條今觀所註迂陋</span>  
<span style="margin-left: 2em">鄙倍之處尚不止此而以空疎臆見輕詆通儒殆</span>  
<span style="margin-left: 2em">亦韓愈所謂蚍蜉撼樹者歟其書本與善註别行</span>  
<span style="margin-left: 2em">故唐志各著錄黃伯思東觀餘論尚譏崇文總目</span>  
<!-- 册5 葉13b　Page:文淵閣四庫全書_0005冊.djvu/8 -->
<span style="margin-left: 2em">悞以五臣註本置李善註本之前至陳振孫書錄</span>  
<span style="margin-left: 2em">解題始有六臣文選之目葢南宋以來偶與善註</span>  
<span style="margin-left: 2em">合刻取便參證元明至今遂輾轉相沿併爲一集</span>  
<span style="margin-left: 2em">附驥以傳葢亦幸矣然其疏通文意亦閒有可采</span>  
<span style="margin-left: 2em">唐人著述傳世已稀固不必竟廢之也田氏刊本</span>  
<span style="margin-left: 2em">頗有刪改猶明人竄亂古書之習此本爲明袁袠</span>  
<span style="margin-left: 2em">所刊朱<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">尊䟦謂從宋崇寧五年廣都裴氏本翻</span>  
<span style="margin-left: 2em">雕諱字闕筆尚仍其舊頗足亂眞惟不題鏤板訖</span>  
<span style="margin-left: 2em">工年月以是爲别耳錢曾讀書敏求記稱所藏宋</span>  
<!-- 册5 葉16a　Page:文淵閣四庫全書_0005冊.djvu/9 -->
<span style="margin-left: 2em">本五臣註作三十卷爲不失蕭統之舊其說與延</span>  
<span style="margin-left: 2em">祚表合今未見此本然田氏本及萬厯戊寅徐成</span>  
<span style="margin-left: 2em">位所刻亦均作三十卷葢或合或分各隨刊者之</span>  
<span style="margin-left: 2em">意但不妄改舊文卽爲善本正不必以卷數多寡</span>  
<span style="margin-left: 2em">定其工拙矣</span>  
文選顔鮑謝詩評四卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">元方回撰回有續古今考巳著錄是編取文選所</span>  
<span style="margin-left: 2em">錄顔延之鮑照謝靈運謝惠連謝脁之詩各爲論</span>  
<span style="margin-left: 2em">次諸家書目皆不著錄惟永樂大典載之考集中</span>  
<!-- 册5 葉16b　Page:文淵閣四庫全書_0005冊.djvu/9 -->
<span style="margin-left: 2em">顔延之三月三日侍游曲阿後湖作一首評曰本</span>  
<span style="margin-left: 2em">不書此詩書之以見夫雕繪滿眼之詩未可以望</span>  
<span style="margin-left: 2em">謝靈運也又北使洛一首評曰所以書此詩者有</span>  
<span style="margin-left: 2em">二又謝靈運擬鄴中集八首評曰規行矩步甃砌</span>  
<span style="margin-left: 2em">粧㸃而成無可圈㸃故余評其詩而不書其全篇</span>  
<span style="margin-left: 2em"><sub class="note-yuan">按此本八首皆書全篇與此評不合葢不載本詩則所評無可繫屬故後人又爲補錄也</sub>則此</span>  
<span style="margin-left: 2em">集葢回手書之冊後人得其墨迹錄之成帙也回</span>  
<span style="margin-left: 2em">所撰瀛奎律髓持論頗偏此集所評如謝靈運詩</span>  
<span style="margin-left: 2em">多取其理路之語又好標一字爲句眼仍不出宋</span>  
<!-- 册5 葉17a　Page:文淵閣四庫全書_0005冊.djvu/9 -->
<span style="margin-left: 2em">人窠臼然其他則多中理解又如謝靈運述祖德</span>  
<span style="margin-left: 2em">第二首評曰文選註高揖七州外謂舜分天下爲</span>  
<span style="margin-left: 2em">十二州時晉有七州故云七州余謂不然此指謝</span>  
<span style="margin-left: 2em">元所解徐兖靑司冀幽并七州都督耳謂晉有七</span>  
<span style="margin-left: 2em">州而髙揖其外則不復居晉土耶謝瞻張子房詩</span>  
<span style="margin-left: 2em">評曰東坡詆五臣誤註三殤其實乃是李善顔延</span>  
<span style="margin-left: 2em">之秋胡詩評曰秋胡之仕於陳止是魯之鄰國而</span>  
<span style="margin-left: 2em">云王畿恐是延之一時寓言雖以秋胡子爲題亦</span>  
<span style="margin-left: 2em">泛言仕宦善註乃引詩緯曰陳王者所起也此意</span>  
<!-- 册5 葉17b　Page:文淵閣四庫全書_0005冊.djvu/9 -->
<span style="margin-left: 2em">似頗未通亦間有所考訂至於評謝靈運九日戲</span>  
<span style="margin-left: 2em">馬臺送孔令詩謂鳴葭當作鳴笳則未考晉書夏</span>  
<span style="margin-left: 2em">統傳評鮑照行藥至城東橋詩謂行藥爲乘興還</span>  
<span style="margin-left: 2em">來看藥欄之意則誤引杜詩評謝脁郡内高齋閒</span>  
<span style="margin-left: 2em">坐答吕法曹詩謂或以爲岫本訓穴以爲遠山亦</span>  
<span style="margin-left: 2em">無害則附會陶潛歸去來詞小小舛漏亦所不免</span>  
<span style="margin-left: 2em">要不害其大體統觀全集究較瀛奎律髓爲勝殆</span>  
<span style="margin-left: 2em">作於晩年所見又進歟</span>  
玉臺新咏十卷<sub class="note-yuan">兵部侍郞紀昀家藏本</sub>  
<!-- 册5 葉20a　Page:文淵閣四庫全書_0005冊.djvu/10 -->
<span style="margin-left: 2em">陳徐陵撰陵有文集巳著錄此所選梁以前詩也</span>  
<span style="margin-left: 2em">按劉肅大唐新語曰梁簡文爲太子好作艶詩境</span>  
<span style="margin-left: 2em">内化之晩年欲改作追之不及乃令徐陵撰玉臺</span>  
<span style="margin-left: 2em">集以大其體據此則是書作於梁時故簡文稱皇</span>  
<span style="margin-left: 2em">太子元帝稱湘東王今本題陳尚書左僕射太子</span>  
<span style="margin-left: 2em">少傅東海徐陵撰殆後人之所追改如劉勰文心</span>  
<span style="margin-left: 2em">雕龍本作於齊而題梁通事舍人耳其梁武帝書</span>  
<span style="margin-left: 2em">諡書國號邵陵王等並書名亦出於追改也其書</span>  
<span style="margin-left: 2em">前八卷爲自漢至梁五言詩第九卷爲歌行第十</span>
