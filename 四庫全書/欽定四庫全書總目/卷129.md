## 欽定四庫全書總目 卷一百二十九　子部三十九　雜家類存目六

欽定四庫全書卷一百二十九  
<span style="margin-left: 1em">子部三十九</span>  
<span style="margin-left: 2em">雜家𩔖存目六</span>  
蔣說二卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 1em">國朝蔣超撰超有峩<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2899.svg?width=24" alt="四庫全書僻字第2899號（⿱山眉 -- 𭗙）" title="四庫全書僻字第2899號（⿱山眉 -- 𭗙）">山志已著錄蔣說者葢因其</span>  
<span style="margin-left: 2em">姓以名書如僧肇著書名曰肇論之𩔖也而觀其</span>  
<span style="margin-left: 2em">自序乃轉讀菰蔣之蔣已爲詭僻其書雜記聞見</span>  
<span style="margin-left: 2em">别𩔖分門附以議論大㫖明<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">而尙儉尤尊佛氏</span>  
<span style="margin-left: 2em">至以儒童菩薩化生孔子爲實然其論時政三十</span>  
<!-- 册3 葉3080b　Page:文淵閣四庫全書_0003冊.djvu/775 -->
<span style="margin-left: 2em">餘條欲復封建一說尤迂謬難行惟卷末記節烈</span>  
<span style="margin-left: 2em">數十條或可備志乘采擇耳</span>  
雲谷卧餘二十卷續八卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 1em">國朝張習孔撰習孔字念難歙縣人順治己丑進士</span>  
<span style="margin-left: 2em">官至山東提學僉事其書喜議論而不甚攷證多</span>  
<span style="margin-left: 2em">以私臆斷古人又果於自信如杜甫之詩皆爲改</span>  
<span style="margin-left: 2em">定左邱明之傳亦爲刪削此自有詩文以來無人</span>  
<span style="margin-left: 2em">敢爲之事也</span>  
蒿菴閒話二卷<sub class="note-yuan">桂林府同知李文藻刋本</sub>  
<!-- 册3 葉3081a　Page:文淵閣四庫全書_0003冊.djvu/775 -->
<span style="margin-left: 1em">國朝張爾岐撰爾岐有周易說畧已著錄是編乃其</span>  
<span style="margin-left: 2em">劄記之文凡二百九十六條顧炎武與汪琬書自</span>  
<span style="margin-left: 2em">稱精於三禮卓然經師不及爾岐故原跋以是編</span>  
<span style="margin-left: 2em">爲日知錄之亞然日知錄原原本本一事務窮其</span>  
<span style="margin-left: 2em">始末一字務核其異同是編特偶有所得隨文生</span>  
<span style="margin-left: 2em">義本無意於著書謂之零璣碎璧則可至於網羅</span>  
<span style="margin-left: 2em">四部鎔鑄羣言則實非日知錄之比如曾子易簀</span>  
<span style="margin-left: 2em">一條稱嘗見一書說楚國曾聘曾子爲相是當時</span>  
<span style="margin-left: 2em">亦曾作大夫故季孫得以此爲遺云云案韓詩外</span>  
<!-- 册3 葉3081b　Page:文淵閣四庫全書_0003冊.djvu/775 -->
<span style="margin-left: 2em">傳稱曾子仕於莒得粟三秉方是之時曾子重其</span>  
<span style="margin-left: 2em">祿而輕其身親没之後齊迎以相楚迎以令尹晉</span>  
<span style="margin-left: 2em">迎以上卿方是之時曾子重其身而輕其祿又稱</span>  
<span style="margin-left: 2em">曾子仕齊爲吏後南遊於楚得尊官爾岐所謂嘗</span>  
<span style="margin-left: 2em">見一書當卽指此然韓嬰採掇雜說前後已自相</span>  
<span style="margin-left: 2em">違異豈可引以詁經顧炎武必無是語矣其論吳</span>  
<span style="margin-left: 2em">澄三禮考註出於依托極爲精核葢爾岐本長於</span>  
<span style="margin-left: 2em">禮故剖析鑿鑿使盡如斯則方駕日知錄可也</span>  
暑窻臆說二卷<sub class="note-yuan">山東廵撫採進本</sub>  
<!-- 册3 葉3084a　Page:文淵閣四庫全書_0003冊.djvu/776 -->
<span style="margin-left: 1em">國朝王龯撰龯有粤遊日記巳著錄是編則世德堂</span>  
<span style="margin-left: 2em">遺書第四種也前有自序稱三伏酷毒揮汗之餘</span>  
<span style="margin-left: 2em">取架上書得明人小說百餘種逡巡讀之隨讀隨</span>  
<span style="margin-left: 2em">筆今核其名目似所讀乃陶珽續說郛也如辨華</span>  
<span style="margin-left: 2em">野纂聞記劉球事渉異編勦太平廣記所載慕容</span>  
<span style="margin-left: 2em">垂詩春風堂隨筆誤記元韶娶魏孝武后事之𩔖</span>  
<span style="margin-left: 2em">亦間有可采而體例不善賔主混淆不辨孰爲原</span>  
<span style="margin-left: 2em">文孰爲龯語是則排纂之過耳</span>  
聽潮居存業十卷<sub class="note-yuan">江西廵撫採進本</sub>  
<!-- 册3 葉3084b　Page:文淵閣四庫全書_0003冊.djvu/776 -->
<span style="margin-left: 1em">國朝原良撰良字鳴喜江西樂安人順治中貢生官</span>  
<span style="margin-left: 2em">寜都縣訓導是書分十編各立四字標目一曰明</span>  
<span style="margin-left: 2em">宗正學前多講學之語後亦雜論經義如謂孔子</span>  
<span style="margin-left: 2em">學問源於契及成湯武丁謂刪詩存車𥻘爲預知</span>  
<span style="margin-left: 2em">秦有趙高之禍皆失之附會二曰身世要則多論</span>  
<span style="margin-left: 2em">世故如陰德一條旣云陰德非惟不求人知亦不</span>  
<span style="margin-left: 2em">可求天知報應緩𢚩一條又稱天不𢚩性却有記</span>  
<span style="margin-left: 2em">性吾輩於善念善事須忍耐爲之隔半頁而自相</span>  
<span style="margin-left: 2em">矛盾附以讀書作文十六則亦殊不倫三曰史會</span>  
<!-- 册3 葉3085a　Page:文淵閣四庫全書_0003冊.djvu/776 -->
<span style="margin-left: 2em">大綱四曰友古特評五曰羣古對觀六曰左國補</span>  
<span style="margin-left: 2em">議皆史論也但大綱多論世運盛衰特評則品藻</span>  
<span style="margin-left: 2em">人物對觀則摭古之相𩔖者論之補議則仿吕祖</span>  
<span style="margin-left: 2em">謙左氏博議柳宗元非國語而斟酌其說耳七曰</span>  
<span style="margin-left: 2em">讀餘誌畧大致如王世貞讀書後而彌爲膚淺如</span>  
<span style="margin-left: 2em">以考工記爲三代以上之書不宜附之於周是併</span>  
<span style="margin-left: 2em">鄭之削宋之斤吳越之劍諸句亦未讀也八曰元</span>  
<span style="margin-left: 2em">圃餘珍剽掇舊事畧加評斷亦史論之旁支九曰</span>  
<span style="margin-left: 2em">韻林隨筆皆所作詩話如謂庾信詩爲梁之特出</span>  
<!-- 册3 葉3085b　Page:文淵閣四庫全書_0003冊.djvu/776 -->
<span style="margin-left: 2em">唐之先鞭而文選少載又謂劉禹錫元稹白居易</span>  
<span style="margin-left: 2em">與宗楚客同賦金陵懷古詩則其他可以槩見矣</span>  
<span style="margin-left: 2em">十曰山野寤言皆私撰經世之策尤多迂濶之談</span>  
<span style="margin-left: 2em">大抵好爲議論而所學則未能淹貫者也</span>  
匡林二卷<sub class="note-yuan">浙江汪汝瑮家藏本</sub>  
<span style="margin-left: 1em">國朝毛先舒撰先舒有聲韻叢說已著錄是編皆其</span>  
<span style="margin-left: 2em">議論之文裒爲一集自序稱讀蘇軾志林稽諸事</span>  
<span style="margin-left: 2em">理時或戾焉因偶爲駁正數叚更取他作之𩔖似</span>  
<span style="margin-left: 2em">者併錄之得若干篇名曰匡林則是書立名當爲</span>  
<!-- 册3 葉3088a　Page:文淵閣四庫全書_0003冊.djvu/777 -->
<span style="margin-left: 2em">匡正志林之義而與軾辨者僅二三條其餘皆自</span>  
<span style="margin-left: 2em">錄集中雜文與近人辨者然則以裒聚衆作謂之</span>  
<span style="margin-left: 2em">林以力排俗論謂之匡觀其小匡文鈔序以小有</span>  
<span style="margin-left: 2em">所匡爲說可互證也先舒嘗與毛竒齡書戒其詆</span>  
<span style="margin-left: 2em">訶太甚故持論不似竒齡之獷然習尙實似竒齡</span>  
<span style="margin-left: 2em">但竒齡喜談經先舒喜談史竒齡好蔓引典籍先</span>  
<span style="margin-left: 2em">舒好推究事理竒齡好與古人爭先舒好與今人</span>  
<span style="margin-left: 2em">爭耳其中如謂春秋不書𨼆公卽位所以誅平王</span>  
<span style="margin-left: 2em">鄭伯克叚之事罪在叚不在鄭伯齊桓首止之盟</span>  
<!-- 册3 葉3088b　Page:文淵閣四庫全書_0003冊.djvu/777 -->
<span style="margin-left: 2em">定王世子爲大惡皆故爲高論牽引夢與九齡之</span>  
<span style="margin-left: 2em">文以駁艾南英亦頗附會使盡如其題杜詩注之</span>  
<span style="margin-left: 2em">𩔖則善矣</span>  
庸言錄<sub class="note-yuan">無卷數　浙江吳玉墀家藏本</sub>  
<span style="margin-left: 1em">國朝姚際恒撰際恒字善夫徽州人是編乃其隨筆</span>  
<span style="margin-left: 2em">劄記或立標題或不立標題葢猶草創未竟之本</span>  
<span style="margin-left: 2em">際恒生於</span>  
<span style="margin-left: 1em">國朝初多從諸耆宿游故徃徃剽其緒論其說經也</span>  
<span style="margin-left: 2em">如闢圖書之僞則本之黄宗羲闢古文尙書之僞</span>  
<!-- 册3 葉3089a　Page:文淵閣四庫全書_0003冊.djvu/777 -->
<span style="margin-left: 2em">則本之閰若璩闢周禮之僞則本之萬斯同論小</span>  
<span style="margin-left: 2em">學之爲書數則本之毛竒齡而持論彌加恣肆至</span>  
<span style="margin-left: 2em">祖歐陽修趙汝禖之說以周易十翼爲僞書則尤</span>  
<span style="margin-left: 2em">横矣其論學也謂周張程朱皆出於禪亦本同時</span>  
<span style="margin-left: 2em">顔元之論至謂程朱之學不息孔孟之道不著則</span>  
<span style="margin-left: 2em">益悍矣他如詆楊漣左光斗爲深文居功則三朝</span>  
<span style="margin-left: 2em">要典之說也謂曾銑爲無故啟邊釁則嚴嵩之說</span>  
<span style="margin-left: 2em">也謂明世宗當考興獻則張桂之說也亦可謂好</span>  
<span style="margin-left: 2em">爲異論者矣</span>  
<!-- 册3 葉3089b　Page:文淵閣四庫全書_0003冊.djvu/777 -->
筠廊偶筆二卷二筆二卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 1em">國朝宋犖撰犖有滄浪小志已著錄是書皆雜記耳</span>  
<span style="margin-left: 2em">目見聞之事其中如回雁峰考之𩔖亦間資考證</span>  
<span style="margin-left: 2em">然如風風雨雨送春歸一詩向謂乃無名道士所</span>  
<span style="margin-left: 2em">作此獨載爲<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">詩劉廷璣在園雜志又考校字句</span>  
<span style="margin-left: 2em">辨其是非實則明人所刋醒世恒言傳竒中詩不</span>  
<span style="margin-left: 2em">知何以訛傳至是也亦足徵小說之不足憑矣</span>  
二樓紀畧四卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 1em">國朝佟賦偉撰賦偉字靑士襄平人官寜國府知府</span>  
<!-- 册3 葉3092a　Page:文淵閣四庫全書_0003冊.djvu/778 -->
<span style="margin-left: 2em">寜國舊有北樓卽南齊謝朓之高齋明嘉靖中知</span>  
<span style="margin-left: 2em">府朱大器又起文昌臺設書院其下賦偉更爲修</span>  
<span style="margin-left: 2em">治題曰南樓毎乘暇遊晏其間因雜錄見聞爲此</span>  
<span style="margin-left: 2em">書多自述其政績及旁渉他事不盡有關於二樓</span>  
<span style="margin-left: 2em">旣非地志又非說部九流之内無𩔖可歸姑附之</span>  
<span style="margin-left: 2em">雜家𩔖焉</span>  
介軒遺筆二卷<sub class="note-yuan">江西廵撫採進本</sub>  
<span style="margin-left: 1em">國朝史旣濟撰旣濟字若川鄱陽人是編皆隨筆記</span>  
<span style="margin-left: 2em">錄多誌其家世本末及江右近事間及經史亦罕</span>  
<!-- 册3 葉3092b　Page:文淵閣四庫全書_0003冊.djvu/778 -->
<span style="margin-left: 2em">所考據發明</span>  
復堂雜說一卷<sub class="note-yuan">江西廵撫採進本</sub>  
<span style="margin-left: 1em">國朝史白撰白字堅又鄱陽人書中皆雜論經史之</span>  
<span style="margin-left: 2em">語其解易卦多尙互體頗能復古其餘皆習見之</span>  
<span style="margin-left: 2em">語首尾僅四十餘則葢其隨筆劄記而後人抄撮</span>  
<span style="margin-left: 2em">成帙者也</span>  
竹村雜記二卷<sub class="note-yuan">江西廵撫採進本</sub>  
<span style="margin-left: 1em">國朝史白撰亦復堂雜說之𩔖而條目稍多其中謂</span>  
<span style="margin-left: 2em">左傳國語非一人所作引黄池之會左氏作先晉</span>  
<!-- 册3 葉3093a　Page:文淵閣四庫全書_0003冊.djvu/778 -->
<span style="margin-left: 2em">人國語作吳公先歃爲證頗能得間解壹發五豝</span>  
<span style="margin-left: 2em">以中必叠雙爲誤解朝隮于西以朱註作雨止爲</span>  
<span style="margin-left: 2em">誤亦頗見疏剔至謂桎梏而死爲桎梏於人欲則</span>  
<span style="margin-left: 2em">殊失之穿鑿其他亦不能一一精<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">也</span>  
山志六卷<sub class="note-yuan">江蘇周厚堉家藏本</sub>
