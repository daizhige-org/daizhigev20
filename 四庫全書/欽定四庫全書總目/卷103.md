## 欽定四庫全書總目 卷一百三　子部十三　醫家類一

<!-- 册3 葉788：整葉圖版，無文字記錄 -->
<!-- 册3 葉789a　Page:文淵閣四庫全書_0003冊.djvu/202 -->
欽定四庫全書總目卷一百三  
<span style="margin-left: 1em">子部十三</span>  
<span style="margin-left: 2em">醫家𩔖一</span>  
<span style="margin-left: 3em">儒之門戸分於宋醫之門戸分於金元觀元好</span>  
<span style="margin-left: 3em">問傷寒會要序知河間之學與易水之學爭觀</span>  
<span style="margin-left: 3em">戴良作朱震亨傳知丹溪之學與宣和局方之</span>  
<span style="margin-left: 3em">學爭也然儒有定理而醫無定法病情萬變難</span>  
<span style="margin-left: 3em">守一宗故今所叙錄兼衆說焉明制定醫院十</span>  
<span style="margin-left: 3em">三科頗爲繁碎而諸家所著徃徃以一書兼數</span>  
<!-- 册3 葉789b　Page:文淵閣四庫全書_0003冊.djvu/202 -->
<span style="margin-left: 3em">科分𨽻爲難今通以時代爲次漢志醫經經方</span>  
<span style="margin-left: 3em">二家後有房中神仙二家後人誤讀爲一故服</span>  
<span style="margin-left: 3em">餌導引歧塗頗雜今悉刪除周禮有獸醫隋志</span>  
<span style="margin-left: 3em">載治馬經等九家雜列醫書間今從其例附錄</span>  
<span style="margin-left: 3em">此門而退置於末簡貴人賤物之義也太素脉</span>  
<span style="margin-left: 3em">法不關治療今别收入術數家茲不著錄</span>  
黄帝素問二十四卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">唐王冰注漢書藝文志載黄帝内經十八篇無素</span>  
<span style="margin-left: 2em">問之名後漢張機傷寒論引之始稱素問晉皇甫</span>  
<!-- 册3 葉792a　Page:文淵閣四庫全書_0003冊.djvu/203 -->
<span style="margin-left: 2em">謐甲乙經序稱鍼經九卷素問九卷皆爲内經與</span>  
<span style="margin-left: 2em">漢志十八篇之數合則素問之名起於漢晉間矣</span>  
<span style="margin-left: 2em">故隋書經籍志始著錄也然隋志所載祗八卷全</span>  
<span style="margin-left: 2em">元起所注已闕其第七冰爲寳應中人乃自謂得</span>  
<span style="margin-left: 2em">舊藏之本補足此卷宋林億等校正謂天元紀大</span>  
<span style="margin-left: 2em">論以下卷帙獨多與素問餘篇絶不相通疑卽張</span>  
<span style="margin-left: 2em">機傷寒論序所稱陰陽大論之文冰取以補所亡</span>  
<span style="margin-left: 2em">之卷理或然也其刺法論本病論則冰本亦闕不</span>  
<span style="margin-left: 2em">能復補矣冰本頗更其篇次然每篇之下必注全</span>  
<!-- 册3 葉792b　Page:文淵閣四庫全書_0003冊.djvu/203 -->
<span style="margin-left: 2em">元起本第幾字猶可考見其舊第所注排抉隠奥</span>  
<span style="margin-left: 2em">多所發明其稱大𤍠而甚寒之不寒是無水也大</span>  
<span style="margin-left: 2em">寒而甚𤍠之不𤍠是無火也無火者不必去水宜</span>  
<span style="margin-left: 2em">益火之源以消陰翳無水者不必去火宜壯水之</span>  
<span style="margin-left: 2em">主以鎮陽光遂開明代薛已諸人探本命門之一</span>  
<span style="margin-left: 2em">法其亦深於醫理者矣冰名見新唐書宰相世系</span>  
<span style="margin-left: 2em">表稱爲京兆府參軍林億等引人物志謂冰爲太</span>  
<span style="margin-left: 2em">僕令未知孰是然醫家皆稱王太僕習讀億書也</span>  
<span style="margin-left: 2em">其名晁公武讀書志作王砅杜甫集有贈重表姪</span>  
<!-- 册3 葉793a　Page:文淵閣四庫全書_0003冊.djvu/203 -->
<span style="margin-left: 2em">王砅詩亦復相合然唐宋志皆作冰而世傳宋槧</span>  
<span style="margin-left: 2em">本亦作冰字或公武因杜甫詩而誤歟</span>  
靈樞經十二卷<sub class="note-yuan">大埋寺卿陸錫熊家藏本</sub>  
<span style="margin-left: 2em">案晁公武讀書志曰王冰謂靈樞卽漢志黄帝内</span>  
<span style="margin-left: 2em">經十八卷之九或謂好事者於皇甫謐所集内經</span>  
<span style="margin-left: 2em">倉公論中鈔出之名爲古書未知孰是又李濂醫</span>  
<span style="margin-left: 2em">史載元吕復羣經古方論曰内經靈樞漢隋唐志</span>  
<span style="margin-left: 2em">皆不錄隋有鍼經九卷唐有靈寳註及黄帝九靈</span>  
<span style="margin-left: 2em">經十二卷而已或謂王冰以九靈更名爲靈樞又</span>  
<!-- 册3 葉793b　Page:文淵閣四庫全書_0003冊.djvu/203 -->
<span style="margin-left: 2em">謂九靈尤詳於鍼故皇甫謐名之爲鍼經苟一經</span>  
<span style="margin-left: 2em">而二名不應唐志别出鍼經十二卷是靈樞不及</span>  
<span style="margin-left: 2em">素問之古宋元人已言之矣近時杭世駿道古堂</span>  
<span style="margin-left: 2em">集亦有靈樞經跋曰七畧漢藝文志黄帝内經十</span>  
<span style="margin-left: 2em">八篇皇甫謐以鍼經九卷素問九卷合十八篇當</span>  
<span style="margin-left: 2em">之隋書經籍志鍼經九卷黄帝九靈十二卷是九</span>  
<span style="margin-left: 2em">靈自九靈鍼經自鍼經不可合而爲一也王冰以</span>  
<span style="margin-left: 2em">九靈名靈樞不知其何所本余觀其文義淺短與</span>  
<span style="margin-left: 2em">素問之言不𩔖又似籍取素問而鋪張之其爲王</span>  
<!-- 册3 葉796a　Page:文淵閣四庫全書_0003冊.djvu/204 -->
<span style="margin-left: 2em">冰所僞託可知後人莫有傳其書者至宋紹興中</span>  
<span style="margin-left: 2em">錦官史崧乃云家藏舊本靈樞九卷除已具狀經</span>  
<span style="margin-left: 2em">所屬申明外准使府指揮依條申轉運司選官詳</span>  
<span style="margin-left: 2em">定其書送秘書省國子監是此書至宋中世而始</span>  
<span style="margin-left: 2em">出未經高保衡林億等校定也其中十二經水一</span>  
<span style="margin-left: 2em">篇黄帝時無此名冰特據身所見而妄臆度之云</span>  
<span style="margin-left: 2em">云其考證尤爲明晳然李杲精究醫理而使羅天</span>  
<span style="margin-left: 2em">益作𩔖經兼採素問靈樞吕復亦稱善學者當與</span>  
<span style="margin-left: 2em">素問並觀其㫖義互相發明葢其書雖僞而其言</span>  
<!-- 册3 葉796b　Page:文淵閣四庫全書_0003冊.djvu/204 -->
<span style="margin-left: 2em">則綴合古經具有源本譬之梅𦣱古文雜採逸書</span>  
<span style="margin-left: 2em">聯成篇目雖牴牾罅漏贋託顯然而先王遺訓多</span>  
<span style="margin-left: 2em">頼其蒐輯以有傳不可廢也此本前有紹興乙亥</span>  
<span style="margin-left: 2em">史崧序稱舊本九卷八十一篇增修音釋附於卷</span>  
<span style="margin-left: 2em">末又目錄首題鼇峯熊宗立<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）">校重刋末題原二</span>  
<span style="margin-left: 2em">十四卷今併爲十二卷是此本爲熊氏重刋所併</span>  
<span style="margin-left: 2em">吕復稱史崧併是書爲十二卷以復其舊殆誤以</span>  
<span style="margin-left: 2em">熊本爲史本歟</span>  
難經本義二卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<!-- 册3 葉797a　Page:文淵閣四庫全書_0003冊.djvu/204 -->
<span style="margin-left: 2em">周秦越人撰元滑壽註越人卽扁鵲事迹具史記</span>  
<span style="margin-left: 2em">本傳壽字伯仁明史方技傳稱爲許州人寄居鄞</span>  
<span style="margin-left: 2em">縣案朱右攖寜生傳曰世爲許州襄城大家元初</span>  
<span style="margin-left: 2em">祖父官江南自許徙儀真而壽生焉又曰在淮南</span>  
<span style="margin-left: 2em">曰滑壽在吳曰伯仁氏在鄞越曰攖寜生然則許</span>  
<span style="margin-left: 2em">乃祖贯鄞乃寄居實則儀真人也壽卒於明洪武</span>  
<span style="margin-left: 2em">中故明史列之方技傳然戴良九靈山房集有懷</span>  
<span style="margin-left: 2em">滑攖寜詩曰海日蒼凉兩𩯭絲異鄉飄泊已多時</span>  
<span style="margin-left: 2em">欲爲散木居官道故託長桑說上池蜀客著書人</span>  
<!-- 册3 葉797b　Page:文淵閣四庫全書_0003冊.djvu/204 -->
<span style="margin-left: 2em">豈識韓公賣藥世偏知道塗同是傷心者只合相</span>  
<span style="margin-left: 2em">從賦黍離則壽亦抱節之遺老託於醫以自逃耳</span>  
<span style="margin-left: 2em">是書首有張翥序稱壽家去東垣近早傳李杲之</span>  
<span style="margin-left: 2em">學攖寜生傳則稱學醫於京口王居中學鍼法於</span>  
<span style="margin-left: 2em">東平高洞陽考李杲足迹未至江南與壽時代亦</span>  
<span style="margin-left: 2em">不相及翥所云云殆因許近東明附會其說歟難</span>  
<span style="margin-left: 2em">經八十一篇漢藝文志不載隋唐志始載難經二</span>  
<span style="margin-left: 2em">卷秦越人著吳太醫令吕廣嘗註之則其文當出</span>  
<span style="margin-left: 2em">三國前廣書今不傳未審卽此本否然唐張守節</span>  
<!-- 册3 葉800a　Page:文淵閣四庫全書_0003冊.djvu/205 -->
<span style="margin-left: 2em">註史記扁鵲列傳所引難經悉與今合則今書猶</span>  
<span style="margin-left: 2em">古本矣其曰難經者謂經文有疑各設問難以明</span>  
<span style="margin-left: 2em">之其中有此稱經云而素問靈樞無之者則今本</span>  
<span style="margin-left: 2em">内經傳寫脫簡也其文辨析精微詞致簡遠讀者</span>  
<span style="margin-left: 2em">不能遽曉故厯代醫家多有註釋壽所採摭凡十</span>  
<span style="margin-left: 2em">一家今惟壽書傳於世其書首列彚考一篇論書</span>  
<span style="margin-left: 2em">之名義源流次列闕誤總𩔖一篇記脫文誤字又</span>  
<span style="margin-left: 2em">次圖說一篇皆不入卷數其註則融會諸家之說</span>  
<span style="margin-left: 2em">而以已意折衷之辨論精核考証亦極詳審攖寜</span>  
<!-- 册3 葉800b　Page:文淵閣四庫全書_0003冊.djvu/205 -->
<span style="margin-left: 2em">生傳稱難經本靈樞素問之㫖設難釋義其間榮</span>  
<span style="margin-left: 2em">衛部位藏府脉法與夫經絡腧穴辨之博矣而闕</span>  
<span style="margin-left: 2em">誤或多愚將本其指義註而讀之卽此本也壽本</span>  
<span style="margin-left: 2em">儒者能通解古書文義故其所註視他家所得爲</span>  
<span style="margin-left: 2em">多云</span>  
甲乙經八卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">晉皇甫謐撰謐有高士傳已著錄是編皆論鍼灸</span>  
<span style="margin-left: 2em">之道隋書經籍志稱黄帝甲乙經十卷註曰音一</span>  
<span style="margin-left: 2em">卷梁十二卷不著撰人姓名考此書首有謐自序</span>  
<!-- 册3 葉801a　Page:文淵閣四庫全書_0003冊.djvu/205 -->
<span style="margin-left: 2em">稱七畧藝文志黄帝内經十八卷今有鍼經九卷</span>  
<span style="margin-left: 2em">素問九卷二九十八卷卽内經也又有明堂孔穴</span>  
<span style="margin-left: 2em">鍼灸治要皆黄帝岐伯選事也三部同歸文多重</span>  
<span style="margin-left: 2em">複錯互非一甘露中吾病風加苦聾百日方治<sub class="note-yuan">案此</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">四字文義未明疑有脫誤今仍舊本錄之謹附識於此</sub>要皆淺近乃撰集三</span>  
<span style="margin-left: 2em">部使事𩔖相從刪其浮詞除其重複至爲十二卷</span>  
<span style="margin-left: 2em"><sub class="note-yuan">案至字文義末明亦疑有誤</sub>云云是此書乃裒合舊文而成故</span>  
<span style="margin-left: 2em">隋志冠以黄帝然刪除謐名似乎黄帝所自作則</span>  
<span style="margin-left: 2em">於文爲謬舊唐書經籍志稱黄帝三部針經十三</span>  
<!-- 册3 葉801b　Page:文淵閣四庫全書_0003冊.djvu/205 -->
<span style="margin-left: 2em">卷始著謐名然較梁本多一卷其併音一卷計之</span>  
<span style="margin-left: 2em">歟新唐書藝文志旣有黄帝甲乙經十二卷又有</span>  
<span style="margin-left: 2em">皇甫謐黄帝三部針經十三卷兼襲二志之文則</span>  
<span style="margin-left: 2em">更舛誤矣書凡一百一十八篇内十二經脉絡脉</span>  
<span style="margin-left: 2em">支别篇疾形脉診篇鍼灸禁忌篇五藏傳病發寒</span>  
<span style="margin-left: 2em">𤍠篇陰受病發痺篇陽受病發痺篇各分上下經</span>  
<span style="margin-left: 2em">脉篇六經受病發傷寒𤍠病篇各分上中下實一</span>  
<span style="margin-left: 2em">百二十八篇句中夾注多引楊上逹太素經孫思</span>  
<span style="margin-left: 2em">邈千金方王冰素問注王惟德銅人圖參考異同</span>  
<!-- 册3 葉804a　Page:文淵閣四庫全書_0003冊.djvu/206 -->
<span style="margin-left: 2em">其書皆在謐後葢宋高保衡孫奇林億等校正所</span>  
<span style="margin-left: 2em">加非謐之舊也考隋志有明堂孔穴五卷明堂孔</span>  
<span style="margin-left: 2em">穴圖三卷又明堂孔穴圖三卷唐志有黄帝内經</span>  
<span style="margin-left: 2em">明堂十三卷黄帝十二經脉明堂五臟圖一卷黄</span>  
<span style="margin-left: 2em">帝十二經明堂偃側人圖十二卷黄帝明堂三卷</span>  
<span style="margin-left: 2em">又楊上善黄帝内經明堂𩔖成十三卷楊元孫黄</span>  
<span style="margin-left: 2em">帝明堂三卷今併亡佚惟頼是書存其精要且節</span>
