欽定四庫全書總目卷五十三  
<span style="margin-left: 1em">史部九</span>  
<span style="margin-left: 2em">雜史類存目二</span>  
三朝聖諭錄三卷<sub class="note-yuan">左都御史張若溎家藏本</sub>  
<span style="margin-left: 2em">明楊士奇撰士奇名寓以字行泰和人建文中充</span>  
<span style="margin-left: 2em">翰林編修官燕王簒立入内閣典機務官至華葢</span>  
<span style="margin-left: 2em">殿大學士諡文貞事迹具明史本傳士奇自降附</span>  
<span style="margin-left: 2em">燕王以後厯事仁宗宣宗英宗以功名終始是編</span>  
<span style="margin-left: 2em">乃自錄其永樂洪熙宣德三朝面承詔旨及奏對</span>  
<!-- 册2 葉729b　Page:文淵閣四庫全書_0002冊.djvu/187 -->
<span style="margin-left: 2em">之語葢仿歐陽修奏事錄司馬光手錄之例明史</span>  
<span style="margin-left: 2em">士奇本傳多採用之序題壬戌十二月爲正統七</span>  
<span style="margin-left: 2em">年乃士奇未卒之前二年也</span>  
天順曰錄一卷<sub class="note-yuan">浙江汪啓淑家藏本</sub>  
<span style="margin-left: 2em">明李賢撰賢字原德鄧州人宣德癸丑進士景泰</span>  
<span style="margin-left: 2em">初由文選郞中超拜兵部右侍郞轉吏部英宗復</span>  
<span style="margin-left: 2em">位兼翰林學士入<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">文淵閣厯官華葢殿大學士</span>  
<span style="margin-left: 2em">諡文達事迹具明史本傳是錄隨手紀載於天順</span>  
<span style="margin-left: 2em">時事頗詳史稱自三楊以來得君無如賢者然自</span>  
<!-- 册2 葉732a　Page:文淵閣四庫全書_0002冊.djvu/188 -->
<span style="margin-left: 2em">郞署結知景帝超擢侍郞而所著書顧謂景帝爲</span>  
<span style="margin-left: 2em">𮎰淫今觀此錄於景帝一則曰𮎰淫失度再則曰</span>  
<span style="margin-left: 2em">流於𮎰淫毁詆頗爲失實史之所譏葢卽指此又</span>  
<span style="margin-left: 2em">謂學士王文與太監王誠謀取襄王子爲東宮冒</span>  
<span style="margin-left: 2em">平侯楊洪不急君父之難當寇薄宣府驚惶無措</span>  
<span style="margin-left: 2em">閉門不出頗與正史不合至於葉盛岳正羅倫諸</span>  
<span style="margin-left: 2em">人之事諱而不言其他事亦槩未紀及皆未免愛</span>  
<span style="margin-left: 2em">憎之見然曰久論定是非亦曷可掩也</span>  
否泰錄一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<!-- 册2 葉732b　Page:文淵閣四庫全書_0002冊.djvu/188 -->
<span style="margin-left: 2em">明劉定之撰定之有易經圖釋已著錄初英宗北</span>  
<span style="margin-left: 2em">狩額森<sub class="note-yuan">案額森原作也先今改正</sub>乞遣報使景帝不許定之疏</span>  
<span style="margin-left: 2em">引故事以請帝下廷議竟不果遣天順改元定之</span>  
<span style="margin-left: 2em">由右庶子調通政使厯官翰林學士入<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">文淵閣</span>  
<span style="margin-left: 2em">葢以是疏𫎇遇也此書所紀卽英宗北狩之事自</span>  
<span style="margin-left: 2em">言參用楊善奉使錄曁錢博所述袁彬傳其曰出</span>  
<span style="margin-left: 2em">征之月爲否卦用事之月囘鑾之年當景泰紀元</span>  
<span style="margin-left: 2em">之年先以否繼以泰雖世運而關天數焉葢所記</span>  
<span style="margin-left: 2em">訖於英宗初歸之時未敘及後來丁丑復辟之事</span>  
<!-- 册2 葉733a　Page:文淵閣四庫全書_0002冊.djvu/188 -->
<span style="margin-left: 2em">故其立言如此其曰身備史官者正其遷右庶子</span>  
<span style="margin-left: 2em">時他書引此或作閣老劉定之撰者據其所終之</span>  
<span style="margin-left: 2em">官言之耳</span>  
朝鮮紀事一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明倪謙撰謙字克讓錢塘人徙上元正統已未進</span>  
<span style="margin-left: 2em">士官至南京禮部尚書諡文僖是編乃景泰元年</span>  
<span style="margin-left: 2em">謙奉使朝鮮頒詔紀行之作自鴨綠江至王城計</span>  
<span style="margin-left: 2em">一千一百七十里所厯賓館凡二十有八語意草</span>  
<span style="margin-left: 2em">畧無足以資考證時朝鮮國王世子並稱疾不迎</span>  
<!-- 册2 葉733b　Page:文淵閣四庫全書_0002冊.djvu/188 -->
<span style="margin-left: 2em">詔謙爭之不得亦無如之何葢新有土木之變正</span>  
<span style="margin-left: 2em">國勢危疑之日也亦足見明之積弱雖至近而令</span>  
<span style="margin-left: 2em">亦不行矣</span>  
南征錄一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明張瑄撰瑄字延璽江浦人正統壬戌進士官至</span>  
<span style="margin-left: 2em">南京刑部尚書是編乃天順八年瑄爲廣西右布</span>  
<span style="margin-left: 2em">政使時値廣西諸洞蠻搆廣東肇高雷連土寇爲</span>  
<span style="margin-left: 2em">亂遣左㕘將范信都指揮徐寧督官兵四千士兵</span>  
<span style="margin-left: 2em">一萬討之以瑄監其軍瑄因述其征𠞰始末爲此</span>  
<!-- 册2 葉736a　Page:文淵閣四庫全書_0002冊.djvu/189 -->
<span style="margin-left: 2em">書始於是年正月初二日止於三月初九日按日</span>  
<span style="margin-left: 2em">紀載所述當日軍政殊無紀律葢明人積弱自其</span>  
<span style="margin-left: 2em">盛時已然非一朝一夕之故矣</span>  
出使錄一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">一名使北錄明李實撰實字孟誠合州人正統壬</span>  
<span style="margin-left: 2em">戌進士官至右都御史以居鄉暴橫斥爲民事迹</span>  
<span style="margin-left: 2em">附見明史楊善傳景泰初澦森議和朝議遣使報</span>  
<span style="margin-left: 2em">之實時爲禮科給事中自請行乃權爲禮部右侍</span>  
<span style="margin-left: 2em">郞偕少卿羅綺往使頗得額森要領及楊善再往</span>  
<!-- 册2 葉736b　Page:文淵閣四庫全書_0002冊.djvu/189 -->
<span style="margin-left: 2em">遂奉英宗南還此乃所紀在漠北見英宗及與額</span>  
<span style="margin-left: 2em">森辨論之語史稱實謁上皇請還京引咎自責失</span>  
<span style="margin-left: 2em">上皇意而錄中乃云實以上昔任用非人當謙遜</span>  
<span style="margin-left: 2em">避位之理懇切應對上喜從之與史不合葢英宗</span>  
<span style="margin-left: 2em">急於求返陽諾而陰憾之實未之覺也</span>  
東征紀行錄一卷<sub class="note-yuan">左都御史張若溎家藏本</sub>  
<span style="margin-left: 2em">明張瓚撰瓚字宗器孝感人正統戊辰進士官至</span>  
<span style="margin-left: 2em">總督漕運左副都御史事迹具明史本傳瓚爲四</span>  
<span style="margin-left: 2em">川巡撫時以播州宣慰司楊輝言所屬夭壩干灣</span>  
<!-- 册2 葉737a　Page:文淵閣四庫全書_0002冊.djvu/189 -->
<span style="margin-left: 2em">溪寨及重安長官司爲生苗竊據率兵討平之此</span>  
<span style="margin-left: 2em">書所錄乃其自重慶啓行迄於班師之事起成化</span>  
<span style="margin-left: 2em">十二年丙申十月終次年丁酉正月凡一百三日</span>  
<span style="margin-left: 2em">皆排日紀載間附以所作詩句明史瓚傳載此事</span>  
<span style="margin-left: 2em">在成化十年與此書互異然此書爲瓚所自記年</span>  
<span style="margin-left: 2em">月必無舛誤也史又稱瓚功名著西蜀其後撫蜀</span>  
<span style="margin-left: 2em">者如謝士元輩雖有名不及瓚惟天壩干之役或</span>  
<span style="margin-left: 2em">言楊輝溺愛少子友欲官之詐言生苗爲亂瓚信</span>  
<span style="margin-left: 2em">而興師其功不無矯飾今觀錄中所記瓚但駐於</span>  
<!-- 册2 葉737b　Page:文淵閣四庫全書_0002冊.djvu/189 -->
<span style="margin-left: 2em">黃平居中調度實未督兵親行或出於所屬之妄</span>  
<span style="margin-left: 2em">報瓚不審核遽以入吿歟此則當以史文爲據不</span>  
<span style="margin-left: 2em">以所自記者爲據矣</span>  
馬端肅三記三卷<sub class="note-yuan">戸部尚書王際華家藏本</sub>  
<span style="margin-left: 2em">明馬文升撰文升字負圖鈞州人景泰辛未進士</span>  
<span style="margin-left: 2em">官至兵部尚書加少師太子太師端肅其諡也事</span>  
<span style="margin-left: 2em">蹟具明史本傳此三篇皆所自述一日西征石城</span>  
<span style="margin-left: 2em">記紀成化初爲陜西巡撫與項忠平滿四之亂事</span>  
<span style="margin-left: 2em">一日撫安遼東記紀成化十四年遼東巡撫陳銊</span>  
<!-- 册2 葉740a　Page:文淵閣四庫全書_0002冊.djvu/190 -->
<span style="margin-left: 2em">冒功激變而文升奉命撫定之事一日興復哈密</span>  
<span style="margin-left: 2em">記紀宏治初土魯番襲執哈密忠順王而文升持</span>  
<span style="margin-left: 2em">議用兵遣許進等討平之事三記本在文升所著</span>  
<span style="margin-left: 2em">集中此其析出别行之本也</span>  
<span style="margin-left: 4em">案三記皆文升所自述宜入傳記類中然三</span>  
<span style="margin-left: 4em">事皆明代大征伐文升特董其役耳實朝廷</span>  
<span style="margin-left: 4em">之事非文升一人之事也故仍𨽻之雜史類</span>  
<span style="margin-left: 4em">焉</span>  
復辟錄一卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<!-- 册2 葉740b　Page:文淵閣四庫全書_0002冊.djvu/190 -->
<span style="margin-left: 2em">明楊暄撰暄字廷獻豐城人景泰甲戌進士官至</span>  
<span style="margin-left: 2em">浙江按察使當徐有貞等奪門時暄官御史事皆</span>  
<span style="margin-left: 2em">目覩又嘗劾曹吉祥石亨坐譴論戍於二人事迹</span>  
<span style="margin-left: 2em">知之尤悉故其辨于謙王文之被誣石亨曹吉祥</span>  
<span style="margin-left: 2em">之恣肆皆與史合後附李賢天順日錄祝允明蘇</span>  
<span style="margin-left: 2em">材小纂陳循辨寃疏葉盛水東日記王瓊雙溪雜</span>  
<span style="margin-left: 2em">記數條蓋皆同時親與其事者故引以爲據明所</span>  
<span style="margin-left: 2em">述之不誣云</span>  
平蠻錄一卷<sub class="note-yuan">左都御史張若溎家藏本</sub>  
<!-- 册2 葉741a　Page:文淵閣四庫全書_0002冊.djvu/190 -->
<span style="margin-left: 2em">明王軾撰軾字用敬公安人天順甲申進士官至</span>  
<span style="margin-left: 2em">南京兵部尙書㕘贊機務諡襄簡事迹具明史本</span>  
<span style="margin-left: 2em">傳史稱軾於宏治十三年督貴州軍討普安賊婦</span>  
<span style="margin-left: 2em">米魯用兵五月破賊砦千餘盡平其地是編所錄</span>  
<span style="margin-left: 2em">卽其奏㨗之疏也</span>  
北征事蹟一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明袁彬撰彬字文質江西新昌人以錦衣衛校尉</span>  
<span style="margin-left: 2em">從英宗北狩䕶蹕南歸官至掌錦衣衛都督僉事</span>  
<span style="margin-left: 2em">莅前軍都督府事迹具明史本傳是編乃憲宗初</span>  
<!-- 册2 葉741b　Page:文淵閣四庫全書_0002冊.djvu/190 -->
<span style="margin-left: 2em">年詔詢從行事蹟彬具述本末上之宣付史館書</span>  
<span style="margin-left: 2em">中首尾皆用題本之式末有成化元年七月二十</span>  
<span style="margin-left: 2em">日所奉諭㫖葢卽當時錄進本也所述與劉定之</span>  
<span style="margin-left: 2em">否泰錄大略相似然有否泰錄所載而是書闕者</span>  
<span style="margin-left: 2em">亦間有互異者如否泰錄有正統十四年十一月</span>  
<span style="margin-left: 2em">二十三日額森遣使求索大臣迎駕及景泰元年</span>  
<span style="margin-left: 2em">正月初七日英宗書至求索大臣來迎二事此書</span>  
<span style="margin-left: 2em">皆未載又否泰錄稱天順元年七月初一日李實</span>  
<span style="margin-left: 2em">羅綺馬顯等至額森營十三日見英宗而是書載</span>  
<!-- 册2 葉744a　Page:文淵閣四庫全書_0002冊.djvu/191 -->
<span style="margin-left: 2em">在五月内明史本紀則載在六月其他與明史異</span>  
<span style="margin-left: 2em">者若喜寧等燒毁紫荆關殺都御史孫祥事此書</span>  
<span style="margin-left: 2em">在正統十四年九月而明史則在十月彬日侍英</span>  
<span style="margin-left: 2em">宗左右其見聞當獨眞而所記與他書輒有異同</span>  
<span style="margin-left: 2em">豈其書上於成化元年距從征之年前後凡十七</span>  
<span style="margin-left: 2em">載諸所記憶或有疑關歟千頃堂書目載此書云</span>  
<span style="margin-left: 2em">一作尹宣撰未知何據似不然也</span>  
正統臨戎錄一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">不著撰人名氏記明英宗北狩始末考明史藝文</span>
