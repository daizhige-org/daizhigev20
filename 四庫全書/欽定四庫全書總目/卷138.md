## 欽定四庫全書總目 卷一百三十八　子部四十八　類書類存目二

<!-- 册3 葉3636：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷一百三十八  
<span style="margin-left: 1em">子部四十八</span>  
<span style="margin-left: 2em">𩔖書𩔖存目二</span>  
續文獻通考二百五十四卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">明王圻撰圻有東吳水利考巳著錄是編續馬端</span>  
<span style="margin-left: 2em">臨之書而稍更其門目大㫖欲於通考之外兼擅</span>  
<span style="margin-left: 2em">通志之長遂致牽於多岐轉成踳駮葢通考踵通</span>  
<span style="margin-left: 2em">典而作數典之書也通志具列朝爲紀傳其畧卽</span>  
<span style="margin-left: 2em">志其譜卽表通史之屬也其體裁本不相同圻旣</span>  
<!-- 册3 葉3637b　Page:文淵閣四庫全書_0003冊.djvu/914 -->
<span style="margin-left: 2em">兼用鄭例遂收及人物巳爲泛濫而分條標目又</span>  
<span style="margin-left: 2em">復治絲而棼如各史有不臣二姓之人不過統以</span>  
<span style="margin-left: 2em">忠義圻則别立忠𨼆一門各史於忠孝節烈之婦</span>  
<span style="margin-left: 2em">女不過統以列女圻則别立忠婦孝婦節婦烈婦</span>  
<span style="margin-left: 2em">諸門各史於篤行畸節不過統以孝義圻則别立</span>  
<span style="margin-left: 2em">順孫義夫義女義徒義母義妾義僕諸門均乖史</span>  
<span style="margin-left: 2em">法至於義物一門孝釋一門尤爲創見罕聞各史</span>  
<span style="margin-left: 2em">但有儒林宋史别出道學傳巳爲門戸之私圻更</span>  
<span style="margin-left: 2em">立道統考而所收如楚元王之𩔖不過性喜聚書</span>  
<!-- 册3 葉3640a　Page:文淵閣四庫全書_0003冊.djvu/915 -->
<span style="margin-left: 2em">范平王接之𩔖不過𨼆居高尙去取更爲不倫此</span>  
<span style="margin-left: 2em">皆牽於通志紀傳之故也他如旧賦考内所載免</span>  
<span style="margin-left: 2em">租當列於脈恤門貴州鹽引課宜列於鹽鐵門打</span>  
<span style="margin-left: 2em">靑草喂養馬匹事例宜列於兵考而皆誤載於田</span>  
<span style="margin-left: 2em">賦國用考内漕運門載金天興元年運餉汝州兵</span>  
<span style="margin-left: 2em">此乃用兵轉餉非漕運也又海運巳自列一門而</span>  
<span style="margin-left: 2em">雜出於漕運之内所載海道遠近尤爲不詳運官</span>  
<span style="margin-left: 2em">選補屬選舉考績之事更不當列於漕運門土貢</span>  
<span style="margin-left: 2em">考内所載明制其時雖已歸折於一條鞭之法然</span>  
<!-- 册3 葉3640b　Page:文淵閣四庫全書_0003冊.djvu/915 -->
<span style="margin-left: 2em">尙有解赴内府之項載於明會典者甚詳乃皆脫</span>  
<span style="margin-left: 2em">畧選舉考内所載邵元節李孜省乃一時思倖不</span>  
<span style="margin-left: 2em">當别立方伎選舉一門學校考内所載州縣書院</span>  
<span style="margin-left: 2em">元制官置山長猶屬學校之支流明則處處私置</span>  
<span style="margin-left: 2em">志書尙不能悉登此書乃泛載之殊爲冗濫職官</span>  
<span style="margin-left: 2em">考内載元職官僅本元史其上京分署載於析津</span>  
<span style="margin-left: 2em">志諸書甚詳見元人集者尤夥乃皆漏畧諡法考</span>  
<span style="margin-left: 2em">祗引史記餘多挂漏卽朱謀㙔所輯諸篇萬厯初</span>  
<span style="margin-left: 2em">尙存不容嘉靖末不見亦爲挂漏經籍考内所載</span>  
<!-- 册3 葉3641a　Page:文淵閣四庫全書_0003冊.djvu/915 -->
<span style="margin-left: 2em">南宋諸人文集尙不及文淵閣書目之半金人文</span>  
<span style="margin-left: 2em">集載於中州集小傳者百有餘家所載僅十之一</span>  
<span style="margin-left: 2em">二而琵琶記水滸傳乃俱著錄宜爲後來論者之</span>  
<span style="margin-left: 2em">所譏六書考全抄鄭樵六書畧又錄唐韻及宋禮</span>  
<span style="margin-left: 2em">部韻畧各序毫無斷制所載法帖僅明代所刻寳</span>  
<span style="margin-left: 2em">賢堂帖十數則又旣立經籍考一門復於六書考</span>  
<span style="margin-left: 2em">内複載字學書法各書更爲舛雜至於釋家一門</span>  
<span style="margin-left: 2em">本可不立旣巳立之而宗律二門未能分晰列釋</span>  
<span style="margin-left: 2em">家法嗣一門而二祖六祖以下旁出法嗣又未能</span>  
<!-- 册3 葉3641b　Page:文淵閣四庫全書_0003冊.djvu/915 -->
<span style="margin-left: 2em">詳叙殆進退無據矣自明以來以馬氏書止於宋</span>  
<span style="margin-left: 2em">嘉定中故多存圻書以備檢閲今𫎇</span>  
特詔儒臣重爲纂輯業巳勒有成書圻之舊笈竟以覆  
<span style="margin-left: 2em">瓿可也</span>  
<span style="margin-left: 4em">案此書雖續文獻通考而體例迥殊故文獻</span>  
<span style="margin-left: 4em">通考入故事此則改隷𩔖書</span>  
三才圖會一百六卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">明王圻撰是書彚輯諸書圖譜共爲一編凡天文</span>  
<span style="margin-left: 2em">四卷地理十六卷人物十四卷時令四卷官室四</span>  
<!-- 册3 葉3644a　Page:文淵閣四庫全書_0003冊.djvu/916 -->
<span style="margin-left: 2em">卷器用十二卷身體七卷衣服三卷人事十卷儀</span>  
<span style="margin-left: 2em">制八卷珍寳二卷文史四卷鳥獸六卷草木十二</span>  
<span style="margin-left: 2em">卷采摭浩博亦有足資考核者而務廣貪多冗雜</span>  
<span style="margin-left: 2em">特甚其人物一門繪畫古來名人形像某甲某乙</span>  
<span style="margin-left: 2em">宛如目睹殊非徵信之道如據倉頡四目之說卽</span>  
<span style="margin-left: 2em">畫一靣有四目之人尤近兒戯也</span>  
正音攟言四卷<sub class="note-yuan"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">隷總督採進本</sub>  
<span style="margin-left: 2em">明王荔撰荔字子巖高陽人嘉靖中舉人官至靑</span>  
<span style="margin-left: 2em">州府推官是書以等韻分二十二部而又非韻書</span>  
<!-- 册3 葉3644b　Page:文淵閣四庫全書_0003冊.djvu/916 -->
<span style="margin-left: 2em">如京字部爲第一則云天對地曰對星曉燕對春</span>  
<span style="margin-left: 2em">鶯云云葢鄉塾屬對之本而首標葉向高選鹿善</span>  
<span style="margin-left: 2em">繼閲似乎必無其事其李國𣚴序殆亦贋托也</span>  
亘史鈔<sub class="note-yuan">無卷數　兩江總督採進本</sub>  
<span style="margin-left: 2em">明潘之恒撰之恒有黄海已著錄是書明史藝文</span>  
<span style="margin-left: 2em">志作九十一卷編首顧起元序云内紀内篇以内</span>  
<span style="margin-left: 2em">之而忠孝節義懿行名言之要舉外紀外篇以外</span>  
<span style="margin-left: 2em">之而豪傑奇偉技術艶異山川名勝之事彰雜記</span>  
<span style="margin-left: 2em">雜篇以雜之而草木鳥獸<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">怪𤨏屑恢諧𨼆僻之</span>  
<!-- 册3 葉3645a　Page:文淵閣四庫全書_0003冊.djvu/916 -->
<span style="margin-left: 2em">用列紀以𩔖其事篇以𩔖其言内之目十七外之</span>  
<span style="margin-left: 2em">目三十雜之目三十二爲目七十九爲卷九百九</span>  
<span style="margin-left: 2em">十有六今是編僅存内紀内篇葢殘缺不完之本</span>  
<span style="margin-left: 2em">然體例糅雜編次錯亂其全書已可見一斑矣</span>  
楚騷綺語六卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">明張之象編之象有太史史例已著錄是書摘楚</span>  
<span style="margin-left: 2em">辭字句以供撏撦已爲剽剟之學又參差雜錄於</span>  
<span style="margin-left: 2em">二十五賦不復著出自何篇亦與黃省曾騷苑同</span>  
<span style="margin-left: 2em">一紕陋</span>  
<!-- 册3 葉3645b　Page:文淵閣四庫全書_0003冊.djvu/916 -->
楮記室十五卷<sub class="note-yuan">浙江汪汝瑮家藏本</sub>  
<span style="margin-left: 2em">明潘塤撰塤有淮郡文獻志已著錄是書分天地</span>  
<span style="margin-left: 2em">人三部每部又各分子目大抵抄撮而成冗雜特</span>  
<span style="margin-left: 2em">甚又多附錄前明事實間以委巷之語尤有乖雅</span>  
<span style="margin-left: 2em">馴也</span>  
註釋啟𫎇對偶續編四卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明孟紱撰鄭以誠注紱以誠皆始末未詳其書按</span>  
<span style="margin-left: 2em">韻屬對自一二字至十餘字不等毎韻三則葢鄉</span>  
<span style="margin-left: 2em">塾啟𫎇之本也紱書成於嘉靖中以誠注成於崇</span>  
<!-- 册3 葉3648a　Page:文淵閣四庫全書_0003冊.djvu/917 -->
<span style="margin-left: 2em">禎中前有周燦序謂書稱續編必原有初編而逸</span>  
<span style="margin-left: 2em">之是初刋之時巳非完本矣</span>  
三通政典<sub class="note-yuan">無卷數　江蘇廵撫採進本</sub>  
<span style="margin-left: 2em">不著撰人名氏并不著書名江蘇採進遺書目錄</span>  
<span style="margin-left: 2em">題曰三通政典亦不知何據也其書皆塲屋策料</span>  
<span style="margin-left: 2em">每題爲論一篇篇末或云爲聖明獻爲執事獻其</span>  
<span style="margin-left: 2em">稱明世宗曰今上叙無錫山川人物曰愚也幸生</span>  
<span style="margin-left: 2em">於斯葢嘉靖間無錫人所作也</span>  
𩔖雋三十卷<sub class="note-yuan">内府藏本</sub>  
<!-- 册3 葉3648b　Page:文淵閣四庫全書_0003冊.djvu/917 -->
<span style="margin-left: 2em">明鄭若庸撰若庸字虚舟崑山人少爲諸生以任</span>  
<span style="margin-left: 2em">俠不羈見斥客趙康王厚煜邸中厚煜給以筆札</span>  
<span style="margin-left: 2em">令其倣初學記藝文𩔖聚越二十年而成此書凡</span>  
<span style="margin-left: 2em">分二十門江南通志文苑傳謂若庸爲趙王著書</span>  
<span style="margin-left: 2em">採掇古文竒字累千卷名曰𩔖雋葢未見其書傳</span>  
<span style="margin-left: 2em">聞失實之詞不足據也沈德符敝帚軒剩語謂其</span>  
<span style="margin-left: 2em">書與俞安期唐𩔖函俱有功藝苑安期亦雅慕鄭</span>  
<span style="margin-left: 2em">書以不得見爲恨久之而太學生汪珙者始爲梓</span>  
<span style="margin-left: 2em">行然徵引太簡叙事多不得首尾未足以爲善本</span>  
<!-- 册3 葉3649a　Page:文淵閣四庫全書_0003冊.djvu/917 -->
含元齋别編十卷<sub class="note-yuan">浙江朱<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">尊家曝書亭藏本</sub>  
<span style="margin-left: 2em">明趙樞生撰樞生字彦材徽州人據其子頤光後</span>  
<span style="margin-left: 2em">跋樞生所著諸書皆無錫顧冶排纂成帙有内編</span>  
<span style="margin-left: 2em">外編遺編别編賡編<sub class="note-yuan">案賡古文續字賡編卽續編也</sub>通三十四卷</span>  
<span style="margin-left: 2em">此别編十卷則所纂輯故實也䟦稱分十八門而</span>  
<span style="margin-left: 2em">書中實十九門其次序又與目錄不應殆偶然劄</span>  
<span style="margin-left: 2em">記以備遺忘本無意於著書故事無始末亦不詳</span>  
<span style="margin-left: 2em">其出典後人强爲編次遂餖飣割裂不堪卒讀其</span>  
<span style="margin-left: 2em">最無義理者莫若同仇考一門如云宋眞宗時契</span>  
<!-- 册3 葉3649b　Page:文淵閣四庫全書_0003冊.djvu/917 -->
<span style="margin-left: 2em">丹𫆀律休哥死其年樞宻使兼侍中曹彬亦卒又</span>  
<span style="margin-left: 2em">云帝昺時陸秀夫張世傑負帝死於海其年元西</span>  
<span style="margin-left: 2em">僧八思巴亦死諸如此𩔖竟不解其何意也</span>  
古雋考畧六卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明顧充撰充有字義總畧已著錄是書摘錄古人</span>  
<span style="margin-left: 2em">雋語爲𩔖三十有四附以註釋亦間有考証宋有</span>  
<span style="margin-left: 2em">重刻自跋稱始集古雋於定海學宮鏤板行之而</span>  
<span style="margin-left: 2em">嫌其未備更加增輯云云然究亦未能精核也</span>  
藝圃萃盤錄十卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<!-- 册3 葉3652a　Page:文淵閣四庫全書_0003冊.djvu/918 -->
<span style="margin-left: 2em">是書分𩔖標題各繫以總論葢經生揣摩對策之</span>  
<span style="margin-left: 2em">本卷首題曰丁卯解元用齋周汝礪選戊辰進士</span>  
<span style="margin-left: 2em">貞菴蔣以忠纂丁卯同年養菴蔣以化輯竟不知</span>  
<span style="margin-left: 2em">實出誰手也</span>  
三才考畧十二卷<sub class="note-yuan">江蘇廵撫採進本</sub>  
<span style="margin-left: 2em">明莊元臣撰元臣字忠原歸安人隆慶戊辰進士</span>  
<span style="margin-left: 2em">是書備科舉答策之用分十二門皆摭通典通考</span>
