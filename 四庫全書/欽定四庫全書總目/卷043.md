## 欽定四庫全書總目 卷四十三　經部四十三　小學類存目一

欽定四庫全書總目卷四十三  
<span style="margin-left: 1em">經部四十三</span>  
<span style="margin-left: 2em">小學𩔖存目一</span>  
爾雅補注六卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 1em">國朝姜兆錫撰兆錫有周易本義述藴已著錄是注</span>  
<span style="margin-left: 2em">多以後世文義推測古人之訓詁如釋詁在終也</span>  
<span style="margin-left: 2em">則注曰凡物有定在亦有終竟之意今人云不知</span>  
<span style="margin-left: 2em">所在亦云不知所終又好以意斷制如釋訓子子</span>  
<span style="margin-left: 2em">孫孫三十二句則注曰每語皆以三字約舉其義</span>  
<!-- 册1 葉3561b　Page:文淵閣四庫全書_0001冊.djvu/940 -->
<span style="margin-left: 2em">與經書小序略相似而又皆以韻叶之此等文疑</span>  
<span style="margin-left: 2em">先賢卜氏受詩於聖人而因爲之也云云葢因詩</span>  
<span style="margin-left: 2em">序首句之文而推求及於子夏然考周易象傳全</span>  
<span style="margin-left: 2em">爲此體王逸注楚詞抽思諸篇亦用此體是又安</span>  
<span style="margin-left: 2em">足爲出自子夏之證乎</span>  
小爾雅一卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">案漢書藝文志有小爾雅一篇無撰人名氏隋書</span>  
<span style="margin-left: 2em">經籍志唐書藝文志並載李軌注小爾雅一卷其</span>  
<span style="margin-left: 2em">書久佚今所傳本則孔叢子第十一篇抄出别行</span>  
<!-- 册1 葉3564a　Page:文淵閣四庫全書_0001冊.djvu/941 -->
<span style="margin-left: 2em">者也分廣詁廣言廣訓廣義廣名廣服廣器廣物</span>  
<span style="margin-left: 2em">廣鳥廣獸十章而益以度量衡爲十三章頗可以</span>  
<span style="margin-left: 2em">資考據然亦時有舛迕如廣量云豆四謂之區區</span>  
<span style="margin-left: 2em">四謂之釡木諸春秋傳四升爲豆各自其四以登</span>  
<span style="margin-left: 2em">于釡之文下云釡二有半謂之籔與儀禮十六斗</span>  
<span style="margin-left: 2em">曰籔合其下又云籔二有半謂之缶缶二謂之鍾</span>  
<span style="margin-left: 2em">則實八斛乃春秋傳所謂陳氏新量非齊舊量六</span>  
<span style="margin-left: 2em">斛四斗之鍾是豆釡區用舊量鍾則用新量也廣</span>  
<span style="margin-left: 2em">衡曰兩有半曰㨗倍㨗曰舉倍舉曰鋝公羊傳疏</span>  
<!-- 册1 葉3564b　Page:文淵閣四庫全書_0001冊.djvu/941 -->
<span style="margin-left: 2em">引賈逵稱俗儒以鋝重六兩者葢卽指此使漢代</span>  
<span style="margin-left: 2em">小學遺書果有此語逵必不以俗儒目之矣他如</span>  
<span style="margin-left: 2em">謂鵠中者謂之正則併正鵠之名不辨謂四尺謂</span>  
<span style="margin-left: 2em">之仞則考工記澮深二仞與洫深八尺無異矣漢</span>  
<span style="margin-left: 2em">儒說經皆不援及迨杜預注左傳始稍見徵引明</span>  
<span style="margin-left: 2em">是書漢末晚出至晉始行非漢志所稱之舊本晁</span>  
<span style="margin-left: 2em">公武讀書志以爲孔子古文殆循名而失之相傳</span>  
<span style="margin-left: 2em">已久姑存其目若其文則已見孔叢子不複錄焉</span>  
崔氏小爾雅一卷<sub class="note-yuan">戸部尙書王際華家藏本</sub>  
<!-- 册1 葉3565a　Page:文淵閣四庫全書_0001冊.djvu/941 -->
<span style="margin-left: 2em">舊本題明崔銑撰銑有讀易餘言已著錄此書凡</span>  
<span style="margin-left: 2em">分十篇核檢其文實卽孔叢子中之小爾雅也閔</span>  
<span style="margin-left: 2em">元衢歐餘漫錄曰小爾雅漢孔鮒撰汝郡袁氏金</span>  
<span style="margin-left: 2em">聲玉振集誤爲崔仲鳬著收入撰述部以漢爲本</span>  
<span style="margin-left: 2em">朝以崔易孔豈其不詳考耶抑以世可欺也則是</span>  
<span style="margin-left: 2em">僞題姓名明人已言之矣</span>  
彚雅二十卷續編二十八卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">明張萱撰萱字孟奇博羅人萬厯壬午舉人由中</span>  
<span style="margin-left: 2em">書舍人官至戸部郎中此書每篇皆列爾雅次以</span>  
<!-- 册1 葉3565b　Page:文淵閣四庫全書_0001冊.djvu/941 -->
<span style="margin-left: 2em">小爾雅廣雅方言之屬下載注疏附以萱所自釋</span>  
<span style="margin-left: 2em">亦頗有發明然如釋詁肅延諉薦餤晉寅藎進也</span>  
<span style="margin-left: 2em">郭注寅未詳萱於他注義未詳者無所證據而晉</span>  
<span style="margin-left: 2em">之爲進人人皆解者乃反詳之殊失體要又若釋</span>  
<span style="margin-left: 2em">詁詭祖也萱釋之曰詭遠祖也親在高尊之上危</span>  
<span style="margin-left: 2em">矣此義尤爲未安葢明人不尙確據而好出新論</span>  
<span style="margin-left: 2em">其流弊往往如此也續編二十八卷則皆割裂陸</span>  
<span style="margin-left: 2em">佃埤雅羅願爾雅翼合爲一集每條以佃願之名</span>  
<span style="margin-left: 2em">别之惟第一卷說鳳一門有一條題張萱曰爲所</span>  
<!-- 册1 葉3568a　Page:文淵閣四庫全書_0001冊.djvu/942 -->
<span style="margin-left: 2em">自釋耳葢未成之本後人不察而誤刊之陸氏羅</span>  
<span style="margin-left: 2em">氏原書具在亦安用此鈔胥爲哉是尤畫蛇之足</span>  
<span style="margin-left: 2em">矣</span>  
方言據二卷<sub class="note-yuan">福建巡撫採進本</sub>  
<span style="margin-left: 2em">明魏濬撰濬有易象古義通已著錄是書乃紀四</span>  
<span style="margin-left: 2em">方語言之異而求其可據者凡二百餘條多見考</span>  
<span style="margin-left: 2em">據然其中亦有字出經史本非方言如張口笑曰</span>  
<span style="margin-left: 2em">哆頤下曰頦足背曰附毛多曰氄之類小學諸書</span>  
<span style="margin-left: 2em">義訓甚明毋煩更爲索解又如畔牢之與畔愁兒</span>  
<!-- 册1 葉3568b　Page:文淵閣四庫全書_0001冊.djvu/942 -->
<span style="margin-left: 2em">良之爲郎皆聲音之轉亦非因方域而殊乃一槩</span>  
<span style="margin-left: 2em">闌入於輶軒絶代語體例頗不類也</span>  
方言類聚四卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明陳與郊撰與郊有檀弓集註巳著錄是編取揚</span>  
<span style="margin-left: 2em">雄原本依爾雅篇目分爲釋詁釋言等十六門別</span>  
<span style="margin-left: 2em">爲編次使以類相聚如原本第三卷氓民也至棖</span>  
<span style="margin-left: 2em">隨也數語移入卷首爲釋詁其原本卷首黨曉也</span>  
<span style="margin-left: 2em">兩節則列爲釋言反載於敦豐龎奔一節之後郭</span>  
<span style="margin-left: 2em">璞原注則總附每節後低一格以别之間有雙行</span>  
<!-- 册1 葉3569a　Page:文淵閣四庫全書_0001冊.djvu/942 -->
<span style="margin-left: 2em">夾注爲與郊所考訂者僅略及音切字畫之異同</span>  
<span style="margin-left: 2em">而已</span>  
越語肯綮錄一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝毛奇齡撰奇齡有仲氏易已著錄是篇皆記其</span>  
<span style="margin-left: 2em">鄉之方言而證以古音古訓以爲與陸法言韻多</span>  
<span style="margin-left: 2em">相合因宋趙叔向有肯綮錄故襲其名然叔向書</span>  
<span style="margin-left: 2em">多述朝制此則但一隅之里諺耳昔揚雄方言多</span>  
<span style="margin-left: 2em">關訓詁厯代史志及諸家書目均入之經部小學</span>  
<span style="margin-left: 2em">類中是編皆里菴常談似未可遽厠六經之末然</span>  
<!-- 册1 葉3569b　Page:文淵閣四庫全書_0001冊.djvu/942 -->
<span style="margin-left: 2em">舊唐書經籍志載李少通俗語難字新唐書藝文</span>  
<span style="margin-left: 2em">志載張推證俗音顔愍林證俗音略李虔續通俗</span>  
<span style="margin-left: 2em">文皆在小學類中以類相從古有此例故今仍列</span>  
<span style="margin-left: 2em">之小學焉</span>  
連文釋義一卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 1em">國朝王言撰言字愼旃仁和人是編凡二字連文及</span>  
<span style="margin-left: 2em">一名而兼兩義與兩字各爲一義者均分別訓釋</span>  
<span style="margin-left: 2em">釐爲十門詞頗淺近葢爲課𫎇而作視方以智通</span>  
<span style="margin-left: 2em">雅所載相去遠矣</span>  
<!-- 册1 葉3572a　Page:文淵閣四庫全書_0001冊.djvu/943 -->
<span style="margin-left: 1em">右小學類訓詁之屬八部六十四卷皆附存目</span>  
別本干祿字書二卷<sub class="note-yuan">直𨽻總督採進本</sub>  
<span style="margin-left: 2em">唐顔元孫撰其原本已著錄此本乃栢鄉魏裔介</span>  
<span style="margin-left: 2em">所刊卷端加以考證其題炎武按者當爲顧炎武</span>  
<span style="margin-left: 2em">語亦有不標姓名者不知出於誰手或卽裔介所</span>  
<span style="margin-left: 2em">加歟元孫是書本依韻編次而不標韻部之目石</span>  
<span style="margin-left: 2em">本可據此依廣韻加之然原本與廣韻次序實不</span>  
<span style="margin-left: 2em">相同如覃談列陽唐之前蒸列鹽之後仄聲亦並</span>  
<span style="margin-left: 2em">相應考夏竦古文四聲韻稱用唐韻部分者其次</span>  
<!-- 册1 葉3572b　Page:文淵閣四庫全書_0001冊.djvu/943 -->
<span style="margin-left: 2em">序亦與此同知非謬誤葢當時韻書非一本炎武</span>  
<span style="margin-left: 2em">議其顚倒亦非通論也</span>  
說文解字五音韻譜十卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">宋李燾撰燾字仁父桯史云一字子眞號巽岩丹</span>  
<span style="margin-left: 2em">稜人紹興八年進士官至敷文閣學士贈光祿大</span>  
<span style="margin-left: 2em">夫諡文簡<sub class="note-yuan">案文獻通考作諡文定</sub>事蹟具宋史本傳初徐鍇</span>  
<span style="margin-left: 2em">作說文韻譜十卷音訓簡畧粗便檢閱而巳非改</span>  
<span style="margin-left: 2em">許愼本書也燾乃取說文而顚倒之其初稿以類</span>  
<span style="margin-left: 2em">篇次序於每部之中易其字數之先後而部分未</span>  
<!-- 册1 葉3573a　Page:文淵閣四庫全書_0001冊.djvu/943 -->
<span style="margin-left: 2em">移後復改從集韻移自一至亥之部爲自東至甲</span>  
<span style="margin-left: 2em">說文舊第遂蕩然無遺考徐鍇說文繫傳仿易序</span>  
<span style="margin-left: 2em">卦傳例作部敘二篇述五百四十部以次相承之</span>  
<span style="margin-left: 2em">故雖不免有所牽合而古人學有淵源要必有說</span>  
<span style="margin-left: 2em">未可以臆見紛更又徐<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）">新附之字本非許愼原</span>  
<span style="margin-left: 2em">文一槩混淆亦乖體例後人援引往往以<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）">說爲</span>  
<span style="margin-left: 2em">愼說實燾之由其中惟手部撝字徐<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）">作許歸切</span>  
<span style="margin-left: 2em">一條能糾本書之謬其餘如𨺅字本作似醉切乃</span>  
<span style="margin-left: 2em">改爲房九切頁字本模結切乃改爲徒結切則多</span>  
<!-- 册1 葉3573b　Page:文淵閣四庫全書_0001冊.djvu/943 -->
<span style="margin-left: 2em">所竄亂說文酉部有酓字音咽嗛切而燾刪去不</span>  
<span style="margin-left: 2em">載則有所遺漏甚至氂字本里之切而誤作莫交</span>  
<span style="margin-left: 2em">切氂字本莫交切而誤作里之切顚倒錯亂全乖</span>  
<span style="margin-left: 2em">其本義本音尤爲疎舛顧其書易於省覽故流俗</span>  
<span style="margin-left: 2em">盛行明人刊文獻通考又偶佚此書標題而連綴</span>  
<span style="margin-left: 2em">其前後序文於徐鍇繫傳條下世遂不知燾有此</span>  
<span style="margin-left: 2em">書明陳大科作序竟誤以爲許愼舊本茅溱作韻</span>  
<span style="margin-left: 2em">譜本義遂推闡許愼說文所以始於東字之意殊</span>  
<span style="margin-left: 2em">爲附㑹顧炎武博極羣書而所作日知錄亦曰說</span>  
<!-- 册1 葉3576a　Page:文淵閣四庫全書_0001冊.djvu/944 -->
<span style="margin-left: 2em">文原本次第不可見今以四聲列者徐<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）">等所定</span>  
<span style="margin-left: 2em">也是雖知非許愼書而又以燾之所編悞歸徐<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）"></span>  
<span style="margin-left: 2em">信乎考古之難矣</span>  
續千文一卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">宋侍其良器撰良器里貫未詳官左朝散大夫知</span>  
<span style="margin-left: 2em">池州軍事是編皆摭周興嗣千字文所遺之字仍</span>
