## 欽定四庫全書總目 卷一百三十九　子部四十九　類書類存目三

<!-- 册3 葉3709a　Page:文淵閣四庫全書_0003冊.djvu/932 -->
欽定四庫全書總目卷一百三十九  
<span style="margin-left: 1em">子部四十九</span>  
<span style="margin-left: 2em">𩔖書類存目三</span>  
類姓登科考六卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">不著撰人名氏亦無序跋其書取明一代登進士</span>  
<span style="margin-left: 2em">者以姓類從而各註鄉貫科分甲第於名下其仕</span>  
<span style="margin-left: 2em">宦顯逹者並註其官階爵諡或一家世膺是選者</span>  
<span style="margin-left: 2em">則註曰某爲某子某爲某孫某爲某之兄弟紀載</span>  
<span style="margin-left: 2em">頗爲詳賅所註下逮崇禎之末則</span>  
<!-- 册3 葉3709b　Page:文淵閣四庫全書_0003冊.djvu/932 -->
<span style="margin-left: 1em">國朝人編也考唐書藝文志有崔氏顯慶科記五卷</span>  
<span style="margin-left: 2em">姚康科第錄十六卷李奕登科錄二卷晁公武讀</span>  
<span style="margin-left: 2em">書志載樂史采唐武德迄天祐進士及諸科登名</span>  
<span style="margin-left: 2em">者爲登科記三十卷陳振孫書錄解題又載洪适</span>  
<span style="margin-left: 2em">唐登科記十五卷是書詳列科名葢猶古例又唐</span>  
<span style="margin-left: 2em">林罕元和姓纂以四聲分編宋謝維新合璧事類</span>  
<span style="margin-left: 2em">所列諸姓故實則以鄉塾所誦之百家姓趙錢孫</span>  
<span style="margin-left: 2em">李諸字爲網此本葢用維新之例其百家姓所不</span>  
<span style="margin-left: 2em">載者則附錄第六卷末焉</span>  
<!-- 册3 葉3712a　Page:文淵閣四庫全書_0003冊.djvu/933 -->
典制紀畧<sub class="note-yuan">無卷數　浙江廵撫採進本</sub>  
<span style="margin-left: 1em">國朝孫承澤撰承澤有尙書集解巳著錄承澤熟於</span>  
<span style="margin-left: 2em">典故是編廣徵博引頗資考核但中雖分官制河</span>  
<span style="margin-left: 2em">道漕運鹽茶錢鈔禮樂諸門而河道前後複見禮</span>  
<span style="margin-left: 2em">教之後又襍入學田刻書數條貢舉之中又襍入</span>  
<span style="margin-left: 2em">趙撝謙精於六書一叚田賦之後復載錢法二則</span>  
<span style="margin-left: 2em">三司使一條又不附於官職之内顛倒龎雜毫無</span>  
<span style="margin-left: 2em">次第葢偶得一二事則隨筆書之故中多空行且</span>  
<span style="margin-left: 2em">間有添補之處亦有删汰之處實未定之書後人</span>  
<!-- 册3 葉3712b　Page:文淵閣四庫全書_0003冊.djvu/933 -->
<span style="margin-left: 2em">錄其殘稿耳</span>  
經世篇十二卷<sub class="note-yuan">編修汪如藻家藏本</sub>  
<span style="margin-left: 2em">舊本題崑山顧炎武撰其書門類悉依塲屋策目</span>  
<span style="margin-left: 2em">每目一篇附以諸家襍說頗爲弇陋葢應科舉者</span>  
<span style="margin-left: 2em">抄撮類書爲之而坊賈託名於炎武也</span>  
考古類編十二卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 1em">國朝柴紹炳撰紹炳有古韻通巳著錄是書分三十</span>  
<span style="margin-left: 2em">三門凡有闗於典章制度者皆摘其指要貫串成</span>  
<span style="margin-left: 2em">篇自序謂取便童𫎇比於小學紺珠之類葢爲舉</span>  
<!-- 册3 葉3713a　Page:文淵閣四庫全書_0003冊.djvu/933 -->
<span style="margin-left: 2em">業後塲設也原名通考纂要雍正甲辰華亭姚培</span>  
<span style="margin-left: 2em">謙爲之評註改題今名</span>  
希姓補五卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 1em">國朝單隆周撰隆周字昌其蕭山人初明楊慎撰希</span>  
<span style="margin-left: 2em">姓二卷隆周以其尙有缺誤撰此補之亦仍以四</span>  
<span style="margin-left: 2em">聲編次每韻先列原編次列補人補姓以及訂誤</span>  
<span style="margin-left: 2em">自唐以後譜學失傳訛異日增紀載難徧隆周是</span>  
<span style="margin-left: 2em">書亦但就所見錄之未能無所舛漏也</span>  
廣羣輔錄六卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<!-- 册3 葉3713b　Page:文淵閣四庫全書_0003冊.djvu/933 -->
<span style="margin-left: 1em">國朝徐汾撰汾字武令錢塘人是書補陶潛聖賢羣</span>  
<span style="margin-left: 2em">輔錄之闕自西晉以前陶氏所遺者補之自東晉</span>  
<span style="margin-left: 2em">以迄明代則續之案羣輔錄託名陶潛實爲僞本</span>  
<span style="margin-left: 2em">原書旣不足據續編亦病繁蕪至所載明代七才</span>  
<span style="margin-left: 2em">子十才子之類皆末流標榜之目尤爲冗濫王晫</span>  
<span style="margin-left: 2em">今世說載汾喜著書苦無由得錢易楮翰常於破</span>  
<span style="margin-left: 2em">几上起草束麻濡煤作字其編摩可謂苦心書則</span>  
<span style="margin-left: 2em">未爲善本也</span>  
氏族箋釋八卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<!-- 册3 葉3716a　Page:文淵閣四庫全書_0003冊.djvu/934 -->
<span style="margin-left: 1em">國朝熊峻運撰峻運字在湄新建人其書取百家姓</span>  
<span style="margin-left: 2em">氏以文義别爲纂次凡四百六十八姓每姓各綴</span>  
<span style="margin-left: 2em">以四六儷語畧注事狀以備應酬尋檢之用於氏</span>  
<span style="margin-left: 2em">族源流未嘗有所考証</span>  
厯朝人物氏族會編十卷<sub class="note-yuan">江西廵撫採進本</sub>  
<span style="margin-left: 2em">舊本題曰禾川南里松山逸叟頴侯氏撰不著名</span>  
<span style="margin-left: 2em">姓檢卷首名字二印一曰尹敏一曰頴侯知此書</span>  
<span style="margin-left: 2em">卽尹敏作書中多載明末殉節諸臣知爲</span>  
<span style="margin-left: 1em">國初人其始末則未之詳也其書以重編百家姓孔</span>  
<!-- 册3 葉3716b　Page:文淵閣四庫全書_0003冊.djvu/934 -->
<span style="margin-left: 2em">師東魯孟席齊梁諸句爲綱而雜引厯代人物列</span>  
<span style="margin-left: 2em">其下然舛謬百出如孔氏條云出宋郯子之後師</span>  
<span style="margin-left: 2em">氏條云師曠晉樂師孟氏條云孟蔑字獻子如斯</span>  
<span style="margin-left: 2em">之類觸目皆是殊不足據爲典要也</span>  
二酉彚删二十四卷<sub class="note-yuan">山東廵撫採進本</sub>  
<span style="margin-left: 1em">國朝王訓撰訓字敷彛安邱人順治丁亥進士是書</span>  
<span style="margin-left: 2em">分十六門一百七十子目大槩爲科舉答䇿而設</span>  
<span style="margin-left: 2em">有採自本書者亦有轉相稗販迷其出典者如敬</span>  
<span style="margin-left: 2em">廪篇中闗龍逢冕危石履春冰語本出自苻子乃</span>  
<!-- 册3 葉3717a　Page:文淵閣四庫全書_0003冊.djvu/934 -->
<span style="margin-left: 2em">漏去闗字但稱龍逢曰似一人姓龍名逢而所註</span>  
<span style="margin-left: 2em">書名乃作諌桀二字又似龍逢所著之書名曰諫</span>  
<span style="margin-left: 2em">桀也知其抄撮類書非根柢之學矣</span>  
古今疏十五卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 1em">國朝朱虚撰虚字邵齋號可菴又號介庵曹州人順</span>  
<span style="margin-left: 2em">治丁亥進士官至紹興府知府其書倣廣雅釋名</span>  
<span style="margin-left: 2em">之例自天地日月至蟲魚草木各自爲篇加以解</span>  
<span style="margin-left: 2em">釋但徵引浩繁不詳所出使舊文新義無自而分</span>  
<span style="margin-left: 2em">縱有依託末由考證是則抄撮著書之通病也</span>  
<!-- 册3 葉3717b　Page:文淵閣四庫全書_0003冊.djvu/934 -->
三才藻異三十三卷<sub class="note-yuan">江蘇廵撫採進本</sub>  
<span style="margin-left: 1em">國朝屠粹忠撰粹忠號芝巖定海人順治戊戌進士</span>  
<span style="margin-left: 2em">官至兵部尙書是編取故實可偹題咏者分類標</span>  
<span style="margin-left: 2em">題其目盈萬各括以四言二韻葢類書之支流而</span>  
<span style="margin-left: 2em">𫎇求之變體也然襞績成文繁蕪無當自序謂厯</span>  
<span style="margin-left: 2em">二十四載而成亦勞而無補矣</span>  
三才彚編四卷<sub class="note-yuan">江蘇廵撫採進本</sub>  
<span style="margin-left: 1em">國朝龔在升撰在升字聞園嘉善人順治己亥進士</span>  
<span style="margin-left: 2em">官蘇州府推官是書分類編纂爲科舉對䇿之用</span>  
<!-- 册3 葉3720a　Page:文淵閣四庫全書_0003冊.djvu/935 -->
<span style="margin-left: 2em">間附議論如郊社主合祀樂律用李文利之說皆</span>  
<span style="margin-left: 2em">非<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">論也</span>  
千家姓文一卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 1em">國朝崔冕撰冕字貢收巢縣人是編以村塾所傳百</span>  
<span style="margin-left: 2em">家姓語無文義因就史傳詳加繙閲得複姓三十</span>  
<span style="margin-left: 2em">四單姓九百七十二計千餘六音聯屬其文較原</span>  
<span style="margin-left: 2em">書爲雅馴然不及王應麟姓氏急就篇典核有據</span>  
<span style="margin-left: 2em">也前有康熙癸卯冕自序又有如臯冒國柱序其</span>  
<span style="margin-left: 2em">註卽國柱所作皆但云某代有某人而不著所出</span>  
<!-- 册3 葉3720b　Page:文淵閣四庫全書_0003冊.djvu/935 -->
<span style="margin-left: 2em">亦無徵不信矣</span>  
教養全書四十一卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 1em">國朝應撝謙撰撝謙有周易集解巳著錄是書分選</span>  
<span style="margin-left: 2em">舉學校治官田賦水利國計漕運治河師役鹽法</span>  
<span style="margin-left: 2em">十考節引史文而取前人評論各叅其下體例畧</span>  
<span style="margin-left: 2em">倣文獻通考於明代事實所載尤詳撝謙間附斷</span>  
<span style="margin-left: 2em">語議論亦多醇正然以視馬端臨之精博則猶未</span>  
<span style="margin-left: 2em">能遽相方駕矣其中不載律𮅕者以徐光啟巳有</span>  
<span style="margin-left: 2em">成書不載輿地者以顧炎武顧祖禹二人方事纂</span>  
<!-- 册3 葉3721a　Page:文淵閣四庫全書_0003冊.djvu/935 -->
<span style="margin-left: 2em">輯故也</span>  
姓氏譜六卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 1em">國朝李繩遠撰繩遠字斯年嘉興人其書雜抄萬姓</span>  
<span style="margin-left: 2em">統譜而成舛漏頗甚疑其錄以備用本非欲著書</span>  
<span style="margin-left: 2em">也</span>  
李氏類纂五十卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 1em">國朝李繩遠撰是編葢偶抄諸家類書以備自用故</span>  
<span style="margin-left: 2em">職官首宗人府用</span>  
<span style="margin-left: 1em">今制也而云</span>  
<!-- 册3 葉3721b　Page:文淵閣四庫全書_0003冊.djvu/935 -->
<span style="margin-left: 1em">國朝置大宗正院改宗人府宗人令一人乃前朝故</span>  
<span style="margin-left: 2em">事而以爲</span>  
<span style="margin-left: 1em">國朝此沿襲抄錄而事同未去<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3575.svg?width=24" alt="四庫全書僻字第3575號（葛）" title="四庫全書僻字第3575號（葛）">龔者矣</span>  
韻粹一百七卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">舊本題</span>  
<span style="margin-left: 1em">國朝朱彛尊撰<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">尊有經義考巳著錄是書采古人</span>  
<span style="margin-left: 2em">新頴之語分韻編次韻爲一卷所摭不爲不富然</span>  
<span style="margin-left: 2em">惟摭詞賦而不及經史其詞賦引據他書者亦卽</span>  
<span style="margin-left: 2em">以詞賦爲出典其病與蘇頌文選雙字類要畧同</span>  
<!-- 册3 葉3724a　Page:文淵閣四庫全書_0003冊.djvu/936 -->
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">尊學有本原著述最富不應爲此餖飣之學其</span>  
<span style="margin-left: 2em">生平文字内未嘗言及此書書中時有闕行闕字</span>  
<span style="margin-left: 2em">亦似未完之本疑爲摭拾私記以備詞賦之用後</span>  
<span style="margin-left: 2em">人重其淹博轉相傳寫遂漸至於流布耳</span>  
宫閨小名錄四卷後錄一卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 1em">國朝尤侗撰侗有明史藝文志巳著錄是編補陸龜</span>  
<span style="margin-left: 2em">𫎇洪适王銍温豫張邦幾諸錄之遺上起於漢下</span>  
<span style="margin-left: 2em">迄於明凡女子以名傳者皆分𩔖編載一曰后妃</span>  
<span style="margin-left: 2em">附以公主外戚二曰列女附以妓妾之有節行者</span>
