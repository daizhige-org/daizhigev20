<span style="margin-left: 2em">堂書目亦同江南通志則載其奉使入浙擊水寨</span>  
<span style="margin-left: 2em">冦論功當叙中蜚語歸卒贈工部尙書據集内山</span>

<span style="margin-left: 2em">刻十六卷後增至十八卷又增至二十卷而目則</span>  
<span style="margin-left: 2em">未改歟</span>

<span style="margin-left: 2em">濟南府知府明史文苑傳附載王世貞傳中是集</span>  
<span style="margin-left: 2em">前三卷皆詩後三卷爲雜文當嘉隆之際李攀龍</span>  
<span style="margin-left: 2em">王世貞方負盛名而裳與南昌余曰德德甫銅梁</span>  
<span style="margin-left: 2em">張佳允肖甫新蔡張九一助甫實左右之當時稱</span>  
<span style="margin-left: 2em">爲四甫裳才地稍弱尤爲墨守不變集首佳允序</span>  
<span style="margin-left: 2em">謂其文非左國兩司馬詩非建安大厯則不以寓</span>  
<span style="margin-left: 2em">目此卽其力持王李餘論之證故世貞藝苑巵言</span>

<span style="margin-left: 2em">亦稱其不失門宗云</span>  
大雅堂摘藳<sub class="note-yuan">無卷數　江西廵撫採進本</sub>

<span style="margin-left: 2em">有後五子廣五子等目而不及叔祺大雅堂集世</span>  
<span style="margin-left: 2em">亦罕有傳者則明代已不行於世矣此本題云摘</span>

<span style="margin-left: 2em">明徐中行撰中行字子與號龍灣長興人讀書天</span>

<span style="margin-left: 2em">爲後七子之一王世貞藝苑巵言亟稱之以爲左</span>  
<span style="margin-left: 2em">準右繩靡所不合胡應麟詩藪則惜其少沈深之</span>  
<span style="margin-left: 2em">致陳子龍明詩選復有摹古太似之譏是非恩怨</span>  
<span style="margin-left: 2em">輾轉相爭要之或褒或貶各有所當合而觀之則</span>

<span style="margin-left: 2em">中行之定評出矣雜文亦有意矯揉頗失渾雅蓋</span>  
<span style="margin-left: 2em">當時風尙七子同一軌轍非如是不能預壇坫也</span>  
靑蘿館詩六卷<sub class="note-yuan">兩江總督採進本</sub>

<span style="margin-left: 2em">守汝寜以後之詩居三分之二汰其古文又汰其</span>  
<span style="margin-left: 2em">少作較全集爲精簡然中行於北地之學漸染旣</span>  
<span style="margin-left: 2em">深時元能删其枝蔓不能變其根柢也</span>  
余德甫集十四卷<sub class="note-yuan">江蘇周厚堉家藏本</sub>  
<span style="margin-left: 2em">明余曰德撰曰德初名應舉字德甫南昌人嘉靖</span>

<span style="margin-left: 2em">庚戌進士官至福建按察司副使明史文苑傳附</span>  
<span style="margin-left: 2em">見王世貞傳中與魏裳汪道昆張佳允張九一所</span>  
<span style="margin-left: 2em">謂嘉靖後五子也世貞稱其詩古近體亡所不佳</span>  
<span style="margin-left: 2em">近體獨超近體五七言亡所不超七言獨妙靜志</span>  
<span style="margin-left: 2em">居詩話則謂其詩尙未見門戸元美冠諸後五子</span>  
<span style="margin-left: 2em">之首未免阿其所好今觀是集彛尊所論公矣</span>  
豐陽集十二卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">明馮臯謨撰臯謨字明卿海鹽人嘉靖庚戌進士</span>  
<span style="margin-left: 2em">官至福建布政司參政是集凡詩四卷文八卷臯</span>

<span style="margin-left: 2em">詩故其趨向亦相近云</span>

<span style="margin-left: 2em">明董傳䇿撰傳䇿有奏疏輯畧已著錄此三集乃</span>

<span style="margin-left: 2em">隨作隨刋卷帙無定未知爲此本不完或黄虞稷</span>  
<span style="margin-left: 2em">誤載又有廓然子藳二卷蘧廬藳七卷此本不載</span>  
<span style="margin-left: 2em">殆偶佚矣</span>

<span style="margin-left: 2em">明吳國倫撰國倫有陳張本末畧已著錄初國倫</span>  
<span style="margin-left: 2em">爲兵科給事中時以倡衆賻楊繼盛忤嚴嵩左遷</span>

<span style="margin-left: 2em">攀龍唱和後與李維楨汪道昆軰狎主詩盟其著</span>  
<span style="margin-left: 2em">述頗富然在當時胡元瑞作詩藪已譏其用句多</span>  
<span style="margin-left: 2em">同一篇而外不耐多讀</span>  
<span style="margin-left: 1em">國朝朱彛尊靜志居詩話亦謂王李旣没甔甀幾與</span>  
<span style="margin-left: 2em">四部爭富而海内之爲眞詩者寡則文章不逮其</span>
