## 欽定四庫全書總目 卷一百四十四　子部五十四　小說家類存目二

欽定四庫全書總目卷一百四十四  
<span style="margin-left: 1em">子部五十四</span>  
<span style="margin-left: 2em">小說家類存目二</span>  
山海經釋義十八卷圖二卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">明王崇慶撰崇慶有周易議卦已著錄是書全載</span>  
<span style="margin-left: 2em">郭璞注崇慶間有論說詞皆膚淺其圖亦書肆俗</span>  
<span style="margin-left: 2em">工所臆作不爲典據</span>  
幽怪錄一卷附續幽怪錄一卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">幽怪錄唐牛僧孺撰僧儒事蹟具新唐書本傳唐</span>  
<!-- 册3 葉4169b　Page:文淵閣四庫全書_0003冊.djvu/1047 -->
<span style="margin-left: 2em">書藝文志作元怪錄朱國楨湧幢小品曰牛僧孺</span>  
<span style="margin-left: 2em">撰元怪錄楊用修改爲幽怪錄因世廟時重元字</span>  
<span style="margin-left: 2em">用修不敢不避其實一書非刻之誤也然宋史藝</span>  
<span style="margin-left: 2em">文志載李德裕幽怪錄十四卷則此名爲複矣唐</span>  
<span style="margin-left: 2em">志作十卷今止一卷殆鈔合而成非其舊本晁公</span>  
<span style="margin-left: 2em">武讀書志云僧孺爲宰相有聞於世而著此等書</span>  
<span style="margin-left: 2em">周秦行紀之謗葢有以致之也末附唐李復言續</span>  
<span style="margin-left: 2em">錄一卷考唐志及館閣書目皆作五卷通考則作</span>  
<span style="margin-left: 2em">十卷云分仙術感應一門今僅殘篇數頁並不成</span>  
<!-- 册3 葉4172a　Page:文淵閣四庫全書_0003冊.djvu/1048 -->
<span style="margin-left: 2em">卷矣然志怪之書無闗風教其完否亦不必深考</span>  
<span style="margin-left: 2em">也</span>  
續元怪錄四卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">唐李復言撰是書世有二本其附載牛僧孺幽怪</span>  
<span style="margin-left: 2em">錄末者葢從說郛錄出一卽此本凡二十三事與</span>  
<span style="margin-left: 2em">唐志卷數亦不符葢從太平廣記錄出者雖稍多</span>  
<span style="margin-left: 2em">於說郛本然亦非完帙也</span>  
龍城錄二卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">舊本題唐柳宗元撰宋葛嶠始編之柳集中然唐</span>  
<!-- 册3 葉4172b　Page:文淵閣四庫全書_0003冊.djvu/1048 -->
<span style="margin-left: 2em">藝文志不著錄何薳春渚紀聞以爲王銍所僞作</span>  
<span style="margin-left: 2em">朱子語錄亦曰柳文後龍城錄雜記王銍之爲也</span>  
<span style="margin-left: 2em">子厚叙事文字多少筆力此記衰弱之甚皆寓古</span>  
<span style="margin-left: 2em">人詩文中不可知者於其中似暗影出今觀錄中</span>  
<span style="margin-left: 2em">所載帝命取書事似爲韓愈調張籍詩天官遣六</span>  
<span style="margin-left: 2em">丁雷電下取將二句作解趙師雄羅浮夢事似爲</span>  
<span style="margin-left: 2em">蘇軾梅花詩月下縞衣來扣門作解朱子所論深</span>  
<span style="margin-left: 2em">得其情莊季裕作雞肋編乃引此錄駁金華圖經</span>  
<span style="margin-left: 2em">季裕與銍爲同時人或其書初出僞迹未露故不</span>  
<!-- 册3 葉4173a　Page:文淵閣四庫全書_0003冊.djvu/1048 -->
<span style="margin-left: 2em">暇致詳歟然自南宋以來詞賦家巳沿爲故實不</span>  
<span style="margin-left: 2em">可復廢是亦王充所謂俗語不實流爲丹靑者矣</span>  
獨異志三卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">唐李冘撰唐藝文志作李亢未詳孰是其書雜錄</span>  
<span style="margin-left: 2em">古事亦及唐代𤨏聞大扺語怪者居多如女媧兄</span>  
<span style="margin-left: 2em">妹爲夫婦事皆齊東之語又如列子海人狎鷗愚</span>  
<span style="margin-left: 2em">公移山事皆摭寓言爲實事尤爲膠固至王涯爲</span>  
<span style="margin-left: 2em">仇士良所害本非文宗之命乃稱涯爲天兵梟戮</span>  
<span style="margin-left: 2em">則悖謬甚矣</span>  
<!-- 册3 葉4173b　Page:文淵閣四庫全書_0003冊.djvu/1048 -->
陸氏集異記四卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">舊本題唐比部郎中陸勲撰書錄解題及宋史藝</span>  
<span style="margin-left: 2em">文志並作二卷陳振孫曰語怪之書也凡三十二</span>  
<span style="margin-left: 2em">事言犬怪者居三之一此書較陳氏所載多二卷</span>  
<span style="margin-left: 2em">而事較振孫所記之數多三四倍亦不多言犬怪</span>  
<span style="margin-left: 2em">豈後人附會非其本書歟</span>  
劍俠傳二卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">舊本題爲唐人撰不著名氏載明吳琯古今逸史</span>  
<span style="margin-left: 2em">中皆紀唐代劍俠之事與太平廣記一百九十三</span>  
<!-- 册3 葉4176a　Page:文淵閣四庫全書_0003冊.djvu/1049 -->
<span style="margin-left: 2em">卷至一百九十六卷所載豪俠四卷文盡相同次</span>  
<span style="margin-left: 2em">序及句下夾注如潘將軍條下所附忘其名疑爲</span>  
<span style="margin-left: 2em">潘鶻硉也九字亦復脗合但訛鶻硉爲鶴碎耳葢</span>  
<span style="margin-left: 2em">明人剿襲廣記之文僞題此名也</span>  
錄異記八卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">蜀杜光庭撰光庭有了證歌已著錄此書宋志作</span>  
<span style="margin-left: 2em">十卷與今本異白雲霽道藏目錄收於洞元部記</span>  
<span style="margin-left: 2em">傳類恭字號中然光庭雖道士而此書所述實無</span>  
<span style="margin-left: 2em">與於道家卷首沈士龍題辭謂光庭以方術事蜀</span>  
<!-- 册3 葉4176b　Page:文淵閣四庫全書_0003冊.djvu/1049 -->
<span style="margin-left: 2em">孟昶故成此書以取悅考陶岳五代史補光庭以</span>  
<span style="margin-left: 2em">唐僖宗幸蜀時入道其後厯事王建王衍未入後</span>  
<span style="margin-left: 2em">蜀卽以此書而論其記蜀丁卯年會昌廟城壕側</span>  
<span style="margin-left: 2em">龜著金書王字大吉字則王建天復七年也又稱</span>  
<span style="margin-left: 2em">蜀皇帝乾德元年已卯七月十五日庚辰降誕廣</span>  
<span style="margin-left: 2em">聖節王彦徽得白龜以進則王衍元年也凡此皆</span>  
<span style="margin-left: 2em">爲前蜀王氏誕陳符瑞以云悅昶失考甚矣其言</span>  
<span style="margin-left: 2em">皆荒誕不足信冶城客論曰廣成先生杜光庭撰</span>  
<span style="margin-left: 2em">仙傳錄異等書率多自作故人有無稽之言謂之</span>  
<!-- 册3 葉4177a　Page:文淵閣四庫全書_0003冊.djvu/1049 -->
<span style="margin-left: 2em">杜撰然則光庭之妄前人已言之矣</span>  
括異志十卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">舊本題宋張師正撰師正字不疑熙寧中爲辰州</span>  
<span style="margin-left: 2em">帥文獻通考載師正擢甲科後宦遊四十年不得</span>  
<span style="margin-left: 2em">志於是推變怪之理參見聞之異得二百五十篇</span>  
<span style="margin-left: 2em">魏泰爲之序此本不載魏序葢傳寫佚之然王銍</span>  
<span style="margin-left: 2em">黙記以是書卽魏泰作葢泰爲曾布之婦兄而銍</span>  
<span style="margin-left: 2em">則曾紆之壻猶及識泰其言當必不誣也</span>  
靑𤨏高議前集十卷後集十卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<!-- 册3 葉4177b　Page:文淵閣四庫全書_0003冊.djvu/1049 -->
<span style="margin-left: 2em">不著撰人名氏晁公武讀書志及宋史藝文志皆</span>  
<span style="margin-left: 2em">著錄亦皆不云誰作趙與峕賔退錄稱爲劉斧靑</span>  
<span style="margin-left: 2em">𤨏高議當必親見其標題前有孫副樞序不稱名</span>  
<span style="margin-left: 2em">而舉其官他書亦無此例其爲里巷俗書可知也</span>  
<span style="margin-left: 2em">所紀皆宋時怪異事蹟及諸雜傳記多乖雅馴每</span>  
<span style="margin-left: 2em">條下各爲七字標目如張乖崖明斷分財囘處士</span>  
<span style="margin-left: 2em">磨鏡題詩之類尤近於傳竒間有稱議曰者寥寥</span>  
<span style="margin-left: 2em">數言亦多陳腐讀書志稱其詞意鄙淺良非輕詆</span>  
<span style="margin-left: 2em">公武所錄作十八卷宋史藝文志亦同此本乃多</span>  
<!-- 册3 葉4180a　Page:文淵閣四庫全書_0003冊.djvu/1050 -->
<span style="margin-left: 2em">兩卷或坊賈傳刻又有所竄入歟蔡絛鐵圍山叢</span>  
<span style="margin-left: 2em">談稱所載孫勔射黿被追見韓𤦺爲紫府眞人事</span>  
<span style="margin-left: 2em">其說不謬然稱爲靑𤨏小說或又其别名也孫勔</span>  
<span style="margin-left: 2em">事魏公別錄魏公家傳皆載之周煇淸波雜志又</span>  
<span style="margin-left: 2em">考其同異謂當以家傳爲正其所引王老志別一</span>  
<span style="margin-left: 2em">說卽蔡絛語夫韓𤦺名德何必死作閻羅王乃足</span>  
<span style="margin-left: 2em">取重斧作小說侈談神怪可矣士大夫以爲實事</span>  
<span style="margin-left: 2em">而記於家傳别錄好事者又校正其異同相率說</span>  
<span style="margin-left: 2em">夢不亦傎乎</span>  
<!-- 册3 葉4180b　Page:文淵閣四庫全書_0003冊.djvu/1050 -->
雲齋廣錄八卷後集一卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋李獻民撰獻民字彦文延津人是書前有政和</span>  
<span style="margin-left: 2em">辛卯獻民自序所載皆一時艷異雜事文旣冗㳫</span>  
<span style="margin-left: 2em">語尤猥䙝晁公武讀書志陳振孫書錄解題俱云</span>  
<span style="margin-left: 2em">十卷分九門今止存六門曰士林淸話曰詩話錄</span>  
<span style="margin-left: 2em">曰靈怪曰麗情曰竒異曰神仙共八卷末有後集</span>  
<span style="margin-left: 2em">一卷曰盈盈傳乃作者自述所遇然首稱皇祐中</span>  
<span style="margin-left: 2em">中稱嘉祐五年皆仁宗年號與獻民時代不相及</span>  
<span style="margin-left: 2em">則傳中所謂余者乃別一人而佚其名非獻民自</span>  
<!-- 册3 葉4181a　Page:文淵閣四庫全書_0003冊.djvu/1050 -->
<span style="margin-left: 2em">稱也其書大致與劉斧靑𤨏高議相類然斧書雖</span>  
<span style="margin-left: 2em">俗猶時有勸戒此則純乎誨淫而已以向來諸家</span>  
<span style="margin-left: 2em">著錄今姑存其目焉</span>  
五色線二卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">不著編輯者名氏載毛晉津逮秘書中考中興館</span>  
<span style="margin-left: 2em">閣書目有此書名然是書雜引諸小說新誕之語</span>  
<span style="margin-left: 2em">或不紀所出割裂舛謬不可枚舉至謂楚襄王夢</span>  
<span style="margin-left: 2em">神女事岀史記其庸妄可知未知果宋時舊本否</span>  
<span style="margin-left: 2em">也</span>  
<!-- 册3 葉4181b　Page:文淵閣四庫全書_0003冊.djvu/1050 -->
峽山神異記一卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋黄輔撰輔里籍未詳是書作於嘉定戊寅輔時</span>  
<span style="margin-left: 2em">辟爲瀧水縣令自序謂予備員西征始聞峽山非</span>  
<span style="margin-left: 2em">常可駭之事始猶未敢以爲然及觀前賢所記由</span>  
<span style="margin-left: 2em">東坡以來連篇累牘悉出於名公巨<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">之口以其</span>  
<span style="margin-left: 2em">人之可信則事必可信矣訪峽山集舊板失散於</span>  
<span style="margin-left: 2em">是裒集傳之然其敘述飛來殿謂至德元年峽有</span>  
<span style="margin-left: 2em">三神人化爲方士夜扣潁州貞俊禪師日本峽居</span>  
<span style="margin-left: 2em">淸遠上流吾欲建道塲師能去否俊諾之是夕風</span>  
<!-- 册3 葉4184a　Page:文淵閣四庫全書_0003冊.djvu/1051 -->
<span style="margin-left: 2em">雨驟作黎明薄霽啟戸而觀則佛殿與神像已運</span>  
<span style="margin-left: 2em">至山中矣俊師乃於峯前石上安坐本淮南西路</span>  
<span style="margin-left: 2em">舒州延祚寺之所移其事渉於語怪是小說之支</span>  
<span style="margin-left: 2em">流非地志之正體也</span>  
閒窻括異志一卷<sub class="note-yuan">浙江鄭大節家藏本</sub>  
<span style="margin-left: 2em">宋魯應龍撰自署東湖葢嘉興人書中稱淳祐甲</span>  
<span style="margin-left: 2em">申館於沈氏則理宗時也其書皆言神怪之事而</span>  
<span style="margin-left: 2em">多借以明因果前半帙皆所聞見後半帙則雜采</span>  
<span style="margin-left: 2em">古事以足之大半與唐五代小說相出入</span>  
<!-- 册3 葉4184b　Page:文淵閣四庫全書_0003冊.djvu/1051 -->
續夷堅志二卷<sub class="note-yuan">浙江巡撫採進本</sub>
