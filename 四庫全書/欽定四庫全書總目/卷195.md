## 欽定四庫全書總目 卷一百九十五　集部四十八　詩文評類一

<!-- 册5 葉860：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷一百九十五  
<span style="margin-left: 1em">集部四十八</span>  
<span style="margin-left: 2em">詩文評類一</span>  
<span style="margin-left: 3em">文章莫盛於兩漢渾渾灝灝交成法立無格律</span>  
<span style="margin-left: 3em">之可拘建安黃初體裁漸備故論文之說出焉</span>  
<span style="margin-left: 3em">典論其首也其勒爲一書傳於今者則斷自劉</span>  
<span style="margin-left: 3em">勰鍾嶸勰究文體之源流而評其工拙嶸第作</span>  
<span style="margin-left: 3em">者之甲乙而溯厥師承爲例各殊至皎然詩式</span>  
<span style="margin-left: 3em">備陳法律孟棨本事詩旁採故實劉攽中山詩</span>  
<!-- 册5 葉861b　Page:文淵閣四庫全書_0005冊.djvu/220 -->
<span style="margin-left: 3em">話歐陽修六一詩話又體兼說部後所論著不</span>  
<span style="margin-left: 3em">出此五例中矣宋明兩代均好爲議論所撰尤</span>  
<span style="margin-left: 3em">繁雖宋人務求深解多穿鑿之詞明人喜作高</span>  
<span style="margin-left: 3em">談多虛憍之論然汰除糟粕採擷菁英每足以</span>  
<span style="margin-left: 3em">考證舊聞觸發新意隋志附總集之内唐書以</span>  
<span style="margin-left: 3em">下則並於集部之末别立此門豈非以其討論</span>  
<span style="margin-left: 3em">瑕瑜别裁眞僞博參廣考亦有裨於文章歟</span>  
文心雕龍十卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">梁劉勰撰勰字彦和東莞莒人天監中兼東宫通</span>  
<!-- 册5 葉864a　Page:文淵閣四庫全書_0005冊.djvu/221 -->
<span style="margin-left: 2em">事舍人遷步兵校尉兼舍人如故後出家爲沙門</span>  
<span style="margin-left: 2em">改名慧地事迹具南史本傳其書原道以下二十</span>  
<span style="margin-left: 2em">五篇論文章體製神思以下二十四篇論文章工</span>  
<span style="margin-left: 2em">拙合序志一篇爲五十篇據序志篇稱上篇以下</span>  
<span style="margin-left: 2em">下篇以上本止二卷然隋志巳作十卷葢後人所</span>  
<span style="margin-left: 2em">分又據時序篇中所言此書實成於齊代此本署</span>  
<span style="margin-left: 2em">梁通事舍人劉勰撰亦後人追題也是書自至正</span>  
<span style="margin-left: 2em">乙未刻於嘉禾至明宏治嘉靖萬厯間凡經五刻</span>  
<span style="margin-left: 2em">其隱秀一篇皆有缺文明末常熟錢允治稱得阮</span>  
<!-- 册5 葉864b　Page:文淵閣四庫全書_0005冊.djvu/221 -->
<span style="margin-left: 2em">華山宋槧本鈔補四百餘字然其書晚出别無顯</span>  
<span style="margin-left: 2em">證其詞亦頗不類如嘔心吐膽似摭李賀小傳語</span>  
<span style="margin-left: 2em">鍛歲煉年似摭六一詩話論周朴語稱班姬爲匹</span>  
<span style="margin-left: 2em">婦亦似摭鍾嶸詩品語皆有可疑况至正去宋未</span>  
<span style="margin-left: 2em">遠不應宋本已無一存三百年後乃爲明人所得</span>  
<span style="margin-left: 2em">又考永樂大典所載舊本闕文亦同其時宋本如</span>  
<span style="margin-left: 2em">林更不應内府所藏無一完刻阮氏所稱殆亦影</span>  
<span style="margin-left: 2em">撰何焯等誤信之也至字句舛訛自楊愼朱謀㙔</span>  
<span style="margin-left: 2em">以下遞有校正而亦不免於妄改如哀誄篇賦憲</span>  
<!-- 册5 葉865a　Page:文淵閣四庫全書_0005冊.djvu/221 -->
<span style="margin-left: 2em">之諡句皆云賦憲當作議德葢以賦形近議憲形</span>  
<span style="margin-left: 2em">近惪惪古德字也然考王應麟玉海曰周書諡法</span>  
<span style="margin-left: 2em">惟三月旣生魄周公旦太公望相嗣王發旣賦憲</span>  
<span style="margin-left: 2em">受臚於牧之野將葬乃制作諡文心雕龍云賦憲</span>  
<span style="margin-left: 2em">之諡出於此然則二字不誤古人巳言以是例之</span>  
<span style="margin-left: 2em">其以意雌黃者多矣</span>  
文心雕龍輯註十卷<sub class="note-yuan">江西巡撫採進本</sub>  
<span style="margin-left: 1em">國朝黃叔琳撰叔琳有研北易鈔已著錄考宋史藝</span>  
<span style="margin-left: 2em">文志有辛處信文心雕龍註十卷其書不傳明梅</span>  
<!-- 册5 葉865b　Page:文淵閣四庫全書_0005冊.djvu/221 -->
<span style="margin-left: 2em">慶生註粗具梗槪多所未備叔琳因其舊本重爲</span>  
<span style="margin-left: 2em">刪補以成此編其譌脫字句皆據諸家校本改正</span>  
<span style="margin-left: 2em">惟宗經篇末附註極論梅本之舛誤謂宜從王維</span>  
<span style="margin-left: 2em">儉本而篇中所載乃仍用梅本非用王本殊自相</span>  
<span style="margin-left: 2em">矛盾所註如宗經篇中書實紀言而訓詁茫昧通</span>  
<span style="margin-left: 2em">乎爾雅則文義曉然句謂爾雅本以釋詩無關書</span>  
<span style="margin-left: 2em">之訓詁案爾雅開卷第二字郭註卽引尚書哉生</span>  
<span style="margin-left: 2em">魄爲證其他釋書者不一而足安得謂與書無關</span>  
<span style="margin-left: 2em">詮賦篇中拓宇於楚詞句拓宇字出顔延年宋郊</span>  
<!-- 册5 葉868a　Page:文淵閣四庫全書_0005冊.djvu/222 -->
<span style="margin-left: 2em">祀歌而改爲括宇引西京雜記所載司馬相如賦</span>  
<span style="margin-left: 2em">家之心包括宇宙語爲證割裂牽合亦爲未協史</span>  
<span style="margin-left: 2em">傳篇中徵賄鬻筆之愆公理辨之究矣句公理爲</span>  
<span style="margin-left: 2em">仲長統字此必所著昌言中有辨班固徵賄之事</span>  
<span style="margin-left: 2em">今原書巳佚遂無可考觀劉知幾史通亦載班固</span>  
<span style="margin-left: 2em">受金事與此書同葢昌言唐時尚存故知幾見之</span>  
<span style="margin-left: 2em">也乃不引史通互證而引陳壽索米事爲註與前</span>  
<span style="margin-left: 2em">漢書何與乎又時序篇中論齊無太祖中宗序志</span>  
<span style="margin-left: 2em">篇中論李充不字宏範皆不附和本書而指瑕篇</span>  
<!-- 册5 葉868b　Page:文淵閣四庫全書_0005冊.djvu/222 -->
<span style="margin-left: 2em">中西京賦稱中黃賁𫉬之疇薛綜繆註謂之閹尹</span>  
<span style="margin-left: 2em">句今文選薛綜註中實無此語乃獨不糾彈小小</span>  
<span style="margin-left: 2em">舛誤亦所不免至於徵聖篇中四象精義以曲隱</span>  
<span style="margin-left: 2em">句註引易有四象所以示也又引朱子本義曰四</span>  
<span style="margin-left: 2em">象謂陰陽老少案繫詞易有四象孔疏引莊氏曰</span>  
<span style="margin-left: 2em">四象謂六十四卦之中有實象有假象有義象有</span>  
<span style="margin-left: 2em">用象爲四象也又引何氏說以天生神物八句爲</span>  
<span style="margin-left: 2em">四象其解兩儀生四象則謂金木水火秉天地而</span>  
<span style="margin-left: 2em">有是自唐以前均無陰陽老少之說劉勰梁人豈</span>  
<!-- 册5 葉869a　Page:文淵閣四庫全書_0005冊.djvu/222 -->
<span style="margin-left: 2em">知後有邵子易乎又秉文之金科句引<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3951.svg?width=24" alt="四庫全書僻字第3951號（揚 --（『昜』上『旦』之『日』與『一』相連））" title="四庫全書僻字第3951號（揚 --（『昜』上『旦』之『日』與『一』相連））">雄劇秦</span>  
<span style="margin-left: 2em">美新金科玉條又引註曰謂法令也言金玉佞詞</span>  
<span style="margin-left: 2em">也案李善註曰金科玉條謂法令言金玉貴之也</span>  
<span style="margin-left: 2em">此云佞詞不知所據何本且在劇秦美新可謂之</span>  
<span style="margin-left: 2em">佞詞此引註徵聖篇而用此註不與本意刺謬乎</span>  
<span style="margin-left: 2em">其他如註宗經篇三墳五典八索九邱不引左傳</span>  
<span style="margin-left: 2em">而引僞孔安國書序註諧讔篇荀卿<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3641.svg?width=24" alt="四庫全書僻字第3641號（蠶）" title="四庫全書僻字第3641號（蠶）">賦不引荀</span>  
<span style="margin-left: 2em">子賦篇而引明人賦苑尤多不得其根柢然較之</span>  
<span style="margin-left: 2em">梅註則詳備多矣</span>  
<!-- 册5 葉869b　Page:文淵閣四庫全書_0005冊.djvu/222 -->
詩品三卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">梁鍾嶸撰嶸字仲偉潁川長社人與兄岏弟嶼並</span>  
<span style="margin-left: 2em">好學有名齊永明中爲國子生王儉舉本州秀才</span>  
<span style="margin-left: 2em">起家王國侍郎入梁仕至晉安王記室卒於官嶸</span>  
<span style="margin-left: 2em">學通周易詞藻兼長所品古今五言詩自漢魏以</span>  
<span style="margin-left: 2em">來一百有三人論其優劣分爲上中下三品每品</span>  
<span style="margin-left: 2em">之首各冠以序皆妙達文理可與文心雕龍並稱</span>  
<span style="margin-left: 2em">近時王士禎極論其品第之間多所違失然梁代</span>  
<span style="margin-left: 2em">迄今邈踰千祀遺篇舊製什九不存未可以掇拾</span>  
<!-- 册5 葉872a　Page:文淵閣四庫全書_0005冊.djvu/223 -->
<span style="margin-left: 2em">殘文定當曰全集之優劣惟其論某人源出某人</span>  
<span style="margin-left: 2em">若一一親見其師承者則不免附會耳史稱嶸嘗</span>  
<span style="margin-left: 2em">求譽於沈約約弗爲奬借故嶸怨之列約中品案</span>  
<span style="margin-left: 2em">約詩列之中品未爲排抑惟序中深詆聲律之學</span>  
<span style="margin-left: 2em">謂蜂腰鶴膝僕病未能雙聲叠韻里俗巳具是則</span>  
<span style="margin-left: 2em">攻擊約說顯然可見言亦不盡無因也又一百三</span>  
<span style="margin-left: 2em">人之中惟王融稱王元長不著其名或疑其有所</span>  
<span style="margin-left: 2em">私尊然徐陵玉臺新詠亦惟融書字葢齊梁之間</span>  
<span style="margin-left: 2em">避齊和帝之諱故以字行實無他故今亦姑仍原</span>  
<!-- 册5 葉872b　Page:文淵閣四庫全書_0005冊.djvu/223 -->
<span style="margin-left: 2em">本以存其舊焉</span>  
文章緣起一卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">舊本題梁任昉撰考隋書經籍志載任昉文章始</span>  
<span style="margin-left: 2em">一卷稱有錄無書是其書在隋已亡唐書藝文志</span>  
<span style="margin-left: 2em">載任昉文章始一卷註曰張績補績不知何許人</span>  
<span style="margin-left: 2em">然在唐已補其亡則唐無是書可知矣宋人修太</span>  
<span style="margin-left: 2em">平御覽所引書一千六百九十種摯虞文章流别</span>  
<span style="margin-left: 2em">李充翰林論之類無不備收亦無此名今檢其所</span>  
<span style="margin-left: 2em">列引據頗疎如以表與讓表分爲二類騷與反騷</span>  
<!-- 册5 葉873a　Page:文淵閣四庫全書_0005冊.djvu/223 -->
<span style="margin-left: 2em">別立兩體挽歌云起繆襲不知薤露之在前玉篇</span>  
<span style="margin-left: 2em">云起凡將不知蒼頡之更古崔駰達旨卽揚雄解</span>  
<span style="margin-left: 2em">嘲之類而别立㫖之一名崔瑗草書𫝑乃論草書</span>  
<span style="margin-left: 2em">之筆𫝑而强標𫝑之一目皆不足據爲典要至於</span>  
<span style="margin-left: 2em">謝恩曰章文心雕龍載有明釋乃<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">以謝恩兩字</span>  
<span style="margin-left: 2em">爲文章之名尤屬未協疑爲依托併書末洪适一</span>  
<span style="margin-left: 2em">跋亦疑從盤州集中鈔入然王得臣爲嘉祐中人</span>  
<span style="margin-left: 2em">而所作麈史有曰梁任昉集秦漢以來文章名之</span>  
<span style="margin-left: 2em">始目曰文章緣起自詩賦離騷至於藝約凡八十</span>  
<!-- 册5 葉873b　Page:文淵閣四庫全書_0005冊.djvu/223 -->
<span style="margin-left: 2em">五題可謂博矣旣載相如喻蜀不錄<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3951.svg?width=24" alt="四庫全書僻字第3951號（揚 --（『昜』上『旦』之『日』與『一』相連））" title="四庫全書僻字第3951號（揚 --（『昜』上『旦』之『日』與『一』相連））">雄劇秦美</span>  
<span style="margin-left: 2em">新錄解嘲而不收韓非說難取劉向列女傳而遺</span>  
<span style="margin-left: 2em">陳壽三國志評又曰任昉以三言詩起晉夏侯湛</span>  
<span style="margin-left: 2em">唐劉存以爲始鷺于飛醉言歸任以頌起漢之王</span>  
<span style="margin-left: 2em">褒劉以始於周公時邁任以檄起漢陳琳檄曹操</span>  
<span style="margin-left: 2em">劉以始於張儀檄楚任以碑起於漢惠帝作四皓</span>  
<span style="margin-left: 2em">碑劉以管子謂無懷氏封太山刻石紀功爲碑任</span>  
<span style="margin-left: 2em">以銘起於秦始皇登會稽山劉以爲蔡邕銘論黄</span>  
<span style="margin-left: 2em">帝有巾机之銘云云所說一一與此本合知北宋</span>  
<!-- 册5 葉876a　Page:文淵閣四庫全書_0005冊.djvu/224 -->
