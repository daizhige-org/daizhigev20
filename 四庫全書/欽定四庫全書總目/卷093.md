## 欽定四庫全書總目 卷九十三　子部三　儒家類三

欽定四庫全書總目卷九十三  
<span style="margin-left: 1em">子部三</span>  
<span style="margin-left: 2em">儒家類三</span>  
讀書分年日程三卷<sub class="note-yuan">編修勵守謙家藏本</sub>  
<span style="margin-left: 2em">元程端禮撰端禮字敬叔號畏齋鄞縣人以薦爲</span>  
<span style="margin-left: 2em">建平教諭遷台州路教授事蹟具元史儒學傳是</span>  
<span style="margin-left: 2em">書有延祐二年自序謂一本輔漢<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">所萃朱子讀</span>  
<span style="margin-left: 2em">書法修之考朱子讀書法六條一曰居敬持志二</span>  
<span style="margin-left: 2em">曰循序漸進三曰熟讀精思四曰虛心涵泳五曰</span>  
<!-- 册3 葉188b　Page:文淵閣四庫全書_0003冊.djvu/52 -->
<span style="margin-left: 2em">切巳體察六曰著𦂳用力端禮本其法而推廣之</span>  
<span style="margin-left: 2em">雖每年月日讀書程限不同而一以六條爲綱領</span>  
<span style="margin-left: 2em">史稱所著有讀書工程國子監以頒示郡縣卽此</span>  
<span style="margin-left: 2em">書也然書末又有端禮自䟦厯敘崇德吳氏平江</span>  
<span style="margin-left: 2em">陸氏池州馮氏及江浙諸處鈔刋各本而不及國</span>  
<span style="margin-left: 2em">子監頒示事則本傳所云或端禮身後之事歟䟦</span>  
<span style="margin-left: 2em">作於元統三年十一月朔考順帝以元統三年十</span>  
<span style="margin-left: 2em">一月辛丑改元至元此標十一月朔則尙在辛丑</span>  
<span style="margin-left: 2em">改元之前故仍稱元統云</span>  
<!-- 册3 葉189a　Page:文淵閣四庫全書_0003冊.djvu/52 -->
辨惑編四卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">元謝應芳撰應芳有思賢錄已著錄是編作於至</span>  
<span style="margin-left: 2em">正中因吳俗信<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">神多拘忌乃引古人事迹及先</span>  
<span style="margin-left: 2em">儒議論一一條析而辨之其目凡十五一曰死生</span>  
<span style="margin-left: 2em">二曰疫癘三曰<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">神四曰祭祀五曰淫祀六曰妖</span>  
<span style="margin-left: 2em">怪七曰巫覡八曰卜筮九曰治喪十曰擇塟十一</span>  
<span style="margin-left: 2em">曰相法十二曰祿命十三曰方位十四曰時日十</span>  
<span style="margin-left: 2em">五曰異端末一卷附錄書及襍著八篇皆力闢俗</span>  
<span style="margin-left: 2em">見齗齗然據理以爭與是編相發明者也昔宋儲</span>  
<!-- 册3 葉189b　Page:文淵閣四庫全書_0003冊.djvu/52 -->
<span style="margin-left: 2em">泳作祛疑說原本久佚惟左圭百川學海中載其</span>  
<span style="margin-left: 2em">節本應芳此書持論雖似乎淺近而能因風俗而</span>  
<span style="margin-left: 2em">藥之用以開導愚迷其有益於勸戒與泳書相等</span>  
<span style="margin-left: 2em">而持論較泳尤正大正不得以平易忽之曹安讕</span>  
<span style="margin-left: 2em">言長語曰毘陵謝子蘭取聖賢問答之詞闢異端</span>  
<span style="margin-left: 2em">者爲書名曰辨惑編經書子史先儒扶正抑邪之</span>  
<span style="margin-left: 2em">言備載眞可以正人心蓋深取之也惟葉盛水東</span>  
<span style="margin-left: 2em">日記曰毘陵謝子蘭氏辨惑編一書誠亦闢邪植</span>  
<span style="margin-left: 2em">正有益於世其中援据經法深怪世人惑於淫祀</span>  
<!-- 册3 葉192a　Page:文淵閣四庫全書_0003冊.djvu/53 -->
<span style="margin-left: 2em">當矣乃云自其先人亡後卽以所事神影火之以</span>  
<span style="margin-left: 2em">其非義之故此獨惜其過當春秋書毁泉臺君子</span>  
<span style="margin-left: 2em">以爲臺之存毁非安危治亂所繫雖勿居可也何</span>  
<span style="margin-left: 2em">必暴揚其失非之毁之至是𫆀子蘭之闢淫祀先</span>  
<span style="margin-left: 2em">儒成說甚多正不必此雖不言可也愛子蘭者須</span>  
<span style="margin-left: 2em">削而去之云云其言切中應芳之失蓋講學之家</span>  
<span style="margin-left: 2em">在往矯枉過<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">此亦其一讀者取其大旨之正可</span>  
<span style="margin-left: 2em">矣</span>  
治世龜鑑一卷<sub class="note-yuan">浙江鄭大節家藏本</sub>  
<!-- 册3 葉192b　Page:文淵閣四庫全書_0003冊.djvu/53 -->
<span style="margin-left: 2em">元蘇天爵撰天爵有名臣事畧已著錄此書爲成</span>  
<span style="margin-left: 2em">化丙午吳江知縣太和陳堯弼所刋篇首天爵結</span>  
<span style="margin-left: 2em">銜題中奉大夫浙江等處行中書省叅知政事考</span>  
<span style="margin-left: 2em">元史天爵本傳凡兩拜是官一在至正七年一在</span>  
<span style="margin-left: 2em">至正十二年此書前有林興祖趙汸二序皆標至</span>  
<span style="margin-left: 2em">正十二年壬辰正月則作於再任之日是時妖㓂</span>  
<span style="margin-left: 2em">自淮右延及冮東詔天爵總兵饒信克復一路六</span>  
<span style="margin-left: 2em">縣正干戈俶擾之際乃能留心於治理所採皆宋</span>  
<span style="margin-left: 2em">以前善政嘉言而大旨歸於培養元氣其目凡六</span>  
<!-- 册3 葉193a　Page:文淵閣四庫全書_0003冊.djvu/53 -->
<span style="margin-left: 2em">一曰治體一曰用人一曰守令一曰愛民一曰爲</span>  
<span style="margin-left: 2em">政而終之以止盜殆有深意也天爵著述載於本</span>  
<span style="margin-left: 2em">傳者名臣事畧十五卷文類七十卷松㕔章疏五</span>  
<span style="margin-left: 2em">卷春風亭筆記二卷詩七卷文三十卷又載有遼</span>  
<span style="margin-left: 2em">金紀元黃河源委二書未及脫稿而不載此書然</span>  
<span style="margin-left: 2em">趙汸序今載東山存稿第二卷中與此本一一相</span>  
<span style="margin-left: 2em">合知非僞託本傳葢偶遺之亦足証元史之多疎</span>  
<span style="margin-left: 2em">矣</span>  
管窺外篇二卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<!-- 册3 葉193b　Page:文淵閣四庫全書_0003冊.djvu/53 -->
<span style="margin-left: 2em">元史伯璿撰伯璿有四書管窺已著錄是書成於</span>  
<span style="margin-left: 2em">至元丁未葢繼管窺而作皆條記友人問答以闡</span>  
<span style="margin-left: 2em">發其餘義大抵皆辨証之文不主於詮釋文句故</span>  
<span style="margin-left: 2em">曰外篇實卽伯璿之語錄經義考四書類中惟列</span>  
<span style="margin-left: 2em">管窺而不載此書葢由於此非<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">尊疎漏也然管</span>  
<span style="margin-left: 2em">窺所論猶僅於胡炳文陳櫟之流叅稽同異此書</span>  
<span style="margin-left: 2em">於天文厯算地理田制言之頗詳多有所援据考</span>  
<span style="margin-left: 2em">證則較炳文及櫟見聞稍博尙非暖暖姝姝守一</span>  
<span style="margin-left: 2em">家之語錄者惟論天𧰼疑月星本自有光不待日</span>  
<!-- 册3 葉196a　Page:文淵閣四庫全書_0003冊.djvu/54 -->
<span style="margin-left: 2em">以受光之類未免仍渉臆斷是則宋元間儒者之</span>  
<span style="margin-left: 2em">積習消除未盡耳自明以來未有刋本康熙乙亥</span>  
<span style="margin-left: 2em">其邑人吕宏誥始以付梓雍正壬子王靈露等復</span>  
<span style="margin-left: 2em">續補成之乃得行於世云</span>  
内訓一卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明仁孝文皇后撰案成袓以簒逆取國淫刑肆𭧂</span>  
<span style="margin-left: 2em">無善可稱后乃特以賢著是書凡二十篇曰德性</span>  
<span style="margin-left: 2em">曰修身曰愼言曰謹行曰勤勵曰警戒曰節儉曰</span>  
<span style="margin-left: 2em">積善曰遷善曰崇聖訓曰景賢範曰事父母曰事</span>  
<!-- 册3 葉196b　Page:文淵閣四庫全書_0003冊.djvu/54 -->
<span style="margin-left: 2em">君曰事舅姑曰奉祭祀曰母儀曰睦親曰慈㓜曰</span>  
<span style="margin-left: 2em">逮下曰待外戚前有永樂三年正月望日自序内</span>  
<span style="margin-left: 2em">有肅事今皇上三十餘年之語考明史后妃傳后</span>  
<span style="margin-left: 2em">以洪武九年册爲燕王妃至永樂三年正月甫及</span>  
<span style="margin-left: 2em">三十年云三十餘年蓋約畧大數耳又考本傳載</span>  
<span style="margin-left: 2em">后撰此書頒行天下在永樂三年而明朝典彚載</span>  
<span style="margin-left: 2em">五年十一月以仁孝皇后内訓頒羣臣俾教於家</span>  
<span style="margin-left: 2em">若五年以前已頒行天下不應至五年之末始賜</span>  
<span style="margin-left: 2em">羣臣又考名山藏坤則記載后初爲此書不過示</span>  
<!-- 册3 葉197a　Page:文淵閣四庫全書_0003冊.djvu/54 -->
<span style="margin-left: 2em">皇太子諸王而已至永樂五年七月以後成祖乃</span>  
<span style="margin-left: 2em">出后内訓觀善二書頒賜臣民與典彚相合此本</span>  
<span style="margin-left: 2em">爲明初刋板首標大明仁孝皇后考后於永樂五</span>  
<span style="margin-left: 2em">年七月乙卯崩甲午諡曰仁孝則此本刊於五年</span>  
<span style="margin-left: 2em">七月以後無疑至十一月特賜臣民正屬刋行之</span>  
<span style="margin-left: 2em">始明史本傳偶未及檢耳各章之下繫以小註多</span>  
<span style="margin-left: 2em">渉頌揚當爲儒臣所加明史藝文志不著其名今</span>  
<span style="margin-left: 2em">遂無考又藝文志載内訓一卷高皇后撰勸善書</span>  
<span style="margin-left: 2em">一卷文皇后撰與本傳所載不同亦偶誤也</span>  
<!-- 册3 葉197b　Page:文淵閣四庫全書_0003冊.djvu/54 -->
理學𩔖編八卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明張九韶撰九韶字美和後以字行故明史附見</span>  
<span style="margin-left: 2em">宋訥傳作張美和淸江人元末累舉不仕洪武三</span>  
<span style="margin-left: 2em">年以薦爲縣學教諭遷國子監助教改翰林編修</span>  
<span style="margin-left: 2em">致仕歸後復徵入校書書成遣還兹編成於至正</span>  
<span style="margin-left: 2em">丙午乃未入明時所作初名格物編臨川吳當見</span>  
<span style="margin-left: 2em">之以爲所輯天地<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">神人物性命之說乃格物之</span>  
<span style="margin-left: 2em">一端不足以盡格物之義因爲易今名凡天地一</span>  
<span style="margin-left: 2em">卷天文二卷地理一卷<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">神一卷人物一卷性命</span>  
<!-- 册3 葉200a　Page:文淵閣四庫全書_0003冊.djvu/55 -->
<span style="margin-left: 2em">一卷異端一卷以周程張邵朱六子之言爲主而</span>  
<span style="margin-left: 2em">以荀子以下五十三家之說輔之復於每篇之末</span>  
<span style="margin-left: 2em">繹以已見其所採擷大都摘取精要不事博引繁</span>  
<span style="margin-left: 2em">稱故條理次序頗爲精宻前代如揚雄谷永淮南</span>  
<span style="margin-left: 2em">子之說近世如洪邁容齋五筆羅大經鶴林玉露</span>  
<span style="margin-left: 2em">之說並加摭集以叅觀互證亦不蹈講學家門戸</span>  
<span style="margin-left: 2em">之見其異端一門於陰陽相術䜟緯諸家斥駁眀</span>  
<span style="margin-left: 2em">切尤足以破世俗之惑史載明初司國子監者有</span>  
<span style="margin-left: 2em">宋訥王家會龔斆而九韶與聶鈜貝瓊亦皆名儒</span>  
<!-- 册3 葉200b　Page:文淵閣四庫全書_0003冊.djvu/55 -->
<span style="margin-left: 2em">當洪武時先後爲博士助教學錄以故諸生多所</span>  
<span style="margin-left: 2em">成就知其躬行導率無忝師範與徒爲高論者異</span>  
<span style="margin-left: 2em">矣</span>  
性理大全書七十卷<sub class="note-yuan">兵部侍郞紀昀家藏本</sub>  
<span style="margin-left: 2em">明胡廣等奉勅撰是書與五經四書大全同以永</span>  
<span style="margin-left: 2em">樂十三年九月告成奏進故成祖御製序文稱二</span>  
<span style="margin-left: 2em">百二十九卷統七部而計之也考自漢以來弟子</span>  
<span style="margin-left: 2em">錄其師說者始於鄭記鄭志是卽後世之語錄其</span>  
<span style="margin-left: 2em">裒諸儒之言以成一書者則古無是例近思錄其</span>  
<!-- 册3 葉201a　Page:文淵閣四庫全書_0003冊.djvu/55 -->
<span style="margin-left: 2em">權輿矣宋景定端平間周程張朱諸儒皆𫎇褒贈</span>
