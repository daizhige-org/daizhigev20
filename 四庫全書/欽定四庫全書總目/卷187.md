## 欽定四庫全書總目 卷一百八十七　集部四十　總集類二

<!-- 册5 葉100a　Page:文淵閣四庫全書_0005冊.djvu/30 -->
欽定四庫全書總目卷一百八十七  
<span style="margin-left: 1em">集部四十</span>  
<span style="margin-left: 2em">總集𩔖二</span>  
坡門酬唱集二十三卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">宋邵浩編浩字叔義金華人前有張叔椿序云嵗</span>  
<span style="margin-left: 2em">已酉朅來豫章機幕邵君實隆興同升出示巨編</span>  
<span style="margin-left: 2em">目曰坡門酬唱總成六百六十篇命工鋟木以廣</span>  
<span style="margin-left: 2em">其傳末題紹興元年五月二十四日又有浩自作</span>  
<span style="margin-left: 2em">引云紹興戊寅浩年未冠肄業成均隆興癸未始</span>  
<!-- 册5 葉100b　Page:文淵閣四庫全書_0005冊.djvu/30 -->
<span style="margin-left: 2em">得第以歸因取兩蘇公兄唱弟和及門下六君子</span>  
<span style="margin-left: 2em">平日屬和兩公之詩摭而錄之曰蘇門酬唱淳熙</span>  
<span style="margin-left: 2em">巳酉浩官豫章臨江謝公爲之作序且更曰坡門</span>  
<span style="margin-left: 2em">酬唱末題紹興庚戌四月一日考癸未爲孝宗隆</span>  
<span style="margin-left: 2em">興元年巳酉爲淳熙十六年上距高宗紹興元年</span>  
<span style="margin-left: 2em">辛亥巳五十九年且庚戌爲建炎四年亦不得題</span>  
<span style="margin-left: 2em">紹興二序紀年顯然有誤案淳熙巳酉孝宗内禪</span>  
<span style="margin-left: 2em">次年庚戌卽光宗紹熙元年則序内紹興必紹熙</span>  
<span style="margin-left: 2em">之訛特據浩引所言叔椿序當先成乃浩引題四</span>  
<!-- 册5 葉101a　Page:文淵閣四庫全書_0005冊.djvu/30 -->
<span style="margin-left: 2em">月叔椿序反題五月亦爲舛錯未合殆傳寫旣久</span>  
<span style="margin-left: 2em">或經後人所妄改歟前十六卷爲軾詩而轍及諸</span>  
<span style="margin-left: 2em">人和之者次轍詩四卷次黃庭堅秦觀晁補之張</span>  
<span style="margin-left: 2em">耒陳師道等詩三卷亦錄軾及諸人和作惟李廌</span>  
<span style="margin-left: 2em">闕焉其不在八人之數而別有繼和者亦皆附入</span>  
<span style="margin-left: 2em">爲注以别之其詩大抵本集所巳有然同題共韻</span>  
<span style="margin-left: 2em">之作比而觀之可以知其才力之强弱與意旨之</span>  
<span style="margin-left: 2em">異同較之散見諸集易於互勘於談藝者亦深有</span>  
<span style="margin-left: 2em">裨也至於山谷外集所載次韻子瞻書黄庭經尾</span>  
<!-- 册5 葉101b　Page:文淵閣四庫全書_0005冊.djvu/30 -->
<span style="margin-left: 2em">付蹇道士次韻晁補之廖正一贈答詩補之又有</span>  
<span style="margin-left: 2em">和子瞻種松贈杜輿秀才三首今坡集載坡詩止</span>  
<span style="margin-left: 2em">二首而此集均未編入小小掛漏在所不免亦不</span>  
<span style="margin-left: 2em">必爲之苛責矣</span>  
樂府詩集一百卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">宋郭茂倩撰建炎以來繋年要錄載茂倩爲侍讀</span>  
<span style="margin-left: 2em">學士郭褒之孫源中之子其仕履未詳本渾州須</span>  
<span style="margin-left: 2em">城人此本題曰太原葢署郡望也是集總括厯代</span>  
<span style="margin-left: 2em">樂府上起陶唐下迄五代凡郊廟歌詞十二卷燕</span>  
<!-- 册5 葉104a　Page:文淵閣四庫全書_0005冊.djvu/31 -->
<span style="margin-left: 2em">射歌詞三卷鼓吹曲詞五卷橫吹曲詞五卷相和</span>  
<span style="margin-left: 2em">歌詞十八卷淸商曲詞八卷舞曲歌詞五卷琴曲</span>  
<span style="margin-left: 2em">歌詞四卷襍曲歌詞十八卷近代曲詞四卷襍謡</span>  
<span style="margin-left: 2em">歌詞七卷新樂府詞十一卷其解題徵引浩博援</span>  
<span style="margin-left: 2em">据精審宋以來考樂府者無能出其範圍每題以</span>  
<span style="margin-left: 2em">古詞居前擬作居後使同一曲調而諸格畢備不</span>  
<span style="margin-left: 2em">相沿襲可以藥剽竊形似之失其古詞多前列本</span>  
<span style="margin-left: 2em">詞後列入樂所改得以考知孰爲側孰爲趨孰爲</span>  
<span style="margin-left: 2em">艷孰爲增字减字其聲詞合寫不可訓詁者亦皆</span>  
<!-- 册5 葉104b　Page:文淵閣四庫全書_0005冊.djvu/31 -->
<span style="margin-left: 2em">題下註明尤可以藥摹擬聱牙之𡚁誠樂府中第</span>  
<span style="margin-left: 2em">一善本明梅鼎祚古樂苑曰郭氏意務博擥間有</span>  
<span style="margin-left: 2em">詩題慁列樂府如採桑則劉邈萬山見採桑人從</span>  
<span style="margin-left: 2em">軍行則王粲從軍詩梁元帝同王僧辨從軍江淹</span>  
<span style="margin-left: 2em">擬李都尉從軍張正見星名從軍詩庾信同盧記</span>  
<span style="margin-left: 2em">室從軍之𩔖有取詩首一二語竄入前題如自君</span>  
<span style="margin-left: 2em">之出矣則鮑令暉題詩後𭔃行人長安少年行則</span>  
<span style="margin-left: 2em">何遜學古詩長安美少年之𩔖有辭𩔖前題原未</span>  
<span style="margin-left: 2em">名爲歌曲如苦𤍠行任昉何遜但云苦𤍠鬬雞篇</span>  
<!-- 册5 葉105a　Page:文淵閣四庫全書_0005冊.djvu/31 -->
<span style="margin-left: 2em">梁簡文但云鬬雞之𩔖有賦詩爲題而其本辭實</span>  
<span style="margin-left: 2em">非樂府若張正見晨雞高樹鳴本阮籍咏懷詩晨</span>  
<span style="margin-left: 2em">雞鳴高樹命駕起旋歸張率雀乳空井中本傅元</span>  
<span style="margin-left: 2em">襍詩鵲巢邱城側雀乳空井中之𩔖亦有全不相</span>  
<span style="margin-left: 2em">𫎇如善哉行則江淹擬魏文遊宴秋風則吳邁遠</span>  
<span style="margin-left: 2em">古意贈今人之𩔖有一題數篇半爲牽合如楊方</span>  
<span style="margin-left: 2em">合歡詩後三首爲襍詩採蓮曲則梁簡文後一首</span>  
<span style="margin-left: 2em">本蓮花賦中歌之𩔖並當刪正云云其說亦頗中</span>  
<span style="margin-left: 2em">理然卷帙旣繁牴牾難保司馬光通鑑猶病之何</span>  
<!-- 册5 葉105b　Page:文淵閣四庫全書_0005冊.djvu/31 -->
<span style="margin-left: 2em">况茂倩斯集要之大厦之材終不以寸朽棄也</span>  
古今嵗時襍詠四十六卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">宋蒲積中編積中履貫未詳初宋綬有嵗時襍咏</span>  
<span style="margin-left: 2em">二十卷晁公武郡齋讀書志謂宣獻昔在中書第</span>  
<span style="margin-left: 2em">三閣手編古詩及魏晉迄唐人嵗時章什釐爲十</span>  
<span style="margin-left: 2em">八卷今益爲二十卷積中因其原本續爲此書前</span>  
<span style="margin-left: 2em">有紹興丁卯自序稱宣獻所集允稱廣博然本朝</span>  
<span style="margin-left: 2em">如歐陽蘇黄與夫半山宛陵文潛無巳之流逢時</span>  
<span style="margin-left: 2em">感<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3004.svg?width=24" alt="四庫全書僻字第3004號（慨）" title="四庫全書僻字第3004號（慨）">發爲辭章不在古人下因取其卷目而擇今</span>  
<!-- 册5 葉108a　Page:文淵閣四庫全書_0005冊.djvu/32 -->
<span style="margin-left: 2em">代之詩附之名曰古今嵗時襍詠鋟板以傳葢所</span>  
<span style="margin-left: 2em">增惟宋人之詩而目𩔖則一仍其舊也晁公武載</span>  
<span style="margin-left: 2em">綬原本詩一千五百六首而此本二千七百四十</span>  
<span style="margin-left: 2em">九首比綬所錄增一千二百四十三首則一代之</span>  
<span style="margin-left: 2em">詩巳敵古人五分之四其蒐採亦可謂博矣其書</span>  
<span style="margin-left: 2em">自一卷至四十二卷爲元日至除夜二十八目其</span>  
<span style="margin-left: 2em">後四卷則凡祗題月令而無節序之詩皆附焉古</span>  
<span style="margin-left: 2em">來時令之詩摘錄編𩔖莫備於此非惟歌詠之林</span>  
<span style="margin-left: 2em">併亦典故之藪頗可以資採掇云</span>  
<!-- 册5 葉108b　Page:文淵閣四庫全書_0005冊.djvu/32 -->
嚴陵集九卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">宋董棻編棻東平人逌之子也自著曰廣川葢欲</span>  
<span style="margin-left: 2em">附仲舒裔耳紹興間知嚴州因輯嚴州詩文自謝</span>  
<span style="margin-left: 2em">靈運沈約以下迄於南宋之初前五卷皆詩第六</span>  
<span style="margin-left: 2em">卷詩後附賦二篇七卷至九卷則皆碑銘題記等</span>  
<span style="margin-left: 2em">襍文棻自序謂嘗與僚屬修是州圖經蒐求碑版</span>  
<span style="margin-left: 2em">稽考載籍所得逸文甚多又得郡人喻彦先家所</span>  
<span style="margin-left: 2em">藏書與教授沈愫廣求備錄而成是集中如司馬</span>  
<span style="margin-left: 2em">光獨樂園釣魚菴詩本作於洛中以首句用嚴子</span>  
<!-- 册5 葉109a　Page:文淵閣四庫全書_0005冊.djvu/32 -->
<span style="margin-left: 2em">陵事因牽而入於此集未免假借附會沿地志之</span>  
<span style="margin-left: 2em">陋習然所錄詩文唐以前人雖尙多習見至於宋</span>  
<span style="margin-left: 2em">人諸作自有專集者數人外他如曹輔吕希純陳</span>  
<span style="margin-left: 2em">瓘朱彦江公望江公著蔡肇張伯玉錢勰李昉扈</span>  
<span style="margin-left: 2em">𫎇劉昌言丁謂范師道張保雝章岷阮逸闗詠李</span>  
<span style="margin-left: 2em">師中龎籍孫<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3179.svg?width=24" alt="四庫全書僻字第3179號（沔）" title="四庫全書僻字第3179號（沔）">王存馮京刁約元綘張景修岑象</span>  
<span style="margin-left: 2em">求邵亢馬存陳軒吳可幾葉棐恭劉涇賈靑王達</span>  
<span style="margin-left: 2em">張綬余闢刁衍倪天隱周邦彦羅汝楫詹亢宗陳</span>  
<span style="margin-left: 2em">公亮錢聞詩諸人今有不知其名者有知名而不</span>  
<!-- 册5 葉109b　Page:文淵閣四庫全書_0005冊.djvu/32 -->
<span style="margin-left: 2em">見其集者藉棻是編尙存梗槩是亦談藝者所取</span>  
<span style="margin-left: 2em">資矣惟棻序作於紹興九年而第九卷中有錢聞</span>  
<span style="margin-left: 2em">詩浚西湖記作於淳熙十六年上距紹興九年凡</span>  
<span style="margin-left: 2em">五十一年又有陳公亮重修嚴先生祠堂記及書</span>  
<span style="margin-left: 2em">瑞粟圖二篇作於淳熙乙巳重修貢院記一篇作</span>  
<span style="margin-left: 2em">於淳熙丙午亦上距棻作序之時凡四十七八年</span>  
<span style="margin-left: 2em">則後人又有所附益已非棻之本書要亦宋人所</span>  
<span style="margin-left: 2em">續也</span>  
南嶽酬唱集一卷附錄一卷<sub class="note-yuan">編修汪如藻家藏本</sub>  
<!-- 册5 葉112a　Page:文淵閣四庫全書_0005冊.djvu/33 -->
<span style="margin-left: 2em">宋朱子與張栻林用中同遊南嶽偪和之詩也用</span>  
<span style="margin-left: 2em">中字擇之號東屏古田人嘗從朱子遊是集作於</span>  
<span style="margin-left: 2em">乾道二年十一月前有栻序稱來往湖湘二紀夢</span>  
<span style="margin-left: 2em">寐衡嶽之勝丁亥秋新安朱元晦來訪予湘水之</span>  
<span style="margin-left: 2em">上偕爲此遊朱子詩題中亦稱栻爲張湖南葢必</span>  
<span style="margin-left: 2em">栻當時官於衡湘間故有此稱而宋史本傳止載</span>  
<span style="margin-left: 2em">栻孝宗時任荆湖北路轉運副使後知江陵府安</span>  
<span style="margin-left: 2em">撫本路不言其曾官湖南疑史有脫漏也其遊自</span>  
<span style="margin-left: 2em">甲戌至庚辰凡七日朱子東歸亂藁序稱得詩百</span>  
<!-- 册5 葉112b　Page:文淵閣四庫全書_0005冊.djvu/33 -->
<span style="margin-left: 2em">四十餘首栻序亦云百四十有九篇今此本所錄</span>  
<span style="margin-left: 2em">止五十七題以朱子大全集參校所載又止五十</span>  
<span style="margin-left: 2em">題亦有大全集所有而此本失載者又每題皆三</span>  
<span style="margin-left: 2em">人同賦以五十七題計之亦不當云一百四十九</span>  
<span style="margin-left: 2em">篇不知何以參錯不合又卷中聯句往往失去姓</span>  
<span style="margin-left: 2em">氏標題其他詩亦多依朱子集中之題至有題作</span>  
<span style="margin-left: 2em">次敬夫韻而其詩實爲栻作者葢傳寫者訛誤脫</span>  
<span style="margin-left: 2em">佚非當日原本矣後有朱子與林用中書三十二</span>  
<span style="margin-left: 2em">篇用中遺事十條及朱子所作字序二首皆非此</span>  
<!-- 册5 葉113a　Page:文淵閣四庫全書_0005冊.djvu/33 -->
<span style="margin-left: 2em">集所應有或林氏後人所附益歟然以南嶽標題</span>  
<span style="margin-left: 2em">而泛及別地之尺牘以唱酬爲名而濫載平居之</span>  
<span style="margin-left: 2em">講論以三人合集而獨贅用中一人之言行皆非</span>  
<span style="margin-left: 2em">體例姑以原本所有存之云爾</span>  
萬首唐人絶句詩九十一卷<sub class="note-yuan">内府藏本</sub>
