## 欽定四庫全書總目 卷四十五　史部一　正史類

<!-- 册2 葉4：整葉圖版，無文字記錄 -->
<!-- 册2 葉5a　Page:文淵閣四庫全書_0002冊.djvu/6 -->
欽定四庫全書總目卷四十五  
<span style="margin-left: 1em">史部總敘</span>  
<span style="margin-left: 2em">史之爲道撰述欲其簡考證則欲其詳莫簡於春</span>  
<span style="margin-left: 2em">秋莫詳於左傳魯史所錄具載一事之始末聖人</span>  
<span style="margin-left: 2em">觀其始末得其是非而後能定以一字之褒貶此</span>  
<span style="margin-left: 2em">作史之資考證也丘明錄以爲傳後人觀其始末</span>  
<span style="margin-left: 2em">得其是非而後能知一字之所以褒貶此讀史之</span>  
<span style="margin-left: 2em">資考證也苟無事迹雖聖人不能作春秋苟不知</span>  
<span style="margin-left: 2em">其事迹雖以聖人讀春秋不知所以褒貶儒者好</span>  
<!-- 册2 葉5b　Page:文淵閣四庫全書_0002冊.djvu/6 -->
<span style="margin-left: 2em">爲大言動曰舍傳以求經此其說必不通其或通</span>  
<span style="margin-left: 2em">者則必私求諸傳詐稱舍傳云爾司馬光通鑑世</span>  
<span style="margin-left: 2em">稱絶作不知其先爲長編後爲考異高似孫緯畧</span>  
<span style="margin-left: 2em">載其與宋敏求書稱到洛八年始了晉宋齊梁陳</span>  
<span style="margin-left: 2em">隋六代唐文字尤多依年月編次爲草卷以四丈</span>  
<span style="margin-left: 2em">爲一卷計不減六七百卷又稱光作通鑑一事川</span>  
<span style="margin-left: 2em">三四山處纂成用襍史諸書凡二百二十二家李</span>  
<span style="margin-left: 2em">燾巽巖集亦稱張新甫見洛陽有資治通鑑草稿</span>  
<span style="margin-left: 2em">盈兩屋<sub class="note-yuan">按燾集今已佚此據馬端臨文獻通考述其父廷鸞之言</sub>今觀其書如</span>  
<!-- 册2 葉8a　Page:文淵閣四庫全書_0002冊.djvu/7 -->
<span style="margin-left: 2em">淖方成禍水之語則採及飛燕外傳張彖氷山之</span>  
<span style="margin-left: 2em">語則採及開元天寳遺事並小說亦不遺之然則</span>  
<span style="margin-left: 2em">古來著錄於正史之外兼收博採列目分編其必</span>  
<span style="margin-left: 2em">有故矣今總括羣書分十五類首曰正史大綱也</span>  
<span style="margin-left: 2em">次曰編年曰別史曰襍史曰詔令奏議曰傳記曰</span>  
<span style="margin-left: 2em">史鈔曰載記皆參考紀傳者也曰時令曰地理曰</span>  
<span style="margin-left: 2em">職官曰政書曰目錄皆參考諸志者也曰史評參</span>  
<span style="margin-left: 2em">考論贊者也舊有譜牒一門然自唐以後譜學殆</span>  
<span style="margin-left: 2em">絶玉牒旣不頒於外家乘亦不上於官徒存虛目</span>  
<!-- 册2 葉8b　Page:文淵閣四庫全書_0002冊.djvu/7 -->
<span style="margin-left: 2em">故從刪焉考私家記載惟宋明兩代爲多葢宋明</span>  
<span style="margin-left: 2em">人皆好議論議論異則門戸分門戸分則朋黨立</span>  
<span style="margin-left: 2em">朋黨立則恩怨結恩怨旣結得志則排擠於朝廷</span>  
<span style="margin-left: 2em">不得志則以筆墨相報復其中是非顚倒頗亦熒</span>  
<span style="margin-left: 2em">聽然雖有疑獄合衆證而質之必得其情雖有虛</span>  
<span style="margin-left: 2em">詞叅衆說而核之亦必得其情張師棣南遷錄之</span>  
<span style="margin-left: 2em">妄鄰國之事無質也趙與峕賓退錄證以金國官</span>  
<span style="margin-left: 2em">制而知之碧雲騢一書誣謗文彦博范仲淹諸人</span>  
<span style="margin-left: 2em">晁公武以爲眞出梅堯臣王銍以爲出自魏泰邵</span>  
<!-- 册2 葉9a　Page:文淵閣四庫全書_0002冊.djvu/7 -->
<span style="margin-left: 2em">博又證其眞出堯臣可謂聚訟李燾卒參互而辨</span>  
<span style="margin-left: 2em">定之至今遂無異說此亦考證欲詳之一驗然則</span>  
<span style="margin-left: 2em">史部諸書自鄙倍冗雜灼然無可採錄外其有裨</span>  
<span style="margin-left: 2em">於正史者固均宜擇而存之矣</span>  
<span style="margin-left: 1em">史部一</span>  
<span style="margin-left: 2em">正史類</span>  
<span style="margin-left: 3em">正史之名見於隋志至宋而定著十有七明刊</span>  
<span style="margin-left: 3em">監板合宋遼金元四史爲二十有一</span>  
皇上欽定明史又  
<!-- 册2 葉9b　Page:文淵閣四庫全書_0002冊.djvu/7 -->
詔增舊唐書爲二十有三近蒐羅四庫薛居正舊五代  
<span style="margin-left: 3em">史得裒集成編欽禀</span>  
睿裁與歐陽脩書並列共爲二十有四今並從官本校  
<span style="margin-left: 3em">錄凡未經</span>  
宸斷者則悉不濫登葢正史體尊義與經配非懸諸  
令典莫敢私增所由與稗官野記異也其他訓釋音義  
<span style="margin-left: 3em">者如史記索隱之類掇拾遺闕者如補後漢書</span>  
<span style="margin-left: 3em">年表之類辨正異同者如新唐書糾謬之類校</span>  
<span style="margin-left: 3em">正字句者如兩漢刊誤補遺之類若別爲編次</span>  
<!-- 册2 葉12a　Page:文淵閣四庫全書_0002冊.djvu/8 -->
<span style="margin-left: 3em">尋檢爲繁卽各附本書用資叅證至宋遼金元</span>  
<span style="margin-left: 3em">四史譯語舊皆舛謬今悉改正以存其眞其子</span>  
<span style="margin-left: 3em">部集部亦均視此以考校釐訂自正史始謹發</span>  
<span style="margin-left: 3em">其凡於此</span>  
史記一百三十卷<sub class="note-yuan">内府刊本</sub>  
<span style="margin-left: 2em">漢司馬遷撰褚少孫補遷事迹具漢書本傳少孫</span>  
<span style="margin-left: 2em">據張守節正義引張晏之說以爲穎川人元成間</span>  
<span style="margin-left: 2em">博士又引褚顗家傳以爲梁相褚大弟之孫宣帝</span>  
<span style="margin-left: 2em">時爲博士寓居沛事大儒王式故號先生二說不</span>  
<!-- 册2 葉12b　Page:文淵閣四庫全書_0002冊.djvu/8 -->
<span style="margin-left: 2em">同然宣帝末距成帝初不過十七八年其相去亦</span>  
<span style="margin-left: 2em">未遠也案遷自序凡十二本紀十表八書三十世</span>  
<span style="margin-left: 2em">家七十二傳共爲百三十篇漢書本傳稱其十篇</span>  
<span style="margin-left: 2em">缺有錄無書張晏注以爲遷殁之後亡景帝紀武</span>  
<span style="margin-left: 2em">帝紀禮書樂書兵書漢興以來將相年表曰者列</span>  
<span style="margin-left: 2em">傳三王世家龜策列傳傳靳列傳劉知幾史通則</span>  
<span style="margin-left: 2em">以爲十篇未成有錄而已駁張晏之說爲非今考</span>  
<span style="margin-left: 2em">曰者龜策二傳並有太史公曰又有褚先生曰是</span>  
<span style="margin-left: 2em">爲補綴殘稿之明證當以知幾爲是也然漢志春</span>  
<!-- 册2 葉13a　Page:文淵閣四庫全書_0002冊.djvu/8 -->
<span style="margin-left: 2em">秋家載史記百三十篇不云有缺葢是時官本已</span>  
<span style="margin-left: 2em">以少孫所續合爲一編觀其曰者龜策二傳並有</span>  
<span style="margin-left: 2em">臣爲郞時云云是必常經奏進故有是稱其褚先</span>  
<span style="margin-left: 2em">生曰字殆後人追題以爲别識歟周密齊東野語</span>  
<span style="margin-left: 2em">摘司馬相如傳贊中有揚雄以爲靡麗之賦勸百</span>  
<span style="margin-left: 2em">而諷一語又摘公孫宏傳中有平帝元始中詔賜</span>  
<span style="margin-left: 2em">宏子孫爵語焦竑筆乘摘賈誼傳中有賈嘉最好</span>  
<span style="margin-left: 2em">學至孝昭時列爲九<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">語皆非遷所及見王懋竑</span>  
<span style="margin-left: 2em">白田襍著亦謂史記止紀年而無歲名今十二諸</span>  
<!-- 册2 葉13b　Page:文淵閣四庫全書_0002冊.djvu/8 -->
<span style="margin-left: 2em">侯年表上列一行載庚申甲子等字乃後人所增</span>  
<span style="margin-left: 2em">則非惟有所散佚且兼有所改易年祀綿邈今亦</span>  
<span style="margin-left: 2em">不得而考矣然字句竄亂或不能無至其全書則</span>  
<span style="margin-left: 2em">仍遷原本焦竑筆乘據張湯傳贊如淳註以爲續</span>  
<span style="margin-left: 2em">之者有馮商孟柳又據後漢書楊經傳以爲嘗刪</span>  
<span style="margin-left: 2em">遷盡爲十餘萬言指今史記非本書則非其實也</span>  
<span style="margin-left: 2em">其書自晉唐以來傳本無大同異惟唐開元二十</span>  
<span style="margin-left: 2em">三年勅升史記老子列傳於伯夷列傳上錢曾讀</span>  
<span style="margin-left: 2em">書敏求記云尙有宋刻今未之見南宋廣漢張材</span>  
<!-- 册2 葉16a　Page:文淵閣四庫全書_0002冊.djvu/9 -->
<span style="margin-left: 2em">又嘗刊去褚少孫所續趙山甫復病其不全取少</span>  
<span style="margin-left: 2em">孫書别刊附入今亦均未見其本世所通行惟此</span>  
<span style="margin-left: 2em">本耳至僞孫奭孟子疏所引史記西子金錢事今</span>  
<span style="margin-left: 2em">本無之葢宋人詐託古書非今本之脫漏又學海</span>  
<span style="margin-left: 2em">類編中載僞洪遵史記眞本凡例一卷於原書臆</span>  
<span style="margin-left: 2em">爲刊削稱卽遷藏在名山之舊稿其事與梁鄱陽</span>  
<span style="margin-left: 2em">王漢書眞本相類益荒誕不足爲據矣註其書者</span>  
<span style="margin-left: 2em">今惟裴駰司馬貞張守節三家尙存其初各爲部</span>  
<span style="margin-left: 2em">帙北宋始合爲一編明代國子監刊板頗有所刊</span>  
<!-- 册2 葉16b　Page:文淵閣四庫全書_0002冊.djvu/9 -->
<span style="margin-left: 2em">除㸃竄南監本至以司馬貞所補三皇本紀冠五</span>  
<span style="margin-left: 2em">帝本紀之上殊失舊觀然彚合羣說檢㝷較易故</span>  
<span style="margin-left: 2em">今錄合併之本以便觀覽仍别錄三家之書以存</span>  
<span style="margin-left: 2em">其完本焉</span>  
史記集解一百三十卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">宋裴駰撰駰字龍駒河東聞喜人官至南中郞叅</span>  
<span style="margin-left: 2em">軍其事迹附見於宋書裴松之傳駰以徐廣史記</span>  
<span style="margin-left: 2em">音義粗有發明殊恨省畧乃采九經諸史并漢書</span>  
<span style="margin-left: 2em">音義及衆書之目别撰此書其所引證多先儒舊</span>  
<!-- 册2 葉17a　Page:文淵閣四庫全書_0002冊.djvu/9 -->
<span style="margin-left: 2em">說張守節正義甞備述所引書目次然如國語多</span>  
<span style="margin-left: 2em">引虞翻注孟子多引劉熙注韓詩多引薛君注而</span>  
<span style="margin-left: 2em">守節未著於目知當日援據浩博守節不能遍數</span>  
<span style="margin-left: 2em">也原本八十卷隋唐志著錄並同此本爲毛氏汲</span>  
<span style="margin-left: 2em">古閣所刊析爲一百三十卷原第遂不可考然註</span>  
<span style="margin-left: 2em">文猶仍舊本自明代監本以索隱正義附入其後</span>  
<span style="margin-left: 2em">又妄加刪削訛舛遂多如五帝本紀昔高陽氏有</span>  
<span style="margin-left: 2em">才子八人句下高辛氏有才子八人句下均脫名</span>  
<span style="margin-left: 2em">見左傳四字秦始皇本紀輕車重馬東就食句下</span>  
<!-- 册2 葉17b　Page:文淵閣四庫全書_0002冊.djvu/9 -->
<span style="margin-left: 2em">脫徐廣曰一無此重字八字項羽本紀其九月會</span>  
<span style="margin-left: 2em">稽守句下脫徐廣曰爾時未言太守九字武帝紀</span>  
<span style="margin-left: 2em">祠上帝明堂句下脫徐廣曰常五年一修耳今適</span>  
<span style="margin-left: 2em">二年故但祀明堂十八字然其效可覩矣句下脫</span>  
<span style="margin-left: 2em">又數本皆無可字七字河渠書岸善崩句下脫如</span>  
<span style="margin-left: 2em">淳曰河水岸六字司馬相如傳傍徨乎海外句下</span>  
<span style="margin-left: 2em">此引郭璞云靑邱山名上有田亦有國出九尾狐</span>  
<span style="margin-left: 2em">在海外太史公自序易大傳句下此引張晏曰謂</span>  
<span style="margin-left: 2em">易繫辭監本均誤作正義至於字句異同前後互</span>  
<!-- 册2 葉20a　Page:文淵閣四庫全書_0002冊.djvu/10 -->
<span style="margin-left: 2em">見如夏本紀九江入賜大龜句下孔安國日出於</span>  
<span style="margin-left: 2em">九江水中監本作山中孝文本紀昌至渭橋句下</span>  
<span style="margin-left: 2em">引蘇林曰在長安北三里監本多渭橋二字祁侯</span>  
<span style="margin-left: 2em">賀爲將軍句下引徐廣曰姓繪監本多一賀字當</span>  
<span style="margin-left: 2em">有玉英見句下引瑞應圖云玉英五帝並修則見</span>  
<span style="margin-left: 2em">監本作五常<sub class="note-yuan">案五帝並修語不可解似當以監本爲是</sub>屬國悍爲將屯</span>  
<span style="margin-left: 2em">將軍句下引徐廣曰姓徐監本多一悍字孝景本</span>  
<span style="margin-left: 2em">紀封故御史大夫周苛孫平爲繩侯句下引徐廣</span>  
<span style="margin-left: 2em">曰一作應監本多一平字武帝紀自太主句下引</span>  
<!-- 册2 葉20b　Page:文淵閣四庫全書_0002冊.djvu/10 -->
<span style="margin-left: 2em">徐廣曰武帝姑也監本多太主二字龜策列傳蝟</span>  
<span style="margin-left: 2em">辱於鵲句下引郭璞曰蝟憎其意心惡之也監本</span>  
<span style="margin-left: 2em">作而心惡之凡此之類當由古注簡質後人以意</span>  
<span style="margin-left: 2em">爲增益已失其舊至坊本流傳脫誤尤甚如夏本</span>
