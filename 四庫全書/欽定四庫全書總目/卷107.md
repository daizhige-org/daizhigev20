## 欽定四庫全書總目 卷一百七　子部十七　天文算法類、天文算法類存目

<!-- 册3 葉1216：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷一百七  
<span style="margin-left: 1em">子部十七</span>  
<span style="margin-left: 2em">天文算法𩔖</span>  
九章算術九卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">謹按九章算術蓋周禮保氏之遺法不知何人所</span>  
<span style="margin-left: 2em">傳永樂大典引古今事通曰王孝通言周公制禮</span>  
<span style="margin-left: 2em">有九章之名其理幽而微其形秘而約張蒼刪補</span>  
<span style="margin-left: 2em">殘缺校其條目頗與古術不同云云今考書内有</span>  
<span style="margin-left: 2em">長安上林之名上林苑在武帝時蒼在漢初何緣</span>  
<!-- 册3 葉1217b　Page:文淵閣四庫全書_0003冊.djvu/309 -->
<span style="margin-left: 2em">預載知述是書者在西漢中葉後矣舊本有注題</span>  
<span style="margin-left: 2em">曰劉徽所作考晉書稱魏景元四年劉徽注九章</span>  
<span style="margin-left: 2em">然注中所云晉武庫銅斛則徽入晉之後又有増</span>  
<span style="margin-left: 2em">損矣又有注釋題曰李淳風所作考唐書稱淳風</span>  
<span style="margin-left: 2em">等奉詔注九章算術爲算經十書之首國子監置</span>  
<span style="margin-left: 2em">算學生三十人習九章及海島算經共限三歲葢</span>  
<span style="margin-left: 2em">卽是時作也北宋以來其術罕傳自沈括夢溪筆</span>  
<span style="margin-left: 2em">談以外士大夫少留意者書遂幾於散佚洎南宋</span>  
<span style="margin-left: 2em">慶元中鮑澣之始得其本於楊忠輔家因傳寫以</span>  
<!-- 册3 葉1220a　Page:文淵閣四庫全書_0003冊.djvu/310 -->
<span style="margin-left: 2em">入秘閣然流傳不廣至明又亡故二三百年來算</span>  
<span style="margin-left: 2em">術之家未有得睹其全者惟分載於永樂大典者</span>  
<span style="margin-left: 2em">依𩔖裒輯尙九篇具在考鮑澣之後序稱唐以來</span>  
<span style="margin-left: 2em">所傳舊圖至宋已亡又稱盈不足方程之篇咸缺</span>  
<span style="margin-left: 2em">淳風注文今校其所言一一悉合知卽慶元之舊</span>  
<span style="margin-left: 2em">本葢顯於唐晦於宋亡於明而幸逢</span>  
聖代表章之盛復完於今其𨼆其見若有數黙存於其  
<span style="margin-left: 2em">間非偶然矣謹排纂成編併考訂訛異各附案語</span>  
<span style="margin-left: 2em">於下方其注中指狀表目如朱實青實黃實之𩔖</span>  
<!-- 册3 葉1220b　Page:文淵閣四庫全書_0003冊.djvu/310 -->
<span style="margin-left: 2em">皆就圖中所列而言圖旣不存則其注猝不易曉</span>  
<span style="margin-left: 2em">今推尋注意爲之補圖以成完帙算數莫古於九</span>  
<span style="margin-left: 2em">數九數莫古於是書雖新法屢更愈推愈密而窮</span>  
<span style="margin-left: 2em">源探本要百變不離其宗錄而傳之固今古算學</span>  
<span style="margin-left: 2em">之弁冕矣</span>  
孫子算經三卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">案隋書經籍志有孫子算經二卷不注其名亦不</span>  
<span style="margin-left: 2em">著其時代唐書藝文志稱李淳風注甄鸞孫子算</span>  
<span style="margin-left: 2em">經三卷於孫子上冠以甄鸞葢如淳風之注周髀</span>  
<!-- 册3 葉1221a　Page:文淵閣四庫全書_0003冊.djvu/310 -->
<span style="margin-left: 2em">算經因鸞所注更加辨論也隋書論審度引孫子</span>  
<span style="margin-left: 2em">算術蠶所吐絲爲忽十忽爲秒十秒爲毫十毫爲</span>  
<span style="margin-left: 2em">𨤲十𨤲爲分本書乃作十忽爲一絲十絲爲一毫</span>  
<span style="margin-left: 2em">又論嘉量引孫子算術六粟爲圭十圭爲秒十秒</span>  
<span style="margin-left: 2em">爲撮十撮爲勺十勺爲合本書乃作十圭爲一撮</span>  
<span style="margin-left: 2em">十撮爲一秒十秒爲一勺考之夏侯陽算經引田</span>  
<span style="margin-left: 2em">曹倉曹亦如本書而隋書中所引與史傳往往多</span>  
<span style="margin-left: 2em">合蓋古書傳本不一校訂之儒各有據證無妨叅</span>  
<span style="margin-left: 2em">差互見也唐之選舉算學孫子五曹共限一歲習</span>  
<!-- 册3 葉1221b　Page:文淵閣四庫全書_0003冊.djvu/310 -->
<span style="margin-left: 2em">肄於後來諸算術中特爲近古第不知孫子何許</span>  
<span style="margin-left: 2em">人朱𢑴尊曝書亭集五曹算經䟦云相傳其法出</span>  
<span style="margin-left: 2em">於孫武然孫子别有算經考古者存其說可爾又</span>  
<span style="margin-left: 2em">有孫子算經䟦云首言度量所起合乎兵法地生</span>  
<span style="margin-left: 2em">度度生量量生數之文次言乘除之法設爲之數</span>  
<span style="margin-left: 2em">十三篇中所云廓地分利委積遠輸貴賣兵役分</span>  
<span style="margin-left: 2em">數比之九章方田粟米差分商功均輸盈不足之</span>  
<span style="margin-left: 2em">日往往相符而要在得算多多算勝以是知是編</span>  
<span style="margin-left: 2em">非僞託也云云合二䟦觀之𢑴尊之意葢以爲<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）"></span>  
<!-- 册3 葉1224a　Page:文淵閣四庫全書_0003冊.djvu/311 -->
<span style="margin-left: 2em">出於孫武今考書内設問有云長安洛陽相去九</span>  
<span style="margin-left: 2em">百里又云佛書二十九章章六十三字則後漢明</span>  
<span style="margin-left: 2em">帝以後人語孫武春秋末人安有是語乎舊本久</span>  
<span style="margin-left: 2em">佚今從永樂大典所載裒集編次仍爲三卷其甄</span>  
<span style="margin-left: 2em">李二家之注則不可復考是則姚廣孝等割裂刋</span>  
<span style="margin-left: 2em">削之過矣</span>  
數術記遺一卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">舊題漢徐岳撰北周甄鸞注岳東萊人晉書律厯</span>  
<span style="margin-left: 2em">志所稱吳中書令闞澤受劉洪乾象法於東萊徐</span>  
<!-- 册3 葉1224b　Page:文淵閣四庫全書_0003冊.djvu/311 -->
<span style="margin-left: 2em">岳者是也隋書經籍志具列岳及甄鸞所撰九章</span>  
<span style="margin-left: 2em">算經七曜術算等目而獨無此書之名至唐藝文</span>  
<span style="margin-left: 2em">志始著於錄書中稱於泰山見劉會稽博識多聞</span>  
<span style="margin-left: 2em">徧於數術余因受業時問曰數有窮乎會稽曰吾</span>  
<span style="margin-left: 2em">曾游天目山中見有𨼆者云云大抵言其傳授之</span>  
<span style="margin-left: 2em">神秘然案後漢志注引袁山松書曰劉洪泰山𫎇</span>  
<span style="margin-left: 2em">陰人延熹中以校尉應太史徵拜郞中後爲會稽</span>  
<span style="margin-left: 2em">東部都尉徵還未至領丹陽太守卒官是洪官會</span>  
<span style="margin-left: 2em">稽後未嘗家居不得言於泰山見之且洪在會稽</span>  
<!-- 册3 葉1225a　Page:文淵閣四庫全書_0003冊.djvu/311 -->
<span style="margin-left: 2em">乃官都尉其爲太守實在丹陽而注以爲官會稽</span>  
<span style="margin-left: 2em">太守錯互殊甚又舊本皆題漢徐岳撰據晉書所</span>  
<span style="margin-left: 2em">載岳魏黄初中與太史丞韓詡論難日月食五事</span>  
<span style="margin-left: 2em">則岳已仕於魏不得繫之於漢攷古尤爲疎謬至</span>  
<span style="margin-left: 2em">天門金虎等語乃道家詭誕之說亦爲𨼆僻不經</span>  
<span style="margin-left: 2em">注所言算式數位按之正文多不相𫎇唐代選舉</span>  
<span style="margin-left: 2em">之制算學九章五曹之外兼習此書此必當時購</span>  
<span style="margin-left: 2em">求古算經好事者因托爲之而嫁名於岳耳然流</span>  
<span style="margin-left: 2em">傳旣久學者或以古本爲疑故仍錄存之而詳斥</span>  
<!-- 册3 葉1225b　Page:文淵閣四庫全書_0003冊.djvu/311 -->
<span style="margin-left: 2em">其僞以祛後人之惑焉</span>  
海島算經一卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">晉劉徽撰唐李淳風等奉詔注據劉徽序九章算</span>  
<span style="margin-left: 2em">術有云徽尋九數有重差之名凡望極高測絶深</span>  
<span style="margin-left: 2em">而兼知其遠者必用重差輙造重差并爲注解以</span>  
<span style="margin-left: 2em">究古人之意綴於勾股之下度高者重表測深者</span>  
<span style="margin-left: 2em">累矩孤離者三望離而又旁求者四望據此則徽</span>  
<span style="margin-left: 2em">之書本名重差初無海島之目亦但附於勾股之</span>  
<span style="margin-left: 2em">下不别爲書故隋志九章算術增爲十卷下云劉</span>  
<!-- 册3 葉1228a　Page:文淵閣四庫全書_0003冊.djvu/312 -->
<span style="margin-left: 2em">徽撰葢以九章九卷合此而爲十也而隋志唐志</span>  
<span style="margin-left: 2em">又皆有劉徽九章重差圖一卷葢其書亦另本單</span>  
<span style="margin-left: 2em">行故别著於錄一書兩出至唐志兼列劉向九章</span>  
<span style="margin-left: 2em">重差一卷則徽之重差旣自爲卷因遂訛劉徽爲</span>  
<span style="margin-left: 2em">劉向而一書三出耳今詳爲考證定爲劉徽之書</span>  
<span style="margin-left: 2em">至海島之名雖古無所見不過後人因卷首以海</span>  
<span style="margin-left: 2em">島之表設問而改斯名然唐選舉志稱算學生九</span>  
<span style="margin-left: 2em">章海島共限習三年試九章三條海島一條則改</span>  
<span style="margin-left: 2em">題海島自唐初已然矣其書世無傳本惟散見永</span>  
<!-- 册3 葉1228b　Page:文淵閣四庫全書_0003冊.djvu/312 -->
<span style="margin-left: 2em">樂大典中今裒而輯之仍爲一卷篇帙無多而古</span>  
<span style="margin-left: 2em">法具在固宜與九章算術同爲表章以見算數家</span>  
<span style="margin-left: 2em">源流之有自焉</span>  
五曹算經五卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">案隋書經籍志有九章六曹算經一卷而無五曹</span>  
<span style="margin-left: 2em">之目其六曹篇題亦不傳唐書藝文志始有甄鸞</span>  
<span style="margin-left: 2em">五曹算經五卷韓延五曹算經五卷李淳風注五</span>  
<span style="margin-left: 2em">曹孫子等算經二十卷魯續新集五曹時要術三</span>  
<span style="margin-left: 2em">卷甄韓二家皆注是書者也其作者則不知爲誰</span>  
<!-- 册3 葉1229a　Page:文淵閣四庫全書_0003冊.djvu/312 -->
<span style="margin-left: 2em">考漢書梅福傳福上書言臣聞齊桓之時有以九</span>  
<span style="margin-left: 2em">九見者顔師古注云九九算術若今九章五曹之</span>  
<span style="margin-left: 2em">輩葢算學雖多不出乘除二者而乘除不出自一</span>  
<span style="margin-left: 2em">至九因而九之之數故舉九九爲言而師古卽以</span>  
<span style="margin-left: 2em">其時所有九章五曹等書實之非梅福時有是書</span>  
<span style="margin-left: 2em">也朱<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">尊曝書亭集有五曹算經䟦云相傳其法</span>  
<span style="margin-left: 2em">岀於孫武然<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">尊第曰相傳無所引證益不足據</span>  
<span style="margin-left: 2em">觀唐書選舉志稱孫子五曹共限一歲旣日共限</span>  
<span style="margin-left: 2em">則五曹不出孫子明矣姑斷以甄鸞之注則其書</span>  
<!-- 册3 葉1229b　Page:文淵閣四庫全書_0003冊.djvu/312 -->
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">在北齊前耳自元明以來久無刻本藏書家傳</span>  
<span style="margin-left: 2em">寫訛舛殆不可通今散見永樂大典内者甄鸞韓</span>  
<span style="margin-left: 2em">延李淳風之注雖亦散佚而經文則逐條完善謹</span>  
<span style="margin-left: 2em">叅互考校俾還舊觀遂爲絶無僅有之善本考夏</span>  
<span style="margin-left: 2em">侯陽算經引田曹倉曹者二引金曹者一而此書</span>  
<span style="margin-left: 2em">皆無其文然此書首尾完具胍絡通貫不似有所</span>  
<span style="margin-left: 2em">亡佚疑隋志之九章六曹其目亦同陽所引田曹</span>  
<span style="margin-left: 2em">倉曹金曹等名乃别爲一書而非此書之文故不</span>  
<span style="margin-left: 2em">敢據以補入以溷其眞焉</span>  
<!-- 册3 葉1232a　Page:文淵閣四庫全書_0003冊.djvu/313 -->
五經算術二卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">北周甄鸞撰唐李淳風注鸞精於歩算仕北周爲</span>  
<span style="margin-left: 2em">司隸校尉漢中郡守嘗釋周髀等算經不聞其有</span>  
<span style="margin-left: 2em">是書而隋唐經籍志有五經算術一卷五經算術</span>  
<span style="margin-left: 2em">錄遺一卷皆不著撰人姓名唐藝文志則有李淳</span>  
<span style="margin-left: 2em">風注五經算術二卷亦不言其書爲誰所撰今考</span>  
<span style="margin-left: 2em">是書舉尙書孝經詩易論語三禮春秋之待算方</span>  
<span style="margin-left: 2em">明者列之而推算之術悉加甄鸞按三字於上則</span>
