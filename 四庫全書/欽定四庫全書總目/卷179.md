<span style="margin-left: 2em">雅澹格調在大厯以前今觀集中若夏日東園詩</span>  
<span style="margin-left: 2em">月落棋聲久涼生酒興多潛龍寺訪孟誠菴詩借</span>  
<span style="margin-left: 2em">宿閒多咏求名靜覺非春初過涵春閣詩酒嫌蘆</span>  
<span style="margin-left: 2em">笋少春恨李花多等句其格調頗近四靈殊未足</span>  
<span style="margin-left: 2em">追踪大厯至於文體聱牙更不出王李流𣲖矣</span>  
芝堂遺草七卷<sub class="note-yuan">福建廵撫採進本</sub>

<span style="margin-left: 2em">堂者朝榮判江州時有靈芝産於所作仕學軒前</span>  
<span style="margin-left: 2em">改軒曰瑞芝堂自爲之記因以名集朝榮詩格文</span>  
<span style="margin-left: 2em">格並明白坦易大抵偶然渉筆非刻意欲成一家</span>

<span style="margin-left: 2em">二卷爲初入翰林時作第三卷爲官南京時作第</span>  
<span style="margin-left: 2em">四卷爲使楚時作第五卷爲客粤時作題曰四遊</span>  
<span style="margin-left: 2em">蓋取於此第六卷乃還山以後之作亦併附焉</span>

<span style="margin-left: 2em">明朱孟震撰孟震有河上楮談已著錄此集文四</span>  
<span style="margin-left: 2em">卷詩四卷爲張九一所選錄文不出當時習尙詩</span>  
<span style="margin-left: 2em">則音節諧暢而意境不深</span>

<span style="margin-left: 2em">明于愼行撰愼行有讀史漫錄已著錄此集乃所</span>  
<span style="margin-left: 2em">作雜文也明中葉以後文格日卑學淺者蹈故守</span>  
<span style="margin-left: 2em">常才高者破律壞度愼行之文雖不渉弔詭之習</span>  
<span style="margin-left: 2em">至於精心結搆灝氣流行終未能與唐順之王愼</span>  
<!-- 册4 葉3141a　Page:文淵閣四庫全書_0004冊.djvu/790 -->
<span style="margin-left: 2em">中歸有光等並據壇坫故錄其詩集而文集則附</span>  
<span style="margin-left: 2em">存目焉</span>  
龎眉生集十六卷<sub class="note-yuan">山東廵撫採進本</sub>  
<span style="margin-left: 2em">明于愼思撰愼思字無妄號航隠東阿人于愼行</span>  
<span style="margin-left: 2em">之弟也是集詩七卷雜文八卷樂府一卷皆有縱</span>  
<span style="margin-left: 2em">横排奡之氣而頗渉粗豪</span>  
程糿博集六卷<sub class="note-yuan">浙江孫仰曾家藏本</sub>  
<span style="margin-left: 2em">明程大約撰大約字糿博休寜人是集爲于愼行</span>  
<span style="margin-left: 2em">所選凡雜文二卷詩四卷多暢所欲言不拘格律</span>  
<!-- 册4 葉3141b　Page:文淵閣四庫全書_0004冊.djvu/790 -->
<span style="margin-left: 2em">如泛駕之馬不可以羈勒範之前有焦竑序引孔</span>  
<span style="margin-left: 2em">子辭逹之說謂巷伯之譏刺巧言之怨悱何人斯</span>  
<span style="margin-left: 2em">之廹切自後世論之豈不傷温柔敦厚之體而聖</span>  
<span style="margin-left: 2em">人乃錄之於經以爲與辭逹之㫖有合又稱其骯</span>  
<span style="margin-left: 2em">髒之姿不爲世格所約結持論侃侃脂韋突梯之</span>  
<span style="margin-left: 2em">人多所不悅而亦爲慷<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3004.svg?width=24" alt="四庫全書僻字第3004號（慨）" title="四庫全書僻字第3004號（慨）">好義者之所深與則大</span>  
<span style="margin-left: 2em">約固賦性剛毅<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">情而徑行者宜發於文章亦肖</span>  
<span style="margin-left: 2em">其爲人也</span>  
雲東拾草十四卷附錄一卷<sub class="note-yuan">浙江孫仰曾家藏本</sub>  
<!-- 册4 葉3144a　Page:文淵閣四庫全書_0004冊.djvu/791 -->
<span style="margin-left: 2em">明韓世能撰世能字存錄長洲人隆慶戊辰進士</span>  
<span style="margin-left: 2em">官至南京禮部侍郞召入兼翰林學士事迹附見</span>  
<span style="margin-left: 2em">明史黄鳯翔傳世能以鑒藏書畫名一時張丑所</span>  
<span style="margin-left: 2em">爲輯南陽書畫表也史稱其教習庻吉士館閣文</span>  
<span style="margin-left: 2em">字是科爲盛考董其昌洛神賦十三行跋稱館師</span>  
<span style="margin-left: 2em">韓宗伯則當爲萬厯己丑科據明史文苑傳所載</span>  
<span style="margin-left: 2em">焦竑黄輝諸人固較他科爲稍勝然世能詩文則</span>  
<span style="margin-left: 2em">不出王李門徑是集爲所自編殁後二十年其子</span>  
<span style="margin-left: 2em">逢祜乃刋行附以誥勅諭祭𦵏文及碑銘傳狀</span>  
<!-- 册4 葉3144b　Page:文淵閣四庫全書_0004冊.djvu/791 -->
玉恩堂集九卷附錄一卷<sub class="note-yuan">浙江孫仰曾家藏本</sub>  
<span style="margin-left: 2em">明林景暘撰景暘字紹熙華亭人隆慶戊辰進士</span>  
<span style="margin-left: 2em">官至南京太僕寺卿是集爲其子有麟所編凡奏</span>  
<span style="margin-left: 2em">議二卷叅詞二卷詩二卷文三卷附錄碑誌行狀</span>  
<span style="margin-left: 2em">一卷王錫爵張以誠二序及張孟男所撰碑申時</span>  
<span style="margin-left: 2em">行所撰墓誌皆不稱其文章惟杜士全序及王圻</span>  
<span style="margin-left: 2em">所作行狀稍稱之云</span>  
醒後集五卷續集一卷附京省次五卷<sub class="note-yuan">福建廵撫採進本</sub>  
<span style="margin-left: 2em">明盧維禎撰維禎字瑞峰號水竹居士漳浦人隆</span>  
<!-- 册4 葉3145a　Page:文淵閣四庫全書_0004冊.djvu/791 -->
<span style="margin-left: 2em">慶戊辰進士官至戸部侍郞是集爲維禎致仕以</span>  
<span style="margin-left: 2em">後所自刊題曰醒後言如夢之醒也其集以奏疏</span>  
<span style="margin-left: 2em">公移評駁與詩文雜著共爲一編葢維禎留心吏</span>  
<span style="margin-left: 2em">事故案牘亦一一錄存末附京省次一冊中分地</span>  
<span style="margin-left: 2em">望次府州縣次財賦次會狀次甲科卿輔次蓋亦</span>  
<span style="margin-left: 2em">手錄成編以備紀事但刋入文集則濫矣</span>  
朱文懿文集十二卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">明朱賡撰賡字少欽浙江山陰人隆慶戊辰進士</span>  
<span style="margin-left: 2em">官至文華殿大學士事迹具明史本傳萬厯二十</span>  
<!-- 册4 葉3145b　Page:文淵閣四庫全書_0004冊.djvu/791 -->
<span style="margin-left: 2em">九年大學士趙志臯罷神宗慮朝臣植黨乃起賡</span>  
<span style="margin-left: 2em">入閣後沈一貫沈鯉並罷賡遂獨相七年史稱其</span>  
<span style="margin-left: 2em">醇謹無過然無所建白惟是時東林聲氣傾動一</span>  
<span style="margin-left: 2em">時賡獨借漢唐宋朋黨之害以立論謂漢之黨皆</span>  
<span style="margin-left: 2em">君子而罹小人之害其𫝑在小人故使卓操之徒</span>  
<span style="margin-left: 2em">得以假手而國移於强臣唐之黨君子小人互相</span>  
<span style="margin-left: 2em">攻擊其𫝑兩盛而卒兩敗故使朱全忠得以竊入</span>  
<span style="margin-left: 2em">而國移於盜賊宋之黨皆以德行文章標表一時</span>  
<span style="margin-left: 2em">其𫝑在君子而芟除太過不能使其身安於朝廷</span>

<span style="margin-left: 2em">之上故使吕蔡諸人得以藉口而國移於隣敵黨</span>  
<span style="margin-left: 2em">愈衆則害愈深變愈大其言切中時病厥後明社</span>  
<span style="margin-left: 2em">旣屋乃信賡言其深識早見有非顧葉諸人所及</span>  
<span style="margin-left: 2em">者其文則未能自成一家葢本不以詞章名也</span>  
王文端集十四卷<sub class="note-yuan">山西廵撫採進本</sub>  
<span style="margin-left: 2em">明王家屏撰家屏有王文端奏疏已著錄據明史</span>  
<span style="margin-left: 2em">藝文志其集凡二十卷千頃堂書目作復宿山房</span>  
<span style="margin-left: 2em">集凡四十卷今未見傳本是集奏疏四卷詩二卷</span>  
<span style="margin-left: 2em">尺牘八卷凡三種据尺牘卷首韓爌序稱家屏之</span>  
<!-- 册4 葉3148b　Page:文淵閣四庫全書_0004冊.djvu/792 -->
<span style="margin-left: 2em">子已裒彚全帙次第授梓則此其不完之本也朱</span>  
<span style="margin-left: 2em">彛尊明詩綜載其題長陵四駿圖古體詩四首茲</span>  
<span style="margin-left: 2em">集亦未載入知其散佚者多矣</span>  
溪山堂草四卷<sub class="note-yuan">浙江汪汝瑮家藏本</sub>  
<span style="margin-left: 2em">明沈思孝撰思孝有秦錄已著錄是編乃其晩年</span>  
<span style="margin-left: 2em">之作思孝名入瑯琊四十子之列論者謂其晩交</span>  
<span style="margin-left: 2em">姚士粦故間作聱牙之語然其有韻之文亦復流</span>  
<span style="margin-left: 2em">麗特雜著喜爲澁體耳</span>  
天遠樓集二十七卷<sub class="note-yuan">浙江孫仰曾家藏本</sub>  
<!-- 册4 葉3149a　Page:文淵閣四庫全書_0004冊.djvu/792 -->
<span style="margin-left: 2em">明徐顯卿撰顯卿字高望號檢菴長洲人隆慶戊</span>  
<span style="margin-left: 2em">辰進士官至吏部侍郞是集爲其嗣子元淓所編</span>  
<span style="margin-left: 2em">前有王穉登序曰先生卜居陽羡士大夫莫名先</span>  
<span style="margin-left: 2em">生文先生亦不自名文也余與先生雖同枌檟迹</span>  
<span style="margin-left: 2em">若風馬牛然第聞人言先生長者遂亦長者先生</span>  
<span style="margin-left: 2em">未幾先生來過余毎談立言之業不東向讓三卽</span>  
<span style="margin-left: 2em">南向讓再余竟莫名先生而僅識先生長者云云</span>  
<span style="margin-left: 2em">是殆有微詞矣</span>  
華禮部集八卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<!-- 册4 葉3149b　Page:文淵閣四庫全書_0004冊.djvu/792 -->
<span style="margin-left: 2em">明華叔陽撰叔陽字起龍無錫人隆慶戊辰進士</span>  
<span style="margin-left: 2em">官禮部主事年二十九卒叔陽爲華察之子王世</span>  
<span style="margin-left: 2em">貞之壻故所作五言頗有父風七言則詞調朗暢</span>  
<span style="margin-left: 2em">兼渉太倉流派其以詩部文部分卷亦仿世貞四</span>  
<span style="margin-left: 2em">部稿式也</span>  
閒雲館集鈔六卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明張位撰位有問竒集已著錄是集據于愼行原</span>  
<span style="margin-left: 2em">序有内外二編今本乃其從子希載所選錄故名</span>  
<span style="margin-left: 2em">集鈔毎篇具綴評語皆希載所爲明史稱位當神</span>  
<!-- 册4 葉3152a　Page:文淵閣四庫全書_0004冊.djvu/793 -->
<span style="margin-left: 2em">宗並封三王遽請篤修交泰早兆高禖及疏薦楊</span>  
<span style="margin-left: 2em">鎬依違礦稅諸事其疏稿是集皆不載葢希載諱</span>  
<span style="margin-left: 2em">而删之也又史稱位諡文莊而此集皆稱文端則</span>  
<span style="margin-left: 2em">未喻其故矣集刻於康熙九年而首有𥠖元寛序</span>  
<span style="margin-left: 2em">葢明末編訂之時元寛尙在云</span>  
江岷嶽文集四卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">明江以東撰以東字貞伯全椒人隆慶戊辰進士</span>  
<span style="margin-left: 2em">官至江西提學副使是集爲其門人謝廷諒謝廷</span>  
<span style="margin-left: 2em">讚舒曰敬晏文輝同編凡詩一卷文三卷皆不出</span>  
<!-- 册4 葉3152b　Page:文淵閣四庫全書_0004冊.djvu/793 -->
