## 欽定四庫全書總目 卷九十九　子部九　兵家類

欽定四庫全書總目卷九十九  
<span style="margin-left: 1em">子部九</span>  
<span style="margin-left: 2em">兵家𩔖</span>  
<span style="margin-left: 3em">史記穰苴列傳稱齊威王使大夫追論古者司</span>  
<span style="margin-left: 3em">馬兵法是古有兵法之明證然風后以下皆出</span>  
<span style="margin-left: 3em">依託其間孤虚王相之說雜以陰陽五行風雲</span>  
<span style="margin-left: 3em">氣色之說又雜以占候故兵家恒與術數相出</span>  
<span style="margin-left: 3em">入術數亦恒與兵家相出入要非古兵法也其</span>  
<span style="margin-left: 3em">最古者當以孫子吳子司馬法爲本大抵生聚</span>  
<!-- 册3 葉605b　Page:文淵閣四庫全書_0003冊.djvu/156 -->
<span style="margin-left: 3em">訓練之術權謀運用之宜而已今所採錄惟以</span>  
<span style="margin-left: 3em">論兵爲主其餘雜說悉别存目古來僞本流傳</span>  
<span style="margin-left: 3em">旣久者詞不害理亦併存以備一家明季遊士</span>  
<span style="margin-left: 3em">撰述尤爲猥雜惟擇其著有明效如戚繼光練</span>  
<span style="margin-left: 3em">兵實紀之𩔖者列於篇</span>  
握竒經一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">一作握機經一作幄機經舊本題風后撰漢丞相</span>  
<span style="margin-left: 2em">公孫宏解晉西平太守馬隆述讚案漢書藝文志</span>  
<span style="margin-left: 2em">兵家陰陽風后十三篇班固自註曰圖二卷依託</span>  
<!-- 册3 葉608a　Page:文淵閣四庫全書_0003冊.djvu/157 -->
<span style="margin-left: 2em">也並無握竒經之名且十三篇七畧著錄固尙以</span>  
<span style="margin-left: 2em">爲依託則此經此解七畧不著錄者其依託更不</span>  
<span style="margin-left: 2em">待辨矣馬隆述讚隋志亦不著錄則猶之公孫宏</span>  
<span style="margin-left: 2em">解也考唐獨孤及毘陵集有八陣圖記曰黄帝順</span>  
<span style="margin-left: 2em">煞氣以作兵法文昌以命將風后握機制勝作爲</span>  
<span style="margin-left: 2em">陣圖故八其陣所以定位也衡抗於外軸布於内</span>  
<span style="margin-left: 2em">風雲附其四維所以備物也虎張翼以進蛇向敵</span>  
<span style="margin-left: 2em">而蟠飛龍翔鳥上下其旁所以致用也至若疑兵</span>  
<span style="margin-left: 2em">以固其餘地游軍以案其後列門具將發然後合</span>  
<!-- 册3 葉608b　Page:文淵閣四庫全書_0003冊.djvu/157 -->
<span style="margin-left: 2em">戰弛張則二廣迭舉犄角則四竒皆出云云所說</span>  
<span style="margin-left: 2em">乃一一與此經合疑唐以來好事者因諸<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3575.svg?width=24" alt="四庫全書僻字第3575號（葛）" title="四庫全書僻字第3575號（葛）">亮八</span>  
<span style="margin-left: 2em">陣之法推演爲圖托之風后其後又因及此記推</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2973.svg?width=24" alt="四庫全書僻字第2973號（衍）" title="四庫全書僻字第2973號（衍）">以爲此經併取記中握機制勝之語以爲之名</span>  
<span style="margin-left: 2em">宋史藝文志始著於錄其晩出之顯證矣高似孫</span>  
<span style="margin-left: 2em">子畧曰馬隆本作幄機序曰幄者帳也大將所居</span>  
<span style="margin-left: 2em">言其事不可妄示人故云幄機則因握幄字近而</span>  
<span style="margin-left: 2em">附會其文今本多題曰握竒則又因經中有四爲</span>  
<span style="margin-left: 2em">正四爲竒餘竒爲握竒之語改易其名也似孫又</span>  
<!-- 册3 葉609a　Page:文淵閣四庫全書_0003冊.djvu/157 -->
<span style="margin-left: 2em">云總有三本一本三百六十字一本三百八十字</span>  
<span style="margin-left: 2em">葢吕尙增字以發明之其一行間有公孫宏等語</span>  
<span style="margin-left: 2em">今本<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2973.svg?width=24" alt="四庫全書僻字第2973號（衍）" title="四庫全書僻字第2973號（衍）">四字校騐此本分爲三章正得三百八十</span>  
<span style="margin-left: 2em">四字葢卽似孫所謂<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2973.svg?width=24" alt="四庫全書僻字第2973號（衍）" title="四庫全書僻字第2973號（衍）">四字本也經後原附續圖</span>  
<span style="margin-left: 2em">據書錄解題亦稱馬隆所補然有目而無圖殆傳</span>  
<span style="margin-left: 2em">寫佚之歟</span>  
六韜六卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">舊本題周吕望撰考莊子徐無<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">篇稱金版六弢</span>  
<span style="margin-left: 2em">經典釋文曰司馬彪崔譔云金版六弢皆周書篇</span>  
<!-- 册3 葉609b　Page:文淵閣四庫全書_0003冊.djvu/157 -->
<span style="margin-left: 2em">名本又作六韜謂太公六韜文武虎豹龍犬也<sub class="note-yuan">案今</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">本以文武龍虎豹犬爲次與陸德明所註不同未詳孰是謹附識於此</sub>則戰國之初</span>  
<span style="margin-left: 2em">原有是名然卽以爲太公六韜未知所據漢書藝</span>  
<span style="margin-left: 2em">文志兵家不著錄惟儒家有周史六弢六篇班固</span>  
<span style="margin-left: 2em">自註曰惠襄之間或曰顯王時或曰孔子問焉則</span>  
<span style="margin-left: 2em">六弢别爲一書顔師古註以今之六韜當之毋亦</span>  
<span style="margin-left: 2em">因陸德明之說而牽合附會歟三國志先主傳註</span>  
<span style="margin-left: 2em">始稱閒暇厯觀諸子及六韜商君書益人志意隋</span>  
<span style="margin-left: 2em">志始載太公六韜五卷註曰梁六卷周文王師姜</span>  
<!-- 册3 葉612a　Page:文淵閣四庫全書_0003冊.djvu/158 -->
<span style="margin-left: 2em">望撰唐宋諸志皆因之今考其文大抵詞意淺近</span>  
<span style="margin-left: 2em">不𩔖古書中間如避正殿乃戰國以後之事將軍</span>  
<span style="margin-left: 2em">二字始見左傳周初亦無此名<sub class="note-yuan">案路史有虞舜時伯益爲百蟲將軍</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">之語雜說依託不足爲據</sub>其依托之迹灼然可騐又龍韜中有</span>  
<span style="margin-left: 2em">陰符篇云主與將有陰符凡八等克敵之符長一</span>  
<span style="margin-left: 2em">尺破軍之符長九寸至失利之符長三寸而止葢</span>  
<span style="margin-left: 2em">僞撰者不知陰符之義誤以爲符節之符遂粉飾</span>  
<span style="margin-left: 2em">以爲此言尤爲鄙陋殆未必漢時舊本故周氏渉</span>  
<span style="margin-left: 2em">筆謂其書並緣吳起漁獵其詞而綴輯以近代軍</span>  
<!-- 册3 葉612b　Page:文淵閣四庫全書_0003冊.djvu/158 -->
<span style="margin-left: 2em">政之浮談淺駁無可施用胡應麟筆叢亦謂其文</span>  
<span style="margin-left: 2em">代陰書等篇爲孫吳尉繚所不屑道然晁公武讀</span>  
<span style="margin-left: 2em">書志稱元豐中以六韜孫子吳子司馬法黄石公</span>  
<span style="margin-left: 2em">三畧尉繚子李衛公問對頒行武學號曰七書則</span>  
<span style="margin-left: 2em">其來巳久談兵之家恒相稱述今故仍錄存之而</span>  
<span style="margin-left: 2em">畧論其踳駮如右</span>  
孫子一卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">周孫武撰考史記孫子列傳載武之書十三篇而</span>  
<span style="margin-left: 2em">漢書藝文志乃載孫子兵法八十二篇圖九卷故</span>  
<!-- 册3 葉613a　Page:文淵閣四庫全書_0003冊.djvu/158 -->
<span style="margin-left: 2em">張守節正義以十三篇爲上卷又有中下二卷杜</span>  
<span style="margin-left: 2em">牧亦謂武書本數十萬言皆曹操削其繁剩筆其</span>  
<span style="margin-left: 2em">精粹以成此書然史記稱十三篇在漢志之前不</span>  
<span style="margin-left: 2em">得以後來附益者爲本書牧之言固末可以爲據</span>  
<span style="margin-left: 2em">也此書注本極夥隋書經籍志所載自曹操外有</span>  
<span style="margin-left: 2em">王凌張子尙賈詡孟氏沈友諸家唐志益以李筌</span>  
<span style="margin-left: 2em">杜牧陳皥賈林孫鎬諸家馬端臨經籍考又有紀</span>  
<span style="margin-left: 2em">燮梅堯臣王晳何氏諸家歐陽修謂兵以不窮爲</span>  
<span style="margin-left: 2em">竒宜其說者之多其言最爲有理然至今傳者寥</span>  
<!-- 册3 葉613b　Page:文淵閣四庫全書_0003冊.djvu/158 -->
<span style="margin-left: 2em">寥應武舉者所誦習惟坊刻講章鄙俚淺陋無一</span>  
<span style="margin-left: 2em">可取故今但存其本文著之於錄武書爲百代談</span>  
<span style="margin-left: 2em">兵之祖葉適以其人不見於左傳疑其書乃春秋</span>  
<span style="margin-left: 2em">末戰國初山林處士之所爲然史記載闔閭謂武</span>  
<span style="margin-left: 2em">曰子之十三篇吾盡觀之矣則<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">爲武所自著非</span>  
<span style="margin-left: 2em">後人嫁名於武也</span>  
吳子一卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">周吳起撰起事蹟見史記列傳司馬遷稱起兵法</span>  
<span style="margin-left: 2em">世多有而不言篇數漢藝文志載吳起四十八篇</span>  
<!-- 册3 葉616a　Page:文淵閣四庫全書_0003冊.djvu/159 -->
<span style="margin-left: 2em">然隋志作一卷賈詡注唐志並同鄭樵通志畧又</span>  
<span style="margin-left: 2em">有孫鎬注一卷均無所謂四十八篇者葢亦如孫</span>  
<span style="margin-left: 2em">武之八十二篇出於附益非其本書世不傳也晁</span>  
<span style="margin-left: 2em">公武讀書志則作三卷稱唐陸希聲𩔖次爲之凡</span>  
<span style="margin-left: 2em">說國料敵治兵論將變化勵士六篇今所行本雖</span>  
<span style="margin-left: 2em">仍併爲一卷然篇目並與讀書志合惟變化作應</span>  
<span style="margin-left: 2em">變則未知孰誤耳起殺妻求將齧臂盟母其行事</span>  
<span style="margin-left: 2em">殊不足道然嘗受學於曾子耳濡目染終有典型</span>  
<span style="margin-left: 2em">故持論頗不詭於正如對魏武侯則曰在德不在</span>  
<!-- 册3 葉616b　Page:文淵閣四庫全書_0003冊.djvu/159 -->
<span style="margin-left: 2em">險論制國治軍則曰教之以禮勵之以義論爲將</span>  
<span style="margin-left: 2em">之道則曰所愼者五一曰理二曰備三曰果四曰</span>  
<span style="margin-left: 2em">戒五曰約大扺皆尙有先王節制之遺高似孫子</span>  
<span style="margin-left: 2em">畧謂其尙禮義明教訓或有得於司馬法者斯言</span>  
<span style="margin-left: 2em">允矣</span>  
可馬法一卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">舊題齊司馬穰苴撰今考史記穰苴列傳稱齊威</span>  
<span style="margin-left: 2em">王使大夫追論古者司馬兵法而附穰苴於其中</span>  
<span style="margin-left: 2em">因號曰司馬穰苴兵法然則是書乃齊國諸臣所</span>  
<!-- 册3 葉617a　Page:文淵閣四庫全書_0003冊.djvu/159 -->
<span style="margin-left: 2em">追輯隋唐諸志皆以爲穰苴之所自撰者非也漢</span>  
<span style="margin-left: 2em">志稱軍禮司馬法百五十五篇陳師道以傳記所</span>  
<span style="margin-left: 2em">載司馬法之文今書皆無之疑非全書然其言大</span>  
<span style="margin-left: 2em">抵據道依德本仁祖義三代軍政之遺規猶藉存</span>  
<span style="margin-left: 2em">什一於干百葢其時去古未遠先王舊典未盡無</span>  
<span style="margin-left: 2em">徵摭拾成編亦漢文博士追述王制之𩔖也班固</span>  
<span style="margin-left: 2em">序兵權謀十三家形𫝑十一家陰陽十六家技巧</span>  
<span style="margin-left: 2em">十三家獨以此書入禮𩔖豈非以其說多與周官</span>  
<span style="margin-left: 2em">相出入爲古來五禮之一歟胡應麟筆叢惜其以</span>  
<!-- 册3 葉617b　Page:文淵閣四庫全書_0003冊.djvu/159 -->
<span style="margin-left: 2em">穰苴所言叅伍於仁義禮樂之中不免懸疣附贅</span>  
<span style="margin-left: 2em">然要其大㫖終爲近正與一切權謀術數逈然别</span>  
<span style="margin-left: 2em">矣隋唐志俱作三卷世所行本以篇頁無多併爲</span>  
<span style="margin-left: 2em">一卷今亦從之以省繁碎焉</span>  
尉繚子五卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">周尉繚撰其人當六國時不知其本末或曰魏人</span>  
<span style="margin-left: 2em">以天官篇有梁惠王問知之或又曰齊人<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">谷子</span>  
<span style="margin-left: 2em">之弟子劉向别錄又云繚爲南君學未詳孰是也</span>  
<span style="margin-left: 2em">漢志雜家有尉繚二十九篇隋志作五卷唐志作</span>  
<!-- 册3 葉620a　Page:文淵閣四庫全書_0003冊.djvu/160 -->
