## 欽定四庫全書總目 卷三十三　經部三十三　五經總義類

<!-- 册1 葉2636：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷三十三  
<span style="margin-left: 1em">經部三十三</span>  
<span style="margin-left: 2em">五經總義類</span>  
<span style="margin-left: 3em">漢代經師如韓嬰治詩兼治易者其訓故皆各</span>  
<span style="margin-left: 3em">自爲書宣帝時始有石渠五經雜義十八篇漢</span>  
<span style="margin-left: 3em">志無類可隷遂雜置之孝經中隋志錄許愼五</span>  
<span style="margin-left: 3em">經異義以下諸家亦附論語之末舊唐書志始</span>  
<span style="margin-left: 3em">別名經解諸家著錄因之然不見兼括諸經之</span>  
<span style="margin-left: 3em">義朱彝尊作經義考別目曰羣經葢覺其未安</span>  
<!-- 册1 葉2637b　Page:文淵閣四庫全書_0001冊.djvu/709 -->
<span style="margin-left: 3em">而採劉勰正緯之語以改之然又不見爲訓詁</span>  
<span style="margin-left: 3em">之文徐乾學刻九經解顧湄兼採總集經解之</span>  
<span style="margin-left: 3em">義名曰總經解何焯復斥其不通<sub class="note-yuan">語見沈廷芳所刻何焯㸃</sub></span>  
<span style="margin-left: 3em"><sub class="note-yuan">校經解目錄中</sub>葢正名若是之難也考隋志於統說諸</span>  
<span style="margin-left: 3em">經者雖不别爲部分然論語類末稱孔叢家語</span>  
<span style="margin-left: 3em">爾雅諸書併五經總義附於此篇則固稱五經</span>  
<span style="margin-left: 3em">總義矣今準以立名庶猶近古論語孝經孟子</span>  
<span style="margin-left: 3em">雖自爲書實均五經之流别亦足以統該之其</span>  
<span style="margin-left: 3em">校正文字及傳經諸圖併約畧附焉從其類也</span>  
<!-- 册1 葉2640a　Page:文淵閣四庫全書_0001冊.djvu/710 -->
駮五經異義一卷補遺一卷<sub class="note-yuan">山西巡撫採進本</sub>  
<span style="margin-left: 2em">漢鄭元所駮許愼五經異義之文也考後漢書許</span>  
<span style="margin-left: 2em">愼傳稱愼以五經傳説臧否不同於是撰爲五經</span>  
<span style="margin-left: 2em">異義傳於世鄭元傳載元所著百餘萬言亦有駮</span>  
<span style="margin-left: 2em">許愼五經異義之名隋書經籍志有五經異義十</span>  
<span style="margin-left: 2em">卷後漢太尉祭酒許愼撰而不及鄭元之駮議舊</span>  
<span style="margin-left: 2em">唐書經籍志五經異義十卷許愼撰鄭元駮新唐</span>  
<span style="margin-left: 2em">書藝文志並同葢鄭氏所駮之文卽附見於許氏</span>  
<span style="margin-left: 2em">原本之内非別爲一書故史志所載亦互有詳畧</span>  
<!-- 册1 葉2640b　Page:文淵閣四庫全書_0001冊.djvu/710 -->
<span style="margin-left: 2em">宋史藝文志遂無此書之名則自唐以來失傳久</span>  
<span style="margin-left: 2em">矣學者所見異義僅出於初學記通典太平御覽</span>  
<span style="margin-left: 2em">諸書所引而鄭氏駮義則自三禮正義而外所存</span>  
<span style="margin-left: 2em">亦復寥寥此本從諸書採掇而成或題宋王應麟</span>  
<span style="margin-left: 2em">編然無<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">據其間有單詞隻句駮存而義闕者原</span>  
<span style="margin-left: 2em">本錯雜相㕘頗失條理今詳加釐正以義駮兩全</span>  
<span style="margin-left: 2em">者彚列於前其僅存駮義者則附錄以備㕘考又</span>  
<span style="margin-left: 2em">近時朱彝尊經義考内亦嘗旁引鄭駮數條而長</span>  
<span style="margin-left: 2em">洲惠氏所輯則蒐羅益爲廣備往往多此本所未</span>  
<!-- 册1 葉2641a　Page:文淵閣四庫全書_0001冊.djvu/710 -->
<span style="margin-left: 2em">及今以二家所採㕘互考證除其複重定著五十</span>  
<span style="margin-left: 2em">七條別爲補遺一卷附之於後其間有異義而鄭</span>  
<span style="margin-left: 2em">無駮者則鄭與許同者也兩漢經學號爲極盛若</span>  
<span style="margin-left: 2em">許若鄭尤皆一代通儒大敵相當輸攻墨守非後</span>  
<span style="margin-left: 2em">來一知半解所可望其津涯此編雖散佚之餘十</span>  
<span style="margin-left: 2em">不存一而引經據古猶見典型殘章斷簡固遠勝</span>  
<span style="margin-left: 2em">後儒之累牘連篇矣</span>  
鄭志三卷補遺一卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">案隋書經籍志鄭志十一卷魏侍中鄭小同撰鄭</span>  
<!-- 册1 葉2641b　Page:文淵閣四庫全書_0001冊.djvu/710 -->
<span style="margin-left: 2em">記六卷鄭元弟子撰後漢書鄭元本傳則稱門生</span>  
<span style="margin-left: 2em">相與撰元答弟子依論語作鄭志八篇劉知幾史</span>  
<span style="margin-left: 2em">通亦稱鄭弟子追論師說及應答謂之鄭志分受</span>  
<span style="margin-left: 2em">門徒各述師言更不問答謂之鄭記<sub class="note-yuan">案通典及初學記所引鄭</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">記均有王贊答詞與知幾所云更不問答者不合考孝經疏引此文作各述師言更爲問答知不字</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">乃爲字之訛王應麟玉海朱彝尊經義考並沿用誤本殊失訂正又通典所引鄭志皆元與門人問</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">答之詞所引鄭記皆其門人互相問答之詞知志之與記其別在此曲禮正義引鄭志有崇精之問</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">焦氏之答月令正義引鄭志有王權之問焦喬之答焦氏之問張逸之答疑本鄭記之文校刊者惟</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">據史通更不問答之說改爲鄭志也</sub>其說不同然范蔚宗去漢未遠</span>  
<!-- 册1 葉2644a　Page:文淵閣四庫全書_0001冊.djvu/711 -->
<span style="margin-left: 2em">其說當必有徵隋志根據七錄亦阮孝緒等所考</span>  
<span style="margin-left: 2em">定非唐宋諸志動輙疎舛者比斷無移甲入乙之</span>  
<span style="margin-left: 2em">事疑追錄之者諸弟子編次成帙者則小同後漢</span>  
<span style="margin-left: 2em">書原其始隋書要其終觀八篇分爲十一卷知非</span>  
<span style="margin-left: 2em">諸弟子之舊本也新舊唐書載鄭記六卷尙與隋</span>  
<span style="margin-left: 2em">志相同而鄭志則作九卷已佚二卷至崇文總目</span>  
<span style="margin-left: 2em">始不著錄則全佚於北宋初矣此本三卷莫考其</span>  
<span style="margin-left: 2em">出自誰氏觀書中禮運註澄酒一條答趙商之問</span>  
<span style="margin-left: 2em">者前後兩見而詳畧小異又陳鑠之名前後兩見</span>  
<!-- 册1 葉2644b　Page:文淵閣四庫全書_0001冊.djvu/711 -->
<span style="margin-left: 2em">而後一條註一作鏗知爲好鄭氏之學者惜其散</span>  
<span style="margin-left: 2em">佚於諸經正義裒輯而成然如所載弼成五服答</span>  
<span style="margin-left: 2em">趙商問一條不稱益稷而稱臯陶謨則正合孔疏</span>  
<span style="margin-left: 2em">所云鄭氏之本又卷首冷剛問大畜童牛之牿一</span>  
<span style="margin-left: 2em">條今周易正義中不見而周禮正義引之較此少</span>  
<span style="margin-left: 2em">冷剛問云以下六十餘字周襛正義引答孫皓問</span>  
<span style="margin-left: 2em">一條較此少夏二月仲春太蔟用事陽氣岀地始</span>  
<span style="margin-left: 2em">溫故禮應開冰先薦寢廟五句其臯陶謨註與經</span>  
<span style="margin-left: 2em">典釋文及正義所引亦互有詳畧而堯典註一條</span>  
<!-- 册1 葉2645a　Page:文淵閣四庫全書_0001冊.djvu/711 -->
<span style="margin-left: 2em">乃不載正義中則亦博採諸書有今日所不盡見</span>  
<span style="margin-left: 2em">者非僅剽剟正義又玉海十八卷引定之方中詩</span>  
<span style="margin-left: 2em">張逸問仲梁子何時答曰先師魯人此本先師之</span>  
<span style="margin-left: 2em">下多一云字方知先師非指仲梁子如此之類亦</span>  
<span style="margin-left: 2em">較他書所載爲長足證爲舊人所輯非近時所新</span>  
<span style="margin-left: 2em">編也問有蒐采未盡者諸經正義及魏書禮志南</span>  
<span style="margin-left: 2em">齊書禮志續漢書郡國志註藝文類聚諸書所引</span>  
<span style="margin-left: 2em">尚有三十六條又鄭記一書亦久散佚今可以考</span>  
<span style="margin-left: 2em">見者尙有初學記通典太平御覽所引三條併附</span>  
<!-- 册1 葉2645b　Page:文淵閣四庫全書_0001冊.djvu/711 -->
<span style="margin-left: 2em">錄之以存鄭學之梗槩併以見漢代經師專門授</span>  
<span style="margin-left: 2em">受師弟子反覆研求而後筆之爲傳註其旣詳且</span>  
<span style="margin-left: 2em">愼至於如此昔朱子與胡紘爭寧宗持禫之禮反</span>  
<span style="margin-left: 2em">覆辨難終無據以折之後讀禮記喪服小記疏所</span>  
<span style="margin-left: 2em">引鄭志一條方得明白證驗因自書於本議之後</span>  
<span style="margin-left: 2em">記其始末有向使無鄭康成則此事終未有所斷</span>  
<span style="margin-left: 2em">決語是朱子議禮未嘗不折服於元矣後之臆斷</span>  
<span style="margin-left: 2em">談經而動輒排斥鄭學者亦多見其不知量也</span>  
經典釋文三十卷<sub class="note-yuan">內府藏本</sub>  
<!-- 册1 葉2648a　Page:文淵閣四庫全書_0001冊.djvu/712 -->
<span style="margin-left: 2em">唐陸元朗撰元朗字德明以字行吳人貞觀中官</span>  
<span style="margin-left: 2em">國子博士兼太子中允事迹具唐書本傳此書前</span>  
<span style="margin-left: 2em">有自序云癸卯之歲承乏上庠因撰集五典孝經</span>  
<span style="margin-left: 2em">論語及老莊爾雅等音古今並錄經註畢詳訓義</span>  
<span style="margin-left: 2em">兼辨示傳一家之學考癸卯爲陳後主至德元年</span>  
<span style="margin-left: 2em">豈德明年甫弱<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2861.svg?width=24" alt="四庫全書僻字第2861號（冠）" title="四庫全書僻字第2861號（冠）">卽能如是淹博抑或積久成書</span>  
<span style="margin-left: 2em">之後追紀其草創之始也首爲序錄一卷次周易</span>  
<span style="margin-left: 2em">一卷古文尚書二卷毛詩三卷周禮二卷儀禮一</span>  
<span style="margin-left: 2em">卷禮記四卷春秋左氏六卷公羊一卷穀梁一卷</span>  
<!-- 册1 葉2648b　Page:文淵閣四庫全書_0001冊.djvu/712 -->
<span style="margin-left: 2em">孝經一卷論語一卷老子一卷莊子三卷爾雅二</span>  
<span style="margin-left: 2em">卷其列老莊於經典而不取孟子頗不可解葢北</span>  
<span style="margin-left: 2em">宋以前孟子不列於經而老莊則自西晉以來爲</span>  
<span style="margin-left: 2em">士大夫所推尙德明生於陳季猶沿六代之餘波</span>  
<span style="margin-left: 2em">也其例諸經皆摘字爲音惟孝經以童𫎇始學老</span>  
<span style="margin-left: 2em">子以衆本多乖各摘全句原本音經者用墨書音</span>  
<span style="margin-left: 2em">註者用朱書以示分別今本則經註通爲一例葢</span>  
<span style="margin-left: 2em">刋板不能備朱墨又文句繁夥不能如本草之作</span>  
<span style="margin-left: 2em">陰陽字自宋以來已混而併之矣所採漢魏六朝</span>  
<!-- 册1 葉2649a　Page:文淵閣四庫全書_0001冊.djvu/712 -->
<span style="margin-left: 2em">音切凡二百三十餘家又兼載諸儒之訓詁證各</span>  
<span style="margin-left: 2em">本之異同後來得以考見古義者註疏以外惟賴</span>  
<span style="margin-left: 2em">此書之存眞所謂殘膏剩馥沾漑無窮者也自宋</span>  
<span style="margin-left: 2em">代監本註疏卽析附諸經之末故文獻通考分見</span>  
<span style="margin-left: 2em">各門後又散附註疏之中往往與註相淆不可辨</span>  
<span style="margin-left: 2em">別此爲通志堂刻本猶其原帙何焯㸃校經解目</span>  
<span style="margin-left: 2em">錄頗<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2753.svg?width=24" alt="四庫全書僻字第2753號（嗤）" title="四庫全書僻字第2753號（嗤）">顧湄校勘之疎然字句偶訛規模自在研</span>  
<span style="margin-left: 2em">經之士終以是爲考證之根柢焉</span>  
七經小傳三卷<sub class="note-yuan">兩江總督採進本</sub>  
<!-- 册1 葉2649b　Page:文淵閣四庫全書_0001冊.djvu/712 -->
<span style="margin-left: 2em">宋劉敞撰敞有春秋傳已著錄是編乃其襍論經</span>  
<span style="margin-left: 2em">義之語其曰七經者一尙書二毛詩三周禮四儀</span>  
<span style="margin-left: 2em">禮五禮記六公羊傳七論語也然公羊傳僅一條</span>  
<span style="margin-left: 2em">又皆校正傳文衍字於傳義無所辨正後又有左</span>  
<span style="margin-left: 2em">傳一條國語一條亦不應獨以公羊標目葢敞本</span>  
<span style="margin-left: 2em">欲作七經傳惟春秋先成凡所創記已編入春秋</span>  
<span style="margin-left: 2em">傳意林權衡文權說例五書中此三條一校衍字</span>  
<span style="margin-left: 2em">一論都城百雉一論禘郊祖宗報於經文無所附</span>  
<span style="margin-left: 2em">麗故其文仍在此書中其標題當爲春秋故得兼</span>

<span style="margin-left: 2em">及外傳傳寫者見第一條爲公羊第二條末亦有</span>
