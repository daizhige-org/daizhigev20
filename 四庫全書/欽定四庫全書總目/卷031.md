## 欽定四庫全書總目 卷三十一　經部三十一　春秋類存目二

<!-- 册1 葉2480：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷三十一  
<span style="margin-left: 1em">經部三十一</span>  
<span style="margin-left: 2em">春秋類存目二</span>  
春秋程傳補二十卷<sub class="note-yuan">浙江汪啟ခ淑家藏本ဂ</sub>  
<span style="margin-left: 1em">國朝孫承澤撰承澤有尚書集解已著錄是編以程</span>  
<span style="margin-left: 2em">子春秋傳非完書集諸儒之說以補之其詞義高</span>  
<span style="margin-left: 2em">簡者重爲申明缺略者詳爲補綴書成於康熙九</span>  
<span style="margin-left: 2em">年按伊川春秋傳宋史藝文志作一卷陳亮龍川</span>  
<span style="margin-left: 2em">集有跋云伊川先生之序此書也葢年七十有一</span>  
<!-- 册1 葉2481b　Page:文淵閣四庫全書_0001冊.djvu/670 -->
<span style="margin-left: 2em">矣四年而先生没今其書之可見者纔二十年陳</span>  
<span style="margin-left: 2em">振孫書錄解題云略舉大義不盡爲說襄昭後尤</span>  
<span style="margin-left: 2em">略考程子春秋傳序作於崇寧二年書未定而黨</span>  
<span style="margin-left: 2em">論興至桓公九年止門人間取經說續其後此陳</span>  
<span style="margin-left: 2em">亮所謂可見者二十年也是書桓公九年以前全</span>  
<span style="margin-left: 2em">載程傳十年以後以經說補之經說所無者采諸</span>  
<span style="margin-left: 2em">說補之中取諸新安汪克寛纂疏者居多纂疏卽</span>  
<span style="margin-left: 2em">明代春秋大全所本其書堅守胡安國傳則仍胡</span>  
<span style="margin-left: 2em">氏之門戸而已未必盡當程子意也又所補諸傳</span>  
<!-- 册1 葉2484a　Page:文淵閣四庫全書_0001冊.djvu/671 -->
<span style="margin-left: 2em">皆不出姓氏於原文亦多所芟改其桓公九年以</span>  
<span style="margin-left: 2em">前程子無傳者亦爲補之則是自爲一書特託名</span>  
<span style="margin-left: 2em">於程子耳考陳亮䟦有云先生於是二十年之間</span>  
<span style="margin-left: 2em">其義甚精其類例甚博學者茍優柔厭飫自得於</span>  
<span style="margin-left: 2em">意言之表不必惜其缺也然則何藉承澤之補乎</span>  
左傳統箋三十五卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 1em">國朝姜希轍撰希轍字二濵餘姚人明崇禎壬午舉</span>  
<span style="margin-left: 2em">人</span>  
<span style="margin-left: 1em">國朝官至奉天府府丞此書循文衍義所据者特杜</span>  
<!-- 册1 葉2484b　Page:文淵閣四庫全書_0001冊.djvu/671 -->
<span style="margin-left: 2em">預林堯叟孔頴達三家叅以朱申句解其所引證</span>  
<span style="margin-left: 2em">又皆不標所出猶沿明季著書之習</span>  
春秋家說三卷<sub class="note-yuan">湖南巡撫採進本</sub>  
<span style="margin-left: 1em">國朝王夫之撰夫之有周易稗疏已著錄是書前有</span>  
<span style="margin-left: 2em">自序稱大義受於其父故以家說爲名其攻駁胡</span>  
<span style="margin-left: 2em">傳之失往往中理而亦好爲高論不顧其安其𡚁</span>  
<span style="margin-left: 2em">乃與胡傳等如文姜之與於弒夫之謂不討則不</span>  
<span style="margin-left: 2em">免於忘父討之則不免於殺母爲莊公者惟有一</span>  
<span style="margin-left: 2em">死而别立桓公之庶子庶子可以申文姜之誅不</span>  
<!-- 册1 葉2485a　Page:文淵閣四庫全書_0001冊.djvu/671 -->
<span style="margin-left: 2em">知子固無殺母之理卽桓之庶子亦豈有殺嫡母</span>  
<span style="margin-left: 2em">之理視生母爲母而視嫡母爲非母此末俗至薄</span>  
<span style="margin-left: 2em">之見可引以斷經義乎閔公之弑夫之謂當歸獄</span>  
<span style="margin-left: 2em">於慶父不當歸獄於哀姜哀姜以母戕子與文姜</span>  
<span style="margin-left: 2em">不同不得以人爵壓天倫此亦牽于俗情以常人</span>  
<span style="margin-left: 2em">立論不知作亂於國家卽爲得罪於宗廟唐武后</span>  
<span style="margin-left: 2em">以母廢中宗天下譁然而思討君子不以爲非彼</span>  
<span style="margin-left: 2em">獨非母子乎首止之㑹定王世子所以消亂端於</span>  
<span style="margin-left: 2em">未萌世子非不當立則不得謂之謀位諸侯非奉</span>  
<!-- 册1 葉2485b　Page:文淵閣四庫全書_0001冊.djvu/671 -->
<span style="margin-left: 2em">所不當奉則不得謂之要挾夫之必責以伯夷叔</span>  
<span style="margin-left: 2em">齊之事則張良之羽翼惠帝何以君子不罪之乎</span>  
<span style="margin-left: 2em">如此之類皆以私情害大義其他亦多詞勝於意</span>  
<span style="margin-left: 2em">全如論體非說經之正軌至於桓公元年無端而</span>  
<span style="margin-left: 2em">論及人君改元宜建年號之類連篇累牘橫生支</span>  
<span style="margin-left: 2em">節於春秋更無關矣</span>  
春秋傳註三十六卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 1em">國朝嚴啟隆撰啟隆字爾泰烏程人前明諸生其說</span>  
<span style="margin-left: 2em">謂孔子欲討陳恒而不得故作春秋以戒三家不</span>  
<!-- 册1 葉2488a　Page:文淵閣四庫全書_0001冊.djvu/672 -->
<span style="margin-left: 2em">始惠公而始隱公者以隱有鍾巫之難特託以發</span>  
<span style="margin-left: 2em">凡不終於陳恒簡公之事而終以獲麟者欲以諱</span>  
<span style="margin-left: 2em">而不書陰愧三家之心論殊穿鑿又謂春秋治大</span>  
<span style="margin-left: 2em">夫非治諸侯以三十六君之事爲經而其餘爲緯</span>  
<span style="margin-left: 2em">以文公以前爲賓而以後爲主經之義當明緯之</span>  
<span style="margin-left: 2em">義可以不問主之義當明賓之義可以不明又謂</span>  
<span style="margin-left: 2em">春秋一字一句皆史舊文聖人並無筆削其意葢</span>  
<span style="margin-left: 2em">深厭說春秋者之迂謬欲一掃而空之而不知矯</span>  
<span style="margin-left: 2em">枉過正反自流於偏駁也</span>  
<!-- 册1 葉2488b　Page:文淵閣四庫全書_0001冊.djvu/672 -->
春秋論二卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 1em">國朝嚴㲄撰㲄字佩之無錫人前明諸生是書凡九</span>  
<span style="margin-left: 2em">十九篇每篇略如袁樞紀事本末之例標舉事目</span>  
<span style="margin-left: 2em">類聚經文於前而附論於下其體在經義史評之</span>  
<span style="margin-left: 2em">間而持論嚴酷又頗傷輕薄其莊公忘父讐一篇</span>  
<span style="margin-left: 2em">云王姬之卒文姜之幸也不然何以奪新昏之宴</span>  
<span style="margin-left: 2em">而復叙淫奔之好也文姜數數與齊侯享㑹是又</span>  
<span style="margin-left: 2em">莊公之幸也不然安得結懽於齊侯而有狩獵之</span>  
<span style="margin-left: 2em">馳騁衛俘之弋獲也是豈儒者說經之體耶</span>  
<!-- 册1 葉2489a　Page:文淵閣四庫全書_0001冊.djvu/672 -->
春秋正業經傳刪本十二卷<sub class="note-yuan">江蘇周厚堉家藏本</sub>  
<span style="margin-left: 1em">國朝金甌撰甌字完城一字寧武秀水人是書專爲</span>  
<span style="margin-left: 2em">舉業而設以胡傳爲主凡經文之不可命題者皆</span>  
<span style="margin-left: 2em">刪去之又上格標單題合題等目每題綴一破題</span>  
<span style="margin-left: 2em">而詳論作文之法與經義如風馬牛之不相及其</span>  
<span style="margin-left: 2em">目本可不存然自有制藝以來坊本五經講章如</span>  
<span style="margin-left: 2em">此者不一而足時文家利於剽竊較先儒傳註轉</span>  
<span style="margin-left: 2em">易於風行苟置之不論不議勢且蔓延不止貽患</span>  
<span style="margin-left: 2em">於學術者彌深故存而闢之俾知凡類於此者皆</span>  
<!-- 册1 葉2489b　Page:文淵閣四庫全書_0001冊.djvu/672 -->
<span style="margin-left: 2em">在所當斥焉</span>  
春秋傳議四卷<sub class="note-yuan">山東巡撫採進本</sub>  
<span style="margin-left: 1em">國朝張爾岐撰爾岐有周易說略已著錄是書意在</span>  
<span style="margin-left: 2em">折衷三傳歸於至當然發明胡傳之意居多猶未</span>  
<span style="margin-left: 2em">敢破除門戸同時有樂安李煥章爲爾岐作傳云</span>  
<span style="margin-left: 2em">著春秋傳議未輟而卒今此本缺略特甚葢未成</span>  
<span style="margin-left: 2em">之藁而好事者刻之也</span>  
學春秋隨筆十卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝萬斯大撰斯大有儀禮商已著錄斯大曾編纂</span>  
<!-- 册1 葉2492a　Page:文淵閣四庫全書_0001冊.djvu/673 -->
<span style="margin-left: 2em">春秋爲二百四十二卷燬於火其後更自蒐輯以</span>  
<span style="margin-left: 2em">成此書其學根柢於三禮故其釋春秋也亦多以</span>  
<span style="margin-left: 2em">禮經爲據較之宋元以後諸家空談書法者有殊</span>  
<span style="margin-left: 2em">然斯大之說經以新見長亦以鑿見短如解閔二</span>  
<span style="margin-left: 2em">年吉禘于莊公謂四時之祭惟禘特大故又曰大</span>  
<span style="margin-left: 2em">事王制天子犆礿祫禘祫嘗祫烝三祫中惟禘特</span>  
<span style="margin-left: 2em">大故又曰大祫後儒因僖八年宣八年定八年皆</span>  
<span style="margin-left: 2em">有禘推合於三年一禘惡知僖宣定八年之禘皆</span>  
<span style="margin-left: 2em">以有故而書非謂惟八年乃禘六年七年與九年</span>  
<!-- 册1 葉2492b　Page:文淵閣四庫全書_0001冊.djvu/673 -->
<span style="margin-left: 2em">皆不禘也今考禮緯三年一祫五年一禘公羊曰</span>  
<span style="margin-left: 2em">五年而再𣪞祭是五年而一祫一禘也公羊必非</span>  
<span style="margin-left: 2em">無據斯大謂每年皆祫卽以時祭爲祫祭葢襲皇</span>  
<span style="margin-left: 2em">氏虞夏每年皆祫之說而不知皇氏固謂嘗以時</span>  
<span style="margin-left: 2em">祭爲祫祭王制曰天子犆礿祫禘祫嘗祫烝諸侯</span>  
<span style="margin-left: 2em">礿犆禘一犆一祫嘗祫烝祫註謂天子先祫而後</span>  
<span style="margin-left: 2em">時祭諸侯先時祭而後祫如謂禘烝嘗卽是祫則</span>  
<span style="margin-left: 2em">與祫無分先後何以經文於天子先言祫而後言</span>  
<span style="margin-left: 2em">禘烝嘗於諸侯先言禘烝嘗而後言祫耶又禘一</span>  
<!-- 册1 葉2493a　Page:文淵閣四庫全書_0001冊.djvu/673 -->
<span style="margin-left: 2em">犆一祫注謂諸侯當夏禘時不爲禘祭惟一犆一</span>  
<span style="margin-left: 2em">祫而已皇氏謂諸侯夏時若祫則不禘若禘則不</span>  
<span style="margin-left: 2em">祫俱謂時禘不與祫並行也若時禘卽是禘則經</span>  
<span style="margin-left: 2em">文又何以云禘一犆一祫耶至於謂四時之祭夏</span>  
<span style="margin-left: 2em">祫爲大故曰大事又曰大祫尤爲牽合穿鑿周禮</span>  
<span style="margin-left: 2em">司<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3297.svg?width=24" alt="四庫全書僻字第3297號（勲）" title="四庫全書僻字第3297號（勲）">曰凡有功者銘書於王之大常享於大烝禮</span>  
<span style="margin-left: 2em">記祭統曰内祭則大嘗禘是烝嘗亦得稱大矣烏</span>  
<span style="margin-left: 2em">得執一大字獨斷爲夏禘也又祔而作主特祀於</span>  
<span style="margin-left: 2em">主烝嘗禘於廟斯大謂祔於祖廟主不復反於寢</span>  
<!-- 册1 葉2493b　Page:文淵閣四庫全書_0001冊.djvu/673 -->
<span style="margin-left: 2em">引黃宗羲之說謂祥禫則於祖廟中祭新死者不</span>  
<span style="margin-left: 2em">及皇祖故云祭於主烝嘗禘則惟及皇祖不及新</span>  
<span style="margin-left: 2em">死者故云於廟今考鄭元士虞禮注凡祔已主復</span>  
<span style="margin-left: 2em">於寢說最精<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">大戴禮諸侯遷廟禮曰徙之日君</span>  
<span style="margin-left: 2em">元服從者皆服從至於廟盧辨注廟謂殯宫也其</span>  
<span style="margin-left: 2em">下又曰奉衣服者至碑君從有司皆以次從出廟</span>  
<span style="margin-left: 2em">門至於新廟據此則遷廟以前主在殯宫明矣鄭</span>  
<span style="margin-left: 2em">注謂練而遷廟杜注謂三年遷廟若卒哭而祔之</span>  
<span style="margin-left: 2em">後主常在廟則於練及三年又何得更自殯宫遷</span>  
<!-- 册1 葉2496a　Page:文淵閣四庫全書_0001冊.djvu/674 -->
<span style="margin-left: 2em">主乎又引王廷相之說謂遷廟禮出廟門至於新</span>  
<span style="margin-left: 2em">廟是自所祔之廟而至新廟今考喪服小記無事</span>  
<span style="margin-left: 2em">不辟廟門註曰廟殯宫雜記曰至於廟門不毁墻</span>  
<span style="margin-left: 2em">遂入適所殯凡以殯宫爲廟見於經傳者甚多其</span>  
<span style="margin-left: 2em">以大戴禮出廟門之廟爲祔廟由不知殯宫之亦</span>  
<span style="margin-left: 2em">名廟也又考禮志云更釁其廟則必先遷高祖於</span>  
<span style="margin-left: 2em">太廟而後納祖考之主又候遷祖考於新廟然後</span>  
<span style="margin-left: 2em">可以改釁故廟而納新祔之主是新主祔於祖廟</span>  
<span style="margin-left: 2em">卽遷於祖廟甚明謂自所祔之廟遷於新廟則是</span>

<span style="margin-left: 2em">祔者一廟遷者又一廟矣與禮志全悖斯大乃襲</span>
