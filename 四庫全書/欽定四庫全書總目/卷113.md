## 欽定四庫全書總目 卷一百十三　子部二十三　藝術類二

<!-- 册3 葉1768a　Page:文淵閣四庫全書_0003冊.djvu/447 -->
欽定四庫全書總目巻一百十三  
<span style="margin-left: 1em">子部二十三</span>  
<span style="margin-left: 2em">藝術類二</span>  
書史㑹要九巻補遺一巻續編一巻<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">書史㑹要九巻補遺一巻明陶宗儀撰續編一巻</span>  
<span style="margin-left: 2em">朱謀垔撰宗儀有國風尊經已著錄謀垔字隱之</span>  
<span style="margin-left: 2em">號厭原山人寧藩支裔也是編載古來能書人上</span>  
<span style="margin-left: 2em">起三皇下至元代凡八巻末爲書法一巻又補遺</span>  
<span style="margin-left: 2em">一巻據孫作滄螺集所載宗儀小傳稱書史㑹要</span>  
<!-- 册3 葉1768b　Page:文淵閣四庫全書_0003冊.djvu/447 -->
<span style="margin-left: 2em">凡九巻此本目錄亦以書法補遺共爲一巻而刋</span>  
<span style="margin-left: 2em">本乃以補遺别爲巻又以朱謀垔所作續編一巻</span>  
<span style="margin-left: 2em">題爲巻十移其次於補遺前殆謀垔之子統鉷重</span>  
<span style="margin-left: 2em">刋是書分析移易遂使宗儀原書中斷爲二今仍</span>  
<span style="margin-left: 2em">退謀垔所補自爲一巻題曰續編以别於宗儀之</span>  
<span style="margin-left: 2em">書其書法補遺如仍合爲一巻則篇頁稍繁姑仍</span>  
<span style="margin-left: 2em">統鉷所編别爲一巻以便省覽宗儀舊本以元繼</span>  
<span style="margin-left: 2em">宋而列遼金於後與所作輟耕錄中載楊維楨正</span>  
<span style="margin-left: 2em">統論以元繼宋者所見相同維楨論已仰禀</span>  
<!-- 册3 葉1769a　Page:文淵閣四庫全書_0003冊.djvu/447 -->
睿裁特存其說宗儀是編亦謹仍其舊文焉  
珊瑚木難八巻<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明朱存理撰存理有旌孝錄已著錄朱彛尊靜志</span>  
<span style="margin-left: 2em">居詩話曰存理自少至老未嘗一日忘學問人有</span>  
<span style="margin-left: 2em">異書必從訪求以必得爲志所纂集凡數百巻旣</span>  
<span style="margin-left: 2em">老不厭坐貧無以自資其書旋亦散去江南通志</span>  
<span style="margin-left: 2em">亦曰元季明初中吳南園何氏笠澤虞氏廬山陳</span>  
<span style="margin-left: 2em">氏書籍金石之富甲於海内繼其後者存理其尤</span>  
<span style="margin-left: 2em">也兹編悉載所見字畫題跋其巻中前人詩文世</span>  
<!-- 册3 葉1769b　Page:文淵閣四庫全書_0003冊.djvu/447 -->
<span style="margin-left: 2em">所罕覩者亦附錄焉前有文徴明文嘉王穉登王</span>  
<span style="margin-left: 2em">騰程四人名氏葢出於四人收藏者爲多徵明等</span>  
<span style="margin-left: 2em">皆以賞鑒相高故所貯並多名蹟存理又工於考</span>  
<span style="margin-left: 2em">證凡所題品具有根據與眞贋雜糅者不同惟其</span>  
<span style="margin-left: 2em">書從無刋本轉相傳寫訛脫頗多今詳加釐正而</span>  
<span style="margin-left: 2em">闕其所不可知者著之於錄</span>  
趙氏鐵綱珊瑚十六巻<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">舊本題明朱存理撰末有萬厯中常熟趙琦美跋</span>  
<span style="margin-left: 2em">稱原從秦四麟家得書品畫品各四巻後從焦竑</span>  
<!-- 册3 葉1772a　Page:文淵閣四庫全書_0003冊.djvu/448 -->
<span style="margin-left: 2em">得一本巻帙較多因兩本互校增爲書品十巻畫</span>  
<span style="margin-left: 2em">品六巻其先後次序則琦美所隲定而又以所見</span>  
<span style="margin-left: 2em">眞蹟續於後稱秦氏原本無撰人姓名别有跋記</span>  
<span style="margin-left: 2em">作者姓名後佚去不復記然非朱存理也據此則</span>  
<span style="margin-left: 2em">是書乃趙琦美得無名氏殘稿所編其稿旣不出</span>  
<span style="margin-left: 2em">於一家且琦美又有所增補題朱存理撰爲誤矣</span>  
<span style="margin-left: 2em">雍正六年年希堯嘗刻此書其跋稱别有一本十</span>  
<span style="margin-left: 2em">四巻者傳爲存理原本今亦未見又世傳有存理</span>  
<span style="margin-left: 2em">所作珊瑚木難八巻所載名蹟末皆有自跋語與</span>  
<!-- 册3 葉1772b　Page:文淵閣四庫全書_0003冊.djvu/448 -->
<span style="margin-left: 2em">此本體例迥異則此書非出存理手愈可知也然</span>  
<span style="margin-left: 2em">所載書畫諸跋頗足以辨析異同考究眞僞至今</span>  
<span style="margin-left: 2em">賞鑒家多引據之其書旣爲可採則亦不必問其</span>  
<span style="margin-left: 2em">定出誰氏矣</span>  
墨池璅錄四巻<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">明楊愼撰愼有檀弓叢訓已著錄王世貞名賢遺</span>  
<span style="margin-left: 2em">墨跋曰愼以博學名世書亦自負吳興堂廡世傳</span>  
<span style="margin-left: 2em">其謫戍雲南時嘗醉傅胡粉作雙髻插花諸伎擁</span>  
<span style="margin-left: 2em">之遊行城市或以精白綾作裓遺諸伎服之酒間</span>  
<!-- 册3 葉1773a　Page:文淵閣四庫全書_0003冊.djvu/448 -->
<span style="margin-left: 2em">乞書醉墨淋漓人毎購歸𧚌潢成巻葢愼亦究心</span>  
<span style="margin-left: 2em">書學者此書頗抑顔眞卿而謂米芾行不逮言至</span>  
<span style="margin-left: 2em">趙孟頫出始一洗顔柳之病<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">以晉人爲師右軍</span>  
<span style="margin-left: 2em">之後一人而已與王世貞吳興堂廡之說合知其</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">出愼手中間或採舊文或抒已意往往皆心得</span>  
<span style="margin-left: 2em">之言其述張天錫草書韻㑹源流及小王破體書</span>  
<span style="margin-left: 2em">亦兼有考證至漢司𨽻楊厥碑ခ字之類偶爾疎</span>  
<span style="margin-left: 2em">謬者已駁正於洪适𨽻釋條下兹不具論云</span>  
書畫跋跋三巻續三巻<sub class="note-yuan">浙江孫仰曾家藏本</sub>  
<!-- 册3 葉1773b　Page:文淵閣四庫全書_0003冊.djvu/448 -->
<span style="margin-left: 2em">明孫鑛撰鑛有月峯評經已著錄是書名書畫跋</span>  
<span style="margin-left: 2em">跋者王世貞先有書畫跋鑛又跋其所跋故重文</span>  
<span style="margin-left: 2em">見義猶非非國語反反離騷例也明以來未有刋</span>  
<span style="margin-left: 2em">本僅有抄本在仁和毛先舒家後歸其邑人趙信</span>  
<span style="margin-left: 2em">信爲孫氏之壻故鑛六世孫宗溥宗濓又從趙氏</span>  
<span style="margin-left: 2em">得之乾隆庚申始刋板印行任蘭枝爲之序初宗</span>  
<span style="margin-left: 2em">溥等以鑛書本因世貞而作如不載世貞原跋則</span>  
<span style="margin-left: 2em">鑛之所云有不知爲何語者乃取世貞諸跋散附</span>  
<span style="margin-left: 2em">於各題之下其明人書札可與鑛參證及爲鑛語</span>  
<!-- 册3 葉1776a　Page:文淵閣四庫全書_0003冊.djvu/449 -->
<span style="margin-left: 2em">所緣起者亦附載焉凡墨蹟一巻碑刻一巻畫一</span>  
<span style="margin-left: 2em">巻續亦如之惟續跋碑刻作墨刻葢偶爾駁文非</span>  
<span style="margin-left: 2em">宏㫖所在也詹氏小辨曰王元美雖不以字名顧</span>  
<span style="margin-left: 2em">吳中諸家惟元美一人知法古人又書史㑹要曰</span>  
<span style="margin-left: 2em">王世貞書學雖非當家而議論翩翩筆法古雅葢</span>  
<span style="margin-left: 2em">拙於揮毫而工於别古者也鑛以制義名一時亦</span>  
<span style="margin-left: 2em">不以書畫傳然所論則時有精理與世貞長短正</span>  
<span style="margin-left: 2em">同亦賞鑒家所當取證者矣</span>  
書訣一巻<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<!-- 册3 葉1776b　Page:文淵閣四庫全書_0003冊.djvu/449 -->
<span style="margin-left: 2em">不著撰人名氏明史藝文志亦未嘗錄案書中稱</span>  
<span style="margin-left: 2em">其十世祖名稷曾祖名慶祖名耘考名熙則當爲</span>  
<span style="margin-left: 2em">嘉靖間鄞人豐坊所作也坊有古易世學已著錄</span>  
<span style="margin-left: 2em">其平生好作僞書妄謬萬端至今爲世詬厲然於</span>  
<span style="margin-left: 2em">書法則有所心得故詹氏小辨曰坊爲人逸出法</span>  
<span style="margin-left: 2em">紀外而書學極博五體並能諸家自魏晉以及國</span>  
<span style="margin-left: 2em">朝靡不兼通規矩盡從手出葢工於執筆者也以</span>  
<span style="margin-left: 2em">故其書大有腕力特神韻稍不足朱謀垔書史㑹</span>  
<span style="margin-left: 2em">要亦曰坊草書自晉唐而來無今人一筆態度惟</span>  
<!-- 册3 葉1777a　Page:文淵閣四庫全書_0003冊.djvu/449 -->
<span style="margin-left: 2em">喜用枯筆乏風韻耳是編皆論學書之法而尤注</span>  
<span style="margin-left: 2em">意於篆籀又排比古今能書之家評其次第其論</span>  
<span style="margin-left: 2em">顔眞卿獨推其擘窠題署第一而詆東方朔贊多</span>  
<span style="margin-left: 2em">寶塔頌爲俗筆又貶蘇軾以肉襯𥿄甚有俗氣於</span>  
<span style="margin-left: 2em">楷法僅取其上淸儲祥宫碑等三種務爲高論葢</span>  
<span style="margin-left: 2em">猶其狂易之餘態要亦各抒所見固與無實大言</span>  
<span style="margin-left: 2em">者異矣</span>  
繪事微言一巻<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明唐志契撰志契字敷五又字元生江都人與弟</span>  
<!-- 册3 葉1777b　Page:文淵閣四庫全書_0003冊.djvu/449 -->
<span style="margin-left: 2em">志伊並能畫而志契尤以山水擅名是編乃其所</span>  
<span style="margin-left: 2em">著畫譜姜紹書無聲詩史以爲頗得六法之藴者</span>  
<span style="margin-left: 2em">也所錄畫家名論自南齊謝赫古畫品錄而下至</span>  
<span style="margin-left: 2em">於明李日華諸人皆芟除蕪冗汰取精華其承訛</span>  
<span style="margin-left: 2em">襲繆者如梁元帝畫松石格荆浩畫山水賦皆不</span>  
<span style="margin-left: 2em">知爲贋本畫麈乃吳中沈顥著見陶宗儀說郛而</span>  
<span style="margin-left: 2em">因顥字朗蒨輾轉傳訛遂誤作朗耀葢技藝之流</span>  
<span style="margin-left: 2em">多喜依託古人以神其授受地師動稱郭璞術家</span>  
<span style="margin-left: 2em">每署劉基皆踵謬沿訛猝難究詰但所言中理卽</span>  
<!-- 册3 葉1780a　Page:文淵閣四庫全書_0003冊.djvu/450 -->
<span style="margin-left: 2em">可不必深求至其自著論斷則多中肯綮如謂佛</span>  
<span style="margin-left: 2em">道人物牛馬則今不如古山水林木花石則古不</span>  
<span style="margin-left: 2em">如今又云作畫以氣韻爲本讀書爲先皆<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">論也</span>  
<span style="margin-left: 2em">讀其書可以知其非庸史矣故</span>  
御定佩文齋書畫譜採志契之說頗多云  
書法雅言一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明項穆撰王穉登所作穆小傳稱其初名德枝郡</span>  
<span style="margin-left: 2em">大夫徐公易爲純後乃更名穆字德純號曰貞元</span>  
<span style="margin-left: 2em">亦號曰無稱子秀水項元汴之子也元汴鑒藏書</span>  
<!-- 册3 葉1780b　Page:文淵閣四庫全書_0003冊.djvu/450 -->
<span style="margin-left: 2em">畫甲於一時至今論眞蹟者尙以墨林印記别眞</span>  
<span style="margin-left: 2em">僞穆承其家學耳濡目染故於書法特工因抒其</span>  
<span style="margin-left: 2em">心得作爲是書凡十七篇曰書統曰古今曰辨體</span>  
<span style="margin-left: 2em">曰形質曰品格曰資學曰規矩曰常變曰正奇曰</span>  
<span style="margin-left: 2em">中和曰老少曰神化曰心相曰取舍曰功序曰器</span>  
<span style="margin-left: 2em">用曰知識大㫖以晉人爲宗而排蘇軾米芾書爲</span>  
<span style="margin-left: 2em">稜角怒張倪瓚書寒儉軾芾加以工力可至古人</span>  
<span style="margin-left: 2em">瓚則終不可到雖持論稍爲過高而終身一藝研</span>  
<span style="margin-left: 2em">求至深烟楮之外實多獨契衡以取法乎上之義</span>  
<!-- 册3 葉1781a　Page:文淵閣四庫全書_0003冊.djvu/450 -->
<span style="margin-left: 2em">未始非書家之圭臬也</span>  
寒山帚談二卷拾遺一卷附錄一卷<sub class="note-yuan">直隸總督採進本</sub>  
<span style="margin-left: 2em">明趙宧光撰宧光有說文長箋已著錄是編本在</span>  
<span style="margin-left: 2em">所撰說文長箋中亦析出别行長箋穿鑿附㑹且</span>  
<span style="margin-left: 2em">引據疎舛頗爲小學家所譏而篆文筆法則差有</span>  
<span style="margin-left: 2em">偏長故此編猶爲後人所重上卷四目曰權輿論</span>  
<span style="margin-left: 2em">一十五種書也曰格調論筆法結構也曰力學論</span>  
<span style="margin-left: 2em">字功書法也曰臨倣則力學之餘緒析而爲篇者</span>  
<span style="margin-left: 2em">也下卷四目曰用才論筆墨硯紙及運用法也曰</span>
