<span style="margin-left: 1em">史部三十四</span>  
<span style="margin-left: 2em">地理類存目七</span>  
古今遊名山記十七卷<sub class="note-yuan">安徽廵撫採進本</sub>  
<span style="margin-left: 2em">明何鏜撰鏜有括蒼彚記已著錄是書採史志文</span>  
<span style="margin-left: 2em">集所載遊覽之文以類編輯首爲總錄三篇曰勝</span>  
<span style="margin-left: 2em">記曰名言曰類考次記兩京各省山川及古今遊</span>  
<span style="margin-left: 2em">人序記</span>  
天下名山諸勝一覧記十六卷<sub class="note-yuan">兩江總督採進本</sub>  
<!-- 册2 葉2545b　Page:文淵閣四庫全書_0002冊.djvu/641 -->
<span style="margin-left: 2em">明愼𫎇撰𫎇字山泉歸安人嘉靖癸丑進士官至</span>  
<span style="margin-left: 2em">監察御史是書以何鏜所作古今遊名山記重複</span>  
<span style="margin-left: 2em">太甚因刪汰繁冗而增入通志及别集所載記文</span>  
<span style="margin-left: 2em">凡十之四視鏜書頗爲簡明然文有加減而事不</span>  
<span style="margin-left: 2em">增損仍無資於攷據其記文之末各加評語亦不</span>  
<span style="margin-left: 2em">出坊刻積習自序稱其書名天下名山諸勝一覽</span>  
<span style="margin-left: 2em">記而第一卷首又題作游名山一覽記第二卷以</span>  
<span style="margin-left: 2em">後則題作名山巖洞泉石古蹟殊不畫一蓋明代</span>  
<span style="margin-left: 2em">文士往往急行其書陸續付梓至書成後始有定</span>  
<!-- 册2 葉2548a　Page:文淵閣四庫全書_0002冊.djvu/642 -->
<span style="margin-left: 2em">名而已刊者遂不復追改故名目往往錯互不獨</span>  
<span style="margin-left: 2em">此書爲然也</span>  
名山游記一卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明王世懋撰世懋有却金傳已著錄是編一曰京</span>  
<span style="margin-left: 2em">口游山記分上下二篇一曰游匡廬山記一曰東</span>  
<span style="margin-left: 2em">游記一曰游二泉記一曰游鼓山記一曰游石竹</span>  
<span style="margin-left: 2em">山記一曰游九鯉湖記而附以游溧陽彭氏園記</span>  
<span style="margin-left: 2em">末有世懋䟦一篇蓋爲鼓山以下三記作後合刻</span>  
<span style="margin-left: 2em">諸記仍以綴於末也</span>

<span style="margin-left: 2em">明潘之恒撰之恒有黃海已著錄是編首江上山</span>  
<span style="margin-left: 2em">志次蜀山志次淮上雜志次新安山水志次越中</span>  
<span style="margin-left: 2em">山水志次三吳雜志或載前人行紀志傳題詠或</span>  
<span style="margin-left: 2em">自爲序記其他名勝漏畧尚多疑就其所遊厯者</span>  
<span style="margin-left: 2em">述之其書不分卷帙前後亦無序䟦而名山注三</span>

<span style="margin-left: 2em">諸省附以雜志其四夷輯一種列目於雜志之前</span>  
<span style="margin-left: 2em">然有錄無書註曰考訂嗣出蓋未刊也凡山川險</span>
