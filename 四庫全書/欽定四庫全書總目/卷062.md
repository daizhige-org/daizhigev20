## 欽定四庫全書總目 卷六十二　史部十八　傳記類存目四

欽定四庫全書總目卷六十二  
<span style="margin-left: 1em">史部十八</span>  
<span style="margin-left: 2em">傳記𩔖存目四</span>  
厯代相臣傳一百六十八卷<sub class="note-yuan"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">隸總督採進本</sub>  
<span style="margin-left: 2em">明魏顯國撰顯國字汝忠南昌人隆慶丁卯舉人</span>  
<span style="margin-left: 2em">是書明史藝文志著錄卷數與此本相合大抵全</span>  
<span style="margin-left: 2em">鈔史傳原文無所褒貶亦無所考正所敘厯代相</span>  
<span style="margin-left: 2em">臣職名如南朝一條以梁初罷相國置丞相罷丞</span>  
<span style="margin-left: 2em">相置司徒後又置相國位列丞相上不知置相國</span>  
<!-- 册2 葉1457b　Page:文淵閣四庫全書_0002冊.djvu/369 -->
<span style="margin-left: 2em">列丞相上乃陳制非梁制又謂唐魏徵以秘書監</span>  
<span style="margin-left: 2em">叅預朝政始有叅議得失叅知政事之名不知其</span>  
<span style="margin-left: 2em">時先以吏部尙書杜淹叅議朝政故有是名又謂</span>  
<span style="margin-left: 2em">開元以後宰相爲鹽鐵轉運延資庫使名尤不正</span>  
<span style="margin-left: 2em">不知其時以宰相兼攝是官非以是官爲宰相况</span>  
<span style="margin-left: 2em">其時太微宫使太淸宮使多以宰相兼之不僅延</span>  
<span style="margin-left: 2em">資庫使也又以李光弼列於宰相不知光弼爲河</span>  
<span style="margin-left: 2em">中節度惟加平章不治政事乃唐之使相唐末節</span>  
<span style="margin-left: 2em">度加侍中中書令三公三師者甚多皆使相非宰</span>  
<!-- 册2 葉1460a　Page:文淵閣四庫全書_0002冊.djvu/370 -->
<span style="margin-left: 2em">相載於史志者甚詳元之叅議中書省事乃六曹</span>  
<span style="margin-left: 2em">管轄官止四品亦非宰相故元史宰相表不列是</span>  
<span style="margin-left: 2em">官又元制三公非相職故别立三公三師表今俱</span>  
<span style="margin-left: 2em">列於宰相舛訛旣甚掛漏尤多至於各史宰相列</span>  
<span style="margin-left: 2em">傳或採或置茫無義例更未免踈脫矣</span>  
儒林全傳二十卷<sub class="note-yuan">浙江汪啓淑家藏本</sub>  
<span style="margin-left: 2em">明魏顯國撰所錄自孔子至元吳澄亦皆鈔錄前</span>  
<span style="margin-left: 2em">史與相臣傳同</span>  
厯代守令傳二十四卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<!-- 册2 葉1460b　Page:文淵閣四庫全書_0002冊.djvu/370 -->
<span style="margin-left: 2em">明魏顯國撰自宓不齊仲由至劉秉<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">爲厯代循</span>  
<span style="margin-left: 2em">吏二十一卷又自郅都至敬羽爲厯代酷吏三卷</span>  
<span style="margin-left: 2em">於史傳原文之外間有所增而又多蕪雜</span>  
元相臣傳十二卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明魏顯國撰其書紀元代丞相自耶律楚材至布</span>  
<span style="margin-left: 2em">延巴哈<sub class="note-yuan">原作普顔不花今改正</sub>二十六人各自爲傳全襲元</span>  
<span style="margin-left: 2em">史之文又前後凌亂脫誤如元史宰相表載安圖</span>  
<span style="margin-left: 2em"><sub class="note-yuan">原作安童今改正</sub>爲右丞相始世祖至元二年乙丑訖於</span>  
<span style="margin-left: 2em">二十七年庚寅布呼密<sub class="note-yuan">原作不忽本今改正</sub>爲平章政事始</span>  
<!-- 册2 葉1461a　Page:文淵閣四庫全書_0002冊.djvu/370 -->
<span style="margin-left: 2em">至元二十八年辛卯訖成宗元貞二年丙申是布</span>  
<span style="margin-left: 2em">呼密後於安圖凡二十七年此書列布呼密於安</span>  
<span style="margin-left: 2em">圖前殊爲倒置又如世祖庚申元年王文統趙璧</span>  
<span style="margin-left: 2em">爲平章政事尤在史天澤諸人之前其相業俱見</span>  
<span style="margin-left: 2em">本傳而此書均汰之葢不特於正史之外無所徵</span>  
<span style="margin-left: 2em">引且於正史之中亦多所挂漏矣</span>  
忠節錄六卷<sub class="note-yuan">浙江鄭大節家藏本</sub>  
<span style="margin-left: 2em">明張朝瑞撰朝瑞字子禎海州人隆慶戊辰進士</span>  
<span style="margin-left: 2em">官至南京鴻臚寺<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">朝瑞以宋端儀革除錄至郞</span>  
<!-- 册2 葉1461b　Page:文淵閣四庫全書_0002冊.djvu/370 -->
<span style="margin-left: 2em">瑛萃忠集記遜國諸臣事者凡十七家互有舛漏</span>  
<span style="margin-left: 2em">因輯此書載當時昭雪之旨於卷首明非私撰自</span>  
<span style="margin-left: 2em">第一卷至五卷記徐輝祖以下凡一百六十三人</span>  
<span style="margin-left: 2em">附錄十六人以官階爲敘不分差等第六卷曰考</span>  
<span style="margin-left: 2em">誤如辨建文於天順中由滇至京唯太監吳亮識</span>  
<span style="margin-left: 2em">之當時三楊皆其舊臣不應僅一吳亮能識舊主</span>  
<span style="margin-left: 2em">而建文時年六十四亦不得有九十餘歲其考證</span>  
<span style="margin-left: 2em">最爲明<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">所列十七家書外尙有高璧之幽光錄</span>  
<span style="margin-left: 2em">陸時中之逸史姜淸之秘史王會之野史袁褧之</span>  
<!-- 册2 葉1464a　Page:文淵閣四庫全書_0002冊.djvu/371 -->
<span style="margin-left: 2em">奉天刑賞錄諸書朝瑞未及蒐考然大槩巳備於</span>  
<span style="margin-left: 2em">此矣</span>  
吳中人物志十二卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明張㫤撰㫤字景春長洲人是編成於隆慶庚午</span>  
<span style="margin-left: 2em">所輯吳中人物上自成周迄於明代分孝友忠義</span>  
<span style="margin-left: 2em">吏治薦舉宦蹟儒林文苑閨秀逸民流寓列仙方</span>  
<span style="margin-left: 2em">外十二門各係以論贊同郡皇甫汸爲之序吳中</span>  
<span style="margin-left: 2em">人物自王賔楊循吉祝允明朱存理等遞有撰述</span>  
<span style="margin-left: 2em">此本因而廣之較諸家稍備然事皆不著出典未</span>  
<!-- 册2 葉1464b　Page:文淵閣四庫全書_0002冊.djvu/371 -->
<span style="margin-left: 2em">免無徵不信也</span>  
輔世編六卷<sub class="note-yuan">江蘇周厚堉家藏本</sub>  
<span style="margin-left: 2em">明唐鶴徵撰鶴徵有周易象義已著錄是書取明</span>  
<span style="margin-left: 2em">代諸臣次其行事起洪武初李善長劉基訖嘉靖</span>  
<span style="margin-left: 2em">中曾銑胡宗愈凡五十二人崇禎間其門人陳睿</span>  
<span style="margin-left: 2em">謨巡撫湖廣爲評校刊板其敘稱戎務孔亟之時</span>  
<span style="margin-left: 2em">輒取名臣傳畧倣其行事多得變通之法間嘗抄</span>  
<span style="margin-left: 2em">書有得多與我師凝庵唐先生輔世編合者因綜</span>  
<span style="margin-left: 2em">其成稿翼以已意勒成一書則是編已不盡鶴徵</span>  
<!-- 册2 葉1465a　Page:文淵閣四庫全書_0002冊.djvu/371 -->
<span style="margin-left: 2em">原本矣其所採諸人事實多主戰畧葢睿謨身在</span>  
<span style="margin-left: 2em">戎行意切時用有所爲而爲之者也</span>  
聖門人物志十二卷<sub class="note-yuan">江西巡撫採進本</sub>  
<span style="margin-left: 2em">明郭子章撰子章有蠙衣生易解已著錄是書則</span>  
<span style="margin-left: 2em">子章官晉陽時所輯凡遊於聖門與私淑而得從</span>  
<span style="margin-left: 2em">祀廟廡者各爲之小傳附以贊論首孔子世家次</span>  
<span style="margin-left: 2em">先賢次先儒而以有明之會典祀儀終焉其中雜</span>  
<span style="margin-left: 2em">以周汝登羅汝芳諸人之論其時心學横流故子</span>  
<span style="margin-left: 2em">章多主張其說孟子傳論謂孔子之學以從心所</span>  
<!-- 册2 葉1465b　Page:文淵閣四庫全書_0002冊.djvu/371 -->
<span style="margin-left: 2em">欲不踰矩爲的顔子從之末由而孟子云能者從</span>  
<span style="margin-left: 2em">之又云心之官則思卽孔子從心之旨猶主持門</span>  
<span style="margin-left: 2em">戸之見也</span>  
豫章書一百二十二卷<sub class="note-yuan">江西巡撫採進本</sub>  
<span style="margin-left: 2em">明郭子章撰是書葢江西之總志全用史體爲之</span>  
<span style="margin-left: 2em">分大記二十卷志二十二卷表十卷事紀二卷列</span>  
<span style="margin-left: 2em">傳六十八卷前無序而有總目其總目以爲列傳</span>  
<span style="margin-left: 2em">六十六卷刊本誤也其體例葢本諸華陽國志然</span>  
<span style="margin-left: 2em">冗雜太甚去常璩所撰遠矣</span>  
<!-- 册2 葉1468a　Page:文淵閣四庫全書_0002冊.djvu/372 -->
國士懿軌十卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明余養䝉撰養䝉臨海人自序謂禀大中丞耿公</span>  
<span style="margin-left: 2em">之命而爲之者案明史耿定向傳弟定力隆慶辛</span>  
<span style="margin-left: 2em">未進士官至南京兵部右侍郞時方爲南京都御</span>  
<span style="margin-left: 2em">史故稱大中丞也書前有定力序復有諭官屬文</span>  
<span style="margin-left: 2em">一首大旨以當時專重科目名實不副故取古今</span>  
<span style="margin-left: 2em">來士子出於太學及以貲郞起家者自列國訖明</span>  
<span style="margin-left: 2em">初凡一百二十七人刪節諸史及志乘各爲之傳</span>  
<span style="margin-left: 2em">意欲以矯偏重之弊然舉一代之進士槩以籠鷹</span>

<span style="margin-left: 2em">檻駒目之不免於矯枉過<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">矣</span>

<span style="margin-left: 2em">奇凡一百四十八人傳末各附以小讚大旨與宋</span>

<span style="margin-left: 2em">用魯史編年之非然旣標以春秋則自應用春秋</span>  
<span style="margin-left: 2em">之年月若各從列國轉致錯互難明以是議當未</span>  
<span style="margin-left: 2em">允也</span>
