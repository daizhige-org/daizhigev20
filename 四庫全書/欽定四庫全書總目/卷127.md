## 欽定四庫全書總目 卷一百二十七　子部三十七　雜家類存目四

<!-- 册3 葉2941a　Page:文淵閣四庫全書_0003冊.djvu/740 -->
欽定四庫全書總目卷一百二十七  
<span style="margin-left: 1em">子部三十七</span>  
<span style="margin-left: 2em">雜家𩔖存目四</span>  
試筆一卷<sub class="note-yuan">兵部侍郞紀昀家藏本</sub>  
<span style="margin-left: 2em">舊本題宋歐陽脩撰末有蘇轍蘇軾二跋葢雜集</span>  
<span style="margin-left: 2em">其手書墨迹錄而成編故徃徃與六一詩話歸田</span>  
<span style="margin-left: 2em">錄語相出入考陸游渭南集有爲楊元𤼵跋東坡</span>  
<span style="margin-left: 2em">所書蘭亭記曰明窻淨几筆研紙墨皆極精良是</span>  
<span style="margin-left: 2em">人間之至樂六一居士嘗以是爲自得云云今其</span>  
<!-- 册3 葉2941b　Page:文淵閣四庫全書_0003冊.djvu/740 -->
<span style="margin-left: 2em">語正載此編中似非贋作惟蘇軾一跋凡猥殊甚</span>  
<span style="margin-left: 2em">决非軾語或刋是書者所依託歟</span>  
章申公九事一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">不著編輯者名氏晁陳二家書目及宋史藝文志</span>  
<span style="margin-left: 2em">皆未著錄卷首序云丞相惇性喜揮翰在政府時</span>  
<span style="margin-left: 2em">日書數幅予嘗見雜書一卷乃抄錄之葢從其墨</span>  
<span style="margin-left: 2em">迹錄岀前七則皆論書體源流及用筆之法惟第</span>  
<span style="margin-left: 2em">八則爲叙吕元圭幻異事第九則末署曰元祐六</span>  
<span style="margin-left: 2em">年十一月五日京口西齋大滌翁書元祐六年正</span>  
<!-- 册3 葉2944a　Page:文淵閣四庫全書_0003冊.djvu/741 -->
<span style="margin-left: 2em">惇貶汝州時按東都事畧惇自汝州徙揚州提舉</span>  
<span style="margin-left: 2em">洞霄宫以父老乞侍養歸蘇州其事宋史不載今</span>  
<span style="margin-left: 2em">據此書所云大滌翁者當因領洞霄宫故以自號</span>  
<span style="margin-left: 2em">而京口亦岀汝赴蘇所經之路與東都事畧一一</span>  
<span style="margin-left: 2em">相合知非僞託然惇人不足道併其書亦爲世所</span>  
<span style="margin-left: 2em">棄置矣</span>  
𫎇齋筆談二卷<sub class="note-yuan">兵部侍郞紀昀家藏本</sub>  
<span style="margin-left: 2em">舊本題宋鄭景望撰商維濬刻之稗海中厲鶚宋</span>  
<span style="margin-left: 2em">詩紀事亦曰景望湘山人生元豐元祐間有𫎇齋</span>  
<!-- 册3 葉2944b　Page:文淵閣四庫全書_0003冊.djvu/741 -->
<span style="margin-left: 2em">筆談今考其書乃全錄葉夢得巖下放言之文但</span>  
<span style="margin-left: 2em">刪其十分之三四而顛倒其次序維濬誤刻僞本</span>  
<span style="margin-left: 2em">又考景望乃永嘉鄭伯熊字見於陳傅良止齋集</span>  
<span style="margin-left: 2em">中其人登紹與十五年進士累官太子侍讀宗正</span>  
<span style="margin-left: 2em">少卿諡曰文肅宋詩紀事旣載伯熊詩於四十七</span>  
<span style="margin-left: 2em">卷中又據此書於三十七卷别出一鄭景望亦殊</span>  
<span style="margin-left: 2em">疎舛也</span>  
麟書一卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">宋汪若海撰若海號東叟歙縣人靖康中爲太學</span>  
<!-- 册3 葉2945a　Page:文淵閣四庫全書_0003冊.djvu/741 -->
<span style="margin-left: 2em">生建炎中官至直秘閣知江州事迹具宋史本傳</span>  
<span style="margin-left: 2em">史稱若海豁逹高亮深沉有度金兵至汴若海上</span>  
<span style="margin-left: 2em">書樞密曹輔請立康王爲大元帥及京城失守若</span>  
<span style="margin-left: 2em">海復述麟爲書以獻卽此本也其書託麟爲喻以</span>  
<span style="margin-left: 2em">儷詞作韻語詭言鴟夷子授之磐固侯大㫖主用</span>  
<span style="margin-left: 2em">兵之是斥和議之非又言不當追回康王而勸欽</span>  
<span style="margin-left: 2em">宗以死社稷用意甚爲剴直因當時金人巳破京</span>  
<span style="margin-left: 2em">城故不敢顯言而以廋詞寄其意後有鄧肅吕本</span>  
<span style="margin-left: 2em">中及其從父藻三跋明人嘗以此書及其圍城中</span>  
<!-- 册3 葉2945b　Page:文淵閣四庫全書_0003冊.djvu/741 -->
<span style="margin-left: 2em">上曹輔書上尼瑪哈<sub class="note-yuan">原作粘没喝今改正</sub>諸書合編爲若海</span>  
<span style="margin-left: 2em">集此則别行之本陳繼儒刻入秘笈者也</span>  
捫蝨新話十五卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">宋陳善撰善字敬甫號秋塘史繩袓學齋佔𠌫稱</span>  
<span style="margin-left: 2em">字子兼葢有兩字善羅源人學齋佔𠌫稱福州人</span>  
<span style="margin-left: 2em">葢舉其郡名也其書攷論經史詩文兼及雜事别</span>  
<span style="margin-left: 2em">𩔖分門頗爲冗𤨏持論尤多蹖駁大㫖以佛氏爲</span>  
<span style="margin-left: 2em">正道以王安石爲宗主故於宋人詆歐陽脩詆楊</span>  
<span style="margin-left: 2em">時詆陳東詆歐陽澈而詆蘇洵蘇軾蘇轍尤力甚</span>  
<!-- 册3 葉2948a　Page:文淵閣四庫全書_0003冊.djvu/742 -->
<span style="margin-left: 2em">至謂轍比神宗於曹操於古人詆韓愈詆孟子誤</span>  
<span style="margin-left: 2em">讀論語甚至謂江西馬師在孔子上而於周邦彦</span>  
<span style="margin-left: 2em">諛頌蔡京之詩所謂化行禹貢山川外人在周公</span>  
<span style="margin-left: 2em">禮樂中者則無譏焉善南北宋間人其始末不可</span>  
<span style="margin-left: 2em">考觀其書顛倒是非毫無忌憚必紹述餘黨之子</span>  
<span style="margin-left: 2em">孫不得志而著書者也錢曾讀書敏求記載是書</span>  
<span style="margin-left: 2em">有二本其一本不分卷帙末有紹興已巳善自跋</span>  
<span style="margin-left: 2em">一本分十五卷而無自跋此本作十五卷當卽曾</span>  
<span style="margin-left: 2em">所言之第二本然實有自跋葢曾所見本偶佚末</span>  
<!-- 册3 葉2948b　Page:文淵閣四庫全書_0003冊.djvu/742 -->
<span style="margin-left: 2em">頁耳</span>  
蕉窻雜錄一卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">舊本題曰宋稼軒居士撰稼軒辛棄疾號也故凡</span>  
<span style="margin-left: 2em">遇宋字必加皇字於上以明其爲眞棄疾作然書</span>  
<span style="margin-left: 2em">中乃引楊愼丹鉛錄王鏊震澤長語都穆聽雨紀</span>  
<span style="margin-left: 2em">談焦竑𩔖林王世貞藝苑巵言其妄殆不足辨其</span>  
<span style="margin-left: 2em">所自增數條如謂木筆名辛夷芍藥一名辛夷云</span>  
<span style="margin-left: 2em">出山海經之𩔖更爲無稽之談殆妄劣書賈鈔合</span>  
<span style="margin-left: 2em">明人說部詭題此名也</span>  
<!-- 册3 葉2949a　Page:文淵閣四庫全書_0003冊.djvu/742 -->
誠齋揮塵錄一卷<sub class="note-yuan">浙江鮑士㳟家藏本</sub>  
<span style="margin-left: 2em">舊本題宋楊萬里撰左圭收入百川學海中今檢</span>  
<span style="margin-left: 2em">其本實從王明淸揮麈錄話内摘出數十條别題</span>  
<span style="margin-left: 2em">此名凡明淸自稱其名者俱改作萬里字葢坊刻</span>  
<span style="margin-left: 2em">贋本自宋巳然百川學海在叢書中最有體要然</span>  
<span style="margin-left: 2em">且如此其餘固無足責矣</span>  
鶴山筆錄一卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">舊本題宋魏了翁撰載陸烜竒晉齋樷書中末有</span>  
<span style="margin-left: 2em">海餘老人跋稱竹坨自粤游回鈔鶴山筆錄一卷</span>  
<!-- 册3 葉2949b　Page:文淵閣四庫全書_0003冊.djvu/742 -->
<span style="margin-left: 2em">見眎予意必陳腐滿𥿄漫不省也近因箋註蘇詩</span>  
<span style="margin-left: 2em">試取檢閱則見辨核紀錄皆有眞趣卓乎小說名</span>  
<span style="margin-left: 2em">家毛氏津逮旣鐫其題跋而不及此想汲古閣中</span>  
<span style="margin-left: 2em">亦無此藏本也云云悔餘老人爲查愼行别號竹</span>  
<span style="margin-left: 2em">坨不知何許人疑爲竹垞之訛也然朱𢑴尊曝書</span>  
<span style="margin-left: 2em">亭集無此書跋而愼行補註蘇詩亦無一字引此</span>  
<span style="margin-left: 2em">書跋中辨核紀錄皆有眞趣二語文義殆不可通</span>  
<span style="margin-left: 2em">恐不出愼行之筆烜又自跋其後云按唐宋叢書</span>  
<span style="margin-left: 2em">曾刻了翁經外雜抄二卷此纔及十分之三大叚</span>  
<!-- 册3 葉2952a　Page:文淵閣四庫全書_0003冊.djvu/743 -->
<span style="margin-left: 2em">相𩔖而互有異同古人於說部徃徃厯年成書各</span>  
<span style="margin-left: 2em">種而後併歸一部此當是初本也察烜之意殆亦</span>  
<span style="margin-left: 2em">𨼆覺其僞而巧爲之詞其實卽書賈剽經外雜抄</span>  
<span style="margin-left: 2em">僞爲之與烜所刻平巢事迹考鈔通鑑半卷者等</span>  
<span style="margin-left: 2em">也</span>  
螢雪叢說二卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">宋俞成撰成字元德東陽人前有慶元庚申自序</span>  
<span style="margin-left: 2em">稱四十後卽不應科舉優游黄卷考究討論付之</span>  
<span style="margin-left: 2em">書記囊螢映雪無所不爲塵積日久遂成一編目</span>  
<!-- 册3 葉2952b　Page:文淵閣四庫全書_0003冊.djvu/743 -->
<span style="margin-left: 2em">曰螢雪叢說其書多言揣摩科舉之學而諄諄於</span>  
<span style="margin-left: 2em">假對之法以爲工巧論皆迂鄙所記契丹祭文之</span>  
<span style="margin-left: 2em">事葢本孫奕示兒編不能糾駁其非仍述爲美談</span>  
<span style="margin-left: 2em">尤齊東之語其解宥過無大刑故無小二句謂過</span>  
<span style="margin-left: 2em">當宥而大者不在所宥故曰無大故當刑而小者</span>  
<span style="margin-left: 2em">不在所刑故曰無小又訓臯陶矢謨爲射䇿之義</span>  
<span style="margin-left: 2em">皆穿鑿附會無可取也</span>  
宜齋野乘一卷<sub class="note-yuan">浙江范懋柱家大一閣藏本</sub>  
<span style="margin-left: 2em">宋吳枋撰枋字木方江陰人是書以野乘爲名而</span>  
<!-- 册3 葉2953a　Page:文淵閣四庫全書_0003冊.djvu/743 -->
<span style="margin-left: 2em">多渉考證其中如謂孟嘗君與孟子同時謂顔子</span>  
<span style="margin-left: 2em">之卒不止二十九謂吞東西周者非始皇皆有依</span>  
<span style="margin-left: 2em">據至論五帝非官天下而舉少昊之傳位於姪顓</span>  
<span style="margin-left: 2em">頊傳位於從姪摯傳位於弟堯堯傳位於五世姪</span>  
<span style="margin-left: 2em">孫舜傳位於六世祖之從兄弟爲家天下之證其</span>  
<span style="margin-left: 2em">說過竒不中經訓矣前有自序稱其書本十卷燬</span>  
<span style="margin-left: 2em">於火後憶錄其一二此本祇十一條與說郛所載</span>  
<span style="margin-left: 2em">相同似又經刪節非完書也</span>  
木筆雜鈔二卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<!-- 册3 葉2953b　Page:文淵閣四庫全書_0003冊.djvu/743 -->
<span style="margin-left: 2em">舊本題宋無名氏撰前有小序稱息軫多年小有</span>  
<span style="margin-left: 2em">紀錄齋前有木筆一叢遂以名之云云其書載曹</span>  
<span style="margin-left: 2em">溶學海𩔖編中今考其書皆宋吳子良荆溪林下</span>  
<span style="margin-left: 2em">偶談之文原書本二卷此本摘抄二卷别標新名</span>  
<span style="margin-left: 2em">又僞撰小序弁於首葢姦𭶑書賈所爲曹溶不辨</span>  
<span style="margin-left: 2em">而收之耳</span>  
吹劍錄一卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">宋俞文豹撰文豹有吹劍錄外集已著錄此編作</span>  
<span style="margin-left: 2em">於淳祐三年癸卯前有自序謂取莊子吹劍首者</span>  
<!-- 册3 葉2956a　Page:文淵閣四庫全書_0003冊.djvu/744 -->
<span style="margin-left: 2em">吷而已之語以名其書言無韻也然議論實多紕</span>  
<span style="margin-left: 2em">繆於古人多所詆詞如貶武王則拾蘇軾之緒論</span>  
<span style="margin-left: 2em">詆孟子則循李覯之謬詞斥諸葛亮爲不明大義</span>  
<span style="margin-left: 2em">不忠漢室亦本其兄文龍之妄說葢文龍以此說</span>  
<span style="margin-left: 2em">取解於同文館故文豹述之也他若韓愈程子並</span>  
<span style="margin-left: 2em">遭掊擊又文彦博燈籠錦之事則獨信魏泰之僞</span>  
<span style="margin-left: 2em">書通鑑綱目帝蜀之辨則力攻朱子之特筆其妄</span>  
<span style="margin-left: 2em">誕無識殊爲悼理所謂小人好議論不樂成人之</span>  
<span style="margin-left: 2em">美者歟</span>  
<!-- 册3 葉2956b　Page:文淵閣四庫全書_0003冊.djvu/744 -->
碧湖雜記一卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">不著撰人名氏陶宗儀說郛載之題曰宋謝枋得</span>  
<span style="margin-left: 2em">撰然宋志及諸家書目皆不著錄未知確出枋得</span>
