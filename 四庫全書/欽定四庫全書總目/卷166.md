## 欽定四庫全書總目 卷一百六十六　集部十九　別集類十九

欽定四庫全書總目卷一百六十六  
<span style="margin-left: 1em">集部十九</span>  
<span style="margin-left: 2em">别集𩔖十九</span>  
拙軒集六卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">金王寂撰寂字元老薊州玉田人登天德二年進</span>  
<span style="margin-left: 2em">士厯官中都路轉運使諡文肅金史不爲立傳元</span>  
<span style="margin-left: 2em">好問中州集載其詩入乙集中而仕履亦僅見梗</span>  
<span style="margin-left: 2em">槪今以寂詩文所著年月事蹟叅互考証知寂自</span>  
<span style="margin-left: 2em">登第後於世宗大定二年爲太原初縣令十五年</span>  
<!-- 册4 葉1409b　Page:文淵閣四庫全書_0004冊.djvu/357 -->
<span style="margin-left: 2em">嘗奉使徃白霫治獄十七年以父艱歸明年起復</span>  
<span style="margin-left: 2em">眞定少尹兼河北西路兵馬副都總管遷通州刺</span>  
<span style="margin-left: 2em">史兼知軍事又遷中都副留守二十六年冬由戸</span>  
<span style="margin-left: 2em">部郎出守蔡州二十九年被命提㸃遼東路刑獄</span>  
<span style="margin-left: 2em">章宗明昌初召還終於轉運使之職而集中謝帶</span>  
<span style="margin-left: 2em">笏表有世宗享國臣得與諫員語則又當爲諫官</span>  
<span style="margin-left: 2em">又有羣言交搆擠臣不測之淵語而丁未肆𤯝詩</span>  
<span style="margin-left: 2em">有萬里湘纍得自新句丁未爲大定二十七年世</span>  
<span style="margin-left: 2em">宗本紀載是年三月辛亥以皇長孫受册肆赦並</span>  
<!-- 册4 葉1412a　Page:文淵閣四庫全書_0004冊.djvu/358 -->
<span style="margin-left: 2em">與集合是寂之刺蔡州當以人言去國而集中情</span>  
<span style="margin-left: 2em">事不具其顚末莫能詳也中州集稱寂著有拙軒</span>  
<span style="margin-left: 2em">集北遷錄諸書今北遷錄巳失傳而好問所選寂</span>  
<span style="margin-left: 2em">詩僅七首又附見姚孝錫傳後一首其他亦久佚</span>  
<span style="margin-left: 2em">不見惟永樂大典所載寂詩文尙多雖如好問所</span>  
<span style="margin-left: 2em">摘留别郭熙民詩諸聯及蔣一葵長安客話所紀</span>  
<span style="margin-left: 2em">盧植墓詩逸句皆未見全篇亦不能盡免於脫闕</span>  
<span style="margin-left: 2em">而各體具存可以得其什七矣寂詩境淸刻鑱露</span>  
<span style="margin-left: 2em">有戞戞獨造之風古文亦博大疏暢在大定明昌</span>  
<!-- 册4 葉1412b　Page:文淵閣四庫全書_0004冊.djvu/358 -->
<span style="margin-left: 2em">間卓然不愧爲作者金朝一代文士見於中州集</span>  
<span style="margin-left: 2em">者不下百數十家今惟趙秉文王若虚數家尙有</span>  
<span style="margin-left: 2em">傳本餘多湮没無存獨寂是編幸於沈埋晦蝕之</span>  
<span style="margin-left: 2em">餘復顯於世而文章體格亦足與滹南<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3223.svg?width=24" alt="四庫全書僻字第3223號（滏）" title="四庫全書僻字第3223號（滏）">水相爲</span>  
<span style="margin-left: 2em">抗行謹次第裒綴𨤲爲六卷俾讀者攬其崖畧猶</span>  
<span style="margin-left: 2em">得以考見金源文獻之遺是亦可爲寳貴矣</span>  
<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3223.svg?width=24" alt="四庫全書僻字第3223號（滏）" title="四庫全書僻字第3223號（滏）">水集二十卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">金趙秉文撰秉文字周臣自號閒閒道人<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3223.svg?width=24" alt="四庫全書僻字第3223號（滏）" title="四庫全書僻字第3223號（滏）">陽人</span>  
<span style="margin-left: 2em">大定二十五年進士厯官翰林侍讀學士拜禮部</span>  
<!-- 册4 葉1413a　Page:文淵閣四庫全書_0004冊.djvu/358 -->
<span style="margin-left: 2em">尙書事迹具金史本傳元好問中州集稱其自㓜</span>  
<span style="margin-left: 2em">至老未嘗一日廢書著易叢說十卷中庸說一卷</span>  
<span style="margin-left: 2em">揚子發微一卷太元贊六卷文中子𩔖說一卷南</span>  
<span style="margin-left: 2em">華畧釋一卷列子補註一卷刪集論語孟子說各</span>  
<span style="margin-left: 2em">十卷資暇錄十五卷今皆未見惟此集存史稱所</span>  
<span style="margin-left: 2em">著詩文三十卷此本乃二十卷與史互異然篇目</span>  
<span style="margin-left: 2em">完具不似有所佚脫考中州集稱秉文所著文章</span>  
<span style="margin-left: 2em">號<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3223.svg?width=24" alt="四庫全書僻字第3223號（滏）" title="四庫全書僻字第3223號（滏）">水集者前後三十卷又劉初歸潛志曰趙閒</span>  
<span style="margin-left: 2em">閒本喜佛學然方之屏山<sub class="note-yuan">案屏山李之純之號也</sub>顧畏士論</span>  
<!-- 册4 葉1413b　Page:文淵閣四庫全書_0004冊.djvu/358 -->
<span style="margin-left: 2em">又欲得扶教傳古之名晩年自擇其文凡主張佛</span>  
<span style="margin-left: 2em">老二家者皆削去號<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3223.svg?width=24" alt="四庫全書僻字第3223號（滏）" title="四庫全書僻字第3223號（滏）">水集首以中和誠諸說冠</span>  
<span style="margin-left: 2em">之以擬退之原道其爲二家所作文及其葛藤詩</span>  
<span style="margin-left: 2em">句另作一編號閒閒外集以與少林寺長老英粹</span>  
<span style="margin-left: 2em">使刋之故二集皆行於世則<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3223.svg?width=24" alt="四庫全書僻字第3223號（滏）" title="四庫全書僻字第3223號（滏）">水集本二十卷别</span>  
<span style="margin-left: 2em">有十卷爲外集本傳合而計之故爲三十卷也歸</span>  
<span style="margin-left: 2em">潛志又曰李屏山教後學爲文欲自成一家趙閒</span>  
<span style="margin-left: 2em">閒教後進爲詩文則曰文章不可拘一體有時竒</span>  
<span style="margin-left: 2em">古有時平淡何拘李嘗與余論趙文曰才甚高氣</span>  
<!-- 册4 葉1416a　Page:文淵閣四庫全書_0004冊.djvu/359 -->
<span style="margin-left: 2em">𧰼甚雄然不免有失支墮節處葢學東坡而不成</span>  
<span style="margin-left: 2em">者又趙詩多犯古人語一節或有數句此亦文章</span>  
<span style="margin-left: 2em">病又曰趙於詩最細於文頗疎止論氣𧰼李於文</span>  
<span style="margin-left: 2em">甚細論闗鍵賔主抑揚於詩頗疎止論詞氣才巧</span>  
<span style="margin-left: 2em">故余於趙則取其作詩法於李則取其爲文法云</span>  
<span style="margin-left: 2em">云今觀是集祁之論可謂公矣</span>  
滹南遺老集四十五卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">金王若虚撰若虛字從之自號慵夫藁城人登承</span>  
<span style="margin-left: 2em">安二年經義進士厯官左司諌轉延州刺史入爲</span>  
<!-- 册4 葉1416b　Page:文淵閣四庫全書_0004冊.djvu/359 -->
<span style="margin-left: 2em">翰林直學士金亡後微服歸里自稱滹南遺老越</span>  
<span style="margin-left: 2em">十年與劉祁東游卒於泰山事迹具金史文藝傳</span>  
<span style="margin-left: 2em">史稱若虚有慵夫集滹南遺老集均曰若干卷不</span>  
<span style="margin-left: 2em">詳其數黄虞稷千頃堂書目載滹南遺老集四十</span>  
<span style="margin-left: 2em">五卷與王鶚序合慵夫集虞稷雖著錄而卷數則</span>  
<span style="margin-left: 2em">缺考大德三年王復翁序稱以中州集所載詩二</span>  
<span style="margin-left: 2em">十首附卷未則慵夫集元時巳佚惟此集存耳此</span>  
<span style="margin-left: 2em">本凡五經辨惑二卷論語辨惑五卷孟子辨惑一</span>  
<span style="margin-left: 2em">卷史記辨惑十一卷諸史辨惑二卷新唐書辨三</span>  
<!-- 册4 葉1417a　Page:文淵閣四庫全書_0004冊.djvu/359 -->
<span style="margin-left: 2em">卷君事實辨二卷臣事實辨三卷議論辨惑一卷</span>  
<span style="margin-left: 2em">著述辨惑一卷雜辨一卷謬誤雜辨一卷文辨四</span>  
<span style="margin-left: 2em">卷詩話三卷雜文及詩五卷與四十五卷之數合</span>  
<span style="margin-left: 2em">然第三卷惟論語辨惑序一篇總論一篇僅三頁</span>  
<span style="margin-left: 2em">有竒與他卷多寡懸殊疑傳寫佚此一卷後人割</span>  
<span style="margin-left: 2em">第四卷首三頁改其標題以足原數也蘇天爵作</span>  
<span style="margin-left: 2em">安熙行狀云國初有傳朱氏四書集註至北方者</span>  
<span style="margin-left: 2em">滹南王公雅以辨博自<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3688.svg?width=24" alt="四庫全書僻字第3688號（負）" title="四庫全書僻字第3688號（負）">爲說非之今考論語孟</span>  
<span style="margin-left: 2em">子辨惑乃雜引先儒異同之說斷以已意其間疑</span>  
<!-- 册4 葉1417b　Page:文淵閣四庫全書_0004冊.djvu/359 -->
<span style="margin-left: 2em">朱子者有之而從朱子者亦不少實非專爲辨駁</span>  
<span style="margin-left: 2em">朱子而作天爵所云不知何據觀其稱陳天祥宗</span>  
<span style="margin-left: 2em">若虚之說撰四書辨疑因熙斥之遂焚其稿今天</span>  
<span style="margin-left: 2em">祥之書具存無焚稿事則天爵是說特欲虚張其</span>  
<span style="margin-left: 2em">師表章朱子之功耳均非實錄也其五經辨惑頗</span>  
<span style="margin-left: 2em">詰難鄭學於周禮禮記及春秋三傳亦時有所疑</span>  
<span style="margin-left: 2em">然所攻者皆漢儒附會之詞亦頗樹偉觀其自稱</span>  
<span style="margin-left: 2em">不深於易卽於易不置一詞所論實止四經則亦</span>  
<span style="margin-left: 2em">非强所不知者矣史記辨惑諸史辨惑新唐書辨</span>  
<!-- 册4 葉1420a　Page:文淵閣四庫全書_0004冊.djvu/360 -->
<span style="margin-left: 2em">皆考証史文掊擊司馬遷宋祁似未免過甚或乃</span>  
<span style="margin-left: 2em">毛舉細故亦失之煩𤨏然所摘遷之自相牴牾與</span>  
<span style="margin-left: 2em">祁之過於彫斵中其病者亦十之七八雜辨君事</span>  
<span style="margin-left: 2em">實辨臣事實辨皆所作史評議論辨惑著述辨惑</span>  
<span style="margin-left: 2em">皆品題先儒之是非其間多持平之論頗足破宋</span>  
<span style="margin-left: 2em">人之拘攣雜辨二卷於訓詁亦多訂正文辨宗蘇</span>  
<span style="margin-left: 2em">軾而於韓愈間有指摘詩話尊杜甫而於黄庭堅</span>  
<span style="margin-left: 2em">多所訾議葢若虚詩文不尙？削鍜鍊之格故其</span>  
<span style="margin-left: 2em">論如是也統觀全集偏駁之處誠有然金元之間</span>  
<!-- 册4 葉1420b　Page:文淵閣四庫全書_0004冊.djvu/360 -->
<span style="margin-left: 2em">學有根柢者實無人出若虚右吳澄稱其博學卓</span>  
<span style="margin-left: 2em">識見之所到不苟同於衆亦可謂不虚美矣</span>  
莊靖集十卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">金李俊民撰俊民字用章澤州人承安五年以經</span>  
<span style="margin-left: 2em">義舉進士第一應奉翰林文字未幾棄官教授南</span>  
<span style="margin-left: 2em">遷後隠於嵩山自號鶴鳴道人元世祖以安車召</span>  
<span style="margin-left: 2em">見仍乞還山卒賜諡莊靖先生集凡詩七卷文三</span>  
<span style="margin-left: 2em">卷澤州守段正<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">嘗爲刋行長平李仲紳等爲之</span>  
<span style="margin-left: 2em">序明正德間郡人李瀚重付諸梓今板巳久佚祗</span>  
<!-- 册4 葉1421a　Page:文淵閣四庫全書_0004冊.djvu/360 -->
<span style="margin-left: 2em">存寫本而巳俊民抗志遯荒於出處之際能潔其</span>  
<span style="margin-left: 2em">身集中於入元後祗書甲子隠然自比陶潛故所</span>  
<span style="margin-left: 2em">作詩𩔖多幽憂激烈之音繋念宗<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3771.svg?width=24" alt="四庫全書僻字第3771號（邦）" title="四庫全書僻字第3771號（邦）">𭔃懐深遠不</span>  
<span style="margin-left: 2em">徒以淸新竒崛爲工文格冲澹和平具有高致亦</span>  
<span style="margin-left: 2em">復似其爲人雖博大不及元好問抑亦其亞矣詩</span>  
<span style="margin-left: 2em">末間有注語序不言何人所加無可考證今仍舊</span>  
<span style="margin-left: 2em">本錄之而註者姓名則姑闕焉</span>  
遺山集四十卷附錄一卷<sub class="note-yuan">江蘇廵撫採進本</sub>  
<span style="margin-left: 2em">金元好問撰好問字裕之秀容人登興寳五年進</span>  
<!-- 册4 葉1421b　Page:文淵閣四庫全書_0004冊.djvu/360 -->
<span style="margin-left: 2em">士厯内鄕令天興中除左司都事轉行尙書省左</span>  
<span style="margin-left: 2em">司員外郞金亡不仕事蹟具金史文藝傳是集凡</span>  
<span style="margin-left: 2em">詩十四卷文二十六卷爲明儲巏家藏本宏治戊</span>
