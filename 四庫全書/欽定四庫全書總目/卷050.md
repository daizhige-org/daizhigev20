## 欽定四庫全書總目 卷五十　史部六　別史類、別史類存目

<!-- 册2 葉444：整葉圖版，無文字記錄 -->
<!-- 册2 葉445a　Page:文淵閣四庫全書_0002冊.djvu/116 -->
欽定四庫全書總目卷五十  
<span style="margin-left: 1em">史部六</span>  
<span style="margin-left: 2em">别史類</span>  
<span style="margin-left: 3em">漢藝文志無史名戰國策史記均附見於春秋</span>  
<span style="margin-left: 3em">厥後著作漸繁隋志乃分正史古史霸史諸目</span>  
<span style="margin-left: 3em">然梁武帝元帝實錄列諸雜史義未安也陳振</span>  
<span style="margin-left: 3em">孫書錄解題創立别史一門以處上不至於正</span>  
<span style="margin-left: 3em">史下不至於雜史者義例獨善今特從之葢編</span>  
<span style="margin-left: 3em">年不列於正史故凡屬編年皆得類附史記漢</span>  
<!-- 册2 葉445b　Page:文淵閣四庫全書_0002冊.djvu/116 -->
<span style="margin-left: 3em">書以下已列爲正史矣其岐出旁分者東觀漢</span>  
<span style="margin-left: 3em">記東都事畧大金國志契丹國志之類則先資</span>  
<span style="margin-left: 3em">草創逸周書路史之類則互取證明古史續後</span>  
<span style="margin-left: 3em">漢書之類則檢校異同其書皆足相輔而其名</span>  
<span style="margin-left: 3em">則不可以並列命曰别史猶大宗之有别子云</span>  
<span style="margin-left: 3em">爾包羅旣廣六體兼存必以類分轉形瑣屑故</span>  
<span style="margin-left: 3em">今所編錄通以年代先後爲敘</span>  
逸周書十卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">舊本題曰汲冡周書考隋經籍志唐藝文志俱稱</span>  
<!-- 册2 葉448a　Page:文淵閣四庫全書_0002冊.djvu/117 -->
<span style="margin-left: 2em">此書以晉太康二年得於魏安釐王冡中則汲冡</span>  
<span style="margin-left: 2em">之說其來已久然晉書武帝紀及荀朂束晳傳載</span>  
<span style="margin-left: 2em">汲郡人不準所得竹書七十五篇具有篇名無所</span>  
<span style="margin-left: 2em">謂周書杜預春秋集解後序載汲冡諸書亦不列</span>  
<span style="margin-left: 2em">周書之目是周書不出汲冡也攷漢書藝文志先</span>  
<span style="margin-left: 2em">有周書七十一篇今本比班固所紀惟少一篇陳</span>  
<span style="margin-left: 2em">振孫書錄解題稱凡七十篇叙一篇在其末京口</span>  
<span style="margin-left: 2em">刊本始以序散入諸篇則篇數仍七十有一與漢</span>  
<span style="margin-left: 2em">志合司馬遷紀武王克商事亦與此書相應許愼</span>  
<!-- 册2 葉448b　Page:文淵閣四庫全書_0002冊.djvu/117 -->
<span style="margin-left: 2em">作說文引周書大翰若翬雉又引周書豲有爪而</span>  
<span style="margin-left: 2em">不敢以撅馬融註論語引周書月令鄭元註周禮</span>  
<span style="margin-left: 2em">引周書王會註儀禮引周書比黨州閭皆在汲冡</span>  
<span style="margin-left: 2em">前知爲漢代相傳之舊郭璞註爾雅稱逸周書李</span>  
<span style="margin-left: 2em">善文選註所引亦稱逸周書知晉及唐初舊本尚</span>  
<span style="margin-left: 2em">不題汲冡其相沿稱爲汲冡者殆以梁任昉得竹</span>  
<span style="margin-left: 2em">簡漆書不能辨識以示劉顯顯識爲孔子刪書之</span>  
<span style="margin-left: 2em">餘其時南史未出流傳不審遂誤合汲冡竹簡爲</span>  
<span style="margin-left: 2em">一事而修隋志者誤采之耶鄭元祐作大戴禮後</span>  
<!-- 册2 葉449a　Page:文淵閣四庫全書_0002冊.djvu/117 -->
<span style="margin-left: 2em">序稱文王官人篇與汲冡周書官人解相出人汲</span>  
<span style="margin-left: 2em">冡書出於晉太康中未審何由相似云云殊失之</span>  
<span style="margin-left: 2em">不考文獻通考所引李燾跋及劉克莊後村詩話</span>  
<span style="margin-left: 2em">皆以爲漢時本有此書其後稍隱賴汲冡竹簡出</span>  
<span style="margin-left: 2em">乃得復顯是又心知其非而巧爲調停之說惟舊</span>  
<span style="margin-left: 2em">本載嘉定十五年丁黼跋反覆考証確以爲不出</span>  
<span style="margin-left: 2em">汲冡斯定論矣其書載有太子晉事則當成於靈</span>  
<span style="margin-left: 2em">王以後所云文王受命稱王武王周公私計東伐</span>  
<span style="margin-left: 2em">俘馘殷遺暴殄原獸輦括寶玉動至億萬三發下</span>  
<!-- 册2 葉449b　Page:文淵閣四庫全書_0002冊.djvu/117 -->
<span style="margin-left: 2em">車懸紂首太白又用之南郊皆古人必無之事陳</span>  
<span style="margin-left: 2em">振孫以爲戰國後人所爲似非無見然左傳引周</span>  
<span style="margin-left: 2em">志勇則犯上不登於明堂又引書愼始而敬終終</span>  
<span style="margin-left: 2em">乃不困又引書居安思危又稱周作九刑其文皆</span>  
<span style="margin-left: 2em">在今書中則春秋時已有之特戰國以後又輾轉</span>  
<span style="margin-left: 2em">附益故其言駁雜耳究厥本始終爲三代之遺文</span>  
<span style="margin-left: 2em">不可廢也近代所行之本皆闕程寤秦陰九政九</span>  
<span style="margin-left: 2em">開劉法文開保開八繁箕子耆德月令十一篇餘</span>  
<span style="margin-left: 2em">亦文多佚脫今考史記楚世家引周書欲起無先</span>  
<!-- 册2 葉452a　Page:文淵閣四庫全書_0002冊.djvu/118 -->
<span style="margin-left: 2em">主父偃傳引周書安危在出令存亡在所命貨殖</span>  
<span style="margin-left: 2em">傳引周書農不出則乏其食工不出則乏其事商</span>  
<span style="margin-left: 2em">不出則三寶絕虞不出則財匱少漢書引周書無</span>  
<span style="margin-left: 2em">爲創首將受其咎又引周書天子不取反受其咎</span>  
<span style="margin-left: 2em">唐六典引周書湯放桀大會諸侯取天子之璽置</span>  
<span style="margin-left: 2em">天子之座今本皆無之葢皆所佚十一篇之文也</span>  
<span style="margin-left: 2em">觀李燾所跋已有脫爛難讀之語則宋本已然矣</span>  
東觀漢記二十四卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">案東觀漢記隋書經籍志稱長水校尉劉珍等撰</span>  
<!-- 册2 葉452b　Page:文淵閣四庫全書_0002冊.djvu/118 -->
<span style="margin-left: 2em">今考之范書珍未嘗爲長水校尉且此書創始在</span>  
<span style="margin-left: 2em">明帝時不可題珍等居首按范書班固傳云明帝</span>  
<span style="margin-left: 2em">始詔班固與睢陽令陳宗長陵令尹敏司𨽻從事</span>  
<span style="margin-left: 2em">孟異共成世祖本紀因又撰功臣㔻林新市公孫</span>  
<span style="margin-left: 2em">述事作列傳載記二十八篇此漢記之初創也劉</span>  
<span style="margin-left: 2em">知幾史通古今正史篇云安帝詔史官謁者僕射</span>  
<span style="margin-left: 2em">劉珍諫議大夫李尤雜作紀表名臣節士儒林外</span>  
<span style="margin-left: 2em">戚諸傳起建武訖永初范書劉珍傳亦稱鄭太后</span>  
<span style="margin-left: 2em">詔珍與劉騊駼作建武以來名臣傳此漢記之初</span>  
<!-- 册2 葉453a　Page:文淵閣四庫全書_0002冊.djvu/118 -->
<span style="margin-left: 2em">續也史通又云劉珍等卒復令侍中伏無忌與諫</span>  
<span style="margin-left: 2em">議大夫黃景作諸王王子功臣恩澤侯表與單于</span>  
<span style="margin-left: 2em">西羌傳地理志元嘉元年復令大中大夫邊韶大</span>  
<span style="margin-left: 2em">軍營司馬崔寔議郞朱穆曹壽雜作孝穆崇二皇</span>  
<span style="margin-left: 2em">及順烈皇后傳又增外戚傳入安思等后儒林傳</span>  
<span style="margin-left: 2em">入崔篆諸人寔壽又與議郞延篤雜作百官表順</span>  
<span style="margin-left: 2em">帝功臣孫程郭願鄭衆蔡倫等傳凡百十有四篇</span>  
<span style="margin-left: 2em">號曰漢記范書伏湛𫝊亦云元嘉中桓帝詔伏無</span>  
<span style="margin-left: 2em">忌與黃景崔寔等共撰漢紀延篤傳亦稱篤與朱</span>  
<!-- 册2 葉453b　Page:文淵閣四庫全書_0002冊.djvu/118 -->
<span style="margin-left: 2em">穆邊韶共著作東觀此漢記之再續也葢至是而</span>  
<span style="margin-left: 2em">史體粗備乃肇有漢記之名史通又云熹平中光</span>  
<span style="margin-left: 2em">祿大夫馬日磾議郞蔡邕楊彪著作東觀接續紀</span>  
<span style="margin-left: 2em">傳之可成者而邕别作朝會車服二志後坐事徙</span>  
<span style="margin-left: 2em">朔方上書求還續成十志董卓作亂舊文散逸及</span>  
<span style="margin-left: 2em">在許都楊彪頗存注紀按范書蔡邕傳邕在東觀</span>  
<span style="margin-left: 2em">與盧植韓說等撰補後漢記所作靈紀及十志又</span>  
<span style="margin-left: 2em">補諸列傳四十二篇因李傕之亂多不存盧植傳</span>  
<span style="margin-left: 2em">亦稱熹平中植與邕說並在東觀補續漢記又劉</span>  
<!-- 册2 葉456a　Page:文淵閣四庫全書_0002冊.djvu/119 -->
<span style="margin-left: 2em">昭補注司馬書引袁崧書云劉洪與蔡邕共述律</span>  
<span style="margin-left: 2em">厯紀又引謝承書云胡廣博綜舊儀蔡邕因以爲</span>  
<span style="margin-left: 2em">志又引謝沈書云蔡邕引中興以來所修者爲祭</span>  
<span style="margin-left: 2em">祀志章懷太子范書注稱邕上書云臣科條諸志</span>  
<span style="margin-left: 2em">所欲刪定者一所當接續者四前志所無臣欲著</span>  
<span style="margin-left: 2em">者五此漢記之三續也其稱東觀者後漢書注引</span>  
<span style="margin-left: 2em">雒陽宮殿名云南宮有東觀范書竇章傳云永初</span>  
<span style="margin-left: 2em">中學者稱東觀爲老氏藏室道家蓬萊山葢東漢</span>  
<span style="margin-left: 2em">初著述在蘭臺至章和以後圖籍盛於東觀修史</span>  
<!-- 册2 葉456b　Page:文淵閣四庫全書_0002冊.djvu/119 -->
<span style="margin-left: 2em">者皆在是焉故以名書隋志稱書凡一百四十三</span>  
<span style="margin-left: 2em">卷而新舊唐書志則云一百二十六卷又錄一卷</span>  
<span style="margin-left: 2em">葢唐時已有闕佚隋志又稱是書起光武訖靈帝</span>  
<span style="margin-left: 2em">今考列傳之文間紀及獻帝時事葢楊彪所補也</span>  
<span style="margin-left: 2em">晉時以此書與史記漢書爲三史人多習之故六</span>  
<span style="margin-left: 2em">朝及初唐人𨽻事釋書類多徵引自唐章懷太子</span>  
<span style="margin-left: 2em">集諸儒注范書盛行於代此書遂㣲北宋時尚有</span>  
<span style="margin-left: 2em">殘本四十三卷趙希弁讀書附志邵博聞見後錄</span>  
<span style="margin-left: 2em">並稱其書乃高麗所獻葢已罕得南宋中興書目</span>  
<!-- 册2 葉457a　Page:文淵閣四庫全書_0002冊.djvu/119 -->
<span style="margin-left: 2em">則止存鄧禹吳漢賈復耿弇冦恂馮異祭遵景丹</span>  
<span style="margin-left: 2em">葢延九傳共八卷有蜀中刊本流傳而錯誤不可</span>  
<span style="margin-left: 2em">讀上蔡任ခ始以秘閣本讐校羅願爲序行之刻</span>  
<span style="margin-left: 2em">板於江夏又陳振孫書錄解題稱其所見本卷第</span>  
<span style="margin-left: 2em">凡十二而闕第七第八二卷卷數雖似稍多而核</span>  
<span style="margin-left: 2em">其列傳之數亦止九篇則固無異於書目所載也</span>  
<span style="margin-left: 2em">自元以來此書已佚永樂大典於鄧吳賈耿諸韻</span>  
<span style="margin-left: 2em">中並無漢記一語則所謂九篇者明初卽已不存</span>  
<span style="margin-left: 2em">矣</span>  
<!-- 册2 葉457b　Page:文淵閣四庫全書_0002冊.djvu/119 -->
<span style="margin-left: 1em">本朝姚之駰撰後漢書補逸曾蒐集遺文析爲八卷</span>  
<span style="margin-left: 2em">然所採秖據劉昭續漢書十志補注後漢書注虞</span>  
<span style="margin-left: 2em">世南北堂書抄歐陽詢藝文類聚徐堅初學記五</span>  
<span style="margin-left: 2em">書又往往掇拾不盡挂漏殊多今謹據姚本舊文</span>  
<span style="margin-left: 2em">以永樂大典各韻所載參考諸書補其闕逸所增</span>  
<span style="margin-left: 2em">者幾十之六其書久無刊板傳寫多訛姚本隨文</span>  
<span style="margin-left: 2em">鈔錄謬戾百出且漢記目錄雖佚而紀表志傳載</span>  
<span style="margin-left: 2em">記諸體例史通及各書所載梗槪尙一一可尋姚</span>  
<span style="margin-left: 2em">本不加考證隨意標題割裂顚倒不可殫數今悉</span>  
<!-- 册2 葉460a　Page:文淵閣四庫全書_0002冊.djvu/120 -->
<span style="margin-left: 2em">加釐正分爲帝紀三卷年表一卷志一卷列傳十</span>  
<span style="margin-left: 2em">七卷載記一卷其篇第無可考者别爲佚文一卷</span>  
<span style="margin-left: 2em">而以漢紀與范書異同附錄於末雖殘珪斷璧零</span>  
<span style="margin-left: 2em">落不完而古澤斑爛罔非瑰寶書中所載如章帝</span>  
<span style="margin-left: 2em">之詔增修羣祀杜林之議郊祀東平王蒼之議廟</span>  
<span style="margin-left: 2em">舞並一朝大典而范書均不詳載其文他如張順</span>  
<span style="margin-left: 2em">預起義之謀王常贊毘陽之策楊正之嚴正趙勤</span>  
<span style="margin-left: 2em">之潔淸亦復槩從闕如殊爲疎畧惟賴兹殘笈讀</span>  
<span style="margin-left: 2em">史者尙有所稽則其有資考證良非淺鮮尤不可</span>

<span style="margin-left: 2em">不亟爲表章矣</span>
