## 欽定四庫全書總目 卷九　經部九　易類存目三

<!-- 册1 葉841a　Page:文淵閣四庫全書_0001冊.djvu/260 -->
欽定四庫全書總目卷九  
<span style="margin-left: 1em">經部九</span>  
<span style="margin-left: 2em">易類存目三</span>  
讀易蒐十二卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 1em">國朝鄭賡唐撰賡唐縉雲人前明天啟丁卯舉人官</span>  
<span style="margin-left: 2em">至福建按察使僉事是書序稱丁亥蓋成於順治</span>  
<span style="margin-left: 2em">四年經文全用注疏本每卦之末附論一篇多經</span>  
<span style="margin-left: 2em">生之常義至繫辭舊雖分章然自漢晉以來未有</span>  
<span style="margin-left: 2em">標目賡唐直加以天尊章設位章諸名則是自造</span>  
<!-- 册1 葉841b　Page:文淵閣四庫全書_0001冊.djvu/260 -->
<span style="margin-left: 2em">篇題殊乖古式又說卦章次亦加刪併而不言所</span>  
<span style="margin-left: 2em">以改定之故更不免變亂之譏蓋猶明季諸人輕</span>  
<span style="margin-left: 2em">改古經之餘習也</span>  
大易則通十五卷閏一卷<sub class="note-yuan">湖北廵撫採進本</sub>  
<span style="margin-left: 1em">國朝胡世安撰世安字處靜號菊潭井研人前明崇</span>  
<span style="margin-left: 2em">禎戊辰進士歴任少詹事入</span>  
<span style="margin-left: 1em">國朝官至大學士是書專主闡明圖學彚萃諸家之</span>  
<span style="margin-left: 2em">圖各爲之說雖亦及於辭變象占而總以數爲主</span>  
<span style="margin-left: 2em">其閏卷則續採明羅喻義讀易珊瑚筯及劉養貞</span>  
<!-- 册1 葉844a　Page:文淵閣四庫全書_0001冊.djvu/261 -->
<span style="margin-left: 2em">易遺象義之說也</span>  
周易感義<sub class="note-yuan">無巻數　兩江總督採進本</sub>  
<span style="margin-left: 2em">此書爲未刻藁本中多朱墨塗乙其撰人姓名墨</span>  
<span style="margin-left: 2em">筆題東海衲民岳嵐墨山氏述蓋所自書朱筆題</span>  
<span style="margin-left: 2em">江西兵憲岳虞巒衡山氏述爲其同里魯釗所書</span>  
<span style="margin-left: 2em">攷太學題名碑錄前明崇禎辛未科有岳虞巒南</span>  
<span style="margin-left: 2em">直隷武進人又江南通志儒林傳稱虞巒字舜牧</span>  
<span style="margin-left: 2em">官至江西按察使晩尤好易撰有周易感及春秋</span>  
<span style="margin-left: 2em">平義二書書中云幼時及見熹廟初年時代亦復</span>  
<!-- 册1 葉844b　Page:文淵閣四庫全書_0001冊.djvu/261 -->
<span style="margin-left: 2em">相合然則所謂周易感者當卽此書特刻板誤脫</span>  
<span style="margin-left: 2em">義字耳書中又云丙申五月著稿則成於</span>  
<span style="margin-left: 1em">國朝順治十三年疑其明亡以後變服爲僧改名岳</span>  
<span style="margin-left: 2em">嵐故自稱東海衲民也是書惟解六十四卦分八</span>  
<span style="margin-left: 2em">巨冊而朱筆又間有標二編第幾巻者殆本有初</span>  
<span style="margin-left: 2em">編二編經釗刪併爲今本耶其說詳於取象近錢</span>  
<span style="margin-left: 2em">一本之學然皆參以佛氏如稱西域之有迦文猶</span>  
<span style="margin-left: 2em">中國之有羲文周孔云云謬妄非一釗雖多所刋</span>  
<span style="margin-left: 2em">削欲滅其迹而能潤飾其字句究不能改易其宗</span>  
<!-- 册1 葉845a　Page:文淵閣四庫全書_0001冊.djvu/261 -->
<span style="margin-left: 2em">旨葢於王宗傳沈作喆之說又變本加厲矣</span>  
易學筮貞四巻<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 1em">國朝趙世對撰世對字襄城衢州人兹編論易爲⺊</span>  
<span style="margin-left: 2em">筮之書故經秦火而獨存命之曰筮貞謂以筮而</span>  
<span style="margin-left: 2em">貞萬世之變也不載經文惟採先儒議論分𩔖編</span>  
<span style="margin-left: 2em">輯一巻曰綴集本旨曰易學源流曰圖書節要二</span>  
<span style="margin-left: 2em">巻曰蓍法指南三巻曰占變詳考四巻曰易道同</span>  
<span style="margin-left: 2em">歸論筮法與占變條理頗爲詳明葢純以數言易</span>  
<span style="margin-left: 2em">者也</span>  
<!-- 册1 葉845b　Page:文淵閣四庫全書_0001冊.djvu/261 -->
周易明善錄二巻<sub class="note-yuan">江西廵撫採進本</sub>  
<span style="margin-left: 1em">國朝徐繼發撰繼發字繩武貴溪人其書專以後天</span>  
<span style="margin-left: 2em">諸圖爲主由占筮卦氣而蔓衍於律呂等韻前有</span>  
<span style="margin-left: 2em">自序謂後天之道以致用爲主而造化之流行有</span>  
<span style="margin-left: 2em">常有變常者宰之於帝變者藏之於神履其常者</span>  
<span style="margin-left: 2em">以卦爲體通其變者以筮爲用是故帝者流行一</span>  
<span style="margin-left: 2em">定之極而神者造化不測之機也其推闡亦頗極</span>  
<span style="margin-left: 2em">苦心然與講先天之圖者亦同一關紐總爲易外</span>  
<span style="margin-left: 2em">之别傳而巳</span>  
<!-- 册1 葉848a　Page:文淵閣四庫全書_0001冊.djvu/262 -->
麗奇軒易經講義<sub class="note-yuan">無巻數　編修勵守謙家藏本</sub>  
<span style="margin-left: 1em">國朝紀克揚撰克揚字武維號六息文安人是編用</span>  
<span style="margin-left: 2em">注疏本不錄經文但每卦約詁數條皆略象數而</span>  
<span style="margin-left: 2em">談義理詳其文義葢標識於經傳之上而其後人</span>  
<span style="margin-left: 2em">錄之成帙者也</span>  
羲畫憤參二十五巻<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 1em">國朝陸位時撰位時字與偕錢塘人在前明嘗官鄞</span>  
<span style="margin-left: 2em">縣訓導是書成於順治丙戌前有位時自序稱小</span>  
<span style="margin-left: 2em">憤小悟大憤大悟不憤不悟憤之云者心求通而</span>  
<!-- 册1 葉848b　Page:文淵閣四庫全書_0001冊.djvu/262 -->
<span style="margin-left: 2em">未得之意故曰憤參其書專闡河洛之數而附益</span>  
<span style="margin-left: 2em">以先天之時令後天之節序首列卦爻象彖諸解</span>  
<span style="margin-left: 2em">圖書諸說每條之首設卦難數條卦畫之下列卦</span>  
<span style="margin-left: 2em">旨數條卦後列六爻總論一篇而以字義諸說别</span>  
<span style="margin-left: 2em">標題目參錯於經文之中體例頗爲龎雜前又有</span>  
<span style="margin-left: 2em">黃道周序不署年月中有時値鼎革語考順治乙</span>  
<span style="margin-left: 2em">酉丙戌之間黃道周方從朱聿鍵稱兵閩中勢不</span>  
<span style="margin-left: 2em">暇爲位時作序况方輔聿鍵僭號改元亦決不肯</span>  
<span style="margin-left: 2em">自稱鼎革其爲依托無疑葢以道周喜談𧰼數與</span>  
<!-- 册1 葉849a　Page:文淵閣四庫全書_0001冊.djvu/262 -->
<span style="margin-left: 2em">此書宗旨相近故假借之以爲重耳</span>  
周易辨疑<sub class="note-yuan">無巻數　山東廵撫採進本</sub>  
<span style="margin-left: 1em">國朝李開先撰開先字傳一長壽人與嘉靖中太常</span>  
<span style="margin-left: 2em">寺卿李開先名姓偶同非一人也其易學受於鄉</span>  
<span style="margin-left: 2em">人來知德<sub class="note-yuan">案知德雖嘉靖三十一年舉人其授待詔則在萬厯三十年下距明亡僅四十</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">年故其門人能至順治初尚存</sub>故其書詮解𧰼數多推闡其師錯</span>  
<span style="margin-left: 2em">綜之例惟卦變之說與知德不合其中駁本義者</span>  
<span style="margin-left: 2em">頗多而不盡愜當至所自立之新義如說卦乾爲</span>  
<span style="margin-left: 2em">馬而爻詞取𧰼於龍朱子以爲理會不得開先則</span>  
<!-- 册1 葉849b　Page:文淵閣四庫全書_0001冊.djvu/262 -->
<span style="margin-left: 2em">謂伏羲時龍馬負圖乾雖爲馬而非馬乃龍馬也</span>  
<span style="margin-left: 2em">周公畧去馬字而止言龍非擬之以馬又擬之以</span>  
<span style="margin-left: 2em">龍也云云案乾與震合德龍與馬同性故說卦傳</span>  
<span style="margin-left: 2em">龍震皆取馬象至震之爲龍亦以一索得男體從</span>  
<span style="margin-left: 2em">乾化故二卦皆取龍𧰼聖人繫易偶舉一端不得</span>  
<span style="margin-left: 2em">膠此以疑彼而委曲以遷合之也且爻詞潛見飛</span>  
<span style="margin-left: 2em">躍諸義豈能施之龍馬耶亦好異而不顧其安矣</span>  
易存<sub class="note-yuan">無巻數　大理寺卿王昶家藏本</sub>  
<span style="margin-left: 1em">國朝蕭雲從撰雲從字尺木蕪湖人前明崇禎巳卯</span>  
<!-- 册1 葉852a　Page:文淵閣四庫全書_0001冊.djvu/263 -->
<span style="margin-left: 2em">副榜貢生是書雲從年八十時所撰以數言易而</span>  
<span style="margin-left: 2em">其數乃以律呂厯算爲宗旁及於三命六壬之術</span>  
<span style="margin-left: 2em">前列易存四學一條稱學者先讀易卦爻詞大傳</span>  
<span style="margin-left: 2em">蓍法次學卦氣以及支干陰陽五行生剋氣運衰</span>  
<span style="margin-left: 2em">旺次學算歸除因乘次學音律詞曲聲調管<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3500.svg?width=24" alt="四庫全書僻字第3500號（「絃」字少最後一點）" title="四庫全書僻字第3500號（「絃」字少最後一點）">以</span>  
<span style="margin-left: 2em">及翻切諸法方得其說頗屬支離夫奇偶陰陽爲</span>  
<span style="margin-left: 2em">萬事萬物之根本故易道廣大推之無所不通律</span>  
<span style="margin-left: 2em">呂爲易中之一理非因律呂作易亦非因易作律</span>  
<span style="margin-left: 2em">呂也厯算亦易中之一理非因厯算作易亦非因</span>  
<!-- 册1 葉852b　Page:文淵閣四庫全書_0001冊.djvu/263 -->
<span style="margin-left: 2em">易作厯算也卽以醫術而論榮衛者陰陽也七竅</span>  
<span style="margin-left: 2em">者奇偶也心腎者坎離之宅也其消長則姤復之</span>  
<span style="margin-left: 2em">機其升降則旣濟未濟之𧰼也至於五運六氣司</span>  
<span style="margin-left: 2em">天在泉無一不與易理通亦將曰因醫有易因易</span>  
<span style="margin-left: 2em">有醫乎哉王士禎池北偶談嘗記雲從作杜律細</span>  
<span style="margin-left: 2em">一書凡吳體抅句俱强使協於平仄如盤渦浴鷺</span>  
<span style="margin-left: 2em">底心性句則讀底爲高低之低江草日日喚愁生</span>  
<span style="margin-left: 2em">句則讀草爲離騷之騷此書言易殆亦類斯與連</span>  
<span style="margin-left: 2em">江童能靈作律呂古義二巻純以河圖洛書爲聲</span>  
<!-- 册1 葉853a　Page:文淵閣四庫全書_0001冊.djvu/263 -->
<span style="margin-left: 2em">音之本者均可謂誤用其心矣</span>  
周易說畧四巻<sub class="note-yuan">山東廵撫採進本</sub>  
<span style="margin-left: 1em">國朝張爾岐撰爾岐字稷若濟陽人篤守朱子之學</span>  
<span style="margin-left: 2em">因作此書以發明本義之㫖内惟第四巻分爲二</span>  
<span style="margin-left: 2em">故亦作五巻李煥章作爾岐傳云八巻者誤也</span>  
周易纂解正宗六巻<sub class="note-yuan">江西廵撫採進本</sub>  
<span style="margin-left: 1em">國朝謝復茪撰復茪字菁來吉水人其書先列朱子</span>  
<span style="margin-left: 2em">本義以直解大全𫎇引諸家之說各系於其下其</span>  
<span style="margin-left: 2em">子能立以圖說未備重加纂訂别爲一編附之於</span>  
<!-- 册1 葉853b　Page:文淵閣四庫全書_0001冊.djvu/263 -->
<span style="margin-left: 2em">後葢里塾講授之本也</span>  
周易麈談<sub class="note-yuan">無巻數　兩淮馬裕家藏夲</sub>  
<span style="margin-left: 2em">不著撰人名氏朱彛尊經義攷載孫應龍有周易</span>  
<span style="margin-left: 2em">麈談十二巻疑此本是也應龍字海門餘杭人順</span>  
<span style="margin-left: 2em">治丁亥進士官隰州知州其書多引先儒語錄排</span>  
<span style="margin-left: 2em">比成文或標曰注或標曰解或標曰傳每章之中</span>  
<span style="margin-left: 2em">三名叠見竟莫得而詳其例也</span>  
周易纂注<sub class="note-yuan">無巻數　江蘇廵撫採進本</sub>  
<span style="margin-left: 1em">國朝朱奇頴撰奇頴字九愚嘉定人順治辛卯拔貢</span>  
<!-- 册1 葉856a　Page:文淵閣四庫全書_0001冊.djvu/264 -->
<span style="margin-left: 2em">生官平遙縣知縣此書大槩依附朱子本義而稍</span>  
<span style="margin-left: 2em">參以巳說後有附錄一巻則其子所刻墓誌行狀</span>  
<span style="margin-left: 2em">也</span>  
易史參錄二巻<sub class="note-yuan">江西廵撫採進本</sub>  
<span style="margin-left: 1em">國朝葉矯然撰矯然字思菴閩縣人順治壬辰進士</span>  
<span style="margin-left: 2em">官樂亭縣知縣是書於每卦𧰼爻各證以史事葢</span>  
<span style="margin-left: 2em">仿李光楊萬里二家易傳之意而所舉不免於偏</span>  
<span style="margin-left: 2em">枯夫易道廣大無所不包而不膠柱於一二事文</span>  
<span style="margin-left: 2em">王箕子偶引以明卦義無所不可至於每𧰼每爻</span>  
<!-- 册1 葉856b　Page:文淵閣四庫全書_0001冊.djvu/264 -->
<span style="margin-left: 2em">必求其事以實之則挂漏牽合固其所矣</span>
