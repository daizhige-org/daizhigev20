欽定四庫全書總目巻六十  
<span style="margin-left: 1em">史部十六</span>  
<span style="margin-left: 2em">傳記類存目二</span>  
草廬年譜二巻附錄二巻<sub class="note-yuan">編修汪如藻家藏本</sub>  
<span style="margin-left: 2em">明危素撰素字太樸金谿人元至正中官至禮部</span>  
<span style="margin-left: 2em">尚書叅知政事翰林學士承㫖出爲嶺北行省左</span>  
<span style="margin-left: 2em">丞後退居房山淮王監國起爲承㫖如故明洪武</span>  
<span style="margin-left: 2em">二年授翰林侍講學士後因御史王著等論素不</span>  
<span style="margin-left: 2em">宜列侍從謫居和州以卒事蹟具明史文苑傳初</span>  
<!-- 册2 葉1289b　Page:文淵閣四庫全書_0002冊.djvu/327 -->
<span style="margin-left: 2em">吳澄孫當嘗編次其祖生平事蹟爲年譜素爲澄</span>  
<span style="margin-left: 2em">之門人因重加訂正刻於至正乙巳至明嘉靖甲</span>  
<span style="margin-left: 2em">寅澄裔孫朝楨復增入行狀神道碑列傳祭文一</span>  
<span style="margin-left: 2em">巻及厯代褒典奏議文移一巻鄒守益爲之序卽</span>  
<span style="margin-left: 2em">此本也</span>  
褒賢集五巻<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">不題撰人名氏取宋元人著作有關范仲淹者及</span>  
<span style="margin-left: 2em">朝廷所降文牒等類合爲一書一巻爲傳碑銘祭</span>  
<span style="margin-left: 2em">文二巻爲優崇典禮三四巻爲碑記五卷爲諸賢</span>  
<!-- 册2 葉1292a　Page:文淵閣四庫全書_0002冊.djvu/328 -->
<span style="margin-left: 2em">贊頌論疏中間載至元順帝至正間則明初人所</span>  
<span style="margin-left: 2em">編也</span>  
滁陽王廟歲祀册一巻<sub class="note-yuan">左都御史張若溎家藏本</sub>  
<span style="margin-left: 2em">不著撰人名氏明初追封郭子興爲滁陽王立廟</span>  
<span style="margin-left: 2em">滁州令有司歲時奉祀此本前列洪武十五年敕</span>  
<span style="margin-left: 2em">諭一通具載祀典規條及守廟人戶次爲太常寺</span>  
<span style="margin-left: 2em">丞張羽所撰滁陽王廟碑文葢卽從廟中碑刻抄</span>  
<span style="margin-left: 2em">出别行者也</span>  
鐘鼎逸事一巻<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<!-- 册2 葉1292b　Page:文淵閣四庫全書_0002冊.djvu/328 -->
<span style="margin-left: 2em">明李文秀撰文秀昆明人黔寧王沐英之閹豎也</span>  
<span style="margin-left: 2em">是編皆紀英行事前列祠堂碑記三篇後爲言行</span>  
<span style="margin-left: 2em">拾遺錄十一條各爲之論末附唐愚士贈文秀詩</span>  
<span style="margin-left: 2em">一篇而冠以張紞劉有年王汝玉王驥序四篇驥</span>  
<span style="margin-left: 2em">序題洪武壬午汝玉序則書元年十二月而劖去</span>  
<span style="margin-left: 2em">年號二字葢汝玉作於革除以前而刻於革除以</span>  
<span style="margin-left: 2em">後故削建文年號驥序作於燕王簒立以後故奉</span>  
<span style="margin-left: 2em">仍稱洪武三十五年之詔耳閹寺之作本不足錄</span>  
<span style="margin-left: 2em">而英本名臣文秀所錄尚與史傳相出入無詭詞</span>  
<!-- 册2 葉1293a　Page:文淵閣四庫全書_0002冊.djvu/328 -->
<span style="margin-left: 2em">夸飾變亂是非之事故姑存其目焉</span>  
<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">道編八巻<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明陳怡編怡吳縣人仕履未詳其祖祚字永錫永</span>  
<span style="margin-left: 2em">樂辛卯進士授河南布政司叅議坐事落職洪熙</span>  
<span style="margin-left: 2em">初起爲監察御史終於福建按察司僉事厯官俱</span>  
<span style="margin-left: 2em">有<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">聲怡因輯其年譜行狀墓表輓詩之類以成</span>  
<span style="margin-left: 2em">此書吳寛爲題此名與明史祚本傳亦大致互相</span>  
<span style="margin-left: 2em">出入案千頃堂書目載有孫堪<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">道編紀御史陳</span>  
<span style="margin-left: 2em">祚事堪嘉靖中人今未見傳本其與此書爲一爲</span>  
<!-- 册2 葉1293b　Page:文淵閣四庫全書_0002冊.djvu/328 -->
<span style="margin-left: 2em">二莫之詳矣</span>  
翊運錄二巻<sub class="note-yuan">江蘇周厚堉家藏本</sub>  
<span style="margin-left: 2em">明劉廌編廌誠意伯基之孫也是書成於永樂中</span>  
<span style="margin-left: 2em">集其祖父所得御書詔誥及行狀事實以爲此錄</span>  
<span style="margin-left: 2em">取誥文中開國翊運之語爲名同郡王景爲之序</span>  
<span style="margin-left: 2em">成化中巡按浙江御史戴用以板久漶漫因增輯</span>  
<span style="margin-left: 2em">重梓楊守陳爲之序嘉靖初從處州府知府潘潤</span>  
<span style="margin-left: 2em">之請以基九世孫瑜襲爵瑜因復增入襲封誥敕</span>  
<span style="margin-left: 2em">及部議題本謝恩表之類自爲後序二巻之首襍</span>  
<!-- 册2 葉1296a　Page:文淵閣四庫全書_0002冊.djvu/329 -->
<span style="margin-left: 2em">入基表頌五篇頗爲不倫以序文考之卽瑜所增</span>  
<span style="margin-left: 2em">入葢徒欲侈陳祖德爲閥閲之光而未知著述體</span>  
<span style="margin-left: 2em">例者也</span>  
崔淸獻全錄十巻<sub class="note-yuan">兵部侍郞紀昀家藏本</sub>  
<span style="margin-left: 2em">明崔子璲編其書成於永樂中皆其五世祖與之</span>  
<span style="margin-left: 2em">之遺事遺文也與之字正子廣州增城人紹熙四</span>  
<span style="margin-left: 2em">年進士理宗時累官廣東安撫使拜叅知政事右</span>  
<span style="margin-left: 2em">丞相致仕卒諡淸獻事迹具宋史本傳與之所著</span>  
<span style="margin-left: 2em">有菊坡文集佚於兵火又有嶺海便民牓海上澄</span>  
<!-- 册2 葉1296b　Page:文淵閣四庫全書_0002冊.djvu/329 -->
<span style="margin-left: 2em">淸錄二書皆記其當時政事後亦不傳僅存其言</span>  
<span style="margin-left: 2em">行錄三巻奏劄詩文五卷子璲因裒爲一編又以</span>  
<span style="margin-left: 2em">理宗御劄及諸家詩文爲附錄二巻其言行錄三</span>  
<span style="margin-left: 2em">巻林鉞跋稱宋太社司令李公裒輯而不載其名</span>  
<span style="margin-left: 2em">宋端儀序稱略爲更定甘鏞跋又稱旁考史傳補</span>  
<span style="margin-left: 2em">其脫略然則已非原本矣又蔣曾瑩家别有寫本</span>  
<span style="margin-left: 2em">分爲二集内集二巻前巻爲言行錄後巻爲奏劄</span>  
<span style="margin-left: 2em">詩文外集三巻上巻爲所賜詔札中巻爲宋史本</span>  
<span style="margin-left: 2em">傳及續通鑑綱目諸書所記與之事下巻爲題贈</span>  
<!-- 册2 葉1297a　Page:文淵閣四庫全書_0002冊.djvu/329 -->
<span style="margin-left: 2em">詩文題其十四孫爌所重編成於嘉靖庚申前有</span>  
<span style="margin-left: 2em">測引一篇稱重編先錄旣成有謂不當以行先言</span>  
<span style="margin-left: 2em">者有謂不當以臣先君者後見舊板篇次記號乃</span>  
<span style="margin-left: 2em">知新本爲後人剷改爌所重編實還其舊今觀其</span>  
<span style="margin-left: 2em">書雖併十巻爲五巻而次序略與子璲本合則所</span>  
<span style="margin-left: 2em">謂還其舊者<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">不誣也</span>  
陸右丞蹈海錄一巻<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">明丁元吉編元吉鎭江人是書成於成化中記宋</span>  
<span style="margin-left: 2em">陸秀夫海上死難事蹟採宋史本傳及龔開所作</span>  
<!-- 册2 葉1297b　Page:文淵閣四庫全書_0002冊.djvu/329 -->
<span style="margin-left: 2em">傳黃溍所作年譜益以諸家題咏彚爲一編並載</span>  
<span style="margin-left: 2em">秀夫遺文二首末附桑海遺錄序大忠祠碑及祭</span>  
<span style="margin-left: 2em">文一首</span>  
張乖厓事文錄四巻<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明顏端徐瀚同編端應山人官成都縣敎諭瀚杭</span>  
<span style="margin-left: 2em">州人官華陽縣敎諭前有文安邢表序葢宏治三</span>  
<span style="margin-left: 2em">年表爲四川左布政使以張詠爲蜀名宦故屬二</span>  
<span style="margin-left: 2em">人輯錄此編一卷爲本傳及事實二巻爲遺文十</span>  
<span style="margin-left: 2em">二篇三巻四巻爲同時贈答及後人祠記祭文之</span>  
<!-- 册2 葉1300a　Page:文淵閣四庫全書_0002冊.djvu/330 -->
<span style="margin-left: 2em">類詠全集尚有傳本端等未見故所輯頗挂漏焉</span>  
李衛公通纂四卷<sub class="note-yuan"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">隸總督採進本</sub>  
<span style="margin-left: 2em">明王承裕撰承裕字天宇三原人吏部尚書恕之</span>  
<span style="margin-left: 2em">子宏治癸丑進士官至南京戸部尚書諡康僖事</span>  
<span style="margin-left: 2em">迹附見明史恕傳承裕與唐李靖爲同里故旣爲</span>  
<span style="margin-left: 2em">建祠又纂其遺事爲此書明史藝文志著錄作四</span>  
<span style="margin-left: 2em">卷此本凡史牒纂一卷遺作纂一卷文集纂一卷</span>  
<span style="margin-left: 2em">存蹟纂一卷與明志合所載皆習見之文至李衛</span>  
<span style="margin-left: 2em">公問對一書出自阮逸僞托而一槪列入絶無辨</span>  
<!-- 册2 葉1300b　Page:文淵閣四庫全書_0002冊.djvu/330 -->
<span style="margin-left: 2em">證可知其考訂之疎矣</span>  
陽明先生浮海傳一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明陸相撰相字良弼餘姚人宏治癸丑進士官至</span>  
<span style="margin-left: 2em">長沙府知府是書專紀王守仁正德初謫龍<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3949.svg?width=24" alt="四庫全書僻字第3949號（場 --（『昜』上『旦』之『日』與『一』相連））" title="四庫全書僻字第3949號（場 --（『昜』上『旦』之『日』與『一』相連））">驛</span>  
<span style="margin-left: 2em">丞道經杭州爲姦人謀害投水中因漂至龍宫得</span>  
<span style="margin-left: 2em">生還之事說頗詭誕不經論者謂守仁多智數慮</span>  
<span style="margin-left: 2em">劉瑾追害故棄衣冠僞托投江而實陰赴龍場故</span>  
<span style="margin-left: 2em">王世貞史乘考誤嘗力辨此事爲不實而同時楊</span>  
<span style="margin-left: 2em">儀高坡異纂亦載此事與相所紀略同蓋文人之</span>  
<!-- 册2 葉1301a　Page:文淵閣四庫全書_0002冊.djvu/330 -->
<span style="margin-left: 2em">好異久矣</span>  
朱子實紀十二卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">明戴銑編銑字寶之婺源人宏治丙辰進士官至</span>  
<span style="margin-left: 2em">給事中以疏彈太監高鳳下詔獄廷杖創甚而卒</span>  
<span style="margin-left: 2em">事迹具明史本傳是書詳述朱子始末首曰道統</span>  
<span style="margin-left: 2em">源流世系源流次年譜次行狀本𫝊次廟宅次門</span>  
<span style="margin-left: 2em">人次褒典次讚述次紀題其書本因年譜而作其</span>  
<span style="margin-left: 2em">標曰實紀者銑自序稱謂之年譜則紹乎前彰乎</span>  
<span style="margin-left: 2em">後者不足談必曰實紀然後并包而無遺葢年譜</span>  
<!-- 册2 葉1301b　Page:文淵閣四庫全書_0002冊.djvu/330 -->
<span style="margin-left: 2em">主於明朱子學問之序出處之道而銑是書則主</span>  
<span style="margin-left: 2em">於以推崇褒贈誇耀世俗爲榮其立意本各有取</span>  
<span style="margin-left: 2em">也</span>  
韓祠錄三卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明葉性談倫同編性里籍未詳官潮州府同知倫</span>  
<span style="margin-left: 2em">上海人天順丁丑進士官至工部右侍郞然是編</span>  
<span style="margin-left: 2em">前有翰林院檢討盛端明序稱性編錄未成以述</span>  
<span style="margin-left: 2em">職北上倫時爲潮州知府因續成之考書成於正</span>  
<span style="margin-left: 2em">德甲戌上距天順丁丑巳五十八年且作序之盛</span>  
<!-- 册2 葉1304a　Page:文淵閣四庫全書_0002冊.djvu/331 -->
<span style="margin-left: 2em">端明爲宏治壬戌進士上距天順丁丑亦四十六</span>  
<span style="margin-left: 2em">年與倫似不相及卽倫老而尚存亦不應七八十</span>
