<span style="margin-left: 1em">集部十八</span>  
<span style="margin-left: 2em">別集類十八</span>  
湏溪集十卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋劉辰翁撰辰翁字㑹孟廬陸人湏溪其所居地</span>  
<span style="margin-left: 2em">名也少補太學生景定壬戌廷試入丙第以親老</span>  
<span style="margin-left: 2em">請濂溪書院山長江萬里陳宜中薦居史館除太</span>  
<span style="margin-left: 2em">學博士皆固辭宋亡遂不復岀辰翁當賈似道當</span>  
<span style="margin-left: 2em">國對䇿極言濟邸無後可慟忠良殘害可傷風節</span>  
<!-- 册4 葉1309b　Page:文淵閣四庫全書_0004冊.djvu/332 -->
<span style="margin-left: 2em">不競可憾幾爲似道所中以此得鯁直名文章亦</span>  
<span style="margin-left: 2em">見重於世其門生王夢應作祭文至稱韓歐後惟</span>  
<span style="margin-left: 2em">先生卓然秦漢巨筆然辰翁論詩評文往往意取</span>  
<span style="margin-left: 2em">尖新太傷佻巧其所批<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）">如杜甫集世說新語及</span>  
<span style="margin-left: 2em">班馬異同諸書今尚有傳本大率破碎纎仄無禆</span>  
<span style="margin-left: 2em">來學卽其所作詩文亦專以竒怪磊落爲宗務在</span>  
<span style="margin-left: 2em">艱<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3232.svg?width=24" alt="四庫全書僻字第3232號（澀）" title="四庫全書僻字第3232號（澀）">其詞甚或至於不可句讀尤不免軼於繩墨</span>  
<span style="margin-left: 2em">之外特蹊徑本自䝉莊故惝恍迷離亦間有意趣</span>  
<span style="margin-left: 2em">不盡墮牛鬼蛇神且於宗<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3771.svg?width=24" alt="四庫全書僻字第3771號（邦）" title="四庫全書僻字第3771號（邦）">淪覆之後睠懷麥秀</span>  
<!-- 册4 葉1312a　Page:文淵閣四庫全書_0004冊.djvu/333 -->
<span style="margin-left: 2em">𭔃托遥深忠愛之忱往往形諸筆墨其志亦多有</span>  
<span style="margin-left: 2em">可取者固不必槪以體格繩之矣湏溪集明人見</span>  
<span style="margin-left: 2em">者甚罕卽諸書亦多不載其卷數韓敬選訂晩宋</span>  
<span style="margin-left: 2em">諸家之文嘗以不得辰翁全集爲恨聞蘭溪胡<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2939.svg?width=24" alt="四庫全書僻字第2939號（應）" title="四庫全書僻字第2939號（應）"></span>  
<span style="margin-left: 2em">麟遺書中有其名往求之卒弗能𫉬葢其散失已</span>  
<span style="margin-left: 2em">久世所傳者惟湏溪記鈔及湏溪四景詩二種篇</span>  
<span style="margin-left: 2em">帙寥寥今檢永樂大典所錄記序雜著詩餘尚多</span>  
<span style="margin-left: 2em">謹採輯裒次𨤲爲十卷其天下同文集及記鈔所</span>  
<span style="margin-left: 2em">載而不見於永樂大典者亦別爲抄補用以存其</span>  
<!-- 册4 葉1312b　Page:文淵閣四庫全書_0004冊.djvu/333 -->
<span style="margin-left: 2em">槩至四景詩則原屬單行之本今仍各著於錄故</span>  
<span style="margin-left: 2em">不復採入云</span>  
湏溪四景詩集四卷<sub class="note-yuan">編修汪如藻家藏本</sub>  
<span style="margin-left: 2em">宋劉辰翁撰考晉宋以前無以古人詩句爲題者</span>  
<span style="margin-left: 2em">沈約始有江蘺生幽渚詩以陸機塘上行句爲題</span>  
<span style="margin-left: 2em">是齊梁以後例也沿及唐宋科舉始專以古句命</span>  
<span style="margin-left: 2em">題其程試之作唐莫詳於文苑英華宋莫詳於萬</span>  
<span style="margin-left: 2em">寶詩山大扺以刻畫爲工轉相傚仿辰翁生於宋</span>  
<span style="margin-left: 2em">末故是集各以四時寫景之句命題春景凡六十</span>  
<!-- 册4 葉1313a　Page:文淵閣四庫全書_0004冊.djvu/333 -->
<span style="margin-left: 2em">三題詩七十二首夏景凡三十二題詩三十五首</span>  
<span style="margin-left: 2em">秋景凡四十題詩四十四首冬景十六題詩如題</span>  
<span style="margin-left: 2em">數所作皆氣韻生動無堆排塗飾之習在程試詩</span>  
<span style="margin-left: 2em">中最爲高格末附東桂堂賦一篇爲劉端伯教子</span>  
<span style="margin-left: 2em">讀書而作此集殆亦授劉之子備科舉之用者歟</span>  
葦航漫遊稿四卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋胡仲弓撰仲弓字希聖淸源人其生平不少槩</span>  
<span style="margin-left: 2em">見惟集中一第詩有衣冠新進士湖海舊詩人之</span>  
<span style="margin-left: 2em">句知嘗登第夜夢䝉仲作二象笏詩有嗟余初筮</span>  
<!-- 册4 葉1313b　Page:文淵閣四庫全書_0004冊.djvu/333 -->
<span style="margin-left: 2em">令之句知嘗宰縣將之官越上留別諸友詩有一</span>  
<span style="margin-left: 2em">官如許冷况復是淸貧槐市風何古蘭亭本𨚫眞</span>  
<span style="margin-left: 2em">之句知官在㑹稽老母適至時已見黜詩有千里</span>  
<span style="margin-left: 2em">迎阿㜷相見翻不樂微祿期奉親親至祿已奪之</span>  
<span style="margin-left: 2em">句知不久罷歸雪中襍興詩有不被功名縛江湖</span>  
<span style="margin-left: 2em">得散行之句知被斥以後浪跡以終故以葦航漫</span>  
<span style="margin-left: 2em">遊名稿其行事則不可考矣仲弓詩名不甚著惟</span>  
<span style="margin-left: 2em">陳起江湖後集錄所作頗夥然校以永樂大典分</span>  
<span style="margin-left: 2em">列於各韻下者起所選之外遺佚尚多今蒐採裒</span>  
<!-- 册4 葉1316a　Page:文淵閣四庫全書_0004冊.djvu/334 -->
<span style="margin-left: 2em">輯編爲四卷雖未必盡覩其全視起所編則增益</span>  
<span style="margin-left: 2em">者多矣南宋末年詩格日下四靈一派攄晩唐淸</span>  
<span style="margin-left: 2em">巧之思江湖一派多五季衰颯之氣故仲弓是編</span>  
<span style="margin-left: 2em">及其兄仲參所作竹莊小集均不出山林枯槁之</span>  
<span style="margin-left: 2em">調如七言律中旱湖一首當凶祲流離之時絶無</span>  
<span style="margin-left: 2em">惻隱乃云但使孤山梅不死其餘風物弗關情尤</span>  
<span style="margin-left: 2em">宋季游士矯語高蹈之陋習然吟咏旣繁性情各</span>  
<span style="margin-left: 2em">見洪纎俱響正變兼陳苟非淫慝之音卽不在放</span>  
<span style="margin-left: 2em">斥之列詩家有此一格固不妨使之並存亦錄唐</span>  
<!-- 册4 葉1316b　Page:文淵閣四庫全書_0004冊.djvu/334 -->
<span style="margin-left: 2em">詩者不遺周曇咏史之例也永樂大典所載別有</span>  
<span style="margin-left: 2em">漫遊集一書核其體例蓋採宋元兩代之作彚爲</span>  
<span style="margin-left: 2em">總集當時校讐未宻朱書標目往往與此集混淆</span>  
<span style="margin-left: 2em">今並考校姓名删除訛異不使與此集相亂庶㡬</span>  
<span style="margin-left: 2em">不失其眞焉</span>  
蘭臯集三卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">宋吳錫疇撰錫疇字元倫休寧人廣南西路安撫</span>  
<span style="margin-left: 2em">使儆之從孫處士垕之子也錫疇四歲而孤刻志</span>  
<span style="margin-left: 2em">於學慕徐穉茅容之爲人咸淳間南康守葉閶聘</span>  
<!-- 册4 葉1317a　Page:文淵閣四庫全書_0004冊.djvu/334 -->
<span style="margin-left: 2em">主白鹿洞書院辭不肯赴葢篤實潛修之士不欲</span>  
<span style="margin-left: 2em">以聚徒講學囂競浮名也性喜藝蘭自號曰蘭臯</span>  
<span style="margin-left: 2em">子因以名集殆亦寓無人自芳之意其人品心術</span>  
<span style="margin-left: 2em">可謂超然流俗之外矣集所存詩不多然皆晩年</span>  
<span style="margin-left: 2em">所自删定簡汰頗嚴其題林逋墓詩淸風千載梅</span>  
<span style="margin-left: 2em">花共說著梅花定說君句爲吕午所賞春日詩燕</span>  
<span style="margin-left: 2em">未成家寒食雨人如中酒落花風句又爲方岳所</span>  
<span style="margin-left: 2em">賞並見於方岳䟦中然集中佳句似此者尚頗不</span>  
<span style="margin-left: 2em">乏岳偶舉其一二耳葢其刻意淸新雖不免偶涉</span>  
<!-- 册4 葉1317b　Page:文淵閣四庫全書_0004冊.djvu/334 -->
<span style="margin-left: 2em">纎巧而視宋季潦倒率易之作則尚能生面別開</span>  
<span style="margin-left: 2em">以繼竹洲集後亦云不愧其家學矣</span>  
雲泉詩一卷<sub class="note-yuan">編修汪如藻家藏本</sub>  
<span style="margin-left: 2em">宋薛嵎撰嵎字仲止一字賔日永嘉人寶祐四年</span>  
<span style="margin-left: 2em">進士官長溪簿宋承五代之後其詩數變一變而</span>  
<span style="margin-left: 2em">西崑再變而元祐三變而江西江西一𣲖由北宋</span>  
<span style="margin-left: 2em">以逮南宋其行最久久而𡚁生於是永嘉一𣲖以</span>  
<span style="margin-left: 2em">晩唐體矯之而四靈出焉然四靈名爲晩唐其所</span>  
<span style="margin-left: 2em">宗實止姚合一家所謂武功體者是也其法以新</span>  
<!-- 册4 葉1320a　Page:文淵閣四庫全書_0004冊.djvu/335 -->
<span style="margin-left: 2em">切爲宗而寫景細瑣邊幅太狹遂爲宋末江湖之</span>  
<span style="margin-left: 2em">濫觴葉適以鄉曲之故初力推之久而亦覺其偏</span>  
<span style="margin-left: 2em">始稍異論吳子良林下偶談述之頗悉嵎之所作</span>  
<span style="margin-left: 2em">皆出入四靈之間不免局於門戸然尚永嘉之初</span>  
<span style="margin-left: 2em">𣲖非永嘉之末𣲖錄之亦足備一格也</span>  
嘉禾百咏一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">宋張堯同撰堯同秀水人仕履未詳詩中所詠㑹</span>  
<span style="margin-left: 2em">景亭爲潘師且所築趙老園爲趙衮歸隱之處核</span>  
<span style="margin-left: 2em">其時代蓋寧宗以後人也宋世文人學士歌詠其</span>  
<!-- 册4 葉1320b　Page:文淵閣四庫全書_0004冊.djvu/335 -->
<span style="margin-left: 2em">土風之勝者往往以誇多鬬靡爲工如阮閱郴江</span>  
<span style="margin-left: 2em">百詠許尚華亭百詠會極金陵百詠皆以百首爲</span>  
<span style="margin-left: 2em">率故堯同所詠嘉興山川古跡亦以百篇槩之徐</span>  
<span style="margin-left: 2em">碩至元嘉禾志已與陸䝉老所賦嘉禾八詠同採</span>  
<span style="margin-left: 2em">入題詠門内後來作郡志者亦頗散見其間而掇</span>  
<span style="margin-left: 2em">拾均未全備此乃其初出單行之本每首之後皆</span>  
<span style="margin-left: 2em">有附考不知何人所作末有䟦語亦不載姓名年</span>  
<span style="margin-left: 2em">月其詞雖不甚工而自吳越以來嘉興典故頗可</span>  
<span style="margin-left: 2em">得其梗槪近時朱𢑱尊作鴛鴦湖櫂歌一百首葢</span>  
<!-- 册4 葉1321a　Page:文淵閣四庫全書_0004冊.djvu/335 -->
<span style="margin-left: 2em">卽踵前例而稍變其面目者雖𢑱尊詩情温麗遠</span>  
<span style="margin-left: 2em">勝堯同而堯同採掇名目臚敘大凡其於地志考</span>  
<span style="margin-left: 2em">據要亦不爲無助矣</span>  
柳塘外集四卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">宋釋道璨撰道璨字無文姓陶氏南昌人咸淳間</span>  
<span style="margin-left: 2em">嘗主饒州薦福寺所著別有語錄故此以外集爲</span>  
<span style="margin-left: 2em">名釋氏以佛典爲内學以儒書爲外學也其詩邊</span>  
<span style="margin-left: 2em">幅頗狹未能脫蔬筍之氣而短章絶句善用其短</span>  
<span style="margin-left: 2em">者亦時有淸致如題水墨草蟲陳了翁祠和恕齋</span>  
<!-- 册4 葉1321b　Page:文淵閣四庫全書_0004冊.djvu/335 -->
<span style="margin-left: 2em">濂溪書院諸作未嘗不楚楚可觀沙中金屑固亦</span>  
<span style="margin-left: 2em">不容捐棄矣雜文中送一侍者序一首乃爲日本</span>  
<span style="margin-left: 2em">僧作考宋史外國傳所載自太宗時奝然入朝後</span>  
<span style="margin-left: 2em">屢有倭僧奉貢迄南渡不復見僅紀其國舟飄至</span>  
<span style="margin-left: 2em">内境數事至嘉泰三年以後遂絶不復書此序作</span>  
<span style="margin-left: 2em">於淳祐戊申稱其去國六年一日東歸計其來日</span>  
<span style="margin-left: 2em">當在淳祐三年殆求法東來非充貢使故史不得</span>  
<span style="margin-left: 2em">而載之非漏略也集凡詩一卷銘記一卷序文疏</span>  
<span style="margin-left: 2em">書一卷墖銘墓誌壙誌祭文一卷宋以來諸家書</span>  
<!-- 册4 葉1324a　Page:文淵閣四庫全書_0004冊.djvu/336 -->
<span style="margin-left: 2em">目皆未著錄</span>  
<span style="margin-left: 1em">國朝康熙甲寅釋大雷始訪得舊本釋元宏燈岱因</span>
