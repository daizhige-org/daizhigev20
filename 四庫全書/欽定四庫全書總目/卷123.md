## 欽定四庫全書總目 卷一百二十三　子部三十三　雜家類七

<!-- 册3 葉2620a　Page:文淵閣四庫全書_0003冊.djvu/660 -->
欽定四庫全書總目卷一百二十三  
<span style="margin-left: 1em">子部三十三</span>  
<span style="margin-left: 2em">雜家𩔖七</span>  
洞天淸錄一卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">宋趙希鵠撰希鵠本宗室子宋史世系表列其名</span>  
<span style="margin-left: 2em">於燕王德昭房下葢太祖之後始末則不可詳考</span>  
<span style="margin-left: 2em">書中有嘉熙庚子自嶺右回至宜春語則家於袁</span>  
<span style="margin-left: 2em">州者也是書所論皆鑒别古器之事凡古琴辨三</span>  
<span style="margin-left: 2em">十二條古硯辨十二條古鐘鼎𢑴器辨二十條怪</span>  
<!-- 册3 葉2620b　Page:文淵閣四庫全書_0003冊.djvu/660 -->
<span style="margin-left: 2em">石辨十一條硯屏辨五條筆格辨三條水滴辨二</span>  
<span style="margin-left: 2em">條古翰墨眞迹辨四條古今石刻辨五條古今𥿄</span>  
<span style="margin-left: 2em">花印色辨十五條古畫辨二十九條大抵洞悉源</span>  
<span style="margin-left: 2em">流辨析精審如謂刁斗乃行軍炊具今世所見古</span>  
<span style="margin-left: 2em">刁斗乃王莽威斗之𩔖爲厭勝家所用又謂今所</span>  
<span style="margin-left: 2em">見銅犀牛天祿蟾蜍之屬皆古人以貯油<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）">燈今</span>  
<span style="margin-left: 2em">人誤以爲水滴其援引考證𩔖皆磪鑿固賞鑒家</span>  
<span style="margin-left: 2em">之指南也明寧獻王權嘗爲刊板於江西見寧藩</span>  
<span style="margin-left: 2em">書目曹溶續藝圃搜奇所載與此本同葢皆從寧</span>  
<!-- 册3 葉2621a　Page:文淵閣四庫全書_0003冊.djvu/660 -->
<span style="margin-left: 2em">王舊刻傳錄明錢塘鍾人傑輯唐宋叢書别載一</span>  
<span style="margin-left: 2em">本與此本迥異考其中有楊愼之說寧庶人宸濠</span>  
<span style="margin-left: 2em">之名及永樂宣德成化年號希鵠何自知之其爲</span>  
<span style="margin-left: 2em">未見此本而刺取他書以贋其名固不待辨矣</span>  
<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3688.svg?width=24" alt="四庫全書僻字第3688號（負）" title="四庫全書僻字第3688號（負）">暄野錄二卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">舊本題曰陳槱撰不著時代卷末有至正七年王</span>  
<span style="margin-left: 2em">東䟦乃云不知何人所述是當時所見之本未署</span>  
<span style="margin-left: 2em">名也今考書中秦璽一條稱槱嘗聞諸老先生議</span>  
<span style="margin-left: 2em">論則其人名槱無可疑但不知何據而題爲陳姓</span>  
<!-- 册3 葉2621b　Page:文淵閣四庫全書_0003冊.djvu/660 -->
<span style="margin-left: 2em">案閩書陳槱陳幾之孫長樂人紹熙元年進士書</span>  
<span style="margin-left: 2em">中秦璽條内稱近嘉定已卯光宗紹熙元年下距</span>  
<span style="margin-left: 2em">寧宗嘉定已卯首尾三十年又西漢碑條内亦稱</span>  
<span style="margin-left: 2em">聞之梁溪尤袤惜不再叩之袤亦當光寧之時疑</span>  
<span style="margin-left: 2em">卽此陳槱也其書上卷論石刻及諸家書格下卷</span>  
<span style="margin-left: 2em">論學書之法及紙墨筆研諸事皆源委分明足資</span>  
<span style="margin-left: 2em">考證至所載鼠鬚筆詩一首宋文鑑題爲蘇過作</span>  
<span style="margin-left: 2em">其時斜川集尚存必無舛誤而槱稱昨見邵道豫</span>  
<span style="margin-left: 2em">賦鼠鬚筆殊有風度今載於此云云則失考之甚</span>  
<!-- 册3 葉2624a　Page:文淵閣四庫全書_0003冊.djvu/661 -->
<span style="margin-left: 2em">矣</span>  
雲烟過眼錄四卷續錄一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">宋周宻撰宻有武林舊事已著錄是書記所見書</span>  
<span style="margin-left: 2em">畫古器畧品甲乙而不甚考證其命名葢取蘇軾</span>  
<span style="margin-left: 2em">之語第考軾寳繪堂記實作烟雲之過眼舊本刊</span>  
<span style="margin-left: 2em">作雲烟殆誤倒其文然錢曾讀書敏求記載元至</span>  
<span style="margin-left: 2em">正間夏頥鈔本已作雲烟則訛異已久矣曾記夏</span>  
<span style="margin-left: 2em">本作一卷而此本四卷或後人所分歟觀所記收</span>  
<span style="margin-left: 2em">藏之人葢入元以後所作中有湯允謨葉森文璧</span>  
<!-- 册3 葉2624b　Page:文淵閣四庫全書_0003冊.djvu/661 -->
<span style="margin-left: 2em">之語葢點勘是書各爲題識傳寫者誤合爲一如</span>  
<span style="margin-left: 2em">王子慶所藏宋太祖御批三件條末云今第三卷</span>  
<span style="margin-left: 2em">只有二件疑有脫誤當參攷志雅堂雜抄云云志</span>  
<span style="margin-left: 2em">雅堂雜抄亦宻所著不應自云當參攷知亦誤連</span>  
<span style="margin-left: 2em">校正之語爲正文矣中記蘇軾手書詞稱郟湛初</span>  
<span style="margin-left: 2em">溢今本訛爲漣漪初溢然郟湛字不可解恐亦有</span>  
<span style="margin-left: 2em">訛又記蘭亭序有隋煬帝内府石刻不知何據又</span>  
<span style="margin-left: 2em">記吳彩鸞書切韻以一先二仙爲十三仙二十四</span>  
<span style="margin-left: 2em">先稱不可曉案困學記聞載魏了翁之言巳稱唐</span>  
<!-- 册3 葉2625a　Page:文淵閣四庫全書_0003冊.djvu/661 -->
<span style="margin-left: 2em">韻下平不作一先則唐韻或有此别本亦未可知</span>  
<span style="margin-left: 2em">也續錄一卷題逢澤湯允謨撰凡三十九條董其</span>  
<span style="margin-left: 2em">昌戲鴻堂帖定絹本黃庭經爲楊許舊跡葢本此</span>  
<span style="margin-left: 2em">書則亦以其賞鑒爲凖矣</span>  
格古要論三卷<sub class="note-yuan">衍聖公孔昭煥家藏本</sub>  
<span style="margin-left: 2em">明曹昭撰昭字明仲松江人其書成於洪武二十</span>  
<span style="margin-left: 2em">年凡分十三門曰古銅器曰古畫曰古墨跡曰古</span>  
<span style="margin-left: 2em">碑法帖曰古琴曰古硯曰珍奇曰金鐵曰古窑器</span>  
<span style="margin-left: 2em">曰古漆器曰錦綺曰異木曰異石毎門又各分子</span>  
<!-- 册3 葉2625b　Page:文淵閣四庫全書_0003冊.djvu/661 -->
<span style="margin-left: 2em">目多者三四十條少者亦五六條其於古今名玩</span>  
<span style="margin-left: 2em">器具眞贋優劣之解皆能剖析纎微又諳悉典故</span>  
<span style="margin-left: 2em">一切源流本末無不𨤲然故其書頗爲賞鑒家所</span>  
<span style="margin-left: 2em">重郎瑛七修𩔖稿嘗議其琴論後當入古笙管淳</span>  
<span style="margin-left: 2em">化帖後當收譜系一卷珍寳欠祖母綠聖鐵異石</span>  
<span style="margin-left: 2em">欠大理仙姑異木欠伽楠香古銅欠布刀等錢古</span>  
<span style="margin-left: 2em">𥿄欠藏經𥿄且珍奇後當設一羽皮如狐貉孔雀</span>  
<span style="margin-left: 2em">翡翠豹兕之𩔖而文房門亦不可不論云云其言</span>  
<span style="margin-left: 2em">雖似有理然其書不過自抒聞見以爲後來攷古</span>  
<!-- 册3 葉2628a　Page:文淵閣四庫全書_0003冊.djvu/662 -->
<span style="margin-left: 2em">之資固與𩔖書隷事體例有殊要未可以一二事</span>  
<span style="margin-left: 2em">之偶未賅備遽訾其脫漏也惟所論銅器入土千</span>  
<span style="margin-left: 2em">年色純靑如翠入水千年色綠如𤓰皮一條孫炯</span>  
<span style="margin-left: 2em">硯山齋珍玩集覽以爲信如所言則水銀色褐色</span>  
<span style="margin-left: 2em">黑漆古色者又將埋於何地而深譏其說爲未確</span>  
<span style="margin-left: 2em">是誠不免於疎駁耳</span>  
竹嶼山房雜部三十二卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">是書凡養生部六卷燕閒部二卷樹畜部四卷皆</span>  
<span style="margin-left: 2em">明華亭宋詡撰種植部十卷尊生部十卷詡子公</span>  
<!-- 册3 葉2628b　Page:文淵閣四庫全書_0003冊.djvu/662 -->
<span style="margin-left: 2em">望撰公望之子懋澄合而編之詡字久夫公望字</span>  
<span style="margin-left: 2em">天民皆見於書中其始末則未詳焉考千頃堂書</span>  
<span style="margin-left: 2em">目載是書凡二十七卷前集樹畜部四卷養生部</span>  
<span style="margin-left: 2em">六卷家要二卷宗儀二卷家規四卷後集種植一</span>  
<span style="margin-left: 2em">卷尊生一卷此本葢不完之書然此書以農圃之</span>  
<span style="margin-left: 2em">言兼玩好之具與家要家規宗儀同爲一帙實屬</span>  
<span style="margin-left: 2em">不倫疑其後析而别行而此五部以𩔖相聚自爲</span>  
<span style="margin-left: 2em">一編則亦不可謂非全帙也至種植養生二部實</span>  
<span style="margin-left: 2em">各十卷與黃氏所云各一卷者不合且以黃氏所</span>  
<!-- 册3 葉2629a　Page:文淵閣四庫全書_0003冊.djvu/662 -->
<span style="margin-left: 2em">載卷數計之與二十七卷之數又自不相合則黃</span>  
<span style="margin-left: 2em">氏所云亦不足據以定此書之完缺矣其書於田</span>  
<span style="margin-left: 2em">居雜事最爲詳悉而亦間附考證如養生部鰣魚</span>  
<span style="margin-left: 2em">條引爾雅鯦當魱以證之鄭樵注謂鯦卽魱魱卽</span>  
<span style="margin-left: 2em">縮項鯿郭璞注謂鯦似鯿而小則非鯿可知鄭注</span>  
<span style="margin-left: 2em">似誤此書取張萱彚雅之說舍鄭從郭以鯦爲鰣</span>  
<span style="margin-left: 2em">所解甚確則猶讀書考古者所爲非僅山人墨客</span>  
<span style="margin-left: 2em">語也</span>  
遵生八牋十九卷<sub class="note-yuan">通行本</sub>  
<!-- 册3 葉2629b　Page:文淵閣四庫全書_0003冊.djvu/662 -->
<span style="margin-left: 2em">明高濂撰濂字深父錢塘人其書分爲八目卷一</span>  
<span style="margin-left: 2em">卷二曰淸修妙論牋皆養身格言其宗旨多出於</span>  
<span style="margin-left: 2em">二氏卷三至卷六曰四時調攝牋皆按時修養之</span>  
<span style="margin-left: 2em">訣卷七卷八曰起居安樂牋皆實物器用可資頥</span>  
<span style="margin-left: 2em">養者卷九卷十曰延年却病牋皆服氣導引諸術</span>  
<span style="margin-left: 2em">卷十一至卷十三曰飮𩜹服食牋皆食品名目附</span>  
<span style="margin-left: 2em">以服餌諸物卷十四至十六曰燕閒淸賞牋皆論</span>  
<span style="margin-left: 2em">賞鑒淸玩之事附以種花卉法卷十七十八曰靈</span>  
<span style="margin-left: 2em">秘丹藥牋皆經驗方藥卷十九曰塵外遐舉牋則</span>  
<!-- 册3 葉2632a　Page:文淵閣四庫全書_0003冊.djvu/663 -->
<span style="margin-left: 2em">厯代隱逸一百人事蹟也書中所載專以供閒適</span>  
<span style="margin-left: 2em">消遣之用標目編𩔖亦多涉纎仄不出明季小品</span>  
<span style="margin-left: 2em">積習遂爲陳繼儒李漁等濫觴又如張卽之宋書</span>  
<span style="margin-left: 2em">家而以爲元人范式官廬江太守而以爲隱逸其</span>  
<span style="margin-left: 2em">訛誤亦復不少特抄撮旣富亦時有助於檢核其</span>  
<span style="margin-left: 2em">詳論古器彚集單方亦時有可採以視勦襲淸言</span>  
<span style="margin-left: 2em">强作雅態者固較勝焉</span>  
淸秘藏二卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">明張應文撰而其子謙德潤色之應文字茂實崑</span>  
<!-- 册3 葉2632b　Page:文淵閣四庫全書_0003冊.djvu/663 -->
<span style="margin-left: 2em">山監生屢試不第乃一意以古器書畫自娛謙德</span>  
<span style="margin-left: 2em">卽作淸河書畫舫眞蹟日錄之張丑後改名也是</span>  
<span style="margin-left: 2em">編雜論玩好賞鑒諸物其曰淸秘藏者王穉登序</span>  
<span style="margin-left: 2em">謂取倪瓚淸秘閣意也上卷分二十門下卷分十</span>  
<span style="margin-left: 2em">門其體例畧如洞天淸錄其文則多採前人舊論</span>  
<span style="margin-left: 2em">如銅劍一條本江淹銅劍讚之𩔖不一而足而皆</span>  
<span style="margin-left: 2em">不著所出葢猶沿明人剽剟之習其中所列香名</span>  
<span style="margin-left: 2em">多引佛經所列奇寳多引小說頗參以子虚烏有</span>  
<span style="margin-left: 2em">之談亦不爲典據然於一切器玩皆辨别眞僞品</span>  
<!-- 册3 葉2633a　Page:文淵閣四庫全書_0003冊.djvu/663 -->
<span style="margin-left: 2em">第甲乙以及收藏裝褙之𩔖一一言之甚詳亦頗</span>  
<span style="margin-left: 2em">有可采卷末記所蓄所見一條稱所蓄法書惟宋</span>  
<span style="margin-left: 2em">高宗行書一卷蘇子瞻詩草元趙子昂歸田賦所</span>  
<span style="margin-left: 2em">蓄名畫惟唐周昉戲嬰圖宋人羅漢八幅畫苑雜</span>  
<span style="margin-left: 2em">跡一册元倪雲林小景一幅而巳而其子丑作淸</span>  
<span style="margin-left: 2em">河書畫表列於應文名下者乃有三十一種此書</span>  
<span style="margin-left: 2em">成於應文臨没之日不得以續購爲詞然則丑表</span>  
<span style="margin-left: 2em">所列殆亦夸飾其富不足盡信歟此本爲鮑士恭</span>
