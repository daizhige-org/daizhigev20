<span style="margin-left: 1em">經部八</span>  
<span style="margin-left: 2em">易類存目二</span>  
周易象通八卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">明朱謀㙔撰謀㙔字鬱儀寧獻王七世孫萬厯間</span>  
<span style="margin-left: 2em">以中尉攝石城王府事是書惟釋上下經文不及</span>  
<span style="margin-left: 2em">十翼大㫖欲稍還古義而轉生臆說如不用陳摶</span>  
<span style="margin-left: 2em">先天圖亦不用周子太極圖是矣而别造河圖四</span>  
<span style="margin-left: 2em">謂三代以來世藏秘府以爲寶學者莫得而窺迨</span>  
<!-- 册1 葉737b　Page:文淵閣四庫全書_0001冊.djvu/234 -->
<span style="margin-left: 2em">宋徽宗考古搜奇始出示於外是出何典記乎邵</span>  
<span style="margin-left: 2em">陳以前無論矣耿南仲張根諸家皆徽宗時人王</span>  
<span style="margin-left: 2em">湜以下諸家皆徽宗後人何不一見也其說易以</span>  
<span style="margin-left: 2em">象象取於互體變體是矣然如謂乾居西北當奎</span>  
<span style="margin-left: 2em">婁白虎之尾故曰履虎尾巳穿鑿附會至於解旣</span>  
<span style="margin-left: 2em">濟云涉者多繫匏以防危離爲大腹匏𤓰之象則</span>  
<span style="margin-left: 2em">涉者也坎爲川瀆則津濟也因外卦爲離而生大</span>  
<span style="margin-left: 2em">腹因大腹而生匏𤓰因匏𤓰而牽合於繫匏涉水</span>  
<span style="margin-left: 2em">以遷就旣濟之象易果若是之迂曲乎又解困卦</span>  
<!-- 册1 葉740a　Page:文淵閣四庫全書_0001冊.djvu/235 -->
<span style="margin-left: 2em">初爻二爻云坎爲叢棘初其株也六三居泉谷之</span>  
<span style="margin-left: 2em">間故爲石梁株木石梁皆因未涸而爲橋梁是急</span>  
<span style="margin-left: 2em">於濟渡而遭困也因坎生叢棘因在初爻而變文</span>  
<span style="margin-left: 2em">曰株木因六三在兌坎之間生泉谷因泉谷而生</span>  
<span style="margin-left: 2em">石梁而省文曰石易果若是之晦澁乎上經始乾</span>  
<span style="margin-left: 2em">坤而終坎離下經始咸恒而終旣濟未濟<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">有義</span>  
<span style="margin-left: 2em">理序卦卽不出孔子亦必漢以前經師所傳謀㙔</span>  
<span style="margin-left: 2em">乃合上下經而一之易未經秦火訛脫甚少而謀</span>  
<span style="margin-left: 2em">㙔或隨意改字或動稱錯簡衍文甚至漸卦上九</span>  
<!-- 册1 葉740b　Page:文淵閣四庫全書_0001冊.djvu/235 -->
<span style="margin-left: 2em">併經文改爲鴻漸于逵並不言舊作鴻漸于陸其</span>  
<span style="margin-left: 2em">武斷尤甚謀㙔以博洽名此書尤爲曹學佺所推</span>  
<span style="margin-left: 2em">許其實多出臆見不爲定論也</span>  
易學識遺一卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明朱睦㮮撰睦㮮字灌甫號西亭周定王六世孫</span>  
<span style="margin-left: 2em">萬歴五年舉宗正領宗學事事跡附見明史周王</span>  
<span style="margin-left: 2em">橚傳是書大指皆辨論諸家說易之異同雖薈萃</span>  
<span style="margin-left: 2em">不多而頗有卓見如乾之四德謂程傳本文言視</span>  
<span style="margin-left: 2em">本義爲勝乾九二利見大人不專指九五明夷九</span>  
<!-- 册1 葉741a　Page:文淵閣四庫全書_0001冊.djvu/235 -->
<span style="margin-left: 2em">三不可疾貞從項安世以貞字爲句井泥之泥讀</span>  
<span style="margin-left: 2em">平聲勿幕之幕卽羃字數往者順用王安石解皆</span>  
<span style="margin-left: 2em">於經傳有裨非同勦說雷同者然明史藝文志不</span>  
<span style="margin-left: 2em">載此書核校其文卽睦㮮五經稽疑中說易之一</span>  
<span style="margin-left: 2em">卷或其初出别行之本抑或書賈作僞改題此名</span>  
<span style="margin-left: 2em">歟</span>  
易經疑問十二卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明姚舜牧撰舜牧字虞佐烏程人萬歴癸酉舉人</span>  
<span style="margin-left: 2em">歴官新興廣昌二縣知縣考舜牧生於嘉靖癸卯</span>  
<!-- 册1 葉741b　Page:文淵閣四庫全書_0001冊.djvu/235 -->
<span style="margin-left: 2em">其五經疑問皆年過六十所撰迨年過八十又重</span>  
<span style="margin-left: 2em">訂詩禮二經及此書其序並載所著來恩堂集中</span>  
<span style="margin-left: 2em">歲月先後一一可考計其一生精力殫於窮經然</span>  
<span style="margin-left: 2em">此書率敷衍舊說間出已意亦了不異人葢其學</span>  
<span style="margin-left: 2em">從坊刻講章而入門徑一左遂終身勞苦而無功</span>  
<span style="margin-left: 2em">耳</span>  
易測十卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">明曾朝節撰朝節字植齋臨武人萬厯丁丑進士</span>  
<span style="margin-left: 2em">官至禮部尚書是編取王弼註孔頴達疏程子傳</span>  
<!-- 册1 葉744a　Page:文淵閣四庫全書_0001冊.djvu/236 -->
<span style="margin-left: 2em">朱子本義及楊氏易傳之說參互考訂惟解上下</span>  
<span style="margin-left: 2em">經彖象文言繫辭而置說卦序卦雜卦又倣王弼</span>  
<span style="margin-left: 2em">畧例之意别作說凡一卷附於末大㫖主於觀辭</span>  
<span style="margin-left: 2em">玩占一切卦圖卦變之說悉所不取頗足掃宋易</span>  
<span style="margin-left: 2em">之葛藤然其去取衆說則未能一一精審也</span>  
周易㝠㝠篇四卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明蘇濬撰濬字君禹號紫溪晉江人萬厯丁丑進</span>  
<span style="margin-left: 2em">士官至廣西布政司叅政此書惟解上下經繫辭</span>  
<span style="margin-left: 2em">說卦刪序卦雜卦大㫖主王弼虗無之說一切歸</span>  
<!-- 册1 葉744b　Page:文淵閣四庫全書_0001冊.djvu/236 -->
<span style="margin-left: 2em">之於心學非惟廢卜筮之說乃併宋儒言理而偶</span>  
<span style="margin-left: 2em">及數者亦以爲執泥牽拘其訓潛龍勿用以爲心</span>  
<span style="margin-left: 2em">之寂然不動訓大明終始以爲心之靈明不昧而</span>  
<span style="margin-left: 2em">於繫辭之末以易主忘言爲歸宿觀其以㝠㝠名</span>  
<span style="margin-left: 2em">書則其說之遁於二氏不問可知矣</span>  
易經兒說四卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">明蘇濬撰濬周易㝠㝠篇恍惚支離頗涉異學及</span>  
<span style="margin-left: 2em">作是書乃墨守朱子本義尺寸不踰其首先曰講</span>  
<span style="margin-left: 2em">者詮釋文句也次曰意者推闡大㫖也次曰總論</span>  
<!-- 册1 葉745a　Page:文淵閣四庫全書_0001冊.djvu/236 -->
<span style="margin-left: 2em">則一卦之綱領也又間出旁註以一二語標題葢</span>  
<span style="margin-left: 2em">專爲科舉之學而設因在家塾以此書爲子姪講</span>  
<span style="margin-left: 2em">授故稱兒說萬歴中嘗刋行板後散佚康熙丁卯</span>  
<span style="margin-left: 2em">其裔孫堯松等重刋之</span>  
續韋齋易義虗裁八卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明涂宗濬撰宗濬字鏡原南昌人萬厯癸未進士</span>  
<span style="margin-left: 2em">官至兵部尚書諡恭襄是編用注疏本彚前儒之</span>  
<span style="margin-left: 2em">說以作解大㫖依傍程朱傳義而亦時有所糾正</span>  
<span style="margin-left: 2em">如坤六五一爻駁程子女媧武后之說是也所說</span>  
<!-- 册1 葉745b　Page:文淵閣四庫全書_0001冊.djvu/236 -->
<span style="margin-left: 2em">頗潔淨不支而隨文生義罕所發明其首列易圖</span>  
<span style="margin-left: 2em">以河圖作旋毛洛書作拆甲葢本吳澄之說非所</span>  
<span style="margin-left: 2em">臆造然澄說實臆造也</span>  
易會八卷<sub class="note-yuan">浙江鄭大節家藏本</sub>  
<span style="margin-left: 2em">明鄒德溥撰德溥字汝光安福人萬厯癸未進士</span>  
<span style="margin-left: 2em">官至司經局洗馬明史儒林傳附見其祖守益傳</span>  
<span style="margin-left: 2em">末是書用注疏本其說多主義理亦兼言象自繫</span>  
<span style="margin-left: 2em">辭以下所解甚畧自序謂就心所會者述之故名</span>  
<span style="margin-left: 2em">易會然往往亦借以寓意如解亢龍有悔曰亢而</span>  
<!-- 册1 葉748a　Page:文淵閣四庫全書_0001冊.djvu/237 -->
<span style="margin-left: 2em">曰龍則亢乎其所不得不亢也葢人處時勢之極</span>  
<span style="margin-left: 2em">固有必亢而後濟者惟聖人純乎天德無一毫全</span>  
<span style="margin-left: 2em">軀保命之思雖履盛滿䝉譏謗冒天下之不韙而</span>  
<span style="margin-left: 2em">弗之避也卽勢且至於悔亦爲天下甘之矣若慮</span>  
<span style="margin-left: 2em">其有悔而先自處於不亢之地則智士之所爲耳</span>  
<span style="margin-left: 2em">何龍德之云乎此明季淸流之見以愧選愞則可</span>  
<span style="margin-left: 2em">矣實非經義也</span>  
像抄六卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明錢一本撰一本有像象管見巳著錄是書雖以</span>  
<!-- 册1 葉748b　Page:文淵閣四庫全書_0001冊.djvu/237 -->
<span style="margin-left: 2em">象爲名實則衍陳摶之數學凡卦圖二卷附錄書</span>  
<span style="margin-left: 2em">札及雜吟二卷上下經解二卷其卦圖以朱子本</span>  
<span style="margin-left: 2em">義所列九圖衍爲三十二圖圖各有說縱橫比對</span>  
<span style="margin-left: 2em">自謂言象而理在其中然孔子所謂象者像也卽</span>  
<span style="margin-left: 2em">指卦爻朱子所列九圖後儒已不免異同一本借</span>  
<span style="margin-left: 2em">以旁推尤爲支蔓雖易道廣大隨拈一義皆有理</span>  
<span style="margin-left: 2em">可通究非聖人設教之本㫖也</span>  
四聖一心錄六卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">明錢一本撰是書於像抄之外又舍數而言理其</span>  
<!-- 册1 葉749a　Page:文淵閣四庫全書_0001冊.djvu/237 -->
<span style="margin-left: 2em">言理舍天而言人其言人又舍事而言心推闡之</span>  
<span style="margin-left: 2em">以至於性命體例近乎語錄其論亦多支離如謂</span>  
<span style="margin-left: 2em">許由讓王爲能知河洛之道又謂序卦傳爲格物</span>  
<span style="margin-left: 2em">之學大抵皆故爲高論也</span>  
易筌六卷附論一卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">明焦竑撰竑字弱侯應天旗手衛籍山東日照人</span>  
<span style="margin-left: 2em">萬厯己丑進士第一授翰林院修撰尋遷東宫講</span>  
<span style="margin-left: 2em">讀官謫福寧州州同事迹具明史文苑傳是書大</span>  
<span style="margin-left: 2em">㫖欲以二氏通於易每雜引列子黃庭内景經抱</span>  
<!-- 册1 葉749b　Page:文淵閣四庫全書_0001冊.djvu/237 -->
<span style="margin-left: 2em">朴子諸書以釋經史稱竑講學以羅汝芳爲宗而</span>  
<span style="margin-left: 2em">善耿定向耿定理及李贄時頗以禪學譏之葢不</span>  
<span style="margin-left: 2em">誣云</span>  
周易正解二十卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">明郝敬撰敬字仲輿京山人萬厯己丑進士厯官</span>  
<span style="margin-left: 2em">縉雲永嘉二縣知縣擢禮科給事中遷戸科尋謫</span>  
<span style="margin-left: 2em">宜興縣丞終於江陰縣知縣明史文苑傳附見李</span>  
<span style="margin-left: 2em">維楨傳末所著有九經解此卽其一用王弼註本</span>  
<span style="margin-left: 2em">凡上下經十七卷其說較詳繫辭以下僅三卷則</span>  
<!-- 册1 葉752a　Page:文淵閣四庫全書_0001冊.djvu/238 -->
<span style="margin-left: 2em">少畧焉大㫖以義理爲主而亦兼及於象其言理</span>  
<span style="margin-left: 2em">多以十翼之說印正卦爻其言象亦頗簡易然好</span>  
<span style="margin-left: 2em">恃其聰明臆爲剏論如釋蠱卦爲武王之事而以</span>  
<span style="margin-left: 2em">先甲後甲爲取象甲子昧爽其他亦多實以文武</span>  
<span style="margin-left: 2em">之事葢本作易者其有憂患一語輾轉旁推遂橫</span>  
<span style="margin-left: 2em">生穿鑿其所著經解大抵均坐此弊也</span>  
易領四卷<sub class="note-yuan">浙江鄭大節家藏本</sub>  
<span style="margin-left: 2em">明郝敬撰是書專釋卦序之義自序謂冠以序卦</span>  
<span style="margin-left: 2em">傳如衣之挈領故以領名卷前標山草堂集第二</span>  
<!-- 册1 葉752b　Page:文淵閣四庫全書_0001冊.djvu/238 -->
<span style="margin-left: 2em">内編葢敬所著九經解皆編入文集此其集中之</span>  
<span style="margin-left: 2em">第二種耳</span>  
易學飮河八卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">明張納陛撰納陛字以登宜興人萬厯己丑進士</span>
