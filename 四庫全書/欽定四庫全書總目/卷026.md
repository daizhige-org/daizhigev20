## 欽定四庫全書總目 卷二十六　經部二十六　春秋類一

<!-- 册1 葉2101a　Page:文淵閣四庫全書_0001冊.djvu/575 -->
欽定四庫全書總目卷二十六  
<span style="margin-left: 1em">經部二十六</span>  
<span style="margin-left: 2em">春秋𩔖一</span>  
<span style="margin-left: 3em">說經家之有門戸自春秋三傳始然迄能並立</span>  
<span style="margin-left: 3em">於世其間諸儒之論中唐以前則左氏勝啖助</span>  
<span style="margin-left: 3em">趙匡以逮北宋則公羊穀梁勝孫復劉敞之流</span>  
<span style="margin-left: 3em">名爲棄傳從經所棄者特左氏事迹公羊穀梁</span>  
<span style="margin-left: 3em">月日例耳其推闡譏貶少可多否實陰本公羊</span>  
<span style="margin-left: 3em">穀梁法猶誅鄧析用竹刑也夫删除事迹何由</span>  
<!-- 册1 葉2101b　Page:文淵閣四庫全書_0001冊.djvu/575 -->
<span style="margin-left: 3em">知其是非無案而斷是春秋爲射覆矣聖人禁</span>  
<span style="margin-left: 3em">人爲非亦予人爲善經典所述不乏褒辭而操</span>  
<span style="margin-left: 3em">筆臨文乃無人不加誅絶春秋豈吉網羅鉗乎</span>  
<span style="margin-left: 3em">至於用夏時則改正朔削尊號則貶天王春秋</span>  
<span style="margin-left: 3em">又何僭以亂也沿波不返此類宏多雖舊說流</span>  
<span style="margin-left: 3em">傳不能盡廢要以切實有徴平易近理者爲本</span>  
<span style="margin-left: 3em">其瑕瑜互見者則别白而存之游談臆說以私</span>  
<span style="margin-left: 3em">意亂聖經者則僅存其目葢六經之中惟易包</span>  
<span style="margin-left: 3em">衆理事事可通春秋具列事實亦人人可解一</span>  
<!-- 册1 葉2104a　Page:文淵閣四庫全書_0001冊.djvu/576 -->
<span style="margin-left: 3em">知半見議論易生著錄之繁二經爲最故取之</span>  
<span style="margin-left: 3em">不可不愼也</span>  
春秋左傳正義六十卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">周左丘明傳晉杜預注唐孔頴達疏自劉向劉歆</span>  
<span style="margin-left: 2em">桓譚班固皆以春秋傳出左丘明左丘明受經於</span>  
<span style="margin-left: 2em">孔子魏晉以來儒者更無異議至唐趙匡始謂左</span>  
<span style="margin-left: 2em">氏非丘明葢欲攻傳之不合經必先攻作傳之人</span>  
<span style="margin-left: 2em">非受經於孔子與王栢欲攻毛詩先攻毛詩不傳</span>  
<span style="margin-left: 2em">於子夏其智一也宋元諸儒相繼並起王安石有</span>  
<!-- 册1 葉2104b　Page:文淵閣四庫全書_0001冊.djvu/576 -->
<span style="margin-left: 2em">春秋解一卷證左氏非丘明者十一事陳振孫書</span>  
<span style="margin-left: 2em">錄解題謂出依託今未見其書不知十一事者何</span>  
<span style="margin-left: 2em">據其餘辨論惟朱子謂虞不臘矣爲秦人語葉夢</span>  
<span style="margin-left: 2em">得謂記事終於智伯當爲六國時人似爲近理然</span>  
<span style="margin-left: 2em">考史記秦本紀稱惠文君十二年始臘張守節正</span>  
<span style="margin-left: 2em">義稱秦惠文王始效中國爲之明古有臘祭秦至</span>  
<span style="margin-left: 2em">是始用非至是始剏閻若璩古文尙書疏證亦駁</span>  
<span style="margin-left: 2em">此說曰史稱秦文公始有史以記事秦宣公初志</span>  
<span style="margin-left: 2em">閏月豈亦中國所無待秦獨創哉則臘爲秦禮之</span>  
<!-- 册1 葉2105a　Page:文淵閣四庫全書_0001冊.djvu/576 -->
<span style="margin-left: 2em">說未可據也左傳載預斷禍福無不徴驗葢不免</span>  
<span style="margin-left: 2em">從後傅合之惟哀公九年稱趙氏其世有亂後竟</span>  
<span style="margin-left: 2em">不然是未見後事之證也經止獲麟而弟子續至</span>  
<span style="margin-left: 2em">孔子卒傳載智伯之亡殆亦後人所續史記司馬</span>  
<span style="margin-left: 2em">相如傳中有揚雄之語不能執是一事指司馬遷</span>  
<span style="margin-left: 2em">爲後漢人也則載及智伯之說不足疑也今仍定</span>  
<span style="margin-left: 2em">爲左丘明作以祛衆惑至其作傳之由則劉知幾</span>  
<span style="margin-left: 2em">躬爲國史之言最爲<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">論疏稱大事書於策者經</span>  
<span style="margin-left: 2em">之所書小事書於傳者傳之所載觀晉史之書趙</span>  
<!-- 册1 葉2105b　Page:文淵閣四庫全書_0001冊.djvu/576 -->
<span style="margin-left: 2em">盾齊史之書崔杼及甯殖所謂載在諸侯之籍者</span>  
<span style="margin-left: 2em">其文體皆與經合墨子稱周春秋載杜伯燕春秋</span>  
<span style="margin-left: 2em">載莊子儀宋春秋載ခ觀辜齊春秋載王里國中</span>  
<span style="margin-left: 2em">里覈其文體皆與傳合經傳同因國史而修斯爲</span>  
<span style="margin-left: 2em">顯證知說經去傳爲舍近而求諸遠矣漢志載春</span>  
<span style="margin-left: 2em">秋古經十二篇經十一卷注曰公羊穀梁二家則</span>  
<span style="margin-left: 2em">左氏經文不著於錄然杜預集解序稱分經之年</span>  
<span style="margin-left: 2em">與傳之年相附比其義𩔖各隨而解之陸德明經</span>  
<span style="margin-left: 2em">典釋文曰舊夫子之經與丘明之傳相異杜氏合</span>  
<!-- 册1 葉2108a　Page:文淵閣四庫全書_0001冊.djvu/577 -->
<span style="margin-left: 2em">而釋之則左傳又自有經考漢志之文旣曰古經</span>  
<span style="margin-left: 2em">十二篇矣不應復云經十一卷觀公穀二傳皆十</span>  
<span style="margin-left: 2em">一卷與經十一卷相配知十一卷爲二傳之經故</span>  
<span style="margin-left: 2em">有是注徐彦公羊傳疏曰左氏先著竹帛故漢儒</span>  
<span style="margin-left: 2em">謂之古學則所謂古經十二篇卽所傳之經故謂</span>  
<span style="margin-left: 2em">之古刻漢書者誤連二條爲一耳今以左傳經文</span>  
<span style="margin-left: 2em">與二傳校勘皆左氏義長知手錄之本確於口授</span>  
<span style="margin-left: 2em">之本也言左傳者孔奇孔嘉之說久佚不傳賈逵</span>  
<span style="margin-left: 2em">服䖍之說亦僅偶見他書今世所傳惟杜注孔疏</span>  
<!-- 册1 葉2108b　Page:文淵閣四庫全書_0001冊.djvu/577 -->
<span style="margin-left: 2em">爲最古杜注多强經以就傳孔疏亦多左杜而右</span>  
<span style="margin-left: 2em">劉<sub class="note-yuan">案劉<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3271.svg?width=24" alt="四庫全書僻字第3271號（炫）" title="四庫全書僻字第3271號（炫）">作規過以攻杜解凡所駁正孔疏皆以爲非</sub>是皆篤信專門之過</span>  
<span style="margin-left: 2em">不能不謂之一失然有注疏而後左氏之義明左</span>  
<span style="margin-left: 2em">氏之義明而後二百四十二年内善惡之迹一一</span>  
<span style="margin-left: 2em">有徴後儒妄作聰明以私意談褒貶者猶得據傳</span>  
<span style="margin-left: 2em">文以知其謬則漢晉以來藉左氏以知經義宋元</span>  
<span style="margin-left: 2em">以後更藉左氏以杜臆說矣傳與注疏均謂有大</span>  
<span style="margin-left: 2em">功於春秋可也</span>  
春秋公羊傳註疏二十八卷<sub class="note-yuan">内府藏本</sub>  
<!-- 册1 葉2109a　Page:文淵閣四庫全書_0001冊.djvu/577 -->
<span style="margin-left: 2em">漢公羊壽傳何休解詁唐徐彥疏案漢書藝文志</span>  
<span style="margin-left: 2em">公羊傳十一卷班固自注曰公羊子齊人<sub class="note-yuan">案漢藝文志不</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">題顏師古名者皆固之自注</sub>顏師古注曰名高<sub class="note-yuan">案此據春秋說題詞之文見徐</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">彥疏所引</sub>徐彥疏引戴宏序曰子夏傳與公羊高高傳</span>  
<span style="margin-left: 2em">與其子平平傳與其子地地傳與其子敢敢傳與</span>  
<span style="margin-left: 2em">其子壽至漢景帝時壽乃與齊人胡母子都著於</span>  
<span style="margin-left: 2em">竹帛何休之注亦同<sub class="note-yuan">休說見隱公二年紀子伯莒子盟于密條下</sub>今觀</span>  
<span style="margin-left: 2em">傳中有子沈子曰子司馬子曰子女子曰子北宫</span>  
<span style="margin-left: 2em">子曰又有高子曰魯子曰葢皆傳授之經師不盡</span>  
<!-- 册1 葉2109b　Page:文淵閣四庫全書_0001冊.djvu/577 -->
<span style="margin-left: 2em">出於公羊子定公元年傳正棺于兩楹之間兩句</span>  
<span style="margin-left: 2em">穀梁傳引之<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">稱沈子不稱公羊是併其不著姓</span>  
<span style="margin-left: 2em">氏者亦不盡出公羊子且併有子公羊子曰尤不</span>  
<span style="margin-left: 2em">岀於高之明證知傳<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">爲壽撰而胡母子都助成</span>  
<span style="margin-left: 2em">之舊本首署高名葢未審也又羅壁識遺稱公羊</span>  
<span style="margin-left: 2em">穀梁自高赤作傳外更不見有此姓萬見春謂皆</span>  
<span style="margin-left: 2em">姜字切韻脚疑爲姜姓假托按芻爲邾婁披爲勃</span>  
<span style="margin-left: 2em">鞮木爲彌牟殖爲舌職記載音訛經典原有是事</span>  
<span style="margin-left: 2em">至弟子記其先師子孫述其祖父必不至竟迷本</span>  
<!-- 册1 葉2112a　Page:文淵閣四庫全書_0001冊.djvu/578 -->
<span style="margin-left: 2em">字别用合聲璧之所言殊爲好異至程端學春秋</span>  
<span style="margin-left: 2em">本義竟指高爲漢初人則講學家臆斷之詞更不</span>  
<span style="margin-left: 2em">足與辨矣三傳與經文漢志皆各爲卷帙以左傳</span>  
<span style="margin-left: 2em">附經始於杜預公羊傳附經則不知始自何人觀</span>  
<span style="margin-left: 2em">何休解詁但釋傳而不釋經與杜異例知漢末猶</span>  
<span style="margin-left: 2em">自别行今所傳蔡邕石經殘字公羊傳亦無經文</span>  
<span style="margin-left: 2em">足以互證今本以傳附經或徐彥作疏之時所合</span>  
<span style="margin-left: 2em">併歟彥疏文獻通考作三十卷今本乃作二十八</span>  
<span style="margin-left: 2em">卷或彦本以經文併爲二卷别冠於前後人又散</span>  
<!-- 册1 葉2112b　Page:文淵閣四庫全書_0001冊.djvu/578 -->
<span style="margin-left: 2em">入傳中故少此二卷亦未可知也彦疏唐志不載</span>  
<span style="margin-left: 2em">崇文總目始著錄稱不著撰人名氏或云徐彦董</span>  
<span style="margin-left: 2em">逌廣川藏書志亦稱世傳徐彦不知時代意其在</span>  
<span style="margin-left: 2em">貞元長慶之後考疏中邲之戰一條猶及見孫炎</span>  
<span style="margin-left: 2em">爾雅注完本知在宋以前又葬桓王一條全襲用</span>  
<span style="margin-left: 2em">楊士勛穀梁傳疏知在貞觀以後中多自設問答</span>  
<span style="margin-left: 2em">文繁語複與邱光庭兼明書相近亦唐末之文體</span>  
<span style="margin-left: 2em">董逌所云不爲無理故今從逌之說定爲唐人焉</span>  
春秋穀梁傳註疏二十卷<sub class="note-yuan">内府藏本</sub>  
<!-- 册1 葉2113a　Page:文淵閣四庫全書_0001冊.djvu/578 -->
<span style="margin-left: 2em">晉范甯集解唐楊士勛疏其傳則士勛疏稱穀梁</span>  
<span style="margin-left: 2em">子名俶字元始一名赤受經於子夏爲經作傳則</span>  
<span style="margin-left: 2em">當爲穀梁子所自作徐彦公羊傳疏又稱公羊高</span>  
<span style="margin-left: 2em">五世相授至胡母生乃著竹帛題其親師故曰公</span>  
<span style="margin-left: 2em">羊傳穀梁亦是著竹帛者題其親師故曰穀梁傳</span>  
<span style="margin-left: 2em">則當爲傳其學者所作按公羊傳定公卽位一條</span>  
<span style="margin-left: 2em">引子沈子曰何休解詁以爲後師<sub class="note-yuan">按此注在隠公十一年所引子</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">沈子條下</sub>此傳定公卽位一條亦稱沈子曰公羊穀梁</span>  
<span style="margin-left: 2em">旣同師子夏不應及見後師又初獻六羽一條稱</span>  
<!-- 册1 葉2113b　Page:文淵閣四庫全書_0001冊.djvu/578 -->
<span style="margin-left: 2em">穀梁子曰傳旣穀梁自作不應自引已說且此條</span>  
<span style="margin-left: 2em">又引尸子曰尸佼爲商鞅之師鞅旣誅俊逃於蜀</span>  
<span style="margin-left: 2em">其人亦在穀梁後不應預爲引据疑徐彦之言爲</span>  
<span style="margin-left: 2em">得其實但誰著於竹帛則不可考耳漢書藝文志</span>  
<span style="margin-left: 2em">載公羊穀梁二家經十一卷傳亦各十一卷則經</span>  
<span style="margin-left: 2em">傳初亦別編范甯集解乃併經注之疑卽甯之所</span>  
<span style="margin-left: 2em">合定公元年春王三月一條發傳於春王二字之</span>  
<span style="margin-left: 2em">下以三月別屬下文頗疑其割裂然考劉向說苑</span>  
<span style="margin-left: 2em">稱文王似元年武王似春王周公似正月向受穀</span>  
<!-- 册1 葉2116a　Page:文淵閣四庫全書_0001冊.djvu/579 -->
<span style="margin-left: 2em">梁春秋知穀梁經文以春王二字別爲一節故向</span>  
<span style="margin-left: 2em">有此讀至公觀魚于棠一條葬桓王一條杞伯來</span>  
<span style="margin-left: 2em">逆叔姬之喪以歸一條曹伯廬卒于師一條天王</span>
