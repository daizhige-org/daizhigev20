## 欽定四庫全書總目 卷十六　經部十六　詩類二

欽定四庫全書總目卷十六  
<span style="margin-left: 1em">經部十六</span>  
<span style="margin-left: 2em">詩類二</span>  
詩集傳名物鈔八卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">兀許謙撰謙有讀書叢說已著録謙雖受學於王</span>  
<span style="margin-left: 2em">柏而醇正則遠過其師研究諸經亦多明古義故</span>  
<span style="margin-left: 2em">是書所考名物音訓頗有根據足以補集傳之闕</span>  
<span style="margin-left: 2em">遺惟王柏作二南相配圖移甘棠何彼穠矣於王</span>  
<span style="margin-left: 2em">風而去野有死麕使召南亦十有一篇適如周南</span>  
<!-- 册1 葉1353b　Page:文淵閣四庫全書_0001冊.djvu/388 -->
<span style="margin-left: 2em">之數師心自用竄亂聖經殊不可訓而謙篤守師</span>  
<span style="margin-left: 2em">說列之卷中猶未免門戸之見至柏所刪國風三</span>  
<span style="margin-left: 2em">十二篇謙疑而未敢遽信正足見其是非之公吳</span>  
<span style="margin-left: 2em">師道作是書序乃反謂已放之鄭聲何爲尙存而</span>  
<span style="margin-left: 2em">不削於謙深致不滿是則以不狂爲狂非謙之失</span>  
<span style="margin-left: 2em">矣卷末譜作詩時世其例本之康成其說則改從</span>  
<span style="margin-left: 2em">集傳葢淵源授受各尊所聞然書中實多采用陸</span>  
<span style="margin-left: 2em">德明釋文及孔頴達正義亦未嘗株守一家名之</span>  
<span style="margin-left: 2em">曰鈔葢以此云</span>  
<!-- 册1 葉1356a　Page:文淵閣四庫全書_0001冊.djvu/389 -->
詩傳通釋二十卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">元劉瑾撰瑾字公瑾安福人其學問淵源出於朱</span>  
<span style="margin-left: 2em">子故是書大㫖在於發明集傳與輔廣詩童子問</span>  
<span style="margin-left: 2em">相同陳啟源作毛詩稽古編於二家之言多所駁</span>  
<span style="margin-left: 2em">詰然廣書皆循文演義故所駁惟訓解之詞瑾書</span>  
<span style="margin-left: 2em">兼辨定故實故所駁多考證之語如注何彼穠矣</span>  
<span style="margin-left: 2em">以齊桓公爲襄公之子註魏風以魏爲七國之魏</span>  
<span style="margin-left: 2em">註綢繆謂心宿之象三星鼎立註鹿鳴之什謂上</span>  
<span style="margin-left: 2em">下通用止小雅二南其大雅獨爲天子之樂註節</span>  
<!-- 册1 葉1356b　Page:文淵閣四庫全書_0001冊.djvu/389 -->
<span style="margin-left: 2em">南山以家父卽春秋之家父師尹卽春秋之尹氏</span>  
<span style="margin-left: 2em"><sub class="note-yuan">案此項安世之說見朱善詩解頤瑾襲之而隱其名也</sub>註楚茨誤讀鄭康成</span>  
<span style="margin-left: 2em">玉藻註以楚茨爲卽采齊註甫田誤讀毛傳車梁</span>  
<span style="margin-left: 2em">以爲卽小戎之梁輈註殷武杜撰殷廟之昭穆及</span>  
<span style="margin-left: 2em">祧廟世次皆一經指摘無可置詞故啓源譏胡廣</span>  
<span style="margin-left: 2em">修詩經大全收瑾說太濫<sub class="note-yuan">案大全卽用瑾此書爲藍本故全用其說啓源</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">未以二書相校故有此語謹附訂於此</sub>然徵實之學不足而研究義</span>  
<span style="margin-left: 2em">埋究有淵源議論亦頗篤實於詩人美刺之旨尙</span>  
<span style="margin-left: 2em">有所發明未可徑廢至周頌豐年篇朱子詩辨說</span>  
<!-- 册1 葉1357a　Page:文淵閣四庫全書_0001冊.djvu/389 -->
<span style="margin-left: 2em">旣駁其悞而集傳乃用序說自相矛盾又三夏見</span>  
<span style="margin-left: 2em">於周禮呂叔玉註以時邁執競思文當之朱子旣</span>  
<span style="margin-left: 2em">用其說乃又謂成康是二王諡執競是昭王後詩</span>  
<span style="margin-left: 2em">則不應篇名先見周禮瑾一一囘䕶亦爲啓源所</span>  
<span style="margin-left: 2em">糾然漢儒務守師傳唐疏皆遵註義此書旣專爲</span>  
<span style="margin-left: 2em">朱傳而作其委曲遷就固勢所必然亦無庸過爲</span>  
<span style="margin-left: 2em">責備也</span>  
詩傳旁通十五卷<sub class="note-yuan">山東巡撫採進本</sub>  
<span style="margin-left: 2em">元梁益撰益字友直號庸齋江陰人自署三山者</span>  
<!-- 册1 葉1357b　Page:文淵閣四庫全書_0001冊.djvu/389 -->
<span style="margin-left: 2em">以其先福州人也嘗舉江浙鄉試不及仕宦敎授</span>  
<span style="margin-left: 2em">鄉里以終事蹟附載元史儒學傳陸文圭傳内朱</span>  
<span style="margin-left: 2em">子詩傳詳於作詩之意而名物訓詁僅舉大凡葢</span>  
<span style="margin-left: 2em">是書仿孔賈諸疏證明註文之例凡集傳所引故</span>  
<span style="margin-left: 2em">實一一引據出處辨析源委因杜文瑛先有語孟</span>  
<span style="margin-left: 2em">旁通體例相似故亦以旁通爲名其中如聖人之</span>  
<span style="margin-left: 2em">耦則引西漢書劉歆論董仲舒語見堯於羮見舜</span>  
<span style="margin-left: 2em">於墻則引後漢書李固傳以明岀典或朱子所未</span>  
<span style="margin-left: 2em">詳者亦旁引諸說以補之如五緎五總引陸佃之</span>  
<!-- 册1 葉1360a　Page:文淵閣四庫全書_0001冊.djvu/390 -->
<span style="margin-left: 2em">語三單引鄭箋羨卒孔疏副丁之類亦間有與朱</span>  
<span style="margin-left: 2em">子之說稍異者如頃筐墍之集傳音許器切大雅</span>  
<span style="margin-left: 2em">民之攸墍集傳音許旣切者從陸德明經典釋文</span>  
<span style="margin-left: 2em">益則引禮部韻謂許旣切者在未韻音餼注云取</span>  
<span style="margin-left: 2em">也許器切者在至韻音洎作巨至切朱子之音與</span>  
<span style="margin-left: 2em">禮部韻不同云云是是非非絕不堅持門戸視胡</span>  
<span style="margin-left: 2em">炳文等之攀附高名言言附合相去遠矣卷首爲</span>  
<span style="margin-left: 2em">類目末一卷則其序說内一條論秦造父封趙因</span>  
<span style="margin-left: 2em">録羅泌國姓紀原之文自謂此於詩傳雖無所繫</span>  
<!-- 册1 葉1360b　Page:文淵閣四庫全書_0001冊.djvu/390 -->
<span style="margin-left: 2em">而宋氏有國其姓亦當知故通之則冗贅之文汗</span>  
<span style="margin-left: 2em">漫無理可已而不已者也前有至正四年太平路</span>  
<span style="margin-left: 2em">總管府推官濱州翟思忠序明朱睦㮮授經圖遂</span>  
<span style="margin-left: 2em">以詩傳旁通爲思忠作殊爲疎舛今從朱彝尊經</span>  
<span style="margin-left: 2em">義考所辨<sub class="note-yuan">案彝尊所引乃陸元輔之言</sub>附訂正焉</span>  
詩經疏義二十卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">元朱公遷撰公遷字克升樂平人江西通志載其</span>  
<span style="margin-left: 2em">至正間爲處州學正何英後序則稱以特恩授校</span>  
<span style="margin-left: 2em">官得主金華郡庠二説互異考樂平縣志載公遷</span>  
<!-- 册1 葉1361a　Page:文淵閣四庫全書_0001冊.djvu/390 -->
<span style="margin-left: 2em">以至正辛巳領浙江鄉試敎婺州改處州然則英</span>  
<span style="margin-left: 2em">序舉其始通志要其終耳是書爲發明朱子集傳</span>  
<span style="margin-left: 2em">而作如註有疏故曰疏義其後同里王逢及逢之</span>  
<span style="margin-left: 2em">門人何英又采衆說以補之逢所補題日輯録英</span>  
<span style="margin-left: 2em">所補題日增釋雖遞相附益其宗旨一也其說墨</span>  
<span style="margin-left: 2em">守朱子不踰尺寸而亦間有所辨證如卷耳篇内</span>  
<span style="margin-left: 2em">朱子悞用毛傳舊說以崔嵬爲土山戴石公遷則</span>  
<span style="margin-left: 2em">引爾雅說文明其當爲石戴土又七月之詩朱子</span>  
<span style="margin-left: 2em">本月令以流火在六月公遷推騐歲差謂公劉時</span>  
<!-- 册1 葉1361b　Page:文淵閣四庫全書_0001冊.djvu/390 -->
<span style="margin-left: 2em">當五六月之交皆足以補集傳之闕又集傳所引</span>  
<span style="margin-left: 2em">典故一一詳其岀處卽所引舊說原本不著其名</span>  
<span style="margin-left: 2em">者如衛風之趙子註爲趙伯循小雅斯千篇之或</span>  
<span style="margin-left: 2em">曰註爲曾氏之類皆一一考訂雖於宏旨無關亦</span>  
<span style="margin-left: 2em">足見其用心不苟也書成於至正丁亥正統甲子</span>  
<span style="margin-left: 2em">英始取逢所授遺稿重加增訂題曰詩傳義詳釋</span>  
<span style="margin-left: 2em">發明以授書林葉氏刋行之而板心又標詩傳會</span>  
<span style="margin-left: 2em">通未喻其故今仍從公遷舊名題曰詩經疏義以</span>  
<span style="margin-left: 2em">不没其始焉</span>  
<!-- 册1 葉1364a　Page:文淵閣四庫全書_0001冊.djvu/391 -->
詩疑問七卷附詩辨說一卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">元朱倬撰倬字孟章建章新城人至正二年進士</span>  
<span style="margin-left: 2em">官遂安縣尹壬辰秋寇至吏卒逃散倬獨坐公所</span>  
<span style="margin-left: 2em">以待盡及寇焚𪠘舍乃赴水死葢亦忠節之士元</span>  
<span style="margin-left: 2em">史遺漏未載</span>  
<span style="margin-left: 1em">國朝納喇性德作是書序始據新安文獻志汪叡所</span>  
<span style="margin-left: 2em">作哀詞爲表章其始末其書畧舉詩篇大㫖發問</span>  
<span style="margin-left: 2em">而各以所註列於下亦有闕而不註者劉錦文序</span>  
<span style="margin-left: 2em">稱其間有問無答者豈眞以爲疑哉在乎學者深</span>  
<!-- 册1 葉1364b　Page:文淵閣四庫全書_0001冊.djvu/391 -->
<span style="margin-left: 2em">思而自得之耳又稱舊本先後無序今爲之論定</span>  
<span style="margin-left: 2em">使語同而㫖小異者因得以互觀焉是此本乃錦</span>  
<span style="margin-left: 2em">文所重編非倬之舊其有問無答者或亦傳寫佚</span>  
<span style="margin-left: 2em">脫而錦文曲爲之詞歟末有趙悳詩辨說一卷悳</span>  
<span style="margin-left: 2em">宋宗室舉進士人元隱居豫章東湖其書與倬書</span>  
<span style="margin-left: 2em">畧相𩔖殆後人以倬忠烈悳高隱其人足以相配</span>  
<span style="margin-left: 2em">故合而編之歟倬書七卷附以悳書爲八卷朱睦</span>  
<span style="margin-left: 2em">㮮授經圖焦竑經籍志乃皆作六卷疑爲傳寫之</span>  
<span style="margin-left: 2em">訛或倬原書六卷劉錦文重編之時析爲七卷亦</span>  
<!-- 册1 葉1365a　Page:文淵閣四庫全書_0001冊.djvu/391 -->
<span style="margin-left: 2em">未可定也</span>  
詩纉緒十八卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">元劉玉汝撰玉汝始末未詳惟以周霆震石初集</span>  
<span style="margin-left: 2em">考之知其爲廬陵人字成之嘗舉鄕貢進士所作</span>  
<span style="margin-left: 2em">石初集序末題洪武癸丑則明初尚存也此書諸</span>  
<span style="margin-left: 2em">家書目皆未著錄獨永樂大典頗載其文其大㫖</span>  
<span style="margin-left: 2em">專以發明朱子集傳故名曰纉緒體例與輔廣童</span>  
<span style="margin-left: 2em">子問相近凡集傳中一二字之斟酌必求其命意</span>  
<span style="margin-left: 2em">所在或存此說而遺彼說或宗主此論而兼用彼</span>  
<!-- 册1 葉1365b　Page:文淵閣四庫全書_0001冊.djvu/391 -->
<span style="margin-left: 2em">論無不尋繹其所以然至論比興之例謂有有取</span>  
<span style="margin-left: 2em">義之興有無取義之興有一句興通章有數句興</span>  
<span style="margin-left: 2em">一句有興兼比賦兼比之類明用韻之法如曰隔</span>  
<span style="margin-left: 2em">句爲韻連章爲韻叠句爲韻重韻爲韻之類論風</span>  
<span style="margin-left: 2em">雅之殊如曰有腔調不同有詞義不同之類於朱</span>  
<span style="margin-left: 2em">子比興叶韻之說皆能反覆體究縷析條分雖未</span>  
<span style="margin-left: 2em">必盡合詩人之㫖而於集傳一家之學則可謂有</span>  
<span style="margin-left: 2em">所闡明矣明以來諸家詩解罕引其說則亡佚已</span>  
<span style="margin-left: 2em">久今就永樂大典所載依經排纂正其脫訛定爲</span>  
<!-- 册1 葉1368a　Page:文淵閣四庫全書_0001冊.djvu/392 -->
<span style="margin-left: 2em">一十八卷</span>  
詩演義十五卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">元梁寅撰寅有周易參義已著錄是書推演朱子</span>  
<span style="margin-left: 2em">詩傳之義故以演義爲名前有自序云此書爲㓜</span>  
<span style="margin-left: 2em">學而作博稽訓詁以啟其塞根之義理以達其義</span>  
<span style="margin-left: 2em">隱也使之顯畧也使之詳今考其書大抵淺顯易</span>  
<span style="margin-left: 2em">見切近不支元儒之學主於篤實猶勝虛談高論</span>  
<span style="margin-left: 2em">横生臆解者也朱𢑱尊經義考載此書作八卷註</span>  
<span style="margin-left: 2em">曰未見此本至小雅苕之華篇止以下皆缺而已</span>  
<!-- 册1 葉1368b　Page:文淵閣四庫全書_0001冊.djvu/392 -->
<span style="margin-left: 2em">有一十五卷則八卷之說殊爲未確葢彜尊未覩</span>
