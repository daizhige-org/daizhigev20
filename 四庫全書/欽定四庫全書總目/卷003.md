## 欽定四庫全書總目 卷三　經部三　易類三

<!-- 册1 葉288a　Page:文淵閣四庫全書_0001冊.djvu/122 -->
欽定四庫全書總目卷三  
<span style="margin-left: 1em">經部三</span>  
<span style="margin-left: 2em">易類三</span>  
周易窺餘十五卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋鄭剛中撰剛中字亨仲金華人紹興二年進士</span>  
<span style="margin-left: 2em">及第官至禮部侍郞出爲川陜宣撫副使謫居桂</span>  
<span style="margin-left: 2em">陽軍又責授濠州團練副使復州安置再從封州</span>  
<span style="margin-left: 2em">卒後追復原官諡忠愍事跡具宋史本傳王應麟</span>  
<span style="margin-left: 2em">困學紀聞稱鄭剛中有周禮解義考王與義周禮</span>  
<!-- 册1 葉288b　Page:文淵閣四庫全書_0001冊.djvu/122 -->
<span style="margin-left: 2em">訂義首列諸家姓氏有三山鄭鍔字剛中淳熙中</span>  
<span style="margin-left: 2em">進周禮全解葢别自一人字與剛中名偶同或混</span>  
<span style="margin-left: 2em">而一之非也剛中所著易解十五卷見於陳振孫</span>  
<span style="margin-left: 2em">書錄解題宋史藝文志者卷目並合惟乾坤二卦</span>  
<span style="margin-left: 2em">及繫辭以下原闕不解振孫以爲或於乾坤之際</span>  
<span style="margin-left: 2em">有所避然其自序有云自屯蒙而往以象求爻因</span>  
<span style="margin-left: 2em">爻識卦萬一見其髣髴則沿流尋源乾坤之微可</span>  
<span style="margin-left: 2em">得而探據此則振孫之言非也自序有云伊川易</span>  
<span style="margin-left: 2em">傳漢上易傳二書頗彌縫於象義之間但易道廣</span>  
<!-- 册1 葉289a　Page:文淵閣四庫全書_0001冊.djvu/122 -->
<span style="margin-left: 2em">大有可窺之餘吾則窺之窺餘之名葢取諸此明</span>  
<span style="margin-left: 2em">初文淵閣書目葉盛綠竹堂書目尚著於錄其後</span>  
<span style="margin-left: 2em">傳本殆絶朱𢑴尊經義考亦以爲未見惟永樂大</span>  
<span style="margin-left: 2em">典尚存其文今採掇裒輯依經編次其七卦爲原</span>  
<span style="margin-left: 2em">本所闕者則但錄經文或其說别見他書者亦蒐</span>  
<span style="margin-left: 2em">錄補入依仿原目仍定爲十五卷自唐以王弼注</span>  
<span style="margin-left: 2em">定爲正義於是學易者專言名理惟李鼎祚集解</span>  
<span style="margin-left: 2em">不主弼義博採諸家以爲刋輔嗣之野文補康成</span>  
<span style="margin-left: 2em">之逸象而當時經生不能盡從其學宋儒若胡瑗</span>  
<!-- 册1 葉289b　Page:文淵閣四庫全書_0001冊.djvu/122 -->
<span style="margin-left: 2em">程子其言理精粹自非晉唐諸儒所可及然於象</span>  
<span style="margin-left: 2em">亦多有缺畧剛中是書始兼取漢學凡荀爽虞翻</span>  
<span style="margin-left: 2em">干寶蜀才九家之說皆參互考稽不主一家其解</span>  
<span style="margin-left: 2em">義間異先儒而亦往往有當於理如訟之九二以</span>  
<span style="margin-left: 2em">不克訟歸爲句而逋其邑人三百戸爲句以爲聖</span>  
<span style="margin-left: 2em">人所以必使逋其邑人三百戸者恐其恃衆憑險</span>  
<span style="margin-left: 2em">以成亂所以謹上下之分也比之初六終來有它</span>  
<span style="margin-left: 2em">吉朱子謂不可曉剛中以爲相比之道以信爲先</span>  
<span style="margin-left: 2em">積之旣久昔之未比者皆自外至故曰有它吉皆</span>  
<!-- 册1 葉292a　Page:文淵閣四庫全書_0001冊.djvu/123 -->
<span style="margin-left: 2em">能自出新意不爲成說所拘至於解泰之九二大</span>  
<span style="margin-left: 2em">有之大象議論尤正大精切通於治體雖其人因</span>  
<span style="margin-left: 2em">秦檜以進身依附和議捐棄舊疆頗不見滿於公</span>  
<span style="margin-left: 2em">論然闡發經義則具有理解要爲說易家所不廢</span>  
<span style="margin-left: 2em">也</span>  
易璇璣三卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">宋吳沆撰沆字德遠臨川人紹興十六年與其弟</span>  
<span style="margin-left: 2em">澥詣行在獻書澥所獻曰宇内辨曰歴代疆域志</span>  
<span style="margin-left: 2em">沆所獻曰易璇璣曰三墳訓義澥書皆不傳沆三</span>  
<!-- 册1 葉292b　Page:文淵閣四庫全書_0001冊.djvu/123 -->
<span style="margin-left: 2em">墳訓義爲太學博士王之望所駁亦不傳惟此書</span>  
<span style="margin-left: 2em">僅存凡爲論二十有七曰法天曰通六子曰貴中</span>  
<span style="margin-left: 2em">曰初上定位曰六九定名曰天地變卦曰論變有</span>  
<span style="margin-left: 2em">四曰有象曰求彖曰明位曰明君道曰明君子曰</span>  
<span style="margin-left: 2em">論養曰論刑曰論伐曰辨聖曰辨内外曰辨吉凶</span>  
<span style="margin-left: 2em">曰通卦曰通象曰通爻曰通詞曰通證曰釋卦曰</span>  
<span style="margin-left: 2em">釋繫曰存互體曰廣演每九篇爲一卷自序謂上</span>  
<span style="margin-left: 2em">卷明天理之自然中卷講人事之修下卷備傳疏</span>  
<span style="margin-left: 2em">之失其大㫖主於觀彖因彖而求之卦求之象求</span>  
<!-- 册1 葉293a　Page:文淵閣四庫全書_0001冊.djvu/123 -->
<span style="margin-left: 2em">之爻其曰璇璣者取王弼易畧例明彖篇處璇璣</span>  
<span style="margin-left: 2em">以觀大運語也胡一桂稱沆尚有易禮圖說有或</span>  
<span style="margin-left: 2em">問六條圖說十二軸今未見其書殆亦散佚惟其</span>  
<span style="margin-left: 2em">環溪詩話爲人所記者尚載永樂大典中今别著</span>  
<span style="margin-left: 2em">錄於集部云</span>  
易變體義十二卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋都絜撰絜字聖與丹陽人紹興中官吏部郞中</span>  
<span style="margin-left: 2em">知德慶府絜父郁字子文嘗爲惠州教官平生留</span>  
<span style="margin-left: 2em">心易學絜因以所聞於父者爲是書大㫖謂卦爻</span>  
<!-- 册1 葉293b　Page:文淵閣四庫全書_0001冊.djvu/123 -->
<span style="margin-left: 2em">辭義先儒之論巳詳故專明變體今考左傳載周</span>  
<span style="margin-left: 2em">易諸占所謂某卦之某卦者凡十事似乎因其動</span>  
<span style="margin-left: 2em">爻隨機斷義不必盡易之本㫖然王子伯廖論鄭</span>  
<span style="margin-left: 2em">公子曼滿稱其在周易豐之離游吉論楚子稱周</span>  
<span style="margin-left: 2em">易有之在復之頤曰迷復凶荀首論邲之戰稱周</span>  
<span style="margin-left: 2em">易有之在師之臨曰師出以律否臧凶蔡墨論龍</span>  
<span style="margin-left: 2em">見于絳稱周易有之在乾之姤曰潛龍勿用其同</span>  
<span style="margin-left: 2em">人曰見龍在田其大有曰飛龍在天其夬曰亢龍</span>  
<span style="margin-left: 2em">有悔其坤曰見羣龍无首吉坤之剝曰龍戰于野</span>  
<!-- 册1 葉296a　Page:文淵閣四庫全書_0001冊.djvu/124 -->
<span style="margin-left: 2em">云云皆未嘗卜筮而咸稱變體知古來周易原有</span>  
<span style="margin-left: 2em">此一義矣但古書散佚其說不傳而絜以義理揣</span>  
<span style="margin-left: 2em">摩求其崖畧其中巧相符合者如坤之初六履霜</span>  
<span style="margin-left: 2em">堅冰至則曰此坤之復也月令孟冬水始冰仲冬</span>  
<span style="margin-left: 2em">冰益壯始則薄而未堅壯則堅而難泮故爻曰履</span>  
<span style="margin-left: 2em">霜以坤爲十月之卦又曰堅冰至者則變體爲復</span>  
<span style="margin-left: 2em">乃十一月卦也家人上九有孚威如終吉則曰此</span>  
<span style="margin-left: 2em">家人之旣濟也雜卦曰旣濟定也彖曰正家而天</span>  
<span style="margin-left: 2em">下定天下之本在國國之本在家家之本在身反</span>  
<!-- 册1 葉296b　Page:文淵閣四庫全書_0001冊.djvu/124 -->
<span style="margin-left: 2em">身而誠孰敢不聽父子夫婦兄弟莫不安分循理</span>  
<span style="margin-left: 2em">而天下化之無事而定矣故變體爲旣濟而曰有</span>  
<span style="margin-left: 2em">孚威如反身之謂也如此之類皆不事傅會而自</span>  
<span style="margin-left: 2em">然貫通立義亦皆正大亦有涉於牽强者如家人</span>  
<span style="margin-left: 2em">六四富家大吉則曰此乾之同人也自道以觀身</span>  
<span style="margin-left: 2em">家皆爲我累而况富乎其有家也姑以同乎人而</span>  
<span style="margin-left: 2em">巳不以家爲累也其家之富亦以同乎人而巳不</span>  
<span style="margin-left: 2em">以富爲累也蓋極高明而道中庸所以爲中人法</span>  
<span style="margin-left: 2em">凡如此類則務爲穿鑿以求合乎卦變之說而義</span>  
<!-- 册1 葉297a　Page:文淵閣四庫全書_0001冊.djvu/124 -->
<span style="margin-left: 2em">亦不醇又多引老莊之辭以釋文周之經則又王</span>  
<span style="margin-left: 2em">弼韓康伯之流弊一變而爲王宗傳楊簡者矣然</span>  
<span style="margin-left: 2em">宋人遺籍傳者日稀是書雖瑜不掩瑕亦瑕不掩</span>  
<span style="margin-left: 2em">瑜分别觀之以備言變體之一家亦無不可也宋</span>  
<span style="margin-left: 2em">志作十六卷玉海引續書目曰自乾之姤至未濟</span>  
<span style="margin-left: 2em">之解以意演之爻爲一篇凡三百八十四篇馮椅</span>  
<span style="margin-left: 2em">易學附錄曰都氏易先以理而次以象義每卦終</span>  
<span style="margin-left: 2em">又有統論今考永樂大典所載爻義皆分載於各</span>  
<span style="margin-left: 2em">爻之下而無所謂卦終之統論與玉海合意應麟</span>  
<!-- 册1 葉297b　Page:文淵閣四庫全書_0001冊.djvu/124 -->
<span style="margin-left: 2em">所見卽輯永樂大典時所據之本巳非其全矣今</span>  
<span style="margin-left: 2em">永樂大典又缺豫隨大畜大壯睽蹇中孚等七卦</span>  
<span style="margin-left: 2em">及晉卦之後四爻謹裒合排比編爲十二卷又其</span>  
<span style="margin-left: 2em">書單明爻義不及彖與大小象故經文亦不全載</span>  
<span style="margin-left: 2em">從絜之舊焉</span>  
周易經傳集解三十六卷<sub class="note-yuan">浙江朱𢑴尊家曝書亭藏本</sub>  
<span style="margin-left: 2em">宋林栗撰栗字黃中福淸人紹興十二年進士官</span>  
<span style="margin-left: 2em">至兵部侍郞與朱子論易及西銘不合遂上疏論</span>  
<span style="margin-left: 2em">朱子時太常博士葉適侍御史胡晉臣皆助朱子</span>  
<!-- 册1 葉300a　Page:文淵閣四庫全書_0001冊.djvu/125 -->
<span style="margin-left: 2em">劾栗因罷知泉州又移明州卒諡簡肅事蹟具宋</span>  
<span style="margin-left: 2em">史本傳是書淳熙十二年四月嘗進於朝首列進</span>  
<span style="margin-left: 2em">書表貼黃勅諭各一道栗自序一篇貼黃稱本名</span>  
<span style="margin-left: 2em">周易爻象序雜指解後以未能該舉彖詞繫詞文</span>  
<span style="margin-left: 2em">言說卦乃改今名王應麟玉海稱其書經傳三十</span>  
<span style="margin-left: 2em">二卷繫詞上下二卷文言說卦序襍本文共一卷</span>  
<span style="margin-left: 2em">河圖洛書八卦九疇大衍總會圖六十四卦立成</span>  
<span style="margin-left: 2em">圖大衍揲蓍解共一卷與今本合當時與朱子所</span>  
<span style="margin-left: 2em">爭者今不可考朱子語類中惟載論繫辭一條謂</span>  
<!-- 册1 葉300b　Page:文淵閣四庫全書_0001冊.djvu/125 -->
<span style="margin-left: 2em">栗以太極生兩儀包四象四象包八卦與聖人所</span>  
<span style="margin-left: 2em">謂生者意思不同其餘則無所排斥朱彝尊經義</span>  
<span style="margin-left: 2em">考引董眞卿之言謂其說每卦必兼互體約象覆</span>  
<span style="margin-left: 2em">卦爲太泥時楊敬仲有易論黃中有易解或曰黃</span>  
<span style="margin-left: 2em">中文字可毁朱子曰却是楊敬仲文字可毁是朱</span>  
<span style="margin-left: 2em">子併不欲廢其書考陳振孫書錄解題稱其與朱</span>  
<span style="margin-left: 2em">侍講有違言以論易不合今以事理推之於時朱</span>  
<span style="margin-left: 2em">子負盛名駸駸嚮用而栗之登第在朱子前七年</span>  
<span style="margin-left: 2em">旣以前輩自居又朱子方除兵部郞中而栗爲兵</span>  
<!-- 册1 葉301a　Page:文淵閣四庫全書_0001冊.djvu/125 -->
<span style="margin-left: 2em">部侍郞正其所屬詞色相軋兩不肯下遂互激而</span>  
<span style="margin-left: 2em">成訐奏葢其釁始於論易而其故不全由於論易</span>  
<span style="margin-left: 2em">故振孫云然後人以朱子之故遂廢栗書似非朱</span>  
<span style="margin-left: 2em">子意矣經義考又曰福淸林黃中金華唐與政皆</span>  
<span style="margin-left: 2em">博通經學而一糾朱子一爲朱子所糾其所著經</span>  
<span style="margin-left: 2em">說學者遂置而不問與政之書無復存者黄中雖</span>  
<span style="margin-left: 2em">有易解而流傳未廣恐後冺没然當黃中旣没勉</span>  
<span style="margin-left: 2em">齋黃氏爲文祭之其畧曰嗟哉我公受天勁氣爲</span>  
<span style="margin-left: 2em">時直臣玩羲經之爻象究筆削於𫉬麟至其立朝</span>  
<!-- 册1 葉301b　Page:文淵閣四庫全書_0001冊.djvu/125 -->
<span style="margin-left: 2em">正色苟咈吾意雖當世大儒或見排斥苟異吾趨</span>  
<span style="margin-left: 2em">雖前賢篤論亦不樂於因循規公之過而公之近</span>  
<span style="margin-left: 2em">仁者抑可見矣論者固不以一𤯝而掩其大醇也</span>  
<span style="margin-left: 2em">勉齋爲文公高弟而好惡之公推許之至若是然</span>  
<span style="margin-left: 2em">則黃中之易其可不傳鈔乎持論頗爲平允昔劉</span>

<span style="margin-left: 2em">二書爲史家所重而經術亦頗究心髙斯得恥堂</span>  
<span style="margin-left: 2em">存稿有學易編誦詩訓二書跋曰秀巖先生近世</span>  
<span style="margin-left: 2em">大儒也世徒見其論著藏於明堂石室金匱玉版</span>  
<span style="margin-left: 2em">遂以良史目之不知先生中年以後窮極道奥經</span>

<span style="margin-left: 2em">元初俞琰所鈔後有琰跋曰此書係借聞德坊周</span>  
<span style="margin-left: 2em">家書肆所鬻者天寒日短老眼昏花併日而鈔其</span>  
<span style="margin-left: 2em">可取者云云蓋所存不及十之一矣然琰邃於易</span>  
<span style="margin-left: 2em">學凡所採摭皆其英華則大旨猶可槩見也心傳</span>  
<span style="margin-left: 2em">自序稱採王氏張子程子與朱文公四家之傳而</span>  
<span style="margin-left: 2em">間以周子邵子及先君子之說補之自唐以上諸</span>  
<span style="margin-left: 2em">儒字義之巽者亦附見焉而琰跋所列則無周子</span>  
<span style="margin-left: 2em">邵子而有郭子和子和郭雍之字卽著郭氏傳家</span>

<span style="margin-left: 2em">邵子皇極經世雖皆闡易理而實於易外别自爲</span>  
<span style="margin-left: 2em">說可以引爲義疏者少惟郭雍依經闡義具有成</span>

<span style="margin-left: 2em">宋趙以夫撰以夫字用父宗室子居於長樂嘉定</span>  
<span style="margin-left: 2em">十年進士歴官資政殿學士是書前有以夫自序</span>  
<span style="margin-left: 2em">皆自稱臣末有不敢自秘將以進於上庶幾仰裨</span>  
<span style="margin-left: 2em">聖學緝熈之萬一則經進之本也考趙汝騰庸齋</span>

<span style="margin-left: 2em">集有繳趙以夫不當爲史館修撰奏劄曰鄭淸以</span>

<span style="margin-left: 2em">可進史乎其後聞爲史館長人又笑曰是昔代筆</span>  
<span style="margin-left: 2em">進易之以夫也又何喬遠閩書曰以夫作易通莆</span>  
<span style="margin-left: 2em">田黃績相與上下其論據其所說則是書實出黃</span>

<span style="margin-left: 2em">曰聚樂堂書目作六卷蓋宋志連或問類例圖象</span>

<span style="margin-left: 2em">言之聚樂堂本則惟有易通此本亦止六卷而無</span>  
<span style="margin-left: 2em">或問類例圖象其自聚樂堂本傳寫與其書大旨</span>  
<span style="margin-left: 2em">在以不易變易二義明人事動靜之凖故其說曰</span>  
<span style="margin-left: 2em">奇偶七八也交重九六也卦畫七八不易也爻書</span>

<span style="margin-left: 2em">雖變易而中有不易是謂之貞洪範占用二貞悔</span>

<span style="margin-left: 2em">無所逃於天地之間於聖人作易之㫖可謂深切</span>

<span style="margin-left: 2em">著明至其眞出於誰手則傳疑可矣</span>  
易象意言一卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋蔡淵撰淵字伯靜號節齋建陽人蔡元定之子</span>  
<span style="margin-left: 2em">而從學於朱子故是書闡發名理多本師傳然兼</span>  
<span style="margin-left: 2em">數而言則又西山之家學也其中惟不廢互體與</span>  
<span style="margin-left: 2em">朱子之說頗異考互體之法見於左傳莊公二十</span>  
<span style="margin-left: 2em">二年陳侯筮遇觀之否曰風爲天于土上山也杜</span>  
<span style="margin-left: 2em">預註曰自二至四有艮象艮爲山也是周官太⺊</span>  
<span style="margin-left: 2em">舊有是法矣顧炎武日知錄曰朱子本義不取互</span>

<span style="margin-left: 2em">體之說惟大壯六五云卦體似兌有羊象焉不言</span>  
<span style="margin-left: 2em">互而言似此又剏先儒所未有不如言互體矣然</span>  
<span style="margin-left: 2em">則朱子特不以互體爲主亦未嘗竟謂無是理也</span>  
<span style="margin-left: 2em">淵於師說可謂通其變而酌其平矣董眞<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">周易</span>  
<span style="margin-left: 2em">會通稱淵周易經傳訓解外又有卦爻辭旨論六</span>  
<span style="margin-left: 2em">十四卦大義易象意言襍論卦爻十翼象數餘論</span>  
<span style="margin-left: 2em">襍論易大義並成於開禧乙丑今悉散佚故朱彞</span>  
<span style="margin-left: 2em">尊經義考僅列其書名而不能舉其卷數惟此書</span>  
<span style="margin-left: 2em">載永樂大典中尚首尾完具蓋當時祕府舊本今</span>

<span style="margin-left: 2em">錄而傳之俾論易者知蔡氏之學不徒以術數見</span>  
<span style="margin-left: 2em">而朱子之徒亦未嘗全棄古義焉</span>

<span style="margin-left: 2em">宋蔡淵撰案朱彞尊經義考蔡淵周易經傳訓解</span>  
<span style="margin-left: 2em">四卷註曰存三卷此本惟存上下經二卷題曰周</span>  
<span style="margin-left: 2em">易卦爻經傳訓解與彞尊所記不符據董眞<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">周</span>  
<span style="margin-left: 2em">易會通稱此書以大象置卦辭下以彖傳置大象</span>  
<span style="margin-left: 2em">後以小象置各爻辭後皆低一字以别卦爻與此</span>  
<span style="margin-left: 2em">本體例相合知非贋託眞<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">又言其繫詞文言說</span>

<span style="margin-left: 2em">卦序卦雜卦亦皆低一字則此本無之又經義考</span>  
<span style="margin-left: 2em">載淵弟沈後序稱易有太極之說知至知終之義</span>  
<span style="margin-left: 2em">正直義方之語皆義理之大原爲後學之至要實</span>  
<span style="margin-left: 2em">發前賢之所未發云云其文皆在繫辭文言則是</span>  
<span style="margin-left: 2em">書原解繫辭文言諸篇非但解卦爻<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">有明證不</span>  
<span style="margin-left: 2em">應揭卦爻以標目蓋眞<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">所見者四卷全本彞尊</span>  
<span style="margin-left: 2em">所見佚其一卷此本又佚其一卷傳寫者諱其殘</span>  
<span style="margin-left: 2em">缺因於書名增入卦爻二字若原本但解上下經</span>  
<span style="margin-left: 2em">者此書賈作僞之技不足據也今刪去卦爻二字</span>

<span style="margin-left: 2em">仍以本名著錄存其眞焉</span>

<span style="margin-left: 2em">宋魏了翁撰了翁字華父號鶴山臨卭人慶元五</span>  
<span style="margin-left: 2em">年進士官至資政殿大學士參知政事僉書樞密</span>  
<span style="margin-left: 2em">院事事迹具宋史本傳了翁以說經者但知誦習</span>  
<span style="margin-left: 2em">成言不能求之詳博因取諸經註疏之文據事别</span>  
<span style="margin-left: 2em">類而錄之謂之九經要義此其中之第一部也方</span>  
<span style="margin-left: 2em">囘桐江集有周易集義跋載了翁嘗言辭變象占</span>  
<span style="margin-left: 2em">易之綱領而繇彖象爻之辭畫爻位虛之别互反</span>

<span style="margin-left: 2em">飛伏之說乘承比應之例有不知則義理闕焉蓋</span>  
<span style="margin-left: 2em">其大㫖主於以象數求義理折衷於漢學宋學之</span>  
<span style="margin-left: 2em">間故是編所錄雖止於注疏釋文而採掇謹嚴别</span>  
<span style="margin-left: 2em">裁精審可謂剪除枝蔓獨擷英華王褘襍說云孔</span>  
<span style="margin-left: 2em">頴達作九經正義往往援引緯書之說歐陽公常</span>  
<span style="margin-left: 2em">欲刪而去之其言不果行迨鶴山魏氏作要義始</span>  
<span style="margin-left: 2em">加黜削而其言絶焉則亦甚與以廓淸之功矣明</span>  
<span style="margin-left: 2em">萬歴中張萱重編内閣書目載九經要義尚存儀</span>  
<span style="margin-left: 2em">禮七冊禮記三冊周易二冊尚書一冊春秋二冊</span>

<span style="margin-left: 2em">取濓洛以來諸大儒易說爲周易集義則爲二書</span>

東谷易翼傳二卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">宋鄭汝諧撰汝諧字舜舉號東谷處州人陳振孫</span>  
<span style="margin-left: 2em">書錄解題云仕至吏部侍郞浙江通志則云中教</span>  
<span style="margin-left: 2em">官科遷知信州召爲考功郞累階徽猷閣待制振</span>  
<span style="margin-left: 2em">孫去汝諧世近疑通志失之其言易宗程子之說</span>  
<span style="margin-left: 2em">所謂翼傳者翼程傳也然亦時有異同其最甚者</span>  
<span style="margin-left: 2em">如程子解艮其背不𫉬其身行其庭不見其人以</span>  
<span style="margin-left: 2em">爲外物不接内欲不萌郭忠恕得其說而守之遂</span>  
<span style="margin-left: 2em">自號兼山以是爲儒者之至學也朱子所解雖微</span>  
<!-- 册1 葉365b　Page:文淵閣四庫全書_0001冊.djvu/141 -->
<span style="margin-left: 2em">異然亦以是爲克已復禮之義獨汝諧以爲艮其</span>  
<span style="margin-left: 2em">背者所謂不見可欲使心不亂也不見而後不亂</span>  
<span style="margin-left: 2em">見則亂矣故僅爲无咎而巳說者或大其事以爲</span>  
<span style="margin-left: 2em">聖人之事非也所見迥乎相左又如解困井諸卦</span>  
<span style="margin-left: 2em">其說亦别然朱子解經於程子亦多所改定蓋聖</span>  
<span style="margin-left: 2em">賢精義愈闡愈深沈潛先儒之說其有合者疏通</span>  
<span style="margin-left: 2em">之其未合於心者别抒所見以發明之於先儒乃</span>  
<span style="margin-left: 2em">爲有功是固不必守一先生之言徒爲門戸之見</span>  
<span style="margin-left: 2em">也是書前有自序及其子如岡曾孫陶孫題語如</span>

<span style="margin-left: 2em">宋朱鑑編案朱子世系朱子三子長曰塾塾二子</span>  
<span style="margin-left: 2em">長曰鑑則朱子嫡長孫也鑑字子明以廕補廸功</span>  
<span style="margin-left: 2em">郞官至湖廣總領朱子注易之書爲目有五曰易</span>  
<span style="margin-left: 2em">傳十一卷曰易本義十二卷曰易學啟䝉三卷曰</span>  
<span style="margin-left: 2em">古易音訓二卷曰蓍卦考悞一卷皆有成帙其朋</span>  
<span style="margin-left: 2em">友論難與及門之辨說則散見語錄中鑑彚而葺</span>  
<span style="margin-left: 2em">之以成是編昔鄭元箋註諸經其孫魏侍中小同</span>

<span style="margin-left: 2em">復裒其門人問答之詞爲鄭志十一卷鑑之編輯</span>  
<span style="margin-left: 2em">緒言亦猶此例也考朱子初作易傳用王弼本後</span>  
<span style="margin-left: 2em">作易本義始用呂祖謙本易傳宋志著錄今已散</span>  
<span style="margin-left: 2em">佚當理宗以後朱子之學大行賸語殘編無不奉</span>  
<span style="margin-left: 2em">爲球璧不應手成巨帙反至無傳殆以未定之說</span>
