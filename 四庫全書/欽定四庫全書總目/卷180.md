<span style="margin-left: 2em">明張愼言撰愼言字金銘號藐山千頃堂書目作</span>  
<span style="margin-left: 2em">號藐姑疑其自號藐姑山人而稱者各省其文也</span>  
<span style="margin-left: 2em">陽城人萬厯庚戌進士官至南京吏部尙書事迹</span>  
<span style="margin-left: 2em">具明史本傳初愼言官御史時以論三案謫戍肅</span>  
<span style="margin-left: 2em">州撰悔草後官刑部侍郞時讞獄失旨罷官家居</span>  
<span style="margin-left: 2em">著泊水詩文集皆已散落此集僅存奏疏三首餘</span>  
<span style="margin-left: 2em">皆序記及雜著卷首有康熙庚辰陳廷敬序謂愼</span>

<span style="margin-left: 2em">明馬之駿撰之駿字仲良新野人萬厯庚戌進士</span>

<span style="margin-left: 2em">季年文體漸變竟陵鍾惺譚元春倡尖新幽冷之</span>  
<span style="margin-left: 2em">派以詩歸一編易天下之耳目之駿於惺爲同年</span>  
<span style="margin-left: 2em">亦與王稺登之子留造作新聲務以鮮警秀異相</span>  
<span style="margin-left: 2em">倡和均别派也鍾譚之名最盛後來受詬亦至深</span>  
<span style="margin-left: 2em">之駿與留名不甚盛故所作亦如花香草媚不久</span>

東極篇<sub class="note-yuan">無卷數　浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明文翔鳳撰翔鳳有太微經已著錄是集皆官萊</span>  
<span style="margin-left: 2em">陽令時所作嘗自製五嶽冠並以五嶽爲號東極</span>  
<span style="margin-left: 2em">亦其號也故以之名篇是集不分卷數詩總目曰</span>  
<span style="margin-left: 2em">海雲集文總目曰日門稿其中子目有所謂蓬萊</span>  
<span style="margin-left: 2em">詩者以登州之蓬萊閣也日華詩者以聽訟之日</span>  
<span style="margin-left: 2em">華堂也九靑詩者以遊大澤山遂易大澤爲九靑</span>  
<span style="margin-left: 2em">也入院詩者奉檄入棘闈前後題詠也詩文率多</span>

<span style="margin-left: 2em">辛酉壬戌行卷此特其中一種大抵墨守七子流</span>

<span style="margin-left: 2em">啓𩔖之中分宰執翰林諸門已可不必乃又列交</span>  
<span style="margin-left: 2em">際通用之門殆近𩔖書昭明文選之分𩔖與杜詩</span>

<span style="margin-left: 2em">兆璜刻集時所附入也</span>

<span style="margin-left: 2em">萬厯癸丑進士官至提督四譯館少<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">是編乃志</span>

<span style="margin-left: 2em">明陳文濤撰文濤字濤生廣濟人是集凡論六卷</span>  
<span style="margin-left: 2em">經解二卷史議二卷子畧一卷書序傳記誌林各</span>  
<span style="margin-left: 2em">一卷詩二卷前有自序及徵古堂書目序列生平</span>  
<span style="margin-left: 2em">著述凡七十五卷謂諸書編輯成帙貲貧務謬不</span>  
<span style="margin-left: 2em">能悉以問世僅梓其畧云云卽四卷至十一卷是</span>  
<span style="margin-left: 2em">也</span>

<span style="margin-left: 2em">明董應揚撰應揚字于廷武進人官翰林院待詔</span>
