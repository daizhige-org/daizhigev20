## 欽定四庫全書總目 卷一百七十七　集部三十　別集類存目四

欽定四庫全書總目卷一百七十七  
<span style="margin-left: 1em">集部三十</span>  
<span style="margin-left: 2em">别集類存目四</span>  
少鶴詩集八卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明武岡王顯槐撰顯槐楚端王榮㳦第三子愍王</span>  
<span style="margin-left: 2em">顯榕之弟嘉靖十七年封榮㳦嘗自稱黃鶴道人</span>  
<span style="margin-left: 2em">故顯槐自號曰少鶴嘉靖乙巳顯榕爲其世子英</span>  
<span style="margin-left: 2em">燿所弑世宗命顯槐攝國事事迹附見明史楚王</span>  
<span style="margin-left: 2em">植傳此集乃其解政後所自編也千頃堂書目載</span>  
<!-- 册4 葉2869b　Page:文淵閣四庫全書_0004冊.djvu/722 -->
<span style="margin-left: 2em">顯槐尚有文集及續集八卷今未之見惟此集存</span>  
雁湖釣叟自在吟九卷附錄一卷<sub class="note-yuan">浙江孫仰曾家藏本</sub>  
<span style="margin-left: 2em">明王周撰周字質齋嘉興人屢試不售自號雁湖</span>  
<span style="margin-left: 2em">釣叟是集以年月先後編次其詩皆率意直書不</span>  
<span style="margin-left: 2em">拘格律故名曰自在吟末附錄同時題贈一卷并</span>  
<span style="margin-left: 2em">前序後䟦皆稱其子爲觀察而不著其名據王錫</span>  
<span style="margin-left: 2em">命張大忠等題詞咸自稱年姪證以太學題名碑</span>  
<span style="margin-left: 2em">所載知其子乃嘉靖乙未進士王俸後官至都御</span>  
<span style="margin-left: 2em">史是編前四卷所稱北上寓京諸詩卽俸官京師</span>  
<!-- 册4 葉2872a　Page:文淵閣四庫全書_0004冊.djvu/723 -->
<span style="margin-left: 2em">迎養時作也</span>  
十岳山人詩集四卷<sub class="note-yuan">浙江孫仰曾家藏本</sub>  
<span style="margin-left: 2em">明王寅撰寅字仲房一字亮卿歙縣人嘗北走大</span>  
<span style="margin-left: 2em">梁問詩於李夢陽中年習禪事古峰和尚古峰曰</span>  
<span style="margin-left: 2em">吾徧遊海内五岳今將徧厯海外五岳而後出世</span>  
<span style="margin-left: 2em">寅聞其語而悅之因自號十岳山人是集寅所自</span>  
<span style="margin-left: 2em">編其詩音節宏亮皆步趨北地之派而鑄語未堅</span>  
<span style="margin-left: 2em">時多累句</span>  
邊仲子詩一卷<sub class="note-yuan">山東巡撫採進本</sub>  
<!-- 册4 葉2872b　Page:文淵閣四庫全書_0004冊.djvu/723 -->
<span style="margin-left: 2em">明邊習撰習字仲學濟南人戸部尚書貢之次子</span>  
<span style="margin-left: 2em">王士禎論詩絶句所謂不及尚書有邊習猶傳林</span>  
<span style="margin-left: 2em">雨忽沾衣者是也貢雖仕宦顯達而圖籍以外無</span>  
<span style="margin-left: 2em">餘資習竟貧困以沒僅存其七十歲客孫氏時詩</span>  
<span style="margin-left: 2em">一卷本名睡足軒集士禎與徐夜共選定之附刻</span>  
<span style="margin-left: 2em">其父詩集後改題今名習詩遠不及其父尤多應</span>  
<span style="margin-left: 2em">俗之作其輓李東陽二詩論雖公而評太訐亦乖</span>  
<span style="margin-left: 2em">詩品夜等特以名父之子重之耳</span>  
世經堂集二十六卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<!-- 册4 葉2873a　Page:文淵閣四庫全書_0004冊.djvu/723 -->
<span style="margin-left: 2em">明徐階撰階所編武穆集已著錄是集文二十四</span>  
<span style="margin-left: 2em">卷賦頌詩詞二卷其中敷陳治體之文皆能不詭</span>  
<span style="margin-left: 2em">於正餘則未見所長</span>  
少湖文集七卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明徐階撰是集乃階外謫延平府推官時三年秩</span>  
<span style="margin-left: 2em">滿北上延平士人裒其前後諸作爲之付梓凡文</span>  
<span style="margin-left: 2em">五卷語錄一卷詩一卷大都應酬之文十居六七</span>  
<span style="margin-left: 2em">皆不足以傳特用誌遺愛云爾</span>  
歐陽南野集三十卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<!-- 册4 葉2873b　Page:文淵閣四庫全書_0004冊.djvu/723 -->
<span style="margin-left: 2em">明歐陽德撰德字崇一泰和人嘉靖癸未進士官</span>  
<span style="margin-left: 2em">至禮部尚書卒諡文莊事迹具明史儒林傳是集</span>  
<span style="margin-left: 2em">爲其門人王宗沐所編凡内集十卷皆講學之文</span>  
<span style="margin-left: 2em">外集六卷皆應制及章奏案牘之文別集十四卷</span>  
<span style="margin-left: 2em">則應俗之詩文也德之學宗法姚江故惟以提唱</span>  
<span style="margin-left: 2em">良知者爲内而餘則外之別之云</span>  
南野文選四卷<sub class="note-yuan">江西巡撫採進本</sub>  
<span style="margin-left: 2em">明歐陽德撰此本爲隆慶中其門人馮惟訥等所</span>  
<span style="margin-left: 2em">編於全集僅十分取一然德在朝著述如建儲災</span>  
<!-- 册4 葉2876a　Page:文淵閣四庫全書_0004冊.djvu/724 -->
<span style="margin-left: 2em">異諸疏皆能言人所不能言而是編不載則惟訥</span>  
<span style="margin-left: 2em">等所錄皆講學之文故也是可以觀明儒之所尚</span>  
<span style="margin-left: 2em">矣</span>  
笠江集十二卷<sub class="note-yuan">浙江孫仰曾家藏本</sub>  
<span style="margin-left: 2em">明潘恩撰恩字子仁上海人嘉靖癸未進士官至</span>  
<span style="margin-left: 2em">左都御史諡恭定事蹟附見明史周延傳是集爲</span>  
<span style="margin-left: 2em">諸生聶叔頣所編凡賦詩五卷策表箋序碑記四</span>  
<span style="margin-left: 2em">卷說對贊誌銘祭文及襍述三卷前有陸樹聲序</span>  
<span style="margin-left: 2em">稱恩所著有笠江集笠江近稿皆已梓行旣沒而</span>  
<!-- 册4 葉2876b　Page:文淵閣四庫全書_0004冊.djvu/724 -->
<span style="margin-left: 2em">其子允哲允端合前後刻彚爲恭定全集今此本</span>  
<span style="margin-left: 2em">仍題曰笠江集殆當時編集未成故以新序冠於</span>  
<span style="margin-left: 2em">舊本歟</span>  
章介菴集十一卷<sub class="note-yuan">江西巡撫採進本</sub>  
<span style="margin-left: 2em">明章袞撰袞字汝明臨川人嘉靖癸未進士官至</span>  
<span style="margin-left: 2em">陜西按察司副使是集首載大學口義中庸口義</span>  
<span style="margin-left: 2em">各一卷皆訓釋章句之語三卷以下皆襍文十卷</span>  
<span style="margin-left: 2em">爲各體詩而以隨筆𤨏言終焉𤨏言者袞所作語</span>  
<span style="margin-left: 2em">錄也其文踈爽而頗乏體要序王臨川集幾萬言</span>  
<!-- 册4 葉2877a　Page:文淵閣四庫全書_0004冊.djvu/724 -->
<span style="margin-left: 2em">極論新法之善謂元祐若能守而不變孰非繼述</span>  
<span style="margin-left: 2em">之善又論公以瞑<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3392.svg?width=24" alt="四庫全書僻字第3392號（眩）" title="四庫全書僻字第3392號（眩）">之藥攻治之於先司馬公又</span>  
<span style="margin-left: 2em">以瞑<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3392.svg?width=24" alt="四庫全書僻字第3392號（眩）" title="四庫全書僻字第3392號（眩）">之藥潰亂之於後遂使國論屢揺民心再</span>  
<span style="margin-left: 2em">擾云云毅然翻久定之案可謂桑梓情深矣</span>  
芝園定集五十一卷別集十一卷<sub class="note-yuan">浙江汪汝瑮家藏本</sub>  
<span style="margin-left: 2em">明張時徹撰時徹有善行錄已著錄是集凡分二</span>  
<span style="margin-left: 2em">編一曰定集爲賦詩二十卷襍文二十七卷史論</span>  
<span style="margin-left: 2em">四卷一曰别集爲奏議五卷公移六卷詩文皆分</span>  
<span style="margin-left: 2em">體而律詩中又分兩京藩臬歸田三稿明史藝文</span>  
<!-- 册4 葉2877b　Page:文淵閣四庫全書_0004冊.djvu/724 -->
<span style="margin-left: 2em">志載芝園全集八十五卷考浙江通志時徹尚有</span>  
<span style="margin-left: 2em">芝園外集史蓋合而總計之然浙江通志載芝園</span>  
<span style="margin-left: 2em">定集五十六卷別集十一卷外集二十四卷與此</span>  
<span style="margin-left: 2em">卷數亦不合或定集當爲五十一卷別集當爲十</span>  
<span style="margin-left: 2em">一卷外集當爲二十四卷共八十六卷史誤八十</span>  
<span style="margin-left: 2em">六爲八十五通志誤五十一爲五十六歟其詩文</span>  
<span style="margin-left: 2em">不出常格樂府喜用古題而所擬諸篇皆舍其本</span>  
<span style="margin-left: 2em">詞而擬其增減入樂之詞未免逐影而失形史論</span>  
<span style="margin-left: 2em">尤多偏駁</span>  
<!-- 册4 葉2880a　Page:文淵閣四庫全書_0004冊.djvu/725 -->
贅疣錄九卷續錄二卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">明顧夢圭撰夢圭字武祥號雍里崑山人嘉靖癸</span>  
<span style="margin-left: 2em">未進士官至江西右布政使此集爲夢圭所自編</span>  
<span style="margin-left: 2em">同里歸有光序之末載府志列傳及有光所撰墓</span>  
<span style="margin-left: 2em">誌則其五世孫登重刋時所附入也首二卷爲就</span>  
<span style="margin-left: 2em">正編乃其讀書劄記之語上卷論五經四書下卷</span>  
<span style="margin-left: 2em">皆襍論而說經講學者居多大㫖以心學爲宗闡</span>  
<span style="margin-left: 2em">王守仁之餘緖考有光序中稱夢圭暇日以所爲</span>  
<span style="margin-left: 2em">文名之曰贅疣錄則贅疣但其文集之名不應冠</span>  
<!-- 册4 葉2880b　Page:文淵閣四庫全書_0004冊.djvu/725 -->
<span style="margin-left: 2em">於此書蘇州府志載其有北海齊梁武平還山諸</span>  
<span style="margin-left: 2em">稿集中亦不標此名意者四稿乃其詩集與就正</span>  
<span style="margin-left: 2em">編皆別行登重刋時始合爲一編而仍襲其文集</span>  
<span style="margin-left: 2em">之名歟文凡五卷詩凡四卷續錄則文一卷有竒</span>  
<span style="margin-left: 2em">而詩附焉詩文皆平正通達<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">抒胷臆無鉤章棘</span>  
<span style="margin-left: 2em">句之習惟詩有捶字未堅者蓋當有明中葉風氣</span>  
<span style="margin-left: 2em">初更學問移於姚江而文章未移於北地猶沿長</span>  
<span style="margin-left: 2em">沙舊格者也</span>  
北泉集<sub class="note-yuan">無卷數　副都御史黃登賢家藏本</sub>  
<!-- 册4 葉2881a　Page:文淵閣四庫全書_0004冊.djvu/725 -->
<span style="margin-left: 2em">明藍田撰田字玉甫號北泉卽墨人嘉靖癸未進</span>  
<span style="margin-left: 2em">士官至河南道監察御史事跡附見明史葉應驄</span>  
<span style="margin-left: 2em">傳當張璁等希㫖議大禮田反覆抗論凡七上章</span>  
<span style="margin-left: 2em">受廷杖幾殆復糾劾陳洸不法事直聲動一時今</span>  
<span style="margin-left: 2em">集中惟錄劾禮部尚書席書一疏不知何故其他</span>  
<span style="margin-left: 2em">古近體詩及書記襍文亦未分卷考千頃堂書目</span>  
<span style="margin-left: 2em">田有侍御集十卷又東歸唱和一卷則此本已非</span>  
<span style="margin-left: 2em">完書且田生平可傳者在諸諫草今章疏缺佚則</span>  
<span style="margin-left: 2em">此本非菁華所在矣</span>  
<!-- 册4 葉2881b　Page:文淵閣四庫全書_0004冊.djvu/725 -->
石比部集八卷<sub class="note-yuan">江蘇周厚堉家藏本</sub>  
<span style="margin-left: 2em">明石英中撰英中字子珍上海人嘉靖癸未進士</span>  
<span style="margin-left: 2em">官刑部主事是集凡詩三卷文四卷英在西曹以</span>  
<span style="margin-left: 2em">受誣被囚其七宣紀夢及古樂府等篇皆獄中所</span>  
<span style="margin-left: 2em">作頗磊落有氣嘗自評其文如赤手捕龍蛇蓋才</span>  
<span style="margin-left: 2em">情俊逸而未能歛才就法者也</span>  
飛鴻亭集二十卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明吳鵬撰鵬字萬里秀水人嘉靖癸未進士官至</span>  
<span style="margin-left: 2em">吏部尚書飛鴻亭者鵬謝事娛老之所因以名集</span>  
<!-- 册4 葉2884a　Page:文淵閣四庫全書_0004冊.djvu/726 -->
<span style="margin-left: 2em">千頃堂書目作十二卷此本實二十巻蓋黃虞稷</span>  
<span style="margin-left: 2em">誤倒其文也鵬常使安南故集中有征南行諸篇</span>  
<span style="margin-left: 2em">其詩文多應酬之作未能精汰後有其孫維貞䟦</span>  
<span style="margin-left: 2em">稱於奏疏外檢得若干首又云先有狀譜之作今</span>  
<span style="margin-left: 2em">是集俱不載豈尚有缺佚𫆀</span>  
葉海峰文一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明葉良佩撰良佩有周易義叢已著錄天台志稱</span>  
<span style="margin-left: 2em">良佩所著有海峰堂前稿十八卷此冊乃天一閣</span>  
<span style="margin-left: 2em">鈔本所載皆襍文僅四十二頁蓋後人所摘錄非</span>
