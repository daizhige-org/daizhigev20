## 欽定四庫全書總目 卷一百二十四　子部三十四　雜家類存目一

<!-- 册3 葉2684：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷一百二十四  
<span style="margin-left: 1em">子部三十四</span>  
<span style="margin-left: 2em">雜家類存目一</span>  
於陵子一卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">舊本題齊陳仲子撰王士禎居易錄曰萬厯間學</span>  
<span style="margin-left: 2em">士多撰僞書以欺世如天祿閣外史之類人多知</span>  
<span style="margin-left: 2em">之今類書中所刻唐韓鄂歲華紀麗乃海鹽胡震</span>  
<span style="margin-left: 2em">亨孝轅所造於陵子其友姚士粦叔祥作也凡十</span>  
<span style="margin-left: 2em">二篇一曰畏人二曰貧居三曰辭祿四曰遺益五</span>  
<!-- 册3 葉2685b　Page:文淵閣四庫全書_0003冊.djvu/676 -->
<span style="margin-left: 2em">曰人問六曰先人七曰辯窮八曰大盜九曰夢葵</span>  
<span style="margin-left: 2em">十曰巷之人十一曰未信十二曰灌園前有元鄧</span>  
<span style="margin-left: 2em">文原題詞稱前代藝文志崇文總目所無惟石廷</span>  
<span style="margin-left: 2em">尉熙明家藏又稱得之道流其說自相矛盾又有</span>  
<span style="margin-left: 2em">王鏊一引一跋鏊集均無其文其僞可驗惟沈士</span>  
<span style="margin-left: 2em">龍一跋引揚雄方言所載齊語及竹書紀年戰國</span>  
<span style="margin-left: 2em">策列女傳所載沃丁殺伊尹齊楚戰重邱及楚王</span>  
<span style="margin-left: 2em">聘仲子爲相事證爲古書共說頗巧然摭此四書</span>  
<span style="margin-left: 2em">以作僞而又援此四書以證非僞此正朱子所謂</span>  
<!-- 册3 葉2688a　Page:文淵閣四庫全書_0003冊.djvu/677 -->
<span style="margin-left: 2em">採天問作淮南子又採淮南子註天問者也士龍</span>  
<span style="margin-left: 2em">與士粦友善是葢同作僞者耳末有徐元文跋詞</span>  
<span style="margin-left: 2em">尤弇鄙則又近時書賈所増以冒稱傳是樓舊本</span>  
<span style="margin-left: 2em">者矣</span>  
天祿閣外史八卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">舊本題漢黄憲撰前有晉謝安唐田宏陸贄題詞</span>  
<span style="margin-left: 2em">每篇又有宋韓洎贊而冠以王鏊之序詞旨凡鄙</span>  
<span style="margin-left: 2em">顯岀一手朱國楨湧幢小品載徐應雷黃叔度二</span>  
<span style="margin-left: 2em">誣辨曰黃叔度言論風旨無所傳聞入明嘉靖之</span>  
<!-- 册3 葉2688b　Page:文淵閣四庫全書_0003冊.djvu/677 -->
<span style="margin-left: 2em">季崑山王舜華名逢年有高才竒癖著天祿閣外</span>  
<span style="margin-left: 2em">史託於叔度以自鳴舜華爲吾友孟肅諸大父行</span>  
<span style="margin-left: 2em">余猶及見其人知其著外史甚確自初出有纂入</span>  
<span style="margin-left: 2em">東漢文者時舜華尚在而天下謂外史出祕閣實</span>  
<span style="margin-left: 2em">黃徵君著則後世曷從核眞贋乎又李詡戒菴漫</span>  
<span style="margin-left: 2em">筆曰天祿閣外史乃近年崑山王逢年所詭託者</span>  
<span style="margin-left: 2em">邇有餘姚人御史某<sub class="note-yuan">案卽刻兩京遺編之胡維新</sub>沾沾以文學</span>  
<span style="margin-left: 2em">自喜雜此文於左國司馬諸篇中刋行頒於蘇常</span>  
<span style="margin-left: 2em">四郡學官令諸生誦習之殆亦一竒事也據其所</span>  
<!-- 册3 葉2689a　Page:文淵閣四庫全書_0003冊.djvu/677 -->
<span style="margin-left: 2em">記則此書出王逢年明人巳早言之考張孔敎雲</span>  
<span style="margin-left: 2em">谷卧餘所言亦合而流傳之本仍題黃憲殆不可</span>  
<span style="margin-left: 2em">解王龯讀書蕞殘曰其賓秦文中有黨錮一篇考</span>  
<span style="margin-left: 2em">後漢書本傳陳蕃爲三公臨朝嘆曰叔度若在吾</span>  
<span style="margin-left: 2em">不敢先佩印綬是黨禍未起憲巳謝世矣又賓晉</span>  
<span style="margin-left: 2em">文有董卓篇益不相見辨其僞迹甚明惟謂傳自</span>  
<span style="margin-left: 2em">謝安或者卽其門下士及子弟所爲則仍爲僞序</span>  
<span style="margin-left: 2em">所欺失考甚矣</span>  
化書新聲<sub class="note-yuan">無卷數　浙江巡撫採進本</sub>  
<!-- 册3 葉2689b　Page:文淵閣四庫全書_0003冊.djvu/677 -->
<span style="margin-left: 2em">明王清一撰前有序自稱先天風雷侍者且言萬</span>  
<span style="margin-left: 2em">厯壬辰自京師奏太后請武當山道藏經回止三</span>  
<span style="margin-left: 2em">公巖大衆推充都管蓋道士也是編取譚峭化書</span>  
<span style="margin-left: 2em">按節分章各爲註釋中如釋大同章思火生暖思</span>  
<span style="margin-left: 2em">水生涼諸語亦時有理解然大致摭採道家之言</span>  
<span style="margin-left: 2em">氾濫恣肆無所歸宿</span>  
心傳錄三卷日新錄一卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">宋于恕編恕張九成之甥此二書皆錄九成語也</span>  
<span style="margin-left: 2em">前有淳熙元年恕序云無垢張先生乃予母之兄</span>  
<!-- 册3 葉2692a　Page:文淵閣四庫全書_0003冊.djvu/678 -->
<span style="margin-left: 2em">頃爲春官宗伯以議忤時相一斥嶺下十四年寓</span>  
<span style="margin-left: 2em">橫浦僧舍嗜書不厭晚年目昏立短簷下展卷就</span>  
<span style="margin-left: 2em">明向暮不輟石間雙趺隱然南安守張公見而歎</span>  
<span style="margin-left: 2em">息標記於柱今猶在也案宋史九成本傳稱九成</span>  
<span style="margin-left: 2em">召除宗正少卿權禮部侍郎兼侍講兼權刑部侍</span>  
<span style="margin-left: 2em">郎謫守邵州秦檜又令司諫詹大方論其與徑山</span>  
<span style="margin-left: 2em">僧宗杲謗訕朝政謫居南安軍在南安十四年以</span>  
<span style="margin-left: 2em">橫浦集考之其到南安在癸亥三月乃紹興十三</span>  
<span style="margin-left: 2em">年其橫浦僧舍題柱字據恕此序是南安張守所</span>  
<!-- 册3 葉2692b　Page:文淵閣四庫全書_0003冊.djvu/678 -->
<span style="margin-left: 2em">記而南安府志載寶界寺題柱識語爲九成自題</span>  
<span style="margin-left: 2em">又失張守之名誤矣陳振孫書錄解題曰張九成</span>  
<span style="margin-left: 2em">無垢語錄十四卷言行編遺文共一卷九成之甥</span>  
<span style="margin-left: 2em">于恕所編心傳錄及其門人郎昱所記日新錄近</span>  
<span style="margin-left: 2em">時徐鹿卿德夫敎授南安復裒其言行繫以歲月</span>  
<span style="margin-left: 2em">及遺文三十篇附於末今此本止三卷恕序稱與</span>  
<span style="margin-left: 2em">其弟憲徒步三千餘里扺嶺下得侍講論難疑荅</span>  
<span style="margin-left: 2em">問莫不備錄名之曰心傳後恕以思親歸弟憲獨</span>  
<span style="margin-left: 2em">住各以所得合爲一集又學生郎昱粗得數語纂</span>  
<!-- 册3 葉2693a　Page:文淵閣四庫全書_0003冊.djvu/678 -->
<span style="margin-left: 2em">爲錄故人刁駿序之而後卷日新錄亦題甥于恕</span>  
<span style="margin-left: 2em">編蓋非陳振孫所謂徐鹿<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">裒集之本中間止有</span>  
<span style="margin-left: 2em">序記等文凡八篇亦與所謂三十篇者不合故仍</span>  
<span style="margin-left: 2em">舊名曰心傳曰日新而不名語錄是尚未經合訂</span>  
<span style="margin-left: 2em">者矣明人刻横浦集已收入之此其别行之本也</span>  
經鉏堂雜志八卷<sub class="note-yuan">江西巡撫採進本</sub>  
<span style="margin-left: 2em">宋倪思撰思有班馬異同已著錄是編乃其晚年</span>  
<span style="margin-left: 2em">劄記之文其學雜出於釋老務爲恬退高曠之說</span>  
<span style="margin-left: 2em">然如謂妻子無論賢不肖皆當以𡨚家視之害理</span>  
<!-- 册3 葉2693b　Page:文淵閣四庫全書_0003冊.djvu/678 -->
<span style="margin-left: 2em">殊甚其他亦皆淺陋無味明代陳繼儒一派發源</span>  
<span style="margin-left: 2em">於此又議論空疎多無根據如顔斶生王死士之</span>  
<span style="margin-left: 2em">論與安步晚食之語同出一時而思引斶前王前</span>  
<span style="margin-left: 2em">一叚附論其下曰此卽晚食以當肉安步以當車</span>  
<span style="margin-left: 2em">之顔斶耶抑别一人耶是併戰國策未讀也賈誼</span>  
<span style="margin-left: 2em">謫長沙王傅作鵬賦之後年餘而死而思謂賈誼</span>  
<span style="margin-left: 2em">陳治安之策乃在於鵩賦之後豈其涉厯世故於</span>  
<span style="margin-left: 2em">事理講明尤更深究耶是併漢書史記亦未詳考</span>  
<span style="margin-left: 2em">也宋史思本傳載陳晦草史彌遠制詞用昆命元</span>  
<!-- 册3 葉2696a　Page:文淵閣四庫全書_0003冊.djvu/679 -->
<span style="margin-left: 2em">龜語思以爲類董賢策文用允執厥中之文上疏</span>  
<span style="margin-left: 2em">爭之坐是罷去考劉克莊後村詩話稱思駁論時</span>  
<span style="margin-left: 2em">晦累疏援引唐人及宋代累朝命相皆用此語以</span>  
<span style="margin-left: 2em">駁思思遂削秩則晦雖曲貢諛詞而轉據典文思</span>  
<span style="margin-left: 2em">雖力持正論而疎於考證是書之陋固其宜矣</span>  
善誘文一卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋陳錄撰錄不知何許人自稱丹穴老人其書皆</span>  
<span style="margin-left: 2em">通俗勸善之言葢明袁黃等之所祖前有嘉定辛</span>  
<span style="margin-left: 2em">巳其弟鍊序末有木石居士虞舜徒跋皆以閻羅</span>  
<!-- 册3 葉2696b　Page:文淵閣四庫全書_0003冊.djvu/679 -->
<span style="margin-left: 2em">王爲說詞㫖頗鄙</span>  
樵談一卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">舊本題宋許棐撰棐字忱父海鹽人嘉熙中居泰</span>  
<span style="margin-left: 2em">溪于水南種梅數千樹自號梅屋是編皆勸戒之</span>  
<span style="margin-left: 2em">言然核其詞氣如出屠隆陳繼儒一輩人口殊不</span>  
<span style="margin-left: 2em">𩔖宋人之作</span>  
几上語一卷枕上語一卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">宋施淸臣撰淸臣號東洲淳祐間人自稱赤城散</span>  
<span style="margin-left: 2em">吏是書皆宗二氏之旨而以儒理附會之詞多儷</span>  
<!-- 册3 葉2697a　Page:文淵閣四庫全書_0003冊.djvu/679 -->
<span style="margin-left: 2em">偶明人小品濫觴於斯其謂易可通修煉之旨亦</span>  
<span style="margin-left: 2em">魏伯陽等之緒餘無足采錄也</span>  
千古功名鏡十二卷拾遺一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">宋吳大有撰大有字勉道號松壑嵊縣人寶祐間</span>  
<span style="margin-left: 2em">遊太學率諸生上書言賈似道姦狀不報遂退處</span>  
<span style="margin-left: 2em">林泉與林昉仇遠白珽等以詩酒相娱元初辟爲</span>  
<span style="margin-left: 2em">國子檢閱不赴是書分十五類皆闡揚因果之說</span>  
<span style="margin-left: 2em">以警世勸善然有所爲而爲之假以誘掖愚䝉則</span>  
<span style="margin-left: 2em">可若士君子之學爲所當爲則固無取於是焉</span>  
<!-- 册3 葉2697b　Page:文淵閣四庫全書_0003冊.djvu/679 -->
厚德錄四卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋李元綱撰元綱有聖門事業圖已著錄此錄盛</span>  
<span style="margin-left: 2em">陳果報兼以神怪如言張孝基以還産爲山神及</span>  
<span style="margin-left: 2em">福州張生捐資救縊遇鍾離權得道事不一而足</span>  
<span style="margin-left: 2em">殊非儒者立言之道與聖門事業圖如出兩手不</span>  
<span style="margin-left: 2em">可解也</span>  
樂善錄二卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋李昌齡撰昌齡始末未詳書中引胡仔苕溪漁</span>  
<span style="margin-left: 2em">隱叢話及葉夢得巖下放言葢紹興後人大旨皆</span>  
<!-- 册3 葉2700a　Page:文淵閣四庫全書_0003冊.djvu/680 -->
<span style="margin-left: 2em">談罪福因果所記宋事爲多亦間及漢以來事然</span>  
<span style="margin-left: 2em">如淳于棼南柯入夢諸條殊於樂善無與記小兒</span>  
<span style="margin-left: 2em">胞胎一條雜引道家符籙之說凡數百言更爲泛</span>  
<span style="margin-left: 2em">濫也</span>  
西疇常言一卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋何坦撰坦旴江人是編分講學律已應世明道</span>  
<span style="margin-left: 2em">莅官原治評古用人正獘九門大扺因舊說而衍</span>  
<span style="margin-left: 2em">之其講學篇謂性與天道子貢不得聞而以後世</span>  
<span style="margin-left: 2em">學者竊襲陳言自謂窮理盡性爲妄明道篇謂儒</span>  
<!-- 册3 葉2700b　Page:文淵閣四庫全書_0003冊.djvu/680 -->
<span style="margin-left: 2em">者之待異端甚於拒㓂敵葢皆有爲而發然其論</span>
