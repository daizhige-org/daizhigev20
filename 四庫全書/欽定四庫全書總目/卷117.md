## 欽定四庫全書總目 卷一百十七　子部二十七　雜家類一

<!-- 册3 葉2157a　Page:文淵閣四庫全書_0003冊.djvu/544 -->
欽定四庫全書總目卷一百十七  
<span style="margin-left: 1em">子部二十七</span>  
<span style="margin-left: 2em">雜家類一</span>  
<span style="margin-left: 3em">衰周之季百氏爭鳴立說著書各爲流品漢志</span>  
<span style="margin-left: 3em">所列備矣或其學不傳後無所述或其名不美</span>  
<span style="margin-left: 3em">人不肯居故絶續不同不能一槪後人著錄株</span>  
<span style="margin-left: 3em">守舊文於是墨家僅墨子晏子二書名家僅公</span>  
<span style="margin-left: 3em">孫龍子尹文子人物志三書縱横家僅鬼谷子</span>  
<span style="margin-left: 3em">一書亦别立標題自爲支𣲖此拘泥門目之過</span>  
<!-- 册3 葉2157b　Page:文淵閣四庫全書_0003冊.djvu/544 -->
<span style="margin-left: 3em">也黄虞稷千頃堂書目於寥寥不能成類者併</span>  
<span style="margin-left: 3em">入雜家雜之義廣無所不包班固所謂合儒墨</span>  
<span style="margin-left: 3em">兼名法也變而得宜於例爲善今從其說以立</span>  
<span style="margin-left: 3em">說者謂之雜學辨證者謂之雜考議論而兼叙</span>  
<span style="margin-left: 3em">述者謂之雜說旁究物理臚陳纎𤨏者謂之雜</span>  
<span style="margin-left: 3em">品類輯舊文塗兼衆軌者謂之雜纂合刻諸書</span>  
<span style="margin-left: 3em">不名一體者謂之雜編凡六類</span>  
鬻子一卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">舊本題周鬻熊撰崇文總目作十四篇高似孫子</span>  
<!-- 册3 葉2160a　Page:文淵閣四庫全書_0003冊.djvu/545 -->
<span style="margin-left: 2em">畧作十二篇陳振孫書錄解題稱陸佃所校十五</span>  
<span style="margin-left: 2em">篇此本題唐逢行珪註凡十四篇葢卽崇文總目</span>  
<span style="margin-left: 2em">所著錄也考漢書藝文志道家鬻子說二十二篇</span>  
<span style="margin-left: 2em">又小說家鬻子說十九篇是當時本有二書列子</span>  
<span style="margin-left: 2em">引鬻子凡三條皆黄老淸淨之說與今本不類疑</span>  
<span style="margin-left: 2em">卽道家二十二篇之文今本所載與賈誼新書所</span>  
<span style="margin-left: 2em">引六條文格畧同疑卽小說家之鬻子說也杜預</span>  
<span style="margin-left: 2em">左傳註稱鬻熊爲祝融十二世孫孔穎達疏謂不</span>  
<span style="margin-left: 2em">知出何書史記載鬻熊子事文王早卒其子曰熊</span>  
<!-- 册3 葉2160b　Page:文淵閣四庫全書_0003冊.djvu/545 -->
<span style="margin-left: 2em">麗熊麗生熊狂熊狂生熊繹成王時舉文武勤勞</span>  
<span style="margin-left: 2em">之後嗣受封於楚漢書載魏相奏記霍光稱文王</span>  
<span style="margin-left: 2em">見鬻子年九十餘雖所說小異然大約文武時人</span>  
<span style="margin-left: 2em">今其書乃有昔者魯周公語又有昔者魯周公使</span>  
<span style="margin-left: 2em">康叔徃守於殷語而賈誼新書亦引其成王問答</span>  
<span style="margin-left: 2em">凡五條時代殊不相及劉勰文心雕龍云鬻熊知</span>  
<span style="margin-left: 2em">道文王諮詢遺文餘事錄爲鬻子則裒輯成編不</span>  
<span style="margin-left: 2em">出熊手流傳附益或構虚詞故漢志别入小說家</span>  
<span style="margin-left: 2em">歟獨是僞四八目一書見北齊陽休之序錄凡古</span>  
<!-- 册3 葉2161a　Page:文淵閣四庫全書_0003冊.djvu/545 -->
<span style="margin-left: 2em">來帝王輔佐有數可紀者靡不具載而此書所列</span>  
<span style="margin-left: 2em">禹七大夫臯陶杜子業旣子施子黯季子甯然子</span>  
<span style="margin-left: 2em">堪輕子玉湯七大夫慶輔伊尹湟里且東門蝡南</span>  
<span style="margin-left: 2em">門蝡西門疵北門側皆具有姓名獨不見收似乎</span>  
<span style="margin-left: 2em">六朝之末尙無此本或唐以來好事之流依仿賈</span>  
<span style="margin-left: 2em">誼所引撰爲贋本亦未可知觀其標題甲乙故爲</span>  
<span style="margin-left: 2em">佚脫錯亂之狀而誼書所引則無一條之偶合豈</span>  
<span style="margin-left: 2em">非有心相避而巧匿其文使讀者互相檢驗生其</span>  
<span style="margin-left: 2em">信心歟且其篇名冗贅古無此體又每篇寥寥數</span>  
<!-- 册3 葉2161b　Page:文淵閣四庫全書_0003冊.djvu/545 -->
<span style="margin-left: 2em">言詞㫖膚淺决非三代舊文姑以流傳旣久存備</span>  
<span style="margin-left: 2em">一家耳卷首有逢行珪序及永徽四年進書表自</span>  
<span style="margin-left: 2em">署華州鄭縣尉里居未詳</span>  
墨子十五卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">舊本題宋墨翟撰考漢書藝文志墨子七十一篇</span>  
<span style="margin-left: 2em">註曰名翟宋大夫隋書經籍志亦曰宋大夫墨翟</span>  
<span style="margin-left: 2em">撰然其書中多稱子墨子則門人之言非所自著</span>  
<span style="margin-left: 2em">又諸書多稱墨子名翟周亮工書影則曰墨子姓</span>  
<span style="margin-left: 2em">翟母夢烏而生因名之曰烏以墨爲道今以姓爲</span>  
<!-- 册3 葉2164a　Page:文淵閣四庫全書_0003冊.djvu/546 -->
<span style="margin-left: 2em">名以墨爲姓是老子當姓老耶其說不著所出未</span>  
<span style="margin-left: 2em">足爲據也宋館閣書目稱墨子十五卷六十一篇</span>  
<span style="margin-left: 2em">此本篇數與漢志合卷數與館閣書目合惟七十</span>  
<span style="margin-left: 2em">一篇之中僅佚節用下第二十二節𦵏上第二十</span>  
<span style="margin-left: 2em">三節𦵏中第二十四明鬼上第二十九明鬼下第</span>  
<span style="margin-left: 2em">三十非樂中第三十三非樂下第三十四非儒上</span>  
<span style="margin-left: 2em">第三十八凡八篇尙存六十三篇與館閣書目不</span>  
<span style="margin-left: 2em">合陳振孫書錄解題又稱有一本止存十三篇者</span>  
<span style="margin-left: 2em">今不可見或後人以兩本相校互有存亡增入二</span>  
<!-- 册3 葉2164b　Page:文淵閣四庫全書_0003冊.djvu/546 -->
<span style="margin-left: 2em">篇歟抑傳寫者訛以六十三爲六十一也墨家者</span>  
<span style="margin-left: 2em">流史罕著錄葢以孟子所闢無人肯居其名然佛</span>  
<span style="margin-left: 2em">氏之教其淸淨取諸老其慈悲則取諸墨韓愈送</span>  
<span style="margin-left: 2em">浮屠文暢序稱儒名墨行墨名儒行以佛爲墨葢</span>  
<span style="margin-left: 2em">得其真而讀墨子一篇乃稱墨必用孔孔必用墨</span>  
<span style="margin-left: 2em">開後人三教歸一之說未爲篤論特在彼法之中</span>  
<span style="margin-left: 2em">能自嗇其身而時時利濟於物亦有足以自立者</span>  
<span style="margin-left: 2em">故其教得列於九流而其書亦至今不冺耳第五</span>  
<span style="margin-left: 2em">十二篇以下皆兵家言其文古奥或不可句讀與</span>  
<!-- 册3 葉2165a　Page:文淵閣四庫全書_0003冊.djvu/546 -->
<span style="margin-left: 2em">全書爲不類疑因五十一篇言公輪般九攻墨子</span>  
<span style="margin-left: 2em">九拒之事其徒因採摭其術附記於末觀其稱弟</span>  
<span style="margin-left: 2em">子禽滑𨤲等三百人巳持守固之器在宋城上是</span>  
<span style="margin-left: 2em">能傳其術之証矣</span>  
子華子二卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">舊本題晉人程本撰按程本之名見於家語子華</span>  
<span style="margin-left: 2em">子之名見於列子本非一人吕氏春秋引子華子</span>  
<span style="margin-left: 2em">者凡三見高誘以爲古體道人是秦以前原有子</span>  
<span style="margin-left: 2em">華子書然漢志已不著錄則劉向時書亡矣此本</span>  
<!-- 册3 葉2165b　Page:文淵閣四庫全書_0003冊.djvu/546 -->
<span style="margin-left: 2em">自宋南渡後始刋板於會稽晁公武以其多用字</span>  
<span style="margin-left: 2em">說指爲元豐後舉子所作朱子以其出於越中指</span>  
<span style="margin-left: 2em">爲王銍姚寛輩所託而又疑非二人所及周氏渉</span>  
<span style="margin-left: 2em">筆則據其神氣一篇指爲黨禁未開之時不得志</span>  
<span style="margin-left: 2em">者所爲今觀其書多采掇黄老之言而叅以術數</span>  
<span style="margin-left: 2em">之說吕氏春秋貴生篇一條今在陽城渠胥問篇</span>  
<span style="margin-left: 2em">中知度篇一條今在虎會篇中審爲篇一條則故</span>  
<span style="margin-left: 2em">佚不載以掩剽剟之迹頗巧於作僞然商𣙜治道</span>  
<span style="margin-left: 2em">大㫖皆不詭於聖賢其論黄帝鑄鼎一條以爲古</span>  
<!-- 册3 葉2168a　Page:文淵閣四庫全書_0003冊.djvu/547 -->
<span style="margin-left: 2em">人之寓言足正方士之謬其論唐堯土堦一條謂</span>  
<span style="margin-left: 2em">聖人不徒貴儉而貴有禮尤足砭墨家之偏其文</span>  
<span style="margin-left: 2em">雖稍渉漫衍而縱横博辯亦徃徃可喜殆能文之</span>  
<span style="margin-left: 2em">士發憤著書託其名於古人者觀篇末自叙世系</span>  
<span style="margin-left: 2em">以程出於趙睠睠不忘其宗屬其子勿有二心以</span>  
<span style="margin-left: 2em">事主則明寓宋姓其殆熙寜紹聖之間宗子之忤</span>  
<span style="margin-left: 2em">時不仕者乎諸子之書僞本不一然此最有理致</span>  
<span style="margin-left: 2em">文彩辨其贋則可以其贋而廢之則不可陳振孫</span>  
<span style="margin-left: 2em">謂其文不古而亦有可觀當出近世能言之流實</span>  
<!-- 册3 葉2168b　Page:文淵閣四庫全書_0003冊.djvu/547 -->
<span style="margin-left: 2em">爲公論晁公武以謬誤淺陋譏之過矣</span>  
尹文子一卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">周尹文撰前有魏黄初末山陽仲長氏序稱條次</span>  
<span style="margin-left: 2em">撰定爲上下篇文獻通考著錄作二卷此本亦題</span>  
<span style="margin-left: 2em">大道上篇大道下篇與序文相符而通爲一卷葢</span>  
<span style="margin-left: 2em">後人所合併也莊子天下篇以尹文田駢並稱顔</span>  
<span style="margin-left: 2em">師古註漢書謂齊宣王時人考劉向說苑載文與</span>  
<span style="margin-left: 2em">宣王問答顔葢據此然吕氏春秋又載其與湣王</span>  
<span style="margin-left: 2em">問答事殆宣王時稷下舊人至湣王時猶在歟其</span>  
<!-- 册3 葉2169a　Page:文淵閣四庫全書_0003冊.djvu/547 -->
<span style="margin-left: 2em">書本名家者流大㫖指陳治道欲自處於虚靜而</span>  
<span style="margin-left: 2em">萬事萬物則一一綜核其實故其言出入於黄老</span>  
<span style="margin-left: 2em">申韓之問周氏渉筆謂其自道以至名自名以至</span>  
<span style="margin-left: 2em">法葢得其真晁公武讀書志以爲誦法仲尼其言</span>  
<span style="margin-left: 2em">誠過宜爲高似孫緯畧所譏然似孫以儒理繩之</span>  
<span style="margin-left: 2em">謂其淆雜亦爲未允百氏爭鳴九流並列各尊所</span>  
<span style="margin-left: 2em">聞各行所知自老莊以下均自爲一家之言讀其</span>  
<span style="margin-left: 2em">文者取其博辨閎肆足矣安能限以一格哉序中</span>  
<span style="margin-left: 2em">所稱熙伯葢繆襲之字其山陽仲長氏不知爲誰</span>  
<!-- 册3 葉2169b　Page:文淵閣四庫全書_0003冊.djvu/547 -->
<span style="margin-left: 2em">李淑邯鄲書目以爲仲長統然統卒於建安之末</span>  
<span style="margin-left: 2em">與所云黄初末者不合晁公武因此而疑史誤未</span>  
<span style="margin-left: 2em">免附會矣</span>  
慎子一卷<sub class="note-yuan">少詹事陸費堓家藏本</sub>  
<span style="margin-left: 2em">周慎到撰到趙人中興書目作瀏陽人陳振孫書</span>  
<span style="margin-left: 2em">錄解題曰慎到趙人見於史記瀏陽在今潭州吳</span>  
<span style="margin-left: 2em">時始置縣與趙南北了不相渉葢據書坊所稱不</span>  
<span style="margin-left: 2em">知何謂也則稱瀏陽者非矣明人刻本又云到一</span>  
<span style="margin-left: 2em">名廣案陸德明莊子釋文田駢下註曰慎子云名</span>  
<!-- 册3 葉2172a　Page:文淵閣四庫全書_0003冊.djvu/548 -->
<span style="margin-left: 2em">廣然則駢一名廣非到一名廣尤舛誤也莊子天</span>  
<span style="margin-left: 2em">下篇曰慎到棄知去已而緣不得已泠汰於物以</span>  
<span style="margin-left: 2em">爲道理曰知不知將薄知而後鄰傷者也謑髁無</span>  
<span style="margin-left: 2em">任而笑天下之尙賢也縱脫無行而非天下之大</span>  
<span style="margin-left: 2em">聖椎拍輐斷與物宛轉舍是與非苟可以免不師</span>  
<span style="margin-left: 2em">智慮不知前後魏然而已矣推而後行曵而後徃</span>  
<span style="margin-left: 2em">若飄風之還若羽之旋若磨石之隧全而無非動</span>  
<span style="margin-left: 2em">靜無過未嘗有罪是何故夫無知之物無建巳之</span>  
<span style="margin-left: 2em">患無用知之累動靜不離於理是以終身無譽故</span>  
<!-- 册3 葉2172b　Page:文淵閣四庫全書_0003冊.djvu/548 -->
<span style="margin-left: 2em">曰至於若無知之物而巳無用賢聖夫塊不失道</span>  
<span style="margin-left: 2em">豪傑相與笑之曰慎到之道非生人之行而至死</span>  
<span style="margin-left: 2em">人之理適得怪焉云云是慎子之學近乎釋氏然</span>  
<span style="margin-left: 2em">漢志列之於法家今考其書大㫖欲因物理之當</span>  
<span style="margin-left: 2em">然各定一法而守之不求於法之外亦不寛於法</span>  
<span style="margin-left: 2em">之中則上下相安可以淸淨而治然法所不行勢</span>
