## 欽定四庫全書總目 卷五十八　史部十四　傳記類二

<!-- 册2 葉1148a　Page:文淵閣四庫全書_0002冊.djvu/292 -->
欽定四庫全書總目卷五十八  
<span style="margin-left: 1em">史部十四</span>  
<span style="margin-left: 2em">傳記𩔖二</span>  
敬鄉錄十四卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">元吳師道撰師道有戰國策校註已著錄是編以</span>  
<span style="margin-left: 2em">宋婺守洪遵東陽志所記人物尚有遺漏因蒐錄</span>  
<span style="margin-left: 2em">舊聞以補其闕始自梁朝迄於宋末每人先次其</span>  
<span style="margin-left: 2em">行畧而附錄其所著詩文亦有止著其目者或已</span>  
<span style="margin-left: 2em">散佚或從刪汰也明正德間金華守趙鶴有金華</span>  
<!-- 册2 葉1148b　Page:文淵閣四庫全書_0002冊.djvu/292 -->
<span style="margin-left: 2em">文統十三卷葢以是錄爲藍本然鶴所編次往往</span>  
<span style="margin-left: 2em">重複舛漏如此錄載潘良貴矯齋記靜勝齋記答</span>  
<span style="margin-left: 2em">雷公達書君子有三戒說四篇而文統止載矯齋</span>  
<span style="margin-left: 2em">記及雷公達書二篇刪汰漫無義例殊不及師道</span>  
<span style="margin-left: 2em">本書又如宋方符所編宗忠簡遺集師道謂不及</span>  
<span style="margin-left: 2em">見故集中封事諸篇此錄不載然此錄有贈鷄山</span>  
<span style="margin-left: 2em">陳七四秀才五言一首方符所編轉未之及則零</span>  
<span style="margin-left: 2em">篇散什藉以存者不少矣至所編輯宋人小傳猶</span>  
<span style="margin-left: 2em">在宋史未成以前故記載多有異同若謂梅執禮</span>  
<!-- 册2 葉1149a　Page:文淵閣四庫全書_0002冊.djvu/292 -->
<span style="margin-left: 2em">宻與諸將謀奪萬勝門夜入金營刼二帝歸范瓊</span>  
<span style="margin-left: 2em">以爲無益獨吳革與趙子方結軍民得衆數萬王</span>  
<span style="margin-left: 2em">時雍徐秉哲聞之懼使瓊泄謀於金師宋史及東</span>  
<span style="margin-left: 2em">都事畧本傳俱不載僅畧見三朝北盟會編中惟</span>  
<span style="margin-left: 2em">此書言之頗悉又若宋史載嘉定十四年三月丁</span>  
<span style="margin-left: 2em">亥金師破黃州知州事何大節棄城遁死己亥金</span>  
<span style="margin-left: 2em">師陷蘄州知州事李誠之死之是錄載李誠之死</span>  
<span style="margin-left: 2em">事與宋史合而於何大節之遁則引劉克莊答傅</span>  
<span style="margin-left: 2em">諫議伯成書辨大節初䕶齊安官吏士民過武昌</span>  
<!-- 册2 葉1149b　Page:文淵閣四庫全書_0002冊.djvu/292 -->
<span style="margin-left: 2em">復自還齊安固守半月城破金師擁入大節死於</span>  
<span style="margin-left: 2em">赤壁磯下則大節實未嘗遁此事與史頗異亦可</span>  
<span style="margin-left: 2em">以資考證元好問中州集以詩存史爲世所重師</span>  
<span style="margin-left: 2em">道此書殆與相埒以其因人物以存文章非因文</span>  
<span style="margin-left: 2em">章以存人物與好問體例畧殊故𨽻之於傳記類</span>  
<span style="margin-left: 2em">焉</span>  
唐才子傳八卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">元辛文房𢰅文房字良史西域人其始末不見於</span>  
<span style="margin-left: 2em">史傳惟陸友仁研北襍志稱其能詩與王執謙齊</span>  
<!-- 册2 葉1152a　Page:文淵閣四庫全書_0002冊.djvu/293 -->
<span style="margin-left: 2em">名蘇天爵元文𩔖中載其蘇小小歌一篇耳是書</span>  
<span style="margin-left: 2em">原本凡十卷總三百九十七人下至妓女女道士</span>  
<span style="margin-left: 2em">之𩔖亦皆載入其見於新舊唐書者僅百人餘皆</span>  
<span style="margin-left: 2em">從傳記說部各書采葺其體例因詩繫人故有唐</span>  
<span style="margin-left: 2em">名人非卓有詩名者不錄卽所載之人亦多詳其</span>  
<span style="margin-left: 2em">逸事及著作之傳否而於功業行誼則祗撮其梗</span>  
<span style="margin-left: 2em">槪葢以論文爲主不以記事爲主也大抵於初盛</span>  
<span style="margin-left: 2em">稍畧中晩以後漸詳至李建<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3297.svg?width=24" alt="四庫全書僻字第3297號（勲）" title="四庫全書僻字第3297號（勲）">孫魴沈彬江爲廖</span>  
<span style="margin-left: 2em">圖熊皦孟賓于孟貫陳摶之倫均有專傳則下包</span>  
<!-- 册2 葉1152b　Page:文淵閣四庫全書_0002冊.djvu/293 -->
<span style="margin-left: 2em">五代矣考楊士奇東里集有是書䟦是明初尚有</span>  
<span style="margin-left: 2em">完帙故永樂大典目錄於傳字韻内載其全書今</span>  
<span style="margin-left: 2em">傳字一韻適佚世間遂無傳本然幸其各韻之内</span>  
<span style="margin-left: 2em">尚雜引其文今隨條摭拾裒輯編次共得二百三</span>  
<span style="margin-left: 2em">十四人又附傳者四十四人共二百七十八人謹</span>  
<span style="margin-left: 2em">依次訂正釐爲八卷按楊士奇䟦稱是書凡行事</span>  
<span style="margin-left: 2em">不關大體不足爲勸戒者不錄又稱襍以臆說不</span>  
<span style="margin-left: 2em">盡可據今考編中如許渾傳稱其夢遊崑崙李羣</span>  
<span style="margin-left: 2em">玉傳稱其夢見神女襍采孟棨本事詩范攄雲溪</span>  
<!-- 册2 葉1153a　Page:文淵閣四庫全書_0002冊.djvu/293 -->
<span style="margin-left: 2em">友議荒唐之說無當史裁又如儲光羲汚祿山僞</span>  
<span style="margin-left: 2em">命而稱其養浩然之氣尤乖大義他如謂駱賓王</span>  
<span style="margin-left: 2em">與宋之問唱和靈隱寺中謂中興間氣集爲高適</span>  
<span style="margin-left: 2em">所𨕖謂李商隱曾爲廣州都督謂唐人效杜甫者</span>  
<span style="margin-left: 2em">惟唐彥謙一人乖舛不一而足葢文房抄掇繁富</span>  
<span style="margin-left: 2em">或未暇檢詳故謬誤牴牾往往襍見然較計有功</span>  
<span style="margin-left: 2em">唐詩紀事叙述差有條理文筆亦秀潤可觀傳後</span>  
<span style="margin-left: 2em">間綴以論多掎摭詩家利病亦足以津逮藝林於</span>  
<span style="margin-left: 2em">學詩者考訂之功固不爲無補焉</span>  
<!-- 册2 葉1153b　Page:文淵閣四庫全書_0002冊.djvu/293 -->
元朝名臣事畧十五卷<sub class="note-yuan">大學士于敏中家藏本</sub>  
<span style="margin-left: 2em">元蘇天爵𢰅天爵字伯修眞定人由國子學生試</span>  
<span style="margin-left: 2em">第一釋褐授從仕郎蘇州判官終浙江行省叅知</span>  
<span style="margin-left: 2em">政事事蹟具元史本傳此書記元代名臣事實始</span>  
<span style="margin-left: 2em">穆呼哩<sub class="note-yuan">原作木華𥠖今改正</sub>終劉因凡四十七人大抵據諸</span>  
<span style="margin-left: 2em">家文集所載墓碑墓誌行狀家傳爲多其襍書可</span>  
<span style="margin-left: 2em">徵信者亦採掇焉一一註其所岀以示有徵葢仿</span>  
<span style="margin-left: 2em">朱子名臣言行錄例而始末較詳又兼仿杜大珪</span>  
<span style="margin-left: 2em">名臣碑傳琬琰集例但有所棄取不盡錄全篇耳</span>  
<!-- 册2 葉1156a　Page:文淵閣四庫全書_0002冊.djvu/294 -->
<span style="margin-left: 2em">後蘇霖作有官龜鑑於當代事跡皆採是書元史</span>  
<span style="margin-left: 2em">列傳亦皆與是書相出入足知其不失爲信史矣</span>  
浦陽人物記二卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明宋濂𢰅濂有洪武聖政記巳著錄是書凡五目</span>  
<span style="margin-left: 2em">曰忠義曰孝友曰政事曰文學曰貞節所紀共二</span>  
<span style="margin-left: 2em">十有九人而以進士題名一篇附於後歐陽元序</span>  
<span style="margin-left: 2em">稱其至公甚當不以私意爲予奪葢濓本以文章</span>  
<span style="margin-left: 2em">名世故所作皆具有史法其書本成於元時後人</span>  
<span style="margin-left: 2em">編輯濂集者止採錄其論贊而全書則仍別行此</span>  
<!-- 册2 葉1156b　Page:文淵閣四庫全書_0002冊.djvu/294 -->
<span style="margin-left: 2em">本爲明宏治中厯陽王珍所重刻卷末有濂自䟦</span>  
<span style="margin-left: 2em">稱始立槀而廉侯景淵遽取刊布牴牾者多今補</span>  
<span style="margin-left: 2em">定五十餘處視舊行爲小勝末題至正十三年此</span>  
<span style="margin-left: 2em">䟦濓集亦未收葢濓元時所作集多失載今所傳</span>  
<span style="margin-left: 2em">未刻稿皆至正時之遺文可以互證也</span>  
古今列女傳三巻<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明解縉等奉勅撰先是洪武中孝慈高皇后每聽</span>  
<span style="margin-left: 2em">女史讀書至列女傳謂宜加討論因請於太祖命</span>  
<span style="margin-left: 2em">儒臣考訂未就永樂元年成祖旣追上高皇后尊</span>  
<!-- 册2 葉1157a　Page:文淵閣四庫全書_0002冊.djvu/294 -->
<span style="margin-left: 2em">諡册寳仁孝皇后因復以此書爲言遂命縉及黃</span>  
<span style="margin-left: 2em">淮胡廣胡儼楊榮金幼孜楊士奇王洪蔣驥沈度</span>  
<span style="margin-left: 2em">等同加編輯書成上進帝自製序文刊印頒行上</span>  
<span style="margin-left: 2em">巻皆厯代后妃中巻諸侯大夫妻下巻士庶人妻</span>  
<span style="margin-left: 2em">時仁孝皇后作貞烈事實以闡幽微顯頗留意風</span>  
<span style="margin-left: 2em">教故諸臣編輯是書稍爲經意不似五經四書大</span>  
<span style="margin-left: 2em">全之潦草所錄事蹟起自有虞迄於元明漢以前</span>  
<span style="margin-left: 2em">多本之劉向書後代則畧取各史列女傳而以明</span>  
<span style="margin-left: 2em">初人附益之去取頗見審愼葢在明代官書之中</span>  
<!-- 册2 葉1157b　Page:文淵閣四庫全書_0002冊.djvu/294 -->
<span style="margin-left: 2em">猶爲善本此爲秀水項元汴家所藏乃明内府初</span>  
<span style="margin-left: 2em">刊之板黄虞稷千頃堂書目稱此書成於永樂元</span>  
<span style="margin-left: 2em">年十二月今考成祖御製序實題九月朔旦知虞</span>  
<span style="margin-left: 2em">稷未見原書僅據傳聞著錄矣</span>  
殿閣詞林記二十二巻<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明廖道南撰道南有楚紀巳著錄道南自正德辛</span>  
<span style="margin-left: 2em">巳改庶吉士由編修厯官侍講學士在禁垣最久</span>  
<span style="margin-left: 2em">嫻習掌故因集詞林殿閣宮坊臺省諸臣舊事分</span>  
<span style="margin-left: 2em">𩔖記載以成是編其例凡仕至華蓋武英諸殿者</span>  
<!-- 册2 葉1160a　Page:文淵閣四庫全書_0002冊.djvu/295 -->
<span style="margin-left: 2em">曰殿學文淵東閣者曰閣學兼六館者曰館學晉</span>  
<span style="margin-left: 2em">詹事者曰宮學屬春坊者曰坊學屬宏文者亦曰</span>  
<span style="margin-left: 2em">館學典成均者曰廱學陞本院者曰卿學有節義</span>  
<span style="margin-left: 2em">者曰贈學擅書翰者曰藝學終始本院者曰院學</span>  
<span style="margin-left: 2em">大槪仿列傳之例悉載其官階恩遇而事實亦附</span>  
<span style="margin-left: 2em">見焉自巻九以下標題皆作國子監祭酒黃佐侍</span>  
<span style="margin-left: 2em">講學士廖道南同編葢道南採掇黃佐翰林記之</span>  
<span style="margin-left: 2em">文不没所自猶有前輩篤實之遺今亦仍從舊本</span>  
<span style="margin-left: 2em">並存其名焉</span>  
<!-- 册2 葉1160b　Page:文淵閣四庫全書_0002冊.djvu/295 -->
嘉靖以來首輔傳八巻<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">明王世貞撰世貞有弇山堂别集巳著錄是編乃</span>  
<span style="margin-left: 2em">紀世宗穆宗神宗三朝閣臣事蹟案明自太祖罷</span>  
<span style="margin-left: 2em">設丞相分其事權於六部至成祖始命儒臣入直</span>  
<span style="margin-left: 2em">文淵閣叅預機務但稱閣臣而不以相名其後閹</span>  
<span style="margin-left: 2em">倖干政閣臣多碌碌充位至嘉靖間始委政内閣</span>  
<span style="margin-left: 2em">而居首揆者責任尤專凡一時政治得失皆視其</span>  
<span style="margin-left: 2em">人爲輕重故世貞作此書斷自嘉靖爲始以明積</span>  
<span style="margin-left: 2em">漸所由來前有總序稱閣臣沿革始末巳具年表</span>  
<!-- 册2 葉1161a　Page:文淵閣四庫全書_0002冊.djvu/295 -->
<span style="margin-left: 2em">者卽指弇山堂别集中之百官表也其所載始楊</span>  
<span style="margin-left: 2em">廷和訖申時行皆以首輔爲主而間以他人事蹟</span>  
<span style="margin-left: 2em">附之於當時國事是非及賢姦進退之故序次詳</span>  
<span style="margin-left: 2em">悉頗得史法惟世貞與王錫爵同鄕錫爵家嘗妄</span>  
<span style="margin-left: 2em">言其女得道仙去世貞據爲作傳當時劾錫爵者</span>  
<span style="margin-left: 2em">或并劾世貞及世貞作此書時仍載入曇陽子事</span>  
<span style="margin-left: 2em">以申巳說不免文過遂非其餘所紀則大抵近實</span>  
<span style="margin-left: 2em">可與正史相叅證不以一節之謬棄其全書也</span>
