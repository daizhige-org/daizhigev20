## 欽定四庫全書總目 卷八十五　史部四十一　目錄類一

<!-- 册2 葉3028a　Page:文淵閣四庫全書_0002冊.djvu/762 -->
欽定四庫全書總目卷八十五  
<span style="margin-left: 1em">史部四十一</span>  
<span style="margin-left: 2em">目錄類一</span>  
<span style="margin-left: 3em">鄭元有三禮目錄一卷此名所昉也其有解題</span>  
<span style="margin-left: 3em">胡應麟經義會通謂始於唐之李肇案漢書錄</span>  
<span style="margin-left: 3em">七畧書名不過一卷而劉氏七畧别錄至二十</span>  
<span style="margin-left: 3em">卷此非有解題而何隋志曰劉向别錄劉歆七</span>  
<span style="margin-left: 3em">畧剖析條流各有其序推尋事迹自是以後不</span>  
<span style="margin-left: 3em">能辨其流别但記書名而巳其文甚明應麟誤</span>  
<!-- 册2 葉3028b　Page:文淵閣四庫全書_0002冊.djvu/762 -->
<span style="margin-left: 3em">也今所傳者以崇文總目爲古晁公武趙希弁</span>  
<span style="margin-left: 3em">陳振孫並凖爲撰述之式惟鄭樵作通志藝文</span>  
<span style="margin-left: 3em">畧始無所詮釋併建議廢崇文總目之解題而</span>  
<span style="margin-left: 3em">尤袤遂初堂書目因之自是以後遂兩體並行</span>  
<span style="margin-left: 3em">今亦兼收以資考核金石之文隋唐志附小學</span>  
<span style="margin-left: 3em">宋志乃附目錄今用宋志之例並列此門而别</span>  
<span style="margin-left: 3em">爲子目不使與經籍相淆焉</span>  
崇文總目十二卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋王堯臣等奉勅撰葢以四館書併合著錄者也</span>  
<!-- 册2 葉3029a　Page:文淵閣四庫全書_0002冊.djvu/762 -->
<span style="margin-left: 2em">宋制以昭文史館集賢爲三館太平興國三年於</span>  
<span style="margin-left: 2em">左升龍門東北建崇文院謂之三館新修書院端</span>  
<span style="margin-left: 2em">拱元年詔分三館之書萬餘卷别爲書庫名曰秘</span>  
<span style="margin-left: 2em">閣以别貯禁中之籍與三館合稱四館景祐元年</span>  
<span style="margin-left: 2em">閏六月以三館及秘閣所藏或謬濫不全命翰林</span>  
<span style="margin-left: 2em">學士張觀知制誥李淑宋祁等看詳定其存廢訛</span>  
<span style="margin-left: 2em">謬者刪去差漏者補寫因詔翰林學士王堯臣史</span>  
<span style="margin-left: 2em">館檢討王洙館閣校勘歐陽修等校正條曰討論</span>  
<span style="margin-left: 2em">撰次定著三萬六百六十九卷分類編目總成六</span>  
<!-- 册2 葉3029b　Page:文淵閣四庫全書_0002冊.djvu/762 -->
<span style="margin-left: 2em">十六卷於慶厯元年十二月已丑上之賜名曰崇</span>  
<span style="margin-left: 2em">文總目後神宗改崇文院曰秘書省徽宗時因改</span>  
<span style="margin-left: 2em">是書曰秘書總目然自南宋以來諸書援引仍謂</span>  
<span style="margin-left: 2em">之崇文總目從其朔也李燾續通鑑長編云崇文</span>  
<span style="margin-left: 2em">總目六十卷麟臺故事亦同中興書目云六十六</span>  
<span style="margin-left: 2em">卷江少虞事實類苑則云六十七卷文獻通考則</span>  
<span style="margin-left: 2em">云六十四卷宋史藝文志則据中興書目作六十</span>  
<span style="margin-left: 2em">六卷其說參差不一考原本於毎條之下具有論</span>  
<span style="margin-left: 2em">說逮南宋時鄭樵作通志始謂其文繁無用紹興</span>  
<!-- 册2 葉3032a　Page:文淵閣四庫全書_0002冊.djvu/763 -->
<span style="margin-left: 2em">中遂從而去其序釋故晁公武讀書志陳振孫書</span>  
<span style="margin-left: 2em">錄解題著錄皆云一卷是刊除序釋之後全本巳</span>  
<span style="margin-left: 2em">不甚行南宋諸家或不見其原書故所記卷數各</span>  
<span style="margin-left: 2em">異也考漢書藝文志本劉歆七畧而作班固已有</span>  
<span style="margin-left: 2em">自註隋書經籍志參考七錄互註存佚亦沿其例</span>  
<span style="margin-left: 2em">唐書於作者姓名不見紀傳者尙間有注文以資</span>  
<span style="margin-left: 2em">考核後來得畧見古書之崖畧實緣於此不可謂</span>  
<span style="margin-left: 2em">之繁文鄭樵作通志二十畧務欲凌跨前人而藝</span>  
<span style="margin-left: 2em">文一畧非目睹其書則不能詳究原委自揣海濵</span>  
<!-- 册2 葉3032b　Page:文淵閣四庫全書_0002冊.djvu/763 -->
<span style="margin-left: 2em">寒畯不能窺中秘之全無以駕乎其上遂惡其害</span>  
<span style="margin-left: 2em">巳而去之此宋人忌刻之故智非出公心厥後托</span>  
<span style="margin-left: 2em">克托等作宋史藝文志紕漏顚倒瑕隙百出於諸</span>  
<span style="margin-left: 2em">史志中最爲叢脞是卽高宗誤用樵言刪除序釋</span>  
<span style="margin-left: 2em">之流弊也宋人官私書目存於今者四家晁氏陳</span>  
<span style="margin-left: 2em">氏二目諸家藉爲考証之資而尤袤遂初堂書目</span>  
<span style="margin-left: 2em">及此書則若存若亡幾希湮滅是亦有說無說之</span>  
<span style="margin-left: 2em">明效矣此本爲范欽天一閣所藏朱彛尊抄而傳</span>  
<span style="margin-left: 2em">之始稍見於世亦無序釋彛尊曝書亭集有康熙</span>  
<!-- 册2 葉3033a　Page:文淵閣四庫全書_0002冊.djvu/763 -->
<span style="margin-left: 2em">庚辰九月作是書跋謂欲從六一居士集曁文獻</span>  
<span style="margin-left: 2em">通考所載别抄一本以補之然是時彛尊年七十</span>  
<span style="margin-left: 2em">二矣竟未能辦今以其言考之其毎類之序見於</span>  
<span style="margin-left: 2em">歐陽修集者秖經史二類及子類之半馬端臨文</span>  
<span style="margin-left: 2em">獻通考所載論說亦然晁公武讀書志陳振孫書</span>  
<span style="margin-left: 2em">錄解題皆在通考之前惟公武所見多通考一條</span>  
<span style="margin-left: 2em">陳氏則但見六十六卷之目題曰紹興改定者而</span>  
<span style="margin-left: 2em">巳永樂大典所引亦卽從晁陳二家目中採出無</span>  
<span style="margin-left: 2em">所增益巳不能復睹其全然蒐輯排比尙可得十</span>  
<!-- 册2 葉3033b　Page:文淵閣四庫全書_0002冊.djvu/763 -->
<span style="margin-left: 2em">之三四是亦較勝於無矣謹依其原次以類補入</span>  
<span style="margin-left: 2em">𨤲爲一十二卷其六十六卷之原次仍注於各類</span>  
<span style="margin-left: 2em">之下又續宋㑹要載大觀四年五月祕書監何志</span>  
<span style="margin-left: 2em">同言慶厯間集四庫爲籍今按籍求之十纔六七</span>  
<span style="margin-left: 2em">宜頒其名類於天下總目之外别有異書並借傳</span>  
<span style="margin-left: 2em">寫紹興十二年十二月權發遣旴眙軍向子固言</span>  
<span style="margin-left: 2em">乞下本省以唐藝文志及崇文總目所闕之書註</span>  
<span style="margin-left: 2em">闕字於其下付諸州軍照應搜訪云云今所傳本</span>  
<span style="margin-left: 2em">毎書之下多注闕字蓋由於此今亦仍之王應麟</span>  
<!-- 册2 葉3036a　Page:文淵閣四庫全書_0002冊.djvu/764 -->
<span style="margin-left: 2em">玉海稱當時國史謂總目序錄多所謬誤黄伯思</span>  
<span style="margin-left: 2em">東觀餘論有校正崇文總目十七條鄭樵通志校</span>  
<span style="margin-left: 2em">讐畧則全爲攻擊此書而作李燾長編亦云總目</span>  
<span style="margin-left: 2em">或有相重亦有可取而誤棄不錄者今觀其書載</span>  
<span style="margin-left: 2em">籍浩繁牴牾誠所難保然數千年著作之曰總滙</span>  
<span style="margin-left: 2em">於斯百世而下藉以騐存佚辨眞贋核同異固不</span>  
<span style="margin-left: 2em">失爲冊府之驪淵藝林之玉圃也</span>  
郡齋讀書志四卷後志二卷考異一卷附志一卷<sub class="note-yuan">兩江總督</sub>  
<sub class="note-yuan">採進本</sub>  
<!-- 册2 葉3036b　Page:文淵閣四庫全書_0002冊.djvu/764 -->
<span style="margin-left: 2em">讀書志四卷宋晁公武撰後志二卷亦公武所撰</span>  
<span style="margin-left: 2em">趙希弁重編附志一卷則希弁所續輯也公武字</span>  
<span style="margin-left: 2em">子止鉅野人冲之之子官至敷文閣<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">學士臨安</span>  
<span style="margin-left: 2em">少尹岳珂桯史記隆興二年湯思退罷相洪适草</span>  
<span style="margin-left: 2em">制作平語侍御史晁公武擊之則亦骨鯁之士希</span>  
<span style="margin-left: 2em">弁袁州人宋宗室子自題稱江西漕貢進士祕書</span>  
<span style="margin-left: 2em">省校勘以輩行推之蓋太祖之九世孫也始南陽</span>  
<span style="margin-left: 2em">井憲孟爲四川轉運使家多藏書悉舉以贈公武</span>  
<span style="margin-left: 2em">乃躬自讐校疏其大畧爲此書以時方守榮州故</span>  
<!-- 册2 葉3037a　Page:文淵閣四庫全書_0002冊.djvu/764 -->
<span style="margin-left: 2em">名郡齋讀書志後書散佚而志獨存淳祐巳酉鄱</span>  
<span style="margin-left: 2em">陽𥠖安朝守袁州因令希弁卽其家所藏書目參</span>  
<span style="margin-left: 2em">校刪其重複摭所未有益爲附志一卷而重刻之</span>  
<span style="margin-left: 2em">是爲袁本時南充游鈞守衢州亦取公武門人姚</span>  
<span style="margin-left: 2em">應績所編蜀本刊傳是爲衢本當時二書並行於</span>  
<span style="margin-left: 2em">世惟衢本分析至二十卷增加書目甚多卷首公</span>  
<span style="margin-left: 2em">武自序一篇文亦互有詳畧希弁以衢本所增乃</span>  
<span style="margin-left: 2em">公武晩年續裒之書而非所得井氏之舊因别摘</span>  
<span style="margin-left: 2em">出爲後志二卷又以袁衢二本異同别爲考異一</span>  
<!-- 册2 葉3037b　Page:文淵閣四庫全書_0002冊.djvu/764 -->
<span style="margin-left: 2em">卷附之編末蓋原志四卷爲井氏書後志二卷爲</span>  
<span style="margin-left: 2em">晁氏書並至南渡而止附志一卷則希弁家書故</span>  
<span style="margin-left: 2em">兼及於慶元以後也馬端臨作經籍考全以是書</span>  
<span style="margin-left: 2em">及陳氏書錄解題爲據然以此本與經籍考互校</span>  
<span style="margin-left: 2em">徃徃乖迕不合如京房易傳此本僅注三十餘字</span>  
<span style="margin-left: 2em">而馬氏所引其文多至十倍又如宋太祖實錄太</span>  
<span style="margin-left: 2em">宗實錄建康實錄汲冡周書之類此志本僅述其</span>  
<span style="margin-left: 2em">撰人時代及卷數而止而馬氏所引尙有考据議</span>  
<span style="margin-left: 2em">論凡數十言其餘文之多寡詞之增損互異者不</span>  
<!-- 册2 葉3040a　Page:文淵閣四庫全書_0002冊.djvu/765 -->
<span style="margin-left: 2em">可勝數又希弁考異稱袁本毗陵易傳衢本作東</span>  
<span style="margin-left: 2em">坡易傳袁本芸閣先生易解衢本作吕氏章句今</span>  
<span style="margin-left: 2em">經籍考所題並同衢本似馬端臨原據衢本採掇</span>  
<span style="margin-left: 2em">然如丁晉公談錄六祖壇經之類希弁考異稱袁</span>  
<span style="margin-left: 2em">本所載而衢本所遺者今經籍考實並引晁氏之</span>  
<span style="margin-left: 2em">說則當時亦兼用袁本疑此書巳經後人刪削不</span>  
<span style="margin-left: 2em">特衢本不可復見卽袁本亦非盡舊文故與馬氏</span>  
<span style="margin-left: 2em">所引不能一一符合歟又前志子部叙錄稱九曰</span>  
<span style="margin-left: 2em">小說類十曰天文厯算類十一曰兵家類十二曰</span>  
<!-- 册2 葉3040b　Page:文淵閣四庫全書_0002冊.djvu/765 -->
<span style="margin-left: 2em">類家類十三曰雜藝類十四曰醫家類十五曰神</span>  
<span style="margin-left: 2em">仙類十六曰釋書類而志中所列小說類鷄跖集</span>  
<span style="margin-left: 2em">後卽爲羣仙㑹眞記王氏神仙傳葛洪神仙傳三</span>  
<span style="margin-left: 2em">種是天文厯算等五類全佚而神仙類亦脫其標</span>  
<span style="margin-left: 2em">目則其他類之殘缺蓋可例推矣然書雖非舊而</span>  
<span style="margin-left: 2em">梗槪仍存終爲考證者所取資也</span>  
遂初堂書目一卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">宋尤袤撰袤字延之無錫人紹興十入年進士官</span>  
<span style="margin-left: 2em">至禮部尙書諡文簡事迹具宋史本傳陳振孫書</span>  
<!-- 册2 葉3041a　Page:文淵閣四庫全書_0002冊.djvu/765 -->
<span style="margin-left: 2em">錄解題稱其遂初堂藏書爲近世冠楊萬里誠齋</span>  
<span style="margin-left: 2em">集有爲袤作益齋書目序其名與此不同然通考</span>  
<span style="margin-left: 2em">引萬里序列遂初堂書目條下知卽一書今此本</span>  
<span style="margin-left: 2em">無此序而有毛幵一序魏了翁陸友仁二跋其書</span>  
<span style="margin-left: 2em">分經爲九門曰經總類周易類尙書類詩類禮類</span>  
<span style="margin-left: 2em">樂類春秋類論語孝經孟子類小學類分史爲十</span>  
<span style="margin-left: 2em">八門曰正史類編年類雜史類故事類雜傳類僞</span>  
<span style="margin-left: 2em">史類國史類本朝雜史類本朝故事類本朝雜傳</span>  
<span style="margin-left: 2em">類實錄類職官類儀注類刑法類姓氏類史學類</span>

<span style="margin-left: 2em">目錄類地理類分子爲十二門曰儒家類雜家類</span>
