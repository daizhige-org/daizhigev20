## 欽定四庫全書總目 卷一百三十二　子部四十二　雜家類存目九

<!-- 册3 葉3208a　Page:文淵閣四庫全書_0003冊.djvu/807 -->
欽定四庫全書總目卷一百三十二  
<span style="margin-left: 1em">子部四十二</span>  
<span style="margin-left: 2em">雜家𩔖存目九</span>  
羣書摘草五卷<sub class="note-yuan">左都御史張若溎家藏本</sub>  
<span style="margin-left: 2em">明王國賔編國賔號養黙武進人萬厯甲戌進士</span>  
<span style="margin-left: 2em">其作此書時方監𣙜杭州北新關未詳其終於何</span>  
<span style="margin-left: 2em">官也其書仿庾仲容子鈔馬總意林之例摘取家</span>  
<span style="margin-left: 2em">語以下至明張時徹說林三十二種附以兵書七</span>  
<span style="margin-left: 2em">種每種各摘數叚無所持擇蓋亦當時書帕之本</span>  
<!-- 册3 葉3208b　Page:文淵閣四庫全書_0003冊.djvu/807 -->
閨範四卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明吕坤撰坤有四禮疑已著錄此編乃其爲山西</span>  
<span style="margin-left: 2em">按察使時所作前一卷爲嘉言皆採六經及女誡</span>  
<span style="margin-left: 2em">女訓諸文爲之訓釋後三卷爲善行分女子婦人</span>  
<span style="margin-left: 2em">母道各一卷敘其本事而繪圖上方並附以贊文</span>  
<span style="margin-left: 2em">頗淺近取易通俗也當時嘗傳入禁中神宗以賜</span>  
<span style="margin-left: 2em">鄭貴妃妃重刻之後妖書案起遂以是書爲口實</span>  
<span style="margin-left: 2em">朱國楨湧幢小品曰吕新吾司㓂廉察山西纂閨</span>  
<span style="margin-left: 2em">範一書焦弱侯以使事至吕索序刋行弱侯亦取</span>  
<!-- 册3 葉3209a　Page:文淵閣四庫全書_0003冊.djvu/807 -->
<span style="margin-left: 2em">數部入京鄭貴妃之姪國泰乞取添入后妃一門</span>  
<span style="margin-left: 2em">而貴妃與焉衆大譁謂鄭氏著書弱侯交結爲序</span>  
<span style="margin-left: 2em">將有他志云云所紀與史小異然國楨與焦竑爲</span>  
<span style="margin-left: 2em">友目睹刋本所記似得其眞此本無鄭貴妃序當</span>  
<span style="margin-left: 2em">爲坤之原本也</span>  
百子咀華十四卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明胡效臣編效臣字鍾衡黃州人萬厯丙子舉人</span>  
<span style="margin-left: 2em">官旌德縣知縣是書取諸子之文而割裂之或摘</span>  
<span style="margin-left: 2em">其一叚或拾其數語或撮其數字以供時文獺祭</span>  
<!-- 册3 葉3209b　Page:文淵閣四庫全書_0003冊.djvu/807 -->
<span style="margin-left: 2em">之用首列左傳次六子次子彚次則以儒家道家</span>  
<span style="margin-left: 2em">法家兵家分𩔖又以明人所著參錯於古人之中</span>  
<span style="margin-left: 2em">不知其體例何在又題曰焦竑批評竑之陋何至</span>  
<span style="margin-left: 2em">於此其依託可不問而知也</span>  
琅邪代醉編四十卷<sub class="note-yuan">編修汪如藻家藏本</sub>  
<span style="margin-left: 2em">明張鼎思撰鼎思有琅邪曼衍已著錄是編乃其</span>  
<span style="margin-left: 2em">自給事中謫滁州驛丞時雜鈔諸史百家之言臚</span>  
<span style="margin-left: 2em">次成書名曰代醉編者歐陽修在滁州時有醉翁</span>  
<span style="margin-left: 2em">亭鼎思適宦其地以著書代飮酒也其書體例龎</span>  
<!-- 册3 葉3212a　Page:文淵閣四庫全書_0003冊.djvu/808 -->
<span style="margin-left: 2em">襍無所折衷考訂特偕以消閒遣日而已</span>  
蘭芳錄二卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">明徐三重撰三重有餘言已著錄是編皆錄古人</span>  
<span style="margin-left: 2em">輕世遺榮之事分内外二篇自序謂内篇近自得</span>  
<span style="margin-left: 2em">外篇稍假物緣亦不入世累然曾<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）">之沂水春風</span>  
<span style="margin-left: 2em">置之外篇葉夢得之讀書飮酒置之内篇殊不曉</span>  
<span style="margin-left: 2em">其優劣之旨首冠以論語飯疏食一章賢哉囘也</span>  
<span style="margin-left: 2em">一章別題曰孔顔樂事又不在内外篇之數則恐</span>  
<span style="margin-left: 2em">失講學本色耳</span>  
<!-- 册3 葉3212b　Page:文淵閣四庫全書_0003冊.djvu/808 -->
警語𩔖抄八卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">明程達撰達字順甫淸江人萬厯丁丑進士官至</span>  
<span style="margin-left: 2em">漳泉兵備道是編取先哲格言善行分𩔖編次其</span>  
<span style="margin-left: 2em">目六十割裂冗襍殊無倫次凡例云是編重理學</span>  
<span style="margin-left: 2em">故諸儒要語獨詳然於仙則信淮南之上昇王母</span>  
<span style="margin-left: 2em">之降漢於釋則言滅佛之報應談禪之超悟均不</span>  
<span style="margin-left: 2em">免自亂其例也</span>  
諸經品節二十卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">明楊起元編起元有證學編已著錄是編刪纂道</span>  
<!-- 册3 葉3213a　Page:文淵閣四庫全書_0003冊.djvu/808 -->
<span style="margin-left: 2em">釋二家之書道家凡陰符經道德經南華經大元</span>  
<span style="margin-left: 2em">經文始經洞古經大通經定觀經玉樞經心印經</span>  
<span style="margin-left: 2em">五厨經護命經胎息經龍虎經洞靈經黃庭經十</span>  
<span style="margin-left: 2em">六種釋家凡楞嚴經維摩經心經金剛經六祖壇</span>  
<span style="margin-left: 2em">經圓覺經楞伽經藥師經法華經無量經彌陀經</span>  
<span style="margin-left: 2em">盂蘭經十二種揚雄太元本爲擬易諸史皆著錄</span>  
<span style="margin-left: 2em">於儒家此引之道家殆晉人老易歸一之旨至列</span>  
<span style="margin-left: 2em">子冲虛經刪而不載又不明其故矣起元傳良知</span>  
<span style="margin-left: 2em">之學遂浸淫入於二氏已不可訓至平生讀書爲</span>  
<!-- 册3 葉3213b　Page:文淵閣四庫全書_0003冊.djvu/808 -->
<span style="margin-left: 2em">儒登會試第一官躋九列所謂國之大臣民之表</span>  
<span style="margin-left: 2em">也而是書卷首乃自題曰比邱尤可駭怪矣</span>  
沈氏學𡸅十六卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明沈堯中撰堯中字執甫嘉興人萬厯庚辰進士</span>  
<span style="margin-left: 2em">官至刑部尙書其自序曰爲綱二十有四爲目三</span>  
<span style="margin-left: 2em">百五十有八皆宇宙内鴻鉅之事非草木鳥獸之</span>  
<span style="margin-left: 2em">𩔖然襍採舊文無所考訂亦無所別擇如日月星</span>  
<span style="margin-left: 2em">宿諸占全錄天官書而不知太初之法最爲疎漏</span>  
<span style="margin-left: 2em">論周官則過信俞廷椿之說以爲冬官不缺散見</span>  
<!-- 册3 葉3216a　Page:文淵閣四庫全書_0003冊.djvu/809 -->
<span style="margin-left: 2em">六官而不知割裂五官有乖經義蓋襍駁之學也</span>  
霞外麈談十卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明周應治編應治字君衡鄞縣人萬厯庚辰進士</span>  
<span style="margin-left: 2em">楊德周序稱爲觀察不知官何省何道也是書輯</span>  
<span style="margin-left: 2em">隱逸髙尙之事分霞想鴻㝠恬尙曠覽幽賞淸鑒</span>  
<span style="margin-left: 2em">達生博雅寓因感適十𩔖大抵以世說新語爲藍</span>  
<span style="margin-left: 2em">本而稍以諸書附益之至於雲仙散錄師古僞杜</span>  
<span style="margin-left: 2em">詩註之類影撰故實亦皆捃拾殊無別裁又多不</span>  
<span style="margin-left: 2em">見原書輾轉稗販如披裘公不取遺金王摩詰詩</span>  
<!-- 册3 葉3216b　Page:文淵閣四庫全書_0003冊.djvu/809 -->
<span style="margin-left: 2em">中有畫列子鄭人蕉鹿諸條尤割裂不成文理至</span>  
<span style="margin-left: 2em">於宗慤乘風破浪鮑生愛妾換馬全與高𨼆無關</span>  
<span style="margin-left: 2em">不過襍凑以盈卷帙耳</span>  
宋賢事彚二卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">明李廷機撰廷機有漢唐宋名臣錄已著錄是編</span>  
<span style="margin-left: 2em">襍采史書說部所載宋人行事分爲四十三𩔖首</span>  
<span style="margin-left: 2em">有自序謂宋之世風人材頗𩔖今日言論行事往</span>  
<span style="margin-left: 2em">往有可用者云云宋明之季儒者如出一轍此𩔖</span>  
<span style="margin-left: 2em">亦可以觀矣</span>  
<!-- 册3 葉3217a　Page:文淵閣四庫全書_0003冊.djvu/809 -->
說𩔖六十二卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">明葉向高編林茂槐增刪向高字進<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">號臺山福</span>  
<span style="margin-left: 2em">淸人萬厯癸未進士官至東閣大學士謚文忠事</span>  
<span style="margin-left: 2em">迹具明史本傳茂槐有諸書字考已著錄是書摘</span>  
<span style="margin-left: 2em">唐宋說部之文分𩔖編次每𩔖之下各分子日每</span>  
<span style="margin-left: 2em">條下悉注原書然皆習見之典别無新異其上細</span>  
<span style="margin-left: 2em">書評語體例尤爲近俗</span>  
遯世編十四卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明錢一本撰一本有像象管見已著錄是編紀古</span>  
<!-- 册3 葉3217b　Page:文淵閣四庫全書_0003冊.djvu/809 -->
<span style="margin-left: 2em">來隱逸之士自唐虞至元分神隱眞隱儒隱節隱</span>  
<span style="margin-left: 2em">俠隱哲隱達隱高隱别隱九𩔖蕪襍殊甚疎漏尤</span>  
<span style="margin-left: 2em">多如不知姓名謂之眞隠然所謂阮籍遇蘇門山</span>  
<span style="margin-left: 2em">人卽是孫登不得曰無姓名也又顧阿瑛以晩年</span>  
<span style="margin-left: 2em">祝髮入之别隱褚伯秀本爲黃冠乃入之高隱梁</span>  
<span style="margin-left: 2em">鴻無排難解紛之事乃入之俠隱林靈素詭譎羽</span>  
<span style="margin-left: 2em">流亦目曰别隱皆未爲允協其他亦多科配未<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）"></span>  
<span style="margin-left: 2em">簡擇未當者一本研心經學所著易解能自成一</span>  
<span style="margin-left: 2em">家之言不應此書獨乖剌如是蓋一本以建言罷</span>  
<!-- 册3 葉3220a　Page:文淵閣四庫全書_0003冊.djvu/810 -->
<span style="margin-left: 2em">歸姑借此以抒忘情仕宦之志考據則非其所留</span>  
<span style="margin-left: 2em">意也</span>  
廉平錄五卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">明傅履禮高爲表同撰履禮題長蘆鹽運司知事</span>  
<span style="margin-left: 2em">爲表題滄州學正其始末均未詳也是書採前代</span>  
<span style="margin-left: 2em">至明事蹟分𩔖編輯凡廉錄三卷曰<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">相曰館閣</span>  
<span style="margin-left: 2em">曰憲臺曰省郞曰監司曰守令曰武臣平錄二卷</span>  
<span style="margin-left: 2em">曰畿内曰外藩曰郡州曰列縣廉者操守平者聽</span>  
<span style="margin-left: 2em">斷也每𩔖之中各以時代爲次萬厯戊子長蘆巡</span>  
<!-- 册3 葉3220b　Page:文淵閣四庫全書_0003冊.djvu/810 -->
<span style="margin-left: 2em">鹽御史東莞譚耀刻之蓋卽耀命二人編輯以充</span>  
<span style="margin-left: 2em">書帕者耳</span>  
焦氏𩔖林八卷<sub class="note-yuan">江西巡撫採進本</sub>  
<span style="margin-left: 2em">明焦竑撰竑有易筌已著錄是編前有自序謂庚</span>  
<span style="margin-left: 2em">辰讀書有感葛稚川語遇會心處輒以片𥿄紀之</span>  
<span style="margin-left: 2em">殘藁委於篋笥李君士龍見之乃手自整理取世</span>  
<span style="margin-left: 2em">說篇目括之其不盡者括以他目譬之溝中之斷</span>  
<span style="margin-left: 2em">文以靑黃則士龍之爲也士龍爲上元李登字然</span>  
<span style="margin-left: 2em">則竑特偶爲標出而成此書者則登也凡分五十</span>  
<!-- 册3 葉3221a　Page:文淵閣四庫全書_0003冊.djvu/810 -->
<span style="margin-left: 2em">有九𩔖皆非竒秘之文</span>  
二十九子品彚釋評二十卷<sub class="note-yuan">江蘇周厚堉家藏本</sub>  
<span style="margin-left: 2em">題曰翰林三狀元會選前列焦竑翁正春朱之藩</span>  
<span style="margin-left: 2em">三人名其書襍錄諸子毫無倫次評語亦皆託名</span>  
<span style="margin-left: 2em">謬陋不可言狀蓋坊賈射利之本不足以當指摘</span>  
<span style="margin-left: 2em">者也</span>  
田居乙記四卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明方大鎭撰大鎭有荷薪義已著錄是編乃其家</span>
