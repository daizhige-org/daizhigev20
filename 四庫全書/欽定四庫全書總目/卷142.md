## 欽定四庫全書總目 卷一百四十二　子部五十二　小說家類三

<!-- 册3 葉3964：整葉圖版，無文字記錄 -->
<!-- 册3 葉3965a　Page:文淵閣四庫全書_0003冊.djvu/996 -->
欽定四庫全書總目卷一百四十二  
<span style="margin-left: 1em">子部五十二</span>  
<span style="margin-left: 2em">小說家𩔖三</span>  
山海經十八卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">晉郭璞注卷首有劉秀校上奏稱爲伯益所作案</span>  
<span style="margin-left: 2em">山海經之名始見史記大宛傳司馬遷但云禹本</span>  
<span style="margin-left: 2em">記山海經所言怪物余不敢道而未言爲何人所</span>  
<span style="margin-left: 2em">作列子稱大禹行而見之伯益知而名之夷堅聞</span>  
<span style="margin-left: 2em">而志之似乎即指此書而不言其名山海經王充</span>  
<!-- 册3 葉3965b　Page:文淵閣四庫全書_0003冊.djvu/996 -->
<span style="margin-left: 2em">論衡别通篇曰禹主行水益主記異物海外山表</span>  
<span style="margin-left: 2em">無所不至以所見聞作山海經趙煜吳越春秋所</span>  
<span style="margin-left: 2em">說亦同惟隨書經籍志云蕭何得秦圖書後又得</span>  
<span style="margin-left: 2em">山海經相傳夏禹所記其文稍異然似皆因列子</span>  
<span style="margin-left: 2em">之說推而衍之觀書中載夏后啓周文王及秦漢</span>  
<span style="margin-left: 2em">長沙象郡餘暨下巂諸地名斷不作於三代以上</span>  
<span style="margin-left: 2em">殆周泰間人所述而後來好異者又附益之歟觀</span>  
<span style="margin-left: 2em">楚詞天問多與相符使古無是言屈原何由杜撰</span>  
<span style="margin-left: 2em">朱子楚詞辨證謂其反因天問而作似乎不然至</span>  
<!-- 册3 葉3968a　Page:文淵閣四庫全書_0003冊.djvu/997 -->
<span style="margin-left: 2em">王應麟王會補傳引朱子之言謂山海經記諸異</span>  
<span style="margin-left: 2em">物飛走之𩔖多云東向或曰東首疑本因圖畫而</span>  
<span style="margin-left: 2em">述之古有此學如九歌天問皆其𩔖云云則得其</span>  
<span style="margin-left: 2em">實矣郭璞注是書見於晉書本傳隋唐二志皆云</span>  
<span style="margin-left: 2em">二十三卷今本乃少五卷疑後人併其卷帙以就</span>  
<span style="margin-left: 2em">劉秀奏中一十八篇之數非缺佚也隋唐志又有</span>  
<span style="margin-left: 2em">郭璞山海經圖讚二卷今其讚猶載璞集中其圖</span>  
<span style="margin-left: 2em">則宋志巳不著錄知久佚矣舊本所載劉秀奏中</span>  
<span style="margin-left: 2em">稱其書凡十八篇與漢志稱十三篇者不合七畧</span>  
<!-- 册3 葉3968b　Page:文淵閣四庫全書_0003冊.djvu/997 -->
<span style="margin-left: 2em">即秀所定不應自相牴牾疑其贋托然璞序巳引</span>  
<span style="margin-left: 2em">其文相傳旣久今仍併錄焉書中序述山水多參</span>  
<span style="margin-left: 2em">以神怪故道藏收入太元部兢字號中究其本㫖</span>  
<span style="margin-left: 2em">實非黃老之言然道里山川率難考據按以耳目</span>  
<span style="margin-left: 2em">所及百不一眞諸家並以爲地理書之冠亦爲未</span>  
<span style="margin-left: 2em">允核實定名實則小說之最古者爾</span>  
山海經廣註十八卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝吳任臣𢰅任臣有十國春秋巳著錄是書因郭</span>  
<span style="margin-left: 2em">璞山海經註而補之故曰廣註於名物訓詁山川</span>  
<!-- 册3 葉3969a　Page:文淵閣四庫全書_0003冊.djvu/997 -->
<span style="margin-left: 2em">道里皆有所訂正雖嗜奇愛博引據稍繁如堂庭</span>  
<span style="margin-left: 2em">山之黃金靑邱山之鴛鴦雖販婦傭奴皆識其物</span>  
<span style="margin-left: 2em">而旁徵典籍未免贅疣卷首冠雜述一篇亦涉冗</span>  
<span style="margin-left: 2em">蔓然掎摭宏富多足爲考證之資所列逸文三十</span>  
<span style="margin-left: 2em">四條自楊愼丹鉛錄以下十八條皆明代之書所</span>  
<span style="margin-left: 2em">見實無別本其爲稗販誤記無可致疑至應劭漢</span>  
<span style="margin-left: 2em">書註以下十四條則或古本有異亦頗足以廣見</span>  
<span style="margin-left: 2em">聞也舊本載圖五卷分爲五𩔖曰靈袛曰異域曰</span>  
<span style="margin-left: 2em">獸族曰羽禽曰鱗介云本宋咸平舒雅舊藁雅本</span>  
<!-- 册3 葉3969b　Page:文淵閣四庫全書_0003冊.djvu/997 -->
<span style="margin-left: 2em">之張僧繇其說影響依稀未之敢據其圖亦以意</span>  
<span style="margin-left: 2em">爲之無論不眞出雅與僧繇卽說果<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">實二人亦</span>  
<span style="margin-left: 2em">何由見而圖之故今惟錄其註圖則從刪又前列</span>  
<span style="margin-left: 2em">引川書目五百三十餘種多採自類書虚陳名目</span>  
<span style="margin-left: 2em">亦不𤨏錄焉</span>  
穆天子傳六卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">晉郭璞注前有荀朂序按束晳傳云太康二年汲</span>  
<span style="margin-left: 2em">縣人不凖盜發魏襄王墓得竹書穆天子傳五篇</span>  
<span style="margin-left: 2em">又雜書十九篇周食田法周書論楚事周穆王美</span>  
<!-- 册3 葉3972a　Page:文淵閣四庫全書_0003冊.djvu/998 -->
<span style="margin-left: 2em">人盛姫事按今盛姫事載穆天子傳第六卷葢卽</span>  
<span style="margin-left: 2em">束晳傳所謂雜書之一篇也尋其文義應歸此傳</span>  
<span style="margin-left: 2em">束晳傳别出之非也此書記事有月日而無年又</span>  
<span style="margin-left: 2em">文多斷缺以今本竹書紀年較之紀年載十二年</span>  
<span style="margin-left: 2em">冬王北巡狩遂征犬戎事在傳之第一卷十四年</span>  
<span style="margin-left: 2em">夏王畋於軍邱五月作范宮作虎牢事在傳之第</span>  
<span style="margin-left: 2em">五卷十五年作重璧臺冬王觀於鹽澤事在傳之</span>  
<span style="margin-left: 2em">第六卷十七年王西征崑崙邱見西王母事在傳</span>  
<span style="margin-left: 2em">之第二卷第三卷第四卷兩書同時並出荀朂等</span>  
<!-- 册3 葉3972b　Page:文淵閣四庫全書_0003冊.djvu/998 -->
<span style="margin-left: 2em">互校其文不應牴牾如此葢今本竹書紀年乃明</span>  
<span style="margin-left: 2em">人撫諸書以爲之非汲冡之舊簡併郭璞註中所</span>  
<span style="margin-left: 2em">引紀年之文尚掇拾未盡况暇考其次第乎是亦</span>  
<span style="margin-left: 2em">今本紀年出於依托之一證或乃謂當移五卷六</span>  
<span style="margin-left: 2em">卷於二卷之前以符竹書之次第則削趾適履矣</span>  
<span style="margin-left: 2em">書中所紀雖多夸言寡實然所謂西王母者不過</span>  
<span style="margin-left: 2em">西方一國君所謂縣圃者不過飛鳥百獸之所飲</span>  
<span style="margin-left: 2em">食爲大荒之圃澤無所謂神仙怪異之事所謂河</span>  
<span style="margin-left: 2em">宗氏者亦僅國名無所謂魚龍變見之說較山海</span>  
<!-- 册3 葉3973a　Page:文淵閣四庫全書_0003冊.djvu/998 -->
<span style="margin-left: 2em">經淮南子猶爲近實郭璞註爾雅於西至西王母</span>  
<span style="margin-left: 2em">句不過曰西方昏荒之國於河出崑崙墟句雖引</span>  
<span style="margin-left: 2em">大荒西經而不言其靈異其注此書乃頗引志怪</span>  
<span style="margin-left: 2em">之談葢釋經不敢不謹嚴而箋釋雜書則務矜博</span>  
<span style="margin-left: 2em">洽故也列子周穆王篇所載與此傳相出入葢當</span>  
<span style="margin-left: 2em">時流俗有此記載如後世小說野乘之𩔖故列禦</span>  
<span style="margin-left: 2em">冦得捃采其文耳道藏目錄載入洞元部記傳𩔖</span>  
<span style="margin-left: 2em">恭字號與杜光庭錄異記諸書同列則牽附甚矣</span>  
<span style="margin-left: 2em">世所傳汲冡書師春之𩔖久已亡佚逸周書又屬</span>  
<!-- 册3 葉3973b　Page:文淵閣四庫全書_0003冊.djvu/998 -->
<span style="margin-left: 2em">誤入紀年僞妄顯然其眞存於今者惟此傳矣然</span>  
<span style="margin-left: 2em">文字旣古訛脫又甚學者多不究心封膜晝於河</span>  
<span style="margin-left: 2em">水之陽見第二卷膜晝自是人名封者錫以爵邑</span>  
<span style="margin-left: 2em">張彦遠歴代名畫記誤以晝字爲畫字遂誤以封</span>  
<span style="margin-left: 2em">膜爲畫家之祖邱陵自出乃西王母謠見第三卷</span>  
<span style="margin-left: 2em">方囘瀛奎律髓註陳子昻詩邱陵徒自出句乃云</span>  
<span style="margin-left: 2em">自出二字疑誤第二卷云乃爲銘迹於縣圃石上</span>  
<span style="margin-left: 2em">第三卷云乃紀其迹於弇山之石其文甚明朱珪</span>  
<span style="margin-left: 2em">名蹟錄乃謂取穆天子傳爲各蹟於弇兹石上全</span>  
<!-- 册3 葉3976a　Page:文淵閣四庫全書_0003冊.djvu/999 -->
<span style="margin-left: 2em">然舛迕則其傳世亦在若存若亡之間固考古者</span>  
<span style="margin-left: 2em">所宜寳重也</span>  
<span style="margin-left: 4em">案穆天子傳舊皆入起居注𩔖徒以編年紀</span>  
<span style="margin-left: 4em">月叙述西遊之事體近乎起居注耳實則恍</span>  
<span style="margin-left: 4em">惚無徵又非逸周書之比以爲古書而存之</span>  
<span style="margin-left: 4em">可也以爲信史而錄之則史體雜史例破矣</span>  
<span style="margin-left: 4em">今退置於小說家義求其當無庸以變古爲</span>  
<span style="margin-left: 4em">嫌也</span>  
神異經一卷<sub class="note-yuan">内府藏本</sub>  
<!-- 册3 葉3976b　Page:文淵閣四庫全書_0003冊.djvu/999 -->
<span style="margin-left: 2em">舊本題漢東方朔𢰅所載皆荒外之言怪誕不經</span>  
<span style="margin-left: 2em">共四十七條陳振孫書錄解題已極斥此書稱東</span>  
<span style="margin-left: 2em">方朔𢰅張茂先傳之僞今考漢書朔本傳歴叙朔</span>  
<span style="margin-left: 2em">所𢰅述言凡劉向所錄朔書俱是世所傳他事皆</span>  
<span style="margin-left: 2em">非其贊又言後世好事者取奇言怪語附著之朔</span>  
<span style="margin-left: 2em">云云則朔書多出附會在班固時巳然此書旣劉</span>  
<span style="margin-left: 2em">向七畧所不載則其爲依托更無疑義晉書張華</span>  
<span style="margin-left: 2em">本傳亦無註神異經之文則併華注亦屬假借振</span>  
<span style="margin-left: 2em">孫所疑誠爲有見然隋志載此書巳稱東方朔𢰅</span>  
<!-- 册3 葉3977a　Page:文淵閣四庫全書_0003冊.djvu/999 -->
<span style="margin-left: 2em">張華注則其僞在隋以前矣觀其詞華縟麗格近</span>  
<span style="margin-left: 2em">齊梁當由六朝文士影𢰅而成與洞冥拾遺諸記</span>  
<span style="margin-left: 2em">先後並出故其中西北荒金闕銀盤明月珠事陸</span>  
<span style="margin-left: 2em">倕石闕鉻引用之其中玉女投壺事徐陵玉臺新</span>  
<span style="margin-left: 2em">詠序引用之流傳旣久固不妨過而存之以廣異</span>  
<span style="margin-left: 2em">聞又考廣韻去聲四十一漾收㺊字說文玉篇皆</span>  
<span style="margin-left: 2em">所不載注稱獸似獅子實本此經北方有獸焉其</span>  
<span style="margin-left: 2em">狀如獅子名曰㺊之文則小學家巳相援據不但</span>  
<span style="margin-left: 2em">文人詞藻轉相採摭巳也隋志列之史部地理𩔖</span>  
<!-- 册3 葉3977b　Page:文淵閣四庫全書_0003冊.djvu/999 -->
<span style="margin-left: 2em">唐志又列之子部神仙類今核所言多世外恍惚</span>  
<span style="margin-left: 2em">之事旣有異於輿圖亦無關於修煉其分𨽻均屬</span>  
<span style="margin-left: 2em">未安今從文獻通考列小說𩔖中庶得其實焉</span>  
海内十洲記一卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">舊本題漢東方朔𢰅十洲者祖洲瀛洲懸洲炎洲</span>  
<span style="margin-left: 2em">長洲元洲流洲生洲鳳麟洲聚窟洲也又後附以</span>  
<span style="margin-left: 2em">滄海島方丈洲扶桑蓬邱崑崙五條其言或稱臣</span>  
<span style="margin-left: 2em">朔似對君之詞或稱武帝又似追記之文又盛稱</span>  
<span style="margin-left: 2em">武帝不能盡朔之術故不得長生則似道家夸大</span>  
<!-- 册3 葉3980a　Page:文淵閣四庫全書_0003冊.djvu/1000 -->
<span style="margin-left: 2em">之語大抵恍惚支離不可究詰考劉向所錄朔書</span>  
<span style="margin-left: 2em">無此名書中載武帝幸華林園射虎事案文𨕖應</span>  
<span style="margin-left: 2em">貞晉武帝華林園集詩李善註引洛陽圖經曰華</span>  
<span style="margin-left: 2em">林園在城内東北隅魏明帝起名芳林園齊王芳</span>  
<span style="margin-left: 2em">改爲華林武帝時安有是號葢六朝詞人所依托</span>  
<span style="margin-left: 2em">觀其引衛叔<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">事知出神仙傳後引五岳眞形圖</span>  
<span style="margin-left: 2em">事知出漢武内傳後也然自隋志已著於錄李善</span>  
<span style="margin-left: 2em">注張衡南都賦宋玉風賦鮑照舞鶴賦張衡思元</span>
