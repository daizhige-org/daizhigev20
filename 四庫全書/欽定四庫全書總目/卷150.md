## 欽定四庫全書總目 卷一百五十　集部三　別集類三

欽定四庫全書總目卷一百五十  
<span style="margin-left: 1em">集部三</span>  
<span style="margin-left: 2em">别集𩔖三</span>  
毘陵集二十卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">唐獨<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2854.svg?width=24" alt="四庫全書僻字第2854號（孤）" title="四庫全書僻字第2854號（孤）">及撰及字至之洛陽人官至司封郞中常</span>  
<span style="margin-left: 2em">州刺史卒諡曰憲事迹具唐書本傳權德輿作及</span>  
<span style="margin-left: 2em">諡議稱其立言遣詞有古風格濬波瀾而去流宕</span>  
<span style="margin-left: 2em">得菁華而無枝葉皇甫湜論業亦稱及文如危峯</span>  
<span style="margin-left: 2em">絶壁穿倚霄漢長松怪石顚倒巖壑王士禎香祖</span>  
<!-- 册4 葉176b　Page:文淵閣四庫全書_0004冊.djvu/49 -->
<span style="margin-left: 2em">筆記則謂其序記尚沿唐習碑版叙事稍見情實</span>  
<span style="margin-left: 2em">仙掌函谷二銘琅邪溪述馬退山茅亭記風后八</span>  
<span style="margin-left: 2em">陣圖記是其傑作文粹畧巳載之頗不以湜言爲</span>  
<span style="margin-left: 2em">然考唐自貞觀以後文士皆沿六朝之體經開元</span>  
<span style="margin-left: 2em">天寳詩格大變而文格猶襲舊規元結與及始奮</span>  
<span style="margin-left: 2em">起湔除蕭頴士李華左右之其後韓柳繼起唐之</span>  
<span style="margin-left: 2em">古文遂蔚然極盛斵雕爲樸數子實居首功唐實</span>  
<span style="margin-left: 2em">錄稱韓愈學獨<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2854.svg?width=24" alt="四庫全書僻字第2854號（孤）" title="四庫全書僻字第2854號（孤）">及之文當必有據<sub class="note-yuan">案此據晁氏讀書志所引</sub></span>  
<span style="margin-left: 2em">特風氣初開明而未融耳士禎於蓽路籃縷之初</span>  
<!-- 册4 葉177a　Page:文淵閣四庫全書_0004冊.djvu/49 -->
<span style="margin-left: 2em">責以制禮作樂之事是未尚論其世也集爲其門</span>  
<span style="margin-left: 2em">人安定梁肅所編李舟爲之序凡詩三卷文十七</span>  
<span style="margin-left: 2em">卷舊本久湮明吳寛自内閣鈔出始傳於世其中</span>  
<span style="margin-left: 2em">如景皇帝配天議郭知運呂諲等諡議皆粹然儒</span>  
<span style="margin-left: 2em">者之言非徒以詞采爲勝不止士禎所舉諸篇至</span>  
<span style="margin-left: 2em">馬退山茅亭記乃柳宗元作後人誤入及集士禎</span>  
<span style="margin-left: 2em">一例稱之尤疎於考證矣又文苑英華載有及賀</span>  
<span style="margin-left: 2em">赦二表代獨<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2854.svg?width=24" alt="四庫全書僻字第2854號（孤）" title="四庫全書僻字第2854號（孤）">將軍讓魏州刺史表爲崔使君讓</span>  
<span style="margin-left: 2em">潤州表代于京兆請停官侍親表唐文粹有招北</span>  
<!-- 册4 葉177b　Page:文淵閣四庫全書_0004冊.djvu/49 -->
<span style="margin-left: 2em">客文凡六篇集内皆無之按賀赦表所云誅翦大</span>  
<span style="margin-left: 2em">憝淸復闕廷及歸過罪巳降去鴻名並德宗興元</span>  
<span style="margin-left: 2em">時事及没於大厯十二年巳不及見招北客文文</span>  
<span style="margin-left: 2em">苑英華又以爲岑參之作彼此錯互疑莫能詳今</span>  
<span style="margin-left: 2em">姑依舊本闕載焉</span>  
蕭茂挺文集一卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">唐蕭頴士撰頴士字茂挺潁川人梁鄱陽王之裔</span>  
<span style="margin-left: 2em">世系具載其贈韋司業書中開元二十三年舉進</span>  
<span style="margin-left: 2em">士對策第一天寳初官祕書正字以搜括遺書淹</span>  
<!-- 册4 葉180a　Page:文淵閣四庫全書_0004冊.djvu/50 -->
<span style="margin-left: 2em">久不報劾免尋召爲集賢校理忤李林甫調廣陵</span>  
<span style="margin-left: 2em">叅軍韋述薦爲史館待制又忤林甫免林甫死調</span>  
<span style="margin-left: 2em">河南府叅軍安祿山反頴士走山南源洧辟掌書</span>  
<span style="margin-left: 2em">記後爲揚州功曹叅軍復棄官去遂客死於汝南</span>  
<span style="margin-left: 2em">事迹具新唐書文藝傳頴士嘗作伐櫻桃賦以刺</span>  
<span style="margin-left: 2em">林甫唐書本傳譏其褊而晁公武讀書志則稱其</span>  
<span style="margin-left: 2em">每俯臨於蕭墻姦回得而窺伺之句爲知幾先見</span>  
<span style="margin-left: 2em">唐書貶之爲非今考頴士當祿山寵盛之時嘗與</span>  
<span style="margin-left: 2em">柳并策其必反旣而言驗乃詣河南採訪使郭納</span>  
<!-- 册4 葉180b　Page:文淵閣四庫全書_0004冊.djvu/50 -->
<span style="margin-left: 2em">言獻策守禦納言不能用祿山别將攻南陽山南</span>  
<span style="margin-left: 2em">節度使源洧欲遁頴士力持之乃堅意拒賊永王</span>  
<span style="margin-left: 2em">璘嘗召之不赴而與宰相崔圓書請先防江淮之</span>  
<span style="margin-left: 2em">亂旣而劉展又果叛其才畧志節皆過於人不但</span>  
<span style="margin-left: 2em">如晁氏之所云文章根柢固不僅在學問之博奥</span>  
<span style="margin-left: 2em">也頴士文章與李華齊名而頴士尤爲當代所重</span>  
<span style="margin-left: 2em">李邕<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3688.svg?width=24" alt="四庫全書僻字第3688號（負）" title="四庫全書僻字第3688號（負）">一代宿望而進芝草表假手頴士則其推</span>  
<span style="margin-left: 2em">挹可知唐志載頴士游梁新集三卷文集十卷宋</span>  
<span style="margin-left: 2em">志僅載文集十卷而游梁新集巳佚此本前有曹</span>  
<!-- 册4 葉181a　Page:文淵閣四庫全書_0004冊.djvu/50 -->
<span style="margin-left: 2em">溶名字二印葢其所藏僅賦九篇表五篇牒一篇</span>  
<span style="margin-left: 2em">序五篇書五篇史稱其與崔圓書今集中不載書</span>  
<span style="margin-left: 2em">錄解題所云柳幷序今亦佚之又後人抄撮文苑</span>  
<span style="margin-left: 2em">英華唐文粹諸書而成非復十卷之舊矣然殘膏</span>  
<span style="margin-left: 2em">賸馥猶足沾漑正不必以不完爲歉也</span>  
李遐叔文集四卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">唐李華撰華字遐叔趙州贊皇人累中進士宏辭</span>  
<span style="margin-left: 2em">科天寳中遷監察御史徙右補闕安祿山反華爲</span>  
<span style="margin-left: 2em">賊所得僞署鳳閣舍人賊平貶杭州司戸叅軍李</span>  
<!-- 册4 葉181b　Page:文淵閣四庫全書_0004冊.djvu/50 -->
<span style="margin-left: 2em">峴表置幕府擢吏部員外郞以風痺去官卒新舊</span>  
<span style="margin-left: 2em">唐書俱載入文苑傳中舊唐書稱華有文集十卷</span>  
<span style="margin-left: 2em">獨<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2854.svg?width=24" alt="四庫全書僻字第2854號（孤）" title="四庫全書僻字第2854號（孤）">及序則稱自監察以前十卷號爲前集其後</span>  
<span style="margin-left: 2em">二十卷爲中集卷數頗不合馬端臨經籍考不列</span>  
<span style="margin-left: 2em">其目則南宋時原本巳亡此本不知何人所編葢</span>  
<span style="margin-left: 2em">取唐文粹文苑英華所載裒集𩔖次而仍以及序</span>  
<span style="margin-left: 2em">冠之有篇次而無卷目今𨤲爲四卷著之於錄華</span>  
<span style="margin-left: 2em">遭逄危亂汚辱賊庭晩而自傷每托之文章以見</span>  
<span style="margin-left: 2em">意如權臯銘云瀆而不滓瑜而不瑕元德秀銘云</span>  
<!-- 册4 葉184a　Page:文淵閣四庫全書_0004冊.djvu/51 -->
<span style="margin-left: 2em">貞玉白華不緇不磷四皓銘云道不可屈南山採</span>  
<span style="margin-left: 2em">芝竦慕元風徘徊古祠其悔志可以想見然大節</span>  
<span style="margin-left: 2em">一虧萬事瓦裂天下不獨與之論心也至其文詞</span>  
<span style="margin-left: 2em">緜麗精彩煥發實可追配古之作者蕭頴士見所</span>  
<span style="margin-left: 2em">著含元殿賦以爲在景福之上靈光之下雖友朋</span>  
<span style="margin-left: 2em">推挹之詞亦庶幾乎近之矣集中原有盧坦之楊</span>  
<span style="margin-left: 2em">烈婦二傳檢勘其文皆見於李翺集中當由悞採</span>  
<span style="margin-left: 2em">今並從刊削焉</span>  
錢仲文集十卷<sub class="note-yuan">内府藏本</sub>  
<!-- 册4 葉184b　Page:文淵閣四庫全書_0004冊.djvu/51 -->
<span style="margin-left: 2em">唐錢起撰起字仲文吳郡人天寳中舉進士官至</span>  
<span style="margin-left: 2em">考功郞中大厯以還詩格初變開寳渾厚之氣漸</span>  
<span style="margin-left: 2em">遠漸漓風調相高稍趨浮響升降之關十子實爲</span>  
<span style="margin-left: 2em">之職志起與郞士元其稱首也然温秀藴藉不失</span>  
<span style="margin-left: 2em">風人之旨前輩典型猶有存焉其集唐志作一卷</span>  
<span style="margin-left: 2em">晁公武讀書志作二卷今本十卷殆後人所分其</span>  
<span style="margin-left: 2em">中凡古體詩皆題曰往體考陸龜𫎇松陵集亦以</span>  
<span style="margin-left: 2em">古體爲往體葢唐代詩集標目有此二名偶然異</span>  
<span style="margin-left: 2em">文别無他義又集末江行絶句一百首胡震亨唐</span>  
<!-- 册4 葉185a　Page:文淵閣四庫全書_0004冊.djvu/51 -->
<span style="margin-left: 2em">音統籖以爲本錢珝之詩誤入起集有考辨甚詳</span>  
<span style="margin-left: 2em">然舊本流傳相沿巳久且珝固起孫卽附錄祖集</span>  
<span style="margin-left: 2em">之末亦無不可故今仍並存之焉</span>  
華陽集三卷附顧非熊詩一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">唐顧况撰况字逋翁海鹽人至德二年進士德宗</span>  
<span style="margin-left: 2em">時官祕書郞遷著作郞貶饒州司戸叅軍晩年退</span>  
<span style="margin-left: 2em">居茅山自號華陽眞逸集有皇甫湜序稱爲三十</span>  
<span style="margin-left: 2em">卷讀書志作二十卷書錄解題惟載其詩集云本</span>  
<span style="margin-left: 2em">十五卷今止五卷其本今皆不傳此本乃明萬厯</span>  
<!-- 册4 葉185b　Page:文淵閣四庫全書_0004冊.djvu/51 -->
<span style="margin-left: 2em">中况裔孫名端裒其詩文成三卷末附况子非熊</span>  
<span style="margin-left: 2em">詩十餘首文苑英華唐文粹中尚有况詩四首非</span>  
<span style="margin-left: 2em">熊詩一首皆未收入尚未爲賅備也非熊詩有父</span>  
<span style="margin-left: 2em">風長慶登第大中間爲盱眙簿亦棄官隱茅山酉</span>  
<span style="margin-left: 2em">陽雜俎記况作殤子詩旦夕悲吟其子之魂聞之</span>  
<span style="margin-left: 2em">因再生爲况子卽非熊也其事怪誕不足信本事</span>  
<span style="margin-left: 2em">詩又載况紅葉題詩事尤屬不經其所題詩亦猥</span>  
<span style="margin-left: 2em">鄙不足傳皆好事者爲之也舊本所有姑存之以</span>  
<span style="margin-left: 2em">爲談助云爾</span>  
<!-- 册4 葉188a　Page:文淵閣四庫全書_0004冊.djvu/52 -->
翰苑集二十二卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">唐陸贄撰贄事蹟具唐書本傳案藝文志載贄議</span>  
<span style="margin-left: 2em">論表疏集十二卷又翰苑集十卷常處厚纂陳振</span>  
<span style="margin-left: 2em">孫書錄解題載陸宣公集二十二卷中分翰苑榜</span>  
<span style="margin-left: 2em">子爲二集其目亦與史志相同惟晁公武讀書志</span>  
<span style="margin-left: 2em">所載乃祗有奏議十二卷且稱舊有榜子集五卷</span>  
<span style="margin-left: 2em">議論集三卷翰苑集十卷元祐中蘇軾乞校正進</span>  
<span style="margin-left: 2em">呈改從今名疑是裒諸集成此書與史志名目全</span>  
<span style="margin-left: 2em">不相合今考尤袤遂初堂書目所列實作翰苑集</span>  
<!-- 册4 葉188b　Page:文淵閣四庫全書_0004冊.djvu/52 -->
<span style="margin-left: 2em">而錢曾讀書敏求記載所見宋槧大字本二十二</span>  
<span style="margin-left: 2em">卷者亦作翰苑集則自南宋以後巳合議論表疏</span>  
<span style="margin-left: 2em">爲一集而總題以翰苑之名公武所見乃元祐本</span>  
<span style="margin-left: 2em">恐非全冊而今世刊行贄集亦有題作陸宣公奏</span>  
<span style="margin-left: 2em">議者則又沿讀書志而失之者也宋祖作贄傳贊</span>  
<span style="margin-left: 2em">稱其論諫數十百篇譏陳時病皆本仁義炳炳如</span>  
<span style="margin-left: 2em">丹靑而惜德宗之不能盡用故新唐書例不錄排</span>  
<span style="margin-left: 2em">偶之作獨取贄文十餘篇以爲後世法司馬光作</span>  
<span style="margin-left: 2em">資治通鑑尤重贄議論採奏疏三十九篇其後蘇</span>  
<!-- 册4 葉189a　Page:文淵閣四庫全書_0004冊.djvu/52 -->
<span style="margin-left: 2em">軾亦乞以贄文校正進讀葢其文雖多出於一時</span>
