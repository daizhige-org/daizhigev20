## 欽定四庫全書總目 卷八十三　史部三十九　政書類存目一

<!-- 册2 葉2893a　Page:文淵閣四庫全書_0002冊.djvu/728 -->
欽定四庫全書總目卷八十三  
<span style="margin-left: 1em">史部三十九</span>  
<span style="margin-left: 2em">政書類存目一</span>  
杜氏通典詳節四十二卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">不知何人所編檢其板式猶宋時麻沙刻本所列</span>  
<span style="margin-left: 2em">引用諸儒姓氏止於呂祖謙陳傅良葉適三人皆</span>  
<span style="margin-left: 2em">注有文集見行字則南宋人所爲也於杜氏通典</span>  
<span style="margin-left: 2em">八門内汰其兵制一門於禮制門内又刪去喪服</span>  
<span style="margin-left: 2em">之制故六朝諸儒議禮之文藉通典以傳者多不</span>  
<!-- 册2 葉2893b　Page:文淵閣四庫全書_0002冊.djvu/728 -->
<span style="margin-left: 2em">見錄又其去取多不可解如通典卷一載後漢田</span>  
<span style="margin-left: 2em">制凡列荀悅崔寔仲長統三人之說而是書獨存</span>  
<span style="margin-left: 2em">荀悅葢力求簡約而畧無義例者也</span>  
元典章前集六十卷附新集<sub class="note-yuan">無卷數内府藏本</sub>  
<span style="margin-left: 2em">不著撰人名氏前集載世祖卽位至延祐七年英</span>  
<span style="margin-left: 2em">宗初政其綱凡十曰詔令曰聖政曰朝綱曰臺綱</span>  
<span style="margin-left: 2em">曰吏部曰戸部曰禮部曰兵部曰刑部曰工部其</span>  
<span style="margin-left: 2em">目凡三百七十有三每目之中又各分條格新集</span>  
<span style="margin-left: 2em">體例畧倣前集皆續載英宗至治元二年事不分</span>  
<!-- 册2 葉2896a　Page:文淵閣四庫全書_0002冊.djvu/729 -->
<span style="margin-left: 2em">卷數似猶未竟之本也此書始末元史不載惟載</span>  
<span style="margin-left: 2em">至治二年金帶御史李端言世祖以來所定制度</span>  
<span style="margin-left: 2em">宜著爲令使吏不得爲姦治獄有所遵守英宗從</span>  
<span style="margin-left: 2em">之書成名曰大元通制頒行天下凡二千五百三</span>  
<span style="margin-left: 2em">十九條計其時代正與此書相同而二千五百三</span>  
<span style="margin-left: 2em">十九條之數則與此書不相應卷首所載中書省</span>  
<span style="margin-left: 2em">劄亦不相合葢各爲一編非通制也考元史以八</span>  
<span style="margin-left: 2em">月成書諸志皆潦草殊甚不足徴一代之法制而</span>  
<span style="margin-left: 2em">元經世大典又久已散佚其散見永樂大典者顛</span>  
<!-- 册2 葉2896b　Page:文淵閣四庫全書_0002冊.djvu/729 -->
<span style="margin-left: 2em">倒割裂不可重編遂使百年掌故無成書之可考</span>  
<span style="margin-left: 2em">此書於當年法令分門臚載採掇頗詳固宜存備</span>  
<span style="margin-left: 2em">一朝之故事然所載皆案牘之文兼雜方言俗語</span>  
<span style="margin-left: 2em">浮詞妨要者十之七八又體例瞀亂漫無端緒觀</span>  
<span style="margin-left: 2em">省劄中有置簿編寫之語知此乃吏胥鈔記之條</span>  
<span style="margin-left: 2em">格不足以資考證故初擬繕錄而終存其目焉</span>  
明祖訓一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明洪武二年命中書編次其目十有三一祖訓首</span>  
<span style="margin-left: 2em">章一持守一嚴祭祀一謹出入一愼國政一禮儀</span>  
<!-- 册2 葉2897a　Page:文淵閣四庫全書_0002冊.djvu/729 -->
<span style="margin-left: 2em">一法律一内令一内官一職制一兵衞一營繕一</span>  
<span style="margin-left: 2em">供用至六年五月書成太祖自爲序復命宋濂序</span>  
<span style="margin-left: 2em">之此本佚濂序惟太祖之序載篇首序稱開導後</span>  
<span style="margin-left: 2em">人立爲家法大書揭於西廡朝夕親覽以求至當</span>  
<span style="margin-left: 2em">首尾六年凡七謄錄稿至今方定命翰林編輯成</span>  
<span style="margin-left: 2em">書禮部刋印云云然則諸詞臣僅繕錄排纂而已</span>  
<span style="margin-left: 2em">其文辭悉太祖御撰也其中多言親藩體制大抵</span>  
<span style="margin-left: 2em">懲前代之失欲兼用封建郡縣以相牽制故親王</span>  
<span style="margin-left: 2em">與方鎭各掌兵王不得與民事官吏亦不得預王</span>  
<!-- 册2 葉2897b　Page:文淵閣四庫全書_0002冊.djvu/729 -->
<span style="margin-left: 2em">府事尤諄諄以姦臣壅蔽離間爲慮所以防之者</span>  
<span style="margin-left: 2em">甚至如云若大臣行姦不令王見天子私下傅致</span>  
<span style="margin-left: 2em">其罪而遇不幸者其長史司併䕶衞移文五軍都</span>  
<span style="margin-left: 2em">督府索取姦臣族滅其家又云如朝無正臣内有</span>  
<span style="margin-left: 2em">姦惡則親王訓兵待命或領正兵討平然則靖難</span>  
<span style="margin-left: 2em">之事肇釁於此高煦宸濠遂接踵效尤是亦矯枉</span>  
<span style="margin-left: 2em">過直作法於涼之弊矣皇甫錄明記畧云祖訓所</span>  
<span style="margin-left: 2em">以教戒後世者甚備獨無委任閹人之禁世以爲</span>  
<span style="margin-left: 2em">怪或云本有此條因版在司禮監削去耳然永樂</span>  
<!-- 册2 葉2900a　Page:文淵閣四庫全書_0002冊.djvu/730 -->
<span style="margin-left: 2em">大典所載亦與此本相同則似非後來削去錄所</span>  
<span style="margin-left: 2em">云云葢以意揣之也</span>  
明朝典彚二百卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明徐學聚撰學聚有厯朝璫鑑已著錄是書採錄</span>  
<span style="margin-left: 2em">明代典故自洪武訖隆慶分類編纂上自實錄下</span>  
<span style="margin-left: 2em">訖稗乘條分類萃凡二百門卷一至三十三卷爲</span>  
<span style="margin-left: 2em">朝政大端三十四卷以下則以六部分標記載頗</span>  
<span style="margin-left: 2em">爲繁富然分隷不無錯雜如明制六部與<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">寺院</span>  
<span style="margin-left: 2em">監不相統攝此書則以宗人府都察院以下皆歸</span>  
<!-- 册2 葉2900b　Page:文淵閣四庫全書_0002冊.djvu/730 -->
<span style="margin-left: 2em">入吏部又如廟號尊諡陵寢巡幸郊祀祈禱祠醮</span>  
<span style="margin-left: 2em">皆禮部職也校閱兵部職也耕<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3641.svg?width=24" alt="四庫全書僻字第3641號（蠶）" title="四庫全書僻字第3641號（蠶）">莊田<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3297.svg?width=24" alt="四庫全書僻字第3297號（勲）" title="四庫全書僻字第3297號（勲）">戚田土</span>  
<span style="margin-left: 2em">皆戸部職也此書則一切歸入朝政大端中於體</span>  
<span style="margin-left: 2em">例皆爲未協又採摭浩博而皆不著其出典亦未</span>  
<span style="margin-left: 2em">免無徴不信李燾續通鑑長編凡所引證必著書</span>  
<span style="margin-left: 2em">名不如是之莫知所本也</span>  
經世實用編二十八巻<sub class="note-yuan">江蘇周厚堉家藏本</sub>  
<span style="margin-left: 2em">明馮應京撰應京有六家詩名物疏已著錄是編</span>  
<span style="margin-left: 2em">乃萬厯甲辰應京下詔獄時所成分乾元亨利貞</span>  
<!-- 册2 葉2901a　Page:文淵閣四庫全書_0002冊.djvu/730 -->
<span style="margin-left: 2em">五集乾集十卷元集二卷亨集二卷利集四卷貞</span>  
<span style="margin-left: 2em">集九巻首載明太祖心法祖訓以迄取士任官重</span>  
<span style="margin-left: 2em">農經武禮樂射御書數而終之以諸儒語錄正學</span>  
<span style="margin-left: 2em">考大都禀祖訓爲律令而以厯朝沿革附之其用</span>  
<span style="margin-left: 2em">意不無可取至以乾元亨利貞分集取羑里演易</span>  
<span style="margin-left: 2em">之義則未免於<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2673.svg?width=24" alt="四庫全書僻字第2673號（僭）" title="四庫全書僻字第2673號（僭）">矣</span>  
明典章<sub class="note-yuan">無卷數　浙江巡撫採進本</sub>  
<span style="margin-left: 2em">不著撰人名氏輯太祖吳元年以後世宗嘉靖十</span>  
<span style="margin-left: 2em">五年以前朝廷制誥典制大抵從實錄抄出編次</span>  
<!-- 册2 葉2901b　Page:文淵閣四庫全書_0002冊.djvu/730 -->
<span style="margin-left: 2em">殊無體例</span>  
會典抄畧<sub class="note-yuan">無巻數内府藏本</sub>  
<span style="margin-left: 2em">不著編輯者名氏前有題詞稱會典一書卷逾二</span>  
<span style="margin-left: 2em">百鬻之價多携之<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3615.svg?width=24" alt="四庫全書僻字第3615號（囊）" title="四庫全書僻字第3615號（囊）">重士有自操槧以至厯官不</span>  
<span style="margin-left: 2em">獲一睹者其在里巷齊民尤可知已但全書紀載</span>  
<span style="margin-left: 2em">雖夥其當訓行者槩有大畧因手抄畧節約十餘</span>  
<span style="margin-left: 2em">帙間附註通紀一二事以備叅考云云是其書在</span>  
<span style="margin-left: 2em">陳建通紀之後矣</span>  
<span style="margin-left: 1em">右政書類通制之屬七部三百三十一卷<sub class="note-yuan">内二部無巻數</sub>皆</span>  
<!-- 册2 葉2904a　Page:文淵閣四庫全書_0002冊.djvu/731 -->
<span style="margin-left: 1em">附存目</span>  
別本漢舊儀二卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">舊本題漢議郞東海衞宏敬仲撰宏所撰漢官舊</span>  
<span style="margin-left: 2em">儀已於永樂大典内繕出著錄語詳本條下此本</span>  
<span style="margin-left: 2em">書名與後漢書宏本傳合而四篇之數仍不合併</span>  
<span style="margin-left: 2em">與書錄解題三卷之數亦不相應其中多引胡廣</span>  
<span style="margin-left: 2em">語廣爲安帝時人宏爲議郞則在光武帝時先後</span>  
<span style="margin-left: 2em">相隔六十餘年不應宏書之内先有廣名又時時</span>  
<span style="margin-left: 2em">稱衞宏曰亦必非宏自著書之體其注中併引及</span>  
<!-- 册2 葉2904b　Page:文淵閣四庫全書_0002冊.djvu/731 -->
<span style="margin-left: 2em">周禮註疏註出鄭康成疏出唐賈公彥宏益不得</span>  
<span style="margin-left: 2em">見之矣葢原書久佚後人從漢書註中摘錄而成</span>  
<span style="margin-left: 2em">觀其中竹宫去壇三里一句前後兩見則爲雜鈔</span>  
<span style="margin-left: 2em">致複無疑矣今宋代舊本猶存永樂大典中業已</span>  
<span style="margin-left: 2em">校錄刋刻重顯於世此後人裒集之本固可置而</span>  
<span style="margin-left: 2em">不論矣</span>  
貢舉叙畧一卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">舊本題宋陳彭年撰載曹溶學海類編中實册府</span>  
<span style="margin-left: 2em">元龜貢舉一門之總序以彭年爲作序五人之一</span>  
<!-- 册2 葉2905a　Page:文淵閣四庫全書_0002冊.djvu/731 -->
<span style="margin-left: 2em">遂題彭年之名然原本不言此序出彭年也</span>  
通祀輯畧三卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">不著撰人名氏載厯代崇祀孔廟禮儀起魯哀公</span>  
<span style="margin-left: 2em">迄宋咸淳三年疑爲元人作也凡三卷上卷分諡</span>  
<span style="margin-left: 2em">號廟祀殿額坐像冕服封爵位序配享八門中卷</span>  
<span style="margin-left: 2em">分從祀鄉賢二門下卷分釋奠樂章曲阜廟幸學</span>  
<span style="margin-left: 2em">謁廟告遷奉安五門</span>  
明堂或問一卷<sub class="note-yuan">左都御史張若溎家藏本</sub>  
<span style="margin-left: 2em">明世宗肅皇帝御撰嘉靖十七年致仕同知豐坊</span>  
<!-- 册2 葉2905b　Page:文淵閣四庫全書_0002冊.djvu/731 -->
<span style="margin-left: 2em">疏請復古禮建明堂加興獻帝廟號稱宗以配上</span>  
<span style="margin-left: 2em">帝詔下禮部會議尙書嚴嵩等皆以明堂爲應建</span>  
<span style="margin-left: 2em">而於稱宗配享二事則依違其辭戸部侍郞唐胄</span>  
<span style="margin-left: 2em">抗疏言宜以太宗配享帝怒下胄獄嵩乃再會廷</span>  
<span style="margin-left: 2em">臣議請以興獻帝稱宗配食帝以疏不言祔廟留</span>  
<span style="margin-left: 2em">中不下復設爲臣下問答之詞作或問一篇大畧</span>  
<span style="margin-left: 2em">言文皇遠祖不應嚴父之義宜以父配稱宗雖無</span>  
<span style="margin-left: 2em">定說尊親崇上義所當行旣稱宗則當祔廟豈有</span>  
<span style="margin-left: 2em">太廟中四親不具之禮是年九月遂尊興獻帝爲</span>  
<!-- 册2 葉2908a　Page:文淵閣四庫全書_0002冊.djvu/732 -->
<span style="margin-left: 2em">睿宗祔太廟又卽元極寳殿爲明堂大享上帝以</span>  
<span style="margin-left: 2em">睿宗配皆如帝指此本前有帝所自作小序後以</span>  
<span style="margin-left: 2em">配享詔書一通附之</span>  
正孔子祀典說一卷<sub class="note-yuan">左都御史張若溎家藏本</sub>  
<span style="margin-left: 2em">明世宗肅皇帝御撰嘉靖九年大學士張璁請正</span>  
<span style="margin-left: 2em">先師祀典帝因言聖人尊天與尊親同今全用祀</span>  
<span style="margin-left: 2em">天儀非正禮諡號章服悉宜改正璁遂請改孔子</span>  
<span style="margin-left: 2em">稱先師不稱王用木主不用塑像籩豆用十樂用</span>
