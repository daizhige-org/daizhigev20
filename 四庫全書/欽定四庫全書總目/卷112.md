## 欽定四庫全書總目 卷一百十二　子部二十二　藝術類一

<!-- 册3 葉1668：整葉圖版，無文字記錄 -->
<!-- 册3 葉1669a　Page:文淵閣四庫全書_0003冊.djvu/422 -->
<span style="margin-left: 1em">欽定四庫全書總目卷一百十二</span>  
<span style="margin-left: 1em">子部二十二</span>  
<span style="margin-left: 2em">藝術𩔖一</span>  
<span style="margin-left: 3em">古言六書後明八法於是字學書品爲二事左</span>  
<span style="margin-left: 3em">圖右史畫亦古義丹靑金碧漸别爲賞鑑一途</span>  
<span style="margin-left: 3em">衣裳製而纂組巧飲食造而陸海陳踵事增華</span>  
<span style="margin-left: 3em">𫝑有馴致然均與文史相岀入要爲藝事之首</span>  
<span style="margin-left: 3em">也琴本雅音舊列樂部後世俗工撥捩率造新</span>  
<span style="margin-left: 3em">聲非復淸廟生民之奏是特一技耳摹印本六</span>  
<!-- 册3 葉1669b　Page:文淵閣四庫全書_0003冊.djvu/422 -->
<span style="margin-left: 3em">體之一自漢白元朱務矜鐫刻與小學遠矣射</span>  
<span style="margin-left: 3em">義投壺載於戴記諸家所述亦事異禮經均退</span>  
<span style="margin-left: 3em">列藝術於義差允至於譜博奕諭歌舞名品紛</span>  
<span style="margin-left: 3em">繁事皆瑣屑亦併爲一𩔖統曰雜技焉</span>  
古畫品錄一卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">南齊謝赫撰赫不知何許人姚最續畫品錄稱其</span>  
<span style="margin-left: 2em">寫貌人物不須對看所須一覽便歸操筆㸃刷精</span>  
<span style="margin-left: 2em">妍意存形似目想毫髮皆無遺失麗服靚妝隨時</span>  
<span style="margin-left: 2em">變改直眉曲髩與世競新别體細微多自赫始委</span>  
<!-- 册3 葉1672a　Page:文淵閣四庫全書_0003冊.djvu/423 -->
<span style="margin-left: 2em">巷逐末皆𩔖效顰至於氣韻精靈未窮生動之致</span>  
<span style="margin-left: 2em">筆路纎弱不副雅壯之懷然中興以來象人爲最</span>  
<span style="margin-left: 2em">據其所說殆後來院畫之發源張彦遠名畫記又</span>  
<span style="margin-left: 2em">稱其有安期先生圖傳於代要亦六朝佳手也是</span>  
<span style="margin-left: 2em">書等差畫家優劣晁公武讀書志謂分四品今考</span>  
<span style="margin-left: 2em">所列實爲六品葢讀書志傳寫之訛大抵謂畫有</span>  
<span style="margin-left: 2em">六法兼善者難自陸探微以下以次品第各爲序</span>  
<span style="margin-left: 2em">引僅得二十七人意頗矜愼惟姚最頗詆其謬謂</span>  
<span style="margin-left: 2em">如長康之美擅高徃代矯然獨歩終始無䨇列於</span>  
<!-- 册3 葉1672b　Page:文淵閣四庫全書_0003冊.djvu/423 -->
<span style="margin-left: 2em">下品尤所未安李嗣眞亦譏其黜衛進曹有渉貴</span>  
<span style="margin-left: 2em">耳之論然張彦遠稱謝赫評畫最爲允愜姚李品</span>  
<span style="margin-left: 2em">藻有所未安則固以是書爲定論所言六法畫家</span>  
<span style="margin-left: 2em">宗之亦至今千載不易也</span>  
書品一卷<sub class="note-yuan">浙江鮑士㳟家藏本</sub>  
<span style="margin-left: 2em">梁庾肩吾撰肩吾字子愼新野人起家晉安王國</span>  
<span style="margin-left: 2em">常侍元帝時官至度支尙書事蹟具梁書文學傳</span>  
<span style="margin-left: 2em">是書載漢至齊梁能眞草者一百二十八人分爲</span>  
<span style="margin-left: 2em">九品毎品各繫以論而以總序冠於前考竇臮述</span>  
<!-- 册3 葉1673a　Page:文淵閣四庫全書_0003冊.djvu/423 -->
<span style="margin-left: 2em">書賦稱肩吾通塞幷乏天性工歸文華拙見草正</span>  
<span style="margin-left: 2em">徒聞師院何至遼敻使鉛刀之均鋒稱並利而則</span>  
<span style="margin-left: 2em">佞云云其於肩吾書學不甚推許又其論述作一</span>  
<span style="margin-left: 2em">條稱庾中庻品格拘於文華則於是書亦頗致不</span>  
<span style="margin-left: 2em">滿然其論列多有理致究不失先民典型如序稱</span>  
<span style="margin-left: 2em">尋隷體發源秦時隷人下邳程邈所作始皇見而</span>  
<span style="margin-left: 2em">重之以奏事繁多<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3478.svg?width=24" alt="四庫全書僻字第3478號（篆）" title="四庫全書僻字第3478號（篆）">字難製遂作此法故曰隷書</span>  
<span style="margin-left: 2em">今時正書是也此足正歐陽修以八分爲隷之誤</span>  
<span style="margin-left: 2em">惟唐之魏徵與肩吾時代邈不相及而並列其間</span>  
<!-- 册3 葉1673b　Page:文淵閣四庫全書_0003冊.djvu/423 -->
<span style="margin-left: 2em">殊爲顚舛故王士禎居易錄詆毛晉刋本之訛又</span>  
<span style="margin-left: 2em">序稱一百二十八人而書中所列實止一百二十</span>  
<span style="margin-left: 2em">三人數亦不符殆後人已有所增削然張彦遠法</span>  
<span style="margin-left: 2em">書要錄全載此書巳同此本併魏徵之謬亦同則</span>  
<span style="margin-left: 2em">其來久矣</span>  
續畫品一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">舊本題陳吳興姚最撰今考書中稱梁元帝爲湘</span>  
<span style="margin-left: 2em">東殿下則作是書時猶在江陵卽位之前葢梁人</span>  
<span style="margin-left: 2em">而入陳者猶玉臺新詠作於梁簡文在東宫時而</span>  
<!-- 册3 葉1676a　Page:文淵閣四庫全書_0003冊.djvu/424 -->
<span style="margin-left: 2em">今本皆題陳徐陵耳其書繼謝赫古畫品錄而作</span>  
<span style="margin-left: 2em">以赫所品高下多失其實故但叙時代不分品目</span>  
<span style="margin-left: 2em">所錄始於梁元帝終於解蒨凡二十人各爲論斷</span>  
<span style="margin-left: 2em">中嵇實鈞聶松合一論釋僧珍僧覺合一論釋迦</span>  
<span style="margin-left: 2em">佛陀吉底俱麾羅菩提合一論凡爲論十六則名</span>  
<span style="margin-left: 2em">下間有附註如湘東殿下條註曰梁元帝初封湘</span>  
<span style="margin-left: 2em">東王嘗畫芙蓉圖醮鼎圖毛棱條下註曰惠秀姪</span>  
<span style="margin-left: 2em">尚似是最之本文至張僧繇條下註曰五代梁時</span>  
<span style="margin-left: 2em">吳興人則決不出最手葢皆後人所益也凡所論</span>  
<!-- 册3 葉1676b　Page:文淵閣四庫全書_0003冊.djvu/424 -->
<span style="margin-left: 2em">斷多不過五六行少或止於三四句而出以儷詞</span>  
<span style="margin-left: 2em">氣體雅儁<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">爲唐以前語非後人所能依託也</span>  
貞觀公私畫史一卷<sub class="note-yuan">浙江鮑士㳟家藏本</sub>  
<span style="margin-left: 2em">唐裴孝源撰孝源里貫未詳卷首有貞觀十三年</span>  
<span style="margin-left: 2em">八月自序結銜題中書舍人按唐書藝文志有裴</span>  
<span style="margin-left: 2em">孝源畫品錄一卷註曰中書舍人與此序合然註</span>  
<span style="margin-left: 2em">又曰記貞觀顯慶年事而此書序中則稱大唐漢</span>  
<span style="margin-left: 2em">王元昌毎燕時暇日多與其流商𣙜精奥以予耿</span>  
<span style="margin-left: 2em">尙嘗賜討論遂命魏晉以來前賢遺跡所存及品</span>  
<!-- 册3 葉1677a　Page:文淵閣四庫全書_0003冊.djvu/424 -->
<span style="margin-left: 2em">格高下列爲先後起於高貴鄉公終於大唐貞觀</span>  
<span style="margin-left: 2em">十三年秘府及佛寺并私家所畜共二百九十八</span>  
<span style="margin-left: 2em">卷屋壁四十七所爲貞觀公私畫錄云云與註所</span>  
<span style="margin-left: 2em">言絶不相符考張彦遠名畫錄引孝源畫錄最多</span>  
<span style="margin-left: 2em">皆此書所無葢孝源别有一書記貞觀顯慶間畫</span>  
<span style="margin-left: 2em">家品第如謝赫古畫品錄之例非此書也又序稱</span>  
<span style="margin-left: 2em">高貴鄉公以下而此本所列乃以宋陸探微爲首</span>  
<span style="margin-left: 2em">反居其前疑傳寫之誤又序稱止於貞觀十三年</span>  
<span style="margin-left: 2em">而此本所列皆隋代收藏官本其畫壁亦終於楊</span>  
<!-- 册3 葉1677b　Page:文淵閣四庫全書_0003冊.djvu/424 -->
<span style="margin-left: 2em">契丹均不可解考其序末稱又集新錄官庫畫總</span>  
<span style="margin-left: 2em">二百九十八卷三百三十卷是隋室官十三卷是</span>  
<span style="margin-left: 2em">左僕射蕭瑀進二十卷是楊素家得三十卷許善</span>  
<span style="margin-left: 2em">心進十卷髙平縣行書佐張氏所獻四卷褚安福</span>  
<span style="margin-left: 2em">進近十八卷先在秘府亦無所得人名並有天和</span>  
<span style="margin-left: 2em">年月其間有二十三卷恐非晉宋人眞迹云云其</span>  
<span style="margin-left: 2em">文重沓不明疑傳寫有誤推其大意似尙有新錄</span>  
<span style="margin-left: 2em">今佚之耳書中皆前列畫名後列作者之名而以</span>  
<span style="margin-left: 2em">梁太淸目所有梁太淸目所無分註於下太淸目</span>  
<!-- 册3 葉1680a　Page:文淵閣四庫全書_0003冊.djvu/425 -->
<span style="margin-left: 2em">旣不可見則考隋以前古畫名目者莫古於是是</span>  
<span style="margin-left: 2em">亦賞鑒家之祖本矣</span>  
書譜一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">唐孫過庭撰竇蒙述書賦註曰孫過庭字䖍禮富</span>  
<span style="margin-left: 2em">陽人右衛冑曹叅軍張懷瓘書斷則云孫䖍禮字</span>  
<span style="margin-left: 2em">過庭陳留人官至率府錄事叅軍二人俱相距不</span>  
<span style="margin-left: 2em">遠而所記名字爵里不同殆與舊唐書稱房喬字</span>  
<span style="margin-left: 2em">元齡新唐書稱房元齡字喬者同一訛異疑唐人</span>  
<span style="margin-left: 2em">多以字行故各據所聞不能畫一也是書篇末自</span>  
<!-- 册3 葉1680b　Page:文淵閣四庫全書_0003冊.djvu/425 -->
<span style="margin-left: 2em">題垂拱三年葢武后時作書斷謂之筆意論然世</span>  
<span style="margin-left: 2em">傳石刻乃其手迹篇中自稱名曰書譜則作書譜</span>  
<span style="margin-left: 2em">爲是矣過庭之書頗爲竇臮述書賦所詆然自宋</span>  
<span style="margin-left: 2em">以來皆推能品不以臮言爲然張懷瓘推奬是書</span>  
<span style="margin-left: 2em">亦稱其深得㫖趣故操翰者奉爲指南然過庭自</span>  
<span style="margin-left: 2em">稱撰爲六篇分爲兩卷此本乃止一篇疑全書巳</span>  
<span style="margin-left: 2em">佚傳流眞迹僅存其總序之文以前賢緒論姑存</span>  
<span style="margin-left: 2em">以見一班而仍題其全書之名耳然微言奥義已</span>  
<span style="margin-left: 2em">足見其大凡矣</span>  
<!-- 册3 葉1681a　Page:文淵閣四庫全書_0003冊.djvu/425 -->
書斷三卷<sub class="note-yuan">浙江鮑士㳟家藏本</sub>  
<span style="margin-left: 2em">唐張懷瓘撰是書唐書藝文志著錄稱懷瓘爲開</span>  
<span style="margin-left: 2em">无中翰林院供奉竇蒙述書賦注則云懷瓘海陵</span>  
<span style="margin-left: 2em">人鄂州司馬與志不同然述書賦張懷瓌條下又</span>  
<span style="margin-left: 2em">注云懷瓌懷瓘弟盛王府司馬兄弟並翰林待詔</span>  
<span style="margin-left: 2em">則與志相合葢嘗爲鄂州司馬終於翰林供奉二</span>  
<span style="margin-left: 2em">書各舉其一官爾所錄皆古今書體及能書人名</span>  
<span style="margin-left: 2em">上卷列古文大<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3478.svg?width=24" alt="四庫全書僻字第3478號（篆）" title="四庫全書僻字第3478號（篆）">籀文小<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3478.svg?width=24" alt="四庫全書僻字第3478號（篆）" title="四庫全書僻字第3478號（篆）">八分隷書章草行書</span>  
<span style="margin-left: 2em">飛白草書十體各述其源流系之以贊末爲總論</span>  
<!-- 册3 葉1681b　Page:文淵閣四庫全書_0003冊.djvu/425 -->
<span style="margin-left: 2em">一篇中卷下卷分神妙能三品毎品各以體分凡</span>  
<span style="margin-left: 2em">神品二十五人除各體重複得十二人妙品九十</span>  
<span style="margin-left: 2em">八人除各體重複得三十九人能品一百七人除</span>  
<span style="margin-left: 2em">各體重複得三十五人前列姓名後爲小傳傳中</span>  
<span style="margin-left: 2em">附錄又三十八人其記述頗詳評論亦允張彦遠</span>  
<span style="margin-left: 2em">法書要錄全載其文葢當代以爲精鑒矣</span>  
述書賦二卷<sub class="note-yuan">浙江鮑士㳟家藏本</sub>  
<span style="margin-left: 2em">唐竇臮撰竇蒙注臮字靈長扶風人官至檢校戸</span>  
<span style="margin-left: 2em">部員外郎宋汴節度叅謀蒙字子全臮之兄官至</span>  
<!-- 册3 葉1684a　Page:文淵閣四庫全書_0003冊.djvu/426 -->
<span style="margin-left: 2em">試國子司業兼太原縣令並見徐浩古迹記按張</span>  
<span style="margin-left: 2em">彦遠法書要錄稱臮作述書賦精窮㫖要詳辨秘</span>  
<span style="margin-left: 2em">義今觀其賦上篇所述自上古至南北朝下篇所</span>  
<span style="margin-left: 2em">述自唐代髙祖太宗武后睿宗明皇以下而終於</span>
