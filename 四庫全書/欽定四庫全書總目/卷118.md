## 欽定四庫全書總目 卷一百十八　子部二十八　雜家類二

<!-- 册3 葉2224：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷一百十八  
<span style="margin-left: 1em">子部二十八</span>  
<span style="margin-left: 2em">雜家類二</span>  
白虎通義四卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">漢班固撰隋書經籍志載白虎通六卷不著撰人</span>  
<span style="margin-left: 2em">唐書藝文志載白虎通義六卷始題班固之名崇</span>  
<span style="margin-left: 2em">文總目載白虎通德論十卷凡十四篇陳振孫書</span>  
<span style="margin-left: 2em">錄解題亦作千卷云凡四十四門今本爲元大德</span>  
<span style="margin-left: 2em">中劉世常所藏凡四十四篇與陳氏所言相符知</span>  
<!-- 册3 葉2225b　Page:文淵閣四庫全書_0003冊.djvu/561 -->
<span style="margin-left: 2em">崇文總目所云十四篇者乃傳寫脫一四字耳然</span>  
<span style="margin-left: 2em">僅分四卷視諸志所載又不同朱翌猗覺寮雜記</span>  
<span style="margin-left: 2em">稱荀子注引白虎通天子之馬六句今本無之然</span>  
<span style="margin-left: 2em">則輾轉傳寫或亦有所脫佚翌因是而指其僞撰</span>  
<span style="margin-left: 2em">則非篤論也據後漢書固本傳稱天子會諸儒講</span>  
<span style="margin-left: 2em">論五經作白虎通德論令固撰集其事而楊終傳</span>  
<span style="margin-left: 2em">稱終言宣帝博徵羣儒論定五經於石渠閣方今</span>  
<span style="margin-left: 2em">天下少事學者得成其業而章句之徒破壞大體</span>  
<span style="margin-left: 2em">宜如石渠故事永爲世則於是詔諸儒於白虎觀</span>  
<!-- 册3 葉2228a　Page:文淵閣四庫全書_0003冊.djvu/562 -->
<span style="margin-left: 2em">論考同異焉會終坐事繫獄博士趙博校書郞班</span>  
<span style="margin-left: 2em">固賈逵等以終深曉春秋學多異聞表請之卽日</span>  
<span style="margin-left: 2em">貰出丁鴻傳稱肅宗詔鴻與廣平王羡及諸儒樓</span>  
<span style="margin-left: 2em">望成封桓郁賈逵等論定五經同異於北宫白虎</span>  
<span style="margin-left: 2em">觀使五官中郎將魏應主承制問難侍中淳于恭</span>  
<span style="margin-left: 2em">奏上帝親稱制臨决時張酺召馴李育皆得與於</span>  
<span style="margin-left: 2em">白虎觀葢諸儒可考者十有餘人其議奏統名白</span>  
<span style="margin-left: 2em">虎通德論猶不名通義後漢書儒林傳序言建初</span>  
<span style="margin-left: 2em">中大會諸儒於白虎觀考詳同異連月乃罷肅宗</span>  
<!-- 册3 葉2228b　Page:文淵閣四庫全書_0003冊.djvu/562 -->
<span style="margin-left: 2em">親臨稱制如石渠故事顧命史臣著爲通義唐章</span>  
<span style="margin-left: 2em">懷太子賢注云卽白虎通義是足証固撰集後乃</span>  
<span style="margin-left: 2em">名其書曰通義唐志所載葢其本名崇文總目稱</span>  
<span style="margin-left: 2em">白虎通德論失其實矣隋志删去義字葢流俗省</span>  
<span style="margin-left: 2em">略有此一名故唐劉知幾史通序引白虎通風俗</span>  
<span style="margin-left: 2em">通爲說實則逓相祖襲忘其本始者也書中徵引</span>  
<span style="margin-left: 2em">六經傳記而外渉及緯䜟乃東漢習尙使然又有</span>  
<span style="margin-left: 2em">王度記三正記别名記親屬記則禮之逸篇方漢</span>  
<span style="margin-left: 2em">時崇尙經學咸兢兢守其師承古義舊聞多存乎</span>  
<!-- 册3 葉2229a　Page:文淵閣四庫全書_0003冊.djvu/562 -->
<span style="margin-left: 2em">是洵治經者所宜從事也</span>  
<span style="margin-left: 1em">國朝任啟運嘗舉正其缺作白虎通撾譌見所自爲</span>  
<span style="margin-left: 2em">制藝序中今其書不傳所糾之當否不可考矣</span>  
獨斷二卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">漢蔡邕撰王應麟玉海謂是書間有顚錯嘉祐中</span>  
<span style="margin-left: 2em">余擇中更爲次序釋以已說故别本題新定獨斷</span>  
<span style="margin-left: 2em">擇中之本今不傳然今書中序厯代帝系未云從</span>  
<span style="margin-left: 2em">高祖乙未至今嵗壬子四百一十年壬子爲靈帝</span>  
<span style="margin-left: 2em">建寧五年而靈帝世系未行小註乃有二十二年</span>  
<!-- 册3 葉2229b　Page:文淵閣四庫全書_0003冊.djvu/562 -->
<span style="margin-left: 2em">之事又有獻帝之謚則决非邕之本文蓋後人亦</span>  
<span style="margin-left: 2em">有所竄亂也是書於禮制多信禮記不從周官若</span>  
<span style="margin-left: 2em">五等封爵全與大司徒異而各條解義與鄭元禮</span>  
<span style="margin-left: 2em">註合者甚多其釋六祝一條與康成大祝註字句</span>  
<span style="margin-left: 2em">全符則其所根據當同出一書又續漢書輿服志</span>  
<span style="margin-left: 2em">樊噲冠廣九寸高七寸前後各出四寸是書則謂</span>  
<span style="margin-left: 2em">高七寸前岀四寸其詞小異劉昭輿服志註引獨</span>  
<span style="margin-left: 2em">斷曰三公諸侯九旒卿七旒今本則作三公九諸</span>  
<span style="margin-left: 2em">侯卿七建華冠註引獨斷曰其狀若婦人縷鹿今</span>  
<!-- 册3 葉2232a　Page:文淵閣四庫全書_0003冊.djvu/563 -->
<span style="margin-left: 2em">本並無此文又初學記引獨斷曰乘輿之車皆副</span>  
<span style="margin-left: 2em">轄者施轄於外乃復設轄者也與今本亦全異此</span>  
<span style="margin-left: 2em">或諸家援引偶訛或今本傳寫脫誤均未可知然</span>  
<span style="margin-left: 2em">全書條理統貫雖小有參錯固不害其宏旨究考</span>  
<span style="margin-left: 2em">證家之淵藪也</span>  
古今註三卷附中華古今註三卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">古今註三卷舊本題晉崔豹撰中華古今註三卷</span>  
<span style="margin-left: 2em">舊本題後唐太學博士馬縞撰豹書無序䟦縞書</span>  
<span style="margin-left: 2em">前有自序稱昔崔豹古今註博識雖廣殆有闕文</span>  
<!-- 册3 葉2232b　Page:文淵閣四庫全書_0003冊.djvu/563 -->
<span style="margin-left: 2em">洎乎黃初莫之聞見今添其註以釋其義然今互</span>  
<span style="margin-left: 2em">勘二書自宋齊以後事二十九條外其魏晉以前</span>  
<span style="margin-left: 2em">之事豹書惟草木一類及鳥獸類吐綬鳥一名功</span>  
<span style="margin-left: 2em">曹七字爲縞書所無縞書惟服飾一類及開卷宫</span>  
<span style="margin-left: 2em">室一條封部兵陳二條馬ခ犬二條爲豹書所缺</span>  
<span style="margin-left: 2em">其餘所載並皆相同不過次序稍有後先字句偶</span>  
<span style="margin-left: 2em">有加減縞所謂添註釋義絶無其事又縞書中卷</span>  
<span style="margin-left: 2em">云棒崔正熊註車輻也使全襲豹語不應此條獨</span>  
<span style="margin-left: 2em">著豹名考太平御覽所引書名有豹書而無縞書</span>  
<!-- 册3 葉2233a　Page:文淵閣四庫全書_0003冊.djvu/563 -->
<span style="margin-left: 2em">文獻通考襍家類又祇有縞書而無豹書知豹書</span>  
<span style="margin-left: 2em">久亡縞書晚出後人摭其中魏以前事贋爲豹作</span>  
<span style="margin-left: 2em">又檢校永樂大典所載蘇鶚演義與二書相同者</span>  
<span style="margin-left: 2em">十之五六則不特豹書出於依托卽縞書亦不免</span>  
<span style="margin-left: 2em">於剿襲特以相傳旣久姑存以備一家耳考劉孝</span>  
<span style="margin-left: 2em">標世說註載豹字正能晉惠帝時官至太傅馬縞</span>  
<span style="margin-left: 2em">稱爲正熊二字相近葢有一誤新舊五代史均有</span>  
<span style="margin-left: 2em">縞傳載其明經及第登㧞萃科仕梁爲太常修撰</span>  
<span style="margin-left: 2em">累厯尙書郞參知理院事遷太常少卿唐莊宗時</span>  
<!-- 册3 葉2233b　Page:文淵閣四庫全書_0003冊.djvu/563 -->
<span style="margin-left: 2em">爲中書舍人刑部侍郞權判太常卿明宗時貶綏</span>  
<span style="margin-left: 2em">州司馬復爲太子賔客遷戸部兵部侍郞終於國</span>  
<span style="margin-left: 2em">子祭酒今本題唐太學博士葢據書錄解題然稱</span>  
<span style="margin-left: 2em">爲太學博士實振孫之誤至其時代則振孫亦稱</span>  
<span style="margin-left: 2em">後唐不專稱唐實明人刋本以意改之也</span>  
資暇集三卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">唐李匡父撰舊本或題李濟翁葢宋刻避太祖諱</span>  
<span style="margin-left: 2em">故書其字如唐修晉書稱石虎爲石季龍或作李</span>  
<span style="margin-left: 2em">乂亦避諱刋除一字如唐修隋書稱韓擒虎爲韓</span>  
<!-- 册3 葉2236a　Page:文淵閣四庫全書_0003冊.djvu/564 -->
<span style="margin-left: 2em">擒實一人也文獻通考一入雜家引書錄解題作</span>  
<span style="margin-left: 2em">李匡文一入小說家引讀書志作李匡義而字濟</span>  
<span style="margin-left: 2em">翁則同陸游集有此書䟦亦作李匡文王楙野客</span>  
<span style="margin-left: 2em">叢書作李正文然讀書志實作匡乂諸書傳寫自</span>  
<span style="margin-left: 2em">誤耳匡乂始末未詳書中稱再從叔翁汧公知爲</span>  
<span style="margin-left: 2em">李勉從孫又稱宗人瀚作䝉求載蘇武鄭衆事云</span>  
<span style="margin-left: 2em">云則晉翰林學士李瀚之旅當爲唐末人唐書藝</span>  
<span style="margin-left: 2em">文志有李匡文兩漢至唐年紀一卷註曰昭宗時</span>  
<span style="margin-left: 2em">宗正少卿葢卽匡乂書中但自稱守南漳葢所厯</span>  
<!-- 册3 葉2236b　Page:文淵閣四庫全書_0003冊.djvu/564 -->
<span style="margin-left: 2em">之官非所終之官也讀書志載是書有匡乂自序</span>  
<span style="margin-left: 2em">曰世俗之談類多訛誤雖有見聞嘿不敢證故著</span>  
<span style="margin-left: 2em">此書上篇正誤中篇談原下篇本物此本前有虞</span>  
<span style="margin-left: 2em">山錢遵王氏藏書印葢也是園舊物未題埭川顧</span>  
<span style="margin-left: 2em">氏家塾梓行中間貞字徵字完字皆闕筆葢南宋</span>  
<span style="margin-left: 2em">所刋殷字亦尙闕筆則猶刻於理宗以前宣祖未</span>  
<span style="margin-left: 2em">祧之時較近本爲善然無此序疑裝緝者佚之書</span>  
<span style="margin-left: 2em">中亦不標三篇之目其所說之事則皆與目應疑</span>  
<span style="margin-left: 2em">自序乃櫽括之詞原未標目也其書大抵考訂舊</span>  
<!-- 册3 葉2237a　Page:文淵閣四庫全書_0003冊.djvu/564 -->
<span style="margin-left: 2em">文黃伯思東觀餘論嘗駁其茶托一條黃朝英緗</span>  
<span style="margin-left: 2em">素襍記嘗駁其儤直一條胡仔苕溪漁隱叢話嘗</span>  
<span style="margin-left: 2em">駁其藥欄一條王楙野客叢書嘗駁其急急如律</span>  
<span style="margin-left: 2em">令一條今觀所辨如千里不唾井事云本因南朝</span>  
<span style="margin-left: 2em">宋之計吏不知玉臺新詠舊本載曹植代劉勲出</span>  
<span style="margin-left: 2em">妻王氏詩已有千里不唾井况乃昔所奉句則宋</span>  
<span style="margin-left: 2em">計吏之說爲誤又蜀妓薛濤見於唐人詩集者無</span>  
<span style="margin-left: 2em">不作濤此書獨作薛陶顯爲訛字又解龍鍾爲龍</span>  
<span style="margin-left: 2em">所踐處亦渉穿鑿又全書均考證之文而穆寧㗖</span>  
<!-- 册3 葉2237b　Page:文淵閣四庫全書_0003冊.djvu/564 -->
<span style="margin-left: 2em">熊白一條忽襍嘲謯襍事於體例尤爲不倫然如</span>  
<span style="margin-left: 2em">謂荀悅漢紀防將來之誤角里直書祿里足驗用</span>  
<span style="margin-left: 2em">字上加一拂别作用字之非謂論語宰子晝寢作</span>  
<span style="margin-left: 2em">畫寢乃梁武帝之說傷人乎不問馬不字斷句乃</span>  
<span style="margin-left: 2em">經典釋文之說均不始於韓愈筆解謂五臣註文</span>  
<span style="margin-left: 2em">選竊據李善之本謂韓愈諱辨誤以杜度爲名謂</span>  
<span style="margin-left: 2em">有母之人不可稱舅氏爲渭陽謂作詩疏之陸璣</span>  
<span style="margin-left: 2em">名從玉傍非士衡謂萬幾字訛作機由漢王嘉封</span>  
<span style="margin-left: 2em">事謂除授二字有分以至座前閣下之别竹甲題</span>  
<!-- 册3 葉2240a　Page:文淵閣四庫全書_0003冊.djvu/565 -->
<span style="margin-left: 2em">籖門杖之始皆引證分明足爲典據其中鄼侯音</span>  
<span style="margin-left: 2em">鹺一條明焦竑作筆乘摭爲異聞不知属沛國者</span>  
<span style="margin-left: 2em">音鹺属南陽者音贊匡乂已引鄒氏史記注駁讀</span>  
<span style="margin-left: 2em">鹺之非竑殆未見此書也歟</span>  
刋誤二卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">唐李涪撰舊本前有結銜稱國子祭酒郭忠恕佩</span>  
<span style="margin-left: 2em">觽引此書亦稱李祭酒涪五代去唐末未遠當得</span>  
<span style="margin-left: 2em">其眞而陸游渭南集有是書䟦曰王行瑜作亂宗</span>
