## 欽定四庫全書總目 卷一百六十二　集部十五　別集類十五

<!-- 册4 葉1124a　Page:文淵閣四庫全書_0004冊.djvu/286 -->
欽定四庫全書總目卷一百六十二  
<span style="margin-left: 1em">集部十五</span>  
<span style="margin-left: 2em">别集𩔖十五</span>  
性善堂稿十五卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋度正撰正有周子年譜已著錄宋史正本傳載</span>  
<span style="margin-left: 2em">正有性善堂集而不著卷數趙希弁讀書附志始</span>  
<span style="margin-left: 2em">列其目凡十五卷曹彦約爲之序自明以來世久</span>  
<span style="margin-left: 2em">失傳今從永樂大典中採撮裒次以𩔖排纂仍析</span>  
<span style="margin-left: 2em">爲十五卷以還其舊正游於朱子之門文章質實</span>  
<!-- 册4 葉1124b　Page:文淵閣四庫全書_0004冊.djvu/286 -->
<span style="margin-left: 2em">大都原本經濟不爲流連光景之語其條奏便民</span>  
<span style="margin-left: 2em">諸疏不下萬餘言指陳利弊明析剴切亦可謂留</span>  
<span style="margin-left: 2em">心世務不徒爲性命空談詩品雖不甚高而詞意</span>  
<span style="margin-left: 2em">暢達頗與朱子格律相近觀其書易學啓𫎇後書</span>  
<span style="margin-left: 2em">晦庵所釋西銘後跋中請釋奠禮諸篇悉於師說</span>  
<span style="margin-left: 2em">篤信不疑宜其一步一趨矣魏了翁朱子語𩔖序</span>  
<span style="margin-left: 2em">稱輔漢<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">授以所集朱子語言文字度周<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">從予</span>  
<span style="margin-left: 2em">乞本刋諸靑衣因屬其以學者之病著於篇端云</span>  
<span style="margin-left: 2em">云是正又嘗梓行語𩔖且爲之序而集中無此文</span>  
<!-- 册4 葉1125a　Page:文淵閣四庫全書_0004冊.djvu/286 -->
<span style="margin-left: 2em">又史稱正官太常時適太廟災爲二說以獻其一</span>  
<span style="margin-left: 2em">用朱子之議其一則因宋朝廟制而叅以朱子之</span>  
<span style="margin-left: 2em">說本傳中具載其畧集中亦無此文葢刪汰編纂</span>  
<span style="margin-left: 2em">之餘固不免有所缺佚也</span>  
漫塘文集三十六卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">宋劉宰撰宰字平國金壇人紹熙元年進士仕至</span>  
<span style="margin-left: 2em">浙東倉司幹官屬北伐釁起遂退居漫塘閱三十</span>  
<span style="margin-left: 2em">年屢薦不起以<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">顯謨閣主管玉局觀卒於家朝</span>  
<span style="margin-left: 2em">廷嘉其節賜諡文淸事蹟具宋史本傳宰著作甚</span>  
<!-- 册4 葉1125b　Page:文淵閣四庫全書_0004冊.djvu/286 -->
<span style="margin-left: 2em">富淳祐初王遂裒其遺藁十僅得四五爲編訂作</span>  
<span style="margin-left: 2em">序名曰前集理宗收入秘閣世遂無傳明正德問</span>  
<span style="margin-left: 2em">大學士靳貴從内閣抄岀因授王臬鋟梓釐爲三</span>  
<span style="margin-left: 2em">十六卷卽此本也宰秉性恬淡平生無他嗜好惟</span>  
<span style="margin-left: 2em">書靡所不讀所爲文章淳古質<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">不事藻飾而自</span>  
<span style="margin-left: 2em">然暢達其漫塘一賦尤爲世所傳誦又頗事講學</span>  
<span style="margin-left: 2em">當爲眞州司法時方禁仕者讀周程氏書宰堅不</span>  
<span style="margin-left: 2em">肯署狀亦多從朱子門人游本傳稱所著别有語</span>  
<span style="margin-left: 2em">錄十卷今已久佚其議論遂不可復考然觀此一</span>  
<!-- 册4 葉1128a　Page:文淵閣四庫全書_0004冊.djvu/287 -->
<span style="margin-left: 2em">集其宗旨已大畧見矣語錄卽不存可也</span>  
克齋集十七卷<sub class="note-yuan">湖北巡撫採進本</sub>  
<span style="margin-left: 2em">宋陳文蔚撰蔚字才<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">上饒人嘗舉進士端平二</span>  
<span style="margin-left: 2em">年都省言其所作尙書𩔖編有益治道詔補迪功</span>  
<span style="margin-left: 2em">郞今尙書𩔖編巳佚其文集亦無傳本故書錄解</span>  
<span style="margin-left: 2em">題宋史藝文志俱未著錄明初其郡人張時雨及</span>  
<span style="margin-left: 2em">其裔孫良鑑始掇拾成編卽此本也文蔚始因同</span>  
<span style="margin-left: 2em">里余大雅以師事朱子見於所撰余正叔墓碣集</span>  
<span style="margin-left: 2em">中與朱子往復書甚多皆以工夫精進相規切而</span>  
<!-- 册4 葉1128b　Page:文淵閣四庫全書_0004冊.djvu/287 -->
<span style="margin-left: 2em">祭朱先生文有云丁巳之冬戊午之春招之使來</span>  
<span style="margin-left: 2em">授業諸孫因獲終歲侍敎諄諄則又嘗館於朱子</span>  
<span style="margin-left: 2em">家當理宗之時朱子之學大行故所著之書得聞</span>  
<span style="margin-left: 2em">於朝廷朝廷亦遂命以官也然文蔚實亦篤信謹</span>  
<span style="margin-left: 2em">守傳其師說所記朱子之語皆戊申以後所聞見</span>  
<span style="margin-left: 2em">於池錄第四已編入朱子語𩔖中此復具載於本</span>  
<span style="margin-left: 2em">集葢一從其所言之人一從其所記之人義可互</span>  
<span style="margin-left: 2em">存不爲假借其詩雖頗拙俚不及朱子遠甚其文</span>  
<span style="margin-left: 2em">則皆明白淳實有朱子之遺講義九條剖析義利</span>  
<!-- 册4 葉1129a　Page:文淵閣四庫全書_0004冊.djvu/287 -->
<span style="margin-left: 2em">之辨亦爲諄切均不愧儒者之言與後來依門傍</span>  
<span style="margin-left: 2em">戸者固迥乎殊矣</span>  
芳蘭軒集一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">宋徐照撰照字道暉一字靈暉永嘉人與徐璣翁</span>  
<span style="margin-left: 2em">卷趙師秀號曰永嘉四靈照卽四靈之首也嘗自</span>  
<span style="margin-left: 2em">號曰山民故其集又曰山民集趙師秀淸苑齋集</span>  
<span style="margin-left: 2em">有哀山民詩可以爲證陳振孫書錄解題獨稱照</span>  
<span style="margin-left: 2em">自號天民未知何據當屬傳刻之訛也葉適作照</span>  
<span style="margin-left: 2em">墓誌稱其詩數百琢思尤奇皆橫絶歘起冰懸雪</span>  
<!-- 册4 葉1129b　Page:文淵閣四庫全書_0004冊.djvu/287 -->
<span style="margin-left: 2em">跨使讀者變踔憀慄肯首吟歎不能自巳然無異</span>  
<span style="margin-left: 2em">語皆人所知也人不能道耳所以推奬之者甚至</span>  
<span style="margin-left: 2em">而吳子良荆溪林下偶談則謂適雖不没其所長</span>  
<span style="margin-left: 2em">而亦終不滿之故其跋劉潛夫詩卷又有進乎古</span>  
<span style="margin-left: 2em">人而不巳何必四靈之語後人不知以爲水心崇</span>  
<span style="margin-left: 2em">晚唐者誤也葢四靈之詩雖鏤心鉥腎刻意雕琢</span>  
<span style="margin-left: 2em">而取逕太狹終不免破碎尖酸之病照在諸家中</span>  
<span style="margin-left: 2em">尤爲淸瘦如其寄翁靈舒詩中樓高望見船句方</span>  
<span style="margin-left: 2em">回以爲眼前事道著便新又冬日書事詩中梅遲</span>  
<!-- 册4 葉1132a　Page:文淵閣四庫全書_0004冊.djvu/288 -->
<span style="margin-left: 2em">思閏月楓遠誤春花方回亦以爲思字誤字當是</span>  
<span style="margin-left: 2em">推𫾣不一乃得之是皆集中所稱佳句要其淸雋</span>  
<span style="margin-left: 2em">者在此其卑靡者亦卽在此風會升降之際固有</span>  
<span style="margin-left: 2em">不能自知者矣照集原本三卷此本祇一卷不知</span>  
<span style="margin-left: 2em">何人所併又從瀛奎律髓得詩六首東甌詩集得</span>  
<span style="margin-left: 2em">詩二首東甌續集得詩一首併爲補遺附之於後</span>  
<span style="margin-left: 2em">焉</span>  
二薇亭集一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">宋徐璣撰璣字文淵一字致中號靈淵趙師秀集</span>  
<!-- 册4 葉1132b　Page:文淵閣四庫全書_0004冊.djvu/288 -->
<span style="margin-left: 2em">作靈囦囦字卽古淵字葢偶以别體書之永嘉四</span>  
<span style="margin-left: 2em">靈之二也宋元詩會載璣官建安主簿龍游丞武</span>  
<span style="margin-left: 2em">當長泰令嘉定七年卒年五十九而陳振孫書錄</span>  
<span style="margin-left: 2em">解題則曰四人者惟師秀嘗登科改官意謂三人</span>  
<span style="margin-left: 2em">皆未嘗出仕曹學佺亦謂二徐皆隱居不仕今觀</span>  
<span style="margin-left: 2em">此卷中璣有監造御茶五言古詩葢爲主簿時作</span>  
<span style="margin-left: 2em">其贈趙師秀詩有游宦歸來幾度春之句七言絶</span>  
<span style="margin-left: 2em">句又有移官南浦一首則陳振孫所言偶然失考</span>  
<span style="margin-left: 2em">學佺又誤因之也書錄解題載璣集一卷與此本</span>  
<!-- 册4 葉1133a　Page:文淵閣四庫全書_0004冊.djvu/288 -->
<span style="margin-left: 2em">相符其名二薇亭集則通考未載或亦偶遺也集</span>  
<span style="margin-left: 2em">後有補遺三首從瀛奎律髓東甌詩集東甌續集</span>  
<span style="margin-left: 2em">中抄出厲鶚宋詩紀事載璣又有泉山集今未之</span>  
<span style="margin-left: 2em">見或東甌詩集所載爲泉山集中詩歟</span>  
西巖集一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">宋翁卷撰卷字續古一字靈舒永嘉四靈之三也</span>  
<span style="margin-left: 2em">嘗登淳祐癸卯鄉薦終於布衣葉適序其詩稱爲</span>  
<span style="margin-left: 2em">自吐性情靡所依傍劉克莊後村集亦有贈卷詩</span>  
<span style="margin-left: 2em">云非止擅唐風尤於選體工有時千載事祇在一</span>  
<!-- 册4 葉1133b　Page:文淵閣四庫全書_0004冊.djvu/288 -->
<span style="margin-left: 2em">聯中張端義貴耳集曰翁卷四靈也有曉對詩云</span>  
<span style="margin-left: 2em">梅花分地落井氣隔簾生瀑布詩云千年流不盡</span>  
<span style="margin-left: 2em">六月地長寒春日云一階春草碧幾片落花輕游</span>  
<span style="margin-left: 2em">寺云分石同僧坐看松見鶴來吾廬云移花連舊</span>  
<span style="margin-left: 2em">土買石帶新苔其所取者大抵尖新刻畫之詞葢</span>  
<span style="margin-left: 2em">一時風氣所趨四靈如出一手也卷别有葦碧軒</span>  
<span style="margin-left: 2em">集今未見其本厲鶚宋詩紀事載卷詩四首皆註</span>  
<span style="margin-left: 2em">出葦碧軒集以校此集惟寄遠一首不載餘皆相</span>  
<span style="margin-left: 2em">同可知二集之詩實互相出入至張端義所舉五</span>  
<!-- 册4 葉1136a　Page:文淵閣四庫全書_0004冊.djvu/289 -->
<span style="margin-left: 2em">聯鶚但列之逸句中不能得其全篇是又在葦碧</span>  
<span style="margin-left: 2em">軒集之外殆當時所刋原非一本尙不止此二集</span>  
<span style="margin-left: 2em">歟</span>  
淸苑齋集一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">宋趙師秀撰師秀字紫芝號靈秀永嘉人太祖八</span>  
<span style="margin-left: 2em">世孫紹熙元年進士浮沉州縣終於高安推官永</span>  
<span style="margin-left: 2em">嘉四靈之四也其詩亦學晚唐然大抵多得於武</span>  
<span style="margin-left: 2em">功一派專以鍊句爲工而句法又以鍊字爲要如</span>  
<span style="margin-left: 2em">詩人玉屑載師秀冷泉夜坐詩樓鐘晴更響池水</span>  
<!-- 册4 葉1136b　Page:文淵閣四庫全書_0004冊.djvu/289 -->
<span style="margin-left: 2em">夜知深一聯後改更字爲聽字改知字爲觀字病</span>  
<span style="margin-left: 2em">起詩朝客偶知承送藥野僧相保爲持經一聯後</span>  
<span style="margin-left: 2em">改承字爲親字爲字爲密字可以知其門徑矣又</span>  
<span style="margin-left: 2em">梅磵詩話杜小山問句法於師秀答曰但能飽喫</span>  
<span style="margin-left: 2em">梅花數斗胸次玲瓏自能作詩云云故其詩主於</span>  
<span style="margin-left: 2em">野逸淸瘦以矯江西之失而開寶遺風則不復沿</span>  
<span style="margin-left: 2em">溯也陳振孫書錄解題載師秀集二卷别本天樂</span>  
<span style="margin-left: 2em">堂集一卷今皆未見此本僅一卷而題曰淸苑齋</span>  
<span style="margin-left: 2em">集未審爲卽天樂堂集之别名否趙與虤娛書堂</span>  
<!-- 册4 葉1137a　Page:文淵閣四庫全書_0004冊.djvu/289 -->
<span style="margin-left: 2em">詩話載送謝耘游淮詩二句又東甌續集載師秀</span>
