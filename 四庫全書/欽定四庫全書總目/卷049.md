## 欽定四庫全書總目 卷四十九　史部五　紀事本末類、紀事本末類存目

<!-- 册2 葉372a　Page:文淵閣四庫全書_0002冊.djvu/98 -->
欽定四庫全書總目卷四十九  
<span style="margin-left: 1em">史部五</span>  
<span style="margin-left: 2em">紀事本末類</span>  
<span style="margin-left: 3em">古之史策編年而已周以前無異軌也司馬遷</span>  
<span style="margin-left: 3em">作史記遂有紀傳一體唐以前亦無異軌也至</span>  
<span style="margin-left: 3em">宋袁樞以通鑑舊文每事爲篇各排比其次第</span>  
<span style="margin-left: 3em">而詳敘其始終命曰紀事本末史遂又有此一</span>  
<span style="margin-left: 3em">體夫事例相循其後謂之因其初皆起於創其</span>  
<span style="margin-left: 3em">初有所創其後卽不能不因故未有是體以前</span>  
<!-- 册2 葉372b　Page:文淵閣四庫全書_0002冊.djvu/98 -->
<span style="margin-left: 3em">微獨紀事本末創卽紀傳亦創編年亦創旣有</span>  
<span style="margin-left: 3em">是體以後微獨編年相因紀傳相因卽紀事本</span>  
<span style="margin-left: 3em">末亦相因因者旣衆遂於二體之外別立一家</span>  
<span style="margin-left: 3em">今亦以類區分使自爲門目凡一書備諸事之</span>  
<span style="margin-left: 3em">本末與一書具一事之本末者總彚於此其不</span>  
<span style="margin-left: 3em">標紀事本末之名而實爲紀事本末者亦併著</span>  
<span style="margin-left: 3em">錄若夫偶然記載篇帙無多則仍隷諸雜史傳</span>  
<span style="margin-left: 3em">記不列於此焉</span>  
通鑑紀事本末四十二卷<sub class="note-yuan">通行本</sub>  
<!-- 册2 葉373a　Page:文淵閣四庫全書_0002冊.djvu/98 -->
<span style="margin-left: 2em">宋袁樞撰樞字機仲建安人孝宗初試禮部詞賦</span>  
<span style="margin-left: 2em">第一厯官至工部侍郞以右文殿修撰知江陵府</span>  
<span style="margin-left: 2em">尋提舉太平興國宫事蹟具宋史本傳案唐劉知</span>  
<span style="margin-left: 2em">幾作史通敘述史例首列六家總歸二體自漢以</span>  
<span style="margin-left: 2em">來不過紀傳編年兩法乘除互用然紀傳之法或</span>  
<span style="margin-left: 2em">一事而複見數篇賓主莫辨編年之法或一事而</span>  
<span style="margin-left: 2em">隔越數卷首尾難稽樞乃自出新意因司馬光資</span>  
<span style="margin-left: 2em">治通鑑區别門目以類排纂每事各詳起訖自爲</span>  
<span style="margin-left: 2em">標題每篇各編年月自爲首尾始於三家之分晉</span>  
<!-- 册2 葉373b　Page:文淵閣四庫全書_0002冊.djvu/98 -->
<span style="margin-left: 2em">終於周世宗之征淮南包括數千年事迹經緯明</span>  
<span style="margin-left: 2em">晰節目詳具前後始末一覽了然遂使紀傳編年</span>  
<span style="margin-left: 2em">貫通爲一實前古之所未有也王應麟玉海稱淳</span>  
<span style="margin-left: 2em">熙三年十一月㕘政龔茂良言樞所編紀事有益</span>  
<span style="margin-left: 2em">見聞詔嚴州摹印十部仍先以繕本上之宋史樞</span>  
<span style="margin-left: 2em">本傳又稱孝宗讀而嘉歎以賜東宫及分賜江上</span>  
<span style="margin-left: 2em">諸帥曰治道盡在是矣朱子亦稱其書部居門目</span>  
<span style="margin-left: 2em">始終離合之間皆曲有微意於以錯綜温公之書</span>  
<span style="margin-left: 2em">乃國語之流蓋樞所綴集雖不出通鑑原文而去</span>  
<!-- 册2 葉376a　Page:文淵閣四庫全書_0002冊.djvu/99 -->
<span style="margin-left: 2em">取翦裁義例極爲精宻非通鑑總類諸書割裂撦</span>  
<span style="margin-left: 2em">撏者可比其後如陳邦瞻谷應泰等遞有沿仿而</span>  
<span style="margin-left: 2em">包括條貫不漏不冗則皆出是書下焉</span>  
春秋左氏傳事類始末五卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">宋章冲撰冲字茂深章惇之孫也淳熙中嘗知台</span>  
<span style="margin-left: 2em">州其妻乃葉夢得女夢得深於春秋故冲亦頗究</span>  
<span style="margin-left: 2em">心於左傳取諸國事蹟排比年月各以類從使節</span>  
<span style="margin-left: 2em">目相承首尾完具前有冲自序及謝諤序考冲與</span>  
<span style="margin-left: 2em">袁樞俱當孝宗之時樞排纂資始通鑑創紀事本</span>  
<!-- 册2 葉376b　Page:文淵閣四庫全書_0002冊.djvu/99 -->
<span style="margin-left: 2em">末之例使端緖分明易於循覽其書刊於淳熙丙</span>  
<span style="margin-left: 2em">申冲作是書亦同斯體據自序刊於淳熙乙巳在</span>  
<span style="margin-left: 2em">樞書之後九年殆踵樞之義例而作雖篇帙無多</span>  
<span style="margin-left: 2em">不及樞書之淹博其有裨學者則一也惟通鑑本</span>  
<span style="margin-left: 2em">屬史家樞不過理其端緖春秋一書經則比事屬</span>  
<span style="margin-left: 2em">辭義多互發傳文則或先經以始事或後經以終</span>  
<span style="margin-left: 2em">義或依經以辨理或錯經以合異絲牽繩貫脈絡</span>  
<span style="margin-left: 2em">潛通冲但以事類裒集遂變經義爲史裁於筆削</span>  
<span style="margin-left: 2em">之文𣺌不相涉舊列經部未見其然今與樞書同</span>  
<!-- 册2 葉377a　Page:文淵閣四庫全書_0002冊.djvu/99 -->
<span style="margin-left: 2em">𨽻史類庶稱其實焉</span>  
三朝北盟會編二百五十卷<sub class="note-yuan">左都御史張若溎家藏本</sub>  
<span style="margin-left: 2em">宋徐夢莘撰夢莘字商老臨江人紹興二十四年</span>  
<span style="margin-left: 2em">進士爲南安軍教授改知湘陰縣官至知賓州以</span>  
<span style="margin-left: 2em">議鹽法不合罷歸事蹟具宋史儒林傳夢莘嗜學</span>  
<span style="margin-left: 2em">博聞生平多所著述史稱其恬於榮進每念生靖</span>  
<span style="margin-left: 2em">康之亂思究見顚末乃網羅舊聞會稡同異爲三</span>  
<span style="margin-left: 2em">朝北盟會編自政和七年海上之盟迄紹興三十</span>  
<span style="margin-left: 2em">一年上下四十五年凡勅制誥詔國書書疏奏議</span>  
<!-- 册2 葉377b　Page:文淵閣四庫全書_0002冊.djvu/99 -->
<span style="margin-left: 2em">記序碑志登載靡遺帝聞而嘉之擢<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">祕省云云</span>  
<span style="margin-left: 2em">今其書鈔本尙存凡分上中下三帙上爲政宣二</span>  
<span style="margin-left: 2em">十五卷中爲靖康七十五卷下爲炎興一百五十</span>  
<span style="margin-left: 2em">卷其起訖年月與史所言合所引書一百二種雜</span>  
<span style="margin-left: 2em">考私書八十四種金國諸錄十種共一百九十六</span>  
<span style="margin-left: 2em">種而文集之類尙不數焉史所言者殊未盡也凡</span>  
<span style="margin-left: 2em">宋金通和用兵之事悉爲詮次本末年經月緯按</span>  
<span style="margin-left: 2em">曰臚載惟靖康中帙之末有諸錄雜記五卷則以</span>  
<span style="margin-left: 2em">無年月可繫者別加編次附之於末其徴引皆全</span>  
<!-- 册2 葉380a　Page:文淵閣四庫全書_0002冊.djvu/100 -->
<span style="margin-left: 2em">錄原文無所去取亦無所論斷蓋是非並見同異</span>  
<span style="margin-left: 2em">互存以備史家之採擇故以會編爲名然自汴都</span>  
<span style="margin-left: 2em">喪敗及南渡立國之始其治亂得失循文考證比</span>  
<span style="margin-left: 2em">事推求已皆可具見其所以然非徒餖飣𤨏碎已</span>  
<span style="margin-left: 2em">也雖其時說部糅雜所記金人事迹往往傳聞失</span>  
<span style="margin-left: 2em">實不盡可憑又當曰臣僚劄奏亦多夸張無據之</span>  
<span style="margin-left: 2em">辭夢莘槪錄全文均未能持擇要其博贍淹通南</span>  
<span style="margin-left: 2em">宋諸野史中自李心傳繫年要錄以外未有能過</span>  
<span style="margin-left: 2em">之者固不以繁蕪病矣考夢莘成此書後又以前</span>  
<!-- 册2 葉380b　Page:文淵閣四庫全書_0002冊.djvu/100 -->
<span style="margin-left: 2em">載不盡者五家續編次於中下二帙以補其闕靖</span>  
<span style="margin-left: 2em">康炎興各爲二十五卷名曰北盟集補今此本無</span>  
<span style="margin-left: 2em">之殆當時二本各行故久而亡佚歟</span>  
蜀鑑十卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">不著撰人名氏前有方孝孺序稱宋端平中紹武</span>  
<span style="margin-left: 2em">李文子嘗仕於蜀蒐採史傳起秦取南鄭至宋平</span>  
<span style="margin-left: 2em">孟昶上下千二百年事之繫乎蜀者爲書十卷云</span>  
<span style="margin-left: 2em">云世遂題爲文子作考亭淵源錄亦載李文子字</span>  
<span style="margin-left: 2em">公瑾光澤人<sub class="note-yuan">案光澤卽紹武之屬縣今尙仍古名</sub>李方子之弟紹興</span>  
<!-- 册2 葉381a　Page:文淵閣四庫全書_0002冊.djvu/100 -->
<span style="margin-left: 2em">四年進士官至知太安軍綿䦘州潼州府著蜀鑑</span>  
<span style="margin-left: 2em">十卷然考端平三年文子所作序中稱燕居深念</span>  
<span style="margin-left: 2em">紬釋前聞因俾資中郭允蹈緝爲一編云云則此</span>  
<span style="margin-left: 2em">書爲資州郭允蹈所撰文子特總其事耳世卽以</span>  
<span style="margin-left: 2em">爲文子作亦猶大易粹言本曾穜命方聞一作而</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">齋書錄解題遂悞以爲穜作也其書每事各標</span>  
<span style="margin-left: 2em">總題如袁樞通鑑紀事本末之例毎條有綱有目</span>  
<span style="margin-left: 2em">有論如朱子通鑑綱目之例其兼以考證附目末</span>  
<span style="margin-left: 2em">則較綱目爲詳贍焉宋自南渡後以荆襄爲前障</span>  
<!-- 册2 葉381b　Page:文淵閣四庫全書_0002冊.djvu/100 -->
<span style="margin-left: 2em">以興元漢中爲後戸天下形勢恒在楚蜀故允蹈</span>  
<span style="margin-left: 2em">是書所述皆戰守勝敗之迹於軍事之得失地形</span>  
<span style="margin-left: 2em">之險易恒三致意而於古人用兵故道必詳其今</span>  
<span style="margin-left: 2em">在某處其經營擘畫用意頗深他如辨荆門之浮</span>  
<span style="margin-left: 2em">橋引水經注以證荆州記之誤陳倉之馬鳴閣引</span>  
<span style="margin-left: 2em">蜀志以證寰宇記之誤斜谷之遮要引興元記以</span>  
<span style="margin-left: 2em">補裴松之注之缺諸葛亮之築樂城引通鑑以辨</span>  
<span style="margin-left: 2em">華陽國志寰宇記之異同於地理亦頗精核又所</span>  
<span style="margin-left: 2em">載羅尙之抗李雄張羅之據犍爲亦較晉書載記</span>  
<!-- 册2 葉384a　Page:文淵閣四庫全書_0002冊.djvu/101 -->
<span style="margin-left: 2em">及十六國春秋爲詳皆足裨史乘之考證唯所論</span>  
<span style="margin-left: 2em">蜀之地勢可以北取中原引漢高祖爲證則與李</span>  
<span style="margin-left: 2em">舜臣江東十鑑同意姑以勵恢復之氣耳諸葛亮</span>  
<span style="margin-left: 2em">所不能爲而謂後人能之乎末二卷敘西南夷始</span>  
<span style="margin-left: 2em">末其載犍爲郡之置始於漢代不知唐之莊琰播</span>  
<span style="margin-left: 2em">郞等州卽其故地又所載南詔始末謂驃信敗於</span>  
<span style="margin-left: 2em">韋皋而南蠻始衰不知敗於高駢而蠻乃不振所</span>  
<span style="margin-left: 2em">記未免稍畧然其時方慮内訌無暇外攘著書之</span>  
<span style="margin-left: 2em">志主於捍拒秦隴之師振控巴渝之險其他邊徼</span>  
<!-- 册2 葉384b　Page:文淵閣四庫全書_0002冊.djvu/101 -->
<span style="margin-left: 2em">之事固在所畧亦其時勢爲之矣</span>  
炎徼紀聞四卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明田汝成撰汝成字叔禾錢塘人嘉靖丙戌進士</span>  
<span style="margin-left: 2em">官至廣西布政司右㕘議事迹具明史文苑傳史</span>  
<span style="margin-left: 2em">稱其博學工古文尤善敘述厯官西南諳曉先朝</span>  
<span style="margin-left: 2em">遺事撰炎徼紀聞卽此編也書凡十四篇首紀王</span>  
<span style="margin-left: 2em">守仁征岑猛事次紀岑璋助擒岑猛事次紀趙楷</span>  
<span style="margin-left: 2em">李寰事次紀黃𤥠請立東官事次紀征大藤峽事</span>  
<span style="margin-left: 2em">次紀奢香事次紀安貴榮事次紀田琛事次紀楊</span>  
<!-- 册2 葉385a　Page:文淵閣四庫全書_0002冊.djvu/101 -->
<span style="margin-left: 2em">輝事次紀阿溪事次紀阿向事次紀雲南諸夷次</span>  
<span style="margin-left: 2em">紀猛宻孟養次雜紀諸蠻夷每篇各繫以論所載</span>  
<span style="margin-left: 2em">較史爲詳前有汝成自序稱自涉炎徼所聞諸事</span>  
<span style="margin-left: 2em">皆起於撫綏缺狀賞罰無章切中明代之弊其論</span>  
<span style="margin-left: 2em">田州之事歸咎於王守仁之姑息論黃𤥠之事歸</span>  
<span style="margin-left: 2em">咎於于謙之隱忍亦持平之議不蹈門戸之見史</span>
