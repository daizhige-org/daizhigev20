## 欽定四庫全書總目 卷六　經部六　易類六

欽定四庫全書總目卷六  
<span style="margin-left: 1em">經部六</span>  
<span style="margin-left: 2em">易𩔖六</span>  
易經通註九卷<sub class="note-yuan">湖北巡撫採進本</sub>  
<span style="margin-left: 1em">國朝大學士傅以漸左庶子曹本榮奉</span>  
勅撰首載順治十三年十二月十五日  
諭㫖次載順治十五年十月以漸等進書表次爲以漸恭  
<span style="margin-left: 2em">撰序文恭繹</span>  
世祖章皇帝聖訓謂自魏王弼唐孔頴達有注與正義宋  
<!-- 册1 葉513b　Page:文淵閣四庫全書_0001冊.djvu/178 -->
程頤有傳朱熹本義出學者宗之明永樂間命儒臣合  
元以前諸儒之說彚爲大全皆於易理多所發明但其  
中同異互存不無繁而可刪華而寡要且迄今幾三百  
年儒生學士發揮經義者亦不乏人當加採擇折衷諸  
論簡切洞達輯成一編昭示來兹仰見  
聰明天亶  
睿鑒高深  
萬幾餘閒遊心經術洋洋  
謨訓發四聖之精微衡諸儒之得失斟酌乎象數義理折  
<!-- 册1 葉516a　Page:文淵閣四庫全書_0001冊.djvu/179 -->
<span style="margin-left: 2em">以大中非儒生株守專門斤斤一家之言者所能</span>  
<span style="margin-left: 2em">窺見萬一以漸等恪遵</span>  
指授亦能鎔鑄衆說薈稡微言詞簡理明可爲說經之圭  
<span style="margin-left: 2em">臬緣其書上備</span>  
乙覽外間莫得而窺僅有原藁尊藏曹本榮子孫之家今  
<span style="margin-left: 2em">奉</span>  
皇上求書  
明詔湖北巡撫乃繕錄進  
<span style="margin-left: 1em">呈原本未標書名恭閱</span>  
<!-- 册1 葉516b　Page:文淵閣四庫全書_0001冊.djvu/179 -->
五朝國史傅以漸舊傳有順治十三年十月纂修易經通  
<span style="margin-left: 2em">註之文謹據以補題伏思此書推闡聖經發明精</span>  
<span style="margin-left: 2em">義雖編摩於衆手實禀受於</span>  
聖裁允宜寶軸琅函昭示無極俾天下萬世共仰  
世祖開天明道之功且以見  
<span style="margin-left: 1em">國家文治超邁古今本本元元一皆欽承</span>  
祖訓故重熙累洽百有餘年而有  
<span style="margin-left: 1em">今日之極盛焉</span>  
日講易經解義十八卷  
<!-- 册1 葉517a　Page:文淵閣四庫全書_0001冊.djvu/179 -->
<span style="margin-left: 2em">康熙二十二年</span>  
聖祖仁皇帝御定易爲四聖所遞傳則四聖之道法治法  
<span style="margin-left: 2em">具在於是故其大㫖在卽陰陽往來剛柔進退明</span>  
<span style="margin-left: 2em">治亂之倚伏君子小人之消長以示人事之宜於</span>  
<span style="margin-left: 2em">帝王之學最爲切要儒者拘泥章句株守一隅非</span>  
<span style="margin-left: 2em">但占驗禨祥漸失其本卽推奇偶者言天而不言</span>  
<span style="margin-left: 2em">人闡義理者言心而不言事聖人立教豈爲是無</span>  
<span style="margin-left: 2em">用之空言乎是編爲</span>  
講幄敷陳  
<!-- 册1 葉517b　Page:文淵閣四庫全書_0001冊.djvu/179 -->
睿裁鑒定其體例與宋以來奏進講義大致畧同而於觀  
<span style="margin-left: 2em">象之中深明經世之道</span>  
御製序文所謂以經學爲治法者實括是書之樞要亦卽  
<span style="margin-left: 2em">括六十四卦三百八十四爻之樞要信乎</span>  
帝王之學能見其大非鮿生一知半解所能窺測  
高深也  
御纂周易折中二十二卷  
<span style="margin-left: 2em">康熙五十四年</span>  
聖祖仁皇帝御纂自宋以來惟說易者至夥亦惟說易者  
<!-- 册1 葉520a　Page:文淵閣四庫全書_0001冊.djvu/180 -->
<span style="margin-left: 2em">多岐門戸交爭務求相勝遂至各倚於一偏故數</span>  
<span style="margin-left: 2em">者易之本主數太過使魏伯陽陳摶之說竄而相</span>  
<span style="margin-left: 2em">雜而易入於道家理者易之藴主理太過使王宗</span>  
<span style="margin-left: 2em">傳楊簡之說溢而旁出而易入於釋氏明永樂中</span>  
<span style="margin-left: 2em">官修易經大全龎雜割裂無所取裁由羣言淆亂</span>  
<span style="margin-left: 2em">無聖人以折其中也我</span>  
聖祖仁皇帝道契羲文心符周孔  
幾餘典學深見彌綸天地之源  
詔大學士李光地採摭羣言恭呈  
<!-- 册1 葉520b　Page:文淵閣四庫全書_0001冊.djvu/180 -->
乙覽以定著是編冠以圖說殿以啟𫎇未嘗不用數而不  
<span style="margin-left: 2em">以盛談河洛致晦玩占觀象之原冠以程傳次以</span>  
<span style="margin-left: 2em">本義未嘗不主理而不以屛斥䜟緯併廢互體變</span>  
<span style="margin-left: 2em">爻之用其諸家訓解或不合於伊川紫陽而實足</span>  
<span style="margin-left: 2em">發明經義者皆兼收並採不病異同惟一切支離</span>  
<span style="margin-left: 2em">幻𣺌之說咸斥不錄不使溷四聖之遺文葢數百</span>  
<span style="margin-left: 2em">年分朋立異之見至是而盡融數千年畫卦繫詞</span>  
<span style="margin-left: 2em">之㫖乃至是而大彰矣至於經傳分編一從古本</span>  
<span style="margin-left: 2em">尤足正費直以來割裂綴附之失焉</span>  
<!-- 册1 葉521a　Page:文淵閣四庫全書_0001冊.djvu/180 -->
<span style="margin-left: 1em">御纂周易述義十卷</span>  
<span style="margin-left: 3em">乾隆二十年奉</span>  
勅撰凡卦爻四卷彖傳一卷象傳二卷繫詞傳二卷文  
<span style="margin-left: 3em">言傳說卦傳序卦傳雜卦傳共一卷以多推闡</span>  
御纂周易折中之藴故  
賜名曰述義所解皆融㑹羣言擷取精要不條列姓名  
<span style="margin-left: 2em">亦不駁辨得失而遺文詮釋簡括宏深大㫖以切</span>  
<span style="margin-left: 2em">於實用爲本故於乾卦發例曰諸爻皆龍而三稱</span>  
<span style="margin-left: 2em">君子明易之立象皆人事也全書綱領具於斯矣</span>  
<!-- 册1 葉521b　Page:文淵閣四庫全書_0001冊.djvu/180 -->
<span style="margin-left: 2em">至於取象則多從古義如解乾九二曰九二剛中</span>  
<span style="margin-left: 2em">變離文明解坤初六曰變震爲足有履象焉解屯</span>  
<span style="margin-left: 2em">六二曰變兌爲女柔正故貞凡斯之類皆取於變</span>  
<span style="margin-left: 2em">爻也解屯六三曰震坎皆木聚於艮山故爲林解</span>  
<span style="margin-left: 2em">屯九五曰陷陰互艮止而不動解需九五曰坎水</span>  
<span style="margin-left: 2em">兌口故爲酒食凡斯之類皆取於互體也解𫎇六</span>  
<span style="margin-left: 2em">三曰三變互兌故爲女解訟九二曰坎坤體故爲</span>  
<span style="margin-left: 2em">邑又互離戸象也三百離數也解訟九四曰乾初</span>  
<span style="margin-left: 2em">復體互巽爲命變艮爲渝變止貞也凡斯之𩔖皆</span>  
<!-- 册1 葉524a　Page:文淵閣四庫全書_0001冊.djvu/181 -->
<span style="margin-left: 2em">兼取變與互也故解繫詞傳若夫雜物撰德辨是</span>  
<span style="margin-left: 2em">與非則非其中爻不備曰物謂八卦之爻雜謂自</span>  
<span style="margin-left: 2em">其中四爻雜而互之又撰成兩卦之德也是非者</span>  
<span style="margin-left: 2em">時物之是非皆於中爻辨之正體則二爲内卦之</span>  
<span style="margin-left: 2em">中五爲外卦之中互體則三爲内卦之中四爲外</span>  
<span style="margin-left: 2em">卦之中故皆謂之中爻云云誠爲根據先儒闡明</span>  
<span style="margin-left: 2em">經義葢漢易之不可訓者在於雜以䜟緯推衍禨</span>  
<span style="margin-left: 2em">祥至其象數之學則去古未遠授受具有端緖故</span>  
<span style="margin-left: 2em">王弼不取漢易而解七日來復不能不仍用六日</span>  
<!-- 册1 葉524b　Page:文淵閣四庫全書_0001冊.djvu/181 -->
<span style="margin-left: 2em">七分之說朱子亦不取漢易而解羝羊觸籓亦不</span>  
<span style="margin-left: 2em">能不仍用互兌之義豈非理有不可易歟諸臣仰</span>  
<span style="margin-left: 2em">承</span>  
指授於宋易漢易酌取其平探羲文之奥藴以決下鄭  
<span style="margin-left: 2em">之是非千古易學可自此更無異議矣</span>  
讀易大㫖五卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝孫奇逢撰奇逢字啟泰號中元又號夏峯容城</span>  
<span style="margin-left: 2em">人前明萬厯庚子舉人是書乃其入</span>  
<span style="margin-left: 1em">國朝後流寓河南時所作前有自序云至蘇門始學</span>  
<!-- 册1 葉525a　Page:文淵閣四庫全書_0001冊.djvu/181 -->
<span style="margin-left: 2em">易年老才盡偶據見之所及撮其體要以示門人</span>  
<span style="margin-left: 2em">子弟原非逐句逐字作解故曰大㫖其門人耿極</span>  
<span style="margin-left: 2em">爲之校訂末附兼山堂問答及與三無道人李崶</span>  
<span style="margin-left: 2em">論易之語別爲一卷崶雄縣人奇逢所從學易者</span>  
<span style="margin-left: 2em">也後奇逢曾孫用正復取其論易之語散見他著</span>  
<span style="margin-left: 2em">述者五條彚冠卷首題曰義例跋稱原本序文凡</span>  
<span style="margin-left: 2em">例皆闕故以是補亡按奇逢說易不顯攻圖書亦</span>  
<span style="margin-left: 2em">無一字及圖書大意發明義理切近人事以象傳</span>  
<span style="margin-left: 2em">通一卦之㫖由一卦通六十四卦之義凡所訓釋</span>  
<!-- 册1 葉525b　Page:文淵閣四庫全書_0001冊.djvu/181 -->
<span style="margin-left: 2em">皆先列巳說後附舊訓其平生之學主於實用故</span>  
<span style="margin-left: 2em">所言皆關法戒有足取焉</span>  
周易稗疏四卷附考異一卷<sub class="note-yuan">湖南巡撫採進本</sub>  
<span style="margin-left: 1em">國朝王夫之撰夫之字而辳號薑齋漢陽人前明舉</span>  
<span style="margin-left: 2em">人是編乃其讀易之時隨筆劄記故毎條但舉經</span>  
<span style="margin-left: 2em">文數字標目不全載經文又遇有疑義乃爲考辨</span>  
<span style="margin-left: 2em">故不逐卦逐爻一一盡爲之說大㫖不信陳摶之</span>  
<span style="margin-left: 2em">學亦不信京房之術於先天諸圖緯書雜說皆排</span>  
<span style="margin-left: 2em">之甚力而亦不空談幻渺附合老莊之㫖故言必</span>  
<!-- 册1 葉528a　Page:文淵閣四庫全書_0001冊.djvu/182 -->
<span style="margin-left: 2em">徵實義必切理於近時說易之家爲最有根據其</span>  
<span style="margin-left: 2em">中如解訟卦鞶帶云帶無鞶名鞶者鞶纓車飾也</span>  
<span style="margin-left: 2em">帶所以繫佩繸及芾者考左傳后之鞶鑑杜預訓</span>  
<span style="margin-left: 2em">鞶爲帶說文鞶字許愼亦註爲大帶安得曰帶無</span>  
<span style="margin-left: 2em">鞶名又何天之衢梁武帝解何爲荷見於經典釋</span>  
<span style="margin-left: 2em">文夫之雖亦以爲<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3688.svg?width=24" alt="四庫全書僻字第3688號（負）" title="四庫全書僻字第3688號（負）">荷之義乃以莊子<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3688.svg?width=24" alt="四庫全書僻字第3688號（負）" title="四庫全書僻字第3688號（負）">雲氣爲</span>  
<span style="margin-left: 2em">證而不援梁武帝之說亦偶然失考至於舊井无</span>  
<span style="margin-left: 2em">禽訓禽爲獲尤不免穿鑿附會然如引禮人君至</span>  
<span style="margin-left: 2em">命士黃裳下士雜裳以證黃裳之美引左傳班馬</span>  
<!-- 册1 葉528b　Page:文淵閣四庫全書_0001冊.djvu/182 -->
<span style="margin-left: 2em">證乘馬班如當讀乘爲去聲引兵法前左下後右</span>  
<span style="margin-left: 2em">高證師左次與論帝乙非紂父王用亨於西山非</span>  
<span style="margin-left: 2em">文王以及臨之八月復之七日易之逆數河圖蓍</span>  
<span style="margin-left: 2em">策之辨皆具有條理卷帙雖少固不失爲徵實之</span>  
<span style="margin-left: 2em">學焉</span>  
易酌十四卷<sub class="note-yuan">直𨽻總督採進本</sub>  
<span style="margin-left: 1em">國朝刁包撰包字𫎇吉祁州人前明天啟辛卯舉人</span>  
<span style="margin-left: 2em">是書用注疏本以程傳本義爲主雖亦偶言象數</span>  
<span style="margin-left: 2em">然皆陳摶李之才之學非漢以來相傳之法也原</span>  
<!-- 册1 葉529a　Page:文淵閣四庫全書_0001冊.djvu/182 -->
<span style="margin-left: 2em">序稱陸隴其官靈壽時欲爲刋板不果雍正初其</span>  
<span style="margin-left: 2em">孫顯祖又以巳意附益之卷首凡例雜卦諸圖及</span>  
<span style="margin-left: 2em">卷中細字稱謹案者皆顯祖筆原序又稱此書爲</span>  
<span style="margin-left: 2em">經學之津梁亦舉業之準的考包在</span>  
<span style="margin-left: 1em">國初與諸儒往來講學其著書一本於義理惟以明</span>  
<span style="margin-left: 2em">道爲主絕不爲程試之計是書推闡易理亦大抵</span>  
<span style="margin-left: 2em">明白正大足以羽翼程朱於宋學之中實深有所</span>  
<span style="margin-left: 2em">得以爲科舉之書則失包之本意多矣</span>  
田間易學十二卷<sub class="note-yuan">副都御史黃登賢家藏本</sub>

<span style="margin-left: 1em">國朝錢澄之撰澄之原名秉鐙字飮光自號田間老</span>

<span style="margin-left: 4em">春秋陰陽核其文體卽是緯書特以顯有主</span>  
<span style="margin-left: 4em">名故不能託諸孔子其他私相撰述漸雜以</span>  
<!-- 册1 葉633a　Page:文淵閣四庫全書_0001冊.djvu/208 -->
<span style="margin-left: 4em">術數之言旣不知作者爲誰因附會以神其</span>  
<span style="margin-left: 4em">說迨彌傳彌失又益以妖妄之辭遂與䜟合</span>  
<span style="margin-left: 4em">而爲一然班固稱聖人作經賢者緯之楊侃</span>  
<span style="margin-left: 4em">稱緯書之類謂之秘經圖䜟之類謂之内學</span>  
<span style="margin-left: 4em">河洛之書謂之靈篇胡應麟亦謂䜟緯二書</span>  
<span style="margin-left: 4em">雖相表裏而實不同則緯與䜟别前人固已</span>  
<span style="margin-left: 4em">分析之後人連類而譏非其實也右乾鑿度</span>  
<span style="margin-left: 4em">等七書皆易緯之文與圖䜟之熒惑民志悖</span>  
<span style="margin-left: 4em">理傷教者不同以其無可附麗故著錄於易</span>  
<!-- 册1 葉633b　Page:文淵閣四庫全書_0001冊.djvu/208 -->
<span style="margin-left: 4em">類之末焉</span>  
<span style="margin-left: 1em">右易類一百五十九部一千七百四十八卷附錄八</span>  
<span style="margin-left: 1em">部十二卷皆文淵閣著錄</span>  
<span style="margin-left: 4em">案盈虛消息理之自然也理不可見聖人卽</span>  
<span style="margin-left: 4em">數以觀之而因立象以著之以乾一卦而論</span>  
<span style="margin-left: 4em">積一至六自下而上者數也一潛二見三惕</span>  
<span style="margin-left: 4em">厲四躍五飛六亢者理也而象以見焉至於</span>  
<span style="margin-left: 4em">互體變爻錯綜貫串易之數無不盡易之理</span>  
<span style="margin-left: 4em">無不通易之象亦無不該矣左氏所載卽古</span>  
<!-- 册1 葉636a　Page:文淵閣四庫全書_0001冊.djvu/209 -->
<span style="margin-left: 4em">占法其條理可覆案也故象也者理之當然</span>  
<span style="margin-left: 4em">也進退存亡所由決也數也者理之所以然</span>  
<span style="margin-left: 4em">也吉凶悔吝所由生也聖人因卜筮以示教</span>  
<span style="margin-left: 4em">如是焉止矣宋人以數言易巳不甚近於人</span>  
<span style="margin-left: 4em">事又務欲究數之所以然於是由卦畫推奇</span>  
<span style="margin-left: 4em">偶由奇偶推河圖洛書由河圖洛書演爲黑</span>  
<span style="margin-left: 4em">白方圓縱橫順逆至於汗漫而不可紀曰此</span>  
<span style="margin-left: 4em">作易之本也及其解經則彖義爻象又絶不</span>  
<span style="margin-left: 4em">本圖書立說豈畫卦者一數繫辭者又别一</span>  
<!-- 册1 葉636b　Page:文淵閣四庫全書_0001冊.djvu/209 -->
<span style="margin-left: 4em">數𫆀夫聖人垂訓實教人用易非教人作易</span>  
<span style="margin-left: 4em">今不談其所以用而但談其所以作是易之</span>  
<span style="margin-left: 4em">一經非千萬世遵爲法戒之書而一二人宻</span>  
<span style="margin-left: 4em">傳妙悟之書矣經者常也曾是而可爲常道</span>  
<span style="margin-left: 4em">乎朱子以康節之學爲易外别傳持論至<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）"></span>  
<span style="margin-left: 4em">其作易學啓蒙葢以程子易傳不及象數故</span>  
<span style="margin-left: 4em">兼備此義以補所闕非專以數立教也後人</span>  
<span style="margin-left: 4em">棄置本義而專以啓蒙爲口實殆倒置其本</span>  
<span style="margin-left: 4em">末矣今所編錄於推演數學者略存梗槩以</span>
