## 欽定四庫全書總目 卷六十三　史部十九　傳記類存目五

<!-- 册2 葉1533a　Page:文淵閣四庫全書_0002冊.djvu/388 -->
欽定四庫全書總目卷六十三  
<span style="margin-left: 1em">史部十九</span>  
<span style="margin-left: 2em">傳記𩔖存目五</span>  
崇禎五十宰相傳一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝曹溶撰溶字潔躬號秋嶽秀水人前明崇禎丁</span>  
<span style="margin-left: 2em">丑進士官監察御史入</span>  
<span style="margin-left: 1em">國朝官至戸部侍郞出爲廣東布政使左遷山西陽</span>  
<span style="margin-left: 2em">和道此傳皆崇禎時入閣諸臣事迹凡六篇前有</span>  
<span style="margin-left: 2em">年表一篇明代自胡惟庸以後不立丞相然自後</span>  
<!-- 册2 葉1533b　Page:文淵閣四庫全書_0002冊.djvu/388 -->
<span style="margin-left: 2em">入閣辦事者亦相沿以相國呼之此書題曰宰相</span>  
<span style="margin-left: 2em">從俗稱也崇禎十六年間輔臣至五十人其行事</span>  
<span style="margin-left: 2em">皆見於明史說者謂其輕進易退不收實用溶篇</span>  
<span style="margin-left: 2em">末總論獨謂其私心朋比門戸相承邪正雖殊植</span>  
<span style="margin-left: 2em">黨則一斯誠探本之說矣傳雖分列五十人而所</span>  
<span style="margin-left: 2em">錄事實皆取賢否懸殊關係治亂之大者其成基</span>  
<span style="margin-left: 2em">命以下十四人但叙官閥黃立極以下四人亦極</span>  
<span style="margin-left: 2em">簡畧蓋以爲無關勸戒不足書也溶門人陶越乃</span>  
<span style="margin-left: 2em">取陳盟所作崇禎内閣行畧補之非溶意矣此書</span>  
<!-- 册2 葉1536a　Page:文淵閣四庫全書_0002冊.djvu/389 -->
<span style="margin-left: 2em">檇李詩系作崇禎五十輔臣傳五卷其實爲傳六</span>  
<span style="margin-left: 2em">篇加以年表一篇非五卷也</span>  
五十輔臣編年錄殘本一卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">不著撰人名氏板心有檇李曹氏倦圃藏書字蓋</span>  
<span style="margin-left: 2em">曹溶家舊本疑溶常作崇禎五十輔臣傳此其稿</span>  
<span style="margin-left: 2em">本之一冊爾始於天啟七年八月中間惟崇禎元</span>  
<span style="margin-left: 2em">年一月差詳崇禎二年則惟韓爌調停沈維炳薛</span>  
<span style="margin-left: 2em">國觀申救任贊一事而卷尾題曰五十輔臣編年</span>  
<span style="margin-left: 2em">錄殆不可曉書中文理斷續率不可讀繕寫惡劣</span>  
<!-- 册2 葉1536b　Page:文淵閣四庫全書_0002冊.djvu/389 -->
<span style="margin-left: 2em">亦幾不成字</span>  
歴代循良錄一卷<sub class="note-yuan">山東巡撫採進本</sub>  
<span style="margin-left: 1em">國朝孫蕙撰蕙字樹百號泰巖又號笠山淄川人順</span>  
<span style="margin-left: 2em">治辛丑進士官至給事中是書彚歴代循良事蹟</span>  
<span style="margin-left: 2em">惟載縣令而不及他官其意謂令與民最近也自</span>  
<span style="margin-left: 2em">秦漢以迄近代僅盈一卷去取可謂謹嚴然掛漏</span>  
<span style="margin-left: 2em">亦所不免</span>  
古人幾部六卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 1em">國朝陳允衡撰允衡字伯璣南昌人是書所錄皆明</span>  
<!-- 册2 葉1537a　Page:文淵閣四庫全書_0002冊.djvu/389 -->
<span style="margin-left: 2em">哲保身之士與急流勇退之人允衡自序云平湖</span>  
<span style="margin-left: 2em">陸叔度著古人幾部始管夷吾終史天澤凡八十</span>  
<span style="margin-left: 2em">一人古之成大功定大策者咸在焉而其人亦有</span>  
<span style="margin-left: 2em">功成而身死名立而毁至者定是不變無以語權</span>  
<span style="margin-left: 2em">因更集古人顏曰幾部然其書首載堯舜以堯之</span>  
<span style="margin-left: 2em">傳舜舜之逃象皆目爲知幾亦淺之乎窺聖人矣</span>  
<span style="margin-left: 2em">豈姑以寓防患之意不規規於品題之當否𫆀</span>  
歴代黨鑑五卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 1em">國朝徐賔撰賔字用王常熟人是書蓋因明季朋黨</span>  
<!-- 册2 葉1537b　Page:文淵閣四庫全書_0002冊.djvu/389 -->
<span style="margin-left: 2em">之禍爰採輯史傳作爲此書上自東漢黨錮次及</span>  
<span style="margin-left: 2em">魏之曹爽晉之賈充唐之王伾王叔文牛僧孺李</span>  
<span style="margin-left: 2em">德裕宋之洛蜀朔三黨元祐黨籍慶元僞學以及</span>  
<span style="margin-left: 2em">明之東林魏黨靡不詳載又採各家論朋黨之語</span>  
<span style="margin-left: 2em">附之於後而以范祖禹唐鑑終焉卷首冠以東林</span>  
<span style="margin-left: 2em">黨籍論三篇亦賔所自作也</span>  
孔庭神在錄八卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 1em">國朝胡時忠撰時忠原名時亨字愼三無錫人崇禎</span>  
<span style="margin-left: 2em">丙子舉人是錄以祀典爲主故先列位次而於聖</span>  
<!-- 册2 葉1540a　Page:文淵閣四庫全書_0002冊.djvu/390 -->
<span style="margin-left: 2em">賢諸儒各爲著錄其第八卷則考證辨論之詞凡</span>  
<span style="margin-left: 2em">十五篇</span>  
畿輔人物志二十卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 1em">國朝孫承澤撰承澤有尚書集解已著錄是編專志</span>  
<span style="margin-left: 2em">有明一代畿輔人物然如李東陽之類究涉假借</span>  
<span style="margin-left: 2em">不出地志之積習又如成基命無所瑕疵亦實無</span>  
<span style="margin-left: 2em">所樹立承澤以其子克鞏方官大學士而盛相推</span>  
<span style="margin-left: 2em">重則亦非盡信史矣</span>  
四朝人物畧六卷<sub class="note-yuan">副都御史黃登賢家藏本</sub>  
<!-- 册2 葉1540b　Page:文淵閣四庫全書_0002冊.djvu/390 -->
<span style="margin-left: 1em">國朝孫承澤撰自漢至唐宋爲五卷全襲名臣錄之</span>  
<span style="margin-left: 2em">文明一代總爲一卷皆用劉孟雷所爲翊運碩輔</span>  
<span style="margin-left: 2em">名<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">正學等傳爲之蓋承澤所長在於習掌故精</span>  
<span style="margin-left: 2em">賞鑒故所撰春明夢餘錄庚子銷夏記諸書皆考</span>  
<span style="margin-left: 2em">證詳明而史筆叙述則非其專門也</span>  
益智錄二十卷<sub class="note-yuan">副都御史黃登賢家藏本</sub>  
<span style="margin-left: 1em">國朝孫承澤撰起周迄明凡聖賢名人言行可錄者</span>  
<span style="margin-left: 2em">銓次爲二十卷而載明人事居三之一間有叙事</span>  
<span style="margin-left: 2em">之後附以論斷者承澤崇禎庚午鄉試出姚希孟</span>  
<!-- 册2 葉1541a　Page:文淵閣四庫全書_0002冊.djvu/390 -->
<span style="margin-left: 2em">之門辛未會試出何如寵之門故其附東林也甚</span>  
<span style="margin-left: 2em">力是書爲萬厯天啟間諸人傳尤詳然承澤門戸</span>  
<span style="margin-left: 2em">㤾固大抵以異同爲愛憎以愛憎爲是非不必盡</span>  
<span style="margin-left: 2em">協於公道也</span>  
顧氏譜系攷一卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 1em">國朝顧炎武撰炎武有左傳杜解補正已著錄是書</span>  
<span style="margin-left: 2em">於顧氏世系攷據最詳然姓氏之書最爲叢雜自</span>  
<span style="margin-left: 2em">唐以後譜學失傳掇拾殘文未必源流盡合姑存</span>  
<span style="margin-left: 2em">其說可也</span>  
<!-- 册2 葉1541b　Page:文淵閣四庫全書_0002冊.djvu/390 -->
檇李往哲續編一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝項玉筍撰玉筍字和父秀水人是書續戚元佐</span>  
<span style="margin-left: 2em">之傳而作補萬厯以前元佐所未載者又益以天</span>  
<span style="margin-left: 2em">啟崇禎兩朝凡十二人而以孝子魏學洢附於其</span>  
<span style="margin-left: 2em">父大中傳毎傳各系以論與元佐例小異</span>  
金華徴獻畧二十卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝王崇炳撰崇炳字虎文東陽人嘗於蘭溪唐氏</span>  
<span style="margin-left: 2em">輯其郡人著述爲金華文畧此則所採金華先賢</span>  
<span style="margin-left: 2em">事蹟也分十有二𩔖曰孝友曰忠義曰儒學曰名</span>  
<!-- 册2 葉1544a　Page:文淵閣四庫全書_0002冊.djvu/391 -->
<span style="margin-left: 2em">臣曰文學曰政績曰卓行曰貞烈曰仙釋曰方技</span>  
<span style="margin-left: 2em">曰來宦曰遊寓自元以前則本之史傳及吳師道</span>  
<span style="margin-left: 2em">敬鄉錄宋濓人物志自明以後則更蒐採諸書以</span>  
<span style="margin-left: 2em">補之然鄉曲之私所錄不免汜濫其序例謂事迹</span>  
<span style="margin-left: 2em">或無可稱而列之名臣者乃序爵之義不知鄉閫</span>  
<span style="margin-left: 2em">耆碩原不當以祿秩爲重輕若槩加採錄則是公</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">表而非耆舊傳矣</span>

<span style="margin-left: 2em">公望散宜生周公孔子顏子曾子子思孟子周子</span>  
<span style="margin-left: 2em">二程子張子朱子許衡薛瑄二十六人博徴經史</span>  
<span style="margin-left: 2em">各爲紀傳復引諸儒之說附於各條之下而衷以</span>

<span style="margin-left: 2em">祖謙眞德秀趙俊金履祥劉因曹端胡居仁羅倫</span>  
<span style="margin-left: 2em">蔡淸羅欽順顧憲成高攀龍二十二人其去取之</span>  
<span style="margin-left: 2em">故亦莫得而詳焉</span>  
希賢錄五卷<sub class="note-yuan"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">隸總督採進本</sub>

<span style="margin-left: 2em">元許衡以下三人附錄一人明薛瑄以下二十人</span>
