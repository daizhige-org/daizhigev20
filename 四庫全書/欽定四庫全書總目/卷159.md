## 欽定四庫全書總目 卷一百五十九　集部十二　別集類十二

欽定四庫全書總目卷一百五十九  
<span style="margin-left: 1em">集部十二</span>  
<span style="margin-left: 2em">别集𩔖十二</span>  
夾漈遺稿三卷<sub class="note-yuan">編修汪如藻家藏本</sub>  
<span style="margin-left: 2em">宋鄭樵撰樵有爾雅註巳著錄樵銳於著述嘗上</span>  
<span style="margin-left: 2em">書自陳稱所作已成者凡四十一種未成者八種</span>  
<span style="margin-left: 2em">當時頗以博洽著而未嘗以文章名其集自陳振</span>  
<span style="margin-left: 2em">孫書錄解題以下亦皆不著錄此本前後無序跋</span>  
<span style="margin-left: 2em">不知何人所編上卷古近體詩五十六首中卷記</span>  
<!-- 册4 葉921b　Page:文淵閣四庫全書_0004冊.djvu/235 -->
<span style="margin-left: 2em">一篇論一篇書二篇下卷書三篇其詩不甚修飾</span>  
<span style="margin-left: 2em">而蕭散無俗韻其文滉漾恣肆多𩔖唐李觀孫樵</span>  
<span style="margin-left: 2em">劉蛻在宋人爲別調其獻皇帝書自譽甚至上宰</span>  
<span style="margin-left: 2em">相書上方禮部書益放言縱論排斥古人秦漢來</span>  
<span style="margin-left: 2em">著述之家無一書能當其意至投宇文樞密江給</span>  
<span style="margin-left: 2em">事二書置學問而誇抱負益傲睨萬狀不可一世</span>  
<span style="margin-left: 2em">其量殊嫌淺狹然南北宋間記誦之富考證之勤</span>  
<span style="margin-left: 2em">實未有過於樵者其高自位置亦非盡無因也觀</span>  
<span style="margin-left: 2em">於是集其學問之始末夫亦可以槪見矣</span>  
<!-- 册4 葉924a　Page:文淵閣四庫全書_0004冊.djvu/236 -->
鄮峯眞隱漫錄五十卷<sub class="note-yuan">浙江范懋桂家天一閣藏本</sub>  
<span style="margin-left: 2em">宋史浩撰浩有尙書講義已著錄其集見於陳振</span>  
<span style="margin-left: 2em">孫書錄解題宋史藝文志者皆五十卷此本卷數</span>  
<span style="margin-left: 2em">並合而目錄别爲三卷首題門人周鑄編則猶宋</span>  
<span style="margin-left: 2em">時刋行舊式也浩事孝宗於潛邸隆興淳熙中兩</span>  
<span style="margin-left: 2em">爲宰揆没後至配享廟庭其推轂善𩔖寛厚不爭</span>  
<span style="margin-left: 2em">亦頗爲世所稱許當孝宗任張浚銳意用兵浩獨</span>  
<span style="margin-left: 2em">以爲不然遂以論劾罷去元代史臣作浩傳贊亦</span>  
<span style="margin-left: 2em">頗詆其不能贊襄恢復之謀今考集中如論山東</span>  
<!-- 册4 葉924b　Page:文淵閣四庫全書_0004冊.djvu/236 -->
<span style="margin-left: 2em">未可用兵論歸正人論未可北伐回奏條具弊事</span>  
<span style="margin-left: 2em">諸劄子皆極言李顯忠邵宏淵之輕脫寡謀不宜</span>  
<span style="margin-left: 2em">輕舉而欲練士卒積資糧以蓄力於十年之後旣</span>  
<span style="margin-left: 2em">而淮西奔潰其言竟驗不可謂非老成謀國之見</span>  
<span style="margin-left: 2em">雖厥後再秉國政亦未能收富强之效以自踐其</span>  
<span style="margin-left: 2em">言而量力知難其初說固有未可深議者至本傳</span>  
<span style="margin-left: 2em">稱浩因專對請於普安恩平二王内擇立一人爲</span>  
<span style="margin-left: 2em">皇子高宗亟稱爲有用之才而集中輪對有司不</span>  
<span style="margin-left: 2em">能推廣恩意劄子下注云見知高宗只因此劄此</span>  
<!-- 册4 葉925a　Page:文淵閣四庫全書_0004冊.djvu/236 -->
<span style="margin-left: 2em">事當在請定繼嗣之先而本傳顧未之及集爲門</span>  
<span style="margin-left: 2em">弟子編排所言當必有據是亦足與史相叅考也</span>  
<span style="margin-left: 2em">集凡詩五卷雜文三十九卷詞曲四卷末二卷爲</span>  
<span style="margin-left: 2em">童卯須知分三十章所言皆治家修身之道而諧</span>  
<span style="margin-left: 2em">以韻語乃錄之家塾以訓子孫者自署辛丑爲淳</span>  
<span style="margin-left: 2em">熙八年蓋其罷官以少傅侍經筵時所著云</span>  
海陵集二十三卷外集一卷<sub class="note-yuan">編修汪如藻家藏本</sub>  
<span style="margin-left: 2em">宋周麟之撰麟之字茂振海陵人紹興十五年進</span>  
<span style="margin-left: 2em">士中宏詞科任起居舍人厯擢兵部侍郞直學士</span>  
<!-- 册4 葉925b　Page:文淵閣四庫全書_0004冊.djvu/236 -->
<span style="margin-left: 2em">院給事中知制誥翰林學士官至同知樞密院事</span>  
<span style="margin-left: 2em">宋史藝文志載麟之海陵集二十三卷與此本合</span>  
<span style="margin-left: 2em">前有淳熙癸卯周必大序亦稱其子準裒遺稿得</span>  
<span style="margin-left: 2em">二十三卷蓋猶舊帙序稱其久官於朝故其詩文</span>  
<span style="margin-left: 2em">因事而作者少集中内外制詞殆居其半今觀其</span>  
<span style="margin-left: 2em">集非惟贈答唱和寥寥無幾卽奏議奏劄亦多不</span>  
<span style="margin-left: 2em">關軍國大計蓋其珥筆禁庭坐躋通顯與王珪約</span>  
<span style="margin-left: 2em">畧相似而文章嫻雅亦猶有北宋館閣之餘風非</span>  
<span style="margin-left: 2em">南渡諸家日趨新巧者比未可以專工儷偶輕也</span>  
<!-- 册4 葉928a　Page:文淵閣四庫全書_0004冊.djvu/237 -->
<span style="margin-left: 2em">別有外集一卷其中使金諸詩稱紹興巳卯考徐</span>  
<span style="margin-left: 2em">夢莘三朝北盟會編載紹興二十九年周麟之爲</span>  
<span style="margin-left: 2em">告哀使蓋以韋太后事而行時金國方謀南伐詩</span>  
<span style="margin-left: 2em">中造海船一章亦知其欲出膠州浮海水陸並進</span>  
<span style="margin-left: 2em">而所載中原民謠十章乃盛陳符䜟以燕京小爲</span>  
<span style="margin-left: 2em">康王坐之兆以迎送亭爲迎宋之兆以金瀾酒爲</span>  
<span style="margin-left: 2em">金闌之兆以歸德府爲復舊之兆以沃州爲天水</span>  
<span style="margin-left: 2em">之兆皆附會牽合亦何異吕紳棄通州而遁乃表</span>  
<span style="margin-left: 2em">言夜夢赤幟朱甲爲中興之瑞乎二老堂詩話又</span>  
<!-- 册4 葉928b　Page:文淵閣四庫全書_0004冊.djvu/237 -->
<span style="margin-left: 2em">載麟之使金金主愛之享以牛魚密糟其首以歸</span>  
<span style="margin-left: 2em">獻時有魚頭公之嘲則當時必有所以取悅於金</span>  
<span style="margin-left: 2em">主者而其詩誇宋詆金與事實絶不相應又前後</span>  
<span style="margin-left: 2em">凱歌三十首虛張虞允文𤓰洲采石僥倖之功殊</span>  
<span style="margin-left: 2em">爲過實詞句亦多鄙俚不類麟之他詩考諸宋志</span>  
<span style="margin-left: 2em">亦無外集之目殆其子諱而削藳後人又掇拾附</span>  
<span style="margin-left: 2em">存歟以原本所有姑仍其舊錄之而附訂其謬如</span>  
<span style="margin-left: 2em">右</span>  
燕堂詩稿一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<!-- 册4 葉929a　Page:文淵閣四庫全書_0004冊.djvu/237 -->
<span style="margin-left: 2em">宋趙公豫撰公豫字仲謙常熟人紹興間由進士</span>  
<span style="margin-left: 2em">知眞州官至寶謨閣待制是集卷首有傳一篇不</span>  
<span style="margin-left: 2em">著撰人名氏稱公豫本宗室子南渡後徙居常熟</span>  
<span style="margin-left: 2em">然考宋史宗室表諸王系中無以公字聯名者不</span>  
<span style="margin-left: 2em">知其出何派也傳又稱公豫所著燕堂類稿原本</span>  
<span style="margin-left: 2em">十六卷詔誥表策多爲時傳誦其詩因屬對不甚</span>  
<span style="margin-left: 2em">工切泉州守蔣雝選錄全部澄汰太甚僅存若干</span>  
<span style="margin-left: 2em">首是公豫止優於文而詩則非所擅長故雖抄本</span>  
<span style="margin-left: 2em">僅存而選錄宋詩者亦未經採摭今讀其詩雖吐</span>  
<!-- 册4 葉929b　Page:文淵閣四庫全書_0004冊.djvu/237 -->
<span style="margin-left: 2em">屬未工而直寫胸臆要自落落不凡傳又稱公豫</span>  
<span style="margin-left: 2em">居官廉正常言吾求爲良吏不求爲健吏去任之</span>  
<span style="margin-left: 2em">日挈壺漿攀轅者甚衆是其政績不愧於古之循</span>  
<span style="margin-left: 2em">吏當因人以重其詩使魯恭卓茂有遺集以傳於</span>  
<span style="margin-left: 2em">後雖聲律未嫻談藝者敢毅然斥去乎存此一集</span>  
<span style="margin-left: 2em">以風厲官方較之掞藻摘華其有補於世道爲多</span>  
<span style="margin-left: 2em">也</span>  
竹洲集二十卷附棣華雜筆一卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">宋吳儆撰儆字益恭初名偁避秀邸諱改名休寧</span>  
<!-- 册4 葉932a　Page:文淵閣四庫全書_0004冊.djvu/238 -->
<span style="margin-left: 2em">人紹興二十七年第進士厯朝散郞廣南西路安</span>  
<span style="margin-left: 2em">撫使主管台州崇道觀卒諡文肅其集宋史藝文</span>  
<span style="margin-left: 2em">志書錄解題文獻通考皆不著錄集首有端平乙</span>  
<span style="margin-left: 2em">未敷文閣學士程珌序稱其文峭直而紆餘嚴潔</span>  
<span style="margin-left: 2em">而平澹質而非俚華而不雕今觀其詩文皆意境</span>  
<span style="margin-left: 2em">劖削於陳師道爲近雖深厚不逮而模範畧同蓋</span>  
<span style="margin-left: 2em">以元祐諸人爲法者其上蔣樞密書論戰和守之</span>  
<span style="margin-left: 2em">俱非與汪楚材書論伊川之徒皆有卓識其芻言</span>  
<span style="margin-left: 2em">中豪民黠吏一條與論邕州以互市刼制化外一</span>  
<!-- 册4 葉932b　Page:文淵閣四庫全書_0004冊.djvu/238 -->
<span style="margin-left: 2em">條亦具有吏才非但以文章重也</span>  
高峯文集十二卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">宋廖剛撰剛字用中順昌人紹興中爲御史中丞</span>  
<span style="margin-left: 2em">出提舉明道宫致仕高峯其號也事迹具宋史本</span>  
<span style="margin-left: 2em">傳考朱子語𩔖論龜山門人謂剛爲助和議今觀</span>  
<span style="margin-left: 2em">其集若漳州被召上殿乞約束邊將諸劄其說誠</span>  
<span style="margin-left: 2em">然然宋史本傳載金人敗盟剛乃有責鄭億年以</span>  
<span style="margin-left: 2em">百口保金人之語又欲起舊相有德望者以是爲</span>  
<span style="margin-left: 2em">檜所惡致斥奉祠而集中與秦相公書亦以和議</span>  
<!-- 册4 葉933a　Page:文淵閣四庫全書_0004冊.djvu/238 -->
<span style="margin-left: 2em">爲失前後如出兩人豈至是乃悟其謬歟宋史以</span>  
<span style="margin-left: 2em">剛爲楊時弟子道學一脉愛屋及烏使與張九成</span>  
<span style="margin-left: 2em">胡銓同傳固爲不倫然視怙過不悛者則有間矣</span>  
<span style="margin-left: 2em">其他奏議指陳當時利弊頗有可採答陳幾叟書</span>  
<span style="margin-left: 2em">論知制誥之失尤爲切當至其乞設親軍劄子舍</span>  
<span style="margin-left: 2em">大慮小所見殊陋又諫止高宗節序拜欽宗事於</span>  
<span style="margin-left: 2em">君臣兄弟之義亦皆未協本傳乃獨采之去取未</span>  
<span style="margin-left: 2em">免失倫亦足證宋史之疎謬其是非不盡可據矣</span>  
<span style="margin-left: 2em">其集久無刻本傳寫多誤脫字或至數行無從校</span>  
<!-- 册4 葉933b　Page:文淵閣四庫全書_0004冊.djvu/238 -->
<span style="margin-left: 2em">補今亦姑從舊本錄之焉</span>  
鄂州小集六卷附錄二卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">宋羅願撰願有爾雅翼巳著錄淳熙甲辰願由知</span>  
<span style="margin-left: 2em">南劍州改鄂州乙巳卒於官州佐劉淸之爲刋其</span>  
<span style="margin-left: 2em">遺藁名鄂州小集止六卷史稱十卷與原集不合</span>  
<span style="margin-left: 2em">蓋宋史多訛不足爲據此本卷數雖符然編次無</span>  
<span style="margin-left: 2em">法又以新安志中小序二篇入之疑經後人掇拾</span>  
<span style="margin-left: 2em">而成亦非其舊也願父汝楫助秦檜以害岳飛犯</span>  
<span style="margin-left: 2em">天下之公怒而願學問該博文章高雅乃卓然有</span>  
<!-- 册4 葉936a　Page:文淵閣四庫全書_0004冊.djvu/239 -->
<span style="margin-left: 2em">以自立不爲父惡之所掩其淳安社壇記朱子自</span>  
<span style="margin-left: 2em">謂不如其爾雅翼後有方回跋曰回聞之先君子</span>  
<span style="margin-left: 2em">南渡後文章有先秦西漢風惟羅鄂州一人甫七</span>  
<span style="margin-left: 2em">歲能爲靑草賦以壽其先尙書少長落筆萬言旣</span>  
<span style="margin-left: 2em">冠乃數月不妄下一語其精思如此又曰小集僅</span>  
<span style="margin-left: 2em">文十之一劉公淸之子澄所刋晦翁謂其文有經</span>  
<span style="margin-left: 2em">緯嘗欲附名集後又謂羅端良止此可惜葢年止</span>  
<span style="margin-left: 2em">四十餘使老壽進未艾也鄭玉作是集序亦曰其</span>  
<span style="margin-left: 2em">陶令祠堂記張烈女廟碑詞嚴理暢至於論成湯</span>  
<!-- 册4 葉936b　Page:文淵閣四庫全書_0004冊.djvu/239 -->
