欽定四庫全書總目卷三十五  
<span style="margin-left: 1em">經部三十五</span>  
<span style="margin-left: 2em">四書類一</span>  
<span style="margin-left: 3em">論語孟子舊各爲帙大學中庸舊禮記之二篇</span>  
<span style="margin-left: 3em">其編爲四書自宋淳熙始其懸爲令甲則自元</span>  
<span style="margin-left: 3em">延祐復科舉始古來無是名也然二戴所錄曲</span>  
<span style="margin-left: 3em">禮檀弓諸篇非一人之書迨立名曰禮記禮記</span>  
<span style="margin-left: 3em">遂爲一家卽王逸所錄屈原宋玉諸篇漢志均</span>  
<span style="margin-left: 3em">謂之賦迨立名曰楚詞楚詞亦遂爲一家元邱</span>  
<!-- 册1 葉2821b　Page:文淵閣四庫全書_0001冊.djvu/755 -->
<span style="margin-left: 3em">葵周禮補亡序稱聖朝以六經取士則當時固</span>  
<span style="margin-left: 3em">以四書爲一經前創後因久則爲律是固難以</span>  
<span style="margin-left: 3em">一說拘矣今從明史藝文志例别立四書一門</span>  
<span style="margin-left: 3em">亦所謂禮以義起也朱𢑴尊經義考於四書之</span>  
<span style="margin-left: 3em">前仍立論語孟子二類黃虞稷千頃堂書目凡</span>  
<span style="margin-left: 3em">說大學中庸者皆附於禮類盖欲以不去餼羊</span>  
<span style="margin-left: 3em">畧存古義然朱子書行五百載矣趙岐何晏以</span>  
<span style="margin-left: 3em">下古籍存者寥寥元明以來之所解則皆自四</span>  
<span style="margin-left: 3em">書分出者耳明史併入四書盖循其實今亦不</span>  
<!-- 册1 葉2824a　Page:文淵閣四庫全書_0001冊.djvu/756 -->
<span style="margin-left: 3em">復强析其名焉</span>  
孟子正義十四卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">漢趙岐註其䟽則舊本題宋孫奭撰岐字邠<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">京</span>  
<span style="margin-left: 2em">兆長陵人初名嘉字臺<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">永興二年辟司空掾遷</span>  
<span style="margin-left: 2em">皮氏長延熹元年中常侍唐衡兄玹爲京兆尹與</span>  
<span style="margin-left: 2em">岐夙隙岐避禍逃避四方乃自改名字後遇赦得</span>  
<span style="margin-left: 2em">出拜并州刺史又遭黨錮十餘歲中平元年徵拜</span>  
<span style="margin-left: 2em">議郞舉燉煌太守後遷太僕終太常事迹具後漢</span>  
<span style="margin-left: 2em">書本傳奭字宗古博平人太宗端拱中九經及第</span>  
<!-- 册1 葉2824b　Page:文淵閣四庫全書_0001冊.djvu/756 -->
<span style="margin-left: 2em">仁宗時官至兵部侍郞龍圖閣學士事迹具宋史</span>  
<span style="margin-left: 2em">本傳是註卽岐避難北海時在孫賔家夾柱中所</span>  
<span style="margin-left: 2em">作漢儒註經多明訓詁名物惟此註箋釋文句乃</span>  
<span style="margin-left: 2em">似後世之口義與古學稍殊然孔安國馬融鄭元</span>  
<span style="margin-left: 2em">之註論語今載於何晏集解者體亦如是盖易書</span>  
<span style="margin-left: 2em">文皆最古非通其訓詁則不明詩禮語皆徵實非</span>  
<span style="margin-left: 2em">明其名物亦不解論語孟子詞㫖顯明惟闡其義</span>  
<span style="margin-left: 2em">理而止所謂言各有當也其中如謂宰予子貢有</span>  
<span style="margin-left: 2em">若縁孔子聖德高美而盛稱之孟子知其太過故</span>  
<!-- 册1 葉2825a　Page:文淵閣四庫全書_0001冊.djvu/756 -->
<span style="margin-left: 2em">貶謂之汚下之類紕繆殊甚以屈原憔悴爲徵於</span>  
<span style="margin-left: 2em">色以甯戚扣角爲發於聲之類亦比擬不倫然朱</span>  
<span style="margin-left: 2em">子作孟子集註或問於岐說不甚掊擊至於書中</span>  
<span style="margin-left: 2em">人名惟盆成括告子不從其學於孟子之說季孫</span>  
<span style="margin-left: 2em">子叔不從其二弟子之說餘皆從之書中字義惟</span>  
<span style="margin-left: 2em">折枝訓按摩之類不取其說餘亦多取之盖其說</span>  
<span style="margin-left: 2em">雖不及後來之精宻而開闢荒蕪俾後來得循途</span>  
<span style="margin-left: 2em">而深造其功要不可泯也胡爌拾遺錄據李善文</span>  
<span style="margin-left: 2em">選註引孟子曰墨子兼愛摩頂致於踵趙岐曰致</span>  
<!-- 册1 葉2825b　Page:文淵閣四庫全書_0001冊.djvu/756 -->
<span style="margin-left: 2em">至也知今本經文及注均與唐本不同今證以孫</span>  
<span style="margin-left: 2em">奭音義所音岐注亦多不相應<sub class="note-yuan">語詳孟子音義條下</sub>盖已非</span>  
<span style="margin-left: 2em">舊本至於盡心下篇夫子之設科也註稱孟子曰</span>  
<span style="margin-left: 2em">夫我設教授之科云云則顯爲予字今本乃作夫</span>  
<span style="margin-left: 2em">子又萬子曰句註稱萬子萬章也則顯爲子字今</span>  
<span style="margin-left: 2em">本乃作萬章是又註文未改而經文誤刊者矣孫</span>  
<span style="margin-left: 2em">奭之䟽朱子語錄謂邵武士人所假託蔡季通識</span>  
<span style="margin-left: 2em">其人今考宋史邢昺傳稱昺於咸平二年受詔與</span>  
<span style="margin-left: 2em">杜鎬舒雅孫奭李慕淸崔偓佺等校定周禮儀禮</span>  
<!-- 册1 葉2828a　Page:文淵閣四庫全書_0001冊.djvu/757 -->
<span style="margin-left: 2em">公羊榖梁春秋傳孝經論語爾雅義䟽不云有孟</span>  
<span style="margin-left: 2em">子正義涑水紀聞載奭所定著有論語孝經爾雅</span>  
<span style="margin-left: 2em">正義亦不云有孟子正義其不出奭手<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">然可信</span>  
<span style="margin-left: 2em">其䟽皆敷衍語氣如鄕塾講章故朱子語錄謂其</span>  
<span style="margin-left: 2em">全不似䟽體不曾解出名物制度只繞纒趙岐之</span>  
<span style="margin-left: 2em">說至岐註好用古事爲比䟽多不得其根據如註</span>  
<span style="margin-left: 2em">謂非禮之禮若趙質娶妻而長拜之非義之義若</span>  
<span style="margin-left: 2em">藉交報讐此誠不得其出典<sub class="note-yuan">案藉交報讐似謂藉交游之力以報讐如</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">朱家郭解非有人姓藉名交也疑不能明謹附識於此</sub>至於單豹養其内而</span>  
<!-- 册1 葉2828b　Page:文淵閣四庫全書_0001冊.djvu/757 -->
<span style="margin-left: 2em">虎食其外事出莊子亦不能舉則弇陋太甚朱𢑴</span>  
<span style="margin-left: 2em">尊經義考摘其欲見西施者人輸金錢一文事詭</span>  
<span style="margin-left: 2em">稱史記今考註以尾生爲不虞之譽以陳不曕爲</span>  
<span style="margin-left: 2em">求全之毁䟽亦並稱史記尾生事實見莊子陳不</span>  
<span style="margin-left: 2em">瞻事實見說苑<sub class="note-yuan">案說苑作陳不占盖古字同音假借</sub>皆史記所無如</span>  
<span style="margin-left: 2em">斯之類益影撰無稽矣以久列學官姑仍舊本錄</span>  
<span style="margin-left: 2em">之爾</span>  
論語義䟽十卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">魏何晏註梁皇侃䟽書前有奏進論語集解序題</span>  
<!-- 册1 葉2829a　Page:文淵閣四庫全書_0001冊.djvu/757 -->
<span style="margin-left: 2em">光祿大夫關内侯孫邕光祿大夫鄭冲散騎常侍</span>  
<span style="margin-left: 2em">中領軍安鄕亭侯曹羲侍中荀顗尚書駙馬都尉</span>  
<span style="margin-left: 2em">關内侯何晏五人之名晉書載鄭冲與孫邕何晏</span>  
<span style="margin-left: 2em">曹羲荀顗等共集論語諸家訓詁之善者義有不</span>  
<span style="margin-left: 2em">安輙改易之名集解亦兼稱五人今本乃獨稱何</span>  
<span style="margin-left: 2em">晏考陸德明經典釋文於學而第一下題集解二</span>  
<span style="margin-left: 2em">字註曰一本作何晏集解又序錄曰何晏集孔安</span>  
<span style="margin-left: 2em">國包咸周氏馬氏鄭元陳羣王肅周生烈之說并</span>  
<span style="margin-left: 2em">下已意爲集解正始中上之盛行於世今以爲主</span>  
<!-- 册1 葉2829b　Page:文淵閣四庫全書_0001冊.djvu/757 -->
<span style="margin-left: 2em">云云是獨題晏名其來久已殆晏以親貴總領其</span>  
<span style="margin-left: 2em">事歟邕字宗儒樂安靑州人冲字文和滎陽開封</span>  
<span style="margin-left: 2em">人羲沛國譙人魏宗室子顗字景倩荀彧之子晏</span>  
<span style="margin-left: 2em">字平叔南陽宛人何進之孫何咸之子也侃梁書</span>  
<span style="margin-left: 2em">作偘盖字異文吳郡人靑州刺史皇象九世孫武</span>  
<span style="margin-left: 2em">帝時官國子助教尋拜散騎侍郞兼助教如故大</span>  
<span style="margin-left: 2em">同十一年卒事迹具梁書儒林傳傳稱所撰禮記</span>  
<span style="margin-left: 2em">義五十卷論語義十卷禮記義久佚此書宋國史</span>  
<span style="margin-left: 2em">志中興書目晁公武讀書志尤袤遂初堂書目皆</span>  
<!-- 册1 葉2832a　Page:文淵閣四庫全書_0001冊.djvu/758 -->
<span style="margin-left: 2em">尚著錄國史志稱侃䟽雖有鄙近然博極羣言補</span>  
<span style="margin-left: 2em">諸書之未至爲後學所宗盖是時講學之風尚未</span>  
<span style="margin-left: 2em">甚熾儒者說經亦尚未盡廢古義故史臣之論云</span>  
<span style="margin-left: 2em">爾迨乾淳以後講學家門戸曰堅羽翼曰衆剷除</span>  
<span style="margin-left: 2em">異已惟恐有一字之遺遂無復稱引之者而陳氏</span>  
<span style="margin-left: 2em">書錄解題亦遂不著錄知其佚在南宋時矣惟唐</span>  
<span style="margin-left: 2em">時舊本流傳存於海外康熙九年日本國山井鼎</span>  
<span style="margin-left: 2em">等作七經孟子考文自稱其國有是書然中國無</span>  
<span style="margin-left: 2em">得其本者故朱𢑴尊經義考註曰未見今恭逢我</span>  
<!-- 册1 葉2832b　Page:文淵閣四庫全書_0001冊.djvu/758 -->
皇上右文稽古經籍道昌乃發其光於鯨波鮫室之中  
<span style="margin-left: 2em">藉海舶而登秘閣殆若有神物撝訶存漢晉經學</span>  
<span style="margin-left: 2em">之一綫俾待</span>  
聖世而復顯者其應運而來信有非偶然者矣據中興  
<span style="margin-left: 2em">書目稱侃以何晏集解去取爲䟽十卷又列晉衛</span>  
<span style="margin-left: 2em">瓘繆播欒肇郭象蔡謨袁宏江厚蔡溪李充孫綽</span>  
<span style="margin-left: 2em">周懷范甯王珉等十三人爵里於前云此十三家</span>  
<span style="margin-left: 2em">是江熙所集其解釋於何集<sub class="note-yuan">案何集二字不甚可解盖何氏集解之省</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">文今姑仍原本錄之</sub>無妨者引取以廣異聞此本之前列十</span>  
<!-- 册1 葉2833a　Page:文淵閣四庫全書_0001冊.djvu/758 -->
<span style="margin-left: 2em">三人爵里數與中興書目合惟江厚作江淳蔡溪</span>  
<span style="margin-left: 2em">作蔡系周懷作周壤殆傳寫異文歟其經文與今</span>  
<span style="margin-left: 2em">本亦多異同如舉一隅句下有而示之三字頗爲</span>  
<span style="margin-left: 2em">冗贅然與文獻通考所引石經論語合夫子之言</span>  
<span style="margin-left: 2em">性與入道不可得而聞也下有巳矣二字亦與錢</span>  
<span style="margin-left: 2em">曾讀書敏求記所引高麗古本合其䟽文與余蕭</span>  
<span style="margin-left: 2em">客古經解鉤沉所引雖字句或有小異而大㫖悉</span>  
<span style="margin-left: 2em">合知其<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">爲古本不岀依託觀古文孝經孔安國</span>  
<span style="margin-left: 2em">傳鮑氏知不足齋刻本信以爲眞而七經孟子考</span>  
<!-- 册1 葉2833b　Page:文淵閣四庫全書_0001冊.djvu/758 -->
<span style="margin-left: 2em">文乃自言其僞則彼國於授受源流分明有考可</span>  
<span style="margin-left: 2em">據以爲信也至臨之以莊則敬作臨民之以莊則</span>  
<span style="margin-left: 2em">敬七經孟子考文亦疑其民字爲悞衍然謹守古</span>  
<span style="margin-left: 2em">本而不敢改知彼國遞相傳寫偶然訛舛或有之</span>  
<span style="margin-left: 2em">亦未嘗有所竄易矣至何氏集解異同尤夥雖其</span>  
<span style="margin-left: 2em">中以包氏爲苞氏以陳恒爲陳桓之𩔖不可據者</span>  
<span style="margin-left: 2em">有之而勝於明刻監本者亦復不少尤可以旁資</span>  
<span style="margin-left: 2em">考證也</span>  
論語正義二十卷<sub class="note-yuan">内府藏本</sub>  
<!-- 册1 葉2836a　Page:文淵閣四庫全書_0001冊.djvu/759 -->
<span style="margin-left: 2em">魏何晏註宋邢昺疏昺字叔明曹州濟陰人太平</span>  
<span style="margin-left: 2em">興國中擢九經及第官至禮部尚書事迹具宋史</span>
