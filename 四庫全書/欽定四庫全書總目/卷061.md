欽定四庫全書總目卷六十一  
<span style="margin-left: 1em">史部十七</span>  
<span style="margin-left: 2em">傳記類存目三</span>  
漢末英雄記一卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">舊本題魏王粲撰粲字仲宣高平人仕魏爲丞相</span>  
<span style="margin-left: 2em">掾賜爵關内侯事迹具三國志本傳按粲卒於建</span>  
<span style="margin-left: 2em">安中其時黃星雖兆玉歩未更不應名書以漢末</span>  
<span style="margin-left: 2em">似後人之所追題然考粲從軍詩中巳稱曹操爲</span>  
<span style="margin-left: 2em">聖君則儼以魏爲新朝此名不足怪矣隋志著錄</span>  
<!-- 册2 葉1369b　Page:文淵閣四庫全書_0002冊.djvu/347 -->
<span style="margin-left: 2em">作八卷註云殘缺其本久佚此本乃王世貞雜抄</span>  
<span style="margin-left: 2em">諸書成之凡四十四人大扺取於裴松之三國志</span>  
<span style="margin-left: 2em">註爲多如水經注載白狼山曹操敲馬鞍作十片</span>  
<span style="margin-left: 2em">事本習見之書乃漏而不載又如築易京本公孫</span>  
<span style="margin-left: 2em">瓚事乃於瓚外别出一張瓚以此事屬之不知據</span>  
<span style="margin-left: 2em">何誤本尤疎舛之甚矣</span>  
廣卓異記二十卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">宋樂史撰史字正子宜黃人官太常博士<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">史館</span>  
<span style="margin-left: 2em">事蹟附載宋史樂黃中傳是編前有自序稱唐李</span>  
<!-- 册2 葉1372a　Page:文淵閣四庫全書_0002冊.djvu/348 -->
<span style="margin-left: 2em">翺卓異記三卷<sub class="note-yuan">案卓異記非李翺作史葢考之未詳謹附訂於此</sub>述唐代</span>  
<span style="margin-left: 2em">君臣卓絶盛事中多漏錄史初爲續記三卷以補</span>  
<span style="margin-left: 2em">其缺後復以僅載唐代未爲廣博因纂集漢魏以</span>  
<span style="margin-left: 2em">下迄五代併唐事共爲一帙名廣卓異記分爲二</span>  
<span style="margin-left: 2em">十卷首卷記帝王次卷記后妃王子公主三卷雜</span>  
<span style="margin-left: 2em">錄四卷至十七卷皆記臣下貴盛之極與顯達之</span>  
<span style="margin-left: 2em">速者十八巻雜錄十九卷舉選二十巻專記神仙</span>  
<span style="margin-left: 2em">之事大扺牽引駁雜訛謬亦多如所稱晉書王導</span>  
<span style="margin-left: 2em">以下至王褒九世皆自有史傳中有儉子仲寶仲</span>  
<!-- 册2 葉1372b　Page:文淵閣四庫全書_0002冊.djvu/348 -->
<span style="margin-left: 2em">寶子規云云案史仲寶乃王儉字非其子名也儉</span>  
<span style="margin-left: 2em">之子名騫騫之子名規非仲寶子名規也且規子</span>  
<span style="margin-left: 2em">褒附見規傳亦非自有傳諸傳雜見於宋齊梁書</span>  
<span style="margin-left: 2em">及南史亦非全在晉書舛謬殊甚又石勒每更聞</span>  
<span style="margin-left: 2em">鼓鼙聲武士彠聞空中言唐公爲天子與夢高祖</span>  
<span style="margin-left: 2em">乘白馬上天之𩔖神怪無稽頗爲蕪雜至引錄傳</span>  
<span style="margin-left: 2em">稱周時尹氏貴盛㑹食家數千人遭饑荒羅粟作</span>  
<span style="margin-left: 2em">糜吮之吮糜之聲聞於數十里亦不近事理之談</span>  
<span style="margin-left: 2em">其末卷則於自撰總仙記中撮其殊異者入此書</span>  
<!-- 册2 葉1373a　Page:文淵閣四庫全書_0002冊.djvu/348 -->
<span style="margin-left: 2em">所言不出全家登仙祖孫兄弟登仙及三世四世</span>  
<span style="margin-left: 2em">五世登仙四人六人七人登仙之類重複支離尤</span>  
<span style="margin-left: 2em">不足信自序稱採自漢魏而下而編中乃及楚孫</span>  
<span style="margin-left: 2em">叔敖周尹氏末卷所列神仙并及堯舜之時與序</span>  
<span style="margin-left: 2em">自相矛盾又其小失矣</span>  
靖康小雅一巻<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">不著撰人名氏錄靖康死事之臣傅察种師中王</span>  
<span style="margin-left: 2em">禀劉翊种師道何慶彦黄經臣劉韐李若水徐揆</span>  
<span style="margin-left: 2em">孫傳張叔夜凡十二人宗澤張慤阨於黄潛善汪</span>  
<!-- 册2 葉1373b　Page:文淵閣四庫全書_0002冊.djvu/348 -->
<span style="margin-left: 2em">伯彦而死者亦附焉澤傳中稱潛善卒不遄死而</span>  
<span style="margin-left: 2em">令公卒則此書作於汪黃秉政之日矣傳末各係</span>  
<span style="margin-left: 2em">以四言詩故以小雅爲名其文散見北盟㑹編中</span>  
<span style="margin-left: 2em">此本次序似以徐夢莘所載抄合之非完書也</span>  
紹興正論一卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">舊本題湘山樵夫撰不著名氏敘列張浚趙鼎胡</span>  
<span style="margin-left: 2em">銓胡寅連南夫張戒常同吕本中張致遠魏矼張</span>  
<span style="margin-left: 2em">絢曾開李彌遜晏敦夫王庶毛叔度范如圭汪應</span>  
<span style="margin-left: 2em">辰許忻方廷寶韓訓陳鼎許時行李光洪皓沈正</span>  
<!-- 册2 葉1376a　Page:文淵閣四庫全書_0002冊.djvu/349 -->
<span style="margin-left: 2em">卿張燾陳康伯陳括陳剛中三十人皆以不附和</span>  
<span style="margin-left: 2em">議而貶謫者每人之下畧具事實少者一二語多</span>  
<span style="margin-left: 2em">亦不過三四行按書錄解題載紹興正論二卷注</span>  
<span style="margin-left: 2em">曰序稱瀟湘野人不著名氏錄文武官不附和議</span>  
<span style="margin-left: 2em">及忤秦檜得罪者又載紹興正論小傳二十卷則</span>  
<span style="margin-left: 2em">樓昉以正論中姓名仿元祐黨傳爲之所謂二卷</span>  
<span style="margin-left: 2em">者似卽此書而書名及撰人之號皆大同小異卷</span>  
<span style="margin-left: 2em">數亦不相符其故則莫得而詳矣</span>  
桐陰舊話一卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<!-- 册2 葉1376b　Page:文淵閣四庫全書_0002冊.djvu/349 -->
<span style="margin-left: 2em">宋韓元吉撰元吉字无咎宰相維之元孫以任子</span>  
<span style="margin-left: 2em">仕歴龍圖閣學士吏部尚書嘗居廣信溪南自號</span>  
<span style="margin-left: 2em">南澗居士此書宋志云十卷陳振孫書錄解題亦</span>  
<span style="margin-left: 2em">同續百川學海所錄乃祇此一卷其條數亦與此</span>  
<span style="margin-left: 2em">本同蓋全書久佚從諸書抄撮成編也書中所記</span>  
<span style="margin-left: 2em">韓億韓綜韓綘韓繹韓維韓縝雜事共存十三條</span>  
<span style="margin-left: 2em">皆其家世舊聞以京師第門有桐木故云桐陰舊</span>  
<span style="margin-left: 2em">話葢北宋兩韓氏並盛世以桐木韓家别於魏國</span>  
<span style="margin-left: 2em">韓琦云</span>  
<!-- 册2 葉1377a　Page:文淵閣四庫全書_0002冊.djvu/349 -->
南渡十將傳十卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">宋章頴撰十將者劉錡岳飛李顯忠魏勝韓世忠</span>  
<span style="margin-left: 2em">張俊虞允文張子蓋張宗顔吳玠也劉岳李魏四</span>  
<span style="margin-left: 2em">傳開禧二年表上後六傳未上核以宋史本傳此</span>  
<span style="margin-left: 2em">所采摭未爲詳核且抑世忠於勝顯忠後似亦未</span>  
<span style="margin-left: 2em">安子蓋宗顔戰功寥寥允文亦僥倖不敗乃與諸</span>  
<span style="margin-left: 2em">人並數皆未免不倫也</span>  
稗傳一巻<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">元徐顯撰顯仕履無可考觀其稱王艮爲鄉里又</span>  
<!-- 册2 葉1377b　Page:文淵閣四庫全書_0002冊.djvu/349 -->
<span style="margin-left: 2em">稱居平江東城則當爲紹興人而寓於姑蘇者也</span>  
<span style="margin-left: 2em">是編紀元末王艮柯九思陳謙葛乾孫潘純陸友</span>  
<span style="margin-left: 2em">王冕王漸楊椿王德元徐文中事後載沈烈婦等</span>  
<span style="margin-left: 2em">十三人敘述頗爲詳備中多及丙申二月平江城</span>  
<span style="margin-left: 2em">䧟事指張士誠軍爲外兵而載已亥紹興被兵事</span>  
<span style="margin-left: 2em">於明人則<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">斥爲宼疑作此書時張氏尚存故其</span>  
<span style="margin-left: 2em">詞如此其敘柯九思之卒在至正癸亥按至正紀</span>  
<span style="margin-left: 2em">年無癸亥而九思之卒實在乙巳蓋此書傳寫誤</span>  
<span style="margin-left: 2em">也</span>  
<!-- 册2 葉1380a　Page:文淵閣四庫全書_0002冊.djvu/350 -->
萬柳溪邊舊話一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">元尤玘撰玘字君玉號知非子自稱尤袤之後不</span>  
<span style="margin-left: 2em">知其世次舊本題爲宋人今此書後跋稱玘爲大</span>  
<span style="margin-left: 2em">司徒則嘗官戸部尚書又末條稱終慕公不肯仕</span>  
<span style="margin-left: 2em">元則當爲元人而巻首題門人張雨塡諱則又句</span>  
<span style="margin-left: 2em">曲外史之師當在元中葉以後也書中所記皆尤</span>  
<span style="margin-left: 2em">氏先世事末有玘曾孫實跋稱宏治二十九年於</span>  
<span style="margin-left: 2em">祠屋中求得舊本簡斷墨闇不可讀者逾半命門</span>  
<span style="margin-left: 2em">人許靈鈔其完者而恨全帙之不可得是此書巳</span>  
<!-- 册2 葉1380b　Page:文淵閣四庫全書_0002冊.djvu/350 -->
<span style="margin-left: 2em">非完本矣元陳世隆載入藝圃搜竒所載之文與</span>  
<span style="margin-left: 2em">此本並同斷無明人所鈔壞爛之本適與元人所</span>  
<span style="margin-left: 2em">見一字不異者此亦足證藝圃搜竒必非元人書</span>  
<span style="margin-left: 2em">也</span>  
旌義編二卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">元鄭濤撰濤字仲舒浦江人官太常禮儀院博士</span>  
<span style="margin-left: 2em">鄭氏稱義門自宋建炎初名綺者始至濤爲八世</span>  
<span style="margin-left: 2em">先是綺六世孫龍灣稅課提領太和爲家規五十</span>  
<span style="margin-left: 2em">八則七世孫欽及其弟<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）">增九十二則共一百五</span>  
<!-- 册2 葉1381a　Page:文淵閣四庫全書_0002冊.djvu/350 -->
<span style="margin-left: 2em">十則勒之於石至濤復謂禮有當隨時變通者乃</span>  
<span style="margin-left: 2em">酌加增損爲一百六十八則列爲上卷又彚輯諸</span>  
<span style="margin-left: 2em">家傳記碑銘之文有關鄭氏事實者列爲下卷通</span>  
<span style="margin-left: 2em">名曰旌義編宋濓序稱三卷其書實止二卷蓋序</span>  
<span style="margin-left: 2em">文傳寫之誤也</span>  
忠傳四卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">不著撰人名氏載於永樂大典中題云國朝忠傳</span>  
<span style="margin-left: 2em">則明初人所作也其書集古今事迹各繪圖繫說</span>  
<span style="margin-left: 2em">語皆鄙俚似委巷演義之流殆亦明太祖時官書</span>  
<!-- 册2 葉1381b　Page:文淵閣四庫全書_0002冊.djvu/350 -->
<span style="margin-left: 2em">歟</span>  
草莽私乘一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">舊本題明陶宗儀編宗儀有國風尊經已著錄是</span>  
<span style="margin-left: 2em">書凡錄胡長孺王惲許有壬虞集劉因李孝光金</span>  
<span style="margin-left: 2em">炯楊維楨林淸源龔開周仔肩揭傒斯貢師泰汪</span>  
<span style="margin-left: 2em">澤民十四人雜文二十首皆紀當時忠孝節義之</span>  
<span style="margin-left: 2em">作王世貞集有此書跋語云係宗儀手抄然孫作</span>  
<span style="margin-left: 2em">滄螺集載有宗儀小傳紀所作書目有說郛一百</span>  
<span style="margin-left: 2em">巻書史㑹要九巻四書備遺二巻輟耕錄三十巻</span>  
<!-- 册2 葉1384a　Page:文淵閣四庫全書_0002冊.djvu/351 -->
<span style="margin-left: 2em">無此書名疑好事者依托也</span>  
宋遺民錄一卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">不著撰人名氏乃洪武中抄本毛晉刻之附於忠</span>  
<span style="margin-left: 2em">義集之後或元人所作或明初人所作均未可知</span>  
<span style="margin-left: 2em">後程敏政亦有宋遺民錄殆未見此本故其名相</span>  
<span style="margin-left: 2em">複歟</span>  
金華賢達傳十二卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>
