欽定四庫全書總目卷二十四  
<span style="margin-left: 1em">經部二十四</span>  
<span style="margin-left: 2em">禮類存目二</span>  
批<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）">檀弓二卷<sub class="note-yuan">兵部侍郞紀昀家藏本</sub>  
<span style="margin-left: 2em">舊本題宋謝枋得撰枋得字君<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">號叠山信州弋</span>  
<span style="margin-left: 2em">陽人寳祐四年進士宋末爲江東制置使臨安破</span>  
<span style="margin-left: 2em">後卽弋陽起義兵兵潰後遁迹浦城元福建行省</span>  
<span style="margin-left: 2em">魏天佑迫脅送燕京遂絕食而卒事迹具宋史忠</span>  
<span style="margin-left: 2em">義傳是編莫知所自來明萬厯丙辰烏程閔齊伋</span>  
<!-- 册1 葉1944b　Page:文淵閣四庫全書_0001冊.djvu/536 -->
<span style="margin-left: 2em">始以朱墨板刻之齊伋序稱得謝高泉所校舊本</span>  
<span style="margin-left: 2em">亦不言謝本出誰氏書中圈<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）">甚宻而評則但標</span>  
<span style="margin-left: 2em">章法句法等字似孫鑛等評書之法不類宋人體</span>  
<span style="margin-left: 2em">例疑因枋得有文章軌範依託爲之又題楊升庵</span>  
<span style="margin-left: 2em">附註而與愼檀弓叢訓復不相同據齊伋序稱彚</span>  
<span style="margin-left: 2em">註疏集註集說諸書去其繁而存其要以著於簡</span>  
<span style="margin-left: 2em">端則齊伋之所加非愼原註也葢明季刋本名實</span>  
<span style="margin-left: 2em">舛互往往如斯矣</span>  
月令七十二候集解一卷<sub class="note-yuan">通行本</sub>  
<!-- 册1 葉1945a　Page:文淵閣四庫全書_0001冊.djvu/536 -->
<span style="margin-left: 2em">舊本題元吳澄撰其書以七十二候分屬於二十</span>  
<span style="margin-left: 2em">四氣各訓釋其所以然考禮記月令本無七十二</span>  
<span style="margin-left: 2em">候之說逸周書時訓解乃以五日爲一候澄作禮</span>  
<span style="margin-left: 2em">記纂言亦引唐月令分著五日一候之義然不聞</span>  
<span style="margin-left: 2em">更有此書其說以經文所記多指北方非南方之</span>  
<span style="margin-left: 2em">所習見乃博考說文埤雅諸書兼訪之於農牧著</span>  
<span style="margin-left: 2em">爲此編然考證名物罕所發明又旣以螻蟈爲土</span>  
<span style="margin-left: 2em">狗又載鼯鼠五技之說自相矛盾旣以虹爲日映</span>  
<span style="margin-left: 2em">雨氣又引虹首如驢之說兼采雜書亦乖解經之</span>  
<!-- 册1 葉1945b　Page:文淵閣四庫全書_0001冊.djvu/536 -->
<span style="margin-left: 2em">法疑託名也</span>  
檀弓叢訓二卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">明楊愼撰愼字用修號升庵新都人正德辛未進</span>  
<span style="margin-left: 2em">士第一授翰林院修撰以諫大禮謫戍滇中事迹</span>  
<span style="margin-left: 2em">具明史本傳此本前有愼自序後有永昌張含䟦</span>  
<span style="margin-left: 2em">葢愼在滇中採鄭孔賀陸黃吳諸家注義以補陳</span>  
<span style="margin-left: 2em">澔集說所未備然如胡寅以檀弓爲曾子門人與</span>  
<span style="margin-left: 2em">子思同纂修論說魏了翁又斷爲子游門人此書</span>  
<span style="margin-left: 2em">旣單行何得於著書之人畧而不敘但引孔䟽數</span>  
<!-- 册1 葉1948a　Page:文淵閣四庫全書_0001冊.djvu/537 -->
<span style="margin-left: 2em">言無所訂正又言思爲子游之子注復遺之至大</span>  
<span style="margin-left: 2em">夫遣車五乘與周官典命之文不合者亦未置一</span>  
<span style="margin-left: 2em">語葢邊地無書姑以<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）">勘遣曰原不足以言詁經</span>  
<span style="margin-left: 2em">也</span>  
就正錄禮記會要六卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明宗周撰周字維翰興化人嘉靖辛卯舉人官至</span>  
<span style="margin-left: 2em">馬湖府知府是編於先王之制先聖之言多以意</span>  
<span style="margin-left: 2em">斷制懸定是非其義皆不考於古其體亦近於語</span>  
<span style="margin-left: 2em">錄</span>  
<!-- 册1 葉1948b　Page:文淵閣四庫全書_0001冊.djvu/537 -->
禮記明音二卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明王覺撰覺江陰人江南通志作武進人嘉靖辛</span>  
<span style="margin-left: 2em">丑進士書末有南京禮部郞中巴郡劉起宗䟦稱</span>  
<span style="margin-left: 2em">溝東王子溝東葢其別號也是書大抵据陳澔集</span>  
<span style="margin-left: 2em">說專標字音因書而及其義因聲而及其形其所</span>  
<span style="margin-left: 2em">引諸書刪節詳略初無體例亦間有不著出典者</span>  
<span style="margin-left: 2em">雖於訂正俗讀不爲無功要亦鄉塾課𫎇之本而</span>  
<span style="margin-left: 2em">巳</span>  
禮記集說辨疑一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<!-- 册1 葉1949a　Page:文淵閣四庫全書_0001冊.djvu/537 -->
<span style="margin-left: 2em">明戴冠撰冠字章甫長洲人以選貢授紹興府訓</span>  
<span style="margin-left: 2em">導是書所論凡曲禮六條檀弓九條王制三條曾</span>  
<span style="margin-left: 2em">子問二條文王世子一條禮器一條郊特牲一條</span>  
<span style="margin-left: 2em">内則五條玉藻二條大傳一條少儀一條喪大記</span>  
<span style="margin-left: 2em">二條祭義一條表記一條緇衣一條葢未竟之書</span>  
<span style="margin-left: 2em">也嘉靖丁未陸粲刋冠所作濯纓亭筆記附載於</span>  
<span style="margin-left: 2em">末然筆記爲雜說而此書究爲經解今仍析爲二</span>  
<span style="margin-left: 2em">各著錄焉</span>  
禮記集註三十卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<!-- 册1 葉1949b　Page:文淵閣四庫全書_0001冊.djvu/537 -->
<span style="margin-left: 2em">明徐師曾撰師曾有今文周易演義已著錄是書</span>  
<span style="margin-left: 2em">以陳澔集說爲未得經義故別採先儒舊訓以爲</span>  
<span style="margin-left: 2em">此註於鄭賈注疏間能體會然訾斥經文者不一</span>  
<span style="margin-left: 2em">而足如曾子問云至如將冠子而未及期日而有</span>  
<span style="margin-left: 2em">齊衰大功小功之喪則因喪服而冠除喪不改冠</span>  
<span style="margin-left: 2em">乎孔子曰天子賜諸侯大夫冕弁服於太廟歸設</span>  
<span style="margin-left: 2em">奠服賜服於斯乎有冠醮無冠醴師曾謂齊衰大</span>  
<span style="margin-left: 2em">小功待除而冠未爲遲何必因喪而冠冠禮三加</span>  
<span style="margin-left: 2em">而醮冠畢而醴若諸侯大夫服賜服不云三加安</span>  
<!-- 册1 葉1952a　Page:文淵閣四庫全書_0001冊.djvu/538 -->
<span style="margin-left: 2em">得有醮而無醴遂指二句爲誤當云有冠醴無冠</span>  
<span style="margin-left: 2em">醮葢師曾以儀禮士冠禮之三醮一醴并爲周人</span>  
<span style="margin-left: 2em">一代之制故謂三醮之時各有醮冠畢而又醴今</span>  
<span style="margin-left: 2em">經文旣無三加則苐當有醴不當有醮不知周制</span>  
<span style="margin-left: 2em">三加之時並無三醮待冠畢而始一醴耳其三加</span>  
<span style="margin-left: 2em">三醮乃殷禮故經文次在冠畢而醴之後先本朝</span>  
<span style="margin-left: 2em">而後前代也士冠禮鄭注賈疏甚明此經因遭喪</span>  
<span style="margin-left: 2em">殺禮故改冠後之一醴爲一醮自用周制師曾不</span>  
<span style="margin-left: 2em">考註疏誤執殷禮故有是說葢於三禮經義未能</span>  
<!-- 册1 葉1952b　Page:文淵閣四庫全書_0001冊.djvu/538 -->
<span style="margin-left: 2em">融合僅隨文而生義宜其說之多誤也</span>  
禮記日錄三十卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明黃乾行撰乾行字玉巖福寧人嘉靖癸未進士</span>  
<span style="margin-left: 2em">官至重慶府知府是書首有嘉靖乙卯鍾一元序</span>  
<span style="margin-left: 2em">言乾行以是經掇科第拜京秩膺命相禮衡藩乃</span>  
<span style="margin-left: 2em">以公之士類今觀其書割裂周禮儀禮散綴於禮</span>  
<span style="margin-left: 2em">記之中不復別識與朱子經傳通解之例巳大相</span>  
<span style="margin-left: 2em">刺謬又以小學故實竄入經文混合爲一尤爲龎</span>  
<span style="margin-left: 2em">雜其註或一節附論一篇或十餘節附論一篇多</span>  
<!-- 册1 葉1953a　Page:文淵閣四庫全書_0001冊.djvu/538 -->
<span style="margin-left: 2em">牽引道學語錄義皆膚廓</span>  
禮記輯覽八卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明徐養相撰養相雎陽衛籍鳳陽人嘉靖丙辰進</span>  
<span style="margin-left: 2em">士其書葢爲科舉而設不載經文惟以某章某節</span>  
<span style="margin-left: 2em">標目循文訓釋不出陳澔之緒論</span>  
禮記要㫖補十卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">舊本題戈九疇撰聞人德行增補蔡必大序又稱</span>  
<span style="margin-left: 2em">古陸守戈公以聞人先生舊所傳要㫖板行先生</span>  
<span style="margin-left: 2em">獨弗是曰是吾土苴也因取舊稿改竄補綴以備</span>  
<!-- 册1 葉1953b　Page:文淵閣四庫全書_0001冊.djvu/538 -->
<span style="margin-left: 2em">一家之言据此則是書始終出德行手九疇特刋</span>  
<span style="margin-left: 2em">行之耳與標題殊相矛盾又朱彞尊經義考載聞</span>  
<span style="margin-left: 2em">人德行禮記要㫖補十六卷又載戈九疇禮記要</span>  
<span style="margin-left: 2em">㫖十六卷戈氏書旣載其後不應聞人氏書先云</span>  
<span style="margin-left: 2em">補尤爲舛互此本僅有十卷而兼題二人之名其</span>  
<span style="margin-left: 2em">書乃鄉塾講章每節下綴以破題最爲猥陋殆書</span>  
<span style="margin-left: 2em">賈以二家之言合併竄亂以成此本歟明季坊本</span>  
<span style="margin-left: 2em">其不足信類如此不足深詰也九疇字雨泉錦衣</span>  
<span style="margin-left: 2em">衛人嘉靖巳未進士據蔡必大序其官爲嚴州府</span>  
<!-- 册1 葉1956a　Page:文淵閣四庫全書_0001冊.djvu/539 -->
<span style="margin-left: 2em">知府德行字越望餘姚人嘉靖戊戌進士據呂本</span>  
<span style="margin-left: 2em">序其官乃由翰林外謫其詳則均不可考矣</span>  
禮記中說三十六卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明馬時敏撰時敏字晉<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">陳留人隆慶中貢生是</span>  
<span style="margin-left: 2em">編不載經文但如坊刻時文題目之式標某章某</span>  
<span style="margin-left: 2em">節而敷衍其語氣其名中說者謂折衆說而得其</span>  
<span style="margin-left: 2em">中也然大㫖株守陳澔集說未見其折中者安在</span>  
禮記新義三十卷<sub class="note-yuan">江西巡撫採進本</sub>  
<span style="margin-left: 2em">明湯三才撰三才字中立丹陽人朱彞尊經義考</span>  
<!-- 册1 葉1956b　Page:文淵閣四庫全書_0001冊.djvu/539 -->
<span style="margin-left: 2em">叙其書於王翼明趙宧光之前蓋隆慶萬厯間人</span>  
<span style="margin-left: 2em">也前有其子道衡序其書與先儒傳注多所牴牾</span>  
<span style="margin-left: 2em">如解純素謂純字不當讀準解負劍辟咡謂負劍</span>  
<span style="margin-left: 2em">爲長者背負童子皆不可爲訓惟於名物度數偶</span>  
<span style="margin-left: 2em">有考證間或可備一解耳</span>  
禮記疑問十二卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明姚舜牧撰舜牧有易經疑問巳著錄是書依文</span>  
<span style="margin-left: 2em">訓義多作語錄之體間有新說則多與經義違背</span>  
<span style="margin-left: 2em">如曲禮爲人子者父母存冠衣不純素孤子當室</span>  
<!-- 册1 葉1957a　Page:文淵閣四庫全書_0001冊.djvu/539 -->
<span style="margin-left: 2em">冠衣不純采鄭氏注純緣也玉藻曰縞冠元武子</span>  
<span style="margin-left: 2em">姓之冠也縞冠素紕旣祥之冠也深衣曰具父母</span>  
<span style="margin-left: 2em">衣純以靑孤子衣純以素訓最明晰舜牧乃云論</span>  
<span style="margin-left: 2em">語麻冕禮也今也純儉此純字亦將作飾緣解乎</span>  
<span style="margin-left: 2em">是併字義未及詳考而漫與鄭孔爲難也</span>
