## 欽定四庫全書總目 卷八十四　史部四十　政書類存目二

欽定四庫全書總目卷八十四  
<span style="margin-left: 1em">史部四十</span>  
<span style="margin-left: 2em">政書類存目二</span>  
邦計彚編一卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">舊本題宋李維撰維字仲方肥鄉人雍熙二年進</span>  
<span style="margin-left: 2em">士召試中書知制誥厯翰林學士工部尙書柳州</span>  
<span style="margin-left: 2em">觀察使事跡具宋史本傳是書載曹溶學海類編</span>  
<span style="margin-left: 2em">中實册府元龜邦計一門之總叙案晁公武讀書</span>  
<span style="margin-left: 2em">志載修册府元龜時預修者十五人維居第四又</span>  
<!-- 册2 葉2961b　Page:文淵閣四庫全書_0002冊.djvu/745 -->
<span style="margin-left: 2em">載初撰編叙諸儒皆作眞宗以體制不一遂擇李</span>  
<span style="margin-left: 2em">維錢惟演陳彭年劉筠夏竦等付楊億竄定其剽</span>  
<span style="margin-left: 2em">剟此序詭題書名而以爲維之所撰葢以此云</span>  
拯荒事畧一卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">舊本題元歐陽元撰元字原功瀏陽人延祐二年</span>  
<span style="margin-left: 2em">進士除同知平江州事調蕪湖武岡二縣尹召爲</span>  
<span style="margin-left: 2em">國子博士遷翰林待制天厯初授藝文少監纂修</span>  
<span style="margin-left: 2em">經世大典至正初以學士告歸詔修宋遼金三史</span>  
<span style="margin-left: 2em">起爲總裁官拜翰林學士承㫖至正十七年卒諡</span>  
<!-- 册2 葉2964a　Page:文淵閣四庫全書_0002冊.djvu/746 -->
<span style="margin-left: 2em">曰文事跡具元史本傳是書前有自序稱蕪湖本</span>  
<span style="margin-left: 2em">南方澤國比隣數邑並在水鄉每當春夏之交陽</span>  
<span style="margin-left: 2em">侯不戢遂成饑歲余忝爲令長因輯拯荒事畧一</span>  
<span style="margin-left: 2em">編云云與本傳稱嘗知蕪湖縣語相合然其書但</span>  
<span style="margin-left: 2em">引故實二十二條無一事之擘畫其唐天復甲子</span>  
<span style="margin-left: 2em">竹放花結米一條尤不近理竹米偶生非人力可</span>  
<span style="margin-left: 2em">致採食竹米亦何需官爲經理𫆀學海𩔖編所載</span>  
<span style="margin-left: 2em">諸書十有五僞此書殆亦托名於元也</span>  
寳鈔通考八卷<sub class="note-yuan">永樂大典本</sub>  
<!-- 册2 葉2964b　Page:文淵閣四庫全書_0002冊.djvu/746 -->
<span style="margin-left: 2em">元武祺撰祺里貫未詳至正十三年爲戸部尙書</span>  
<span style="margin-left: 2em">因當時鈔法漸壞浮議者但以不動鈔本爲名而</span>  
<span style="margin-left: 2em">不詳流通之實乃厯考中統以後八十餘年中鈔</span>  
<span style="margin-left: 2em">法撰爲此書大㫖謂自世祖至元二十四年至武</span>  
<span style="margin-left: 2em">宗至大四年二十五年中印者多燒者少流轉廣</span>  
<span style="margin-left: 2em">而鈔法通自仁宗皇慶元年至延祐七年共九年</span>  
<span style="margin-left: 2em">印雖多而燒亦多流轉漸少鈔法始壊自英宗至</span>  
<span style="margin-left: 2em">治元年至三年印雖多而燒者寡流轉愈多鈔法</span>  
<span style="margin-left: 2em">愈壞自泰定元年至至順三年共八年印者少而</span>  
<!-- 册2 葉2965a　Page:文淵閣四庫全書_0002冊.djvu/746 -->
<span style="margin-left: 2em">燒者多流轉絶無鈔法大壞復合計六十四年中</span>  
<span style="margin-left: 2em">總印鈔五千九百五萬六千餘錠總支五千六百</span>  
<span style="margin-left: 2em">二十餘萬錠總燒三千六百餘萬錠民間流轉不</span>  
<span style="margin-left: 2em">及二萬錠以經世大典所載南北戸口民數計之</span>  
<span style="margin-left: 2em">其無鈔可用者至二千萬戸之多民生安得而不</span>  
<span style="margin-left: 2em">匱財用安得而不絀乎其言可爲行鈔之戒元史</span>  
<span style="margin-left: 2em">食貨志所載鈔法僅詳其制度數目而於財之息</span>  
<span style="margin-left: 2em">耗民之貧富未之詳言似乎未見祺書存此一編</span>  
<span style="margin-left: 2em">亦可以補史之缺然此書在當日爲洞悉利弊之</span>  
<!-- 册2 葉2965b　Page:文淵閣四庫全書_0002冊.djvu/746 -->
<span style="margin-left: 2em">言在今日則鈔法之不可行無智愚皆能知之無</span>  
<span style="margin-left: 2em">待縷陳矣故撮舉大要附存其目而書則不復錄</span>  
<span style="margin-left: 2em">焉</span>  
元海運志一卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">舊本題明危素撰素有草廬年譜巳著錄是編載</span>  
<span style="margin-left: 2em">曹溶學海類編中騐其文乃邱濬大學衍義補之</span>  
<span style="margin-left: 2em">海運一條也亦不善作僞矣</span>  
漕政舉要錄十八卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明邵寳撰寳有左觽已著錄是編乃正德巳巳寳</span>  
<!-- 册2 葉2968a　Page:文淵閣四庫全書_0002冊.djvu/747 -->
<span style="margin-left: 2em">以副都御史總漕江北時所作卷一至卷六爲河</span>  
<span style="margin-left: 2em">渠之政卷七爲舟楫之政卷八爲倉厫之政卷九</span>  
<span style="margin-left: 2em">爲卒伍之政卷十卷十一爲轉輸之政卷十二爲</span>  
<span style="margin-left: 2em">統領之政卷十三至卷十五爲紀載之政卷十六</span>  
<span style="margin-left: 2em">爲稽古之政卷十七爲凖令之政卷十八以襍錄</span>  
<span style="margin-left: 2em">終焉</span>  
鹽法考畧一卷錢法纂要一卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">舊本皆題明邱濬撰濬有家禮儀節巳著錄此二</span>  
<span style="margin-left: 2em">書諸家書目皆不載以其文考之卽濬大學衍義</span>  
<!-- 册2 葉2968b　Page:文淵閣四庫全書_0002冊.djvu/747 -->
<span style="margin-left: 2em">補中之兩篇也曹溶割裂其文並載學海𩔖編中</span>  
<span style="margin-left: 2em">較其以元海運志爲危素撰者猶爲近實然摘錄</span>  
<span style="margin-left: 2em">巨帙之一篇卽别立新名亦猶之乎作僞也</span>  
鐵冶志二卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明傅浚撰浚字汝源南安人宏治巳未進士官至</span>  
<span style="margin-left: 2em">工部郞中正德癸酉浚督理遵化鐵厰創爲此志</span>  
<span style="margin-left: 2em">自建置山塲迄於雜職凡二十三目冠以公署鐵</span>  
<span style="margin-left: 2em">厰二圖所紀皆歲辦出入之數頗𤨏屑無裨考証</span>  
<span style="margin-left: 2em">案明史職官志載工部分司祗有提督易州山厰</span>  
<!-- 册2 葉2969a　Page:文淵閣四庫全書_0002冊.djvu/747 -->
<span style="margin-left: 2em">柴炭一員而浚所志遵化分司始委主事宏治中</span>  
<span style="margin-left: 2em">改用郞中奉勅董理列厯官姓名甚悉不知史志</span>  
<span style="margin-left: 2em">何以遺之殆其後又經裁汰𫆀</span>  
陽明鄉約法一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明王守仁撰守仁字伯安號陽明餘姚人宏治巳</span>  
<span style="margin-left: 2em">未進士官至兵部尙書封新建伯事迹具明史本</span>  
<span style="margin-left: 2em">傳是書巳載陽明全書中崇禎間嘉善陳龍正復</span>  
<span style="margin-left: 2em">錄出别行其法有約長約副約正約史知約約贊</span>  
<span style="margin-left: 2em">諸人已極繁𤨏至爭鬬賦役諸事以至𭔃莊人戸</span>  
<!-- 册2 葉2969b　Page:文淵閣四庫全書_0002冊.djvu/747 -->
<span style="margin-left: 2em">納糧當差皆約長主之葢欲以約長代周官比長</span>  
<span style="margin-left: 2em">黨正之法然古法實不盡宜於今也</span>  
陽明保甲法一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明王守仁撰悉載牌諭諸文亦見陽明全集中陳</span>  
<span style="margin-left: 2em">龍正錄出别行而各附題識於其下</span>  
救荒活民補遺書三卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明朱熊撰熊字維吉汇陰人取宋從政郞董煟原</span>  
<span style="margin-left: 2em">書而益以有明䘏賑制詔及前代好施𫉬福事蹟</span>  
<span style="margin-left: 2em">其立意不爲不善然序述典故備錄經典重農之</span>  
<!-- 册2 葉2972a　Page:文淵閣四庫全書_0002冊.djvu/748 -->
<span style="margin-left: 2em">語則迂而不切襍載諸史賑恤之文則繁而鮮要</span>  
<span style="margin-left: 2em">皆不免勦襲陳言無裨實政至於盛陳福報尤渉</span>  
<span style="margin-left: 2em">於有爲而爲葢鄉里勸施之格言而非經國之碩</span>  
<span style="margin-left: 2em">畫二氏因果之緒論而非儒者之正理也</span>  
鹽政志十卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明朱廷立撰廷立通山人嘉靖癸未進士官至禮</span>  
<span style="margin-left: 2em">部右侍郞嘉靖八年廷立以河南道監察御史奉</span>  
<span style="margin-left: 2em">使淸理兩淮鹽政因博考古今鹽制以成此書凡</span>  
<span style="margin-left: 2em">分七門曰出産曰建立曰制度曰制詔曰疏議曰</span>  
<!-- 册2 葉2972b　Page:文淵閣四庫全書_0002冊.djvu/748 -->
<span style="margin-left: 2em">鹽官曰禁令每門各分子目凡三百九十有四葢</span>  
<span style="margin-left: 2em">制詔疏議每一篇列一目故其繁至是也</span>  
嘉靖淸源關志四卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明劉璽撰璽字雙泉濟州衞籍唐縣人嘉靖壬辰</span>  
<span style="margin-left: 2em">進士官至右副都御史廵撫宣府是編乃璽以戸</span>  
<span style="margin-left: 2em">部主事監理臨淸闗稅時所編卽是關之條例也</span>  
<span style="margin-left: 2em">序稱嘉靖九年以前案牘無徴故舊事皆不載是</span>  
<span style="margin-left: 2em">猶可以散佚委也其凡例云凡例制不合於今者</span>  
<span style="margin-left: 2em">亦棄不取則是徴課簿籍榜示商賈吏役者耳志</span>  
<!-- 册2 葉2973a　Page:文淵閣四庫全書_0002冊.djvu/748 -->
<span style="margin-left: 2em">乘以存舊典寧計其現行否𫆀璽自序稱訪於僚</span>  
<span style="margin-left: 2em">屬或曰孫松山監淸源有聲過通州會松山松山</span>  
<span style="margin-left: 2em">因出所集淸源關𣙜政錄示余遂因而補葺爲此</span>  
<span style="margin-left: 2em">書則其原本實爲簿籍宜其如是矣璽任滿未及</span>  
<span style="margin-left: 2em">刋繼其事者爲莆田雍潤乃授之梓書中凡署潤</span>  
<span style="margin-left: 2em">名者又所續增也</span>  
淮關志八卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">明馬麟撰麟巴縣人嘉靖戊戌進士官南京戸部</span>  
<span style="margin-left: 2em">員外郞是書凡分八門其建置不叙淮關之始末</span>  
<!-- 册2 葉2973b　Page:文淵閣四庫全書_0002冊.djvu/748 -->
<span style="margin-left: 2em">而泛引厯代征商典故綴爲一卷殊爲汗漫又地</span>  
<span style="margin-left: 2em">志列藝文一門原爲風土而設此志不過徴𣙜之</span>  
<span style="margin-left: 2em">條格一關之外皆非所屬而亦濫載藝文尤非體</span>  
<span style="margin-left: 2em">例矣</span>  
茶馬𩔖考六卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">明胡彥撰彥<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3179.svg?width=24" alt="四庫全書僻字第3179號（沔）" title="四庫全書僻字第3179號（沔）">陽人嘉靖辛丑進士官巡察茶馬</span>  
<span style="margin-left: 2em">御史因厯考典故及時事利弊作爲此書明制茶</span>  
<span style="margin-left: 2em">馬御史兼理寧夏鹽務故第三卷併記鹽政云</span>  
海運詳考一卷海運志二卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<!-- 册2 葉2976a　Page:文淵閣四庫全書_0002冊.djvu/749 -->
<span style="margin-left: 2em">明王宗沐撰宗沐字新甫臨海人嘉靖甲辰進士</span>  
<span style="margin-left: 2em">官至刑部左侍郎事迹其明史本傳是編乃隆慶</span>  
<span style="margin-left: 2em">六年二月宗沐任山東布政使時議開海運而作</span>  
<span style="margin-left: 2em">所載皆其議事呈文是年七月復鋟海運志於詳</span>  
<span style="margin-left: 2em">考之外增入海運圖並海運路程奏疏事宜考宗</span>  
<span style="margin-left: 2em">沐官右副都御史總督漕運時請復海運其疏載</span>  
<span style="margin-left: 2em">所著敬所文集中本傳亦載其畧然史載宗沐運</span>  
<span style="margin-left: 2em">米十二萬石自淮入海抵天津南京給事中張煥</span>  
<span style="margin-left: 2em">言比聞八舟漂没失米三千二百石宗沐預計有</span>  
<!-- 册2 葉2976b　Page:文淵閣四庫全書_0002冊.djvu/749 -->
