## 欽定四庫全書總目 卷二十三　經部二十三　禮類存目一

欽定四庫全書總目卷二十三  
<span style="margin-left: 1em">經部二十三</span>  
<span style="margin-left: 2em">禮類存目一</span>  
周禮補亡六卷<sub class="note-yuan">衍聖公孔昭焕家藏本</sub>  
<span style="margin-left: 2em">元邱葵撰葵字吉甫莆田人閩書作同安人未之</span>  
<span style="margin-left: 2em">詳也是書本俞庭椿王與之之說謂冬官一職散</span>  
<span style="margin-left: 2em">見五官又㕘以諸家之說訂定天官之屬六十地</span>  
<span style="margin-left: 2em">官之屬五十七春官之屬六十夏官之屬五十九</span>  
<span style="margin-left: 2em">秋官之屬五十九冬官之屬五十四又云先王不</span>  
<!-- 册1 葉1857b　Page:文淵閣四庫全書_0001冊.djvu/514 -->
<span style="margin-left: 2em">能以祿食養無用之官故周官雖曰三百六十而</span>  
<span style="margin-left: 2em">兼攝相半如掌葛徴絺綌及掌染徵染之類每官</span>  
<span style="margin-left: 2em">掌一事無是事未必有是官也其說皆自信不疑</span>  
<span style="margin-left: 2em">周禮一書不過闕冬官耳至南宋淳熙嘉熙之間</span>  
<span style="margin-left: 2em">俞王二家倡爲異說而五官俱亂葵又從而推波</span>  
<span style="margin-left: 2em">助瀾閩書稱宋末科舉廢葵杜門勵學居海嶼中</span>  
<span style="margin-left: 2em">因自號釣磯翁所著有易解義書解義詩口義春</span>  
<span style="margin-left: 2em">秋通義四書日講周禮補亡今諸書散佚惟此書</span>  
<span style="margin-left: 2em">爲世所詬病轉以見異而存據葵自序書葢成於</span>  
<!-- 册1 葉1860a　Page:文淵閣四庫全書_0001冊.djvu/515 -->
<span style="margin-left: 2em">泰定丙子葵年八十一矣虛殫一生之力使至今</span>  
<span style="margin-left: 2em">談周禮者稱俞庭椿爲變亂古經之魁而葵與王</span>  
<span style="margin-left: 2em">與之爲煽助異說之黨不亦傎歟其書世有二本</span>  
<span style="margin-left: 2em">其一分六卷題曰周禮注其一卽此本不分卷數</span>  
<span style="margin-left: 2em">而題曰周禮冬官補亡經義考又作周禮全書而</span>  
<span style="margin-left: 2em">注曰一作周禮補亡按此書别無他長惟補亡是</span>  
<span style="margin-left: 2em">其本志故今以補亡之名著錄焉</span>  
周禮集註七卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">明何喬新撰喬新字廷秀江西廣昌人景泰甲戍</span>  
<!-- 册1 葉1860b　Page:文淵閣四庫全書_0001冊.djvu/515 -->
<span style="margin-left: 2em">進士官至刑部尚書諡文肅事蹟具明史本傳是</span>  
<span style="margin-left: 2em">書謂冬官不亡大約沿俞庭椿王與之邱葵及晏</span>  
<span style="margin-left: 2em">璧僞託吳澄之說臆爲竄亂如引邱葵說謂太史</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">筆而書爲天官之屬無疑不知太史之文曰讀</span>  
<span style="margin-left: 2em">禮而協事又曰以事協禮事又曰執其禮事然則</span>  
<span style="margin-left: 2em">太史當入春官經有明文可據唐職官志以太史</span>  
<span style="margin-left: 2em">令屬禮曹是其遺意今并入天官旣不通經且不</span>  
<span style="margin-left: 2em">明史矣又如所引僞本吳澄考註謂諸子掌國子</span>  
<span style="margin-left: 2em">之倅使之修德學道當入教官之屬不知諸子之</span>  
<!-- 册1 葉1861a　Page:文淵閣四庫全書_0001冊.djvu/515 -->
<span style="margin-left: 2em">職曰若有兵甲之事則授之車甲合其卒伍置其</span>  
<span style="margin-left: 2em">有司以軍法治之葢主以戎事詔國子故隷司馬</span>  
<span style="margin-left: 2em">今徒以修德學道之語并入司徒則夏官都司馬</span>  
<span style="margin-left: 2em">之職曰掌其政學亦未嘗不及於敎將并移入司</span>  
<span style="margin-left: 2em">徒歟是皆妄取前人謬戾之論割裂倒置踵其失</span>  
<span style="margin-left: 2em">而加甚故前後義例率多不能自通徒爲談周禮</span>  
<span style="margin-left: 2em">者所詬病耳</span>  
周禮定本四卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明舒芬撰芬有周易箋已著錄兹編亦其所著梓</span>  
<!-- 册1 葉1861b　Page:文淵閣四庫全書_0001冊.djvu/515 -->
<span style="margin-left: 2em">溪内集之一大㫖祖俞庭椿冬官不亡雜岀於五</span>  
<span style="margin-left: 2em">官之說而㕘以僞本吳澄考注復以巳意進退之</span>  
<span style="margin-left: 2em">凡爲五官敘辨五篇六官圖說一篇周官剔僞一</span>  
<span style="margin-left: 2em">篇周禮正經六篇刪舊本考工記移天官太宰地</span>  
<span style="margin-left: 2em">官大司徒之文以入於冬官大司空移小司徒及</span>  
<span style="margin-left: 2em">遂人之文入小司空又移天官之掌舍幕人掌次</span>  
<span style="margin-left: 2em">地官之遂師遂大夫縣正鄙師酇長里宰鄰長土</span>  
<span style="margin-left: 2em">訓誦訓司稼草人稻人場人囿人載師問師縣師</span>  
<span style="margin-left: 2em">均人稍人旅師山虞林衡川衡澤虞迹人卝人角</span>  
<!-- 册1 葉1864a　Page:文淵閣四庫全書_0001冊.djvu/516 -->
<span style="margin-left: 2em">人羽人掌葛掌染掌炭掌茶掌蜃舂人廩人舍人</span>  
<span style="margin-left: 2em">倉人遺人委人槀人夏官之掌畜職方氏形方氏</span>  
<span style="margin-left: 2em">山師川師邍師司勲量人以屬冬官明史芬本傳</span>  
<span style="margin-left: 2em">稱芬精於周禮嘗謂周禮視儀禮禮記猶蜀之視</span>  
<span style="margin-left: 2em">吳魏疾革其子請所言惟以未及表章周禮爲恨</span>  
<span style="margin-left: 2em">於是經可云篤信乃從俞庭椿之謬說虛耗聰明</span>  
<span style="margin-left: 2em">徒貽嗤<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）">不亦深可惜歟</span>  
讀禮疑圖六卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明季本撰本有易學四同巳著錄是書辨論周禮</span>  
<!-- 册1 葉1864b　Page:文淵閣四庫全書_0001冊.djvu/516 -->
<span style="margin-left: 2em">賦役諸法祖何休林孝存之說以爲戰國策士之</span>  
<span style="margin-left: 2em">所述前三卷以其疑周禮者爲圖辨之後三卷依</span>  
<span style="margin-left: 2em">據孟子立斷因及後代徭役軍屯之法論其得失</span>  
<span style="margin-left: 2em">大㫖主於輕徭薄賦其意未始不善其說亦辨而</span>  
<span style="margin-left: 2em">可聽然古今時勢各殊制度亦異有不得盡以後</span>  
<span style="margin-left: 2em">世情形推論前代者至其牽合魯頌公車千乘公</span>  
<span style="margin-left: 2em">徒三萬則欲改小司徒四井爲邑四邑爲丘四甸</span>  
<span style="margin-left: 2em">爲縣四縣爲都之文謂四當作五又增四都爲同</span>  
<span style="margin-left: 2em">一語則更輾轉竄亂矣葢本傳姚江之學故高明</span>  
<!-- 册1 葉1865a　Page:文淵閣四庫全書_0001冊.djvu/516 -->
<span style="margin-left: 2em">之過末流至於如斯也</span>  
考工記述注二卷<sub class="note-yuan">福建巡撫採進本</sub>  
<span style="margin-left: 2em">明林兆珂撰兆珂有詩經多識編巳著錄此編因</span>  
<span style="margin-left: 2em">考工記一書文句古奥乃取漢唐注疏㕘訂訓詁</span>  
<span style="margin-left: 2em">以疏通其大意於記文皆傍加圈<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）">綴以評語葢</span>  
<span style="margin-left: 2em">仿謝枋得批檀弓標出章法句法字法之例使童</span>  
<span style="margin-left: 2em">𫎇誦習以當古文選本於名物制度絶無所發明</span>  
<span style="margin-left: 2em">末附考工記圖一卷亦林希逸之舊本無所增損</span>  
周禮訓雋二十卷<sub class="note-yuan">副都御史黃登賢家藏本</sub>  
<!-- 册1 葉1865b　Page:文淵閣四庫全書_0001冊.djvu/516 -->
<span style="margin-left: 2em">明陳深撰深字子淵長興人嘉靖乙酉舉人官至</span>  
<span style="margin-left: 2em">雷州府推官是書割裂五官沿俞庭椿之說於經</span>  
<span style="margin-left: 2em">義無所發明</span>  
周禮因論一卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">明唐樞撰樞有易修墨守巳著錄是書以民極爲</span>  
<span style="margin-left: 2em">周禮本原葢本葉時禮經會元之說謂詩蔽以一</span>  
<span style="margin-left: 2em">言思無邪周禮蔽以一言曰爲民極也其駁夏休</span>  
<span style="margin-left: 2em">并田譜之妄亦卓然有識然其文如語錄之體寥</span>  
<span style="margin-left: 2em">寥數條未爲詳備</span>  
<!-- 册1 葉1868a　Page:文淵閣四庫全書_0001冊.djvu/517 -->
周禮發明一卷<sub class="note-yuan">江西巡撫採進本</sub>  
<span style="margin-left: 2em">明沈瑤撰瑤字林珍德淸人嘉靖癸丑進士官至</span>  
<span style="margin-left: 2em">兵部郞中是編於六官之後各爲總論一篇皆無</span>  
<span style="margin-left: 2em">深意其雜取司徒之屬以補冬官葢用三禮考註</span>  
<span style="margin-left: 2em">之本所錄經文亦頗多刪節</span>  
周禮述註六卷<sub class="note-yuan">編修鄭際唐家藏本</sub>  
<span style="margin-left: 2em">明金瑤撰瑤有六爻原意巳著錄是書成於萬厯</span>  
<span style="margin-left: 2em">已卯前有瑤自序并所作凡例十條謂周禮之文</span>  
<span style="margin-left: 2em">爲漢儒所竄攺其中有僞官亂句悉爲考定别以</span>  
<!-- 册1 葉1868b　Page:文淵閣四庫全書_0001冊.djvu/517 -->
<span style="margin-left: 2em">陰文書之大㫖本元吳澄三禮考註明何喬新周</span>  
<span style="margin-left: 2em">禮集註之說而又以臆見更定之其補冬官之末</span>  
<span style="margin-left: 2em">附以改官議改文議二篇卽評論二氏之得失者</span>  
<span style="margin-left: 2em">也所定僞官亂句諸條若親得周公舊本一一互</span>  
<span style="margin-left: 2em">校而知者亦可謂果於自信矣</span>  
周禮說十四卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">明徐卽登撰卽登字獻和又字德竣號匡樂豐城</span>  
<span style="margin-left: 2em">人萬厯癸未進士官至河南按察使其書前十三</span>  
<span style="margin-left: 2em">卷解五官不載考工記末一卷爲冬官闕疑葢亦</span>  
<!-- 册1 葉1869a　Page:文淵閣四庫全書_0001冊.djvu/517 -->
<span style="margin-left: 2em">取俞庭椿之說但尚未敢改經耳</span>  
批<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）">考工記一卷<sub class="note-yuan">兵部侍郞紀昀家藏本</sub>  
<span style="margin-left: 2em">明郭正域撰正域字美命江夏人萬厯癸未進士</span>  
<span style="margin-left: 2em">官至禮部侍郞諡文毅事迹具明史本傳是編取</span>  
<span style="margin-left: 2em">考工記之文圈<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）">批評惟論其章法句法字法毎</span>  
<span style="margin-left: 2em">節後所附註釋亦頗淺略葢爲論文而作不爲詁</span>  
<span style="margin-left: 2em">經而作也</span>  
周禮完解十二卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">明郝敬撰敬有周易正解巳著錄此書亦謂冬官</span>  
<!-- 册1 葉1869b　Page:文淵閣四庫全書_0001冊.djvu/517 -->
<span style="margin-left: 2em">散見於五官而又變幻其詞謂陽分六官以成歲</span>  
<span style="margin-left: 2em">序陰省冬官以法五行穿鑿尤甚中間橫生枝節</span>  
<span style="margin-left: 2em">不一而足如典瑞職王晉大圭執鎭圭晉卽搢字</span>  
<span style="margin-left: 2em">鄭衆注本不誤賈疏云搢揷也謂揷大圭長三尺</span>  
<span style="margin-left: 2em">玉笏於帶間手執鎭圭尺二寸其義亦最明而敬</span>  
<span style="margin-left: 2em">謂接見曰晉晉進也行禮從容漸進如日之升以</span>  
<span style="margin-left: 2em">附會於經文朝日之語果終歲如是乎此亦務勝</span>  
<span style="margin-left: 2em">古人之過矣</span>  
周禮古本訂注六卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<!-- 册1 葉1872a　Page:文淵閣四庫全書_0001冊.djvu/518 -->
<span style="margin-left: 2em">明郭良翰撰良翰字道憲莆田人萬厯中以蔭官</span>  
<span style="margin-left: 2em">太僕寺寺丞是編自序謂俞庭椿王與之邱葵吳</span>  
<span style="margin-left: 2em">澄何喬新五家補本分割殊甚不知冬官可以不</span>  
<span style="margin-left: 2em">補五官必不可淆五官自存冬官自闕何必强臆</span>
