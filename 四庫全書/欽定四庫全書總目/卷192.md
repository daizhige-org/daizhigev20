## 欽定四庫全書總目 卷一百九十二　集部四十五　總集類存目二

欽定四庫全書總目卷一百九十二  
<span style="margin-left: 1em">集部四十五</span>  
<span style="margin-left: 2em">總集類存目二</span>  
浙元三會錄<sub class="note-yuan">無卷數　浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明楊守阯編守阯有碧川文選已著録是書乃以</span>  
<span style="margin-left: 2em">浙江解元同仕於朝者邀爲文會其六元文會始</span>  
<span style="margin-left: 2em">於成化六年范理商輅姚䕫楊守陳盧楷及守阯</span>  
<span style="margin-left: 2em">也至成化十五年復爲七元會則胡謐沈繼先楊</span>  
<span style="margin-left: 2em">文卿黃珣謝遷及守陳守阯也成化二十二年再</span>  
<!-- 册5 葉533b　Page:文淵閣四庫全書_0005冊.djvu/138 -->
<span style="margin-left: 2em">爲後七元會則李旻王華胡謐沈繼先謝遷及守</span>  
<span style="margin-left: 2em">陳守阯也守阯兄弟後先三會皆與焉故守阯錄</span>  
<span style="margin-left: 2em">贈答倡和詩文彚爲此編</span>  
二戴小簡二卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">不著編輯者名氏所載一曰贅言錄明戴豪撰一</span>  
<span style="margin-left: 2em">曰筠溪集戴顒撰豪字師文台州太平人成化戊</span>  
<span style="margin-left: 2em">戌進士官至廣東布政司叅政顒字師觀豪之弟</span>  
<span style="margin-left: 2em">正德辛未進士官至兵科給事中萬姓統譜載豪</span>  
<span style="margin-left: 2em">所著有贅言錄若干卷太平志載顒有倦歌集又</span>  
<!-- 册5 葉536a　Page:文淵閣四庫全書_0005冊.djvu/139 -->
<span style="margin-left: 2em">有筠溪雜稿此本以兩人書簡各一卷合爲一編</span>  
<span style="margin-left: 2em">葢摘錄於全集之中故仍以原集標目非其完本</span>  
<span style="margin-left: 2em">也</span>  
宸章集錄一卷<sub class="note-yuan">左都御史張若塗家藏本</sub>  
<span style="margin-left: 2em">明費宏編宏有文集已著錄此書乃嘉靖五年六</span>  
<span style="margin-left: 2em">月十三日世宗御平臺召宏及大學士楊一淸石</span>  
<span style="margin-left: 2em">珤賈詠入見各賜御製詩宏得七言古詩一章一</span>  
<span style="margin-left: 2em">淸珤詠各得五言古詩一章宏等疏謝並依原韻</span>  
<span style="margin-left: 2em">和進帝復賜以批答宏因集爲一帙梓而傳之明</span>  
<!-- 册5 葉536b　Page:文淵閣四庫全書_0005冊.djvu/139 -->
<span style="margin-left: 2em">史宏本傳稱帝常御平臺特賜御製七言詩一章</span>  
<span style="margin-left: 2em">命輯倡和詩集署其銜曰内閣掌㕘機務輔導首</span>  
<span style="margin-left: 2em">臣其見尊禮前此未有張璁桂萼滋害宏寵萼言</span>  
<span style="margin-left: 2em">詩文小技不足勞聖心且使宏得憑寵靈凌壓朝</span>  
<span style="margin-left: 2em">士帝置不省云云然則此書乃承世宗之命所編</span>  
<span style="margin-left: 2em">也</span>  
振鷺集一卷<sub class="note-yuan">衍聖公孔眧煥家藏本</sub>  
<span style="margin-left: 2em">明陳鎬編鎬有闕里志已著錄宏治十六年孔子</span>  
<span style="margin-left: 2em">六十二代孫襲封衍聖公孔聞韶入覲京師事畢</span>  
<!-- 册5 葉537a　Page:文淵閣四庫全書_0005冊.djvu/139 -->
<span style="margin-left: 2em">將還朝臣咸賦詩贈行館閣自大學士劉健以下</span>  
<span style="margin-left: 2em">三十五人爲一軸吳寛爲之序卿寺自馬文升以</span>  
<span style="margin-left: 2em">下三十六人爲一軸謝鐸爲之序聞韶爲李東陽</span>  
<span style="margin-left: 2em">壻故朝士出東陽之門者又別爲一軸凡二十一</span>  
<span style="margin-left: 2em">人靳貴爲之序鎬時爲山東提學副使乃合而梓</span>  
<span style="margin-left: 2em">之以聖系出自殷後故以振鷺爲名然衍聖公非</span>  
<span style="margin-left: 2em">三恪之列數典頗爲不切也</span>  
聯句私抄四卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明毛紀編紀有密勿稿已著錄是集前有引一篇</span>  
<!-- 册5 葉537b　Page:文淵閣四庫全書_0005冊.djvu/139 -->
<span style="margin-left: 2em">稱昔在翰林與僚友及諸司善鳴者會晤遊賞多</span>  
<span style="margin-left: 2em">形之聯句得二卷後爲部佐與同年數公相處因</span>  
<span style="margin-left: 2em">事感懷復得一卷其末卷則在内閣與諸老同作</span>  
<span style="margin-left: 2em">者總七言律二百二十五首排律二首五言古詩</span>  
<span style="margin-left: 2em">一首歸田後葺錄爲一帙並題姓名履貫於卷首</span>  
<span style="margin-left: 2em">自華亭顧淸以下共三十有二人</span>  
古黃遺蹟集一卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明盧濬編濬天台人成化丁未進士宏治中官黃</span>  
<span style="margin-left: 2em">州府知府是編輯黃州古蹟題詠大旨以詩賦爲</span>  
<!-- 册5 葉540a　Page:文淵閣四庫全書_0005冊.djvu/140 -->
<span style="margin-left: 2em">主而以唐許遠祠祭文三篇錯雜諸詩之内又宣</span>  
<span style="margin-left: 2em">聖遺像碑記亦附卷末頗無體例至王禹侢黃州</span>  
<span style="margin-left: 2em">竹樓記在耳目之前轉遺不採亦莫喻其故也</span>  
文翰𩔖選大成一百六十三卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">明李伯璵馮原同編伯璵上海人官淮王府長史</span>  
<span style="margin-left: 2em">原慈谿人官淮王府紀善是書卽奉淮王之命作</span>  
<span style="margin-left: 2em">也前有淮王序自稱西江頤仙按明史仁宗子淮</span>  
<span style="margin-left: 2em">靖王瞻墺以永樂二十二年封宣德四年就藩饒</span>  
<span style="margin-left: 2em">州瞻墺子康王祁銓以正統十一年嗣封此書作</span>  
<!-- 册5 葉540b　Page:文淵閣四庫全書_0005冊.djvu/140 -->
<span style="margin-left: 2em">於成化宏治間則所稱頤仙者卽祁銓也其書總</span>  
<span style="margin-left: 2em">錄前代及明人詩分體編次每體之中各以時代</span>  
<span style="margin-left: 2em">爲次採綴頗詳然愛博而無所持擇往往乖誤如</span>  
<span style="margin-left: 2em">以梁劉琨爲晉劉琨以班媫妤詩爲漢宫怨以阮</span>  
<span style="margin-left: 2em">籍咏懷爲咏歌以宋楊傑爲不知爵里皆疎舛之</span>  
<span style="margin-left: 2em">甚者至於李白詩中收入李赤詩又以吳隱之爲</span>  
<span style="margin-left: 2em">唐人與李義山同編尤爲顚舛</span>  
古括遺芳四卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">舊本題南山鄭宣撰不著時代亦無序跋考書中</span>  
<!-- 册5 葉541a　Page:文淵閣四庫全書_0005冊.djvu/140 -->
<span style="margin-left: 2em">所錄止於明天順中則明人也其書裒輯處州之</span>  
<span style="margin-left: 2em">文凡三十三家分序文奏疏䇿論辨說四門採摭</span>  
<span style="margin-left: 2em">甚畧似乎鈔撮志乘爲之未博考於諸集其考證</span>  
<span style="margin-left: 2em">亦多弇陋如著漢雋者本林鉞見書錄解題而以</span>  
<span style="margin-left: 2em">靑田志不載鉞有著述疑之至以鮑彪戰國䇿序</span>  
<span style="margin-left: 2em">誤疑爲劉向之文則更異矣</span>  
羣公小簡六卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">不著編輯者名氏前有成化乙未徐傳序稱蘇文</span>  
<span style="margin-left: 2em">忠方秋崖趙淸曠盧柳南孫仲益五先生之所著</span>  
<!-- 册5 葉541b　Page:文淵閣四庫全書_0005冊.djvu/140 -->
<span style="margin-left: 2em">而第六卷乃爲歐陽修作其第一卷題五先生手</span>  
<span style="margin-left: 2em">簡自第二卷以下又題曰六先生手簡後有成化</span>  
<span style="margin-left: 2em">二十年周信跋稱出醉翁帖一帙贈徐徐亦以此</span>  
<span style="margin-left: 2em">書報贈又稱捐俸命工仍舊本重刋則末一卷爲</span>  
<span style="margin-left: 2em">信所增入其改題六先生亦信所爲也葢明代朝</span>  
<span style="margin-left: 2em">覲述職之官例以一書一帕贈京中親故其書皆</span>  
<span style="margin-left: 2em">潦草刋板茍應故事謂之書帕本卽此之𩔖其標</span>  
<span style="margin-left: 2em">題顚舛固不足深詰矣</span>  
太白樓集十卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<!-- 册5 葉544a　Page:文淵閣四庫全書_0005冊.djvu/141 -->
<span style="margin-left: 2em">明蔡鍊編鍊字懋成餘姚人宏治庚戌進士官工</span>  
<span style="margin-left: 2em">部主事此編乃其管理山東河道時以濟寧州城</span>  
<span style="margin-left: 2em">東南有太白樓爲李白遺蹟因錄諸題詠碑刻之</span>  
<span style="margin-left: 2em">文合爲一集而二賢祠碑亦附入焉二賢祠者州</span>  
<span style="margin-left: 2em">人所建以祀白及賀知章者也</span>  
東甌詩集七卷補遺一卷續集八卷<sub class="note-yuan">江蘇周厚堉家藏本</sub>  
<span style="margin-left: 2em">明趙諫編諫字士忠温州人初成化中樂淸蔡璞</span>  
<span style="margin-left: 2em">嘗輯温州一郡之詩自王十朋以下爲七卷又補</span>  
<span style="margin-left: 2em">遺一卷諫以其去取爲未善乃因蔡本而增損之</span>  
<!-- 册5 葉544b　Page:文淵閣四庫全書_0005冊.djvu/141 -->
<span style="margin-left: 2em">温州知府趙淮序而刋之又爲續集八卷或補人</span>  
<span style="margin-left: 2em">或補詩以拾蔡本之遺諫自序之並刻於宏治庚</span>  
<span style="margin-left: 2em">戌其體例頗雜不出地志之積習如張子容本襄</span>  
<span style="margin-left: 2em">陽人爲樂成尉故其詩多永嘉所作子容及孟浩</span>  
<span style="margin-left: 2em">然集中諸詩班班可考續集乃以爲永嘉人然則</span>  
<span style="margin-left: 2em">謝靈運集不當全入此選歟</span>  
金華正學編十二卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明趙鶴編唐邦佐重輯鶴字叔鳴江都人宏治丙</span>  
<span style="margin-left: 2em">辰進士官至山東提學副使邦佐字維良蘭谿人</span>  
<!-- 册5 葉545a　Page:文淵閣四庫全書_0005冊.djvu/141 -->
<span style="margin-left: 2em">隆慶戊辰進士官至光州知州初嘉靖間鶴官金</span>  
<span style="margin-left: 2em">華知府以宋吕祖謙何基王柏元金履祥許謙皆</span>  
<span style="margin-left: 2em">金華名儒因錄五家之文涉於講學者數篇及其</span>  
<span style="margin-left: 2em">本傳行狀墓誌等各爲二卷萬厯庚寅邦佐復取</span>  
<span style="margin-left: 2em">鶴原書爲之刪訂而益以明章懋以祖謙朱子之</span>  
<span style="margin-left: 2em">友基等皆傳朱子之派故命曰正學</span>  
金華文統十三卷<sub class="note-yuan">副都御史黃登賢家藏本</sub>  
<span style="margin-left: 2em">明趙鶴編是書於正學編外兼錄金華耆舊之文</span>  
<span style="margin-left: 2em">宋宗澤梅執禮潘良貴鄭剛中賈廷佐范浚陳亮</span>  
<!-- 册5 葉545b　Page:文淵閣四庫全書_0005冊.djvu/141 -->
<span style="margin-left: 2em">吕祖儉徐僑何恪時少章喬行簡等十二人元柳</span>  
<span style="margin-left: 2em">貫張樞吳師道黃溍吳萊等六人明宋濂王褘蘇</span>  
<span style="margin-left: 2em">伯衡胡翰戴良吳沉王紳章懋等八人而宋濂所</span>  
<span style="margin-left: 2em">錄獨多葢視諸人較吕祖謙等爲稍亞故所錄亦</span>  
<span style="margin-left: 2em">稍寛然前列吕祖謙修文鑑法朱子取文字法及</span>  
<span style="margin-left: 2em">王柏吳師道論文之語則大旨仍以講學爲宗故</span>  
<span style="margin-left: 2em">劉孝綽駱賓王舒元輿之文皆所不取然唐仲友</span>  
<span style="margin-left: 2em">亦不登一字則門戸之見殊未能化矣</span>  
來蘇吳氏原泉詩集八卷<sub class="note-yuan">内府藏本</sub>  
<!-- 册5 葉548a　Page:文淵閣四庫全書_0005冊.djvu/142 -->
<span style="margin-left: 2em">明吳宗周編宗周字子旦號石岡宣城人宏治丙</span>  
<span style="margin-left: 2em">辰進士官至臨江府知府是編輯其先世以來之</span>  
<span style="margin-left: 2em">詩始宋迄明據宗周自序稱以先人之作爲内集</span>  
<span style="margin-left: 2em">外人所贈爲外集附以拙作此本自五卷至七卷</span>  
<span style="margin-left: 2em">皆宗周詩宗周詩後益以按察司副使大本貢士</span>  
<span style="margin-left: 2em">棻府庠士木又有宗周拾遺而無所謂外集者葢</span>  
<span style="margin-left: 2em">其後人所損益已非復宗周之舊矣</span>  
唐文鑑二十一卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">明賀泰編泰字志同吳縣人宏治已未進士官至</span>  
<!-- 册5 葉548b　Page:文淵閣四庫全書_0005冊.djvu/142 -->
<span style="margin-left: 2em">監察御史巡按福建是編雜採唐文所見殊爲隘</span>
