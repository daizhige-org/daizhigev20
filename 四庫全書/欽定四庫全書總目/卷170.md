## 欽定四庫全書總目 卷一百七十　集部二十三　別集類二十三

<!-- 册4 葉1952：整葉圖版，無文字記錄 -->
<!-- 册4 葉1953a　Page:文淵閣四庫全書_0004冊.djvu/493 -->
欽定四庫全書總目卷一百七十  
<span style="margin-left: 1em">集部二十三</span>  
<span style="margin-left: 2em">别集類二十三</span>  
全室外集九卷續集一卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">明僧宗泐撰宗泐字季潭臨安人洪武初舉高行</span>  
<span style="margin-left: 2em">沙門命住天界寺尋往西域求遺經還授左善世</span>  
<span style="margin-left: 2em">太祖欲授以官固辭太祖爲撰免官說其後胡惟</span>  
<span style="margin-left: 2em">庸謀逆詞連宗泐特原之是編題曰外集蓋釋氏</span>  
<span style="margin-left: 2em">以佛經爲内學故以詩文爲外猶宋釋道璨柳塘</span>  
<!-- 册4 葉1953b　Page:文淵閣四庫全書_0004冊.djvu/493 -->
<span style="margin-left: 2em">外集例也首二卷爲應制詩及樂府供佛讚佛諸</span>  
<span style="margin-left: 2em">曲三卷至八卷爲古近體詩九卷爲疏及題䟦續</span>  
<span style="margin-left: 2em">集詩文合編而詩文之間闕四頁其原數遂不可</span>  
<span style="margin-left: 2em">考今所存者凡詩三十六首題䟦十五篇千頃堂</span>  
<span style="margin-left: 2em">書目作全室外集十卷蓋合此一卷言之耳宗泐</span>  
<span style="margin-left: 2em">雖託跡緇流而篤好儒術故其詩風骨高騫可抗</span>  
<span style="margin-left: 2em">行於作者之間徐一䕫作是集序稱其如霜晨老</span>  
<span style="margin-left: 2em">鶴聲聞九臯淸廟朱<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3500.svg?width=24" alt="四庫全書僻字第3500號（「絃」字少最後一點）" title="四庫全書僻字第3500號（「絃」字少最後一點）">曲終三嘆彷彿近之皎然</span>  
<span style="margin-left: 2em">齊巳固未易言要不在契嵩惠洪下與句曲外史</span>  
<!-- 册4 葉1956a　Page:文淵閣四庫全書_0004冊.djvu/494 -->
<span style="margin-left: 2em">張羽均元明之際方外之秀出者也千頃堂書目</span>  
<span style="margin-left: 2em">載宗泐尙有西游集一卷蓋奉使求經時道路往</span>  
<span style="margin-left: 2em">還所作見聞旣異其記載必有可觀今未見其本</span>  
<span style="margin-left: 2em">存佚殆不可知矣徐禎卿翦勝野聞謂宗泐奉使</span>  
<span style="margin-left: 2em">西域未至其地塗遇神僧幻化而歸者蓋未知宗</span>  
<span style="margin-left: 2em">泐有此集故造是齊東之語與所謂宗泐蓄髮還</span>  
<span style="margin-left: 2em">俗者同一謬妄也</span>  
練中丞集二卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">明練子寧撰子寧名安以字行號松月居士新淦</span>  
<!-- 册4 葉1956b　Page:文淵閣四庫全書_0004冊.djvu/494 -->
<span style="margin-left: 2em">人洪武乙丑進士建文時官左副都御史燕兵入</span>  
<span style="margin-left: 2em">殉節死事迹具明史本傳當燕王簒立之初誣建</span>  
<span style="margin-left: 2em">文諸臣爲姦黨禁其文字甚嚴宏治中王佐始輯</span>  
<span style="margin-left: 2em">其遺文名曰金川玉屑故徐泰詩說有金川練子</span>  
<span style="margin-left: 2em">寧玉屑無多爲世所寶之語此本乃泰和郭子章</span>  
<span style="margin-left: 2em">重編附以遺事一卷其裔孫綺復増輯之黃溥簡</span>  
<span style="margin-left: 2em">籍遺聞嘗記集中可疑者三事一曰送花狀元歸</span>  
<span style="margin-left: 2em">娶詩謂洪武辛亥至建文庚辰狀元但有吳伯宗</span>  
<span style="margin-left: 2em">丁顯任亨泰許觀張信陳䢿胡靖七人無所謂狀</span>  
<!-- 册4 葉1957a　Page:文淵閣四庫全書_0004冊.djvu/494 -->
<span style="margin-left: 2em">元花綸綸乃洪武十七年浙江鄉試第二人不應</span>  
<span style="margin-left: 2em">有奉詔歸娶事一曰故耆老理庭黃公墓誌謂子</span>  
<span style="margin-left: 2em">寧及第在洪武十八年此誌後題洪武丙辰三月</span>  
<span style="margin-left: 2em">之吉乃洪武九年不應結銜稱賜進士及第授翰</span>  
<span style="margin-left: 2em">林院修撰一曰集後雜考引葉盛水東日記載長</span>  
<span style="margin-left: 2em">樂鄭氏有手卷練子寧賦張顯宗䟦稱顯宗狀元</span>  
<span style="margin-left: 2em">及第洪武時亦無此狀元其言頗核蓋子寧一代</span>  
<span style="margin-left: 2em">偉人人爭依託因而影撰者有之然終不以僞廢</span>  
<span style="margin-left: 2em">其眞也</span>  
<!-- 册4 葉1957b　Page:文淵閣四庫全書_0004冊.djvu/494 -->
遜志齋集二十四卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明方孝孺撰孝孺有雜誡巳著錄是集凡雜著八</span>  
<span style="margin-left: 2em">卷書三卷序三卷記三卷題䟦一卷贊一卷祭文</span>  
<span style="margin-left: 2em">誄哀辭一卷行狀傳一卷碑表誌一卷古體詩一</span>  
<span style="margin-left: 2em">卷近體詩一卷史稱孝孺殉節後文禁甚嚴其門</span>  
<span style="margin-left: 2em">人王稔藏其遺稿宣德後始稍傳播故其中闕文</span>  
<span style="margin-left: 2em">脫簡頗多原本凡三十卷拾遺十卷乃黃孔昭謝</span>  
<span style="margin-left: 2em">鐸所編此本併爲二十四卷則正德中顧璘守台</span>  
<span style="margin-left: 2em">州時所重刋也孝孺學術醇正而文章乃縱橫豪</span>  
<!-- 册4 葉1960a　Page:文淵閣四庫全書_0004冊.djvu/495 -->
<span style="margin-left: 2em">放頗出入於東坡龍川之間蓋其志在於駕軼漢</span>  
<span style="margin-left: 2em">唐銳復三代故其毅然自命之氣發揚蹈厲時露</span>  
<span style="margin-left: 2em">於筆墨之間鄭瑗井觀瑣言稱其志高氣銳而詞</span>  
<span style="margin-left: 2em">鋒浩然足以發之然聖人之道與時偕行周去唐</span>  
<span style="margin-left: 2em">虞僅千年周禮一書巳不全用唐虞之法明去周</span>  
<span style="margin-left: 2em">幾三千年勢移事變不知凡幾而乃與惠帝講求</span>  
<span style="margin-left: 2em">六官改制定禮卽使燕兵不起其所設施亦未必</span>  
<span style="margin-left: 2em">能致太平正不必執講學家門戸之見曲爲之諱</span>  
<span style="margin-left: 2em">惟是燕王簒立之初齊黃諸人爲所切齒卽委蛇</span>  
<!-- 册4 葉1960b　Page:文淵閣四庫全書_0004冊.djvu/495 -->
<span style="margin-left: 2em">求活亦勢不能存若孝孺則深欲藉其聲名俾草</span>  
<span style="margin-left: 2em">詔以欺天下使稍稍遷就未必不接跡三楊而致</span>  
<span style="margin-left: 2em">命成仁遂湛十族而不悔語其氣節可謂贯金石</span>  
<span style="margin-left: 2em">動天地矣文以人重則斯集固懸諸日月不可磨</span>  
<span style="margin-left: 2em">滅之書也都穆南濠詩話曰方正學先生集傳之</span>  
<span style="margin-left: 2em">天下人人知愛誦之但其中多雜以他人之詩如</span>  
<span style="margin-left: 2em">勉學二十四首乃陳子平作漁樵一首乃楊孟載</span>  
<span style="margin-left: 2em">作又有牧牛圖一絶亦元人作然兩集互見古人</span>  
<span style="margin-left: 2em">多有今姑仍原本錄之而附存穆說備考焉</span>  
<!-- 册4 葉1961a　Page:文淵閣四庫全書_0004冊.djvu/495 -->
貞白遺稿十卷附顯忠錄二卷<sub class="note-yuan">浙江孫仰曾家藏本</sub>  
<span style="margin-left: 2em">明程通撰通字彦亨貞白其齋名也績溪人洪武</span>  
<span style="margin-left: 2em">乙丑貢入太學庚午舉應天鄉試時方遣諸王將</span>  
<span style="margin-left: 2em">兵因以封建䇿貢士於廷通所對稱旨擢第一授</span>  
<span style="margin-left: 2em">遼府紀善進左長史燕王叛後通上書數千言論</span>  
<span style="margin-left: 2em">戰守大計永樂初錦衣衞都督紀綱發其事詔械</span>  
<span style="margin-left: 2em">通詣京師與二子俱論死事迹具明史本傳所著</span>  
<span style="margin-left: 2em">述凡百餘卷悉毁於官後十年其弟赴荆州遼王</span>  
<span style="margin-left: 2em">以所圖通像及遺稿授之嘉靖中黨禁漸弛其從</span>  
<!-- 册4 葉1961b　Page:文淵閣四庫全書_0004冊.djvu/495 -->
<span style="margin-left: 2em">孫長等乃搜訪佚篇裒爲六卷附以遼王並同時</span>  
<span style="margin-left: 2em">諸人贈言及行狀小傳等篇别爲四卷天啟中其</span>  
<span style="margin-left: 2em">裔孫樞及子應階又集前後建祠請諡之文爲顯</span>  
<span style="margin-left: 2em">忠錄二卷附綴於末卽此本也初通以祖平久戍</span>  
<span style="margin-left: 2em">陳情乞賜還鄉人稱其孝及建文中遭逢國難上</span>  
<span style="margin-left: 2em">防禦封事而卒以是死人稱其忠今陳情之表具</span>  
<span style="margin-left: 2em">在而封事獨有題無文蓋嘉靖中刻集時猶有所</span>  
<span style="margin-left: 2em">諱而不敢存也封建二䇿乃其受知於太祖者持</span>  
<span style="margin-left: 2em">議頗正其他詩文亦俱醇樸有法雖所存無多而</span>  
<!-- 册4 葉1964a　Page:文淵閣四庫全書_0004冊.djvu/496 -->
<span style="margin-left: 2em">大節凛然有不僅以詞章論者固宜與方練諸集</span>  
<span style="margin-left: 2em">並傳不朽矣</span>  
靜學文集一卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">明王叔英撰叔英名原采以字行黃巖人洪武中</span>  
<span style="margin-left: 2em">與楊大中葉見泰方孝孺林佑並徵至叔英固辭</span>  
<span style="margin-left: 2em">還鄉後以薦官仙居訓導改德安教授遷漢陽知</span>  
<span style="margin-left: 2em">縣建文時召爲翰林修撰燕兵至淮奉詔募兵行</span>  
<span style="margin-left: 2em">至廣德會齊泰來奔知事不可爲乃書絶命詞自</span>  
<span style="margin-left: 2em">經於元妙觀邏捕其家妻金氏及二女并殉焉事</span>  
<!-- 册4 葉1964b　Page:文淵閣四庫全書_0004冊.djvu/496 -->
<span style="margin-left: 2em">迹具明史本傳乾隆四十一年</span>  
賜諡忠節史稱叔英在建文朝嘗上資治八䇿又稱方  
<span style="margin-left: 2em">孝孺欲行井田叔英貽之書曰事有行於古亦可</span>  
<span style="margin-left: 2em">行於今者夏時周冕之類是也有行於古而不可</span>  
<span style="margin-left: 2em">行於今者井田封建之類是也可行者行則人之</span>  
<span style="margin-left: 2em">從之也易而民受其利難行者行則人之從之也</span>  
<span style="margin-left: 2em">難而民受其患云云今是集三十篇僅存序記二</span>  
<span style="margin-left: 2em">體而所上八䇿及貽孝孺書並無之按徐敬孚䟦</span>  
<span style="margin-left: 2em">稱楊士奇嘗欲纂集叔英之文求無完本深悼惜</span>  
<!-- 册4 葉1965a　Page:文淵閣四庫全書_0004冊.djvu/496 -->
<span style="margin-left: 2em">之成化年有謝世修者欲募刻以廣其傳蓋搜葺</span>  
<span style="margin-left: 2em">重編非其舊本卷首林佑序作於洪武中者乃後</span>  
<span style="margin-left: 2em">人所錄入非卽爲此本作也叔英嘗自云趙孟之</span>  
<span style="margin-left: 2em">貴非所慕陶朱之富非所願使吾文如聖賢是吾</span>  
<span style="margin-left: 2em">心也今觀是集大扺皆規橅昌黎稍失之拘而簡</span>  
<span style="margin-left: 2em">樸有度非漫無裁制者比所存雖少巳可以見其</span>  
<span style="margin-left: 2em">生平矣前有黃綰所爲傳稱其文章有原本知時</span>  
<span style="margin-left: 2em">達勢爲用世之儒蓋不誣云</span>  
芻蕘集六卷<sub class="note-yuan">江西巡撫採進本</sub>  
<!-- 册4 葉1965b　Page:文淵閣四庫全書_0004冊.djvu/496 -->
<span style="margin-left: 2em">明周是修撰是修有綱常懿範已著錄是集爲其</span>  
<span style="margin-left: 2em">孫應鼇所編凡詩三卷賦及雜文共三卷大抵風</span>  
<span style="margin-left: 2em">骨稜稜溢於楮墨望而知爲忠臣義士之文其矩</span>  
<span style="margin-left: 2em">度波瀾亦具合古法不在當時作者下世不甚稱</span>  
<span style="margin-left: 2em">殆轉以氣節掩歟史稱是修由霍邱訓導遷周王</span>  
<span style="margin-left: 2em">府紀善王多不法是修動繩以禮今觀集中修巳</span>  
<span style="margin-left: 2em">十箴與保國<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">言二篇蓋卽是時之所作其剛正</span>  
<span style="margin-left: 2em">不阿不待後來始見矣末附解縉所作誌銘及楊</span>  
<span style="margin-left: 2em">士奇所作傳誌銘但稱歸京師爲紀善預翰林纂</span>  
<!-- 册4 葉1968a　Page:文淵閣四庫全書_0004冊.djvu/497 -->
<span style="margin-left: 2em">修以死竟不言其殉節傳乃言其自經應天府學</span>  
<span style="margin-left: 2em">蓋縉作誌在永樂元年時黨禁方嚴故諱其事士</span>  
<span style="margin-left: 2em">奇作傳則在宣德四年時公論稍明故著其實也</span>  
<span style="margin-left: 2em">傳又稱是修數論國家大計至指斥用事者誤國</span>  
<span style="margin-left: 2em">用事者怒衆共挫折之云云於當時情事亦得其</span>  
<span style="margin-left: 2em">眞雖是修精贯三光不待二人之文而顯二人之</span>  
<span style="margin-left: 2em">文尤不足以榮是修然有誓死不死者而後見眞</span>  
<span style="margin-left: 2em">能死者之難有委曲以文其不死者而後見慷槪</span>
