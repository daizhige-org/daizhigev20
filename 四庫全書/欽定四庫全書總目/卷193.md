## 欽定四庫全書總目 卷一百九十三　集部四十六　總集類存目三

欽定四庫全書總目卷一百九十三  
<span style="margin-left: 1em">集部四十六</span>  
<span style="margin-left: 2em">總集類存目三</span>  
今文選十二卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明孫鑛編鑛有孫月峯評經已著錄是編裒錄明</span>  
<span style="margin-left: 2em">人之文所選自羅玘至李維楨凡三十一人並撮</span>  
<span style="margin-left: 2em">其姓氏爵里於卷前其前七卷稱今文選後五卷</span>  
<span style="margin-left: 2em">稱續選觀其自序葢以李夢陽爲宗故明初諸人</span>  
<span style="margin-left: 2em">皆不之及焉</span>  
<!-- 册5 葉641b　Page:文淵閣四庫全書_0005冊.djvu/165 -->
三忠集十四卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">明郭惟賢編惟賢晉江人萬厯甲戌進士官至左</span>  
<span style="margin-left: 2em">副都御史以憂歸起戸部右侍郞未上而卒事蹟</span>  
<span style="margin-left: 2em">具明史本傳是集乃惟賢官湖廣巡撫時所編前</span>  
<span style="margin-left: 2em">有萬厯甲午自序謂屈原秭歸人孔明南陽人岳</span>  
<span style="margin-left: 2em">忠武雖起家湯陰而封鄂王苗裔迄今猶在武黃</span>  
<span style="margin-left: 2em">間均以楚稱故合爲一編於離騷取朱子註編爲</span>  
<span style="margin-left: 2em">七卷於武侯集兼取將苑心書及雜文編爲三卷</span>  
<span style="margin-left: 2em">於忠武集則取金陀粹編中家集十卷汰其大半</span>  
<!-- 册5 葉644a　Page:文淵閣四庫全書_0005冊.djvu/166 -->
<span style="margin-left: 2em">編爲四卷其大篇關一時興亡得䘮者多不見採</span>  
<span style="margin-left: 2em">於三賢事狀文章俱無可證覈惟賢一代名臣此</span>  
<span style="margin-left: 2em">編則未爲精善葢一時書帕本也</span>  
文府滑稽十二卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明鄒迪光編迪光有鬱儀樓集已著錄是書選周</span>  
<span style="margin-left: 2em">秦迄於唐宋寓言俳諧之文故以滑稽爲名而正</span>  
<span style="margin-left: 2em">言莊論時亦採入爲例已自不純或錄全編或摘</span>  
<span style="margin-left: 2em">數語亦漫無體例又雖分文部說部二目而配隷</span>  
<span style="margin-left: 2em">實無定軌如莊子齊物論以齧缺問於王倪一段</span>  
<!-- 册5 葉644b　Page:文淵閣四庫全書_0005冊.djvu/166 -->
<span style="margin-left: 2em">入文部罔兩問景一段入說部瞿鵲子一段復入</span>  
<span style="margin-left: 2em">文部人間世匠石之齊一段入文部南伯子葵一</span>  
<span style="margin-left: 2em">段入說部大宗師子祀子輿一段入文部意而子</span>  
<span style="margin-left: 2em">見許由一段入說部其餘忽謂之文忽謂之說似</span>  
<span style="margin-left: 2em">此類者不可枚舉其編次無緒可知矣</span>  
釣臺集六卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明陳文焕編文焕字静菴臨川人官嚴州府知府</span>  
<span style="margin-left: 2em">是集成於萬厯丙子因釣臺集舊本續以後來詩</span>  
<span style="margin-left: 2em">文别無發凢起例之處</span>  
<!-- 册5 葉645a　Page:文淵閣四庫全書_0005冊.djvu/166 -->
詩宿二十八卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明劉一相編一相字惟衡長山人萬厯丁丑進士</span>  
<span style="margin-left: 2em">官至陜西布政使是編採周秦漢魏六朝三唐之</span>  
<span style="margin-left: 2em">詩區别差次爲部二十八子目一百五十有四陳</span>  
<span style="margin-left: 2em">隋以上詩體不甚異者都稱古詩惟以時代爲序</span>  
<span style="margin-left: 2em">唐則類以題分人以詩分詩以體分亦張之象唐</span>  
<span style="margin-left: 2em">詩類苑之流亞也</span>  
翰墨選註十二卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">舊本題明屠隆撰隆有篇海類編已著錄是書皆</span>  
<!-- 册5 葉645b　Page:文淵閣四庫全書_0005冊.djvu/166 -->
<span style="margin-left: 2em">厯代尺牘謬妄不可殫述如前載漢晁錯與友人</span>  
<span style="margin-left: 2em">索詩編尺牘一篇曰日外入芳圃知騎氣南遊抱</span>  
<span style="margin-left: 2em">恨而返所謂南山千萬峯盡是相思情也吟編久</span>  
<span style="margin-left: 2em">客左右偶欲檢點敢請頒下霜月更白尚容凟寒</span>  
<span style="margin-left: 2em">往見話前人工拙云云則其他可知矣隆雖縱誕</span>  
<span style="margin-left: 2em">之士不以學問名然其陋不應至是必書肆僞托</span>  
<span style="margin-left: 2em">也</span>  
鉅文十二卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">舊本題明屠隆撰是集雜選經傳及古文詞分宏</span>  
<!-- 册5 葉648a　Page:文淵閣四庫全書_0005冊.djvu/167 -->
<span style="margin-left: 2em">放悲壯竒古閒適莊嚴綺麗六門僅八十篇以考</span>  
<span style="margin-left: 2em">工記檀弓諸聖賢經典之文與稗官小說如柳毅</span>  
<span style="margin-left: 2em">傳飛燕外傳等雜然並選殊爲謬誕疑亦坊賈托</span>  
<span style="margin-left: 2em">名也</span>  
四六叢珠彚選十卷<sub class="note-yuan">副都御史黃登賢家藏本</sub>  
<span style="margin-left: 2em">明王明嶅編明嶅字懋良晉江人萬厯已卯舉人</span>  
<span style="margin-left: 2em">官至寧波府通判宋葉適所編四六叢珠凡四十</span>  
<span style="margin-left: 2em">卷見於千頃堂書目明時抄本尚存明嶅病其繁</span>  
<span style="margin-left: 2em">冗因別爲選錄刋行所分大目十一子目數百皆</span>  
<!-- 册5 葉648b　Page:文淵閣四庫全書_0005冊.djvu/167 -->
<span style="margin-left: 2em">仍葉氏之舊然適原書所採多錄全文今散見永</span>  
<span style="margin-left: 2em">樂大典中者尚可考見其體例明嶅乃隨意刋削</span>  
<span style="margin-left: 2em">僅存摘句又不列標題不署撰人名氏一仿坊刻</span>  
<span style="margin-left: 2em">表聯活套之式割裂破碎遂致盡失其本來亦可</span>  
<span style="margin-left: 2em">謂不善變矣</span>  
詩所五十六卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">明臧懋循編懋循有負苞堂集已著錄初臨胊馮</span>  
<span style="margin-left: 2em">惟訥輯上古至三代諸詩爲風雅廣逸後又益以</span>  
<span style="margin-left: 2em">漢魏迄於陳隋諸詩總名曰古詩紀懋循是編實</span>  
<!-- 册5 葉649a　Page:文淵閣四庫全書_0005冊.djvu/167 -->
<span style="margin-left: 2em">據惟訥之書爲稿本惟訥書以詩𨽻人以人𨽻代</span>  
<span style="margin-left: 2em">源流本末開卷燦然懋循無所見長遂取其書而</span>  
<span style="margin-left: 2em">割裂之分二十有三門曰郊祀歌辭曰廟祀歌辭</span>  
<span style="margin-left: 2em">曰燕射歌辭曰鼓吹曲辭曰橫吹曲辭曰相和歌</span>  
<span style="margin-left: 2em">辭曰淸商曲辭曰舞曲歌辭曰琴曲歌辭曰古歌</span>  
<span style="margin-left: 2em">辭曰雜曲歌辭曰雜歌謡辭曰古語古諺曰古雜</span>  
<span style="margin-left: 2em">詩曰四言古詩曰五言古詩曰六言古詩曰七言</span>  
<span style="margin-left: 2em">古詩曰雜言古詩曰騷體古詩曰闕文曰璇璣圖</span>  
<span style="margin-left: 2em">詩曰雜歌詩曰補遺顚倒瞀亂茫無體例且古詩</span>  
<!-- 册5 葉649b　Page:文淵閣四庫全書_0005冊.djvu/167 -->
<span style="margin-left: 2em">之名本對近體而起故沈宋變律以後編唐宋詩</span>  
<span style="margin-left: 2em">者二體迥分若陳隋以前無非古體乃亦稱曰幾</span>  
<span style="margin-left: 2em">言古詩於格調已爲檮味中如傅元有女篇本樂</span>  
<span style="margin-left: 2em">府而入之古詩傅毅冉冉孤生竹一首本古詩而</span>  
<span style="margin-left: 2em">入之歌曲者不可僕數又詩紀蒐采雖博亦頗傷</span>  
<span style="margin-left: 2em">泛濫故後來常熟馮舒有匡謬一書頗中其病懋</span>  
<span style="margin-left: 2em">循不能有所考訂而掇拾餖飣以博相誇又不分</span>  
<span style="margin-left: 2em">眞僞稗販雜書以增之甚至庾信諸賦以句雜七</span>  
<span style="margin-left: 2em">言亦復收入尤爲冗雜矣</span>  
<!-- 册5 葉652a　Page:文淵閣四庫全書_0005冊.djvu/168 -->
唐詩所四十七卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">明臧懋循編凡十有四門曰古樂府曰樂府系曰</span>  
<span style="margin-left: 2em">三言四言古詩曰五言古詩曰七言古詩曰雜體</span>  
<span style="margin-left: 2em">古詩曰風體騷體古詩曰五言律詩曰七言律詩</span>  
<span style="margin-left: 2em">曰五言排律曰七言排律曰五言絶句曰七言絶</span>  
<span style="margin-left: 2em">句曰闕文每門之内又各以題目類從餖飣割裂</span>  
<span style="margin-left: 2em">亦張之象唐詩類苑之流也每卷之首皆註前集</span>  
<span style="margin-left: 2em">二字則當有後集今未之見然大槩可睹矣</span>  
詞致錄十六卷<sub class="note-yuan">兩江總督採進本</sub>  
<!-- 册5 葉652b　Page:文淵閣四庫全書_0005冊.djvu/168 -->
<span style="margin-left: 2em">明李天麟編天麟大興人萬厯庚辰進士官至監</span>  
<span style="margin-left: 2em">察御史巡按浙江是集皆載詞命之文分制詞進</span>  
<span style="margin-left: 2em">奏啟劄祈告雜著五門中又各分子目所採上自</span>  
<span style="margin-left: 2em">漢晉下迄於宋頗勝明末之猥濫然意主於剽剟</span>  
<span style="margin-left: 2em">詞藻仍餖飣之學耳</span>  
廣廣文選二十三卷<sub class="note-yuan">副都御史黃登賢家藏本</sub>  
<span style="margin-left: 2em">明周應治編應治有霞外麈談巳著錄嘉靖中劉</span>  
<span style="margin-left: 2em">節嘗編廣文選此又拾節之遺故曰廣廣文選猶</span>  
<span style="margin-left: 2em">之反離騷後有反反離騷非國語後有非非國語</span>  
<!-- 册5 葉653a　Page:文淵閣四庫全書_0005冊.djvu/168 -->
<span style="margin-left: 2em">也其舛漏蹖駁與節書亦魯衛之政甚至松柏歌</span>  
<span style="margin-left: 2em">題曰齊王建是併共建住者客耶一句亦未觀也</span>  
<span style="margin-left: 2em">越絶書序題周吳平如據論衡及書末題詞則平</span>  
<span style="margin-left: 2em">爲後漢人不得謂之周如以爲周人書則當曰子</span>  
<span style="margin-left: 2em">貢子胥不得謂之吳平也則其他可不問矣</span>  
江皋小築集三卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">明李元弼撰元弼字靖吾廣東人萬厯中卜築江</span>  
<span style="margin-left: 2em">皋題爲十景集友朋唱和成編而以所作詩稿附</span>  
<span style="margin-left: 2em">錄焉</span>  
<!-- 册5 葉653b　Page:文淵閣四庫全書_0005冊.djvu/168 -->
順則集八卷<sub class="note-yuan">編修勵守謙家藏本</sub>  
<span style="margin-left: 2em">明程文潞編文潞字希古歙縣人是編成於萬厯</span>  
<span style="margin-left: 2em">壬午輯程氏先世遺詩自後唐程炳迄明程百教</span>  
<span style="margin-left: 2em">凡百有四人但分時代而皆不詳其仕履葢以別</span>  
<span style="margin-left: 2em">有譜牒在也其稱順則者以世業耕鑿取順帝之</span>  
<span style="margin-left: 2em">則意爾</span>  
塤篪音二卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明虞淳熙虞淳貞仝撰淳熙有孝經集靈已著錄</span>  
<span style="margin-left: 2em">淳貞字僧孺淳熙弟也是集凡賦溪上落花詩一</span>  
<!-- 册5 葉656a　Page:文淵閣四庫全書_0005冊.djvu/169 -->
<span style="margin-left: 2em">百五十首又次韻沈嘉則雜咏一百二十首又倣</span>  
<span style="margin-left: 2em">杜甫同谷七歌淳熙作者命曰塤音淳貞作者命</span>  
<span style="margin-left: 2em">曰篪音原序稱其溪上落花詩伯仲皆一夜而就</span>  
<span style="margin-left: 2em">大意欲夸多鬬㨗耳不知一題衍至百餘首卽曹</span>  
<span style="margin-left: 2em">劉沈謝亦不必工也</span>  
韓文杜律二卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明郭正域編正域有批㸃考工記已著錄是編選</span>  
<span style="margin-left: 2em">錄韓愈文一卷杜甫七言律詩一卷各爲之評㸃</span>  
<span style="margin-left: 2em">大抵明末猖狂之論如謂佛骨表不知佛理之類</span>  
<!-- 册5 葉656b　Page:文淵閣四庫全書_0005冊.djvu/169 -->
<span style="margin-left: 2em">多不足與辨所評杜詩欲矯七子摹擬之𡚁遂動</span>  
<span style="margin-left: 2em">以肥濁爲詬病是公安之驂乘而竟陵之先鞭也</span>  
頻陽四先生集四卷<sub class="note-yuan">陜西巡撫採進本</sub>  
<span style="margin-left: 2em">明劉兌編兌始末未詳其編此書則官富平縣知</span>

<span style="margin-left: 2em">編輯然大抵輾轉勦襲體例畧同此書較名媛詩</span>  
<span style="margin-left: 2em">歸等書不過增入雜文其餘皆互相出入訛謬亦</span>  
<span style="margin-left: 2em">復相沿魯衛之間固無可優劣也</span>

<span style="margin-left: 2em">明董說編說有易發已著錄是書取漢鐃歌十八</span>  
<span style="margin-left: 2em">章反復解說首論大意次爲論韻次爲論音其論</span>  
<span style="margin-left: 2em">韻則有伏有擊有進退有同攝有同母同入論音</span>

<span style="margin-left: 2em">本周禮三宫之說按宫商角徵羽篇分章位章分</span>  
<span style="margin-left: 2em">句位立說殊爲創闢然沈約嘗言漢鐃歌大字爲</span>  
<span style="margin-left: 2em">詞細字爲聲後來聲詞合寫不復可辨遂無文義</span>  
<span style="margin-left: 2em">可尋但存其聲而已自唐後樂府失傳新題迭作</span>  
<span style="margin-left: 2em">於是併聲而亦亡之說不知聲詞合寫之源而强</span>  
<span style="margin-left: 2em">爲索解已迷宗指至鐃歌乃鼓吹之曲但奏其音</span>  
<span style="margin-left: 2em">而不歌其詞故十八章或韻或不韻亦猶風雅皆</span>  
<span style="margin-left: 2em">有韻而頌不盡韻也說一槩强爲叶讀非惟不知</span>
