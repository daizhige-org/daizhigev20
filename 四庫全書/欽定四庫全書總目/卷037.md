## 欽定四庫全書總目 卷三十七　經部三十七　四書類存目

欽定四庫全書總目巻三十七  
<span style="margin-left: 1em">經部三十七</span>  
<span style="margin-left: 2em">四書類存目</span>  
蘇評孟子二卷<sub class="note-yuan">兵部侍郞紀昀家藏本</sub>  
<span style="margin-left: 2em">舊本題宋蘇洵評考是書宋志不著錄孫緖無用</span>  
<span style="margin-left: 2em">閒談稱其論文頗精而摘其中引洪邁之語在洵</span>  
<span style="margin-left: 2em">以後知出依託則正德中是書已行矣此本爲康</span>  
<span style="margin-left: 2em">熙三十三年杭州沈李雲所校其子心友刻之然</span>  
<span style="margin-left: 2em">無所謂洪邁語者豈經緒指摘故削之以滅蹟耶</span>  
<!-- 册1 葉2985b　Page:文淵閣四庫全書_0001冊.djvu/796 -->
<span style="margin-left: 2em">抑併非孫緒所見之本又偽本中之重儓耶宋人</span>  
<span style="margin-left: 2em">讀書於切要處率以筆抹故朱子語類論讀書法</span>  
<span style="margin-left: 2em">云先以某色筆抹出再以某色筆抹岀吕祖謙古</span>  
<span style="margin-left: 2em">文關鍵樓昉迂齋評注古文亦皆用抹其明例也</span>  
<span style="margin-left: 2em">謝枋得文章軌範方囘瀛奎律髓羅椅放翁詩選</span>  
<span style="margin-left: 2em">始稍稍具圈點是盛於南宋末矣此本有大圈有</span>  
<span style="margin-left: 2em">小圈有連圏有重圏有三角圈已斷非北宋人筆</span>  
<span style="margin-left: 2em">其評語全以時文之法行之詞意庸淺不但非洵</span>  
<span style="margin-left: 2em">語亦斷非宋人語也</span>  
<!-- 册1 葉2988a　Page:文淵閣四庫全書_0001冊.djvu/797 -->
孟子解二卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">舊本題宋尹焞撰案陳振孫書錄解題載尹氏論</span>  
<span style="margin-left: 2em">語解十卷孟子解十四卷徽猷閣待制河南尹焞</span>  
<span style="margin-left: 2em">彦明紹興中經筵所上孟子解未成不及上而卒</span>  
<span style="margin-left: 2em">趙希弁讀書附志則謂焞於紹興初再以崇政殿</span>  
<span style="margin-left: 2em">說書召旣侍經筵首解論語以進繼解孟子甫及</span>  
<span style="margin-left: 2em">終篇而卒邢正夫嘗刻於岳陽泮宫其書世罕傳</span>  
<span style="margin-left: 2em">本故朱彞尊經義考註曰已佚此本出浙江吳玉</span>  
<span style="margin-left: 2em">墀家莫知其所自來每章之末畧贅數語評論大</span>  
<!-- 册1 葉2988b　Page:文淵閣四庫全書_0001冊.djvu/797 -->
<span style="margin-left: 2em">意多者不過三四行皆詞義膚淺或類坊刻史評</span>  
<span style="margin-left: 2em">或類時文批語無一語之發明焞爲程氏高弟疑</span>  
<span style="margin-left: 2em">其陋不至於此又書止上下二卷首尾完具無所</span>  
<span style="margin-left: 2em">闕佚與十四卷之數亦不相合殆近時妄人所依</span>  
<span style="margin-left: 2em">託也</span>  
孟子發題一卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">宋施德操撰徳操字彦執海昌人以病廢不能婚</span>  
<span style="margin-left: 2em">宦坎壈而殁此書所述孟子七篇之㫖大意謂孟</span>  
<span style="margin-left: 2em">子有大功四一曰道性善二曰明浩然之氣三曰</span>  
<!-- 册1 葉2989a　Page:文淵閣四庫全書_0001冊.djvu/797 -->
<span style="margin-left: 2em">闢楊墨四曰黜五霸而尊三王皆聖人心術之要</span>  
<span style="margin-left: 2em">而孟子直指以示人者其前後反覆不外此意張</span>  
<span style="margin-left: 2em">九成門人嘗取附九成横浦集末鋟板以傳今析</span>  
<span style="margin-left: 2em">出存目於經部庶不没其名焉</span>  
或問小注三十六卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">舊本題朱子撰宋以來諸家書目皆不著錄諸儒</span>  
<span style="margin-left: 2em">傳朱子之學者亦無一人言及之康熙壬午始有</span>  
<span style="margin-left: 2em">陳彞則家刻本稱明徐方廣所增注越二十年壬</span>  
<span style="margin-left: 2em">寅鄭任鑰又爲重刻而附以己說併作後序反覆</span>  
<!-- 册1 葉2989b　Page:文淵閣四庫全書_0001冊.djvu/797 -->
<span style="margin-left: 2em">力辨信爲朱子書如卷首載朱子與劉用之書及</span>  
<span style="margin-left: 2em">序四篇晦庵集中不載則以爲集中偶佚年譜不</span>  
<span style="margin-left: 2em">記作此書則以爲年譜遺漏書中多講時文作法</span>  
<span style="margin-left: 2em">則以爲制義始王安石朱子亦十九舉進士必善</span>  
<span style="margin-left: 2em">時文連篇累牘欲以强詞奪理至如解中庸其至</span>  
<span style="margin-left: 2em">矣乎一節道之不行也一節皆剽四書大全所載</span>  
<span style="margin-left: 2em">雙峰饒氏語射有似乎君子一節全剽四書大全</span>  
<span style="margin-left: 2em">所載新安陳氏語僞蹟昭然萬難置喙則以爲大</span>  
<span style="margin-left: 2em">全誤題姓名其偏執殆不足與辨又旣稱此書作</span>  
<!-- 册1 葉2992a　Page:文淵閣四庫全書_0001冊.djvu/798 -->
<span style="margin-left: 2em">於集注之後而孟子萬物皆備於我矣一章乃於</span>  
<span style="margin-left: 2em">第三條下附記曰此條係語類說第八條係或問</span>  
<span style="margin-left: 2em">說前輩多疑此爲未定之說在集注之前信哉是</span>  
<span style="margin-left: 2em">小注又在集注前矣不亦自相牴牾耶所載中庸</span>  
<span style="margin-left: 2em">原序稱淳熙己酉冬十月壬申考宋史孝宗本紀</span>  
<span style="margin-left: 2em">是月有庚子壬寅二日使庚子爲朔則下推三十</span>  
<span style="margin-left: 2em">二日爲壬申使壬寅爲晦則上推三十一日爲壬</span>  
<span style="margin-left: 2em">申均不得在十月文獻通考載朱子之言曰集注</span>  
<span style="margin-left: 2em">後來改定處多遂與或問不相應又無工夫修得</span>  
<!-- 册1 葉2992b　Page:文淵閣四庫全書_0001冊.djvu/798 -->
<span style="margin-left: 2em">云云是或問尙未暇改何暇又作小註陳振孫書</span>  
<span style="margin-left: 2em">錄解題又曰論語通輯十卷黃榦撰其書兼載或</span>  
<span style="margin-left: 2em">問發明婦翁未盡之意使朱子果有此書榦亦何</span>  
<span style="margin-left: 2em">必發明乎其爲近人依託無疑王懋竑白田雜著</span>  
<span style="margin-left: 2em">有是書跋稱任鑰刻是書後自知其謬深悔爲湯</span>  
<span style="margin-left: 2em">友信所賣併稱序及諸論皆友信之筆任鑰未嘗</span>  
<span style="margin-left: 2em">寓目云</span>  
四書問目<sub class="note-yuan">無卷數　浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">舊本題曰考亭朱元晦先生講授門人雲莊劉爚</span>  
<!-- 册1 葉2993a　Page:文淵閣四庫全書_0001冊.djvu/798 -->
<span style="margin-left: 2em">睦堂劉炳述記前有永樂壬寅其九世孫劉文序</span>  
<span style="margin-left: 2em">稱四書問目世所傳者四書大全朱子文集内載</span>  
<span style="margin-left: 2em">數條而已近於親表敎授程蕃家求得論語二十</span>  
<span style="margin-left: 2em">篇及任江西豐城尉適吳侍御家得大學中庸數</span>  
<span style="margin-left: 2em">十條而孟子則同修國史崇邑邱公永錫家藏焉</span>  
<span style="margin-left: 2em">於是散者復合而缺者幾全又有宏治十一年鄭</span>  
<span style="margin-left: 2em">京序稱宣德間書林有與同姓者欲附其族爲劉</span>  
<span style="margin-left: 2em">氏子孫所辱遂於凡載籍間二人姓名悉剔去之</span>  
<span style="margin-left: 2em">或易以他名欲滅其迹又稱劉文所輯湮晦失傳</span>  
<!-- 册1 葉2993b　Page:文淵閣四庫全書_0001冊.djvu/798 -->
<span style="margin-left: 2em">其裔孫復於廌山游氏得其全帙云云案朱彞尊</span>  
<span style="margin-left: 2em">經義考劉爚有四書集成劉炳有四書問目並注</span>  
<span style="margin-left: 2em">已佚則問目獨山於炳不應兼題爚名又豐城縣</span>  
<span style="margin-left: 2em">志載明一代典史六十三人亦無所謂建陽劉文</span>  
<span style="margin-left: 2em">且建陽一書賈其力幾何安能盡毁爚炳之書又</span>  
<span style="margin-left: 2em">安能盡剷爚炳之名易以他氏其說皆牴牾支離</span>  
<span style="margin-left: 2em">書中問答亦皆粗淺不類朱子之語殆皆其後人</span>  
<span style="margin-left: 2em">所依託歟</span>  
朱子四書語類五十二卷<sub class="note-yuan">江西巡撫採進本</sub>  
<!-- 册1 葉2996a　Page:文淵閣四庫全書_0001冊.djvu/799 -->
<span style="margin-left: 1em">國朝周在延編在延祥符人後流寓於江寧其書乃</span>  
<span style="margin-left: 2em">於朱子語類中專取四書諸卷刊行别無增損亦</span>  
<span style="margin-left: 2em">無所考訂發明</span>  
論語孟子考異二卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">舊本題宋王應麟撰凡注疏諸儒之說與集注互</span>  
<span style="margin-left: 2em">異者各爲考訂然應麟著作傳世者多而此書諸</span>  
<span style="margin-left: 2em">家皆不著錄今考所載實皆採之困學紀聞中葢</span>  
<span style="margin-left: 2em">書肆作僞之本也</span>  
中庸合注一卷<sub class="note-yuan">浙江汪啓淑家藏本</sub>  
<!-- 册1 葉2996b　Page:文淵閣四庫全書_0001冊.djvu/799 -->
<span style="margin-left: 2em">不著撰人名氏前有元吳澂序然篇末題曰序而</span>  
<span style="margin-left: 2em">篇首題曰總說其文亦不類序體殆割裂移掇强</span>  
<span style="margin-left: 2em">爲標目書中所載雙峯饒氏新安陳氏所說皆澂</span>  
<span style="margin-left: 2em">同時之人而郊社之禮一條乃引吳氏澂曰云云</span>  
<span style="margin-left: 2em">其不出於澂更無疑義元史澂傳亦不言澂有此</span>  
<span style="margin-left: 2em">書考其所引皆明永樂中所修四書大全之說必</span>  
<span style="margin-left: 2em">書賈摘錄大全僞託澂名也</span>  
重訂四書輯釋二十卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">元倪士毅撰士毅字仲宏歙縣人是書前有至正</span>  
<!-- 册1 葉2997a　Page:文淵閣四庫全書_0001冊.djvu/799 -->
<span style="margin-left: 2em">丙戌汪克寛序稱近世儒者取朱子平日所以語</span>  
<span style="margin-left: 2em">諸學者及其弟子訓釋之詞疏於四書之左眞氏</span>  
<span style="margin-left: 2em">有集義祝氏有附錄蔡氏趙氏有集疏纂疏相繼</span>  
<span style="margin-left: 2em">成編而吳氏最晩出但辨論未爲完傋去取頗欠</span>  
<span style="margin-left: 2em">精審定宇陳氏雲峯胡氏因其書行於東南輾轉</span>  
<span style="margin-left: 2em">承悞陳氏因作四書發明胡氏因作四書通陳氏</span>  
<span style="margin-left: 2em">晚年又欲合二書爲一而未遂士毅受業於陳氏</span>  
<span style="margin-left: 2em">因成此書至正辛巳刻於建陽越二年又加刊削</span>  
<span style="margin-left: 2em">而克寛爲之序卷首有士毅與書賈劉叔簡書述</span>  
<!-- 册1 葉2997b　Page:文淵閣四庫全書_0001冊.djvu/799 -->
<span style="margin-left: 2em">改刻之意甚詳此重訂所由名也此本改題曰重</span>  
<span style="margin-left: 2em">訂輯釋章圖通義大成首行列士毅之名次列新</span>  
<span style="margin-left: 2em">安東山趙汸同訂次列鄱陽克升朱公遷約㫖次</span>  
<span style="margin-left: 2em">列新安林隱程復心章圖莆田王元善通考次列</span>  
<span style="margin-left: 2em">鄱陽王逢訂定通義書中亦糅雜𫎇混紛如亂絲</span>  
<span style="margin-left: 2em">不可復究其端緖是已爲書賈所改竄非士毅之</span>  
<span style="margin-left: 2em">舊矣然陳櫟胡炳文本因吳眞子之書士毅又因</span>  
<span style="margin-left: 2em">陳胡之書究其由來實轉相稗販則王逢因人成</span>  
<span style="margin-left: 2em">事亦有所效法不足爲譏至明永樂中詔修四書</span>  
<!-- 册1 葉3000a　Page:文淵閣四庫全書_0001冊.djvu/800 -->
<span style="margin-left: 2em">大全胡廣等又併士毅與逢之書一槩竊據而輯</span>  
<span style="margin-left: 2em">釋通義並隱矣有明一代尊大全爲著龜沿及近</span>  
<span style="margin-left: 2em">代講章亦無非依傍大全變換面貌烏知其淵源</span>  
<span style="margin-left: 2em">所自不過如斯哉</span>  
四書通義二十卷<sub class="note-yuan">江西巡撫採進本</sub>  
<span style="margin-left: 2em">明劉剡撰剡字用章休寧人是書因倪士毅四書</span>  
<span style="margin-left: 2em">輯釋重爲訂正更益以金履祥疏義指義朱公遷</span>  
<span style="margin-left: 2em">通㫖約說程復心章圖史伯璿管窺王善通考及</span>  
<span style="margin-left: 2em">當時諸儒著述改題此名夫吳眞子據眞氏祝氏</span>  
<!-- 册1 葉3000b　Page:文淵閣四庫全書_0001冊.djvu/800 -->
<span style="margin-left: 2em">蔡氏趙氏之書纂爲四書集成自以爲善矣而胡</span>  
<span style="margin-left: 2em">炳文陳櫟重訂之胡氏陳氏自以爲善矣而倪士</span>  
<span style="margin-left: 2em">毅又重訂之倪氏自以爲善矣而剡又重訂之自</span>  
<span style="margin-left: 2em">剡以後重訂者又不知凡幾葢隷首不能算其數</span>  
<span style="margin-left: 2em">也而大㫖皆曰前人未善吾不得已而作焉實則</span>  
<span style="margin-left: 2em">轉相剽襲改換其面貌更易其名目而已輯一四</span>
