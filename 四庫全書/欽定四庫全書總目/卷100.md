## 欽定四庫全書總目 卷一百　子部十　兵家類存目

<!-- 册3 葉653a　Page:文淵閣四庫全書_0003冊.djvu/168 -->
欽定四庫全書總目巻一百  
<span style="margin-left: 1em">子部十</span>  
<span style="margin-left: 2em">兵家類存目</span>  
握機經三巻握機緯十五巻<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明曹允儒撰允儒字魯川太倉人是書首載風后</span>  
<span style="margin-left: 2em">古文一十九字次載太公望增衍三百六十五字</span>  
<span style="margin-left: 2em">次載宋阮逸所撰李衞公問對中六十七字採輯</span>  
<span style="margin-left: 2em">諸家註釋於衡衝風雲諸陣皆繪爲圖凡三巻又</span>  
<span style="margin-left: 2em">以孫子十三篇吳子六篇爲握機緯孫子輯諸家</span>  
<!-- 册3 葉653b　Page:文淵閣四庫全書_0003冊.djvu/168 -->
<span style="margin-left: 2em">訓釋凡十三巻吳子惟用劉寅註凡二巻考千頃</span>  
<span style="margin-left: 2em">堂書目有元人孫子握機緯十三巻劉寅吳子握</span>  
<span style="margin-left: 2em">機緯二巻書名巻數與此書一一相合其卽得此</span>  
<span style="margin-left: 2em">書之殘本誤爲標目歟據王世貞序稱崑山明齋</span>  
<span style="margin-left: 2em">王氏與念菴羅公荆川唐公因倭變力研窮之而</span>  
<span style="margin-left: 2em">以其說盡授之魯川曹君曹君向與戚大將軍商</span>  
<span style="margin-left: 2em">之戚深以爲然數數向予稱道之云云則確非元</span>  
<span style="margin-left: 2em">人及劉寅作矣然以孫吳二子加以緯名亦殊杜</span>  
<span style="margin-left: 2em">撰二子之書各明一義與握機不相發明也</span>  
<!-- 册3 葉656a　Page:文淵閣四庫全書_0003冊.djvu/169 -->
握機經解一巻<sub class="note-yuan">山西巡撫採進本</sub>  
<span style="margin-left: 1em">國朝王瞰撰瞰字始旦絳州人是編据李衞公問對</span>  
<span style="margin-left: 2em">以握機經三百八十四字皆太公增衍之文因捃</span>  
<span style="margin-left: 2em">摭往說並攄已見爲之集註考李衞公問對三巻</span>  
<span style="margin-left: 2em">本宋阮逸僞撰瞰乃据以定此書爲太公之文殊</span>  
<span style="margin-left: 2em">不足信後附增衍握奇經六十八字自註云相傳</span>  
<span style="margin-left: 2em">宋阮逸擬作則亦明知其僞矣</span>  
太公兵法一巻<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">案此書首列天陣地陣人陣之名其說出於六韜</span>  
<!-- 册3 葉656b　Page:文淵閣四庫全書_0003冊.djvu/169 -->
<span style="margin-left: 2em">而風雲日星等占皆以七言詩句爲歌訣辭甚鄙</span>  
<span style="margin-left: 2em">俚其僞托不待辨也</span>  
孫子參同五巻<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">此本不知何人所輯前有凡例又有萬厯庚申吳</span>  
<span style="margin-left: 2em">興松筠館主人序亦不署姓名其板用朱墨二色</span>  
<span style="margin-left: 2em">與世所稱閔板者同疑爲烏程閔氏刻也所採註</span>  
<span style="margin-left: 2em">釋列曹操李筌杜牧王晳張預賈林梅堯臣陳皥</span>  
<span style="margin-left: 2em">杜佑孟氏何氏解元張鏊李材黃治徵十五家所</span>  
<span style="margin-left: 2em">採批評列蘇洵王圻唐順之王世貞陳深李贄梅</span>  
<!-- 册3 葉657a　Page:文淵閣四庫全書_0003冊.djvu/169 -->
<span style="margin-left: 2em">國楨焦竑郞文煥陸宏祚十家而巻中不盡見巻</span>  
<span style="margin-left: 2em">中所見如茅坤王鏊之類巻首又不列名其凡例</span>  
<span style="margin-left: 2em">稱卓吾子以吳子司馬法李靖問答六韜三畧集</span>  
<span style="margin-left: 2em">其品類分列十三篇後今悉從之又稱今旁集諸</span>  
<span style="margin-left: 2em">書廣采事實以補前人所未備又稱批㸃悉係鳳</span>  
<span style="margin-left: 2em">洲了凡原筆而評則蘇王諸家並存又稱卓吾參</span>  
<span style="margin-left: 2em">同具載叢書中原有梅司馬評㸃並不擅改所言</span>  
<span style="margin-left: 2em">輾轉糾紛無從得其端緒葢坊賈凑合之本故漫</span>  
<span style="margin-left: 2em">無體例如是也</span>  
<!-- 册3 葉657b　Page:文淵閣四庫全書_0003冊.djvu/169 -->
孫子彚徵四巻<sub class="note-yuan">直隸總督採進本</sub>  
<span style="margin-left: 1em">國朝鄭端撰端有政學編巳著錄攷孫子十三篇舊</span>  
<span style="margin-left: 2em">註見於史志及諸家書目者今多不傳傳者亦多</span>  
<span style="margin-left: 2em">散見諸書罕專行之完本端此編彚集衆說兼采</span>  
<span style="margin-left: 2em">古來談兵之言足與孫子發明者附錄於各句之</span>  
<span style="margin-left: 2em">下頗爲詳備然徵引太冗如作戰篇公家之費節</span>  
<span style="margin-left: 2em">注内所錄車馬器械之論於車則全載考工記於</span>  
<span style="margin-left: 2em">馬則悉引相馬經於弓矢戈㦸牌棒鈀鐵等類則</span>  
<span style="margin-left: 2em">縷陳演習攻打之法極其𤨏細亦博而不精者也</span>  
<!-- 册3 葉660a　Page:文淵閣四庫全書_0003冊.djvu/170 -->
<span style="margin-left: 2em">其書每巻皆標曰孫武子集解廣義而端自序則</span>  
<span style="margin-left: 2em">又題曰孫子彚徵未詳二名孰先孰後今姑從端</span>  
<span style="margin-left: 2em">自序之名焉</span>  
十六䇿一巻<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">此本載永樂大典中舊題漢諸葛亮撰考亮所著</span>  
<span style="margin-left: 2em">作陳壽三國志詳列於本傳之後初無是書之名</span>  
<span style="margin-left: 2em">故晁公武讀書志疑附託者所爲又晁志曰有序</span>  
<span style="margin-left: 2em">稱謹進便宜十六事是尚有僞撰亮序文今本不</span>  
<span style="margin-left: 2em">載而末有李革跋云泰和五祀中秋日閱圖書得</span>  
<!-- 册3 葉660b　Page:文淵閣四庫全書_0003冊.djvu/170 -->
<span style="margin-left: 2em">此集因錄一本旣竟而題於此革字君美河津人</span>  
<span style="margin-left: 2em">登大定二十五年進士貞祐中爲吏部尚書葢晁</span>  
<span style="margin-left: 2em">氏所據宋人本此則金人本耳又晁氏稱六曰治</span>  
<span style="margin-left: 2em">民今本作治人十二曰治亂今本作治政十六曰</span>  
<span style="margin-left: 2em">陰察今本作陰誡亦小小異同然皆不足究詰也</span>  
將苑一巻<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">舊本題漢諸葛亮撰前有明僉都御史𡩋仲升序</span>  
<span style="margin-left: 2em">謂出於士人周源所藏考此書諸家不著錄至尤</span>  
<span style="margin-left: 2em">袤遂初堂書目乃載其名亦稱亮撰葢僞書之晩</span>  
<!-- 册3 葉661a　Page:文淵閣四庫全書_0003冊.djvu/170 -->
<span style="margin-left: 2em">出者又明焦竑經籍志更有亮心書六軍鏡心訣</span>  
<span style="margin-left: 2em">兵機法諸書益爲依託葢宋以來兵家之書多託</span>  
<span style="margin-left: 2em">於亮明以來術數之書多託於劉基委巷之談均</span>  
<span style="margin-left: 2em">無足與深辨者耳</span>  
心書一巻<sub class="note-yuan">陜西巡撫採進本</sub>  
<span style="margin-left: 2em">舊本題漢諸葛亮撰書中皆言爲將用兵之法陶</span>  
<span style="margin-left: 2em">宗儀說郛作新書明宏治間關西劉讓鋟之於木</span>  
<span style="margin-left: 2em">始改名心書附以出師二表嘉靖中䕫人張銳重</span>  
<span style="margin-left: 2em">刊增入䕫門圖前載讓序後有鄖鄕進士冦韋跋</span>  
<!-- 册3 葉661b　Page:文淵閣四庫全書_0003冊.djvu/170 -->
<span style="margin-left: 2em">皆以爲眞出於亮考五十篇内之文大都竊取孫</span>  
<span style="margin-left: 2em">子書而附以迂陋之言至不足道葢妄人所僞作</span>  
<span style="margin-left: 2em">又出於將苑之後也</span>  
兵要望江南謌一巻<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">是書詳述兵家占候凡三十二門各以望江南詞</span>  
<span style="margin-left: 2em">括之崇文總目題武安軍左押衙易靜撰葢唐人</span>  
<span style="margin-left: 2em">也晁公武讀書志則稱舊題黃石公以授張良其</span>  
<span style="margin-left: 2em">妄殆不待辨此本又題唐李靖撰案段安節樂府</span>  
<span style="margin-left: 2em">雜錄望江南詞本李德裕爲亡妓謝秋娘作則其</span>  
<!-- 册3 葉664a　Page:文淵閣四庫全書_0003冊.djvu/171 -->
<span style="margin-left: 2em">調起於中唐世傳海山記隋煬帝作實出僞託靖</span>  
<span style="margin-left: 2em">在唐初安得預製是詞推厥所出葢以望江南調</span>  
<span style="margin-left: 2em">始德裕德裕實封衛國公言兵者多稱靖靖亦封</span>  
<span style="margin-left: 2em">衛國公此書以望江南談兵遂合兩衛公而一之</span>  
<span style="margin-left: 2em">耳末附李淳風占風法諸葛亮氣候歌前有梁楨</span>  
<span style="margin-left: 2em">明三年安邱劉鄩序均詞意凡鄙亦僞託也</span>  
武經體註大全會解七巻<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 1em">國朝夏振翼撰振翼字遯闇蕪湖人孫子等七書武</span>  
<span style="margin-left: 2em">科用以試士故相傳謂之武經振翼因依五經講</span>  
<!-- 册3 葉664b　Page:文淵閣四庫全書_0003冊.djvu/171 -->
<span style="margin-left: 2em">章例作體註以訓釋之冠以胡秉中射學摘要一</span>  
<span style="margin-left: 2em">篇葢坊間通俗之本也</span>  
<span style="margin-left: 4em">謹案四庫編纂之例凡註古書者仍以古書</span>  
<span style="margin-left: 4em">之時代爲次則此書當列孫子彚徵後然七</span>  
<span style="margin-left: 4em">書合爲一編實始於宋元豐中又與自爲一</span>  
<span style="margin-left: 4em">書者不同故今移冠宋人兵書之前</span>  
將鑑論斷十巻<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">舊本題宋戴少望撰考沈光作戴溪岷隱春秋傳</span>  
<span style="margin-left: 2em">序稱其字曰少望則此書當爲溪作然溪以淳熙</span>  
<!-- 册3 葉665a　Page:文淵閣四庫全書_0003冊.djvu/171 -->
<span style="margin-left: 2em">五年登第開禧中尚官資善堂說書而此書自序</span>  
<span style="margin-left: 2em">題紹興辛酉爲高宗十一年下距其登第之嵗三</span>  
<span style="margin-left: 2em">十八年距開禧元年更六十五年溪不應如是之</span>  
<span style="margin-left: 2em">老壽疑别一人其名偶與溪字同也是書採輯古</span>  
<span style="margin-left: 2em">來善用兵者始於孫武終於郭崇韜凡九十三人</span>  
<span style="margin-left: 2em">各以時代爲次每人之下皆以一語標目評其得</span>  
<span style="margin-left: 2em">失而反覆論其所以然大抵多爲南渡後時事而</span>  
<span style="margin-left: 2em">發如第一條詆孫武之徒能滅楚終於恃强以亡</span>  
<span style="margin-left: 2em">吳葢隱以比金兵破汴之事第二條稱范蠡能復</span>  
<!-- 册3 葉665b　Page:文淵閣四庫全書_0003冊.djvu/171 -->
<span style="margin-left: 2em">吳仇爲春秋大夫第一則又隱激諸將恢復之心</span>  
<span style="margin-left: 2em">而耿弇一條竇憲一條尤三致意焉然大旨主於</span>  
<span style="margin-left: 2em">尚仁義賤權謀尊儒者抑武臣至以能讀三畧之</span>  
<span style="margin-left: 2em">書者始可以立功則又衣冠而拯焚溺與南渡事</span>  
<span style="margin-left: 2em">𫝑逈乎不合矣此本爲宋麻沙板明武定侯郭勛</span>  
<span style="margin-left: 2em">嘗重刻之前有正德十年達賓序題曰將鑑博議</span>  
<span style="margin-left: 2em">與宋板不同考永樂大典巳引爲將鑑博議則其</span>  
<span style="margin-left: 2em">來久矣</span>  
江東十鑑一巻<sub class="note-yuan">兩淮鹽政採進本</sub>  
<!-- 册3 葉668a　Page:文淵閣四庫全書_0003冊.djvu/172 -->
<span style="margin-left: 2em">朱李舜臣撰舜臣字子思井研人乾道二年進士</span>  
<span style="margin-left: 2em">官成都府教授擢宗正寺主簿事蹟具宋史本傳</span>  
<span style="margin-left: 2em">是編蒐輯江東戰勝之迹上起三國下至六朝共</span>  
<span style="margin-left: 2em">得十事一曰周瑜赤壁之戰二曰祖逖譙城之戰</span>  
<span style="margin-left: 2em">三曰褚裒彭城之戰四曰桓温灞水之戰五曰謝</span>  
<span style="margin-left: 2em">元淝水之戰六曰劉裕關中之戰七曰到彦之河</span>  
<span style="margin-left: 2em">南之戰八曰蕭衍義陽之戰九曰陳慶之洛陽之</span>  
<span style="margin-left: 2em">戰十曰吳明徹淮南之戰皆先敘其事次加論斷</span>  
<span style="margin-left: 2em">葢宋自高宗南渡偏據一隅地處下游外臨勍敵</span>  
<!-- 册3 葉668b　Page:文淵閣四庫全書_0003冊.djvu/172 -->
<span style="margin-left: 2em">岌岌乎不能自保故舜臣特作此編以勵戰氣然</span>  
<span style="margin-left: 2em">自古以來無以偏安江左而能北取中原者舜臣</span>  
<span style="margin-left: 2em">徒爲大言未核事𫝑也明姚廣孝等編緝永樂大</span>  
<span style="margin-left: 2em">典特錄其書殆以廣孝吳人故借以誇鄕<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3771.svg?width=24" alt="四庫全書僻字第3771號（邦）" title="四庫全書僻字第3771號（邦）">之形</span>  
<span style="margin-left: 2em">勝又成祖詔修是書之時猶在南都故廣孝等遷</span>  
<span style="margin-left: 2em">就其說不知明太祖之得天下實緣起於江北與</span>
