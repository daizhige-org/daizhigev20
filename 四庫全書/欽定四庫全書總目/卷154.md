## 欽定四庫全書總目 卷一百五十四　集部七　別集類七

<!-- 册4 葉549a　Page:文淵閣四庫全書_0004冊.djvu/142 -->
欽定四庫全書總目卷一百五十四  
<span style="margin-left: 1em">集部七</span>  
<span style="margin-left: 2em">别集類七</span>  
東坡全集一百十五卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋蘇軾撰軾有易傳巳著錄案蘇轍作軾墓誌稱</span>  
<span style="margin-left: 2em">軾所著有東坡集四十卷後集二十卷奏議十五</span>  
<span style="margin-left: 2em">卷内制十卷外制三卷和陶詩四卷晁公武讀書</span>  
<span style="margin-left: 2em">志陳振孫書錄解題所載並同而别增應詔集十</span>  
<span style="margin-left: 2em">卷合爲一編卽世所稱東坡七集者是也宋史藝</span>  
<!-- 册4 葉549b　Page:文淵閣四庫全書_0004冊.djvu/142 -->
<span style="margin-left: 2em">文志則載前後集七十卷卷數與墓誌不合而又</span>  
<span style="margin-left: 2em">别出奏議補遺三卷南征集一卷詞一卷南省說</span>  
<span style="margin-left: 2em">書一卷别集四十六卷黃州集二卷續集二卷北</span>  
<span style="margin-left: 2em">歸集六卷儋耳手澤一卷名目頗爲叢碎今考軾</span>  
<span style="margin-left: 2em">集在宋世原非一本邵博聞見後錄稱京師印本</span>  
<span style="margin-left: 2em">東坡集軾自校其中香醪字誤者不更見於他書</span>  
<span style="margin-left: 2em">殆燬於靖康之亂陳振孫所稱有杭水蜀本又有</span>  
<span style="margin-left: 2em">軾曾孫嶠所刋建安本又有麻沙書坊大全集本</span>  
<span style="margin-left: 2em">又有張某所刋吉州本蜀本建安本無應詔集麻</span>  
<!-- 册4 葉552a　Page:文淵閣四庫全書_0004冊.djvu/143 -->
<span style="margin-left: 2em">沙本吉州本兼載志林雜說之類不加考訂而陳</span>  
<span style="margin-left: 2em">鵠耆舊續聞則稱姑胥居世英刋東坡全集殊有</span>  
<span style="margin-left: 2em">序又少舛謬極可賞是當時以蘇州本爲最善而</span>  
<span style="margin-left: 2em">今亦無存葉盛水東曰記又云邵復儒家有細字</span>  
<span style="margin-left: 2em">小本東坡大全文集松江東曰和尙所藏有大本</span>  
<span style="margin-left: 2em">東坡集又有小字大本東坡集盛所見皆宋代舊</span>  
<span style="margin-left: 2em">刻而其錯互已如此觀捫蝨新話稱葉嘉傳乃其</span>  
<span style="margin-left: 2em">邑人陳元規作和賀方回靑玉案詞乃華亭姚晉</span>  
<span style="margin-left: 2em">作集中如睡鄉醉鄉記鄙俚淺近決非坡作今書</span>  
<!-- 册4 葉552b　Page:文淵閣四庫全書_0004冊.djvu/143 -->
<span style="margin-left: 2em">肆往往增添改换以求速售而官不之禁云云則</span>  
<span style="margin-left: 2em">軾集風行海内傳刻曰多而紊亂愈甚固其所矣</span>  
<span style="margin-left: 2em">然傳本雖夥其體例大要有一二爲分集編訂者</span>  
<span style="margin-left: 2em">乃因軾原本原目而後人稍增益之卽陳振孫所</span>  
<span style="margin-left: 2em">云杭本當軾無恙之時已行於世者至明代江西</span>  
<span style="margin-left: 2em">刻本猶然而重刻久絶其一爲分𩔖合編者疑卽</span>  
<span style="margin-left: 2em">始於居世英本宋時所謂大全集者𩔖用此例迄</span>  
<span style="margin-left: 2em">明而傳刻尤多有七十五卷者號東坡先生全集</span>  
<span style="margin-left: 2em">載文不載詩漏畧尤甚有一百十四卷者號蘇文</span>  
<!-- 册4 葉553a　Page:文淵閣四庫全書_0004冊.djvu/143 -->
<span style="margin-left: 2em">忠全集板稍工而編緝無法此本乃</span>  
<span style="margin-left: 1em">國朝蔡士英所刋葢亦據舊刻重訂世所通行今故</span>  
<span style="margin-left: 2em">用以著錄集首舊有年譜一卷乃宋南海王宗稷</span>  
<span style="margin-left: 2em">所編邵長蘅查愼行補註軾詩稱其於作詩歲月</span>  
<span style="margin-left: 2em">編次多誤以原本所有今亦並存焉</span>  
東坡詩集註三十二卷<sub class="note-yuan">少詹事陸費墀家藏本</sub>  
<span style="margin-left: 2em">舊本題宋王十朋撰十朋有會稽三賦已著錄是</span>  
<span style="margin-left: 2em">集前有趙䕫序稱分五十𩔖此本實止二十九類</span>  
<span style="margin-left: 2em">葢有所合併十朋序題百家註此本所引數亦不</span>  
<!-- 册4 葉553b　Page:文淵閣四庫全書_0004冊.djvu/143 -->
<span style="margin-left: 2em">足則猶杜詩稱千家注韓柳文稱五百家註也其</span>  
<span style="margin-left: 2em">分類頗多顚舛如芙蓉城詩入古蹟虎兒詩入詠</span>  
<span style="margin-left: 2em">史之𩔖不可殫數不但以畫魚歌入書畫爲查愼</span>  
<span style="margin-left: 2em">行東坡詩補注所譏其注爲邵長蘅所掊擊者凡</span>  
<span style="margin-left: 2em">三十八條至作正譌一卷冠所校施注之首考十</span>  
<span style="margin-left: 2em">朋梅溪前集載序八篇後集載序三篇獨無此序</span>  
<span style="margin-left: 2em">又有讀蘇文三則亦無一字及蘇詩梅溪集爲其</span>  
<span style="margin-left: 2em">子聞詩聞禮所編十朋著述搜輯無遺不應獨漏</span>  
<span style="margin-left: 2em">此序又趙䕫序稱崇寧間僕年志於學逮今三十</span>  
<!-- 册4 葉556a　Page:文淵閣四庫全書_0004冊.djvu/144 -->
<span style="margin-left: 2em">年一字一句推究來厯必欲見其用事之處頃者</span>  
<span style="margin-left: 2em">赴調京師繼復守官累與小坡叔黨游從至熟叩</span>  
<span style="margin-left: 2em">其所未知者叔黨亦能爲僕言之云云考宋史載</span>  
<span style="margin-left: 2em">軾知杭州蘇過年十九其時在元祐五六年間又</span>  
<span style="margin-left: 2em">稱過殁時年五十二則當在宣和五六年間若從</span>  
<span style="margin-left: 2em">崇寧元年下推三十年巳爲紹興元年過之殁七</span>  
<span style="margin-left: 2em">八年矣䕫安能見過而問之則併䕫序亦出依託</span>  
<span style="margin-left: 2em">核書中體例與杜詩千家註相同殆必一時書肆</span>  
<span style="margin-left: 2em">所爲借十朋之名以行耳然長蘅摘其體例三失</span>  
<!-- 册4 葉556b　Page:文淵閣四庫全書_0004冊.djvu/144 -->
<span style="margin-left: 2em">而云中間援引詳明展卷瞭如者僅僅及半則疎</span>  
<span style="margin-left: 2em">陋者不過十之五未可全廢其於施注所闕十二</span>  
<span style="margin-left: 2em">卷亦云參酌王注徵引羣書以補之則未嘗不於</span>  
<span style="margin-left: 2em">此注取材大抵剏始者難工繼事者易宻邵注正</span>  
<span style="margin-left: 2em">王注之譌查注又摘邵注之誤今觀查註亦譌漏</span>  
<span style="margin-left: 2em">尙多考證之學不可窮盡難執一家以廢其餘錄</span>  
<span style="margin-left: 2em">存是書亦足資讀蘇詩者之旁參也</span>  
施注蘇詩四十二卷東坡年譜一卷王注正譌一卷蘇  
詩續補遺二卷<sub class="note-yuan">内府藏本</sub>  
<!-- 册4 葉557a　Page:文淵閣四庫全書_0004冊.djvu/144 -->
<span style="margin-left: 2em">宋施元之注元之字德初吳興人陸游作是書序</span>  
<span style="margin-left: 2em">但稱其官曰司諫其始末則無可考矣其同注者</span>  
<span style="margin-left: 2em">爲吳郡顧禧游序所謂助以顧君景繁之賅洽也</span>  
<span style="margin-left: 2em">元之子宿又爲補綴書錄解題所謂其子宿從而</span>  
<span style="margin-left: 2em">推廣且爲年譜以傳於世也吳興掌故但言宿推</span>  
<span style="margin-left: 2em">廣爲年譜不言補註與書錄解題不同今考書中</span>  
<span style="margin-left: 2em">實有宿注則吳興掌故爲漏矣嘉泰中宿官餘姚</span>  
<span style="margin-left: 2em">嘗以是書刋板竟緣是遭論罷故傳本頗稀世所</span>  
<span style="margin-left: 2em">行者惟王十朋分𩔖注本康熙已卯宋犖官江蘇</span>  
<!-- 册4 葉557b　Page:文淵閣四庫全書_0004冊.djvu/144 -->
<span style="margin-left: 2em">巡撫始得殘本於藏書家巳佚其卷一卷二卷五</span>  
<span style="margin-left: 2em">卷六卷八卷九卷二十三卷二十六卷三十五卷</span>  
<span style="margin-left: 2em">三十六卷三十九卷四十犖屬武進邵長蘅補其</span>  
<span style="margin-left: 2em">闕卷長蘅撰王注正譌一卷又訂定王宗稷年譜</span>  
<span style="margin-left: 2em">一卷冠於集首其注則僅補八卷以病未能卒業</span>  
<span style="margin-left: 2em">更倩高郵李必恒續成三十五卷三十六卷三十</span>  
<span style="margin-left: 2em">九卷四十卷犖又摭拾遺詩爲施氏所未收者得</span>  
<span style="margin-left: 2em">四百餘首别屬錢塘馮景注之重爲刋板乾隆初</span>  
<span style="margin-left: 2em">又</span>  
<!-- 册4 葉560a　Page:文淵閣四庫全書_0004冊.djvu/145 -->
詔内府刋爲巾箱本取攜旣便遂衣被彌宏元之原本  
<span style="margin-left: 2em">註在各句之下長蘅病其間隔乃彚注於篇末又</span>  
<span style="margin-left: 2em">於原注多所刋削或失其舊後查愼行作蘇詩補</span>  
<span style="margin-left: 2em">注頗斥其非亦如長蘅之詆王注然數百年沉晦</span>  
<span style="margin-left: 2em">之笈實由犖與長蘅復見於世遂得以上邀</span>  
<span style="margin-left: 1em">乙夜之觀且剞劂棗梨壽諸不朽其功亦何可盡没</span>  
<span style="margin-left: 2em">歟</span>  
補注東坡編年詩五十卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 1em">國朝查愼行撰愼行有周易玩詞集解已著錄初宋</span>  
<!-- 册4 葉560b　Page:文淵閣四庫全書_0004冊.djvu/145 -->
<span style="margin-left: 2em">犖刻施注蘇詩急遽成書頗傷潦草又舊本黴黯</span>  
<span style="margin-left: 2em">字跡多難辨識邵長蘅等憚於尋繹往往臆改其</span>  
<span style="margin-left: 2em">文或竟刪除以滅跡併存者亦失其眞愼行是編</span>  
<span style="margin-left: 2em">凡長蘅等所竄亂者並勘驗原書一一釐正又於</span>  
<span style="margin-left: 2em">施注所未及者悉蒐採諸書以補之其間編年錯</span>  
<span style="margin-left: 2em">亂及以他詩溷入者悉攷訂重編凡爲正集四十</span>  
<span style="margin-left: 2em">五卷又補錄帖子詞致語口號一卷遺詩補編二</span>  
<span style="margin-left: 2em">卷他集互見詩二卷别以年譜冠前而以同時倡</span>  
<span style="margin-left: 2em">和散附各詩之後雖卷帙浩博不免牴牾如蘇轍</span>  
<!-- 册4 葉561a　Page:文淵閣四庫全書_0004冊.djvu/145 -->
<span style="margin-left: 2em">辛丑除日寄軾詩軾得而和必在壬寅乃亦入之</span>  
<span style="margin-left: 2em">辛丑卷末則編年有差題李白寫眞詩前後文義</span>  
<span style="margin-left: 2em">相屬本爲一首惠洪所說甚明乃據聲畫集分爲</span>  
<span style="margin-left: 2em">二首則校讎爲舛漁父詞四首醉翁操一首本皆</span>  
<span style="margin-left: 2em">詩餘乃列之詩集則體裁未明倡和詩中所列曾</span>  
<span style="margin-left: 2em">鞏上元遊祥符寺詩陳舜俞送周開祖詩楊蟠北</span>  
<span style="margin-left: 2em">固北高峯塔詩張舜民西征三絶句皆與軾渺不</span>  
<span style="margin-left: 2em">相關乃一槪闌入至於所補諸篇如怪石詩指爲</span>  
<span style="margin-left: 2em">遭憂時作不知朱子語𩔖謂二蘇居喪無詩文鼠</span>  
<!-- 册4 葉561b　Page:文淵閣四庫全書_0004冊.djvu/145 -->
<span style="margin-left: 2em">鬚筆詩本軾子過作而乃不信宋文鑑和錢穆父</span>  
<span style="margin-left: 2em">寄弟詩已見三十一卷乃全篇複見元祐九年立</span>  
<span style="margin-left: 2em">春詩卽戲李端叔詩中四句已見三十七卷乃割</span>  
<span style="margin-left: 2em">裂再出雙井白龍詩冷齋夜話明言非東坡作乃</span>  
<span style="margin-left: 2em">反云據以補入甚至李白山中日夕忽然有懷詩</span>  
<span style="margin-left: 2em">亦引爲軾作尢失於檢校如斯之類皆不免<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3271.svg?width=24" alt="四庫全書僻字第3271號（炫）" title="四庫全書僻字第3271號（炫）">博</span>  
<span style="margin-left: 2em">貪多其所補注如宋叔達家聽琵琶詩夢回猶識</span>  
<span style="margin-left: 2em">歸舟字句本用箜篌朱字事見太平廣記乃惟引</span>  
<span style="margin-left: 2em">天際識歸舟句又誤謝朓爲謝靈運黃精鹿詩本</span>  
<!-- 册4 葉564a　Page:文淵閣四庫全書_0004冊.djvu/146 -->
<span style="margin-left: 2em">畫黃精與鹿乃引雷斆炮炙論黄精汁製鹿茸事</span>  
<span style="margin-left: 2em">皆爲舛誤又如紀夢詩引李白粲然啓玉齒句不</span>  
<span style="margin-left: 2em">知先見郭璞游仙詩游徑山詩引廣異記<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2854.svg?width=24" alt="四庫全書僻字第2854號（孤）" title="四庫全書僻字第2854號（孤）">雲兩</span>  
<span style="margin-left: 2em">角語不知先見辛氏三秦記端午詩引屈原飯筒</span>  
<span style="margin-left: 2em">事云初學記引齊諧記不知續齊諧記今本猶載</span>  
<span style="margin-left: 2em">此條皆爲未窮根柢其他訛漏之處爲近時馮應</span>  
<span style="margin-left: 2em">榴合註本所校補者亦復不少然考核地理訂正</span>  
<span style="margin-left: 2em">年月引據時事原原本本無不具有條理非惟邵</span>  
<span style="margin-left: 2em">註新本所不及卽施注原本亦出其下現行蘇詩</span>
