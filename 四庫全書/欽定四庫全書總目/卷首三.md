## 欽定四庫全書總目 卷首三　凡例

<!-- 册1 葉136a　Page:文淵閣四庫全書_0001冊.djvu/84 -->
欽定四庫全書總目卷首三  
<span style="margin-left: 1em">凡例<small>二十則</small></span>  
<span style="margin-left: 2em">一是書卷帙浩博爲亘古所無然每進一編必經</span>  
親覽宏綱巨目悉禀  
天裁定千載之是非决百家之疑似  
權衡獨運衮鉞斯昭  
睿鑒高深迥非諸臣管蠡之所及隨時  
訓示曠若發𫎇八載以來不能一一殫記謹錄厯次恭  
<span style="margin-left: 2em">奉</span>  
<!-- 册1 葉136b　Page:文淵閣四庫全書_0001冊.djvu/84 -->
聖諭爲一卷載諸簡端俾共知我  
皇上稽古右文功嫓删述懸諸日月昭示方來與厯代  
<span style="margin-left: 2em">官修之本泛稱御定者迥不相同</span>  
<span style="margin-left: 2em">一是書以經史子集提綱列目經部分十類史部</span>  
<span style="margin-left: 2em">分十五類子部分十四類集部分五類或流別繁</span>  
<span style="margin-left: 2em">碎者又分析子目使條理分明所錄諸書各以時</span>  
<span style="margin-left: 2em">代爲次其厯代帝王著作從隋書經籍志例冠各</span>  
<span style="margin-left: 2em">代之首至於</span>  
列朝聖製  
<!-- 册1 葉137a　Page:文淵閣四庫全書_0001冊.djvu/84 -->
皇上御撰揆以古例當弁冕全書而我  
皇上道秉大公義求至當以四庫所錄包括古今義在  
<span style="margin-left: 2em">衡鑒千秋非徒取尊崇</span>  
<span style="margin-left: 1em">昭代</span>  
特命各從門目弁於  
<span style="margin-left: 1em">國朝著述之前此尤</span>  
聖裁獨斷義愜理精非館臣所能仰贊一詞者矣  
<span style="margin-left: 2em">一前代藏書率無簡擇蕭蘭並擷珉玉雜陳殊未</span>  
<span style="margin-left: 2em">協別裁之義今</span>  
<!-- 册1 葉137b　Page:文淵閣四庫全書_0001冊.djvu/84 -->
詔求古籍  
特創新規一一辨厥妍媸嚴爲去取其上者悉登編錄  
<span style="margin-left: 2em">罔致遺珠其次者亦長短兼臚見瑕瑜之不掩其</span>  
<span style="margin-left: 2em">有言非立訓義或違經則附載其名兼匡厥繆至</span>  
<span style="margin-left: 2em">於尋常著述未越羣流雖咎譽之咸無究流傳之</span>  
<span style="margin-left: 2em">已久凖諸家著錄之例亦併存其目以備考核等</span>  
<span style="margin-left: 2em">差有辨旌別兼施自有典籍以來無如斯之博且</span>  
<span style="margin-left: 2em">精矣</span>  
<span style="margin-left: 2em">一自隋志以下門目大同小異互有出入亦各具</span>  
<!-- 册1 葉140a　Page:文淵閣四庫全書_0001冊.djvu/85 -->
<span style="margin-left: 2em">得失今擇善而從如詔令奏議文獻通考入集部</span>  
<span style="margin-left: 2em">今以其事關國政詔令從唐志例入史部奏議從</span>  
<span style="margin-left: 2em">漢志例亦入史部東都事略之屬不可入正史而</span>  
<span style="margin-left: 2em">亦不可入雜史者從宋史例立別史一門香譜䳸</span>  
<span style="margin-left: 2em">譜之屬舊志無所附麗强入農家今從尤袤遂初</span>  
<span style="margin-left: 2em">堂書目例立譜錄一門名家墨家縱橫家厯代著</span>  
<span style="margin-left: 2em">錄各不過一二種難以成帙今從黃虞稷千頃堂</span>  
<span style="margin-left: 2em">書目例併入雜家爲一門又別集之有詩無文者</span>  
<span style="margin-left: 2em">文獻通考別立詩集一門然則有文無詩者何不</span>  
<!-- 册1 葉140b　Page:文淵閣四庫全書_0001冊.djvu/85 -->
<span style="margin-left: 2em">別立文集一門多事區分徒滋繁碎今仍從諸史</span>  
<span style="margin-left: 2em">之例併爲別集一門又兼詁羣經者唐志題曰經</span>  
<span style="margin-left: 2em">解則不見其爲羣經朱𢑴尊經義考題曰羣經又</span>  
<span style="margin-left: 2em">不見其爲經解徐乾學通志堂所刻改名曰總經</span>  
<span style="margin-left: 2em">解何焯又譏其杜撰今取隋志之文名之曰五經</span>  
<span style="margin-left: 2em">總義凡斯之類皆務求典據非事更張</span>  
<span style="margin-left: 2em">一焦竑國史經籍志多分子目頗以餖飣爲嫌今</span>  
<span style="margin-left: 2em">酌乎其中惟經部之小學類史部之地理傳記政</span>  
<span style="margin-left: 2em">書三類子部之術數藝術譜錄雜家四類集部之</span>  
<!-- 册1 葉141a　Page:文淵閣四庫全書_0001冊.djvu/85 -->
<span style="margin-left: 2em">詞曲類流派至爲繁夥端緒易至茫如謹約分小</span>  
<span style="margin-left: 2em">學爲三子目地理爲九子目傳記爲五子目政書</span>  
<span style="margin-left: 2em">爲六子目術數爲七子目藝術譜錄各爲四子目</span>  
<span style="margin-left: 2em">雜家爲五子目詞曲爲四子目使條理秩然又經</span>  
<span style="margin-left: 2em">部之禮類史部之詔令奏議類目錄類子部之天</span>  
<span style="margin-left: 2em">文算法類小說家類亦各約分子目以便檢尋其</span>  
<span style="margin-left: 2em">餘瑣節槩爲删併</span>  
<span style="margin-left: 2em">一古來諸家著錄往往循名失實配𨽻乖宜不但</span>  
<span style="margin-left: 2em">崇文總目以𣗳萱錄入之種植爲鄭樵所譏今並</span>  
<!-- 册1 葉141b　Page:文淵閣四庫全書_0001冊.djvu/85 -->
<span style="margin-left: 2em">考校原書詳爲釐定如筆陣圖之屬舊入小學類</span>  
<span style="margin-left: 2em">今惟以論六書者入小學其論八法者不過筆札</span>  
<span style="margin-left: 2em">之工則改𨽻藝術羯鼓錄之屬舊入樂類今惟以</span>  
<span style="margin-left: 2em">論律吕者入樂其論管<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3500.svg?width=24" alt="四庫全書僻字第3500號（「絃」字少最後一點）" title="四庫全書僻字第3500號（「絃」字少最後一點）">工尺者不過世俗之音</span>  
<span style="margin-left: 2em">亦改𨽻藝術左傳類對賦之屬舊入春秋類今以</span>  
<span style="margin-left: 2em">其但取儷詞無關經義改𨽻類書孝經集靈舊入</span>  
<span style="margin-left: 2em">孝經類穆天子傳舊入起居注類山海經十洲記</span>  
<span style="margin-left: 2em">舊入地理類漢武帝内傳飛燕外傳舊入傳記類</span>  
<span style="margin-left: 2em">今以其或涉荒誕或涉鄙猥均改𨽻小說他如揚</span>  
<!-- 册1 葉144a　Page:文淵閣四庫全書_0001冊.djvu/86 -->
<span style="margin-left: 2em">雄太元經舊入儒家類今改𨽻術數俞琰易外別</span>  
<span style="margin-left: 2em">傳舊入易類今改𨽻道家又如倪石陵書名似子</span>  
<span style="margin-left: 2em">書而實文集陳埴木鍾集名似文集而實語錄凡</span>  
<span style="margin-left: 2em">斯之流不可殫述並一一考核務使不失其眞</span>  
<span style="margin-left: 2em">一諸書刋寫之本不一謹擇其善本錄之增删之</span>  
<span style="margin-left: 2em">本亦不一謹擇其足本錄之每書名之下欽遵</span>  
諭㫖各註某家藏本以不没所自其坊刻之書不可專  
<span style="margin-left: 2em">題一家者則註曰通行本至其編次先後漢書藝</span>  
<span style="margin-left: 2em">文志以高帝文帝所撰雜置諸臣之中殊爲非體</span>  
<!-- 册1 葉144b　Page:文淵閣四庫全書_0001冊.djvu/86 -->
<span style="margin-left: 2em">隋書經籍志以帝王各冠其本代於義爲允今從</span>  
<span style="margin-left: 2em">其例其餘槩以登第之年生卒之歲爲之排比或</span>  
<span style="margin-left: 2em">據所往來倡和之人爲次無可考者則附本代之</span>  
<span style="margin-left: 2em">末釋道閨閣亦各從時代不復區分宦寺之作雖</span>  
<span style="margin-left: 2em">不宜厠士大夫間然漢志小學家嘗收趙高之爰</span>  
<span style="margin-left: 2em">厯史游之急就今從其例亦間存一二外國之作</span>  
<span style="margin-left: 2em">前史罕載然旣歸王化卽屬外臣不必分疆絶界</span>  
<span style="margin-left: 2em">故木增鄭麟趾徐敬德之屬亦隨時代編入焉</span>  
<span style="margin-left: 2em">一諸書次序雖從其時代至於箋釋舊文則仍從</span>  
<!-- 册1 葉145a　Page:文淵閣四庫全書_0001冊.djvu/86 -->
<span style="margin-left: 2em">所註之書而不論作註之人如儒家類明曹端太</span>  
<span style="margin-left: 2em">極圖述解以註周子之書則列於張子全書前</span>  
<span style="margin-left: 1em">國朝李光地註解正𫎇以註張子之書則列於二程</span>  
<span style="margin-left: 2em">遺書前是也他如史記疑問附史記後班馬異同</span>  
<span style="margin-left: 2em">附漢書後之類亦同此例以便參考至於汪晫所</span>  
<span style="margin-left: 2em">輯之曾子子思子則仍列於朱吕柟所輯之周子</span>  
<span style="margin-left: 2em">鈔釋諸書則仍列於明葢雖裒輯舊文而實自爲</span>  
<span style="margin-left: 2em">著述與因原書而考辨者事理固不同也</span>  
<span style="margin-left: 2em">一劉向校理祕文每書具奏曾鞏刋定官本亦各</span>  
<!-- 册1 葉145b　Page:文淵閣四庫全書_0001冊.djvu/86 -->
<span style="margin-left: 2em">製序文然鞏好借題抒議往往冗長而本書之始</span>  
<span style="margin-left: 2em">末源流轉從疎畧王堯臣崇文總目晁公武郡齋</span>  
<span style="margin-left: 2em">讀書志陳振孫書錄解題稍具崖畧亦未詳明馬</span>  
<span style="margin-left: 2em">端臨經籍考薈稡羣言較爲賅博而兼收並列未</span>  
<span style="margin-left: 2em">能貫串折衷今於所列諸書各撰爲提要分之則</span>  
<span style="margin-left: 2em">散弁諸編合之則共爲總目每書先列作者之爵</span>  
<span style="margin-left: 2em">里以論世知人次考本書之得失權衆說之異同</span>  
<span style="margin-left: 2em">以及文字增删篇帙分合皆詳爲訂辨巨細不遺</span>  
<span style="margin-left: 2em">而人品學術之醇疵國紀朝章之法戒亦未嘗不</span>  
<!-- 册1 葉148a　Page:文淵閣四庫全書_0001冊.djvu/87 -->
<span style="margin-left: 2em">各昭彰癉用著勸懲其體例悉承</span>  
聖斷亦古來之所未有也  
<span style="margin-left: 2em">一四部之首各冠以總序撮述其源流正變以挈</span>  
<span style="margin-left: 2em">綱領四十三類之首亦各冠以小序詳述其分併</span>  
<span style="margin-left: 2em">改𨽻以析條目如其義有未盡例有未該則或於</span>  
<span style="margin-left: 2em">子目之末或於本條之下附註案語以明通變之</span>  
<span style="margin-left: 2em">由</span>  
<span style="margin-left: 2em">一厯代勅撰官書如周易正義之類承詔纂修不</span>  
<span style="margin-left: 2em">出一手一一詳其爵里則末大於本轉病繁冗故</span>  
<!-- 册1 葉148b　Page:文淵閣四庫全書_0001冊.djvu/87 -->
<span style="margin-left: 2em">今但記其成書年月任事姓名而不縷陳其爵里</span>  
<span style="margin-left: 2em">又如漢之賈董唐之李杜韓柳宋之歐蘇曾王以</span>  
<span style="margin-left: 2em">及韓范司馬諸名臣周程張朱諸道學其書並家</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2959.svg?width=24" alt="四庫全書僻字第2959號（弦）" title="四庫全書僻字第2959號（弦）">戸誦雖村塾童䜿皆能知其爲人其爵里亦不</span>  
<span style="margin-left: 2em">復贅至一人而著數書分見於各部中者其爵里</span>  
<span style="margin-left: 2em">惟見於第一部後但云某人有某書巳著錄以省</span>  
<span style="margin-left: 2em">重複如二書在一卷之中或數頁之内易於省記</span>  
<span style="margin-left: 2em">者則第二部但著其名<sub class="note-yuan">如明戴原禮巳見所校補朱震亨金匱鈎元條下其</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">推求師意二卷僅隔五條之類</sub></span>  
<!-- 册1 葉149a　Page:文淵閣四庫全書_0001冊.djvu/87 -->
<span style="margin-left: 2em">一劉勰有言意翻空而易奇詞徵實而難巧儒者</span>  
<span style="margin-left: 2em">說經論史其理亦然故說經主於明義理然不得</span>  
<span style="margin-left: 2em">其文字之訓詁則義理何自而推論史主於示褒</span>  
<span style="margin-left: 2em">貶然不得其事迹之本末則褒貶何據而定如成</span>  
<span style="margin-left: 2em">風爲魯僖公之母明載左傳而趙鵬飛春秋經筌</span>  
<span style="margin-left: 2em">謂不知爲莊公之妾爲僖公之妾是不知其人之</span>  
<span style="margin-left: 2em">名分可定其禮之得失乎劉子翼入唐爲著作郞</span>  
<span style="margin-left: 2em">宏文館直學士明載唐書劉禕之傳而朱子通鑑</span>  
<span style="margin-left: 2em">綱目書貞觀元年徵隋秘書劉子翼不至尹起莘</span>  
<!-- 册1 葉149b　Page:文淵閣四庫全書_0001冊.djvu/87 -->
<span style="margin-left: 2em">發明稱特書隋官以美之與陶潛稱晉一例是未</span>  
<span style="margin-left: 2em">知其人之始終可定其品之賢否乎今所錄者率</span>  
<span style="margin-left: 2em">以考證精核論辨明<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">爲主庶幾可謝彼虛談敦</span>  
<span style="margin-left: 2em">兹實學</span>  
<span style="margin-left: 2em">一文章流別厯代增新古來有是一家卽應立是</span>  
<span style="margin-left: 2em">一類作者有是一體卽應備是一格斯協於全書</span>  
<span style="margin-left: 2em">之名故釋道外教詞曲末技咸登簡牘不廢蒐羅</span>  
<span style="margin-left: 2em">然二氏之書必擇其可資考證者其經懴章咒並</span>  
<span style="margin-left: 2em">凛遵</span>  
<!-- 册1 葉152a　Page:文淵閣四庫全書_0001冊.djvu/88 -->
諭㫖一字不收宋人朱表靑詞亦槩從删削其倚聲塡  
<span style="margin-left: 2em">調之作如石孝友之金谷遺音張可久之小山小</span>  
<span style="margin-left: 2em">令<small>臣</small>等初以相傳舊本姑爲錄存並𫎇</span>  
皇上指示命從屏斥仰見  
大聖人敦崇風教釐正典籍之至意是以編輯雖富而  
<span style="margin-left: 2em">謹持繩墨去取不敢不嚴</span>  
<span style="margin-left: 2em">一聖賢之學主於明體以達用凡不可見諸實事</span>  
<span style="margin-left: 2em">者皆屬卮言儒生著書務爲高論陰陽太極累牘</span>  
<span style="margin-left: 2em">連篇斯巳不切人事矣至於論九河則欲修禹迹</span>  
<!-- 册1 葉152b　Page:文淵閣四庫全書_0001冊.djvu/88 -->
<span style="margin-left: 2em">考六典則欲復周官封建井田動稱三代而不揆</span>  
<span style="margin-left: 2em">時勢之不可行至黃諫之流欲使天下筆札皆改</span>  
<span style="margin-left: 2em">篆體顧炎武之流欲使天下言語皆作古音迂謬</span>  
<span style="margin-left: 2em">抑更甚焉又如明之曲士人喜言兵二麓正議欲</span>  
<span style="margin-left: 2em">掘坑藏錐以刺敵武備新書欲雕木爲虎以臨陣</span>  
<span style="margin-left: 2em">陳禹謨至欲使九邊將士人人皆讀左傳凡斯之</span>  
<span style="margin-left: 2em">類並闢其異說黜彼空言庶讀者知致遠經方務</span>  
<span style="margin-left: 2em">求爲有用之學</span>  
<span style="margin-left: 2em">一漢唐儒者謹守師說而巳自南宋至明凡說經</span>  
<!-- 册1 葉153a　Page:文淵閣四庫全書_0001冊.djvu/88 -->
<span style="margin-left: 2em">講學論文皆各立門戸大抵數名人爲之主而依</span>  
<span style="margin-left: 2em">草附木者囂然助之朋黨一分千秋吳越漸流漸</span>  
<span style="margin-left: 2em">遠并其本師之宗㫖亦失其傳而讐隙相尋操戈</span>  
<span style="margin-left: 2em">不巳名爲争是非實則争勝負也人心世道之害</span>  
<span style="margin-left: 2em">莫甚於斯伏讀</span>  
御題朱弁曲洧舊聞致遺憾於洛黨又  
御題顧憲成涇皋藏稿示炯戒於東林誠洞鑒情僞之  
<span style="margin-left: 2em">至論也我</span>  
<span style="margin-left: 1em">國家文敎昌明崇眞黜僞翔陽赫燿陰翳潛消巳盡</span>  
<!-- 册1 葉153b　Page:文淵閣四庫全書_0001冊.djvu/88 -->
<span style="margin-left: 2em">滌前朝之敝俗然防微杜漸不能不慮遠思深故</span>  
<span style="margin-left: 2em">甄別遺編皆一凖至公剷除畛㽣以預消芽蘗之</span>  
<span style="margin-left: 2em">萌至詩社之標榜聲名地志之矜誇人物浮辭塗</span>  
<span style="margin-left: 2em">飾不盡可憑亦併詳爲考訂務核其眞庶幾公道</span>  
<span style="margin-left: 2em">大彰俾尚論者知所勸戒</span>  
<span style="margin-left: 2em">一文章德行自孔門旣已分科兩擅厥長代不一</span>  
<span style="margin-left: 2em">二今所錄者如龔詡楊繼盛之文集周宗建黃道</span>  
<span style="margin-left: 2em">周之經解則論人而不論其書耿南仲之說易吳</span>  
<span style="margin-left: 2em">幵之評詩則論書而不論其人凡兹之類畧示變</span>  
<!-- 册1 葉156a　Page:文淵閣四庫全書_0001冊.djvu/89 -->
<span style="margin-left: 2em">通一則表章之公一則節取之義也至於姚廣孝</span>  
<span style="margin-left: 2em">之逃虛子集嚴嵩之鈐山堂詩雖詞華之美足以</span>  
<span style="margin-left: 2em">方軌文壇而廣孝則助逆興兵嵩則怙權蠧國繩</span>  
<span style="margin-left: 2em">以名義非止微瑕凡兹之流並著其見斥之由附</span>  
<span style="margin-left: 2em">存其目用見</span>  
聖朝彰善癉惡悉凖千秋之公論焉  
<span style="margin-left: 2em">一儒者著書往往各明一義或相反而適相成或</span>  
<span style="margin-left: 2em">相攻而實相救所謂言豈一端各有當也考古者</span>  
<span style="margin-left: 2em">無所别裁則多岐而太雜有所專主又膠執而過</span>  
<!-- 册1 葉156b　Page:文淵閣四庫全書_0001冊.djvu/89 -->
<span style="margin-left: 2em">偏左右佩劍均未協中今所採錄惟離經畔道顚</span>  
<span style="margin-left: 2em">倒是非者掊擊必嚴懷詐挾私熒惑視聽者屏斥</span>  
<span style="margin-left: 2em">必力至於闡明學術各擷所長品騭文章不名一</span>  
<span style="margin-left: 2em">格兼收並蓄如渤澥之納衆流庶不乖於全書之</span>  
<span style="margin-left: 2em">目</span>  
<span style="margin-left: 2em">一七畧所著古書卽多依託班固漢書藝文志註</span>  
<span style="margin-left: 2em">可覆按也遷流洎於明季譌妄彌增魚目混珠猝</span>  
<span style="margin-left: 2em">難究詰今一一詳核並斥而存目兼辨證其非其</span>  
<span style="margin-left: 2em">有本屬僞書流傳已久或掇拾殘剩眞贋相參厯</span>

<span style="margin-left: 2em">代詞人已引爲故實未可槩爲捐棄則姑錄存而</span>  
<span style="margin-left: 2em">辨别之大抵灼爲原帙者則題曰某代某人撰灼</span>  
<span style="margin-left: 2em">爲贋造者則題曰舊本題某代某人撰其踵誤傳</span>  
<span style="margin-left: 2em">訛如吕本中春秋傳舊本稱吕祖謙之類其例亦</span>  
<span style="margin-left: 2em">同至於其書雖厯代著錄而實一無可取如燕丹</span>  
<span style="margin-left: 2em">子陶潛聖賢羣輔錄之類經</span>  
聖鑒洞燭其妄者則亦斥而存目不使濫登  
<span style="margin-left: 2em">一九流自七畧以來卽已著錄然方技家遞相增</span>  
<span style="margin-left: 2em">益篇帙日繁往往僞妄荒唐不可究詰抑或卑𤨏</span>

<span style="margin-left: 2em">微末不足編摩今但就四庫所儲擇其稍古而近</span>  
<span style="margin-left: 2em">理者各存數種以見彼法之梗槩其所未備不復</span>  
<span style="margin-left: 2em">搜求葢</span>  
聖朝編錄遺文以闡聖學明王道者爲主不以百氏雜  
<span style="margin-left: 2em">學爲重也</span>  
<span style="margin-left: 2em">一是書主於考訂異同别白得失故辨駁之文爲</span>  
<span style="margin-left: 2em">多然大抵於衆說互殊者權其去取幽光未耀者</span>  
<span style="margin-left: 2em">加以表章至於馬班之史李杜之詩韓柳歐蘇之</span>  
<span style="margin-left: 2em">文章濂洛關閩之道學定論久孚無庸更贅一語</span>

<span style="margin-left: 2em">者則但論其刋刻傳寫之異同編次增删之始末</span>
