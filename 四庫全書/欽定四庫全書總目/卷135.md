## 欽定四庫全書總目 卷一百三十五　子部四十五　類書類一

<!-- 册3 葉3380：整葉圖版，無文字記錄 -->
<!-- 册3 葉3381a　Page:文淵閣四庫全書_0003冊.djvu/850 -->
欽定四庫全書總目卷一百三十五  
<span style="margin-left: 1em">子部四十五</span>  
<span style="margin-left: 2em">𩔖書𩔖一</span>  
<span style="margin-left: 3em">𩔖事之書兼收四部而非經非史非子非集四</span>  
<span style="margin-left: 3em">部之内乃無𩔖可歸皇覽始於魏文晉荀勗中</span>  
<span style="margin-left: 3em">經部分隸何門今蕪所考隋志載入子部當有</span>  
<span style="margin-left: 3em">所受之厯代相承莫之或易明胡應麟作筆叢</span>  
<span style="margin-left: 3em">始議改入集部然無所取義徒事紛更則不如</span>  
<span style="margin-left: 3em">仍舊貫矣此體一興而操觚者易於檢尋注書</span>  
<!-- 册3 葉3381b　Page:文淵閣四庫全書_0003冊.djvu/850 -->
<span style="margin-left: 3em">者利於剽竊輾轉稗販實學頗荒然古籍散亡</span>  
<span style="margin-left: 3em">十不存一遺文舊事往往託以得存藝文𩔖聚</span>  
<span style="margin-left: 3em">初學記太平御覽諸編殘璣斷璧至捃拾不窮</span>  
<span style="margin-left: 3em">要不可謂之無補也其專考一事如同姓名錄</span>  
<span style="margin-left: 3em">之𩔖者别無可附舊皆入之𩔖書今亦仍其例</span>  
古今同姓名錄二卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">梁孝元皇帝撰是書見於梁書本紀及隋書經籍</span>  
<span style="margin-left: 2em">志者皆作一卷唐陸善經續而廣之故讀書志書</span>  
<span style="margin-left: 2em">錄解題皆作三卷其本皆不傳此本爲永樂大典</span>  
<!-- 册3 葉3384a　Page:文淵閣四庫全書_0003冊.djvu/851 -->
<span style="margin-left: 2em">所載又元人葉森所増補者也雖輾轉附益已非</span>  
<span style="margin-left: 2em">其舊然幸其體例分明不相淆雜凡善經及森所</span>  
<span style="margin-left: 2em">綴入者皆一一標注尙可考見元帝之原本則類</span>  
<span style="margin-left: 2em">事之書莫古於是編矣史記淮陰侯列傳贊稱兩</span>  
<span style="margin-left: 2em">韓信此辨同姓名之始然劉知幾史通猶譏司馬</span>  
<span style="margin-left: 2em">遷全然不别班固曾無更張至遷不知有兩子我</span>  
<span style="margin-left: 2em">故以宰子爲預田恒之亂不知有兩公孫龍故以</span>  
<span style="margin-left: 2em">堅白同異之論傅合於孔門之弟子其人相混其</span>  
<span style="margin-left: 2em">事俱淆更至於語皆失實則辨析異同殊别時代</span>  
<!-- 册3 葉3384b　Page:文淵閣四庫全書_0003冊.djvu/851 -->
<span style="margin-left: 2em">亦未常非讀史之要務非但綴𤨏聞供談資也明</span>  
<span style="margin-left: 2em">萬厯中余寅别撰同姓名錄十二卷周應賔又補</span>  
<span style="margin-left: 2em">一卷</span>  
<span style="margin-left: 1em">國朝王廷燦又補八卷所錄比此本加詳然發凡起</span>  
<span style="margin-left: 2em">例終以此本爲椎輪之始焉</span>  
編珠二卷補遺二卷續編珠二卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">編珠二卷舊本題隋杜公瞻撰補遺二卷續編珠</span>  
<span style="margin-left: 2em">二卷則</span>  
<span style="margin-left: 1em">國朝康熙戊寅詹事府詹事錢塘高士奇所輯也案</span>  
<!-- 册3 葉3385a　Page:文淵閣四庫全書_0003冊.djvu/851 -->
<span style="margin-left: 2em">編珠隋志不載唐志但有杜公瞻荆楚嵗時記一</span>  
<span style="margin-left: 2em">卷而無此書宋志始著於錄然世無傳本始出於</span>  
<span style="margin-left: 2em">士竒家其序稱於</span>  
<span style="margin-left: 1em">内庫廢紙中得之原目凡四卷佚其半遍覔不可得</span>  
<span style="margin-left: 2em">輒因原目補爲四卷又廣其類之未具者爲二卷</span>  
<span style="margin-left: 2em">首載大業七年公瞻自序稱奉勅撰進其結銜題</span>  
<span style="margin-left: 2em">著作佐郞兼散騎侍郎又有徐乾學序稱杜公瞻</span>  
<span style="margin-left: 2em">無所表著談藪載隋京兆杜公瞻嘗邀楊玠過宅</span>  
<span style="margin-left: 2em">酒酣嘲謔者卽此公瞻無疑今觀其書隷事爲對</span>  
<!-- 册3 葉3385b　Page:文淵閣四庫全書_0003冊.djvu/851 -->
<span style="margin-left: 2em">畧如徐堅初學記之體但前無序事後無詩文原</span>  
<span style="margin-left: 2em">目分天地山川居處儀衞音樂器玩珍寳繒綵酒</span>  
<span style="margin-left: 2em">膳黍稷菜蔬果實車馬舟楫所存者音樂以上五</span>  
<span style="margin-left: 2em">門而已顧煬帝諱廣故廣川改長河廣雅改博雅</span>  
<span style="margin-left: 2em">而此書桂林水條下引廣州山川記治雞水條下</span>  
<span style="margin-left: 2em">引廣州記柏心桂條下引伏滔北征記稱廣陵縣</span>  
<span style="margin-left: 2em">城南門三條路條下引班固西都賦披三條之廣</span>  
<span style="margin-left: 2em">路隋高祖之父諱忠故隋書忠節改誠節而此書</span>  
<span style="margin-left: 2em">斬馬劍條下引漢書王莽斬董忠事此猶可曰臨</span>  
<!-- 册3 葉3388a　Page:文淵閣四庫全書_0003冊.djvu/852 -->
<span style="margin-left: 2em">文不諱未必盡拘又菖蒲海一條本與茱萸江爲</span>  
<span style="margin-left: 2em">對菖字從草無疑矣而條下所注乃引漢書西域</span>  
<span style="margin-left: 2em">傳于闐河與葱嶺合東流注菖蒲海今檢漢書乃</span>  
<span style="margin-left: 2em">蒲昌非菖蒲也唐以前書不應荒謬至此此尙可</span>  
<span style="margin-left: 2em">曰一時失記至於音樂門南城鼓一條引樂府解</span>  
<span style="margin-left: 2em">題曰鼓吹曲有巫山高戰城南則非惟文理未安</span>  
<span style="margin-left: 2em">且樂府解題一書古不著錄始見於崇文總目云</span>  
<span style="margin-left: 2em">不知撰人名氏列於吳兢樂府古題要解之後郭</span>  
<span style="margin-left: 2em">茂倩樂府詩集漢鐃歌上之囘篇引之<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">題曰吳</span>  
<!-- 册3 葉3388b　Page:文淵閣四庫全書_0003冊.djvu/852 -->
<span style="margin-left: 2em">兢雖未必<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">然其書晚出必非六朝舊籍無疑也</span>  
<span style="margin-left: 2em">公瞻安得而見之或明人所依托士竒偶未審歟</span>  
<span style="margin-left: 2em">楊士竒文淵閣書目張萱内閣書目俱不著錄永</span>  
<span style="margin-left: 2em">樂大典於前代𩔖書如四六叢珠截江網之𩔖無</span>  
<span style="margin-left: 2em">不具採亦不登其一字知其出明中葉以後矣以</span>  
<span style="margin-left: 2em">其採擷詞華頗爲鮮艶士奇所續亦皆取唐以前</span>  
<span style="margin-left: 2em">事較他𩔖書爲近古故疑以傳疑姑存以備叅考</span>  
<span style="margin-left: 2em">焉</span>  
藝文𩔖聚一百卷<sub class="note-yuan">内府藏本</sub>  
<!-- 册3 葉3389a　Page:文淵閣四庫全書_0003冊.djvu/852 -->
<span style="margin-left: 2em">唐歐陽詢撰詢字信本潭州臨湘人仕隋爲太常</span>  
<span style="margin-left: 2em">博士入唐官至太子率更令宏文閣學士事迹具</span>  
<span style="margin-left: 2em">唐書本傳是書據其自序葢亦奉詔所作唐書藝</span>  
<span style="margin-left: 2em">文志注令狐德棻袁朗趙宏智同修唐書詢本傳</span>  
<span style="margin-left: 2em">又稱武德七年詔與裴矩陳叔達同修殆以詢董</span>  
<span style="margin-left: 2em">其成故相傳但署詢名歟葉大慶考古質疑論其</span>  
<span style="margin-left: 2em">正月十五日有蘇味道夜遊詩洛水門有李嶠游</span>  
<span style="margin-left: 2em">洛詩寒食門有沈佺期宋之問詩四子皆後人歐</span>  
<span style="margin-left: 2em">陽安得預編之則傳寫又有所竄亂非盡詢等之</span>  
<!-- 册3 葉3389b　Page:文淵閣四庫全書_0003冊.djvu/852 -->
<span style="margin-left: 2em">舊也序稱流别文選專取其文皇覽徧畧<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">書其</span>  
<span style="margin-left: 2em">事文義旣殊尋檢難一是書比𩔖相從事居於前</span>  
<span style="margin-left: 2em">文列於後俾覽者易爲功作者資其用於諸類書</span>  
<span style="margin-left: 2em">中體例<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2866.svg?width=24" alt="四庫全書僻字第2866號（㝡）" title="四庫全書僻字第2866號（㝡）">善凡爲𩔖四十有八其中門目頗有繁</span>  
<span style="margin-left: 2em">簡失宜分合未當如山水部五岳存三四瀆缺一</span>  
<span style="margin-left: 2em">帝王部三國不錄蜀漢北朝惟載高齊儲宫部公</span>  
<span style="margin-left: 2em">主附太子而諸王别入職官雜文部附紙筆硯而</span>  
<span style="margin-left: 2em">武部外又别出刀匕首等爲軍器一門道路宜入</span>  
<span style="margin-left: 2em">地部壇宜入禮部而列之居處鍼宜入器物錢宜</span>  
<!-- 册3 葉3392a　Page:文淵閣四庫全書_0003冊.djvu/853 -->
<span style="margin-left: 2em">入寳玉而列之産業案几杖扇麈尾如意之𩔖宜</span>  
<span style="margin-left: 2em">入器物而列之服飾疾病宜入人部而列之方術</span>  
<span style="margin-left: 2em">夢魂魄亦宜入人部而列之靈異以及茱萸黃連</span>  
<span style="margin-left: 2em">入木部芙蓉菱藤入草部鴻之外又别出雁蚌之</span>  
<span style="margin-left: 2em">外又别出蛤鶴之外又别出黄鶴馬之外别出騊</span>  
<span style="margin-left: 2em">駼如斯之𩔖皆不免業脞少緖唐覲延州筆記嘗</span>  
<span style="margin-left: 2em">摘其所載徐陵玉臺新詠序謂以誄德爲累德傳</span>  
<span style="margin-left: 2em">訛自此書始考劉熙釋名誄者累也累其德行而</span>  
<span style="margin-left: 2em">述之也則詢書不誤誤乃在覲至王楙野客叢書</span>  
<!-- 册3 葉3392b　Page:文淵閣四庫全書_0003冊.djvu/853 -->
<span style="margin-left: 2em">摘其以漢書長陵一抔土事誤抔爲杯收入杯門</span>  
<span style="margin-left: 2em">又摘其蒲柳門中收趙高束蒲爲脯事云出史記</span>  
<span style="margin-left: 2em">史記無此文彭叔夏文苑英華辨證亦摘其引梁</span>  
<span style="margin-left: 2em">君射白雁事云出莊子莊子無其語則皆中其失</span>  
<span style="margin-left: 2em">然隋以前遺文秘籍迄今十九不存得此一書尙</span>  
<span style="margin-left: 2em">畧資考證宋周必大校文苑英華多引是集而近</span>  
<span style="margin-left: 2em">代馮惟訥詩紀梅鼎祚文紀張溥百三家集從此</span>  
<span style="margin-left: 2em">採岀者尤多亦所謂殘膏賸馥沾漑百代者矣</span>  
北堂書鈔一百六十卷<sub class="note-yuan">内府藏本</sub>  
<!-- 册3 葉3393a　Page:文淵閣四庫全書_0003冊.djvu/853 -->
<span style="margin-left: 2em">唐虞世南撰世南字伯施餘姚人官至銀靑光祿</span>  
<span style="margin-left: 2em">大夫宏文館學士諡文懿事蹟具唐書本傳北堂</span>  
<span style="margin-left: 2em">者秘書省之後堂此書葢世南在隋爲秘書郞時</span>  
<span style="margin-left: 2em">所作劉禹錫嘉話錄曰虞公之爲秘書於省後堂</span>  
<span style="margin-left: 2em">集羣書中事可爲文用者號爲北堂書鈔今北堂</span>  
<span style="margin-left: 2em">猶存而書鈔盛行於世云云是其事也分八十卷</span>  
<span style="margin-left: 2em">八百一𩔖唐志作一百七十三卷晁公武讀書志</span>  
<span style="margin-left: 2em">因之中興書目作一百六十卷宋史藝文志因之</span>  
<span style="margin-left: 2em">今本卷帙與中興書目同其地部至泥沙石而畢</span>  
<!-- 册3 葉3393b　Page:文淵閣四庫全書_0003冊.djvu/853 -->
<span style="margin-left: 2em">度非完帙豈原書在宋已有亡佚𫆀王應麟玉海</span>  
<span style="margin-left: 2em">云二館舊闕書鈔惟趙安仁家有本眞宗命内侍</span>  
<span style="margin-left: 2em">取之手詔褒美葢已甚珍其書矣此本爲明萬厯</span>  
<span style="margin-left: 2em">間常熟陳禹謨所校刻錢曾讀書敏求記云世行</span>  
<span style="margin-left: 2em">北堂書鈔攙亂増改無從訂正向聞嘉禾收藏家</span>  
<span style="margin-left: 2em">有原書尋訪十餘年而始得繙閱之令人心目朗</span>  
<span style="margin-left: 2em">然朱𢑴尊曝書亭集亦稱曾見大唐𩔖要百六十</span>  
<span style="margin-left: 2em">卷反覆觀之卽虞氏北堂書鈔今世所行者出陳</span>  
<span style="margin-left: 2em">禹謨刪補至以貞觀後事及五代十五國之書雜</span>  
<!-- 册3 葉3396a　Page:文淵閣四庫全書_0003冊.djvu/854 -->
<span style="margin-left: 2em">入其中盡失其舊𩔖要大畧出於原書世未易得</span>  
<span style="margin-left: 2em">云云葢明人好増刪古書逞臆私改其庸妄無識</span>

<span style="margin-left: 2em">要均已不可得見獨禹謨此本獨存其増加各條</span>
