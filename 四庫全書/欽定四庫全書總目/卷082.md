## 欽定四庫全書總目 卷八十二　史部三十八　政書類二

欽定四庫全書總目卷八十二  
<span style="margin-left: 1em">史部三十八</span>  
<span style="margin-left: 2em">政書𩔖二</span>  
漢官舊儀一卷補遺一卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">案永樂大典載漢官舊儀一卷不著撰人名氏考</span>  
<span style="margin-left: 2em">梁劉昭注續漢書百官志引用漢官儀則曰應劭</span>  
<span style="margin-left: 2em">引用漢舊儀則不著其名隋書經籍志唐書藝文</span>  
<span style="margin-left: 2em">志作四卷宋史藝文志作三卷書錄解題始作漢</span>  
<span style="margin-left: 2em">官舊儀注曰衛宏撰或云胡廣宏本傳作漢舊儀</span>  
<!-- 册2 葉2785b　Page:文淵閣四庫全書_0002冊.djvu/701 -->
<span style="margin-left: 2em">四篇以載西京雜事不名漢官今惟此三卷而又</span>  
<span style="margin-left: 2em">有漢官之目未知果當時本書否今按永樂大典</span>  
<span style="margin-left: 2em">此卷雖以漢官標題而篇目自皇帝起居皇后親</span>  
<span style="margin-left: 2em">蠶以及璽綬之等爵級之差靡不條繫件舉與宏</span>  
<span style="margin-left: 2em">傳所云西京雜事相合又前後漢書注中凡引用</span>  
<span style="margin-left: 2em">漢舊儀者並與此卷所載相同則其爲衛氏本書</span>  
<span style="margin-left: 2em">更無疑義或後人以其多載官制增題官字歟原</span>  
<span style="margin-left: 2em">本轉相傳寫節目淆亂字句舛訛殆不可韻兹據</span>  
<span style="margin-left: 2em">班范正史綜覈參訂以讞其疑其原有注者畧仿</span>  
<!-- 册2 葉2788a　Page:文淵閣四庫全書_0002冊.djvu/702 -->
<span style="margin-left: 2em">劉昭注百官志之例通爲大書稱本注以別之又</span>  
<span style="margin-left: 2em">考前後漢書紀志注中別有徵引舊儀數條並屬</span>  
<span style="margin-left: 2em">郊天祫祭耕籍飲酎諸大典此巻俱未採入葢流</span>  
<span style="margin-left: 2em">傳旣久脫佚者多謹復蒐擇甄錄別爲一篇附諸</span>  
<span style="margin-left: 2em">巻尾以補本書之未備云</span>  
大唐開元禮一百五十巻<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">唐太子太師同中書門下三品兼中書令蕭嵩等</span>  
<span style="margin-left: 2em">奉勅撰杜佑通典及新舊唐書禮志稱唐初禮司</span>  
<span style="margin-left: 2em">無定制遇有大事輒制一儀臨時專定開元中通</span>  
<!-- 册2 葉2788b　Page:文淵閣四庫全書_0002冊.djvu/702 -->
<span style="margin-left: 2em">事舍人王巖上疏請刪削禮記舊文益以今事集</span>  
<span style="margin-left: 2em">賢學士張說奏禮記不刋之書難以改易請取貞</span>  
<span style="margin-left: 2em">觀顯慶禮書折衷異同以爲唐禮乃詔右散𮪍常</span>  
<span style="margin-left: 2em">侍徐堅左拾遺李銳太常博士施敬本撰述厯年</span>  
<span style="margin-left: 2em">未就至蕭嵩爲學士復奏起居舍人王仲邱等撰</span>  
<span style="margin-left: 2em">次成書由是唐之五禮始備卽此本也其書巻一</span>  
<span style="margin-left: 2em">至巻三爲序例巻四至七十八爲吉禮巻七十九</span>  
<span style="margin-left: 2em">至八十爲賔禮巻八十一至九十爲軍禮巻九十</span>  
<span style="margin-left: 2em">一至一百三十爲嘉禮巻一百三十一至一百五</span>  
<!-- 册2 葉2789a　Page:文淵閣四庫全書_0002冊.djvu/702 -->
<span style="margin-left: 2em">十爲凶禮凶禮古居第二而退居第五者用貞觀</span>  
<span style="margin-left: 2em">顯慶舊制也貞元中詔以其書設科取士習者先</span>  
<span style="margin-left: 2em">授太常官以備講討則唐時已列之學官矣新舊</span>  
<span style="margin-left: 2em">唐書禮志皆取材是書而所存僅十之三四杜佑</span>  
<span style="margin-left: 2em">撰通典别載開元禮纂類三十五巻比唐志差詳</span>  
<span style="margin-left: 2em">而節目亦多未備其討論古今斟酌損益首末完</span>  
<span style="margin-left: 2em">具粲然勒一代典制者終不及原書之賅治故周</span>  
<span style="margin-left: 2em">必大序稱朝廷有大疑稽是書而可定國家有盛</span>  
<span style="margin-left: 2em">舉卽是書而可行誠攷禮者之圭臬也新唐書藝</span>  
<!-- 册2 葉2789b　Page:文淵閣四庫全書_0002冊.djvu/702 -->
<span style="margin-left: 2em">文志載修開元禮者尚有張烜陸善經洪孝昌諸</span>  
<span style="margin-left: 2em">人名而通典纂類中所載五獄四瀆名號及衣服</span>  
<span style="margin-left: 2em">一門間有與此書相出入者葢傳寫異文不能畫</span>  
<span style="margin-left: 2em">一旣未詳其孰是今亦並仍原本錄之不復竄改</span>  
<span style="margin-left: 2em">庶幾不失闕疑之義焉</span>  
諡法四巻<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋蘇洵撰洵字明允眉山人官秘書省校書郎以</span>  
<span style="margin-left: 2em">霸州文安縣主簿修太常因革禮書成而卒事迹</span>  
<span style="margin-left: 2em">具宋史本傳自周公諡法以後厯代言諡者有劉</span>  
<!-- 册2 葉2792a　Page:文淵閣四庫全書_0002冊.djvu/703 -->
<span style="margin-left: 2em">熙來奥沈約賀琛王彦威蘇冕扈𫎇之書然皆襍</span>  
<span style="margin-left: 2em">糅附益不爲典要至洵奉詔編定六家諡法乃取</span>  
<span style="margin-left: 2em">春秋廣諡及諸家之本刪訂考證以成是書凡所</span>  
<span style="margin-left: 2em">取一百六十八諡三百十一條新改者二十三條</span>  
<span style="margin-left: 2em">新補者十七條别有七去八類於舊文所有者刊</span>  
<span style="margin-left: 2em">削甚多其間如堯舜禹湯桀紂乃古帝王之名並</span>  
<span style="margin-left: 2em">非諡號而沿襲前訛槩行載入亦不免疎失然較</span>  
<span style="margin-left: 2em">之諸家義例要爲嚴整後鄭樵通志諡畧大都因</span>  
<span style="margin-left: 2em">此書而增補之且稱其斷然有所去取善惡有一</span>  
<!-- 册2 葉2792b　Page:文淵閣四庫全書_0002冊.djvu/703 -->
<span style="margin-left: 2em">定之論實前人所不及葢其斟酌損益審定字義</span>  
<span style="margin-left: 2em">皆<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">有根據故爲禮家所宗雖其中間收僻字今</span>  
<span style="margin-left: 2em">或不能盡見諸施行而厯代相傳之舊典猶可以</span>  
<span style="margin-left: 2em">備參考焉曾鞏作洵墓誌載此書作三卷而此本</span>  
<span style="margin-left: 2em">實四卷殆後人所分析歟</span>  
政和五禮新儀二百二十卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">宋議禮局官知樞宻院鄭居中等奉勅撰徽宗御</span>  
<span style="margin-left: 2em">製序文題政和新元三月一日葢政和改元之年</span>  
<span style="margin-left: 2em">錢曾讀書敏求記誤以新元爲心元遂以爲不知</span>  
<!-- 册2 葉2793a　Page:文淵閣四庫全書_0002冊.djvu/703 -->
<span style="margin-left: 2em">何解謬也前列局官隨時酌議科條及逐事御筆</span>  
<span style="margin-left: 2em">指揮次列御製冠禮葢當時頒此十卷爲格式故</span>  
<span style="margin-left: 2em">以冠諸篇次爲目錄六卷次爲序例二十四卷禮</span>  
<span style="margin-left: 2em">之綱也次爲吉禮一百一十一卷次爲賔禮二十</span>  
<span style="margin-left: 2em">一卷次爲軍禮八卷次爲嘉禮四十二卷升婚儀</span>  
<span style="margin-left: 2em">於冠儀前徽宗所定也次爲凶禮十四卷惟官民</span>  
<span style="margin-left: 2em">之制特詳焉是書頗爲朱子所不取自中興禮書</span>  
<span style="margin-left: 2em">旣出遂格不行故流傳絶少今本第七十四卷第</span>  
<span style="margin-left: 2em">八十八卷至九十卷第一百八卷至一百十二卷</span>  
<!-- 册2 葉2793b　Page:文淵閣四庫全書_0002冊.djvu/703 -->
<span style="margin-left: 2em">第一百二十八卷至一百三十七卷第二百卷皆</span>  
<span style="margin-left: 2em">有錄無書第七十五卷九十一卷九十二卷亦佚</span>  
<span style="margin-left: 2em">其半然北宋一代典章如開寶禮太常因革禮禮</span>  
<span style="margin-left: 2em">閣新儀今俱不傳中興禮書散見永樂大典中亦</span>  
<span style="margin-left: 2em">無完本惟是書僅存亦論掌故者所宜參考矣</span>  
紹熙州縣釋奠儀圖一卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">宋朱子撰考朱子年譜紹興二十五年乙亥官同</span>  
<span style="margin-left: 2em">安主簿以縣學釋奠舊例止以人吏行事求政和</span>  
<span style="margin-left: 2em">五禮新儀於縣無之乃取周禮儀禮唐開元禮紹</span>  
<!-- 册2 葉2796a　Page:文淵閣四庫全書_0002冊.djvu/704 -->
<span style="margin-left: 2em">興祀令更相參考畫成禮儀器用衣服等圖訓釋</span>  
<span style="margin-left: 2em">辨明纎微必備此釋奠禮之初稿也淳熙六年巳</span>  
<span style="margin-left: 2em">亥差知南康軍奏請頒降禮書又請增修禮書事</span>  
<span style="margin-left: 2em">未施行紹熙元年庚戌改知漳州復列上釋奠禮</span>  
<span style="margin-left: 2em">儀數事且移書禮官乃得頗爲討究時淳熙所鏤</span>  
<span style="margin-left: 2em">之板巳不復存後乃得於老吏之家又以議論不</span>  
<span style="margin-left: 2em">一越再歲始能定議而主其事者適徙他官遂格</span>  
<span style="margin-left: 2em">不下此釋奠禮之再修也紹熙五年甲寅除知潭</span>  
<span style="margin-left: 2em">州㑹前太常博士詹元善還爲太常少<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">始復取</span>  
<!-- 册2 葉2796b　Page:文淵閣四庫全書_0002冊.djvu/704 -->
<span style="margin-left: 2em">往年所被勅命下之本郡吏文繁複幾不可讀且</span>  
<span style="margin-left: 2em">曰屬有大典禮未遑徧下諸州時朱子方召還奏</span>  
<span style="margin-left: 2em">事又適病目乃力疾鉤校刪剔猥襍定爲四條以</span>  
<span style="margin-left: 2em">附州案俾移學官是爲最後之定稿卽此本也書</span>  
<span style="margin-left: 2em">首載淳熙六年禮部指揮一通尚書省指揮一通</span>  
<span style="margin-left: 2em">次紹熙五年牒潭州州學備准指揮一通皆具錄</span>  
<span style="margin-left: 2em">原文次州縣釋奠文宣王儀次禮器十九圖其所</span>  
<span style="margin-left: 2em">行儀節大抵採自杜氏通典及五禮新儀而折衷</span>  
<span style="margin-left: 2em">之後來二丁行事雖儀注少有損益而所據率本</span>  
<!-- 册2 葉2797a　Page:文淵閣四庫全書_0002冊.djvu/704 -->
<span style="margin-left: 2em">是書惟所列兩廡從祀位次有吕祖謙張栻則其</span>  
<span style="margin-left: 2em">事在理宗以後又有咸淳三年改定位次之文檢</span>  
<span style="margin-left: 2em">勘宋史禮志載咸淳詔書其先儒名數及東西次</span>  
<span style="margin-left: 2em">序與此書一一脗合與朱子益不相及葢後人隨</span>  
<span style="margin-left: 2em">時附益又非其原本矣</span>  
大金集禮四十卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">不著撰人名氏亦不著成書年月據黃虞稷千頃</span>  
<span style="margin-left: 2em">堂書目葢明昌六年禮部尚書張暐等所進今考</span>  
<span style="margin-left: 2em">書中紀事斷至大定知爲章宗時書虞稷所載當</span>  
<!-- 册2 葉2797b　Page:文淵閣四庫全書_0002冊.djvu/704 -->
<span style="margin-left: 2em">不誤也其書分類排纂具有條理自尊號册諡以</span>  
<span style="margin-left: 2em">及祠祀朝㑹燕饗諸儀燦然悉備以金史諸志相</span>  
<span style="margin-left: 2em">校其藍本全出於此而志文援引舛漏失其本意</span>  
<span style="margin-left: 2em">者頗多若祭方丘儀是書有前祭二日太尉告廟</span>  
<span style="margin-left: 2em">之儀而金史遺落不載又金史云設饌幕於内壝</span>  
<span style="margin-left: 2em">東門之外道北南向考之此書則陳設饌幕乃有</span>  
<span style="margin-left: 2em">東門西門二處葢壇上及神州東方南方之饌陳</span>  
<span style="margin-left: 2em">於東門外西方北方之饌陳於西門外金史獨載</span>  
<span style="margin-left: 2em">設於東門外者於禮爲舛如斯之類不一而足非</span>  
<!-- 册2 葉2800a　Page:文淵閣四庫全書_0002冊.djvu/705 -->
<span style="margin-left: 2em">得此書無以知史志之疎謬也則數金源之掌故</span>  
<span style="margin-left: 2em">者此爲總滙矣惟第十卷載夏至日祭方丘儀而</span>  
<span style="margin-left: 2em">圜丘郊天儀獨闕考金史自天德以後並祀南北</span>  
<span style="margin-left: 2em">郊大定明昌其制漸備編書者旣載北郊儀注不</span>  
<span style="margin-left: 2em">應反遺南郊葢傳寫脫佚非原書有所不備也</span>  
大金德運圖說一卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">金尙書省㑹官集議德運所存案牘之文也案金</span>  
<span style="margin-left: 2em">史本紀金初色尙白章宗泰和二年十一月更定</span>  
<span style="margin-left: 2em">德運爲土臘月辰詔告中外至宣宗貞祐二年正</span>
