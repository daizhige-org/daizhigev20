## 欽定四庫全書總目 卷七十九　史部三十五　職官類

<!-- 册2 葉2600：整葉圖版，無文字記錄 -->

欽定四庫全書總目巻七十九  
<span style="margin-left: 1em">史部三十五</span>  
<span style="margin-left: 2em">職官類</span>  
<span style="margin-left: 3em">前代官制史多著錄然其書恒不傳南唐書徐</span>  
<span style="margin-left: 3em">鍇傳稱後主得齊職制其書罕覯惟鍇知之今</span>  
<span style="margin-left: 3em">亦無舉其名者世所稱述周官以外惟唐六典</span>  
<span style="margin-left: 3em">最古耳蓋建官爲百度之綱其名品職掌史志</span>  
<span style="margin-left: 3em">必撮舉大凡足備叅考故本書繁重反爲人所</span>  
<span style="margin-left: 3em">倦觀且惟議政廟堂乃稽舊典其間如元豐變</span>  
<!-- 册2 葉2601b　Page:文淵閣四庫全書_0002冊.djvu/655 -->
<span style="margin-left: 3em">法事不數逢故著述之家或通是學而無所用</span>  
<span style="margin-left: 3em">習者少則傳者亦稀焉今所採錄大扺唐宋以</span>  
<span style="margin-left: 3em">來一曹一司之舊事與儆戒訓誥之詞今釐爲</span>  
<span style="margin-left: 3em">官制官箴二子目亦足以攷稽掌故激勸官方</span>  
<span style="margin-left: 3em">明人所著率類州縣志書則等之自鄶矣</span>  
唐六典三十巻<sub class="note-yuan">浙江汪汝瑮家藏本</sub>  
<span style="margin-left: 2em">唐元宗明皇帝御𢰅李林甫奉勅注其書以三師</span>  
<span style="margin-left: 2em">三公三省九寺五監十二衞列其職司官佐敘其</span>  
<span style="margin-left: 2em">品秩以擬周禮書錄解題引韋述集賢記注曰開</span>  
<!-- 册2 葉2604a　Page:文淵閣四庫全書_0002冊.djvu/656 -->
<span style="margin-left: 2em">元十年起居舍人陸堅被旨修是書帝手寫白麻</span>  
<span style="margin-left: 2em">紙六條曰理敎禮政刑事令以類相從𢰅錄以進</span>  
<span style="margin-left: 2em">張說以其事委徐堅思之經歲莫能定又委毋焸</span>  
<span style="margin-left: 2em">徐欽韋述始以令式入六司其沿革並入注中後</span>  
<span style="margin-left: 2em">張九齡又委苑咸二十六年奏草上迄今在<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">院</span>  
<span style="margin-left: 2em">亦不行用程大昌雍錄則曰唐世制度凡最皆在</span>  
<span style="margin-left: 2em">六典或曰書成未嘗頒用今案㑹要則牛僧孺奏</span>  
<span style="margin-left: 2em">升諫議爲三品用六典也貞元二年定著朝班次</span>  
<span style="margin-left: 2em">序每班以尚書省官爲首用六典也又其年竇叅</span>  
<!-- 册2 葉2604b　Page:文淵閣四庫全書_0002冊.djvu/656 -->
<span style="margin-left: 2em">論祠祭當以監察涖之亦援六典也此類殆不勝</span>  
<span style="margin-left: 2em">述草制之官每入院必首索六典則時制盡在故</span>  
<span style="margin-left: 2em">也二說截然不同考吕温集有代陳相公請刪定</span>  
<span style="margin-left: 2em">施行六典開元禮狀一篇稱宣示中外星紀六周</span>  
<span style="margin-left: 2em">未有明詔施行遂使䘮祭冠昏家猶疑禮等威名</span>  
<span style="margin-left: 2em">分國靡成規請於常叅官内𨕖學藝優敏者三五</span>  
<span style="margin-left: 2em">人就集賢院各盡異同量加刪定然後特降德音</span>  
<span style="margin-left: 2em">明下有司云云與韋述之言相合唐人所說當無</span>  
<span style="margin-left: 2em">訛誤大昌所引諸事疑當時討論典章亦相引據</span>  
<!-- 册2 葉2605a　Page:文淵閣四庫全書_0002冊.djvu/656 -->
<span style="margin-left: 2em">而公私科律則未嘗事事遵用如明代之㑹典云</span>  
<span style="margin-left: 2em">爾范祖禹唐鑑論其旣有太尉司徒司空又有尚</span>  
<span style="margin-left: 2em">書省是政出於二也旣有尚書省又有九寺是政</span>  
<span style="margin-left: 2em">出於三也蓋自唐虞至周有六官而無寺監自秦</span>  
<span style="margin-left: 2em">迄陳有寺監而無六官獨此書兼之故官多重複</span>  
<span style="margin-left: 2em">今考是書如林甫注中以諸州祥瑞預立條格以</span>  
<span style="margin-left: 2em">待奏報之類誠爲可<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2753.svg?width=24" alt="四庫全書僻字第2753號（嗤）" title="四庫全書僻字第2753號（嗤）">然一代典章釐然具備祖</span>  
<span style="margin-left: 2em">禹之所論或以元豐官制全祖是書有所激而云</span>  
<span style="margin-left: 2em">然歟又唐㑹要載開元二十三年九齡等𢰅是書</span>  
<!-- 册2 葉2605b　Page:文淵閣四庫全書_0002冊.djvu/656 -->
<span style="margin-left: 2em">而唐書載九齡以開元二十四年罷知政事則書</span>  
<span style="margin-left: 2em">成時九齡猶在位後至二十七年林甫乃注成獨</span>  
<span style="margin-left: 2em">上之宋陳騤館閣錄載書局有經修經進經修不</span>  
<span style="margin-left: 2em">經進經進不經修三格說與九齡皆所謂經修不</span>  
<span style="margin-left: 2em">經進者巻首獨著林甫蓋卽此例今亦姑仍舊本</span>  
<span style="margin-left: 2em">書之不復追改焉</span>  
翰林志一巻<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">唐李肇𢰅案肇所作國史補結銜題尚書左司郎</span>  
<span style="margin-left: 2em">中此書結銜則題翰林學士左補闕王定保摭言</span>  
<!-- 册2 葉2608a　Page:文淵閣四庫全書_0002冊.djvu/657 -->
<span style="margin-left: 2em">又稱肇爲元和中中書舍人新唐書藝文志亦云</span>  
<span style="margin-left: 2em">肇爲翰林學士坐薦柏耆自中書舍人左遷將作</span>  
<span style="margin-left: 2em">少監以唐官制考之葢自左司改補闕入翰林後</span>  
<span style="margin-left: 2em">爲中書舍人坐事左遷國史補及此書各題其作</span>  
<span style="margin-left: 2em">書時官也唐時翰林院在銀臺門内麟德殿西重</span>  
<span style="margin-left: 2em">廊之後爲待詔之所新唐書百官志謂乘輿所在</span>  
<span style="margin-left: 2em">必有文詞經學之士下至卜醫伎術之流皆<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">於</span>  
<span style="margin-left: 2em">別院以備燕見者是也韋執誼翰林院故事亦謂</span>  
<span style="margin-left: 2em">其地乃天下以藝能𠆸術見召者之所處蓋其始</span>  
<!-- 册2 葉2608b　Page:文淵閣四庫全書_0002冊.djvu/657 -->
<span style="margin-left: 2em">本以延引雜流原非爲文學侍從而設至明皇置</span>  
<span style="margin-left: 2em">翰林待詔供奉與集賢學士分掌制誥其職始重</span>  
<span style="margin-left: 2em">後又改爲學士別置學士院謂之東翰林院於是</span>  
<span style="margin-left: 2em">舊翰林院雖尚有以伎能入<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">如德宗時術士桑</span>  
<span style="margin-left: 2em">道茂之類而翰林之名實盡歸於學士院厯代相</span>  
<span style="margin-left: 2em">沿遂爲儒臣定職肇此書成於元和十四年唐宋</span>  
<span style="margin-left: 2em">藝文志皆著於錄其記載賅備本末粲然於一代</span>  
<span style="margin-left: 2em">詞臣職掌最爲詳晰宋洪遵輯翰苑羣書巳經收</span>  
<span style="margin-left: 2em">入今以言翰林典故者莫古於是書故仍錄專本</span>  
<!-- 册2 葉2609a　Page:文淵閣四庫全書_0002冊.djvu/657 -->
<span style="margin-left: 2em">以存其朔焉</span>  
麟臺故事五巻<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋程俱𢰅俱字致道衢州開化人舉進士試南宫</span>  
<span style="margin-left: 2em">第一廷試中甲科厯官徽猷閣待制封新安縣伯</span>  
<span style="margin-left: 2em">事蹟具宋史文苑𫝊玉海載元祐中宋匪躬作館</span>  
<span style="margin-left: 2em">閣錄紹興元年程俱上麟臺故事淳熙四年陳騤</span>  
<span style="margin-left: 2em">續爲館閣錄葢一代翰林故實具是三書今宋錄</span>  
<span style="margin-left: 2em">已亡陳錄僅存而亦稍譌闕是書則自明以來惟</span>  
<span style="margin-left: 2em">說郛載有數條別無傳本今考永樂大典徵引是</span>  
<!-- 册2 葉2609b　Page:文淵閣四庫全書_0002冊.djvu/657 -->
<span style="margin-left: 2em">書者特多排比其文猶可成帙其書多記宋初之</span>  
<span style="margin-left: 2em">事典章文物燦然可觀葢紹興元年初復秘書省</span>  
<span style="margin-left: 2em">首以俱爲少監故俱爲是書得諸官府舊章最爲</span>  
<span style="margin-left: 2em">詳備如束都事畧邢昺傳載由侍讀學士遷工部</span>  
<span style="margin-left: 2em">侍郎不著加中散大夫宋綬傳載召試中書不著</span>  
<span style="margin-left: 2em">遷大理評事宋史韓琦傳載由通判淄州入<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">集</span>  
<span style="margin-left: 2em">賢院不著爲太常寺丞及太子中允王陶傳載爲</span>  
<span style="margin-left: 2em">太子中允不著編校昭文館書籍孫洙傳亦不著</span>  
<span style="margin-left: 2em">洙嘗爲於潛令及編校秘閣書籍而皆見於是書</span>  
<!-- 册2 葉2612a　Page:文淵閣四庫全書_0002冊.djvu/658 -->
<span style="margin-left: 2em">又如玉海引謝泌傳泌上言請分四庫書籍人掌</span>  
<span style="margin-left: 2em">一庫事在端拱初而其一百六十八卷又載此事</span>  
<span style="margin-left: 2em">於天聖五年前後自相剌謬據此書所載則在咸</span>  
<span style="margin-left: 2em">平之初又續通鑑長編載咸平二年七月甲寅幸</span>  
<span style="margin-left: 2em">國子監還幸崇文院而此日之後又有癸丑則是</span>  
<span style="margin-left: 2em">月之内不容先有甲寅顯然牴牾據是書乃是七</span>  
<span style="margin-left: 2em">月甲辰如此之類凡百餘條皆足以考證異同補</span>  
<span style="margin-left: 2em">綴疎畧於掌故深爲有禆原書文獻通考作五巻</span>  
<span style="margin-left: 2em">今所裒錄仍符此數疑當時全部收之通考又稱</span>  
<!-- 册2 葉2612b　Page:文淵閣四庫全書_0002冊.djvu/658 -->
<span style="margin-left: 2em">凡十二篇而不詳其篇目其見於永樂大典者有</span>  
<span style="margin-left: 2em">官聨職掌廪祿三門皆與陳騤書標題相合疑騤</span>  
<span style="margin-left: 2em">書卽因俱舊目修之今卽以騤之篇目分隸諸條</span>  
<span style="margin-left: 2em">莫不一一條貫無所齟齬亦可謂神明煥然頓還</span>  
<span style="margin-left: 2em">舊觀矣騤錄載曝書㑹餞㑹及大宴學士院三條</span>  
<span style="margin-left: 2em">俱云出麟臺故事然引其事不載其詞殆姚廣孝</span>  
<span style="margin-left: 2em">等排纂之時刋除重複誤削前而存後當時編輯</span>  
<span style="margin-left: 2em">無緖卽此可見一端今亦無從補入惟俱北山集</span>  
<span style="margin-left: 2em">中載有後序一篇並附錄之以存其舊焉</span>  
<!-- 册2 葉2613a　Page:文淵閣四庫全書_0002冊.djvu/658 -->
翰苑羣書十二卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">宋洪遵編遵字景嚴鄱陽人皓之仲子也與兄适</span>  
<span style="margin-left: 2em">同中紹興十二年博學鴻詞科賜進士出身厯官</span>  
<span style="margin-left: 2em">徽猷閣<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">學士出知平江府孝宗時召除翰林學</span>  
<span style="margin-left: 2em">士承旨拜同知樞宻院事江東安撫使資政殿學</span>  
<span style="margin-left: 2em">士提舉洞霄宫卒諡文安事蹟具宋史本傳是書</span>  
<span style="margin-left: 2em">後有乾道九年遵題記曰翰苑秩淸地近㳂唐及</span>  
<span style="margin-left: 2em">今爲薦紳榮遵世蒙國恩父子兄弟接武而進爲</span>  
<span style="margin-left: 2em">千載幸遇曩嘗稡遺事一編朅來建業以家舊藏</span>  
<!-- 册2 葉2613b　Page:文淵閣四庫全書_0002冊.djvu/658 -->
<span style="margin-left: 2em">李肇元稹韋處厚韋執誼楊鉅丁居晦洎我宋數</span>  
<span style="margin-left: 2em">公凡有紀於此併刋之木仍以國朝年表中興題</span>  
<span style="margin-left: 2em">名附陳振孫書錄解題曰自李肇而下十一家及</span>  
<span style="margin-left: 2em">年表中興後題名共爲一書此本上卷爲李肇翰</span>  
<span style="margin-left: 2em">林志元稹承旨學士院記韋處厚翰林學士記韋</span>  
<span style="margin-left: 2em">執誼翰林院故事楊鉅翰林學士院舊䂓丁居晦</span>  
<span style="margin-left: 2em">重修承旨學士壁記李昉禁林宴㑹集凡七家下</span>
