## 欽定四庫全書總目 卷六十五　史部二十一　史鈔類、史鈔類存目

<!-- 册2 葉1648a　Page:文淵閣四庫全書_0002冊.djvu/417 -->
欽定四庫全書總目巻六十五  
<span style="margin-left: 1em">史部二十一</span>  
<span style="margin-left: 2em">史鈔類</span>  
<span style="margin-left: 3em">帝魁以後書凡三千二百四十篇孔子刪取百</span>  
<span style="margin-left: 3em">篇此史鈔之祖也宋志始自立門然隋志雜史</span>  
<span style="margin-left: 3em">類中有史要十巻註漢桂陽太守衛颯撰約史</span>  
<span style="margin-left: 3em">記要言以類相從又有三史畧二十巻吳太子</span>  
<span style="margin-left: 3em">太傅張温撰嗣後專鈔一史者有葛洪漢書鈔</span>  
<span style="margin-left: 3em">三十巻張緬晉書鈔三十巻合鈔衆史者有阮</span>  
<!-- 册2 葉1648b　Page:文淵閣四庫全書_0002冊.djvu/417 -->
<span style="margin-left: 3em">孝緒正史削繁九十四巻則其來巳古矣沿及</span>  
<span style="margin-left: 3em">宋代又增四例通鑑總類之類則離析而編纂</span>  
<span style="margin-left: 3em">之十七史詳節之類則簡汰而刋削之史漢精</span>  
<span style="margin-left: 3em">語之類則採摭文句而存之兩漢博聞之類則</span>  
<span style="margin-left: 3em">割裂詞藻而次之迨乎明季彌衍餘風趨簡易</span>  
<span style="margin-left: 3em">利剽竊史學荒矣要其含咀英華刪除冗贅卽</span>  
<span style="margin-left: 3em">韓愈所稱記事提要之義不以末流蕪濫責及</span>  
<span style="margin-left: 3em">本始也博取約存亦資循覽若倪思班馬異同</span>  
<span style="margin-left: 3em">惟品文字婁機班馬字類惟明音訓及三國志</span>  
<!-- 册2 葉1649a　Page:文淵閣四庫全書_0002冊.djvu/417 -->
<span style="margin-left: 3em">文類總滙文章者則各從本類不列此門</span>  
兩漢博聞十二巻<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明嘉靖中黄省曾刋本不著撰人名氏案晁公武</span>  
<span style="margin-left: 2em">讀書志乃宋楊侃所編也侃錢塘人端拱中進士</span>  
<span style="margin-left: 2em">官至集賢院學士晚爲知制誥避眞宗舊諱更名</span>  
<span style="margin-left: 2em">大稚是編摘錄前後漢書不依篇第不分門類惟</span>  
<span style="margin-left: 2em">簡擇其字句故事列爲標目而節取顔師古及章</span>  
<span style="margin-left: 2em">懐太子注列於其下凡前漢書七巻後漢書五巻</span>  
<span style="margin-left: 2em">雖於史學無關然較他類書摭採雜說者究爲雅</span>  
<!-- 册2 葉1649b　Page:文淵閣四庫全書_0002冊.djvu/417 -->
<span style="margin-left: 2em">馴後漢書中間有引及前漢書者必標顔師古字</span>  
<span style="margin-left: 2em">而所引梁劉昭續漢志註乃與章懷註無别體例</span>  
<span style="margin-left: 2em">未免少疎至所列紀傳篇目亦徃徃名有訛舛然</span>  
<span style="margin-left: 2em">如四皓條下引顔師古註曰四皓稱號本起於此</span>  
<span style="margin-left: 2em">更無姓名可稱葢𨼆居之人匿迹遠害不自標顯</span>  
<span style="margin-left: 2em">秘其氏族故史傳無得而詳至於皇甫謐圈稱之</span>  
<span style="margin-left: 2em">徒及諸地理書說竟爲四人安姓字自相錯互語</span>  
<span style="margin-left: 2em">又不經班氏不載於書諸家皆臆說今並棄畧一</span>  
<span style="margin-left: 2em">無取焉云云明監本漢書註竟佚此條惟頼此書</span>  
<!-- 册2 葉1652a　Page:文淵閣四庫全書_0002冊.djvu/418 -->
<span style="margin-left: 2em">幸存則亦非無資考證者矣</span>  
通鑑總類二十巻<sub class="note-yuan">安徽廵撫採進本</sub>  
<span style="margin-left: 2em">宋沈樞撰樞字持要德淸人紹興間進士官至太</span>  
<span style="margin-left: 2em">子詹事光祿卿諡憲敏是書乃其致仕時所編取</span>  
<span style="margin-left: 2em">司馬光資治通鑑事迹仿冊府元龜之例分爲二</span>  
<span style="margin-left: 2em">百七十一門毎門各以事標題略依時代前後爲</span>  
<span style="margin-left: 2em">次亦間採光議論附之所分門目頗有繁碎如賞</span>  
<span style="margin-left: 2em">罰門外又立貶責功賞二門外戚門外又立貴戚</span>  
<span style="margin-left: 2em">一門近習門外又立寵倖一門𨼆逸門外又立高</span>  
<!-- 册2 葉1652b　Page:文淵閣四庫全書_0002冊.djvu/418 -->
<span style="margin-left: 2em">尙一門積善門外又立陰德一門者不一而足又</span>  
<span style="margin-left: 2em">如安重榮奏請踰分不過驕蹇乃以此一條别立</span>  
<span style="margin-left: 2em">僭竊一門則配隸不<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">東周下迄五代興廢不一</span>  
<span style="margin-left: 2em">乃獨取申徹論燕必亡黄<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3180.svg?width=24" alt="四庫全書僻字第3180號（泓）" title="四庫全書僻字第3180號（泓）">論燕必復二條立爲</span>  
<span style="margin-left: 2em">興廢一門則疎漏太甚然通鑑浩博猝難盡覽司</span>  
<span style="margin-left: 2em">馬光嘗言惟王勝之曾讀一過餘人不能數巻卽</span>  
<span style="margin-left: 2em">巳倦睡則採摭菁華區分事類使考古者易於檢</span>  
<span style="margin-left: 2em">尋其書雖陋亦不妨過而存之也嘉定中鋟板潮</span>  
<span style="margin-left: 2em">陽樓鑰嘗爲之序元至正中浙江行省重刋周伯</span>  
<!-- 册2 葉1653a　Page:文淵閣四庫全書_0002冊.djvu/418 -->
<span style="margin-left: 2em">琦又序之二人皆博物君子而肯以文章弁其首</span>  
<span style="margin-left: 2em">殆以操觚數典尙有一壺千金之用歟</span>  
南史識小錄八巻北史識小錄八巻<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 1em">國朝沈名蓀朱昆田同編名蓀字澗芳錢塘人昆田</span>  
<span style="margin-left: 2em">字文盎秀水人彛尊之子也是書倣兩漢博聞之</span>  
<span style="margin-left: 2em">例取南北二史摘其字句之鮮華事跡之新異者</span>  
<span style="margin-left: 2em">摘錄成編不分門目惟以原書次第臚列而各著</span>  
<span style="margin-left: 2em">其篇名亦不加訓釋惟括舉數字標目以原文載</span>  
<span style="margin-left: 2em">於其下著是語之緣起而巳文獻通考載陳正敏</span>  
<!-- 册2 葉1653b　Page:文淵閣四庫全書_0002冊.djvu/418 -->
<span style="margin-left: 2em">之言曰李延壽作南北史粗得作史之體故唐書</span>  
<span style="margin-left: 2em">本傳亦謂其刪略穢詞過本書遠甚然好述妖異</span>  
<span style="margin-left: 2em">兆祥謡䜟特爲繁猥又引司馬光之言亦謂李延</span>  
<span style="margin-left: 2em">壽書於禨祥詼嘲小事無所不載葢自沈約宋書</span>  
<span style="margin-left: 2em">以下大抵競標藻采務摭異聞詞每渉乎儷裁事</span>  
<span style="margin-left: 2em">或取諸小說延壽因仍舊習未盡湔除宜爲論者</span>  
<span style="margin-left: 2em">之所惜然揆以史體固曰稍乖至於賦手取材詩</span>  
<span style="margin-left: 2em">人隸事則樵蘇漁獵捃拾靡窮此譬如柟瘤爲病</span>  
<span style="margin-left: 2em">而製枕者反貴其文理也名蓀等擷其精華以備</span>  
<!-- 册2 葉1656a　Page:文淵閣四庫全書_0002冊.djvu/419 -->
<span style="margin-left: 2em">選用使遺文𤨏事披巻燦然其書雖作自近人其</span>  
<span style="margin-left: 2em">所採錄則皆唐以前事與藝文類聚諸書約畧相</span>  
<span style="margin-left: 2em">似存以備考愈於冗雜之類書多矣</span>  
<span style="margin-left: 1em">右史鈔類三部四十八巻皆文淵閣著錄</span>  
<span style="margin-left: 2em">史鈔類存目</span>  
史記法語八巻<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">宋洪邁編邁字景盧鄱陽人紹興乙丑中博學宏</span>  
<span style="margin-left: 2em">詞科官至端明殿學士諡文敏事迹具宋史本傳</span>  
<span style="margin-left: 2em">是編於史記百三十篇内自二字以上句法古雋</span>  
<!-- 册2 葉1656b　Page:文淵閣四庫全書_0002冊.djvu/419 -->
<span style="margin-left: 2em">者依次標岀亦間錄舊注葢與經子法語等編同</span>  
<span style="margin-left: 2em">以備修詞之用書錄解題載之類書類稱十八巻</span>  
<span style="margin-left: 2em">此本乃止八巻似非完書然巻末有題識一行云</span>  
<span style="margin-left: 2em">淳熙十二年二月刋於婺州是當時刋本實止八</span>  
<span style="margin-left: 2em">巻書錄解題所載衍一十字明矣</span>  
南朝史精語十巻<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">宋洪邁撰邁於諸書多有節本其所纂輯自經子</span>  
<span style="margin-left: 2em">至前漢皆曰法語自後漢至唐書皆曰精語此所</span>  
<span style="margin-left: 2em">摘宋齊梁陳四朝史中之語也凡宋書四巻齊書</span>  
<!-- 册2 葉1657a　Page:文淵閣四庫全書_0002冊.djvu/419 -->
<span style="margin-left: 2em">三巻梁書二巻陳書一巻其去取多不可解卽以</span>  
<span style="margin-left: 2em">巻首宋本紀考之如桓元與劉邁書有云北府人</span>  
<span style="margin-left: 2em">情云何近見劉云何所道乃獨摘北府人情云何</span>  
<span style="margin-left: 2em">句宋順帝反正詔曰故順聲一唱二溟巻波英風</span>  
<span style="margin-left: 2em">振路宸居淸翳乃獨摘二溟巻波句高祖北討加</span>  
<span style="margin-left: 2em">領征將軍司豫二州刺史以世子爲徐兖二州刺</span>  
<span style="margin-left: 2em">史下書有云今當奉辭西斾有事闗中弱嗣叨𫎇</span>  
<span style="margin-left: 2em">復忝今授乃獨摘復忝今授四字又如加高祖九</span>  
<span style="margin-left: 2em">錫䇿文駢詞麗句叠出不窮乃獨摘出藩入輔鋒</span>  
<!-- 册2 葉1657b　Page:文淵閣四庫全書_0002冊.djvu/419 -->
<span style="margin-left: 2em">無前對二句葢南宋最重詞科士大夫多節錄古</span>  
<span style="margin-left: 2em">書以備遣用其排比成編者則有王應麟玉海章</span>  
<span style="margin-left: 2em">俊卿山堂考索之流若巾箱祕本本非著書不幸</span>  
<span style="margin-left: 2em">而爲人所傳者則有如此類後人以其名重存之</span>  
<span style="margin-left: 2em">實非其志也惟其中所錄宋書本紀第一列傳第</span>  
<span style="margin-left: 2em">二第三志第四志反在列傳之後考劉知幾史通</span>  
<span style="margin-left: 2em">曰舊史以表志之帙分於紀傳之間降及蔚宗肇</span>  
<span style="margin-left: 2em">加𨤲革沈魏繼作相與因循今北監板魏書志在</span>  
<span style="margin-left: 2em">列傳後是其顯證與史通合而宋書則移其次第</span>  
<!-- 册2 葉1660a　Page:文淵閣四庫全書_0002冊.djvu/420 -->
<span style="margin-left: 2em">列於紀傳之間觀邁所序猶從古本知幾之言不</span>  
<span style="margin-left: 2em">妄是則可資考證之一端十巻之中惟此一節足</span>  
<span style="margin-left: 2em">取耳</span>  
十七史詳節二百七十三巻<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">宋吕祖謙編祖謙有古周易已著錄此葢其讀史</span>  
<span style="margin-left: 2em">時刪節備檢之本而建陽書坊爲刻而傳之者凡</span>  
<span style="margin-left: 2em">史記二十巻西漢書三十巻東漢書三十巻三國</span>  
<span style="margin-left: 2em">志二十巻晉書三十巻南史二十五巻北史二十</span>  
<span style="margin-left: 2em">八巻隋書二十巻唐書六十巻五代史十巻前冠</span>  
<!-- 册2 葉1660b　Page:文淵閣四庫全書_0002冊.djvu/420 -->
<span style="margin-left: 2em">以疆理世系紀年之圖所錄大抵隨時節抄不必</span>  
<span style="margin-left: 2em">盡出精要如東漢晉二史内四言贊語於本書巳</span>  
<span style="margin-left: 2em">屬贅拇駢枝乃一槩摘存殊爲冗襍又如北史紀</span>  
<span style="margin-left: 2em">傳爲隋代而作者業巳併入隋書乃獨四夷一𫝊</span>  
<span style="margin-left: 2em">仍及隋事而隋書内遂刪去之爲例亦間有不純</span>  
<span style="margin-left: 2em">然南宋諸儒大抵研究性命而輕視史學故朱子</span>  
<span style="margin-left: 2em">作貢舉私議欲分年試士以史記兩漢爲一科三</span>  
<span style="margin-left: 2em">國晉書南北史爲一科新舊唐書五代史爲一科</span>  
<span style="margin-left: 2em">葢虚談無實之𡚁朱子亦深慮之矣祖謙雖亦從</span>  
<!-- 册2 葉1661a　Page:文淵閣四庫全書_0002冊.djvu/420 -->
<span style="margin-left: 2em">事講學而淹通典籍不肯借程子玩物䘮志之說</span>  
<span style="margin-left: 2em">以文飾空疎故朱子稱其史學分外子細附存其</span>  
<span style="margin-left: 2em">目俾儒者知前人讀書必貫徹首尾卽一刪節之</span>  
<span style="margin-left: 2em">本而用功深至巳如此足以爲宋儒不廢史學之</span>  
<span style="margin-left: 2em">明證也</span>  
東漢精華十四巻<sub class="note-yuan">衍聖公孔昭煥家藏本</sub>  
<span style="margin-left: 2em">宋吕祖謙撰是編乃其兩漢精華之一卽范氏之</span>  
<span style="margin-left: 2em">書摘其要語而論之或比類以明之於光武明章</span>  
<span style="margin-left: 2em">和四帝紀尤爲詳悉所略者惟表志耳然不具事</span>
