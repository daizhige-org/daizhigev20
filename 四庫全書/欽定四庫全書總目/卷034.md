## 欽定四庫全書總目 卷三十四　經部三十四　五經總義類存目

欽定四庫全書總目卷三十四  
<span style="margin-left: 1em">經部三十四</span>  
<span style="margin-left: 2em">五經總義類存目</span>  
五經圖六卷<sub class="note-yuan">河南巡撫採進本</sub>  
<span style="margin-left: 2em">不著撰人名氏雍正癸卯襄城常定遠得明章達</span>  
<span style="margin-left: 2em">原本重刻達序稱是本得自盧侍御盧又得之信</span>  
<span style="margin-left: 2em">州鉛山爲鵞湖石刻本考明慮謙字黙存廬江人</span>  
<span style="margin-left: 2em">萬厯甲辰進士官至江西布政使參政初官永豐</span>  
<span style="margin-left: 2em">縣知縣時得信州學五經圖石本廬江縣知縣章</span>  
<!-- 册1 葉2752b　Page:文淵閣四庫全書_0001冊.djvu/738 -->
<span style="margin-left: 2em">達爲刻之其始末見李維禎序及謙孫雲英重編</span>  
<span style="margin-left: 2em">五經圖中此本稱章達刊當卽謙所傳信州石本</span>  
<span style="margin-left: 2em">也前有萬<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3771.svg?width=24" alt="四庫全書僻字第3771號（邦）" title="四庫全書僻字第3771號（邦）">榮序稱是書與信州石本對校前後</span>  
<span style="margin-left: 2em">參錯多所不同盖又有所<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2872.svg?width=24" alt="四庫全書僻字第2872號（竄）" title="四庫全書僻字第2872號（竄）">亂矣且原書兼圖周</span>  
<span style="margin-left: 2em">禮是以名爲六經此本仍存周禮諸圖而改題曰</span>  
<span style="margin-left: 2em">五經名實亦相舛迕又每經縮爲八頁而諸圖雜</span>  
<span style="margin-left: 2em">列其間大圖之餘隙卽塡小圖補之尤毫無體例</span>  
<span style="margin-left: 2em">矣</span>  
羣經辨疑錄三卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<!-- 册1 葉2753a　Page:文淵閣四庫全書_0001冊.djvu/738 -->
<span style="margin-left: 2em">明周洪謨撰洪謨字堯弼長寧人正統乙丑進士</span>  
<span style="margin-left: 2em">官至禮部尙書諡文安事蹟具明史本傳是編盖</span>  
<span style="margin-left: 2em">其官祭酒時與諸生講論之語凡辨正四書五經</span>  
<span style="margin-left: 2em">訓釋與經㫖違誤老百有四條又發明先儒言外</span>  
<span style="margin-left: 2em">之㫖者百有九條自序稱寧爲朱子忠臣無爲朱</span>  
<span style="margin-left: 2em">子佞臣成化十五年嘗䟽進於朝併請勅修諸經</span>  
<span style="margin-left: 2em">憲宗以大全諸書久爲學者所誦習不允所請觀</span>  
<span style="margin-left: 2em">此書頗可得其用意所在然其說以三光五行爲</span>  
<span style="margin-left: 2em">七政則不及古傳日月五星之確其辨周書八誥</span>  
<!-- 册1 葉2753b　Page:文淵閣四庫全書_0001冊.djvu/738 -->
<span style="margin-left: 2em">及蘇軾之說以爲思殷叛周者皆紂所比眤之罪</span>  
<span style="margin-left: 2em">人則於當時情事未合仍不及蘇傳之允當至謂</span>  
<span style="margin-left: 2em">社稷之神龍柱農棄以前仍當有所謂稷者其言</span>  
<span style="margin-left: 2em">雖似有理然亦無所依據至下卷則多屬空言益</span>  
<span style="margin-left: 2em">無所取矣</span>  
石渠意見四卷拾遺二卷補闕二卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明王恕撰恕有玩易意見已著錄考明史恕本傳</span>  
<span style="margin-left: 2em">其初致仕在成化二十二年孝宗立復召用後與</span>  
<span style="margin-left: 2em">邱濬不合求去以宏治六年閏五月復致仕自是</span>  
<!-- 册1 葉2756a　Page:文淵閣四庫全書_0001冊.djvu/739 -->
<span style="margin-left: 2em">家居凡十五年此本首篇自題云已未季秋據七</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">表當在宏治十二年則是書作於再致仕時故</span>  
<span style="margin-left: 2em">自序稱作意見時八十四作拾遺時八十六作補</span>  
<span style="margin-left: 2em">闕時八十八可謂耄而好學矣其書大意以五經</span>  
<span style="margin-left: 2em">四書傳註列在學官者於理或有未安故以已意</span>  
<span style="margin-left: 2em">詮解而筆記之間亦有所發明而語無考證純以</span>  
<span style="margin-left: 2em">臆測如謂左傳爲子貢等所作之類殊游談無根</span>  
<span style="margin-left: 2em">也</span>  
五經心義<sub class="note-yuan">無卷數　浙江巡撫採進本</sub>  
<!-- 册1 葉2756b　Page:文淵閣四庫全書_0001冊.djvu/739 -->
<span style="margin-left: 2em">明王崇慶撰崇慶有周易議卦已著錄此本又合</span>  
<span style="margin-left: 2em">所著書經說畧詩經衍義春秋斷義禮記約𫎇與</span>  
<span style="margin-left: 2em">議卦共爲一編唯周易無序餘皆有自序大抵皆</span>  
<span style="margin-left: 2em">剽掇舊文罕所心得</span>  
十三經解詁五十六卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明陳深撰深有周禮訓雋己著錄是編凡易三卷</span>  
<span style="margin-left: 2em">書三卷詩四卷周禮六卷儀禮四卷禮記十卷左</span>  
<span style="margin-left: 2em">傳十四卷公羊傳三卷穀梁傳二卷論語一卷孝</span>  
<span style="margin-left: 2em">經一卷爾雅三卷孟子二卷其易惟取程傳及本</span>  
<!-- 册1 葉2757a　Page:文淵閣四庫全書_0001冊.djvu/739 -->
<span style="margin-left: 2em">義各標其名書惟取孔傳蔡傳不復分别詩取小</span>  
<span style="margin-left: 2em">序及朱子集傳亦兼採子貢詩傳周禮分序官於</span>  
<span style="margin-left: 2em">各職之前使長屬相統用王應電本稱曰古本禮</span>  
<span style="margin-left: 2em">記増入夏小正一篇置曾子問前左傳主夏正之</span>  
<span style="margin-left: 2em">說謂用周正爲誣論語孝經孟子俱無註惟孟子</span>  
<span style="margin-left: 2em">加以評<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）">用世所稱蘇洵本餘亦皆鈔錄舊註無</span>  
<span style="margin-left: 2em">所發明</span>  
說經劄記六卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明蔡汝楠撰汝楠字子木號白石德淸人嘉靖壬</span>  
<!-- 册1 葉2757b　Page:文淵閣四庫全書_0001冊.djvu/739 -->
<span style="margin-left: 2em">辰進士官至南京工部侍郎明史文苑傳附見高</span>  
<span style="margin-left: 2em">叔嗣傳中是編說易說書說詩說春秋說禮記說</span>  
<span style="margin-left: 2em">論語說學庸說孟子各爲一卷末附太極問答數</span>  
<span style="margin-left: 2em">則史稱汝楠以憂歸聚諸生石鼓書院講求經義</span>  
<span style="margin-left: 2em">此書卽是時作也汝楠少嘗從湛若水游晚更友</span>  
<span style="margin-left: 2em">鄒守益羅洪先其學皆本於良知欲以治經爲治</span>  
<span style="margin-left: 2em">心之功故所說多如語錄罕博考之功云</span>  
五經異文十一卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">明陳士元撰士元有易象鈎解己著錄是編考訂</span>  
<!-- 册1 葉2760a　Page:文淵閣四庫全書_0001冊.djvu/740 -->
<span style="margin-left: 2em">五經文字異同大抵以許愼說文陸德明經典釋</span>  
<span style="margin-left: 2em">文爲主而捃摭雜說附益之其所援據頗爲寒窘</span>  
<span style="margin-left: 2em">如易本義坤初爻小象順當作愼詩集傳景古影</span>  
<span style="margin-left: 2em">字之類亦縷載之又如宋本恒之作𢘆避眞宗諱</span>  
<span style="margin-left: 2em">猶貞之作ခ避仁宗諱愼之作ဂ避孝宗諱而於</span>  
<span style="margin-left: 2em">恒卦注曰恒釋文作𢘆殊爲失考至雝雍一字而</span>  
<span style="margin-left: 2em">於書於變時雍注路史作時雝睂眉一字而於以</span>  
<span style="margin-left: 2em">介眉壽注呂氏讀詩記眉作睂益可以不必矣</span>  
五經繹十五卷<sub class="note-yuan">江西巡撫採進本</sub>  
<!-- 册1 葉2760b　Page:文淵閣四庫全書_0001冊.djvu/740 -->
<span style="margin-left: 2em">明鄧元錫撰元錫有三禮編繹己著錄是書凡易</span>  
<span style="margin-left: 2em">五卷書二卷詩三卷三禮四卷春秋一卷元錫先</span>  
<span style="margin-left: 2em">有三禮編繹二十卷別行故此編惟摘錄其中自</span>  
<span style="margin-left: 2em">作發明之語而刪其經文及註書詩春秋亦不載</span>  
<span style="margin-left: 2em">經文惟存篇目其所詮釋多屬空談易則雖載經</span>  
<span style="margin-left: 2em">文而頗更其次第如乾卦乾元亨利貞句下繼以</span>  
<span style="margin-left: 2em">大哉乾元至萬國咸寧五十七字又繼以元者善</span>  
<span style="margin-left: 2em">之長也至故曰乾元亨利貞六十四字又繼以乾</span>  
<span style="margin-left: 2em">元者至天下平也五十七字又繼以天行健十字</span>  
<!-- 册1 葉2761a　Page:文淵閣四庫全書_0001冊.djvu/740 -->
<span style="margin-left: 2em">乃繼以六爻及小象小象以後復繼以文言初九</span>  
<span style="margin-left: 2em">曰以下之文皆元錫以意更定其繋辭說卦序卦</span>  
<span style="margin-left: 2em">雜卦則全刪傳文而自撰天圖原等三卷以代之</span>  
<span style="margin-left: 2em">其憑臆杜撰亦畧與三禮編繹等也</span>  
經書音釋二卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">明馮保撰保字永亭號雙林深州人嘉靖中秉筆</span>  
<span style="margin-left: 2em">司禮太監隆慶及萬厯之初最用事事迹具明史</span>  
<span style="margin-left: 2em">宦官傳是編摭拾經典釋文說文廣韻諸書參以</span>  
<span style="margin-left: 2em">已意如解論語過則勿憚改憚字曰難也畏也則</span>  
<!-- 册1 葉2761b　Page:文淵閣四庫全書_0001冊.djvu/740 -->
<span style="margin-left: 2em">己詳於朱注解宓不齊宓字曰三國時秦宓人名</span>  
<span style="margin-left: 2em">則更與音釋無關至其鈔襲舛誤更不可枚舉末</span>  
<span style="margin-left: 2em">有隆慶辛未保自䟦其私印曰内翰之章尤可怪</span>  
<span style="margin-left: 2em">笑史稱保善琴能書是編當卽所自撰意當時士</span>  
<span style="margin-left: 2em">大夫憚其權𫝑必有從而譽之者故竟至於災梨</span>  
<span style="margin-left: 2em">其人其書本均不足存以趙高爰厯六篇漢志著</span>  
<span style="margin-left: 2em">錄故存其目亦以見明代貂璫之横至儼然以詞</span>  
<span style="margin-left: 2em">臣自居而無一人議之足爲萬世之炯戒也</span>  
孫月峯評經十六卷<sub class="note-yuan">江蘇周厚堉家藏本</sub>  
<!-- 册1 葉2764a　Page:文淵閣四庫全書_0001冊.djvu/741 -->
<span style="margin-left: 2em">明孫鑛撰鑛字文融月峯其號也萬厯甲戌進士</span>

<span style="margin-left: 2em">經不可僅以文論蘇洵評孟子本屬僞書謝枋得</span>  
<span style="margin-left: 2em">批<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）">檀弓亦非眞本鑛乃竟用評閱時文之式一</span>  
<span style="margin-left: 2em">一標舉其字句之法詞意纖仄鍾譚流派此已兆</span>

<span style="margin-left: 2em">其先聲矣今以其無類可歸姑附之五經總義類</span>

<span style="margin-left: 2em">已卯前有繼仕自序云得舊本摹校舊圖三百有</span>

<span style="margin-left: 2em">二十有七共爲圖五百四十有八所謂舊本卽毛</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3771.svg?width=24" alt="四庫全書僻字第3771號（邦）" title="四庫全書僻字第3771號（邦）">翰之書所謂儀禮圖卽楊復之書均非繼仕所</span>  
<span style="margin-left: 2em">自撰也</span>  
<!-- 册1 葉2765a　Page:文淵閣四庫全書_0001冊.djvu/741 -->
九經考異十二卷附九經逸語一卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">明周應賔撰應賔鄞縣人萬厯癸未進士官至禮</span>
