## 欽定四庫全書總目 卷一百九十八　集部五十一　詞曲類一

<!-- 册5 葉1120：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷一百九十八  
<span style="margin-left: 1em">集部五十一</span>  
<span style="margin-left: 2em">詞曲𩔖一</span>  
<span style="margin-left: 3em">詞曲二體在文章技藝之間厥品頗卑作者弗</span>  
<span style="margin-left: 3em">貴特才華之士以綺語相高耳然三百篇變而</span>  
<span style="margin-left: 3em">古詩古詩變而近體近體變而詞詞變而曲層</span>  
<span style="margin-left: 3em">累而降莫知其然究厥淵源實亦樂府之餘音</span>  
<span style="margin-left: 3em">風人之末派其於文苑尚屬附庸亦未可全斥</span>  
<span style="margin-left: 3em">爲俳優也今酌取往例附之篇終詞曲兩家又</span>  
<!-- 册5 葉1121b　Page:文淵閣四庫全書_0005冊.djvu/285 -->
<span style="margin-left: 3em">畧分甲乙詞爲五𩔖曰別集曰總集曰詞話曰</span>  
<span style="margin-left: 3em">詞譜詞韻曲則惟錄品題論斷之詞及中原音</span>  
<span style="margin-left: 3em">韻而曲文則不錄焉王圻續文獻通考以西廂</span>  
<span style="margin-left: 3em">記琵琶記俱入經籍𩔖中全失論撰之體裁不</span>  
<span style="margin-left: 3em">可訓也</span>  
珠玉詞一卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">宋晏殊撰殊有𩔖要已著錄陳振孫書錄解題載</span>  
<span style="margin-left: 2em">殊詞有珠玉集一卷此本爲毛晉所刻與陳氏所</span>  
<span style="margin-left: 2em">記合蓋猶舊本名臣錄稱殊詞名珠玉集張子野</span>  
<!-- 册5 葉1124a　Page:文淵閣四庫全書_0005冊.djvu/286 -->
<span style="margin-left: 2em">爲之序子野張先字也今卷首無先序蓋傳寫佚</span>  
<span style="margin-left: 2em">之矣殊賦性剛峻而詞語特婉麗故劉攽中山詩</span>  
<span style="margin-left: 2em">話謂元獻喜馮延已歌詞其所自作亦不減延已</span>  
<span style="margin-left: 2em">趙與旹賓退錄記殊幼子幾道嘗稱殊詞不作婦</span>  
<span style="margin-left: 2em">人語今觀其集綺豔之詞不少蓋幾道欲重其父</span>  
<span style="margin-left: 2em">名故作是言非<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">論也集中浣溪沙春恨詞無可</span>  
<span style="margin-left: 2em">奈何花落去似曾相識燕歸來二句乃殊示張寺</span>  
<span style="margin-left: 2em">丞王校勘七言律中腹聯復齋漫錄嘗述之今復</span>  
<span style="margin-left: 2em">塡入詞内豈自愛其造語之工故不嫌複用耶考</span>  
<!-- 册5 葉1124b　Page:文淵閣四庫全書_0005冊.djvu/286 -->
<span style="margin-left: 2em">唐許渾集中一罇酒盡青山暮千里書回碧樹秋</span>  
<span style="margin-left: 2em">二句亦前後兩見知古人原有此例矣</span>  
六一詞一卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">宋歐陽修撰修有詩本義已著錄其詞陳振孫書</span>  
<span style="margin-left: 2em">錄解題作一卷此爲毛晉所刻亦止一卷而於總</span>  
<span style="margin-left: 2em">目中註原本三卷葢廬陵舊刻兼載樂語分爲三</span>  
<span style="margin-left: 2em">卷晉刪去樂語仍併爲一卷也曾慥樂府雅詞序</span>  
<span style="margin-left: 2em">有云歐公一代儒宗風流自命詞章窈眇世所矜</span>  
<span style="margin-left: 2em">式乃小人或作艷曲謬爲公詞蔡絛西淸詩話云</span>  
<!-- 册5 葉1125a　Page:文淵閣四庫全書_0005冊.djvu/286 -->
<span style="margin-left: 2em">歐陽詞之淺近者謂是劉煇僞作名臣錄亦云修</span>  
<span style="margin-left: 2em">知貢舉爲下第舉子劉煇等所忌以醉蓬萊望江</span>  
<span style="margin-left: 2em">南誣之則修詞中已雜他人之作又元豐中崔公</span>  
<span style="margin-left: 2em">度䟦馮延已陽春錄謂其間有誤入六一詞者則</span>  
<span style="margin-left: 2em">修詞又或竄入他集葢在宋時已無定本矣晉此</span>  
<span style="margin-left: 2em">刻亦多所釐正然諸選本中有梅堯臣少年遊闌</span>  
<span style="margin-left: 2em">干十二獨凭春一首吳曾能改齋漫錄獨引爲修</span>  
<span style="margin-left: 2em">詞且云不惟聖俞君復二詞不及雖求諸唐人温</span>  
<span style="margin-left: 2em">李集中殆難與之爲一則堯臣當别有詞此詞斷</span>  
<!-- 册5 葉1125b　Page:文淵閣四庫全書_0005冊.djvu/286 -->
<span style="margin-left: 2em">當屬修晉未收此詞尚不能無所闕漏又如越溪</span>  
<span style="margin-left: 2em">春結語沈麝不燒金鴨玲瓏月照梨花係六字二</span>  
<span style="margin-left: 2em">句集内尚沿坊本誤玲爲冷瓏爲籠遂以七字爲</span>  
<span style="margin-left: 2em">句是校讐亦未盡無訛然終較他刻爲稍善故今</span>  
<span style="margin-left: 2em">從其本焉</span>  
樂章集一卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">宋柳永撰永初名三變字耆卿崇安人景祐元年</span>  
<span style="margin-left: 2em">進士官至屯田員外郞故世號柳屯田葉夢得避</span>  
<span style="margin-left: 2em">署錄話曰柳永爲舉子時多游狹斜善爲歌詞教</span>  
<!-- 册5 葉1128a　Page:文淵閣四庫全書_0005冊.djvu/287 -->
<span style="margin-left: 2em">坊樂工每得新腔必求永爲詞始行於世余仕丹</span>  
<span style="margin-left: 2em">徒嘗見一西夏歸朝官云凡有井水飮處卽能歌</span>  
<span style="margin-left: 2em">柳詞言其傳之廣也張端義貴耳集亦曰項平齋</span>  
<span style="margin-left: 2em">言詩當學杜詩詞當學柳詞杜詩柳詞皆無表德</span>  
<span style="margin-left: 2em">只是實說云云葢詞本管<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3500.svg?width=24" alt="四庫全書僻字第3500號（「絃」字少最後一點）" title="四庫全書僻字第3500號（「絃」字少最後一點）">冶蕩之音而永所作</span>  
<span style="margin-left: 2em">旖旎近情故使人易入雖頗以俗爲病然好之者</span>  
<span style="margin-left: 2em">終不絶也陳振孫書錄解題載其樂章集三卷今</span>  
<span style="margin-left: 2em">止一卷葢毛晉刋本所合并宋人詞之傳於今者</span>  
<span style="margin-left: 2em">惟此集最爲殘缺晉此刻亦殊少勘正訛不勝乙</span>  
<!-- 册5 葉1128b　Page:文淵閣四庫全書_0005冊.djvu/287 -->
<span style="margin-left: 2em">其分調之顯然舛誤者如笛家别久二字小鎭西</span>  
<span style="margin-left: 2em">久離缺三字小鎭西犯路遼遶三字臨江仙蕭條</span>  
<span style="margin-left: 2em">二字皆係後段换頭今乃截作前段結句字句之</span>  
<span style="margin-left: 2em">顯然舛誤者如尾犯之一種芳心力芳字當作勞</span>  
<span style="margin-left: 2em">浪淘沙慢之幾度飮散歌闌闌字當作闋如何時</span>  
<span style="margin-left: 2em">如字當作知浪淘沙令之有一箇人人一字屬衍</span>  
<span style="margin-left: 2em">促盡隨紅袖舉促字下缺拍字破陣樂之各明珠</span>  
<span style="margin-left: 2em">各字下脫採字定風波之拘束教吟咏咏字當叶</span>  
<span style="margin-left: 2em">韻作和字鳯歸雲之霜月夜夜字下脫明字如魚</span>  
<!-- 册5 葉1129a　Page:文淵閣四庫全書_0005冊.djvu/287 -->
<span style="margin-left: 2em">水之蘭芷汀洲望中中字當作裏望遠行之亂飄</span>  
<span style="margin-left: 2em">僧舍宻灑歌樓二句上下倒置紅窻睡之如削肌</span>  
<span style="margin-left: 2em">膚紅玉瑩句已屬叶韻下又誤增峯字河傳之露</span>  
<span style="margin-left: 2em">淸江芳交亂淸字當改淨塞鴻之漸西風𦂳𦂳字</span>  
<span style="margin-left: 2em">屬衍訴衷情之不堪更𠋣木蘭木蘭二字當作蘭</span>  
<span style="margin-left: 2em">棹夜半樂之嫩紅光數光字當作無金歛爭笑賭</span>  
<span style="margin-left: 2em">歛字當作<img class="rare-char" src="https://commons.wikimedia.org/w/thumb.php?f=SKQSfont2.pdf&page=164&w=24" alt="四庫全書僻字第二表第164號（（⿰釒义）-- 釵）" title="四庫全書僻字第二表第164號（（⿰釒义）-- 釵）">萬樹作詞律嘗駁正之今並從其說</span>  
<span style="margin-left: 2em">其必不可通者則疑以𫝊疑姑仍其舊焉</span>  
安陸集一卷<sub class="note-yuan">兵部侍郞紀昀家藏本</sub>  
<!-- 册5 葉1129b　Page:文淵閣四庫全書_0005冊.djvu/287 -->
<span style="margin-left: 2em">宋張先撰案仁宗時有兩張先皆字子野其一博</span>  
<span style="margin-left: 2em">州人樞宻副使張遜之孫天聖三年進士官至知</span>  
<span style="margin-left: 2em">亳州卒於寶元二年歐陽修爲作墓誌者是也其</span>  
<span style="margin-left: 2em">一烏程人天聖八年進士官至都官郞中卽作此</span>  
<span style="margin-left: 2em">集者是也道山淸話竟以博州張先爲此張先誤</span>  
<span style="margin-left: 2em">之甚矣張鐸湖州府志稱先有文集一百卷惟樂</span>  
<span style="margin-left: 2em">府行於世宋史藝文志載先詩集二十卷陳振孫</span>  
<span style="margin-left: 2em">十詠圖䟦稱偶藏子野詩一帙名安陸集舊京本</span>  
<span style="margin-left: 2em">也鄉守楊嗣翁見之因取刻之郡齋云云<sub class="note-yuan">案此䟦載周宻</sub></span>  
<!-- 册5 葉1132a　Page:文淵閣四庫全書_0005冊.djvu/288 -->
<span style="margin-left: 2em"><sub class="note-yuan">齊東野語</sub>則振孫時其集尚存然振孫作<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">齋書錄解</span>  
<span style="margin-left: 2em">題乃惟載張子野詞一卷而無其詩集殊不解其</span>  
<span style="margin-left: 2em">何故也自明以來併其詞集亦不傳故毛晉刻六</span>  
<span style="margin-left: 2em">十家詞獨不及先此本乃近時安邑葛鳴陽所輯</span>  
<span style="margin-left: 2em">凡詩八首詞六十八首其編次雖以詩列詞前而</span>  
<span style="margin-left: 2em">爲數無幾今從其多者爲主錄之於詞曲𩔖中考</span>  
<span style="margin-left: 2em">蘇軾集有題張子野詩集後曰子野詩筆老妙歌</span>  
<span style="margin-left: 2em">詞乃其餘技耳華州西溪詩云浮萍破處見山影</span>  
<span style="margin-left: 2em">野艇歸時聞草聲<sub class="note-yuan">案石林詩話瀛奎律髓草聲並誤作棹聲近時安邑葛氏刊本</sub></span>  
<!-- 册5 葉1132b　Page:文淵閣四庫全書_0005冊.djvu/288 -->
<span style="margin-left: 2em"><sub class="note-yuan">據漁隱叢話改正今從之</sub>與余和詩云愁似鰥魚知夜永懶同</span>  
<span style="margin-left: 2em">蝴蝶爲春忙若此之𩔖皆可以追配古人而世俗</span>  
<span style="margin-left: 2em">但稱其歌詞昔周昉畫人物皆入神品而世俗但</span>  
<span style="margin-left: 2em">知有周昉士女皆所謂未見好德如好色者歟云</span>  
<span style="margin-left: 2em">云然軾所舉二聯皆涉纎巧自此二聯外今所傳</span>  
<span style="margin-left: 2em">者惟吳江一首稍可觀然欲圖江色不上筆静覓</span>  
<span style="margin-left: 2em">鳥聲深在蘆一聯亦有纎巧之病平心而論要爲</span>  
<span style="margin-left: 2em">詞勝於詩當時以張三影得名殆非無故軾所題</span>  
<span style="margin-left: 2em">䟦當由好爲高論未可據爲定評也</span>  
<!-- 册5 葉1133a　Page:文淵閣四庫全書_0005冊.djvu/288 -->
東坡詞一卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">宋蘇軾撰軾有易𫝊巳著錄宋史藝文志載軾詞</span>  
<span style="margin-left: 2em">一卷書錄解題則稱東坡詞二卷此本乃毛晉所</span>  
<span style="margin-left: 2em">刻後有晉䟦云得金陵刊本凡混入黄晁秦柳之</span>  
<span style="margin-left: 2em">作俱經芟去然刊削尙有未盡者如開卷陽關曲</span>  
<span style="margin-left: 2em">三首已載入詩集之中乃餞李公擇絶句其曰以</span>  
<span style="margin-left: 2em">小秦王歌之者乃唐人歌詩之法宋代失傳惟小</span>  
<span style="margin-left: 2em">秦王調近絶句故借其聲律以歌之非別有詞調</span>  
<span style="margin-left: 2em">謂之陽關曲也使當時有陽關曲一調則必自有</span>  
<!-- 册5 葉1133b　Page:文淵閣四庫全書_0005冊.djvu/288 -->
<span style="margin-left: 2em">本調之宫律何必更借小秦王乎以是收之詞集</span>  
<span style="margin-left: 2em">未免泛濫至集中念奴嬌一首朱𢑴尊詞綜據容</span>  
<span style="margin-left: 2em">齋隨筆所載黃庭堅手書本改浪淘盡爲浪聲沈</span>  
<span style="margin-left: 2em">多情應笑我早生華髮爲多情應是我笑生華髮</span>  
<span style="margin-left: 2em">因謂浪淘盡三字於調不協多情句應上四下五</span>  
<span style="margin-left: 2em">然考毛开此調如筭無地䦘風頂皆作仄平仄豈</span>  
<span style="margin-left: 2em">可俱謂之未協石孝友此調云九重頻念此衮衣</span>  
<span style="margin-left: 2em">華髮周紫芝此調云白頭應記得尊前傾蓋亦何</span>
