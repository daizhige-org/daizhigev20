## 欽定四庫全書總目 卷九十五　子部五　儒家類存目一

<!-- 册3 葉289a　Page:文淵閣四庫全書_0003冊.djvu/77 -->
欽定四庫全書總目巻九十五  
<span style="margin-left: 1em">子部五</span>  
<span style="margin-left: 2em">儒家𩔖存目一</span>  
孔子家語註八巻<sub class="note-yuan">湖南廵撫採進本</sub>  
<span style="margin-left: 2em">明何孟春撰孟春有何文簡疏議巳著錄古本家</span>  
<span style="margin-left: 2em">語久佚今本家語撰自王肅其註亦肅所作名註</span>  
<span style="margin-left: 2em">古書實自註也故其本於諸家爲善然明代罕傳</span>  
<span style="margin-left: 2em">至崇禎末毛晉始得北宋本刻之故崇禎以前明</span>  
<span style="margin-left: 2em">人無見舊本者孟春以元王廣謀家語註庸陋荒</span>  
<!-- 册3 葉289b　Page:文淵閣四庫全書_0003冊.djvu/77 -->
<span style="margin-left: 2em">昧又正文多所漏畧乃爲此註其考訂補綴不爲</span>  
<span style="margin-left: 2em">無功而由未見肅註故臆測亦所不免其序謂今</span>  
<span style="margin-left: 2em">本不同於唐未必非廣謀之妄庸有所刪除其論</span>  
<span style="margin-left: 2em">近理而近時重刋孟春註者因顔師古註漢書藝</span>  
<span style="margin-left: 2em">文志家語條下有非今所有家語之文遂謂唐以</span>  
<span style="margin-left: 2em">前本業巳不同烏知孟春所據非古本案師古但</span>  
<span style="margin-left: 2em">云唐時家語非古家語不云其時别有古家語也</span>  
<span style="margin-left: 2em">隋志孔子家語二十一巻王肅註梁有當家語二</span>  
<span style="margin-left: 2em">巻魏博士張融撰亡舊唐書經籍志孔子家語十</span>  
<!-- 册3 葉292a　Page:文淵閣四庫全書_0003冊.djvu/78 -->
<span style="margin-left: 2em">巻王肅註新唐書藝文志亦同孟春安得古家語</span>  
<span style="margin-left: 2em">此假借之詞非篤論也至近本所校補孟春闕誤</span>  
<span style="margin-left: 2em">凡數百條皆引據精<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">則孟春是註它舛漏抑可</span>  
<span style="margin-left: 2em">知矣</span>  
家語正義十巻<sub class="note-yuan">江蘇廵撫採進本</sub>  
<span style="margin-left: 1em">國朝姜兆錫撰兆錫有周易本義述藴巳著錄是書</span>  
<span style="margin-left: 2em">首列至聖年表正譌其四十四篇之次則從<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3575.svg?width=24" alt="四庫全書僻字第3575號（葛）" title="四庫全書僻字第3575號（葛）">鼐</span>  
<span style="margin-left: 2em">本以正論與三典禮篇爲巻九以本姓終記與七</span>  
<span style="margin-left: 2em">十二弟子篇爲巻十案明毛晉汲古閣本自跋謂</span>  
<!-- 册3 葉292b　Page:文淵閣四庫全書_0003冊.djvu/78 -->
<span style="margin-left: 2em">初從吳興賈人得一編乃北宋王肅注本惜二巻</span>  
<span style="margin-left: 2em">十六葉以前皆蠧繼從錫山酒家得一函亦宋刻</span>  
<span style="margin-left: 2em">王氏注也所逸者僅末二巻因𢚩倩能書者一補</span>  
<span style="margin-left: 2em">其首一補其尾二冊儼然䨇璧縱未必夫子舊堂</span>  
<span style="margin-left: 2em">壁中故物巳不失王肅本注矣是汲古閣刋本其</span>  
<span style="margin-left: 2em">篇目次第胥仍王本之舊卽徐𤊹家宋本家語亦</span>  
<span style="margin-left: 2em">僅與毛本小異不云巻目有所易置也兆錫乃從</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3575.svg?width=24" alt="四庫全書僻字第3575號（葛）" title="四庫全書僻字第3575號（葛）">鼐之本竄亂舊次殊爲勇於變古其訓釋亦似</span>  
<span style="margin-left: 2em">俗下講章之體不足以資考證</span>  
<!-- 册3 葉293a　Page:文淵閣四庫全書_0003冊.djvu/78 -->
孔叢子正義五巻<sub class="note-yuan">江蘇廵撫採進本</sub>  
<span style="margin-left: 1em">國朝姜兆錫撰是編卽世傳孔叢子刪去連叢子上</span>  
<span style="margin-left: 2em">下篇又刪去小爾雅詰墨二篇但以記孔氏言行</span>  
<span style="margin-left: 2em">者編爲五巻毎條之下畧仿詩序之例註曰此言</span>  
<span style="margin-left: 2em">某義也謂之正義其中偶有考訂者如納於大錄</span>  
<span style="margin-left: 2em">作大錄萬幾之政此自舊說而引蔡沈傳以駁之</span>  
<span style="margin-left: 2em">其他凡引經與宋儒傳注不合者悉謂之斷章未</span>  
<span style="margin-left: 2em">免拘墟之見至於子順說趙王以歸齊尸助嫪毐</span>  
<span style="margin-left: 2em">以存魏國兆錫亦頗疑之然徃徃回䕶其詞不肯</span>  
<!-- 册3 葉293b　Page:文淵閣四庫全書_0003冊.djvu/78 -->
<span style="margin-left: 2em">竟斥爲依託也</span>  
曾子全書三巻<sub class="note-yuan">江蘇周厚堉家藏本</sub>  
<span style="margin-left: 2em">明曾承業編承業爲曾子六十二代孫序稱博士</span>  
<span style="margin-left: 2em">葢襲職之宗子也案宋汪晫嘗輯曾子一巻分十</span>  
<span style="margin-left: 2em">二篇割裂補綴巳非唐以來之舊本是編又分主</span>  
<span style="margin-left: 2em">言一篇爲巻一修身事父母制言上中下疾病天</span>  
<span style="margin-left: 2em">圓七篇爲巻二本孝立孝大孝三篇爲巻三與王</span>  
<span style="margin-left: 2em">應麟玉海所云今十篇自修身至天圓皆見於大</span>  
<span style="margin-left: 2em">戴禮者又多出主言一篇而分合逈異不知其何</span>  
<!-- 册3 葉296a　Page:文淵閣四庫全書_0003冊.djvu/79 -->
<span style="margin-left: 2em">所依據殆亦以意爲之也</span>  
忠經一巻<sub class="note-yuan">江蘇廵撫採進本</sub>  
<span style="margin-left: 2em">舊本題漢馬融撰鄭元註其文擬孝經爲十八章</span>  
<span style="margin-left: 2em">經與註如出一手考融所述作具載後漢書本傳</span>  
<span style="margin-left: 2em">元所訓釋載於鄭志目錄尤詳孝經註依托於元</span>  
<span style="margin-left: 2em">劉知幾尙設十二騐以辨之其文具載唐會要烏</span>  
<span style="margin-left: 2em">有所謂忠經註哉隋志唐志皆不著錄崇文總目</span>  
<span style="margin-left: 2em">始列其名其爲宋代僞書殆無疑義玉海引宋兩</span>  
<span style="margin-left: 2em">朝志載有海鵬忠經然則此書本有撰人原非贋</span>  
<!-- 册3 葉296b　Page:文淵閣四庫全書_0003冊.djvu/79 -->
<span style="margin-left: 2em">造後人詐題馬鄭掩其本名轉使眞本變僞耳</span>  
女孝經一巻<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">唐鄭氏撰鄭氏朝散郞侯莫陳邈之妻侯莫陳三</span>  
<span style="margin-left: 2em">字複姓也前載進書表稱姪女冊爲永王妃因作</span>  
<span style="margin-left: 2em">此以戒唐書藝文志不載宋史藝文志始載之宣</span>  
<span style="margin-left: 2em">和畫譜載孟昶時有石恪畫女孝經像八則五代</span>  
<span style="margin-left: 2em">時乃盛行於世也其書倣孝經分十八章章首皆</span>  
<span style="margin-left: 2em">假班大家以立言進表所謂不敢自專因以班大</span>  
<span style="margin-left: 2em">家爲主其文甚明陳振孫書錄解題<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">以爲班昭</span>  
<!-- 册3 葉297a　Page:文淵閣四庫全書_0003冊.djvu/79 -->
<span style="margin-left: 2em">所撰誤之甚矣</span>  
千秋金鑑錄一巻<sub class="note-yuan">江蘇周厚堉家藏本</sub>  
<span style="margin-left: 2em">舊本題唐張九齡撰按王士禎皇華紀聞曰隆慶</span>  
<span style="margin-left: 2em">閒曲江刻張文獻千秋金鑑錄一巻又僞撰序表</span>  
<span style="margin-left: 2em">平湖陸世楷爲南雄守著論辨之此等謬僞凡畧</span>  
<span style="margin-left: 2em">識之無者亦不肯爲而粤中新刻曲江文集竟收</span>  
<span style="margin-left: 2em">入故孝山謂𢚩應火其書碎其板云云今此書序</span>  
<span style="margin-left: 2em">中所謂非吾子孫不得記錄非人而傳必遭刑憲</span>  
<span style="margin-left: 2em">學則素衣之人爲上達不學則赭衣之人爲白士</span>  
<!-- 册3 葉297b　Page:文淵閣四庫全書_0003冊.djvu/79 -->
<span style="margin-left: 2em">此錄一千年後方許流布諸語皆與世楷所指駁</span>  
<span style="margin-left: 2em">者合士禎又言别有金鑑錄一册乃嘉靖間文獻</span>  
<span style="margin-left: 2em">裔孫張希祖所撰康熙甲辰曲江令凌作聖重刻</span>  
<span style="margin-left: 2em">士禎所摘謬妄不經之處如安祿山爲野猪之精</span>  
<span style="margin-left: 2em">史思明爲翮鳥之精楊貴妃爲白鷴之精又立子</span>  
<span style="margin-left: 2em">旦爲相王武后太子先爲中宗皇后廢之又名哲</span>  
<span style="margin-left: 2em">宗又蜀州司戸楊元琰女爲上子壽王妃今上寵</span>  
<span style="margin-left: 2em">之賜名楊貴妃又宫室未委肅宗也諸語今亦皆</span>  
<span style="margin-left: 2em">在錄中則兩本亦大槩畧同也末一章預作䜟語</span>  
<!-- 册3 葉300a　Page:文淵閣四庫全書_0003冊.djvu/80 -->
<span style="margin-left: 2em">言及狄靑諸人尤爲妖妄葢粗識字義而不通文</span>  
<span style="margin-left: 2em">理者所爲本不足存以其出於九齡之子孫恐惑</span>  
<span style="margin-left: 2em">流俗故存而闢之俾無熒衆聽焉</span>  
漁樵對問一巻<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">舊本題宋邵子撰晁公武讀書志又作張子劉安</span>  
<span style="margin-left: 2em">上集中亦載它三人時代相接未詳孰是也其書</span>  
<span style="margin-left: 2em">設爲問答以𤼵明義理所稱有温泉而無寒火者</span>  
<span style="margin-left: 2em">楊愼丹鉛錄嘗引<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3575.svg?width=24" alt="四庫全書僻字第3575號（葛）" title="四庫全書僻字第3575號（葛）">洪抱朴子蕭邱寒熖以駁之</span>  
<span style="margin-left: 2em">不知儒者論理論其常耳其偶異者卽使有之不</span>  
<!-- 册3 葉300b　Page:文淵閣四庫全書_0003冊.djvu/80 -->
<span style="margin-left: 2em">足爲據執松栢而謂冬不肅殺執靡草而謂夏不</span>  
<span style="margin-left: 2em">茂育則拘墟之見也且蕭邱誰得而見之<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3575.svg?width=24" alt="四庫全書僻字第3575號（葛）" title="四庫全書僻字第3575號（葛）">洪又</span>  
<span style="margin-left: 2em">何自而知之摭百家迂怪之言以曲相詰難則道</span>  
<span style="margin-left: 2em">經釋典理外之事亦多矣可援以爲證乎至天何</span>  
<span style="margin-left: 2em">依曰依乎地地何附曰附乎天天地何依何附曰</span>  
<span style="margin-left: 2em">自相依附一條愼亦駁之然地處天中大氣包而</span>  
<span style="margin-left: 2em">舉之所以不墜卵黄脬豆厥譬甚明是卽依附它</span>  
<span style="margin-left: 2em">明證愼不知厯術所以獻疑均不足爲是書病然</span>  
<span style="margin-left: 2em">書中所論大抵習見之談或後人摭其緒論爲之</span>  
<!-- 册3 葉301a　Page:文淵閣四庫全書_0003冊.djvu/80 -->
<span style="margin-left: 2em">如二程遺書不盡出於口授歟</span>  
太極圖分解一巻<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">不著撰人名氏天一閣書目作羅鶴撰然書中自</span>  
<span style="margin-left: 2em">稱鶚曰則名鶚非名鶴矣考江西通志羅鶚宜黄</span>  
<span style="margin-left: 2em">人嘉靖辛酉舉人官至思南府同知當卽其人范</span>  
<span style="margin-left: 2em">氏誤以鶚爲鶴也<sub class="note-yuan">案嘉靖中別有羅鶴泰和人所著有應菴任意錄詳雜家𩔖中</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">本條下</sub>其書列周子太極圖說與朱子之註而申陸</span>  
<span style="margin-left: 2em">九淵之說以駁之案聖人立教使天下知所持循</span>  
<span style="margin-left: 2em">而巳未有辨也孟子始辨性善亦闡明四端而巳</span>  
<!-- 册3 葉301b　Page:文淵閣四庫全書_0003冊.djvu/80 -->
<span style="margin-left: 2em">未爭諸受生以前也至宋儒因性而言理氣因理</span>  
<span style="margin-left: 2em">氣而言天因天而言及天它先輾轉相推而太極</span>  
<span style="margin-left: 2em">無極之辨生焉朱陸之說旣巳連篇累牘衍朱陸</span>  
<span style="margin-left: 2em">之說者又復充棟汗牛夫性善性惡闗乎民彛天</span>  
<span style="margin-left: 2em">理此不得不辨者也若夫言太極不言無極於陽</span>  
<span style="margin-left: 2em">變陰合之妙修吉悖凶之理未有害也言太極兼</span>  
<span style="margin-left: 2em">言無極於陽變陰合之妙修吉悖凶之理亦未有</span>  
<span style="margin-left: 2em">害也顧舍人事而爭天又舍共睹共聞之天而爭</span>  
<span style="margin-left: 2em">耳目不及之天其所爭者毫無與人事之得失而</span>  
<!-- 册3 葉304a　Page:文淵閣四庫全書_0003冊.djvu/81 -->
<span style="margin-left: 2em">曰吾以衛道學問之醇疵心術人品之邪正天下</span>  
<span style="margin-left: 2em">國家之治亂果繫於此二字乎醫家之論三焦也</span>  
<span style="margin-left: 2em">或曰有名而無形或曰上焦如霧中焦如漚下焦</span>  
<span style="margin-left: 2em">如瀆實有名而有形轇轕喧闐動盈巻帙及問其</span>
