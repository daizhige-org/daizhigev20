梅花道入遺墨二卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">元吳鎭撰鎭字仲圭自號梅花道人嘉興人嘉興</span>  
<span style="margin-left: 2em">志稱其卒於明洪武中考鎭自書墓碣稱生於至</span>  
<span style="margin-left: 2em">元十七年庚辰卒於至正十四年甲午則未嘗入</span>  
<span style="margin-left: 2em">明志爲舛誤又陳繼儒梅花庵集稱鎭自題墓碣</span>  
<span style="margin-left: 2em">爲梅花和尚之塔後扎木揚喇勒智<sub class="note-yuan">原作楊璉眞伽今改正</sub></span>  
<!-- 册4 葉1693b　Page:文淵閣四庫全書_0004冊.djvu/428 -->
<span style="margin-left: 2em">所至椎冡燔槨獨鎭之墓疑爲僧塔遂舍去考扎</span>  
<span style="margin-left: 2em">木揚喇勒智發宋陵在至元甲申乙酉之間元史</span>  
<span style="margin-left: 2em">與癸辛雜識所記並同是時鎭方五六歲安有預</span>  
<span style="margin-left: 2em">題墓碣之事此好事者因鎭明於易數故神其說</span>  
<span style="margin-left: 2em">而未思歲月之顚舛繼儒摭以爲說亦疎謬也鎭</span>  
<span style="margin-left: 2em">以畫傳初不以文章見重而抗懷孤往窮餓不移</span>  
<span style="margin-left: 2em">胸次旣高吐屬自能㧞俗舊無專集此本題曰遺</span>  
<span style="margin-left: 2em">墨乃其鄉人錢棻捃拾題畫之作薈稡成編其中</span>  
<span style="margin-left: 2em">如題竹詩陰凉生硯池葉葉秋可數東華客夢醒</span>  
<!-- 册4 葉1696a　Page:文淵閣四庫全書_0004冊.djvu/429 -->
<span style="margin-left: 2em">一片江南雨一篇考鎭杜門高隱終於魏塘足跡</span>  
<span style="margin-left: 2em">未至京師不應有東華客夢之句核以高士竒江</span>  
<span style="margin-left: 2em">村銷夏錄乃知爲鮮于樞詩鎭偶書之非其自作</span>  
<span style="margin-left: 2em">棻葢未之詳審又鎭畫深自矜重不肯輕爲人作</span>  
<span style="margin-left: 2em">後來假名求售贋跡頗多亦往往有庸俗畫賈僞</span>  
<span style="margin-left: 2em">爲題識如題畫骷髏之沁園春詞無論厯代畫家</span>  
<span style="margin-left: 2em">從無畫及骷髏之事卽詞中漏洩元陽爹娘搬販</span>  
<span style="margin-left: 2em">至今未休諸句鄙俚荒謬亦决非鎭之所爲又如</span>  
<span style="margin-left: 2em">嘉禾八景之酒泉子詞詞旣弇陋其序末乃稱梅</span>  
<!-- 册4 葉1696b　Page:文淵閣四庫全書_0004冊.djvu/429 -->
<span style="margin-left: 2em">花道人鎭頓首偶自作畫爲誰頓首耶卽題竹佚</span>  
<span style="margin-left: 2em">句之我亦有亭深竹裏也思歸去聽秋聲亦字也</span>  
<span style="margin-left: 2em">字重叠而用鎭亦不應昧於字義如此凡斯之類</span>  
<span style="margin-left: 2em">棻皆一例編載未免失於决擇然僞本雖多眞跡</span>  
<span style="margin-left: 2em">亦在披沙簡金往往見寶要未可以糅雜之故一</span>  
<span style="margin-left: 2em">例廢斥之矣</span>  
玩齋集十卷拾遺一卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">元貢師泰撰師泰字泰甫宣城人以國子生中江</span>  
<span style="margin-left: 2em">浙鄉試除泰和州判官薦充應奉翰林文字出爲</span>  
<!-- 册4 葉1697a　Page:文淵閣四庫全書_0004冊.djvu/429 -->
<span style="margin-left: 2em">紹興府推官復入翰林遷宣文閣授經郞至正十</span>  
<span style="margin-left: 2em">四年擢吏部侍郞除浙江都水庸田使尋拜禮部</span>  
<span style="margin-left: 2em">尚書調平江路總管張士誠據吳避之海上江浙</span>  
<span style="margin-left: 2em">行省丞相承制授參知政事二十年改戸部尚書</span>  
<span style="margin-left: 2em">命督海運二十二年召爲秘書<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">道卒事蹟具元</span>  
<span style="margin-left: 2em">史本傳明嘉靖中李黙作是集䟦云予在宣州諸</span>  
<span style="margin-left: 2em">生貢安國者爲言其先世禮部公流寓海寧時自</span>  
<span style="margin-left: 2em">名其里曰小桃源元命旣革宋學士景濂嘗過之</span>  
<span style="margin-left: 2em">公爲置酒飮夜分乃起就臥仰藥而斃顧嗣立元</span>  
<!-- 册4 葉1697b　Page:文淵閣四庫全書_0004冊.djvu/429 -->
<span style="margin-left: 2em">百家詩選則據其門人朱鐩所作紀年錄及揭汯</span>  
<span style="margin-left: 2em">所作墓誌載至正十六年正月張士誠陷平江公</span>  
<span style="margin-left: 2em">抱印隱居吳淞江上主釣臺山長吳景文家易姓</span>  
<span style="margin-left: 2em">名爲端木氏號戾契子喌喌翁二十六年卒於海</span>  
<span style="margin-left: 2em">寧寓舍證黙䟦所紀之誣案明史宋濂傳濂乞假</span>  
<span style="margin-left: 2em">歸省在至元二十五年乙巳師泰沒於至元二十</span>  
<span style="margin-left: 2em">二年壬辰其時濂無由至海寧且太祖稱吳王在</span>  
<span style="margin-left: 2em">至正二十四年甲辰稱吳元年在二十七年丁未</span>  
<span style="margin-left: 2em">元順帝北趨上都在二十八年戊申七月是爲洪</span>  
<!-- 册4 葉1700a　Page:文淵閣四庫全書_0004冊.djvu/430 -->
<span style="margin-left: 2em">武元年師泰旣沒於壬寅尚在元亡前六年何以</span>  
<span style="margin-left: 2em">稱元命旣革此其後人之餙詞欲附於王蠋之節</span>  
<span style="margin-left: 2em">殊非事實嗣立疑之當矣師泰所著有友迂集余</span>  
<span style="margin-left: 2em">闕序之玩齋集黃溍序之東軒集程文序之又有</span>  
<span style="margin-left: 2em">奊𡔢集閩南集見於李國鳳之序其門人謝肅劉</span>  
<span style="margin-left: 2em">欽類爲一編總名曰玩齋集今未之見明天順間</span>  
<span style="margin-left: 2em">寧國守會稽沈性重加蒐輯得詩文六百五十三</span>  
<span style="margin-left: 2em">首𨤲爲十卷又補遺一卷其年譜之類别爲一卷</span>  
<span style="margin-left: 2em">附之是爲今本師泰本以政事傳而少承其父奎</span>  
<!-- 册4 葉1700b　Page:文淵閣四庫全書_0004冊.djvu/430 -->
<span style="margin-left: 2em">家學又從吳澄受業復與虞集揭傒斯游故文章</span>  
<span style="margin-left: 2em">亦具有原本其在元末足以凌厲一時詩格尤爲</span>  
<span style="margin-left: 2em">高雅虞楊范揭之後可謂挻然晚秀矣集中題陶</span>  
<span style="margin-left: 2em">淵明五柳圖絶句明詩別裁集以爲燕王篡位之</span>  
<span style="margin-left: 2em">後建文舊臣江右袁敬所作併記敬所本末甚詳</span>  
<span style="margin-left: 2em">今考明孫原禮所撰元音成於洪武甲子張中達</span>  
<span style="margin-left: 2em">爲之刋板在建文辛巳均在遜國以前而收入是</span>  
<span style="margin-left: 2em">詩題爲師泰所作則爲師泰之詩誤附㑹於敬所</span>  
<span style="margin-left: 2em">非敬所之詩誤<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2872.svg?width=24" alt="四庫全書僻字第2872號（竄）" title="四庫全書僻字第2872號（竄）">入師泰集中明矣</span>  
<!-- 册4 葉1701a　Page:文淵閣四庫全書_0004冊.djvu/430 -->
羽庭集六卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">元劉仁本撰仁本字德元天台人以進士乙科厯</span>  
<span style="margin-left: 2em">官温州路總管江浙行省左右司郞中時方國珍</span>  
<span style="margin-left: 2em">據有温台招延諸郡士大夫仁本入其幕中參預</span>  
<span style="margin-left: 2em">謀議國珍歲治海舟輸江淮之粟於大都仁本實</span>  
<span style="margin-left: 2em">司其事其所署省郞官葢卽元所授故集中諸作</span>  
<span style="margin-left: 2em">大都感<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3004.svg?width=24" alt="四庫全書僻字第3004號（慨）" title="四庫全書僻字第3004號（慨）">阽危眷懷王室其從國珍葢欲借其力</span>  
<span style="margin-left: 2em">以有爲徐圖興復亦如羅隱之仕吳越實心不忘</span>  
<span style="margin-left: 2em">唐觀其贈李員外自集慶回河南詩云漢兵早已</span>  
<!-- 册4 葉1701b　Page:文淵閣四庫全書_0004冊.djvu/430 -->
<span style="margin-left: 2em">定中華孫述猶鳴井底蛙於明祖顯然指斥其志</span>  
<span style="margin-left: 2em">可知厥後國珍兵敗仁本就擒抗節不撓至鞭背</span>  
<span style="margin-left: 2em">潰爛而死則仁本終始元人未嘗一日入明永樂</span>  
<span style="margin-left: 2em">大典題曰國朝劉仁本非其實也仁本學問淹雅</span>  
<span style="margin-left: 2em">工於吟詠多與趙俶謝理朱佑等唱和嘗治兵餘</span>  
<span style="margin-left: 2em">姚作雩詠亭於龍泉左麓仿彿蘭亭景物集一時</span>  
<span style="margin-left: 2em">文士修禊賦詩自爲之敘其文雖不見於集中而</span>  
<span style="margin-left: 2em">石刻今日猶存文采風流可以想見故所作皆淸</span>  
<span style="margin-left: 2em">雋絶俗不染塵氛其序記諸篇述方國珍與察罕</span>  
<!-- 册4 葉1704a　Page:文淵閣四庫全書_0004冊.djvu/431 -->
<span style="margin-left: 2em">通使及歲漕大都諸事多記傳所不載亦可補史</span>  
<span style="margin-left: 2em">闕原本久佚今就永樂大典所載以類編次𨤲爲</span>  
<span style="margin-left: 2em">詩四卷文二卷仍改題曰元劉仁本以存其眞焉</span>  
不繫舟漁集十六卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">元陳高撰高字子上温州平陽人至正十四年進</span>  
<span style="margin-left: 2em">士授慶元路錄事未三年輒自免去平陽陷棄妻</span>  
<span style="margin-left: 2em">子往來閩浙間自號不繫舟漁者至正十六年浮</span>  
<span style="margin-left: 2em">海過山東謁河南王庫庫特穆爾<sub class="note-yuan">原作擴廓鐡木兒今改正</sub>於</span>  
<span style="margin-left: 2em">懷慶宻論江南虚實庫庫特穆爾欲官之會疾作</span>  
<!-- 册4 葉1704b　Page:文淵閣四庫全書_0004冊.djvu/431 -->
<span style="margin-left: 2em">卒葢當國祚阽危猶力謀匡復明太祖稱王保保</span>  
<span style="margin-left: 2em">眞男子<sub class="note-yuan">卽庫庫特穆爾</sub>如高者事雖不就其志亦不愧王</span>  
<span style="margin-left: 2em">保保矣不但詩之足傳也明洪武初蘇伯衡訪其</span>  
<span style="margin-left: 2em">遺集𨤲定成編題曰子上存稿此本題不繫舟漁</span>  
<span style="margin-left: 2em">集不知何人所改文格頗雅潔詩惟七言古體不</span>  
<span style="margin-left: 2em">擅場絶句亦不甚經意其五言古體源出陶潛近</span>  
<span style="margin-left: 2em">體律詩格從杜甫面目稍別而神思不遠亦元季</span>  
<span style="margin-left: 2em">之錚錚者矣元又有嘉定僧祖柏其詩亦名不繫</span>  
<span style="margin-left: 2em">舟集見顧嗣立元詩選集中有題倪瓚芝秀圖詩</span>  
<!-- 册4 葉1705a　Page:文淵閣四庫全書_0004冊.djvu/431 -->
<span style="margin-left: 2em">葢與高同時然其詩不及高遠甚今未見其本以</span>  
<span style="margin-left: 2em">集名相亂附著其異於此庶來者無疑焉</span>  
居竹軒集四卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">元成延珪撰廷珪字原常一字元章又字禮執揚</span>  
<span style="margin-left: 2em">州人好學不求仕進惟以吟咏自娛奉母居市㕓</span>  
<span style="margin-left: 2em">植竹庭院間頗有山林意趣因扁其燕息之所曰</span>  
<span style="margin-left: 2em">居竹軒晚遭世亂避地吳中踪跡多在松江故集</span>  
<span style="margin-left: 2em">中有欲卜居海上之作後竟歿於雲間其年葢已</span>  
<span style="margin-left: 2em">七十餘矣此集乃其友郜肅劉欽搜輯遺稿所刋</span>  
<!-- 册4 葉1705b　Page:文淵閣四庫全書_0004冊.djvu/431 -->
<span style="margin-left: 2em">也廷珪與河東張翥爲忘年交其詩音律體製多</span>  
<span style="margin-left: 2em">得法於翥而聲價亦與翥相亞觀詩中所載酬答</span>  
<span style="margin-left: 2em">者如楊維禎危素楊基李黼余闕張雨倪瓚皆一</span>  
<span style="margin-left: 2em">代勝流而黼與闕之忠義瓚之孤僻尤非標榜聲</span>  
<span style="margin-left: 2em">氣之輩其傾例於廷珪必有所以取之矣劉欽稱</span>  
<span style="margin-left: 2em">廷珪五言務自然不事雕劌七言律最爲工深合</span>  
<span style="margin-left: 2em">唐人之體今觀其七言古詩亦頗遒麗惟五言古</span>  
<span style="margin-left: 2em">詩竟無一篇似不應全卷遺佚或自知此體不擅</span>  
<span style="margin-left: 2em">長遂不復作亦如宋无之翠寒集歟</span>  
<!-- 册4 葉1708a　Page:文淵閣四庫全書_0004冊.djvu/432 -->
句曲外史集三卷補遺三卷集外詩一卷<sub class="note-yuan">浙江鮑土恭家藏本</sub>  
<span style="margin-left: 2em">元張雨撰雨有元品錄已著錄其平生詩文嘗手</span>

<span style="margin-left: 2em">案集中洪武壬戌辭聘詩有雅以非才例䝉郡舉</span>  
<span style="margin-left: 2em">云云知其名爲雅而伯言乃其字也又雅雖辭聘</span>  
<span style="margin-left: 2em">而末一卷乃爲朝京紀行詩且有應制賦鍾山雲</span>  
<span style="margin-left: 2em">氣沍寒之作葢當時未允其辭起送入都之後始</span>

<span style="margin-left: 2em">得放還與張昱等相𩔖也時梁寅方講學石門山</span>  
<span style="margin-left: 2em">中雅與之游此集卽寅所勘定然江西通志失載</span>  
<span style="margin-left: 2em">其人此集諸家書目亦未著錄惟此抄帙流傳僅</span>  
<span style="margin-left: 2em">存至今耳卷首有梁寅序及荅書一首又何淑丁</span>  
<span style="margin-left: 2em">節戴正心序各一首謝觀題詞一首皆極相推挹</span>  
<span style="margin-left: 2em">今觀其詩雖未免稍涉率易而氣味冲澹頗有自</span>  
<span style="margin-left: 2em">然之致究爲不失雅音與梁寅石門集體裁正復</span>  
<span style="margin-left: 2em">相近宜其契分之深矣</span>
