## 欽定四庫全書總目 卷一百十四　子部二十四　藝術類存目

欽定四庫全書總目卷一百十四  
<span style="margin-left: 1em">子部二十四</span>  
<span style="margin-left: 2em">藝術類存目</span>  
山水松石格一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">舊本題梁孝元皇帝撰案是書宋藝文志始著錄</span>  
<span style="margin-left: 2em">其文凡鄙不𩔖六朝人語且元帝之畫南史載有</span>  
<span style="margin-left: 2em">宣尼像金樓子載有職貢圖厯代名畫記載有蕃</span>  
<span style="margin-left: 2em">客入朝圖遊春苑圖鹿圖師利圖鶼鶴陂澤圖芙</span>  
<span style="margin-left: 2em">蓉湖醮㬥圖貞觀畫史載有交殊像是其擅長惟</span>  
<!-- 册3 葉1853b　Page:文淵閣四庫全書_0003冊.djvu/468 -->
<span style="margin-left: 2em">在人物故姚最續畫品錄惟稱湘東王殿下工於</span>  
<span style="margin-left: 2em">像人特盡神妙未聞以山水松石傳安有此書也</span>  
後畫錄一卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">唐釋彦悰撰前有彦悰自序稱爲帝京寺錄就所</span>  
<span style="margin-left: 2em">見長安名畫係以品題凡三十七人葢以續姚最</span>  
<span style="margin-left: 2em">之書者序題貞觀九年故稱閻立本猶爲司平太</span>  
<span style="margin-left: 2em">常伯然末一人爲廣陵郡倉曹參軍李湊考張彦</span>  
<span style="margin-left: 2em">遠名畫記李湊林甫之姪也初爲廣陵倉曹天寶</span>  
<span style="margin-left: 2em">中貶明州象山尉尤工綺羅人物爲時驚絶則湊</span>  
<!-- 册3 葉1856a　Page:文淵閣四庫全書_0003冊.djvu/469 -->
<span style="margin-left: 2em">爲明皇時人彦悰遠在太宗之世何以能預錄之</span>  
<span style="margin-left: 2em">乎張彦遠厯代名畫記曰僧悰之評最爲謬誤傳</span>  
<span style="margin-left: 2em">寫又復脫錯殊不足看也是眞本尙不足重無論</span>  
<span style="margin-left: 2em">僞本矣</span>  
續畫品録一卷<sub class="note-yuan">江西巡撫採進本</sub>  
<span style="margin-left: 2em">舊本題唐李嗣眞撰案舊唐書李嗣眞滑州匡城</span>  
<span style="margin-left: 2em">人永昌中拜御史中丞知大夫事爲來俊臣所陷</span>  
<span style="margin-left: 2em">配流嶺南萬歲通天中徵還行至桂陽卒此本前</span>  
<span style="margin-left: 2em">題結銜爲御史大夫而張彦遠厯代名畫記亦稱</span>  
<!-- 册3 葉1856b　Page:文淵閣四庫全書_0003冊.djvu/469 -->
<span style="margin-left: 2em">爲李大夫與舊唐書合彦遠又稱嗣眞爲尹琳弟</span>  
<span style="margin-left: 2em">子善畫佛道鬼神琳高宗時人時代亦符當卽其</span>  
<span style="margin-left: 2em">人也是書名載唐藝文志朱景元唐朝名畫錄序</span>  
<span style="margin-left: 2em">稱嗣眞空錄人名而不記其善惡無品格高下與</span>  
<span style="margin-left: 2em">此本體例合然名畫記引李嗣眞云曹不興以一</span>  
<span style="margin-left: 2em">蠅輒擅重價列於上品恐爲未當况拂蠅之事一</span>  
<span style="margin-left: 2em">說是楊修謝赫黜衛進曹是涉貴耳之論云云凡</span>  
<span style="margin-left: 2em">數條又李綽尚書故實亦引嗣眞云顧畫屈居第</span>  
<span style="margin-left: 2em">一然虎頭又伏衛協畫北風圖是嗣眞之書又本</span>  
<!-- 册3 葉1857a　Page:文淵閣四庫全書_0003冊.djvu/469 -->
<span style="margin-left: 2em">有論斷同出唐人而所言互異晁公武郡齋讀書</span>  
<span style="margin-left: 2em">志載嗣眞名畫記一卷又畫人名一卷豈彦遠所</span>  
<span style="margin-left: 2em">引爲名畫記之文而此爲畫人名耶然嗣眞唐人</span>  
<span style="margin-left: 2em">而稱梁元帝爲湘東殿下仍同姚最之文其序又</span>  
<span style="margin-left: 2em">云今之所載並謝赫之所遺轉不及最一字恐嗣</span>  
<span style="margin-left: 2em">眞原本巳佚明人剽姚最之書稍爲附益僞托於</span>  
<span style="margin-left: 2em">嗣眞耳法書要錄載嗣眞書品後一卷所載八十</span>  
<span style="margin-left: 2em">一人分爲十等各有敘錄又有評有贊條理秩然</span>  
<span style="margin-left: 2em">計其畫品體例亦必一律不應草草如此是尤作</span>  
<!-- 册3 葉1857b　Page:文淵閣四庫全書_0003冊.djvu/469 -->
<span style="margin-left: 2em">僞之顯證矣</span>  
畫學祕訣一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">舊本題唐王維撰詞作駢體而句格皆似南宋人</span>  
<span style="margin-left: 2em">語王縉編維集亦不載此篇明焦竑經籍志始著</span>  
<span style="margin-left: 2em">於錄葢亦近代依託也明人收入維集失考甚矣</span>  
山水訣一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">舊本題唐李成撰案宋史李覺傳載李成字咸熙</span>  
<span style="margin-left: 2em">本京兆長安人唐末徙家靑州工畫山水周樞宻</span>  
<span style="margin-left: 2em">王朴將薦其能㑹朴卒鬱鬱不得志乾德中司農</span>  
<!-- 册3 葉1860a　Page:文淵閣四庫全書_0003冊.djvu/470 -->
<span style="margin-left: 2em">卿衛融知陳州召之成因挈族而往劉道醇宋朝</span>  
<span style="margin-left: 2em">名畫評又載其開寶中舉進士集於春官邵博聞</span>  
<span style="margin-left: 2em">見後錄亦稱國初營邱李成畫山水然則成爲宋</span>  
<span style="margin-left: 2em">人題唐者誤矣是書宋志及晁陳書目皆不著錄</span>  
<span style="margin-left: 2em">宋人諸家畫錄亦不言成有是書殆後人依託其</span>  
<span style="margin-left: 2em">文與王氏畫苑所載嘉定中李澄叟山水訣大同</span>  
<span style="margin-left: 2em">小異大抵庸俗畫工有是口訣輾轉相傳互有損</span>  
<span style="margin-left: 2em">益隨意僞題古人耳</span>  
宣和論畫雜評一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<!-- 册3 葉1860b　Page:文淵閣四庫全書_0003冊.djvu/470 -->
<span style="margin-left: 2em">此本爲王氏畫苑所載題宋嶶宗皇帝御撰勘騐</span>  
<span style="margin-left: 2em">其文卽宣和畫譜中諸論也明人叢書往往如是</span>  
<span style="margin-left: 2em">亦拙於作僞矣</span>  
華光梅譜一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">舊本題宋僧仲仁撰考鄧椿畫繼曰仲仁㑹稽人</span>  
<span style="margin-left: 2em">住衡州華光山陶宗儀書史㑹要曰華光長老酷</span>  
<span style="margin-left: 2em">好梅花方丈植梅數本每花放時移牀其下吟咏</span>  
<span style="margin-left: 2em">終日偶月夜見牕間疎影橫斜蕭然可愛遂以筆</span>  
<span style="margin-left: 2em">規其狀因此好寫得其三昧黃庭堅詩曰雅聞華</span>  
<!-- 册3 葉1861a　Page:文淵閣四庫全書_0003冊.djvu/470 -->
<span style="margin-left: 2em">光能墨梅更乞一枝洗煩惱此華光畫梅所以傳</span>  
<span style="margin-left: 2em">也然庭堅又書題其平沙遠水則不止能畫梅矣</span>  
<span style="margin-left: 2em">此書葢後人因仲仁之名依託爲之其口訣一則</span>  
<span style="margin-left: 2em">詞旨凡鄙其取象一則附㑹於太極陰陽竒偶旁</span>  
<span style="margin-left: 2em">涉講學家門徑尤乖畫家蕭散之趣末有補之總</span>  
<span style="margin-left: 2em">論一則華光指迷一則補之卽揚无咎字南宋高</span>  
<span style="margin-left: 2em">宗時始以畫梅著曾敏行獨醒雜志載紹興初有</span>  
<span style="margin-left: 2em">華光寺僧來居淸江慧力寺士人揚補之譚逢原</span>  
<span style="margin-left: 2em">與之往來乃得仲仁之傳仲仁在元祐閒不應先</span>  
<!-- 册3 葉1861b　Page:文淵閣四庫全書_0003冊.djvu/470 -->
<span style="margin-left: 2em">引其說至華光著書乃又自引華光之書其謬尤</span>  
<span style="margin-left: 2em">不待辨矣</span>  
金壺記三卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">宋僧適之撰適之始末未詳案拾遺記載周時浮</span>  
<span style="margin-left: 2em">提國獻書生二人有金壺壺中墨汁灑水石皆成</span>  
<span style="margin-left: 2em">篆籀或科斗文字記之取名葢出於此適之原有</span>  
<span style="margin-left: 2em">金壺字考一卷取書之異音者以𩔖相從標題二</span>  
<span style="margin-left: 2em">字而音其下其書具有條理是書雜述書體及能</span>  
<span style="margin-left: 2em">書人名乃頗爲蕪襍如項籍記姓名揚雄心畫之</span>  
<!-- 册3 葉1864a　Page:文淵閣四庫全書_0003冊.djvu/471 -->
<span style="margin-left: 2em">𩔖雜敘於五十六種書體内殊爲不𩔖又皆不著</span>  
<span style="margin-left: 2em">出處亦乖傳信之道也</span>  
畫山水訣一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">舊本題宋李澄叟撰澄叟始末不可考惟序未自</span>  
<span style="margin-left: 2em">稱湖中人序題嘉定辛巳六月而中稱盤礴乎其</span>  
<span style="margin-left: 2em">間者六十餘年則髙宗末年人至寧宗時猶存矣</span>  
<span style="margin-left: 2em">其論畫謂南渡以後有李蕭二君考南渡後畫手</span>  
<span style="margin-left: 2em">李姓者不下數十人蕭姓者則無所考莫詳所指</span>  
<span style="margin-left: 2em">又澄叟僅及紹興之末而泛說一條中乃稱紹興</span>  
<!-- 册3 葉1864b　Page:文淵閣四庫全書_0003冊.djvu/471 -->
<span style="margin-left: 2em">中有一晚進亦殊矛盾考畫史㑹要載元有李澄</span>  
<span style="margin-left: 2em">叟湘中人自㓜觀湘中山水長游三峽䕫門或水</span>  
<span style="margin-left: 2em">或陸盡得其態寫之水墨甚有妙悟作山水訣一</span>  
<span style="margin-left: 2em">卷人名書名與此皆合惟時代與書中違異今勘</span>  
<span style="margin-left: 2em">驗書中所載皆世傳李成畫山水訣之文而小變</span>  
<span style="margin-left: 2em">其字句始原本散佚妄人勦李成之書僞撰此本</span>  
<span style="margin-left: 2em">又誤以爲宋人故全然牴牾王氏畫苑乃與成書</span>  
<span style="margin-left: 2em">並收之亦失於互勘矣</span>  
竹譜詳錄一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<!-- 册3 葉1865a　Page:文淵閣四庫全書_0003冊.djvu/471 -->
<span style="margin-left: 2em">舊本題元李衎撰衎竹譜十卷已於永樂大典中</span>  
<span style="margin-left: 2em">採輯著錄此鈔其百分之一乃改題曰詳錄傎亦</span>  
<span style="margin-left: 2em">甚矣</span>  
書法鈎元四卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">元蘇霖撰霖字子啟鎭江人是書取前人論書之</span>  
<span style="margin-left: 2em">語始漢楊雄終宋劉辰翁凡六十五條畧具梗槩</span>  
<span style="margin-left: 2em">未爲該備其去取亦未精審</span>  
字學新書摘抄一卷<sub class="note-yuan">浙江鄭大節家藏本</sub>  
<span style="margin-left: 2em">元劉惟志撰惟志達州人仕履未詳是編摘錄古</span>  
<!-- 册3 葉1865b　Page:文淵閣四庫全書_0003冊.djvu/471 -->
<span style="margin-left: 2em">人論書之語分四目曰六書曰六體曰書法曰書</span>  
<span style="margin-left: 2em">評簡畧殊甚詳其書名似先有字學新書而惟志</span>  
<span style="margin-left: 2em">摘鈔之也</span>  
畫紀補遺二卷元畫紀一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">不著撰人名氏載宋高宗以後元至正以前諸畫</span>  
<span style="margin-left: 2em">家頗多舛錯如馬遠之父名公顯足名逵乃以逵</span>  
<span style="margin-left: 2em">爲遠之弟以公顯爲逵之孫并云傳家學不逮厥</span>  
<span style="margin-left: 2em">祖顚例甚矣其他脫漏更指不勝屈也</span>  
法書通釋二卷<sub class="note-yuan">衍聖公孔昭焕家藏本</sub>  
<!-- 册3 葉1868a　Page:文淵閣四庫全書_0003冊.djvu/472 -->
<span style="margin-left: 2em">明張紳撰紳字士行一曰字仲紳書史㑹要但稱</span>  
<span style="margin-left: 2em">爲山東人洪武中官浙江布政使不詳爲山東何</span>  
<span style="margin-left: 2em">地之人亦不詳其出身考明史吳伯宗傳附載鮑</span>  
<span style="margin-left: 2em">恂事稱洪武十五年吉安余詮高郵張長年登州</span>  
<span style="margin-left: 2em">張紳並以明經老成爲禮部主事所薦召至京恂</span>  
<span style="margin-left: 2em">長年皆以老病辭歸惟紳授鄠縣教諭尋召爲右</span>  
<span style="margin-left: 2em">僉都御史終浙江左布政使則紳乃登州人以薦</span>  
<span style="margin-left: 2em">舉起家也是書分十篇曰八法曰結構曰執使曰</span>  
<span style="margin-left: 2em">篇段曰從古曰立式曰辨體曰名稱曰利器曰總</span>  
<!-- 册3 葉1868b　Page:文淵閣四庫全書_0003冊.djvu/472 -->
<span style="margin-left: 2em">論皆彚集晉唐以來名論亦間及蘇軾黄庭堅姜</span>
