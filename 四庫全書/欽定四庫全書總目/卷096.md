## 欽定四庫全書總目 卷九十六　子部六　儒家類存目二

欽定四庫全書總目卷九十六  
<span style="margin-left: 1em">子部六</span>  
<span style="margin-left: 2em">儒家𩔖存目二</span>  
後渠庸書一卷<sub class="note-yuan">編俢程晉芳家藏本</sub>  
<span style="margin-left: 2em">明崔銑撰銑有讀易餘言已著錄此其筆記之文</span>  
<span style="margin-left: 2em">如論春王正月爲周正幽贊於神明而生蓍爲用</span>  
<span style="margin-left: 2em">䇿論易不本於先天圖在今日爲已定之論在明</span>  
<span style="margin-left: 2em">人則爲卓識矣又曰圖象繁而易荒矣小序廢而</span>  
<span style="margin-left: 2em">詩蕪且淺矣左氏輕而春秋虚矣喜新變古君子</span>  
<!-- 册3 葉373b　Page:文淵閣四庫全書_0003冊.djvu/98 -->
<span style="margin-left: 2em">無樂乎斯焉耳又曰宋人之說古事也多以其意</span>  
<span style="margin-left: 2em">億之始猶昭然也習之久遂若眞者誣矣哉尤講</span>  
<span style="margin-left: 2em">學家所諱不肯言者銑獨不巧言回䕶亦絶無門</span>  
<span style="margin-left: 2em">戸之私然諸條皆見所作士翼中殆後人摘抄僞</span>  
<span style="margin-left: 2em">立此名曹溶不及詳核誤收入學海𩔖編耳</span>  
同異錄二卷<sub class="note-yuan">浙江鮑士㳟家藏本</sub>  
<span style="margin-left: 2em">明陸深撰深有南廵日錄已著錄是書採漢以來</span>  
<span style="margin-left: 2em">名臣奏疏雜文有闗於典章政事之大者節而錄</span>  
<span style="margin-left: 2em">之分爲二卷上篇曰典常下篇曰論述每條之末</span>  
<!-- 册3 葉376a　Page:文淵閣四庫全書_0003冊.djvu/99 -->
<span style="margin-left: 2em">各附以論斷大㫖欲取古人成說相其緩𢚩而通</span>  
<span style="margin-left: 2em">之於當世之務其書始脫稿於閩中及提學山西</span>  
<span style="margin-left: 2em">重加詮次欲奏上之旣而不果其進書原序猶存</span>  
<span style="margin-left: 2em">卷首書中凡原文有陛下云云者俱空白二字而</span>  
<span style="margin-left: 2em">註其下云前朝臣子尊稱君上之文義當避闕然</span>  
<span style="margin-left: 2em">古來傳寫舊文實無此例世所見石經尙書於帝</span>  
<span style="margin-left: 2em">字王字均未有避闕者也</span>  
心性書<sub class="note-yuan">無卷數　浙江廵撫採進本</sub>  
<span style="margin-left: 2em">明湛若水撰若水有二禮經傳測已著錄是書首</span>  
<!-- 册3 葉376b　Page:文淵閣四庫全書_0003冊.djvu/99 -->
<span style="margin-left: 2em">列心性圖圖後有說復集心性通三十五章其門</span>  
<span style="margin-left: 2em">人黄民凖鍾景星周學心袁郵郭肇乾謝錫命湛</span>  
<span style="margin-left: 2em">天潤共爲之注與贊霍任又著或問數十條以發</span>  
<span style="margin-left: 2em">明之葢欲仿周子太極圖說通書也</span>  
楊子折衷六卷<sub class="note-yuan">浙江鄭大節家藏本</sub>  
<span style="margin-left: 2em">明湛若水撰宋儒之學至陸九淵始以超悟爲宗</span>  
<span style="margin-left: 2em">諸弟子中最號得傳者莫如楊簡然推<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2973.svg?width=24" alt="四庫全書僻字第2973號（衍）" title="四庫全書僻字第2973號（衍）">九淵之</span>  
<span style="margin-left: 2em">說變本加厲遂至全入於禪所著<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3584.svg?width=24" alt="四庫全書僻字第3584號（慈）" title="四庫全書僻字第3584號（慈）">湖遺書以心</span>  
<span style="margin-left: 2em">之精神是謂聖一語爲道之主宰而以不起一意</span>  
<!-- 册3 葉377a　Page:文淵閣四庫全書_0003冊.djvu/99 -->
<span style="margin-left: 2em">使此心虚明洞照爲學之功夫其極至於斥大學</span>  
<span style="margin-left: 2em">非聖言而謂子思孟子同一病源開後來心學之</span>  
<span style="margin-left: 2em">宗至於窅㝠恍惚以爲獨得眞傳其弊實成於簡</span>  
<span style="margin-left: 2em">若水因當時有梓其書者乃卽其所言條析而辨</span>  
<span style="margin-left: 2em">之凡書中低一格者簡之說平格者若水之論也</span>  
遵道錄八卷<sub class="note-yuan">江蘇廵撫採進本</sub>  
<span style="margin-left: 2em">明湛若水撰所輯皆明道程子之說其曰遵道者</span>  
<span style="margin-left: 2em">自序謂遵明道也若水與王守仁同講學而守仁</span>  
<span style="margin-left: 2em">主致良知若水主隨處體驗天理守仁言若水之</span>  
<!-- 册3 葉377b　Page:文淵閣四庫全書_0003冊.djvu/99 -->
<span style="margin-left: 2em">學求之於外若水亦謂守仁格致之說不可信者</span>  
<span style="margin-left: 2em">四遂各分門戸斷斷然相爭是編因若水之學出</span>  
<span style="margin-left: 2em">陳獻章獻章之學每教人靜坐使此心灑然獨得</span>  
<span style="margin-left: 2em">於宋儒中獨推尊明道故闡明師說追溯淵源此</span>  
<span style="margin-left: 2em">本凡八卷<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2973.svg?width=24" alt="四庫全書僻字第2973號（衍）" title="四庫全書僻字第2973號（衍）">聖公孔昭煥所進本則作十卷葢當</span>  
<span style="margin-left: 2em">時原有兩刻明史藝文志作十卷所據卽孔氏本</span>  
<span style="margin-left: 2em">也</span>  
甘泉新論一卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">明湛若水撰若水之學以虚明爲宗故其論心則</span>  
<!-- 册3 葉380a　Page:文淵閣四庫全書_0003冊.djvu/100 -->
<span style="margin-left: 2em">以爲主一而無物其論性則以宋儒理氣對舉爲</span>  
<span style="margin-left: 2em">非視程朱所論頗殊千頃堂書目載甘泉明論十</span>  
<span style="margin-left: 2em">卷又甘泉新論一卷其明論今未見此本則曹溶</span>  
<span style="margin-left: 2em">學海𩔖編所載也</span>  
劉兩峰集四卷<sub class="note-yuan">江西廵撫採進本</sub>  
<span style="margin-left: 2em">明劉陽撰陽字一舒安福人由舉人授碭山縣知</span>  
<span style="margin-left: 2em">縣官至監察御史是編凡論學要語一卷洞語一</span>  
<span style="margin-left: 2em">卷接善編一卷人倫外史一卷陽初從族人劉曉</span>  
<span style="margin-left: 2em">授經曉告以王守仁之學遂徃謁守仁於贛州故</span>  
<!-- 册3 葉380b　Page:文淵閣四庫全書_0003冊.djvu/100 -->
<span style="margin-left: 2em">要語洞語大率不離良知之㫖其接善編多採儒</span>  
<span style="margin-left: 2em">先粹語非所自作其人倫外史卽墓誌傳狀詩詠</span>  
<span style="margin-left: 2em">等作以其係於孝弟忠義貞節之大故以外史爲</span>  
<span style="margin-left: 2em">名雖總爲一集實未可著錄於集部故仍以語錄</span>  
<span style="margin-left: 2em">爲主隸之儒家𩔖焉</span>  
閑闢錄十卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">明程曈撰曈有新安學系錄已著錄是編錄朱子</span>  
<span style="margin-left: 2em">集中辨正異學之語以闢陸王之說凡九卷其末</span>  
<span style="margin-left: 2em">一卷則雜取宋史以下諸家之論朱陸者立說不</span>  
<!-- 册3 葉381a　Page:文淵閣四庫全書_0003冊.djvu/100 -->
<span style="margin-left: 2em">爲不正而門戸之見太深詞氣之間激烈已甚殊</span>  
<span style="margin-left: 2em">非儒者氣象與陳建學蔀通辨均謂之善罵可也</span>  
<span style="margin-left: 2em">江南通志載曈所著尙有新安文獻紫陽風雅二</span>  
<span style="margin-left: 2em">書今並未見然大畧可睹矣</span>  
苑洛語錄六卷<sub class="note-yuan">副都御史黄登賢家藏本</sub>  
<span style="margin-left: 2em">明韓<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3771.svg?width=24" alt="四庫全書僻字第3771號（邦）" title="四庫全書僻字第3771號（邦）">竒撰<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3771.svg?width=24" alt="四庫全書僻字第3771號（邦）" title="四庫全書僻字第3771號（邦）">竒有易學啟𫎇意見已著錄是書</span>  
<span style="margin-left: 2em">皆平日論學之語及所紀錄時事輯爲一編本名</span>  
<span style="margin-left: 2em">見聞攷隨錄已編入所著苑洛集中惟集本五卷</span>  
<span style="margin-left: 2em">此本作六卷所載雖稍有出入而大畧皆同葢此</span>  
<!-- 册3 葉381b　Page:文淵閣四庫全書_0003冊.djvu/100 -->
<span style="margin-left: 2em">本乃<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3771.svg?width=24" alt="四庫全書僻字第3771號（邦）" title="四庫全書僻字第3771號（邦）">竒門人山西參議白璧所刋前有璧序稱</span>  
<span style="margin-left: 2em">刻而題之曰苑洛先生語錄疑又爲璧所重編矣</span>  
願學編二卷<sub class="note-yuan">陜西廵撫採進本</sub>  
<span style="margin-left: 2em">明胡纘宗撰纘宗有安慶府志已著錄此編乃其</span>  
<span style="margin-left: 2em">講學之語成於嘉靖甲寅時纘宗已七十五矣闗</span>  
<span style="margin-left: 2em">中之學大抵源出河東三原無矜竒弔詭之習纘</span>  
<span style="margin-left: 2em">宗又師羅欽順而友魏校湛若水何瑭吕柟馬理</span>  
<span style="margin-left: 2em">故所論頗爲篤實其解大學雖用古本而不廢朱</span>  
<span style="margin-left: 2em">子格物之說雖與王守仁異趨而稱其如程門之</span>  
<!-- 册3 葉384a　Page:文淵閣四庫全書_0003冊.djvu/101 -->
<span style="margin-left: 2em">有游楊亦無門戸詬爭之習然核其全書大抵皆</span>  
<span style="margin-left: 2em">先儒所已言也</span>  
近取編二卷<sub class="note-yuan">陜西廵撫採進本</sub>  
<span style="margin-left: 2em">明胡纘宗撰是編取朱子要語𨤲成二卷名曰近</span>  
<span style="margin-left: 2em">取者謂取諸曰用切近以救宗金谿者之弊殆爲</span>  
<span style="margin-left: 2em">王守仁發也</span>  
海樵子一卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">明王崇慶撰崇慶有周易議卦已著錄是編僅二</span>  
<span style="margin-left: 2em">十六則多摹仿王通中說周子通書張子正𫎇之</span>  
<!-- 册3 葉384b　Page:文淵閣四庫全書_0003冊.djvu/101 -->
<span style="margin-left: 2em">體大抵老生常談末一條論爲將必用儒者謂有</span>  
<span style="margin-left: 2em">張良之楚歌則項羽之䰟自褫有諸葛之雲鳥則</span>  
<span style="margin-left: 2em">南人之反自定夫渡瀘之役未必徒恃陣圖至於</span>  
<span style="margin-left: 2em">四面楚歌出自張良史記漢書皆不載不知其何</span>  
<span style="margin-left: 2em">所本矣</span>  
東石講學錄十一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明王蓂撰蓂有忠義錄已著錄是集爲其門人黄</span>  
<span style="margin-left: 2em">文龍所編皆平生講學之語蓂與陸九淵爲鄉人</span>  
<span style="margin-left: 2em">故其說一以九淵爲本云</span>  
<!-- 册3 葉385a　Page:文淵閣四庫全書_0003冊.djvu/101 -->
心學錄四卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明王蓂撰是編乃蓂養親家居之時取陸九淵之</span>  
<span style="margin-left: 2em">言擇其發明心學者彚爲一編凡五百二十條而</span>  
<span style="margin-left: 2em">以已意推闡之大㫖亦主王守仁晚年定論</span>  
大儒心學語錄二十七卷<sub class="note-yuan">江蘇廵撫採進本</sub>  
<span style="margin-left: 2em">明王蓂撰是編亦其歸養之時所輯諸儒語錄凡</span>  
<span style="margin-left: 2em">周子程子張子邵子楊時謝良佐吕大臨尹焞羅</span>  
<span style="margin-left: 2em">從彦李侗胡宏朱子陸九淵張栻呂祖謙黄幹蔡</span>  
<span style="margin-left: 2em">沈陳淳眞德秀薛瑄吳與弼陳獻章胡居仁二十</span>  
<!-- 册3 葉385b　Page:文淵閣四庫全書_0003冊.djvu/101 -->
<span style="margin-left: 2em">四家皆論心學之語也</span>  
性理羣書集覽七十卷<sub class="note-yuan">江蘇廵撫採進本</sub>  
<span style="margin-left: 2em">不著撰人名氏但題<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3353.svg?width=24" alt="四庫全書僻字第3353號（⿰王𤔫 -- 瓊）" title="四庫全書僻字第3353號（⿰王𤔫 -- 瓊）">山玉<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2895.svg?width=24" alt="四庫全書僻字第2895號（峯）" title="四庫全書僻字第2895號（峯）">道人集覽不知爲</span>  
<span style="margin-left: 2em">誰其書取永樂性理大全中人名地名年號訓詁</span>  
<span style="margin-left: 2em">之𩔖依王㓜學通鑑綱目集覽之例各爲註釋有</span>  
<span style="margin-left: 2em">增注者卽别標爲附錄然淺陋殊甚如太極圖說</span>  
<span style="margin-left: 2em">後遂寜傅耆伯成句於遂寜下則詳註傅耆下則</span>  
<span style="margin-left: 2em">註未詳出處又如律吕新書内於梁武帝之通則</span>  
<span style="margin-left: 2em">註於晉荀朂之笛則不註葢出不學者所爲卷尾</span>  
<!-- 册3 葉388a　Page:文淵閣四庫全書_0003冊.djvu/102 -->
<span style="margin-left: 2em">有大德辛未刋行字尤爲舛謬是書本註性理大</span>  
<span style="margin-left: 2em">全安得大德中先有刊本考辛未爲明正德六年</span>
