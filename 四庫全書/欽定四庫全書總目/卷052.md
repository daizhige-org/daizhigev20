## 欽定四庫全書總目 卷五十二　史部八　雜史類存目一

<!-- 册2 葉648a　Page:文淵閣四庫全書_0002冊.djvu/167 -->
欽定四庫全書總目巻五十二  
<span style="margin-left: 1em">史部八</span>  
<span style="margin-left: 2em">雜史類存目一</span>  
左逸一卷短長一卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">是書凡左傳逸文三則戰國䇿逸文三則二書各</span>  
<span style="margin-left: 2em">有小引前稱嶧陽樵者𫉬石篋得竹簡漆書古文</span>  
<span style="margin-left: 2em">左傳讀之中有小牴牾三余得而錄之或謂秦漢</span>  
<span style="margin-left: 2em">人所傳而託也余不能辨後稱耕於齊野者地墳</span>  
<span style="margin-left: 2em">得大篆竹冊一袠曰短長劉向敘戰國䇿一名短</span>  
<!-- 册2 葉648b　Page:文淵閣四庫全書_0002冊.djvu/167 -->
<span style="margin-left: 2em">長所謂短長者豈戰國逸䇿歟然多載秦及漢初</span>  
<span style="margin-left: 2em">事意文景之世好奇之士僞托以撰前題延陵蔣</span>  
<span style="margin-left: 2em">謹手次及子世枋重訂又冠以世枋序稱二帙爲</span>  
<span style="margin-left: 2em">其先人手錄貯篋中者四十年未詳作者誰氏并</span>  
<span style="margin-left: 2em">所序嶧陽齊野二說亦不知何人惟是紀事用意</span>  
<span style="margin-left: 2em">筆法遒古非秦漢以下所能道隻字云云漆書竹</span>  
<span style="margin-left: 2em">簡豈能閱二千年而不毁其僞殊不足辨也</span>  
戰國䇿談棷十卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明張文爟撰文爟字維昇仁和人是書全用吳師</span>  
<!-- 册2 葉649a　Page:文淵閣四庫全書_0002冊.djvu/167 -->
<span style="margin-left: 2em">道補正鮑彪之本惟增入李斯諫逐客書楚人以</span>  
<span style="margin-left: 2em">弱弓微繳說頃襄王中山君饗都士大夫三章爲</span>  
<span style="margin-left: 2em">吳本所無註中國名人名或間補數言餘皆采諸</span>  
<span style="margin-left: 2em">家評語書之簡端冗雜特甚所謂談棷卽指是也</span>  
<span style="margin-left: 2em">棷集韻蘇后切與藪同談棷卽談藪特變易其字</span>  
<span style="margin-left: 2em">以見異耳</span>  
七雄䇿纂八卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">明穆文熙編文熙字敬止東明人嘉靖壬戌進士</span>  
<span style="margin-left: 2em">官吏部員外郞是編取戰國䇿之文加以評語並</span>  
<!-- 册2 葉649b　Page:文淵閣四庫全書_0002冊.djvu/167 -->
<span style="margin-left: 2em">集諸家議論附於上闌大抵剿襲陳因無所考證</span>  
戰國䇿去毒二卷<sub class="note-yuan">江蘇周厚堉家藏本</sub>  
<span style="margin-left: 1em">國朝陸隴其編隴其有古文尙書考已著錄此書前</span>  
<span style="margin-left: 2em">有自記謂戰國䇿一書其文章之奇足以悅人耳</span>  
<span style="margin-left: 2em">目而其機變之巧足以壞人心術如厚味之中有</span>  
<span style="margin-left: 2em">大毒焉故今舉文士所共讀者指示其得失庶幾</span>  
<span style="margin-left: 2em">嚌其味而不中其毒也故以去毒名其持論甚正</span>  
<span style="margin-left: 2em">然百家諸子各自爲書原不能盡繩以儒理旣以</span>  
<span style="margin-left: 2em">縱橫爲術又安怪其但言縱橫况自漢以來孔孟</span>  
<!-- 册2 葉652a　Page:文淵閣四庫全書_0002冊.djvu/168 -->
<span style="margin-left: 2em">之道大明如戰國䇿之類不過史家或考其事迹</span>  
<span style="margin-left: 2em">詞人或取其文章是以至今猶存原無人奉爲典</span>  
<span style="margin-left: 2em">型懸以立教與釋氏之近理亂眞異學之援儒入</span>  
<span style="margin-left: 2em">墨必須辨别者截然不同是固不必懲羮而吹虀</span>  
<span style="margin-left: 2em">也</span>  
藝祖受禪錄一卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">舊本題宋趙普曹彬同撰記太祖初生及幼時事</span>  
<span style="margin-left: 2em">特詳末云先是晉天福中兩浙兒童聚戲率以趙</span>  
<span style="margin-left: 2em">字爲語助如得曰趙得可曰趙可云云亦侈陳符</span>  
<!-- 册2 葉652b　Page:文淵閣四庫全書_0002冊.djvu/168 -->
<span style="margin-left: 2em">瑞之故智帝王受命自有本原豈以小兆爲驗耶</span>  
龍飛記一卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">舊本題宋趙普撰書作於建隆元年記太祖受禪</span>  
<span style="margin-left: 2em">事普時爲樞宻學士蓋太祖卽位之初也然普旣</span>  
<span style="margin-left: 2em">有受禪錄何以又爲此書疑與受禪錄皆後人所</span>  
<span style="margin-left: 2em">依託以普及曹彬爲文武佐命各假借其名耳</span>  
景命萬年錄一卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">不著撰人名氏記太祖受禪之事畧與趙普龍飛</span>  
<span style="margin-left: 2em">記同而叙得姓及前數代事特詳末載顯德末有</span>  
<!-- 册2 葉653a　Page:文淵閣四庫全書_0002冊.djvu/168 -->
<span style="margin-left: 2em">男子升中書政事堂據案而坐曰宋州官家教我</span>  
<span style="margin-left: 2em">來范質曰此人病風急遣之忽不見是時太祖始</span>  
<span style="margin-left: 2em">鎭許州至是乃驗云云頗類小說家言殊出於附</span>  
<span style="margin-left: 2em">會也</span>  
靑溪㓂軌一卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">宋方勺𢰅勺字仁聲婺州人元祐中蘇軾知杭州</span>  
<span style="margin-left: 2em">値省試嘗薦送之浙江通志載潘良貴之言稱其</span>  
<span style="margin-left: 2em">超然遐舉神情散朗如晉宋間高士似以隱遯終</span>  
<span style="margin-left: 2em">身者而所作泊宅編中記䖍州安遠龍南二縣有</span>  
<!-- 册2 葉653b　Page:文淵閣四庫全書_0002冊.djvu/168 -->
<span style="margin-left: 2em">瘴因自述其管勾常平季㸃到邑事則亦曾官於</span>  
<span style="margin-left: 2em">江右也是編記宣和二年靑溪妖㓂方臘作亂童</span>  
<span style="margin-left: 2em">貫譚稹等討平之事原載勺泊宅編中曹溶摘入</span>  
<span style="margin-left: 2em">學海類編因改題此名所述睦州之陷及譚稹之</span>  
<span style="margin-left: 2em">爲兩浙制置使劉延慶王禀王涣楊維忠之功皆</span>  
<span style="margin-left: 2em">與宋史不合葢傳聞異詞後附論二則其一追述</span>  
<span style="margin-left: 2em">魔教之始不署姓名其一署曰容齋追敘致亂之</span>  
<span style="margin-left: 2em">故甚詳併載韓世忠時爲王淵裨將潛行谿谷問</span>  
<span style="margin-left: 2em">野婦得徑卽挺身<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">前度險數重搗其穴格殺數</span>  
<!-- 册2 葉656a　Page:文淵閣四庫全書_0002冊.djvu/169 -->
<span style="margin-left: 2em">十人擒臘以出又稱泊宅翁之志冦軌也蘄王猶</span>  
<span style="margin-left: 2em">未知名故畧之且時宰猶多在朝臘等陰謀亦多</span>  
<span style="margin-left: 2em">忌諱故削不載今表而出之以戒後世司民者容</span>  
<span style="margin-left: 2em">齋爲洪邁之號疑或邁所附題歟宋史韓世忠傳</span>  
<span style="margin-left: 2em">載其平靑溪之功與此所載合當卽據此載入也</span>  
淸溪弄兵錄二卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">宋王彌大編彌大字約父爵里未詳是編記宣和</span>  
<span style="margin-left: 2em">中方臘冦睦州事分前後二篇其前篇從方勺泊</span>  
<span style="margin-left: 2em">宅編錄出其後篇從續會要第二百五十三卷出</span>  
<!-- 册2 葉656b　Page:文淵閣四庫全書_0002冊.djvu/169 -->
<span style="margin-left: 2em">師門中錄出後有自識稱嘉泰元年夏在金陵時</span>  
<span style="margin-left: 2em">命表姪陳知新摘錄以備㕘考葢裒合舊文非所</span>  
<span style="margin-left: 2em">自𢰅也靑溪縣卽今浙江淳安縣宋屬睦州字當</span>  
<span style="margin-left: 2em">作靑此本從水作淸傳寫者悞耳</span>  
避戎夜話一卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">宋石茂良𢰅案陳振孫書錄解題載茂良字太初</span>  
<span style="margin-left: 2em">其爵里則振孫亦未詳無可考也是編載靖康元</span>  
<span style="margin-left: 2em">年十一月金人陷汴京事葢親在圍城之内記所</span>  
<span style="margin-left: 2em">見聞其中多言都統制姚友仲守禦東南壁之功</span>  
<!-- 册2 葉657a　Page:文淵閣四庫全書_0002冊.djvu/169 -->
<span style="margin-left: 2em">史不爲友仲立傳然欽宗本紀頗採用之徐夢莘</span>  
<span style="margin-left: 2em">三朝北盟會編第九十八卷引此書有云汴京城</span>  
<span style="margin-left: 2em">陷僕逃難於鄉人王升卿舍館夜論朝廷守禦之</span>  
<span style="margin-left: 2em">方一話一言莫不驗其文摭其實<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">而不詐非所</span>  
<span style="margin-left: 2em">見聞則畧而不書云云葢茂良自敘之詞此本爲</span>  
<span style="margin-left: 2em">明末李蘅刋入璅探内者檢勘並無此文知爲删</span>  
<span style="margin-left: 2em">節不全之本矣尤袤遂初堂書目載有靖康夜話</span>  
<span style="margin-left: 2em">疑卽此書晁公武讀書志列金人背盟錄七卷圍</span>  
<span style="margin-left: 2em">城雜記一卷避戎夜話一卷金國行程十卷南歸</span>  
<!-- 册2 葉657b　Page:文淵閣四庫全書_0002冊.djvu/169 -->
<span style="margin-left: 2em">錄一卷朝野僉言一卷總注曰皇朝汪藻編記金</span>  
<span style="margin-left: 2em">人伐契丹迄於宣和乙巳犯京城圍城雜記等五</span>  
<span style="margin-left: 2em">書皆記靖康時事其意葢謂金人背盟錄以下六</span>  
<span style="margin-left: 2em">書皆靖康時人所作藻合而編之耳而其文義混</span>  
<span style="margin-left: 2em">淆似乎六書皆出於藻故有引是書爲藻作者其</span>  
<span style="margin-left: 2em">實書錄解題載朝野僉言爲夏少曾作南歸錄爲</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">秘閣沈琯作此書爲茂良作各有主名也况汪</span>  
<span style="margin-left: 2em">藻未從北行安得有金國行程乎</span>  
<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2854.svg?width=24" alt="四庫全書僻字第2854號（孤）" title="四庫全書僻字第2854號（孤）">臣泣血錄一卷<sub class="note-yuan">編修汪如藻家藏本</sub>  
<!-- 册2 葉660a　Page:文淵閣四庫全書_0002冊.djvu/170 -->
<span style="margin-left: 2em">舊本題宋太學丁特起撰所紀自欽宗靖康元年</span>  
<span style="margin-left: 2em">十一月五日起至高宗建炎元年五月一日卽位</span>  
<span style="margin-left: 2em">止載汴京失守二帝播遷之事徐夢莘北盟會編</span>  
<span style="margin-left: 2em">頗采之文獻通考載其書三卷又補遺一卷此本</span>  
<span style="margin-left: 2em">僅存一卷然首尾完具年月聯貫不似有所缺佚</span>  
<span style="margin-left: 2em">者殆由後人所合併耶其中稱范瓊爲高義而於</span>  
<span style="margin-left: 2em">瓊殺吳革一事亦無貶詞頗乖公論特起不知何</span>  
<span style="margin-left: 2em">許人又<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">書太學生丁特起上書者三皆不似自</span>  
<span style="margin-left: 2em">述之語前載特起自敘粗鄙少文其敘事亦多俚</span>  
<!-- 册2 葉660b　Page:文淵閣四庫全書_0002冊.djvu/170 -->
<span style="margin-left: 2em">語豈當時好事者所爲以特起上書有名故以託</span>  
<span style="margin-left: 2em">之歟此本爲明吳思所刊前有思序而附載汪旦</span>  
<span style="margin-left: 2em">復評語語皆凡鄙仍多舛誤如吳革起兵謀反正</span>  
<span style="margin-left: 2em">句實以當時僞楚僣號故以反正爲文乃誤讀正</span>  
<span style="margin-left: 2em">字屬上句謂以謀反書革乃特起之微詞則其謬</span>  
<span style="margin-left: 2em">不足與辨矣</span>  
靖康𫎇塵錄一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">不著𢰅人名氏所載宋徽欽二帝北狩事與世所</span>  
<span style="margin-left: 2em">傳南燼紀聞文多相同徐夢莘三朝北盟會編載</span>  
<!-- 册2 葉661a　Page:文淵閣四庫全書_0002冊.djvu/170 -->
<span style="margin-left: 2em">所採集書目甚詳亦無此書葢坊賈改易其名以</span>  
<span style="margin-left: 2em">欺世者卷後附有建炎復辟錄一卷似爲高宗苗</span>  
<span style="margin-left: 2em">劉之變而作而所紀仍北狩本末寥寥數條年月</span>  
<span style="margin-left: 2em">皆舛錯不合作僞之尤甚者也</span>  
靖康紀聞拾遺一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">不著𢰅人名氏案文獻通考載靖康拾遺錄一卷</span>  
<span style="margin-left: 2em">何烈𢰅又名靖康小史又名草史疑卽是書也考</span>
