## 欽定四庫全書總目 卷八十一　史部三十七　政書類一

欽定四庫全書總目卷八十一  
<span style="margin-left: 1em">史部三十七</span>  
<span style="margin-left: 2em">政書類一</span>  
<span style="margin-left: 3em">志藝文者有故事一類其間祖宗創法奕葉愼</span>  
<span style="margin-left: 3em">守者爲一朝之故事後鑒前師與時損益者爲</span>  
<span style="margin-left: 3em">前代之故事史家著錄大抵前代事也隋志載</span>  
<span style="margin-left: 3em">漢武故事濫及稗官唐志載魏文貞故事横牽</span>  
<span style="margin-left: 3em">家傳循名悞列義例殊乖今總核遺文惟以國</span>  
<span style="margin-left: 3em">政朝章六官所職者人於斯類以符周官故府</span>  
<!-- 册2 葉2709b　Page:文淵閣四庫全書_0002冊.djvu/682 -->
<span style="margin-left: 3em">之遺至儀注條格舊皆別出然均爲成憲義可</span>  
<span style="margin-left: 3em">同歸惟我</span>  
皇上制作日新垂模冊府業已恭登新笈未可仍襲舊  
<span style="margin-left: 3em">名考錢溥秘閣書目有政書一類謹據以標目</span>  
<span style="margin-left: 3em">見綜括古今之義焉</span>  
通典二百卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">唐杜佑撰佑字君<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">京兆萬年人以蔭補濟南參</span>  
<span style="margin-left: 2em">軍事厯官至檢校司徒同中書門下平章事守太</span>  
<span style="margin-left: 2em">保致仕諡安簡事蹟具唐書本傳先是劉秩倣周</span>  
<!-- 册2 葉2712a　Page:文淵閣四庫全書_0002冊.djvu/683 -->
<span style="margin-left: 2em">官之法摭拾百家分門詮次作政典三十五卷佑</span>  
<span style="margin-left: 2em">以爲未備因廣其所闕參益新體勒爲此書凡分</span>  
<span style="margin-left: 2em">八門曰食貨曰選舉曰職官曰禮曰樂曰兵刑曰</span>  
<span style="margin-left: 2em">州郡曰邊防每門又各分子目自序謂旣富而教</span>  
<span style="margin-left: 2em">故先食貨行教化在設官故次職官任官在於審</span>  
<span style="margin-left: 2em">材故次選舉人才得而治以理乃興禮樂故次禮</span>  
<span style="margin-left: 2em">次樂教化隳則用刑罸故次兵次刑設州郡分領</span>  
<span style="margin-left: 2em">故次州郡而終之以邊防所載上溯黃虞訖於唐</span>  
<span style="margin-left: 2em">之天寳肅代以後間有沿革亦附載注中其中如</span>  
<!-- 册2 葉2712b　Page:文淵閣四庫全書_0002冊.djvu/683 -->
<span style="margin-left: 2em">食貨門之賦稅載周官貢賦而太宰所掌九貢之</span>  
<span style="margin-left: 2em">法失載載北齊租調之法河淸三年令民十八受</span>  
<span style="margin-left: 2em">田輸租調而露田之數失載錢幣不載陳永定元</span>  
<span style="margin-left: 2em">年制四柱錢法𣙜酤不載後周𣙜酒坊法選舉門</span>  
<span style="margin-left: 2em">不載齊明帝時制士人品第有九品之科小人之</span>  
<span style="margin-left: 2em">官復有五等法考績不載宋齊間治民之官以三</span>  
<span style="margin-left: 2em">年六年爲小滿遷換法職官門如周禮地官有舍</span>  
<span style="margin-left: 2em">人上士二人掌宫中之政乃云中書舍人魏置又</span>  
<span style="margin-left: 2em">隋書大業時改内史監爲内書監乃僅云改内史</span>  
<!-- 册2 葉2713a　Page:文淵閣四庫全書_0002冊.djvu/683 -->
<span style="margin-left: 2em">侍耶爲内書侍郎又集賢殿書院載梁有文德殿</span>  
<span style="margin-left: 2em">藏書不知宋巳有聰明觀藏書之所似此之類未</span>  
<span style="margin-left: 2em">免間有挂漏兵門所列諸子目如分引退取之引</span>  
<span style="margin-left: 2em">退佯敗取之爲二門分出其不意擊其不備攻其</span>  
<span style="margin-left: 2em">不整爲三門未免稍渉繁冗而火獸火鳥之類尤</span>  
<span style="margin-left: 2em">近於戲劇州郡門分九州以敘沿革而信都郡冀</span>  
<span style="margin-left: 2em">州當屬兗而誤屬冀又極詆水經及酈道元水經</span>  
<span style="margin-left: 2em">注爲僻書詭誕不經未免過當邊防門所載多數</span>  
<span style="margin-left: 2em">萬里外重譯乃通之國亦有僅傳其名不通朝貢</span>  
<!-- 册2 葉2713b　Page:文淵閣四庫全書_0002冊.djvu/683 -->
<span style="margin-left: 2em">者旣不臨邊亦無事於防題曰邊防名實亦舛然</span>  
<span style="margin-left: 2em">其傳取五經羣史及漢魏六朝人文集奏疏之有</span>  
<span style="margin-left: 2em">裨得失者毎事以類相從凡厯代沿革悉爲記載</span>  
<span style="margin-left: 2em">詳而不煩簡而有要元元本本皆爲有用之實學</span>  
<span style="margin-left: 2em">非𢓺資記問者可比考唐以前之掌故者兹編其</span>  
<span style="margin-left: 2em">淵海矣至其各門徵引尙書周書諸條多存舊詁</span>  
<span style="margin-left: 2em">如食貨門引尙書下土墳壚注謂壚疎也與孔疏</span>  
<span style="margin-left: 2em">所引說文黒剛士也互異又瑶琨篠簜注篠竹箭</span>  
<span style="margin-left: 2em">簜大竹亦傳疏所未備職官門引周官太宰之屬</span>  
<!-- 册2 葉2716a　Page:文淵閣四庫全書_0002冊.djvu/684 -->
<span style="margin-left: 2em">有司會逆羣吏之治而聽其會計注云逆謂受也</span>  
<span style="margin-left: 2em">受而鉤考之可知得失多少較賈公彦疏頗爲明</span>  
<span style="margin-left: 2em">晰似此之類尤頗有補於經訓宋鄭樵作通志與</span>  
<span style="margin-left: 2em">馬端臨作文獻通考悉以是書爲藍本然鄭多泛</span>  
<span style="margin-left: 2em">雜無歸馬或詳畧失當均不及是書之精核也</span>  
唐會要一百卷<sub class="note-yuan">浙江江啟淑家藏本</sub>  
<span style="margin-left: 2em">宋王溥撰溥字齊物幷州祁人漢乾祐中登進士</span>  
<span style="margin-left: 2em">第一周廣順初拜端明殿學士恭帝嗣位官右僕</span>  
<span style="margin-left: 2em">射入宋仍故官進司空同平章事監修國史加太</span>  
<!-- 册2 葉2716b　Page:文淵閣四庫全書_0002冊.djvu/684 -->
<span style="margin-left: 2em">子太師封祁國公卒諡康定事迹具宋史本傳初</span>  
<span style="margin-left: 2em">唐蘇冕嘗次高祖至德宗九朝之事爲會要四十</span>  
<span style="margin-left: 2em">卷宣宗大中七年又詔楊紹復等次德宗以來事</span>  
<span style="margin-left: 2em">爲續會要四十卷以崔<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）">監修叚公路北戸錄所</span>  
<span style="margin-left: 2em">稱會要卽冕等之書也惟宣宗以後記載尙缺溥</span>  
<span style="margin-left: 2em">因復採宣宗至唐末事續之爲新編唐會要一百</span>  
<span style="margin-left: 2em">卷建隆二年正月奏御詔藏史館書凡分目五百</span>  
<span style="margin-left: 2em">十有四於唐代沿革損益之制極其詳核官號内</span>  
<span style="margin-left: 2em">有識量忠諫舉賢委任崇樊諸條亦頗載事蹟其</span>  
<!-- 册2 葉2717a　Page:文淵閣四庫全書_0002冊.djvu/684 -->
<span style="margin-left: 2em">細𤨏典故不能槪以定目者則別爲雜錄附於各</span>  
<span style="margin-left: 2em">條之後又間載蘇冕駁議義例該備有裨考証今</span>  
<span style="margin-left: 2em">僅傳抄本脫誤頗多八卷題曰郊儀而所載乃南</span>  
<span style="margin-left: 2em">唐事九卷題曰雜郊儀而所載乃唐初奏疏皆與</span>  
<span style="margin-left: 2em">目錄不相應七卷十卷亦多錯入他文葢原書殘</span>  
<span style="margin-left: 2em">缺而後人妄摭竄入以盈卷帙又一別本所闕四</span>  
<span style="margin-left: 2em">卷亦同而有補亡四卷採摭諸書所載唐事依原</span>  
<span style="margin-left: 2em">目編類雖未必合溥之舊本而宏綱細目約畧粗</span>  
<span style="margin-left: 2em">具猶可以見其大凡今據以錄入仍各註補字於</span>  
<!-- 册2 葉2717b　Page:文淵閣四庫全書_0002冊.djvu/684 -->
<span style="margin-left: 2em">標目之下以示區別焉</span>  
五代會要三十卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">宋王溥撰五代干戈俶攘百度凌夷故府遺規多</span>  
<span style="margin-left: 2em">未暇修舉然五十年間法制典章尙畧具於累朝</span>  
<span style="margin-left: 2em">實錄溥因檢尋舊史條分件繫類輯成編建隆二</span>  
<span style="margin-left: 2em">年與唐會要並進詔藏史館後歐陽修作五代史</span>  
<span style="margin-left: 2em">僅列司天職方二考其他均未之及如晉叚顒劉</span>  
<span style="margin-left: 2em">昫等之議廟制用王朴之議樂皆事關鉅典亦畧</span>  
<span style="margin-left: 2em">而不詳又如經籍鏤板昉自長興千古官書肇端</span>  
<!-- 册2 葉2720a　Page:文淵閣四庫全書_0002冊.djvu/685 -->
<span style="margin-left: 2em">於是崇文善政豈宜削而不書乃一槪刋除尤爲</span>  
<span style="margin-left: 2em">漏畧頼溥是編得以收放失之舊聞厥功甚偉至</span>  
<span style="margin-left: 2em">於租稅類中載周世宗讀長慶集見元微之所上</span>  
<span style="margin-left: 2em">均田表因令製素成圖頒賜諸道而歐史乃云世</span>  
<span style="margin-left: 2em">宗見元微之均田圖是<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">以圖爲元微之作乖舛</span>  
<span style="margin-left: 2em">尤甚微溥是編亦無由訂歐史之謬也葢歐史務</span>  
<span style="margin-left: 2em">談褒貶爲春秋之遺法是編務核典章爲周官之</span>  
<span style="margin-left: 2em">舊例各明一義相輔而行讀五代史者又何可無</span>  
<span style="margin-left: 2em">此一書哉</span>  
<!-- 册2 葉2720b　Page:文淵閣四庫全書_0002冊.djvu/685 -->
宋朝事實二十卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋李攸撰文獻通考作李伋按攸字好德義從洪</span>  
<span style="margin-left: 2em">範若作伋字與好德之意不符宋史藝文志亦作</span>  
<span style="margin-left: 2em">李攸通考葢傳寫誤也陳振孫書錄解題稱其官</span>  
<span style="margin-left: 2em">爲承議郎而不詳其里貫原序稱政和初編輯西</span>  
<span style="margin-left: 2em">山圖經九域志等書瀘帥孫義叟招之書上轉一</span>  
<span style="margin-left: 2em">官張浚入朝約與俱以家事辭攷西山屬成都府</span>  
<span style="margin-left: 2em">瀘州屬潼川路則攸當爲蜀人其曰張浚入朝葢</span>  
<span style="margin-left: 2em">紹興四年浚自川陜宣撫使召還時也其書據原</span>  
<!-- 册2 葉2721a　Page:文淵閣四庫全書_0002冊.djvu/685 -->
<span style="margin-left: 2em">序葢上起建隆下迄宣和凡六十卷其三十卷先</span>  
<span style="margin-left: 2em">聞於時後以餘三十卷上之因語觸秦檜寢其書</span>  
<span style="margin-left: 2em">不報故晁陳二家書目俱作三十卷與序相合而</span>  
<span style="margin-left: 2em">趙希弁讀書附志宋史藝文志乃俱作三十五卷</span>  
<span style="margin-left: 2em">今書中有高孝兩朝登極赦詔及紹興間南郊赦</span>  
<span style="margin-left: 2em">詔而紀元亦迄於紹興殆又有所附益兼及南宋</span>  
<span style="margin-left: 2em">之初歟攸熟於掌故經靖康兵燹之後圖籍散佚</span>  
<span style="margin-left: 2em">獨汲汲搜輯舊聞使一代典章粲然具備其用力</span>  
<span style="margin-left: 2em">頗爲勤摯所載厯朝登極南郊大赦詔令太宗親</span>  
<!-- 册2 葉2721b　Page:文淵閣四庫全書_0002冊.djvu/685 -->
<span style="margin-left: 2em">製趙普碑銘西京崇福宫記景靈西宫記大晟樂</span>  
<span style="margin-left: 2em">記往往爲宋文鑑名臣碑傳琬琰集播芳大全諸</span>  
<span style="margin-left: 2em">書所闕漏他如宗室換官之制不見於宋史職官</span>  
<span style="margin-left: 2em">志郊祀勘箭之儀不詳於禮志太廟崇寧廟圖紫</span>  
<span style="margin-left: 2em">宸殿集英殿上壽賜宴再坐立班起居諸圖宫架</span>  
<span style="margin-left: 2em">鼓吹十二按圖尤爲記宋代掌故者所未備至其</span>  
<span style="margin-left: 2em">事蹟之異同年月之先後紀載之詳畧尤多可與</span>  
<span style="margin-left: 2em">東都事畧續通鑑長編及宋史互相叅訂又如石</span>  
<span style="margin-left: 2em">晉賂契丹十六州分代北山前山後足訂薛歐五</span>  
<!-- 册2 葉2724a　Page:文淵閣四庫全書_0002冊.djvu/686 -->
<span style="margin-left: 2em">代史稱山後十六州之誤周世宗兵下三關並載</span>  
<span style="margin-left: 2em">淤口關亦足補薛歐二史祗載瓦橋益津二關之</span>  
<span style="margin-left: 2em">闕當時如江少虞事實類苑錦繡萬花谷多引用</span>  
<span style="margin-left: 2em">之宋史亦多採用其文第原本久佚惟散見於永</span>  
<span style="margin-left: 2em">樂大典各韻下者尙存梗槪而割裂𤨏碎莫由考</span>
