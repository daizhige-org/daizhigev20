## 欽定四庫全書總目 卷一百三十六　子部四十六　類書類二

<!-- 册3 葉3492：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷一百三十六  
<span style="margin-left: 1em">子部四十六</span>  
<span style="margin-left: 2em">𩔖書𩔖二</span>  
？正𫎇求三卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">元胡炳文撰炳文有周易本義通釋已著錄𫎇求</span>  
<span style="margin-left: 2em">自李瀚以下仿其體者數家大抵雜採經傳事實</span>  
<span style="margin-left: 2em">隸以韻語以便童子之記誦然多以對偶求工不</span>  
<span style="margin-left: 2em">盡有闗於法戒炳文是書則集古嘉言善行各以</span>  
<span style="margin-left: 2em">四字屬對成文而自注其出處於下所載皆有裨</span>  
<!-- 册3 葉3493b　Page:文淵閣四庫全書_0003冊.djvu/878 -->
<span style="margin-left: 2em">㓜學之事以視餖飣割裂僅供口耳者於啟導較</span>  
<span style="margin-left: 2em">爲切近上卷敘立教明倫之事中卷敘立身行已</span>  
<span style="margin-left: 2em">之事下卷敘待人接物之事畧以白鹿洞規爲準</span>  
<span style="margin-left: 2em">每卷一百二十句總爲三百六十句卷中又各有</span>  
<span style="margin-left: 2em">子目每一目多者一二十句少者不過四句中間</span>  
<span style="margin-left: 2em">以拘於駢儷格於聲韻故漏落甚多又如黄香暖</span>  
<span style="margin-left: 2em">席宜入父子之倫而反入幼學見趣條下陳子髙</span>  
<span style="margin-left: 2em">讓田宜入長㓜之倫而反入處宗族條下其分隸</span>  
<span style="margin-left: 2em">亦未能悉允然養𫎇之教取其顯明易曉不貴以</span>  
<!-- 册3 葉3496a　Page:文淵閣四庫全書_0003冊.djvu/879 -->
<span style="margin-left: 2em">淹博相高此書循諷吟哦以資感發與朱子小學</span>  
<span style="margin-left: 2em">外篇足相表裏固未可以淺近廢也</span>  
排韻増廣事𩔖氏族大全二十卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">不著撰人名氏書中所引事蹟迄於南宋季年葢</span>  
<span style="margin-left: 2em">元人所編次相其板式亦建陽麻沙所刋乃當時</span>  
<span style="margin-left: 2em">書肆本也其例以十干分集毎一集爲二卷依廣</span>  
<span style="margin-left: 2em">韻次第以四聲分隸各姓末一卷爲覆姓則以上</span>  
<span style="margin-left: 2em">一字爲韻而排次之每姓俱引史傳人物摘敘大</span>  
<span style="margin-left: 2em">略而採其中三四字爲標題大抵在擷取新頴以</span>  
<!-- 册3 葉3496b　Page:文淵閣四庫全書_0003冊.djvu/879 -->
<span style="margin-left: 2em">供綴文之用姓末多别附女德婚姻一門厯敘古</span>  
<span style="margin-left: 2em">來淑媛及兩姓結婚故事葢宋元之間婚禮必有</span>  
<span style="margin-left: 2em">四六書啟故載之獨詳亦以便於剽掇也葉盛水</span>  
<span style="margin-left: 2em">東日記曰近代雜書著述考據多不精如翰墨全</span>  
<span style="margin-left: 2em">書以彭思永爲明道母舅所謂氏族大全者尤甚</span>  
<span style="margin-left: 2em">如以趙明誠爲趙抃之子廣州十賢有李朝隱一</span>  
<span style="margin-left: 2em">作李尙隱因而訛爲李商隱今考中間所列朝代</span>  
<span style="margin-left: 2em">先後多顚倒失次如王導妾雷氏干預政事陳之</span>  
<span style="margin-left: 2em">張貴妃龔孔二嬪怙寵亡國而並入之女德則深</span>  
<!-- 册3 葉3497a　Page:文淵閣四庫全書_0003冊.djvu/879 -->
<span style="margin-left: 2em">爲不倫又如韋思廉劉奉林諸人旣别立仙之一</span>  
<span style="margin-left: 2em">目而張果姜識諸人亦以仙術顯名乃仍混入人</span>  
<span style="margin-left: 2em">物之中無所區别體例亦殊疎舛至每姓之末間</span>  
<span style="margin-left: 2em">附韻藻數語如洪韻龎洪涵洪翁韻仙翁塞翁之</span>  
<span style="margin-left: 2em">𩔖旣與氏族不相闗渉且掛漏無取徒滋蛇足特</span>  
<span style="margin-left: 2em">捃摭尙爲廣博有其人爲史傳志乘所不詳而獨</span>  
<span style="margin-left: 2em">見於此者頗足以資旁證至於王氏有臨沂太原</span>  
<span style="margin-left: 2em">二𣲖勾氏避宋高宗諱分作數姓蘭亭會詩名氏</span>  
<span style="margin-left: 2em">諸本之不同亦間附考訂寸有所長固未嘗無裨</span>  
<!-- 册3 葉3497b　Page:文淵閣四庫全書_0003冊.djvu/879 -->
<span style="margin-left: 2em">於藝苑也</span>  
名疑四卷<sub class="note-yuan">河南巡撫採進本</sub>  
<span style="margin-left: 2em">明陳士元撰士元有易象鈎解已著錄是書上自</span>  
<span style="margin-left: 2em">三皇下迄元代博採史傳及百家雜說凡古人姓</span>  
<span style="margin-left: 2em">名異字及更名更字與同姓名者皆彚萃之其中</span>  
<span style="margin-left: 2em">如以司馬遷諱談爲同遂謂談同一音以童烏爲</span>  
<span style="margin-left: 2em">揚雄小字以揚雄本姓楊字訛爲揚字之類間有</span>  
<span style="margin-left: 2em">訛誤又神仙<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">怪之名如吳剛姮娥豐隆屏翳神</span>  
<span style="margin-left: 2em">荼鬱壘等皆詳載之體例亦頗冗雜然其採摭繁</span>  
<!-- 册3 葉3500a　Page:文淵閣四庫全書_0003冊.djvu/880 -->
<span style="margin-left: 2em">富頗廣見聞如洞神部載三皇姓名列仙傳稱介</span>  
<span style="margin-left: 2em">子推姓王名光之𩔖皆指駁其謬又據史記佞幸</span>  
<span style="margin-left: 2em">傳辨朱建傳誤閎孺爲閎籍孺據顔延之誄辨陶</span>  
<span style="margin-left: 2em">徵士名淵明字元亮亦皆有所根據存以備考固</span>  
<span style="margin-left: 2em">亦有資參證焉</span>  
荆川稗編一百二十卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明唐順之編順之有廣右戰功錄已著錄是編義</span>  
<span style="margin-left: 2em">例畧仿章如愚山堂考索薈萃羣言區分𩔖聚其</span>  
<span style="margin-left: 2em">大旨欲使萬事萬物畢貫通於一書故鉅細兼陳</span>  
<!-- 册3 葉3500b　Page:文淵閣四庫全書_0003冊.djvu/880 -->
<span style="margin-left: 2em">門目浩博始之以六經終之以六官六經所不能</span>  
<span style="margin-left: 2em">盡則條次以九流諸家之學術凡爲𩔖二十有七</span>  
<span style="margin-left: 2em">六官所不能盡則賅括以厯代之史傳凡爲𩔖二</span>  
<span style="margin-left: 2em">十有五其門人左烝先爲之考校付梓烝没而書</span>  
<span style="margin-left: 2em">多殘缺茅一相復加𨤲正刋行所引書名人名原</span>  
<span style="margin-left: 2em">本錯互不合者一相亦爲訂正然卷帙旣繁檢校</span>  
<span style="margin-left: 2em">難徧牴牾舛駁尙往往而有如程大昌詩議在所</span>  
<span style="margin-left: 2em">撰考古編中而乃以爲出自新安文獻志正諫本</span>  
<span style="margin-left: 2em">說苑篇名而標之爲論林泉高致集所載荆浩山</span>  
<!-- 册3 葉3501a　Page:文淵閣四庫全書_0003冊.djvu/880 -->
<span style="margin-left: 2em">水賦李成山水訣乃其人所自作而槩以爲出郭</span>  
<span style="margin-left: 2em">思之手敖陶孫字器之而訛作孫器之陶九成輟</span>  
<span style="margin-left: 2em">耕錄天䦧之說與鑑戒無闗而濫引入宦者門中</span>  
<span style="margin-left: 2em">褚淵王儉雖身事二姓然不可謂之佞臣乃列其</span>  
<span style="margin-left: 2em">傳論於倖門此𩔖不知爲原本之訛爲茅一相之</span>  
<span style="margin-left: 2em">竄亂玉瑕珠纇頗累全書特以其網羅本富渉獵</span>  
<span style="margin-left: 2em">攸資當語錄盛行之時尙不失爲徵實之學錄備</span>  
<span style="margin-left: 2em">多識之一助固亦無不可焉</span>  
萬姓統譜一百二十六卷<sub class="note-yuan">直隸總督採進本</sub>  
<!-- 册3 葉3501b　Page:文淵閣四庫全書_0003冊.djvu/880 -->
<span style="margin-left: 2em">明凌迪知撰迪知有左國腴詞已著錄是書以古</span>  
<span style="margin-left: 2em">今姓氏分韻編次略仿林寳元和姓纂以厯代名</span>  
<span style="margin-left: 2em">人履貫事蹟按次時代分隷各姓下又仿章定名</span>  
<span style="margin-left: 2em">賢氏族言行𩔖藁名爲姓譜實則合譜牒傳記而</span>  
<span style="margin-left: 2em">共成一𩔖事之書也古者族系掌於官故周禮小</span>  
<span style="margin-left: 2em">史定世系辨昭穆南史王僧䖍傳稱司馬遷仿周</span>  
<span style="margin-left: 2em">譜以作年表其體皆旁行斜上是其制也戰國策</span>  
<span style="margin-left: 2em">稱智果别族於太史爲輔氏是周末法猶未改秦</span>  
<span style="margin-left: 2em">漢以下始私相記錄自世本以下纂述不一其存</span>  
<!-- 册3 葉3504a　Page:文淵閣四庫全書_0003冊.djvu/881 -->
<span style="margin-left: 2em">於今者惟林寳鄧名世鄭樵三家餘皆散佚然散</span>  
<span style="margin-left: 2em">見他書者尙可考見不過明世系辨流品而已迨</span>  
<span style="margin-left: 2em">乎南宋啟劄盛行駢偶之文務切姓氏於是錦繡</span>  
<span style="margin-left: 2em">萬花谷合璧事𩔖各有𩔖姓一門元人排韻氏族</span>  
<span style="margin-left: 2em">大全而下作者彌衆其合諸家之書勒爲一帙者</span>  
<span style="margin-left: 2em">則迪知此編稱賅備焉其中龎雜牴牾均所不免</span>  
<span style="margin-left: 2em">至於遼金元三史姓氏音譯失眞舛訛尤甚然蒐</span>  
<span style="margin-left: 2em">羅旣廣足備考訂故世俗頗行用之亦未可盡廢</span>  
<span style="margin-left: 2em">也書前别有氏族博考十四卷大旨皆本之氏族</span>  
<!-- 册3 葉3504b　Page:文淵閣四庫全書_0003冊.djvu/881 -->
<span style="margin-left: 2em">畧無大發明以其與原本相附而行今亦姑並錄</span>  
<span style="margin-left: 2em">之焉</span>  
喻林一百二十卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明徐元太撰元太字汝賢宣城人嘉靖乙丑進士</span>  
<span style="margin-left: 2em">官至刑部尙書是書採摭古人設譬之詞彚爲二</span>  
<span style="margin-left: 2em">編分十門毎門又各分子目凡五百八十餘𩔖厯</span>  
<span style="margin-left: 2em">二十餘年而後成用心頗爲勤至其引書用程大</span>  
<span style="margin-left: 2em">昌演繁露之例皆於條下注明岀處併篇目卷第</span>  
<span style="margin-left: 2em">一一臚載亦迥異明人剽竊撦撏之習其自序稱</span>  
<!-- 册3 葉3505a　Page:文淵閣四庫全書_0003冊.djvu/881 -->
<span style="margin-left: 2em">閱書四百餘種而檢其所列書名實不逾半殆約</span>  
<span style="margin-left: 2em">舉其數未及詳核歟其中隨手摭拾亦往往不得</span>  
<span style="margin-left: 2em">本始如兒說宋人善辯者一條本出韓非子周人</span>  
<span style="margin-left: 2em">有仕不遇者一條本出王充論衡皆引藝文𩔖聚</span>  
<span style="margin-left: 2em">懷金玉者至不生歸一條本出後漢書耿弇傳而</span>  
<span style="margin-left: 2em">引文選李善注頭白可期汗靑無日一條本出劉</span>  
<span style="margin-left: 2em">知幾史通而引事文𩔖聚天寒卽飛鳥走獸尙知</span>  
<span style="margin-left: 2em">相依一條本出沈約所作阮籍詠懷詩注而亦以</span>  
<span style="margin-left: 2em">爲李善此類頗多又如以杜預何休范甯爲漢人</span>  
<!-- 册3 葉3505b　Page:文淵閣四庫全書_0003冊.djvu/881 -->
<span style="margin-left: 2em">以陳壽爲魏人以李善爲隋人皆時代舛迕申培</span>  
<span style="margin-left: 2em">詩說天祿閣外史武侯心書之𩔖皆明代僞書不</span>  
<span style="margin-left: 2em">能辨别廣成子本蘇軾從莊子摘出偶題此名乃</span>  
<span style="margin-left: 2em">别爲一書無能子云不知何代人皆未免失於疎</span>  
<span style="margin-left: 2em">畧然自六經以來卽多以況譬達意而自古未有</span>  
<span style="margin-left: 2em">彚爲一書者元太是編實爲剏例其蒐羅繁富零</span>  
<span style="margin-left: 2em">璣斷璧均足爲掇文者沾丐之資是亦不可無一</span>  
<span style="margin-left: 2em">之書矣</span>  
經濟𩔖編一百卷<sub class="note-yuan">山東巡撫採進本</sub>  
<!-- 册3 葉3508a　Page:文淵閣四庫全書_0003冊.djvu/882 -->
<span style="margin-left: 2em">明馮琦編琦字琢菴臨胊人萬厯丁丑進士官至</span>  
<span style="margin-left: 2em">禮部尙書諡文敏事蹟具明史本傳是編爲琦手</span>  
<span style="margin-left: 2em">錄之稿粗分門𩔖琦没之後其弟瑗與其門人周</span>  
<span style="margin-left: 2em">家楝吳光儀稍爲排纂且刪其重複定爲帝王政</span>  
<span style="margin-left: 2em">治儲宮宮掖臣諫諍銓衡財賦禮儀樂文學武功</span>  
<span style="margin-left: 2em">邊塞刑罰工虞天地人倫人品人事道術物雜言</span>  
<span style="margin-left: 2em">二十三𩔖大致與冊府元龜互相出入但冊府元</span>  
<span style="margin-left: 2em">龜惟隸事迹此則兼錄文章冊府元龜惟以史傳</span>  
<span style="margin-left: 2em">爲據此則諸子百家靡不捃拾體例少異耳其中</span>  
<!-- 册3 葉3508b　Page:文淵閣四庫全書_0003冊.djvu/882 -->
<span style="margin-left: 2em">採摭繁富頗爲賅洽史稱琦明習典故學有根柢</span>  
<span style="margin-left: 2em">此亦可見一斑惟此書旣非琦所手校其間所錄</span>

<span style="margin-left: 2em">之餘論也然詩文隸事在於比例精切詞藻典雅</span>  
<span style="margin-left: 2em">不必限以時代漢去戰國不遠而詞賦多用戰國</span>  
<span style="margin-left: 2em">事六朝去漢不遠而詞賦多用漢事唐去六朝不</span>  
<span style="margin-left: 2em">遠而詞賦多用六朝事今距唐幾千年距宋元亦</span>  
<span style="margin-left: 2em">數百年而曰唐以後事不可用豈通論歟况唐代</span>

<span style="margin-left: 2em">稽近有所考源流本末一一燦然計其卷數雖僅</span>  
<span style="margin-left: 2em">及太平御覽之半然御覽以數頁爲一卷此則篇</span>  
<span style="margin-left: 2em">帙旣繁兼以密行細字計其所載實倍於御覽葢</span>

<span style="margin-left: 2em">矣與佩文韻府駢字𩔖編皆亘古所無之巨製不</span>  
<span style="margin-left: 2em">數宋之四大書也</span>

<span style="margin-left: 2em">萬八千餘頁藝林傳布已浩若望洋而</span>

<span style="margin-left: 2em">備者謂之補注東字下引周易折中集說居東諸</span>  
<span style="margin-left: 2em">條是也蒐羅賅備體例詳明大學士王掞等恭製</span>
