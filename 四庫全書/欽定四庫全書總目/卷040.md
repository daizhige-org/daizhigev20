## 欽定四庫全書總目 卷四十　經部四十　小學類一

<!-- 册1 葉3269a　Page:文淵閣四庫全書_0001冊.djvu/867 -->
欽定四庫全書總目卷四十  
<span style="margin-left: 1em">經部四十</span>  
<span style="margin-left: 2em">小學類一</span>  
<span style="margin-left: 3em">古小學所敎不過六書之類故漢志以弟子職</span>  
<span style="margin-left: 3em">附孝經而史籀等十家四十五篇列爲小學隋</span>  
<span style="margin-left: 3em">志增以金石刻文唐志增以書法書品已非初</span>  
<span style="margin-left: 3em">旨自朱子作小學以配大學趙希弁讀書附志</span>  
<span style="margin-left: 3em">遂以弟子職之類併入小學又以𫎇求之類相</span>  
<span style="margin-left: 3em">叅並列而小學益多岐矣考訂源流惟漢志根</span>  
<!-- 册1 葉3269b　Page:文淵閣四庫全書_0001冊.djvu/867 -->
<span style="margin-left: 3em">據經義要爲近古今以論幼儀者別入儒家以</span>  
<span style="margin-left: 3em">論筆法者别入雜藝以𫎇求之屬𨽻故事以便</span>  
<span style="margin-left: 3em">記誦者别入類書惟以爾雅以下編爲訓詁說</span>  
<span style="margin-left: 3em">文以下編爲字書廣韻以下編爲韻書庶體例</span>  
<span style="margin-left: 3em">謹嚴不失古義其有兼舉兩家者則各以所重</span>  
<span style="margin-left: 3em">爲主<sub class="note-yuan">如李燾說文五音韻譜實字書袁子讓字學元元實論等韻之類</sub>悉條其</span>  
<span style="margin-left: 3em">得失具於本篇</span>  
爾雅註疏十卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">晉郭璞註宋邢昺疏璞字景純河東聞喜人官至</span>  
<!-- 册1 葉3272a　Page:文淵閣四庫全書_0001冊.djvu/868 -->
<span style="margin-left: 2em">宏農太守事迹具晉書本傳昺有孝經疏已著錄</span>  
<span style="margin-left: 2em">案大戴禮孔子三朝記稱孔子敎魯哀公學爾雅</span>  
<span style="margin-left: 2em">則爾雅之來遠矣然不云爾雅爲誰作據張揖進</span>  
<span style="margin-left: 2em">廣雅表稱周公著爾雅一篇<sub class="note-yuan">案經典釋文以揖所稱一篇爲釋詁</sub>今</span>  
<span style="margin-left: 2em">俗所傳三篇<sub class="note-yuan">案漢志爾雅三卷此三篇謂三卷也</sub>或言仲尼所增或</span>  
<span style="margin-left: 2em">言子夏所益或言叔孫通所補或言沛郡梁文所</span>  
<span style="margin-left: 2em">考皆解家所說疑莫能明也於作書之人亦無<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）"></span>  
<span style="margin-left: 2em">指其餘諸家所說小異大同今參互而考之郭璞</span>  
<span style="margin-left: 2em">爾雅註序稱豹鼠旣辨其業亦顯邢昺疏以爲漢</span>  
<!-- 册1 葉3272b　Page:文淵閣四庫全書_0001冊.djvu/868 -->
<span style="margin-left: 2em">武帝時終軍事七錄載犍爲文學爾雅註三卷<sub class="note-yuan">案七</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">錄久佚此據隋志所稱梁有某書亡知爲七錄所載</sub>陸德明經典釋文以爲</span>  
<span style="margin-left: 2em">漢武帝時人則其書在武帝以前曹粹中放齋詩</span>  
<span style="margin-left: 2em">說曰<sub class="note-yuan">按此書今未見傳本此據永樂大典所引</sub>爾雅毛公以前其文猶</span>  
<span style="margin-left: 2em">畧至鄭康成時則加詳如學有緝熙于光明毛公</span>  
<span style="margin-left: 2em">云光廣也康成則以爲學於有光明者而爾雅曰</span>  
<span style="margin-left: 2em">緝熙光明也又齊子豈弟康成以爲猶發夕也而</span>  
<span style="margin-left: 2em">爾雅曰豈弟發也薄言觀者毛公無訓振古如兹</span>  
<span style="margin-left: 2em">毛公云振自也康成則以觀爲多以振爲古其說</span>  
<!-- 册1 葉3273a　Page:文淵閣四庫全書_0001冊.djvu/868 -->
<span style="margin-left: 2em">皆本於爾雅使爾雅成書在毛公之前顧得爲異</span>  
<span style="margin-left: 2em">哉則其書在毛亨以後<sub class="note-yuan">案詩傳乃毛亨作非毛萇作語詳詩正義條下</sub>大</span>  
<span style="margin-left: 2em">抵小學家綴緝舊文遞相增益周公孔子皆依託</span>  
<span style="margin-left: 2em">之詞觀釋地有鶼鶼釋鳥又有鶼鶼同文複出知</span>  
<span style="margin-left: 2em">非纂自一手也其書歐陽修詩本義以爲學詩者</span>  
<span style="margin-left: 2em">纂集博士解詁高承事物紀原亦以爲大抵解詁</span>  
<span style="margin-left: 2em">詩人之旨然釋詩者不及十之一非專爲詩作揚</span>  
<span style="margin-left: 2em">雄方言以爲孔子門徒解釋六藝王充論衡亦以</span>  
<span style="margin-left: 2em">爲五經之訓故然釋五經者不及十之三四更非</span>  
<!-- 册1 葉3273b　Page:文淵閣四庫全書_0001冊.djvu/868 -->
<span style="margin-left: 2em">專爲五經作今觀其文大抵採諸書訓詁名物之</span>  
<span style="margin-left: 2em">同異以廣見聞實自爲一書不附經義如釋天云</span>  
<span style="margin-left: 2em">暴雨謂之涷釋草云卷施草㧞心不死此取楚詞</span>  
<span style="margin-left: 2em">之文也釋天云扶搖謂之猋釋蟲云蒺藜蝍蛆此</span>  
<span style="margin-left: 2em">取莊子之文也釋詁云嫁往也釋水云瀵大岀尾</span>  
<span style="margin-left: 2em">下此取列子之文也釋地云西至西王母釋獸云</span>  
<span style="margin-left: 2em">小領盗驪此取穆天子傳之文也釋地云東方有</span>  
<span style="margin-left: 2em">比目魚焉不比不行其名謂之鰈南方有比翼鳥</span>  
<span style="margin-left: 2em">焉不比不飛其名謂之鶼此取管子之文也又云</span>  
<!-- 册1 葉3276a　Page:文淵閣四庫全書_0001冊.djvu/869 -->
<span style="margin-left: 2em">卭卭岠虛負而走其名謂之蟨此取吕氏春秋之</span>  
<span style="margin-left: 2em">文也又云北方有比肩民焉迭食而迭望釋地云</span>  
<span style="margin-left: 2em">河出崑崙墟此取山海經之文也釋言云天帝皇</span>  
<span style="margin-left: 2em">王后辟公侯又云洪廓宏溥介純夏幠釋天云春</span>  
<span style="margin-left: 2em">爲靑陽至謂之醴泉此尸子之文也釋鳥曰爰居</span>  
<span style="margin-left: 2em">雜縣此取國語之文也如是之類不可殫數葢亦</span>  
<span style="margin-left: 2em">方言急就之流特說經之家多資以証古義故從</span>  
<span style="margin-left: 2em">其所重列之經部耳璞時去漢未遠如遂幠大東</span>  
<span style="margin-left: 2em">稱詩釗我周王稱逸書所見尚多古本故所註多</span>  
<!-- 册1 葉3276b　Page:文淵閣四庫全書_0001冊.djvu/869 -->
<span style="margin-left: 2em">可據後人雖迭爲補正然宏綱大旨終不出其範</span>  
<span style="margin-left: 2em">圍昺疏亦多能引證如尸子廣澤篇仁意篇皆非</span>  
<span style="margin-left: 2em">今人所及暏其犍爲文學樊光李巡之註見於陸</span>  
<span style="margin-left: 2em">氏釋文者雖多所遺漏然疏家之體惟明本註註</span>  
<span style="margin-left: 2em">所未及不復旁搜此亦唐以來之通弊不能獨責</span>  
<span style="margin-left: 2em">於昺惟旣列註文而疏中時複述其文但曰郭註</span>  
<span style="margin-left: 2em">云云不異一字亦更不别下一語殆不可解豈其</span>  
<span style="margin-left: 2em">初疏與註别行歟今未見原刻不可復考矣</span>  
爾雅注三卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<!-- 册1 葉3277a　Page:文淵閣四庫全書_0001冊.djvu/869 -->
<span style="margin-left: 2em">宋鄭樵撰樵字漁仲莆田人居夾漈山中因以爲</span>  
<span style="margin-left: 2em">號又自稱西溪逸民紹興間以薦召對授右迪功</span>  
<span style="margin-left: 2em">郞兵部架閣尋改監潭州南嶽廟給札歸鈔所撰</span>  
<span style="margin-left: 2em">通志書成入爲樞宻院編修事蹟具宋史儒林傳</span>  
<span style="margin-left: 2em">南宋諸儒大抵崇義理而疎考證故樵以博洽傲</span>  
<span style="margin-left: 2em">睨一時遂至肆作聰明詆諆毛鄭其詩辨妄一書</span>  
<span style="margin-left: 2em">開數百年杜撰說經之㨗徑爲通儒之所深非惟</span>  
<span style="margin-left: 2em">作是書乃通其所可通闕其所不可通文似簡畧</span>  
<span style="margin-left: 2em">而絶無穿鑿附會之失於說爾雅家爲善本中間</span>  
<!-- 册1 葉3277b　Page:文淵閣四庫全書_0001冊.djvu/869 -->
<span style="margin-left: 2em">駁正舊文如後序中所列饘餬訊言襺袍衮黼四</span>  
<span style="margin-left: 2em">條峩峩丁丁嚶嚶三條註中所列釋詁台朕陽之</span>  
<span style="margin-left: 2em">予爲我賚𢌿卜之予爲與一條閱閱噰噰當入釋</span>  
<span style="margin-left: 2em">訓一條釋親據左傳辨正娣姒一條釋天謂景風</span>  
<span style="margin-left: 2em">句上脫文一條星名脫實沈鶉首鶉尾三次一條</span>  
<span style="margin-left: 2em">釋水天子造舟一條釋魚鯉鱣一條釋蟲食根蟊</span>  
<span style="margin-left: 2em">一條蝮虺首大如臂一條皆極精<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">惟魚謂之丁</span>  
<span style="margin-left: 2em">一條務牽引假借以就其六書畧之說又堅執作</span>  
<span style="margin-left: 2em">爾雅者江南人凡郭璞所云蜀語河中語者悉駁</span>  
<!-- 册1 葉3280a　Page:文淵閣四庫全書_0001冊.djvu/870 -->
<span style="margin-left: 2em">辨之是則偏僻之過習氣猶未盡除又汪師韓集</span>  
<span style="margin-left: 2em">有書此書後一篇駁其誤改郭註者以劉劉𣏾爲</span>  
<span style="margin-left: 2em">安石榴以齧雕蓬爲其米雕胡二條補郭註而未</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">者孟勉也以爲孟卽暋於代也以爲更詞二條</span>  
<span style="margin-left: 2em">仍郭註之悞未改者訓郵過也爲道路所經過不</span>  
<span style="margin-left: 2em">知郵古字同尤訓比目魚爲王餘不知吳都賦雙</span>  
<span style="margin-left: 2em">則比目片則王餘二條亦頗中其失至於議其釋</span>  
<span style="margin-left: 2em">言篇内經文脫弇同也三字釋水篇内經文脫水</span>  
<span style="margin-left: 2em">之由膝以下爲揭至爲厲十八字釋草篇内經文</span>  
<!-- 册1 葉3280b　Page:文淵閣四庫全書_0001冊.djvu/870 -->
<span style="margin-left: 2em">脫葦醜艻三字釋魚篇内經文脫蛭蟣二字釋鳥</span>  
<span style="margin-left: 2em">篇内脫倉庚黧黃也五字皆當爲毛氏刊本之悞</span>  
<span style="margin-left: 2em">併以詆樵則過矣</span>  
方言十三卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">舊本題漢揚雄撰晉郭璞註考晉書郭璞傳有註</span>  
<span style="margin-left: 2em">方言之文而漢書揚雄傳備列所著之書不及方</span>  
<span style="margin-left: 2em">言一字藝文志亦惟小學有雄訓纂一篇儒家有</span>  
<span style="margin-left: 2em">雄所序三十八篇注云太元十九法言十三樂四</span>  
<span style="margin-left: 2em">箴二雜賦有雄賦十二篇皆無方言東漢一百九</span>  
<!-- 册1 葉3281a　Page:文淵閣四庫全書_0001冊.djvu/870 -->
<span style="margin-left: 2em">十年中亦無稱雄作方言者至漢末應劭風俗通</span>  
<span style="margin-left: 2em">義序始稱周秦常以歲八月遣輶軒之使求異代</span>  
<span style="margin-left: 2em">方言還奏籍之藏於秘室及嬴氏之亡遺棄脫漏</span>  
<span style="margin-left: 2em">無見之者蜀人嚴君平有千餘言林閭翁孺才有</span>  
<span style="margin-left: 2em">梗槪之法揚雄好之天下孝亷衞卒交㑹周章質</span>  
<span style="margin-left: 2em">問以次注續二十七年爾乃治正凡九千字又劭</span>  
<span style="margin-left: 2em">注漢書亦引揚雄方言一條是稱雄作方言實自</span>  
<span style="margin-left: 2em">劭始魏晉以後諸儒轉相沿述皆無異詞惟宋洪</span>  
<span style="margin-left: 2em">邁容齋隨筆始考證漢書斷非揚雄作然邁所摘</span>  
<!-- 册1 葉3281b　Page:文淵閣四庫全書_0001冊.djvu/870 -->
<span style="margin-left: 2em">劉歆與雄往返書中旣稱在成帝時不應稱孝成</span>  
<span style="margin-left: 2em">皇帝一條又東漢明帝始諱莊不應西漢之末卽</span>  
<span style="margin-left: 2em">稱莊遵爲嚴君平一條則未深中其要領考書首</span>  
<span style="margin-left: 2em">成帝時云云乃後人題下標注之文傳寫舛訛致</span>  
<span style="margin-left: 2em">與書連爲一實非歆之本詞文義尚犁然可辨書</span>  
<span style="margin-left: 2em">中載楊莊之名不作嚴字實未嘗預爲明帝諱其</span>  
<span style="margin-left: 2em">巖君平字或後人傳寫追改亦未可知皆不足斷</span>  
<span style="margin-left: 2em">是書之偽惟後漢許愼說文解字多引雄說而其</span>  
<span style="margin-left: 2em">文皆不見於方言又愼所注字義與今方言相同</span>  
<!-- 册1 葉3284a　Page:文淵閣四庫全書_0001冊.djvu/871 -->
<span style="margin-left: 2em">者不一而足而皆不標揚雄方言字知當愼之時</span>  
<span style="margin-left: 2em">此書尚不名方言亦尚不以方言爲雄作故馬鄭</span>  
<span style="margin-left: 2em">諸儒未嘗稱述至東漢之末應劭始有是說魏孫</span>  
<span style="margin-left: 2em">炎註爾雅莫貈螳螂蛑字晉杜預註左傳授師孑</span>
