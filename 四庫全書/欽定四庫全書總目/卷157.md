## 欽定四庫全書總目 卷一百五十七　集部十　別集類十

欽定四庫全書總目卷一百五十七  
<span style="margin-left: 1em">集部十</span>  
<span style="margin-left: 2em">别集𩔖十</span>  
龜溪集十二卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">宋沈與求撰與求字必先德淸人政和五年進士</span>  
<span style="margin-left: 2em">高宗時官至知樞宻院事卒諡忠敏事跡具宋史</span>  
<span style="margin-left: 2em">本傳是集爲紹熙中其孫說所刋前有觀文殿大</span>  
<span style="margin-left: 2em">學士李彥潁湖州教授張叔椿二序史稱與求歴</span>  
<span style="margin-left: 2em">御史三院知無不言前後幾四百奏其言切直今</span>  
<!-- 册4 葉793b　Page:文淵閣四庫全書_0004冊.djvu/203 -->
<span style="margin-left: 2em">所存僅十之三四𩔖多深中時弊陳振孫書錄解</span>  
<span style="margin-left: 2em">題曰與求嘗奏王安石之罪大者在於取揚雄馮</span>  
<span style="margin-left: 2em">道當時學者惟知有安石䘮亂之際甘心從僞無</span>  
<span style="margin-left: 2em">仗節死義之風實安石倡之此論前未之及也云</span>  
<span style="margin-left: 2em">云考熙寧以逮政和王蔡諸人以權勢奔走天下</span>  
<span style="margin-left: 2em">誅鋤善𩔖引掖宵人其夤緣以苟富貴者本無廉</span>  
<span style="margin-left: 2em">恥之心又安能望以名節之事其偷生賣國實積</span>  
<span style="margin-left: 2em">漸使然不必盡由於推奬揚雄表章馮道與求此</span>  
<span style="margin-left: 2em">奏亦事後推索之詞然其說主持風教振刷綱常</span>  
<!-- 册4 葉796a　Page:文淵閣四庫全書_0004冊.djvu/204 -->
<span style="margin-left: 2em">要不可不謂之偉論也至其制誥諸篇典雅舂容</span>  
<span style="margin-left: 2em">亦具有唐人軌度又不徒以奏議見長矣</span>  
栟櫚集十六卷<sub class="note-yuan">福建巡撫採進本</sub>  
<span style="margin-left: 2em">宋鄧肅撰按王明淸揮麈後錄稱宣和千寅艮岳</span>  
<span style="margin-left: 2em">成徽宗御製記李質曹組各獻賦獨太學生鄧肅</span>  
<span style="margin-left: 2em">上十詩備述花石之事其末句云但願君王安萬</span>  
<span style="margin-left: 2em">姓圃中何日不春風詔屏逐之靖康初李伯紀啓</span>  
<span style="margin-left: 2em">其事薦其才召對賜進士出身後爲右正言著亮</span>  
<span style="margin-left: 2em">直之名於當日肅字志宏南劔人有文集號栟櫚</span>  
<!-- 册4 葉796b　Page:文淵閣四庫全書_0004冊.djvu/204 -->
<span style="margin-left: 2em">遺文三十卷詩附集中云云卽其人也今本僅詩</span>  
<span style="margin-left: 2em">一卷詞一卷文十四卷與三十卷之數不符殆散</span>  
<span style="margin-left: 2em">佚不完又經後人重編歟當張<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3771.svg?width=24" alt="四庫全書僻字第3771號（邦）" title="四庫全書僻字第3771號（邦）">昌之僭立也肅</span>  
<span style="margin-left: 2em">間行奔赴南京其擢右正言卽在是時大節與杜</span>  
<span style="margin-left: 2em">甫畧相似其靖康迎駕行後迎駕行等篇亦頗近</span>  
<span style="margin-left: 2em">甫奉先諸作在南北宋間可謂篤勵名節之士又</span>  
<span style="margin-left: 2em">唐宋以來學者皆尊揚雄熙寧中遂至配享而肅</span>  
<span style="margin-left: 2em">書揚雄事獨指爲叛臣無可容於天地之間與沈</span>  
<span style="margin-left: 2em">與求疏論王安石過尊揚雄未知孰爲先後然均</span>  
<!-- 册4 葉797a　Page:文淵閣四庫全書_0004冊.djvu/204 -->
<span style="margin-left: 2em">在朱子綱目書莽大夫之前考陸深溪山餘話載</span>  
<span style="margin-left: 2em">肅與朱子父松相善有醉留冠帶以質𥿄筆之戲</span>  
<span style="margin-left: 2em">肅有寄朱韋齋詩卽道其事然則綱目之斥揚雄</span>  
<span style="margin-left: 2em">得無傳肅之說乎其識如是宜其立身有本末矣</span>  
黙成文集八卷<sub class="note-yuan">浙江汪啓淑家藏本</sub>  
<span style="margin-left: 2em">宋潘良貴撰良貴字義榮一字子賤號黙成居士</span>  
<span style="margin-left: 2em">婺州金華人政和五年以廷試第二人釋褐爲辟</span>  
<span style="margin-left: 2em">雍博士累遷提舉淮南東路常平靖康元年召還</span>  
<span style="margin-left: 2em">坐事除監信州汭口排岸高宗卽位召爲左司諫</span>  
<!-- 册4 葉797b　Page:文淵閣四庫全書_0004冊.djvu/204 -->
<span style="margin-left: 2em">厯除徽猷閣待制提舉亳州明道官坐與李光通</span>  
<span style="margin-left: 2em">書降三官卒贈左朝𫯠大夫事蹟具宋史本傳良</span>  
<span style="margin-left: 2em">貴學術醇正侃直不阿首論何𣓨等之不可爲相</span>  
<span style="margin-left: 2em">又與黃潛善吕頤浩相忤又面劾向子諲屢坐屏</span>  
<span style="margin-left: 2em">斥而所守不移故朱子亦稱其剛毅近仁其論治</span>  
<span style="margin-left: 2em">體劄子等篇悱惻沈痛足以感人尤足以覘其節</span>  
<span style="margin-left: 2em">槪其集見於史者十五卷久佚不傳此本乃康熙</span>  
<span style="margin-left: 2em">中其裔孫所刋僅文二十首詩二十七首詞一首</span>  
<span style="margin-left: 2em">皆掇拾於散亡之餘粗存梗槪然以集中除謝諸</span>  
<!-- 册4 葉800a　Page:文淵閣四庫全書_0004冊.djvu/205 -->
<span style="margin-left: 2em">表與本傳年譜相較亦多足資參訂如年譜載良</span>  
<span style="margin-left: 2em">貴旣至嚴州任請祠得主管亳州明道宫轉秘書</span>  
<span style="margin-left: 2em">少監遷起居郞拜中書舍人今集中有辭免秘書</span>  
<span style="margin-left: 2em">少監申省狀可與年譜相證而本傳不云轉秘書</span>  
<span style="margin-left: 2em">少監又良貴知嚴州之後凡再爲中書舍人集中</span>  
<span style="margin-left: 2em">有謝中書舍人誥表又有謝中書舍人表可證而</span>  
<span style="margin-left: 2em">本傳但云起爲中書舍人不著前後再命皆可以</span>  
<span style="margin-left: 2em">補宋史之闕誤惟是篇頁寥寥而强分卷帙未免</span>  
<span style="margin-left: 2em">有意求多又一卷二卷皆載本傳及年譜誥<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2706.svg?width=24" alt="四庫全書僻字第2706號（勅）" title="四庫全書僻字第2706號（勅）">等</span>  
<!-- 册4 葉800b　Page:文淵閣四庫全書_0004冊.djvu/205 -->
<span style="margin-left: 2em">文至三卷乃及其著作雖用宋敏求編李白集之</span>  
<span style="margin-left: 2em">例而喧奪太甚究爲編次無法至潘畤乃良佐之</span>  
<span style="margin-left: 2em">子於良貴爲猶子而亦附其傳誌於末編尤爲不</span>  
<span style="margin-left: 2em">倫今姑仍舊本錄之而附糾其叢脞如右</span>  
鄱陽集四卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋洪皓撰皓有松漠紀聞巳著錄此其詩集也皓</span>  
<span style="margin-left: 2em">建炎中擢徽猷閣待制假禮部尙書爲大金通間</span>  
<span style="margin-left: 2em">使龔璹副之後璹仕劉豫皓獨不屈節遂流遞冷</span>  
<span style="margin-left: 2em">山居雪窖中陳王固新<sub class="note-yuan">按固新宋史作悟室今據金國語解改正</sub>甚敬</span>  
<!-- 册4 葉801a　Page:文淵閣四庫全書_0004冊.djvu/205 -->
<span style="margin-left: 2em">禮之使教諸子八人集中所稱彥淸彥亨彥隆彥</span>  
<span style="margin-left: 2em">深者皆固新子也皓所作詩亦於此時爲多及烏</span>  
<span style="margin-left: 2em">珠<sub class="note-yuan">按烏珠宋史作兀朮今據金國語解改正</sub>殺固新遷皓雲中至紹興</span>  
<span style="margin-left: 2em">十二年始歸國留金首尾凡十五年後爲秦檜所</span>  
<span style="margin-left: 2em">嫉安置英州皓詩所謂六十之年入瘴鄉是也居</span>  
<span style="margin-left: 2em">九年始内徙行至南雄州卒其詩世無傳本傳稱</span>  
<span style="margin-left: 2em">皓有文集五十卷而書錄解題作十卷考皓子适</span>  
<span style="margin-left: 2em">盤洲集中載有皓集跋語一篇稱裒其在北方詩</span>  
<span style="margin-left: 2em">文爲十卷刻之新安郡則宋史誤矣其集久不傳</span>  
<!-- 册4 葉801b　Page:文淵閣四庫全書_0004冊.djvu/205 -->
<span style="margin-left: 2em">今從永樂大典所載裒輯編次共爲四卷凡其始</span>  
<span style="margin-left: 2em">奉使時塗次所經及遷居冷山以及歸國後南竄</span>  
<span style="margin-left: 2em">之作有年月可考者悉以年月排比或年月不可</span>  
<span style="margin-left: 2em">考而<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">知其爲奉使後作歸國後作南遷後作者</span>  
<span style="margin-left: 2em">亦皆以類相從其不知作於何時者則别綴於後</span>  
<span style="margin-left: 2em">而以适跋語附焉皓大節凛然照映今古雖不必</span>  
<span style="margin-left: 2em">以文章爲重然其子适邁遵承藉家學並掇詞科</span>  
<span style="margin-left: 2em">著述紛綸蜚聲一代淵源有自皓實開之迄今年</span>  
<span style="margin-left: 2em">代迢遙篇章散佚幸得遭逢</span>  
<!-- 册4 葉804a　Page:文淵閣四庫全書_0004冊.djvu/206 -->
聖世蒐羅遺逸復光耀於蠧蝕之餘斯亦忠義之氣不  
<span style="margin-left: 2em">可冺没待</span>  
<span style="margin-left: 1em">昌期而自發其光者矣</span>  
韋齋集十二卷附玉瀾集一卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋朱松撰松字喬年别字韋齋朱子之父也政和</span>  
<span style="margin-left: 2em">八年同上舍出身官至吏部員外郞以言事忤秦</span>  
<span style="margin-left: 2em">檜出知饒州未上請間得主管台州崇道觀滿秩</span>  
<span style="margin-left: 2em">再請命下而卒朱子作松行狀稱有韋齋集十二</span>  
<span style="margin-left: 2em">卷外集十卷外集今巳久佚是集初刻於淳熙再</span>  
<!-- 册4 葉804b　Page:文淵閣四庫全書_0004冊.djvu/206 -->
<span style="margin-left: 2em">刻於至元又刻於宏治傳本亦稀康熙庚寅其裔</span>  
<span style="margin-left: 2em">孫昌辰又校錄重刋是爲今本核其卷數與行狀</span>  
<span style="margin-left: 2em">所言相合葢猶舊帙也前有𫝊自得序稱其詩高</span>  
<span style="margin-left: 2em">遠而幽潔其文温婉而典裁至表奏書疏又皆中</span>  
<span style="margin-left: 2em">理而切事情雖友朋推許之詞然松早友李侗晩</span>  
<span style="margin-left: 2em">折秦檜其學識本殊於俗故其發爲文章氣格高</span>  
<span style="margin-left: 2em">逸翛然自異卽不藉朱子以爲子其集亦足以自</span>  
<span style="margin-left: 2em">傳自得所云頗爲近實非後來門戸之私以張栻</span>  
<span style="margin-left: 2em">而尊張浚者比也後附朱橰玉瀾集一卷橰字逢</span>  
<!-- 册4 葉805a　Page:文淵閣四庫全書_0004冊.djvu/206 -->
<span style="margin-left: 2em">年松之弟也其集原别本自行故書錄解題與松</span>  
<span style="margin-left: 2em">集各自著錄明宏治丙辰任邱鄺璠得其本於睢</span>  
<span style="margin-left: 2em">陽陳性之因附刻松集之後昌辰此刻亦仍之後</span>  
<span style="margin-left: 2em">有尤袤跋極稱其春風一篇盛事三首然橰詩實</span>  
<span style="margin-left: 2em">不及松袤所稱亦未爲盡允姑附驥以行云爾</span>  
澹齋集十八卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋李流謙撰流謙字無變漢州德陽人少以父良</span>  
<span style="margin-left: 2em">臣廕補將仕郞授成都府靈泉縣尉職滿調雅州</span>  
<span style="margin-left: 2em">教授會虞允文宣撫全蜀置之幕下多所贊畫尋</span>  
<!-- 册4 葉805b　Page:文淵閣四庫全書_0004冊.djvu/206 -->
<span style="margin-left: 2em">以薦除諸王宫大小學教授力丐補外改奉議郞</span>  
<span style="margin-left: 2em">通判潼州府事其事迹不見於宋史惟其兄益謙</span>  
<span style="margin-left: 2em">所作行狀尙具見其始末所著文集宋志亦不著</span>  
<span style="margin-left: 2em">錄惟焦竑國史經籍志黃虞稷千頃堂書目俱載</span>  
<span style="margin-left: 2em">有澹齋集八十一卷是明世尙有傳本今已湮没</span>  
<span style="margin-left: 2em">無聞厲鶚撰宋詩紀事僅從成都文𩔖中蒐得梅</span>  
<span style="margin-left: 2em">林分韻一首其文亦與本集頗冇異同又以流謙</span>  
<span style="margin-left: 2em">爲綿竹人與行狀不合知鶚未覩本集故傳聞異</span>  
<span style="margin-left: 2em">詞也流謙以文學知名其父良臣嘗出張浚門下</span>  
<!-- 册4 葉808a　Page:文淵閣四庫全書_0004冊.djvu/207 -->
<span style="margin-left: 2em">爲所論薦集中分陜志專爲頌浚勲德而作鋪張</span>  
<span style="margin-left: 2em">太甚殊不免門戸之私其詩文邊幅稍狹間傷淺</span>  
<span style="margin-left: 2em">俚亦未能盡臻醇粹然筆力峭勁不屑屑以彫𤥨</span>  
<span style="margin-left: 2em">爲工視後來破碎薾弱之習較爲勝之宋代遺集</span>  
<span style="margin-left: 2em">大半散佚若流謙者固不妨存備一家矣謹就永</span>
