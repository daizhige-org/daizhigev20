## 欽定四庫全書總目 卷一百四十　子部五十　小說家類一

欽定四庫全書總目卷一百四十  
<span style="margin-left: 1em">字部五十</span>  
<span style="margin-left: 2em">小說家類一</span>  
<span style="margin-left: 3em">張衡西京賦曰小說九百本自虞初漢書藝文</span>  
<span style="margin-left: 3em">志載虞初周說九百四十三篇註稱武帝時方</span>  
<span style="margin-left: 3em">士則小說興於武帝時矣故伊尹說以下九家</span>  
<span style="margin-left: 3em">班固多註依託也<sub class="note-yuan">漢書藝文志註凡不著姓名者皆班固自註</sub>然屈</span>  
<span style="margin-left: 3em">原天問雜陳神怪多莫知所岀意卽小說家言</span>  
<span style="margin-left: 3em">而漢志所載靑史子五十七篇賈誼新書保傅</span>  
<!-- 册3 葉3753b　Page:文淵閣四庫全書_0003冊.djvu/943 -->
<span style="margin-left: 3em">篇中先引之則其來巳久特盛於虞初耳迹其</span>  
<span style="margin-left: 3em">流别凡有三𣲖其一叙述雜事其一記錄異聞</span>  
<span style="margin-left: 3em">其一綴緝𤨏語也唐宋而後作者彌繁中間誣</span>  
<span style="margin-left: 3em">謾失真妖妄熒聽者固爲不少然寓勸戒廣見</span>  
<span style="margin-left: 3em">聞資考證者亦錯出其中班固稱小說家流蓋</span>  
<span style="margin-left: 3em">出於稗官如淳註謂王者欲知閭巷風俗故立</span>  
<span style="margin-left: 3em">稗官使稱說之然則博采旁蒐是亦古制固不</span>  
<span style="margin-left: 3em">必以冗雜廢矣今甄錄其近雅馴者以廣見聞</span>  
<span style="margin-left: 3em">惟猥鄙荒誕徒亂耳目者則黜不載焉</span>  
<!-- 册3 葉3756a　Page:文淵閣四庫全書_0003冊.djvu/944 -->
西京雜記六卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">舊本題晉<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3575.svg?width=24" alt="四庫全書僻字第3575號（葛）" title="四庫全書僻字第3575號（葛）">洪撰洪有肘後備𢚩方巳著錄黄伯</span>  
<span style="margin-left: 2em">思東觀餘諭稱此書中事皆劉歆所說<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3575.svg?width=24" alt="四庫全書僻字第3575號（葛）" title="四庫全書僻字第3575號（葛）">稚川采</span>  
<span style="margin-left: 2em">之其稱余者皆歆本文云云今檢書後有洪跋稱</span>  
<span style="margin-left: 2em">其家有劉歆漢書一百卷考校班固所作殆是全</span>  
<span style="margin-left: 2em">取劉氏有小異同固所不取不過二萬許言今鈔</span>  
<span style="margin-left: 2em">出爲二卷名曰西京雜記以補漢書之闕云云伯</span>  
<span style="margin-left: 2em">思所說葢据此文案隋書經籍志載此書二卷不</span>  
<span style="margin-left: 2em">著撰人名氏漢書匡衡傳顔師古註稱今有西京</span>  
<!-- 册3 葉3756b　Page:文淵閣四庫全書_0003冊.djvu/944 -->
<span style="margin-left: 2em">雜記者岀於里巷亦不言作者爲何人至叚成式</span>  
<span style="margin-left: 2em">酉陽雜爼廣動植篇始載<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3575.svg?width=24" alt="四庫全書僻字第3575號（葛）" title="四庫全書僻字第3575號（葛）">稚川就上林令魚泉</span>  
<span style="margin-left: 2em">問草木名今在此書第一卷中張彦遠厯代名畫</span>  
<span style="margin-left: 2em">記載毛延壽畫王昭君事亦引<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3575.svg?width=24" alt="四庫全書僻字第3575號（葛）" title="四庫全書僻字第3575號（葛）">洪西京雜記則</span>  
<span style="margin-left: 2em">指爲<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3575.svg?width=24" alt="四庫全書僻字第3575號（葛）" title="四庫全書僻字第3575號（葛）">洪者實起於唐故舊唐書經籍志載此書</span>  
<span style="margin-left: 2em">遂註曰晉<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3575.svg?width=24" alt="四庫全書僻字第3575號（葛）" title="四庫全書僻字第3575號（葛）">洪撰然酉陽雜爼語資篇别載庾信</span>  
<span style="margin-left: 2em">作詩用西京雜記事旋自追改曰此吳均語恐不</span>  
<span style="margin-left: 2em">足用晁公武讀書志亦稱江左人或以爲吴均依</span>  
<span style="margin-left: 2em">託葢卽據叚成式所載庾信語也今考晉書<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3575.svg?width=24" alt="四庫全書僻字第3575號（葛）" title="四庫全書僻字第3575號（葛）">洪</span>  
<!-- 册3 葉3757a　Page:文淵閣四庫全書_0003冊.djvu/944 -->
<span style="margin-left: 2em">傳載洪所著有抱朴子神仙良吏集異等傳金匱</span>  
<span style="margin-left: 2em">要方肘後備𢚩方並諸雜文共五百餘卷無西京</span>  
<span style="margin-left: 2em">雜記之名則作洪撰者自屬舛誤特是向歆父子</span>  
<span style="margin-left: 2em">作漢書史無明文以此書所紀與班書叅校又往</span>  
<span style="margin-left: 2em">往錯互不合如漢書載文帝以代王卽位而此書</span>  
<span style="margin-left: 2em">乃云文帝爲太子漢書又載廣陵王胥淮南王安</span>  
<span style="margin-left: 2em">並謀逆自殺而此書乃云胥格猛獸䧟脰死安與</span>  
<span style="margin-left: 2em">方士俱去漢書楊王孫傳卽以王孫爲名而此書</span>  
<span style="margin-left: 2em">乃云名貴似是故謬其事以就洪跋中小有異同</span>  
<!-- 册3 葉3757b　Page:文淵閣四庫全書_0003冊.djvu/944 -->
<span style="margin-left: 2em">之文又歆始終臣莽而此書載吳章被誅事乃云</span>  
<span style="margin-left: 2em">章後爲王莽所殺尤不類歆語又漢書匡衡傳匡</span>  
<span style="margin-left: 2em">鼎來句服䖍訓鼎爲當應劭訓鼎爲方此書亦載</span>  
<span style="margin-left: 2em">是語而以鼎爲匡衡小名使歆先有此說服䖍應</span>  
<span style="margin-left: 2em">劭皆後漢人不容不見至<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3575.svg?width=24" alt="四庫全書僻字第3575號（葛）" title="四庫全書僻字第3575號（葛）">洪乃傳是以陳振孫</span>  
<span style="margin-left: 2em">等皆深以爲疑然庾信指爲吳均别無他證叚成</span>  
<span style="margin-left: 2em">式所述信語亦未見於他書流傳旣久未可遽更</span>  
<span style="margin-left: 2em">今姑從原跋兼題劉歆<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3575.svg?width=24" alt="四庫全書僻字第3575號（葛）" title="四庫全書僻字第3575號（葛）">洪姓名以存其舊其書</span>  
<span style="margin-left: 2em">諸志皆作二卷今作六卷據書錄解題葢宋人所</span>  
<!-- 册3 葉3760a　Page:文淵閣四庫全書_0003冊.djvu/945 -->
<span style="margin-left: 2em">分今亦仍之其中所述雖多爲小說家言而摭採</span>  
<span style="margin-left: 2em">繁富取材不竭李善註文選徐堅作初學記巳引</span>  
<span style="margin-left: 2em">其文杜甫詩用事謹嚴亦多採其語詞人沿用數</span>  
<span style="margin-left: 2em">百年久成故實固有不可遽廢者焉</span>  
世說新語三卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋臨川王劉義慶撰梁劉孝標註義慶事迹具宋</span>  
<span style="margin-left: 2em">書孝標名峻以字行事迹具梁書黄伯思東觀餘</span>  
<span style="margin-left: 2em">論謂世說之名肇於劉向其書巳亡故義慶所集</span>  
<span style="margin-left: 2em">名世說新書叚成式酉陽雜爼引王敦澡豆事尙</span>  
<!-- 册3 葉3760b　Page:文淵閣四庫全書_0003冊.djvu/945 -->
<span style="margin-left: 2em">作世說新書可證不知何人改爲新語蓋近世所</span>  
<span style="margin-left: 2em">傳然相沿巳久不能復正矣所記分三十八門上</span>  
<span style="margin-left: 2em">起後漢下迄東晉皆軼事𤨏語足爲談助唐藝文</span>  
<span style="margin-left: 2em">志稱劉義慶世說八卷劉孝標續十卷崇文總目</span>  
<span style="margin-left: 2em">惟載十卷晁公武謂當是孝標續義慶元本八卷</span>  
<span style="margin-left: 2em">通成十卷又謂家有詳略二本逈不相同今其本</span>  
<span style="margin-left: 2em">皆不傳惟陳振孫書錄解題作三卷與今本合其</span>  
<span style="margin-left: 2em">每卷析爲上下則世傳陸游所刋本巳然葢卽舊</span>  
<span style="margin-left: 2em">本至振孫載汪藻所云叙錄二卷首爲考異繼列</span>  
<!-- 册3 葉3761a　Page:文淵閣四庫全書_0003冊.djvu/945 -->
<span style="margin-left: 2em">人物世譜姓字異同末記所引書目者則佚之久</span>  
<span style="margin-left: 2em">矣自明以來世俗所行凡二本一爲王世貞所刋</span>  
<span style="margin-left: 2em">註文多所删節殊乖其舊一爲袁褧所刋葢卽從</span>  
<span style="margin-left: 2em">陸本翻雕者雖板巳刓敝然猶屬完書義慶所述</span>  
<span style="margin-left: 2em">劉知幾史通深以爲譏然義慶本小說家言而知</span>  
<span style="margin-left: 2em">幾繩之以史法擬不於倫未爲通論孝標所注特</span>  
<span style="margin-left: 2em">爲典贍高似孫緯略亟推之其糾正義慶之紕繆</span>  
<span style="margin-left: 2em">尤爲精核所引諸書今巳佚其十之九惟頼是註</span>  
<span style="margin-left: 2em">以傳故與裴松之三國志註酈道元水經註李善</span>  
<!-- 册3 葉3761b　Page:文淵閣四庫全書_0003冊.djvu/945 -->
<span style="margin-left: 2em">文選註同爲考證家所引據焉</span>  
朝野僉載六卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">舊本題唐張鷟撰鷟有龍筋鳯髓判巳著錄此書</span>  
<span style="margin-left: 2em">新唐書藝文志作三十卷宋史藝文志作僉載二</span>  
<span style="margin-left: 2em">十卷又僉載補遺三卷文獻通考則但有僉載補</span>  
<span style="margin-left: 2em">遺三卷此本六卷叅考諸書皆不合晁公武讀書</span>  
<span style="margin-left: 2em">志又謂其分三十五門而今本乃逐條聯綴不分</span>  
<span style="margin-left: 2em">門目亦與晁氏所記不同考莫休符桂林風土記</span>  
<span style="margin-left: 2em">載鷟在開元中姚崇誣其奉使江南受遺賜死其</span>  
<!-- 册3 葉3764a　Page:文淵閣四庫全書_0003冊.djvu/946 -->
<span style="margin-left: 2em">子上表請代減死流嶺南數年起爲長史而卒計</span>  
<span style="margin-left: 2em">其時尙在天寳之前而書中有寳厯元年資陽石</span>  
<span style="margin-left: 2em">走事寳厯乃敬宗年號又有孟宏微對宣宗事時</span>  
<span style="margin-left: 2em">代皆不相及按尤袤遂初堂書目亦分朝野僉載</span>  
<span style="margin-left: 2em">及僉載補遺爲二書疑僉載乃鷟所作補遺則爲</span>  
<span style="margin-left: 2em">後人附益凡闌入中唐後事者皆應爲補遺之文</span>  
<span style="margin-left: 2em">而陳振孫所謂書本三十卷此其節畧者當卽此</span>  
<span style="margin-left: 2em">本蓋嘗經宋人摘錄合僉載補遺爲一删併門類</span>  
<span style="margin-left: 2em">巳非原書又不知何時析三卷爲六卷也其書皆</span>  
<!-- 册3 葉3764b　Page:文淵閣四庫全書_0003冊.djvu/946 -->
<span style="margin-left: 2em">紀唐代故事而於諧噱荒怪纎悉臚載未免失於</span>  
<span style="margin-left: 2em">纎碎故洪邁容齋隨筆譏其記事𤨏雜擿裂且多</span>  
<span style="margin-left: 2em">媟語然耳目所接可據者多故司馬光作通鑑亦</span>  
<span style="margin-left: 2em">引用之兼收博采固未嘗無裨於見聞也</span>  
大唐新語十三卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">唐劉肅撰唐書藝文志載此書三卷注曰元和中</span>  
<span style="margin-left: 2em">江都主簿此本結銜乃題登仕郎守江州潯陽縣</span>  
<span style="margin-left: 2em">主簿未詳孰是也所記起武德之初迄大厯之末</span>  
<span style="margin-left: 2em">凡分三十門皆取軼文舊事有裨勸戒者前有自</span>  
<!-- 册3 葉3765a　Page:文淵閣四庫全書_0003冊.djvu/946 -->
<span style="margin-left: 2em">序後有總論一篇稱昔荀爽紀漢事可爲鑒戒者</span>  
<span style="margin-left: 2em">以爲漢語今之所記庶嗣前修云云故唐志列之</span>  
<span style="margin-left: 2em">襍史類中然其中諧謔一門繁蕪猥𤨏未免自穢</span>  
<span style="margin-left: 2em">其書有乖史家之體例今退置小說家類庻協其</span>  
<span style="margin-left: 2em">實是書本名新語唐志以下諸家著錄並同明馮</span>  
<span style="margin-left: 2em">夢禎俞安期等因與李垕續世說僞本合刻遂改</span>  
<span style="margin-left: 2em">題曰唐世說殊爲臆撰商維濬刻入稗海併於肅</span>  
<span style="margin-left: 2em">自序中增入世說二字益僞妄矣稗海又佚其卷</span>  
<span style="margin-left: 2em">末總論一篇及政能第八之標題亦較馮氏姚氏</span>  
<!-- 册3 葉3765b　Page:文淵閣四庫全書_0003冊.djvu/946 -->
<span style="margin-left: 2em">之本更爲疎舛今合諸本參校定爲書三十篇總</span>  
<span style="margin-left: 2em">論一篇而仍名爲大唐新語以復其舊焉</span>  
次柳氏舊聞一卷<sub class="note-yuan">江蘇廵撫採進本</sub>  
<span style="margin-left: 2em">唐李德裕撰德裕事迹具唐書本傳是書所記皆</span>
