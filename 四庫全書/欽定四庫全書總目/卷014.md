## 欽定四庫全書總目 卷十四　經部十四　書類存目二

<!-- 册1 葉1212：整葉圖版，無文字記錄 -->

欽定四庫全書總目巻十四  
<span style="margin-left: 1em">經部十四</span>  
<span style="margin-left: 2em">書類存目二</span>  
書經疑問十二巻<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明姚舜牧撰舜牧有易經疑問已著錄是編於經</span>  
<span style="margin-left: 2em">義罕所攷定惟推尋文句以意說之往往穿鑿杜</span>  
<span style="margin-left: 2em">撰如解堯典湯湯洪水方割云湯湯如湯滚沸一</span>  
<span style="margin-left: 2em">般様解舜典有能奮庸熙帝之載曰載字下得極</span>  
<span style="margin-left: 2em">妙天下事重且大矣帝王以一身擔當負荷如車</span>  
<!-- 册1 葉1213b　Page:文淵閣四庫全書_0001冊.djvu/353 -->
<span style="margin-left: 2em">載者然可謂游談無根矣</span>  
書帷别記四巻<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">明王樵撰樵所著尚書日記十六巻說者稱其該</span>  
<span style="margin-left: 2em">洽已著於錄此書則爲科舉而作曰别記者所以</span>  
<span style="margin-left: 2em">别於日記也書前舊有萬歴甲申自序見朱𢑴尊</span>  
<span style="margin-left: 2em">經義攷此本不載葢偶失之</span>  
尚書要㫖三十巻<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明王肯堂撰肯堂字宇泰金壇人樵之子也萬厯</span>  
<span style="margin-left: 2em">巳丑進士官至福建布政司參政事迹附見明史</span>  
<!-- 册1 葉1216a　Page:文淵閣四庫全書_0001冊.djvu/354 -->
<span style="margin-left: 2em">樵傳是書承樵所撰尚書别記抄撮緒言敷衍其</span>  
<span style="margin-left: 2em">說以備時文之用其經文較講義低二格每節惟</span>  
<span style="margin-left: 2em">書首尾二句亦如時文之式</span>  
尚書辨解十巻<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">明郝敬撰敬有周易正解巳著錄是編前八巻解</span>  
<span style="margin-left: 2em">伏書二十八篇後二篇辨孔書故名曰辨解其解</span>  
<span style="margin-left: 2em">周公居東爲就管叔以兄弟之義感之解罪人斯</span>  
<span style="margin-left: 2em">得爲成王與太公召公誅管叔而周公不與聞他</span>  
<span style="margin-left: 2em">若周公稱成王爲孺子爲國史代周公之辭非周</span>  
<!-- 册1 葉1216b　Page:文淵閣四庫全書_0001冊.djvu/354 -->
<span style="margin-left: 2em">公口出其說多與先儒異葢敬之解經率憑臆度</span>  
<span style="margin-left: 2em">亦不但此書爲然也</span>  
禹貢備遺增註二巻<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明胡瓚撰其曾孫宗緒增註瓚字伯玉桐城人萬</span>  
<span style="margin-left: 2em">厯巳正進士官至江西布政司叅政宗緒字襲叅</span>  
<span style="margin-left: 2em">雍正庚戌進士官至國子監司業是書先發明禹</span>  
<span style="margin-left: 2em">貢書法别爲巻首自禹敷土至西戎卽叙爲一巻</span>  
<span style="margin-left: 2em">𨗳岍及岐以下爲一巻依經附註多遵蔡氏集傳</span>  
<span style="margin-left: 2em">宗緒增註則間引蔡傳原文以証其同異如謂淄</span>  
<!-- 册1 葉1217a　Page:文淵閣四庫全書_0001冊.djvu/354 -->
<span style="margin-left: 2em">水入海不入濟考左傳昭公二十六年成人伐齊</span>  
<span style="margin-left: 2em">師之飲馬于淄者杜預註云出泰山梁父縣北此</span>  
<span style="margin-left: 2em">乃淄汶鄭樵誤會其文遂據此謂濰淄之淄爲入</span>  
<span style="margin-left: 2em">汶不入海固爲牽合蔡傳云淄水東入濟亦不知</span>  
<span style="margin-left: 2em">通淄濟之間乃漢時事有河渠書可証也禹貢之</span>  
<span style="margin-left: 2em">淄出益都縣東南岳陽山歴今臨淄博興樂安至</span>  
<span style="margin-left: 2em">壽光縣北由清水泊入海水道顯然此紏正之得</span>  
<span style="margin-left: 2em">實者也至謂汾本西流則從蔡傳攷水經注汾水</span>  
<span style="margin-left: 2em">出太原汾陽縣北管涔山南流與東西温谿合以</span>  
<!-- 册1 葉1217b　Page:文淵閣四庫全書_0001冊.djvu/354 -->
<span style="margin-left: 2em">今地輿考之自汶陽至臨汾縣東皆南流自此而</span>  
<span style="margin-left: 2em">南西流經曲沃縣所謂故絳也由曲沃至河津滎</span>  
<span style="margin-left: 2em">河諸縣則皆西流蔡傳未爲明晣如是之類尙未</span>  
<span style="margin-left: 2em">盡正也</span>  
書傳會衷十巻<sub class="note-yuan">江蘇周厚堉家藏本</sub>  
<span style="margin-left: 2em">明曹學佺撰學佺有易經通論巳著錄是書自一</span>  
<span style="margin-left: 2em">巻堯典至六巻召誥題曰書傳會衷七巻洛誥以</span>  
<span style="margin-left: 2em">下則題曰書傳折衷篇帙相連而兩名互見莫喻</span>  
<span style="margin-left: 2em">其故今姑從其前名以歸畫一其說多沿襲舊文</span>  
<!-- 册1 葉1220a　Page:文淵閣四庫全書_0001冊.djvu/355 -->
<span style="margin-left: 2em">間自立議則又多舛誤如四岳舊說以爲四人學</span>  
<span style="margin-left: 2em">佺則以爲一人而總四岳諸侯之事不知下文僉</span>  
<span style="margin-left: 2em">曰爲衆應之辭也其以三江爲松江婁江東江九</span>  
<span style="margin-left: 2em">江爲洞庭則皆取舊說之難信者洪範之六三德</span>  
<span style="margin-left: 2em">不取鄭康成臣道之說而用孔傳亦失於决擇也</span>  
虞書箋二巻<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明茅瑞徵撰瑞徵字伯符歸安人萬厯辛丑進士</span>  
<span style="margin-left: 2em">官至南京光祿寺卿解官後自號苕上漁父又稱</span>  
<span style="margin-left: 2em">澹樸居士此書前有自序言南局多暇讀唐虞論</span>  
<!-- 册1 葉1220b　Page:文淵閣四庫全書_0001冊.djvu/355 -->
<span style="margin-left: 2em">治之書輙次數語葢卽官光祿時作也考定陵註</span>  
<span style="margin-left: 2em">略瑞徵官職方郎中時欲黜一副將不遂反爲所</span>  
<span style="margin-left: 2em">搆又御史姚永濟韓浚皆有所請託瑞徵不從遂</span>  
<span style="margin-left: 2em">合力排擠之去其人葢亦錚錚者而此書所箋大</span>  
<span style="margin-left: 2em">抵敷衍舊說無所發明如解柔遠能邇句云柔字</span>  
<span style="margin-left: 2em">下得最妙解惟時亮天工句云卽熙帝載意解天</span>  
<span style="margin-left: 2em">敘有典節云兩我字正與兩天字相應解愼乃在</span>  
<span style="margin-left: 2em">位句云卽愼乃有位皆不過隨文敷衍殆閒曹無</span>  
<span style="margin-left: 2em">事姑以遣日本無意於著書而其子漫付剞劂耳</span>  
<!-- 册1 葉1221a　Page:文淵閣四庫全書_0001冊.djvu/355 -->
禹貢滙疏十五巻<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明茅瑞徵撰其書前冠圖經二巻上巻二十四圖</span>  
<span style="margin-left: 2em">皆鄭曉原本下巻二十四圖則瑞徵所補緝也次</span>  
<span style="margin-left: 2em">以九州爲九巻導山𨗳水各一巻而九州攸同至</span>  
<span style="margin-left: 2em">末自爲一巻又採摭大禹神怪之事爲附錄一巻</span>  
<span style="margin-left: 2em">書作於崇禎壬申多借以抒冩時事故其自序曰</span>  
<span style="margin-left: 2em">讀禹貢者詳九州之山川則可供聚米之畫習澮</span>  
<span style="margin-left: 2em">渠之岐路則可商飛輓之宜察東南之物力則當</span>  
<span style="margin-left: 2em">念杼軸之空攷甸服之遺制則當興樹藝之利而</span>  
<!-- 册1 葉1221b　Page:文淵閣四庫全書_0001冊.djvu/355 -->
<span style="margin-left: 2em">挈要於底愼財賦一語疏解浩繁可一言以蔽之</span>  
<span style="margin-left: 2em">如必句櫛字比執今圖誌疑古山川此不離經生</span>  
<span style="margin-left: 2em">之耳食何異孔蔡之舊文蓋其志不在於解經也</span>  
<span style="margin-left: 2em">然徵引浩繁而無所斷制動引及天文分野未免</span>  
<span style="margin-left: 2em">泛濫至其附錄一巻盡摭雜家之言侈談靈異則</span>  
<span style="margin-left: 2em">非惟無與於經義亦並無關於時事矣豈說經之</span>  
<span style="margin-left: 2em">體哉</span>  
尙書傳翼十巻<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明陸鍵撰鍵字實府秀水人是書惟敷衍蔡沈之</span>  
<!-- 册1 葉1224a　Page:文淵閣四庫全書_0001冊.djvu/356 -->
<span style="margin-left: 2em">說無所異同故曰傳翼犬旨主於通俗體例亦全</span>  
<span style="margin-left: 2em">似語錄</span>  
尙書晩訂十二巻<sub class="note-yuan">編修勵守謙家藏本</sub>  
<span style="margin-left: 2em">明史維堡撰維堡字心傳金壇人萬厯丙辰進士</span>  
<span style="margin-left: 2em">官至工部郞中是書本名尚書集覽後更名晩訂</span>  
<span style="margin-left: 2em">葢取晩年論定之意也大旨以蔡傳爲藍本惟攷</span>  
<span style="margin-left: 2em">據典故頗引舊文不盡同於蔡傳葢參用朱子尚</span>  
<span style="margin-left: 2em">書名物度數當看註疏之語也</span>  
尚書揆一六巻<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<!-- 册1 葉1224b　Page:文淵閣四庫全書_0001冊.djvu/356 -->
<span style="margin-left: 2em">明鄒期楨撰期楨字公寧無錫人萬厯中諸生江</span>  
<span style="margin-left: 2em">南通志儒林傳附見吳桂森傳中稱與桂森俱從</span>  
<span style="margin-left: 2em">高攀龍學稱兩素衣先生是書專主蔡傳而雜引</span>  
<span style="margin-left: 2em">諸儒之說以發明之葢爲科舉而作書成於萬厯</span>  
<span style="margin-left: 2em">丙辰前有高攀龍序又有讀尚書六要其孫陞所</span>  
<span style="margin-left: 2em">述也</span>  
尚書葦籥二十一巻<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明潘士遴撰士遴字叔獻烏程人天啟壬戌進士</span>  
<span style="margin-left: 2em">官至大理寺寺副是書大意欲囊括漢宋諸儒而</span>  
<!-- 册1 葉1225a　Page:文淵閣四庫全書_0001冊.djvu/356 -->
<span style="margin-left: 2em">折衷以已見然博引繁稱卮言多而精理少其凡</span>  
<span style="margin-left: 2em">例高自標置謂從來說經非稽天之射卽無病之</span>  
<span style="margin-left: 2em">呻葦籥指㸃虛實筆光開洞眞可引人心氣資人</span>  
<span style="margin-left: 2em">聰明其經如經星之左旋其緯如緯星之右轉無</span>  
<span style="margin-left: 2em">可增减無可讚宣烟霞寶氣結爲祥光瑞靄萬古</span>  
<span style="margin-left: 2em">執迷一旦葦籥獨見曉焉云云自古以來著述之</span>  
<span style="margin-left: 2em">家未有誇誕至於如是者其華而不實亦可槪見</span>  
<span style="margin-left: 2em">矣目錄止二十一巻而分編則爲五十八巻葢以</span>  
<span style="margin-left: 2em">篇數爲子巻也</span>  
<!-- 册1 葉1225b　Page:文淵閣四庫全書_0001冊.djvu/356 -->
書經集意六巻<sub class="note-yuan">江蘇廵撫採進本</sub>  
<span style="margin-left: 2em">明萬嗣達撰嗣達字孝仲潯陽人其履貫無可考</span>  
<span style="margin-left: 2em">自序稱天啟壬戌書於陪京序中謂雲曹簡靜葢</span>  
<span style="margin-left: 2em">官南京刑部時所作書中分節講論罕逢奥義至</span>  
<span style="margin-left: 2em">禹貢内雜引明代漕輓東壩諸事以便荅䇿尤非</span>  
<span style="margin-left: 2em">解經之體矣</span>  
禹貢圖註<sub class="note-yuan">無巻數　江西廵撫採進本</sub>  
<span style="margin-left: 2em">明艾南英撰南英字千子東鄕人天啟甲子舉人</span>  
<span style="margin-left: 2em">朱聿鍵僭號於福建以爲監察御史病卒於延平</span>  
<!-- 册1 葉1228a　Page:文淵閣四庫全書_0001冊.djvu/357 -->
<span style="margin-left: 2em">事蹟具明史文苑傳楊陸榮三藩紀事本末則以</span>  
<span style="margin-left: 2em">爲殉節自經傳聞異詞莫之詳也是編以禹貢九</span>  
<span style="margin-left: 2em">州分繪九圖列於各州經文之前又繪五服圖列</span>  
<span style="margin-left: 2em">於五百里甸服一節之前後附輿地總圖據明代</span>  
<span style="margin-left: 2em">郡縣紀其大畧採錄蔡註之簡明者爲内註有不</span>  
<span style="margin-left: 2em">可廢者仍錄爲外註其圖與注俱頗簡畧無所考</span>  
<span style="margin-left: 2em">證南英自序亦稱爲便於童𫎇記誦云</span>  
禹貢合註五巻<sub class="note-yuan">江蘇廵撫採進本</sub>

<span style="margin-left: 2em">縣教諭伏生尙書大傳久無刻本外間傳寫殘帙</span>  
<span style="margin-left: 2em">訛缺顚倒殆不可讀元和惠棟號爲博洽修明堂</span>  
<span style="margin-left: 2em">大道錄時亦未見原本僅從他書輾轉援引故之</span>  
<span style="margin-left: 2em">騄蒐採補綴仍勒爲三巻其不註出典者殘缺之</span>  
<span style="margin-left: 2em">原文其注某書引者之騄所增入也殘章斷句頗</span>  
<span style="margin-left: 2em">頼以存近時朱本復出揚州巳有雕板此本原可</span>  
<span style="margin-left: 2em">不存然之騄於舊帙未出之前鈎稽參考閱歲月</span>  
<span style="margin-left: 2em">而成是編其好古之勤亦不可没故仍附存其目</span>
