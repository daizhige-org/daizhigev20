## 欽定四庫全書總目 卷六十九　史部二十五　地理類二

<!-- 册2 葉1940：整葉圖版，無文字記錄 -->

欽定四庫全書總目巻六十九  
<span style="margin-left: 1em">史部二十五</span>  
<span style="margin-left: 2em">地理𩔖二</span>  
水經注四十巻<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">後魏酈道元撰道元字善長范陽人官至御史中</span>  
<span style="margin-left: 2em">尉事迹具魏書酷吏傳自晉以來注水經者凡二</span>  
<span style="margin-left: 2em">家郭璞注三巻杜佑作通典時猶見之今惟道元</span>  
<span style="margin-left: 2em">所註存崇文總目稱其中巳佚五巻故元和郡縣</span>  
<span style="margin-left: 2em">志太平寰宇記所引滹沱水涇水洛水皆不見於</span>  
<!-- 册2 葉1941b　Page:文淵閣四庫全書_0002冊.djvu/490 -->
<span style="margin-left: 2em">今書然今書仍作四十巻蓋宋人重刋分析以足</span>  
<span style="margin-left: 2em">原數也是書自明以來絶無善本惟朱謀㙔所校</span>  
<span style="margin-left: 2em">盛行於世而舛謬亦復相仍今以永樂大典所引</span>  
<span style="margin-left: 2em">各案水名逐條參校非惟字句之訛層出叠見其</span>  
<span style="margin-left: 2em">中脫簡錯簡有自數十字至四百餘字者其道元</span>  
<span style="margin-left: 2em">自序一篇諸本皆佚亦惟永樂大典僅存蓋當時</span>  
<span style="margin-left: 2em">所據猶屬宋槧善本也謹排比原文與近本鉤稽</span>  
<span style="margin-left: 2em">校勘凡補其闕漏者二千一百二十八字刪其𡚶</span>  
<span style="margin-left: 2em">增者一千四百四十八字正其臆改者三千七百</span>  
<!-- 册2 葉1944a　Page:文淵閣四庫全書_0002冊.djvu/491 -->
<span style="margin-left: 2em">一十五字神明焕然頓還舊觀三四百年之疑竇</span>  
<span style="margin-left: 2em">一旦曠若發䝉是皆我</span>  
皇上稽古右文經籍道盛嫏嬛宛委之秘響然並臻遂  
<span style="margin-left: 2em">使前代遺編幸逢</span>  
<span style="margin-left: 1em">昌運發其光於蠧簡之中若有神物撝呵以待</span>  
聖朝而出者是亦曠世之一遇矣至於經文注語諸本  
<span style="margin-left: 2em">率多混淆今考驗舊文得其端緖凡水道所經之</span>  
<span style="margin-left: 2em">地經則云過注則云逕經則統舉都㑹注則兼及</span>  
<span style="margin-left: 2em">繁碎地名凡一水之名經則首句標明後不重舉</span>  
<!-- 册2 葉1944b　Page:文淵閣四庫全書_0002冊.djvu/491 -->
<span style="margin-left: 2em">注則文多旁涉必重舉其名以更端凡書内郡縣</span>  
<span style="margin-left: 2em">經則但舉當時之名注則兼考故城之迹皆尋其</span>  
<span style="margin-left: 2em">義例一一釐定各以案語附於下方至塞外羣流</span>  
<span style="margin-left: 2em">江南諸派道元足迹皆所未經紀載傳聞間或失</span>  
<span style="margin-left: 2em">實流傳旣久引用相仍則姑仍舊文不復改易焉</span>  
<span style="margin-left: 2em">又水經作者唐書題曰桑欽然班固嘗引欽說與</span>  
<span style="margin-left: 2em">此經文異道元注亦引欽所作地理志不曰水經</span>  
<span style="margin-left: 2em">觀其涪水條中稱廣漢巳爲廣魏則决非漢時鐘</span>  
<span style="margin-left: 2em">水條中稱晉寧仍曰魏寧則未及晉代推尋文句</span>  
<!-- 册2 葉1945a　Page:文淵閣四庫全書_0002冊.djvu/491 -->
<span style="margin-left: 2em">大抵三國時人今旣得道元原序知並無桑欽之</span>  
<span style="margin-left: 2em">文則據以削去舊題亦庶幾闕疑之義云爾</span>  
水經注集釋訂訛四十巻<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝沈炳巽撰炳巽字繹旃歸安人其書據明嘉靖</span>  
<span style="margin-left: 2em">間黃省曾所刊水經注本而以已意校定之多所</span>  
<span style="margin-left: 2em">釐正又以道元徵引之書極爲博贍傳寫旣久訛</span>  
<span style="margin-left: 2em">誤相仍因徧檢史記漢書志表及諸史各志取其</span>  
<span style="margin-left: 2em">文字異同者錄於下方以備參考其無他書可校</span>  
<span style="margin-left: 2em">者則闕之間附以諸家考訂之說凡州縣沿革則</span>  
<!-- 册2 葉1945b　Page:文淵閣四庫全書_0002冊.djvu/491 -->
<span style="margin-left: 2em">悉以今名釋焉中間於地理方位往往有不能詳</span>  
<span style="margin-left: 2em">審而漫爲臆度者如漳水注稱絳瀆逕九門城南</span>  
<span style="margin-left: 2em">又東南逕南宫城北炳巽釋云九門城今在藁城</span>  
<span style="margin-left: 2em">縣西北二十里而不知一在滹沱之南一在滹沱</span>  
<span style="margin-left: 2em">之北中隔新河寧晉束鹿晉州相去甚遠水經沁</span>  
<span style="margin-left: 2em">水過穀遠縣東又南過陭氏縣東此陭氏在潞安</span>  
<span style="margin-left: 2em">府屯留縣西南卽北魏之寄氏陭譌作猗而炳巽</span>  
<span style="margin-left: 2em">釋云今屬平陽府則不知漢志有上黨之陭氏非</span>  
<span style="margin-left: 2em">卽河東之猗氏他若河水過高唐縣南道元言河</span>  
<!-- 册2 葉1948a　Page:文淵閣四庫全書_0002冊.djvu/492 -->
<span style="margin-left: 2em">水於縣漯水注之此下有地理志曰漯水出東武</span>  
<span style="margin-left: 2em">陽今漯水上承河水於武陽縣東南西北逕武陽</span>  
<span style="margin-left: 2em">新城東云云炳巽以其重見於前刪此存彼不知</span>  
<span style="margin-left: 2em">下文水自城東北逕東武陽縣故城南所謂自城</span>  
<span style="margin-left: 2em">者承武陽新城言也使如所刪則自城<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">接高唐</span>  
<span style="margin-left: 2em">不可通矣此𩔖皆爲舛誤然炳巽作此書凡厯九</span>  
<span style="margin-left: 2em">年而成丹鉛矻矻手自<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）">定其初未見朱謀㙔本</span>  
<span style="margin-left: 2em">後求得之而所見大畧相同亦可知其用心之勤</span>  
<span style="margin-left: 2em">至雖不能盡出前人範圍而鈎索考証之功亦未</span>  
<!-- 册2 葉1948b　Page:文淵閣四庫全書_0002冊.djvu/492 -->
<span style="margin-left: 2em">可没也</span>  
水經注釋四十巻刊誤十二巻<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝趙一淸撰一淸字誠夫仁和人酈道元水經注</span>  
<span style="margin-left: 2em">傳寫舛訛其來巳久諸家藏本互有校讐而大致</span>  
<span style="margin-left: 2em">不甚相遠歐陽元功王褘諸人但稱經註混淆而</span>  
<span style="margin-left: 2em">巳於注文無異詞也近時寧波全祖望始自稱得</span>  
<span style="margin-left: 2em">先世舊聞謂道元注中有注本雙行夾寫今混作</span>  
<span style="margin-left: 2em">大字幾不可辨一淸因從其說辨驗文義離析其</span>  
<span style="margin-left: 2em">注中之注以大字細字分别書之使語不相雜而</span>  
<!-- 册2 葉1949a　Page:文淵閣四庫全書_0002冊.djvu/492 -->
<span style="margin-left: 2em">文仍相屬考沈約宋書稱漢鐃歌本大字爲詞細</span>  
<span style="margin-left: 2em">字爲聲後人聲詞合寫是以莫辨是傳錄混淆古</span>  
<span style="margin-left: 2em">有是事又如明嘉靖中所刻齊民要術簡端周書</span>  
<span style="margin-left: 2em">曰神農之時天雨粟云云一條崇禎中刻孔子家</span>  
<span style="margin-left: 2em">語本姓解中微國名子爵五字間以注文刻作大</span>  
<span style="margin-left: 2em">字者亦時有之至於巨帙連篇盈四十巻而全部</span>  
<span style="margin-left: 2em">夾注悉誤寫爲正文揆以事理似乎不近姚宏補</span>  
<span style="margin-left: 2em">注戰國䇿范成大作吳郡志並於注中夾注前人</span>  
<span style="margin-left: 2em">嘗舉以爲例而自宋以來未嘗有舉及水經注者</span>  
<!-- 册2 葉1949b　Page:文淵閣四庫全書_0002冊.djvu/492 -->
<span style="margin-left: 2em">祖望所云先世舊聞不識傳於何代載在何書殆</span>  
<span style="margin-left: 2em">出於以意推求而詭稱授受然倪思作班馬異同</span>  
<span style="margin-left: 2em">以大字細字連書猝難辨析明許相卿改爲史漢</span>  
<span style="margin-left: 2em">方駕以班馬相同者書於中以馬有而班無者側</span>  
<span style="margin-left: 2em">注於左以班有而馬無者側注於右遂使增刪之</span>  
<span style="margin-left: 2em">意開巻釐然而原書仍無改易最爲善變一淸此</span>  
<span style="margin-left: 2em">書殆亦𩔖是但使正文旁義條理分明是亦道元</span>  
<span style="margin-left: 2em">之功臣矣何必託諸原本效豐坊之故智乎又唐</span>  
<span style="margin-left: 2em">六典注稱桑欽所引天下之水百三十七江河在</span>  
<!-- 册2 葉1952a　Page:文淵閣四庫全書_0002冊.djvu/493 -->
<span style="margin-left: 2em">焉今本所列僅一百一十六水考崇文總目載水</span>  
<span style="margin-left: 2em">經注三十五巻蓋宋代巳佚其五巻今本乃後人</span>  
<span style="margin-left: 2em">離析篇帙以合原數此二十一水蓋卽在所佚之</span>  
<span style="margin-left: 2em">中一淸證以本注雜採他籍得<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3223.svg?width=24" alt="四庫全書僻字第3223號（滏）" title="四庫全書僻字第3223號（滏）">洺滹沱派滋伊</span>  
<span style="margin-left: 2em">𤄊澗洛豐經汭渠𫉬洙滁曰南弱黑十八水於㶟</span>  
<span style="margin-left: 2em">水下分㶟餘水又考驗本經知淸漳水濁漳水大</span>  
<span style="margin-left: 2em">遼水小遼水皆原分爲二共得二十一水與六典</span>  
<span style="margin-left: 2em">注原數相符其考据訂補亦極精核巻首列所據</span>  
<span style="margin-left: 2em">以校正者凡四十本雖其中不免影附誇多<sub class="note-yuan">如所稱黄</sub></span>  
<!-- 册2 葉1952b　Page:文淵閣四庫全書_0002冊.djvu/493 -->
<span style="margin-left: 2em"><sub class="note-yuan">宗羲本原無成書顧炎武本顧祖禹本閻若璩本皆所著書引用考辨實無刻本又黃儀本稱其書</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">今歸新城王氏池北書庫考王士禎殁後池北書庫所藏皆已散佚見趙執信因園集是其子孫斷</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">無收書之事若士禎存時所收則書歸王氏在康熙辛卯以前一淸年齒亦斷不及見也</sub>然旁</span>  
<span style="margin-left: 2em">引博徵頗爲淹貫訂疑辨訛是正良多自官校宋</span>  
<span style="margin-left: 2em">本以外外間諸刻固不能不以是爲首矣</span>  
吳中水利書一巻<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">宋單鍔撰鍔字季隱宜興人嘉祐四年進士歐陽</span>  
<span style="margin-left: 2em">修知舉時所取士也得第以後不就官獨留心於</span>  
<span style="margin-left: 2em">吳中水利嘗獨乘小舟往來於蘇州常州湖州之</span>  
<!-- 册2 葉1953a　Page:文淵閣四庫全書_0002冊.djvu/493 -->
<span style="margin-left: 2em">間經三十年凡一溝一瀆無不周覽其源流考究</span>  
<span style="margin-left: 2em">其形勢因以所閱厯著爲此書元祐六年蘇軾知</span>  
<span style="margin-left: 2em">杭州日嘗爲狀進於朝㑹軾爲李定舒亶所劾逮</span>  
<span style="margin-left: 2em">赴御史臺鞫治其議遂寢明永樂中夏原吉疏吳</span>  
<span style="margin-left: 2em">江水門濬宜興百瀆正統中周忱修築溧陽二𭐏</span>  
<span style="margin-left: 2em">皆用鍔說嘉靖中歸有光作三吳水利錄則稱治</span>  
<span style="margin-left: 2em">太湖不若治松江鍔欲修伍堰開夾苧于瀆以截</span>  
<span style="margin-left: 2em">西來之水使不入太湖不知揚州藪澤天所以瀦</span>  
<span style="margin-left: 2em">東南之水也水爲民之害亦爲民之利今以人力</span>  
<!-- 册2 葉1953b　Page:文淵閣四庫全書_0002冊.djvu/493 -->
<span style="margin-left: 2em">遏之就使太湖乾枯於民豈爲利哉其說稍與鍔</span>  
<span style="margin-left: 2em">異蓋歲月綿邈陵谷變遷地形今古異宜各據所</span>  
<span style="margin-left: 2em">見以爲論要之舊法未可全執亦未可全廢在隨</span>  
<span style="margin-left: 2em">時消息之耳蘇軾進書狀載東坡集五十九巻中</span>  
<span style="margin-left: 2em">此書卽附其後書中有併圖以進之語而於其上</span>  
<span style="margin-left: 2em">加貼黃云其圖畫得草畧未敢進上乞下有司計</span>  
<span style="margin-left: 2em">㑹單鍔别畫此本刪此貼黃惟存别畫二字自爲</span>  
<span style="margin-left: 2em">一行蓋此書久無專刻志書從東坡集中錄出此</span>  
<span style="margin-left: 2em">本又從志書錄出故輾轉舛漏如是也</span>  
<!-- 册2 葉1956a　Page:文淵閣四庫全書_0002冊.djvu/494 -->
四明它山水利備覽二巻<sub class="note-yuan">浙江吳王墀家藏本</sub>  
<span style="margin-left: 2em">宋魏峴撰峴鄞縣人官朝奉郎提舉福建路市舶</span>  
<span style="margin-left: 2em">鄞故有它山一水其始大溪與江通流鹹潮衝接</span>  
<span style="margin-left: 2em">耕者弗利唐太和七年邑令王元暐始築堰以捍</span>
