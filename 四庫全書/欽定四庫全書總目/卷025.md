欽定四庫全書總目卷二十五  
<span style="margin-left: 1em">經部二十五</span>  
<span style="margin-left: 2em">禮類存目三</span>  
禮經奥㫖一卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">舊本題宋鄭樵撰考其文卽六經奥論之一卷也</span>  
<span style="margin-left: 2em">六經奥論本危<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3771.svg?width=24" alt="四庫全書僻字第3771號（邦）" title="四庫全書僻字第3771號（邦）">輔託之鄭樵此更僞中作僞摘</span>  
<span style="margin-left: 2em">其一卷別立書名以<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3271.svg?width=24" alt="四庫全書僻字第3271號（炫）" title="四庫全書僻字第3271號（炫）">世曹溶漫收之學海類編</span>  
<span style="margin-left: 2em">中失考甚矣</span>  
二禮考一卷<sub class="note-yuan">内府藏本</sub>  
<!-- 册1 葉2013b　Page:文淵閣四庫全書_0001冊.djvu/553 -->
<span style="margin-left: 2em">舊本題宋眞德秀撰諸家書目不著錄惟曹溶學</span>  
<span style="margin-left: 2em">海類編載之書止五頁引程朱諸儒之說凡九條</span>  
<span style="margin-left: 2em">條下係以案語然案語内引元泰定中邱葵更定</span>  
<span style="margin-left: 2em">周禮又引吳澄三禮考注德秀何由得見之其僞</span>  
<span style="margin-left: 2em">不待言矣</span>  
三禮考注六十四卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">舊本題元吳澄撰其書據尙書周官篇以改周禮</span>  
<span style="margin-left: 2em">六官之屬分大司徒之半以補冬官而考工記别</span>  
<span style="margin-left: 2em">爲一卷儀禮十七篇爲正經於大小戴記中取六</span>  
<!-- 册1 葉2016a　Page:文淵閣四庫全書_0001冊.djvu/554 -->
<span style="margin-left: 2em">篇爲儀禮逸經取十五篇爲儀禮傳别有曲禮八</span>  
<span style="margin-left: 2em">篇然澄作尙書纂言不信古文何乃據周官以定</span>  
<span style="margin-left: 2em">周禮卽以澄三禮敘錄及禮記纂言考之所列篇</span>  
<span style="margin-left: 2em">目亦不合其經義混淆先後矛盾者不一而足虞</span>  
<span style="margin-left: 2em">集作澄墓誌宋濂元史澄本傳皆不言澄有此書</span>  
<span style="margin-left: 2em">相傳初藏廬陵康震家後爲郡人晏璧所得遂掩</span>  
<span style="margin-left: 2em">爲已作經楊士奇等抄傳改正然士奇序及成化</span>  
<span style="margin-left: 2em">中羅倫校刻序皆疑其爲璧所作則當時固有異</span>  
<span style="margin-left: 2em">論矣士奇又言聞諸長老澄晚年於此書不及考</span>  
<!-- 册1 葉2016b　Page:文淵閣四庫全書_0001冊.djvu/554 -->
<span style="margin-left: 2em">訂授意於其孫當當嘗爲之而未就朱𢑴尊經義</span>  
<span style="margin-left: 2em">考言曾購得當所補周官禮以驗今書多不合又</span>  
<span style="margin-left: 2em">張爾岐蒿菴閒話曰愚讀儀禮偶得吳氏考注其</span>  
<span style="margin-left: 2em">注皆採自鄭賈往往失其端末其不用鄭賈者四</span>  
<span style="margin-left: 2em">十餘事惟少牢篇尸入正祭章補出尸授祭肺四</span>  
<span style="margin-left: 2em">字爲有功於經餘皆支離之甚草廬名宿豈應疎</span>  
<span style="margin-left: 2em">謬至此後得三禮考註序云輒因朱子所分禮章</span>  
<span style="margin-left: 2em">重加倫紀其經後之記依經章次秩序其文不敢</span>  
<span style="margin-left: 2em">割裂一仍其舊今此書則割裂記文散附經内矣</span>  
<!-- 册1 葉2017a　Page:文淵閣四庫全書_0001冊.djvu/554 -->
<span style="margin-left: 2em">序又云二戴之記中有經篇離之爲逸經禮各有</span>  
<span style="margin-left: 2em">義則經之傳也以戴氏所存兼劉氏所補合之而</span>  
<span style="margin-left: 2em">爲傳傳十五篇今此書十五篇則具矣士相見公</span>  
<span style="margin-left: 2em">食大夫二篇但採掇禮記之文以充數求所謂清</span>  
<span style="margin-left: 2em">江劉氏之書無有也至於逸經八篇序詳列其目</span>  
<span style="margin-left: 2em">公冠遷廟釁廟取之大戴奔喪投壺取之小戴中</span>  
<span style="margin-left: 2em">霤禘於太廟王居明堂取之鄭氏注逸經雖曰八</span>  
<span style="margin-left: 2em">篇實具其書者五篇而已其三篇僅存篇題非實</span>  
<span style="margin-left: 2em">有其書也今此書大戴明堂列之第二葢不知王</span>  
<!-- 册1 葉2017b　Page:文淵閣四庫全書_0001冊.djvu/554 -->
<span style="margin-left: 2em">居明堂之與明堂爲有辨也三者與序皆不合其</span>  
<span style="margin-left: 2em">不出於吳氏也審矣序又云正經居首逸經次之</span>  
<span style="margin-left: 2em">傳終焉皆别爲卷而不相紊此外悉以歸諸戴氏</span>  
<span style="margin-left: 2em">之記朱子所輯及黃氏喪禮楊氏祭禮亦叅伍以</span>  
<span style="margin-left: 2em">去其重複名曰朱氏記而與二戴爲三本書次第</span>  
<span style="margin-left: 2em">畧見於此今此書朱記了不可見而又雜取二戴</span>  
<span style="margin-left: 2em">之書名爲曲禮者八篇龎雜稡會望之欲迷與所</span>  
<span style="margin-left: 2em">云悉以歸諸戴氏之記者又不合何物妄人謬誣</span>  
<span style="margin-left: 2em">先儒至此云云然則是書之僞可以無庸疑似矣</span>  
<!-- 册1 葉2020a　Page:文淵閣四庫全書_0001冊.djvu/555 -->
二禮經傳測六十八卷<sub class="note-yuan">原仕工部侍郎李友棠家藏本</sub>  
<span style="margin-left: 2em">明湛若水撰若水字元明增城人宏治乙丑進士</span>  
<span style="margin-left: 2em">厯官南京吏禮兵三部尙書事跡具明史儒林傳</span>  
<span style="margin-left: 2em">是編從孔子曲禮三千經禮三百之說故曰二禮</span>  
<span style="margin-left: 2em">以戴記曲禮附以少儀爲曲禮上經三卷以儀禮</span>  
<span style="margin-left: 2em">爲下經十七卷冠義等十六篇爲儀禮正傳十六</span>  
<span style="margin-left: 2em">卷王制等二十三篇爲二禮雜傳通傳二十三卷</span>  
<span style="margin-left: 2em">又别分小戴郊特牲等五篇與大戴公符等四篇</span>  
<span style="margin-left: 2em">爲儀禮逸經傳每節各爲章㫖標目殊傷頊碎所</span>  
<!-- 册1 葉2020b　Page:文淵閣四庫全書_0001冊.djvu/555 -->
<span style="margin-left: 2em">註亦皆空談</span>  
廟制考議<sub class="note-yuan">無卷數　浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明季本撰本有易學四同已著錄是書總論凡七</span>  
<span style="margin-left: 2em">義附錄七十七圖其中如謂天子五廟周加文武</span>  
<span style="margin-left: 2em">二世室乃七廟其說主鄭康成注惟書咸有一德</span>  
<span style="margin-left: 2em">稱七世之廟可以觀德則似商以前已有七廟無</span>  
<span style="margin-left: 2em">以爲解乃謂自太甲逆溯至相士爲七世所謂七</span>  
<span style="margin-left: 2em">世之廟專指相士今考魯語曰商人禘舜而祖契</span>  
<span style="margin-left: 2em">郊𡨋而宗湯將觀列祖之德何遠不及契近不及</span>  
<!-- 册1 葉2021a　Page:文淵閣四庫全書_0001冊.djvu/555 -->
<span style="margin-left: 2em">湯而獨舉相士又考殷本紀相士以下曰昌若曰</span>  
<span style="margin-left: 2em">曹圉曰𡨋曰振曰微曰報丁曰報乙曰報丙曰主</span>  
<span style="margin-left: 2em">壬曰主癸曰湯曰太丁曰太甲自太甲逆溯至相</span>  
<span style="margin-left: 2em">士十四世而本謂太甲上溯相士爲七世其說舛</span>  
<span style="margin-left: 2em">謬葢因僞古文尙書之言七廟致生穿鑿不知吕</span>  
<span style="margin-left: 2em">氏春秋引商書實作五世之廟無庸如是牽合也</span>  
<span style="margin-left: 2em">本又謂禘非審諦昭穆惟有功德而廟不毁者則</span>  
<span style="margin-left: 2em">當禘於所出之祖廟而以受命之祖配之長發之</span>  
<span style="margin-left: 2em">詩小序曰大禘也而述契及相士以至於湯是特</span>  
<!-- 册1 葉2021b　Page:文淵閣四庫全書_0001冊.djvu/555 -->
<span style="margin-left: 2em">審諦其賢君而以湯配也今考魯語曰上甲微能</span>  
<span style="margin-left: 2em">帥契者商人報焉祭法曰𡨋勤其官而水死以死</span>  
<span style="margin-left: 2em">勤事則祀之是湯以上惟微𡨋得永列祀典而未</span>  
<span style="margin-left: 2em">聞商人列諸不毁之廟今本謂相士有功德而廟</span>  
<span style="margin-left: 2em">不毁擬於三宗殊爲踈舛况相士本在毁廟之列</span>  
<span style="margin-left: 2em">而長發爲大禘之詩得及相土則毁廟未毁廟之</span>  
<span style="margin-left: 2em">主皆得與矣此正可以折本之說而本反引以爲</span>  
<span style="margin-left: 2em">難乎至謂公劉太王王季廟皆不當毁不特文武</span>  
<span style="margin-left: 2em">則益不經矣本又斥朱子考妣同祫之說謂禘祫</span>  
<!-- 册1 葉2024a　Page:文淵閣四庫全書_0001冊.djvu/556 -->
<span style="margin-left: 2em">男主得入女主不得入故周公營洛邑特立文武</span>  
<span style="margin-left: 2em">廟父子同廟而其廟無妣主今考春秋僖公八年</span>  
<span style="margin-left: 2em">秋七月禘于太廟用致夫人左氏傳曰禘而致哀</span>  
<span style="margin-left: 2em">姜焉非禮也凡夫人不薨于寢不殯于廟不赴於</span>  
<span style="margin-left: 2em">同盟不祔于姑則弗致也據此則夫人薨于寢殯</span>  
<span style="margin-left: 2em">於廟赴于同盟祔于姑者皆得以禘致太廟矣何</span>  
<span style="margin-left: 2em">得云妣主不得與於禘祫乎祭統鋪筵設同几爲</span>  
<span style="margin-left: 2em">依神也鄭註同之爲言洞也祭者以其妃配亦不</span>  
<span style="margin-left: 2em">待几也據此則凡祭皆有配明矣洛誥烝祭歲文</span>  
<!-- 册1 葉2024b　Page:文淵閣四庫全書_0001冊.djvu/556 -->
<span style="margin-left: 2em">王騂牛一武王騂牛一又曰王入太室祼孔傳曰</span>  
<span style="margin-left: 2em">王賔異周公殺牲精意以享文武皆至其廟親告</span>  
<span style="margin-left: 2em">曰據云皆至其廟則祭文武别廟可知本何得云</span>  
<span style="margin-left: 2em">父子同廟雝詩序禘太祖也鄭箋太祖謂文王而</span>  
<span style="margin-left: 2em">其詩曰旣右列考亦右文母則明以文母配也本</span>  
<span style="margin-left: 2em">又何得謂洛邑之文廟獨無文母乎本又謂七廟</span>  
<span style="margin-left: 2em">之制太祖居中昭不必居左穆不必居右古人以</span>  
<span style="margin-left: 2em">右爲尊當於太祖廟之東平行以次而東爲四親</span>  
<span style="margin-left: 2em">廟今考廟以昭穆爲左右雖不見於經然考周禮</span>  
<!-- 册1 葉2025a　Page:文淵閣四庫全書_0001冊.djvu/556 -->
<span style="margin-left: 2em">冡人曰先王之葬居中以昭穆爲左右註曰昭居</span>  
<span style="margin-left: 2em">左穆居右夾處東西則昭穆分左右之明證也故</span>  
<span style="margin-left: 2em">賈疏卽以墓之昭穆推廟之昭穆今本謂廟之昭</span>  
<span style="margin-left: 2em">穆皆在祖廟之中又何以解於墓之昭穆别左右</span>  
<span style="margin-left: 2em">乎又考匠人曰左祖右社賈疏引祭義註云周尙</span>  
<span style="margin-left: 2em">左又考桓公二年取郜大鼎於宋納於太廟何休</span>  
<span style="margin-left: 2em">云文家左宗廟尙尊據此則於王宫之外立祖廟</span>  
<span style="margin-left: 2em">與社稷旣尙左而立祖廟與羣廟則又尙右何同</span>  
<span style="margin-left: 2em">一地而所尙頓異耶眞無據之談也本又謂禘祫</span>  
<!-- 册1 葉2025b　Page:文淵閣四庫全書_0001冊.djvu/556 -->
<span style="margin-left: 2em">在太廟容主多則太廟宜大高祖以下羣廟僅容</span>  
<span style="margin-left: 2em">考妣足矣故其制小周禮祭僕言小喪復于小廟</span>  
<span style="margin-left: 2em">𨽻僕言大喪復於小寢大寢是也今考閔公二年</span>  
<span style="margin-left: 2em">夏五月乙酉吉禘于莊公定公八年冬十月辛卯</span>  
<span style="margin-left: 2em">禘於僖公則春秋禘祭有于羣廟者矣而未見羣</span>  
<span style="margin-left: 2em">廟之不容多主則亦未見羣廟之必小於太廟也</span>  
<span style="margin-left: 2em">周禮言小寢大寢小廟非以規制之大小言特以</span>  
<span style="margin-left: 2em">尊卑言耳故鄭註但云髙祖以下高祖以上考工</span>  
<span style="margin-left: 2em">記曰廟門容大扁七个於凡廟之門同可知凡廟</span>  
<!-- 册1 葉2028a　Page:文淵閣四庫全書_0001冊.djvu/557 -->
<span style="margin-left: 2em">之室亦同矣而何大小之别乎本又不信商祖契</span>  
<span style="margin-left: 2em">周祖后稷今考周語明云我太祖后稷之所經緯</span>  
<span style="margin-left: 2em">也祭法明云祖契而宗湯而本不信之尤荒經芮</span>  
<span style="margin-left: 2em">古之甚矣其論厯代廟制若謂漢光武但當立高</span>  
<span style="margin-left: 2em">祖舂陵節侯以上四世廟不當爲宣元成哀立廟</span>  
<span style="margin-left: 2em">則明世宗明倫大典之說時𫝑所牽又當别論者</span>  
<span style="margin-left: 2em">也前明三禮之學本最著稱後世儒者往往承其</span>  
<span style="margin-left: 2em">謬說故舉其最誤者辨之庶可得其是非之實焉</span>

齊家寶要二卷<sub class="note-yuan">江蘇周厚堉家藏本</sub>

<span style="margin-left: 1em">國朝張文嘉撰文嘉字仲嘉錢塘人是書本書儀家</span>  
<span style="margin-left: 2em">禮諸書酌爲古今通禮曰居家禮曰童子禮曰義</span>  
<span style="margin-left: 2em">學約曰師範曰家誡曰家規曰宗講約曰鄉約曰</span>  
<span style="margin-left: 2em">社約曰冠禮曰婚禮曰喪禮曰祭禮每門前引經</span>  
<span style="margin-left: 2em">傳及新定儀注間有附論折衷頗爲詳愼但據沈</span>  
<span style="margin-left: 2em">堯中之說謂三年之喪當三十六月不知此說始</span>  
<span style="margin-left: 2em">於唐王元感而張柬之駁之其議遂寢載在唐書</span>  
<span style="margin-left: 2em">張柬之傳文嘉取之殊爲失考又謂宣公新宫灾</span>  
<span style="margin-left: 2em">在薨後二十九月其時主猶在寢證古人喪不止</span>  
<!-- 册1 葉2097a　Page:文淵閣四庫全書_0001冊.djvu/574 -->
<span style="margin-left: 2em">於二十七月尤爲誤中之誤考成公三年二月甲</span>  
<span style="margin-left: 2em">子新宫灾杜註三年喪畢宣公神主新入廟故謂</span>  
<span style="margin-left: 2em">之新宫據此則宣公之主已入廟矣公羊傳曰新</span>  
<span style="margin-left: 2em">宮者宣公之宮也宣公則曷爲謂之新宫不忍言</span>  
<span style="margin-left: 2em">也榖梁傳曰新宫者禰宫也迫近不敢稱諡恭也</span>  
<span style="margin-left: 2em">據此則不稱宣公而稱新宫必不由於主不在廟</span>  
<span style="margin-left: 2em">至胡傳始引劉絢之說謂不稱宣宫以未遷主於</span>  
<span style="margin-left: 2em">三傳畧無所據然絢謂宣公薨至是二十有八月</span>  
<span style="margin-left: 2em">緩於遷主則以緩遷爲失明矣今文嘉乃引以爲</span>

<span style="margin-left: 2em">三十六月之證則是以二十八月主不遷廟爲持</span>  
<span style="margin-left: 2em">喪之正經其誤又甚於絢矣文嘉又謂凡期喪皆</span>  
<span style="margin-left: 2em">有禫今考雜記曰期之喪十一月而練十三月而</span>  
<span style="margin-left: 2em">祥十五月而禫注曰此爲父在爲母也喪服小記</span>  
<span style="margin-left: 2em">曰爲父母妻長子禫是期之喪得禫者止有母妻</span>  
<span style="margin-left: 2em">及長子耳小記曰庻子在父之室則爲其母不禫</span>  
<span style="margin-left: 2em">又曰宗子母在爲妻禫明父在爲妻不禫則是母</span>  
<span style="margin-left: 2em">妻期喪且有不得禫者矣今文嘉謂凡期皆得禫</span>  
<span style="margin-left: 2em">尤未詳考葢是書未能窮源於禮經注疏第從家</span>
