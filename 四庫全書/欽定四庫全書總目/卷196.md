## 欽定四庫全書總目 卷一百九十六　集部四十九　詩文評類二

<!-- 册5 葉972：整葉圖版，無文字記錄 -->
<!-- 册5 葉973a　Page:文淵閣四庫全書_0005冊.djvu/248 -->
欽定四庫全書總目卷一百九十六  
<span style="margin-left: 1em">集部四十九</span>  
<span style="margin-left: 2em">詩文評類二</span>  
文說一卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">元陳繹曾撰繹曾字伯敷元史附見儒學傳作處</span>  
<span style="margin-left: 2em">州人而吳興續志亦載其名蓋家本括蒼而僑居</span>  
<span style="margin-left: 2em">苕水者也至順中官至國子監助敎嘗從學於戴</span>  
<span style="margin-left: 2em">表元而與陳旅友善師友淵源具有所自故所學</span>  
<span style="margin-left: 2em">頗見根柢是書乃因延祐復行科舉爲程試之式</span>  
<!-- 册5 葉973b　Page:文淵閣四庫全書_0005冊.djvu/248 -->
<span style="margin-left: 2em">而作書中分列八條論行文之法時五經皆以宋</span>  
<span style="margin-left: 2em">儒傳註爲主懸爲功令莫敢異趨故是書大㫖皆</span>  
<span style="margin-left: 2em">折衷於朱子吳興續志稱繹曾嘗著文筌譜論科</span>  
<span style="margin-left: 2em">舉天階使學者知所向方人爭傳錄焦竑經籍志</span>  
<span style="margin-left: 2em">又載繹曾古今文矜式二卷今考繹曾所著文筌</span>  
<span style="margin-left: 2em">八卷附詩小譜二卷元時麻沙坊刻附列於䇿學</span>  
<span style="margin-left: 2em">統宗之首今尙有傳本其文與此編迥殊惟科舉</span>  
<span style="margin-left: 2em">天階與古今文矜式今未之見疑此編卽二書之</span>  
<span style="margin-left: 2em">一但名目錯互莫能證定今姑仍永樂大典舊題</span>  
<!-- 册5 葉976a　Page:文淵閣四庫全書_0005冊.djvu/249 -->
<span style="margin-left: 2em">以文說著錄用闕所疑卷首所稱陳文靖公蓋卽</span>  
<span style="margin-left: 2em">元翰林學士東平陳儼亦以文名至其自稱先尙</span>  
<span style="margin-left: 2em">書者則已失其世系無可考矣</span>  
修辭鑑衡二卷<sub class="note-yuan">編修汪如藻家藏本</sub>  
<span style="margin-left: 2em">元王構編構字肯堂東平人官至翰林學士承㫖</span>  
<span style="margin-left: 2em">諡文肅事迹具元史本傳據至順四年王理序是</span>  
<span style="margin-left: 2em">編乃構官濟南總管時以授其門人劉氏而理爲</span>  
<span style="margin-left: 2em">刻於集慶路者舊本殘蠧闕其前頁其劉氏之名</span>  
<span style="margin-left: 2em">則不可考矣上卷論詩下卷論文皆採宋人詩話</span>  
<!-- 册5 葉976b　Page:文淵閣四庫全書_0005冊.djvu/249 -->
<span style="margin-left: 2em">及文集說部爲之構所附論者惟下卷結語一條</span>  
<span style="margin-left: 2em">而已所錄雖多習見之語而去取頗爲精核元史</span>  
<span style="margin-left: 2em">稱構弱冠以詞賦中選至元十一年爲翰林國史</span>  
<span style="margin-left: 2em">院編修草伐宋詔書爲世祖所賞又稱構練習臺</span>  
<span style="margin-left: 2em">閣故事凡祖宗諡議册文皆所撰定又稱其子士</span>  
<span style="margin-left: 2em">熙士<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）">皆能以文學世其家則構在當時實以文</span>  
<span style="margin-left: 2em">章名世宜是編所錄具有鑒裁矣其中所引如詩</span>  
<span style="margin-left: 2em">文發源詩憲蒲氏漫齋錄之類今皆亡佚不傳賴</span>  
<span style="margin-left: 2em">此書存其一二又世傳吕氏童𫎇訓非其全帙此</span>  
<!-- 册5 葉977a　Page:文淵閣四庫全書_0005冊.djvu/249 -->
<span style="margin-left: 2em">書所採凡三十一條皆今本所未載亦頗足以資</span>  
<span style="margin-left: 2em">考證較詩話總龜之類浩博而傷猥雜者實爲勝</span>  
<span style="margin-left: 2em">之固談藝家之指南也此書久無刋本傳寫多訛</span>  
<span style="margin-left: 2em">而卷中不著書名者凡十條又上卷佚其第五頁</span>  
<span style="margin-left: 2em">序文僅存末頁中亦時有缺字今檢其可考者補</span>  
<span style="margin-left: 2em">之其無可考者則姑仍原本以存其舊焉</span>  
金石例十卷<sub class="note-yuan">山東巡撫採進本</sub>  
<span style="margin-left: 2em">元潘昂霄撰昂霄有河源記已著錄是書一卷至</span>  
<span style="margin-left: 2em">五卷述銘誌之始於品級塋墓羊虎德政神道家</span>  
<!-- 册5 葉977b　Page:文淵閣四庫全書_0005冊.djvu/249 -->
<span style="margin-left: 2em">廟賜碑之制一一詳考六卷至八卷述唐韓愈所</span>  
<span style="margin-left: 2em">撰碑誌以爲括例於家世宗族職名妻子死葬日</span>  
<span style="margin-left: 2em">月之類咸條列其文標爲程式九卷則雜論文體</span>  
<span style="margin-left: 2em">十卷則史院凡例然昂霄是書以金石例爲名所</span>  
<span style="margin-left: 2em">述宜止於碑誌而泛及雜文之格與起居注之式</span>  
<span style="margin-left: 2em">似乎不倫又雜文之中其目載有郝伯常先生編</span>  
<span style="margin-left: 2em">類金石八例蒼崖先生十五例二條皆有錄無書</span>  
<span style="margin-left: 2em">九卷之末有䟦云右先生金石例皆取韓文類輯</span>  
<span style="margin-left: 2em">以爲例大約與徐秋山括例相去不遠若再備錄</span>  
<!-- 册5 葉980a　Page:文淵閣四庫全書_0005冊.djvu/250 -->
<span style="margin-left: 2em">似爲重複故止記其目於此然則最後二卷其始</span>  
<span style="margin-left: 2em">必別自爲編附之金石例後後人刋板乃併爲一</span>  
<span style="margin-left: 2em">書又知六卷至八卷所謂韓文括例者皆全採徐</span>  
<span style="margin-left: 2em">氏之書非昂霄所自撰矣其書敘述古制頗爲典</span>  
<span style="margin-left: 2em">核雖所載括例但舉韓愈之文未免舉一而廢百</span>  
<span style="margin-left: 2em">然明以來金石之文往往不考古法漫無矩度得</span>  
<span style="margin-left: 2em">是書以爲依據亦可謂尙有典型愈於率意妄撰</span>  
<span style="margin-left: 2em">者多矣書在元代板凡三刻此本乃其子詡至正</span>  
<span style="margin-left: 2em">五年刋於鄱陽者也</span>  
<!-- 册5 葉980b　Page:文淵閣四庫全書_0005冊.djvu/250 -->
作義要訣一卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">元倪士毅撰士毅有四書輯釋已著錄是編皆當</span>  
<span style="margin-left: 2em">時經義之體例自宋神宗熙寧四年始以經義試</span>  
<span style="margin-left: 2em">士元太宗從耶律楚材之請以三科選舉經義亦</span>  
<span style="margin-left: 2em">居其一至仁宗皇慶二年酌議科舉條制乃定𫎇</span>  
<span style="margin-left: 2em">古色目人第一場經問五條漢人南人第一場經</span>  
<span style="margin-left: 2em">疑二問限三百字以上不拘格律元統以後蒙古</span>  
<span style="margin-left: 2em">色目人亦增經義一道明以來科舉之文實因是</span>  
<span style="margin-left: 2em">而引伸者也是書所論雖規模淺狹朱究文章之</span>  
<!-- 册5 葉981a　Page:文淵閣四庫全書_0005冊.djvu/250 -->
<span style="margin-left: 2em">本源然如云第一要識得道理透徹第二要識得</span>  
<span style="margin-left: 2em">經文本㫖分曉第三要識得古今治亂安危之大</span>  
<span style="margin-left: 2em">體又云長而轉換新意不害其爲長短而曲折意</span>  
<span style="margin-left: 2em">盡不害其爲短務高則多涉乎僻欲新則類入乎</span>  
<span style="margin-left: 2em">怪下字惡乎俗而造作太過則語澁立意惡乎同</span>  
<span style="margin-left: 2em">而搜索太甚則理背皆後來制藝之龜鑒也</span>  
<span style="margin-left: 1em">國家設科取士仍以經義爲先我</span>  
皇上聖訓諄諄釐正文體操觚之士皆知以先正爲步  
<span style="margin-left: 2em">趨是書又在明前法雖小異而理則相通錄而存</span>  
<!-- 册5 葉981b　Page:文淵閣四庫全書_0005冊.djvu/250 -->
<span style="margin-left: 2em">之或亦先河後海之義歟原序稱兼采謝氏張氏</span>  
<span style="margin-left: 2em">之說永樂大典註其說已載舉業筌蹄卷中故不</span>  
<span style="margin-left: 2em">復錄今是卷適佚姑仍舊本闕之然大㫖則已具</span>  
<span style="margin-left: 2em">於此矣</span>  
墓銘舉例四卷<sub class="note-yuan">山東巡撫採進本</sub>  
<span style="margin-left: 2em">明王行撰行有半軒集已著錄行以墓誌銘書法</span>  
<span style="margin-left: 2em">有例其大要十有三事曰諱曰字曰姓氏曰鄉邑</span>  
<span style="margin-left: 2em">曰族出曰治行曰履厯曰卒日曰壽年曰妻曰子</span>  
<span style="margin-left: 2em">曰塟其序次或有先後要不越此十餘事而已取</span>  
<!-- 册5 葉984a　Page:文淵閣四庫全書_0005冊.djvu/251 -->
<span style="margin-left: 2em">唐韓愈李翺柳宗元宋歐陽修尹洙曾鞏王安石</span>  
<span style="margin-left: 2em">蘇軾朱子陳師道黃庭堅陳瓘晁補之張耒吕祖</span>  
<span style="margin-left: 2em">謙一十五家所作碑誌錄其目而舉其例以補元</span>  
<span style="margin-left: 2em">潘昂霄金石例之遺墓誌之興或云宋顔延之或</span>  
<span style="margin-left: 2em">云晉王戎或云魏繆襲或云漢杜子夏其源不可</span>  
<span style="margin-left: 2em">詳考由齊梁以至隋唐諸家文集傳者頗多然詞</span>  
<span style="margin-left: 2em">皆駢偶不爲典要惟韓愈始以史法作之後之文</span>  
<span style="margin-left: 2em">士率祖其體故是編所述以愈爲始焉</span>  
懷麓堂詩話一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<!-- 册5 葉984b　Page:文淵閣四庫全書_0005冊.djvu/251 -->
<span style="margin-left: 2em">明李東陽撰東陽有東祀錄已著錄李何未出已</span>  
<span style="margin-left: 2em">前東陽實以臺閣耆宿主持文柄其論詩主於法</span>  
<span style="margin-left: 2em">度音調而極論剽竊摹擬之非當時奉以爲宗至</span>  
<span style="margin-left: 2em">李何旣出始變其體然贋古之病適中其所詆訶</span>  
<span style="margin-left: 2em">故後人多抑彼而伸此此編所論多得古人之意</span>  
<span style="margin-left: 2em">雖詩家三昧不盡於是要亦深知甘苦之言矣姚</span>  
<span style="margin-left: 2em">希孟松癭集有此書跋云李長沙詩以勻穩爲主</span>  
<span style="margin-left: 2em">其爲古樂府弇州譏其類小學史斷迺其談詩頗</span>  
<span style="margin-left: 2em">津津是時詞林諸公多以詩爲事卷中所載如彭</span>  
<!-- 册5 葉985a　Page:文淵閣四庫全書_0005冊.djvu/251 -->
<span style="margin-left: 2em">民望謝方石輩相與抨彈甚切讀之猶想見前輩</span>  
<span style="margin-left: 2em">風致云云核其詞意似頗不滿於東陽然王世貞</span>  
<span style="margin-left: 2em">詆西涯樂府乃其少年盛氣之時迨其晩年作西</span>  
<span style="margin-left: 2em">涯樂府跋已自悔前論希孟所引殊不足爲憑惟</span>  
<span style="margin-left: 2em">好譽其子兆先殆有王福畤之癖是其一瑕耳林</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3271.svg?width=24" alt="四庫全書僻字第3271號（炫）" title="四庫全書僻字第3271號（炫）">巵言餘錄曰成化間姑熟夏宏集句有聯錦集</span>  
<span style="margin-left: 2em">懷麓堂詩話載其客醉已無言秋蛩自相語爲高</span>  
<span style="margin-left: 2em">季迪詩宏揑寫他人姓名今考集中無之云云聯</span>  
<span style="margin-left: 2em">錦集今未見然<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3271.svg?width=24" alt="四庫全書僻字第3271號（炫）" title="四庫全書僻字第3271號（炫）">與東陽均正德間人所見之本</span>  
<!-- 册5 葉985b　Page:文淵閣四庫全書_0005冊.djvu/251 -->
<span style="margin-left: 2em">不應有異或東陽偶誤記歟近時鮑氏知不足齋</span>  
<span style="margin-left: 2em">刻此編於浦源雲邊路繞巴山色樹裏河流漢水</span>  
<span style="margin-left: 2em">聲句下注曰案二句宋詩紀事以爲<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">詩今考宋</span>  
<span style="margin-left: 2em">詩紀事所載吳簡詩誠有此聯惟上句稍異一二</span>  
<span style="margin-left: 2em">字然厲鶚所據乃荆門紀畧其書爲康熙戊戌已</span>  
<span style="margin-left: 2em">亥間胡作炳所撰餖飣龎雜頗無根據似未可執</span>  
<span style="margin-left: 2em">以駁東陽况浦源此事都穆南濠詩話亦載之知</span>  
<span style="margin-left: 2em">當時必有所據安知非荆門紀畧反摭源此聯僞</span>  
<span style="margin-left: 2em">撰<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">詩耶是尤不當輕信新聞遽疑舊記矣</span>  
<!-- 册5 葉988a　Page:文淵閣四庫全書_0005冊.djvu/252 -->
頤山詩話二卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明安磐撰磐字公石頤山其號也嘉定州人宏治</span>  
<span style="margin-left: 2em">乙丑進士官至兵科給事中嘉靖初以爭大禮廷</span>  
<span style="margin-left: 2em">杖除名事迹具明史本傳其論詩以嚴羽爲宗其</span>
