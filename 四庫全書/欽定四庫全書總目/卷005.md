## 欽定四庫全書總目 卷五　經部五　易類五

<!-- 册1 葉457a　Page:文淵閣四庫全書_0001冊.djvu/164 -->
欽定四庫全書總目卷五  
<span style="margin-left: 1em">經部五</span>  
<span style="margin-left: 2em">易類五</span>  
周易大全二十四卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明胡廣等奉勅撰考明成祖實錄永樂十二年十</span>  
<span style="margin-left: 2em">一月甲寅命行在翰林院學士胡廣侍講楊榮金</span>  
<span style="margin-left: 2em">幼孜修五經四書大全十三年九月告成成祖親</span>  
<span style="margin-left: 2em">製序弁之卷首命禮部刋賜天下賜胡廣等鈔幣</span>  
<span style="margin-left: 2em">有差仍賜宴於禮部同時預纂修者自廣榮幼孜</span>  
<!-- 册1 葉457b　Page:文淵閣四庫全書_0001冊.djvu/164 -->
<span style="margin-left: 2em">外尙有翰林編修葉時中等三十九人此其五經</span>  
<span style="margin-left: 2em">之首也朱彞尊經義考謂廣等就前儒成編雜爲</span>  
<span style="margin-left: 2em">鈔錄而去其姓名易則取諸天台鄱陽二董氏雙</span>  
<span style="margin-left: 2em">湖雲峰二胡氏於諸書外未寓目者至多云云天</span>  
<span style="margin-left: 2em">台董氏者董楷之周易傳義附錄鄱陽董氏者董</span>  
<span style="margin-left: 2em">眞卿之周易會通雙湖胡氏者胡一桂之周易本</span>  
<span style="margin-left: 2em">義附錄纂疏雲峰胡氏者胡炳文之周易本義通</span>  
<span style="margin-left: 2em">釋也今勘驗舊文一一符合彞尊所論未可謂之</span>  
<span style="margin-left: 2em">苛求然董楷胡一桂胡炳文篤守朱子其說頗謹</span>  
<!-- 册1 葉460a　Page:文淵閣四庫全書_0001冊.djvu/165 -->
<span style="margin-left: 2em">嚴董眞卿則以程朱爲主而博採諸家以翼之其</span>  
<span style="margin-left: 2em">說亦頗賅備取材於四家之書而刋除重複勒爲</span>  
<span style="margin-left: 2em">一編雖不免守匱抱殘要其宗㫖則尙可謂不失</span>  
<span style="margin-left: 2em">其正且二百餘年以此取士一代之令甲在焉錄</span>  
<span style="margin-left: 2em">存其書見有明儒者之經學其初之不敢放軼者</span>  
<span style="margin-left: 2em">由於此其後之不免固陋者亦由於此鄭曉今言</span>  
<span style="margin-left: 2em">曰洪武開科五經皆主古注疏及宋儒易程朱書</span>  
<span style="margin-left: 2em">蔡詩朱春秋左公羊穀梁程胡張禮記陳後乃盡</span>  
<span style="margin-left: 2em">棄注疏不知始何時或曰始於頒五經大全時以</span>  
<!-- 册1 葉460b　Page:文淵閣四庫全書_0001冊.djvu/165 -->
<span style="margin-left: 2em">爲諸家說優者采入故耳然古注疏終不可廢也</span>  
<span style="margin-left: 2em">是當明盛時識者巳憂其弊矣觀於是編未始非</span>  
<span style="margin-left: 2em">千古得失之林也</span>  
易經䝉引十二卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">明蔡淸撰淸字介夫號虛齋晉江人成化甲辰進</span>  
<span style="margin-left: 2em">士官至南京國子監祭酒事蹟具明史儒林傳是</span>  
<span style="margin-left: 2em">書專以發明朱子本義爲主故其體例以本義與</span>  
<span style="margin-left: 2em">經文並書但於本義每條之首加一圈以示别葢</span>  
<span style="margin-left: 2em">尊之亞於經也然實多與本義異同如經分上下</span>  
<!-- 册1 葉461a　Page:文淵閣四庫全書_0001冊.djvu/165 -->
<span style="margin-left: 2em">朱子云以其簡袠重大故分爲上下二篇淸則云</span>  
<span style="margin-left: 2em">六十四卦何以不三十二卦爲上經三十二卦爲</span>  
<span style="margin-left: 2em">下經而乃上經三十卦下經三十四卦也用九見</span>  
<span style="margin-left: 2em">羣龍无首朱子云用九是諸卦百九十二陽爻之</span>  
<span style="margin-left: 2em">通例見羣龍无首是此卦六爻皆用九者之占詞</span>  
<span style="margin-left: 2em">淸則云孔子象傳及文言節節皆是主六爻皆用</span>  
<span style="margin-left: 2em">九者言但本義不主此說又云若依朱子之說則</span>  
<span style="margin-left: 2em">於用九下又當添六爻皆用九者一句知至至之</span>  
<span style="margin-left: 2em">知終終之朱子說上句知字重下句終字重淸則</span>  
<!-- 册1 葉461b　Page:文淵閣四庫全書_0001冊.djvu/165 -->
<span style="margin-left: 2em">云此未必是本文之意本文下句一知字豈偶然</span>  
<span style="margin-left: 2em">哉豈姑以對上句而無所當哉其他不肯委曲附</span>  
<span style="margin-left: 2em">和大率類此朱子不全從程傳而能發明程傳者</span>  
<span style="margin-left: 2em">莫若朱子淸不全從本義而能發明本義者莫若</span>  
<span style="margin-left: 2em">淸醇儒心得之學所由與爭門戸者異歟</span>  
讀易餘言五卷<sub class="note-yuan">副都御史黃登賢家藏本</sub>  
<span style="margin-left: 2em">明崔銑撰銑字仲鳬一字子鍾安陽人宏治乙丑</span>  
<span style="margin-left: 2em">進士官至南京禮部侍郞諡文敬事蹟具明史儒</span>  
<span style="margin-left: 2em">林傳是書以程傳爲主而兼採王弼吳澄之說與</span>  
<!-- 册1 葉464a　Page:文淵閣四庫全書_0001冊.djvu/166 -->
<span style="margin-left: 2em">朱子本義頗有異同大㫖舍象數而闡義理故謂</span>  
<span style="margin-left: 2em">陳摶所傳圖象皆衍術數與易無干諸儒卦變之</span>  
<span style="margin-left: 2em">說亦支離無取其上經卦略下經卦略大象說皆</span>  
<span style="margin-left: 2em">但標卦名不載經文繫辭輯說卦訓則備錄傳文</span>  
<span style="margin-left: 2em">葢書非一時所著故體例偶殊且經有卦名而繫</span>  
<span style="margin-left: 2em">辭說卦無章名其勢亦不能不異也惟刪說卦廣</span>  
<span style="margin-left: 2em">象八章而别以蔡淸之說增損之又序卦雜卦文</span>  
<span style="margin-left: 2em">言三傳一槩從刪則未免改經之嫌要其篤實近</span>  
<span style="margin-left: 2em">理故不失爲洛閩之傳矣朱彞尊經義考載銑讀</span>  
<!-- 册1 葉464b　Page:文淵閣四庫全書_0001冊.djvu/166 -->
<span style="margin-left: 2em">易餘言五卷又載銑易大象說一卷考此書第三</span>  
<span style="margin-left: 2em">卷卽大象說彞尊以其别本單行遂析爲二偶未</span>  
<span style="margin-left: 2em">考也今附著於此不更複出焉</span>  
易學啟䝉意見五卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">明韓<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3771.svg?width=24" alt="四庫全書僻字第3771號（邦）" title="四庫全書僻字第3771號（邦）">奇撰<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3771.svg?width=24" alt="四庫全書僻字第3771號（邦）" title="四庫全書僻字第3771號（邦）">奇字汝節朝邑人正德戊辰進士</span>  
<span style="margin-left: 2em">官至南京兵部尙書諡恭簡事跡具明史本傳是</span>  
<span style="margin-left: 2em">編因朱子易學啟䝉而闡明其說一卷曰本圖書</span>  
<span style="margin-left: 2em">二卷曰原卦畫皆推演邵氏之學詳爲圖解三卷</span>  
<span style="margin-left: 2em">曰明蓍䇿亦發明古法而附論近世後二變不掛</span>  
<!-- 册1 葉465a　Page:文淵閣四庫全書_0001冊.djvu/166 -->
<span style="margin-left: 2em">之誤四卷曰考占變述六爻不變及六爻逓變之</span>  
<span style="margin-left: 2em">舊例五卷曰七占凡六爻不變六爻俱變及一爻</span>  
<span style="margin-left: 2em">變者皆仍其舊其二爻三爻四爻五爻變者則别</span>  
<span style="margin-left: 2em">立新法以占之所列卦圖皆以一卦變六十四卦</span>  
<span style="margin-left: 2em">與焦延壽易林同然其宗㫖則宋儒之易非漢儒</span>  
<span style="margin-left: 2em">之易也</span>  
易經存疑十二卷<sub class="note-yuan">福建巡撫採進本</sub>  
<span style="margin-left: 2em">明林希元撰希元字茂貞號次崖同安人正德丁</span>  
<span style="margin-left: 2em">丑進士官至廣東提學僉事見自序及王愼中序</span>  
<!-- 册1 葉465b　Page:文淵閣四庫全書_0001冊.djvu/166 -->
<span style="margin-left: 2em">泉州府志稱官至大理寺丞誤也明史儒林傳附</span>  
<span style="margin-left: 2em">載蔡淸傳中是書用注疏本其解經一以朱子本</span>  
<span style="margin-left: 2em">義爲主多引用蔡淸䝉引故楊時喬周易古今文</span>  
<span style="margin-left: 2em">謂其繼䝉引而作㣲有異同其曰存疑者洪朝選</span>  
<span style="margin-left: 2em">序謂存朱子之疑以羽翼程朱之傳義也自序謂</span>  
<span style="margin-left: 2em">今必下視程朱則吾之說焉能有易於彼無巳則</span>  
<span style="margin-left: 2em">上宗鄭賈鄭賈之說其可施於今乎葢其書本爲</span>  
<span style="margin-left: 2em">科舉之學故主於祧漢而尊宋然研究義理持論</span>  
<span style="margin-left: 2em">謹嚴比古經師則不足要猶愈於剽竊庸膚爲時</span>  
<!-- 册1 葉468a　Page:文淵閣四庫全書_0001冊.djvu/167 -->
<span style="margin-left: 2em">文弋𫉬之術者葢正嘉以前儒者猶近篤實也原</span>  
<span style="margin-left: 2em">刻漫漶此本爲乾隆壬戌其裔孫廷玣所刻舊有</span>  
<span style="margin-left: 2em">王愼中洪朝選二序載朱彞尊經義考廷玣刪之</span>  
<span style="margin-left: 2em">所言皆無大發明今亦不復補錄焉</span>  
周易辨錄四卷<sub class="note-yuan">山東巡撫採進本</sub>  
<span style="margin-left: 2em">明楊爵撰爵字伯修富平人嘉靖巳丑進士官至</span>  
<span style="margin-left: 2em">山東道監察御史以上疏極論符瑞下詔獄繫七</span>  
<span style="margin-left: 2em">年始得釋事迹具明史本傳其書前有自序題嘉</span>  
<span style="margin-left: 2em">靖二十四年乙巳葢卽其與周怡劉魁等在獄中</span>  
<!-- 册1 葉468b　Page:文淵閣四庫全書_0001冊.djvu/167 -->
<span style="margin-left: 2em">講論所作故取繫辭困德之辨一語爲名明史本</span>  
<span style="margin-left: 2em">傳作周易辨說其名小異然藝文志仍作周易辨</span>  
<span style="margin-left: 2em">錄葢刋本字誤也所釋惟六十四卦每卦惟載上</span>  
<span style="margin-left: 2em">下經卦辭然其訓解則六爻及彖傳象傳皆兼及</span>  
<span style="margin-left: 2em">之特不列其文耳其說多以人事爲主頗剴切著</span>  
<span style="margin-left: 2em">明葢以正直之操處杌𣕕之會幽居遠念寄托良</span>  
<span style="margin-left: 2em">深有未可以經生常義律之者然自始至終無一</span>  
<span style="margin-left: 2em">字之怨尤其所以爲純臣歟</span>  
易象鈔四卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<!-- 册1 葉469a　Page:文淵閣四庫全書_0001冊.djvu/167 -->
<span style="margin-left: 2em">明胡居仁撰居仁字叔心號敬齋餘干人事迹具</span>  
<span style="margin-left: 2em">明史儒林傳是書前有居仁自序稱讀易二十年</span>  
<span style="margin-left: 2em">有所得輒鈔積之手訂成帙取先儒圖書論說合</span>  
<span style="margin-left: 2em">於心得者錄之三卷以下則皆與人論易往復劄</span>  
<span style="margin-left: 2em">記及自記所學又爲櫽括歌辭以舉其要居仁之</span>  
<span style="margin-left: 2em">學雖出於吳與弼而篤實則遠過其師故在明代</span>  
<span style="margin-left: 2em">與曹端薛瑄俱號醇儒所著居業錄至今稱道學</span>  
<span style="margin-left: 2em">正宗其說易亦簡明<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">切不渉支離幽𣺌之談考</span>  
<span style="margin-left: 2em">萬歴乙酉御史李頤請以居仁從祀孔子廟廷疏</span>  
<!-- 册1 葉469b　Page:文淵閣四庫全書_0001冊.djvu/167 -->
<span style="margin-left: 2em">稱所著有易傳春秋傳今頗散佚失次朱彞尊經</span>  
<span style="margin-left: 2em">義考載有居仁易通解注曰未見而不載此書豈</span>  
<span style="margin-left: 2em">此書一名易通解歟然李頤時巳稱散佚失次何</span>  
<span style="margin-left: 2em">以此本獨完疑後人裒其緒言重爲編次非居仁</span>  
<span style="margin-left: 2em">手著也</span>  
周易象㫖决錄七卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明熊過撰過字叔仁號南沙富順人嘉靖巳丑進</span>  
<span style="margin-left: 2em">士官至禮部祠祭司郞中明史文苑傳附載陳束</span>  
<span style="margin-left: 2em">傳中稱過及陳束王愼中唐順之趙時春任瀚李</span>  
<!-- 册1 葉472a　Page:文淵閣四庫全書_0001冊.djvu/168 -->
<span style="margin-left: 2em">開先吕高爲嘉靖八才子然過研思經訓實不止</span>  
<span style="margin-left: 2em">以文章名是書據過自序初名易象㫖後遂加決</span>  
<span style="margin-left: 2em">錄之名案三輔決錄名始趙岐而命名之義古無</span>  
<span style="margin-left: 2em">傳說以意推之葢定本之謂也自序又稱初聞閩</span>  
<span style="margin-left: 2em">人蔡淸善爲易購得其書惟開陳宗義不及象於</span>  
<span style="margin-left: 2em">是稍記疑者爲贅言辛丑謫入滇晤楊愼勸成此</span>  
<span style="margin-left: 2em">書葢初讀宋易覺不合乃去而爲漢易故其說以</span>  
<span style="margin-left: 2em">象爲主考左傳韓起適魯見易象春秋古人旣以</span>

<span style="margin-left: 2em">不信䜟緯之說惟於語言文字間求其諦當有益</span>

<span style="margin-left: 2em">易稿而後成持論最爲篤實於乾卦遵用王弼本</span>

<span style="margin-left: 2em">卦自某卦而來皆夫子之所不言河圖洛書之外</span>
