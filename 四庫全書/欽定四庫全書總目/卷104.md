<span style="margin-left: 1em">子部十四</span>  
<span style="margin-left: 2em">醫家𩔖二</span>  
素問元機原病式一卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">金劉完素撰完素字守眞河間人事蹟具金史方</span>  
<span style="margin-left: 2em">技傳是書因素問至眞要論詳言五運六氣盛衰</span>  
<span style="margin-left: 2em">勝復之理而以病機一十九條附於篇末乃於十</span>  
<span style="margin-left: 2em">九條中采一百七十六字演爲二百七十七字以</span>  
<span style="margin-left: 2em">爲綱領而反復辨論以申之凡二萬餘言大旨多</span>  
<!-- 册3 葉905b　Page:文淵閣四庫全書_0003冊.djvu/231 -->
<span style="margin-left: 2em">主於火故張介賔作景岳全書攻之最力然完素</span>  
<span style="margin-left: 2em">生於北地其人秉賦原强兼以飲食醇醲久而藴</span>  
<span style="margin-left: 2em">𤍠與南方風土原殊又完素生於金時人情淳樸</span>  
<span style="margin-left: 2em">習於勤苦大抵充實剛勁亦異乎南方之脆弱故</span>  
<span style="margin-left: 2em">其持論多以寒凉之劑攻其有餘皆能應手奏功</span>  
<span style="margin-left: 2em">其作是書亦因地因時各明一義補前人所未及</span>  
<span style="margin-left: 2em">耳醫者拘泥成法不察虛實槪以攻伐𢦤生氣譬</span>  
<span style="margin-left: 2em">諸檢譜角觝宜其致敗其過實不在譜也介賔憤</span>  
<span style="margin-left: 2em">嫉力排盡歸其罪於完素然則參桂誤用亦可殺</span>  
<!-- 册3 葉908a　Page:文淵閣四庫全書_0003冊.djvu/232 -->
<span style="margin-left: 2em">人又將以是而廢東垣書哉張機傷寒論有日桂</span>  
<span style="margin-left: 2em">枝下咽陽盛乃斃承氣入胃陰盛以亡明藥務審</span>  
<span style="margin-left: 2em">證不執一也故今仍錄完素之書並著偏主之𡚁</span>  
<span style="margin-left: 2em">以持其平焉</span>  
宣明方論十五卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">金劉完素撰是書皆對病處方之法首諸證門自</span>  
<span style="margin-left: 2em">煎厥薄厥餐洩䐜脤以及諸痺心疝凡六十一證</span>  
<span style="margin-left: 2em">皆採用内經諸篇每證各有主治之方一宗仲景</span>  
<span style="margin-left: 2em">次諸風次𤍠次傷寒次積聚次水濕次痰飲次勞</span>  
<!-- 册3 葉908b　Page:文淵閣四庫全書_0003冊.djvu/232 -->
<span style="margin-left: 2em">次洩痢次婦人次補養次諸痛次痔瘻次眼目次</span>  
<span style="margin-left: 2em">小兒次雜病共十七門每門各有總論亦發明運</span>  
<span style="margin-left: 2em">氣之理兼及諸家方論於軒岐奥㫖寔多闡發而</span>  
<span style="margin-left: 2em">多用凉劑偏主其說者不無流𡚁在善用者消息</span>  
<span style="margin-left: 2em">之耳攷原病式自序云作醫方精要宣明論一部</span>  
<span style="margin-left: 2em">三卷十萬餘言今刊入河間六書者乃有十五卷</span>  
<span style="margin-left: 2em">其二卷之菊葉法薄荷白檀湯四卷之妙功藏用</span>  
<span style="margin-left: 2em">九十二卷之蓽澄茄丸補中丸楮實子丸皆注新</span>  
<span style="margin-left: 2em">增字而七卷之信香十方靑金膏不注新增字者</span>  
<!-- 册3 葉909a　Page:文淵閣四庫全書_0003冊.djvu/232 -->
<span style="margin-left: 2em">據其方下小序稱灌頂法王子所傳併有偈咒金</span>  
<span style="margin-left: 2em">時安有灌頂法王顯爲元明以後之方則竄入而</span>  
<span style="margin-left: 2em">不注者不知其幾矣卷增於舊殆以是歟</span>  
傷寒<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">格方三卷傷寒標本心法𩔖萃二卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">舊本皆題金劉完素撰傷寒<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">格方大旨出入於</span>  
<span style="margin-left: 2em">原病式而於傷寒證治議論較詳前序一篇不知</span>  
<span style="margin-left: 2em">何人所撰馬宗素傷寒醫鑒引平城翟公宵行遇</span>  
<span style="margin-left: 2em">燈之語與此序正相合殆卽翟公所撰歟醫鑒又</span>  
<span style="margin-left: 2em">云完素著六經傳變<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">格一部計一萬七千零九</span>  
<!-- 册3 葉909b　Page:文淵閣四庫全書_0003冊.djvu/232 -->
<span style="margin-left: 2em">字又於宣明論中集𦂳切藥方六十道分六門亦</span>  
<span style="margin-left: 2em">名<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">格此書有方有論不分門𩔖不能<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">定原爲</span>  
<span style="margin-left: 2em">何種卷首又題爲臨川葛雍編葢經後人竄亂未</span>  
<span style="margin-left: 2em">必完素之舊矣傷寒標本心法類萃上卷分别表</span>  
<span style="margin-left: 2em">裏辨其緩急下卷則載所用之方其中傳染一條</span>  
<span style="margin-left: 2em">稱雙解散益元散皆爲神方二方卽完素所製不</span>  
<span style="margin-left: 2em">應自譽至此考完素原病式序稱集傷寒襍病<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3108.svg?width=24" alt="四庫全書僻字第3108號（胍）" title="四庫全書僻字第3108號（胍）"></span>  
<span style="margin-left: 2em">證方論之文目日醫方精要宣明論今檢宣明論</span>  
<span style="margin-left: 2em">中已有傷寒二卷則完素治傷寒法已在宣明論</span>  
<!-- 册3 葉912a　Page:文淵閣四庫全書_0003冊.djvu/233 -->
<span style="margin-left: 2em">中不别爲書二書恐出於依託然流傳已久姑存</span>  
<span style="margin-left: 2em">之以備叅考焉</span>  
病機氣宜保命集三卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">金張元素撰元素字潔古易州人八歲應童子舉</span>  
<span style="margin-left: 2em">二十七試進士以犯廟諱下第乃去而學醫精通</span>  
<span style="margin-left: 2em">其術因抒所心得述爲此書凡分三十二門首原</span>  
<span style="margin-left: 2em">道原脉攝生陰陽諸論次及處方用藥次第加減</span>  
<span style="margin-left: 2em">君臣佐使之法於醫理精藴闡發極爲深至其書</span>  
<span style="margin-left: 2em">初半傳播金末楊威始得本刋行而題爲河間劉</span>  
<!-- 册3 葉912b　Page:文淵閣四庫全書_0003冊.djvu/233 -->
<span style="margin-left: 2em">完素所著明初寧王權重刋亦沿其誤并僞撰完</span>  
<span style="margin-left: 2em">素序文詞調於卷首以附會之至李時珍作本草</span>  
<span style="margin-left: 2em">綱目始糾其謬而定爲出於元素之手於序例中</span>  
<span style="margin-left: 2em">辨之甚明考李濂醫史稱完素嘗病傷寒八日頭</span>  
<span style="margin-left: 2em">痛脉𦂳嘔逆不食元素往候令服某藥完素大服</span>  
<span style="margin-left: 2em">如其言遂愈元素自此顯名是其造詣深䆳足以</span>  
<span style="margin-left: 2em">自成一家原不必託完素以爲重今特爲改正其</span>  
<span style="margin-left: 2em">僞託之序亦並從刪削焉</span>  
儒門事親十五卷<sub class="note-yuan">大學士英廉家藏本</sub>  
<!-- 册3 葉913a　Page:文淵閣四庫全書_0003冊.djvu/233 -->
<span style="margin-left: 2em">金張從正撰從正字子和號戴人睢州考城人興</span>  
<span style="margin-left: 2em">定中召補太醫尋辭去事蹟具金史方技傳從正</span>  
<span style="margin-left: 2em">與麻知幾常仲明輩講求醫理輯爲此書劉祁歸</span>  
<span style="margin-left: 2em">潛志稱麻知幾九疇與之善使子和論說其術因</span>  
<span style="margin-left: 2em">爲文之則此書實知幾所記也其例有說有辨有</span>  
<span style="margin-left: 2em">記有解有誡有箋有詮有式有斷有論有疏有述</span>  
<span style="margin-left: 2em">有衍有訣有十形三療有六門三法名目頗煩碎</span>  
<span style="margin-left: 2em">而大旨主於用攻其曰儒門事親者以爲惟儒者</span>  
<span style="margin-left: 2em">能明其理而事親者當知醫也從正宗河間劉守</span>  
<!-- 册3 葉913b　Page:文淵閣四庫全書_0003冊.djvu/233 -->
<span style="margin-left: 2em">眞用藥多寒凉其汗吐下三法當時已多異議故</span>  
<span style="margin-left: 2em">書中辨謗之處爲多丹溪朱震亨亦譏其偏後人</span>  
<span style="margin-left: 2em">遂井其書置之然病情萬狀各有所宜當攻不攻</span>  
<span style="margin-left: 2em">與當補不補厥𡚁維均偏執其法固非竟斥其法</span>  
<span style="margin-left: 2em">亦非也惟中間負氣求勝不免過激欲矯庸醫恃</span>  
<span style="margin-left: 2em">補之失或至於過<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">又傳其學者不知察脉虛實</span>  
<span style="margin-left: 2em">論病久暫槩以峻利施治遂致爲世所藉口要之</span>  
<span style="margin-left: 2em">未明從正本意耳</span>  
内外傷辨惑論三卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<!-- 册3 葉916a　Page:文淵閣四庫全書_0003冊.djvu/234 -->
<span style="margin-left: 2em">金李杲撰杲字明之自號東垣老人眞定人嘗以</span>  
<span style="margin-left: 2em">納貲得官監濟源稅案元硯堅作東垣老人傳稱</span>  
<span style="margin-left: 2em">杲以辛亥年卒年七十二則當生於世宗大定二</span>  
<span style="margin-left: 2em">十年庚子金亡時年五十五入元十七年乃終故</span>  
<span style="margin-left: 2em">舊本亦或題元人而元史亦載入方技傳也初杲</span>  
<span style="margin-left: 2em">母嬰疾爲衆醫襍治而死訖莫知爲何證杲自傷</span>  
<span style="margin-left: 2em">不知醫理遂捐千金從易州張元素學盡得其法</span>  
<span style="margin-left: 2em">而名乃出於元素上卓爲醫者大宗是編發明内</span>  
<span style="margin-left: 2em">傷之證有𩔖外感辨别陰陽寒𤍠有餘不足而大</span>  
<!-- 册3 葉916b　Page:文淵閣四庫全書_0003冊.djvu/234 -->
<span style="margin-left: 2em">旨總以脾胃爲主故特製補中益氣湯專治飲食</span>  
<span style="margin-left: 2em">勞倦虛人感冒法取補土生金升淸降濁得陰陽</span>  
<span style="margin-left: 2em">生化之旨其闡發醫理至爲深微前有自序題丁</span>  
<span style="margin-left: 2em">未歲序中稱此論束之高閣十六年以長厯推之</span>  
<span style="margin-left: 2em">其書葢出於金哀宗之正大九年辛卯也</span>  
脾胃論三卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">金李杲撰杲旣著辨惑論恐世俗不悟復爲此書</span>  
<span style="margin-left: 2em">其說以土爲萬物之母故獨重脾胃引經立論精</span>  
<span style="margin-left: 2em">鑿不磨明孫一奎醫旨緖餘云東垣生當金元之</span>  
<!-- 册3 葉917a　Page:文淵閣四庫全書_0003冊.djvu/234 -->
<span style="margin-left: 2em">交中原擾攘士失其所人疲奔命或以勞倦傷脾</span>  
<span style="margin-left: 2em">或以憂思傷脾或以僟飽傷脾病有緩急不得不</span>  
<span style="margin-left: 2em">以急者爲先務此眞知杲者也前有元好問序攷</span>  
<span style="margin-left: 2em">遺山文集有杲所著傷寒會要引一篇備載其所</span>  
<span style="margin-left: 2em">治騐元史方技傳全取之而此序獨不見集中意</span>  
<span style="margin-left: 2em">其偶有散佚歟又有羅天益後序一篇天益字謙</span>  
<span style="margin-left: 2em">父杲晚年弟子盡得其傳元硯堅東垣老人傳稱</span>  
<span style="margin-left: 2em">杲臨終取平日所著書檢勘卷帙以次相從列於</span>  
<span style="margin-left: 2em">儿前囑謙父日此書付汝者卽其人也</span>  
<!-- 册3 葉917b　Page:文淵閣四庫全書_0003冊.djvu/234 -->
蘭室秘藏三卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">金李杲撰其日蘭室秘藏者葢取黃帝素問藏諸</span>  
<span style="margin-left: 2em">靈蘭之室語前有至元丙子羅天益序在杲没後</span>  
<span style="margin-left: 2em">二十五年疑卽硯堅所謂臨終以付天益者也其</span>  
<span style="margin-left: 2em">治病分二十一門以飲食勞倦居首他如中滿腹</span>  
<span style="margin-left: 2em">脤如心腹痞如胃脘痛諸門皆諄諄於脾胃葢其</span>  
<span style="margin-left: 2em">所獨重也東垣發明内傷之類外感實有至理而</span>  
<span style="margin-left: 2em">以土爲萬物之母脾胃爲生化之源脾虛損論一</span>  
<span style="margin-left: 2em">篇極言寒凉峻利之害尤深切著明葢預睹劉張</span>  
<!-- 册3 葉920a　Page:文淵閣四庫全書_0003冊.djvu/235 -->
