## 欽定四庫全書總目 卷五十一　史部七　雜史類

<!-- 册2 葉580：整葉圖版，無文字記錄 -->
<!-- 册2 葉581a　Page:文淵閣四庫全書_0002冊.djvu/150 -->
欽定四庫全書總目卷五十一  
<span style="margin-left: 1em">史部七</span>  
<span style="margin-left: 2em">雜史類</span>  
<span style="margin-left: 3em">雜史之目肇於隋書葢載籍旣繁難於條析義</span>  
<span style="margin-left: 3em">取乎兼包衆體宏括殊名故王嘉拾遺記汲冢</span>  
<span style="margin-left: 3em">璅語得與魏尚書梁實錄並列不爲嫌也然旣</span>  
<span style="margin-left: 3em">繫史名事殊小說著書有體焉可無分今仍用</span>  
<span style="margin-left: 3em">舊文立此一類凡所著錄則務示別裁大抵取</span>  
<span style="margin-left: 3em">其事繫廟堂語關軍國或但具一事之始末非</span>  
<!-- 册2 葉581b　Page:文淵閣四庫全書_0002冊.djvu/150 -->
<span style="margin-left: 3em">一代之全編或但述一時之見聞祇一家之私</span>  
<span style="margin-left: 3em">記要期遺文舊事足以存掌故資考證備讀史</span>  
<span style="margin-left: 3em">者之㕘稽云爾若夫語神怪供詼啁里巷瑣言</span>  
<span style="margin-left: 3em">稗官所述則別有雜家小說家存焉</span>  
國語二十一卷<sub class="note-yuan">戸部員外郎章銓家藏本</sub>  
<span style="margin-left: 2em">吳韋昭註昭字宏嗣雲陽人官至中書僕射三國</span>  
<span style="margin-left: 2em">志作韋曜裴松之註謂爲司馬昭諱也國語出自</span>  
<span style="margin-left: 2em">何人說者不一然終以漢人所說爲近古所記之</span>  
<span style="margin-left: 2em">事與左傳俱迄智伯之亡時代亦復相合中有與</span>  
<!-- 册2 葉584a　Page:文淵閣四庫全書_0002冊.djvu/151 -->
<span style="margin-left: 2em">左傳未符者猶新序說苑同出劉向而時復牴牾</span>  
<span style="margin-left: 2em">葢古人著書各據所見之舊文疑以存疑不似後</span>  
<span style="margin-left: 2em">人輕改也漢志作二十一篇其諸家所註隋志虞</span>  
<span style="margin-left: 2em">翻唐固本皆二十一卷王肅本二十二卷賈逵本</span>  
<span style="margin-left: 2em">二十卷互有增減葢偶然分併非有異同惟昭所</span>  
<span style="margin-left: 2em">註本隋志作二十二卷唐志作二十卷而此本首</span>  
<span style="margin-left: 2em">尾完具實二十一卷諸家所傳南北宋版無不相</span>  
<span style="margin-left: 2em">同知隋志誤一字唐志脫一字也前有昭自序稱</span>  
<span style="margin-left: 2em">兼采鄭衆賈逵虞翻唐固之注今考所引鄭說虞</span>  
<!-- 册2 葉584b　Page:文淵閣四庫全書_0002冊.djvu/151 -->
<span style="margin-left: 2em">說寥廖數條惟賈唐二家援据駁正爲多序又稱</span>  
<span style="margin-left: 2em">凡所發正三百七事今考註文之中昭自立義者</span>  
<span style="margin-left: 2em">周語凡服數一條國子一條虢文公一條常棣一</span>  
<span style="margin-left: 2em">條鄭武莊一條仲任一條叔妘一條鄭伯南也一</span>  
<span style="margin-left: 2em">條請隧一條凟姓一條楚子入陳一條晉成公一</span>  
<span style="margin-left: 2em">條共工一條大錢一條無射一條魯語朝聘一條</span>  
<span style="margin-left: 2em">刻桷一條命祀一條郊禘一條祖文宗武一條官</span>  
<span style="margin-left: 2em">寮一條齊語凡二十一鄉一條士鄉十五一條良</span>  
<span style="margin-left: 2em">人一條使海於有蔽一條八百乘一條反胙一條</span>  
<!-- 册2 葉585a　Page:文淵閣四庫全書_0002冊.djvu/151 -->
<span style="margin-left: 2em">大路龍旂一條晉語凡伯氏一條不懼不得一條</span>  
<span style="margin-left: 2em">聚居異情一條貞之無報一條轅田一條二十五</span>  
<span style="margin-left: 2em">宗一條少典一條十月一條嬴氏一條觀狀一條</span>  
<span style="margin-left: 2em">三德一條上軍一條蒲城伯一條三軍一條錞于</span>  
<span style="margin-left: 2em">一條吕錡佐上軍一條新軍一條韓無忌一條女</span>  
<span style="margin-left: 2em">樂一條張老一條鄭語凡十數一條億事一條秦</span>  
<span style="margin-left: 2em">景襄一條楚語聲子一條懿戒一條武丁作書一</span>  
<span style="margin-left: 2em">條屏攝一條吳語官帥一條錞于一條自𠜲一條</span>  
<span style="margin-left: 2em">王總百執事一條兄弟之國一條來告一條向檐</span>  
<!-- 册2 葉585b　Page:文淵閣四庫全書_0002冊.djvu/151 -->
<span style="margin-left: 2em">一條越語乘車一條宰一條德虐一條解骨一條</span>  
<span style="margin-left: 2em">重祿一條不過六十七事合以所正訛字衍文錯</span>  
<span style="margin-left: 2em">簡亦不足三百七事之數其傳寫有誤以六十爲</span>  
<span style="margin-left: 2em">三百歟崇文總目作三百十事又七字轉訛也錢</span>  
<span style="margin-left: 2em">曾讀書敏求記謂周語昔我先世后稷句天聖本</span>  
<span style="margin-left: 2em">先下有王字左右免胄而下句天聖本下下有拜</span>  
<span style="margin-left: 2em">字今本皆脫去然所引註曰云云與此本絕不相</span>  
<span style="margin-left: 2em">同又不知何說也此本爲衍聖公孔傳鐸所刊如</span>  
<span style="margin-left: 2em">魯語公父文伯飲酒一章註中此堵父詞四字當</span>  
<!-- 册2 葉588a　Page:文淵閣四庫全書_0002冊.djvu/152 -->
<span style="margin-left: 2em">在將使鼈長句下而誤入遂出二字下小小舛訛</span>  
<span style="margin-left: 2em">亦所不免然較諸坊本則頗爲精善自鄭衆解詁</span>  
<span style="margin-left: 2em">以下諸書並亡國語註存於今者惟昭爲最古黃</span>  
<span style="margin-left: 2em">震日鈔嘗稱其簡潔而先儒舊訓亦往往散見其</span>  
<span style="margin-left: 2em">中如朱子注論語無所取材毛奇齡詆其訓材爲</span>  
<span style="margin-left: 2em">裁不見經傳改從鄭康成桴材之說而不知鄭語</span>  
<span style="margin-left: 2em">計億事材兆物句昭注曰計算也材裁也已有此</span>  
<span style="margin-left: 2em">訓然則奇齡失之眉睫間矣此亦見其多資考證</span>  
<span style="margin-left: 2em">也</span>  
<!-- 册2 葉588b　Page:文淵閣四庫全書_0002冊.djvu/152 -->
<span style="margin-left: 4em">案國語二十一篇漢志雖載春秋後然無春</span>  
<span style="margin-left: 4em">秋外傳之名也漢書律厯志始稱春秋外傳</span>  
<span style="margin-left: 4em">王充論衡云國語左氏之外傳也左氏傳經</span>  
<span style="margin-left: 4em">詞語尚畧故復選錄國語之詞以實之劉熙</span>  
<span style="margin-left: 4em">釋名亦云國語亦曰外傳春秋以魯爲内以</span>  
<span style="margin-left: 4em">諸國爲外外國所傳之事也考國語上包周</span>  
<span style="margin-left: 4em">穆王下曁魯悼公與春秋時代首尾皆不相</span>  
<span style="margin-left: 4em">應其事亦多與春秋無關係之春秋殊爲不</span>  
<span style="margin-left: 4em">類至書中明有魯語而劉熙以爲外國所傳</span>  
<!-- 册2 葉589a　Page:文淵閣四庫全書_0002冊.djvu/152 -->
<span style="margin-left: 4em">尤爲舛迕附之於經於義未允史通六家國</span>  
<span style="margin-left: 4em">語居一實古左史之遺今改𨽻之雜史類焉</span>  
國語補音三卷<sub class="note-yuan">衍聖公孔昭焕家藏本</sub>  
<span style="margin-left: 2em">唐人舊本宋宋庠補葺庠字公序安陸人徙居雍</span>  
<span style="margin-left: 2em">邱天聖二年進士第一厯官檢校太尉平章事樞</span>  
<span style="margin-left: 2em">密使封苢國公以司空致仕諡文憲事迹具宋史</span>  
<span style="margin-left: 2em">本傳自漢以來註國語者凡賈逵王肅虞翻唐固</span>  
<span style="margin-left: 2em">韋昭孔晁六家然皆無音宋時相傳有音一卷不</span>  
<span style="margin-left: 2em">著名氏庠以其中鄯州字推之知出唐人然簡畧</span>  
<!-- 册2 葉589b　Page:文淵閣四庫全書_0002冊.djvu/152 -->
<span style="margin-left: 2em">殊甚乃採經典釋文及說文集韻等書補成此編</span>  
<span style="margin-left: 2em">觀目錄前列二十一篇之名詳註諸本標題之異</span>  
<span style="margin-left: 2em">同後列補音三卷夾註其下曰庠自撰附於末知</span>  
<span style="margin-left: 2em">其初本附韋昭注後後人以昭註世多傳本遂抄</span>  
<span style="margin-left: 2em">出別行明人刊本又散附各句之下間多脫誤葢</span>  
<span style="margin-left: 2em">非其舊此本猶從宋本錄出其例存唐人舊音於</span>  
<span style="margin-left: 2em">前舊音所遺及但用<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">音而闕反切者隨字增入</span>  
<span style="margin-left: 2em">皆以補注二字别之其釋正文者大書其字夾註</span>  
<span style="margin-left: 2em">其音其釋韋昭註者亦大書其字而冠以註字爲</span>  
<!-- 册2 葉592a　Page:文淵閣四庫全書_0002冊.djvu/153 -->
<span style="margin-left: 2em">别較陸德明經典釋文以朱墨分别經註輾轉傳</span>  
<span style="margin-left: 2em">寫遂至混合爲一者頗便省覽自記稱舊本參差</span>  
<span style="margin-left: 2em">不一最後得其同年宋緘本大體爲詳因取公私</span>  
<span style="margin-left: 2em">書十五六本與參互考正以定是編其辨證最爲</span>  
<span style="margin-left: 2em">詳核惜其前二十一卷全佚僅存此音也又庠此</span>  
<span style="margin-left: 2em">音實全收唐人舊本而附益其說故謂之補諸家</span>  
<span style="margin-left: 2em">著錄惟署庠名殊爲失考今仍標唐人於前以存</span>  
<span style="margin-left: 2em">其實焉</span>  
戰國策註三十三卷<sub class="note-yuan">衍聖公孔昭焕家藏本</sub>  
<!-- 册2 葉592b　Page:文淵閣四庫全書_0002冊.djvu/153 -->
<span style="margin-left: 2em">舊本題漢高誘註今考其書實宋姚宏校本也文</span>  
<span style="margin-left: 2em">獻通考引崇文總目曰戰國䇿篇卷亡闕第二至</span>  
<span style="margin-left: 2em">第十第三十一至第三十三闕又有後漢高誘注</span>  
<span style="margin-left: 2em">二十一卷今闕第一第五第十一至二十止存八</span>  
<span style="margin-left: 2em">卷曾鞏校定序曰此書有高誘註者二十一篇或</span>  
<span style="margin-left: 2em">曰三十二篇崇文總目存者八篇今存者十篇此</span>  
<span style="margin-left: 2em">爲毛晉汲古閣影宋鈔本雖三十三卷皆題曰高</span>  
<span style="margin-left: 2em">誘註而有誘註者僅二卷至四卷六卷至十卷與</span>  
<span style="margin-left: 2em">崇文總目八篇數合又最末三十二三十三兩卷</span>  
<!-- 册2 葉593a　Page:文淵閣四庫全書_0002冊.djvu/153 -->
<span style="margin-left: 2em">合前八卷與曾鞏序十篇數合而其餘二十三卷</span>  
<span style="margin-left: 2em">則但有考異而無注其有注者多冠以續字其偶</span>  
<span style="margin-left: 2em">遺續字者如趙䇿一郗疵註雒陽註皆引唐林寳</span>  
<span style="margin-left: 2em">元和姓纂趙䇿二歐越註引魏孔衍春秋後語魏</span>  
<span style="margin-left: 2em">䇿三芒卯注引淮南子註衍與竇在誘後而淮南</span>  
<span style="margin-left: 2em">子註卽誘所自作其非誘註可無庸置辨葢鞏校</span>  
<span style="margin-left: 2em">書之時官本所少之十二篇誘書適有其十惟闕</span>  
<span style="margin-left: 2em">第五第三十一誘書所闕則官書悉有之亦惟闕</span>  
<span style="margin-left: 2em">第五第三十一意必以誘書足官書而又於他家</span>  
<!-- 册2 葉593b　Page:文淵閣四庫全書_0002冊.djvu/153 -->
<span style="margin-left: 2em">書内摭二卷補之此官書誘書合爲一本之由然</span>  
<span style="margin-left: 2em">鞏不言校誘註則所取惟正文也迨姚宏重校之</span>  
<span style="margin-left: 2em">時乃併所存誘註入之故其自序稱不題校人并</span>  
<span style="margin-left: 2em">題續注者皆余所益知爲先載誘注故以續爲别</span>  
<span style="margin-left: 2em">且凡有誘註復加校正者並於夾行之中又爲夾</span>  
<span style="margin-left: 2em">行與無注之卷不同知校正之時注已與正文並</span>  
<span style="margin-left: 2em">列矣卷端曾鞏李格王覺孫朴諸序䟦皆前列標</span>  
<span style="margin-left: 2em">題各題其字而宏序獨空一行列於末前無標題</span>  
<span style="margin-left: 2em">序中所言體例又一一與書合其爲宏校本無疑</span>  
<!-- 册2 葉596a　Page:文淵閣四庫全書_0002冊.djvu/154 -->
<span style="margin-left: 2em">其卷卷題高誘名者殆傳寫所增以贋古書耳書</span>  
<span style="margin-left: 2em">中校正稱曾者曾鞏本也稱錢者錢藻本也稱劉</span>  
<span style="margin-left: 2em">者劉敞本也稱集者集賢院本也無姓名者卽宏</span>  
<span style="margin-left: 2em">序所謂不題校人爲所加入者也其㸃勘頗爲精</span>  
<span style="margin-left: 2em">密吳師道作戰國䇿鮑注補正亦稱爲善本是元</span>  
<span style="margin-left: 2em">時猶知註出於宏不知毛氏宋本何以全題高誘</span>  
<span style="margin-left: 2em">考周密癸辛雜識稱賈似道嘗刊是書豈其門客</span>  
<span style="margin-left: 2em">廖瑩中等皆媟褻下流昧於檢校一時誤題毛氏</span>  
<span style="margin-left: 2em">適從其本影抄歟近時揚州所刊卽從此本錄出</span>  
<!-- 册2 葉596b　Page:文淵閣四庫全書_0002冊.djvu/154 -->
<span style="margin-left: 2em">而仍題誘名殊爲沿誤今於原有註之卷題高誘</span>  
<span style="margin-left: 2em">注姚宏校正續注原注已佚之卷則惟題姚宏校</span>
