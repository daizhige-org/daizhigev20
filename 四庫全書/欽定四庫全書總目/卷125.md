<span style="margin-left: 1em">子部三十五</span>  
<span style="margin-left: 2em">雜家類存目二</span>  
古言二卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明鄭曉撰曉有禹貢圖說巳著錄曉淸直端諒號</span>  
<span style="margin-left: 2em">爲名臣其人足以自傳此編則隨筆成文議論時</span>  
<span style="margin-left: 2em">有偏僻引據亦不免疎舛如謂公孫宏勝司馬光</span>  
<span style="margin-left: 2em">謂王安石遠過韓范富歐謂王通勝董仲舒謂柳</span>  
<span style="margin-left: 2em">宗元勝韓愈謂張子勝程子甚至謂堯舜非生知</span>  
<!-- 册3 葉2769b　Page:文淵閣四庫全書_0003冊.djvu/697 -->
<span style="margin-left: 2em">安行皆務爲高論而不近理又謂佛言空道家言</span>  
<span style="margin-left: 2em">虚儒言太極只一個空圈爲學只要還此本體謂</span>  
<span style="margin-left: 2em">吾儒格致誠正工夫與佛老無甚異但二家不歸</span>  
<span style="margin-left: 2em">於修身謂佛老莫可繫絆天理完固又欲以老子</span>  
<span style="margin-left: 2em">周子文中子别爲三子其他如前劫後劫無不毁</span>  
<span style="margin-left: 2em">之天地豈有不亡之國不敗之家不死之身云云</span>  
<span style="margin-left: 2em">提唱二氏之說不一而足尤不可爲訓至於以竹</span>  
<span style="margin-left: 2em">書紀伊尹事誤爲逸周書以大禹謨爲今文尚書</span>  
<span style="margin-left: 2em">之𩔖小小筆誤又不足言矣</span>  
<!-- 册3 葉2772a　Page:文淵閣四庫全書_0003冊.djvu/698 -->
渾然子一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">明張翀撰按明史有兩張翀一在列傳第八十者</span>  
<span style="margin-left: 2em">字習之潼川人正德辛未進士官戸科給事中以</span>  
<span style="margin-left: 2em">疏爭大禮謫戍此張翀在列傳九十八字子儀柳</span>  
<span style="margin-left: 2em">州衛籍馬平人嘉靖癸丑進士授刑部主事以疏</span>  
<span style="margin-left: 2em">劾嚴嵩下詔獄謫戍都匀隆慶初起爲吏部主事</span>  
<span style="margin-left: 2em">官至刑部右侍郞是書凡十八篇曰神遊論曰田</span>  
<span style="margin-left: 2em">說曰樵問曰將曰明心曰士貴曰體用論曰興廢</span>  
<span style="margin-left: 2em">曰禍福曰忠孝曰變化曰窮理曰求知曰弭盗曰</span>  
<!-- 册3 葉2772b　Page:文淵閣四庫全書_0003冊.djvu/698 -->
<span style="margin-left: 2em">用材曰强弱曰臣道曰高潔皆設爲主客問答旁</span>  
<span style="margin-left: 2em">引曲證以推明事物之理大抵規仿劉基郁離子</span>  
<span style="margin-left: 2em">也</span>  
經子臆解一卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明王世懋撰世懋有却金傳巳著錄是編凡解易</span>  
<span style="margin-left: 2em">二條解論語二條解孟子三條解老子一條大抵</span>  
<span style="margin-left: 2em">自以巳意推衍無所考證發明不脫明人語錄之</span>  
<span style="margin-left: 2em">習</span>  
<span style="margin-left: 4em">案陸德明經典釋文兼及老子莊子而古來</span>  
<!-- 册3 葉2773a　Page:文淵閣四庫全書_0003冊.djvu/698 -->
<span style="margin-left: 4em">著錄皆入經解以其考訂音訓始末兼該漢</span>  
<span style="margin-left: 4em">以來諸儒舊學藉是以傳二子附錄其中存</span>  
<span style="margin-left: 4em">而不論可也世懋是編雖亦解周易四書然</span>  
<span style="margin-left: 4em">不過偶拈數則特筆記之流不足以言經義</span>  
<span style="margin-left: 4em">又叅以道家之言是有德明之過而無其功</span>  
<span style="margin-left: 4em">不能與之並論矣今入之雜家類中從其實</span>  
<span style="margin-left: 4em">也</span>  
望崖錄二卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明王世懋撰是書内篇一卷皆談佛理自稱以三</span>  
<!-- 册3 葉2773b　Page:文淵閣四庫全書_0003冊.djvu/698 -->
<span style="margin-left: 2em">教歸一與林兆恩屠隆所見相同葢明中葉以後</span>  
<span style="margin-left: 2em">士大夫之所見大抵如斯外篇一卷記師事曇陽</span>  
<span style="margin-left: 2em">子事尤爲怪異</span>  
澹思子一卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明王世懋撰是編乃其講學之書多浸淫於二氏</span>  
<span style="margin-left: 2em">葢萬厯以後士大夫操此論者十之九也至謂孟</span>  
<span style="margin-left: 2em">子所以不及孔子者爲性善二字則益橫矣</span>  
内外篇二卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">明周宏祖撰宏祖字少魯麻城人嘉靖巳未進士</span>  
<!-- 册3 葉2776a　Page:文淵閣四庫全書_0003冊.djvu/699 -->
<span style="margin-left: 2em">官至南京光祿寺<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">事迹具明史本傳是編内篇</span>  
<span style="margin-left: 2em">所論皆性命道德事物多剽取老莊之旨外篇則</span>  
<span style="margin-left: 2em">自天文地理錢穀甲兵皆各有論然皆畧涉籓籬</span>  
<span style="margin-left: 2em">不能得其精要也</span>  
文雅社約一卷附錄一卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">明沈鯉撰鯉字仲化歸德人嘉靖乙丑進士官至</span>  
<span style="margin-left: 2em">文淵閣大學士諡文端事迹具明史本傳鯉里中</span>  
<span style="margin-left: 2em">有文雅臺相傳卽矍相之圃鯉與里人修舉社飮</span>  
<span style="margin-left: 2em">之禮以禮法相約凡書劄宴會稱呼揖讓交際冠</span>  
<!-- 册3 葉2776b　Page:文淵閣四庫全書_0003冊.djvu/699 -->
<span style="margin-left: 2em">服閑家御下田宅器用勸義明微冠婚䘮祭身檢</span>  
<span style="margin-left: 2em">心檢十六條附錄社倉約義學約族田約勸施迂</span>  
<span style="margin-left: 2em">談<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2618.svg?width=24" alt="四庫全書僻字第2618號（⿱乖一）" title="四庫全書僻字第2618號（⿱乖一）">涕衷言鄉射約篤親會墓享儀沈氏祠堂生</span>  
<span style="margin-left: 2em">忌單女訓約言十篇刻本題爲社約下卷然沈氏</span>  
<span style="margin-left: 2em">祠堂生忌之𩔖非可約之一社者前有鯉自序稱</span>  
<span style="margin-left: 2em">總十六類百六十三<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3897.svg?width=24" alt="四庫全書僻字第3897號（款）" title="四庫全書僻字第3897號（款）">則十篇顯爲附錄爲其後</span>  
<span style="margin-left: 2em">人所誤合明矣明史稱鯉念時侈因稽典制自冠</span>  
<span style="margin-left: 2em">婚䘮祭以及酬酢往來率定爲中制頒示天下葢</span>  
<span style="margin-left: 2em">救奢崇朴鯉之本志此書猶是意也中多太畧太</span>  
<!-- 册3 葉2777a　Page:文淵閣四庫全書_0003冊.djvu/699 -->
<span style="margin-left: 2em">儉不合古禮者葢事取易行義主救弊不無矯枉</span>  
<span style="margin-left: 2em">過直耳</span>  
脈望八卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明趙台鼎撰台鼎字長元自號丹華洞主内江人</span>  
<span style="margin-left: 2em">大學士貞吉之子也其書雜論三教於道藏尤爲</span>  
<span style="margin-left: 2em">詳悉故名以脈望自比於書内蠧魚三食神仙之</span>  
<span style="margin-left: 2em">字然陳因相襲未能獨抽奇秘也</span>  
庭幃雜錄二卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">明嘉善袁衷等錄其父母之訓而錢曉所訂定者</span>  
<!-- 册3 葉2777b　Page:文淵閣四庫全書_0003冊.djvu/699 -->
<span style="margin-left: 2em">也衷父參坡生五子長卽衷次曰襄曰裳曰表曰</span>  
<span style="margin-left: 2em">衮表嘗舉於鄉衮游文徵明之門能以文學世其</span>  
<span style="margin-left: 2em">家曉婚於袁氏故删定而爲之跋云</span>  
甘露園長書六卷短書四卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">明陳汝錡撰汝錡字伯容高安人嘉靖中由貢生</span>  
<span style="margin-left: 2em">官建陽縣訓導是編前有自序云文之有首尾稍</span>  
<span style="margin-left: 2em">紆徐曲折者爲長書其邊幅稍狹辭不加純緣若</span>  
<span style="margin-left: 2em">語錄說家之𩔖者爲短書題曰甘露園從所居也</span>  
<span style="margin-left: 2em">長書於經史及古今人物各爲論一篇大約多縱</span>  
<!-- 册3 葉2780a　Page:文淵閣四庫全書_0003冊.djvu/700 -->
<span style="margin-left: 2em">橫之辭持論亦多紕繆如論宋和議謂李通歸附</span>  
<span style="margin-left: 2em">韓常王鎮崔慶輩乞降皆烏珠<sub class="note-yuan">案烏珠原作兀术今改正</sub>陰指</span>  
<span style="margin-left: 2em">使之而岳飛不悟偶以班師故不輿尸返耳又斥</span>  
<span style="margin-left: 2em">胡銓封事爲欲使其君爲無父無母之人又論張</span>  
<span style="margin-left: 2em">巡遮蔽江淮食人以守死不爲功至力爲王安石</span>  
<span style="margin-left: 2em">辨寃作史謗十九條其中如辨安石排滕甫貶吕</span>  
<span style="margin-left: 2em">公著皆引東軒筆錄以證之考魏泰爲曾布婦弟</span>  
<span style="margin-left: 2em">傾險無行所作東軒筆錄與碧雲騢皆黨邪醜正</span>  
<span style="margin-left: 2em">顛倒是非可據以爲公論乎短書尤議論多而考</span>  
<!-- 册3 葉2780b　Page:文淵閣四庫全書_0003冊.djvu/700 -->
<span style="margin-left: 2em">證少亦間記時事大致失之佻巧巳開屠隆陳繼</span>  
<span style="margin-left: 2em">儒等小品風氣其論入定苦行諸條則全入於外</span>  
<span style="margin-left: 2em">道更篤信輪迥之說歴引古事以證且謂劉基爲</span>  
<span style="margin-left: 2em">北斗六星王守仁爲南安上座殊屬荒渺不經至</span>  
<span style="margin-left: 2em">謂嘗至法雲寺見阿羅漢像一一如舊相識一僧</span>  
<span style="margin-left: 2em">在旁知其意謂爾原此會中人遂悟平生因緣云</span>  
<span style="margin-left: 2em">云尤恍惚不足詰初其從子兵部侍郎邦瞻取短</span>  
<span style="margin-left: 2em">書汰其十一刋行後其同里劉願人以邦瞻所删</span>  
<span style="margin-left: 2em">過甚又據原本增刋之願人刻書凡例曰司馬公</span>  
<!-- 册3 葉2781a　Page:文淵閣四庫全書_0003冊.djvu/700 -->
<span style="margin-left: 2em">刻短書删有十之一余細細求之大都司馬公膽</span>  
<span style="margin-left: 2em">較小耳其膽之小以官之大也云云可謂悍然無</span>  
<span style="margin-left: 2em">忌矣</span>  
海蠡編二卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明袁士瑜撰士瑜號七澤公安人卽宗道宏道中</span>  
<span style="margin-left: 2em">道之父也其書大㫖以儒釋二家同源異派或援</span>  
<span style="margin-left: 2em">釋疏孔或證孔於釋謂濓洛諸儒於聖人書詮釋</span>  
<span style="margin-left: 2em">妙暢如樽注海是篇如蠡注海故名海蠡編開卷</span>  
<span style="margin-left: 2em">釋明德謂明德卽是良知德卽是明不可以明更</span>  
<!-- 册3 葉2781b　Page:文淵閣四庫全書_0003冊.djvu/700 -->
<span style="margin-left: 2em">求於明朱子註爲虛靈不昧最妙又謂善何以曰</span>  
<span style="margin-left: 2em">至住於惡固非至善住於善亦非至善善惡兩邊</span>  
<span style="margin-left: 2em">俱不倚是何境界所謂至善也但起心動念便不</span>  
<span style="margin-left: 2em">是止起心動念不屬善邊便屬惡邊便不是至善</span>  
<span style="margin-left: 2em">息機忘見便是止於至善皆本釋氏之虚寂與無</span>  
<span style="margin-left: 2em">善無惡之說而曼衍之葢沿姚江末流而變本加</span>  
<span style="margin-left: 2em">厲者耳</span>  
槐亭漫錄<sub class="note-yuan">無卷數　湖北巡撫採進本</sub>  
<span style="margin-left: 2em">明嚴堯黻撰堯黻字汝儀號槐亭朝邑人官房縣</span>  
<!-- 册3 葉2784a　Page:文淵閣四庫全書_0003冊.djvu/701 -->
<span style="margin-left: 2em">主簿是書凡十一篇曰明元曰太極曰天文曰地</span>  
<span style="margin-left: 2em">理曰時令曰人物曰性命曰鬼神曰文史曰雜著</span>  
<span style="margin-left: 2em">曰拒邪前有嘉靖甲辰自序謂是錄皆經傳格言</span>  
<span style="margin-left: 2em">師友緖論然鈔撮舊文叅以膚談不足稱窮理格</span>  
<span style="margin-left: 2em">物之功</span>  
東水質疑六卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明胡衮撰衮字補之自號味莱山人鄱陽人嘉靖</span>  
<span style="margin-left: 2em">中官台州教授東水者其所居也前四卷皆史論</span>  
<span style="margin-left: 2em">起周訖宋後二卷皆讀書題記自左傳國語以曁</span>  
<!-- 册3 葉2784b　Page:文淵閣四庫全書_0003冊.djvu/701 -->
<span style="margin-left: 2em">諸子諸集起周訖明前有小引自謂於諸生講論</span>
