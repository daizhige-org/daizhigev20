## 欽定四庫全書總目 卷一百五十八　集部十一　別集類十一

欽定四庫全書總目卷一百五十八  
<span style="margin-left: 1em">集部十一</span>  
<span style="margin-left: 2em">别集類十一</span>  
岳武穆遺文一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">宋岳飛撰飛事迹具宋史本傳陳振孫書錄解題</span>  
<span style="margin-left: 2em">載岳武穆集十卷今巳不傳此遺文一卷乃明徐</span>  
<span style="margin-left: 2em">階所編凡上書一篇劄十六篇奏二篇狀二篇表</span>  
<span style="margin-left: 2em">一篇檄一篇䟦一篇盟文一篇題識三篇詩四篇</span>  
<span style="margin-left: 2em">詞二篇其辭鎭南軍承宣使僅有第三奏辭開府</span>  
<!-- 册4 葉849b　Page:文淵閣四庫全書_0004冊.djvu/217 -->
<span style="margin-left: 2em">僅有第四劄辭男雲轉官僅有第二劄辭男雲特</span>  
<span style="margin-left: 2em">轉恩命僅有第四劄辭少保僅有第三劄第五劄</span>  
<span style="margin-left: 2em">乞敘立王次翁下僅有第二劄乞解樞柄僅有第</span>  
<span style="margin-left: 2em">三劄辭除兩鎭僅有第二劄則其佚篇葢不可殫</span>  
<span style="margin-left: 2em">數史稱万俟卨白秦檜簿錄飛家取當時御札藏</span>  
<span style="margin-left: 2em">之以滅跡則奏議文字同遭毁棄固𫝑所必然矣</span>  
<span style="margin-left: 2em">然宋高宗御書聖賢像贊刻石太學秦檜作記勒</span>  
<span style="margin-left: 2em">於後明宣德中宋訥乃磨而去之飛之零章斷句</span>  
<span style="margin-left: 2em">後人乃掇拾於蠧蝕灰燼之餘是非之公千古不</span>  
<!-- 册4 葉852a　Page:文淵閣四庫全書_0004冊.djvu/218 -->
<span style="margin-left: 2em">冺固不以篇什之多少論矣階所編本附錄岳廟</span>  
<span style="margin-left: 2em">集後前冠以後人詩文四卷巳爲倒置其中明人</span>  
<span style="margin-left: 2em">惡札如提學僉事蔡兖詩曰千古人來笑會之會</span>  
<span style="margin-left: 2em">之却恐笑今時若教似我當鈞軸未必相知岳少</span>  
<span style="margin-left: 2em">師尤爲頂上之穢今併芟除獨以飛遺文著錄集</span>  
<span style="margin-left: 2em">部用示</span>  
聖朝表章之義焉  
茶山集八卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋曾幾撰幾字吉甫贛縣人徙居河南以兄弼卹</span>  
<!-- 册4 葉852b　Page:文淵閣四庫全書_0004冊.djvu/218 -->
<span style="margin-left: 2em">恩授將仕郞試吏部優等賜上舍出身授校書郞</span>  
<span style="margin-left: 2em">高宗朝厯官江西浙西提刑忤秦檜去位僑寓上</span>  
<span style="margin-left: 2em">饒茶山寺自號茶山居士檜死召爲秘書少監權</span>  
<span style="margin-left: 2em">禮部侍郞提舉玉隆觀致仕卒諡文淸陸游爲作</span>  
<span style="margin-left: 2em">墓誌云公治經學道之餘發於文章而詩尤工以</span>  
<span style="margin-left: 2em">杜甫黃庭堅爲宗魏慶之詩人玉屑則云茶山之</span>  
<span style="margin-left: 2em">學出於韓子蒼其說小異然韓駨雖蘇氏之徒而</span>  
<span style="margin-left: 2em">名列江西詩派中其格法實近於黃殊塗同歸實</span>  
<span style="margin-left: 2em">亦一而巳矣後幾之學傳於陸游加以研練面目</span>  
<!-- 册4 葉853a　Page:文淵閣四庫全書_0004冊.djvu/218 -->
<span style="margin-left: 2em">略殊遂爲南渡大宗又詩人玉屑載趙庚夫題茶</span>  
<span style="margin-left: 2em">山集曰淸於月白初三夜淡似湯烹第一泉咄咄</span>  
<span style="margin-left: 2em">逼人門弟子劍南已見一燈傳其句律淵源固灼</span>  
<span style="margin-left: 2em">然可考也又游䟦幾奏議稿曰紹興末先生居會</span>  
<span style="margin-left: 2em">稽禹跡精舍某自勅局歸無三日不進見見必聞</span>  
<span style="margin-left: 2em">憂國之言先生時年過七十聚族百口未嘗以爲</span>  
<span style="margin-left: 2em">憂憂國而已据此則幾之一飯不忘君殆與杜甫</span>  
<span style="margin-left: 2em">之忠愛等故發之文章具有根柢不得僅以詩人</span>  
<span style="margin-left: 2em">目之求諸字句間矣墓誌稱有文集三十卷易釋</span>  
<!-- 册4 葉853b　Page:文淵閣四庫全書_0004冊.djvu/218 -->
<span style="margin-left: 2em">象五卷易釋象巳不傳文集則書錄解題及宋史</span>  
<span style="margin-left: 2em">藝文志均作十五卷是當時巳佚其半自明以來</span>  
<span style="margin-left: 2em">并十五卷亦佚僅僅散見各書偶存一二兹從永</span>  
<span style="margin-left: 2em">樂大典中搜採編輯勒爲八卷凡得古今體五百</span>  
<span style="margin-left: 2em">五十八首雖不足盡幾之長然較劉克莊後村詩</span>  
<span style="margin-left: 2em">話所記九百一十篇之數所佚者不過三百五十</span>  
<span style="margin-left: 2em">二篇耳殘膏賸馥要足沾丐無窮也</span>  
雪溪集五卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">宋王銍撰銍有侍兒小名錄補遺巳著錄是編乃</span>  
<!-- 册4 葉856a　Page:文淵閣四庫全書_0004冊.djvu/219 -->
<span style="margin-left: 2em">其詩集陳振孫書錄解題宋史藝文志並作八卷</span>  
<span style="margin-left: 2em">此本僅五卷考墨莊漫錄載銍所作王文孺臞菴</span>  
<span style="margin-left: 2em">詩一首又山村詩一首越詠載銍所作雲門寺詩</span>  
<span style="margin-left: 2em">一首今皆不見於集中知今世所傳巳佚其三卷</span>  
<span style="margin-left: 2em">非完帙矣銍詩格近温李王士禎居易錄詆其詩</span>  
<span style="margin-left: 2em">不甚工而獨稱其附載廬山僧可和詩一篇似非</span>  
<span style="margin-left: 2em">篤論惟銍以博洽名乃集中白頭吟序不引西京</span>  
<span style="margin-left: 2em">雜記而引吳兢樂府解題巳迷其本<sub class="note-yuan">案西京雜記雖僞書然在</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">吳兢之前卽兢說所自出</sub>又稱宋志載文君詩云云不知宋書</span>  
<!-- 册4 葉856b　Page:文淵閣四庫全書_0004冊.djvu/219 -->
<span style="margin-left: 2em">樂志白頭吟實作古詞不作文君此亦千慮之一</span>  
<span style="margin-left: 2em">失信乎考證之難也</span>  
蘆川歸來集五卷附錄一卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋張元幹撰元幹字仲宗自號眞隱山人又曰蘆</span>  
<span style="margin-left: 2em">川老隱周必大䟦其送胡銓詞稱長樂張元幹睢</span>  
<span style="margin-left: 2em">陽王浚明䟦其幽嵓尊祖錄則稱永福張仲宗皆</span>  
<span style="margin-left: 2em">宋人之詞莫詳孰是也王明淸揮麈錄紀其以作</span>  
<span style="margin-left: 2em">詞送胡銓得罪除名考卷末其孫欽臣䟦語稱得</span>  
<span style="margin-left: 2em">賀新郞詞二首眞跡於銓之子其說當信然銓貶</span>  
<!-- 册4 葉857a　Page:文淵閣四庫全書_0004冊.djvu/219 -->
<span style="margin-left: 2em">於紹興戊午而集中上張丞相詩稱罪放丙午末</span>  
<span style="margin-left: 2em">歸來辛亥初又自䟦祭祖母劉氏文後稱宣和元</span>  
<span style="margin-left: 2em">年八月獲緣職事道過墓下則徽宗時巳仕宦欽</span>  
<span style="margin-left: 2em">宗時巳貶謫但不知嘗爲何官耳元幹及識蘇軾</span>  
<span style="margin-left: 2em">見所作蘇黃門帖䟦又從陳瓘游頗久見所作了</span>  
<span style="margin-left: 2em">翁文集序其結詩社同唱和者則<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3200.svg?width=24" alt="四庫全書僻字第3200號（⿰氵𠔏）" title="四庫全書僻字第3200號（⿰氵𠔏）">芻<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3200.svg?width=24" alt="四庫全書僻字第3200號（⿰氵𠔏）" title="四庫全書僻字第3200號（⿰氵𠔏）">炎蘇堅</span>  
<span style="margin-left: 2em">蘇庠潘淳吕本中汪藻向子諲見所作蘇養直詩</span>  
<span style="margin-left: 2em">帖䟦而江端友王銍諸人皆有贈荅之作劉安世</span>  
<span style="margin-left: 2em">游酢楊時李綱朱松諸人皆爲題幽嵓尊祖錄故</span>  
<!-- 册4 葉857b　Page:文淵閣四庫全書_0004冊.djvu/219 -->
<span style="margin-left: 2em">其學尊元祐而詆熙寧詩文亦皆有淵源其集今</span>  
<span style="margin-left: 2em">有抄本稱嘉定已卯其孫欽臣所鋟然䟦稱誦上</span>  
<span style="margin-left: 2em">陳侍郞詩序知掛冠之年甫四十一抄本無此篇</span>  
<span style="margin-left: 2em">又曾季貍艇齋詩話載元幹題瀟湘圖詩抄本亦</span>  
<span style="margin-left: 2em">無此篇考胡仔苕溪漁隱叢話稱嘗錄元幹之詩</span>  
<span style="margin-left: 2em">一卷而元幹不自憶則當時巳不自收拾疑欽臣</span>  
<span style="margin-left: 2em">所錄本有佚失然近本但有五言律詩一卷七言</span>  
<span style="margin-left: 2em">律詩一卷而無古體及絶句知非完書又䟦米元</span>  
<span style="margin-left: 2em">暉瀑布軸䟦蘇養直絶句後䟦江天暮雨圖䟦江</span>  
<!-- 册4 葉860a　Page:文淵閣四庫全書_0004冊.djvu/220 -->
<span style="margin-left: 2em">貫道古松絶句乃收之題䟦𩔖中亦似後人所竄</span>  
<span style="margin-left: 2em">亂非其原本及考永樂大典所載則所佚諸篇𨤲</span>  
<span style="margin-left: 2em">然具在今裒集成帙與鈔本互相勘校刪其重複</span>  
<span style="margin-left: 2em">補其殘缺定爲五卷元幹詩格頗遒雜文多禪家</span>  
<span style="margin-left: 2em">疏文道家靑詞今從芟削其題䟦諸篇則具有蘇</span>  
<span style="margin-left: 2em">黃遺意葢耳目漸染之故也鈔本末有幽嵓尊祖</span>  
<span style="margin-left: 2em">錄一卷乃記其爲祖母外家置祭田事附以同時</span>  
<span style="margin-left: 2em">諸人題䟦中多元祐名臣之筆亦仍其舊第并附</span>  
<span style="margin-left: 2em">錄焉</span>

東萊詩集二十卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">宋吕本中撰本中有春秋集解巳著錄其詩法出</span>  
<span style="margin-left: 2em">於黃庭堅嘗作江西宗派圖列陳師道以下二十</span>  
<span style="margin-left: 2em">五人而以已殿其末其紫微詩話及童䝉訓論詩</span>  
<span style="margin-left: 2em">語皆具有精詣<sub class="note-yuan">案今本童䝉訓不載論詩諸條其文散見各書中說見本條之下</sub></span>  
<span style="margin-left: 2em">敖陶孫詩評稱其詩如散聖安禪自能奇逸頗爲</span>  
<span style="margin-left: 2em">近似苕溪胡仔漁隱叢話稱其樹移午影重<img class="rare-char" src="https://commons.wikimedia.org/w/thumb.php?f=SKQSfont2.pdf&page=824&w=24" alt="四庫全書僻字第二表第824號（（⿱𥫗亷）-- 簾）" title="四庫全書僻字第二表第824號（（⿱𥫗亷）-- 簾）">靜</span>  
<span style="margin-left: 2em">門閉春風十日閒往事高低半枕夢故人南北數</span>  
<span style="margin-left: 2em">行書殘雨入<img class="rare-char" src="https://commons.wikimedia.org/w/thumb.php?f=SKQSfont2.pdf&page=824&w=24" alt="四庫全書僻字第二表第824號（（⿱𥫗亷）-- 簾）" title="四庫全書僻字第二表第824號（（⿱𥫗亷）-- 簾）">收薄暑破窗留月鏤微明諸句殊</span>  
<!-- 册4 葉861a　Page:文淵閣四庫全書_0004冊.djvu/220 -->
<span style="margin-left: 2em">不盡其所長朱子語錄乃稱本中論詩欲字字響</span>  
<span style="margin-left: 2em">而暮年詩多啞然朱子以詩爲餘事而本中以詩</span>  
<span style="margin-left: 2em">爲專門吟咏一道所造自有淺深未必遂爲定論</span>  
<span style="margin-left: 2em">也此集有慶元二年陸游序乾道二年曾幾後序</span>  
<span style="margin-left: 2em">文獻通考别載有集外詩二卷此本無之葢巳散</span>  
<span style="margin-left: 2em">佚又陸游序稱嗣孫祖平悉裒集他文爲若干卷</span>  
<span style="margin-left: 2em">今此本有詩無文惟其草趙鼎遷右僕射制詞所</span>  
<span style="margin-left: 2em">云合晉楚之成不若尊王而賤伯散牛李之黨未</span>  
<span style="margin-left: 2em">如明是而去非之語以秦檜惡之載於日厯尚爲</span>

<span style="margin-left: 2em">世所傳誦其他文則冺沒久矣</span>

<span style="margin-left: 2em">紹興五年以薦除樞宻院編修官抗疏詆和議謪</span>  
<span style="margin-left: 2em">吉陽軍孝宗卽位特召還擢用厯官權中書舍人</span>  
<span style="margin-left: 2em">兼國子祭酒權兵部侍郞以資政殿學士致仕卒</span>
