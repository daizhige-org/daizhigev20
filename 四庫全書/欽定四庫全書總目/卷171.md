## 欽定四庫全書總目 卷一百七十一　集部二十四　別集類二十四

<!-- 册4 葉2061a　Page:文淵閣四庫全書_0004冊.djvu/520 -->
欽定四庫全書總目卷一百七十一  
<span style="margin-left: 1em">集部二十四</span>  
<span style="margin-left: 2em">別集類二十四</span>  
一峯集十卷<sub class="note-yuan">浙江汪汝瑮家藏本</sub>  
<span style="margin-left: 2em">明羅倫撰倫字彝正別號一峯江西永豐人成化</span>  
<span style="margin-left: 2em">丙戌進士第一授修撰釋褐甫三月以疏劾大學</span>  
<span style="margin-left: 2em">士李賢謫泉州市舶副提舉明年詔還復原官改</span>  
<span style="margin-left: 2em">南京供職尋以疾辭歸退居金牛山授徒講學以</span>  
<span style="margin-left: 2em">終事蹟具明史本傳倫與陳獻章稱石交然獻章</span>  
<!-- 册4 葉2061b　Page:文淵閣四庫全書_0004冊.djvu/520 -->
<span style="margin-left: 2em">以超悟爲宗而倫篤守宋儒之途轍所學則殊明</span>  
<span style="margin-left: 2em">儒學案云倫剛介絶俗生平不作合同之語不爲</span>  
<span style="margin-left: 2em">軟巽之行凍餒幾於死亡而無足以動其中庶可</span>  
<span style="margin-left: 2em">謂之無欲今覽其文剛毅之氣形於楮墨詩亦磊</span>  
<span style="margin-left: 2em">砢不凡雖執意過堅時或失於迂濶又喜排叠先</span>  
<span style="margin-left: 2em">儒傳註成語少淘汰之功或失於繁冗然亦多心</span>  
<span style="margin-left: 2em">得之言非外强中乾者比也後載夢稿二卷記夢</span>  
<span style="margin-left: 2em">之詞至三百餘首隱約幻渺幾莫測其用意所在</span>  
<span style="margin-left: 2em">亦文集中罕見之體以其人足重故得附本集以</span>  
<!-- 册4 葉2064a　Page:文淵閣四庫全書_0004冊.djvu/521 -->
<span style="margin-left: 2em">傳今亦姑仍舊本錄之焉</span>  
篁墩集九十三卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">明程敏政撰敏政有宋遺民錄已著錄是集爲敏</span>  
<span style="margin-left: 2em">政所自訂據千頃堂書目尙有外集十二卷別集</span>  
<span style="margin-left: 2em">二卷行素稿一卷拾遺一卷雜著一卷今皆不在</span>  
<span style="margin-left: 2em">此編中疑其本別行也敏政學問淹通著作具有</span>  
<span style="margin-left: 2em">根柢非游談無根者比特以生於朱子之鄉又自</span>  
<span style="margin-left: 2em">稱爲程子之裔故於漢儒宋儒判如冰炭於蜀黨</span>  
<span style="margin-left: 2em">洛黨亦爭若宼讐門戸之見旣深狥其私心遂往</span>  
<!-- 册4 葉2064b　Page:文淵閣四庫全書_0004冊.djvu/521 -->
<span style="margin-left: 2em">往傷於偏駁如奏考正祀典欲黜鄭康成祀於其</span>  
<span style="margin-left: 2em">鄉作蘇氏檮杌以鍜鍊蘇軾復伊川九世之讐至</span>  
<span style="margin-left: 2em">今爲通人所詬厲其文格亦頗頽唐不出當時風</span>  
<span style="margin-left: 2em">氣詩歌多至數千篇尤多率易求其警䇿者殊稀</span>  
<span style="margin-left: 2em">然明之中葉士大夫侈談性命其病日流於空疎</span>  
<span style="margin-left: 2em">敏政獨以雄才博學挺出一時集中徵引故實恃</span>  
<span style="margin-left: 2em">其淹博不加詳檢舛悞者固多其考證精當者亦</span>  
<span style="margin-left: 2em">時有可取要爲一時之碩學未可盡以蕪雜廢也</span>  
<span style="margin-left: 2em">其集名曰篁墩者考新安有黃墩爲晉新安太守</span>  
<!-- 册4 葉2065a　Page:文淵閣四庫全書_0004冊.djvu/521 -->
<span style="margin-left: 2em">黃積所居子孫世宅於此故以黃爲名自羅願新</span>  
<span style="margin-left: 2em">安志朱子文集所載皆同敏政乃稱黃本篁字因</span>  
<span style="margin-left: 2em">黃巢而改遂稱曰篁墩爲之作記且以自號其說</span>  
<span style="margin-left: 2em">杜撰無稽然名從主人實爲古義今亦仍其舊稱</span>  
<span style="margin-left: 2em">焉</span>  
楓山集四卷附錄一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明章懋撰懋有楓山語錄已著錄懋初在詞垣以</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">諫著名今集中第一篇卽其原疏考元夕張燈</span>  
<span style="margin-left: 2em">未爲失德詞臣賡韻亦有前規而反覆力爭近乎</span>  
<!-- 册4 葉2065b　Page:文淵閣四庫全書_0004冊.djvu/521 -->
<span style="margin-left: 2em">伊川之諫折柳未免矯激太過然其意要不失於</span>  
<span style="margin-left: 2em">持正故君子猶有取焉至其生平淸節矯矯過人</span>  
<span style="margin-left: 2em">可謂耿介拔俗之操其講學恪守前賢弗踰尺寸</span>  
<span style="margin-left: 2em">不屑爲浮夸表暴之談在明代諸儒尤爲淳實明</span>  
<span style="margin-left: 2em">史本傳稱或諷之爲文章則對曰此小技耳予弗</span>  
<span style="margin-left: 2em">暇有勸以著述者曰先儒之言至矣芟其繁可也</span>  
<span style="margin-left: 2em">葢其旨惟在身體力行而於語言文字之間非所</span>  
<span style="margin-left: 2em">留意故生平所作止於如此然所存皆辭意醇正</span>  
<span style="margin-left: 2em">有和平温厚之風葢道德之腴發爲詞章固非蠟</span>  
<!-- 册4 葉2068a　Page:文淵閣四庫全書_0004冊.djvu/522 -->
<span style="margin-left: 2em">貌梔言者所可比爾</span>  
莊定山集十卷<sub class="note-yuan">山東巡撫採進本</sub>  
<span style="margin-left: 2em">明莊㫤撰㫤字孔暘江浦人成化丙戌進士官至</span>  
<span style="margin-left: 2em">南京禮部郞中事蹟具明史本傳㫤官檢討時以</span>  
<span style="margin-left: 2em">不奉詔作鼇山詩與章懋黃仲昭同謫淪落者垂</span>  
<span style="margin-left: 2em">三十年世頗推其氣節惟癖於講學故其文多闡</span>  
<span style="margin-left: 2em">太極圖之義其詩亦全作擊壤集之體又頗爲世</span>  
<span style="margin-left: 2em">所嗤㸃然如病眼詩殘書漢楚燈前壘草閣江山</span>  
<span style="margin-left: 2em">霧裏詩句楊愼亦嘗稱之其他如山隨病起靑逾</span>  
<!-- 册4 葉2068b　Page:文淵閣四庫全書_0004冊.djvu/522 -->
<span style="margin-left: 2em">峻菊到秋深瘦亦香士屋背墻烘野日午溪隨步</span>  
<span style="margin-left: 2em">領和風碧樹可驚遊子夢黃花偏愛老人頭酒琖</span>  
<span style="margin-left: 2em">漫傾剛月上釣絲纔颺恰風和諸句亦未嘗不語</span>  
<span style="margin-left: 2em">舍興象葢其學以主靜爲宗故息慮澄觀天機偶</span>  
<span style="margin-left: 2em">到往往妙合自然不可以文章格律論要亦文章</span>  
<span style="margin-left: 2em">之一種譬諸釣叟田翁不可繩以禮貌而野逸之</span>  
<span style="margin-left: 2em">態乃有時可入畫圖錄之以備別格亦論唐詩者</span>  
<span style="margin-left: 2em">存寒山子集之意也</span>  
未軒文集十二卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<!-- 册4 葉2069a　Page:文淵閣四庫全書_0004冊.djvu/522 -->
<span style="margin-left: 2em">明黃仲昭撰仲昭有八閩通志已著錄是集爲其</span>  
<span style="margin-left: 2em">門人劉節所編凡文六卷詩五卷詞一卷而以碑</span>  
<span style="margin-left: 2em">文墓誌銘附之仲昭官編修時與章懋莊㫤並以</span>  
<span style="margin-left: 2em">疏爭元宵烟火事廷杖謫官當時有翰林三君子</span>  
<span style="margin-left: 2em">之目後懋與㫤並以聚徒講學爲事而仲昭獨刻</span>  
<span style="margin-left: 2em">意紀述八閩通志延平府志邵武府志南平縣志</span>  
<span style="margin-left: 2em">興化府志皆所編錄故楓山定山之名滿於天下</span>  
<span style="margin-left: 2em">仲昭幾爲所掩然三人氣節相同居官淸介相同</span>  
<span style="margin-left: 2em">文章質實亦畧相同未可以仲昭篤志勵行不作</span>  
<!-- 册4 葉2069b　Page:文淵閣四庫全書_0004冊.djvu/522 -->
<span style="margin-left: 2em">語錄遂分優劣於其間也林瀚作仲昭墓誌稱其</span>  
<span style="margin-left: 2em">作爲文章渾厚典重無艱深聱磽之語鄭岳莆陽</span>  
<span style="margin-left: 2em">文獻傳亦稱其有未軒集若干卷文詞典雅今觀</span>  
<span style="margin-left: 2em">其集雖尙沿當日平實之格而人品旣高自無鄙</span>  
<span style="margin-left: 2em">語頡頏於作者之間正不以坦易爲嫌矣</span>  
醫閭集九卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">明賀欽撰欽字克恭其先浙之定海人以戍籍隸</span>  
<span style="margin-left: 2em">遼東義州衛登成化丙戌進士授戸科給事中謝</span>  
<span style="margin-left: 2em">病歸宏治初起陜西㕘議檄未至而母殁乃上疏</span>  
<!-- 册4 葉2072a　Page:文淵閣四庫全書_0004冊.djvu/523 -->
<span style="margin-left: 2em">懇辭服闋遂不復出事蹟具明史儒林傳此編乃</span>  
<span style="margin-left: 2em">其子士諮蒐輯遺稿並生平言行都爲一集前三</span>  
<span style="margin-left: 2em">卷爲言行錄四卷至七卷爲存稿皆雜文第八卷</span>  
<span style="margin-left: 2em">爲奏稿第九卷爲詩稿以欽嘗讀書醫無閭山自</span>  
<span style="margin-left: 2em">號醫閭山人因以名集欽之學出於陳獻章然獻</span>  
<span style="margin-left: 2em">章之學主靜悟欽之學則期於返身實踐能補苴</span>  
<span style="margin-left: 2em">其師之所偏嘗言爲學不在求之高遠在主靜以</span>  
<span style="margin-left: 2em">收放心而已故集中所錄言行皆平易眞樸非高</span>  
<span style="margin-left: 2em">談性命者可比而所上諸奏疏亦無不通達治理</span>  
<!-- 册4 葉2072b　Page:文淵閣四庫全書_0004冊.djvu/523 -->
<span style="margin-left: 2em">確然可見諸施行在講學諸人之中獨爲篤實而</span>  
<span style="margin-left: 2em">純正文章雖多信筆揮灑不甚修詞而仁義之言</span>  
<span style="margin-left: 2em">藹然可見固不必以工拙論也</span>  
翠渠摘稿七卷補遺一卷<sub class="note-yuan">福建巡撫採進本</sub>  
<span style="margin-left: 2em">明周瑛撰瑛有書纂已著錄所著詩文集曰翠渠</span>  
<span style="margin-left: 2em">類稿此本乃其門人林近龍所選錄故曰摘稿鄭</span>  
<span style="margin-left: 2em">岳撰瑛傳稱其文章渾成雅健詩格調高古瑛亦</span>  
<span style="margin-left: 2em">嘗作絶句云老去歸平澹時人或未知則其自命</span>  
<span style="margin-left: 2em">不在以繁音縟節務諧俗耳矣朱彝尊明詩綜鄭</span>  
<!-- 册4 葉2073a　Page:文淵閣四庫全書_0004冊.djvu/523 -->
<span style="margin-left: 2em">王臣莆風淸籟集並載瑛履霜操樂府其言怨而</span>  
<span style="margin-left: 2em">不怒足正昌黎之失此集中乃未收之或近龍去</span>  
<span style="margin-left: 2em">取失當誤佚之歟未附說三篇序一篇詩十八首</span>  
<span style="margin-left: 2em">共爲一卷乃康熙戊子其七世孫維鑣於家乘中</span>  
<span style="margin-left: 2em">鈔出以補摘稿所遺者然冠以鄭岳所撰傳其八</span>  
<span style="margin-left: 2em">世孫成又於雍正壬子求得瑛自撰誌銘補錄於</span>  
<span style="margin-left: 2em">後亦列於題跋之中均乖編次之體張詡作陳獻</span>  
<span style="margin-left: 2em">章行狀稱瑛爲獻章門人而成跋力辨其非以二</span>  
<span style="margin-left: 2em">人之集考之葢始合而終暌者詡與成之說皆各</span>  
<!-- 册4 葉2073b　Page:文淵閣四庫全書_0004冊.djvu/523 -->
<span style="margin-left: 2em">執其一偏明史儒林傳亦稱瑛始與獻章友獻章</span>  
<span style="margin-left: 2em">之學主於靜瑛不然之謂學當以居敬爲主云</span>  
家藏集七十七卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明吳寛撰寛字原博號匏庵長洲人成化壬辰進</span>  
<span style="margin-left: 2em">士第一官至掌詹事府禮部尙書諡文定事蹟具</span>  
<span style="margin-left: 2em">明史本傳集爲寛所自訂李東陽王鏊二序皆稱</span>  
<span style="margin-left: 2em">詩三十卷雜文四十卷總爲七十卷今此本詩目</span>  
<span style="margin-left: 2em">相同而文集實多七卷又附以補遺文六篇後序</span>  
<span style="margin-left: 2em">亦稱寛子中書舍人奭蒐閱笥稿得詩三十卷文</span>  
<!-- 册4 葉2076a　Page:文淵閣四庫全書_0004冊.djvu/524 -->
<span style="margin-left: 2em">四十七卷與前序頗不合疑七十卷以上乃寛原</span>  
<span style="margin-left: 2em">編而其後七卷則出奭等所附益也寛學有根柢</span>  
<span style="margin-left: 2em">爲當時館閣鉅手平生學宗蘇氏字法亦酷肖東</span>  
<span style="margin-left: 2em">坡縑素流傳賞鑒家至今藏弆詩文亦和平恬雅</span>  
<span style="margin-left: 2em">有鳴鸞佩玉之風朱承爵存餘堂詩話稱其雪後</span>  
<span style="margin-left: 2em">入朝詩雖非高格至謂其詩格尙渾厚琢句沉著</span>  
<span style="margin-left: 2em">用事典切無漫然嘲風弄月之語則頗爲得實以</span>  
<span style="margin-left: 2em">之羽翼茶陵實如驂之有靳至其作史彬墓表稱</span>
