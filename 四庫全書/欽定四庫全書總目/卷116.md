<span style="margin-left: 2em">宋吕大臨撰大臨原書十六卷巳著錄此本無續</span>  
<span style="margin-left: 2em">圖及釋文乃元大德己亥茶陵陳翼子所重刋附</span>  
<span style="margin-left: 2em">以諸家之考證已非吕氏之舊且亦自多謬誤如</span>

<span style="margin-left: 2em">舊本題宋張掄撰掄字材甫履貫未詳周宻武林</span>  
<span style="margin-left: 2em">舊事載乾道三年三月高宗幸聚景園知閣張掄</span>  
<span style="margin-left: 2em">進柳梢靑詞𫎇宣賜淳熙六年二月再幸聚景園</span>  
<span style="margin-left: 2em">掄進壺中天慢詞賜金盃盤法錦是年九月孝宗</span>  
<span style="margin-left: 2em">幸絳華宫掄進臨江仙詞則亦能文之士又王應</span>  
<span style="margin-left: 2em">麟玉海曰張掄爲易卦補遺其說曰易以初上二</span>  
<span style="margin-left: 2em">爻爲定體以中四爻爲變繫辭謂之中爻先儒謂</span>  
<span style="margin-left: 2em">之互體所謂雜物撰德辨是與非八卦互成剛柔</span>  
<!-- 册3 葉2073b　Page:文淵閣四庫全書_0003冊.djvu/523 -->
<span style="margin-left: 2em">相易之道非此無見焉則掄亦留心於經術又張</span>  
<span style="margin-left: 2em">端義貴耳集曰孝宗朝幸臣雖多其讀書作文不</span>  
<span style="margin-left: 2em">减儒生應制燕閒未可輕視當倉卒翰墨之奉豈</span>  
<span style="margin-left: 2em">容宿撰其人有曾覿龍大淵張掄徐本中王忭劉</span>  
<span style="margin-left: 2em">弼當時士大夫少有不游曾龍張徐之門者則掄</span>  
<span style="margin-left: 2em">亦狎客之流然宋史侫倖傳僅有曾覿龍大淵王</span>  
<span style="margin-left: 2em">忭不列掄等則但以詞章邀寵未亂政也是書宋</span>  
<span style="margin-left: 2em">以來諸家書日皆不著錄據書末毛晉䟦稱晉得</span>  
<span style="margin-left: 2em">於范景文景文得於于奕正至奕正從何得之則</span>

<span style="margin-left: 2em">莫明所自上卷凡九十八事下卷凡九十七事皆</span>  
<span style="margin-left: 2em">漢以前物漢以後者惟梁中大同博山鑪一器其</span>  
<span style="margin-left: 2em">中如上卷之周文王鼎商若癸鼎父辛鼎商持刀</span>  
<span style="margin-left: 2em">祖乙卣周召父𢑴商父辛尊商父癸尊商父庚觚</span>  
<span style="margin-left: 2em">商持刀父已鼎周淮父卣周虎斚周季父鼎周南</span>  
<span style="margin-left: 2em">宫中鼎商癸鼎商瞿鼎商貫耳弓壺商亞虎父丁</span>  
<span style="margin-left: 2em">鼎商祖戊尊商兄癸卣周已酉方𢑴周觚稜壺周</span>  
<span style="margin-left: 2em">龻女鼎商子孫父辛𢑴周叔液鼎商父已鼎周宰</span>  
<span style="margin-left: 2em">辟父敦周刺公敦周孟皇父𢑴下卷如商冀父辛</span>

<span style="margin-left: 2em">饕餮鼎周節鼎周中鼎周婦氏鼎商提梁田鳯卣</span>  
<span style="margin-left: 2em">漢麟瓶周虬紐鐘周樂司徒卣漢獸耳圓壺漢提</span>  
<span style="margin-left: 2em">梁小匾壺商祖丙爵商子孫巳爵周仲偁父鼎皆</span>  
<span style="margin-left: 2em">卽博古圖之文割剝<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）">竄詞義往往不通其他諸</span>  
<span style="margin-left: 2em">器亦皆博古圖所載惟上卷商虎乳𢑴周言鼎周</span>  
<span style="margin-left: 2em">尹鼎周獸足鼎下卷商祖癸鼎周乙父鼎周公命</span>

<span style="margin-left: 2em">有不知名者二十三事嘉定以後續降付八十三</span>  
<span style="margin-left: 2em">事與此書所錄數旣不符而此書所載商冀父辛</span>  
<span style="margin-left: 2em">卣父辛鼎周南宫中鼎周䜌女鼎皆嘉定十八年</span>  
<span style="margin-left: 2em">十一月所續降付何以先著錄於紹興中其爲明</span>

焦岀古鼎考一卷<sub class="note-yuan">兩江總督採進本</sub>

<span style="margin-left: 2em">一理學第二史第三古書第四諸子第五文集第</span>

<span style="margin-left: 2em">六詩集第七類書第八雜史第九地志第十韻書</span>  
<span style="margin-left: 2em">第十一小學醫學第十二雜流第十三又特爲制</span>  
<span style="margin-left: 2em">書一類其義例與厯代書目頗有不同葢深以意</span>  
<span style="margin-left: 2em">爲之非古法也</span>  
古器具名二卷附古器總說一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明胡文焕編文焕有文會堂琴譜已著錄是書於</span>  
<span style="margin-left: 2em">每一古器各繪一圖先以博古圖考古圖次以欣</span>  
<span style="margin-left: 2em">賞編欣賞編者卽抄襲說郛内之古玉圖也古玉</span>  
<span style="margin-left: 2em">圖元人朱德潤編有德潤自序刻說郛者旣失其</span>  
<!-- 册3 葉2080b　Page:文淵閣四庫全書_0003冊.djvu/525 -->
<span style="margin-left: 2em">序而沈潤卿欣賞編又没所自來文焕此書遂直</span>  
<span style="margin-left: 2em">以爲据欣賞編訛以傳訛其無所考証可見兄博</span>  
<span style="margin-left: 2em">古考古二圖所載甚備乃每器僅擇其一亦不知</span>  
<span style="margin-left: 2em">其何取末附總說一卷則全襲博古圖之文益爲</span>  
<span style="margin-left: 2em">弇鄙博古圖成於宣和禁絶史學之日引据原踈</span>  
<span style="margin-left: 2em">文焕不能考定乃剽竊割裂又從而汨亂之其鉤</span>  
<span style="margin-left: 2em">摹古篆亦不解古人筆法尤訛謬百出不知而作</span>  
<span style="margin-left: 2em">其此書之謂歟</span>  
分宜淸玩譜一卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<!-- 册3 葉2081a　Page:文淵閣四庫全書_0003冊.djvu/525 -->
<span style="margin-left: 2em">不著撰人名氏取嚴嵩家藏弆書畫器玩之目彚</span>  
<span style="margin-left: 2em">爲一册皆摘其尤珍異者錄之尙非其全籍也</span>  
古玉圖譜一百卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">舊本題宋龍大淵等奉勅撰宋史藝文志不載他</span>  
<span style="margin-left: 2em">家著錄者皆未之及尤袤遂初堂書目有譜錄一</span>  
<span style="margin-left: 2em">門自博古考古圖外尙有李伯時古器圖晏氏辨</span>  
<span style="margin-left: 2em">古圖八寳記玉璽譜諸目亦無是書之名朱澤民</span>  
<span style="margin-left: 2em">古玉圖作於元時亦不言曾見是書莫審其所自</span>  
<span style="margin-left: 2em">來今卽其前列修書諸臣職銜以史傳考證舛互</span>  
<!-- 册3 葉2081b　Page:文淵閣四庫全書_0003冊.djvu/525 -->
<span style="margin-left: 2em">之處不可枚舉案宋制凡修書處有提舉監修詳</span>  
<span style="margin-left: 2em">定編修諸職名從無總裁副總裁之稱其可疑一</span>  
<span style="margin-left: 2em">也宋制翰林學士承旨以學士久次者爲之宋史</span>  
<span style="margin-left: 2em">侫倖傳載龍大淵紹興中爲建王内知客孝宗受</span>  
<span style="margin-left: 2em">襌自左武大夫除樞宻副都承旨知閤門事出爲</span>  
<span style="margin-left: 2em">江東總管是大淵官本武階不應爲是職又提舉</span>  
<span style="margin-left: 2em">嵩山崇福官下加一使字宋制亦無此名且傳稱</span>  
<span style="margin-left: 2em">大淵於乾道四年死此書作於淳熙三年在大淵</span>  
<span style="margin-left: 2em">死後九年何得尙領修纂之事其可疑二也又字</span>  
<!-- 册3 葉2084a　Page:文淵閣四庫全書_0003冊.djvu/526 -->
<span style="margin-left: 2em">文粹中列銜稱翰林直學士考南宋館閣錄及翰</span>  
<span style="margin-left: 2em">院題名記自乾道至淳熙僅有王淮崔敦詩胡元</span>  
<span style="margin-left: 2em">質周必大程叔達諸人無粹中之名其可疑三也</span>  
<span style="margin-left: 2em">又宋史侫倖傳載曾覿字純甫汴人紹興中爲建</span>  
<span style="margin-left: 2em">王内知客孝宗以潛邸舊人除權知閤門事淳熙</span>  
<span style="margin-left: 2em">元年除開府儀同三司六年加少保醴泉觀使今</span>
