## 欽定四庫全書總目 卷一百四十七　子部五十七　道家類存目

欽定四庫全書總目卷一百四十七  
<span style="margin-left: 1em">子部五十七</span>  
<span style="margin-left: 2em">道家𩔖存目</span>  
陰符經三皇玉訣三卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">其書述黃帝得陰符經問於廣成子及天眞皇人</span>  
<span style="margin-left: 2em">皆稱黄帝問而二人荅詞旨鄙淺前有黃帝御製</span>  
<span style="margin-left: 2em">序一首文尤謬陋葢粗知字義道士所爲也然金</span>  
<span style="margin-left: 2em">明昌中范懌作陰符經註序已引之則其僞亦久</span>  
<span style="margin-left: 2em">矣</span>  
<!-- 册3 葉4417b　Page:文淵閣四庫全書_0003冊.djvu/1109 -->
陰符經註一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">舊本題金陵道人唐淳撰前有至大巳丑孟綽然</span>  
<span style="margin-left: 2em">序稱不知淳爲何代人其說皆主於内丹中稱天</span>  
<span style="margin-left: 2em">性人也人心機也立天之道以定人也十六字爲</span>  
<span style="margin-left: 2em">杜光庭所加則五代後人矣</span>  
陰符經集解三卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">宋袁淑眞撰是書前有淑眞銜稱朝散郎行潭州</span>  
<span style="margin-left: 2em">長沙縣主簿其里貫則未詳也其本亦分三篇引</span>  
<span style="margin-left: 2em">驪山老姥百言演道百言演法百言演術之說惟</span>  
<!-- 册3 葉4420a　Page:文淵閣四庫全書_0003冊.djvu/1110 -->
<span style="margin-left: 2em">末附一叚祗五十八字又與諸本不同</span>  
陰符經註一卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">宋俞琰撰琰有周易集說已著錄琰本文士故是</span>  
<span style="margin-left: 2em">編所注較他家具有條理其闢詹谷以容成之術</span>  
<span style="margin-left: 2em">釋强兵戰勝之義尤爲正論其本亦合爲一篇而</span>  
<span style="margin-left: 2em">人以慮愚一百十四字則兩存經文注文之說</span>  
陰符經註一卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">金劉處元撰處元卽王重陽七弟子之一也其說</span>  
<span style="margin-left: 2em">叅以佛經前有明昌辛亥寧海州學正范懌序</span>  
<!-- 册3 葉4420b　Page:文淵閣四庫全書_0003冊.djvu/1110 -->
陰符經註一卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">舊本題姑射山太元子侯善淵注不知何許人其</span>  
<span style="margin-left: 2em">本合三篇爲一而末有人以慮愚以下一百十四</span>  
<span style="margin-left: 2em">字註較他本頗有文義而傷於簡畧</span>  
陰符經解一卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明焦竑撰竑有易筌已著錄考戰國䇿稱蘇秦得</span>  
<span style="margin-left: 2em">太公陰符之謀其書漢志隋志皆不著錄葢已不</span>  
<span style="margin-left: 2em">傳今世所行之本出唐李筌宋黃庭堅以爲卽筌</span>  
<span style="margin-left: 2em">所托註其書者自筌而後凡數十家或以爲道家</span>  
<!-- 册3 葉4421a　Page:文淵閣四庫全書_0003冊.djvu/1110 -->
<span style="margin-left: 2em">言或以爲兵家言或以爲神仙家言竑此註雖引</span>  
<span style="margin-left: 2em">張永叔眞土擒眞鉛眞鉛制眞汞之說似乎神仙</span>  
<span style="margin-left: 2em">家言而核其宗旨實以佛理解之與劉處元註相</span>  
<span style="margin-left: 2em">近葢竑與李贄友善故氣𩔖薰染喜談禪悅其作</span>  
<span style="margin-left: 2em">此註仍然三教歸一之旨也</span>  
陰符經質劑一卷<sub class="note-yuan">江蘇周厚堉家藏本</sub>  
<span style="margin-left: 2em">明方時化撰時化有易引已著錄是編大旨以陰</span>  
<span style="margin-left: 2em">符與易理相合前有自序謂已有易引百篇不可</span>  
<span style="margin-left: 2em">不質劑於陰符末又附陰符質劑問設爲問答以</span>  
<!-- 册3 葉4421b　Page:文淵閣四庫全書_0003冊.djvu/1110 -->
<span style="margin-left: 2em">暢其說大都不離乎禪學</span>  
陰符經註一卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 1em">國朝李光地撰光地有周易觀彖已著錄陰符經文</span>  
<span style="margin-left: 2em">意刻酷五賊三盜之名尤爲竒險光地註義純粹</span>  
<span style="margin-left: 2em">頗能補苴其罅漏其註禽之制在炁謂以心制目</span>  
<span style="margin-left: 2em">以目制心如禽鳥之以氣相制雖雄鷙者不敢動</span>  
<span style="margin-left: 2em">似較李筌註爲順然此書本筌所僞撰自作之而</span>  
<span style="margin-left: 2em">自註之自必不失其本意可不必與立異同况此</span>  
<span style="margin-left: 2em">本禽之制在炁句次在心生於物死於物機在目</span>  
<!-- 册3 葉4424a　Page:文淵閣四庫全書_0003冊.djvu/1111 -->
<span style="margin-left: 2em">之下故此註會通四語以立義漢魏叢書本次此</span>  
<span style="margin-left: 2em">句於天之至私用之至公二句下則義有難通矣</span>  
<span style="margin-left: 2em">傳寫互異莫可究詰楚失齊得輾轉安窮旣非儒</span>  
<span style="margin-left: 2em">書要義亦聽其各存一說於天地間耳</span>  
古老子二卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">舊本題許劍道人手刋卷首有自題絶句一首云</span>  
<span style="margin-left: 2em">道人自昔不談元何事幡然繪此篇料得浮雲無</span>  
<span style="margin-left: 2em">挂礙欲從牛背學長年稱壬子閏五題於申州傳</span>  
<span style="margin-left: 2em">舍末有二小印一曰史垂名一曰靑史葢其名字</span>  
<!-- 册3 葉4424b　Page:文淵閣四庫全書_0003冊.djvu/1111 -->
<span style="margin-left: 2em">次爲所畫老子像亦有二小印一曰許劍道人一</span>  
<span style="margin-left: 2em">曰別號題橋生又書首二小印一曰垂名原名南</span>  
<span style="margin-left: 2em">一曰兩江一字靑史不知何許人也考石墨鐫華</span>  
<span style="margin-left: 2em">有元至元間盩厔樓觀說經臺篆書古老子及正</span>  
<span style="margin-left: 2em">書釋文與此無異末刻夷門天樂道人李道謙䟦</span>  
<span style="margin-left: 2em">云魯之大儒高翿文舉者善古篆嘗爲會眞宮提</span>  
<span style="margin-left: 2em">㸃張志偉壽符書道德五千言筆法精妙古今罕</span>  
<span style="margin-left: 2em">有至元庚寅承命祀香嶽瀆駐於終南山重陽萬</span>  
<span style="margin-left: 2em">壽宫遂摹諸經臺垂之永久然則高翿所書李道</span>  
<!-- 册3 葉4425a　Page:文淵閣四庫全書_0003冊.djvu/1111 -->
<span style="margin-left: 2em">謙摹刻於石而是冊又從石刻摹出耳字體怪異</span>  
<span style="margin-left: 2em">不合六書趙崡謂其雜出頡籀欵識古文大小二</span>  
<span style="margin-left: 2em">篆沾沾自喜尙不堪郭忠恕一嗤非過論也考翿</span>  
<span style="margin-left: 2em">自識有云老子舊有古本厯嵗滋久不可復見於</span>  
<span style="margin-left: 2em">古文韻海中檢討綴緝越月乃成據此則翿所書</span>  
<span style="margin-left: 2em">篆體徒本之古文韻海耳其文視今本老子惟增</span>  
<span style="margin-left: 2em">減數虛字亦不足以資考校也</span>  
道德經說奥二卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">舊本題朱孟嘗撰附刻朱翊ခ廣讌堂集後明宗</span>  
<!-- 册3 葉4425b　Page:文淵閣四庫全書_0003冊.djvu/1111 -->
<span style="margin-left: 2em">室命名毎府以二十字爲次其下一字則偏旁取</span>  
<span style="margin-left: 2em">五行相生此曰孟嘗葢其字號惟未審卽翊ဂ作</span>  
<span style="margin-left: 2em">或其子孫所作耳其書於毎章之後寥寥各贅數</span>  
<span style="margin-left: 2em">言殊未盡老氏之旨</span>  
道德經編註二卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 1em">國朝胡與高撰與高字岱瞻黟縣人雍正癸卯舉人</span>  
<span style="margin-left: 2em">是書謂老子今本相沿章句多舛乃遍訪古本考</span>  
<span style="margin-left: 2em">正其文併註釋其義而篇中分合增改之處絶不</span>  
<span style="margin-left: 2em">注所據者何本未免無徵其謂老子與六經相發</span>  
<!-- 册3 葉4428a　Page:文淵閣四庫全書_0003冊.djvu/1112 -->
<span style="margin-left: 2em">明亦蘇轍之緖論每章註釋之後又有附解則其</span>  
<span style="margin-left: 2em">弟與宗所續與高之註成於雍正甲寅與宗之解</span>  
<span style="margin-left: 2em">成於乾隆戊辰據與宗自䟦仍其兄之餘意云</span>  
讀道德經私記二卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 1em">國朝汪縉撰縉字大紳吳縣人是書以易義解老子</span>  
<span style="margin-left: 2em">前有自序曰釋老子者多矣別於諸子方外與易</span>  
<span style="margin-left: 2em">相出入者私記之盖其大意欲於諸註之外獨標</span>  
<span style="margin-left: 2em">新義然晉人淸談實合老莊與易爲一王弼以老</span>  
<span style="margin-left: 2em">子解易人人𩔖能言之卽三語掾之故實亦非僻</span>  
<!-- 册3 葉4428b　Page:文淵閣四庫全書_0003冊.djvu/1112 -->
<span style="margin-left: 2em">事也</span>  
道德經懸解二卷<sub class="note-yuan">編修周永年家藏本</sub>  
<span style="margin-left: 1em">國朝黃元御撰元御有周易懸象已著錄是書多以</span>  
<span style="margin-left: 2em">養生家言訓釋老子於原文章次多所變更字句</span>  
<span style="margin-left: 2em">亦多有竄亂謂之改本老子可也</span>  
列子辨二卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">不著撰人名氏前有康熙後壬寅自序署其號日</span>  
<span style="margin-left: 2em">復堂不知何許人也其注用林希逸口義本稍爲</span>  
<span style="margin-left: 2em">刪削而間附以劉辰翁評卷首凡例稱列子刻本</span>  
<!-- 册3 葉4429a　Page:文淵閣四庫全書_0003冊.djvu/1112 -->
<span style="margin-left: 2em">書肆絶少此特借抄其中必多訛字云云則亦寒</span>  
<span style="margin-left: 2em">鄉之士罕睹舊籍者矣其辨論大旨謂漢藝文志</span>  
<span style="margin-left: 2em">載列子八篇典午之禍典籍蕩然六朝淸談之士</span>  
<span style="margin-left: 2em">依傍藝文志所云而妄托之然其所證據特以文</span>  
<span style="margin-left: 2em">句臆斷之耳考柳宗元集有辨列子一篇摘其言</span>  
<span style="margin-left: 2em">魏牟孔穿皆出列子後然特謂其不免增竄不以</span>  
<span style="margin-left: 2em">爲僞也高似孫緯畧頗以史記無傳爲疑又疑其</span>  
<span style="margin-left: 2em">出於後人之薈萃然未敢定爲誰氏作也是編漫</span>  
<span style="margin-left: 2em">無所據竟毅然斷其出於六朝極詆其文詞之惡</span>  
<!-- 册3 葉4429b　Page:文淵閣四庫全書_0003冊.djvu/1112 -->
<span style="margin-left: 2em">以朱筆勒其旁者不一而足文詞工拙姑置無論</span>  
<span style="margin-left: 2em">第考東晉光祿勲張湛所注已疑其言鄭穆公以</span>  
<span style="margin-left: 2em">後事與劉向所云鄭穆公時人者不合則書在東</span>  
<span style="margin-left: 2em">晉以前審矣作者未見湛注遂以爲出自六朝耳</span>  
<span style="margin-left: 2em">觀其批篇首將嫁於衛句云嫁字諸書所無但此</span>  
<span style="margin-left: 2em">書率多訛字嫁或家字之譌不知爾雅釋詁曰嫁</span>  
<span style="margin-left: 2em">往也郭璞注引方言曰自家而出謂之嫁猶女出</span>  
<span style="margin-left: 2em">爲嫁古訓炳然乃橫生揣度其空言臆斷可知矣</span>  
莊子通義十卷<sub class="note-yuan">兩江總督採進本</sub>  
<!-- 册3 葉4432a　Page:文淵閣四庫全書_0003冊.djvu/1113 -->
<span style="margin-left: 2em">明朱得之撰得之有宵練匣已著錄此書以爲莊</span>  
<span style="margin-left: 2em">子之書命辭跌宕設喻險竒人多謂其荒唐謬悠</span>  
<span style="margin-left: 2em">不知異者辭也不異者道也故爲作通義并加旁</span>  
<span style="margin-left: 2em">註以詳釋之先是宋咸淳間錢塘道士褚伯秀嘗</span>  
<span style="margin-left: 2em">作義海纂微未行於世王潼錄其遺稿以授得之</span>  
<span style="margin-left: 2em">得之因附刻於每叚之下先列通義次及義海前</span>  
<span style="margin-left: 2em">有得之自序案伯秀義海纂微採掇詳博今原本</span>  
<span style="margin-left: 2em">尙存已著於錄得之所解議論陳因殊無可採至</span>  
<span style="margin-left: 2em">於評論文格動至連篇累牘尤冗蔓無謂矣</span>  
<!-- 册3 葉4432b　Page:文淵閣四庫全書_0003冊.djvu/1113 -->
解莊十二卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明陶望齡撰望齡字周望號石簣會稽人萬厯癸</span>  
<span style="margin-left: 2em">丑進士官至國子監祭酒諡文簡事迹附見明史</span>  
<span style="margin-left: 2em">唐文獻傳是編僅寥寥數則歸安茅兆河取與郭</span>  
<span style="margin-left: 2em">正域所評合刻之均無所發明</span>
