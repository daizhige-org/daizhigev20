## 欽定四庫全書總目 卷首一　聖諭

欽定四庫全書總目卷首一  
聖諭  
<span style="margin-left: 2em">乾隆三十七年正月初四日奉</span>  
上諭朕稽古右文聿資治理幾餘典學日有孜孜因思  
<span style="margin-left: 1em">策府縹緗載籍極博其鉅者羽翼經訓垂範方來固</span>  
<span style="margin-left: 1em">足稱千秋法鑒卽在識小之徒專門撰述細及名物</span>  
<span style="margin-left: 1em">象數兼綜條貫各自成家亦莫不有所發明可爲游</span>  
<span style="margin-left: 1em">藝養心之一助是以御極之初卽詔中外搜訪遺書</span>  
<span style="margin-left: 1em">並令儒臣校勘十三經二十一史徧布黌宫嘉惠後</span>  
<!-- 册1 葉5b　Page:文淵閣四庫全書_0001冊.djvu/51 -->
<span style="margin-left: 1em">學復開館纂修綱目三編通鑑輯覽及三通諸書凡</span>  
<span style="margin-left: 1em">藝林承學之士所當戸誦家<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3500.svg?width=24" alt="四庫全書僻字第3500號（「絃」字少最後一點）" title="四庫全書僻字第3500號（「絃」字少最後一點）">者旣已薈萃各備第</span>  
<span style="margin-left: 1em">念讀書固在得其要領而多識前言往行以蓄其德</span>  
<span style="margin-left: 1em">惟蒐羅益廣則研討愈精如康熙年間所修圖書集</span>  
<span style="margin-left: 1em">成全部兼收並錄極方策之大觀引用諸編率屬因</span>  
<span style="margin-left: 1em">類取裁𫝑不能悉載全文使閱者沿流溯源一一徵</span>  
<span style="margin-left: 1em">其來處今内府藏書插架不爲不富然古今來著作</span>  
<span style="margin-left: 1em">之手無慮數千百家或逸在名山未登柱史正宜及</span>  
<span style="margin-left: 1em">時採集彚送京師以彰千古同文之盛其令直省督</span>  
<!-- 册1 葉8a　Page:文淵閣四庫全書_0001冊.djvu/52 -->
<span style="margin-left: 1em">撫學政等通飭所屬加意購訪除坊肆所售舉業時</span>  
<span style="margin-left: 1em">文及民間無用之族譜尺牘屏幛壽言等類又其人</span>  
<span style="margin-left: 1em">本無實學不過嫁名馳騖編刻酬倡詩文𤨏屑無當</span>  
<span style="margin-left: 1em">者均無庸採取其厯代流傳舊書内有闡明性學治</span>  
<span style="margin-left: 1em">法關繫世道人心者自當首先購覔至若發揮傳注</span>  
<span style="margin-left: 1em">攷覈典章旁曁九流百家之言有裨實用者亦應備</span>  
<span style="margin-left: 1em">爲甄擇又如厯代名人洎本朝士林宿望向有詩文</span>  
<span style="margin-left: 1em">專集及近時沈潛經史原本風雅如顧棟高陳祖范</span>  
<span style="margin-left: 1em">任啟運沈德潛輩亦各著成編並非勦說卮言可比</span>  
<!-- 册1 葉8b　Page:文淵閣四庫全書_0001冊.djvu/52 -->
<span style="margin-left: 1em">均應槪行查明在坊肆者或量爲給價家藏者或官</span>  
<span style="margin-left: 1em">爲裝印其有未經鐫刊祇係抄本存留者不妨繕錄</span>  
<span style="margin-left: 1em">副本仍將原書給還並嚴飭所屬一切善爲經理毋</span>  
<span style="margin-left: 1em">使吏胥藉端滋擾但各省蒐輯之書卷帙必多若不</span>  
<span style="margin-left: 1em">加之鑑别悉令呈送煩複皆所不免著該督撫等先</span>  
<span style="margin-left: 1em">將各書敘列目錄注係某朝某人所著書中要旨何</span>  
<span style="margin-left: 1em">在簡明開載具摺奏聞候彚齊後令廷臣撿覈有堪</span>  
<span style="margin-left: 1em">備閱者再開單行知取進庶幾副在石渠用儲乙覽</span>  
<span style="margin-left: 1em">從此四庫七畧益昭美備稱朕意焉欽此</span>  
<!-- 册1 葉9a　Page:文淵閣四庫全書_0001冊.djvu/52 -->
<span style="margin-left: 2em">乾隆三十八年二月初六日奉</span>  
旨軍機大臣議覆朱筠條奏内將永樂大典擇取繕寫  
<span style="margin-left: 1em">各自爲書一節議請分派各館修書翰林等官前往</span>  
<span style="margin-left: 1em">檢查恐責成不專徒致歲月久稽汗靑無日葢此書</span>  
<span style="margin-left: 1em">移貯年久旣多殘缺又原編體例係分韻類次先巳</span>  
<span style="margin-left: 1em">割裂全文首尾難期貫串特因當時採摭甚博其中</span>  
<span style="margin-left: 1em">或有古書善本世不恒見今就各門彚訂可以湊合</span>  
<span style="margin-left: 1em">成部者亦足廣名山石室之藏著卽派軍機大臣爲</span>  
<span style="margin-left: 1em">總裁官仍於翰林等官内選定員數責令及時專司</span>  
<!-- 册1 葉9b　Page:文淵閣四庫全書_0001冊.djvu/52 -->
<span style="margin-left: 1em">查校將原書詳細檢閱並將圖書集成互爲校覈擇</span>  
<span style="margin-left: 1em">其未經採錄而實在流傳已久尚可裒綴成編者先</span>  
<span style="margin-left: 1em">行摘開目錄奏聞候朕裁定其應如何酌定規條卽</span>  
<span style="margin-left: 1em">著派出之大臣詳悉議奏至朱筠所奏每書必校其</span>  
<span style="margin-left: 1em">得失撮舉大旨敘於本書卷首之處若欲悉仿劉向</span>  
<span style="margin-left: 1em">校書序錄成規未免過於繁冗但向閱内府所貯康</span>  
<span style="margin-left: 1em">熙年間舊藏書籍多有摘敘簡明畧節附夾本書之</span>  
<span style="margin-left: 1em">内者於檢查洵爲有益應俟移取各省購書全到時</span>  
<span style="margin-left: 1em">卽令承辦各員將書中要指櫽括總敘厓畧粘開卷</span>  
<!-- 册1 葉12a　Page:文淵閣四庫全書_0001冊.djvu/53 -->
<span style="margin-left: 1em">副頁右方用便觀覽餘依議欽此</span>  
<span style="margin-left: 2em">乾隆三十八年二月十一日奉</span>  
上諭昨據軍機大臣議覆朱筠條奏校核永樂大典一  
<span style="margin-left: 1em">摺已降旨派軍機大臣爲總裁揀選翰林等官詳定</span>  
<span style="margin-left: 1em">條規酌量辦理兹檢閱原書卷首序文其言採掇蒐</span>  
<span style="margin-left: 1em">羅頗稱浩博謂足津逮四庫及攷之書中别部區函</span>  
<span style="margin-left: 1em">編韻分字意在貪多務得不岀類書窠臼是以蹖駁</span>  
<span style="margin-left: 1em">乖離於體例未能允協卽如所用韻次不依唐宋舊</span>  
<span style="margin-left: 1em">部惟以洪武正韻爲斷巳覺凌雜不倫况經訓爲羣</span>  
<!-- 册1 葉12b　Page:文淵閣四庫全書_0001冊.djvu/53 -->
<span style="margin-left: 1em">籍根源乃因各韻轇轕於易先列𫎇卦於詩先列大</span>  
<span style="margin-left: 1em">東於周禮先列冬官且採用各字不論易書詩禮春</span>  
<span style="margin-left: 1em">秋之序前後錯互甚至載入六書篆𨽻眞草字樣摭</span>  
<span style="margin-left: 1em">拾米芾趙孟頫字格描頭畫角支離無謂至儒書之</span>  
<span style="margin-left: 1em">外闌入釋典道經於古柱下史專掌藏書守先待後</span>  
<span style="margin-left: 1em">之義尤爲鑿枘不合朕意從來四庫書目以經史子</span>  
<span style="margin-left: 1em">集爲綱領裒輯分儲實古今不易之法是書旣遺編</span>  
<span style="margin-left: 1em">淵海若準此以採擷所登用廣石渠金匱之藏較爲</span>  
<span style="margin-left: 1em">有益著再添派王際華裘日修爲總裁官卽令同遴</span>  
<!-- 册1 葉13a　Page:文淵閣四庫全書_0001冊.djvu/53 -->
<span style="margin-left: 1em">簡分校各員悉心酌定條例將永樂大典詳悉校核</span>  
<span style="margin-left: 1em">除本係現在通行及雖屬古書而詞義無關典要者</span>  
<span style="margin-left: 1em">不必再行採錄外其有實在流傳已少其書足資啟</span>  
<span style="margin-left: 1em">牖後學廣益多聞者卽將書名摘出撮取著書大㫖</span>  
<span style="margin-left: 1em">敘列目錄進呈俟朕裁定彚付剞劂其中有書無可</span>  
<span style="margin-left: 1em">採而其名未可盡滅者祗須注出簡明畧節以佐流</span>  
<span style="margin-left: 1em">傳考訂之用不必將全部付梓副朕裨補闕遺嘉惠</span>  
<span style="margin-left: 1em">士林至意再是書卷帙如此繁重而明代蕆役僅閱</span>  
<span style="margin-left: 1em">六年今諸臣從事釐輯更係棄多取少自當刻期告</span>  
<!-- 册1 葉13b　Page:文淵閣四庫全書_0001冊.djvu/53 -->
<span style="margin-left: 1em">竣不得任意稽延徒誚汗青無日仍將應定條例卽</span>  
<span style="margin-left: 1em">行詳議具奏欽此</span>  
<span style="margin-left: 2em">乾隆三十八年五月十七日奉</span>  
上諭前經降㫖博採遺編彚爲四庫全書用昭石渠美  
<span style="margin-left: 1em">備並以嘉惠藝林旋據浙江江南督撫及兩淮鹽政</span>  
<span style="margin-left: 1em">等奏到購求呈送之書已不下四五千種並有稱藏</span>  
<span style="margin-left: 1em">書家願將所有舊書呈獻者固屬踴躍奉公尚未能</span>  
<span style="margin-left: 1em">深喻朕意方今文治光昭典籍大備恐名山石室儲</span>  
<span style="margin-left: 1em">蓄尚多用是廣爲蒐輯俾無遺佚冀以闡疑補闕所</span>  
<!-- 册1 葉16a　Page:文淵閣四庫全書_0001冊.djvu/54 -->
<span style="margin-left: 1em">有進到各遺書並交總裁等同永樂大典内現有各</span>  
<span style="margin-left: 1em">種詳加核勘分别刊抄擇其中罕見之書有益於世</span>  
<span style="margin-left: 1em">道人心者壽之梨棗以廣流傳餘則選派謄錄彚繕</span>  
<span style="margin-left: 1em">成編陳之冊府其中有俚淺訛謬者止存書名彚爲</span>  
<span style="margin-left: 1em">總目以彰右文之盛此採擇四庫全書本指也今外</span>  
<span style="margin-left: 1em">省進到之書大小長短參差不一旣無當於編列縹</span>  
<span style="margin-left: 1em">緗而業已或刻或抄其原書又何必復留内府且伊</span>  
<span style="margin-left: 1em">等將珍藏善本應詔彚交深爲可嘉若因此收藏不</span>  
<span style="margin-left: 1em">發轉使耽書明理之人不得保其世守於理未爲公</span>  
<!-- 册1 葉16b　Page:文淵閣四庫全書_0001冊.djvu/54 -->
<span style="margin-left: 1em">允朕豈肯爲之所有各家進到之書俟校辦完竣日</span>  
<span style="margin-left: 1em">仍行給還原獻之家但現在各省所進書籍巳屬不</span>  
<span style="margin-left: 1em">少嗣後自必陸續加多其如何分别標記俾還本人</span>  
<span style="margin-left: 1em">不致淆混遺失之處著該總裁等妥議具奏仍將此</span>  
<span style="margin-left: 1em">通諭知之欽此</span>  
<span style="margin-left: 2em">乾隆三十八年八月二十五日奉</span>  
上諭辦理四庫全書處將永樂大典内檢出各書陸續  
<span style="margin-left: 1em">進呈朕親加披閱間予題評見其考訂分排具有條</span>  
<span style="margin-left: 1em">理而撰述提要粲然可觀則成於紀昀陸錫熊之手</span>  
<!-- 册1 葉17a　Page:文淵閣四庫全書_0001冊.djvu/54 -->
<span style="margin-left: 1em">二人學問本優校書亦極勤勉甚屬可嘉紀昀曾任</span>  
<span style="margin-left: 1em">學士陸錫熊現任郞中均著授爲翰林院侍讀遇缺</span>  
<span style="margin-left: 1em">卽補以示奬勵欽此</span>  
<span style="margin-left: 2em">乾隆三十九年五月十四日奉</span>  
上諭國家當文治休明之會所有古今載籍宜及時蒐  
<span style="margin-left: 1em">羅大備以光冊府而裨藝林因降㫖命各督撫加意</span>  
<span style="margin-left: 1em">採訪彚上於朝旋據各省陸續奏送而江浙兩省藏</span>  
<span style="margin-left: 1em">書家呈獻種數尤多廷臣中亦有紛紛奏進者因命</span>  
<span style="margin-left: 1em">詞臣分别校勘應刊應錄以廣流傳其進書百種以</span>  
<!-- 册1 葉17b　Page:文淵閣四庫全書_0001冊.djvu/54 -->
<span style="margin-left: 1em">上者並命擇其中精醇之本進呈乙覽朕幾餘親爲</span>  
<span style="margin-left: 1em">評詠題識簡端復命將進到各書於篇首用翰林院</span>  
<span style="margin-left: 1em">印並加鈐記載明年月姓名於書面頁俟將來辦竣</span>  
<span style="margin-left: 1em">後仍給還各本家自行收藏其已經題詠諸本並令</span>  
<span style="margin-left: 1em">書館先行錄副將原書發還俾收藏之人益增榮幸</span>  
<span style="margin-left: 1em">今閱進到各家書目其最多者如浙江鮑士恭范懋</span>  
<span style="margin-left: 1em">柱汪啟淑兩淮之馬裕四家爲數至五六七百種皆</span>  
<span style="margin-left: 1em">其累世弆藏子孫克守其業甚可嘉尚因思内府所</span>  
<span style="margin-left: 1em">有古今圖書集成爲書城鉅觀人間罕覯此等世守</span>  
<!-- 册1 葉20a　Page:文淵閣四庫全書_0001冊.djvu/55 -->
<span style="margin-left: 1em">陳編之家宜俾專藏勿失以示留貽鮑士恭范懋柱</span>  
<span style="margin-left: 1em">汪啟淑馬裕四家著賞古今圖書集成各一部以爲</span>  
<span style="margin-left: 1em">好古之勸又如進呈一百種以上之江蘇周厚堉蔣</span>  
<span style="margin-left: 1em">曾瑩浙江吳玉墀孫仰曾汪汝瑮以及朝紳中黃登</span>
