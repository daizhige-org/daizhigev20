## 欽定四庫全書總目 卷一百九十四　集部四十七　總集類存目四

欽定四庫全書總目卷一百九十四  
<span style="margin-left: 1em">集部四十七</span>  
<span style="margin-left: 2em">總集𩔖存目四</span>  
蕭氏世集<sub class="note-yuan">無卷數　山東巡撫採進本</sub>  
<span style="margin-left: 1em">國朝蕭伯升編伯升字孟昉泰和人是集皆錄其先</span>  
<span style="margin-left: 2em">世詩文日正周先生集詩文各一卷蕭岐撰岐字</span>  
<span style="margin-left: 2em">尚仁洪武初以賢良徵授潭府左長史改平凉訓</span>  
<span style="margin-left: 2em">導自顔其齋曰正固一日坦行自誌岐子遵撰遵</span>  
<span style="margin-left: 2em">字用道號坦行以明經薦授靖江王府長史永樂</span>  
<!-- 册5 葉757b　Page:文淵閣四庫全書_0005冊.djvu/194 -->
<span style="margin-left: 2em">間謫宣府鷂兒嶺巡檢有仕學齋集散佚不存獨</span>  
<span style="margin-left: 2em">存其自誌所載陳靖江王八啟及四門箴一篇曰</span>  
<span style="margin-left: 2em">雪崖詩集蕭晅撰晅字仰善號雪崖宣德丁未進</span>  
<span style="margin-left: 2em">士官南京禮部尚書前有伯升自序稱與吏部郞</span>  
<span style="margin-left: 2em">中蕭士瑋春浮園集并士瑋弟士𤦺陶庵雜記牘</span>  
<span style="margin-left: 2em">雋諸書同時合刻爲蕭氏世集今士瑋士𤦺之書</span>  
<span style="margin-left: 2em">各有別本而此帙之内均不載未知何故也</span>  
太倉十子詩選十卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝吳偉業編偉業有綏㓂紀畧已著錄是書採其</span>  
<!-- 册5 葉760a　Page:文淵閣四庫全書_0005冊.djvu/195 -->
<span style="margin-left: 2em">同里能詩者得十人人各一集首周肇東岡集次</span>  
<span style="margin-left: 2em">王揆芝㕓集次許旭秋水集次黃與堅忍菴集次</span>  
<span style="margin-left: 2em">王撰三餘集次王昊頋園集次王抃健菴集次王</span>  
<span style="margin-left: 2em">曜升東臯集次顧湄水鄉集次王攄步蟾集皆其</span>  
<span style="margin-left: 2em">同時之人前有偉業序葢猶明季詩社餘風也偉</span>  
<span style="margin-left: 2em">業本工詩故其所別裁猶不至如他家之冗濫特</span>  
<span style="margin-left: 2em">風格如出一手不免域於流派是亦宗一先生之</span>  
<span style="margin-left: 2em">故耳</span>  
樂府英華十卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<!-- 册5 葉760b　Page:文淵閣四庫全書_0005冊.djvu/195 -->
<span style="margin-left: 1em">國朝顧有孝編有孝字茂倫吳江人自序稱自漢迄</span>  
<span style="margin-left: 2em">唐樂府有數十家而最著者郭茂倩之樂苑<sub class="note-yuan">案郭茂倩</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">書名樂府詩集不名樂苑名樂苑者乃梅鼎祚書</sub>左克明之樂府吳兢之</span>  
<span style="margin-left: 2em">樂錄<sub class="note-yuan">案吳兢書名樂府古題要解不名樂錄</sub>郄昂之題解沈建之廣</span>  
<span style="margin-left: 2em">題徐獻忠之樂府各有意見因取而參定之然所</span>  
<span style="margin-left: 2em">分各𩔖亦多踵茂倩舊目於體製無所考訂惟每</span>  
<span style="margin-left: 2em">章下略加註釋而附以評語葢其例主於選詩與</span>  
<span style="margin-left: 2em">吳郭諸家用意各不同也</span>  
同人集十二卷<sub class="note-yuan">兩江總督採進本</sub>  
<!-- 册5 葉761a　Page:文淵閣四庫全書_0005冊.djvu/195 -->
<span style="margin-left: 1em">國朝冒襄編襄字辟疆如臯人自號巢民所居有樸</span>  
<span style="margin-left: 2em">巢水繪園深翠山房諸勝晩年却掃家居與友朋</span>  
<span style="margin-left: 2em">觴詠輯其酬答詩文都爲一集凡十二卷葢仿顧</span>  
<span style="margin-left: 2em">阿瑛玉山草堂雅集而作然阿瑛但文酒之歡此</span>  
<span style="margin-left: 2em">併其壽序之𩔖亦皆載入故繁富勝之而精美則</span>  
<span style="margin-left: 2em">不及焉</span>  
唐宫閨詩二卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 1em">國朝費宻編宻有燕峯文抄已著錄是編錄唐代女</span>  
<span style="margin-left: 2em">子之作頗有別裁然皆習見</span>  
<!-- 册5 葉761b　Page:文淵閣四庫全書_0005冊.djvu/195 -->
牘雋四卷<sub class="note-yuan">兵部侍郞紀昀家藏本</sub>  
<span style="margin-left: 1em">國朝蕭士𤦺撰士𤦺字季公泰和人前明貢生是編</span>  
<span style="margin-left: 2em">選自漢至宋尺牘分三十二門卷首有其子伯升</span>  
<span style="margin-left: 2em">所記緣起大㫖主於淸省故所錄往往摘一二語</span>  
<span style="margin-left: 2em">非其全文又如龔使者告隗照妻一條原非尺牘</span>  
<span style="margin-left: 2em">而亦載之殊不可解也</span>  
斯文正統十二卷<sub class="note-yuan">直𨽻總督採進本</sub>  
<span style="margin-left: 1em">國朝刁包編包有易酌已著錄是編所錄厯代諸儒</span>  
<span style="margin-left: 2em">之文凡二百一十有六篇其凡例稱專以品行爲</span>  
<!-- 册5 葉764a　Page:文淵閣四庫全書_0005冊.djvu/196 -->
<span style="margin-left: 2em">主若言是人非雖絶技無取蓋本眞德秀文章正</span>  
<span style="margin-left: 2em">宗之例持論可云嚴正然三代以前文皆載道三</span>  
<span style="margin-left: 2em">代以後流派漸分猶之衣資布帛不能廢五采之</span>  
<span style="margin-left: 2em">華食主菽粟不能廢八珍之味必欲一掃而空之</span>  
<span style="margin-left: 2em">於理甚正而於事必不能行卽如文章正宗行世</span>  
<span style="margin-left: 2em">已久究不能盡廢諸集其𫝑然也至蘇軾大悲閣</span>  
<span style="margin-left: 2em">四大菩薩諸記因題製文原非講學言各有當義</span>  
<span style="margin-left: 2em">豈一端而包於歐陽修本論評語中極詞詆斥然</span>  
<span style="margin-left: 2em">則眞德秀西山集中爲二氏而作者不知凡幾包</span>  
<!-- 册5 葉764b　Page:文淵閣四庫全書_0005冊.djvu/196 -->
<span style="margin-left: 2em">旣講學不應不見是集何以置之不言豈非以蘇</span>  
<span style="margin-left: 2em">氏爲程子之敵眞氏則朱子之徒乎恐未足服軾</span>  
<span style="margin-left: 2em">之心也</span>  
樂府廣序三十卷<sub class="note-yuan">編修勵守謙家藏本</sub>  
<span style="margin-left: 1em">國朝朱嘉徵編嘉徵字岷左別號止谿圃人海寧人</span>  
<span style="margin-left: 2em">前明崇禎壬午舉人入</span>  
<span style="margin-left: 1em">國朝官徽州府推官此編取漢魏樂府及詩分爲三</span>  
<span style="margin-left: 2em">集以相和吟嘆平調淸調瑟調楚調大曲雜曲之</span>  
<span style="margin-left: 2em">𩔖爲風以鼓吹橫吹之𩔖爲雅以雅舞雜舞之𩔖</span>  
<!-- 册5 葉765a　Page:文淵閣四庫全書_0005冊.djvu/196 -->
<span style="margin-left: 2em">爲變雅以郊祀樂章爲頌而別附以歌詩琴曲又</span>  
<span style="margin-left: 2em">仿詩序之例每篇各爲小序以明其意葢刻意續</span>  
<span style="margin-left: 2em">經惟恐一毫之不似然三代樂制至漢盡亡樂府</span>  
<span style="margin-left: 2em">之於三百篇猶阡陌之於井田郡縣之於封建也</span>  
<span style="margin-left: 2em">端緖亦有時相屬而不相屬者十之九嘉徵必摹</span>  
<span style="margin-left: 2em">擬刻畫一以風雅頌分配之牽强支離固其所矣</span>  
三蘇談十卷<sub class="note-yuan">兵部侍郞紀昀家藏本</sub>  
<span style="margin-left: 1em">國朝高阜撰阜字康生號蘿栖祥符人所錄凡蘇洵</span>  
<span style="margin-left: 2em">文二卷蘇軾文六卷蘇轍文二卷每篇爲之反覆</span>  
<!-- 册5 葉765b　Page:文淵閣四庫全書_0005冊.djvu/196 -->
<span style="margin-left: 2em">詳論故名曰三蘇談其言瀾翻不竭亦足以自暢</span>  
<span style="margin-left: 2em">其說然必謂三蘇本㫖如是則不盡然也</span>  
柳洲詩集十卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝陳增新等編增新字子更嘉善人柳洲在嘉善</span>  
<span style="margin-left: 2em">熙寧門外順治初增新與同里魏學渠等結詩社</span>  
<span style="margin-left: 2em">相倡和稱柳洲八子其後攀附者日衆因遴次所</span>  
<span style="margin-left: 2em">作錄爲一編共七十餘人其詩體格相似大抵五</span>  
<span style="margin-left: 2em">言多宗選體七言悉學唐音猶明季幾社餘派也</span>  
江左十五子詩選十五卷<sub class="note-yuan">内府藏本</sub>  
<!-- 册5 葉768a　Page:文淵閣四庫全書_0005冊.djvu/197 -->
<span style="margin-left: 1em">國朝宋犖編犖有滄浪小志已著錄是編乃犖爲蘇</span>  
<span style="margin-left: 2em">州巡撫時甄別境内能文之士王式丹等十五人</span>  
<span style="margin-left: 2em">各選詩一卷刻之考自古𩔖舉數人共爲標目四</span>  
<span style="margin-left: 2em">八之所載其來久矣然文士則無是名也文士之</span>  
<span style="margin-left: 2em">有是名實胚胎於建安之七子厯代沿波至明代</span>  
<span style="margin-left: 2em">而前後七子廣續五子之𩔖或分壘交攻或置棊</span>  
<span style="margin-left: 2em">不定而泛濫斯極往往以聲氣之標榜釀爲朋黨</span>  
<span style="margin-left: 2em">之傾軋覆轍可厯厯數也犖與王士禎並以文章</span>  
<span style="margin-left: 2em">宿老領袖詩壇士禎旣以同時之人爲十子詩選</span>  
<!-- 册5 葉768b　Page:文淵閣四庫全書_0005冊.djvu/197 -->
<span style="margin-left: 2em">犖亦以所㧞之士編爲此集雖奬成後進原不失</span>  
<span style="margin-left: 2em">爲君子之用心究未免前明詩社之習也夫諸人</span>  
<span style="margin-left: 2em">詩儻不佳裒刻何益其詩果佳則人人各足以自</span>  
<span style="margin-left: 2em">傅又何必藉此品題乎</span>  
溯洄集十卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 1em">國朝魏裔介撰裔介有孝經注義已著錄裔介嘗選</span>  
<span style="margin-left: 1em">國初詩爲觀始集今未見傳本是編乃所選康熙中</span>  
<span style="margin-left: 2em">詩以續前集者也意求備一時之人故限於卷帙</span>  
<span style="margin-left: 2em">不能備一人之詩大抵一人三數首而已惟每體</span>  
<!-- 册5 葉769a　Page:文淵閣四庫全書_0005冊.djvu/197 -->
<span style="margin-left: 2em">之末必附以已作所收較他人爲夥則似不若待</span>  
<span style="margin-left: 2em">諸他人之論定焉</span>  
高言集四卷<sub class="note-yuan">江蘇周厚堉家藏本</sub>  
<span style="margin-left: 1em">國朝田茂遇董俞同編茂遇字髴淵順治戊子舉人</span>  
<span style="margin-left: 2em">俞字蒼水終於布衣皆華亭人是書題曰十五國</span>  
<span style="margin-left: 2em">風高言集而别標一閩字爲子目據其凡例乃以</span>  
<span style="margin-left: 2em">一省之詩爲一集此乃十五集中之一也</span>  
古文輯略<sub class="note-yuan">無卷數　湖北巡撫採進本</sub>  
<span style="margin-left: 1em">國朝曹本榮編本榮有奏議稽詢已著錄是書文以</span>  
<!-- 册5 葉769b　Page:文淵閣四庫全書_0005冊.djvu/197 -->
<span style="margin-left: 2em">體分各體前俱引文體明辨一條大槪因是書而</span>  
<span style="margin-left: 2em">廣之然所分子目冗瑣特甚舛誤尤多漢文帝賢</span>  
<span style="margin-left: 2em">良文學䇿問武帝賢良䇿問之𩔖亦往往一文而</span>  
<span style="margin-left: 2em">兩載皆失詳檢鐵券文𩔖止載唐德宗賜王武俊</span>  
<span style="margin-left: 2em">一篇諭祭文𩔖止載隋文帝祭薛濬一篇之𩔖亦</span>  
<span style="margin-left: 2em">殊挂漏至每篇刪削尤不免失其本來</span>  
臨川文獻八卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 1em">國朝胡亦堂編亦堂字二齊慈谿人順治辛卯舉人</span>  
<span style="margin-left: 2em">官臨川縣知縣後行取主事是編選臨川一縣之</span>  
<!-- 册5 葉772a　Page:文淵閣四庫全書_0005冊.djvu/198 -->
<span style="margin-left: 2em">文宋晏殊晏幾道王安石三人明章衮陳九川帥</span>  
<span style="margin-left: 2em">機湯顯祖邱兆麟章世純艾南英羅萬藻陳際泰</span>  
<span style="margin-left: 2em">揭重熙十人</span>  
<span style="margin-left: 1em">國朝游東昇傅占衡二人皆有集行世者每集各爲</span>  
<span style="margin-left: 2em">小序書中仍各標本集之名略如張溥百三家集</span>  
<span style="margin-left: 2em">例但溥書全錄其集此則多所刪削耳</span>  
詩原二十五卷<sub class="note-yuan">江蘇周厚堉家藏本</sub>  
<span style="margin-left: 1em">國朝顧大申撰大申有堪齋詩存已著錄是編以詩</span>  
<span style="margin-left: 2em">教起於三百降而屈宋則有王逸之章句漢魏六</span>  
<!-- 册5 葉772b　Page:文淵閣四庫全書_0005冊.djvu/198 -->
<span style="margin-left: 2em">朝則有昭明之文選三唐之詩則以明李攀龍之</span>  
<span style="margin-left: 2em">詩選爲能存唐聲於是總輯諸家裒爲一集一集</span>
