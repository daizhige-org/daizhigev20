## 欽定四庫全書總目 卷二十　經部二十　禮類二

<!-- 册1 葉1640：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷二十  
<span style="margin-left: 1em">經部二十</span>  
<span style="margin-left: 2em">禮類二</span>  
儀禮註疏十七卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">漢鄭元註唐賈公彥疏儀禮岀殘缺之餘漢代所</span>  
<span style="margin-left: 2em">傳凡有三本一曰戴德本以冠禮第一昏禮第二</span>  
<span style="margin-left: 2em">相見第三士喪第四旣夕第五士虞第六特牲第</span>  
<span style="margin-left: 2em">七少牢第八有司徹第九鄕飮酒第十鄕射第十</span>  
<span style="margin-left: 2em">一燕禮第十二大射第十三聘禮第十四公食第</span>  
<!-- 册1 葉1641b　Page:文淵閣四庫全書_0001冊.djvu/460 -->
<span style="margin-left: 2em">十五覲禮第十六喪服第十七一曰戴聖本亦以</span>  
<span style="margin-left: 2em">冠禮第一昏禮第二相見第三其下則鄕飮第四</span>  
<span style="margin-left: 2em">鄕射第五燕禮第六大射第七士虞第八喪服第</span>  
<span style="margin-left: 2em">九特牲第十少牢第十一有司徹第十二士喪第</span>  
<span style="margin-left: 2em">十三旣夕第十四聘禮第十五公食第十六覲禮</span>  
<span style="margin-left: 2em">第十七一曰劉向别錄本卽鄭氏所註賈公彥疏</span>  
<span style="margin-left: 2em">謂别錄尊卑吉凶次第倫序故鄭用之二戴尊卑</span>  
<span style="margin-left: 2em">吉凶雜亂故鄭不從之也其經文亦有二本高堂</span>  
<span style="margin-left: 2em">生所傳者謂之今文魯恭王壞孔子宅得古儀禮</span>  
<!-- 册1 葉1644a　Page:文淵閣四庫全書_0001冊.djvu/461 -->
<span style="margin-left: 2em">五十六篇其字皆以篆書之謂之古文元註㕘用</span>  
<span style="margin-left: 2em">二本其從今文而不從古文者則今文大書古文</span>  
<span style="margin-left: 2em">附註士冠禮闑西閾外句註古文闑爲𣙗閾爲蹙</span>  
<span style="margin-left: 2em">是也從古文而不從今文者則古文大書今文附</span>  
<span style="margin-left: 2em">註士冠禮醴辭孝友時格句註今文格爲嘏是也</span>  
<span style="margin-left: 2em">其書自元以前絶無註本元後有王肅注十七卷</span>  
<span style="margin-left: 2em">見於隋志然賈公彥序稱周禮註者則有多門儀</span>  
<span style="margin-left: 2em">禮所註後鄭而巳則唐初肅書巳佚也爲之義疏</span>  
<span style="margin-left: 2em">者有沈重見於北史又有無名氏二家見於隋志</span>  
<!-- 册1 葉1644b　Page:文淵閣四庫全書_0001冊.djvu/461 -->
<span style="margin-left: 2em">然皆不傳故賈公彥僅據齊黃慶隋李孟悊二家</span>  
<span style="margin-left: 2em">之疏定爲今本其書自明以來刻本舛訛殊甚顧</span>  
<span style="margin-left: 2em">炎武日知錄曰萬厯北監本十三經中儀禮脫誤</span>  
<span style="margin-left: 2em">尤多士昏禮脫壻授綏姆辭曰未教不足與爲禮</span>  
<span style="margin-left: 2em">也一節十四字賴有長安石經據以補此一節而</span>  
<span style="margin-left: 2em">其注疏遂亡鄕射禮脫士鹿中翿旌以𫉬七字士</span>  
<span style="margin-left: 2em">虞禮脫哭止告事畢實出七字特牲饋食禮脫舉</span>  
<span style="margin-left: 2em">觶者祭卒觶拜長者答拜十一字少牢饋食禮脫</span>  
<span style="margin-left: 2em">以授尸至取簞興七字此則秦火之所未亡而亡</span>  
<!-- 册1 葉1645a　Page:文淵閣四庫全書_0001冊.djvu/461 -->
<span style="margin-left: 2em">於監刻矣云云葢由儀禮文古義奥傳習者少註</span>  
<span style="margin-left: 2em">釋者亦代不數人寫刻有訛猝不能校故紕漏至</span>  
<span style="margin-left: 2em">於如是也今㕘考諸本一一釐正著於錄焉</span>  
儀禮識誤三卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋張淳撰淳字忠甫永嘉人是書乃乾道八年兩</span>  
<span style="margin-left: 2em">浙轉運判官直秘閣曾逮刋儀禮鄭氏注十七卷</span>  
<span style="margin-left: 2em">陸氏釋文一卷淳爲之校定因舉所改字句彚爲</span>  
<span style="margin-left: 2em">一編其所引據有周廣順三年及顯德六年刋行</span>  
<span style="margin-left: 2em">之監本有汴京之巾箱本杭之細字本嚴之重刋</span>  
<!-- 册1 葉1645b　Page:文淵閣四庫全書_0001冊.djvu/461 -->
<span style="margin-left: 2em">巾箱本㕘以陸氏釋文賈氏疏覈訂異同最爲詳</span>  
<span style="margin-left: 2em">審近世久無傳本故朱彝尊經義考以爲巳佚惟</span>  
<span style="margin-left: 2em">永樂大典所載諸條猶散附經文之後可以綴錄</span>  
<span style="margin-left: 2em">成編其鄕射大射二篇適在永樂大典缺卷中則</span>  
<span style="margin-left: 2em">不可復考矣朱子語錄有曰儀禮士所罕讀難得</span>  
<span style="margin-left: 2em">善本而鄭註賈疏之外先儒舊說多不復見陸氏</span>  
<span style="margin-left: 2em">釋文亦甚疎畧近世永嘉張淳忠甫校定又爲一</span>  
<span style="margin-left: 2em">書以識其誤號爲精宻然亦不能無舛謬又曰張</span>  
<span style="margin-left: 2em">忠甫所校儀禮甚子細較他本爲最勝今觀其書</span>  
<!-- 册1 葉1648a　Page:文淵閣四庫全書_0001冊.djvu/462 -->
<span style="margin-left: 2em">株守釋文往往以習俗相沿之字轉改六書正經</span>  
<span style="margin-left: 2em">則朱子所謂不能無舛謬者誠所未免然是書存</span>  
<span style="margin-left: 2em">而古經漢注之訛文脫句藉以考識舊槧諸本之</span>  
<span style="margin-left: 2em">不傳於今者亦藉以得見崖畧其有功於儀禮誠</span>  
<span style="margin-left: 2em">匪淺小今覆加檢勘各疏明其得失俾瑜瑕不相</span>  
<span style="margin-left: 2em">揜原本殘缺數處亦考訂補輯附於下方其書宋</span>  
<span style="margin-left: 2em">史藝文志作一卷而陳振孫書錄解題作三卷考</span>  
<span style="margin-left: 2em">淳自序言裒所校之字次爲二卷以釋文誤字爲</span>  
<span style="margin-left: 2em">一卷附其後總爲三卷則宋志一卷爲傳寫之誤</span>  
<!-- 册1 葉1648b　Page:文淵閣四庫全書_0001冊.djvu/462 -->
<span style="margin-left: 2em">明矣今仍釐爲三卷存其舊焉</span>  
儀禮集釋三十卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋李如圭撰如圭字寶之廬陵人官至福建路撫</span>  
<span style="margin-left: 2em">幹案文獻通考引宋中興藝文志曰儀禮旣廢學</span>  
<span style="margin-left: 2em">者不復誦習乾道間有張淳始訂其訛爲儀禮識</span>  
<span style="margin-left: 2em">誤淳熙中李如圭爲集釋出入經傳又爲綱目以</span>  
<span style="margin-left: 2em">别章句之指爲釋宫以論宫室之制朱熹常與之</span>  
<span style="margin-left: 2em">校定禮書葢習於禮者云云則如圭當與朱子同</span>  
<span style="margin-left: 2em">時而陳振孫書錄解題言如圭淳熙癸丑進士文</span>  
<!-- 册1 葉1649a　Page:文淵閣四庫全書_0001冊.djvu/462 -->
<span style="margin-left: 2em">獻通考引振孫語又作紹興癸丑進士考淳熙紀</span>  
<span style="margin-left: 2em">元凡十六年中間實無癸丑紹興癸丑爲高宗改</span>  
<span style="margin-left: 2em">元之三年朱子校正儀禮乃在晩歲疑當爲紹熙</span>  
<span style="margin-left: 2em">癸丑陳氏馬氏各訛一字也宋自熙寧中廢罷儀</span>  
<span style="margin-left: 2em">禮學者鮮治是經如圭乃全錄鄭康成注而旁徵</span>  
<span style="margin-left: 2em">博引以爲之釋多發賈公彥疏所未備又撰綱目</span>  
<span style="margin-left: 2em">釋宫各一篇世無傳本故朱彝尊經義考俱云未</span>  
<span style="margin-left: 2em">見今從永樂大典錄出排纂成書十七篇中首尾</span>  
<span style="margin-left: 2em">完具者尚十五篇惟鄕射大射二篇在永樂大典</span>  
<!-- 册1 葉1649b　Page:文淵閣四庫全書_0001冊.djvu/462 -->
<span style="margin-left: 2em">缺卷内其綱目一篇亦缺無從考補姑仍其舊然</span>  
<span style="margin-left: 2em">巳得其十之九矣儀禮一經因治之者希經文併</span>  
<span style="margin-left: 2em">注往往訛脫如圭生於南宋尚見古本今據以校</span>  
<span style="margin-left: 2em">正補注疏本經文脫字二十四改訛字十四刪衍</span>  
<span style="margin-left: 2em">字十補注文脫字五百有三改訛字一百三十二</span>  
<span style="margin-left: 2em">刪衍字一百六十九併㕘考唐石經及陸德明經</span>  
<span style="margin-left: 2em">典釋文張淳儀禮識誤及各本文句字體之殊應</span>  
<span style="margin-left: 2em">加辨證者不勝指數各附案語於下方其鄕射大</span>  
<span style="margin-left: 2em">射兩篇如圭之釋雖佚亦㕘取惠棟沈大成二家</span>  
<!-- 册1 葉1652a　Page:文淵閣四庫全書_0001冊.djvu/463 -->
<span style="margin-left: 2em">所校宋本證以唐石經本補經文脫字七改訛字</span>  
<span style="margin-left: 2em">四刪衍字二補註文脫字四十一改訛字三十九</span>  
<span style="margin-left: 2em">刪衍字十七以成儀禮之完帙如圭舊本本十七</span>  
<span style="margin-left: 2em">篇篇自爲卷其間文句稍繁者篇頁太多難於分</span>  
<span style="margin-left: 2em">帙今析之得三十卷其釋宮則仍自爲一書别著</span>  
<span style="margin-left: 2em">於錄焉</span>  
儀禮釋宮一卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋李如圭撰如圭旣爲儀禮集釋又爲是書以考</span>  
<span style="margin-left: 2em">論古人宫室之制仿爾雅釋宮條分臚序各引經</span>  
<!-- 册1 葉1652b　Page:文淵閣四庫全書_0001冊.djvu/463 -->
<span style="margin-left: 2em">記註疏㕘考證明如據顧命東西序東西夾東西</span>  
<span style="margin-left: 2em">房之文證寢廟之制異於明堂而不用鄭志成王</span>  
<span style="margin-left: 2em">時在鎬京宮室因文武不改作故制同諸侯之說</span>  
<span style="margin-left: 2em"><sub class="note-yuan">按鄭志此條見顧命孔疏</sub>又如大夫士東房西室之說雖仍舊</span>  
<span style="margin-left: 2em">註而據聘禮賓館於大夫士證其亦有右房據鄕</span>  
<span style="margin-left: 2em">飮酒及少牢饋食證大夫士亦有左房東房之稱</span>  
<span style="margin-left: 2em">與天子諸侯言左對右言東對西者同其辨析詳</span>  
<span style="margin-left: 2em">明深得經意發先儒之所未發大抵類此非以空</span>  
<span style="margin-left: 2em">言說禮者所能也考朱子大全集亦載其文與此</span>  
<!-- 册1 葉1653a　Page:文淵閣四庫全書_0001冊.djvu/463 -->
<span style="margin-left: 2em">大畧相同惟無序引宋中興藝文志稱朱子嘗與</span>  
<span style="margin-left: 2em">之較定禮書疑朱子固嘗錄如圭是篇而集朱子</span>  
<span style="margin-left: 2em">之文者遂疑爲朱子所撰取以入集猶蘇軾書劉</span>  
<span style="margin-left: 2em">禹錫語題姜秀才課冊遂誤編入軾集耳觀朱子</span>  
<span style="margin-left: 2em">儀禮經傳通解於鄕飮酒薦出自左房聘禮負右</span>  
<span style="margin-left: 2em">房皆但存賈疏與是篇所言不同是亦不出朱子</span>  
<span style="margin-left: 2em">之一證矣古者宫室皆有定制厯代屢更漸非其</span>  
<span style="margin-left: 2em">舊如序楹楣阿箱夾牖戸當榮當碑之屬讀儀禮</span>  
<span style="margin-left: 2em">者倘不能備知其處則於陳設之地進退之位俱</span>  
<!-- 册1 葉1653b　Page:文淵閣四庫全書_0001冊.djvu/463 -->
<span style="margin-left: 2em">不能知甚或以後世之規模臆測先王之度數殊</span>  
<span style="margin-left: 2em">失其眞是篇之作誠治儀禮者之圭臬也宋陳汶</span>  
<span style="margin-left: 2em">嘗序集釋刻之桂林郡學舍兼刻是篇今刻本不</span>  
<span style="margin-left: 2em">傳惟永樂大典内全錄其文别爲一卷題云李如</span>  
<span style="margin-left: 2em">圭儀禮釋官葢其所據猶爲宋本今據以錄出仍</span>  
<span style="margin-left: 2em">與集釋相輔其間字句與朱子本稍有異同似彼</span>  
<span style="margin-left: 2em">爲初藁此爲定本今悉從永樂大典所載以存如</span>  
<span style="margin-left: 2em">圭之舊焉</span>  
儀禮圖十七卷儀禮旁通圖一卷<sub class="note-yuan">内府藏本</sub>  
<!-- 册1 葉1656a　Page:文淵閣四庫全書_0001冊.djvu/464 -->
<span style="margin-left: 2em">宋楊復撰復字茂才號信齋福州人鄭逢辰爲江</span>  
<span style="margin-left: 2em">西漕以所撰儀禮經傳通解續獻於朝贈文林郞</span>  
<span style="margin-left: 2em">是書成於紹定元年戊子書錄解題謂成於淳熙</span>  
<span style="margin-left: 2em">中葢未核其自序也序稱彦陵趙彦肅作特牲少</span>  
<span style="margin-left: 2em">牢二禮圖質於朱子以爲更得冠昏圖及堂室制</span>  
<span style="margin-left: 2em">度更考之乃佳復因原本師意錄十七篇經文節</span>  
<span style="margin-left: 2em">取舊說疏通其意各詳其儀節陳設之方位繫之</span>  
<span style="margin-left: 2em">以圖凡二百有五又分宮廟門冕弁門牲鼎禮器</span>  
<span style="margin-left: 2em">門爲圖二十有五名儀禮旁通圖附於其後於是</span>  
<!-- 册1 葉1656b　Page:文淵閣四庫全書_0001冊.djvu/464 -->
<span style="margin-left: 2em">經可謂用心勤摯惟是讀儀禮者必明於古人宫</span>  
<span style="margin-left: 2em">室之制然後所位所陳揖讓進退不失其方故李</span>  
<span style="margin-left: 2em">如圭儀禮通釋朱子儀禮經傳通解皆特出釋宮</span>
