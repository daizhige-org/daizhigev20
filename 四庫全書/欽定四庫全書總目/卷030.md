## 欽定四庫全書總目 卷三十　經部三十　春秋類存目一

<!-- 册1 葉2416a　Page:文淵閣四庫全書_0001冊.djvu/654 -->
欽定四庫全書總目卷三十  
<span style="margin-left: 1em">經部三十</span>  
<span style="margin-left: 2em">春秋類存目一</span>  
左傳節文十五卷<sub class="note-yuan">兵部侍郎紀昀家藏本</sub>  
<span style="margin-left: 2em">舊本題宋歐陽修編明萬厯中刊板也取左傳之</span>  
<span style="margin-left: 2em">文畧爲删削每篇之首分標敘事議論詞令諸目</span>  
<span style="margin-left: 2em">又標神品能品眞品具品妙品諸名及章法句法</span>  
<span style="margin-left: 2em">字法諸字前有慶厯五年修自序序中稱胡安國</span>  
<span style="margin-left: 2em">春秋傳及眞德秀文章正宗是不足與辨矣</span>  
<!-- 册1 葉2416b　Page:文淵閣四庫全書_0001冊.djvu/654 -->
春秋道統二卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">是書僅分上下二卷而抄本細字乃八巨册不著</span>  
<span style="margin-left: 2em">撰人名氏惟冠以乾道八年晉江傅伯成序稱爲</span>  
<span style="margin-left: 2em">元祐間春秋博士劉絢質夫所作考陳振孫書錄</span>  
<span style="margin-left: 2em">解題載劉絢春秋傳無道統之名文獻通考作十</span>  
<span style="margin-left: 2em">二卷玉海作五卷與二卷之數亦不合又振孫稱</span>  
<span style="margin-left: 2em">所解明正簡切而此本並無解經之語止抄撮左</span>  
<span style="margin-left: 2em">氏傳間及公穀國語及畧採諸家一二條且不特</span>  
<span style="margin-left: 2em">傳文多所删節卽經文亦止摘錄一二字如明代</span>  
<!-- 册1 葉2417a　Page:文淵閣四庫全書_0001冊.djvu/654 -->
<span style="margin-left: 2em">坊本之標題宋人經說亦無此例序中以何休學</span>  
<span style="margin-left: 2em">連爲人名其陋已極又稱後之有功於春秋者有</span>  
<span style="margin-left: 2em">杜預林堯叟林堯叟在南宋中年伯成此序作於</span>  
<span style="margin-left: 2em">南宋之初何由得見且杜林合註是明末坊間所</span>  
<span style="margin-left: 2em">刻伯成又何由以杜林並稱乎又伯成慶元初爲</span>  
<span style="margin-left: 2em">太府丞寶慶初始加龍圖閣學士此序旣曰乾道</span>  
<span style="margin-left: 2em">八年壬辰是時伯成方舉進士何得先以龍圖閣</span>  
<span style="margin-left: 2em">學士結銜訛謬種種不可殫述僞書之拙無過是</span>  
<span style="margin-left: 2em">矣其卷首收藏諸印亦一手僞造不足信也</span>  
<!-- 册1 葉2417b　Page:文淵閣四庫全書_0001冊.djvu/654 -->
左氏君子例一卷詩如例一卷詩補遺一卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋李石撰石有方舟易學已著錄左氏春秋傳多</span>  
<span style="margin-left: 2em">有君子曰字林栗指爲劉歆所加其說無據<sub class="note-yuan">案栗說見</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">經義考所引</sub>石則以爲左氏傳有所謂君子曰者又有</span>  
<span style="margin-left: 2em">稱仲尼孔子曰者皆示後學以褒貶大法聖人作</span>  
<span style="margin-left: 2em">經之意義因錄爲例凡君子七十三條而以聖語</span>  
<span style="margin-left: 2em">三十二條附之皆無所發明又以左傳引詩不皆</span>  
<span style="margin-left: 2em">與今說詩者同因取所載一篇一句悉裒集而闡</span>  
<span style="margin-left: 2em">論之以蘄合於斷章取義之指凡一百六十八條</span>  
<!-- 册1 葉2420a　Page:文淵閣四庫全書_0001冊.djvu/655 -->
<span style="margin-left: 2em">名曰詩如例復採左傳所載筮詞歌謠三十八事</span>  
<span style="margin-left: 2em">名曰詩補遺於經義悉無大裨益特當南北宋間</span>  
<span style="margin-left: 2em">正說春秋者掊擊三傳之時而石獨篤志古學爲</span>  
<span style="margin-left: 2em">足尚耳舊載方舟集中石門人劉伯熊合爲一編</span>  
<span style="margin-left: 2em">題曰左氏諸例實非石之舊名今仍各標本目其</span>  
<span style="margin-left: 2em">文則與方舟易學仍歸諸方舟集中不更錄焉</span>  
春秋通論二卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">舊本題曰宋人撰不著名氏諸家書目亦不著錄</span>  
<span style="margin-left: 2em">其書統論周及列國大勢推其興廢之由周及魯</span>  
<!-- 册1 葉2420b　Page:文淵閣四庫全書_0001冊.djvu/655 -->
<span style="margin-left: 2em">齊晉宋衛鄭楚秦各爲一篇吳越共爲一篇皆捃</span>  
<span style="margin-left: 2em">拾舊文爲事後成敗之論每句𨽻事而各引傳以</span>  
<span style="margin-left: 2em">爲之注其言膚淺無所發明</span>  
春秋握奇圖一卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">金利鸞孫撰鸞孫字士貴旴江人前有自序稱握</span>  
<span style="margin-left: 2em">奇圖者春秋家之學也二百四十二年而該之萬</span>  
<span style="margin-left: 2em">八千言編年以爲經而列五伯内外諸侯以緯之</span>  
<span style="margin-left: 2em">縱取則年與事類衡切則國之本末具在乃各序</span>  
<span style="margin-left: 2em">事畧於其後一覽而思過半矣云云據其所言則</span>  
<!-- 册1 葉2421a　Page:文淵閣四庫全書_0001冊.djvu/655 -->
<span style="margin-left: 2em">此書所重在於年表今年表散佚祗存其論巳非</span>  
<span style="margin-left: 2em">鑾孫著書之本㫖不足取矣</span>  
春秋左傳句解三十五卷<sub class="note-yuan">兩淮馬𥙿家藏本</sub>  
<span style="margin-left: 2em">元朱申撰申有周禮句解已著錄是書惟解左傳</span>  
<span style="margin-left: 2em">不㕘以經文葢猶用杜預以前之本其一事而始</span>  
<span style="margin-left: 2em">末别見者各附注本文之下端委亦詳惟傳文頗</span>  
<span style="margin-left: 2em">有删節是其所短如隠公之首删惠公元配孟子</span>  
<span style="margin-left: 2em">一節則隠桓兄弟之故何自而明哉</span>  
春秋經疑問對二卷<sub class="note-yuan">永樂大典本</sub>  
<!-- 册1 葉2421b　Page:文淵閣四庫全書_0001冊.djvu/655 -->
<span style="margin-left: 2em">元黃復祖撰復祖字仲篪廬陵人元史仁宗皇慶</span>  
<span style="margin-left: 2em">三年復科舉法漢人南人第一塲明經經疑二間</span>  
<span style="margin-left: 2em">大學論語孟子中庸内岀題經義一道各治一經</span>  
<span style="margin-left: 2em">元統以後少變其程式易漢人南人第一塲四書</span>  
<span style="margin-left: 2em">爲本經復祖序云至正辛巳大科載復有經義之</span>  
<span style="margin-left: 2em">條卽元史志所謂變程式之時也其書以經傳之</span>  
<span style="margin-left: 2em">事同辭異者求其常變察其詳畧以經覈傳以傳</span>  
<span style="margin-left: 2em">考經以待舉子之問葢亦比事屬辭之遺意其大</span>  
<span style="margin-left: 2em">㫖則專爲塲屋進取而作故議論多而義理則踈</span>  
<!-- 册1 葉2424a　Page:文淵閣四庫全書_0001冊.djvu/656 -->
<span style="margin-left: 2em">焉</span>  
春秋合題著說三卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">元楊維楨撰維楨字廉夫號鐵崖山陰人泰定四</span>  
<span style="margin-left: 2em">年進士初署天台尹改錢清塲鹽司令轉建徳總</span>  
<span style="margin-left: 2em">管府推官擢江西儒學提舉未及上而兵亂遂不</span>  
<span style="margin-left: 2em">復仕放浪於詩酒歌無之間明初命修禮樂書旋</span>  
<span style="margin-left: 2em">以老病辭歸事迹具明史文苑傳案宋禮部貢舉</span>  
<span style="margin-left: 2em">條式崇寧貢舉令春秋義題聽於三傳解經處出</span>  
<span style="margin-left: 2em">靖康元年改止川正經出題紹興五年禮部議春</span>  
<!-- 册1 葉2424b　Page:文淵閣四庫全書_0001冊.djvu/656 -->
<span style="margin-left: 2em">秋正經詞語簡約比之五經爲畧問目所在易於</span>  
<span style="margin-left: 2em">周徧往往州郡間目重複甚多每遇程文鮮不相</span>  
<span style="margin-left: 2em">犯請仍聽於三傳解經處相兼出題元史選舉志</span>  
<span style="margin-left: 2em">所載元祐條例不言春秋出題之法以維楨是書</span>  
<span style="margin-left: 2em">考之葢亦以經文易複改爲合題明制春秋合題</span>  
<span style="margin-left: 2em">之法葢沿元舊也維楨自序曰春秋正變無定例</span>  
<span style="margin-left: 2em">故關合無定題筆削有微㫖故會通有微意初學</span>  
<span style="margin-left: 2em">者不知通活法以求義場屋中往往不得有司之</span>  
<span style="margin-left: 2em">意今以當合題凡若干各題著說使推其正變無</span>  
<!-- 册1 葉2425a　Page:文淵閣四庫全書_0001冊.djvu/656 -->
<span style="margin-left: 2em">常縱橫各出以禦場屋之敵又曰學者因是而得</span>  
<span style="margin-left: 2em">其活法則求經之微亦無出於此不止决科之計</span>  
<span style="margin-left: 2em">然其書究爲科舉而作非通經者所尚也</span>  
春秋透天關四卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">舊本題晏兼善撰不著時代據其兼及合題是元</span>  
<span style="margin-left: 2em">人也其書專爲場屋而作義殊膚淺如解元年春</span>  
<span style="margin-left: 2em">王正月云若就春字正月上用工則春者天之所</span>  
<span style="margin-left: 2em">爲聖人紀人道之始全以天道王道立說亦可云</span>  
<span style="margin-left: 2em">云則一書之大指可知矣</span>  
<!-- 册1 葉2425b　Page:文淵閣四庫全書_0001冊.djvu/656 -->
春秋四傳三十八卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">不知何人所編首載杜預何休范甯胡安國四序</span>  
<span style="margin-left: 2em">次春秋綱領述各家議論次春秋提要如周十二</span>  
<span style="margin-left: 2em">王魯十二公以及會盟戰伐之數並撮舉大凡次</span>  
<span style="margin-left: 2em">春秋列國圖說次春秋二十國年表次春秋諸國</span>  
<span style="margin-left: 2em">興廢說凡經文之下皆分註左氏公羊穀梁三傳</span>  
<span style="margin-left: 2em">而胡傳則别爲標出間加音注别無發明參考之</span>  
<span style="margin-left: 2em">處考元俞臯春秋集傳釋義大成始於三傳之後</span>  
<span style="margin-left: 2em">附錄胡傳吳澄序稱其兼列胡氏以從時尚而四</span>  
<!-- 册1 葉2428a　Page:文淵閣四庫全書_0001冊.djvu/657 -->
<span style="margin-left: 2em">傳之稱亦卽見於澄序中知胡傳躐躋三傳之列</span>  
<span style="margin-left: 2em">自元初已然此本騐其板式猶爲元槧葢當時鄉</span>  
<span style="margin-left: 2em">塾讀本也</span>  
麟經指南一卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">不著撰人名氏前有自序署曰退修菴題亦不詳</span>  
<span style="margin-left: 2em">何人也序稱幼習是經以舉進士爲業投老山林</span>  
<span style="margin-left: 2em">兵火之餘先世遺書無復存者間因餘暇條分大</span>  
<span style="margin-left: 2em">義立題命意凡可引用之語各附於後又間引先</span>  
<span style="margin-left: 2em">儒破題葢元末鄉塾之陋本也</span>  
<!-- 册1 葉2428b　Page:文淵閣四庫全書_0001冊.djvu/657 -->
春秋圖說<sub class="note-yuan">無卷數　浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">不著撰人名氏前列目百二十有二始十二公年</span>  
<span style="margin-left: 2em">譜終諸儒傳授中間列國世次輿地山川名號以</span>  
<span style="margin-left: 2em">及經傳所載名物典故悉有圖有說其年表皆抄</span>  
<span style="margin-left: 2em">史記其名號歸一圖卽馮繼先所撰而分爲十九</span>  
<span style="margin-left: 2em">圖至歲星八音四凶十六相諸圖則又掇之五經</span>  
<span style="margin-left: 2em">圖中春秋列國圖說則摭自東坡指掌圖又列鄭</span>  
<span style="margin-left: 2em">樵考定諸國地名及敘國邑地同異說敘山水同</span>  
<span style="margin-left: 2em">異說大抵雜駁不倫未見精核卷首題曰春秋筆</span>  
<!-- 册1 葉2429a　Page:文淵閣四庫全書_0001冊.djvu/657 -->
<span style="margin-left: 2em">削發微考楊甲六經圖中有春秋筆削發微圖以</span>  
<span style="margin-left: 2em">此本互勘一一相合葢掇取甲書春秋一卷而攙</span>  
<span style="margin-left: 2em">以襍說僞立此名卷首有竹垞二字朱文印葢朱</span>  
<span style="margin-left: 2em">彞尊所藏而經義考不著此名是必後覺其贋託</span>  
<span style="margin-left: 2em">棄之不錄而所棄之本又爲吳氏所收耳</span>  
春秋提要四卷<sub class="note-yuan">江西巡撫採進本</sub>  
<span style="margin-left: 2em">明饒秉鑑撰秉鑑字憲章號雯峯廣昌人正統甲</span>  
<span style="margin-left: 2em">子舉人官至廉州府知府朱彞尊經義考載秉鑑</span>  
<span style="margin-left: 2em">春秋會通十五卷提要一卷今按此書實四卷與</span>  
<!-- 册1 葉2429b　Page:文淵閣四庫全書_0001冊.djvu/657 -->
<span style="margin-left: 2em">春秋會通另爲一書彞尊葢未見其本故傳聞訛</span>  
<span style="margin-left: 2em">異其書以春秋書時書月難於記誦故錯綜而次</span>  
<span style="margin-left: 2em">序之分十二公爲十二篇先列經文於右而總論</span>  
<span style="margin-left: 2em">其義於後大㫖以胡傳爲宗</span>  
左觿一卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">明邵寶撰寶字國賢號二泉無錫人成化甲辰進</span>
