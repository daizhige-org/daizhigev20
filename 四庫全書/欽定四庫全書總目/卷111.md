<span style="margin-left: 2em">術數𩔖存目二</span>

<span style="margin-left: 2em">不著撰人名氏前有自序稱昔因遇樓敬先生傳</span>  
<span style="margin-left: 2em">陰陽書三本其用甚驗直指休咎之理出生入死</span>  
<span style="margin-left: 2em">遁甲之法乾兌坎離遷宅之法辨年月日時加臨</span>  
<span style="margin-left: 2em">運式余因暇曰述斯文五十四篇分爲十卷備陳</span>  
<span style="margin-left: 2em">奥㫖立塜安墳擇地斬草塜穴高深䘮庭門陌碑</span>

<span style="margin-left: 2em">碣旒旐無不備矣云云葢術家所依托所云樓敬</span>

<span style="margin-left: 2em">題云靑烏先生𦵏經大金丞相兀欽仄注考靑烏</span>

<span style="margin-left: 2em">爲眞古書否此本文義淺近經與注如出一手殆</span>

<span style="margin-left: 2em">見於此本然字句頗有異同葢作僞者獵取璞書</span>  
<span style="margin-left: 2em">以自證而又稍易其文以冺剽襲之迹耳未可據</span>

<span style="margin-left: 2em">兵亂曾求已楊益於瓊林庫𫉬玉函發之得天機</span>

<span style="margin-left: 2em">玉函天機本一書而二名也然其說頗誕巳不足</span>

<span style="margin-left: 2em">圖說叅半所謂三仙講五虎講諸圖冗複牽綴皆</span>  
<span style="margin-left: 2em">無意義大抵明代地師因景鸞之說所爲又非宋</span>

<span style="margin-left: 2em">檢其文實出僞託其大例以天星二十八宿附於</span>  
<span style="margin-left: 2em">二十四山龍之下以乾坤艮巽爲四鼇極配以炁</span>  
<span style="margin-left: 2em">羅計孛四星以角亢奎婁斗牛井<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">分爲四候不</span>

<span style="margin-left: 2em">不以方位言專以在地之形應在天之象考星野</span>  
<span style="margin-left: 2em">見於周禮其占候畧見於左傳唐書載僧一行亦</span>  
<span style="margin-left: 2em">以山河兩戒配列宿然第就方輿大勢言之初非</span>

<span style="margin-left: 2em">間借天星以代干支字靣如亥曰紫微兌曰少微</span>

<span style="margin-left: 2em">合天罡燥火爲九其中又分正體開口懸乳弓脚</span>

<span style="margin-left: 2em">雙臂單股側腦没骨平靣爲九等各系以圖與說</span>  
<span style="margin-left: 2em">巳不免强無定之形以就一定之格至其雙臂太</span>  
<span style="margin-left: 2em">隂一條云若兩臂太尖名夾刃主殺人至毒須人</span>
