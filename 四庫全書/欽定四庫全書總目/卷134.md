## 欽定四庫全書總目 卷一百三十四　子部四十四　雜家類存目十一

<!-- 册3 葉3321a　Page:文淵閣四庫全書_0003冊.djvu/835 -->
欽定四庫全書總目卷一百三十四  
<span style="margin-left: 1em">子部四十四</span>  
<span style="margin-left: 2em">雜家類存目十一</span>  
五子纂圖互註四十二卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">宋龔士卨編士卨爵里無考前有自序題景定改</span>  
<span style="margin-left: 2em">元葢理宗時人又有三私印一曰龔氏一曰子質</span>  
<span style="margin-left: 2em">一曰石廬子葢其字與號也是書於老子用河上</span>  
<span style="margin-left: 2em">公註凡二卷於莊子用郭象註附以陸德明音義</span>  
<span style="margin-left: 2em">凡十卷於荀子用楊倞註凡十卷於揚子法言用</span>  
<!-- 册3 葉3321b　Page:文淵閣四庫全書_0003冊.djvu/835 -->
<span style="margin-left: 2em">李軌柳宗元宋咸吳秘司馬光五家註凡十卷於</span>  
<span style="margin-left: 2em">文中子中說用阮逸註凡十卷每種前各有圖而</span>  
<span style="margin-left: 2em">於原註之中増以互註多引五經四書及諸子習</span>  
<span style="margin-left: 2em">見之語未能有所發明其於文中子則並無互註</span>  
<span style="margin-left: 2em">體例殊未畫一至老子之首列三圖一曰混元三</span>  
<span style="margin-left: 2em">寳一曰初眞内觀靜令一曰金丹莊子之首惟列</span>  
<span style="margin-left: 2em">周子太極圖荀子之首列三圖一曰欹器一曰天</span>  
<span style="margin-left: 2em">子大路一曰龍旂九斿揚子之首列二圖一曰渾</span>  
<span style="margin-left: 2em">儀一曰五聲十二律文中子之首列二圖一曰世</span>  
<!-- 册3 葉3324a　Page:文淵閣四庫全書_0003冊.djvu/836 -->
<span style="margin-left: 2em">系一曰年表無一足資考證者而莊子因大宗師</span>  
<span style="margin-left: 2em">篇有太極二字遂附㑹以周子之圖尤爲無理核</span>  
<span style="margin-left: 2em">其紙色板式乃宋末建陽麻沙本葢無知書賈苟</span>  
<span style="margin-left: 2em">且射利者所爲因其宋人舊刻姑存其目以備考</span>  
<span style="margin-left: 2em">耳</span>  
藝圃蒐奇十八卷補闕二卷<sub class="note-yuan">編修汪如藻家藏本</sub>  
<span style="margin-left: 2em">舊本題明徐一䕫編一䕫字大章天台人僑寓嘉</span>  
<span style="margin-left: 2em">興元末嘗官建寧教授<sub class="note-yuan">案一䕫官建寧教授見其始豊稿與危素書明史本</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">傳不載葢未考其文集</sub>洪武初徵修禮書王禕又薦修元史</span>  
<!-- 册3 葉3324b　Page:文淵閣四庫全書_0003冊.djvu/836 -->
<span style="margin-left: 2em">辭不至後起爲杭州教授又召修大明日厯特授</span>  
<span style="margin-left: 2em">以翰林官以足病辭歸事迹具明史文苑傳翦勝</span>  
<span style="margin-left: 2em">野聞稱其官杭州教授時以表文忤旨收捕斬之</span>  
<span style="margin-left: 2em">殊爲妄誕野聞托名徐禎卿多齊東之語此亦其</span>  
<span style="margin-left: 2em">一也是書前有至正戊申自序稱錢塘陳子彥高</span>  
<span style="margin-left: 2em">避兵檇李惠子之五車茂先之三十乘携以俱來</span>  
<span style="margin-left: 2em">適余亦樓止是<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3771.svg?width=24" alt="四庫全書僻字第3771號（邦）" title="四庫全書僻字第3771號（邦）">嘗得借觀兹編皆古今名人雜</span>  
<span style="margin-left: 2em">著之小者從無刊板彥高檢有副本悉以贈余裝</span>  
<span style="margin-left: 2em">成若干冊名之曰藝圃搜奇云云彥高陳世隆字</span>  
<!-- 册3 葉3325a　Page:文淵閣四庫全書_0003冊.djvu/836 -->
<span style="margin-left: 2em">也故是書或亦題世隆所編凡一百三種其中舛</span>  
<span style="margin-left: 2em">謬顚倒不可縷舉其最甚者如褚少孫補史記自</span>  
<span style="margin-left: 2em">前代卽附刊史記中並非秘笈而取爲壓卷名曰</span>  
<span style="margin-left: 2em">史記外編又佚其平津侯列傳建元以來侯年表</span>  
<span style="margin-left: 2em">二篇摰虞文章流别諭乃抄藝文類聚太平御覽</span>  
<span style="margin-left: 2em">之文猶有所本也至谷神子卽博異記醴泉筆錄</span>  
<span style="margin-left: 2em">卽江休復嘉祐雜志俞琰月下偶談卽席上腐談</span>  
<span style="margin-left: 2em">楊萬里誠齋揮麈錄卽王明淸揮麈錄晁說之墨</span>  
<span style="margin-left: 2em">經卽晁子一墨經大抵改易書名人名以售其欺</span>  
<!-- 册3 葉3325b　Page:文淵閣四庫全書_0003冊.djvu/836 -->
<span style="margin-left: 2em">至鎦績雖元明間人而霏雪錄成於洪武中此編</span>  
<span style="margin-left: 2em">旣輯於至正戊申猶順帝之末年何以預載其書</span>  
<span style="margin-left: 2em">且所錄灌畦暇語與李東陽重編殘缺之本一字</span>  
<span style="margin-left: 2em">不易豈元人所及見𫆀其爲近時所贋托不問可</span>  
<span style="margin-left: 2em">知矣原本有錄無書者凡十三種</span>  
<span style="margin-left: 1em">國朝曹寅爲補錄之釐爲二卷葢寅亦爲姦𭶑書賈</span>  
<span style="margin-left: 2em">所紿也</span>  
柏齋三書三卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明何瑭撰瑭有醫學管見已著錄是書一爲陰陽</span>  
<!-- 册3 葉3328a　Page:文淵閣四庫全書_0003冊.djvu/837 -->
<span style="margin-left: 2em">管見一爲樂律管見一爲儒學管見大都好爲異</span>  
<span style="margin-left: 2em">說以自高如論陰陽則以周子相生之說爲不可</span>  
<span style="margin-left: 2em">信於張子正𫎇邵子經世諸書皆排詆其失論樂</span>  
<span style="margin-left: 2em">律則以蔡元定律呂新書爲不可行并譏禮經之</span>  
<span style="margin-left: 2em">樂記爲過當而失實論儒學則以朱子爲欠明切</span>  
<span style="margin-left: 2em">而眞德秀大學衍義於大學之道實亦不知皆所</span>  
<span style="margin-left: 2em">謂一知半解也未有崔銑䟦銑學頗醇正而極稱</span>  
<span style="margin-left: 2em">所論之超卓殊不可解</span>  
六詔記聞二卷<sub class="note-yuan">戸部尚書王際華家藏本</sub>  
<!-- 册3 葉3328b　Page:文淵閣四庫全書_0003冊.djvu/837 -->
<span style="margin-left: 2em">上卷曰會勘夷情錄乃嘉靖十四年建昌道兵備</span>  
<span style="margin-left: 2em">副使俞䕫處置四川鹽井衛士千戸與雲南麗永</span>  
<span style="margin-left: 2em">二府土舍爭界事公移案牘下卷曰南荒振玉乃</span>  
<span style="margin-left: 2em">乩仙方海何眞人與䕫等唱和之詩南京吏科給</span>  
<span style="margin-left: 2em">事中彭汝嘉合刻傳之䕫門人李應元爲之序二</span>  
<span style="margin-left: 2em">卷一記邊防一談神怪殊爲不倫殆於無類可歸</span>  
<span style="margin-left: 2em">姑隸之雜編附存其目䕫建德人正德丁丑進士</span>  
<span style="margin-left: 2em">汝嘉嘉定州人正德辛已進士</span>  
木鐘臺集<sub class="note-yuan">無卷數　副都御史黃登賢家藏本</sub>  
<!-- 册3 葉3329a　Page:文淵閣四庫全書_0003冊.djvu/837 -->
<span style="margin-left: 2em">明唐樞撰樞有易修墨守已著錄此編凡分二十</span>  
<span style="margin-left: 2em">九種曰禮元剩語曰眞談曰語錄曰遊錄曰周禮</span>  
<span style="margin-left: 2em">因論曰因領錄曰三十測曰咨言曰感學編曰答</span>  
<span style="margin-left: 2em">言曰轄圜窩雜著曰證道曰偶客談曰疑誼曰海</span>  
<span style="margin-left: 2em">議曰國琛集曰未學學曰館論曰易修墨守曰法</span>  
<span style="margin-left: 2em">綴曰列流測曰宋學商求曰枝辭曰積承錄曰政</span>  
<span style="margin-left: 2em">問曰冀越通曰嘉禾問錄曰春秋讀意曰激衷小</span>  
<span style="margin-left: 2em">擬晰門分𩔖俱各冠以序文其别行之本已各存</span>  
<span style="margin-left: 2em">目此其總滙之本也</span>  
<!-- 册3 葉3329b　Page:文淵閣四庫全書_0003冊.djvu/837 -->
邱陵學山<sub class="note-yuan">無卷數　浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">明王文祿編文祿有廉矩已著錄此本乃其彚刻</span>  
<span style="margin-left: 2em">諸書以擬宋左圭百川學海故以邱陵學山爲名</span>  
<span style="margin-left: 2em">所載以千字文編次自天字至師字凡七十四種</span>  
<span style="margin-left: 2em">然欲矜繁富而考訂未精故類多刪節原文不能</span>  
<span style="margin-left: 2em">全錄又以前人文集所已載者析出而附益之强</span>  
<span style="margin-left: 2em">立名目牽率殊甚至海沂子以下數種皆文祿自</span>  
<span style="margin-left: 2em">著之書而亦闌入其中尤不出明人積習非但遠</span>  
<span style="margin-left: 2em">遜左圭卽視商維濬吳琯輩相去亦懸絶矣</span>  
<!-- 册3 葉3332a　Page:文淵閣四庫全書_0003冊.djvu/838 -->
陸學士雜著十一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明陸樹聲撰樹聲有平泉題䟦已著錄是編皆其</span>  
<span style="margin-left: 2em">所著雜說曰汲古叢語一卷曰適圜雜著一卷曰</span>  
<span style="margin-left: 2em">陸學士題䟦二卷曰耄餘雜識一卷曰禪林餘藻</span>  
<span style="margin-left: 2em">一卷曰陸氏家訓一卷曰善俗禆議一卷曰病榻</span>  
<span style="margin-left: 2em">寤言一卷曰淸暑筆談一卷曰長水日抄一卷其</span>  
<span style="margin-left: 2em">中亦有别本單行者此則其門人子弟所合刊成</span>  
<span style="margin-left: 2em">帙者也</span>  
陸文定公書<sub class="note-yuan">無卷數　江蘇巡撫採進本</sub>  
<!-- 册3 葉3332b　Page:文淵閣四庫全書_0003冊.djvu/838 -->
<span style="margin-left: 2em">明陸樹聲撰是集首列適園雜著次淸暑筆談次</span>  
<span style="margin-left: 2em">善俗裨議次鄉會公約次題䟦皆其罷官家居時</span>  
<span style="margin-left: 2em">所作較陸學士雜著所刊少五種而多鄉會公約</span>  
<span style="margin-left: 2em">一種葢其刻在雜著前也</span>  
兩京遺編五十七卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明胡維新編維新餘姚人嘉靖已未進士官監察</span>  
<span style="margin-left: 2em">御史是刻凡新語二卷賈子十卷鹽鐵論十卷白</span>  
<span style="margin-left: 2em">虎通二卷潛夫論二卷仲長統論一卷風俗通十</span>  
<span style="margin-left: 2em">卷中論二卷人物志三卷申鑒五卷文心雕龍十</span>  
<!-- 册3 葉3333a　Page:文淵閣四庫全書_0003冊.djvu/838 -->
<span style="margin-left: 2em">卷共十一種以所採皆漢文故以兩京名書其中</span>  
<span style="margin-left: 2em">如徐幹雖名附魏志然卒於建安二十二年附之</span>  
<span style="margin-left: 2em">漢未可也至於劉邵爲魏人劉勰爲梁人序乃稱</span>  
<span style="margin-left: 2em">以其文似漢而進之王充論衡劉向說苑實皆漢</span>  
<span style="margin-left: 2em">人之文又以其卷帙之多而棄之去取殊無義例</span>  
<span style="margin-left: 2em">且文心雕龍純爲四六駢體而云其文似漢尤乖</span>  
<span style="margin-left: 2em">謬之甚矣</span>  
紀錄彚編二百十六卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">明沈節甫編節甫鳥程人嘉靖已未進士官至工</span>  
<!-- 册3 葉3333b　Page:文淵閣四庫全書_0003冊.djvu/838 -->
<span style="margin-left: 2em">部左侍郞諡端靖是書採嘉靖以前諸家雜記裒</span>  
<span style="margin-left: 2em">爲一集凡一百一十九種其中有關典故者多已</span>  
<span style="margin-left: 2em">别本自行其餘如王貞明詩評之𩔖則文士之餘</span>  
<span style="margin-left: 2em">談祝允明志怪之𩔖又小說之末派一槪闌入未</span>  
<span style="margin-left: 2em">免務博好奇傷於冗雜且諸書有全載者有摘鈔</span>  
<span style="margin-left: 2em">者甚或有一書而全錄其半摘鈔其半者爲例亦</span>  
<span style="margin-left: 2em">復不純卷帙雖富不足取也</span>  
左傳國語國策評苑六十一卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">明穆文熙編文熙有七雄策纂已著錄是編凡左</span>  
<!-- 册3 葉3336a　Page:文淵閣四庫全書_0003冊.djvu/839 -->
<span style="margin-left: 2em">傳三十卷國語二十一卷戰國策十卷左傳用杜</span>  
<span style="margin-left: 2em">預注陸德明釋文而標預名不標德明之名國語</span>  
<span style="margin-left: 2em">用韋昭注宋庠補音戰國策用鮑彪註叅以吳師</span>  
<span style="margin-left: 2em">道之補正均略有所刪補非其原文葢明人凡刻</span>  
<span style="margin-left: 2em">古書例皆如是謂必如是然後見其有所改定非</span>  
<span style="margin-left: 2em">徒翻刻舊文也其曰評苑者葢於簡端雜採諸家</span>  
<span style="margin-left: 2em">之論云</span>  
中都四子集六十四卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">明朱東光編東光字元曦浦城人隆慶戊辰進士</span>  
<!-- 册3 葉3336b　Page:文淵閣四庫全書_0003冊.djvu/839 -->
