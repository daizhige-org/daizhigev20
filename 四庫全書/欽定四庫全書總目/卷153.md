## 欽定四庫全書總目 卷一百五十三　集部六　別集類六

<!-- 册4 葉456：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷一百五十三  
<span style="margin-left: 1em">集部六</span>  
<span style="margin-left: 2em">別集類六</span>  
旴江集三十七卷年譜一卷外集三卷<sub class="note-yuan">浙江孫仰曾家藏本</sub>  
<span style="margin-left: 2em">宋李覯撰覯字泰伯建昌南城人皇祐初以薦授</span>  
<span style="margin-left: 2em">太學助教終海門主簿太學說書事跡具宋史儒</span>  
<span style="margin-left: 2em">林傳考覯年譜稱慶厯三年癸未集退居𩔖稿十</span>  
<span style="margin-left: 2em">二卷又皇祐四年庚辰集皇祐續稿八卷此集爲</span>  
<span style="margin-left: 2em">明南城左贊所編凡詩交雜著三十七卷前列年</span>  
<!-- 册4 葉457b　Page:文淵閣四庫全書_0004冊.djvu/119 -->
<span style="margin-left: 2em">譜一卷後以制誥薦章之類爲外集三卷葢非當</span>  
<span style="margin-left: 2em">日之舊宋人多稱覯不喜孟子余允文尊孟辨中</span>  
<span style="margin-left: 2em">載覯常語十七條而此集所載僅仲尼之徒無道</span>  
<span style="margin-left: 2em">桓文之事及伊尹廢太甲周公封魯三條葢贊諱</span>  
<span style="margin-left: 2em">而刪之集首載祖無揮退居𩔖稿序特以孟子比</span>  
<span style="margin-left: 2em">覯又集中答李觀書云孟氏荀揚醇疵之說不可</span>  
<span style="margin-left: 2em">復輕重其他文中亦頗引及孟子與宋人所記種</span>  
<span style="margin-left: 2em">種相反以所刪常語推之母亦贊所竄亂歟覯文</span>  
<span style="margin-left: 2em">格次於歐曾其論治體悉可見於實用故朱子謂</span>  
<!-- 册4 葉460a　Page:文淵閣四庫全書_0004冊.djvu/120 -->
<span style="margin-left: 2em">覯文實有得於經不喜孟子特偶然偏見與歐陽</span>  
<span style="margin-left: 2em">修不喜繫辭同可以置而不論贊必欲委曲彌縫</span>  
<span style="margin-left: 2em">務滅其跡所見陋矣集中平土書明堂五宗皆别</span>  
<span style="margin-left: 2em">有圖此本不載則或久佚不傳未必贊所刋除也</span>  
<span style="margin-left: 2em">覯在宋不以詩名然王士禎居易錄嘗稱其王方</span>  
<span style="margin-left: 2em">平璧月梁元帝送僧還廬山憶錢塘江五絶句以</span>  
<span style="margin-left: 2em">爲風致似義山今觀諸詩惟梁元帝一首不免傖</span>  
<span style="margin-left: 2em">父面目餘皆不媿所稱亦可謂淵明之賦閒情矣</span>  
<span style="margin-left: 2em">湘山野錄載覯望海亭席上作一首集中不載考</span>  
<!-- 册4 葉460b　Page:文淵閣四庫全書_0004冊.djvu/120 -->
<span style="margin-left: 2em">是時蔡襄守福唐於此亭邀覯與陳烈飮烈聞官</span>  
<span style="margin-left: 2em">妓唱歌纔一發聲卽越牆攀樹遁去講學家以爲</span>  
<span style="margin-left: 2em">美談覯所謂山鳥不知紅粉樂一聲拍板便驚飛</span>  
<span style="margin-left: 2em">者正以嘲烈殆亦左贊病其輕薄諱而刪之歟</span>  
金氏文集二卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋金君卿撰君卿字正叔浮梁人江西通志載君</span>  
<span style="margin-left: 2em">卿登慶厯進士累官知臨川權江西提刑人爲度</span>  
<span style="margin-left: 2em">支郞中洪邁夷堅志載君卿讀書浮梁山一條稱</span>  
<span style="margin-left: 2em">其䇿高科厯郡守部使者積代至度支郞中與通</span>  
<!-- 册4 葉461a　Page:文淵閣四庫全書_0004冊.djvu/120 -->
<span style="margin-left: 2em">志相合然亦不詳其事迹考曾鞏元豐類稿有衛</span>  
<span style="margin-left: 2em">尉寺丞致仕金君墓誌銘一篇乃爲君卿父温叟</span>  
<span style="margin-left: 2em">而作稱温叟四子君著君佐君卿君佑皆舉進士</span>  
<span style="margin-left: 2em">君卿以皇祐二年官祕書丞五年官太常博士得</span>  
<span style="margin-left: 2em">以褒崇其親其敘述頗詳又稱君卿方以材自起</span>  
<span style="margin-left: 2em">於貧賤欲以其所爲爲天下<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3004.svg?width=24" alt="四庫全書僻字第3004號（慨）" title="四庫全書僻字第3004號（慨）">然有志則其人亦</span>  
<span style="margin-left: 2em">非碌碌者也宋史藝文志載金君卿集十卷江西</span>  
<span style="margin-left: 2em">通志作十五卷考永樂大典載是集有當臨原序</span>  
<span style="margin-left: 2em">一篇稱臨川江明仲求遺稿編成十五卷號金氏</span>  
<!-- 册4 葉461b　Page:文淵閣四庫全書_0004冊.djvu/120 -->
<span style="margin-left: 2em">文集則宋志稱十卷者誤矣原本久佚今掇拾永</span>  
<span style="margin-left: 2em">樂大典所載僅得十之一二然北宋文集傳者日</span>  
<span style="margin-left: 2em">稀此本尤世所罕見殘珪碎璧彌少彌珍謹以𩔖</span>  
<span style="margin-left: 2em">編次分爲上下二卷集中所作有文彦博韓琦生</span>  
<span style="margin-left: 2em">日詩范仲淹移鎭杭州次韻詩和歐陽修潁州西</span>  
<span style="margin-left: 2em">湖及芍藥二詩是君卿所與遊者皆一代端人正</span>  
<span style="margin-left: 2em">士故詩文皆清醇雅飭猶有古風陳災事貢舉諸</span>  
<span style="margin-left: 2em">疏剴切詳明尤爲有裨世用又如和介甫寄安豐</span>  
<span style="margin-left: 2em">張公儀一首卽用臨川集中安豐張令修芍陂之</span>  
<!-- 册4 葉464a　Page:文淵閣四庫全書_0004冊.djvu/121 -->
<span style="margin-left: 2em">韻而据君<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">詩知張字爲公儀爲李壁注所未引</span>  
<span style="margin-left: 2em">又和曾子固直言謫官者一首檢元豐𩔖藁無其</span>  
<span style="margin-left: 2em">原唱知此篇爲鞏所自刪亦均可互資考證富臨</span>  
<span style="margin-left: 2em">序稱君<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">長於易嘗著易說易箋今並不存獨有</span>  
<span style="margin-left: 2em">傳易之家一篇具載傳授本末疑卽易說前所載</span>  
<span style="margin-left: 2em">之敘錄今旣無可考姑並附於集末焉</span>  
公是集五十四卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋劉敞撰敞有春秋傳巳著錄葉夢得避暑錄話</span>  
<span style="margin-left: 2em">稱敞集一百七十五卷據其弟攽所作集序稱公</span>  
<!-- 册4 葉464b　Page:文淵閣四庫全書_0004冊.djvu/121 -->
<span style="margin-left: 2em">是總集七十五卷敘爲五種曰古詩二十卷律詩</span>  
<span style="margin-left: 2em">十五卷内集二十卷外集十五卷小集五卷文獻</span>  
<span style="margin-left: 2em">通考亦作七十五卷則夢得所記爲誤矣原本不</span>  
<span style="margin-left: 2em">傳今新喻所刻三劉文集公是集僅四卷大約採</span>  
<span style="margin-left: 2em">自宋文鑑者居多而又以劉跂趙氏金石錄序泰</span>  
<span style="margin-left: 2em">山泰篆譜序誤入集中卽攽所作公是集序亦采</span>  
<span style="margin-left: 2em">自文獻通考而未見其全故注云失名其編次疎</span>  
<span style="margin-left: 2em">舛可知又錢塘吳允嘉別編公是集六卷亦殊缺</span>  
<span style="margin-left: 2em">畧考史有之序春秋意林曰淸江爲二劉三孔之</span>  
<!-- 册4 葉465a　Page:文淵閣四庫全書_0004冊.djvu/121 -->
<span style="margin-left: 2em">鄉文獻宜徵而足今三孔集故在獨二劉所著燬</span>  
<span style="margin-left: 2em">於兵則其佚巳久矣惟永樂大典所載頗富今裒</span>  
<span style="margin-left: 2em">輯排次釐爲五十四卷疑當時重其兄弟之文全</span>  
<span style="margin-left: 2em">部收入故所存獨多也敞之談經雖好與先儒立</span>  
<span style="margin-left: 2em">異而淹通典籍具由心得究非南宋諸家游談無</span>  
<span style="margin-left: 2em">根者比故其文湛深經術具有本原攽序稱其合</span>  
<span style="margin-left: 2em">衆美爲巳用超倫𩔖而獨得瓌偉奇特放肆自若</span>  
<span style="margin-left: 2em">又稱其考百子之雜博六經可以折衷極帝王之</span>  
<span style="margin-left: 2em">治功今日可以按行學聖人而得其道所以優出</span>  
<!-- 册4 葉465b　Page:文淵閣四庫全書_0004冊.djvu/121 -->
<span style="margin-left: 2em">於前人友于之情雖未免推揚太過然曾肇曲阜</span>  
<span style="margin-left: 2em">集有敞贈特進制曰經術文章追古作者朱子晦</span>  
<span style="margin-left: 2em">菴集有墨莊記曰學士舍人兄弟皆以文章大顯</span>  
<span style="margin-left: 2em">於時而名後世語錄曰原父文才思極多湧將出</span>  
<span style="margin-left: 2em">來每作文多法古絶相似有幾件文字學禮記春</span>  
<span style="margin-left: 2em">秋說學公穀又曰劉侍讀氣平文緩乃自經書中</span>  
<span style="margin-left: 2em">來比之蘇公有高古之趣云云則其文詞古雅可</span>  
<span style="margin-left: 2em">以槪見矣晁公武讀書志謂歐陽修嘗短其文於</span>  
<span style="margin-left: 2em">韓琦葉適習學記言亦謂敞言經㫖間以謔語酬</span>  
<!-- 册4 葉468a　Page:文淵閣四庫全書_0004冊.djvu/122 -->
<span style="margin-left: 2em">修積不能平復忤韓琦遂不得爲翰林學士葢祖</span>  
<span style="margin-left: 2em">公武之說今考修草敞知制誥詔曰議論宏博詞</span>  
<span style="margin-left: 2em">章爛然又作其父立之墓誌曰敞與攽皆賢而有</span>  
<span style="margin-left: 2em">文章又作敞墓誌曰於學博自六經百氏古今傳</span>  
<span style="margin-left: 2em">記下至天文地理卜醫數術浮屠老莊之說無所</span>  
<span style="margin-left: 2em">不通爲文章尤敏贍嘗直紫薇閣一日追封皇子</span>  
<span style="margin-left: 2em">公主九人方將下直止馬却坐一揮九制數千言</span>  
<span style="margin-left: 2em">文辭典雅各得其體其銘詞曰惟其文章燦曰星</span>  
<span style="margin-left: 2em">雖欲有毁知莫能則修亦雅重之晁氏葉氏所言</span>  
<!-- 册4 葉468b　Page:文淵閣四庫全書_0004冊.djvu/122 -->
<span style="margin-left: 2em">殆非其實歟</span>  
彭城集四十卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋劉攽撰攽字貢父號公非與兄敞同登慶厯六</span>  
<span style="margin-left: 2em">年進士第官至中書舍人事迹具宋史本傳史稱</span>  
<span style="margin-left: 2em">攽未冠通五經博覽羣書沈作喆寓簡亦曰國朝</span>  
<span style="margin-left: 2em">六經之學自賈文元倡之而原父兄弟爲最高司</span>  
<span style="margin-left: 2em">馬光修資治通鑑自辟所屬極天下之選而任史</span>  
<span style="margin-left: 2em">記前後漢書者攽也其知兖亳二州以不能奉行</span>  
<span style="margin-left: 2em">新法黜監衡州鹽倉哲宗初起知襄州入爲祕書</span>  
<!-- 册4 葉469a　Page:文淵閣四庫全書_0004冊.djvu/122 -->
<span style="margin-left: 2em">少監錢勰草制極稱其詞藝之富後以直龍圖閣</span>  
<span style="margin-left: 2em">出知蔡州孫覺胡宗愈蘇軾范百祿交薦之言攽</span>  
<span style="margin-left: 2em">博記能文章政事侔古循吏身兼數器守道不回</span>  
<span style="margin-left: 2em">乃召拜中書舍人蘇軾草制稱其能讀典墳邱索</span>  
<span style="margin-left: 2em">之書習知漢魏晉唐之故其沒也曾鞏祭文有曰</span>  
<span style="margin-left: 2em">强學博敏超絶一世肇自載籍孔墨百氏太史所</span>  
<span style="margin-left: 2em">錄俚問野記延及荒外陰陽<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">神細大萬殊一載</span>  
<span style="margin-left: 2em">以身下至律令老吏所疑故事舊章盈廷不知有</span>  
<span style="margin-left: 2em">問於子歸如得師直貫傍穿水決矢飛一時書林</span>  
<!-- 册4 葉469b　Page:文淵閣四庫全書_0004冊.djvu/122 -->
<span style="margin-left: 2em">衆俊並馳滿堂賢豪視子麈揮云云葢一時廷評</span>  
<span style="margin-left: 2em">士論莫不共推卽朱子於元祐諸人自洛黨以外</span>  
<span style="margin-left: 2em">多所不滿而語錄云貢父文字工於摹倣學公羊</span>  
<span style="margin-left: 2em">儀禮亦復稱之豈非攽學問博洽詞章奥雅有不</span>  
<span style="margin-left: 2em">可遏抑者乎史載所著諸書有文集五十卷五代</span>  
<span style="margin-left: 2em">春秋十五卷内傳國語二十卷經史新議七卷東</span>  
<span style="margin-left: 2em">漢刋誤四卷詩話二卷漢官儀三卷芍藥譜三卷</span>  
<span style="margin-left: 2em">今所存者自詩話以外惟東漢刋誤散附北監本</span>  
<span style="margin-left: 2em">後漢書中近日始有刻本芍藥譜亦僅而不亡文</span>  
<!-- 册4 葉472a　Page:文淵閣四庫全書_0004冊.djvu/123 -->
<span style="margin-left: 2em">集則宋史藝文志文獻通考俱作六十卷明文淵</span>  
<span style="margin-left: 2em">閣書目有彭城集十五冊不列卷數今所傳三劉</span>
