欽定四庫全書總目卷一百五十二  
<span style="margin-left: 1em">集部五</span>  
<span style="margin-left: 2em">别集𩔖五</span>  
騎省集三十卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">宋徐<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）">撰<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）">有稽神錄巳著錄晁公武讀書志陳</span>  
<span style="margin-left: 2em">振孫書錄解題並載<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）">集三十卷與今本同陳氏</span>  
<span style="margin-left: 2em">稱其前二十卷仕南唐時作後十卷皆歸宋後作</span>  
<span style="margin-left: 2em">今勘集中所載年月事迹亦皆相符葢猶舊本也</span>  
<span style="margin-left: 2em">集爲其婿吳淑所編天禧中都官員外郞胡克順</span>  
<!-- 册4 葉357b　Page:文淵閣四庫全書_0004冊.djvu/94 -->
<span style="margin-left: 2em">得其本於陳彭年刋刻表進始行於世<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）">精於小</span>  
<span style="margin-left: 2em">學所校許愼說文至今爲六書矩矱而文章淹雅</span>  
<span style="margin-left: 2em">亦冠一時讀書志稱其文思敏速凡有撰述常不</span>  
<span style="margin-left: 2em">喜豫作有欲從其求文者必戒臨事卽來請往往</span>  
<span style="margin-left: 2em">執筆立就未嘗沉思常曰文速則意思敏壯緩則</span>  
<span style="margin-left: 2em">體勢疎漫故其詩流易有餘而深警不足然如臨</span>  
<span style="margin-left: 2em">漢隱居詩話所稱喜李少保卜隣詩井泉分地脉</span>  
<span style="margin-left: 2em">砧杵共秋聲之句亦未嘗不具有思致葢其才高</span>  
<span style="margin-left: 2em">而學博故振筆而成時出名雋也當五季之未古</span>  
<!-- 册4 葉360a　Page:文淵閣四庫全書_0004冊.djvu/95 -->
<span style="margin-left: 2em">文未興故其文沿溯燕許不能嗣韓柳之音而就</span>  
<span style="margin-left: 2em">一時體格言之則亦逈然<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2854.svg?width=24" alt="四庫全書僻字第2854號（孤）" title="四庫全書僻字第2854號（孤）">秀翟耆年籀史曰太</span>  
<span style="margin-left: 2em">平興國中李煜薨詔侍臣撰神道碑有欲中傷<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）"></span>  
<span style="margin-left: 2em">者奏曰吳王事莫若徐<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）">爲詳遂詔<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）">撰<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）">請存</span>  
<span style="margin-left: 2em">故主之義太宗許之<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）">但推言厯數有盡天命有</span>  
<span style="margin-left: 2em">歸而已其警句曰東隣搆禍南箕扇疑投杼致慈</span>  
<span style="margin-left: 2em">親之惑乞火無隣婦之詞始勞因壘之師終後塗</span>  
<span style="margin-left: 2em">山之會太宗覽之稱歎不巳云云後吕祖謙編文</span>  
<span style="margin-left: 2em">鑑多不取儷偶之詞而特錄此碑葢亦賞其立言</span>  
<!-- 册4 葉360b　Page:文淵閣四庫全書_0004冊.djvu/95 -->
<span style="margin-left: 2em">有體以視楊維楨作明鼓吹曲反顏而詆故主者</span>  
<span style="margin-left: 2em">其心術相去遠矣然則<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）">之見重於世又不徒以</span>  
<span style="margin-left: 2em">詞章也</span>  
河東集十五卷附錄一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">宋柳開撰開字仲塗大名人開寶六年進士厯典</span>  
<span style="margin-left: 2em">州郡終於如京使事蹟具宋史文苑傳開少慕韓</span>  
<span style="margin-left: 2em">愈柳宗元爲文因名肩愈字紹先旣又改名改字</span>  
<span style="margin-left: 2em">自以爲能開聖道之塗也集中東郊野夫補亡先</span>  
<span style="margin-left: 2em">生二傳自述甚詳集十五卷其門人張景所編附</span>  
<!-- 册4 葉361a　Page:文淵閣四庫全書_0004冊.djvu/95 -->
<span style="margin-left: 2em">以景所撰行狀一卷蔡絛鐵圍山叢談記其在陜</span>  
<span style="margin-left: 2em">右爲刺史喜生膾人肝爲鄭文寶所按賴徐<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3787.svg?width=24" alt="四庫全書僻字第3787號（鉉）" title="四庫全書僻字第3787號（鉉）">救</span>  
<span style="margin-left: 2em">之得免則其人實酷暴之流石介集有過魏東郊</span>  
<span style="margin-left: 2em">詩爲開而作乃推重不遺餘力絛說固多虛飾介</span>  
<span style="margin-left: 2em">亦名心過重好爲詭激不合中庸其說未知孰<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）"></span>  
<span style="margin-left: 2em">今第就其文而論則宋朝變偶儷爲古文實自開</span>  
<span style="margin-left: 2em">始惟體近艱<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3232.svg?width=24" alt="四庫全書僻字第3232號（澀）" title="四庫全書僻字第3232號（澀）">是其所短耳盛如梓恕齋叢談載</span>  
<span style="margin-left: 2em">開論文之語曰古文非在詞澁言苦令人難讀在</span>  
<span style="margin-left: 2em">於古其理高其意王士禎池北偶談譏開能言而</span>  
<!-- 册4 葉361b　Page:文淵閣四庫全書_0004冊.djvu/95 -->
<span style="margin-left: 2em">不能行非過論也又尊崇揚雄太過至比之聖人</span>  
<span style="margin-left: 2em">持論殊謬要其轉移風氣於文格實爲有功謂之</span>  
<span style="margin-left: 2em">明而未融則可王士禎以爲初無好處則巳甚之</span>  
<span style="margin-left: 2em">詞也</span>  
咸平集三十卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">宋田錫撰錫有奏議巳著錄考奏議乃明安磐所</span>  
<span style="margin-left: 2em">輯其文巳全載此集中然宋史藝文志載錫奏議</span>  
<span style="margin-left: 2em">二卷文獻通考載錫咸平集五十卷此本載奏議</span>  
<span style="margin-left: 2em">一卷書三卷賦五卷論三卷箴銘二卷詩六卷頌</span>  
<!-- 册4 葉364a　Page:文淵閣四庫全書_0004冊.djvu/96 -->
<span style="margin-left: 2em">䇿笏記表狀七卷制誥考詞三卷以奏議與詩文</span>  
<span style="margin-left: 2em">集合爲一編僅三十卷則亦後人重輯之本非其</span>  
<span style="margin-left: 2em">舊也錫常慕魏徵李絳之爲人以獻納爲巳任國</span>  
<span style="margin-left: 2em">老談苑記太宗幸龍圖閣閱書指西北架一漆畫</span>  
<span style="margin-left: 2em">篋上親自署鑰者謂學士陳堯叟曰此田錫之奏</span>  
<span style="margin-left: 2em">疏也愴然者久之則當時巳重其言故其没也范</span>  
<span style="margin-left: 2em">仲淹作墓誌司馬光作神道碑而蘇軾序其奏議</span>  
<span style="margin-left: 2em">亦比之賈誼爲之操筆者皆天下偉人則錫之生</span>  
<span style="margin-left: 2em">平可知也詩文乃其餘事然亦具有典型其氣體</span>  
<!-- 册4 葉364b　Page:文淵閣四庫全書_0004冊.djvu/96 -->
<span style="margin-left: 2em">光明磊落如其爲人固終非淟涊者所得彷彿焉</span>  
逍遙集一卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋潘閬撰閬大名人晁公武讀書志謂其字曰逍</span>  
<span style="margin-left: 2em">遙江少虞事實𩔖苑則謂其自號逍遙子少虞說</span>  
<span style="margin-left: 2em">或近是歟太宗時召對賜進士第後坐事亡命眞</span>  
<span style="margin-left: 2em">宗捕得之釋其罪以爲滁州叅軍閬在宋初去五</span>  
<span style="margin-left: 2em">代餘風未遠其詩如秋夕旅舍書懷一篇喜臘雪</span>  
<span style="margin-left: 2em">一篇間有五代粗獷之習而其他風格孤峭亦尙</span>  
<span style="margin-left: 2em">有晚唐作者之遺蘇軾嘗稱其夏日宿西禪詩又</span>  
<!-- 册4 葉365a　Page:文淵閣四庫全書_0004冊.djvu/96 -->
<span style="margin-left: 2em">稱其題資福院石井詩不在石曼卿蘇子美下劉</span>  
<span style="margin-left: 2em">攽中山詩話稱其歲暮自桐廬歸錢塘詩不減劉</span>  
<span style="margin-left: 2em">長卿事實𩔖苑稱其苦吟詩貧居詩峽中聞猿詩</span>  
<span style="margin-left: 2em">哭高舍人詩寄張詠詩諸佳句劉克莊後村詩話</span>  
<span style="margin-left: 2em">稱其客舍詩方回瀛奎律髓稱其渭上秋夕閒望</span>  
<span style="margin-left: 2em">詩秋日題瑯琊寺詩落葉詩事實𩔖苑又記其在</span>  
<span style="margin-left: 2em">浙江時好事者畫爲潘閬詠潮圖郭若虛圖畫見</span>  
<span style="margin-left: 2em">聞志又記長安許道寧愛其華山詩畫爲潘閬倒</span>  
<span style="margin-left: 2em">騎驢圖一時若王禹偁柳開宼準宋白林逋諸人</span>  
<!-- 册4 葉365b　Page:文淵閣四庫全書_0004冊.djvu/96 -->
<span style="margin-left: 2em">皆與贈答葢宋人絶重之也讀書志載逍遙詩三</span>  
<span style="margin-left: 2em">卷宋史藝文志則作潘閬集一卷原本久佚未詳</span>  
<span style="margin-left: 2em">孰是今考永樂大典所載裒而錄之編爲一卷而</span>  
<span style="margin-left: 2em">逸篇遺句載在他書者亦併採輯以補其闕雖不</span>  
<span style="margin-left: 2em">能如晁氏著錄之數而較宋志所載則約畧得其</span>  
<span style="margin-left: 2em">八九矣其古意一首今刻唐詩者皆以爲崔國輔</span>  
<span style="margin-left: 2em">作而永樂大典則題閬名疑以傳疑亦姑並錄之</span>  
<span style="margin-left: 2em">而註其訛異於本題之下焉</span>  
乖崖集十二卷附錄一卷<sub class="note-yuan">衍聖公孔昭煥家藏本</sub>  
<!-- 册4 葉368a　Page:文淵閣四庫全書_0004冊.djvu/97 -->
<span style="margin-left: 2em">宋張詠撰詠事蹟具宋史本傳其集宋代有兩本</span>  
<span style="margin-left: 2em">一本十卷見於趙希弁讀書附志所稱錢易墓誌</span>  
<span style="margin-left: 2em">李畋語錄附於後者是也一本十二卷見於陳振</span>  
<span style="margin-left: 2em">孫書錄解題所稱郭森卿宰崇陽刻此集舊本十</span>  
<span style="margin-left: 2em">卷今增廣并語錄爲十二卷者是也此本前有森</span>  
<span style="margin-left: 2em">卿序葢卽振孫所見之本序稱於世刻中增詩八</span>  
<span style="margin-left: 2em">篇別附以韓琦神道碑王禹偁送宰崇陽序李燾</span>  
<span style="margin-left: 2em">祠堂記項安世北峯亭記今檢勘並合惟所稱刪</span>  
<span style="margin-left: 2em">次年譜別爲一卷者則已不見葢傳寫有所脫佚</span>  
<!-- 册4 葉368b　Page:文淵閣四庫全書_0004冊.djvu/97 -->
<span style="margin-left: 2em">矣詠兩莅益州爲政恩威並用吏民畏服平日剛</span>  
<span style="margin-left: 2em">方尙氣有巖巖不可犯之節其文乃疏通平易不</span>  
<span style="margin-left: 2em">爲嶄絶之語其詩亦列名西崑體中<sub class="note-yuan">案西崑酬唱十七人詠名</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">在第十一</sub>其聲賦一首窮極幽渺梁周翰至歎爲一百</span>  
<span style="margin-left: 2em">年不見此作則亦非無意於爲文者特其光明俊</span>  
<span style="margin-left: 2em">偉發於自然故眞氣流露無雕章琢句之態耳案</span>  
<span style="margin-left: 2em">韓琦神道碑稱詠與邑人傅霖友善登第後與傅</span>  
<span style="margin-left: 2em">詩有巢由莫相笑心不爲輕肥之句今集中乃作</span>  
<span style="margin-left: 2em">七言琦葢節用其意故與集本不合又案陳輔之</span>  
<!-- 册4 葉369a　Page:文淵閣四庫全書_0004冊.djvu/97 -->
<span style="margin-left: 2em">詩話稱蕭林之知溧陽時張乖崖召食見几案一</span>  
<span style="margin-left: 2em">絶句云獨恨太平無一事江南閒殺老尙書蕭改</span>  
<span style="margin-left: 2em">恨作幸字且言公功高身重姦人側目以此與公</span>  
<span style="margin-left: 2em">全身乖崖曰蕭弟一字之師也云云今考集中游</span>  
<span style="margin-left: 2em">趙氏西園詩末聯云方信承平無一事淮陽閒殺</span>
