## 欽定四庫全書總目 卷一百七十二　集部二十五　別集類二十五

欽定四庫全書總目卷一百七十二  
<span style="margin-left: 1em">集部二十五</span>  
<span style="margin-left: 2em">別集𩔖二十五</span>  
升庵集八十一卷<sub class="note-yuan">副都御史黃登賢家藏本</sub>  
<span style="margin-left: 2em">明楊愼撰愼有檀弓叢訓巳著錄此集爲萬厯中</span>  
<span style="margin-left: 2em">四川巡撫張士佩所訂凡賦及雜文十一卷詩二</span>  
<span style="margin-left: 2em">十九卷又雜記四十一卷葢士佩取愼丹鉛錄譚</span>  
<span style="margin-left: 2em">苑醍醐諸書刪除重複分𩔖編次附其詩文之後</span>  
<span style="margin-left: 2em">者也愼以博洽冠一時其詩含吐六朝於明代獨</span>  
<!-- 册4 葉2157b　Page:文淵閣四庫全書_0004冊.djvu/544 -->
<span style="margin-left: 2em">立門戸文雖不及其詩然猶存古法賢於何李諸</span>  
<span style="margin-left: 2em">家窒塞艱澁不可句讀者葢多見古書薰蒸沉浸</span>  
<span style="margin-left: 2em">吐屬自無鄙語譬諸世祿之家天然無寒儉之氣</span>  
<span style="margin-left: 2em">矣至於論說考證往往恃其强識不及檢核原書</span>  
<span style="margin-left: 2em">致多疎舛又恃氣求勝每說有窒礙輙造古書以</span>  
<span style="margin-left: 2em">實之遂爲陳耀文等所詬病致糾紛而不可解諸</span>  
<span style="margin-left: 2em">書本別本各行士佩離析其文分類排纂合而爲</span>  
<span style="margin-left: 2em">一較易檢尋而所分諸目較丹鉛總錄亦尙有條</span>  
<span style="margin-left: 2em">理故仍錄之集中備互考焉</span>  
<!-- 册4 葉2160a　Page:文淵閣四庫全書_0004冊.djvu/545 -->
東巖集六卷<sub class="note-yuan">浙江汪汝瑮家藏本</sub>  
<span style="margin-left: 2em">明夏尙樸撰尙樸字敦夫東巖其號也永豐人正</span>  
<span style="margin-left: 2em">德辛未進士官至南京太僕寺少卿尙樸初師吳</span>  
<span style="margin-left: 2em">與弼後師婁諒故明史儒林傳附見諒傳中惟史</span>  
<span style="margin-left: 2em">於薛瑄傳末又稱瑄之門人有周蕙蕙之門人有</span>  
<span style="margin-left: 2em">薛敬之李錦王爵夏尙樸與諒傳不合考傳末惟</span>  
<span style="margin-left: 2em">敘敬之錦爵三人事迹一字不及尙樸則瑄傳列</span>  
<span style="margin-left: 2em">尙樸之名殆衍文歟諒以勿忘勿助爲敬胡居仁</span>  
<span style="margin-left: 2em">羅欽順多譏其近禪而史載尙樸常言纔提起便</span>  
<!-- 册4 葉2160b　Page:文淵閣四庫全書_0004冊.djvu/545 -->
<span style="margin-left: 2em">是天理纔放下便是人欲魏校亟稱之王守仁少</span>  
<span style="margin-left: 2em">時亦學於諒然守仁贈尙樸詩有舍瑟春風之句</span>  
<span style="margin-left: 2em">尙樸則答曰孔門沂水春風景不出虞廷敬畏中</span>  
<span style="margin-left: 2em">至謂心所以窮理未足以盡理又謂學不難於一</span>  
<span style="margin-left: 2em">贯而難於萬殊則與王守仁卽心卽理之說迥異</span>  
<span style="margin-left: 2em">又與湛若水書斤斤以厭常喜新爲戒其語錄中</span>  
<span style="margin-left: 2em">復取陳獻章與論學詩一一爲之箋疏指其謬誤</span>  
<span style="margin-left: 2em">正嘉之際學問漸岐而尙樸獨恪守先儒不爲高</span>  
<span style="margin-left: 2em">論可謂篤實之士矣至其論中庸分八節獨不用</span>  
<!-- 册4 葉2161a　Page:文淵閣四庫全書_0004冊.djvu/545 -->
<span style="margin-left: 2em">朱子之說則見仁見智各有所得其不爲苟同卽</span>  
<span style="margin-left: 2em">其不爲苟異者也史載所著有中庸說東巖文集</span>  
<span style="margin-left: 2em">此本爲其壻劉賓所編以語錄中庸說爲第一卷</span>  
<span style="margin-left: 2em">與文集併爲一編史葢據其初出各行之本也尙</span>  
<span style="margin-left: 2em">樸本講學之士不以文章爲工然其言醇正固亦</span>  
<span style="margin-left: 2em">不乖於大雅焉</span>  
瀼溪草堂稿五十八卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明孫承恩撰承恩字貞父南<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">隸華亭人正德辛</span>  
<span style="margin-left: 2em">未進士官至禮部尙書兼翰林院學士掌詹事府</span>  
<!-- 册4 葉2161b　Page:文淵閣四庫全書_0004冊.djvu/545 -->
<span style="margin-left: 2em">諡文簡是集爲其門人楊豫孫董宜陽朱大韶所</span>  
<span style="margin-left: 2em">編七卷以前爲疏表講章皆進呈之作八卷以後</span>  
<span style="margin-left: 2em">爲賦詩詞曲二十七卷以後爲雜文承恩於嘉靖</span>  
<span style="margin-left: 2em">之初以庶子充經筵講官今集中所載正始箴鑒</span>  
<span style="margin-left: 2em">古韻語及講章卽是時所作及官禮部時齋宫設</span>  
<span style="margin-left: 2em">醮承恩獨不肯黃冠遂乞致仕較之嚴嵩諸人靑</span>  
<span style="margin-left: 2em">詞自媚者人品卓乎不同其文章亦純正恬雅有</span>  
<span style="margin-left: 2em">明初作者之遺卷首陸樹聲序有曰國初之文淳</span>  
<span style="margin-left: 2em">厚渾噩彬彬焉質有其文迨關西信陽兩君子山</span>  
<!-- 册4 葉2164a　Page:文淵閣四庫全書_0004冊.djvu/546 -->
<span style="margin-left: 2em">追宗秦漢薄魏晉而下海内藝學之士咸願執鞭</span>  
<span style="margin-left: 2em">弭從之標品位置率人人自詭先秦兩漢以希方</span>  
<span style="margin-left: 2em">軌雖體尙一新國初淳龎渾厚之氣或少漓焉公</span>  
<span style="margin-left: 2em">生長憲孝朝博稽宏覽邃詣淵蓄故出之撰述𩔖</span>  
<span style="margin-left: 2em">皆深厚爾雅紆徐委宻論者謂公平生立言𩔖其</span>  
<span style="margin-left: 2em">爲人云云承恩文章宗旨盡是數十言矣</span>  
方齋詩文集十卷<sub class="note-yuan">福建巡撫採進本</sub>  
<span style="margin-left: 2em">明林文俊撰文俊字汝英號方齋莆田人正德辛</span>  
<span style="margin-left: 2em">未進士官至南京吏部右侍郞事迹具明史本傳</span>  
<!-- 册4 葉2164b　Page:文淵閣四庫全書_0004冊.djvu/546 -->
<span style="margin-left: 2em">湛若水撰文俊神道碑載所著有方齋存稿世無</span>  
<span style="margin-left: 2em">刋本此本乃其家藏舊抄凡疏表序文雜著九卷</span>  
<span style="margin-left: 2em">詩一卷史稱其文章醇雅今觀其詩亦從容恬適</span>  
<span style="margin-left: 2em">不事雕琢</span>  
<span style="margin-left: 1em">國朝朱彝尊輯明詩綜乃獨不載之當由未見此本</span>  
<span style="margin-left: 2em">非黜之不錄也又近人鄭王臣輯莆風淸籟集所</span>  
<span style="margin-left: 2em">錄文俊詩尙有彭城夜泊七言律詩一首送黃主</span>  
<span style="margin-left: 2em">簿赴蘄水七言絶句一首爲是集所未收未知王</span>  
<span style="margin-left: 2em">臣何自得之王臣卽莆田人於文俊爲郷里或墨</span>  
<!-- 册4 葉2165a　Page:文淵閣四庫全書_0004冊.djvu/546 -->
<span style="margin-left: 2em">迹流傳據以載入歟今世傳明北監板二十一史</span>  
<span style="margin-left: 2em">卽文俊所梭刋竄改舛訛頗爲後人訾議然文俊</span>  
<span style="margin-left: 2em">爲祭酒巳在雕板將竣之日陳騤館閣續錄所謂</span>  
<span style="margin-left: 2em">經進不經修者未可以是並訾其詩文也</span>  
考功集十卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">明薛蕙撰蕙有西原遺書巳著錄正嘉之際文體</span>  
<span style="margin-left: 2em">初新北地信陽聲華方盛蕙詩獨以淸削婉約介</span>  
<span style="margin-left: 2em">乎其間古體上挹晉宋近體旁涉錢郞核其遺編</span>  
<span style="margin-left: 2em">雖亦擬議多而變化少然當其自得覺筆墨之外</span>  
<!-- 册4 葉2165b　Page:文淵閣四庫全書_0004冊.djvu/546 -->
<span style="margin-left: 2em">别有微情非生吞漢魏活剝盛唐者比其戲成五</span>  
<span style="margin-left: 2em">絶句取何景明之俊逸而病李夢陽之麤豪所尙</span>  
<span style="margin-left: 2em">畧可見矣又蕙與湛若水俱爲嚴嵩同年嵩權極</span>  
<span style="margin-left: 2em">盛之時若水年已垂耄不免爲嵩作鈐山堂集序</span>  
<span style="margin-left: 2em">反覆推頌頗爲盛德之累蕙初亦愛嵩文采頗相</span>  
<span style="margin-left: 2em">酬答迨其柄國以後卽薄其爲人不相聞問凡舊</span>  
<span style="margin-left: 2em">時倡和亦悉除其稿故全集十卷無一字與嵩相</span>  
<span style="margin-left: 2em">關人品之高逈出流輩其詩格蔚然孤秀實有自</span>  
<span style="margin-left: 2em">來是其所樹立又不在區區文字間也</span>  
<!-- 册4 葉2168a　Page:文淵閣四庫全書_0004冊.djvu/547 -->
雲邨文集十四卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明許相卿撰相卿有史漢方駕已著錄是集爲相</span>  
<span style="margin-left: 2em">卿所自定簡擇頗精自序調棄其脫遺不可讀者</span>  
<span style="margin-left: 2em">存其餘可讀者其自題絶句有曰雲村病老語多</span>  
<span style="margin-left: 2em">嚨造次詩成絶宋腔還溯開元論風格拾遺壇上</span>  
<span style="margin-left: 2em">樹旌幢葢自以所學爲未足欲進而求之唐人也</span>  
<span style="margin-left: 2em">今觀其詩大抵近體居多五言有大厯之調七言</span>  
<span style="margin-left: 2em">出入於陳師道陳與義間可謂自知之審矣章疏</span>  
<span style="margin-left: 2em">切實雜文體裁雅潔亦多有道之言無明季士大</span>  
<!-- 册4 葉2168b　Page:文淵閣四庫全書_0004冊.djvu/547 -->
<span style="margin-left: 2em">夫求名若渴之習殆篤實君子歟其歸田後與王</span>  
<span style="margin-left: 2em">子揚書稱時慮更切不敢以歸爲幸乃今傳聞日</span>  
<span style="margin-left: 2em">駭事勢日危旦夕念北如昔之思南其惓惓君國</span>  
<span style="margin-left: 2em">之意視所謂去國一身輕似葉高名千古重於山</span>  
<span style="margin-left: 2em">者相去葢不啻倍蓰也</span>  
小山類稿二十卷<sub class="note-yuan">浙江孫仰曾家藏本</sub>  
<span style="margin-left: 2em">明張岳撰岳字維喬惠安人正德丁丑進士官至</span>  
<span style="margin-left: 2em">刑部侍郞掌都察院事復出總督湖廣四川貴州</span>  
<span style="margin-left: 2em">卒諡襄惠事迹具明史本傳岳初授行人卽以疏</span>  
<!-- 册4 葉2169a　Page:文淵閣四庫全書_0004冊.djvu/547 -->
<span style="margin-left: 2em">諫南巡廷杖調南京國子監學正嘉靖初牽復原</span>  
<span style="margin-left: 2em">官又以議禮忤張璁繼忤夏言忤嚴嵩父子而卒</span>  
<span style="margin-left: 2em">得以功名終若有天幸然其剛正之操天下推之</span>  
<span style="margin-left: 2em">集中奏議分行人司稿廉州稿粤藩稿督撫鄖陽</span>  
<span style="margin-left: 2em">稿巡撫江南稿督撫兩廣稿總督湖廣川貴稿皆</span>  
<span style="margin-left: 2em">據其厯官年月次第編𩔖雖文義樸<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">而經濟大</span>  
<span style="margin-left: 2em">業亦可據以考見又史稱岳博覽工文章經術湛</span>  
<span style="margin-left: 2em">深不喜王守仁學今觀集中草堂學則及諸書牘</span>  
<span style="margin-left: 2em">中辨學之語大都推闡切至歸於篤實近裏葢有</span>  
<!-- 册4 葉2169b　Page:文淵閣四庫全書_0004冊.djvu/547 -->
<span style="margin-left: 2em">體有用之言固與空談無根者異也</span>  
夢澤集二十三卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">明王廷陳撰廷陳字稚欽黃岡人正德丁丑進士</span>  
<span style="margin-left: 2em">選庶吉士以言事廷杖出知裕州事迹具明史文</span>  
<span style="margin-left: 2em">苑傳其集一刻於惟安再刻於蘇州此本爲其從</span>  
<span style="margin-left: 2em">孫追淳知潁州時所刻乃第三本也廷陳少年高</span>  
<span style="margin-left: 2em">第以恃才傲物致放廢終身其器量殊爲淺狹至</span>  
<span style="margin-left: 2em">其詩意警語圓軒然出俗則不得不稱爲一時之</span>  
<span style="margin-left: 2em">秀王世貞藝苑巵言稱其如良馬走坂美女舞竿</span>  
<!-- 册4 葉2172a　Page:文淵閣四庫全書_0004冊.djvu/548 -->
<span style="margin-left: 2em">五言尤自長城又稱王稚欽吳明卿之五言律各</span>  
<span style="margin-left: 2em">集妙境專至而有餘朱彝尊靜志居詩話亦謂其</span>  
<span style="margin-left: 2em">音高秋竹色艷春蘭樂府古詩殊多精詣葢在正</span>  
<span style="margin-left: 2em">嘉之間何景明最爲俊逸廷陳之天骨雄秀抑亦</span>  
<span style="margin-left: 2em">驂乘矣若雜文則藻采太多華掩其實等諸自檜</span>
