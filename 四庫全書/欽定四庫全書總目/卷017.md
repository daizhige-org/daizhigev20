## 欽定四庫全書總目 卷十七　經部十七　詩類存目一

欽定四庫全書總目卷十七  
<span style="margin-left: 1em">經部十七</span>  
<span style="margin-left: 2em">詩類存目一</span>  
詩說一卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋張耒撰耒字文潛楚州淮陰人登進士第元祐</span>  
<span style="margin-left: 2em">中官至起居舍人紹聖中謫監黃州酒稅徽宗召</span>  
<span style="margin-left: 2em">爲太常寺<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">坐元祐黨復貶房州别駕黃州安置</span>  
<span style="margin-left: 2em">尋得自便居於陳州主管崇福宫卒事迹具宋史</span>  
<span style="margin-left: 2em">文苑傳是書本載柯山集中納喇性德以其集不</span>  
<!-- 册1 葉1449b　Page:文淵閣四庫全書_0001冊.djvu/412 -->
<span style="margin-left: 2em">甚傳因刻之通志堂經解中凡十二條如抑篇愼</span>  
<span style="margin-left: 2em">爾出話一條葢爲蘇軾烏臺詩案而發卷阿篇爾</span>  
<span style="margin-left: 2em">土宇昄章一條葢爲熙河之役而發餘亦多借抒</span>  
<span style="margin-left: 2em">熙寧時事不必盡與經義比附也</span>  
詩論一卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">宋程大昌撰大昌有易原巳著錄是書本載大昌</span>  
<span style="margin-left: 2em">考古編中故宋志不列其名朱彜尊經義考始别</span>  
<span style="margin-left: 2em">立標題謂之詩議曹溶學海類編則作詩論江南</span>  
<span style="margin-left: 2em">通志則作毛詩辨正考原本實作詩論則曹溶本</span>  
<!-- 册1 葉1452a　Page:文淵閣四庫全書_0001冊.djvu/413 -->
<span style="margin-left: 2em">是也又曹溶本作十八篇而彞尊引陸元輔之言</span>  
<span style="margin-left: 2em">謂程氏詩議十七篇一論古有二南而無國風之</span>  
<span style="margin-left: 2em">名二論南雅頌爲樂詩諸國爲徒詩三論南雅頌</span>  
<span style="margin-left: 2em">之爲樂無疑四論四始品目五論國風之名出於</span>  
<span style="margin-left: 2em">左荀六證左荀創標風名之悞七論逸詩有豳雅</span>  
<span style="margin-left: 2em">豳頌而無豳風以證風不得抗雅八論豳詩非七</span>  
<span style="margin-left: 2em">月九辨詩序不出子夏十辨小序綴詩出於衛宏</span>  
<span style="margin-left: 2em">十一辨詩序不可廢十二據季札序詩篇次知無</span>  
<span style="margin-left: 2em">風名<sub class="note-yuan">案此篇爲改定毛詩標題元輔此語未明</sub>十三論毛詩有古序所</span>  
<!-- 册1 葉1452b　Page:文淵閣四庫全書_0001冊.djvu/413 -->
<span style="margin-left: 2em">以勝於三家十四論採詩序詩因乎其地十五論</span>  
<span style="margin-left: 2em">南爲樂名十六論關雎爲文王詩<sub class="note-yuan">案此解周道闕而關雎作一語</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">非論文王元輔此語亦未明</sub>十七論詩樂及商魯二頌乃併末</span>  
<span style="margin-left: 2em">兩篇爲一考原本亦作十七篇元輔之言不爲無</span>  
<span style="margin-left: 2em">據然詳其文意論詩樂與論商魯頌了不相屬似</span>  
<span style="margin-left: 2em">考古編刻本悞合曹本分之亦非無見也其大㫖</span>  
<span style="margin-left: 2em">謂國風之名出漢儒之附會其說甚辨惟左傳風</span>  
<span style="margin-left: 2em">有采蘩采蘋語荀子風之所以爲風語不出漢儒</span>  
<span style="margin-left: 2em">無可指駁則以左氏爲秦人風字出於臆說謂荀</span>  
<!-- 册1 葉1453a　Page:文淵閣四庫全書_0001冊.djvu/413 -->
<span style="margin-left: 2em">子之學出於仲弓仲弓非商賜可與言詩之比故</span>  
<span style="margin-left: 2em">荀子所傳亦爲臆說近時蕭山毛奇齡據樂記正</span>  
<span style="margin-left: 2em">直而静廉而謙者宜歌風表記引詩我躬不閱遑</span>  
<span style="margin-left: 2em">恤我後又引詩心之憂矣於我歸說皆稱國風以</span>  
<span style="margin-left: 2em">駁詰大昌不知大昌之意惟在求勝於漢儒原不</span>  
<span style="margin-left: 2em">計經義之合否卽引樂記表記以詰之亦不難以</span>  
<span style="margin-left: 2em">戴記四十九篇指爲漢儒附會也觀其於左氏所</span>  
<span style="margin-left: 2em">言季札觀樂合於巳說者則以傳文爲可信所言</span>  
<span style="margin-left: 2em">風有采蘩采蘋不合巳說者則又以傳文爲不可</span>  
<!-- 册1 葉1453b　Page:文淵閣四庫全書_0001冊.djvu/413 -->
<span style="margin-left: 2em">信顚倒任意務便巳私是尚可與口舌爭乎且卽</span>  
<span style="margin-left: 2em">所謂可據者言之十五國風同謂之周樂南雅頌</span>  
<span style="margin-left: 2em">亦同謂之歌不云南雅頌奏樂國風徒歌也豈此</span>  
<span style="margin-left: 2em">傳又半可據半不可據乎傳又稱金奏肆夏之三</span>  
<span style="margin-left: 2em">工歌鹿鳴之三亦將謂頌八樂雅徒歌乎是與所</span>  
<span style="margin-left: 2em">引孔子正樂但言雅頌不言風而忘其亦不言南</span>  
<span style="margin-left: 2em">者同一不充其類而巳矣</span>  
詩疑二卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋王柏撰柏有書疑巳著錄書疑雖頗有竄亂尚</span>  
<!-- 册1 葉1456a　Page:文淵閣四庫全書_0001冊.djvu/414 -->
<span style="margin-left: 2em">未敢刪削經文此書則攻駁毛鄭不巳併本經而</span>  
<span style="margin-left: 2em">攻駁之攻駁本經不巳又併本經而刪削之其以</span>  
<span style="margin-left: 2em">行露首章爲亂入據列女傳爲說猶有所本也以</span>  
<span style="margin-left: 2em">小弁無逝我梁四句爲漢儒所妄補猶曰其詞與</span>  
<span style="margin-left: 2em">谷風相同似乎移掇也以下泉末章爲錯簡謂與</span>  
<span style="margin-left: 2em">上三章不類猶著其疑也至於召南刪野有死麕</span>  
<span style="margin-left: 2em">邶風刪靜女鄘風刪桑中衛風删氓有狐王風刪</span>  
<span style="margin-left: 2em">大車丘中有麻鄭風刪將仲子遵大路有女同車</span>  
<span style="margin-left: 2em">山有扶蘇籜兮狡童褰裳東門之墠丰風雨子衿</span>  
<!-- 册1 葉1456b　Page:文淵閣四庫全書_0001冊.djvu/414 -->
<span style="margin-left: 2em">野有蔓草溱洧秦風刪晨風齊風刪東方之日唐</span>  
<span style="margin-left: 2em">風刪綢繆葛生陳風刪東門之池東門之枌東門</span>  
<span style="margin-left: 2em">之楊防有鵲巢月出株林澤陂凡三十二篇<sub class="note-yuan">案書中所</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">列之目實止三十一篇疑傳刻者脫其一篇</sub>又曰小雅中凡雜以怨誚</span>  
<span style="margin-left: 2em">之語可謂不雅子今歸之王風且使小雅粲然整</span>  
<span style="margin-left: 2em">潔其所移之篇目雖未具列其降雅爲風巳明言</span>  
<span style="margin-left: 2em">之矣又曰桑中當曰采唐權輿當曰夏屋大東當</span>  
<span style="margin-left: 2em">曰小東則併篇名改之矣此自有六籍以來第一</span>  
<span style="margin-left: 2em">怪變之事也柏亦自知詆斥聖經爲公論所不許</span>  
<!-- 册1 葉1457a　Page:文淵閣四庫全書_0001冊.djvu/414 -->
<span style="margin-left: 2em">乃託詞於漢儒之竄入夫漢儒各尊師說字句或</span>  
<span style="margin-left: 2em">有異同至篇數則傳授昭然其增减一一可考如</span>  
<span style="margin-left: 2em">易雜卦傳爲河内女子壞老屋所得書出伏生者</span>  
<span style="margin-left: 2em">二十九篇孔安國以孔壁古文增十六篇而泰誓</span>  
<span style="margin-left: 2em">三篇亦爲河内女子所續得舜典首二十八字爲</span>  
<span style="margin-left: 2em">姚方興所上周禮考工記爲河間獻王所補具有</span>  
<span style="margin-left: 2em">明文下至左傳增其處者爲劉氏一句秦穆姬登</span>  
<span style="margin-left: 2em">臺履薪一段先儒亦具有記載惟詩不言有所增</span>  
<span style="margin-left: 2em">加安得指國風三十二篇爲漢儒竄入也王弼之</span>  
<!-- 册1 葉1457b　Page:文淵閣四庫全書_0001冊.djvu/414 -->
<span style="margin-left: 2em">易杜預之左傳以傳附經離其章句鄭元禮記目</span>  
<span style="margin-left: 2em">錄與劉向别錄不同亦咸有舊說惟詩不言有所</span>  
<span style="margin-left: 2em">更易安得謂王風之詩竟移入小雅也且春秋有</span>  
<span style="margin-left: 2em">三家可以互考故公羊經文增孔子生一條而左</span>  
<span style="margin-left: 2em">傳無詩有四家亦可以互考故三家般詩多於繹</span>  
<span style="margin-left: 2em">思一句毛詩無之見經典釋文毛詩都人士有首</span>  
<span style="margin-left: 2em">章而三家無之見禮記緇衣注卽韓詩雨無正多</span>  
<span style="margin-left: 2em">雨無其極二句宋人亦尚能道之見元城語錄一</span>  
<span style="margin-left: 2em">句一字之損益卽彼此參差昭昭乎不能掩也此</span>  
<!-- 册1 葉1460a　Page:文淵閣四庫全書_0001冊.djvu/415 -->
<span style="margin-left: 2em">三十二篇之竄入如在四家旣分以後則齊增者</span>  
<span style="margin-left: 2em">魯未必增魯增者韓未必增韓增者毛未必增斷</span>  
<span style="margin-left: 2em">不能如是之畫一如在四家未分以前則爲孔門</span>  
<span style="margin-left: 2em">之舊本確矣柏何人斯敢奮筆而進退孔子哉至</span>  
<span style="margin-left: 2em">於謂碩人第二章形容莊姜之色太䙝秦風黃鳥</span>  
<span style="margin-left: 2em">乃淺識之人所作則更直排刪定之失不復託詞</span>  
<span style="margin-left: 2em">於漢儒尤爲恣肆陳振孫書錄解題載陳鵬飛作</span>  
<span style="margin-left: 2em">詩解二十卷不解商頌魯頌以爲商頌當闕魯頌</span>  
<span style="margin-left: 2em">當廢其說巳妄猶未如柏之竟刪也後人乃以柏</span>  
<!-- 册1 葉1460b　Page:文淵閣四庫全書_0001冊.djvu/415 -->
<span style="margin-left: 2em">嘗師何基基師黃榦榦師朱子相距不過三傳遂</span>  
<span style="margin-left: 2em">併此書亦莫敢異議是門戸之見非天下之公義</span>  
<span style="margin-left: 2em">也</span>  
毛詩正變指南圖六卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">是書爲明末陳重光所刻前有李雯序謂其書爲</span>  
<span style="margin-left: 2em">宋人未竟之本故詳於大而畧於小今考卷首列</span>  
<span style="margin-left: 2em">漢迄宋諸儒訓故圖譜音訓之目頗叢雜無次第</span>  
<span style="margin-left: 2em">一卷全錄小序首句二卷作詩次序皆本鄭氏詩</span>  
<span style="margin-left: 2em">譜三卷世次四卷族譜五六卷雜釋名物俱爲簡</span>  
<!-- 册1 葉1461a　Page:文淵閣四庫全書_0001冊.djvu/415 -->
<span style="margin-left: 2em">畧惟五卷釋刻漏稍詳其義例淺陋不似古人著</span>  
<span style="margin-left: 2em">作且亦别無佐證疑卽重光自輯而託之舊本也</span>  
<span style="margin-left: 2em">重光字瑞義華亭人</span>  
詩義斷法五卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">不著撰人名氏卷首有建安日新書堂刋行字又</span>  
<span style="margin-left: 2em">有至正丙戌字葢元時所刻朱彜尊經義考載宋</span>  
<span style="margin-left: 2em">謝叔孫詩義斷法不列卷數注引江西通志曰叔</span>  
<span style="margin-left: 2em">孫南城人舉進士官翰林編修又載詩義斷法一</span>  
<span style="margin-left: 2em">卷不著名氏注曰見菉竹堂書目並云巳佚此本</span>  
<!-- 册1 葉1461b　Page:文淵閣四庫全書_0001冊.djvu/415 -->
<span style="margin-left: 2em">五卷與後一部一卷之數不符其叔孫之書歟首</span>  
<span style="margin-left: 2em">有自序詞極鄙俚殆不成文卷前冠以作義之法</span>  
<span style="margin-left: 2em">分總論冐題原題講題結題五則次爲學詩入門</span>  
<span style="margin-left: 2em">須知次爲先儒格言次爲總論六義皆剽竊陳言</span>  
<span style="margin-left: 2em">不出兔園冊子又書中但列擬題於經文刋削十</span>  
<span style="margin-left: 2em">七始於鄘風之干旄不知何取盖揣摩弋取之書</span>  
<span style="margin-left: 2em">本不爲解經而作也</span>  
國風尊經一卷<sub class="note-yuan">編修朱筠家藏本</sub>  
<span style="margin-left: 2em">舊本題明陶宗儀撰宗儀字九成黃巖人元末舉</span>  
<!-- 册1 葉1464a　Page:文淵閣四庫全書_0001冊.djvu/416 -->
<span style="margin-left: 2em">進士不中卽棄去累辭辟舉洪武中乃出爲教官</span>  
<span style="margin-left: 2em">事迹具明史文苑傳是書前有宗儀自序案孫作</span>  
<span style="margin-left: 2em">滄螺集有陶九成小傳備列其生平著述無此書</span>  
<span style="margin-left: 2em">名明史藝文志及朱彜尊經義考皆不著錄其書</span>  
<span style="margin-left: 2em">多用字說如序中解大小雅云雅知風者也故名</span>  
<span style="margin-left: 2em">相風解君子好逑云逑從求從行謂行而求之也</span>  
<span style="margin-left: 2em">解參差荇菜云荇從草從行謂草生水中而東西</span>
