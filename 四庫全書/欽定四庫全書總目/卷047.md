## 欽定四庫全書總目 卷四十七　史部三　編年類

欽定四庫全書總目卷四十七  
<span style="margin-left: 1em">史部三</span>  
<span style="margin-left: 2em">編年類</span>  
<span style="margin-left: 3em">司馬遷改編年爲紀傳荀悅又改紀傳爲編年</span>  
<span style="margin-left: 3em">劉知幾深通史法而史通分敘六家統歸二體</span>  
<span style="margin-left: 3em">則編年紀傳均正史也其不列爲正史者以班</span>  
<span style="margin-left: 3em">馬舊裁厯朝繼作編年一體則或有或無不能</span>  
<span style="margin-left: 3em">使時代相續故姑置焉無他義也今仍蒐羅遺</span>  
<span style="margin-left: 3em">帙次於正史俾得相輔而行隋志史部有起居</span>  
<!-- 册2 葉197b　Page:文淵閣四庫全書_0002冊.djvu/54 -->
<span style="margin-left: 3em">注一門著錄四十四部舊唐書載二十九部併</span>  
<span style="margin-left: 3em">實錄爲四十一部新唐書載二十九部存於今</span>  
<span style="margin-left: 3em">者穆天子傳六卷温大雅大唐創業起居注三</span>  
<span style="margin-left: 3em">卷而巳穆天子傳雖編次年月類小說傳記不</span>  
<span style="margin-left: 3em">可以爲信史實惟存温大雅一書不能自爲門</span>  
<span style="margin-left: 3em">目稽其體例亦屬編年今併合爲一猶舊唐書</span>  
<span style="margin-left: 3em">以實錄附起居注之意也</span>  
竹書紀年二卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">案晉書束晳傳晉咸和七年汲縣人發魏襄王冡</span>  
<!-- 册2 葉200a　Page:文淵閣四庫全書_0002冊.djvu/55 -->
<span style="margin-left: 2em">得古書七十五卷中有竹書紀年十三篇今世所</span>  
<span style="margin-left: 2em">行題沈約注亦與隋志相符顧炎武考證之學最</span>  
<span style="margin-left: 2em">爲精核所作日知錄中往往引以爲據然反覆推</span>  
<span style="margin-left: 2em">勘似非汲冡原書考平王東遷以後惟載晉事三</span>  
<span style="margin-left: 2em">家分晉以後惟載魏事是魏承晉史之明騐然晉</span>  
<span style="margin-left: 2em">靈公桃園之事董狐所書明見左傳孔子稱趙盾</span>  
<span style="margin-left: 2em">爲法受惡足知未改史文乃今本所載仍以趙穿</span>  
<span style="margin-left: 2em">蔽獄則非晉史之舊也束晳傳稱竹書載夏年多</span>  
<span style="margin-left: 2em">殷益干啟位殺之今本皆無此文又杜預註左傳</span>  
<!-- 册2 葉200b　Page:文淵閣四庫全書_0002冊.djvu/55 -->
<span style="margin-left: 2em">攜王奸命句引服䖍說以爲伯服疏併引束晳以</span>  
<span style="margin-left: 2em">爲伯盤今本乃有余由之說使竹書原有此文不</span>  
<span style="margin-left: 2em">應二人皆未睹則非束晳杜預所見本也郭璞註</span>  
<span style="margin-left: 2em">穆天子傳引紀年七條以今本核之相同者三條</span>  
<span style="margin-left: 2em">璞稱紀年而今在註中者三條璞時不應先有註</span>  
<span style="margin-left: 2em">且三條併爲一條文亦不屬其穆天子見西王母</span>  
<span style="margin-left: 2em">西王母止之曰有鳥ခ人一條今本無之則非郭</span>  
<span style="margin-left: 2em">璞所見本也隋書經籍志曰紀年皆用夏正建寅</span>  
<span style="margin-left: 2em">月爲歲首今本自入春秋以後時月並與經同全</span>  
<!-- 册2 葉201a　Page:文淵閣四庫全書_0002冊.djvu/55 -->
<span style="margin-left: 2em">從周正則非隋時所見本也水經注引竹書七十</span>  
<span style="margin-left: 2em">六條皆以晉國紀年如春秋之爲魯史而此本晉</span>  
<span style="margin-left: 2em">國之年皆附周下又引出公六年荀瑶城宅陽梁</span>  
<span style="margin-left: 2em">惠王元年鄴師邯鄲師次于平陽魏襄王六年秦</span>  
<span style="margin-left: 2em">取我焦及齊師伐趙東鄙圍中牟諸條今本皆無</span>  
<span style="margin-left: 2em">其他年月亦多舛異則非酈道元所見本也史通</span>  
<span style="margin-left: 2em">引竹書文王殺季厯今本作文丁又引竹書鄭桓</span>  
<span style="margin-left: 2em">公厲王之子今本錫王子多父命居洛在宣王二</span>  
<span style="margin-left: 2em">十二年王子多父爲鄭公在幽王二年皆不云厲</span>  
<!-- 册2 葉201b　Page:文淵閣四庫全書_0002冊.djvu/55 -->
<span style="margin-left: 2em">王子則非劉知幾所見本也文選註引竹書五條</span>  
<span style="margin-left: 2em">今惟有太甲殺伊尹一條則非李善所見本也開</span>  
<span style="margin-left: 2em">元占經引竹書四條今本皆無則非翟曇悉達所</span>  
<span style="margin-left: 2em">見本也史記索隱引竹書晉出公二十三年奔楚</span>  
<span style="margin-left: 2em">乃立昭公之孫是爲敬公今本作出公薨又引秦</span>  
<span style="margin-left: 2em">舆衛戰岸門惠王後元十一年會齊于平阿十三</span>  
<span style="margin-left: 2em">年會齊于甄齊桓公君母齊宣王后宋易成肝廢</span>  
<span style="margin-left: 2em">君自立楮里疾圍蒲七條今本皆無則非司馬貞</span>  
<span style="margin-left: 2em">所見本也穀梁傳疏引竹書紀年周昭王膠舟之</span>  
<!-- 册2 葉204a　Page:文淵閣四庫全書_0002冊.djvu/56 -->
<span style="margin-left: 2em">事以駁吕氏春秋今本但曰王陟無膠舟事則非</span>  
<span style="margin-left: 2em">楊士勛所見本也元豐九域志引竹書陰司馬敗</span>  
<span style="margin-left: 2em">燕公子翌于武垣一條今本亦無則非王存所見</span>  
<span style="margin-left: 2em">本也路史引竹書周武王年五十四辨武王非年</span>  
<span style="margin-left: 2em">九十三今本乃作九十三又註引竹書夏后不降</span>  
<span style="margin-left: 2em">六十九年證世紀五十九年之異今本乃亦作五</span>  
<span style="margin-left: 2em">十九路史又引梁惠王八年雨骨于赤鞞註又引</span>  
<span style="margin-left: 2em">夏桀末年社圻裂今本並無則非羅泌羅苹所見</span>  
<span style="margin-left: 2em">本也戰國䇿註引竹書魏救中山塞集胥口今本</span>  
<!-- 册2 葉204b　Page:文淵閣四庫全書_0002冊.djvu/56 -->
<span style="margin-left: 2em">無之則非鮑彪所見本也廣川書跋引竹書秦穆</span>  
<span style="margin-left: 2em">公十一年取靈丘今本無之則非董逌所見本也</span>  
<span style="margin-left: 2em">雖其他證以竹書往往相合然允征稱辰弗集于</span>  
<span style="margin-left: 2em">房說命稱舊學于甘盤均出梅賾古文尙書在西</span>  
<span style="margin-left: 2em">晉之後不應先見竹書豈亦明人鈔合諸書以爲</span>  
<span style="margin-left: 2em">之如十六國春秋類歟觀其以春秋合夏正斷斷</span>  
<span style="margin-left: 2em">爲胡傳盛行以後書也沈約註外又有小字夾行</span>  
<span style="margin-left: 2em">之註不知誰作中殷小庚一條稱約案史記作太</span>  
<span style="margin-left: 2em">庚則亦當爲約說考元和郡縣志魏武定七年始</span>  
<!-- 册2 葉205a　Page:文淵閣四庫全書_0002冊.djvu/56 -->
<span style="margin-left: 2em">置海州隋煬帝時始置衛縣而註舜在鳴條一條</span>  
<span style="margin-left: 2em">稱今海州夏啓十一年放武觀一條稱今頓邱衛</span>  
<span style="margin-left: 2em">縣則非約語矣又所註惟五帝三王最詳他皆寥</span>  
<span style="margin-left: 2em">寥而五帝三王皆全鈔宋書符瑞志語約不應旣</span>  
<span style="margin-left: 2em">著於史又不易一字移而爲此本之註然則此註</span>  
<span style="margin-left: 2em">亦依託耳自明以來流傳已久姑錄之以備一說</span>  
<span style="margin-left: 2em">其僞則終不可掩也</span>  
竹書統箋十二卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 1em">國朝徐文靖撰文靖有禹貢會箋巳著錄是編蓋作</span>  
<!-- 册2 葉205b　Page:文淵閣四庫全書_0002冊.djvu/56 -->
<span style="margin-left: 2em">於孫之騄考定竹書以後亦因僞沈約註爲之引</span>  
<span style="margin-left: 2em">證推闡首仿司馬貞補史記例作伏羲神農紀年</span>  
<span style="margin-left: 2em">題曰前編而自爲之註多據毛漸僞三墳殊失考</span>  
<span style="margin-left: 2em">正次爲雜述述竹書源流皆不入卷數其箋則依</span>  
<span style="margin-left: 2em">諸經註疏之例發明於各條之下蓋文靖誤以紀</span>  
<span style="margin-left: 2em">年爲原書又誤以其註眞出沈約故以箋自名如</span>  
<span style="margin-left: 2em">鄭元之於毛公也然其引證諸書皆著出典較孫</span>  
<span style="margin-left: 2em">之騄爲切實而考正地里訂正世系亦較之騄爲</span>  
<span style="margin-left: 2em">詳晰如坊本誤於外丙元年後係以小庚五年小</span>  
<!-- 册2 葉208a　Page:文淵閣四庫全書_0002冊.djvu/57 -->
<span style="margin-left: 2em">甲十七年雍已十二年太戊三十五年乃繼以二</span>  
<span style="margin-left: 2em">年陟葢舊本顚倒一頁重刻者因而仍之陳仁錫</span>  
<span style="margin-left: 2em">作四書考遂據以駁難異同文靖以殷本紀排比</span>  
<span style="margin-left: 2em">知其脫誤亦較之騄爲密也</span>  
漢紀三十卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">漢荀悅撰悅字仲豫潁陰人獻帝時官秘書監侍</span>  
<span style="margin-left: 2em">中後漢書附見其祖荀淑傳稱獻帝好典籍以班</span>  
<span style="margin-left: 2em">固漢書文繁難省乃令悅依左氏傳體爲漢紀三</span>  
<span style="margin-left: 2em">十篇詞約事詳論辨多美張璠漢記亦稱其因事</span>  
<!-- 册2 葉208b　Page:文淵閣四庫全書_0002冊.djvu/57 -->
<span style="margin-left: 2em">以明臧否致有典要大行於世唐劉知幾史通六</span>  
<span style="margin-left: 2em">家篇以悅書爲左傳家之首其二體篇又稱其厯</span>  
<span style="margin-left: 2em">代寶之有踰本傳班荀二體角力爭先其推之甚</span>  
<span style="margin-left: 2em">至故唐人試士以悅紀與史漢爲一科文獻通考</span>  
<span style="margin-left: 2em">載宋李燾跋曰悅爲此紀固不出班書亦時有所</span>  
<span style="margin-left: 2em">删潤而諫大夫王仁侍中王閎諫疏班書皆無之</span>  
<span style="margin-left: 2em">又稱司馬光編資治通鑑書太上皇事及五鳳郊</span>  
<span style="margin-left: 2em">泰畤之月皆舍班而從荀葢以悅修紀時固書猶</span>  
<span style="margin-left: 2em">未舛訛又稱其君蘭君簡端瑞興譽寛竟諸字與</span>  
<!-- 册2 葉209a　Page:文淵閣四庫全書_0002冊.djvu/57 -->
<span style="margin-left: 2em">漢書互異者先儒皆兩存之王銍作兩漢紀後序</span>  
<span style="margin-left: 2em">亦稱荀袁二紀於朝廷紀綱禮樂刑政治亂成敗</span>  
<span style="margin-left: 2em">忠邪是非之際指陳論著毎致意焉反復辨達明</span>  
<span style="margin-left: 2em">白條暢啓告當代而<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2618.svg?width=24" alt="四庫全書僻字第2618號（⿱乖一）" title="四庫全書僻字第2618號（⿱乖一）">訓無窮是宋人亦甚重其</span>  
<span style="margin-left: 2em">書也其中若壺關三老茂漢書無姓悅書云姓令</span>  
<span style="margin-left: 2em">狐朱雲請尙方劍漢書作斬馬悅書乃作斷馬證</span>  
<span style="margin-left: 2em">以唐張渭詩願得上方斷馬劍斬取朱門公子頭</span>  
<span style="margin-left: 2em">句知漢書字誤資考証者亦不一近時顧炎武曰</span>  
<span style="margin-left: 2em">知錄乃惟取其宣帝賜陳遂璽書一條及元康三</span>  
<!-- 册2 葉209b　Page:文淵閣四庫全書_0002冊.djvu/57 -->
<span style="margin-left: 2em">年封海昏侯詔一條能改正漢書三四字其餘則</span>  
<span style="margin-left: 2em">病其敘事索然無意味間或首尾不備其小有不</span>  
<span style="margin-left: 2em">同皆以班書爲長未免抑揚過當又曰紀王莽事</span>  
<span style="margin-left: 2em">自始建國元年以後則云其二年其三年以至其</span>  
<span style="margin-left: 2em">十五年以别於正統而盡没其天鳳地皇之號云</span>  
<span style="margin-left: 2em">云其語不置可否然不曰盡削而曰盡没似反病</span>  
<span style="margin-left: 2em">其疏畧者不知班書莽自爲傳自可載其僞號荀</span>  
<span style="margin-left: 2em">書以漢系編年豈可以莽紀元哉是亦非<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">論不</span>  
<span style="margin-left: 2em">足爲悅病也是書考李燾所跋自天聖中已無善</span>  
<!-- 册2 葉212a　Page:文淵閣四庫全書_0002冊.djvu/58 -->
<span style="margin-left: 2em">本明黃姬水所刋亦間有舛訛康熙中襄平蔣國</span>  
<span style="margin-left: 2em">祥蔣國祚與袁宏後漢紀合刻後附兩漢紀字句</span>  
<span style="margin-left: 2em">異同考一卷今用以參校較舊本稍完善焉</span>  
後漢紀三十卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">晉袁宏撰宏字彦伯陽夏人太元初官至東陽太</span>  
<span style="margin-left: 2em">守事迹具晉書文苑傳是書前有宏自序稱嘗讀</span>  
<span style="margin-left: 2em">後漢書煩穢雜亂聊以暇日撰集爲後漢紀其所</span>  
<span style="margin-left: 2em">綴會漢紀<sub class="note-yuan">案此漢紀葢指荀悅之書涉及東漢初事者非張璠書也</sub>謝承書司</span>
