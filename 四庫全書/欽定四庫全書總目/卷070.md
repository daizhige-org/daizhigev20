<span style="margin-left: 1em">史部二十六</span>  
<span style="margin-left: 2em">地理類三</span>  
南嶽小錄一巻<sub class="note-yuan">浙江汪汝瑮家藏本</sub>  
<span style="margin-left: 2em">唐道士李冲昭𢰅巻首有自序稱弱年悟道近歲</span>  
<span style="margin-left: 2em">依師洎臨嶽門頻訪靈跡徧閱古碑及衡山圖經</span>  
<span style="margin-left: 2em">湘中記仍致詰於師資長者嶽下耆年或得一事</span>  
<span style="margin-left: 2em">旋？篋笥撮而直書總成一巻案書中有咸通年</span>  
<span style="margin-left: 2em">號當作於懿宗以後序末所題壬戌歲蓋昭宗天</span>  
<!-- 册2 葉2009b　Page:文淵閣四庫全書_0002冊.djvu/507 -->
<span style="margin-left: 2em">復二年也舊唐書經籍志新唐書藝文志皆不著</span>  
<span style="margin-left: 2em">錄鄭樵通志藝文畧始載有此名與此本巻數相</span>  
<span style="margin-left: 2em">合惟冲昭作仲昭或傳刻誤歟書中先列五峯三</span>  
<span style="margin-left: 2em">澗次敘宫觀祠廟壇院之屬而以厯代得道飛昇</span>  
<span style="margin-left: 2em">之跡附之雖黃冠自張其教不無夸誕之詞而唐</span>  
<span style="margin-left: 2em">世名山洞府之書如盧鴻一嵩山記張宻廬山雜</span>  
<span style="margin-left: 2em">記令狐見堯玉笥山記杜光庭武夷山記今並無</span>  
<span style="margin-left: 2em">存此獨以舊本流傳勝境靈跡足資掌故是亦考</span>  
<span style="margin-left: 2em">圖經者所宜徵据矣此本爲明蔡汝楠守衡州時</span>  
<!-- 册2 葉2012a　Page:文淵閣四庫全書_0002冊.djvu/508 -->
<span style="margin-left: 2em">所刻前有小引亦謂所載事蹟名物悉與今本不</span>  
<span style="margin-left: 2em">同云</span>

<span style="margin-left: 2em">宋陳舜俞撰舜俞字令舉烏程人所居曰白牛村</span>  
<span style="margin-left: 2em">因自號白牛居士慶厯六年進士嘉祐四年又中</span>  
<span style="margin-left: 2em">制科第一厯官都官員外郎熈寧中出知山陰縣</span>  
<span style="margin-left: 2em">以不奉行靑苗法謫南康監稅事迹具宋史本傳</span>  
<span style="margin-left: 2em">舜俞謫官時與致仕劉渙游覽廬山嘗以六十日</span>  
<span style="margin-left: 2em">之力盡南北山水之勝每恨慧遠周景武輩作山</span>

<span style="margin-left: 2em">記疎畧而渙舊嘗雜錄聞見未暇詮次舜俞因採</span>  
<span style="margin-left: 2em">其說參以記載耆舊所傳晝則山行夜則發書考</span>  
<span style="margin-left: 2em">證<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3180.svg?width=24" alt="四庫全書僻字第3180號（泓）" title="四庫全書僻字第3180號（泓）">泉塊石具載不遺折衷是非必可傳而後已</span>  
<span style="margin-left: 2em">又作俯仰之圖尋山先後之次以冠之人服其勤</span>  
<span style="margin-left: 2em">自記云余始遊廬山問山中塔廟興廢及水石之</span>  
<span style="margin-left: 2em">名無能爲予言者雖言之往往襲謬失實因取九</span>  
<span style="margin-left: 2em">江圖經前人雜錄稽之本史或親至其處考騐銘</span>  
<span style="margin-left: 2em">志參訂耆老作廬山記其湮泐蕪没不可復知者</span>  
<span style="margin-left: 2em">則闕疑焉凡唐以前碑記因其有歲月甲子爵里</span>  
<!-- 册2 葉2013a　Page:文淵閣四庫全書_0002冊.djvu/508 -->
<span style="margin-left: 2em">之詳故并錄之庶或有補史氏云云其目有總敘</span>  
<span style="margin-left: 2em">山篇第一敘北山篇第二敘南山篇第三而無第</span>  
<span style="margin-left: 2em">四五篇圖亦不存勘騐永樂大典所缺亦同然北</span>  
<span style="margin-left: 2em">宋地志傳世者稀此書考据精核尤非後來廬山</span>  
<span style="margin-left: 2em">紀勝諸書所及雖經殘缺猶可寶貴故特錄而存</span>  
<span style="margin-left: 2em">之釋惠遠廬山記畧一卷舊載此本之末不知何</span>  
<span style="margin-left: 2em">人所附入今亦併錄存之備參考焉</span>  
赤松山志一卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">宋道士倪守約撰守約未詳何許人惟書前自敘</span>

<span style="margin-left: 2em">稱捨家辭父母來投師資又自署松山羽士知爲</span>  
<span style="margin-left: 2em">黃冠書中稱眞廟神廟孝廟寧廟知爲宋人人物</span>  
<span style="margin-left: 2em">之末稱咸淳年號知作於度宗時矣其書首敘皇</span>  
<span style="margin-left: 2em">初起皇初平兄弟仙迹以著是山靈異爲全書綱</span>  
<span style="margin-left: 2em">領次丹𩔖次洞穴類次山𩔖次水𩔖次宫宇𩔖次</span>  
<span style="margin-left: 2em">人物𩔖次制誥𩔖次碑籍𩔖書末又有正統四年</span>  
<span style="margin-left: 2em">明英宗御製數行非詩非文似乎聨額與此書篇</span>  
<span style="margin-left: 2em">頁不相屬葢後人所附入明代刊本喜於竄亂古</span>  
<span style="margin-left: 2em">書往往如是今刪汰不錄以存守約之舊焉</span>

<span style="margin-left: 2em">明田汝成撰汝成有炎徼紀聞巳著錄是書雖以</span>  
<span style="margin-left: 2em">逰覽爲名多紀湖山之勝實則關於宋史者爲多</span>  
<span style="margin-left: 2em">故於高宗而後偏安逸豫每一篇之中三致意焉</span>  
<span style="margin-left: 2em">宋乾道間周淙撰臨安志十五卷咸淳間潜說友</span>  
<span style="margin-left: 2em">又續成一百卷湖山特其中之一目例不當詳吳</span>  
<span style="margin-left: 2em">自牧作夢梁錄周密作武林舊事於歲時風俗特</span>  
<span style="margin-left: 2em">詳而山川古跡又在所畧惟汝成此書因名勝而</span>  
<span style="margin-left: 2em">附以事蹟鴻纎鉅細一一兼該非惟可廣見聞併</span>

<span style="margin-left: 2em">可以考文獻其體在地志雜史之間與明人逰記</span>  
<span style="margin-left: 2em">徒以觴咏登臨流連光景者不侔其志餘二十六</span>

<span style="margin-left: 2em">其義例之善也惟所徵故實悉不列書名遂使出</span>  
<span style="margin-left: 2em">典無徵莫能考證其眞僞是則明人之通弊汝成</span>  
<span style="margin-left: 2em">亦未能免俗者矣</span>

<span style="margin-left: 2em">舉厯代之制葢疆域明則先獻有所斷限職制明</span>
