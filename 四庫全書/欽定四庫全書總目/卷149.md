## 欽定四庫全書總目 卷一百四十九　集部二　別集類二

欽定四庫全書總目卷一百四十九  
<span style="margin-left: 1em">集部二</span>  
<span style="margin-left: 2em">别集𩔖二</span>  
東臯子集三卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">唐王績撰績字無功太原祁人隋大業中授秘書</span>  
<span style="margin-left: 2em">省正字出爲六合丞歸隱北山東臯自號東臯子</span>  
<span style="margin-left: 2em">唐初以前官待詔門下復求爲太樂丞後乃解官</span>  
<span style="margin-left: 2em">歸里是身事兩朝皆以仕途不逹乃退而放浪於</span>  
<span style="margin-left: 2em">山林新唐書列之隠逸傳所未喻也然績爲王通</span>  
<!-- 册4 葉97b　Page:文淵閣四庫全書_0004冊.djvu/29 -->
<span style="margin-left: 2em">之弟而志趣高雅不隨通聚徒講學獻䇿干進其</span>  
<span style="margin-left: 2em">人品亦不可及矣史稱其簡放嗜酒嘗作醉鄕記</span>  
<span style="margin-left: 2em">五斗先生傳無心子傳其醉鄕記爲蘇軾所稱然</span>  
<span style="margin-left: 2em">他文亦疎野有致其詩惟野望一首爲世傳誦然</span>  
<span style="margin-left: 2em">如石竹詠意境高古薛記室收過莊見尋詩二十</span>  
<span style="margin-left: 2em">四韵氣格遒健皆能滌初唐俳偶板滯之習置之</span>  
<span style="margin-left: 2em">開元天寶間弗能别也唐書藝文志載績集五卷</span>  
<span style="margin-left: 2em">陳振孫書錄解題亦云其友吕才鳩訪遺文編成</span>  
<span style="margin-left: 2em">五卷爲之序而今本實止三卷又晁公武讀書志</span>  
<!-- 册4 葉100a　Page:文淵閣四庫全書_0004冊.djvu/30 -->
<span style="margin-left: 2em">引吕才序稱績年十五謁楊素占對英辨薛道衡</span>  
<span style="margin-left: 2em">見其登龍門憶禹賦嘆爲今之庾信且載其卜筮</span>  
<span style="margin-left: 2em">之驗者數事今本吕才序尙存而晁公武所引之</span>  
<span style="margin-left: 2em">文則無之又序稱鳩訪未畢緝爲三卷與書錄解</span>  
<span style="margin-left: 2em">題不合其登龍門一賦亦不載集中或宋末本集</span>  
<span style="margin-left: 2em">已佚後人從文苑英華文粹諸書中采績詩文彚</span>  
<span style="margin-left: 2em">爲此編而僞託才序以冠之未可知也此本爲明</span>  
<span style="margin-left: 2em">崇禎中刋本卷首尙有陸淳序一首晁陳二家目</span>  
<span style="margin-left: 2em">中皆未言及其眞僞亦在兩可間矣</span>  
<!-- 册4 葉100b　Page:文淵閣四庫全書_0004冊.djvu/30 -->
寒山子詩集二卷附豐干拾得詩一卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">案寒山子貞觀中天台廣興縣僧居於寒巖時還</span>  
<span style="margin-left: 2em">往國淸寺豐干拾得則皆國淸寺僧也世傳台州</span>  
<span style="margin-left: 2em">刺史閭邱允遇三僧事踪跡甚怪盖莫得而考證</span>  
<span style="margin-left: 2em">矣其詩相傳卽允令寺僧道翹尋寒山平日於竹</span>  
<span style="margin-left: 2em">木石壁上及人家㕔壁所書得三百餘首又取拾</span>  
<span style="margin-left: 2em">得土地堂壁上所書偈言並纂集成卷豐干則僅</span>  
<span style="margin-left: 2em">存房中壁上詩二首允自爲之序宋時又名三隱</span>  
<span style="margin-left: 2em">集見淳熙十六年沙門道南所作記中唐書藝文</span>  
<!-- 册4 葉101a　Page:文淵閣四庫全書_0004冊.djvu/30 -->
<span style="margin-left: 2em">志載寒山詩入釋家𩔖作七卷今本併爲一卷以</span>  
<span style="margin-left: 2em">拾得豐干詩别爲一卷附之則明新安吳明春所</span>  
<span style="margin-left: 2em">校刻也王士禎居易錄云寒山詩詩家每稱其鸚</span>  
<span style="margin-left: 2em">鵡花間弄琵琶月下彈長歌三月響短舞萬人㸔</span>  
<span style="margin-left: 2em">謂其有唐調<sub class="note-yuan">案此明江盈科雪濤評語士禎引之寒山子卽唐人盈科以爲有唐調蓋</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">偶未考其時代謹附訂於此</sub>其詩有工語有率語有莊語有諧</span>  
<span style="margin-left: 2em">語至云不煩鄭氏箋豈待毛公解又似儒生語大</span>  
<span style="margin-left: 2em">抵佛語菩薩語也今觀所作皆信手拈弄全作禪</span>  
<span style="margin-left: 2em">門偈語不可復以詩格繩之而機趣橫溢多足以</span>  
<!-- 册4 葉101b　Page:文淵閣四庫全書_0004冊.djvu/30 -->
<span style="margin-left: 2em">資勸戒且專集傳自唐時行世已久今仍著之於</span>  
<span style="margin-left: 2em">錄以備釋氏文字之一種焉又案太平廣記引仙</span>  
<span style="margin-left: 2em">傳拾遺曰寒山子者不知其名氏大厯中隱居天</span>  
<span style="margin-left: 2em">台翠屏山其山深邃當暑有雪亦名寒巖因自號</span>  
<span style="margin-left: 2em">寒山子好爲詩每得一篇一句輙題於𣗳間石上</span>  
<span style="margin-left: 2em">有好事者隨而錄之凡三百餘篇多述山林幽隱</span>  
<span style="margin-left: 2em">之興或譏諷時態能警勵流俗桐栢徴君徐靈府</span>  
<span style="margin-left: 2em">序而集之分爲三卷行於人問云云則寒山子又</span>  
<span style="margin-left: 2em">爲中唐仙人與閭邱允事又異無從深考姑就文</span>  
<!-- 册4 葉104a　Page:文淵閣四庫全書_0004冊.djvu/31 -->
<span style="margin-left: 2em">論文可矣</span>  
王子安集十六卷<sub class="note-yuan">山東廵撫採進本</sub>  
<span style="margin-left: 2em">唐王勃撰唐書文苑傳稱其文集三十卷而楊炯</span>  
<span style="margin-left: 2em">集序則謂分爲二十卷具諸篇目洪邁容齋隨筆</span>  
<span style="margin-left: 2em">亦稱今存者二十卷蓋猶舊本明以來其集已佚</span>  
<span style="margin-left: 2em">原目遂不可考世所傳初唐十二家集僅載勃詩</span>  
<span style="margin-left: 2em">賦二卷闕畧殊甚故皇甫汸作楊炯集序稱王詩</span>  
<span style="margin-left: 2em">賦之餘未睹他製此本乃明崇禎中閩人張燮搜</span>  
<span style="margin-left: 2em">緝文苑英華諸書編爲一十六卷雖非唐宋之舊</span>  
<!-- 册4 葉104b　Page:文淵閣四庫全書_0004冊.djvu/31 -->
<span style="margin-left: 2em">而以視别本則較爲完善矣勃文爲四傑之冠儒</span>  
<span style="margin-left: 2em">者頗病其浮艷案叚成式酉陽雜爼曰張燕公嘗</span>  
<span style="margin-left: 2em">讀勃夫子學堂碑頌帝車南指遁七曜於中階華</span>  
<span style="margin-left: 2em">蓋西臨高五雲於太甲四句悉不解訪之一公<sub class="note-yuan">案一</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">公謂僧一行也</sub>一公言北斗建午七曜在南方有是之祥</span>  
<span style="margin-left: 2em">無位聖人當出華蓋以下卒不可悉洪邁容齋隨</span>  
<span style="margin-left: 2em">筆亦曰王勃等四子之文皆精切有本原其用駢</span>  
<span style="margin-left: 2em">麗作記序碑碣蓋一時體格如此而後來頗議之</span>  
<span style="margin-left: 2em">杜詩云王楊盧駱當時體輕薄爲文哂未休爾曹</span>  
<!-- 册4 葉105a　Page:文淵閣四庫全書_0004冊.djvu/31 -->
<span style="margin-left: 2em">身與名俱滅不廢江河萬古流正謂此耳身名俱</span>  
<span style="margin-left: 2em">滅以責輕薄子江河萬古指四子也韓公滕王閣</span>  
<span style="margin-left: 2em">記云江南多游觀之美而滕王閣獨爲第一及得</span>  
<span style="margin-left: 2em">三王爲序賦記等壯其文詞註謂王勃作遊閣序</span>  
<span style="margin-left: 2em">又云中丞命爲記竊喜載名其上詞列三王之次</span>  
<span style="margin-left: 2em">有榮耀焉則韓之所以推勃亦爲不淺矣夫一行</span>  
<span style="margin-left: 2em">叚成式博洽冠絶古今杜甫韓愈詩文亦冠絶古</span>  
<span style="margin-left: 2em">今而其推勃如是枵腹白戰之徒掇拾語錄之糟</span>  
<span style="margin-left: 2em">粕乃沾沾焉而動其喙殆所謂蚍蜉撼樹者歟今</span>  
<!-- 册4 葉105b　Page:文淵閣四庫全書_0004冊.djvu/31 -->
<span style="margin-left: 2em">錄勃集併錄成式及邁之所記庶耳食者無輕詆</span>  
<span style="margin-left: 2em">焉</span>  
盈川集十卷附錄一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">唐楊炯撰唐書文苑傳稱其文集本三十卷晁公</span>  
<span style="margin-left: 2em">武讀書志僅著錄二十卷云今多亡逸是宋代已</span>  
<span style="margin-left: 2em">非完本然其本今亦不傳此乃明萬厯中龍游童</span>  
<span style="margin-left: 2em">佩從諸書裒集詮次成編併以本傳及贈答之文</span>  
<span style="margin-left: 2em">評論之語别爲附錄一卷皇甫汸爲之序凡賦八</span>  
<span style="margin-left: 2em">首詩三十四首雜文三十九首文苑英華載其彭</span>  
<!-- 册4 葉108a　Page:文淵閣四庫全書_0004冊.djvu/32 -->
<span style="margin-left: 2em">城公夫人爾朱氏墓誌銘一首伯母東平郡夫人</span>  
<span style="margin-left: 2em">李氏墓誌銘一首列庾信文後明人因誤編入信</span>  
<span style="margin-left: 2em">集中此本收爾朱氏誌一篇而李氏誌仍不載則</span>  
<span style="margin-left: 2em">蒐羅尙有所遺也舊唐書本傳最稱其盂蘭盆賦</span>  
<span style="margin-left: 2em">然炯之麗製不止此篇劉昫殆以爲奏御之作故</span>  
<span style="margin-left: 2em">特加紀錄歟傳又載其駁太常博士蘇知幾冕服</span>  
<span style="margin-left: 2em">議一篇引援經義排斥游談炯文之最有根柢者</span>  
<span style="margin-left: 2em">知其詞章瑰麗由於貫穿興籍不止渉獵浮華而</span>  
<span style="margin-left: 2em">新唐書本傳刪之不載蓋猶本紀不載詔令之意</span>  
<!-- 册4 葉108b　Page:文淵閣四庫全書_0004冊.djvu/32 -->
<span style="margin-left: 2em">是米祁之偏見非定評也又新舊唐書並稱炯爲</span>  
<span style="margin-left: 2em">政嚴酷則非循吏可槩見童佩序稱盈川廢縣在</span>  
<span style="margin-left: 2em">瀫水北其地𨽻龍邱去郡四十餘里今址巋然獨</span>  
<span style="margin-left: 2em">存炯令盈川無何卒縣尋罷民尸祝其地至今春</span>  
<span style="margin-left: 2em">秋不輟是則因其文藝而更粉飾其治績亦非公</span>  
<span style="margin-left: 2em">論矣</span>  
盧昇之集七卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">唐盧照隣撰唐書文苑傳稱照隣初爲鄧王府典</span>  
<span style="margin-left: 2em">籖調新都尉以病去官後手足攣廢竟自沉潁水</span>  
<!-- 册4 葉109a　Page:文淵閣四庫全書_0004冊.djvu/32 -->
<span style="margin-left: 2em">而死考集中相里夫人檀龕序稱乾封紀歲當爲</span>  
<span style="margin-left: 2em">乾封元年丙寅對蜀父老問稱龍集荒落當爲總</span>  
<span style="margin-left: 2em">章二年巳巳皆在益州時所作病梨樹賦序稱癸</span>  
<span style="margin-left: 2em">酉之歲卧病長安則其罷官當在咸亨四年以前</span>  
<span style="margin-left: 2em">計其覊栖一尉僅五六年又窮魚賦序稱曾以橫</span>  
<span style="margin-left: 2em">事被拘將致之深議則中間又遭非罪其病廢以</span>  
<span style="margin-left: 2em">後與洛陽名流朝士乞藥値書至每人求乞錢二</span>  
<span style="margin-left: 2em">千其貧亦可想見蓋文士之極坎坷者故平生所</span>  
<span style="margin-left: 2em">作大抵歡寡愁殷有騷人之遺響亦遭遇使之然</span>  
<!-- 册4 葉109b　Page:文淵閣四庫全書_0004冊.djvu/32 -->
<span style="margin-left: 2em">也史又稱王楊盧駱以文章齊名楊炯嘗謂愧在</span>  
<span style="margin-left: 2em">盧前恥居王後張說則曰盈川文如懸河酌之不</span>  
<span style="margin-left: 2em">竭優於盧而不减王恥居後信然愧在前謙也今</span>  
<span style="margin-left: 2em">觀照鄰之文似不及王楊駱三家之宏放疑說之</span>  
<span style="margin-left: 2em">論爲然然所傳篇什獨少未可以一斑槩全豹杜</span>  
<span style="margin-left: 2em">甫均以江河萬古許之似難執殘編斷簡以强定</span>  
<span style="margin-left: 2em">低昻况張鷟朝野僉載亦記是語而作照鄰謂喜</span>  
<span style="margin-left: 2em">居王後恥在駱前文人品目多一時興到之言尤</span>  
<span style="margin-left: 2em">未可據爲定論也其集晁氏陳氏書目俱作十卷</span>  
<!-- 册4 葉112a　Page:文淵閣四庫全書_0004冊.djvu/33 -->
<span style="margin-left: 2em">此本僅七卷則其散佚者已多又窮魚賦序稱嘗</span>  
<span style="margin-left: 2em">思報德故冠之篇首則照隣自編之集當以是賦</span>  
<span style="margin-left: 2em">爲第一而此本列秋霖馴鳶二賦後其與在朝諸</span>  
<span style="margin-left: 2em">賢書亦非完本知由後人掇拾而成非其舊帙矣</span>
