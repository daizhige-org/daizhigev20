## 欽定四庫全書總目 卷一百四十一　子部五十一　小說家類二

欽定四庫全書總目卷一百四十一  
<span style="margin-left: 1em">子部五十一</span>  
<span style="margin-left: 2em">小說家類二</span>  
東軒筆錄十五卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋魏泰撰泰字道輔襄陽人曾布之婦弟也桐江</span>  
<span style="margin-left: 2em">詩話載其試院中因上請忿爭毆主文幾死坐是</span>  
<span style="margin-left: 2em">不得取應潘子眞詩話稱其博極羣書尤能談朝</span>  
<span style="margin-left: 2em">野可喜事王銍䟦范仲尹墓誌稱其場屋不得志</span>  
<span style="margin-left: 2em">喜僞作他人著書如志怪集括異志倦遊錄盡假</span>  
<!-- 册3 葉3865b　Page:文淵閣四庫全書_0003冊.djvu/971 -->
<span style="margin-left: 2em">名武人張師正又不能自抑作東軒筆錄用私喜</span>  
<span style="margin-left: 2em">怒誣衊前人最後作碧雲騢假作梅堯臣毁及范</span>  
<span style="margin-left: 2em">仲淹晁公武讀書志稱其元祐中記少時所聞成</span>  
<span style="margin-left: 2em">此書是非多不可信心喜章惇數稱其長則大槩</span>  
<span style="margin-left: 2em">巳可見又摘王曾登甲科劉翬爲翰林學士相戲</span>  
<span style="margin-left: 2em">事嵗月差舛相去幾二十年則泰是書宋人無不</span>  
<span style="margin-left: 2em">詆諆之而流傳至今則以其書自報復恩怨以外</span>  
<span style="margin-left: 2em">所記雜事亦多可採故也</span>  
泊宅編三卷<sub class="note-yuan">内府藏本</sub>  
<!-- 册3 葉3868a　Page:文淵閣四庫全書_0003冊.djvu/972 -->
<span style="margin-left: 2em">宋方勺撰勺有靑溪冦軌巳著錄勺家本婺州後</span>  
<span style="margin-left: 2em">徙居湖州之西溪湖有張志和泊舟處後人以志</span>  
<span style="margin-left: 2em">和有泛宅浮家之語謂之泊宅村勺寓其間因自</span>  
<span style="margin-left: 2em">號泊宅村翁是編葢卽是時所作也宋史藝文志</span>  
<span style="margin-left: 2em">載勺泊宅編十卷此本僅三卷乃商維濬載入稗</span>  
<span style="margin-left: 2em">海者明人傳刻古書每多臆爲竄亂今無别本可</span>  
<span style="margin-left: 2em">校不知其爲原帙否矣所載皆元祐迄政和間朝</span>  
<span style="margin-left: 2em">野舊事於王安石張商英輩皆有不滿之詞葢亦</span>  
<span style="margin-left: 2em">公論至宗澤乃其鄉里而徽宗時功名未盛故勺</span>  
<!-- 册3 葉3868b　Page:文淵閣四庫全書_0003冊.djvu/972 -->
<span style="margin-left: 2em">頗譏其好殺則是非未必盡允又袁文甕牖閒評</span>  
<span style="margin-left: 2em">據欽宗實錄知欽宗卽位之日王黼入賀巳勅閤</span>  
<span style="margin-left: 2em">門使勿納卽貶崇信軍節度使賜死於路而勺乃</span>  
<span style="margin-left: 2em">記其有從幸龍德宫獻詩識者指以爲讖事則記</span>  
<span style="margin-left: 2em">載亦或失實然其間遺聞軼事摭拾甚多亦考古</span>  
<span style="margin-left: 2em">者所不廢書中間有附注如教授誤據建板坤爲</span>  
<span style="margin-left: 2em">金一條言不欲顯其姓名而條下注曰姚祐尚書</span>  
<span style="margin-left: 2em">也又秦觀贈妓陶心詞一條條下注曰此乃誤記</span>  
<span style="margin-left: 2em">東坡詞云云皆似非勺之自注然詳其詞氣當亦</span>  
<!-- 册3 葉3869a　Page:文淵閣四庫全書_0003冊.djvu/972 -->
<span style="margin-left: 2em">宋人筆也</span>  
珍席放談二卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋高晦叟撰晦叟仕履無可考所紀上自太祖下</span>  
<span style="margin-left: 2em">及哲宗時事則崇寧以後人也是書宋史藝文志</span>  
<span style="margin-left: 2em">不著錄惟文淵閣書目載有一冊世無傳本今散</span>  
<span style="margin-left: 2em">見於永樂大典者尚可裒緝成編謹採集排綴𨤲</span>  
<span style="margin-left: 2em">爲上下二卷書中於朝廷典章制度沿革損益及</span>  
<span style="margin-left: 2em">士大夫言行可爲法鑒者隨所聞見分條錄載如</span>  
<span style="margin-left: 2em">王旦之友悌吕夷簡之識度富弼之避嫌韓琦之</span>  
<!-- 册3 葉3869b　Page:文淵閣四庫全書_0003冊.djvu/972 -->
<span style="margin-left: 2em">折佞其事皆本傳所未詳可補史文之闕特間加</span>  
<span style="margin-left: 2em">評論是非軒輊徃徃不能持平又當王氏學術盛</span>  
<span style="margin-left: 2em">行之時於安石多曲加迴䕶頗乖公議然一代掌</span>  
<span style="margin-left: 2em">故猶藉以考見大凡所謂識小之流於史學固不</span>  
<span style="margin-left: 2em">無裨助也</span>  
鐵圍山叢談六卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">宋蔡絛撰絛字約之自號百衲居士興化仙遊人</span>  
<span style="margin-left: 2em">蔡京之季子也官至徽猷閣待制京敗流白州以</span>  
<span style="margin-left: 2em">死宋史附載京傳末稱宣和六年京再起領三省</span>  
<!-- 册3 葉3872a　Page:文淵閣四庫全書_0003冊.djvu/973 -->
<span style="margin-left: 2em">目昏眊不能視事悉决於絛凡京所判皆絛爲之</span>  
<span style="margin-left: 2em">且代京入奏由是恣爲姦利竊弄威柄宰臣白時</span>  
<span style="margin-left: 2em">中李邦彦惟奉行文書其罪蓋與京等曾敏行獨</span>  
<span style="margin-left: 2em">醒雜志則載絛作西淸詩話多稱引蘇黃諸人竟</span>  
<span style="margin-left: 2em">以崇尚元祐之學爲言者論列蓋雖盗權怙𫝑而</span>  
<span style="margin-left: 2em">知博風雅之名者陳振孫書錄解題稱西淸詩話</span>  
<span style="margin-left: 2em">乃絛使其客爲之殆以蔡攸領袖書局懵不知學</span>  
<span style="margin-left: 2em">爲物論所不歸故疑絛所著作亦出假手然此書</span>  
<span style="margin-left: 2em">作於竄逐之後黨與解散誰與捉乃而叙述舊聞</span>  
<!-- 册3 葉3872b　Page:文淵閣四庫全書_0003冊.djvu/973 -->
<span style="margin-left: 2em">具有文采則謂之驕恣紈袴則可不能謂之不知</span>  
<span style="margin-left: 2em">書也書中稱高宗爲今上謝石相字一條稱中原</span>  
<span style="margin-left: 2em">傾覆後二十一年爲紹興十七年徽宗買茴香一</span>  
<span style="margin-left: 2em">條稱中興嵗戊辰爲紹興十八年又趙鼎亦卒於</span>  
<span style="margin-left: 2em">紹興十七年而此書記鼎卒後王趯坐調䕶鼎被</span>  
<span style="margin-left: 2em">劾罷官過白州見絛之事是南渡後二十餘年尚</span>  
<span style="margin-left: 2em">謫居無恙亦可云倖逃顯戮矣絛所作北征紀實</span>  
<span style="margin-left: 2em">二卷述伐燕之事陳振孫謂其歸罪童贯蔡攸爲</span>  
<span style="margin-left: 2em">蔡京文飾此書所叙京事亦往往如是如史稱京</span>  
<!-- 册3 葉3873a　Page:文淵閣四庫全書_0003冊.djvu/973 -->
<span style="margin-left: 2em">患言者議已作御筆宻進丐徽宗親書以降絛則</span>  
<span style="margin-left: 2em">稱政和三四年上自攬權綱政歸九重皆以御筆</span>  
<span style="margin-left: 2em">從事史稱京由童貫以進又稱宦官宫妾合詞譽</span>  
<span style="margin-left: 2em">京絛則稱京力遏宦官遏之不得更反折角史稱</span>  
<span style="margin-left: 2em">范袓禹劉安世皆因京遠竄絛則謂京欲援復安</span>  
<span style="margin-left: 2em">世及陳瓘而不能巳則與祖禹子温最相契其巧</span>  
<span style="margin-left: 2em">爲彌縫大抵類此惟於其兄攸無恕詞葢以攸嘗</span>  
<span style="margin-left: 2em">劾絛又請京殺絛故也至於元祐黨籍不置一語</span>  
<span style="margin-left: 2em">詞氣之間頗與其父異趣於三蘇尤極意推崇而</span>  
<!-- 册3 葉3873b　Page:文淵閣四庫全書_0003冊.djvu/973 -->
<span style="margin-left: 2em">丁仙現一條乃深詆王安石新法則仍其西淸詩</span>  
<span style="margin-left: 2em">話之旨也他如述九璽之源流元圭之形製九鼎</span>  
<span style="margin-left: 2em">之鑄造三館之建置大晟樂之宫律及徽宗五改</span>  
<span style="margin-left: 2em">年號之義公主初改帝嬴後改帝姬之故宣和書</span>  
<span style="margin-left: 2em">譜畫譜博古圖之緣起記所目覩皆較他書爲詳</span>  
<span style="margin-left: 2em">核以及辨禁中無六更之例宫花有三等之别俗</span>  
<span style="margin-left: 2em">諺包彈之始粤人雞卜之法諸葛氏筆張滋墨米</span>  
<span style="margin-left: 2em">芾研山大觀端研玻璃母龍涎香薔薇水沈水香</span>  
<span style="margin-left: 2em">合浦珠鎭庫帶藕絲燈百衲琴建溪茶姚黃花諸</span>  
<!-- 册3 葉3876a　Page:文淵閣四庫全書_0003冊.djvu/974 -->
<span style="margin-left: 2em">條皆足以資考證廣異聞又如陳師道後山詩話</span>  
<span style="margin-left: 2em">稱蘇軾詞如教坊雷大使舞諸家引爲故實而不</span>  
<span style="margin-left: 2em">知雷爲何人觀此書乃知爲雷中慶宣和中以善</span>  
<span style="margin-left: 2em">舞隸教坊三經新義宋人皆稱王安石觀此書乃</span>  
<span style="margin-left: 2em">知惟周禮爲安石親筆詩書二經實出王雱又徽</span>  
<span style="margin-left: 2em">宗繪事世稱絶藝觀此書乃知皆畫院供奉代爲</span>  
<span style="margin-left: 2em">染寫非眞自作尤厯來賞鑒家所未言其人雖不</span>  
<span style="margin-left: 2em">足道以其書論之亦說部中之佳本矣文獻通考</span>  
<span style="margin-left: 2em">作五卷此本實六卷或通考爲傳寫之誤歟</span>  
<!-- 册3 葉3876b　Page:文淵閣四庫全書_0003冊.djvu/974 -->
國老談苑一卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">舊本題夷門隱叟王君玉撰考陳振孫書錄解題</span>  
<span style="margin-left: 2em">宋史藝文志作國老閒談卷數與此相合而注稱</span>  
<span style="margin-left: 2em">夷門君玉撰不著其姓然則此名後人所改王字</span>  
<span style="margin-left: 2em">亦後人所增也是編所紀乃宋太祖太宗眞宗三</span>  
<span style="margin-left: 2em">朝雜事於當時士大夫頗有所毁譽尤推重田錫</span>  
<span style="margin-left: 2em">而貶斥陶穀其餘如馮拯諸人俱不免於㣲詞雖</span>  
<span style="margin-left: 2em">間或抑揚過情而大致猶據實可信如范質不受</span>  
<span style="margin-left: 2em">賂遺竇儀議今皇帝開封尹署勅趙普請從征上</span>  
<!-- 册3 葉3877a　Page:文淵閣四庫全書_0003冊.djvu/974 -->
<span style="margin-left: 2em">黨曹彬平蜀回囊中惟圖書諸條宋史皆採入本</span>  
<span style="margin-left: 2em">傳中他亦多敘述詳贍足與史文相叅攷惟記太</span>  
<span style="margin-left: 2em">祖淸流關之戰謂臨陣親斬僞驍將皇甫暉不知</span>  
<span style="margin-left: 2em">暉兵敗見擒送壽州行在周世宗尚賜以金帶鞍</span>  
<span style="margin-left: 2em">馬因創甚不肯治而死並非戮之陣前又謂是時</span>  
<span style="margin-left: 2em">環滁僧寺皆鳴鐘遂爲定制案滁人一日五時鳴</span>  
<span style="margin-left: 2em">鐘乃後人感暉之義以資追薦亦非爲太祖則戰</span>  
<span style="margin-left: 2em">而起此則傳聞之訛異未可槪從至謂太宗嚮用</span>  
<span style="margin-left: 2em">老成冦凖欲求速進遂餌地黃蘆菔以求白髪恐</span>  
<!-- 册3 葉3877b　Page:文淵閣四庫全書_0003冊.djvu/974 -->
<span style="margin-left: 2em">凖亦未必至是也</span>  
道山淸話一卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">不著撰人名氏說郛摘其數條刻之題曰宋王暐</span>  
<span style="margin-left: 2em">案書末有暐䟦語云先大父國史在館閣最久多</span>  
<span style="margin-left: 2em">識前輩嘗以聞見著館祕錄曝書記并此書爲三</span>  
<span style="margin-left: 2em">仍嵗兵火散失不存近方得此書於南豐曾仲存</span>  
<span style="margin-left: 2em">家因手抄藏示子孫後題建炎四年庚戌孫朝奉</span>  
<span style="margin-left: 2em">大夫主管亳州明道宫賜紫金魚袋暐書則撰此</span>  
<span style="margin-left: 2em">書者乃暐之祖非暐也周煇淸波雜志稱成都富</span>  
<!-- 册3 葉3880a　Page:文淵閣四庫全書_0003冊.djvu/975 -->
<span style="margin-left: 2em">春坊火詩乃洛中名德之後號道山公子者所作</span>  
<span style="margin-left: 2em">亦不言其姓氏書中記元祐五年其父爲賀遼國</span>  
<span style="margin-left: 2em">正旦使論范純仁吕公著事歸奏哲宗哲宗命寄</span>  
<span style="margin-left: 2em">書純仁後純仁再相哲宗問曾見李某書否則撰</span>  
<span style="margin-left: 2em">此書者李姓非王姓也然攷李燾通鑑長編是年</span>  
<span style="margin-left: 2em">八月庚戌命吏部郎中蘇注戸部郎中劉昱爲正</span>  
<span style="margin-left: 2em">旦使供備庫使郭宗顏西京左藏庫副使畢可濟</span>  
<span style="margin-left: 2em">副之後郭宗顏病改遣西頭供奉官閤門陸孝立</span>  
<span style="margin-left: 2em">無李姓者在其間而所稱去年范純仁出守潁昌</span>
