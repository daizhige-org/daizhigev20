## 欽定四庫全書總目 卷八十六　史部四十二　目錄類二

<!-- 册2 葉3072a　Page:文淵閣四庫全書_0002冊.djvu/773 -->
欽定四庫全書總目卷八十六  
<span style="margin-left: 1em">史部四十二</span>  
<span style="margin-left: 2em">目錄𩔖二</span>  
集古錄十卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">宋歐陽修撰修有詩本義巳著錄古人法書惟重</span>  
<span style="margin-left: 2em">眞蹟自梁元帝始集錄碑刻之文爲碑英一百二</span>  
<span style="margin-left: 2em">十卷見所撰金樓子是爲金石文字之祖今其書</span>  
<span style="margin-left: 2em">不傳曾鞏欲作金石錄而未就僅製一序存元豐</span>  
<span style="margin-left: 2em">𩔖稿中修始採摭佚逸積至千卷撮其大要各爲</span>  
<!-- 册2 葉3072b　Page:文淵閣四庫全書_0002冊.djvu/773 -->
<span style="margin-left: 2em">之說至嘉祐治平間修在政府又各書其卷尾於</span>  
<span style="margin-left: 2em">是文或小異蓋隨時有所竄定也修自書其後題</span>  
<span style="margin-left: 2em">嘉祐癸卯至熙寜二年已酉修季子棐復摭其畧</span>  
<span style="margin-left: 2em">别爲目錄上距癸卯蓋六年而棐記稱錄旣成之</span>  
<span style="margin-left: 2em">八年則是錄之成當在嘉祐六年辛丑其眞蹟跋</span>  
<span style="margin-left: 2em">尾則多係治平初年所書亦間有在熙寜初者知</span>  
<span style="margin-left: 2em">棐之目錄固承修之命而爲之也諸碑跋今皆具</span>  
<span style="margin-left: 2em">修集中其跋自爲書則自宋方崧<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">裒聚眞蹟刻</span>  
<span style="margin-left: 2em">於廬陵曾宏父石刻鋪叙稱有二百四十六跋陳</span>  
<!-- 册2 葉3073a　Page:文淵閣四庫全書_0002冊.djvu/773 -->
<span style="margin-left: 2em">振孫書錄解題稱有三百五十跋修子棐所記則</span>  
<span style="margin-left: 2em">曰凡二百九十六跋修又自云凡四百餘篇有跋</span>  
<span style="margin-left: 2em">近日刻集古錄者又爲之說曰世所傳集古跋四</span>  
<span style="margin-left: 2em">百餘篇而棐乃謂二百九十六雖是時修尙無恙</span>  
<span style="margin-left: 2em">然續跋不應多逾百篇因疑寫本誤以三百爲二</span>  
<span style="margin-left: 2em">百以今考之則通此十卷乃正符四百餘跋之數</span>  
<span style="margin-left: 2em">蓋以集本與眞蹟合編與專据集本者不同宋時</span>  
<span style="margin-left: 2em">廬陵之刻本今巳不傳無從核定不必以棐記爲</span>  
<span style="margin-left: 2em">疑矣是書原本但隨得隨錄不復詮次年月故修</span>  
<!-- 册2 葉3073b　Page:文淵閣四庫全書_0002冊.djvu/773 -->
<span style="margin-left: 2em">之自序曰有卷帙而無時世先後蓋其取多而未</span>  
<span style="margin-left: 2em">已也近來刻本乃以時代先後爲序而於毎卷之</span>  
<span style="margin-left: 2em">末附列原本卷帙次第轉有年月倒置更易補正</span>  
<span style="margin-left: 2em">之處錢曾讀書敏求記以爲失其初意然考毛晉</span>  
<span style="margin-left: 2em">跋是書曰自序謂上自周穆王以來則當以吉曰</span>  
<span style="margin-left: 2em">癸巳石刻爲卷首毛伯敦三銘是作序目後所得</span>  
<span style="margin-left: 2em">宜在卷末卽子棐亦未敢妄爲詮次蓋周益公未</span>  
<span style="margin-left: 2em">能精於考訂云云据此則周必大時之本巳按時</span>  
<span style="margin-left: 2em">世爲次則其由來久矣今刻修文集者但序時代</span>  
<!-- 册2 葉3076a　Page:文淵閣四庫全書_0002冊.djvu/774 -->
<span style="margin-left: 2em">不復存毎卷末之原次則益爲疎耳今仍依見行</span>  
<span style="margin-left: 2em">篇次著於錄焉</span>  
金石錄三十卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">宋趙明誠撰明誠字德父密州諸城人厯官知湖</span>  
<span style="margin-left: 2em">州軍州事是書以所藏三代彛器及漢唐以來石</span>  
<span style="margin-left: 2em">刻仿歐陽修集古錄例編排成帙紹興中其妻李</span>  
<span style="margin-left: 2em">淸照表上於朝張端義貴耳集謂淸照亦筆削其</span>  
<span style="margin-left: 2em">間理或然也有明誠自序並淸照後序其前十卷</span>  
<span style="margin-left: 2em">皆以時代爲次自第一至二千咸著於目毎題下</span>  
<!-- 册2 葉3076b　Page:文淵閣四庫全書_0002冊.djvu/774 -->
<span style="margin-left: 2em">注年月撰書人名後二十卷爲辨證凡跋尾五百</span>  
<span style="margin-left: 2em">二篇中邢義李證義興茶舍般舟和尙四碑目錄</span>  
<span style="margin-left: 2em">中不列其名或編次偶有疎舛或所續得之本未</span>  
<span style="margin-left: 2em">及補入卷中歟初鋟板於龍舒開禧元年浚儀趙</span>  
<span style="margin-left: 2em">不譾又重刻之其本今巳罕傳故歸有光朱彛尊</span>  
<span style="margin-left: 2em">所見皆傳抄之本或遂指爲未完之書其實當曰</span>  
<span style="margin-left: 2em">有所考證乃爲題識故李淸照跋稱二千卷中有</span>  
<span style="margin-left: 2em">題跋者五百二卷耳原非卷卷有跋未可以殘缺</span>  
<span style="margin-left: 2em">疑也淸照跋據洪邁容齋四筆原爲龍舒刻本所</span>  
<!-- 册2 葉3077a　Page:文淵閣四庫全書_0002冊.djvu/774 -->
<span style="margin-left: 2em">不載邁於王順伯家見原稿乃撮述大槪載之此</span>  
<span style="margin-left: 2em">本所列乃與邁所撮述者同則後人補入非淸照</span>  
<span style="margin-left: 2em">之全文矣自明以來轉相抄錄各以意爲更移或</span>  
<span style="margin-left: 2em">刪除其目内之次第又或竄亂其目之年月第十</span>  
<span style="margin-left: 2em">一卷以下或併削毎卷之細目或竟佚卷末之後</span>  
<span style="margin-left: 2em">序沿訛踵謬彌失其眞顧炎武日知錄載章邱刻</span>  
<span style="margin-left: 2em">本至以後序壯月朔爲牡丹朔其書之舛謬可以</span>  
<span style="margin-left: 2em">槩見近日所傳惟焦竑從秘府抄出本文嘉從宋</span>  
<span style="margin-left: 2em">刻影抄本崑山葉氏本閩中徐氏本濟南謝氏重</span>  
<!-- 册2 葉3077b　Page:文淵閣四庫全書_0002冊.djvu/774 -->
<span style="margin-left: 2em">刻本又有長洲何焯錢塘丁敬諸校本差爲完善</span>  
<span style="margin-left: 2em">今揚州刻本皆爲採錄又於注中以𨽻釋𨽻續諸</span>  
<span style="margin-left: 2em">書增附按語較爲詳核别有范氏天一閣惠氏紅</span>  
<span style="margin-left: 2em">豆山房諸校本皆稍不及故今從揚州所刋著於</span>  
<span style="margin-left: 2em">錄焉</span>  
法帖刋誤二卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋黄伯思撰伯思有東觀餘論巳著錄初米芾取</span>  
<span style="margin-left: 2em">淳化閣帖一一評其眞僞多以意斷制罕所考證</span>  
<span style="margin-left: 2em">伯思復取芾之所定重爲訂正以成此書前有大</span>  
<!-- 册2 葉3080a　Page:文淵閣四庫全書_0002冊.djvu/775 -->
<span style="margin-left: 2em">觀戊子自序稱芾疎畧甚多或僞跡甚著而不覺</span>  
<span style="margin-left: 2em">者若李懷琳所作衛夫人書逸少濶别稍久帖之</span>  
<span style="margin-left: 2em">𩔖有審其僞而譏評未當者若知伯英大人諸草</span>  
<span style="margin-left: 2em">帖爲唐人書而不知乃書晉人帖語之𩔖有譏評</span>  
<span style="margin-left: 2em">雖當主名昭然而不能辨者若以田疇字爲非李</span>  
<span style="margin-left: 2em">斯書而不知乃李陽冰明州碑中字之𩔖有誤著</span>  
<span style="margin-left: 2em">其主名者若以晉人章草諸<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3575.svg?width=24" alt="四庫全書僻字第3575號（葛）" title="四庫全書僻字第3575號（葛）">亮傳中語遂以爲</span>  
<span style="margin-left: 2em">亮書之𩔖其論多<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">其他亦指摘眞僞率有依據</span>  
<span style="margin-left: 2em">末有政和中王珍許翰二跋據珍跋乃伯思官洛</span>  
<!-- 册2 葉3080b　Page:文淵閣四庫全書_0002冊.djvu/775 -->
<span style="margin-left: 2em">中時觀珍家所藏閣帖作也其書本自爲一編故</span>  
<span style="margin-left: 2em">至今有别行之本諸家書目亦别著錄後其子䚮</span>  
<span style="margin-left: 2em">乃編入東觀餘論中耳湯垕畫鑒曰宋人賞鑒精</span>  
<span style="margin-left: 2em">妙無如米元章然此公天資極高立論時有過處</span>  
<span style="margin-left: 2em">後有黄伯思長睿者出作法帖刋誤專攻米公之</span>  
<span style="margin-left: 2em">失僕從而辨析其詳作法帖正誤專指長睿之過</span>  
<span style="margin-left: 2em">今未見垕書不知所正者何誤然垕亦空談鑒别</span>  
<span style="margin-left: 2em">而不以考證爲事者恐所正亦未必<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">也</span>  
法帖釋文十卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<!-- 册2 葉3081a　Page:文淵閣四庫全書_0002冊.djvu/775 -->
<span style="margin-left: 2em">宋劉次莊撰次莊字中叟長沙人崇寜中嘗官御</span>  
<span style="margin-left: 2em">史曹士冕法帖譜系云臨江戲魚堂帖元祐間劉</span>  
<span style="margin-left: 2em">次莊以家藏淳化閣帖十卷摹刻其上除去卷尾</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3478.svg?width=24" alt="四庫全書僻字第3478號（篆）" title="四庫全書僻字第3478號（篆）">題而增釋文曾敏行獨醒雜志曰劉殿院次莊</span>  
<span style="margin-left: 2em">自糿喜書嘗寓於新淦所居民屋窓牖牆壁題寫</span>  
<span style="margin-left: 2em">殆徧臨江郡庫有法帖十卷釋以小楷他法帖之</span>  
<span style="margin-left: 2em">所無也觀二書所記則次莊之作法帖釋文本附</span>  
<span style="margin-left: 2em">註石刻之中未嘗别爲一集此本殆後人於戲魚</span>  
<span style="margin-left: 2em">堂帖中鈔合成帙而仍以閣本原第編之者也陳</span>  
<!-- 册2 葉3081b　Page:文淵閣四庫全書_0002冊.djvu/775 -->
<span style="margin-left: 2em">振孫書錄解題又稱武岡人嘗傳刻絳州潘氏帖</span>  
<span style="margin-left: 2em">嘉定中汪立中又取劉本分入二十卷中官帖所</span>  
<span style="margin-left: 2em">無者增附之蓋絳帖本閣帖而廣之故立中釋文</span>  
<span style="margin-left: 2em">亦因次莊釋文而廣之與此又别一書矣</span>  
籀史一卷<sub class="note-yuan">編修汪如藻家藏本</sub>  
<span style="margin-left: 2em">宋翟耆年撰耆年字伯壽參政汝文之子别號黄</span>  
<span style="margin-left: 2em">鶴山人是書首載宣和博古圖有紹興十有二年</span>  
<span style="margin-left: 2em">二月帝命臣耆年云云蓋南宋初所作本上下二</span>  
<span style="margin-left: 2em">卷歲久散佚惟嘉興曹溶家尙有鈔本然巳僅存</span>  
<!-- 册2 葉3084a　Page:文淵閣四庫全書_0002冊.djvu/776 -->
<span style="margin-left: 2em">上卷今藏弆家所著錄皆自曹杰傳寫者也王士</span>  
<span style="margin-left: 2em">禎嘗載其目於居易錄欲以訪求其下卷卒未之</span>  
<span style="margin-left: 2em">獲知無完本久矣其以籀名史特因所載多金石</span>  
<span style="margin-left: 2em">欵識<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3478.svg?width=24" alt="四庫全書僻字第3478號（篆）" title="四庫全書僻字第3478號（篆）">𨽻之體爲多實非專述籀文所錄各種之</span>  
<span style="margin-left: 2em">後皆附論說括其梗槪於岐陽石鼓不深信爲史</span>  
<span style="margin-left: 2em">籀之作與唐代所傳特異亦各存所見然未至如</span>  
<span style="margin-left: 2em">金馬定國堅執爲宇文周所作也所錄不及薛尙</span>  
<span style="margin-left: 2em">功鐘鼎彛器欵識備載<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3478.svg?width=24" alt="四庫全書僻字第3478號（篆）" title="四庫全書僻字第3478號（篆）">文而所述源委則較薛</span>  
<span style="margin-left: 2em">爲詳二書相輔而行固未可以偏廢其中所云趙</span>  
<!-- 册2 葉3084b　Page:文淵閣四庫全書_0002冊.djvu/776 -->
<span style="margin-left: 2em">明誠古器物銘碑十五卷稱商器三卷周器十卷</span>  
<span style="margin-left: 2em">奏漢器二卷河間劉跂序洛陽王壽<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3478.svg?width=24" alt="四庫全書僻字第3478號（篆）" title="四庫全書僻字第3478號（篆）">据其所</span>  
<span style="margin-left: 2em">說則十五卷皆古器物銘而無石刻當於金石錄</span>  
<span style="margin-left: 2em">之外别爲一書而士禎以爲卽金石錄者其說殊</span>  
<span style="margin-left: 2em">誤豈士禎偶未檢金石錄歟</span>  
𨽻釋二十七卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">宋洪适撰适初名造後更今名字景伯饒州都陽</span>  
<span style="margin-left: 2em">人皓之長子紹興壬戌中博學宏詞科官至尙書</span>  
<span style="margin-left: 2em">左僕射同中書門下平章事諡文惠事蹟具宋史</span>
