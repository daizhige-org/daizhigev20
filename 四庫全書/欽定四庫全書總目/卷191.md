## 欽定四庫全書總目 卷一百九十一　集部四十四　總集類存目一

<!-- 册5 葉449a　Page:文淵閣四庫全書_0005冊.djvu/117 -->
欽定四庫全書總目卷一百九十一  
<span style="margin-left: 1em">集部四十四</span>  
<span style="margin-left: 2em">總集類存目一</span>  
文選句圖一卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">宋高似孫撰似孫有剡錄已著錄案摘句爲圖始</span>  
<span style="margin-left: 2em">於張爲其書以白居易等六人爲主以楊乘等七</span>  
<span style="margin-left: 2em">十八人爲客主分六派客亦各有上入室入室升</span>  
<span style="margin-left: 2em">堂及門四格排比聯貫事同譜牒故以圖名後九</span>  
<span style="margin-left: 2em">僧各摘名句亦曰句圖葢非其本似孫此書亦沿</span>  
<!-- 册5 葉449b　Page:文淵閣四庫全書_0005冊.djvu/117 -->
<span style="margin-left: 2em">舊名所錄皆文選諸詩去取不甚可解如蘇武詩</span>  
<span style="margin-left: 2em">之馥馥我蘭芳馨香中夜發上下聯各割一句尤</span>  
<span style="margin-left: 2em">爲剏調其句下附錄之句葢卽鍾嶸詩品源出某</span>  
<span style="margin-left: 2em">某之意其句下附錄一兩首者則莫喻其體例矣</span>  
文選纂註十二卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">明張鳳翼撰鳳翼有夢占類考已著錄是書雜采</span>  
<span style="margin-left: 2em">諸家詮釋文選之說故曰藄註然所引多不著所</span>  
<span style="margin-left: 2em">出夫詮釋義理可以融會羣言至於考證舊文豈</span>  
<span style="margin-left: 2em">可不言依據言各有當不得以朱子集傳集註藉</span>  
<!-- 册5 葉452a　Page:文淵閣四庫全書_0005冊.djvu/118 -->
<span style="margin-left: 2em">口也其論神女賦王字訛玉玉字訛王葢採姚寛</span>  
<span style="margin-left: 2em">西溪叢語之說極爲精審其註無名氏古詩以東</span>  
<span style="margin-left: 2em">城高且長與燕趙多佳人分爲兩篇十九首遂成</span>  
<span style="margin-left: 2em">二十不知陸機擬作文義可尋未免太自用矣</span>  
選詩約註十二卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明林兆珂撰兆珂有詩經多識編已著錄是編取</span>  
<span style="margin-left: 2em">昭明文選所錄諸詩重爲編次以時代先後爲序</span>  
<span style="margin-left: 2em">其訓釋文義較舊註稍爲簡約亦無攷證發明</span>  
文選章句二十八卷<sub class="note-yuan">内府藏本</sub>  
<!-- 册5 葉452b　Page:文淵閣四庫全書_0005冊.djvu/118 -->
<span style="margin-left: 2em">明陳與郊編與郊有檀弓集註已著錄此書以坊</span>  
<span style="margin-left: 2em">刻文選顚倒棼亂每以李善所注竄入五臣注中</span>  
<span style="margin-left: 2em">因重爲釐正汰其重複斥五臣而獨存善註凡善</span>  
<span style="margin-left: 2em">所錄舊注如楚辭之王逸兩都賦之薛綜詠懷詩</span>  
<span style="margin-left: 2em">之顏延之沈約皆仍存之亦時時正其舛誤較閔</span>  
<span style="margin-left: 2em">齊華張鳳翼諸本差爲勝之然㸃竄古人增附已</span>  
<span style="margin-left: 2em">說究不出明人積習不如存其原本之愈也</span>  
文選尤十四卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明鄒思明編思明字見吾歸安人始末未詳前有</span>  
<!-- 册5 葉453a　Page:文淵閣四庫全書_0005冊.djvu/118 -->
<span style="margin-left: 2em">韓敬序其私印已稱庚戌會狀兩元則萬厯後人</span>  
<span style="margin-left: 2em">也其書取文選舊本臆爲刪削以三色板印之凡</span>  
<span style="margin-left: 2em">例謂總評分脈則用朱細評探意則用綠釋音義</span>  
<span style="margin-left: 2em">解文詞則用墨云</span>  
文選瀹注三十卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明閔齊華編齊華烏程人崇禎中以歲貢任沙河</span>  
<span style="margin-left: 2em">縣知縣是書以六臣注本刪削舊文分繋於各段</span>  
<span style="margin-left: 2em">之下復采孫鑛評語列於上格葢以批㸃制藝之</span>  
<span style="margin-left: 2em">法施之於古人著作也</span>  
<!-- 册5 葉453b　Page:文淵閣四庫全書_0005冊.djvu/118 -->
昭明文選越裁十一卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 1em">國朝洪若臯編若臯有南沙文集已著錄是編取昭</span>  
<span style="margin-left: 2em">明文選重爲刪定復捃拾諸家之註畧爲詮解其</span>  
<span style="margin-left: 2em">圈㸃評語則全如時文之式其謂之越裁者自序</span>  
<span style="margin-left: 2em">謂時避居越城志地亦志僭也案昭明舊本唐人</span>  
<span style="margin-left: 2em">奉爲蓍龜以杜甫詩才凌跨百代猶有熟精文選</span>  
<span style="margin-left: 2em">理之句餘子可以知矣若臯橫加翦薙可謂不自</span>  
<span style="margin-left: 2em">揣量卽以開卷一篇而論班固兩都賦文本相承</span>  
<span style="margin-left: 2em">乃刪去東都一篇遂使語無歸宿全乖本意是於</span>  
<!-- 册5 葉456a　Page:文淵閣四庫全書_0005冊.djvu/119 -->
<span style="margin-left: 2em">作賦之故且茫然未考矣</span>  
選詩定論十八卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 1em">國朝吳湛撰湛字伯其號冉渠睢陽人其書以文選</span>  
<span style="margin-left: 2em">所錄諸詩歌自漢高帝以下以時代編次而荆軻</span>  
<span style="margin-left: 2em">易水歌十五字别爲一卷終焉前列六朝選詩緣</span>  
<span style="margin-left: 2em">起一卷皆雜引六經以釋之迂遠鮮當次統論古</span>  
<span style="margin-left: 2em">今詩及總論六朝一卷區分時世至謂陳隋無選</span>  
<span style="margin-left: 2em">詩宋金元皆無詩而明人古體學選律詩學唐亦</span>  
<span style="margin-left: 2em">七子之緖論其詮釋諸詩亦皆高而不切繁而鮮</span>  
<!-- 册5 葉456b　Page:文淵閣四庫全書_0005冊.djvu/119 -->
<span style="margin-left: 2em">要如解中山王孺子妾歌之類於考證尤疎也</span>  
文選音義八卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 1em">國朝余蕭客撰蕭客有古經解鉤沉採掇舊詁最爲</span>  
<span style="margin-left: 2em">詳核已别著錄此書則罅漏叢生如出二手約舉</span>  
<span style="margin-left: 2em">其失凡有數端一曰引証亡書不具出典如李善</span>  
<span style="margin-left: 2em">進文選注表化龍引晉陽秋肅成引王沈魏書筴</span>  
<span style="margin-left: 2em">字引徐邈李順莊子音如斯之類開卷皆是舊籍</span>  
<span style="margin-left: 2em">存佚諸家著錄可考世無傳本之書蕭客何由得</span>  
<span style="margin-left: 2em">見此輾轉稗販而諱所自來也一曰本書尙存轉</span>  
<!-- 册5 葉457a　Page:文淵閣四庫全書_0005冊.djvu/119 -->
<span style="margin-left: 2em">引他籍如西都賦火齊引龎元英文昌雜錄南史</span>  
<span style="margin-left: 2em">中天竺國說火齊云云何不竟引南史也逸民傳</span>  
<span style="margin-left: 2em">論引宋俞成螢雪叢說嚴子陵本姓莊避顯宗諱</span>  
<span style="margin-left: 2em">遂稱嚴氏此說果宋末始有耶一曰嗜博貪多不</span>  
<span style="margin-left: 2em">辨眞僞海賦陰火引王嘉拾遺記西海之西浮玉</span>  
<span style="margin-left: 2em">山巨穴云云與木華所云陰火何涉盧諶覽古詩</span>  
<span style="margin-left: 2em">和璧引杜光庭錄異記歲星之精墮於荆山云云</span>  
<span style="margin-left: 2em">是晉人讀五代書矣飮馬長城窟行雙鯉魚引元</span>  
<span style="margin-left: 2em">散堂詩話試鶯以朝鮮厚繭𥿄作鯉魚云云此出</span>  
<!-- 册5 葉457b　Page:文淵閣四庫全書_0005冊.djvu/119 -->
<span style="margin-left: 2em">龍輔女紅餘志案錢希言戲瑕明言嫏嬛記女紅</span>  
<span style="margin-left: 2em">餘志諸書皆桑懌依托則女紅餘志已屬僞本所</span>  
<span style="margin-left: 2em">引元散堂詩話更僞中之僞乃據爲實事不亦傎</span>  
<span style="margin-left: 2em">耶一曰摭拾舊文漫無考訂如閒居賦櫻字引<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）"></span>  
<span style="margin-left: 2em">谷子崖蜜櫻桃也案此惠洪冷齋夜話之文<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">谷</span>  
<span style="margin-left: 2em">子實無此語蕭客旣没惠洪之名攘爲已有又不</span>  
<span style="margin-left: 2em">知宋人已屢有駁正吳都賦欃槍引李周翰注以</span>  
<span style="margin-left: 2em">爲鯨魚目精此因博物志鯨魚死彗星出之文而</span>  
<span style="margin-left: 2em">加以妄誕陸機贈從兄詩言樹背與襟引謝氏詩</span>  
<!-- 册5 葉460a　Page:文淵閣四庫全書_0005冊.djvu/120 -->
<span style="margin-left: 2em">源堂北曰背堂南曰襟亦杜撰虛詞不出典記歸</span>  
<span style="margin-left: 2em">去來詞西疇引何焯批本曰卽農服先疇之意西</span>  
<span style="margin-left: 2em">先古通用案西古音先非義同先也西疇正如詩</span>  
<span style="margin-left: 2em">之南畝偶舉一方言之耳如是穿鑿則本詞之東</span>  
<span style="margin-left: 2em">臯何以獨言東耶凡斯之類皆疏舛也一曰叠引</span>  
<span style="margin-left: 2em">瑣說繁複矛盾如三都賦序玉樹引顏師古漢書</span>  
<span style="margin-left: 2em">注謂左思不曉其義甘泉賦玉樹又引王楙野客</span>  
<span style="margin-left: 2em">叢書謂師古註甚謬劉琨重贈盧諶詩下注引蔡</span>  
<span style="margin-left: 2em">寛夫詩話曰秦漢以前平仄皆通魏晉間此體猶</span>  
<!-- 册5 葉460b　Page:文淵閣四庫全書_0005冊.djvu/120 -->
<span style="margin-left: 2em">存潘安詩位同單父邑愧無子賤歌豈敢陋微官</span>  
<span style="margin-left: 2em">但恐忝所荷是也潘岳河陽詩下又注曰國語補</span>  
<span style="margin-left: 2em">音<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3688.svg?width=24" alt="四庫全書僻字第3688號（負）" title="四庫全書僻字第3688號（負）">荷之荷亦音何兩卷之中是非頓異數頁之</span>  
<span style="margin-left: 2em">後平仄迥殊將使讀者何從耶一曰見事卽引不</span>  
<span style="margin-left: 2em">究本始如蜀都賦琥珀引曹昭格古要論不知昭</span>  
<span style="margin-left: 2em">據廣韻楓字注也飮馬長城窟行引吳兢樂府解</span>  
<span style="margin-left: 2em">題或云蔡邕不知兢據玉臺新詠也尙書序伏生</span>  
<span style="margin-left: 2em">引經典敘錄云名勝不知晉書伏滔傳稱遠祖勝</span>  
<span style="margin-left: 2em">也至於凡注花草必引王象晉羣芳譜益不足據</span>  
<!-- 册5 葉461a　Page:文淵閣四庫全書_0005冊.djvu/120 -->
<span style="margin-left: 2em">矣一曰旁引浮文苟盈卷帙首引何焯批本稱麈</span>  
<span style="margin-left: 2em">史宋景文母夢朱衣人擕文選一部與之遂生景</span>  
<span style="margin-left: 2em">文故小字選哥已爲枝蔓又沿用其例於顏延年</span>  
<span style="margin-left: 2em">贈王太常詩玉水記方流句下注曰王定保唐摭</span>  
<span style="margin-left: 2em">言白樂天及第省試玉水記方流詩此於音義居</span>  
<span style="margin-left: 2em">何等也曰抄撮習見徒溷簡牘如賢良詔漢武帝</span>  
<span style="margin-left: 2em">下注向曰漢書云諱徹景帝中子洛神賦曹子建</span>  
<span style="margin-left: 2em">下注翰曰武帝第三子世有不知漢武帝曹子建</span>  
<span style="margin-left: 2em">而讀文選者乎至於八言詩見東方朔本傳蕭統</span>  
<!-- 册5 葉461b　Page:文淵閣四庫全書_0005冊.djvu/120 -->
<span style="margin-left: 2em">序所云八字正用此事乃引吕延濟注以八字爲</span>  
<span style="margin-left: 2em">魏文帝樂府詩已爲紕繆又引何焯批本蔓引三</span>  
<span style="margin-left: 2em">言至五言獨遺八字挂漏者亦所不免惟魏都賦</span>  
<span style="margin-left: 2em">注廣蒼一條效曹子建題注孫巖宋書一條並引</span>  
<span style="margin-left: 2em">隋書經籍志爲證洞簫賦注顏叔子一條引毛萇</span>  
<span style="margin-left: 2em">詩傳巷伯篇爲證曲水詩序三月三曰一條引宋</span>  
<span style="margin-left: 2em">書禮志爲證東京賦注偷字協韻一條引沈重毛</span>  
<span style="margin-left: 2em">詩音義爲證糾何焯批本之誤爲有考正耳葢蕭</span>  
<span style="margin-left: 2em">客究心經義詞章非所擅長强賦六合違才易務</span>  
<!-- 册5 葉464a　Page:文淵閣四庫全書_0005冊.djvu/121 -->
<span style="margin-left: 2em">其見短也宜矣</span>  
馮氏校定玉臺新詠十卷<sub class="note-yuan">兵部侍郞紀昀家藏本</sub>  
<span style="margin-left: 1em">國朝馮舒所校其猶子武所刋也舒有詩紀匡謬已</span>  
<span style="margin-left: 2em">著錄徐陵玉臺新詠久無善本明人所刻多以意</span>  
<span style="margin-left: 2em">增竄全失其眞後趙宧光得宋嘉定乙亥永嘉陳</span>
