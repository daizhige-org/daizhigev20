御選古文淵鑒六十四卷  
<span style="margin-left: 2em">康熙二十四年</span>  
聖祖仁皇帝御選内閣學士徐乾學等奉  
勅編注所錄上起春秋左傳下迨於宋用眞德秀文章正  
<span style="margin-left: 2em">宗例而</span>  
睿鑒精深别裁至當不同德秀之拘迂名物訓詁各有箋  
<!-- 册5 葉369b　Page:文淵閣四庫全書_0005冊.djvu/97 -->
<span style="margin-left: 2em">釋用李善注文選例而考證明確詳畧得宜不同</span>  
<span style="margin-left: 2em">善之煩碎每篇各有評㸃用樓昉古文標註例而</span>  
<span style="margin-left: 2em">批導𥧾要闡發精微不同昉之簡畧備載前人評</span>  
<span style="margin-left: 2em">語用王霆震古文集成例而蒐羅賅備去取謹嚴</span>  
<span style="margin-left: 2em">不同霆震之蕪雜諸臣附論各列其名用五臣註</span>  
<span style="margin-left: 2em">文選例而夙承</span>  
聖訓語見根源不同五臣之疎陋至於甲乙品題  
親揮奎藻别百家之工拙窮三準之精微則自有總集以  
<span style="margin-left: 2em">來厯代帝王未聞斯著無可援以爲例者葢</span>  
<!-- 册5 葉372a　Page:文淵閣四庫全書_0005冊.djvu/98 -->
聖人之心無不通  
聖人之道無不備非惟  
功隆  
德盛上軼唐虞卽  
乙覽之餘  
品題文萟亦詞苑之金桴儒林之玉律也雖帝堯之焕乎  
<span style="margin-left: 2em">文章何以加哉</span>  
御定厯代賦彚一百四十卷外集二十卷逸句二卷補遺  
二十二卷  
<!-- 册5 葉372b　Page:文淵閣四庫全書_0005冊.djvu/98 -->
<span style="margin-left: 2em">康熙四十五年</span>  
聖祖仁皇帝御定賦雖古詩之流然自屈宋以來卽與詩  
<span style="margin-left: 2em">别體自漢迄宋文質遞變格律日新元祝堯作古</span>  
<span style="margin-left: 2em">賦辨體於源流正變言之詳矣至於厯代鴻篇則</span>  
<span style="margin-left: 2em">不能備載明人作賦苑近人作賦格均千百之中</span>  
<span style="margin-left: 2em">錄存十一未能賅備無遺也是編所錄上起周末</span>  
<span style="margin-left: 2em">下訖明季以有關於經濟學問者爲正集分三十</span>  
<span style="margin-left: 2em">類計三千四十二篇其勞人思婦哀怨窮愁畸士</span>  
<span style="margin-left: 2em">幽人放言任達者别爲外集分八類計四百二十</span>  
<!-- 册5 葉373a　Page:文淵閣四庫全書_0005冊.djvu/98 -->
<span style="margin-left: 2em">三篇旁及佚文墜簡片語單詞見於諸書所引者</span>  
<span style="margin-left: 2em">碎璧零璣亦多資考證裒爲逸句二卷計一百一</span>  
<span style="margin-left: 2em">十七篇又書成之後補遺三百六十九篇散附逸</span>  
<span style="margin-left: 2em">句五十篇二千餘年體物之作散在藝林者耳目</span>  
<span style="margin-left: 2em">所及亦約畧備焉揚雄有言能讀千賦則善賦是</span>  
<span style="margin-left: 2em">編且四倍之學者沿波得奇於以黼黻太平潤色</span>  
鴻業亦足和聲鳴盛矣  
御定全唐詩九百卷  
<span style="margin-left: 2em">康熙四十二年</span>  
<!-- 册5 葉373b　Page:文淵閣四庫全書_0005冊.djvu/98 -->
聖祖仁皇帝御定詩莫備於唐然自北宋以來但有選錄  
<span style="margin-left: 2em">之總集而無輯一代之詩共爲一集者明海鹽胡</span>  
<span style="margin-left: 2em">震亨唐音統籖始蒐羅成帙粗見規模然尙多所</span>  
<span style="margin-left: 2em">舛漏是編禀承</span>  
聖訓以震亨書爲藁本而益以  
<span style="margin-left: 1em">内府所藏全唐詩集又旁採殘碑斷碣稗史襍書之</span>  
<span style="margin-left: 2em">所載補苴所遺凡得詩四萬八千九百餘首作者</span>  
<span style="margin-left: 2em">二千二百餘人冠以帝王后妃次以樂章樂府殿</span>  
<span style="margin-left: 2em">以聯句逸句名媛僧道外國仙神鬼怪諧謔及諸</span>  
<!-- 册5 葉376a　Page:文淵閣四庫全書_0005冊.djvu/99 -->
<span style="margin-left: 2em">雜體其餘皆以作者先後爲次而以補遺六卷詞</span>  
<span style="margin-left: 2em">十二卷别綴於末綱羅賅備細大不遺然如冊府</span>  
<span style="margin-left: 2em">元龜所載唐高祖賜秦王詩則考訂其僞托又舊</span>  
<span style="margin-left: 2em">以六朝人誤作唐人者如陳昭儀沈氏衛敬瑜妻</span>  
<span style="margin-left: 2em">之類以六朝人訛其姓名誤爲唐人者如楊愼卽</span>  
<span style="margin-left: 2em">陳陽愼沈煙卽陳沈炯之類以六朝詩誤入唐詩</span>  
<span style="margin-left: 2em">者如吳均妾安所居劉孝勝武陵深行誤作曹鄴</span>  
<span style="margin-left: 2em">薛道衡昔昔鹽誤作劉長卿之類唐詩之誤以詩</span>  
<span style="margin-left: 2em">題爲姓名者如上官儀高密公主輓詞作高密詩</span>  
<!-- 册5 葉376b　Page:文淵閣四庫全書_0005冊.djvu/99 -->
<span style="margin-left: 2em">王維慕容承擕素饌見過詩作慕容承詩之類亦</span>  
<span style="margin-left: 2em">並釐正唐音統籖收道家章咒釋氏偈頌多至二</span>  
<span style="margin-left: 2em">十八卷本非詩歌之體傷於冗雜者咸爲刪削義</span>  
<span style="margin-left: 2em">例乃極謹嚴至於字句之異同篇章之互見根據</span>  
<span style="margin-left: 2em">諸本一一校注尤爲周密得此一編而唐詩之源</span>  
<span style="margin-left: 2em">流正變始末釐然自有總集以來更無如是之旣</span>  
<span style="margin-left: 2em">博且精者矣</span>  
御定佩文齋詠物詩選四百八十六卷  
<span style="margin-left: 2em">康熙四十五年</span>  
<!-- 册5 葉377a　Page:文淵閣四庫全書_0005冊.djvu/99 -->
聖祖仁皇帝御定自萟文類聚初學記始以詠物之詩分  
<span style="margin-left: 2em">隸各類後宋綬蒲積中有歲時雜詠專收節序之</span>  
<span style="margin-left: 2em">篇陳景沂有全芳備祖惟採草木之什未有蒐合</span>  
<span style="margin-left: 2em">遺篇包括厯代分門列目共爲一總集者明華亭</span>  
<span style="margin-left: 2em">張之象始有古詩類苑唐詩類苑兩集然亦多以</span>  
<span style="margin-left: 2em">人事分編不專於詠物其全輯詠物之詩者實始</span>  
<span style="margin-left: 2em">自是編所錄上起古初下訖明代凡四百八十六</span>  
<span style="margin-left: 2em">類又附見者四十九類諸體咸備庶彚畢陳洋洋</span>  
<span style="margin-left: 2em">乎詞苑之大觀也夫鳥獸草木學詩者資其多識</span>  
<!-- 册5 葉377b　Page:文淵閣四庫全書_0005冊.djvu/99 -->
<span style="margin-left: 2em">孔門之訓也郭璞作山海經贊戴凱之作竹譜宋</span>  
<span style="margin-left: 2em">祁作益部方物畧記並以韻語叙物產豈非以諧</span>  
<span style="margin-left: 2em">諸聲律易於記誦歟學者坐諷一編而周知萬品</span>  
<span style="margin-left: 2em">是以摛文而兼博物之功也至於借題以託比觸</span>  
<span style="margin-left: 2em">目以起興美刺法戒繼軌風人又不止爾雅之注</span>  
<span style="margin-left: 2em">蟲魚矣知</span>  
聖人隨事寓敎嘉惠藝林者深也原本未標卷第惟分六  
<span style="margin-left: 2em">十四冊篇頁稍繁今依類分析編爲四百八十六</span>  
<span style="margin-left: 2em">卷</span>  
<!-- 册5 葉380a　Page:文淵閣四庫全書_0005冊.djvu/100 -->
御定題畫詩一百二十卷  
<span style="margin-left: 2em">康熙四十六年</span>  
聖祖仁皇帝御定裒合題畫之詩共爲一集者始於宋之  
<span style="margin-left: 2em">孫紹遠然書止八卷所錄僅唐宋之作未爲賅備</span>  
<span style="margin-left: 2em">所分二十六門義例亦未能盡協自是以來論書</span>  
<span style="margin-left: 2em">畫者如無名氏之鐵網珊瑚<sub class="note-yuan">案鐵網珊瑚舊誤稱朱存理作今巳訂正</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">語詳本條之下</sub>郁逢慶之書畫題跋記張丑之淸河書畫</span>  
<span style="margin-left: 2em">舫眞蹟日錄汪砢玉之珊瑚網孫承澤之庚子銷</span>  
<span style="margin-left: 2em">夏記高士奇之江邨銷夏錄卞永譽之書畫彚考</span>  
<!-- 册5 葉380b　Page:文淵閣四庫全書_0005冊.djvu/100 -->
<span style="margin-left: 2em">所錄皆題跋爲多詩句僅附見其一二卽</span>  
御定佩文齋書畫譜與此書同時並纂亦不立題詠一門  
<span style="margin-left: 2em">臣等竊以管蠡之見窺測</span>  
高深或以古人題畫者多題書者少卷帙旣慮偏枯又書  
<span style="margin-left: 2em">畫譜爲卷一百而此書篇什繁富爲卷一百二十</span>  
<span style="margin-left: 2em">如併爲一編則末大於本亦未協體例是以</span>  
分命廷臣各爲編校歟集中所錄凡詩八千九百六十二  
<span style="margin-left: 2em">首分爲三十門如樹石别於山水名勝亦别於山</span>  
<span style="margin-left: 2em">水古蹟别於名勝古像别於寫眞漁樵耕織牧養</span>  
<!-- 册5 葉381a　Page:文淵閣四庫全書_0005冊.djvu/100 -->
<span style="margin-left: 2em">别於閒適蘭竹禾麥蔬果别於花卉配隸具有條</span>  
<span style="margin-left: 2em">理末爲人事雜題二類包舉亦爲簡括較諸孫氏</span>  
<span style="margin-left: 2em">舊編實博而有要披覽之餘覺名物典故有資考</span>  
<span style="margin-left: 2em">證鴻篇巨製有益文章卽山川景物開卷如逢魚</span>  
<span style="margin-left: 2em">鳥留連烟雲供養亦足以悅性怡情及恭讀</span>  
御製序文則謂不逾几席而得流觀山川險易之形近在  
目前而可考鏡往代留遺之蹟以至農耕蠶織纎悉必  
具雞犬桑麻宛然如睹庶幾與昔人豳風無逸之圖有  
互相發明者焉益知  
<!-- 册5 葉381b　Page:文淵閣四庫全書_0005冊.djvu/100 -->
聖人之心卽物寓道所見者大又不徒作藝事觀焉  
御定四朝詩三百一十二卷  
<span style="margin-left: 2em">康熙四十八年</span>  
聖祖仁皇帝御定右庶子張豫章等奉  
勅編次凡宋詩七十八卷作者八百八十二人金詩二十  
<span style="margin-left: 2em">五卷作者三百二十一人元詩八十一卷作者一</span>  
<span style="margin-left: 2em">千一百九十七人明詩一百二十八卷作者三千</span>  
<span style="margin-left: 2em">四百人每代之前各詳叙作者之爵里其詩則首</span>  
<span style="margin-left: 2em">帝製次四言次樂府歌行次古體次律詩次絶句</span>  
<!-- 册5 葉384a　Page:文淵閣四庫全書_0005冊.djvu/101 -->
<span style="margin-left: 2em">次六言次雜言以體分編唐詩至五代而衰至宋</span>  
<span style="margin-left: 2em">初而未振王禹偁初學白居易如古文之有柳穆</span>  
<span style="margin-left: 2em">明而未融楊億等倡西崑體流布一時歐陽修梅</span>  
<span style="margin-left: 2em">堯臣始變舊格蘇軾黃庭堅益出新意宋詩於時</span>  
<span style="margin-left: 2em">爲極盛南渡以後擊壤集一派參錯並行遷流至</span>  
<span style="margin-left: 2em">於四靈江湖二派遂弊極而不復焉金人奄有中</span>  
<span style="margin-left: 2em">原故詩格多沿元祐迨其末造國運與宋同衰詩</span>  
<span style="margin-left: 2em">道乃較宋爲獨盛元好問自題中州集後詩日鄴</span>  
<span style="margin-left: 2em">下曹劉氣儘豪江東諸謝韻尤高若從華實評詩</span>  
<!-- 册5 葉384b　Page:文淵閣四庫全書_0005冊.djvu/101 -->
<span style="margin-left: 2em">品未便吳儂得錦袍誠非虛語有元一代作者雲</span>  
<span style="margin-left: 2em">興虞楊范揭以下指不勝屈而末葉爭趨綺麗乃</span>  
<span style="margin-left: 2em">類小詞楊維禎<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3688.svg?width=24" alt="四庫全書僻字第3688號（負）" title="四庫全書僻字第3688號（負）">其才氣破崖岸而爲之風氣一</span>  
<span style="margin-left: 2em">新然訖不能返諸古也明詩總雜門戸多岐約而</span>  
<span style="margin-left: 2em">論之高啓諸人爲極盛洪熙宣德以後體參臺閣</span>  
<span style="margin-left: 2em">風雅漸微李東陽稍稍振之而北地信陽已崛起</span>  
<span style="margin-left: 2em">與爭詩體遂變後再變而公安三變而竟陵淫哇</span>  
<span style="margin-left: 2em">競作明祚遂終大抵四朝各有其盛衰其作者亦</span>  
<span style="margin-left: 2em">互有長短而七百餘年之中著作浩繁雖博識通</span>  
<!-- 册5 葉385a　Page:文淵閣四庫全書_0005冊.djvu/101 -->
<span style="margin-left: 2em">儒亦無從徧觀遺集至於澄汰沙礫披檢精英合</span>  
<span style="margin-left: 2em">四朝而爲一巨帙勢更有所不能矣我</span>  
<span style="margin-left: 1em">國家稽古右文石渠天祿之藏旣逾前代我</span>  
聖祖仁皇帝游心風雅典學維勤  
乙覽之餘咸無遺照用能别裁得失勒著鴻編非惟四朝  
<span style="margin-left: 2em">作者得</span>  
睿鑒而表章卽讀者沿波以得奇於詩家正變源流亦一
