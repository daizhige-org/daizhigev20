<span style="margin-left: 1em">史部二十</span>  
<span style="margin-left: 2em">傳記類存目六</span>  
西征記一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">宋盧襄撰襄字贊元觀其自序蓋衢州人此書載</span>  
<span style="margin-left: 2em">於錦繡萬花谷前集之末不知何人鈔出别行乃</span>  
<span style="margin-left: 2em">襄赴京春試時紀行之作末題庚辰仲春元日案</span>  
<span style="margin-left: 2em">北宋凡三庚辰吳自牧所作歴科狀元表太宗太</span>  
<span style="margin-left: 2em">平興國五年庚辰曁仁宗康定元年庚辰皆不見</span>  
<!-- 册2 葉1589b　Page:文淵閣四庫全書_0002冊.djvu/402 -->
<span style="margin-left: 2em">有進士科惟哲宗元符三年庚辰有李釡榜進士</span>  
<span style="margin-left: 2em">則是人應試或在此年所敘述皆無關考据又雜</span>  
<span style="margin-left: 2em">載詩歌詞多鄙俚雖出宋人無可採錄也</span>  
乙巳泗州錄一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">宋胡舜申撰舜申績溪人舜陟之兄官至舒州通</span>  
<span style="margin-left: 2em">判宣和乙巳舜申在泗州親見朱勔父子往來及</span>  
<span style="margin-left: 2em">徽宗幸泗州事因爲此錄紀載寥寥無可采擇</span>  
己酉避亂錄一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">宋胡舜申撰建炎己酉金兵攻平江宣撫周望出</span>

<span style="margin-left: 2em">走舜申之兄舜陟時爲叅謀舉家避難舜申次爲</span>  
<span style="margin-left: 2em">此錄其言頗詆韓世忠末復載世忠攜妓一事似</span>  
<span style="margin-left: 2em">有宿憾之言未必實錄此書與乙巳泗州錄王明</span>  
<span style="margin-left: 2em">淸玉照新志皆全載其文蓋卽後人於明淸書内</span>  
<span style="margin-left: 2em">鈔出别行也</span>  
逢辰記一卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">不著撰人名氏宋史藝文志著錄注云吕頥浩歴</span>  
<span style="margin-left: 2em">官次序此書末有附記云公平昔所爲文及奏議</span>  
<span style="margin-left: 2em">並載之别集此外又有公之勤王記及遺事可考</span>  
<!-- 册2 葉1592b　Page:文淵閣四庫全書_0002冊.djvu/403 -->
<span style="margin-left: 2em">故爲家傳以紀事則此記乃頥浩後人所撰矣</span>  
勤王記一卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">舊本題宋臧梓撰梓里貫未詳此書結銜題左宣</span>  
<span style="margin-left: 2em">敎郞荆湖南路安撫制置大使司幹辦公事蓋作</span>  
<span style="margin-left: 2em">書時所居之官其始末亦不可考矣案原序稱紹</span>  
<span style="margin-left: 2em">興五年史館修纂建炎日厯令勤王臣僚吕頥浩</span>  
<span style="margin-left: 2em">等各錄建炎三年金人攻泗州諸路勤王事蹟梓</span>  
<span style="margin-left: 2em">因卽頤浩所𫐠以成此書則梓特編次頥浩之文</span>  
<span style="margin-left: 2em">非所自撰也</span>  
<!-- 册2 葉1593a　Page:文淵閣四庫全書_0002冊.djvu/403 -->
西征道里記一卷<sub class="note-yuan">永樂大典本</sub>

<span style="margin-left: 2em">中爲左宣敎郞試祕書少監充樞密行府叅謀時</span>  
<span style="margin-left: 2em">記行之作前有自序稱紹興已未陜西初復命簽</span>  
<span style="margin-left: 2em">書樞密樓公諭以朝廷安輯之意某以祕書少監</span>  
<span style="margin-left: 2em">預叅謀所過道里集而記之雖搜覽不能周盡而</span>  
<span style="margin-left: 2em">耳目之際亦可以驗遺蹤而知往古與夫兵火凋</span>  
<span style="margin-left: 2em">落之後人事興衰物情向背時有可得而窺者同</span>  
<span style="margin-left: 2em">行者右通<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">郞尚書員外李若虛等九十五人云</span>

烏臺詩案一卷<sub class="note-yuan">編修汪如藻家藏本</sub>  
<span style="margin-left: 2em">舊本題宋朋九萬編卽蘇軾御史臺獄詞也案周</span>  
<span style="margin-left: 2em">必大二老堂詩話曰元豐已未東坡坐作詩訕謗</span>  
<span style="margin-left: 2em">追赴御史獄當時所供詩案今已印行所謂烏臺</span>  
<span style="margin-left: 2em">詩案是也靖康丁未歲臺吏隨駕挈眞案至維揚</span>  
<span style="margin-left: 2em">張全眞叅政時爲中丞南渡取而藏之後張丞相</span>  
<span style="margin-left: 2em">德遠爲全眞作墓誌諸子以其半遺德遠充<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3257.svg?width=24" alt="四庫全書僻字第3257號（⿰氵閠 -- 潤）" title="四庫全書僻字第3257號（⿰氵閠 -- 潤）">筆</span>  
<span style="margin-left: 2em">其半猶在全眞家余嘗借觀皆坡親筆凡有塗改</span>  
<span style="margin-left: 2em">卽押字於下而用臺印云云是必大親見眞迹然</span>  
<!-- 册2 葉1596a　Page:文淵閣四庫全書_0002冊.djvu/404 -->
<span style="margin-left: 2em">不言與刋板有異同陳振孫書錄解題載是書十</span>  
<span style="margin-left: 2em">三卷胡仔漁隱叢話所錄則三卷有奇皆與此本</span>  
<span style="margin-left: 2em">不合仔稱其父舜陟靖康間嘗爲臺端臺中子瞻</span>  
<span style="margin-left: 2em">詩案具在因錄得其本視近時所刋行烏臺詩話</span>  
<span style="margin-left: 2em">爲尤詳今節入叢話是仔書所載已爲節本今考</span>  
<span style="margin-left: 2em">叢話諸條不過較此本少一二事其餘則條目皆</span>  
<span style="margin-left: 2em">同則未必仔所見本振孫稱九萬錄東坡下御史</span>  
<span style="margin-left: 2em">獄公案附以初舉發章疏及謫官後表章書啟詩</span>  
<span style="margin-left: 2em">詞此本但冠以章疏而無謫官後表章書啟詩詞</span>  
<!-- 册2 葉1596b　Page:文淵閣四庫全書_0002冊.djvu/404 -->
<span style="margin-left: 2em">則亦非振孫所見本或後人摭拾仔之所錄稍附</span>  
<span style="margin-left: 2em">益之追題朋九萬名以合於振孫之所錄非九萬</span>  
<span style="margin-left: 2em">本書歟</span>  
客杭日記一卷<sub class="note-yuan">光祿寺<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">陸錫熊家藏本</sub>

<span style="margin-left: 2em">作日記原本共四册眞蹟在揚州程氏家雍正乙</span>  
<span style="margin-left: 2em">巳厲鶚遊揚州得見之鶚杭人也因手錄其中客</span>  
<span style="margin-left: 2em">杭一册以歸其書自至大戊申九月初一日至次</span>  
<span style="margin-left: 2em">年二月初九日逐日𤨏記交遊聞見中頗多請託</span>  
<!-- 册2 葉1597a　Page:文淵閣四庫全書_0002冊.djvu/404 -->
<span style="margin-left: 2em">吏胥之事蓋畀於江浙行省求充學正山長時作</span>  
<span style="margin-left: 2em">也鶚稱其所記白塔以進士題名碑爲基銅鐘有</span>  
<span style="margin-left: 2em">淳熙改元曾覿篆銘爲他書所未載而寺壁一詩</span>  
<span style="margin-left: 2em">與桯史所記康與之題徽宗畫扇詩亦可叅考異</span>  
<span style="margin-left: 2em">同云</span>

<span style="margin-left: 2em">部員外郞誠嘗副中使李達使西域諸國所厯哈</span>  
<span style="margin-left: 2em">烈撒馬兒罕等凡十七國述其山川風俗物產撰</span>  
<!-- 册2 葉1597b　Page:文淵閣四庫全書_0002冊.djvu/404 -->
<span style="margin-left: 2em">成此記永樂十一年返命上之明史藝文志載有</span>  
<span style="margin-left: 2em">陳誠西域行程記卽此書也末有秀水沈德符跋</span>  
<span style="margin-left: 2em">其所載音譯旣多訛舛且所歴之地不過涉嘉峪</span>

東祀錄一卷<sub class="note-yuan">兩淮馬裕家藏本</sub>

<span style="margin-left: 2em">所作記序銘文奏疏詩章等篇共爲一編而冠以</span>

<span style="margin-left: 2em">此其别行之本也</span>  
七人聯句詩記一卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">明楊循吉撰循吉有蘇州府纂修識畧已著錄是</span>  
<!-- 册2 葉1600b　Page:文淵閣四庫全書_0002冊.djvu/405 -->
<span style="margin-left: 2em">編乃循吉與王仁甫徐寛陳章王弼侯<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">趙寛六</span>

<span style="margin-left: 2em">始末而以制詞敕旨具錄左方又闢尋樂軒與二</span>  
<span style="margin-left: 2em">三故老立忘形會軒有記會有約有啟與恩遇圖</span>

<span style="margin-left: 2em">馬中錫撫賊事較史所載尤備可旁資叅攷云</span>  
南遷日記一卷<sub class="note-yuan">江蘇巡撫採進本</sub>

<span style="margin-left: 2em">明陸深撰嘉靖中深以祭酒侍經筵因爭閣臣改</span>

<span style="margin-left: 2em">以舟中日讀漢書故評史之語亦雜載其間</span>
