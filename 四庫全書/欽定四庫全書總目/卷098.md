<span style="margin-left: 2em">儒家𩔖存目四</span>  
大學辨業四卷聖經學規纂二卷論學二卷<sub class="note-yuan">直隸總督採進本</sub>  
<span style="margin-left: 1em">國朝李塨撰塨有周易傳注已著錄是編發明古大</span>  
<span style="margin-left: 2em">學之法以辨俗學之非大旨與其大學傳注同首</span>  
<span style="margin-left: 2em">總論大學次辨後儒所論小學大學次論小學次</span>  
<span style="margin-left: 2em">辨後儒改易大學原本次大學原文及全篇解次</span>  
<span style="margin-left: 2em">大學之道至致知格物解次辨後儒格物解次其</span>  
<!-- 册3 葉549b　Page:文淵閣四庫全書_0003冊.djvu/142 -->
<span style="margin-left: 2em">本亂至此謂知之至也解次申論格物次所謂誠</span>  
<span style="margin-left: 2em">其意者至末解次申解全篇其所爭在以格物爲</span>  
<span style="margin-left: 2em">周禮三物其謂孔子之時古大學教法所謂六德</span>  
<span style="margin-left: 2em">六行六藝者規矩尚存故格物之學人人所習不</span>  
<span style="margin-left: 2em">必再言惟以明德親民標其宗要以誠意指其入</span>  
<span style="margin-left: 2em">手功夫而已格物一傳可不必補其說較他家爲</span>  
<span style="margin-left: 2em">巧故當時學者多稱之聖經學規纂二卷則摘錄</span>  
<span style="margin-left: 2em">四書五經之言學者申明其說論學二卷則錄朋</span>  
<span style="margin-left: 2em">友問難之語其凡例所謂辨業意有不盡者入之</span>  
<!-- 册3 葉552a　Page:文淵閣四庫全書_0003冊.djvu/143 -->
<span style="margin-left: 2em">學規學規意有不盡者入之論學是也</span>  
小學稽業五卷<sub class="note-yuan">直隸總督採進本</sub>  
<span style="margin-left: 1em">國朝李塨撰其序謂朱子小學所載天道性命上達</span>  
<span style="margin-left: 2em">也親迎朝覲年及壯强者也以及居相告老諸條</span>  
<span style="margin-left: 2em">皆非㓜童事且無分於大學乃別輯此編卷一爲</span>  
<span style="margin-left: 2em">小學四子韻語括其總綱以便誦讀卷二爲食食</span>  
<span style="margin-left: 2em">能言六年教數方名七年别男女八年入小學教</span>  
<span style="margin-left: 2em">讓九年教數目十年學幼儀諸條卷三爲學書卷</span>  
<span style="margin-left: 2em">四爲學記卷五爲十有五學樂誦詩舞勺大旨以</span>  
<!-- 册3 葉552b　Page:文淵閣四庫全書_0003冊.djvu/143 -->
<span style="margin-left: 2em">禮樂書數爲綱其中如引曲禮履不上堂一節在</span>  
<span style="margin-left: 2em">今日並無解屨之事引内則凡路男子由右婦人</span>  
<span style="margin-left: 2em">由左車從中央一節在今日亦跬步不可行此虚</span>  
<span style="margin-left: 2em">陳古禮者也又誦詩一條自造詩譜舞勺一條自</span>  
<span style="margin-left: 2em">造舞譜此又杜撰古樂者也惟學書一篇辨篆楷</span>  
<span style="margin-left: 2em">之分極爲精核然亦非童子之所急其膚廓正與</span>  
<span style="margin-left: 2em">親迎朝覲等耳</span>  
性理纂要八卷<sub class="note-yuan">河南巡撫採進本</sub>  
<span style="margin-left: 1em">國朝冉覲祖撰覲祖有易經詳說已著錄是書前四</span>  
<!-- 册3 葉553a　Page:文淵閣四庫全書_0003冊.djvu/143 -->
<span style="margin-left: 2em">卷爲性理纂要附訓五卷至八卷爲性理纂要附</span>  
<span style="margin-left: 2em">評自序謂附訓者周子太極圖通書張子西銘東</span>  
<span style="margin-left: 2em">銘程子定性書五者之訓詁太極圖通書西銘本</span>  
<span style="margin-left: 2em">朱子之註諸儒之說東銘定性書則雜考朱子及</span>  
<span style="margin-left: 2em">諸儒之說而叅以已意附評者以程子之言爲經</span>  
<span style="margin-left: 2em">朱子之言爲傳諸儒爲之羽翼而以已意爲之評</span>  
<span style="margin-left: 2em">推覲祖之意蓋以性理所載太極圖諸書爲周張</span>  
<span style="margin-left: 2em">程所手著故尊爲經典名之曰訓其性理諸條以</span>  
<span style="margin-left: 2em">下則胡廣等裒集之言故儕諸文史目之曰評然</span>  
<!-- 册3 葉553b　Page:文淵閣四庫全書_0003冊.djvu/143 -->
<span style="margin-left: 2em">同一先儒之言何必分疆别界况評中所引程子</span>  
<span style="margin-left: 2em">之說不一而足何所見忽尊而訓忽卑而評也</span>  
天理主敬圖一卷<sub class="note-yuan">河南巡撫採進本</sub>  
<span style="margin-left: 1em">國朝冉覲祖撰其圖上標天理二字明性道之重中</span>  
<span style="margin-left: 2em">列存養省察講學力行四項爲體道之功下書一</span>  
<span style="margin-left: 2em">敬字以示心法之要蓋爲姚江之學言超悟者而</span>  
<span style="margin-left: 2em">發然古人著書必言不能盡其意者乃圖以明之</span>  
<span style="margin-left: 2em">若體認天理而存養省察講學力行以歸於主敬</span>  
<span style="margin-left: 2em">此可以言詮者也何必託諸繪畫乎</span>

程功錄五卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 1em">國朝楊名時撰名時有周易劄記已著錄是編乃其</span>  
<span style="margin-left: 2em">講學劄記體例全仿薛瑄讀書錄然中間頗涉雜</span>  
<span style="margin-left: 2em">論第四卷中剖析鉛汞之說尤於儒理無關其亦</span>  
<span style="margin-left: 2em">鄒訢註參同契意耶以大旨醇實故仍列之儒家</span>  
<span style="margin-left: 2em">焉</span>  
嵩陽學凡六卷<sub class="note-yuan">副都御史黃登賢家藏本</sub>  
<span style="margin-left: 1em">國朝景日昣撰日昣有嵩岳廟史已著錄是書依大</span>  
<span style="margin-left: 2em">學八條目排纂諸家語錄意取通俗故言皆淺近</span>

<span style="margin-left: 2em">亦不免於蕪雜</span>  
續小學六卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝葉鉁編鉁號潛夫嘉善人是書成於康熙辛未</span>  
<span style="margin-left: 2em">以朱子小學一書所采至宋淳熙而止因續采自</span>  
<span style="margin-left: 2em">宋迄明諸儒言行可爲師法者仍以内外篇目分</span>  
<span style="margin-left: 2em">條𩔖敘自爲之注其立敎第一篇末附㓜儀三十</span>  
<span style="margin-left: 2em">則則鉁所自撰也</span>  
心印正說三十四卷<sub class="note-yuan">江蘇巡撫採進本</sub>

<span style="margin-left: 1em">國朝吳台碩撰台碩字位三嘉定人陸隴其之門人</span>  
<span style="margin-left: 2em">也是書成於康熙壬申以學術治功之要分立篇</span>  
<span style="margin-left: 2em">目而各爲論以發明之凡三十四𩔖每𩔖又各有</span>  
<span style="margin-left: 2em">子目於洛閩緖言及厯代史論多所徵引又間有</span>

<span style="margin-left: 2em">之義然二字乃佛語非儒語也其說存二篇則仿</span>  
<span style="margin-left: 2em">序卦傳體述其次第亦涉擬經陸隴其爲之作序</span>  
<span style="margin-left: 2em">不一糾正何耶</span>  
尊道集四卷<sub class="note-yuan">湖北巡撫採進本</sub>  
<!-- 册3 葉557b　Page:文淵閣四庫全書_0003冊.djvu/144 -->
<span style="margin-left: 1em">國朝朱搴撰搴字良一黃陂人是書成於康熙丁丑</span>  
<span style="margin-left: 2em">第一卷爲聖賢前編自孔子至孟子事蹟及後人</span>  
<span style="margin-left: 2em">論說第二卷節取伊洛淵源錄第三卷節取伊洛</span>  
<span style="margin-left: 2em">淵源續錄第四卷爲前明五子錄紀薛瑄胡居仁</span>  
<span style="margin-left: 2em">羅欽順顧憲成高攀龍五人行誼而兼及其言論</span>  
<span style="margin-left: 2em">大指主於攻擊陸王</span>  
近思續錄四卷<sub class="note-yuan">副都御史黃登賢家藏本</sub>  
<span style="margin-left: 1em">國朝劉源淥撰源淥字崑石自號直齋安邱人是書</span>  
<span style="margin-left: 2em">因朱子近思錄篇目采輯朱子或間語𩔖文集分</span>

<span style="margin-left: 2em">門編輯前有康熙辛己其門人陳舜錫馬恒謙二</span>  
<span style="margin-left: 2em">序舜錫序稱其毎祭朱子品物豐潔極其誠敬恒</span>  
<span style="margin-left: 2em">謙序稱其於朱子文集或問語𩔖三書沉潛反覆</span>

<span style="margin-left: 2em">草三脫稿乃成是書云</span>

<span style="margin-left: 1em">國朝劉源淥撰其門人馬恒謙編其書仿語𩔖之體</span>  
<span style="margin-left: 2em">大旨本朱子之說而衍之其三卷中一條詆劉安</span>  
<span style="margin-left: 2em">世爲邪人謂其害甚於章惇邢恕以其與伊川不</span>

<span style="margin-left: 2em">今體詩存齋詩話亦五卷</span>

<span style="margin-left: 2em">士官至内閣學士兼禮部侍郞朱陸之徒自宋代</span>
