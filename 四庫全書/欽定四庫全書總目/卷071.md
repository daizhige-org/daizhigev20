<span style="margin-left: 1em">史部二十七</span>  
<span style="margin-left: 2em">地理類四</span>  
遊城南記一卷<sub class="note-yuan">編修注如藻家藏本</sub>  
<span style="margin-left: 2em">宋張禮撰禮字茂中浙江人元祐元年與其友楚</span>  
<span style="margin-left: 2em">人陳微明遊長安城南訪唐代都邑舊址因作此</span>  
<span style="margin-left: 2em">記而自爲之注凡門坊寺觀園囿村墟及前賢遺</span>  
<span style="margin-left: 2em">迹見於載籍者叙錄甚備如嘉話錄載<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3584.svg?width=24" alt="四庫全書僻字第3584號（慈）" title="四庫全書僻字第3584號（慈）">恩寺題</span>  
<span style="margin-left: 2em">名始於張莒禮則引唐登科記謂進士中有大中</span>

<span style="margin-left: 2em">十三年及第之張台而無張莒又長安志載章敬</span>  
<span style="margin-left: 2em">寺本魚朝恩莊後爲章敬皇后立寺故以爲名禮</span>  
<span style="margin-left: 2em">則以宋代寺基與志所載地理不同而疑其巳非</span>  
<span style="margin-left: 2em">古址皆能據所目見而考辨之其徵据頗爲典核</span>  
<span style="margin-left: 2em">所列金石碑刻名目亦可與集古錄諸書互相叅</span>  
<span style="margin-left: 2em">証毎條下間有續注不知何人所増中有金代年</span>  
<span style="margin-left: 2em">號其薦福寺一條又有辛卯遷徙之語案辛卯爲</span>  
<span style="margin-left: 2em">金哀宗正大八年史載是年四月元兵克鳯翔兩</span>  
<span style="margin-left: 2em">行省棄京兆遷居民於河南所云遷徙當卽此事</span>

<span style="margin-left: 2em">葢金末元初人也</span>

<span style="margin-left: 2em">不著撰人名氏明焦竑國史經籍志著錄亦不云</span>  
<span style="margin-left: 2em">誰作考元劉仁本羽庭集有是書序曰今翰林國</span>

<span style="margin-left: 2em">故事曁近代金宋戰爭疆埸更變者或得於圖經</span>

<span style="margin-left: 2em">地志或聞諸故老舊家流風遺俗一皆考訂夜還</span>

<span style="margin-left: 2em">焦氏作十二卷亦誤也納新族出西北郭囉洛因</span>  
<span style="margin-left: 2em">以爲氏郭囉洛者以</span>  
欽定西域圖志考之卽今塔爾巴哈台也元時色目諸  
<span style="margin-left: 2em">人散處天下故納新寓居南陽後移於鄞縣初辟</span>  
<span style="margin-left: 2em">爲浙東東湖書院山長以薦授翰林編修官出叅</span>

<span style="margin-left: 2em">桑戩實哩<sub class="note-yuan">原作桑前失里今改正</sub>軍事卒於軍所著金臺集</span>  
<span style="margin-left: 2em">尙有刋本惟此書久軼今散見永樂大典中者惟</span>  
<span style="margin-left: 2em">一百三十四條所紀皆在眞定河南境内而其餘</span>  
<span style="margin-left: 2em">不存又仁本所稱繼以詩歌者亦不復可見然據</span>  
<span style="margin-left: 2em">今所存諸條其山川古蹟多向來地志所未詳而</span>  
<span style="margin-left: 2em">金石遺文言之尤悉皆可以爲考証之助謹彚而</span>  
<span style="margin-left: 2em">編之核其道里疆界各以類從眞定路爲一卷河</span>  
<span style="margin-left: 2em">南路爲一卷仍錄劉仁本原序冠之雖殘缺之餘</span>  
<span style="margin-left: 2em">十存一二而崖畧宛在條理可尋講輿地之學者</span>

<span style="margin-left: 2em">猶可多所取資焉</span>  
徐霞客遊記十二卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明徐宏祖撰宏祖江陰人霞客其號也少負奇氣</span>  
<span style="margin-left: 2em">年三十出遊擕一襆被遍歴東南佳山水自吳越</span>  
<span style="margin-left: 2em">之閩之楚北歴齊魯燕冀嵩雒登華山而歸旋復</span>  
<span style="margin-left: 2em">由閩之粤又由終南背走峩<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2899.svg?width=24" alt="四庫全書僻字第2899號（⿱山眉 -- 𭗙）" title="四庫全書僻字第2899號（⿱山眉 -- 𭗙）">訪恒山又南過大</span>

<span style="margin-left: 2em">峪關數千里窮星宿海而還所至輙爲文以志遊</span>  
<span style="margin-left: 2em">蹟没後手稿散逸其友季夢良求得之而中多闕</span>

<span style="margin-left: 2em">失宜興史氏亦有抄本而譌異尤甚此則楊名時</span>

<span style="margin-left: 2em">恒華各爲一篇第二卷以下皆西南遊記凡二十</span>  
<span style="margin-left: 2em">五篇首浙江江西一篇次湖廣一篇次廣西六篇</span>  
<span style="margin-left: 2em">次貴州一篇次雲南十有六篇所缺者一篇而巳</span>  
<span style="margin-left: 2em">自古名山大澤秩祀所先但以表望封圻未聞品</span>

<span style="margin-left: 2em">祖耽奇嗜僻刻意遠遊旣銳於捜尋尤工於摹寫</span>

<span style="margin-left: 2em">未嘗有意於爲文然以耳目所親見聞較<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">且黔</span>

<span style="margin-left: 2em">爲有資考證是亦山經之别乘輿記之外篇矣存</span>  
<span style="margin-left: 2em">茲一體於地理之學未嘗無補也</span>

佛國記一卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋釋法顯撰杜佑通典引此書又作法明葢中宗</span>  
<!-- 册2 葉2125a　Page:文淵閣四庫全書_0002冊.djvu/536 -->
<span style="margin-left: 2em">諱顯唐人以明字代之故原註有國諱改焉四字</span>  
<span style="margin-left: 2em">也法顯晉義熙中自長安遊天竺經三十餘國還</span>  
<span style="margin-left: 2em">到京與天竺禪師叅互辨定以成是書胡震亨刻</span>  
<span style="margin-left: 2em">入秘冊函中從舊題曰佛國記而震亨附䟦則以</span>  
<span style="margin-left: 2em">爲當名法顯傳今考酈道元水經注引此書所云</span>

<span style="margin-left: 2em">水上流有一國以下二百七十六字皆稱曰法顯</span>

<span style="margin-left: 2em">顯傳二卷法顯行傳一卷不著撰人地理類載佛</span>

<span style="margin-left: 2em">以中國爲邊地葢釋氏自尊其教其誕謬不足與</span>

<span style="margin-left: 2em">年當稱庚子所紀較前差一年然晉書本紀載趙</span>  
<span style="margin-left: 2em">石虎建武六年當咸康五年歲在已亥而金石錄</span>  
<span style="margin-left: 2em">載趙横山李君神碑及西門豹祠殿基記乃均作</span>

<span style="margin-left: 2em">踰年改元或不踰年改元漫無定制又南北隔絶</span>

<span style="margin-left: 2em">文以從闕疑之義焉</span>

<span style="margin-left: 2em">唐釋元奘譯辨機撰元奘事蹟具舊唐書列傳晁</span>

<span style="margin-left: 2em">國記其文頗畧唐書西域列傳較爲詳核此書所</span>

<span style="margin-left: 2em">此所記者經行之地也讀書志載有元奘自序此</span>  
<span style="margin-left: 2em">本佚之惟前有尙書左僕射燕國公張說序後有</span>

<span style="margin-left: 2em">辨機自序句下間有註文或曰唐言某某或曰某</span>  
<span style="margin-left: 2em">印度境疑爲原註又有校正譯語云舊作某某訛</span>  
<span style="margin-left: 2em">者及毎卷之末附有音釋疑爲後人所加第十一</span>

<span style="margin-left: 2em">晁公武讀書志稱元奘至天竺求佛書因記其所</span>

<span style="margin-left: 2em">此書侈陳靈異尤不足稽然山川道里亦有互相</span>
