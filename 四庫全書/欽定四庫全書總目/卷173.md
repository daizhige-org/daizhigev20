<span style="margin-left: 2em">可圖以藻繪非惟仰鑽所莫罄抑亦歌頌所難名</span>

<span style="margin-left: 2em">運</span>  
<!-- 册4 葉2312a　Page:文淵閣四庫全書_0004冊.djvu/583 -->
龍飛  
宵旰勵精心營四海

硃批諭㫖至三百六十卷  
上諭内閣至一百五十九卷  
上諭八旗及  
上諭旗務議覆  
諭行旗務議奏至四十八卷則剞劂梨棗共見共聞仰計

<span style="margin-left: 2em">十三年中固無日不</span>  
親御丹毫疇咨庶政而𭔃情翰墨遂炳然與典誥雅頌輝  
<span style="margin-left: 2em">映後先葢</span>  
體協健行  
心懷無逸精明强固之氣舉措萬化而有餘故旁涉詞章  
<span style="margin-left: 2em">尤足以陶鑄百氏如元化運轉時行物生而二曜</span>  
<span style="margin-left: 2em">五緯三垣列𪧐自然成在天之文也豈非攝提合</span>  
<span style="margin-left: 2em">雒以來超軼三五之</span>  
至聖哉  
<!-- 册4 葉2313a　Page:文淵閣四庫全書_0004冊.djvu/583 -->
御製樂善堂文集定本三十卷  
<span style="margin-left: 2em">乾隆二十三年協辦大學士戸部尚書蔣溥等同</span>  
<span style="margin-left: 2em">奉</span>  
勅重編欽惟我  
皇上聖聰夙擅道岸先登學海詞源苞涵富有昔當  
睿養卽擅  
生知雍正庚戌之秋嘗訂  
樂善堂文鈔十四卷乾隆丁巳取  
文鈔所載存十之三益以雍正乙卯以前續著十之七  
<!-- 册4 葉2313b　Page:文淵閣四庫全書_0004冊.djvu/583 -->
<span style="margin-left: 2em">彚爲</span>

<span style="margin-left: 2em">刻卷帙稍繁復</span>  
指授溥等校閱刪定併省去制義一卷定爲此本伏考  
<span style="margin-left: 2em">今之制義卽宋之經義也劉安節等皆載入别集</span>  
<span style="margin-left: 2em">吕祖謙選宋文鑑亦載入總集初刻兼錄制義葢</span>  
<span style="margin-left: 2em">沿古例而我</span>  
皇上區分體裁昭<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2618.svg?width=24" alt="四庫全書僻字第2618號（⿱乖一）" title="四庫全書僻字第2618號（⿱乖一）">矩矱俾共知古文時文之分

<span style="margin-left: 2em">大所較歐陽修集多至一百五十三卷而修自定</span>  
<span style="margin-left: 2em">居士集原本乃止五十卷文獻通考引葉適之言</span>

<span style="margin-left: 2em">集古錄䟦尾集本視眞跡亦多所追改我</span>  
皇上奎章藻耀籠括古今逾修亦何啻萬倍而  
釐定舊製必審必精  
聖意之謹嚴乃與修相近  
天懷冲挹尤亘古之所無矣易曰日新之謂盛德又曰  
<span style="margin-left: 2em">日進無疆<small>臣</small>等伏讀斯編仰見</span>

<span style="margin-left: 2em">集四十四卷凡四百一十餘篇爲二十有三門門</span>  
<span style="margin-left: 2em">各以歲月爲次皆</span>  
萬幾餘暇  
<!-- 册4 葉2317a　Page:文淵閣四庫全書_0004冊.djvu/584 -->
親御丹素所成其  
誥勅碑記之屬詞臣恭擬代言者不與焉伏考三古以  
<span style="margin-left: 2em">來帝王著作散見諸子百家者大抵有韻之語爲</span>  
<span style="margin-left: 2em">多如黃帝巾机銘唐堯神人暢虞舜南風詩<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">雲</span>  
<span style="margin-left: 2em">歌禹玉牒詞湯鑄鼎繇以及武王丹書之戒成王</span>  
<span style="margin-left: 2em">紫庭之操古籍所傳不可縷舉皆詩之𩔖也其以</span>  
<span style="margin-left: 2em">文傳者則殊不多見吕覽記神農之教鬻子記顓</span>  
<span style="margin-left: 2em">頊以下修政之語<sub class="note-yuan">案諸語今本鬻子不載見賈誼新書所引</sub>或山追記</span>  
<span style="margin-left: 2em">或出依託未必親所撰錄也兩漢以後諸帝王惟</span>  
<!-- 册4 葉2317b　Page:文淵閣四庫全書_0004冊.djvu/584 -->
<span style="margin-left: 2em">梁武帝有詩賦集又有文集其餘亦無專以文傳</span>  
<span style="margin-left: 2em">者然武帝文集不過十卷未爲甚富且六朝輕艷</span>  
<span style="margin-left: 2em">之詞亦未能闡聖賢之奥嫓典謨之體也惟我</span>

<span style="margin-left: 2em">散文亦迥超藝苑凡闡明義理之作多濂洛關閩</span>

<span style="margin-left: 2em">乎春秋至於體裁盡善華實酌中則賈董崔蔡以</span>  
<span style="margin-left: 2em">還韓柳歐曾以上號爲作者無不包羅豈特列朝</span>

觀書乙夜悅性怡情是以  
<!-- 册4 葉2321b　Page:文淵閣四庫全書_0004冊.djvu/585 -->
聖學通微  
睿思契妙  
天機所到造化生心如雲霞之麗天變化不窮而形容  
<span style="margin-left: 2em">意態無一相複如江河之紀地流行不息而波瀾</span>  
<span style="margin-left: 2em">湍折無一相同如二氣之育物生化不已而耳目</span>  
<span style="margin-left: 2em">口鼻無一相𩔖故從心所欲動合自然</span>  
染翰擘牋頃刻輒數十首侍臣授簡吮墨沉思  
前韻未賡  
新題已作  
<!-- 册4 葉2324a　Page:文淵閣四庫全書_0004冊.djvu/586 -->
丹毫宣示日以爲常四十八年之中卷帙如是之浩博  
<span style="margin-left: 2em">職是故也若夫有舉必書可以注</span>

聖人之德  
聖人之功與

<span style="margin-left: 2em">非雕章繪句者所知矣考帝王有集始於漢武帝</span>  
<span style="margin-left: 2em">然止二卷魏晉至唐御撰詩文惟唐高宗大帝集</span>  
<span style="margin-left: 2em">多至八十六卷今所存者亦大抵皆纂組之詞其</span>

<span style="margin-left: 2em">於</span>

<span style="margin-left: 2em">集三百卷眞宗御集亦三百卷仁宗御集一百卷</span>  
<span style="margin-left: 2em">觀其目錄皆湊合襍纂書籍以充卷帙其數旣已</span>  
<span style="margin-left: 2em">不<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">又惟眞宗集稱鏤板然宋人書目皆不著錄</span>

<span style="margin-left: 2em">人宋人詩話說部所稱述者太宗詩僅傳二首眞</span>

<!-- 册4 葉2325a　Page:文淵閣四庫全書_0004冊.djvu/586 -->
