## 欽定四庫全書總目 卷一百二十二　子部三十二　雜家類六

<!-- 册3 葉2544：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷一百二十二  
<span style="margin-left: 1em">子部三十二</span>  
<span style="margin-left: 2em">雜家𩔖六</span>  
困學齋雜錄一卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">元鮮于樞撰樞字伯機漁陽人官太常寺典簿書</span>  
<span style="margin-left: 2em">史會要稱其酒酣驁放吟詩作字奇態橫生趙孟</span>  
<span style="margin-left: 2em">頫極推重之是書所紀當時詩話襍事爲多原本</span>  
<span style="margin-left: 2em">不著名氏故嘉靖中袁袠跋稱撰人未詳曹溶收</span>  
<span style="margin-left: 2em">入學海類編以鮮于樞自號困學民題所居曰困</span>  
<!-- 册3 葉2545b　Page:文淵閣四庫全書_0003冊.djvu/641 -->
<span style="margin-left: 2em">學齋遂以此書爲樞撰今考其書雖隨筆劄錄草</span>  
<span style="margin-left: 2em">草不甚經意而筆墨之間具有雅人深致非俗士</span>  
<span style="margin-left: 2em">所能僞托且元初諸人亦別無稱困學齋者溶定</span>  
<span style="margin-left: 2em">爲樞作似乎可信末有厲鶚跋謂卷中金源人詩</span>  
<span style="margin-left: 2em">可補劉祁歸潛志之缺存之亦可以資采錄也開</span>  
<span style="margin-left: 2em">卷引李平許楮二事但錄舊文無所論斷莫詳其</span>  
<span style="margin-left: 2em">意卷中趙復初二詩前後兩見字句亦有異同殆</span>  
<span style="margin-left: 2em">亦偶然襍錄未經編定之本後人因其墨迹繕錄</span>  
<span style="margin-left: 2em">成書如蘇軾志林仇池筆記之𩔖歟</span>  
<!-- 册3 葉2548a　Page:文淵閣四庫全書_0003冊.djvu/642 -->
隱居通議三十一卷<sub class="note-yuan">江西巡撫採進本</sub>  
<span style="margin-left: 2em">元劉壎撰壎字起潛南豐人書中自稱開慶元年</span>  
<span style="margin-left: 2em">年二十則宋亡之時已年三十六故於宋多内詞</span>  
<span style="margin-left: 2em">然書中又稱至大辛亥爲南劍州學官計其年已</span>  
<span style="margin-left: 2em">七十二矣日暮途窮復食元祿而是書乃以隱居</span>  
<span style="margin-left: 2em">爲名殊不可解考其水雲村稿中延祐已未重題</span>  
<span style="margin-left: 2em">梅氏海棠詩有花甲重周人八十之句則壎入元</span>  
<span style="margin-left: 2em">四十四年尚存最爲老壽是書當其晚嵗退休時</span>  
<span style="margin-left: 2em">所著也凡分十一門理學三卷古賦二卷詩歌七</span>  
<!-- 册3 葉2548b　Page:文淵閣四庫全書_0003冊.djvu/642 -->
<span style="margin-left: 2em">卷文章八卷駢儷三卷經史三卷禮樂造化地理</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">神襍錄各一卷其論理學以悟爲宗尊陸九淵</span>  
<span style="margin-left: 2em">爲正傳而援引朱子以合之至謂朱子後與道士</span>  
<span style="margin-left: 2em">白玉蟾游始知讀書爲徒勞葢姚江晩年定論之</span>  
<span style="margin-left: 2em">說源出於此皆郷曲門戸之私無庸深辨其經史</span>  
<span style="margin-left: 2em">以下六門考證亦未爲精核且多餖飣而<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">神一</span>  
<span style="margin-left: 2em">門尤近於稗官小說惟評詩論文之二十卷則壎</span>  
<span style="margin-left: 2em">生於宋末舊集多存其所稱引之文今多未見其</span>  
<span style="margin-left: 2em">篇帙其所稱引之人今亦多莫識其姓名又多備</span>  
<!-- 册3 葉2549a　Page:文淵閣四庫全書_0003冊.djvu/642 -->
<span style="margin-left: 2em">錄全篇首尾完具足以補諸家總集之遺如宋璟</span>  
<span style="margin-left: 2em">梅花賦今惟據田藝衡留靑日札傳鮮于樞所書</span>  
<span style="margin-left: 2em">一篇又據李綱忠定集知原賦已亡綱爲補作今</span>  
<span style="margin-left: 2em">觀壎所錄知宋元間行於世者乃有二本又如陸</span>  
<span style="margin-left: 2em">游之從韓伲冑以牽於愛妾㓜子之故爲他書之</span>  
<span style="margin-left: 2em">所未言厲鶚宋詩紀事載李義山詩不能舉其仕</span>  
<span style="margin-left: 2em">履觀壎所記乃知其嘗以江東提刑守池州凡此</span>  
<span style="margin-left: 2em">之𩔖頗足以廣聞見至於論詩論文尤多前輩緒</span>  
<span style="margin-left: 2em">餘皆出於諸家說部之外於徵文考獻皆爲有裨</span>  
<!-- 册3 葉2549b　Page:文淵閣四庫全書_0003冊.djvu/642 -->
<span style="margin-left: 2em">固談藝者所必錄也壎所著水雲村稿杜有二本</span>  
<span style="margin-left: 2em">其一本别題曰冺稿卷帙頗少不知何人删取是</span>  
<span style="margin-left: 2em">書三分之一附諸稿末殊爲闕畧此爲三十一卷</span>  
<span style="margin-left: 2em">之足本固罕覯之祕笈矣書中間有案語葢其後</span>  
<span style="margin-left: 2em">人所附自署其名曰凝考國初有南豐劉凝字二</span>  
<span style="margin-left: 2em">至嘗撰稽禮辨論韻原表石鼓文定本三書或卽</span>  
<span style="margin-left: 2em">其人歟</span>  
湛淵靜語二卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">元白珽撰珽字廷玉錢塘人家於西湖有泉自竺</span>  
<!-- 册3 葉2552a　Page:文淵閣四庫全書_0003冊.djvu/643 -->
<span style="margin-left: 2em">山滙於其門珽名曰湛淵因以爲號是書爲其友</span>  
<span style="margin-left: 2em">海陵周𰖍所編前有珽自序又有𰖍序題至大庚</span>  
<span style="margin-left: 2em">戌稱珽是年六十三嵗以長厯推之當生於宋理</span>  
<span style="margin-left: 2em">宗淳祐八年戊申元兵破臨安時年二十七矣故</span>  
<span style="margin-left: 2em">其書於宋多内詞與劉壎相𩔖然考珽入元以後</span>  
<span style="margin-left: 2em">以李衎之薦授太平路儒學正未幾攝教授事尋</span>  
<span style="margin-left: 2em">轉常州路教授陞江浙等處副提舉遷淮東鹽倉</span>  
<span style="margin-left: 2em">大使再遷蘭谿州判官乃致仕則食元之祿久矣</span>  
<span style="margin-left: 2em">而猶作宋遺民之詞其進退無據亦與壎相𩔖也</span>  
<!-- 册3 葉2552b　Page:文淵閣四庫全書_0003冊.djvu/643 -->
<span style="margin-left: 2em">是書乃其襍記之文據卷末有明人跋語稱嘉靖</span>  
<span style="margin-left: 2em">丙午鈔自崑山沈玉麟家而疑其不止此二卷殆</span>  
<span style="margin-left: 2em">殘本歟厲鶚作宋詩紀事蒐采極博而此書開卷</span>  
<span style="margin-left: 2em">載理宗賜林希逸詩一篇鶚不及收則鶚未見其</span>  
<span style="margin-left: 2em">本矣其中如謂皎然銅盌爲龍吟歌詠房琯事詩</span>  
<span style="margin-left: 2em">家未有引用者不知李賀昌谷集中實有假龍吟</span>  
<span style="margin-left: 2em">歌謂匡謬正俗爲顔眞<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">作不知實出顔師古不</span>  
<span style="margin-left: 2em">免稍有疏舛文中子李德林一條乃晁公武讀書</span>  
<span style="margin-left: 2em">志之語辨常儀占月一條亦史繩祖學齋佔畢之</span>  
<!-- 册3 葉2553a　Page:文淵閣四庫全書_0003冊.djvu/643 -->
<span style="margin-left: 2em">說亦未免偶相剽襲其載倪思論司馬光疑孟一</span>  
<span style="margin-left: 2em">條謂王安石援孟子大有爲之說欲神宗師尊之</span>  
<span style="margin-left: 2em">故光著此書明其未可盡信其說爲從來所未及</span>  
<span style="margin-left: 2em">案晁公武讀書志稱王安石喜孟子自爲之解其</span>  
<span style="margin-left: 2em">子雱與其門人許允成皆有註釋葢唐以前孟子</span>  
<span style="margin-left: 2em">皆入儒家至宋乃尊爲經元豐末遂追封鄒國公</span>  
<span style="margin-left: 2em">建廟鄒縣亦安石所爲則謂光疑孟實由安石異</span>  
<span style="margin-left: 2em">議相激而成不爲無見必以爲但因大有爲二語</span>  
<span style="margin-left: 2em">則似又出於牽合非確論也然其他辨析考證可</span>  
<!-- 册3 葉2553b　Page:文淵閣四庫全書_0003冊.djvu/643 -->
<span style="margin-left: 2em">取者多其記汴京故宫尤爲詳備在元人說部之</span>  
<span style="margin-left: 2em">中固不失爲佳本矣</span>  
敬齋古今黈八卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">元李冶撰冶有測圓海鏡已著錄此書原目凡四</span>  
<span style="margin-left: 2em">十卷其以黈名者案漢書東方朔傳黈纊充耳所</span>  
<span style="margin-left: 2em">以塞聰顔師古注曰示不外聽冶殆以專精覃思</span>  
<span style="margin-left: 2em">穿穴古今以成是書故有取於不外聽之義歟元</span>  
<span style="margin-left: 2em">史本傳邵經邦宏簡錄黃虞稷千頃堂書目俱作</span>  
<span style="margin-left: 2em">古今難當因字形相似傳寫致訛文淵閣書目題</span>  
<!-- 册3 葉2556a　Page:文淵閣四庫全書_0003冊.djvu/644 -->
<span style="margin-left: 2em">作宋人則併其時代亦誤矣其書皆訂正舊文以</span>  
<span style="margin-left: 2em">考證佐其議論詞鋒駿利博辨不窮其說毛詩草</span>  
<span style="margin-left: 2em">蟲阜螽一條云師說相承五經大抵如此學者止</span>  
<span style="margin-left: 2em">可以意求之膠者不卓不膠則卓矣是其著書之</span>  
<span style="margin-left: 2em">大旨也其中如謂<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2894.svg?width=24" alt="四庫全書僻字第2894號（蚩）" title="四庫全書僻字第2894號（蚩）">尤之名取義於<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2894.svg?width=24" alt="四庫全書僻字第2894號（蚩）" title="四庫全書僻字第2894號（蚩）"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2894.svg?width=24" alt="四庫全書僻字第2894號（蚩）" title="四庫全書僻字第2894號（蚩）">之尤謂</span>  
<span style="margin-left: 2em">内則一篇卑𤨏凡猥大𩔖世所傳食纂謂中庸索</span>  
<span style="margin-left: 2em">隱行怪乃素餐之素謂孟子兄戴蓋爲一句祿萬</span>  
<span style="margin-left: 2em">鍾爲一句戴蓋卽乘軒之義或不免於好爲僻論</span>  
<span style="margin-left: 2em">橫生别解又如淳化閣帖漢章帝書干字文米芾</span>  
<!-- 册3 葉2556b　Page:文淵閣四庫全書_0003冊.djvu/644 -->
<span style="margin-left: 2em">書史黄伯思法帖刊誤秦觀淮海集俱以爲僞帖</span>  
<span style="margin-left: 2em">而冶據以駁千字文非周興嗣作太平廣記載徐</span>  
<span style="margin-left: 2em">浦鹽官李伯禽戲侮廟神其事在貞元中具有年</span>  
<span style="margin-left: 2em">月而冶卽以爲李白之子伯禽亦偶或失考然如</span>  
<span style="margin-left: 2em">辨史記微子面縛左牽羊右把茅乃其從者牽之</span>  
<span style="margin-left: 2em">把之司馬遷所記不謬孔頴達書正義所駁爲非</span>  
<span style="margin-left: 2em">辨鄭語收經入行姟極謂經卽京姟卽垓韋昭不</span>  
<span style="margin-left: 2em">當注經爲常辨論語五十以學易謂論語爲未學</span>  
<span style="margin-left: 2em">易時語史記所載則作十翼後語不必改五十字</span>  
<!-- 册3 葉2557a　Page:文淵閣四庫全書_0003冊.djvu/644 -->
<span style="margin-left: 2em">作卒辨孟子龍斷卽列子所謂冀之南漢之北無</span>  
<span style="margin-left: 2em">龍斷焉辨史記自敘甌駱相攻謂當爲閩越相攻</span>  
<span style="margin-left: 2em">辨張耒書鄒陽傳後謂韓安國實兩見長公主漢</span>  
<span style="margin-left: 2em">書不誤而耒誤辨衞靑傳三千一十七級謂級字</span>  
<span style="margin-left: 2em">𫎇上斬字顔師古誤𫎇上捕字遂以生獲爲級辨</span>  
<span style="margin-left: 2em">魏志穿方<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3688.svg?width=24" alt="四庫全書僻字第3688號（負）" title="四庫全書僻字第3688號（負）">土謂卽算經之立方定率辨吳志孫</span>  
<span style="margin-left: 2em">權告天文謂不當呼上帝爲爾辨通鑑握槊不輟</span>  
<span style="margin-left: 2em">謂胡三省誤以長行局爲長矛以及辨古者私家</span>  
<span style="margin-left: 2em">及官衙皆可稱朝引後漢書劉寵成瑨及左傳伯</span>  
<!-- 册3 葉2557b　Page:文淵閣四庫全書_0003冊.djvu/644 -->
<span style="margin-left: 2em">有事爲證辨佝僂丈人承蜩所以供食引内則鄭</span>  
<span style="margin-left: 2em">元注苟子楊倞注爲證辨吳都賦𤟤子長嘯當作</span>  
<span style="margin-left: 2em">長笑引山海經爲證皆具有根據要異乎虛騁浮</span>  
<span style="margin-left: 2em">詞徒慿臆斷者矣至於所引戰國策蔡聖侯因是</span>  
<span style="margin-left: 2em">已君王之事因是已二已字今本並作以而證以</span>  
<span style="margin-left: 2em">李善註阮籍詠懷詩所引實作已字足以考訂古</span>  
<span style="margin-left: 2em">本又大學絜矩今本章句作絜度也冶所見本則</span>  
<span style="margin-left: 2em">作絜圍束也蘇軾赤壁賦今本作而吾與子之所</span>  
<span style="margin-left: 2em">共適冶所見本則作共食而駁一本作共樂之非</span>
