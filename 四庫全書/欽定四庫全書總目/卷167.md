## 欽定四庫全書總目 卷一百六十七　集部二十　別集類二十

欽定四庫全書總目卷一百六十七  
<span style="margin-left: 1em">集部二十</span>  
<span style="margin-left: 2em">別集類二十</span>  
蘭軒集十六卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">元王旭撰旭字景初東平人其事蹟不見於元史</span>  
<span style="margin-left: 2em">談藝家亦罕見稱述顧嗣立撰元詩選彚緝至三</span>  
<span style="margin-left: 2em">百家而不載旭集則久佚可知惟山東通志稱旭</span>  
<span style="margin-left: 2em">與同郡王搆及永年王槃俱以文章名世天下號</span>  
<span style="margin-left: 2em">爲三王而於其岀處本末亦未詳載則併其人亦</span>  
<!-- 册4 葉1549b　Page:文淵閣四庫全書_0004冊.djvu/392 -->
<span style="margin-left: 2em">幾湮沒矣今以集中詩文考之葢旭家貧力學教</span>  
<span style="margin-left: 2em">授四方嘗爲碭山令所賔禮送王侯二生序所謂</span>  
<span style="margin-left: 2em">至元庚寅碭宰崔公以禮招余至其邑俾專講席</span>  
<span style="margin-left: 2em">者是也又嘗至長蘆主高百川家中和書院記所</span>  
<span style="margin-left: 2em">云辱承君幣來自泰山者是也其餘如安陽如鄃</span>  
<span style="margin-left: 2em">城如鯨川皆所曾僑寓之地又嘗至杭州之長沙</span>  
<span style="margin-left: 2em">遊迹幾半天下而卒未登仕版其有𭔃詩云處困</span>  
<span style="margin-left: 2em">不堪家累重謀生聊籍主人賢生平境遇卽此可</span>  
<span style="margin-left: 2em">以見其大槪矣其詩隨意抒寫不屑屑於雕章琢</span>  
<!-- 册4 葉1552a　Page:文淵閣四庫全書_0004冊.djvu/393 -->
<span style="margin-left: 2em">句而氣體超邁亦復時見性靈古文多講學家言</span>  
<span style="margin-left: 2em">其井田說一篇務欲復三代之制迂濶尤甚殆全</span>  
<span style="margin-left: 2em">不解事之腐儒然如記序諸作和平通達與之坐</span>  
<span style="margin-left: 2em">而談理其持論則未嘗不醇正未可廢也其集見</span>  
<span style="margin-left: 2em">於文淵閣書目者一部一册而焦竑經籍志則作</span>  
<span style="margin-left: 2em">二十卷今從永樂大典採掇排比尙可得一十六</span>  
<span style="margin-left: 2em">卷決非一册所能盡或一冊一字爲十字之訛歟</span>  
淸容居士集五十卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">元袁桷撰桷有延祐四明志已著錄其集據蘇天</span>  
<!-- 册4 葉1552b　Page:文淵閣四庫全書_0004冊.djvu/393 -->
<span style="margin-left: 2em">爵行狀及元史本傳俱稱五十卷此本卷數相符</span>  
<span style="margin-left: 2em">葢猶舊本也桷少從戴表元王應麟舒岳祥諸遺</span>  
<span style="margin-left: 2em">老游學問淵源具有所自其在朝踐厯淸華再入</span>  
<span style="margin-left: 2em">集賢八登翰苑凡朝廷制冊勛臣碑板多出其手</span>  
<span style="margin-left: 2em">故其文章博碩偉麗有盛世之音尤練習掌故長</span>  
<span style="margin-left: 2em">於考据集中如南郊十議明堂郊天異制議祭天</span>  
<span style="margin-left: 2em">無間歲議郊不當立從祀議郊非辛日議諸篇皆</span>  
<span style="margin-left: 2em">成宗初所上其援引經訓原原本本非空談聚訟</span>  
<span style="margin-left: 2em">者所能當時以其精博並採用之其詩格俊邁高</span>  
<!-- 册4 葉1553a　Page:文淵閣四庫全書_0004冊.djvu/393 -->
<span style="margin-left: 2em">華造語亦多工鍊卓然能自成一家葢桷本舊家</span>  
<span style="margin-left: 2em">文獻之遺又當大德延祐間爲元治極盛之際故</span>  
<span style="margin-left: 2em">其著作宏富氣象光昌蔚爲承平雅頌之聲文采</span>  
<span style="margin-left: 2em">風流遂爲虞楊范揭等先路之導其承前啟後稱</span>  
<span style="margin-left: 2em">一代文章之鉅公良無愧色矣</span>  
此山集四卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">元周權撰權字衡之號此山處州人嘗游京師以</span>  
<span style="margin-left: 2em">詩贄翰林學士袁桷桷深重之薦爲館職竟報罷</span>  
<span style="margin-left: 2em">然詩名日起唱和日多集中有贈趙孟頫詩云瓣</span>  
<!-- 册4 葉1553b　Page:文淵閣四庫全書_0004冊.djvu/393 -->
<span style="margin-left: 2em">香未展師道敬擕琴暫出松蘿中贈虞集詩云遠</span>  
<span style="margin-left: 2em">遊非涉聲利途願謁國文開榛蕪贈揭徯斯詩云</span>  
<span style="margin-left: 2em">嗟予觀光老賔客瓣香仰止懷生平贈陳旅詩云</span>  
<span style="margin-left: 2em">下榻淸風延孺子高樓豪氣臥元龍贈歐陽元詩</span>  
<span style="margin-left: 2em">云<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3314.svg?width=24" alt="四庫全書僻字第3314號（牀）" title="四庫全書僻字第3314號（牀）">頭萍綠多矜色長價還從薛卞門贈馬祖常</span>  
<span style="margin-left: 2em">詩云絶憐白髪南州士山斗彌高獨仰韓而趙孟</span>  
<span style="margin-left: 2em">頫贈權詩亦有青青雲外山炯炯松下石頋此山</span>  
<span style="margin-left: 2em">中人風神照松色之句且親寫此山二字爲額以</span>  
<span style="margin-left: 2em">贈是時文章耆宿不過此數人而數人無不酬答</span>  
<!-- 册4 葉1556a　Page:文淵閣四庫全書_0004冊.djvu/394 -->
<span style="margin-left: 2em">似權亦聲氣干謁之流然孟頫等並以儒雅風流</span>  
<span style="margin-left: 2em">照映一世其宏奬後進迥異於南宋末葉分朋標</span>  
<span style="margin-left: 2em">榜之私故終元之世士大夫無鈎黨之禍權與諸</span>  
<span style="margin-left: 2em">人𣢾契葢文字之相知固未可以依門傍戸論也</span>  
<span style="margin-left: 2em">是集爲陳旅所選定旅及袁桷歐陽元等各爲之</span>  
<span style="margin-left: 2em">序揭徯斯又爲之䟦旅本作者故別擇特精旅序</span>  
<span style="margin-left: 2em">稱其簡淡和平無鬱憤放傲之色桷序稱其法蘇</span>  
<span style="margin-left: 2em">黃之凖繩達騷選之㫖趣元序稱其無險勁之詞</span>  
<span style="margin-left: 2em">而有深長之味無輕靡之習而有舂容之風今觀</span>  
<!-- 册4 葉1556b　Page:文淵閣四庫全書_0004冊.djvu/394 -->
<span style="margin-left: 2em">其詩元所稱尤爲知言矣</span>  
霞外詩集十卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">元馬臻撰臻字志道號虗中錢塘道士仇遠序是</span>  
<span style="margin-left: 2em">集稱共隱約西湖之濵士大夫慕與之交不過習</span>  
<span style="margin-left: 2em">淸虚談淡泊無一言及勢力聲利龔開序則稱大</span>  
<span style="margin-left: 2em">德辛丑嗣天師張眞人如燕主行内醮元教名流</span>  
<span style="margin-left: 2em">並翼然景從王子繇馬志道在焉其人葢在通介</span>  
<span style="margin-left: 2em">之間者也集中鋪張富貴者數篇如嗣師吳眞人</span>  
<span style="margin-left: 2em">詩之𩔖頗乖山林之格然所作皆神骨秀騫風力</span>  
<!-- 册4 葉1557a　Page:文淵閣四庫全書_0004冊.djvu/394 -->
<span style="margin-left: 2em">遒上琅琅有金石之音雖不能具金鳷擘海香象</span>  
<span style="margin-left: 2em">渡河之力而亦不類酸寒細碎蟲吟草閒觀其述</span>  
<span style="margin-left: 2em">懷一詩殆宋末遺老𭔃託黃冠而其豪逸俊邁之</span>  
<span style="margin-left: 2em">氣無所不可政不以枯寂恬淡爲高耳此本爲毛</span>  
<span style="margin-left: 2em">晉所刻末有晉䟦稱伯雨之後復有虚中今考諸</span>  
<span style="margin-left: 2em">家之序皆作於仁宗大德初年則臻尚在張雨前</span>  
<span style="margin-left: 2em">晉偶失檢也</span>  
申齋集十五卷<sub class="note-yuan">編修汪如藻家藏本</sub>  
<span style="margin-left: 2em">元劉岳申撰岳申字高仲吉水人以吳澄薦召爲</span>  
<!-- 册4 葉1557b　Page:文淵閣四庫全書_0004冊.djvu/394 -->
<span style="margin-left: 2em">遼陽儒學副提舉不就後授泰和州判致仕是集</span>  
<span style="margin-left: 2em">乃其門人蕭洵所編李祁爲之序元季嘗付剞劂</span>  
<span style="margin-left: 2em">久經兵燬顧嗣立元詩選蒐羅至備獨不及此編</span>  
<span style="margin-left: 2em">江西通志亦謂岳申文集今已不傳今此鈔帙僅</span>  
<span style="margin-left: 2em">存亦可云希覯之本矣岳申文宗法韓蘇故其氣</span>  
<span style="margin-left: 2em">骨遒上無南宋卑冗之習豫章人物志稱所作簡</span>  
<span style="margin-left: 2em">約峻潔殆非虚語至集中碑誌之作居什之四五</span>  
<span style="margin-left: 2em">尤可據以考證史事如文天祥傳比宋史所載爲</span>  
<span style="margin-left: 2em">詳夏貴墓誌稱其出竒計立戰功甚悉而貴之失</span>  
<!-- 册4 葉1560a　Page:文淵閣四庫全書_0004冊.djvu/395 -->
<span style="margin-left: 2em">節偷生絶不爲諱且深致婉惜之詞亦非曲筆諛</span>  
<span style="margin-left: 2em">墓者可比觀其不妄許與其文品之矜貴可知也</span>  
西巖集二十卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">元張之翰撰之翰字周卿邯鄲人元史無傳惟松</span>  
<span style="margin-left: 2em">江府志載之翰至元末自翰林侍講學士知松江</span>  
<span style="margin-left: 2em">府事有古循吏風時民苦荒租額以十萬計之翰</span>  
<span style="margin-left: 2em">力除其𡚁得以蠲除至今猶祠於名宦祠生平著</span>  
<span style="margin-left: 2em">述甚富晚號西巖老人故以西巖名集其詩淸新</span>  
<span style="margin-left: 2em">逸宕有蘇軾黃庭堅之遺文亦頗具唐宋舊格其</span>  
<!-- 册4 葉1560b　Page:文淵閣四庫全書_0004冊.djvu/395 -->
<span style="margin-left: 2em">集據松江府志所載本三十卷今於永樂大典中</span>  
<span style="margin-left: 2em">蒐採綴輯分體編次釐爲二十卷雖當時舊本篇</span>  
<span style="margin-left: 2em">頁多寡不可知而約畧大數計巳得什之六七矣</span>  
<span style="margin-left: 2em">永樂大典所載有標題張西巖集而核其詩文實</span>  
<span style="margin-left: 2em">爲張起岩作者起岩字夢臣濟南人有華峯漫稿</span>  
<span style="margin-left: 2em">𩔖稿金陵集尚行於世與之翰截然兩人殆當世</span>  
<span style="margin-left: 2em">繕錄之人以張西巖集與張起巖集聲音畧近故</span>  
<span style="margin-left: 2em">隨讀而訛致相淆亂今並釐正各存其眞焉</span>  
蒲室集十五卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<!-- 册4 葉1561a　Page:文淵閣四庫全書_0004冊.djvu/395 -->
<span style="margin-left: 2em">元釋大訢撰大訢字笑隱南昌陳氏子居杭之鳳</span>  
<span style="margin-left: 2em">山遷中天竺又主建康集慶寺是集詩六卷文九</span>  
<span style="margin-left: 2em">卷前有虞集序謂其如洞庭之野衆樂並作鏗宏</span>  
<span style="margin-left: 2em">軒昂蛟龍起躍物怪屏走沉冥發興至於名教節</span>  
<span style="margin-left: 2em">義則感厲奮激老於文學者不能過雖稱之少溢</span>  
<span style="margin-left: 2em">其量然其五言古詩實足揖讓於士大夫間餘體</span>  
<span style="margin-left: 2em">亦不舍蔬筍之氣在僧詩中猶屬雅音又文宗入</span>  
<span style="margin-left: 2em">繼大統改建康潛邸爲集慶寺特起大訢居之授</span>  
<span style="margin-left: 2em">大中大夫故雖隸緇流頗諳朝廷掌故若所著王</span>  
<!-- 册4 葉1561b　Page:文淵閣四庫全書_0004冊.djvu/395 -->
<span style="margin-left: 2em">可毅尚書厯任記證以元史文宗本紀皆相符合</span>  
<span style="margin-left: 2em">惟本紀謂至治元年五月中政使耀珠<sub class="note-yuan">原作咬住今改正</sub></span>  
<span style="margin-left: 2em">告托歡徹爾<sub class="note-yuan">原作脫歡察兒今改正</sub>等交通親王於是出文</span>  
<span style="margin-left: 2em">宗居海南而是記則謂至治二年讒慝搆禍文宗</span>  
<span style="margin-left: 2em">遷海南與本紀相差一年或傳寫誤元爲二故與</span>  
<span style="margin-left: 2em">史異耶集中多與趙孟頫柯九思薩都拉<sub class="note-yuan">原作薩都刺今</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">改正</sub>高彦敬虞集馬臻張翥李孝光往來之作而第</span>  
<span style="margin-left: 2em">九卷中杭州路金剛顯教院記第十二卷金陵天</span>  
<span style="margin-left: 2em">禧講寺佛光大師德公塔銘並註曰代趙魏公作</span>  
<!-- 册4 葉1564a　Page:文淵閣四庫全書_0004冊.djvu/396 -->
<span style="margin-left: 2em">則孟頫亦嘗假手於大訢知非俗僧矣</span>  
弁山小隱吟錄二卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">元黃玠撰玠姓名不見於史傳惟宏治湖州府志</span>  
<span style="margin-left: 2em">載玠字伯成慈谿人宋黃震之曾孫淸苦力學無</span>  
<span style="margin-left: 2em">所不通周游西湖樂吳興山水因卜居弁山與趙</span>  
<span style="margin-left: 2em">文敏游文敏稱許之有卞山集知非稿唐詩選藄</span>
