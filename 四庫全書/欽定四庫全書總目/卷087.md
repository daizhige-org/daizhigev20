## 欽定四庫全書總目 卷八十七　史部四十三　目錄類存目

<!-- 册2 葉3168：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷八十七  
<span style="margin-left: 1em">史部四十三</span>  
<span style="margin-left: 2em">目錄𩔖存目</span>  
<span style="margin-left: 1em">藩書目一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub></span>  
<span style="margin-left: 2em">不著撰人名氏初寧獻王權以永樂中改封南昌</span>  
<span style="margin-left: 2em">日與文士往還所纂輯及刋刻之書甚多嘉靖二</span>  
<span style="margin-left: 2em">十年弋陽王世子多焜求得其書目因命敎授施</span>  
<span style="margin-left: 2em">文明校刋行之所載書凡一百三十七種詞曲院</span>  
<span style="margin-left: 2em">本道家煉度齋醮諸儀俱匯焉前有多焜序及啓</span>  
<!-- 册2 葉3169b　Page:文淵閣四庫全書_0002冊.djvu/797 -->
<span style="margin-left: 2em">一通後有施文明跋多焜啓中所稱父王者乃弋</span>  
<span style="margin-left: 2em">陽端惠王拱樻以嘉靖初受命攝寧府事多焜後</span>  
<span style="margin-left: 2em">亦襲封諡曰恭懿見明史諸王世表</span>  
秘閣書目<sub class="note-yuan">無卷數　兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明錢溥𢰅溥有使交錄已著錄是編前有自序蓋</span>  
<span style="margin-left: 2em">其致仕歸里後所作稱自𨕖入東閣爲史官日閱</span>  
<span style="margin-left: 2em">中秘書凡五十餘大橱因錄其目藏以待考近兒</span>  
<span style="margin-left: 2em">子山自京授職囘又錄未收書目芟其重複併爲</span>  
<span style="margin-left: 2em">一集所載書祇有冊數而無卷數大扺多與文淵</span>  
<!-- 册2 葉3172a　Page:文淵閣四庫全書_0002冊.djvu/798 -->
<span style="margin-left: 2em">閣書目相岀入正統六年楊士竒等奏疏一篇亦</span>  
<span style="margin-left: 2em">附於後黃虞稷千頃堂書目載此書爲馬愉𢰅而</span>  
<span style="margin-left: 2em">溥别有内閣書目一卷然溥序實載此書卷首疑</span>  
<span style="margin-left: 2em">虞稷所紀誤也</span>  
菉竹堂書目六卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明葉盛𢰅盛有葉文莊奏議已著錄此其家藏書</span>  
<span style="margin-left: 2em">之目首卷日制乃官頒各書及賜書賜勅之𩔖中</span>  
<span style="margin-left: 2em">爲經史子集各一卷末卷日後錄則其家所刋及</span>  
<span style="margin-left: 2em">自著書前有成化七年自序謂先之以制尊朝廷</span>  
<!-- 册2 葉3172b　Page:文淵閣四庫全書_0002冊.djvu/798 -->
<span style="margin-left: 2em">也葉氏書獨以爲後錄是吾一家之書也其敘列</span>  
<span style="margin-left: 2em">體例大率本之馬端臨經籍考然如集部別出舉</span>  
<span style="margin-left: 2em">業類亦畧有所增改所載凡爲册者四千六百有</span>  
<span style="margin-left: 2em">竒爲卷者二萬二千七百有竒在儲藏家稱極富</span>  
<span style="margin-left: 2em">故於舊書著錄爲多獨其不載𢰅人姓名頗傷闕</span>  
<span style="margin-left: 2em">畧又別有新書目一卷附於後中載夏言王守仁</span>  
<span style="margin-left: 2em">諸人集皆不與盛同時蓋其子孫所續入也</span>  
文苑春秋敘錄一卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明崔銑𢰅銑有讀易餘言已著錄是書自序稱夫</span>  
<!-- 册2 葉3173a　Page:文淵閣四庫全書_0002冊.djvu/798 -->
<span style="margin-left: 2em">子刪書百篇以寓懲勸後來選文家未有繼夫子</span>  
<span style="margin-left: 2em">之志而法尚書者乃錄漢詔疏以迄明太祖檄元</span>  
<span style="margin-left: 2em">文共爲百篇名曰文苑春秋爲敘錄一卷畧表作</span>  
<span style="margin-left: 2em">者之志自漢文以下凡十一目今已散入文苑春</span>  
<span style="margin-left: 2em">秋各冠本篇之首此則其单行別本也大扺皆仿</span>  
<span style="margin-left: 2em">尚書小序之文欲自比於王通擬經未免近妄其</span>  
<span style="margin-left: 2em">所去取專主明理惟漢文稍多餘則代各數篇更</span>  
<span style="margin-left: 2em">不足盡文章之變矣</span>  
寶文堂分類書目三卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<!-- 册2 葉3173b　Page:文淵閣四庫全書_0002冊.djvu/798 -->
<span style="margin-left: 2em">明晁瑮撰瑮字君石號春陵開州人宋太子太傅</span>  
<span style="margin-left: 2em">迥之後嘉靖辛丑進士官至國子監司業其子東</span>  
<span style="margin-left: 2em">吳字叔權嘉靖癸丑進士𨕖翰林院庶吉士父子</span>  
<span style="margin-left: 2em">皆喜儲藏嘗刋行諸書有飮月圃百忍堂諸板此</span>  
<span style="margin-left: 2em">本以御製爲首上卷分總經五經四書性理史子</span>  
<span style="margin-left: 2em">文集詩詞等十二目中卷分類書子雜樂府四六</span>  
<span style="margin-left: 2em">經濟舉業等六目下卷分韻書政書兵書刑書陰</span>  
<span style="margin-left: 2em">陽醫書農圃藝譜算法圖誌年譜姓氏佛藏道藏</span>  
<span style="margin-left: 2em">法帖等十五目其著錄極富雖不能盡屬古本而</span>  
<!-- 册2 葉3176a　Page:文淵閣四庫全書_0002冊.djvu/799 -->
<span style="margin-left: 2em">每書下間爲注明某刻亦足以考見明人板本源</span>  
<span style="margin-left: 2em">流特其編次無法類目叢襍複見錯出者不一而</span>  
<span style="margin-left: 2em">足殊妨簡閲蓋愛博而未能精者也</span>  
經序錄五卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明朱睦㮮𢰅睦㮮旣作授經圖又取諸家說經之</span>  
<span style="margin-left: 2em">書各采篇首一序編爲一集以誌其槩頗嫌挂漏</span>  
國史經籍志六卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明焦竑𢰅竑有易筌已著錄是書首列制書𩔖凡</span>  
<span style="margin-left: 2em">御製及中宫著作記註時政敕修諸書皆附焉餘</span>  
<!-- 册2 葉3176b　Page:文淵閣四庫全書_0002冊.djvu/799 -->
<span style="margin-left: 2em">分經史子集四部末附糾繆一卷則駁正漢書隋</span>  
<span style="margin-left: 2em">書唐書宋書諸藝文志及四庫書目崇文總目鄭</span>  
<span style="margin-left: 2em">樵藝文畧馬端臨經籍考晁公武讀書志諸家分</span>  
<span style="margin-left: 2em">門之誤蓋萬厯間陳于陛議修國史引竑專領其</span>  
<span style="margin-left: 2em">事書未成而罷僅成此志故仍以國史爲名顧其</span>  
<span style="margin-left: 2em">書叢抄舊目無所考核不論存亡率爾濫載古來</span>  
<span style="margin-left: 2em">目錄惟是書最不足憑世以竑負博物之名莫之</span>  
<span style="margin-left: 2em">敢詰往往貽誤後生其譎詞<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3271.svg?width=24" alt="四庫全書僻字第3271號（炫）" title="四庫全書僻字第3271號（炫）">世又甚於楊愼之</span>  
<span style="margin-left: 2em">丹鉛錄矣</span>  
<!-- 册2 葉3177a　Page:文淵閣四庫全書_0002冊.djvu/799 -->
經厰書目一卷<sub class="note-yuan">編修汪如藻家藏本</sub>  
<span style="margin-left: 2em">明内府所刋書目也黃虞稷千頃堂書目有此書</span>  
<span style="margin-left: 2em">亦作一卷經厰卽内繙經厰明世以宦官主之書</span>  
<span style="margin-left: 2em">籍刋板皆貯於此所列書一百十四部凡冊數頁</span>  
<span style="margin-left: 2em">數𥿄幅多寡一一詳載蓋卽當時通行則例好事</span>  
<span style="margin-left: 2em">者錄而傳之然大扺皆習見之書甚至神童詩百</span>  
<span style="margin-left: 2em">家姓亦厠其中殊爲猥雜今印行之本尚有流傳</span>  
<span style="margin-left: 2em">往往舛錯疑誤後生蓋天祿石渠之任而以寺人</span>  
<span style="margin-left: 2em">領之此與唐魚朝恩判國子監何異又不止辟陽</span>  
<!-- 册2 葉3177b　Page:文淵閣四庫全書_0002冊.djvu/799 -->
<span style="margin-left: 2em">長信指揮馬鄭之前周勃張飛弹壓雷桐之右如</span>  
<span style="margin-left: 2em">劉知幾之所云矣明政不綱此亦一端而當時未</span>  
<span style="margin-left: 2em">有論及之者宜馮保刻私印其文曰内翰之章也</span>  
<span style="margin-left: 2em"><sub class="note-yuan">按馮保印文見所作經書輯音序文末</sub></span>  
讀書敏求記四卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 1em">國朝錢曾𢰅曾字遵王自號也是翁常熟人家富圖</span>  
<span style="margin-left: 2em">籍多蓄舊笈此書皆載其最佳之本手所題識彷</span>  
<span style="margin-left: 2em">彿歐陽修集古錄之意凡分經史子集四目經之</span>  
<span style="margin-left: 2em">支有六曰禮樂曰字學曰韻書曰書曰數書曰小</span>  
<!-- 册2 葉3180a　Page:文淵閣四庫全書_0002冊.djvu/800 -->
<span style="margin-left: 2em">學史之支有十曰時令曰器用曰食經曰種藝曰</span>  
<span style="margin-left: 2em">豢養曰傳記曰譜牒曰科第曰地理輿圖曰別志</span>  
<span style="margin-left: 2em">子之支有二十曰雜家曰農家曰兵家曰天文曰</span>  
<span style="margin-left: 2em">五行曰六壬曰竒門曰厯法曰卜筮曰星命曰相</span>  
<span style="margin-left: 2em">法曰宅經曰塟書曰醫家曰鍼灸曰本草方書曰</span>  
<span style="margin-left: 2em">傷寒曰攝生曰藝術曰類家集之支有四曰詩集</span>  
<span style="margin-left: 2em">曰總集曰詩文評曰詞其分別門目多不甚可解</span>  
<span style="margin-left: 2em">如五經併爲一而字學韻書小學乃歧而三紀傳</span>  
<span style="margin-left: 2em">編年襍史之類併爲一而器用食經之𩔖乃多立</span>  
<!-- 册2 葉3180b　Page:文淵閣四庫全書_0002冊.djvu/800 -->
<span style="margin-left: 2em">子目儒家道家墨家縱橫家併爲一而雜家農家</span>  
<span style="margin-left: 2em">兵家以下乃又縷析諸名皆離合未當又如書法</span>  
<span style="margin-left: 2em">數書本藝術而入經種藝豢養本農家而入史皆</span>  
<span style="margin-left: 2em">配隸無緒至於朱子家禮入禮樂而司馬氏書儀</span>  
<span style="margin-left: 2em">韓氏家祭禮則入史吾衍續古篆韻入字書而夏</span>  
<span style="margin-left: 2em">竦古文四聲韻則入韻書以至北夢瑣言本小說</span>  
<span style="margin-left: 2em">而入史元經本編年碧雞漫志本詞品而皆入子</span>  
<span style="margin-left: 2em">編列失次者尤不一而足其中解題大畧多論繕</span>  
<span style="margin-left: 2em">寫刋刻之工拙於考證不甚留意如韻畧易通至</span>  
<!-- 册2 葉3181a　Page:文淵閣四庫全書_0002冊.djvu/800 -->
<span style="margin-left: 2em">謬之本而以爲心目了然東坡石鼓文全本實楊</span>  
<span style="margin-left: 2em">愼僞託而以爲篆籀特全臞仙史畧載元順帝爲</span>  
<span style="margin-left: 2em">瀛國公子誣妄無據而以爲修元史者見不及此</span>  
<span style="margin-left: 2em">了證歌稱杜光庭太素脉法稱空峒仙翁本皆僞</span>  
<span style="margin-left: 2em">託而以爲實然元珠密語最爲妄誕而以爲中素</span>  
<span style="margin-left: 2em">問六氣之隱奥李商隱留贈畏之詩後二首本爲</span>  
<span style="margin-left: 2em">誤先原題而强生曲解聲畫集本孫紹遠𢰅而以</span>  
<span style="margin-left: 2em">爲無名氏歲寒堂詩話本張戒𢰅而以爲趙戒魏</span>  
<span style="margin-left: 2em">校六書精藴最穿鑿而謂徐官音釋六書之學極</span>  
<!-- 册2 葉3181b　Page:文淵閣四庫全書_0002冊.djvu/800 -->
<span style="margin-left: 2em">佳四聲等子與劉鑑切韻指南異同不一而以爲</span>  
<span style="margin-left: 2em">卽一書古三墳書及東家襍記之琴歌僞託顯然</span>  
<span style="margin-left: 2em">而依違不斷蕭常續後漢書正三國史之誤而大</span>  
<span style="margin-left: 2em">以爲非王弼註老子世有刻本而以爲不傳龎安</span>  
<span style="margin-left: 2em">常聖散子方宋人已力辨蘇軾之誤信而復稱道</span>  
<span style="margin-left: 2em">其說屈原賦宋玉賦漢藝文志有明文而斥錢杲</span>  
<span style="margin-left: 2em">之謂離騷爲賦之非歐陽詹贈妓詩眞迹至邵伯</span>  
<span style="margin-left: 2em">温時猶在而以爲𭔃懷隱士之作皆不爲<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">論然</span>  
<span style="margin-left: 2em">其述授受之源流究繕刻之同異見聞旣愽辨別</span>  
<!-- 册2 葉3184a　Page:文淵閣四庫全書_0002冊.djvu/801 -->
<span style="margin-left: 2em">尤精但以板本而論亦可謂之賞鑒家矣</span>  
述古堂書目<sub class="note-yuan">無卷數　浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝錢曾𢰅曾此編乃其藏書總目所列門𩔖瑣碎</span>  
<span style="margin-left: 2em">冗雜全不師古其分𨽻諸書尤舛謬顚倒不可名</span>  
<span style="margin-left: 2em">狀較讀書敏求記更無條理如楊伯嵓九經補韻</span>  
<span style="margin-left: 2em">乃摭九經之字以補禮部韻畧非九經音釋而列</span>  
<span style="margin-left: 2em">之於經玉篇龍龕手鏡篇海從古正文皆字書也</span>

<span style="margin-left: 2em">作就所得金石採錄其文彚輯成帙王士禎分甘</span>  
<span style="margin-left: 2em">餘話稱奕禧於秦漢唐宋以來金石文字收藏尤</span>  
<span style="margin-left: 2em">富皆爲題䟦辨證而以爲米元章黃伯思一流人</span>

<span style="margin-left: 2em">在錄文而不全在䟦也卽以錄文而論亦尠體例</span>

<span style="margin-left: 2em">於今者不知奕禧果見其拓本抑或僅於金石書</span>  
<span style="margin-left: 2em">中錄之若果見拓本則是希有之蹟必當詳注所</span>  
<span style="margin-left: 2em">自來若僅從金石書抄取則挂漏在所不免矣至</span>  
<span style="margin-left: 2em">於碑之原額原題頗有改竄又於題下標列姓氏</span>
