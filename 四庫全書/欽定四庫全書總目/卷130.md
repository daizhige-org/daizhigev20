<span style="margin-left: 1em">子部四十</span>  
<span style="margin-left: 2em">雜家𩔖存目七</span>  
感應𩔖從志一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">舊題晉張華撰隋唐以來經籍藝文諸志皆所不</span>  
<span style="margin-left: 2em">載諸家書目亦不著錄書中語多俚陋且皆妖妄</span>  
<span style="margin-left: 2em">魘制之法其爲依託無疑也</span>  
物𩔖相感志十八巻<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">舊本題東坡先生撰然蘇軾不聞有此書又題僧</span>  
<!-- 册3 葉3129b　Page:文淵閣四庫全書_0003冊.djvu/787 -->
<span style="margin-left: 2em">贊寧編次按晁公武讀書志及鄭樵通志藝文略</span>  
<span style="margin-left: 2em">皆載物𩔖相感志十巻僧贊寧撰是書分十八巻</span>  
<span style="margin-left: 2em">旣不相符又贊寧爲宋初人軾爲熙寧元祐間人</span>  
<span style="margin-left: 2em">豈有軾著此書而贊寧編次之理其爲不通坊賈</span>  
<span style="margin-left: 2em">僞撰售欺審矣且書以物𩔖相感爲名自應載琥</span>  
<span style="margin-left: 2em">珀拾芥磁石引針之屬而分天地人<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">鳥獸草木</span>  
<span style="margin-left: 2em">竹蟲魚寳器十二門𨽻事全似𩔖書名實乖舛尤</span>  
<span style="margin-left: 2em">徵其妄也</span>  
物𩔖相感志一巻<sub class="note-yuan">浙江巡撫採進本</sub>  
<!-- 册3 葉3132a　Page:文淵閣四庫全書_0003冊.djvu/788 -->
<span style="margin-left: 2em">舊本題宋蘇軾撰凡分身體衣服飮食器用藥品</span>  
<span style="margin-left: 2em">疾病文房果子蔬菜花竹禽魚襍著十二門共四</span>  
<span style="margin-left: 2em">百四十八條皆療治及禁忌之事疑十八卷之本</span>  
<span style="margin-left: 2em">卽因此本而衍之也</span>  
格物麤談二卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">舊本亦題蘇軾撰分天時地理等二十門與世所</span>  
<span style="margin-left: 2em">傳軾物𩔖相感志大畧相似後有元范楟識斷爲</span>  
<span style="margin-left: 2em">後人假託他書亦罕見著錄惟曹溶收入學海𩔖</span>  
<span style="margin-left: 2em">編中葢物𩔖相感志已出僞作此更僞書之重儓</span>

<span style="margin-left: 2em">也</span>  
居家必用事𩔖全集十卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">不著撰人名氏載厯代名賢格訓及居家日用事</span>  
<span style="margin-left: 2em">宜以十干分集體例頗爲簡潔辛集中有大德五</span>  
<span style="margin-left: 2em">年吳郡徐元瑞吏學指南序聖朝字俱跳行又永</span>  
<span style="margin-left: 2em">樂大典屢引用之其爲元人書無疑黃虞稷千頃</span>  
<span style="margin-left: 2em">堂書目云或謂熊宗立撰恐未必然也</span>  
多能鄙事十二卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">舊本題明劉基撰基有淸𩔖天文分野之書已著</span>  
<!-- 册3 葉3133a　Page:文淵閣四庫全書_0003冊.djvu/788 -->
<span style="margin-left: 2em">錄是書凡飮食器用方藥農圃牧養陰陽占卜之</span>  
<span style="margin-left: 2em">法無不備載頗適於用然體近𤨏碎若小兒四季</span>  
<span style="margin-left: 2em">闗百日闗之𩔖俱見臚列殊失雅馴立名取孔子</span>  
<span style="margin-left: 2em">之言亦屬僣妄殆託名於基者也</span>  
都氏鐵網珊瑚二十卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明都穆撰穆有壬午功臣爵賞錄已著錄是書與</span>  
<span style="margin-left: 2em">世傳朱存理鐵網珊瑚同名<sub class="note-yuan">案存理之書非存理所撰辨詳本條下此</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">姑從世俗刋本稱之</sub>然存理之書分書品畫品二門備錄題</span>  
<span style="margin-left: 2em">䟦印記爲張丑郁逢慶諸書所宗是書則前四卷</span>  
<!-- 册3 葉3133b　Page:文淵閣四庫全書_0003冊.djvu/788 -->
<span style="margin-left: 2em">皆穆所爲諸書序䟦及書畫題䟦卷五以下卽穆</span>  
<span style="margin-left: 2em">所作寓意編葢穆嘗以所見書畫别爲一書此又</span>  
<span style="margin-left: 2em">以𩔖相從附於書目之後然其中忽雜入書畫銘</span>  
<span style="margin-left: 2em">心錄乃何良俊所撰第七卷内鶴鵲一條又忽標</span>  
<span style="margin-left: 2em">爾雅二字之目皆不可解至第九卷雜錄研銘皆</span>  
<span style="margin-left: 2em">採自諸家文集非親見拓本第十卷以下則鈔僞</span>  
<span style="margin-left: 2em">本張掄紹興古器評十二卷以下則鈔湯垕畫鑒</span>  
<span style="margin-left: 2em">十五卷後半以下則鈔趙希鵠洞天淸錄十八卷</span>  
<span style="margin-left: 2em">以下則鈔周宻雲烟過眼錄皆非所自著葢姦𭶑</span>  
<!-- 册3 葉3136a　Page:文淵閣四庫全書_0003冊.djvu/789 -->
<span style="margin-left: 2em">書賈襍裒成編借穆之名以行也</span>  
水雲錄二卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明楊溥撰溥長沙人自號水雲居士千頃堂書目</span>  
<span style="margin-left: 2em">列於劉基多能鄙事後卽以爲永樂中石首楊溥</span>  
<span style="margin-left: 2em">然考書中自述有戎務之暇語則其人乃嘗爲武</span>  
<span style="margin-left: 2em">職者又所撰有用藥珍珠<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3615.svg?width=24" alt="四庫全書僻字第3615號（囊）" title="四庫全書僻字第3615號（囊）">其書成於宏治中葢</span>  
<span style="margin-left: 2em">名姓偶同非一人也上卷載十二月種植花果飮</span>  
<span style="margin-left: 2em">饌及文房襍用下卷分衞生養生器用牧養四門</span>  
<span style="margin-left: 2em">所記多農圃種畜法頗爲𤨏屑</span>  
<!-- 册3 葉3136b　Page:文淵閣四庫全書_0003冊.djvu/789 -->
李氏居室記五卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明李濂撰濂有祥符先賢傳已著錄是編乃其退</span>  
<span style="margin-left: 2em">老居鄉築别墅於郊外有堂有亭各爲撰記室中</span>  
<span style="margin-left: 2em">器物悉製箴銘以寓規警葢林居放志之作故隨</span>  
<span style="margin-left: 2em">所欲言不以修詞爲意云</span>  
便民圖纂十六卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">不著撰人名氏第一卷爲農務圖十五第二卷爲</span>  
<span style="margin-left: 2em">女紅圖十六毎圖皆係以竹枝詞一首第三卷以</span>  
<span style="margin-left: 2em">下分十一𩔖曰耕穫曰桑蠶曰樹藝曰雜占日月</span>  
<!-- 册3 葉3137a　Page:文淵閣四庫全書_0003冊.djvu/789 -->
<span style="margin-left: 2em">占曰祈禳曰涓吉曰起居曰調攝曰牧養曰製造</span>  
<span style="margin-left: 2em">嘉靖壬子刻於貴州前有左布政使李涵序稱鄺</span>  
<span style="margin-left: 2em">廷瑞始刻於吳中吕經又刻於滇省其中利民用</span>  
<span style="margin-left: 2em">者甚多然意求全備往往冗𤨏如末卷載辟<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">魅</span>  
<span style="margin-left: 2em">法用桃枝洒雄黃水葢據本草桃枝殺<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">雄黃殺</span>  
<span style="margin-left: 2em">精魅之說已爲迂濶又有祛狐狸法云妖狸能變</span>  
<span style="margin-left: 2em">形惟千年枯木能照之可尋得年久枯木擊之其</span>  
<span style="margin-left: 2em">形自見則據張華然華表照斑狸事衍爲此法殆</span>  
<span style="margin-left: 2em">於兒戲矣其書本農家者流然旁及祈福擇日及</span>  
<!-- 册3 葉3137b　Page:文淵閣四庫全書_0003冊.djvu/789 -->
<span style="margin-left: 2em">諸格言不名一家故附之雜家𩔖焉</span>  
鼂采館淸課二卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明費元祿撰元祿字學<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">鉛山人鉛山之河口有</span>  
<span style="margin-left: 2em">五湖其一曰官湖卽鼂采湖也元祿搆館其上因</span>  
<span style="margin-left: 2em">以爲名是書皆記其館中景物及遊賞閒適之事</span>  
蕉窗九錄<sub class="note-yuan">無卷數　江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">舊本題明項元汴撰元汴字子京秀水人家藏書</span>  
<span style="margin-left: 2em">畫之富甲於天下今賞鑒家所稱項墨林者是也</span>  
<span style="margin-left: 2em">是書首𥿄錄次墨錄次筆錄次硯錄次帖錄次書</span>  
<!-- 册3 葉3140a　Page:文淵閣四庫全書_0003冊.djvu/790 -->
<span style="margin-left: 2em">錄次琴錄次香錄前有文彭序稱大半採自吳文</span>  
<span style="margin-left: 2em">定鑒古彚編間有刪潤今考其書陋畧殊甚彭序</span>  
<span style="margin-left: 2em">亦弇鄙不文二人皆萬萬不至此殆稍知字義之</span>  
<span style="margin-left: 2em">書賈以二人有博雅名依託之以<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3271.svg?width=24" alt="四庫全書僻字第3271號（炫）" title="四庫全書僻字第3271號（炫）">俗也</span>  
考槃餘事四卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">明屠隆撰隆有篇海𩔖編已著錄是書雜論文房</span>  
<span style="margin-left: 2em">淸玩之事一卷言書板碑帖二卷評書畫琴𥿄三</span>  
<span style="margin-left: 2em">卷四卷則筆硯爐瓶以至一切器用服御之物皆</span>  
<span style="margin-left: 2em">詳載之列目頗爲𤨏碎其論明一代書家以祝允</span>  
<!-- 册3 葉3140b　Page:文淵閣四庫全書_0003冊.djvu/790 -->
<span style="margin-left: 2em">明爲第一而文徵明次之軒輊亦未盡平允</span>  
游具雅編一卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">明屠隆撰所載笠杖漁竿之屬皆便於遊覽之具</span>  
<span style="margin-left: 2em">故以爲名卷末附圖四式一曰太極樽一曰葫蘆</span>  
<span style="margin-left: 2em">樽一曰山遊提盒一曰提爐雖書中所已具以其</span>  
<span style="margin-left: 2em">形製皆須圖乃明故復附繪於末</span>  
筠軒淸秘錄三卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">舊本題董其昌撰其昌有學科考畧已著錄是書</span>  
<span style="margin-left: 2em">凡列目二十有九皆論玉石銅磁諸古器及法書</span>  
<!-- 册3 葉3141a　Page:文淵閣四庫全書_0003冊.djvu/790 -->
<span style="margin-left: 2em">名畫之𩔖前有陳繼儒序謂可與項元汴薌林淸</span>  
<span style="margin-left: 2em">課並稱今考其書卽張應文所撰淸秘藏但析二</span>  
<span style="margin-left: 2em">卷爲三卷葢應文之書近日始有鮑氏知不足齋</span>  
<span style="margin-left: 2em">刋板附其子丑眞蹟日錄後從前抄本流傳不甚</span>  
<span style="margin-left: 2em">顯著書賈以其昌名重故僞造繼儒之序以<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3271.svg?width=24" alt="四庫全書僻字第3271號（炫）" title="四庫全書僻字第3271號（炫）">俗</span>  
<span style="margin-left: 2em">射利耳</span>  
墨林快事十二卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">明安世鳳撰世鳳有燕居功課已著錄此書以所</span>  
<span style="margin-left: 2em">見古器古刻古書畫各爲䟦語凡六百九十五則</span>  
<!-- 册3 葉3141b　Page:文淵閣四庫全書_0003冊.djvu/790 -->
<span style="margin-left: 2em">多渉議論頗乏考據之功</span>  
飛鳬語畧一卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">明沈德符撰德符字虎臣又字景伯又字景倩秀</span>  
<span style="margin-left: 2em">水人萬厯戊午舉人此書論字墨法帖及古器眞</span>  
<span style="margin-left: 2em">贋之別皆舉生平所聞見者凡十八條其中多與</span>  
<span style="margin-left: 2em">所著敝帚軒剩語相同疑卽從剩語中抄出者曹</span>  
<span style="margin-left: 2em">溶學海𩔖編乃兩收之未免失於詳檢也</span>  
華夷花木鳥獸珍玩考十卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明愼懋官撰懋官字汝學湖州人是書凡花木考</span>  
<!-- 册3 葉3144a　Page:文淵閣四庫全書_0003冊.djvu/791 -->
