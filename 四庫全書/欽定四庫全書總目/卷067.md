## 欽定四庫全書總目 卷六十七　史部二十三　時令類、時令類存目

<!-- 册2 葉1784a　Page:文淵閣四庫全書_0002冊.djvu/451 -->
欽定四庫全書總目巻六十七  
<span style="margin-left: 1em">史部二十三</span>  
<span style="margin-left: 2em">時令類</span>  
<span style="margin-left: 3em">堯典首授時舜初受命亦先齊七政後世推步</span>  
<span style="margin-left: 3em">測算重爲專門已别著錄其本天道之宜以立</span>  
<span style="margin-left: 3em">人事之節者則有時令諸書孔子考獻徴文以</span>  
<span style="margin-left: 3em">小正爲尙存夏道然則先王之政兹其大綱歟</span>  
<span style="margin-left: 3em">後世承流遞有撰述大抵農家曰用閭閻風俗</span>  
<span style="margin-left: 3em">爲多與禮經所載小異然民事卽王政也淺識</span>  
<!-- 册2 葉1784b　Page:文淵閣四庫全書_0002冊.djvu/451 -->
<span style="margin-left: 3em">者岐視之耳至於選詞章𨽻故實誇多鬬靡寖</span>  
<span style="margin-left: 3em">失厥初則踵事增華其來有漸不獨時令一家</span>  
<span style="margin-left: 3em">爲然汰除鄙倍採摭典要亦未始非豳風月令</span>  
<span style="margin-left: 3em">之遺矣</span>  
歲時廣記四巻<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">宋陳元靚撰元靚不知其里貫自署曰廣寒仙裔</span>  
<span style="margin-left: 2em">而劉純作後序稱爲隱君子其始末亦未詳言莫</span>  
<span style="margin-left: 2em">之考也書前又有知無爲軍巢縣事朱鑑序一篇</span>  
<span style="margin-left: 2em">鑑乃朱子之孫卽嘗輯詩傳遺說者後仕至湖廣</span>  
<!-- 册2 葉1785a　Page:文淵閣四庫全書_0002冊.djvu/451 -->
<span style="margin-left: 2em">總領元靚與之相識則理宗時人矣其書宋志不</span>  
<span style="margin-left: 2em">著錄惟見於錢曾讀書敏求記稱前列圖說分四</span>  
<span style="margin-left: 2em">時爲四巻今此本乃曹溶學海類編所載巻首並</span>  
<span style="margin-left: 2em">無圖說葢傳鈔者佚之書中摭月令孝經緯三統</span>  
<span style="margin-left: 2em">厯諸書爲綱而以雜書所說關於節序者按月分</span>  
<span style="margin-left: 2em">𨽻凡春令四十六條夏令五十條秋令三十二條</span>  
<span style="margin-left: 2em">冬令三十八條大抵爲啓剳應用而設故於稗官</span>  
<span style="margin-left: 2em">說部多所徴据而爾雅淮南諸書所載足資考證</span>  
<span style="margin-left: 2em">者反多遺缺未可以稱善本特其於所引典故皆</span>  
<!-- 册2 葉1785b　Page:文淵閣四庫全書_0002冊.djvu/451 -->
<span style="margin-left: 2em">備錄原文詳記所出未失前人遺意尙與後來類</span>  
<span style="margin-left: 2em">書隨意刪竄者不同姑錄存之以備叅考焉</span>  
欽定月令輯要二十四巻圖說一巻  
<span style="margin-left: 2em">康熙五十四年</span>  
聖祖仁皇帝御定初明馮應京與戴任共輯月令廣義二  
<span style="margin-left: 2em">十五巻體例粗備而所錄繁簡失中雅俗弗别頗</span>  
<span style="margin-left: 2em">不免於蕪雜未可以前民利用我</span>  
聖祖仁皇帝欽崇天道敬授人時  
特命儒臣别爲編纂門目雖仍其舊而刋除無稽之論增  
<!-- 册2 葉1788a　Page:文淵閣四庫全書_0002冊.djvu/452 -->
<span style="margin-left: 2em">補未備之文定爲圖說一卷歲令二卷毎月令一</span>  
<span style="margin-left: 2em">卷春夏秋冬令及土王令五卷十二月令及閏月</span>  
<span style="margin-left: 2em">令十三卷晝夜令二卷時刻令二卷毎類分天道</span>  
<span style="margin-left: 2em">政典民用物候占騐雜紀六子目毎月令則六子</span>  
<span style="margin-left: 2em">目外增日次一子目十二月令閏月令則六子目</span>  
<span style="margin-left: 2em">外增節序日次二子目各援引圖籍注明出典具</span>  
<span style="margin-left: 2em">有根據其爲舊本所有者標題原字今本所加者</span>  
<span style="margin-left: 2em">標題增字亦不掩古人所長本本元元條分縷析</span>  
<span style="margin-left: 2em">用以乘時布政順五氣之宜趨事勸功裨四民之</span>  
<!-- 册2 葉1788b　Page:文淵閣四庫全書_0002冊.djvu/452 -->
<span style="margin-left: 2em">業敬</span>  
天出治敦本重農之  
淵衷具見於是固不僅㸃綴歲華採擷詞藻徒供翰墨之  
<span style="margin-left: 2em">資焉</span>  
<span style="margin-left: 1em">右時令類二部二十九巻皆文淵閣著錄</span>  
<span style="margin-left: 2em">時令類存目</span>  
四時宜忌一巻<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">明瞿佑撰佑字宗吉錢塘人洪武初官國子助教</span>  
<span style="margin-left: 2em">永樂間官周王府右長史謫戍保安洪熙初赦還</span>  
<!-- 册2 葉1789a　Page:文淵閣四庫全書_0002冊.djvu/452 -->
<span style="margin-left: 2em">此書記十二月所宜所忌歴引孝經緯荆楚歲時</span>  
<span style="margin-left: 2em">記玉燭寳典而兼及於濟世仁術法天生意指月</span>  
<span style="margin-left: 2em">錄白雲雜忌諸書甚至道家符籙亦皆載入徴引</span>  
<span style="margin-left: 2em">雖博究不免傷於蕪雜</span>  
四時氣候集解四巻<sub class="note-yuan">江西廵撫採進本</sub>  
<span style="margin-left: 2em">明李泰撰泰字淑通鹿邑人洪武丁丑進士姚福</span>  
<span style="margin-left: 2em">靑溪漫筆稱其官爲詹事府通事舍人其事迹則</span>  
<span style="margin-left: 2em">無考也是書成於洪熙元年大㫖以月令諸書紀</span>  
<span style="margin-left: 2em">載時物僅得其大畧前人訓釋又互有異同因蒐</span>  
<!-- 册2 葉1789b　Page:文淵閣四庫全書_0002冊.djvu/452 -->
<span style="margin-left: 2em">采羣籍以爲考證然篇幅太隘未能詳覈</span>  
月令通考十六巻<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明盧翰撰翰有易經中說巳著錄此書以一歲十</span>  
<span style="margin-left: 2em">二月毎月雜採故事兼及流俗舊聞首記天道次</span>  
<span style="margin-left: 2em">治法次地利次民用次攝生次涓吉次占候次跡</span>  
<span style="margin-left: 2em">往次考言次擴聞謂之十例頗爲龎雜其自序云</span>  
<span style="margin-left: 2em">因見家塾事親一書而廣之爲此則託始已爲俗</span>  
<span style="margin-left: 2em">學其不能精核宜矣</span>  
月令廣義二十五巻<sub class="note-yuan"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">𨽻總督採進本</sub>  
<!-- 册2 葉1792a　Page:文淵閣四庫全書_0002冊.djvu/453 -->
<span style="margin-left: 2em">明馮應京撰戴任續成之應京有六家詩名物疏</span>  
<span style="margin-left: 2em">巳著錄任始末未詳惟巻端有二私印一曰肩吾</span>  
<span style="margin-left: 2em">父一曰新安布衣而巳是書前有任叙由一篇稱</span>  
<span style="margin-left: 2em">應京初爲士民月令一巻凡十有二令今益以閏</span>  
<span style="margin-left: 2em">月而增五紀篇冠以圖綂之以歲總約十二月文</span>  
<span style="margin-left: 2em">義之同者括爲毎月令領於春令之前復槩毎月</span>  
<span style="margin-left: 2em">三十日所同者立晝夜令而一十二時區爲時令</span>  
<span style="margin-left: 2em">系諸篇終共爲巻二十有五則應京原書祇一巻</span>  
<span style="margin-left: 2em">此本皆任所增加而巻首馮霑紀畧乃稱應京在</span>  
<!-- 册2 葉1792b　Page:文淵閣四庫全書_0002冊.djvu/453 -->
<span style="margin-left: 2em">鎭撫司作此書二十四巻應京自序又稱任僅增</span>  
<span style="margin-left: 2em">三之二大抵二人先後成之而彼此均欲據以爲</span>  
<span style="margin-left: 2em">功故其說矛盾也其書較盧氏月令通考差詳備</span>  
<span style="margin-left: 2em">而亦多猥雜</span>  
節宣輯四巻<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明上洛王朝瞌撰朝瞌周定王橚七世孫成化三</span>  
<span style="margin-left: 2em">年橚曾孫同䤪始分封上洛萬厯三十二年朝瞌</span>  
<span style="margin-left: 2em">襲封其書專記時令多襲舊文</span>  
養餘月令二十九巻<sub class="note-yuan">浙江廵撫採進本</sub>  
<!-- 册2 葉1793a　Page:文淵閣四庫全書_0002冊.djvu/453 -->
<span style="margin-left: 2em">明戴羲撰羲字馭長里貫未詳崇禎中官光祿寺</span>  
<span style="margin-left: 2em">典簿其書分紀歲序而附以蠶魚竹牡丹芍藥蘭</span>  
<span style="margin-left: 2em">菊諸譜鈔撮舊籍無所發明</span>  
日渉編十二巻<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明陳堦撰堦字升也應城人是書雜采故實詩歌</span>  
<span style="margin-left: 2em">按時令編次毎一月爲一巻先叙月令節𠉀而三</span>  
<span style="margin-left: 2em">十日以次列之皆以故實居前詩歌居後所采頗</span>  
<span style="margin-left: 2em">爲蕪雜前有康熙二十七年鞏昌知府文安紀元</span>  
<span style="margin-left: 2em">重刋序乃惜其列代事跡有闗勸戒者尙未詳錄</span>  
<!-- 册2 葉1793b　Page:文淵閣四庫全書_0002冊.djvu/453 -->
<span style="margin-left: 2em">非也至謂其不載閏月爲疎漏則所言當矣</span>  
廣月令三巻後集二巻<sub class="note-yuan">安徽廵撫採進本</sub>  
<span style="margin-left: 2em">明王勲撰後集則其子璞所補勲字曰放璞字伯</span>  
<span style="margin-left: 2em">懷黟縣人其書採掇傳記欲爲月令通考諸家廣</span>  
<span style="margin-left: 2em">所未備而好取新竒轉成淺陋如十二月云大茅</span>  
<span style="margin-left: 2em">君降白鶴吐火烘客老子降九十六種魔皆道家</span>  
<span style="margin-left: 2em">無稽之談尤爲荒誕其標目曰别有天曰有本如</span>  
<span style="margin-left: 2em">是曰山外山曰衆香國逸史皆佻纎尖巧亦不出</span>  
<span style="margin-left: 2em">明季小品習徑也</span>  
<!-- 册2 葉1796a　Page:文淵閣四庫全書_0002冊.djvu/454 -->
古今類傳歲時部四巻<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 1em">國朝董榖士董炳文同編榖士字農山炳文字霞山</span>  
<span style="margin-left: 2em">烏程人是書前有潘耒序稱其兄弟共撰類書分</span>  
<span style="margin-left: 2em">天地人物爲四部名曰古今類傳先以歲時日次</span>  
<span style="margin-left: 2em">一編見示乃天部中之一種然則未成之書也其</span>  
<span style="margin-left: 2em">例首爲歲序總類次爲春夏秋冬四時類毎於一</span>  
<span style="margin-left: 2em">時一月又先爲總類後以一月分三十日各纂輯</span>  
<span style="margin-left: 2em">典故詩文畧注所出而以通用麗句附諸簡末其</span>  
<span style="margin-left: 2em">所出則咸不注焉蒐採頗爲繁富然𨽻事在其意</span>  
<!-- 册2 葉1796b　Page:文淵閣四庫全書_0002冊.djvu/454 -->
<span style="margin-left: 2em">義不在其字句是書所摭徃徃乖其本㫖如王羲</span>  
<span style="margin-left: 2em">之春蚓秋蛇本論書法乃以春秋二字入之歲序</span>  
<span style="margin-left: 2em">類中是豈得古人之意哉</span>  
節序同風錄<sub class="note-yuan">無巻數　衍聖公孔昭煥家藏本</sub>  
<span style="margin-left: 1em">國朝孔尙任撰尙任有人瑞錄巳著錄是書仿荆楚</span>  
<span style="margin-left: 2em">歲時記爲之以十二月爲綱而以佳辰令節分列</span>  
<span style="margin-left: 2em">爲目各載其風俗事宜於下頗爲詳備然人事今</span>  
<span style="margin-left: 2em">古不同方隅各異尙任不分其時其地比而同之</span>  
<span style="margin-left: 2em">又不著其所出未免失之淆雜不足以爲典據也</span>  
<!-- 册2 葉1797a　Page:文淵閣四庫全書_0002冊.djvu/454 -->
時令彚紀十六巻餘日事文四巻<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 1em">國朝朱濓編濓爵里未詳是編所采皆四時十二月</span>  
<span style="margin-left: 2em">事實詩賦全用藝文類聚之體復以是書但分節</span>  
<span style="margin-left: 2em">候而無日次故更作餘日事文四巻毎月三十日</span>  
<span style="margin-left: 2em">皆摭拾事實詩賦以補之然所引神仙降誕飛昇</span>  
<span style="margin-left: 2em">之期旣爲荒誕又多以古人行記如范成大吳船</span>  
<span style="margin-left: 2em">錄之類所載毎日至某處者取爲其日之故實尤</span>  
<span style="margin-left: 2em">爲假借也</span>  
<span style="margin-left: 1em">右時令類十一部一百二十巻<sub class="note-yuan">内一部無巻數</sub>皆附存目</span>
