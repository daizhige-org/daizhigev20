<span style="margin-left: 1em">集部八</span>

樂圃餘藁十卷附録一卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">宋朱長文撰長文有吳郡圖經續記巳著錄長文</span>  
<span style="margin-left: 2em">著述甚富所撰詩詞賦辨表章雜說凡一百卷以</span>  
<span style="margin-left: 2em">所居名樂圃故名之曰樂圃集南渡以後盡燬於</span>  
<span style="margin-left: 2em">兵其從孫知漢陽軍思裒集遺文得詩百六十有</span>  
<span style="margin-left: 2em">三記五序六啟七墓誌五雜文六重爲編次類爲</span>  
<!-- 册4 葉633b　Page:文淵閣四庫全書_0004冊.djvu/163 -->
<span style="margin-left: 2em">十卷又以墓銘表傳爲附錄一卷鋟本以傳以非</span>  
<span style="margin-left: 2em">樂圃集之全本故名之曰餘藁歲久板佚藏書家</span>  
<span style="margin-left: 2em">遞相傳錄惟寫本僅存康熙壬辰其裔孫岳壽卽</span>  
<span style="margin-left: 2em">舊本重刋復行於世外附補遺詩一首贊一首則</span>  
<span style="margin-left: 2em">明嘉定陸嘉頴所掇拾增入也稿中墓銘皆署其</span>  
<span style="margin-left: 2em">父公綽名蓋長文少時代其父作思從石刻錄出</span>  
<span style="margin-left: 2em">亦可見當時搜討之勤矣葉夢得避署錄話曰元</span>  
<span style="margin-left: 2em">豐間淮浙士人以疾不仕因以行義聞於鄉里者</span>  
<span style="margin-left: 2em">二人楚州徐積仲車蘇州朱長文伯原則長文在</span>  
<!-- 册4 葉636a　Page:文淵閣四庫全書_0004冊.djvu/164 -->
<span style="margin-left: 2em">南北宋間與徐積齊名然積之學問主精研事理</span>  
<span style="margin-left: 2em">長文之學問主博考古今積之文章多怪偉駭俗</span>  
<span style="margin-left: 2em">長文之文章多平易近人其所造則各有不同云</span>  
龍雲集三十二卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">宋劉弇撰弇字偉明安福人元豐二年進士復中</span>  
<span style="margin-left: 2em">博學宏詞科初知峩眉縣改博士元符改元進南</span>  
<span style="margin-left: 2em">郊大禮賦除祕書省正字厯實錄院檢討事迹具</span>  
<span style="margin-left: 2em">宋史本傳是集名曰龍雲者書錄解題謂龍雲安</span>  
<span style="margin-left: 2em">福鄉名弇所居也其文不名一格大都氣體宏整</span>  
<!-- 册4 葉636b　Page:文淵閣四庫全書_0004冊.djvu/164 -->
<span style="margin-left: 2em">詞致敷腴周必大作是集序謂其醺經飫史吞吐</span>  
<span style="margin-left: 2em">百氏爲足繼歐陽修之後而上接韓文則推許未</span>  
<span style="margin-left: 2em">免溢分宋史本傳稱其文剷削瑕纇卓詭不凡庶</span>  
<span style="margin-left: 2em">幾乎近其實矣詩雖才地稍弱要亦峭拔不俗異</span>  
<span style="margin-left: 2em">於庸音之足曲也其集初刋於浦城僅二十五卷</span>  
<span style="margin-left: 2em">紹興四年其鄉人羅良弼搜求別本益以彭德源</span>  
<span style="margin-left: 2em">曾如晦等所編又得宏詞時議諸篇於郭明叔家</span>  
<span style="margin-left: 2em">總六百三十一首釐爲三十二卷後附誌銘及良</span>  
<span style="margin-left: 2em">弼跋歲久板佚明宏治中劉璋復序而重刋吳之</span>  
<!-- 册4 葉637a　Page:文淵閣四庫全書_0004冊.djvu/164 -->
<span style="margin-left: 2em">振撰宋詩鈔不及弇集曹庭楝撰宋詩存始補收</span>  
<span style="margin-left: 2em">之蓋傳本較稀故之振偶未見云</span>  
雲溪居士集三十卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋華鎭撰鎭字安仁會稽人元豐二年進士官至</span>  
<span style="margin-left: 2em">朝奉大夫知漳州軍事鎭原集本一百卷又有揚</span>  
<span style="margin-left: 2em">子法言訓解十卷書說三卷會稽覽古詩一百三</span>  
<span style="margin-left: 2em">篇長短句一卷會稽錄一卷并附哀文一卷通一</span>  
<span style="margin-left: 2em">百十七卷紹興十三年其子初成裒集刋刻曾表</span>  
<span style="margin-left: 2em">進於朝又鎭上蔡樞密書自云有所作王制解一</span>  
<!-- 册4 葉637b　Page:文淵閣四庫全書_0004冊.djvu/164 -->
<span style="margin-left: 2em">編而初成所爲狀跋則不載是書蓋當時巳散佚</span>  
<span style="margin-left: 2em">矣其集諸家書目皆不著錄寶慶會稽續志但稱</span>  
<span style="margin-left: 2em">鎭好學博古嘗著會稽覽古詩一百三篇不及其</span>  
<span style="margin-left: 2em">集惟焦竑經籍志載雲溪居士集一百卷而其他</span>  
<span style="margin-left: 2em">著作亦均未載近錢塘厲鶚編宋詩紀事僅從地</span>  
<span style="margin-left: 2em">志之中抄得會稽覽古詩九首知自明以來是集</span>  
<span style="margin-left: 2em">無傳本也兹於永樂大典中掇緝詮次釐爲三十</span>  
<span style="margin-left: 2em">卷雖未能頓還舊觀然原刻卷數巳得三之一矣</span>  
<span style="margin-left: 2em">樓炤序其集曰精深典贍遒麗逸發又曰介然自</span>  
<!-- 册4 葉640a　Page:文淵閣四庫全書_0004冊.djvu/165 -->
<span style="margin-left: 2em">重不輕以求人之知其名之不昭也固宜然觀其</span>  
<span style="margin-left: 2em">學術大扺以王安石爲宗且與蔡京章惇輩贈答</span>  
<span style="margin-left: 2em">往來干祈甚至炤之所云未必遽爲公論特幸不</span>  
<span style="margin-left: 2em">爲京輩所汲引故尙未麗名姦黨身敗名裂耳至</span>  
<span style="margin-left: 2em">其所爲詩文則才氣豐蔚詞條惕達雖不足與歐</span>  
<span style="margin-left: 2em">曾蘇黃比絜長短而在元豐元祐之際亦裒然自</span>  
<span style="margin-left: 2em">成一家置其人品取其文章可矣</span>  
演山集六十卷<sub class="note-yuan">編修汪如藻家藏本</sub>  
<span style="margin-left: 2em">宋黃裳撰裳字冕仲南平人元豐五年進士第一</span>  
<!-- 册4 葉640b　Page:文淵閣四庫全書_0004冊.djvu/165 -->
<span style="margin-left: 2em">累官禮部尙書宋史列傳別有一黃裳普城人乾</span>  
<span style="margin-left: 2em">道五年進士光宗時官至顯謨閣待制名姓偶同</span>  
<span style="margin-left: 2em">非一人也其集見於陳振孫書錄解題者六十卷</span>  
<span style="margin-left: 2em">今此本卷目相符蓋猶宋時原本國史經籍志作</span>  
<span style="margin-left: 2em">黃裳兼山集四十卷書名卷數俱不合蓋焦竑傳</span>  
<span style="margin-left: 2em">錄之誤耳裳宋史無傳其行事不甚可考福建通</span>  
<span style="margin-left: 2em">志稱政和宣和間三舍法行裳上書謂宜近不宜</span>  
<span style="margin-left: 2em">遠宜少不宜老宜富不宜貧不如遵祖宗科舉之</span>  
<span style="margin-left: 2em">制人以爲<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">論要亦伉直有守之士故其詩文俱</span>  
<!-- 册4 葉641a　Page:文淵閣四庫全書_0004冊.djvu/165 -->
<span style="margin-left: 2em">骨力堅勁不爲委靡之音同時莊念祖述方外志</span>  
<span style="margin-left: 2em">乃謂裳爲紫薇天官九眞人之一因誤校籍墮人</span>  
<span style="margin-left: 2em">間云云說殊誕妄蓋以裳素喜道家元祕之書又</span>  
<span style="margin-left: 2em">自稱紫元翁往往愛作塵外語故從而附會之耳</span>  
<span style="margin-left: 2em">兹編爲乾道初其季子玠裒輯建昌軍教授廖挺</span>  
<span style="margin-left: 2em">訂其舛誤刻於軍學前有王說序亦稱其淵源六</span>  
<span style="margin-left: 2em">經議論悉出於正云</span>  
姑溪居士前集五十卷後集二十卷<sub class="note-yuan">編修汪如藻家藏夲</sub>  
<span style="margin-left: 2em">宋李之儀撰之儀字端叔宋史稱滄州無棣人而</span>  
<!-- 册4 葉641b　Page:文淵閣四庫全書_0004冊.djvu/165 -->
<span style="margin-left: 2em">吳芾作前集序乃曰景城人考元豐九域志熙寧</span>  
<span style="margin-left: 2em">六年省景城入樂壽則當爲樂壽人史殆因滄州</span>  
<span style="margin-left: 2em">景城郡橫海軍節度治平九年嘗由淸池徒治無</span>  
<span style="margin-left: 2em">棣遂誤以景城卽無棣也陳氏書錄解題據所題</span>  
<span style="margin-left: 2em">郡望稱爲趙郡人益失之矣之儀元豐中舉進士</span>  
<span style="margin-left: 2em">元祐初爲樞密院編修官通判原州元符中監内</span>  
<span style="margin-left: 2em">香藥庫以嘗從蘇軾幕府爲御史石豫劾罷崇寧</span>  
<span style="margin-left: 2em">初提舉河東常平坐草范純仁遺表過於鯁直忤</span>  
<span style="margin-left: 2em">蔡京意編管太平是編前集五十卷爲乾道丁亥</span>

<span style="margin-left: 2em">吳芾所輯併爲之序姑溪居士之儀南遷後自號</span>  
<span style="margin-left: 2em">因以名其集也後集二十卷不知誰編然文獻通</span>  
<span style="margin-left: 2em">考巳著錄則亦出宋人手矣之儀在元祐熙寧間</span>  
<span style="margin-left: 2em">文章與張耒秦觀相上下王明淸揮塵後錄稱其</span>  
<span style="margin-left: 2em">尺牘最工然他作亦皆神鋒俊逸往往具蘇軾之</span>  
<span style="margin-left: 2em">一體蓋氣類漸染與之化也其詩名稍不及黃陳</span>  
<span style="margin-left: 2em">論者因蘇軾題其詩後有暫借好詩消永夜每逢</span>  
<span style="margin-left: 2em">佳處輒參禪句遂以爲諷其過於僻澁今觀集中</span>  
<span style="margin-left: 2em">諸詩雖魄力雄厚不足敵軾然大抵軒豁磊落實</span>

<span style="margin-left: 2em">無郊島鉤棘艱苦之狀註家所論附會其詞非軾</span>  
<span style="margin-left: 2em">本意矣</span>  
潏水集十六卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋李復撰復字履中先世家開封祥符以其父官</span>  
<span style="margin-left: 2em">關右遂爲長安人登元豐二年進士厯官熙河轉</span>  
<span style="margin-left: 2em">運使終於中大夫集賢殿修撰其事迹不見於宋</span>  
<span style="margin-left: 2em">史洪邁容齋隨筆載其於蔡京刑恕謀用戰車戰</span>  
<span style="margin-left: 2em">艦一事上疏排詆甚爲切直而恨史傳之不能詳</span>  
<span style="margin-left: 2em">盡朱子語錄亦曰閩人李復<sub class="note-yuan">案復非閩人此句或傳寫之誤</sub>及識</span>  
<!-- 册4 葉645a　Page:文淵閣四庫全書_0004冊.djvu/166 -->
<span style="margin-left: 2em">橫渠先生紹聖間爲西邊使者博記能文今信州</span>  
<span style="margin-left: 2em">有潏水集者卽其文也其間有論孟子養氣謂動</span>  
<span style="margin-left: 2em">必由理故仰不愧於天俯不怍於人無憂無懼其</span>  
<span style="margin-left: 2em">氣豈不充乎舍是則明有人非幽有<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">責自歉於</span>  
<span style="margin-left: 2em">中氣爲之喪矣此語雖疎却得其大旨近世諸儒</span>  
<span style="margin-left: 2em">之論多似過高流於老莊而不知不若此說之爲</span>  
<span style="margin-left: 2em">得也今觀是集如謂揚雄不知道謂井田兵制不</span>  
<span style="margin-left: 2em">可遽言復古皆<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">然中理其他持論亦皆醇正不</span>  
<span style="margin-left: 2em">止朱子所稱一條又久居兵間嫻習戎事故所上</span>  
<!-- 册4 葉645b　Page:文淵閣四庫全書_0004冊.djvu/166 -->
<span style="margin-left: 2em">奏議大都侃侃建白深中時弊亦不止洪邁所稱</span>  
<span style="margin-left: 2em">二疏至其考證今古貫穿博洽於易𧰼算術五行</span>  
<span style="margin-left: 2em">律吕之學無不剖晰精微具有本末尤非空談者</span>  
<span style="margin-left: 2em">所可及在宋儒之中可謂有體有用者矣集本四</span>  
<span style="margin-left: 2em">十卷乾道間嘗刻於饒郡卽朱子所謂信州本也</span>  
<span style="margin-left: 2em">後散佚無存談宋文者多不能舉其名氏今從永</span>

<span style="margin-left: 2em">發潛德之光且以補史傳之闕畧焉</span>  
道鄉集四十卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<!-- 册4 葉648a　Page:文淵閣四庫全書_0004冊.djvu/167 -->
<span style="margin-left: 2em">宋鄒浩撰浩字志完常州晉陵人元豐五年進士</span>  
<span style="margin-left: 2em">官終直龍圖閣贈寶文閣學士諡曰忠事迹具宋</span>  
<span style="margin-left: 2em">史本傳此集乃其子柄栩所輯凡詩十四卷文二</span>
