## 欽定四庫全書總目 卷一百二　子部十二　農家類、農家類存目

<!-- 册3 葉752a　Page:文淵閣四庫全書_0003冊.djvu/193 -->
欽定四庫全書總目巻一百二  
<span style="margin-left: 1em">子部十二</span>  
<span style="margin-left: 2em">農家𩔖</span>  
<span style="margin-left: 3em">農家條目至爲蕪襍諸家著錄大抵輾轉旁牽</span>  
<span style="margin-left: 3em">因耕而及相牛經因相牛經及相馬經相鶴經</span>  
<span style="margin-left: 3em">鷹經蟹錄至於相貝經而香譜錢譜相隨入矣</span>  
<span style="margin-left: 3em">因五穀而及圃史因圃史而及竹譜荔支譜橘</span>  
<span style="margin-left: 3em">譜至於梅譜菊譜而唐昌玉蘂辨證揚州瓊花</span>  
<span style="margin-left: 3em">譜相隨入矣因蠶桑而及茶經因茶經及酒史</span>  
<!-- 册3 葉752b　Page:文淵閣四庫全書_0003冊.djvu/193 -->
<span style="margin-left: 3em">糖霜譜至於疏食譜而易牙遺意飲膳正要相</span>  
<span style="margin-left: 3em">隨入矣觸𩔖蔓延將因四民月令而及算術天</span>  
<span style="margin-left: 3em">文因田家五行而及風角鳥占因救荒本草而</span>  
<span style="margin-left: 3em">及素問靈樞乎今逐𩔖汰除惟存本業用以見</span>  
<span style="margin-left: 3em">重農貴粟其道至大其義至深庶幾不失豳風</span>  
<span style="margin-left: 3em">無逸之初旨茶事一𩔖與農家稍近然龍團鳳</span>  
<span style="margin-left: 3em">餅之製銀匙玉盌之華終非耕織者所事今亦</span>  
<span style="margin-left: 3em">別入譜錄類明不以末先本也</span>  
齊民要術十巻<sub class="note-yuan">浙江巡撫採進本</sub>  
<!-- 册3 葉753a　Page:文淵閣四庫全書_0003冊.djvu/193 -->
<span style="margin-left: 2em">後魏賈思勰撰思勰始末未詳惟知其官爲高平</span>  
<span style="margin-left: 2em">太守而已自序稱起自耕農終於醯醢資生之樂</span>  
<span style="margin-left: 2em">靡不畢書凡九十二篇今本乃終於五穀果蓏非</span>  
<span style="margin-left: 2em">中國物者自序又稱商賈之事闕而不錄今本貨</span>  
<span style="margin-left: 2em">殖一篇乃列於第六十二莫知其義中第三十篇</span>  
<span style="margin-left: 2em">爲襍說而巻端又列襍記數條不入篇數一名再</span>  
<span style="margin-left: 2em">見於例殊乖其詞亦鄙俗不𩔖疑後人所竄入然</span>  
<span style="margin-left: 2em">陳振孫書錄解題稱其治生之道不仕則農爲名</span>  
<span style="margin-left: 2em">言正見於巻端襍說中則宋本已有之矣思勰序</span>  
<!-- 册3 葉753b　Page:文淵閣四庫全書_0003冊.djvu/193 -->
<span style="margin-left: 2em">不言作注亦不云有音今本句下之注有似自作</span>  
<span style="margin-left: 2em">然多引及顔師古者考文獻通考載李燾孫氏齊</span>  
<span style="margin-left: 2em">民要術音義解釋序曰賈思勰著此書專主民事</span>  
<span style="margin-left: 2em">又旁摭異聞多可觀在農家最嶢然出其類奇字</span>  
<span style="margin-left: 2em">錯見往往艱讀今運使秘丞孫公爲之音義解釋</span>  
<span style="margin-left: 2em">畧備其正名小物葢與揚雄郭璞相上下不但借</span>  
<span style="margin-left: 2em">助於思勰也則今本之注葢孫氏之書特宋藝文</span>  
<span style="margin-left: 2em">志不著錄其名不可考耳董穀碧里襍存以注中</span>  
<span style="margin-left: 2em">一石當今二斗七升之文疑其與魏時長安童謡</span>  
<!-- 册3 葉756a　Page:文淵閣四庫全書_0003冊.djvu/194 -->
<span style="margin-left: 2em">百升飛上天句不合<sub class="note-yuan">案斛律光齊人非魏人此語殊誤</sub>葢未知註</span>  
<span style="margin-left: 2em">非思勰作也錢曾讀書敏求記云嘉靖甲申刻齊</span>  
<span style="margin-left: 2em">民要術於湖湘首巻簡端周書曰云云原係細書</span>  
<span style="margin-left: 2em">夾註今刊作大字毛晉津逮秘書亦然今以第二</span>  
<span style="margin-left: 2em">篇至六十篇之例推之其說良是葢唐以前書文</span>  
<span style="margin-left: 2em">詞古奥校勘者不盡能通輾轉訛脫因而訛異固</span>  
<span style="margin-left: 2em">亦事所恒有矣</span>  
農書三巻附蠶書一巻<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">此書影宋抄木題曰陳旉撰宋史藝文志亦同陳</span>  
<!-- 册3 葉756b　Page:文淵閣四庫全書_0003冊.djvu/194 -->
<span style="margin-left: 2em">振孫書錄解題作西山隱居全眞子陳雱撰未詳</span>  
<span style="margin-left: 2em">何人永樂大典所載則作陳敷考漢郊祀歌朱明</span>  
<span style="margin-left: 2em">旉與顔師古注曰旉古敷字永樂大典葢改古文</span>  
<span style="margin-left: 2em">從今文陳氏作雱則字形相似而誤也首有自序</span>  
<span style="margin-left: 2em">佚其前二頁末有洪興祖後序及旉自跋興祖序</span>  
<span style="margin-left: 2em">稱山西陳居士於六經諸子百家之書釋老氏黃</span>  
<span style="margin-left: 2em">帝神農氏之學貫穿出入往往成誦下至術數小</span>  
<span style="margin-left: 2em">道亦精其能平生讀書不求仕進所至卽種藥治</span>  
<span style="margin-left: 2em">圃以自給又稱其紹興己巳年七十四則南北宋</span>  
<!-- 册3 葉757a　Page:文淵閣四庫全書_0003冊.djvu/194 -->
<span style="margin-left: 2em">間處士也自跋稱此書成於紹興十九年眞州雖</span>  
<span style="margin-left: 2em">曾刊行而當時傳者失其眞首尾顚倒意義不貫</span>  
<span style="margin-left: 2em">者甚多又爲或人不曉旨趣妄自刪改徒事絺章</span>  
<span style="margin-left: 2em">繪句而理致乖越故取家藏副本繕寫成帙以待</span>  
<span style="margin-left: 2em">當世之君子採取以獻於上則興祖所刊之本有</span>  
<span style="margin-left: 2em">所<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）">竄旉葢不以爲然其自序又稱此書非騰口</span>  
<span style="margin-left: 2em">空言誇張盗名如齊民要術四時纂要迂疎不適</span>  
<span style="margin-left: 2em">用之比其自命殊高今觀其書上巻泛言農事中</span>  
<span style="margin-left: 2em">巻論養牛下巻論養蠶大抵泛陳大要引經史以</span>  
<!-- 册3 葉757b　Page:文淵閣四庫全書_0003冊.djvu/194 -->
<span style="margin-left: 2em">證明之虛論多而實事少殊不及齊民要術之典</span>  
<span style="margin-left: 2em">核詳明遽詆前人殊不自量然所言亦頗有入理</span>  
<span style="margin-left: 2em">者宋入舊帙久無刊本姑存備一家可也未有蠶</span>  
<span style="margin-left: 2em">書一巻宋秦湛撰湛字處度高郵人秦觀之子所</span>  
<span style="margin-left: 2em">言蠶事頗詳宋志與旉書各著錄不知何人綴旉</span>  
<span style="margin-left: 2em">書後合爲一編其說與旉書下篇可以互相補苴</span>  
<span style="margin-left: 2em">今亦仍並錄之焉</span>  
農桑輯要七巻<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">元世祖時官撰頒行本也前有至元十年翰林學</span>  
<!-- 册3 葉760a　Page:文淵閣四庫全書_0003冊.djvu/195 -->
<span style="margin-left: 2em">士王磐序稱詔立大司農司不治他事專以勸課</span>  
<span style="margin-left: 2em">農桑爲務行之五六年功效大著農司諸公又慮</span>  
<span style="margin-left: 2em">夫播植之宜蠶繰之節未得其術於是徧求古今</span>  
<span style="margin-left: 2em">農家之書刪其繁重摭其切要纂成一書鏤爲板</span>  
<span style="margin-left: 2em">本進呈將以頒布天下云云案元史司農司設於</span>  
<span style="margin-left: 2em">至元七年分布勸農官巡行郡邑察舉農事成否</span>  
<span style="margin-left: 2em">達於戸部以殿最牧民長官史又稱世祖卽位之</span>  
<span style="margin-left: 2em">初首詔天下崇本抑末於是頒農桑輯要之書於</span>  
<span style="margin-left: 2em">民均與王磐所言合惟至元七年至十年不足五</span>  
<!-- 册3 葉760b　Page:文淵閣四庫全書_0003冊.djvu/195 -->
<span style="margin-left: 2em">六年之數磐葢據建議設官之始約略言之耳焦</span>  
<span style="margin-left: 2em">竑國史經籍志錢曾讀書敏求記皆作七巻永樂</span>  
<span style="margin-left: 2em">大典所載僅有二巻葢編纂者所合併非有闕佚</span>  
<span style="margin-left: 2em">永樂大典又載有至順三年印行萬部官牒蘇天</span>  
<span style="margin-left: 2em">爵元文類又載有蔡文淵序一篇稱延祐元年仁</span>  
<span style="margin-left: 2em">宗特命刊板於江浙行省明宗文宗復申命頒布</span>  
<span style="margin-left: 2em">葢有元一代以是書爲經國要務也書凡分典訓</span>  
<span style="margin-left: 2em">耕墾播種栽桑養蠶𤓰菜果實竹木藥草孶畜十</span>  
<span style="margin-left: 2em">門大致以齊民要術爲藍木芟除其浮文𤨏事而</span>  
<!-- 册3 葉761a　Page:文淵閣四庫全書_0003冊.djvu/195 -->
<span style="margin-left: 2em">襍採他書以附益之詳而不蕪簡而有要於農家</span>  
<span style="margin-left: 2em">之中最爲善本當時著爲功令亦非漫然矣</span>  
農桑衣食撮要二巻<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">元魯明善撰明善元史無傳其始末未詳此本有</span>  
<span style="margin-left: 2em">其幕僚導江張㮚序一篇稱明善威烏爾人<sub class="note-yuan">舊作畏吾</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">兒今依元國語解改正</sub>以父字魯爲氏名鐵柱以字行於延</span>  
<span style="margin-left: 2em">祐甲寅出監壽郡始撰是書且鋟諸梓又有明善</span>  
<span style="margin-left: 2em">自序則稱明憲紀之任取所藏農桑撮要刊之學</span>  
<span style="margin-left: 2em">官末署至順元年六月葢自壽陽刊板之後閱十</span>  
<!-- 册3 葉761b　Page:文淵閣四庫全書_0003冊.djvu/195 -->
<span style="margin-left: 2em">有七年而重付剞劂者也考豳風所紀皆陳物候</span>  
<span style="margin-left: 2em">夏小正所記亦多切田功古來四民月令四時纂</span>  
<span style="margin-left: 2em">要諸書葢其遺意而今多不傳至元中頒行農桑</span>  
<span style="margin-left: 2em">輯要於耕種樹畜之法言之頗詳而嵗用襍事僅</span>  
<span style="margin-left: 2em">列爲巻末一篇未爲賅備明善此書分十二月令</span>  
<span style="margin-left: 2em">件繫條別簡明易曉使種藝歛藏之節開巻了然</span>  
<span style="margin-left: 2em">葢以陰補農桑輯要所未備亦可謂留心民事講</span>  
<span style="margin-left: 2em">求實用者矣</span>  
農書二十二巻<sub class="note-yuan">永樂大典本</sub>  
<!-- 册3 葉764a　Page:文淵閣四庫全書_0003冊.djvu/196 -->
<span style="margin-left: 2em">元王禎撰禎字伯善東平人官豐城縣尹文淵閣</span>  
<span style="margin-left: 2em">書目曰王禎農書一部十冊讀書敏求記曰農桑</span>  
<span style="margin-left: 2em">通訣六穀譜四農器圖譜十二總名曰農書永樂</span>  
<span style="margin-left: 2em">大典所載併爲八巻割裂綴合已非其舊今依原</span>  
<span style="margin-left: 2em">序條目以𩔖區分編爲二十二巻其書典贍而有</span>  
<span style="margin-left: 2em">法葢賈思勰齊民要術之流圖譜中所載水器尤</span>  
<span style="margin-left: 2em">於實用有禆又每圖之末必系以銘贊詩賦亦風</span>  
<span style="margin-left: 2em">雅可誦今外間所有王禎農務集卽從是書摘抄</span>  
<span style="margin-left: 2em">者也唐中和節所進農書世無傳本宋人農書惟</span>  
<!-- 册3 葉764b　Page:文淵閣四庫全書_0003冊.djvu/196 -->
<span style="margin-left: 2em">陳旉所作存元人農書存於今者三本農桑輯要</span>  
<span style="margin-left: 2em">農桑衣食撮要二書一辨物產一明時令皆取其</span>  
<span style="margin-left: 2em">通俗易行惟禎此書引據賅洽文章爾雅繪畫亦</span>  
<span style="margin-left: 2em">皆工緻可謂華實兼資明人刊本舛訛漏落疑誤</span>  
<span style="margin-left: 2em">宏多諸圖尤失其眞永樂大典所載猶元時舊本</span>  
<span style="margin-left: 2em">今據以繕寫校勘以還其舊觀焉</span>  
救荒本草二巻<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明周王橚撰橚太祖第五子洪武十一年封十四</span>  
<span style="margin-left: 2em">年就藩開封建文中廢徒雲南永樂初復爵洪熙</span>  
<!-- 册3 葉765a　Page:文淵閣四庫全書_0003冊.djvu/196 -->
<span style="margin-left: 2em">元年薨諡曰定明史本傳稱橚好學能詞賦以國</span>  
<span style="margin-left: 2em">土夷曠庶草蕃廡考核其可佐饑饉者四百餘種</span>  
<span style="margin-left: 2em">繪圖上之卽此書也李時珍本草綱目以此書及</span>  
<span style="margin-left: 2em">普濟方俱云洪武初周憲王著考憲王有燉於仁</span>  
<span style="margin-left: 2em">宗初始嗣封其說殊誤是編爲嘉靖乙卯陸東所</span>  
<span style="margin-left: 2em">重刊每巻又分爲前後共成四巻其見諸舊本草</span>  
<span style="margin-left: 2em">者一百三十八種新增者二百七十六種皆詳核</span>  
<span style="margin-left: 2em">可據前有東序亦稱周憲王著葢當時以親藩貴</span>  
<span style="margin-left: 2em">重刊書皆不題名故輾轉傳訛有所不免今特爲</span>  
<!-- 册3 葉765b　Page:文淵閣四庫全書_0003冊.djvu/196 -->
