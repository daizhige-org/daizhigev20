欽定四庫全書總目卷九十七  
<span style="margin-left: 1em">子部七</span>  
<span style="margin-left: 2em">儒家𩔖存目三</span>  
藤陰劄記<sub class="note-yuan">無巻數　副都御史黃登賢家藏本</sub>  
<span style="margin-left: 1em">國朝孫承澤撰承澤有尚書集解已著錄是編乃其</span>  
<span style="margin-left: 2em">講學之語共一百餘條大抵以程朱爲宗而深詆</span>  
<span style="margin-left: 2em">金谿姚江亦頗涉及史事其論元許衡劉因一條</span>  
<span style="margin-left: 2em">謂衡不對世祖伐宋之問爲是而以因作渡江賦</span>  
<span style="margin-left: 2em">有我有名而衆彼無義而小留我奉使讐我大<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3771.svg?width=24" alt="四庫全書僻字第3771號（邦）" title="四庫全書僻字第3771號（邦）"></span>  
<!-- 册3 葉477b　Page:文淵閣四庫全書_0003冊.djvu/124 -->
<span style="margin-left: 2em">云云過於尊元抑宋爲非不知二人生長北方由</span>  
<span style="margin-left: 2em">金入元自其高曾祖父皆非宋之臣子乃於一百</span>  
<span style="margin-left: 2em">餘年之後使背其踐土食毛之國而遥尊邈不相</span>  
<span style="margin-left: 2em">關之南宋是率天下而爲逆也可謂紕繆之至矣</span>  
學約續編十四卷<sub class="note-yuan">直隸總督採進本</sub>  
<span style="margin-left: 1em">國朝孫承澤編初承澤嘗輯周程張朱之言爲學約</span>  
<span style="margin-left: 2em">一編是編又以明薛瑄胡居仁羅欽順高攀龍四</span>  
<span style="margin-left: 2em">家之語倣近思錄之例訂爲一集以續之前有自</span>  
<span style="margin-left: 2em">記稱學約於二程同時不入堯夫考亭同時不入</span>  
<!-- 册3 葉480a　Page:文淵閣四庫全書_0003冊.djvu/125 -->
<span style="margin-left: 2em">南軒東萊故兹編亦不入月川楓山後渠涇野念</span>  
<span style="margin-left: 2em">菴涇陽少墟諸家云</span>  
考正晚年定論二卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 1em">國朝孫承澤撰是書以王守仁所作朱子晩年定論</span>  
<span style="margin-left: 2em">不言晚年始於何年但取偶然謙抑之詞或隨問</span>  
<span style="margin-left: 2em">而答之語及早年與人之筆錄之特欲借朱子之</span>  
<span style="margin-left: 2em">言以攻朱子不足爲據乃取朱子年譜行狀文集</span>  
<span style="margin-left: 2em">語𩔖等語詳爲考正以宋孝宗淳熙甲午爲始朱</span>  
<span style="margin-left: 2em">子是時年四十有五其後乃始與陸九淵兄弟相</span>  
<!-- 册3 葉480b　Page:文淵閣四庫全書_0003冊.djvu/125 -->
<span style="margin-left: 2em">會以次逐年編輯實無一言合於陸氏亦無一字</span>  
<span style="margin-left: 2em">涉於自悔因逐條辨駁輯爲是編考晚年定論初</span>  
<span style="margin-left: 2em">出之時羅洪先致書守仁所辨何叔京黃眞<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">二</span>  
<span style="margin-left: 2em">書已極爲明晰是書特申而明之大旨固不出羅</span>  
<span style="margin-left: 2em">書之外至謂守仁立身居家並無實學惟事智術</span>  
<span style="margin-left: 2em">籠𦋐乃吾道之莽懿又取明世宗時請奪守仁封</span>  
<span style="margin-left: 2em">爵會勘疏及不准䘏典之詔以爲口實則摭拾他</span>  
<span style="margin-left: 2em">事以快報復之私尤門戸之見矣</span>  
明辨錄二卷<sub class="note-yuan">副都御史黃登賢家藏本</sub>  
<!-- 册3 葉481a　Page:文淵閣四庫全書_0003冊.djvu/125 -->
<span style="margin-left: 1em">國朝孫承澤撰是書取諸儒闢佛之言彚載成帙上</span>  
<span style="margin-left: 2em">卷首載昌黎原道及佛骨表而傅奕疏及太宗斥</span>  
<span style="margin-left: 2em">蕭瑀詔轉列於後其餘辨論陸九淵楊簡王守仁</span>  
<span style="margin-left: 2em">之說者亦備記之下册則皆諸儒語錄辨駁佛氏</span>  
<span style="margin-left: 2em">之學者</span>  
紫陽通志錄四卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 1em">國朝高世泰編世泰有五朝三楚文獻錄已著錄是</span>  
<span style="margin-left: 2em">編本徽州汪知黙等輯其紫陽書院講會之語名</span>  
<span style="margin-left: 2em">曰理學歸一寄示世泰適孫承澤以學約續編魏</span>  
<!-- 册3 葉481b　Page:文淵閣四庫全書_0003冊.djvu/125 -->
<span style="margin-left: 2em">裔介以知統翼錄先後寄至世泰因合刁包潛室</span>  
<span style="margin-left: 2em">劄記陳揆省心日記諸條并梓行之其曰通志者</span>  
<span style="margin-left: 2em">葢謂通彼此應求之志以明爲學之出於一源卷</span>  
<span style="margin-left: 2em">末自附格致講學講各一篇又有講畢送難之語</span>  
<span style="margin-left: 2em">頗涉禪宗窠臼葢猶沿明季書院之餘習也</span>  
聖學入門書<sub class="note-yuan">無卷數　江西巡撫採進本</sub>  
<span style="margin-left: 1em">國朝陳瑚撰瑚字言夏號確菴太倉人前明崇禎壬</span>  
<span style="margin-left: 2em">午舉人是書分大學日程小學日程二種大學日</span>  
<span style="margin-left: 2em">程曰格致之學誠意之學正心之學修身之學齊</span>  
<!-- 册3 葉484a　Page:文淵閣四庫全書_0003冊.djvu/126 -->
<span style="margin-left: 2em">家之學治平之學於八條目之中復分條目各爲</span>  
<span style="margin-left: 2em">疏解小學曰程曰入孝之學出弟之學謹行之學</span>  
<span style="margin-left: 2em">信言之學親愛之學文藝之學其條目較之大學</span>  
<span style="margin-left: 2em">爲簡其用功之要曰日省敬怠日省善過末附日</span>  
<span style="margin-left: 2em">程格式於後毎日爲空格以四格記晨起午前午</span>  
<span style="margin-left: 2em">後燈下以二格總記敬怠善過又有半月總結之</span>  
<span style="margin-left: 2em">法葢卽仿袁黃功過格意惟不言果報稍異乎有</span>  
<span style="margin-left: 2em">爲而爲然科條密於秋荼非萬緣俱謝靜坐觀心</span>  
<span style="margin-left: 2em">不能時時刻刻操管繕錄也</span>  
<!-- 册3 葉484b　Page:文淵閣四庫全書_0003冊.djvu/126 -->
學言三卷<sub class="note-yuan">山西巡撫採進本</sub>  
<span style="margin-left: 1em">國朝白允謙撰允謙字子益陽城人前明崇禎癸未</span>  
<span style="margin-left: 2em">進士改庶吉士入</span>  
<span style="margin-left: 1em">國朝授祕書院檢討官至刑部尚書此書皆其講學</span>  
<span style="margin-left: 2em">之語上卷五十九條下卷六十條又續一卷凡八</span>  
<span style="margin-left: 2em">十一條其曰無我之我是謂眞我無知之知是謂</span>  
<span style="margin-left: 2em">良知又曰聖人無内無外仁可智也智可仁也皆</span>  
<span style="margin-left: 2em">語涉惝怳非篤實之學也</span>  
此菴語錄十卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<!-- 册3 葉485a　Page:文淵閣四庫全書_0003冊.djvu/126 -->
<span style="margin-left: 1em">國朝胡統虞撰統虞字孝緖武陵人前明崇禎癸未</span>  
<span style="margin-left: 2em">進士入</span>  
<span style="margin-left: 1em">國朝官至國子監祭酒此書前二卷爲成均語錄乃</span>  
<span style="margin-left: 2em">官祭酒時與諸生講論者附原性或問學規三種</span>  
<span style="margin-left: 2em">三卷至七卷爲四書語錄八卷爲萬壽官語錄末</span>  
<span style="margin-left: 2em">二卷爲此菴語錄以别乎成均萬壽宫也其學禰</span>  
<span style="margin-left: 2em">姚江而祖象山專持良知之說於朱子頗不能盡</span>  
<span style="margin-left: 2em">合如記陸子靜鵞湖講喻義一章滿座爲之揮淚</span>  
<span style="margin-left: 2em">講畢朱晦菴長跪以謝曰熹平生學問實實未嘗</span>  
<!-- 册3 葉485b　Page:文淵閣四庫全書_0003冊.djvu/126 -->
<span style="margin-left: 2em">看到此處其軒輊𩔖多如此亦可謂深於門戸之</span>  
<span style="margin-left: 2em">見者矣</span>  
理學傳心纂要八卷<sub class="note-yuan">湖北巡撫採進本</sub>  
<span style="margin-left: 1em">國朝孫奇逢撰漆士昌補奇逢有讀易大旨已著錄</span>  
<span style="margin-left: 2em">士昌江陵人奇逢之門人也奇達原書錄周子二</span>  
<span style="margin-left: 2em">程子張子邵子朱子陸九淵薛瑄王守仁羅洪先</span>  
<span style="margin-left: 2em">顧憲成十一人以爲直接道統之傳人爲一篇皆</span>  
<span style="margin-left: 2em">前敘其行事而後節錄其遺文凡三卷又取漢董</span>  
<span style="margin-left: 2em">仲舒以下至明末周汝登各略載其言行以爲羽</span>  
<!-- 册3 葉488a　Page:文淵閣四庫全書_0003冊.djvu/127 -->
<span style="margin-left: 2em">翼理學之派凡四卷竒逢殁後士昌復删削其語</span>  
<span style="margin-left: 2em">錄一卷攙列於顧憲成後共爲八卷奇逢行誼不</span>  
<span style="margin-left: 2em">愧古人其講學叅酌朱陸之間有體有用亦有異</span>  
<span style="margin-left: 2em">於迂儒故湯斌慕其爲人至解官以從之遊然道</span>  
<span style="margin-left: 2em">統所歸談何容易奇逢以顧憲成當古今第十一</span>  
<span style="margin-left: 2em">人士昌又以奇逢當古今第十二人醇儒若董仲</span>  
<span style="margin-left: 2em">舒等猶不得肩隨於後其猶東林標榜之餘風乎</span>  
嵗寒居答問二卷附錄一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 1em">國朝孫奇逢撰皆自錄朋友答問之語奇逢之學主</span>  
<!-- 册3 葉488b　Page:文淵閣四庫全書_0003冊.djvu/127 -->
<span style="margin-left: 2em">於明體達用宗旨出於姚江而變以篤實化以和</span>  
<span style="margin-left: 2em">平兼採程朱之旨以彌其闕失故其言有曰門宗</span>  
<span style="margin-left: 2em">分裂使人知反而求之事物之際晦翁之功也然</span>  
<span style="margin-left: 2em">晦翁殁而天下之實病不可不瀉詞章繁興使人</span>  
<span style="margin-left: 2em">知反而求之心性之中陽明之功也然陽明殁而</span>  
<span style="margin-left: 2em">天下之虚病不可不補是其宗旨所在也舊本前</span>  
<span style="margin-left: 2em">有附錄一卷爲奇逢所作格物說及楊東明興學</span>  
<span style="margin-left: 2em">㑹約八條旣曰附錄不應弁首或裝輯時誤置卷</span>  
<span style="margin-left: 2em">端耳</span>  
<!-- 册3 葉489a　Page:文淵閣四庫全書_0003冊.djvu/127 -->
潛室劄記二卷<sub class="note-yuan">直隸總督採進本</sub>  
<span style="margin-left: 1em">國朝刁包撰包有易酌已著錄其書以平日所見隨</span>  
<span style="margin-left: 2em">筆劄記王士禎池北偶談嘗稱其中爲葢世豪傑</span>  
<span style="margin-left: 2em">易爲愜心聖賢難一條又稱其趨吉避凶葢言趨</span>  
<span style="margin-left: 2em">正避邪若認作趨福避禍便誤一條然所言心性</span>  
<span style="margin-left: 2em">及格致誠敬𩔖多拾前人緒餘其謂讀春秋而不</span>  
<span style="margin-left: 2em">知胡傳之妙不可以言春秋亦不出里塾拘墟之</span>  
<span style="margin-left: 2em">見又稱吾輩第一座名山在大學知止一節且謂</span>  
<span style="margin-left: 2em">此山又不在書本上還在腔子裏語殊虚渺尤不</span>  
<!-- 册3 葉489b　Page:文淵閣四庫全書_0003冊.djvu/127 -->
<span style="margin-left: 2em">免墮入姚江門徑矣</span>  
張界軒集八卷<sub class="note-yuan">江西廵撫採進本</sub>  
<span style="margin-left: 1em">國朝張時爲撰時爲字景明餘千人前明福王時貢</span>  
<span style="margin-left: 2em">生是編乃其族孫司直所刻目列十六卷首序傳</span>  
<span style="margin-left: 2em">目錄一卷次爲學約言四卷次讀近思錄紀言一</span>  
<span style="margin-left: 2em">卷次六一寤言一卷次喪禮去非一卷次讀左言</span>  
<span style="margin-left: 2em">一卷次語錄一卷次詩文六卷故總以集名然讀</span>  
<span style="margin-left: 2em">左言語錄詩文皆未刻刻者皆講學之書仍以集</span>  
<span style="margin-left: 2em">名非其實也江右之學大抵以陸氏爲宗時爲生</span>  
<!-- 册3 葉492a　Page:文淵閣四庫全書_0003冊.djvu/128 -->
<span style="margin-left: 2em">胡居仁之鄉乃獨從居仁宗朱子故其言平正篤</span>  
<span style="margin-left: 2em">實者居多然頗有主持太過者如曰六經載道之</span>  
<span style="margin-left: 2em">書非止爲治天下之書是徒知尊崇性命菲薄事</span>  
<span style="margin-left: 2em">功而不知大人之學由格致而治平中庸之理自</span>  
<span style="margin-left: 2em">中和而位育也又謂程子雲淡風輕一詩與陰陽</span>  
<span style="margin-left: 2em">四時相凖四句分配四時之氣一句亦分配四時</span>  
<span style="margin-left: 2em">之氣如雲淡二字是春氣風輕二字是夏氣近午</span>  
<span style="margin-left: 2em">二字是秋氣天字是冬氣恐程子吟詩之時斷無</span>  
<span style="margin-left: 2em">此意卽伶倫製律后䕫典樂周公輯頌亦斷無此</span>  
<!-- 册3 葉492b　Page:文淵閣四庫全書_0003冊.djvu/128 -->
<span style="margin-left: 2em">法也他如擬奏疏於朝請</span>
