<span style="margin-left: 2em">總集𩔖四</span>  
乾坤淸氣集十四卷<sub class="note-yuan">浙江鮑士㳟家藏本</sub>  
<span style="margin-left: 2em">明偶桓編桓字武孟號海翁因眇一目又自號瞎</span>  
<span style="margin-left: 2em">牛太倉人洪武中官荆門州吏目是集錄元一代</span>  
<span style="margin-left: 2em">之詩分體編次其中如汪元量瀛國公元好問等</span>  
<span style="margin-left: 2em">上該金宋之末張以寜危素等亦下渉明初朱<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）"></span>  
<span style="margin-left: 2em">尊靜志居詩話稱明初詩人操選政者賴直良卿</span>

<span style="margin-left: 2em">許中麗仲孚劉仔肩汝弼沈巽士偁王偁孟敭皆</span>  
<span style="margin-left: 2em">有所蔽惟瞎牛乾坤淸氣一編能别開生靣惜余</span>  
<span style="margin-left: 2em">所鈔闕七言近體絶句未得全書恒以爲憾此本</span>  
<span style="margin-left: 2em">稱鈔自孫氏蒼雪齋所缺與<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">尊本同又以厲氏</span>  
<span style="margin-left: 2em">樊榭山房本郁氏東嘯軒本參校頗爲精善雖卷</span>  
<span style="margin-left: 2em">帙無多而去取極爲不苟又編在明初多見舊刻</span>  
<span style="margin-left: 2em">如七言古詩中陳旅泰定元年八月一首張翥周</span>  
<span style="margin-left: 2em">昉按樂圖一首鄭元祐送林彦淸一首將還淮<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3951.svg?width=24" alt="四庫全書僻字第3951號（揚 --（『昜』上『旦』之『日』與『一』相連））" title="四庫全書僻字第3951號（揚 --（『昜』上『旦』之『日』與『一』相連））"></span>  
<span style="margin-left: 2em">一首古樂府中揭徯斯馬上郞車中女二首陳泰</span>  
<!-- 册5 葉256a　Page:文淵閣四庫全書_0005冊.djvu/69 -->
<span style="margin-left: 2em">漢使謡一首薩都拉<sub class="note-yuan">原作薩都刺今改正</sub>秋夜長一首張憲</span>  
<span style="margin-left: 2em">飛來狐一首五言律詩中如馬祖常𭔃邵允文一</span>  
<span style="margin-left: 2em">首南征一首張翥禖臺一首遊石頭城淸凉寺一</span>  
<span style="margin-left: 2em">首楊基夏夜有懐第二首今本集皆佚不載惟賴</span>  
<span style="margin-left: 2em">此集以存又五言律詩中趙孟頫次袁學士上都</span>  
<span style="margin-left: 2em">集韻一首松雪集不載而譚氏所刻趙子昂詩集</span>  
<span style="margin-left: 2em">有之當亦從此本摭入也他如題金淵集詩山村</span>  
<span style="margin-left: 2em">集竹素山房集皆作吾衍此本作屠<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">烏夜啼將</span>  
<span style="margin-left: 2em">進酒趙孝子歌三首玉山草堂雅集作柯九思此</span>

<span style="margin-left: 2em">作雅琥皆足以考異其餘字句互異諸集者不一</span>  
<span style="margin-left: 2em">而足甚如倪瓚春日雲林齋居詩凡六韻六十字</span>  
<span style="margin-left: 2em">而與本集相同者僅十七字桓受知倪瓚最深是</span>  
<span style="margin-left: 2em">必其手授定本爲編雲林集者所未見矣至於甘</span>  
<span style="margin-left: 2em">立烏夜啼一首旣見八卷古樂府又載入一卷中</span>  
<span style="margin-left: 2em">作晩出西掖第二首編次亦未免小疎李孝光題</span>  
<span style="margin-left: 2em">楊鐵厓琴書安樂窩詩艷妻歡娛自令身枯二句</span>  
<span style="margin-left: 2em">誤析令字爲人之二字傳寫亦未免有舛然元詩</span>  
<span style="margin-left: 2em">選本究當以此編爲善也</span>

元音十二卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">不著編輯者名氏前有洪武甲子烏斯道序稱寜</span>  
<span style="margin-left: 2em">波孫原理彚輯又有曾用臧序稱爲定海丞張中</span>  
<span style="margin-left: 2em">達所刻未題辛巳九月下澣而空其年號兩字考</span>  
<span style="margin-left: 2em">辛巳爲建文三年殆以靖難革除剷削其板葢猶</span>  
<span style="margin-left: 2em">明初本也所錄自劉因至龍雲從凡一百七十六</span>  
<span style="margin-left: 2em">人毎人之下畧注字號爵里大抵詳於元末而畧</span>  
<span style="margin-left: 2em">於元初末附無名氏詩十一首又陳益稷詩一首</span>  
<span style="margin-left: 2em">程文海詩四首滕賔詩一首虞集詩五首别題曰</span>  
<!-- 册5 葉257b　Page:文淵閣四庫全書_0005冊.djvu/69 -->
<span style="margin-left: 2em">補遺均爲原目所不載其中無名氏諸篇尤爲淺</span>  
<span style="margin-left: 2em">俗與全書體例稍異或中達刻板之時以意増入</span>  
<span style="margin-left: 2em">歟顧嗣立元百家詩選凡例嘗議宋公傳元詩體</span>  
<span style="margin-left: 2em">要蔣易元風雅及原理是書所收均爲不廣然是</span>  
<span style="margin-left: 2em">書於去取之間頗具持擇雖未能盡汰當時穠縟</span>  
<span style="margin-left: 2em">之習而大致崇尙風格巳有除煩滌濫之功矣</span>  
雅頌正音五卷<sub class="note-yuan">江西廵撫採進本</sub>  
<span style="margin-left: 2em">明劉仔肩編仔肩字汝弼鄱陽人洪武初因薦應</span>  
<span style="margin-left: 2em">召至京集同時之詩爲此書上自公卿下至衲子</span>  
<!-- 册5 葉260a　Page:文淵閣四庫全書_0005冊.djvu/70 -->
<span style="margin-left: 2em">凡五十餘人而仔肩所作亦附焉用劉向王逸徐</span>  
<span style="margin-left: 2em">陵芮挺章例也有宋濓張孟兼前後二序皆作於</span>  
<span style="margin-left: 2em">洪武三年所選之詩毎人僅數首葢是時諸人之</span>  
<span style="margin-left: 2em">集皆未成編隨得隨錄故未能賅備然明初諸家</span>  
<span style="margin-left: 2em">今無專集行世者頗藉以畧存梗槪其時武功初</span>  
<span style="margin-left: 2em">定文治方興仔肩擬之雅頌固未免溢美要其春</span>  
<span style="margin-left: 2em">容諧婉雍雍乎開國之音存之亦足以見明初之</span>  
<span style="margin-left: 2em">風氣也此本猶洪武時舊刻歲久刓敝頗有糢糊</span>  
<span style="margin-left: 2em">佚脫之處無别本可校今悉姑仍其舊焉</span>

唐詩品彚九十卷拾遺十卷<sub class="note-yuan">編修鄭際唐家藏本</sub>  
<span style="margin-left: 2em">明高棅編棅有嘯臺集巳著錄宋之末年江西一</span>  
<span style="margin-left: 2em">𣲖與四靈一𣲖併合而爲江湖𣲖猥襍細碎如出</span>  
<span style="margin-left: 2em">一轍詩以大𡚁元人欲以新艷竒麗矯之迨其末</span>  
<span style="margin-left: 2em">流飛卿長吉一𣲖與盧仝馬異劉义一𣲖併合而</span>  
<span style="margin-left: 2em">爲鐵體妖冶俶詭如出一轍詩又大𡚁百餘年中</span>  
<span style="margin-left: 2em">能自拔於風氣外者落落數十人耳明初閩人林</span>  
<span style="margin-left: 2em">鴻始以規仿盛唐立論而棅實左右之是集其職</span>  
<span style="margin-left: 2em">志也所錄凡六百二十家得詩五千七百六十九</span>  
<!-- 册5 葉261a　Page:文淵閣四庫全書_0005冊.djvu/70 -->
<span style="margin-left: 2em">首分體編次爲五言古詩二十四卷七言古詩十</span>  
<span style="margin-left: 2em">三卷長短句附焉五言絶句八卷六言附焉七言</span>  
<span style="margin-left: 2em">絶句十卷五言律詩十五卷五言排律十一卷七</span>  
<span style="margin-left: 2em">言律詩九卷排律附焉始於洪武甲子成於癸酉</span>  
<span style="margin-left: 2em">至戊寅又搜補作者六十一人詩九百五十四首</span>  
<span style="margin-left: 2em">爲拾遺十卷附於後考玉臺新詠有古絶句四首</span>  
<span style="margin-left: 2em">棅以絶句居律詩前葢有所考至排律之名古所</span>  
<span style="margin-left: 2em">未有楊仲宏撰唐音始别爲一目棅祖其說遂至</span>  
<span style="margin-left: 2em">今沿用二馮批<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）">才調集以堆砌板𣻉雜亂無章</span>  
<!-- 册5 葉261b　Page:文淵閣四庫全書_0005冊.djvu/70 -->
<span style="margin-left: 2em">之病歸咎於排之一字詆棅爲作俑然詩家不善</span>  
<span style="margin-left: 2em">𨽻事卽二韻四韻未嘗不堆砌板𣻉雜亂無章是</span>  
<span style="margin-left: 2em">亦不必盡以排字爲誤矣諸體之中各分正始正</span>  
<span style="margin-left: 2em">宗大家名家羽翼接武正變餘響旁流九格其凡</span>  
<span style="margin-left: 2em">例謂大畧以初唐爲正始盛唐爲正宗爲大家爲</span>  
<span style="margin-left: 2em">名家爲羽翼中唐爲接武晩唐爲正變爲餘響方</span>  
<span style="margin-left: 2em">外異人等詩爲旁流間有一二成家特立與時異</span>  
<span style="margin-left: 2em">者則不以世次拘之如陳子昂與李白列在正宗</span>  
<span style="margin-left: 2em">劉長卿錢起韋應物柳宗元與高適岑參同在名</span>

<span style="margin-left: 2em">家是也其分初盛中晩葢宋嚴羽巳有是說二馮</span>  
<span style="margin-left: 2em">嘗以劉長卿亦盛亦中之𩔖力攻其謬然限斷之</span>  
<span style="margin-left: 2em">例亦論大槩耳寒温相代必有半冬半春之一日</span>  
<span style="margin-left: 2em">遂可謂四時無别哉明史文苑傳謂終明之世館</span>  
<span style="margin-left: 2em">閣以此書爲宗厥後李夢陽何景明等摹擬盛唐</span>  
<span style="margin-left: 2em">名爲崛起其胚胎實兆於此平心而論唐音之流</span>  
<span style="margin-left: 2em">爲膚廓者此書實啟其𡚁唐音之不絶於後世者</span>  
<span style="margin-left: 2em">亦此書實衍其傳功過並存不能互掩後來過毁</span>  
<span style="margin-left: 2em">過譽皆門戸之見非公論也至於章懷太子黄臺</span>

<span style="margin-left: 2em">𤓰詞沈佺期古意之𩔖或<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）">竄舊文康寳月劉令</span>

<span style="margin-left: 2em">大體可矣</span>  
廣州四先生詩四卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">不著編輯者名氏乃明初廣州黄哲李德王佐趙</span>  
<span style="margin-left: 2em">介四人詩也哲字庸之用薦拜翰林待制侍懿文</span>  
<span style="margin-left: 2em">太子讀書出知東阿縣陞東平通判歸尋坐法死</span>  
<span style="margin-left: 2em">有雪蓬集德字仲修洪武中用薦授雒陽長史官</span>  
<!-- 册5 葉265a　Page:文淵閣四庫全書_0005冊.djvu/71 -->
<span style="margin-left: 2em">至義寜縣知縣有易庵集佐字彦舉本河東人元</span>  
<span style="margin-left: 2em">末侍父官南雄遂占南海籍洪武初徵至京師授</span>  
<span style="margin-left: 2em">給事中有聽雨軒瀛洲二集没後稿多遺逸僅存</span>  
<span style="margin-left: 2em">詩一卷郡人彭森刻於建安介字伯貞明初閉戸</span>  
<span style="margin-left: 2em">讀書不求仕進屢薦皆辭免坐累逮赴京師卒於</span>  
<span style="margin-left: 2em">南昌舟中後以子純官監察御史贈如其官有臨</span>  
<span style="margin-left: 2em">淸集四人初與同郡孫蕡號南園五先生後惟蕡</span>  
<span style="margin-left: 2em">集流傳四人著作巳多散佚此乃後人重輯之本</span>  
<span style="margin-left: 2em">以蕡集别行故惟稱四先生焉雖網羅放失篇帙</span>

<span style="margin-left: 2em">篇胎息温李俱可自名一家惟佐氣骨稍卑未能</span>  
<span style="margin-left: 2em">驂駕而介詩所存太少不足以見所長耳然粤東</span>  
<span style="margin-left: 2em">詩𣲖數人實開其先其提唱風雅之功有未可没</span>  
<span style="margin-left: 2em">者故存之以著其槩俾與西庵集並傳焉</span>
