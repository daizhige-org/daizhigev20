<span style="margin-left: 1em">經部三十九</span>  
<span style="margin-left: 2em">樂類存目</span>  
雅樂發微八卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">明張敔撰考明有兩張敔其一字伯起合肥人永</span>  
<span style="margin-left: 2em">樂中貢入太學除廣東道監察御史官至陜西按</span>  
<span style="margin-left: 2em">察使僉事所著有京氏易考見朱𢑴尊經義考此</span>  
<span style="margin-left: 2em">張敔饒州人朱載堉律吕精義第五卷中載有其</span>  
<span style="margin-left: 2em">名又明史陸粲傳載粲劾張璁桂萼疏有禮部員</span>  
<!-- 册1 葉3197b　Page:文淵閣四庫全書_0001冊.djvu/849 -->
<span style="margin-left: 2em">外郎張敔假律厯而結知之語與此書亦相合葢</span>  
<span style="margin-left: 2em">卽其人也敔論樂大㫖以人聲最低者命爲黃鐘</span>  
<span style="margin-left: 2em">其最高者爲應鐘之變宫是書自元聲正半律諸</span>  
<span style="margin-left: 2em">法以逮樂器樂歌懸圖舞表分門畢具後又作雅</span>  
<span style="margin-left: 2em">義三卷附之六十律八十四調十六鐘以及累黍</span>  
<span style="margin-left: 2em">生尺之法無不悉究其序謂論琴律本之朱子論</span>  
<span style="margin-left: 2em">笛制本之杜䕫論旋宫本之周禮論鐘鎛本之國</span>  
<span style="margin-left: 2em">語於樂制頗有考証然如論<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3358.svg?width=24" alt="四庫全書僻字第3358號（蕤）" title="四庫全書僻字第3358號（蕤）">賓生大吕主吕覽</span>  
<span style="margin-left: 2em">淮南子上生之說不知律吕相生定法上生與下</span>

<span style="margin-left: 2em">生相間故左旋與右旋相乘今應鐘旣上生<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3358.svg?width=24" alt="四庫全書僻字第3358號（蕤）" title="四庫全書僻字第3358號（蕤）">賔</span>  
<span style="margin-left: 2em">而<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3358.svg?width=24" alt="四庫全書僻字第3358號（蕤）" title="四庫全書僻字第3358號（蕤）">賔又上生大吕與上下相生之序極爲錯迕</span>  
<span style="margin-left: 2em">乃先儒已廢之論殊不足據也</span>  
大樂律吕元聲六卷附律吕考注四卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明李文利撰文利字乾遂號兩山莆田人成化庚</span>  
<span style="margin-left: 2em">子舉人官思南府教授是書據吕氏春秋黄鐘長</span>  
<span style="margin-left: 2em">三寸九分之說駁司馬遷黄鐘長九寸之誤明史</span>  
<span style="margin-left: 2em">藝文志又載黃積慶作樂律管見二卷駁文利之</span>  
<span style="margin-left: 2em">誤考吕氏春秋仲夏適音篇言黄帝令伶倫自大</span>  
<!-- 册1 葉3200b　Page:文淵閣四庫全書_0001冊.djvu/850 -->
<span style="margin-left: 2em">夏之西阮隃之陰取竹嶰溪之谷空竅厚匀者斷</span>  
<span style="margin-left: 2em">兩節間其長三寸九分而吹之以爲黃鐘之宫曰</span>  
<span style="margin-left: 2em">含少次制十二筒以聽鳳凰之鳴以别十二律其</span>  
<span style="margin-left: 2em">雄鳴爲六雌鳴亦六以比黃鐘之宫而皆可以生</span>  
<span style="margin-left: 2em">之故曰黃鐘之宫律吕之本其季夏六月紀又曰</span>  
<span style="margin-left: 2em">黃鐘生林鐘林鐘生太蔟太蔟生南吕南吕生姑</span>  
<span style="margin-left: 2em">洗姑洗生應鐘應鐘生<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3358.svg?width=24" alt="四庫全書僻字第3358號（蕤）" title="四庫全書僻字第3358號（蕤）">賔<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3358.svg?width=24" alt="四庫全書僻字第3358號（蕤）" title="四庫全書僻字第3358號（蕤）">賔生大吕大吕生</span>  
<span style="margin-left: 2em">夷則夷則生夾鐘夾鐘生無射無射生仲吕三分</span>  
<span style="margin-left: 2em">所生益之一分以上生三分所生去其一分以下</span>  
<!-- 册1 葉3201a　Page:文淵閣四庫全書_0001冊.djvu/850 -->
<span style="margin-left: 2em">生黃鐘大吕太蔟夾鐘姑洗仲吕<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3358.svg?width=24" alt="四庫全書僻字第3358號（蕤）" title="四庫全書僻字第3358號（蕤）">賓爲上林鐘</span>  
<span style="margin-left: 2em">夷則南吕無射應鐘爲下是其損益相生與史記</span>  
<span style="margin-left: 2em">同也假令以三寸九分爲黄鐘而如其上下相生</span>  
<span style="margin-left: 2em">之法而三分損益之至於應鐘止長一寸八分四</span>  
<span style="margin-left: 2em">釐有竒何以成聲耶又按吳韋昭注國語曰黃鐘</span>  
<span style="margin-left: 2em">陽之變言陽氣變而爲黃鐘耳猶漢志云黃鐘爲</span>  
<span style="margin-left: 2em">乾之初九也與<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3358.svg?width=24" alt="四庫全書僻字第3358號（蕤）" title="四庫全書僻字第3358號（蕤）">賓無與也其言黃鐘爲管長九</span>  
<span style="margin-left: 2em">寸徑三分圍九分而又舉<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3358.svg?width=24" alt="四庫全書僻字第3358號（蕤）" title="四庫全書僻字第3358號（蕤）">賓成數云管長六寸</span>  
<span style="margin-left: 2em">三分所以分别黃鐘<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3358.svg?width=24" alt="四庫全書僻字第3358號（蕤）" title="四庫全書僻字第3358號（蕤）">賓者尋文按數甚爲明了</span>  
<!-- 册1 葉3201b　Page:文淵閣四庫全書_0001冊.djvu/850 -->
<span style="margin-left: 2em">其不以九寸本<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3358.svg?width=24" alt="四庫全書僻字第3358號（蕤）" title="四庫全書僻字第3358號（蕤）">賓之律而爲黃鐘之變者亦甚</span>  
<span style="margin-left: 2em">明矣至吕覽先言三寸九分爲黃鐘之宫又云次</span>  
<span style="margin-left: 2em">制十二筒以比黃鐘之宫而皆可以生之則黃鐘</span>  
<span style="margin-left: 2em">之宫非卽黃鐘與月令云六月律中黃鐘之宫十</span>  
<span style="margin-left: 2em">一月律中黃鐘者正同也文利誤解吕覽韋昭之</span>  
<span style="margin-left: 2em">意而堅執三寸九分爲黃鐘并以黃鐘之九寸爲</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3358.svg?width=24" alt="四庫全書僻字第3358號（蕤）" title="四庫全書僻字第3358號（蕤）">賓不亦舛乎至於以三寸九分起數循環升降</span>  
<span style="margin-left: 2em">自大吕以至<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3358.svg?width=24" alt="四庫全書僻字第3358號（蕤）" title="四庫全書僻字第3358號（蕤）">賓五陽辰皆以陽升而進九分惟</span>  
<span style="margin-left: 2em">黃鐘陽氣尙㣲故止進六分自林鐘以至黃鐘五</span>  
<!-- 册1 葉3204a　Page:文淵閣四庫全書_0001冊.djvu/851 -->
<span style="margin-left: 2em">陰辰皆以陰降而退九分惟林鐘陰氣未盛故止</span>  
<span style="margin-left: 2em">退六分夫陰陽進退皆由馴致或多或少以漸而</span>  
<span style="margin-left: 2em">加不得進退先以六分而後驟增至九分也又五</span>  
<span style="margin-left: 2em">聲生數次第宫五十商八十角九十徵七十羽六</span>  
<span style="margin-left: 2em">十多少之數毫無法象又云變宫五十變徵七十</span>  
<span style="margin-left: 2em">二變與正律同數尤不可解也其六十調圖雖本</span>  
<span style="margin-left: 2em">律吕新書改其次序以從左旋而每五調之後又</span>  
<span style="margin-left: 2em">列一宫與大司樂奏歌之說相附其雙宫對調圖</span>  
<span style="margin-left: 2em">則止據奏歌二律分配之更爲牽强矣</span>  
<!-- 册1 葉3204b　Page:文淵閣四庫全書_0001冊.djvu/851 -->
六樂說<sub class="note-yuan">無卷數　江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">明劉績撰績有三禮圖說已著錄此其論樂之書</span>  
<span style="margin-left: 2em">也前有自序謂蔡氏律吕新書不合者多因以古</span>  
<span style="margin-left: 2em">義求已亡之器以古器推未言之義作爲此書然</span>  
<span style="margin-left: 2em">持論偏執且多踈畧如云七音漢以前但謂之和</span>  
<span style="margin-left: 2em">繆不能立名又云天地自然之聲每律有極淸聲</span>  
<span style="margin-left: 2em">淸多濁少聲五聲未盡故又生變徵極淸變商淸</span>  
<span style="margin-left: 2em">多濁少以盡之而不取先儒變宫之說夫變宫之</span>  
<span style="margin-left: 2em">說漢以前固無有矣若變商之說則淮南以後亦</span>  
<!-- 册1 葉3205a　Page:文淵閣四庫全書_0001冊.djvu/851 -->
<span style="margin-left: 2em">無有也斯亦杜撰之甚者矣又云凡字能調爲他</span>  
<span style="margin-left: 2em">字者爲陰聲不能調爲他字者爲陽聲如黃陽𮎰</span>  
<span style="margin-left: 2em">陰之𩔖按字分陰陽自周德淸中原音韻以聲之</span>  
<span style="margin-left: 2em">高下論之非謂其能調他聲否也以字母言之則</span>  
<span style="margin-left: 2em">見有陰無陽疑有陽無隂卽純淸純濁字也見之</span>  
<span style="margin-left: 2em">陽疑之陰雖有聲而無其字溪羣二母則卽一聲</span>  
<span style="margin-left: 2em">而溪陰羣陽自爲淸濁劉氏所言於音韻殊爲隔</span>  
<span style="margin-left: 2em">閡至於鐘磬等制多據博古圖以變亂古人舊說</span>  
<span style="margin-left: 2em">尤不可訓矣</span>  
<!-- 册1 葉3205b　Page:文淵閣四庫全書_0001冊.djvu/851 -->
古樂經傳三卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明湛若水𢰅若水有二禮經傳測已著錄是書𥙷</span>  
<span style="margin-left: 2em">樂經一篇若水所擬古樂正傳十篇則錄其門人</span>  
<span style="margin-left: 2em">吕懷之書古樂本傳一篇卽樂記原文別傳一篇</span>  
<span style="margin-left: 2em">皆周禮所言樂事雜傳一篇律傳一篇則雜採孟</span>  
<span style="margin-left: 2em">子以下及厯代論樂語也其大㫖以論度數爲主</span>  
<span style="margin-left: 2em">以論義理爲後故以已所作者反謂之經而樂記</span>  
<span style="margin-left: 2em">以下古經反謂之傳然古之度數其宻率已不可</span>  
<span style="margin-left: 2em">知非聖人聲律身度者何由於百世之下闇與古</span>  
<!-- 册1 葉3208a　Page:文淵閣四庫全書_0001冊.djvu/852 -->
<span style="margin-left: 2em">合而用以播諸金右管<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3500.svg?width=24" alt="四庫全書僻字第3500號（「絃」字少最後一點）" title="四庫全書僻字第3500號（「絃」字少最後一點）">之器若水遽定爲經未</span>  
<span style="margin-left: 2em">免自信之過矣</span>  
樂律纂要一卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">明季本𢰅本有易學四同已著錄是書凡十三篇</span>  
<span style="margin-left: 2em">其論聲氣之源欲舍古尺而治以耳亦不甚取候</span>  
<span style="margin-left: 2em">氣之法其論律管圍徑頗以祖冲之宻率疑胡瑗</span>  
<span style="margin-left: 2em">三分四𨤲六毫有奇之說其論黃鐘生十一律以</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3358.svg?width=24" alt="四庫全書僻字第3358號（蕤）" title="四庫全書僻字第3358號（蕤）">賓生大吕非本法其論十二律寸法以六變律</span>  
<span style="margin-left: 2em">補鐘律解之闕其論正變倍半駁但用四淸聲之</span>  
<!-- 册1 葉3208b　Page:文淵閣四庫全書_0001冊.djvu/852 -->
<span style="margin-left: 2em">非其論五聲相生不取沈括筆談論二變聲不取</span>  
<span style="margin-left: 2em">杜佑通典後附趙彦肅所傳開元詩譜十二章則</span>  
<span style="margin-left: 2em">舊文也本承姚江之學派其持論務欲掃滌舊文</span>  
<span style="margin-left: 2em">獨標心得至於論禮諭樂亦皆自出新裁一知半</span>  
<span style="margin-left: 2em">解雖不無可取而大致不根於古義觀其自序亦</span>  
<span style="margin-left: 2em">言無所師承以意考究而得之也</span>  
蔡氏律同二卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">明蔡宗兖𢰅宗兖字我齋山陰人正德丁丑進士</span>  
<span style="margin-left: 2em">官興化府教授是書以本性稽數候氣三篇爲上</span>  
<!-- 册1 葉3209a　Page:文淵閣四庫全書_0001冊.djvu/852 -->
<span style="margin-left: 2em">卷以文聲協律制器正度量權四篇爲下卷其稽</span>  
<span style="margin-left: 2em">數所据史記生鍾分演爲圖說皆人所同有其以</span>  
<span style="margin-left: 2em">古人半律當元定蔡氏變律不如仍古人之名爲</span>  
<span style="margin-left: 2em">是其謂變律之不必增設亦似有所見而未盡其</span>  
<span style="margin-left: 2em">奥文聲一篇不用二變古亦有此論騐之於今南</span>  
<span style="margin-left: 2em">曲如此北曲則必有二變矣皆其宫調之乙凡二</span>  
<span style="margin-left: 2em">字也至謂五聲則有二變如樓之梯堂之階則殊</span>
