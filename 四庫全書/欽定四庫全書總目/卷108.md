## 欽定四庫全書總目 卷一百八　子部十八　術數類一

<!-- 册3 葉1320：整葉圖版，無文字記錄 -->
<!-- 册3 葉1321a　Page:文淵閣四庫全書_0003冊.djvu/335 -->
欽定四庫全書總目卷一百八  
<span style="margin-left: 1em">子部十八</span>  
<span style="margin-left: 2em">術數𩔖一</span>  
<span style="margin-left: 3em">術數之興多在秦漢以後要其旨不出乎陰陽</span>  
<span style="margin-left: 3em">五行生尅制化實皆易之支流傳以雜說耳物</span>  
<span style="margin-left: 3em">生有𧰼𧰼生有數乘除推闡務究造化之源者</span>  
<span style="margin-left: 3em">是爲數學星土雲物見於經典流傳妖妄寖失</span>  
<span style="margin-left: 3em">其眞然不可謂古無其說是爲占候自是以外</span>  
<span style="margin-left: 3em">末流猥雜不可殫名史志總槪以五行今參驗</span>  
<!-- 册3 葉1321b　Page:文淵閣四庫全書_0003冊.djvu/335 -->
<span style="margin-left: 3em">古書旁稽近法析而别之者三曰相宅相墓曰</span>  
<span style="margin-left: 3em">占卜曰命書相書併而合之者一曰陰陽五行</span>  
<span style="margin-left: 3em">雜技術之有成書者亦别爲一類附焉中惟數</span>  
<span style="margin-left: 3em">學一家爲易外别傳不切事而猶近理其餘則</span>  
<span style="margin-left: 3em">皆百僞一眞遞相煽動必謂古無是說亦無是</span>  
<span style="margin-left: 3em">理固儒者之迂談必謂今之術士能得其傳亦</span>  
<span style="margin-left: 3em">世俗之惑志徒以冀福畏禍今古同情趨避之</span>  
<span style="margin-left: 3em">念一萌方技者流遂各乘其隙以中之故悠謬</span>  
<span style="margin-left: 3em">之談彌變彌夥耳然衆志所趨雖聖人有所弗</span>  
<!-- 册3 葉1324a　Page:文淵閣四庫全書_0003冊.djvu/336 -->
<span style="margin-left: 3em">能禁其可通者存其理其不可通者姑存其說</span>  
<span style="margin-left: 3em">可也</span>  
太元經十卷<sub class="note-yuan">編修勵守謙家藏本</sub>  
<span style="margin-left: 2em">漢揚雄撰晉范望注漢書藝文志稱揚雄所序三</span>  
<span style="margin-left: 2em">十八篇太元十九其本傳則稱太元三方九州二</span>  
<span style="margin-left: 2em">十七部八十一家二百四十三表七百二十九贊</span>  
<span style="margin-left: 2em">分爲三卷曰一二三與太初厯相應又稱有首衝</span>  
<span style="margin-left: 2em">錯測攡<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3284.svg?width=24" alt="四庫全書僻字第3284號（瑩）" title="四庫全書僻字第3284號（瑩）">數文掜圖告十一篇皆以解剝元體離</span>  
<span style="margin-left: 2em">散其文章句尙不存焉與藝文志十九篇之說已</span>  
<!-- 册3 葉1324b　Page:文淵閣四庫全書_0003冊.djvu/336 -->
<span style="margin-left: 2em">相違異桓譚新論則稱太元經三篇傳十二篇合</span>  
<span style="margin-left: 2em">之乃十五篇較本傳又多一篇案阮孝緒稱太元</span>  
<span style="margin-left: 2em">經九卷雄自作章句隋志亦載雄太元經章句九</span>  
<span style="margin-left: 2em">卷疑漢志所云十九篇乃合其章句言之今章句</span>  
<span style="margin-left: 2em">已佚故篇數有異至桓譚新論則世無傳本惟諸</span>  
<span style="margin-left: 2em">書逓相援引或訛十一爲十二耳以今本校之其</span>  
<span style="margin-left: 2em">篇名篇數一一與本傳皆合固未嘗有脫佚也注</span>  
<span style="margin-left: 2em">其書者自漢以來惟宋衷陸績最著至晉范望乃</span>  
<span style="margin-left: 2em">因二家之注勒爲一編雄書本擬易而作以家準</span>  
<!-- 册3 葉1325a　Page:文淵閣四庫全書_0003冊.djvu/336 -->
<span style="margin-left: 2em">卦以首準彖以贊準爻以測準𧰼以文準文言以</span>  
<span style="margin-left: 2em">攡<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3284.svg?width=24" alt="四庫全書僻字第3284號（瑩）" title="四庫全書僻字第3284號（瑩）">掜圖告準繫辭以數準説卦以衝準序卦以</span>  
<span style="margin-left: 2em">錯準雜卦全仿周易古本經傳各自爲篇望作注</span>  
<span style="margin-left: 2em">時析元首一篇分冠八十一家之前析元測一篇</span>  
<span style="margin-left: 2em">分繫七百二十九贊之下始變其舊至今仍之其</span>  
<span style="margin-left: 2em">書唐藝文志作十二卷文獻通考則作十卷均名</span>  
<span style="margin-left: 2em">曰太元經注此本十卷與通考合而卷端標題則</span>  
<span style="margin-left: 2em">稱晉范望字叔明解贊考元測第一條下有附注</span>  
<span style="margin-left: 2em">曰此是宋陸二家所注卽非范望注也蓋范望採</span>  
<!-- 册3 葉1325b　Page:文淵閣四庫全書_0003冊.djvu/336 -->
<span style="margin-left: 2em">此注意自解經贊儒有近習罔知本末妄將此注</span>  
<span style="margin-left: 2em">升於測日之上以雜范注混亂義訓今依范望正</span>  
<span style="margin-left: 2em">本移於測日之下免誤學者已下七百二十九測</span>  
<span style="margin-left: 2em">注並同云云考望自序亦稱因陸君爲本錄宋所</span>  
<span style="margin-left: 2em">長捐其所短並首一卷本經之上散測一卷注文</span>  
<span style="margin-left: 2em">之中訓理其義以測爲據然則望所自注特其贊</span>  
<span style="margin-left: 2em">詞其他文則酌取二家之舊故獨以解贊爲文今</span>  
<span style="margin-left: 2em">槪稱望注要其終而目之耳卷端列陸績述元一</span>  
<span style="margin-left: 2em">篇據陳振孫書錄解題爲范本所舊有又列王涯</span>  
<!-- 册3 葉1328a　Page:文淵閣四庫全書_0003冊.djvu/337 -->
<span style="margin-left: 2em">說元五篇又列釋文一卷則不知何人附入其太</span>  
<span style="margin-left: 2em">元圖旁范望序末及元首元測之首尾凡附記九</span>  
<span style="margin-left: 2em">條卷末又有一䟦均不著名氏考序後附記稱近</span>  
<span style="margin-left: 2em">時林瑀瑀與賈昌朝同時則此九條當出北宋人</span>  
<span style="margin-left: 2em">手又王涯說元之末附題一行云右廸功郎充兩</span>  
<span style="margin-left: 2em">浙東路提舉茶鹽司幹辦公事張實校勘則附記</span>  
<span style="margin-left: 2em">或出於實歟其釋文一卷亦不著名氏考鄭樵通</span>  
<span style="margin-left: 2em">志太元經釋文一卷亦林瑀撰疑實刋是書時併</span>  
<span style="margin-left: 2em">以涯之說瑀之釋文冠於編首也</span>  
<!-- 册3 葉1328b　Page:文淵閣四庫全書_0003冊.djvu/337 -->
太元本旨九卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">明葉子奇撰子奇字世杰號靜齋龍泉人明初以</span>  
<span style="margin-left: 2em">薦官巴陵縣主簿揚雄以元擬易卷首所列舊圖</span>  
<span style="margin-left: 2em">具七十二候晁說之易元星紀譜亦以星候爲機</span>  
<span style="margin-left: 2em">括子竒獨謂太元附會律厯節候而强其合不無</span>  
<span style="margin-left: 2em">臆見厯舉所求而未通者八條以明未足盡易之</span>  
<span style="margin-left: 2em">旨而又稱其能自成一家之學在兩漢不可多得</span>  
<span style="margin-left: 2em">因别爲詮釋以正宋陸舊註之訛蓋亦如說易之</span>  
<span style="margin-left: 2em">家廢𧰼數而言義理也考太元大意雖不盡渉乎</span>  
<!-- 册3 葉1329a　Page:文淵閣四庫全書_0003冊.djvu/337 -->
<span style="margin-left: 2em">飛伏互應與焦京之說冇别然漢書雄本傳稱元</span>  
<span style="margin-left: 2em">首四重者非卦也數也其用自天元推一晝一夜</span>  
<span style="margin-left: 2em">陰陽數度律厯之紀九九大運與天終始與太初</span>  
<span style="margin-left: 2em">厯相應亦有顓頊之厯焉漢儒所述其說至明子</span>  
<span style="margin-left: 2em">奇必以爲不協律厯其說殊戾然元文艱澁子奇</span>  
<span style="margin-left: 2em">能循文闡發使讀者易明亦有一節之可取數百</span>  
<span style="margin-left: 2em">年來註是書者寥寥存以備一家可也</span>  
元包五卷附元包數總義二卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">北周衞元嵩撰唐蘇源明傳李江注宋韋漢<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">釋</span>  
<!-- 册3 葉1329b　Page:文淵閣四庫全書_0003冊.djvu/337 -->
<span style="margin-left: 2em">音其總義二卷則張行成所補撰也楊楫嘗序其</span>  
<span style="margin-left: 2em">書云元嵩益州成都人明陰陽厯算獻䇿後周賜</span>  
<span style="margin-left: 2em">爵持節蜀郡公胡應麟四部正譌則云元嵩後周</span>  
<span style="margin-left: 2em">人所撰述有齊三教論七卷見鄭樵通志又隋志</span>  
<span style="margin-left: 2em">釋氏類稱蜀郡沙門衞元嵩上書言僧徒猥濫周</span>  
<span style="margin-left: 2em">武帝下詔一切廢毁卽其人也楊楫本序頗與隋</span>  
<span style="margin-left: 2em">志合序稱元嵩有傳考北史無之楊氏誤也案應</span>  
<span style="margin-left: 2em">麟謂元嵩先爲沙門所考較楫爲詳然北史載元</span>  
<span style="margin-left: 2em">嵩藝術傳中應麟求之於專傳不見其名遂以爲</span>  
<!-- 册3 葉1332a　Page:文淵閣四庫全書_0003冊.djvu/338 -->
<span style="margin-left: 2em">北史不載則楫不誤而應麟反誤至崇文總目以</span>  
<span style="margin-left: 2em">爲唐人通志通考並因之則踈舛更甚矣唐釋道</span>  
<span style="margin-left: 2em">宣廣宏明集於元嵩深有詆詞蓋以澄汰僧徒故</span>  
<span style="margin-left: 2em">緇流積恨然温大雅創業起居注載元嵩造謡䜟</span>  
<span style="margin-left: 2em">裴寂等引之以勸進則亦妖妄之徒也是書體例</span>  
<span style="margin-left: 2em">近太元序次則用歸藏首坤而繼以乾兌艮離坎</span>  
<span style="margin-left: 2em">巽震卦凡七變合本卦共成八八六十四自繫以</span>  
<span style="margin-left: 2em">辭文多詰屈又好用僻字難以猝讀及究其傳注</span>  
<span style="margin-left: 2em">音釋乃别無奥義以艱深而文淺易不過效太元</span>  
<!-- 册3 葉1332b　Page:文淵閣四庫全書_0003冊.djvu/338 -->
<span style="margin-left: 2em">之顰宋紹興中臨卭張行成以蘇李二氏徒言其</span>  
<span style="margin-left: 2em">理未知其數復徧采易說以通其旨著爲總義元</span>  
<span style="margin-left: 2em">嵩書唐志作十卷今本五卷其或併或佚蓋不可</span>  
<span style="margin-left: 2em">考楊楫序稱大觀庚寅前進士張昇景初擕元包</span>  
<span style="margin-left: 2em">見遺日自後周厯隋唐迄今五百餘載世莫得聞</span>  
<span style="margin-left: 2em">頃因楊元素内翰傳秘閣本俾鏤板以傳然此書</span>  
<span style="margin-left: 2em">唐志崇文總目並著錄何以云五百餘年世莫得</span>  
<span style="margin-left: 2em">聞王世貞疑爲依托似非無見今術數家從無用</span>  
<span style="margin-left: 2em">以占卜者徒以流傳旣久姑錄存之行成書玉海</span>  
<!-- 册3 葉1333a　Page:文淵閣四庫全書_0003冊.djvu/338 -->
<span style="margin-left: 2em">作二卷與今本合與元包本别著錄然考昇子張</span>  
<span style="margin-left: 2em">洸䟦已稱以行成疏義與臨卭韋漢<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">釋音合爲</span>  
<span style="margin-left: 2em">一編則二書之併其來巳久毛晉刋板蓋有所本</span>  
<span style="margin-left: 2em">今亦仍之其釋音漏題漢<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">名則晉之疎耳</span>  
潛虛一卷附潛虚發徵論一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">宋司馬光撰光有温公易說巳著錄是編乃擬太</span>  
<span style="margin-left: 2em">元而作晁公武讀書志曰此書是五行爲本五行</span>  
<span style="margin-left: 2em">相乘爲二十五兩之爲五十首有氣體性名行變</span>  
<span style="margin-left: 2em">解七圖然其辭有闕者蓋未成也其手寫草稿一</span>  
<!-- 册3 葉1333b　Page:文淵閣四庫全書_0003冊.djvu/338 -->
<span style="margin-left: 2em">通今在子建姪房朱子䟦張氏潛虚圖亦曰范仲</span>  
<span style="margin-left: 2em">彪炳文家多藏司馬文正公遺墨嘗示子潛虚别</span>  
<span style="margin-left: 2em">本則其所闕之文甚多問之云温公晚著此書未</span>  
<span style="margin-left: 2em">竟而薨故所傳止此近見泉州所刻乃無一字之</span>  
<span style="margin-left: 2em">闕始復驚疑讀至數行乃釋然曰此贋本也其說</span>  
<span style="margin-left: 2em">與公武合此本首尾完具當卽朱子所謂泉州本</span>  
<span style="margin-left: 2em">非光之舊又公武言氣體性名行變解七圖熊朋</span>  
<span style="margin-left: 2em">來則言潛虛有氣圖其次體圖其次性圖其次名</span>  
<span style="margin-left: 2em">圖其次行圖其次命圖其目凡六而張氏或言八</span>  
<!-- 册3 葉1336a　Page:文淵閣四庫全書_0003冊.djvu/339 -->
<span style="margin-left: 2em">圖者行圖中有變圖解圖也是命圖爲後人所補</span>  
<span style="margin-left: 2em">公武言五行相乘爲二十五兩之爲五十首而今</span>  
<span style="margin-left: 2em">本實五十五行是其中五行亦後人所補不止增</span>  
<span style="margin-left: 2em">其文句已也吳師道禮部集有此書後序稱初得</span>
