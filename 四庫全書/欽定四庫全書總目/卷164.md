## 欽定四庫全書總目 卷一百六十四　集部十七　別集類十七

<!-- 册4 葉1240a　Page:文淵閣四庫全書_0004冊.djvu/315 -->
欽定四庫全書總目卷一百六十四  
<span style="margin-left: 1em">集部十七</span>  
<span style="margin-left: 2em">別集𩔖十七</span>  
文溪存稿二十卷<sub class="note-yuan">兩江巡撫採進本</sub>  
<span style="margin-left: 2em">宋李昴英撰昴英字俊明番禺人寶慶三年廷對</span>  
<span style="margin-left: 2em">第三淳祐初官至龍圖閣待制吏部侍郞致仕卒</span>  
<span style="margin-left: 2em">諡忠簡文溪其退居之地也張端義貴耳集載昴</span>  
<span style="margin-left: 2em">英初任臨汀推官陳孝嚴激軍變盡出家貲撫定</span>  
<span style="margin-left: 2em">之曾冶鳳帥廣激曾忠之變崔菊坡臨城借用經</span>  
<!-- 册4 葉1240b　Page:文淵閣四庫全書_0004冊.djvu/315 -->
<span style="margin-left: 2em">畧使印撫諭李縋城入賊曉以禍福五羊城郭得</span>  
<span style="margin-left: 2em">全賊至肇慶就捕朝廷錄功名之首除榮王府敎</span>  
<span style="margin-left: 2em">授力辭不供職但云素無學問難以移氣習士論</span>  
<span style="margin-left: 2em">韙之云云則昴英葢具幹濟之才而又能介然自</span>  
<span style="margin-left: 2em">守者其後劾史嵩之趙與籌<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">聲動天下有自來</span>  
<span style="margin-left: 2em">也是集爲元至元間其門人李春叟所輯凡奏稿</span>  
<span style="margin-left: 2em">雜文一百二十二篇詩詞一百二十五首明成化</span>  
<span style="margin-left: 2em">中重刻陳獻章爲之序其文質實簡勁如其爲人</span>  
<span style="margin-left: 2em">詩間有粗俗之語不離宋格而骨力遒健亦非靡</span>  
<!-- 册4 葉1241a　Page:文淵閣四庫全書_0004冊.djvu/315 -->
<span style="margin-left: 2em">靡之音葢言者心聲其剛<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">之氣有自然不掩者</span>  
<span style="margin-left: 2em">矣</span>  
庸齋集六卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋趙汝騰撰汝騰字茂實庸齋其自號也太宗七</span>  
<span style="margin-left: 2em">世孫居於福州登寶慶二年進士厯官端明殿學</span>  
<span style="margin-left: 2em">士提舉佑神觀兼翰林學士承旨事蹟具宋史本</span>  
<span style="margin-left: 2em">傳其集宋史藝文志及諸家書目皆不著錄厲鶚</span>  
<span style="margin-left: 2em">宋詩紀事載宋宗室共七十五人亦無汝騰之名</span>  
<span style="margin-left: 2em">惟永樂大典各韻中間收入汝騰之文有題趙庸</span>  
<!-- 册4 葉1241b　Page:文淵閣四庫全書_0004冊.djvu/315 -->
<span style="margin-left: 2em">齋集者有題庸齋蓬萊閣紫霞洲集者又有題庸</span>  
<span style="margin-left: 2em">齋瑣闥集者而舊序巳佚其卷目次第不可復考</span>  
<span style="margin-left: 2em">謹蒐羅殘缺釐次成編析爲六卷篇帙無多可無</span>  
<span style="margin-left: 2em">煩名目統題作庸齋集以歸於一汝騰生朱子之</span>  
<span style="margin-left: 2em">鄉故沿溯餘波頗能講學然史稱其守正不撓其</span>  
<span style="margin-left: 2em">爲禮部尙書兼給事中時上疏極論姦諛興利之</span>  
<span style="margin-left: 2em">臣𢦤損國脉而規切理宗之私惠羣小今集中壬</span>  
<span style="margin-left: 2em">子六月內引第一第二劄卽其全文反覆詳明深</span>  
<span style="margin-left: 2em">中時弊又集中內外制序自稱嘗以草制忤史嵩</span>  
<!-- 册4 葉1244a　Page:文淵閣四庫全書_0004冊.djvu/316 -->
<span style="margin-left: 2em">之去國又稱時有無罪被謫如王三俊李伯玉之</span>  
<span style="margin-left: 2em">𩔖皆留黃不書上疏申救施行遂爲之格是其氣</span>  
<span style="margin-left: 2em">節嶽嶽眞不愧朱子之徒非假借門墻者可比惟</span>  
<span style="margin-left: 2em">考周密癸辛雜識稱汝騰爲從官力薦三衢徐霖</span>  
<span style="margin-left: 2em">爲著作郞至比之范文正公而霖舉止顚怪妄自</span>  
<span style="margin-left: 2em">尊大霖之無忌憚皆汝騰縱其狂至目汝騰爲大</span>  
<span style="margin-left: 2em">宗師己爲小宗師遞相汲引霖旣被逐汝騰亦不</span>  
<span style="margin-left: 2em">自安遂求補外云云按集中與徐徑坂唱和最多</span>  
<span style="margin-left: 2em">徑坂卽霖之字其贈詹生謁徑坂詩云瞻彼徑坂</span>  
<!-- 册4 葉1244b　Page:文淵閣四庫全書_0004冊.djvu/316 -->
<span style="margin-left: 2em">今之泗水又贊徑坂使君柯山講席之盛詩云立</span>  
<span style="margin-left: 2em">天地心鳴道鐸開生靈眼識師儒其推挹之詞殊</span>  
<span style="margin-left: 2em">爲誕謾無狀知周密所紀爲不誣是則宋季士大</span>  
<span style="margin-left: 2em">夫崇尙道學矯激沽名之流弊觀於是集良足爲</span>  
<span style="margin-left: 2em">千古炯鑒也</span>  
彝齋文編四卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋趙孟堅撰孟堅字子固自號彝齋太祖十一世</span>  
<span style="margin-left: 2em">孫其先以安定郡王從高宗南渡家於嘉禾之廣</span>  
<span style="margin-left: 2em">陳鎭而孟堅自作告墓文中又作廣成葢俗語相</span>  
<!-- 册4 葉1245a　Page:文淵閣四庫全書_0004冊.djvu/316 -->
<span style="margin-left: 2em">沿初無定字至元嘉禾志載廣陳鎭在海鹽縣東</span>  
<span style="margin-left: 2em">北九十里則孟堅當爲海鹽人其或作嘉興者誤</span>  
<span style="margin-left: 2em">也孟堅以宗室子登寶慶三年進士好學工書喜</span>  
<span style="margin-left: 2em">藏名蹟時人比之米芾至今遺墨流傳人人能知</span>  
<span style="margin-left: 2em">其姓字惟其生平本末則諸書所紀往往不同如</span>  
<span style="margin-left: 2em">周密齊東野語謂其終提轄左帑身後有嚴陵之</span>  
<span style="margin-left: 2em">命是孟堅殁於宋世而姚桐壽樂郊私語謂孟堅</span>  
<span style="margin-left: 2em">入元不樂仕進隱居避客從弟孟頫來訪坐定問</span>  
<span style="margin-left: 2em">弁山笠澤佳否孟頫云佳孟堅曰弟奈山澤佳何</span>  
<!-- 册4 葉1245b　Page:文淵閣四庫全書_0004冊.djvu/316 -->
<span style="margin-left: 2em">旣退使人濯其坐其云云則又似元初尙存者二</span>  
<span style="margin-left: 2em">說錯互殊甚今案孟堅甲辰歲朝把筆詩有四十</span>  
<span style="margin-left: 2em">五番見除夕之句以干支逆數之當生於慶元己</span>  
<span style="margin-left: 2em">未距宋亡時凡七十八年孟頫仕元尙在其後孟</span>  
<span style="margin-left: 2em">堅必不能及見又考朱存理鐵網珊瑚載孟堅梅</span>  
<span style="margin-left: 2em">竹譜卷有咸淳丁卯葉隆禮跋稱子固晩年工梅</span>  
<span style="margin-left: 2em">竹步驟逃禪予自江右歸將與之是正而子固死</span>  
<span style="margin-left: 2em">矣跋出隆禮手蹟其言可信是孟堅之卒於丁卯</span>  
<span style="margin-left: 2em">以前更爲<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">鑿亦足證桐壽之說爲誕妄矣至其</span>  
<!-- 册4 葉1248a　Page:文淵閣四庫全書_0004冊.djvu/317 -->
<span style="margin-left: 2em">厯官次第他書不載而見於詩文自述者如爲湖</span>  
<span style="margin-left: 2em">州掾入轉運司幕知諸曁縣以御史言罷歸皆厯</span>  
<span style="margin-left: 2em">厯可考獨不言其嘗爲朝官宋詩紀事乃謂其景</span>  
<span style="margin-left: 2em">定初遷翰林學士又不知何所據也其集宋史藝</span>  
<span style="margin-left: 2em">文志不著錄惟見於明秘閣書目者四冊世久失</span>  
<span style="margin-left: 2em">傳今從永樂大典摭拾補綴釐爲四卷大都淸遠</span>  
<span style="margin-left: 2em">絶俗類其爲人剩璧零珪風流未冺亦足與書畫</span>  
<span style="margin-left: 2em">並傳不朽云</span>  
張氏拙軒集六卷<sub class="note-yuan">永樂大典本</sub>  
<!-- 册4 葉1248b　Page:文淵閣四庫全書_0004冊.djvu/317 -->
<span style="margin-left: 2em">宋張侃撰侃字<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">夫其事蹟不見於史乘据集中</span>  
<span style="margin-left: 2em">自稱䢴城又稱淮海則當爲揚州人而自寶祐維</span>  
<span style="margin-left: 2em">揚志以下記廣陵人物者皆未嘗舉其姓名獨錢</span>  
<span style="margin-left: 2em">溥秘閣書目載有張拙軒初稿四冊焦竑國史經</span>  
<span style="margin-left: 2em">籍志則有張侃拙軒稿四卷而宋藝文志書錄解</span>  
<span style="margin-left: 2em">題俱無之宋人江湖前後諸集及近時選錄宋詩</span>  
<span style="margin-left: 2em">者亦多未之及則其湮晦於世葢巳久矣今永樂</span>  
<span style="margin-left: 2em">大典各韻內尙頗載其詩文或題拙軒集或題拙</span>  
<span style="margin-left: 2em">軒初稿勘驗標目與錢溥焦竑所記並合當卽其</span>  
<!-- 册4 葉1249a　Page:文淵閣四庫全書_0004冊.djvu/317 -->
<span style="margin-left: 2em">書惟其人無可考見今卽集中謝樓監丞爲其父</span>  
<span style="margin-left: 2em">作行實一書反覆參核知侃卽開禧中知樞密院</span>  
<span style="margin-left: 2em">張巖之子也案宋史巖以參知政事進筦樞密督</span>  
<span style="margin-left: 2em">視江淮軍馬書中稱其父訏謨兩社出董戎師厯</span>  
<span style="margin-left: 2em">官旣已相符又巖附和韓𠈁冑用兵敗衂御史劾</span>  
<span style="margin-left: 2em">其朋姦誤國奪官而書中謂其父惟主於和以靖</span>  
<span style="margin-left: 2em">國家或者不之察極力詆毁云云其言皆爲父辨</span>  
<span style="margin-left: 2em">白益足與巖事相證史又稱巖家本大梁徙揚州</span>  
<span style="margin-left: 2em">紹興末渡江居湖州考集中歸來詩有結亭苕水</span>  
<!-- 册4 葉1249b　Page:文淵閣四庫全書_0004冊.djvu/317 -->
<span style="margin-left: 2em">旁句江淮錄跋中亦有吾家近西塞語知其卜宅</span>  
<span style="margin-left: 2em">吳興尤爲<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">據至其生平宦蹟雖不盡詳以其詩</span>  
<span style="margin-left: 2em">文考之則嘗監常州犇牛鎭酒稅遷爲上虞丞尙</span>  
<span style="margin-left: 2em">畧見大槪也巖以諂媚權姦致位通顯爲世詬病</span>  
<span style="margin-left: 2em">而侃獨志𧼈蕭散浮沉末僚所與游者如趙師秀</span>  
<span style="margin-left: 2em">周文璞輩皆吟詠自適恬靜不爭之士故所作亦</span>  
<span style="margin-left: 2em">多淸雋圓穩時有閒澹之致雖未能開闢門徑自</span>  
<span style="margin-left: 2em">成一家而其集久佚僅存實爲世所未睹謹排訂</span>  
<span style="margin-left: 2em">編次釐爲六卷俾言宋詩者猶得以知其名氏焉</span>  
<!-- 册4 葉1252a　Page:文淵閣四庫全書_0004冊.djvu/318 -->
玉楮集八卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">宋岳珂撰珂有九經三傳沿革例已著錄此集凡</span>  
<span style="margin-left: 2em">詩三百八十五首其編年起理宗嘉熙戊戌迄於</span>  
<span style="margin-left: 2em">庚子珂桯史稱紹熙壬子年十歲則是集其五十</span>  
<span style="margin-left: 2em">八歲所編名曰玉楮葢取列子刻玉爲楮葉三年</span>  
<span style="margin-left: 2em">而成之意也考珂於紹定癸巳元夕京口觀燈因</span>  
<span style="margin-left: 2em">作詩及祐陵事韓正倫疑其借端諷己遂搆怨䧟</span>  
<span style="margin-left: 2em">以他罪會事白得釋至戊戌復召用故首篇冇五</span>  
<span style="margin-left: 2em">年坐奇謗之語他詩亦屢及此詩止錄此三年者</span>  
<!-- 册4 葉1252b　Page:文淵閣四庫全書_0004冊.djvu/318 -->
<span style="margin-left: 2em">其意實原於此自敘云木以不材壽雁以不鳴棄</span>  
<span style="margin-left: 2em">犧尊以靑黃喪大<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2826.svg?width=24" alt="四庫全書僻字第2826號（⿰夸𤓰 -- 瓠）" title="四庫全書僻字第2826號（⿰夸𤓰 -- 瓠）">以浮游取葢有<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3004.svg?width=24" alt="四庫全書僻字第3004號（慨）" title="四庫全書僻字第3004號（慨）">乎其言之</span>  
<span style="margin-left: 2em">也雖時傷淺露少詩人一唱三嘆之致而軒爽磊</span>  
<span style="margin-left: 2em">落氣格亦有可觀王士禎居易錄稱是集流傳絶</span>  
<span style="margin-left: 2em">少安邱張貞得高唐王家舊抄本乃錄而傳之葢</span>  
<span style="margin-left: 2em">亦罕覯之笈矣</span>
