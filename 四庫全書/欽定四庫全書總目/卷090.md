<span style="margin-left: 2em">史評𩔖存目二</span>  
世譜增定二卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明吕顓編顓字夢賔陜西寧州人嘉靖癸未進士</span>  
<span style="margin-left: 2em">官至應天府尹是編因陳璘所刋世譜一書益以</span>  
<span style="margin-left: 2em">司馬光厯年圖梁氏總論而以黃繼善提要割屬</span>  
<span style="margin-left: 2em">歴代之下以上古至東晉爲前卷劉宋至元爲後</span>  
<span style="margin-left: 2em">卷葢鄉塾課𫎇之本也</span>

帝鑑圖說<sub class="note-yuan">無卷數内府藏本</sub>  
<span style="margin-left: 2em">明張居正吕調陽同撰居正有書經直解已著錄</span>  
<span style="margin-left: 2em">調陽臨桂人嘉靖庚戊進士官至建極殿大學士</span>  
<span style="margin-left: 2em">諡文簡事迹具明史本傳是編乃二人奏御之書</span>  
<span style="margin-left: 2em">取堯舜以來善可爲法者八十一事惡可爲戒者</span>  
<span style="margin-left: 2em">三十六事每事前繪一圖後錄傳記本文而爲之</span>  
<span style="margin-left: 2em">直解前有隆慶六年十二月進疏一篇葢當神宗</span>  
<span style="margin-left: 2em">諒闇時也疏云善爲陽爲吉故數川九九惡爲陰</span>  
<span style="margin-left: 2em">爲㓙故數用六六取唐太宗以古爲鑑之語名之</span>  
<!-- 册2 葉3332a　Page:文淵閣四庫全書_0002冊.djvu/838 -->
<span style="margin-left: 2em">書中所載皆史册所有神宗方在冲齡語取易暁</span>  
<span style="margin-left: 2em">不免於俚俗</span>  
羣史品藻三十卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">明戴璟撰璟有廣東通志初稿已著錄是編取司</span>  
<span style="margin-left: 2em">馬光通鑑摘其事蹟爲之論斷其凡例云以通鑑</span>  
<span style="margin-left: 2em">節要爲主而摘其可爲論策命題者按千頃堂書</span>  
<span style="margin-left: 2em">目有宋江贄所撰資治通鑑節要又有元劉剡所</span>  
<span style="margin-left: 2em">撰資治通鑑節要皆三十卷未知璟所指何本然</span>  
<span style="margin-left: 2em">止爲命題而設則不出<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_0977.svg?width=24" alt="四庫全書僻字第977號（兔）" title="四庫全書僻字第977號（兔）">園册子之積習也</span>  
<!-- 册2 葉3332b　Page:文淵閣四庫全書_0002冊.djvu/838 -->
漢唐通鑑品藻三十卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">明戴璟撰是書明史藝文志著錄然卽璟所著讀</span>  
<span style="margin-left: 2em">史品藻坊本改易其名也書中起周威烈王終周</span>  
<span style="margin-left: 2em">世宗與通鑑首尾相應而以漢唐名書璟未必謬</span>  
<span style="margin-left: 2em">陋至此其出自庸妄書賈明矣</span>  
兩漢解疑二卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明唐順之撰順之有廣右戰功錄已著錄是編摘</span>  
<span style="margin-left: 2em">兩漢人物論其行事設爲問難而以己意解之大</span>  
<span style="margin-left: 2em">抵好爲異論務與前人相左如以紀信之代死爲</span>

<span style="margin-left: 2em">不足訓以漢高之斬丁公爲悖恩欺世之𩔖皆乖</span>  
<span style="margin-left: 2em">平允不足爲訓也</span>  
兩晉解疑一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明唐順之撰持論與所作兩漢解疑相𩔖而乖舛</span>  
<span style="margin-left: 2em">尤多如賈充一條稱秦檜有息民之功故得善終</span>  
<span style="margin-left: 2em">馮道和藹温柔故有長樂老之榮悖理殊甚順之</span>  
<span style="margin-left: 2em">學問文章具有根柢而論史之紕繆如此葢務欲</span>  
<span style="margin-left: 2em">出奇勝人而不知適所以自敗前明學者之通病</span>  
<span style="margin-left: 2em">也</span>  
<!-- 册2 葉3333b　Page:文淵閣四庫全書_0002冊.djvu/838 -->
覺山史說二卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">明洪垣撰垣字峻之婺源人覺山其號也嘉靖壬</span>  
<span style="margin-left: 2em">辰進士官至温州府知府事蹟具明史本傳又湛</span>  
<span style="margin-left: 2em">若水傳末稱湛氏門人最著者永豐李懷德安何</span>  
<span style="margin-left: 2em">遷婺源洪垣德安唐樞懷之言變化氣質遷之言</span>  
<span style="margin-left: 2em">知止樞之言求眞心大約出入王湛兩家之間而</span>  
<span style="margin-left: 2em">自爲一義垣則主於調停兩家而互救其失皆不</span>  
<span style="margin-left: 2em">盡守師說云云其講學之書今未之見是編其論</span>  
<span style="margin-left: 2em">史之書也所論起上古迄宋末如論伍員鞭墓之</span>  
<!-- 册2 葉3336a　Page:文淵閣四庫全書_0002冊.djvu/839 -->
<span style="margin-left: 2em">𩔖頗能主持名教他如論管叔蔡叔合於義而不</span>  
<span style="margin-left: 2em">知天命詆紀信代死爲吕祿辨𡨚之𩔖則不免文</span>  
<span style="margin-left: 2em">士好奇務爲新論至於論余闕死節一條斥闕不</span>  
<span style="margin-left: 2em">當仕元且以全家併命爲非是則紕繆至極無論</span>  
<span style="margin-left: 2em">闕本色目人實非南宋遺民垣於事實爲不考卽</span>  
<span style="margin-left: 2em">使闕之祖父果爲南宋遺民而是時元混一天下</span>  
<span style="margin-left: 2em">巳届百年踐士食毛久爲黎庶垣乃於數世之後</span>  
<span style="margin-left: 2em">使爲宋守故臣之節此於理不更悖乎</span>  
太史史例一百卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<!-- 册2 葉3336b　Page:文淵閣四庫全書_0002冊.djvu/839 -->
<span style="margin-left: 2em">明張之象撰之象字元超華亭人嘉靖中官浙江</span>  
<span style="margin-left: 2em">按察司知事明史文苑傳附載文徵明傳中是編</span>  
<span style="margin-left: 2em">取史記所書分𩔖標列爲二百八十七例摘其文</span>  
<span style="margin-left: 2em">以繫於各𩔖之後名目皆極瑣屑夫文字詳畧勢</span>  
<span style="margin-left: 2em">無定體本不可以例言况太史公成一家之書往</span>  
<span style="margin-left: 2em">往意在文外尤不得盡以定法拘之而之象乃毛</span>  
<span style="margin-left: 2em">舉細微以爲事事有例此又以說春秋家之窠臼</span>  
<span style="margin-left: 2em">移而論史矣</span>

<span style="margin-left: 2em">四十一條陶望齡爲之序書之上方及行旁皆有</span>

古史要評五卷<sub class="note-yuan">江西巡撫採進本</sub>  
<span style="margin-left: 2em">明吳崇節撰崇節字介甫弋陽人嘉靖甲子舉人</span>  
<span style="margin-left: 2em">官武岡縣知縣是編所載起周靈王迄南宋每事</span>  
<span style="margin-left: 2em">先標題目後載史文而斷以己意葢坊刻鑑纂鑑</span>  
<span style="margin-left: 2em">畧之𩔖而掛一漏萬茫無始末并不足以裨初學</span>

<span style="margin-left: 2em">人物尤爲偏謬</span>

<span style="margin-left: 2em">體</span>

<span style="margin-left: 2em">者簡書成於萬厯中一奇書又當在前耳一奇書</span>  
<span style="margin-left: 2em">五卷本名史談於諸史中摘錄事迹加以論斷皆</span>
