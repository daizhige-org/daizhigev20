## 欽定四庫全書總目 卷六十八　史部二十四　地理類一

<!-- 册2 葉1800：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷六十八  
<span style="margin-left: 1em">史部二十四</span>  
<span style="margin-left: 2em">地理類一</span>  
<span style="margin-left: 3em">古之地志載方域山川風俗物産而已其書今</span>  
<span style="margin-left: 3em">不可見然禹貢周禮職方氏其大較矣元和郡</span>  
<span style="margin-left: 3em">縣志頗渉古蹟葢用山海經例太平寰宇記增</span>  
<span style="margin-left: 3em">以人物又偶及藝文於是爲州縣志書之濫觴</span>  
<span style="margin-left: 3em">元明以後體例相沿列傳侔乎家牒藝文溢於</span>  
<span style="margin-left: 3em">總集末大於本而輿圖反若附錄其間假借夸</span>  
<!-- 册2 葉1801b　Page:文淵閣四庫全書_0002冊.djvu/455 -->
<span style="margin-left: 3em">飾以侈風土者抑又甚焉王士禎稱漢中府志</span>  
<span style="margin-left: 3em">載木牛流馬法武功縣志載織錦璇璣圖此文</span>  
<span style="margin-left: 3em">士愛博之談非古法也然踵事增華勢難遽返</span>  
<span style="margin-left: 3em">今惟去泰去甚擇尤雅者錄之凡蕪濫之篇皆</span>  
<span style="margin-left: 3em">斥而存目其編類首宫殿䟽尊宸居也次總志</span>  
<span style="margin-left: 3em">大一統也次都會郡縣辨方域也次河防次邊</span>  
<span style="margin-left: 3em">防崇實用也次山川次古蹟次雜記次遊記備</span>  
<span style="margin-left: 3em">考核也次外紀廣見聞也若夫山海經十洲記</span>  
<span style="margin-left: 3em">之屬體雜小說則各從其本類兹不錄焉</span>  
<!-- 册2 葉1804a　Page:文淵閣四庫全書_0002冊.djvu/456 -->
三輔黃圖六巻<sub class="note-yuan">編修勵守謙家藏本</sub>  
<span style="margin-left: 2em">不著撰人名氏晁公武讀書志據所引劉昭續漢</span>  
<span style="margin-left: 2em">志註定爲梁陳間人作程大昌雍錄則謂晉灼所</span>  
<span style="margin-left: 2em">引黃圖多不見於今本而今本漸臺彪池高廟元</span>  
<span style="margin-left: 2em">始祭社稷儀皆明引舊圖知非晉灼之所見又據</span>  
<span style="margin-left: 2em">改槐里爲興平事在至德二載知爲唐肅宗以後</span>  
<span style="margin-left: 2em">人作其說較公武爲有據此本惟高廟一條不引</span>  
<span style="margin-left: 2em">舊圖滄池一條引舊圖而大昌未及其餘三條並</span>  
<span style="margin-left: 2em">同葢卽大昌所見之本偶悞滄池爲高廟也其書</span>  
<!-- 册2 葉1804b　Page:文淵閣四庫全書_0002冊.djvu/456 -->
<span style="margin-left: 2em">皆記長安古迹間及周靈臺靈囿諸事然以漢爲</span>  
<span style="margin-left: 2em">主亦間及河間日華宫梁曜華宮諸事而以京師</span>  
<span style="margin-left: 2em">爲主故稱三輔黃圖三輔者顔師古漢書註謂長</span>  
<span style="margin-left: 2em">安以東爲京兆以北爲左馮翊渭城以西爲右扶</span>  
<span style="margin-left: 2em">風也所紀宫殿苑囿之制條分縷析至爲詳備考</span>  
<span style="margin-left: 2em">古者恒所取資惟兼取西京雜記漢武故事諸僞</span>  
<span style="margin-left: 2em">書洞㝠記拾遺記諸雜說愛博嗜竒轉失精核不</span>  
<span style="margin-left: 2em">免爲白璧徴瑕耳</span>  
禁扁五巻<sub class="note-yuan">兩江總督採進本</sub>  
<!-- 册2 葉1805a　Page:文淵閣四庫全書_0002冊.djvu/456 -->
<span style="margin-left: 2em">元王士㸃撰士㸃字繼志東平人是書凡爲目百</span>  
<span style="margin-left: 2em">一十有六篇一十有五釐爲甲乙丙丁戊五巻考</span>  
<span style="margin-left: 2em">何晏景福殿賦云爰有禁楄勒分翼張注引說文</span>  
<span style="margin-left: 2em">扁從戸册者署門戸也扁與楄同此書詳載歴代</span>  
<span style="margin-left: 2em">宫殿門觀池館苑籞等名故取義於此巻首有歐</span>  
<span style="margin-left: 2em">陽元至順庚午序虞集至順癸酉序皆以詳贍推</span>  
<span style="margin-left: 2em">之其中如釋東西箱以西淸附之葢本前漢司馬</span>  
<span style="margin-left: 2em">相如傳注謂西淸卽西箱也而其釋東西序則與</span>  
<span style="margin-left: 2em">東西箱别爲一類不知景福殿賦西箱踟蹰以開</span>  
<!-- 册2 葉1805b　Page:文淵閣四庫全書_0002冊.djvu/456 -->
<span style="margin-left: 2em">宴東序重深而秘奥註西箱西序也東序東箱也</span>  
<span style="margin-left: 2em">本屬互文而析爲兩地則於宫室之制殊未能詳</span>  
<span style="margin-left: 2em">考又如釋秦雲陽宫一名林光一名甘泉考程大</span>  
<span style="margin-left: 2em">昌雍錄漢之甘泉在渭北之雲陽秦之甘泉在渭</span>  
<span style="margin-left: 2em">南之鄠縣謂秦甘泉一名雲陽殊誤又孟康郊祀</span>  
<span style="margin-left: 2em">志注漢甘泉一名林光師古謂漢於秦林光宫旁</span>  
<span style="margin-left: 2em">别起甘泉宫謂漢甘泉一名林光亦非則於地理</span>  
<span style="margin-left: 2em">之學亦不免偶疎至於秦祈年宫三輔黃圖以爲</span>  
<span style="margin-left: 2em">穆公作此書獨本漢書及水經註之說以爲作於</span>  
<!-- 册2 葉1808a　Page:文淵閣四庫全書_0002冊.djvu/457 -->
<span style="margin-left: 2em">惠公似非無見又若曲臺宫之類兼採雍錄以補</span>  
<span style="margin-left: 2em">黃圖之所遺頗可藉以叅考末附名釋一篇訓詁</span>  
<span style="margin-left: 2em">亦極典核雖時有疎密要於史學不爲無補矣</span>  
<span style="margin-left: 1em">右地理類宫殿疏之屬二部十一巻皆文淵閣著錄</span>  
<span style="margin-left: 4em">案太平御覽所引有漢宫殿疏劉知幾史通</span>  
<span style="margin-left: 4em">所引有晉宫闕名皆自爲記載不與地志相</span>  
<span style="margin-left: 4em">雜今别立子目冠於地理類之首</span>  
元和郡縣志四十巻<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">唐李吉甫撰吉甫字宏憲趙州人御史大夫栖筠</span>  
<!-- 册2 葉1808b　Page:文淵閣四庫全書_0002冊.djvu/457 -->
<span style="margin-left: 2em">之子以蔭補左司禦率府倉曹參軍貞元初爲太</span>  
<span style="margin-left: 2em">常博士官至中書侍郞同中書門下平章事卒謚</span>  
<span style="margin-left: 2em">忠懿事迹具唐書本傳是書據宋洪邁䟦稱爲元</span>  
<span style="margin-left: 2em">和八年所上然書中更置宥州一條乃在元和九</span>  
<span style="margin-left: 2em">年葢其事爲吉甫所經畫故書成之後又自續入</span>  
<span style="margin-left: 2em">之也前有吉甫原序稱起京兆府盡隴右道凡四</span>  
<span style="margin-left: 2em">十七鎭成四十巻每鎭皆圖在篇首冠於叙事之</span>  
<span style="margin-left: 2em">前並目錄兩巻共成四十二巻故名曰元和郡縣</span>  
<span style="margin-left: 2em">圖志後有淳熙二年程大昌䟦稱圖至今已亡獨</span>  
<!-- 册2 葉1809a　Page:文淵閣四庫全書_0002冊.djvu/457 -->
<span style="margin-left: 2em">志存焉故書錄解題惟稱元和郡縣志四十巻此</span>  
<span style="margin-left: 2em">本又闕第十九巻二十巻二十三巻二十四卷二</span>  
<span style="margin-left: 2em">十六卷三十六巻其第十八巻則闕其半二十五</span>  
<span style="margin-left: 2em">巻亦闕二頁又非宋本之舊矣篇目斷續頗難尋</span>  
<span style="margin-left: 2em">檢考水經註本四十巻至宋代佚其五巻故水名</span>  
<span style="margin-left: 2em">闕二十有一南宋刋版仍均配爲四十巻使相聯</span>  
<span style="margin-left: 2em">屬今用其例亦重編爲四十巻以便循覽仍註其</span>  
<span style="margin-left: 2em">所闕於巻中以存舊第其書唐志作五十四巻證</span>  
<span style="margin-left: 2em">以吉甫之原序葢志之誤又按唐六典及新舊唐</span>  
<!-- 册2 葉1809b　Page:文淵閣四庫全書_0002冊.djvu/457 -->
<span style="margin-left: 2em">書地理志貞觀初分天下爲十道一關内道二河</span>  
<span style="margin-left: 2em">南道三河東道四河北道五山南道六隴右道七</span>  
<span style="margin-left: 2em">淮南道八江南道九劍南道十嶺南道此書移隴</span>  
<span style="margin-left: 2em">右爲第十殆以中葉後陷没吐蕃故退以爲殿至</span>  
<span style="margin-left: 2em">淮南一道在今本闕巻之中以唐志淮南道所屬</span>  
<span style="margin-left: 2em">諸州考之今本河南道内有所屬申光二州列蔡</span>  
<span style="margin-left: 2em">州之後江南道内有所屬之蘄黃安三州列鄂沔</span>  
<span style="margin-left: 2em">二州之後似乎傳寫之錯簡然考唐書方鎭表大</span>  
<span style="margin-left: 2em">厯十四年淮西節度使復治蔡州尋更號申光蔡</span>  
<!-- 册2 葉1812a　Page:文淵閣四庫全書_0002冊.djvu/458 -->
<span style="margin-left: 2em">節度使又永泰元年蘄黃二州𨽻鄂岳節度升鄂</span>  
<span style="margin-left: 2em">州都團練使爲觀察使增領岳蘄黃三州元和元</span>  
<span style="margin-left: 2em">年升鄂州觀察使爲武昌軍節度使增領安黃二</span>  
<span style="margin-left: 2em">州則申州光州嘗由淮南道割𨽻河南道蘄州安</span>  
<span style="margin-left: 2em">州黃州亦嘗由淮南道割𨽻江南道唐志偶失移</span>  
<span style="margin-left: 2em">併非今本錯亂也輿記圖經隋唐志所著錄者率</span>  
<span style="margin-left: 2em">散佚無存其傳於今者惟此書爲最古其體例亦</span>  
<span style="margin-left: 2em">爲最善後來雖遞相損益無能出其範圍今錄以</span>  
<span style="margin-left: 2em">冠地理總志之首著諸家祖述之所自焉</span>  
<!-- 册2 葉1812b　Page:文淵閣四庫全書_0002冊.djvu/458 -->
太平寰宇記一百九十三巻<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">宋樂史撰史有廣卓異記已著錄宋太宗時始平</span>  
<span style="margin-left: 2em">閩越并北漢史因合輿圖所𨽻考尋始末條分件</span>  
<span style="margin-left: 2em">繫以成此書始於東京迄於四裔然是時幽嬀營</span>  
<span style="margin-left: 2em">檀等十六州晉所割以賂遼者實未入昄章史乃</span>  
<span style="margin-left: 2em">因賈耽十道志李吉甫元和郡縣志之舊槪列其</span>  
<span style="margin-left: 2em">名葢太宗置封樁庫冀復燕雲終身未嘗少置史</span>  
<span style="margin-left: 2em">亦預探其志載之於篇非無所因而漫錄也史進</span>  
<span style="margin-left: 2em">書序譏賈耽李吉甫爲漏缺故其書采摭繁富惟</span>  
<!-- 册2 葉1813a　Page:文淵閣四庫全書_0002冊.djvu/458 -->
<span style="margin-left: 2em">取賅博於列朝人物一一並登至於題詠古蹟若</span>  
<span style="margin-left: 2em">張祐金山詩之類亦皆並錄後來方志必列人物</span>  
<span style="margin-left: 2em">藝文者其體皆始於史葢地理之書記載至是書</span>  
<span style="margin-left: 2em">而始詳體例亦自是而大變然史書雖巻帙浩博</span>  
<span style="margin-left: 2em">而考據特爲精核要不得以末流冗雜追咎濫觴</span>  
<span style="margin-left: 2em">之源矣原本二百巻諸家藏本並多殘缺惟浙江</span>  
<span style="margin-left: 2em">汪氏進本所闕自一百十三巻至一百十九巻僅</span>  
<span style="margin-left: 2em">佚七巻又每巻末附校正一頁不知何人所作辨</span>  
<span style="margin-left: 2em">析頗詳較諸本最爲精善今據以著錄文獻通考</span>  
<!-- 册2 葉1813b　Page:文淵閣四庫全書_0002冊.djvu/458 -->
<span style="margin-left: 2em">作太平寰字志此本標題實作太平寰宇記諸書</span>  
<span style="margin-left: 2em">所引名亦兩岐今考史進書原序亦作記字則通</span>  
<span style="margin-left: 2em">考爲傳寫之誤不足據也</span>  
元豐九域志十巻<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">宋承議郞知制誥丹陽王存等奉勅撰存字敬仲</span>  
<span style="margin-left: 2em">丹陽人登進士第調嘉興主簿歴官尙書右丞事</span>  
<span style="margin-left: 2em">蹟具宋史本傳初祥符中李宗諤王曾先後修九</span>  
<span style="margin-left: 2em">域圖至熙寧八年都官員外郞劉師旦以州縣名</span>  
<span style="margin-left: 2em">號多有改易奏乞重修乃命館閣校勘曾肇光祿</span>  
<!-- 册2 葉1816a　Page:文淵閣四庫全書_0002冊.djvu/459 -->
<span style="margin-left: 2em">丞李德芻刪定而以存總其事以舊書名圖而無</span>  
<span style="margin-left: 2em">繪圖請改曰志迄元豐三年閏九月書成此本前</span>  
<span style="margin-left: 2em">有存等進書原序稱國朝以來州縣廢置與夫鎭</span>  
<span style="margin-left: 2em">戍城堡之名山澤虞衡之利前書所畧則謹志之</span>  
<span style="margin-left: 2em">至於道里廣輪之數昔人罕得其詳今則一州之</span>  
<span style="margin-left: 2em">内首叙州封次及旁郡彼此互舉弗相混殽總二</span>  
<span style="margin-left: 2em">十三路京府四次府十州二百四十二軍三十七</span>  
<span style="margin-left: 2em">監四縣一千二百三十五釐爲十巻王應麟稱其</span>  
<span style="margin-left: 2em">文見於曲阜集葢曾肇之詞也其書始於四京終</span>
