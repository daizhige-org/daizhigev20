## 欽定四庫全書總目 卷一百一　子部十一　法家類、法家類存目

<!-- 册3 葉708a　Page:文淵閣四庫全書_0003冊.djvu/182 -->
欽定四庫全書總目卷一百一  
<span style="margin-left: 1em">子部十一</span>  
<span style="margin-left: 2em">法家𩔖</span>  
<span style="margin-left: 3em">刑名之學起於周季其術爲</span>  
聖世所不取然流覽遺篇兼資法戒觀於管仲諸家可  
<span style="margin-left: 3em">以知近功小利之隘觀於商鞅韓非諸家可以</span>  
<span style="margin-left: 3em">知刻薄寡恩之非鑒彼前車卽所以克端治本</span>  
<span style="margin-left: 3em">曾鞏所謂不滅其籍乃善於放絶者歟至於凝</span>  
<span style="margin-left: 3em">㠓所編<sub class="note-yuan">和凝和㠓父子相繼撰疑獄集</sub>闡明疑獄桂吳所錄<sub class="note-yuan">桂萬</sub></span>  
<!-- 册3 葉708b　Page:文淵閣四庫全書_0003冊.djvu/182 -->
<span style="margin-left: 3em"><sub class="note-yuan">榮吳訥相續撰棠陰比事</sub>矜愼祥刑並義取持平道資弼教</span>  
<span style="margin-left: 3em">雖𩔖從而錄均𨽻法家然立義不同用心各異</span>  
<span style="margin-left: 3em">於虞廷欽恤亦屬有裨是以仍凖舊史錄此一</span>  
<span style="margin-left: 3em">家焉</span>  
管子二十四卷<sub class="note-yuan">大理寺卿陸錫熊家藏本</sub>  
<span style="margin-left: 2em">舊本題管仲𢰅劉恕通鑑外紀引傅子曰管仲之</span>  
<span style="margin-left: 2em">書過半便是後之好事所加乃說管仲死後事輕</span>  
<span style="margin-left: 2em">重篇尤復鄙俗葉適水心集亦曰管子非一人之</span>  
<span style="margin-left: 2em">筆亦非一時之書以其言毛嬙西施吳王好劍推</span>  
<!-- 册3 葉709a　Page:文淵閣四庫全書_0003冊.djvu/182 -->
<span style="margin-left: 2em">之當是春秋末年今考其文大抵後人附會多於</span>  
<span style="margin-left: 2em">仲之本書其他姑無論卽仲卒於桓公之前而篇</span>  
<span style="margin-left: 2em">中處處稱桓公其不出仲手巳無疑義矣書中稱</span>  
<span style="margin-left: 2em">經言者九篇稱外言者八篇稱内言者九篇稱短</span>  
<span style="margin-left: 2em">語者十九篇稱區言者五篇稱雜篇者十一篇稱</span>  
<span style="margin-left: 2em">管子解者五篇稱管子輕重者十九篇意其中孰</span>  
<span style="margin-left: 2em">爲手𢰅孰爲記其緒言如語錄之𩔖孰爲述其逸</span>  
<span style="margin-left: 2em">事如家傳之𩔖孰爲推其義旨如箋疏之𩔖當時</span>  
<span style="margin-left: 2em">必有分别觀其五篇明題管子解者可以類推必</span>  
<!-- 册3 葉709b　Page:文淵閣四庫全書_0003冊.djvu/182 -->
<span style="margin-left: 2em">由後人混而一之致滋疑竇耳晁公武讀書志曰</span>  
<span style="margin-left: 2em">劉向所校本八十六篇今亡十篇考李善註陸機</span>  
<span style="margin-left: 2em">猛虎行曰江邃文釋引管子云夫士懷耿介之心</span>  
<span style="margin-left: 2em">不蔭惡木之枝惡木尚能恥之况與惡人同處今</span>  
<span style="margin-left: 2em">檢管子近亡數篇恐是亡篇之内而邃見之則唐</span>  
<span style="margin-left: 2em">初巳非完本矣明梅士享所刊又復顚倒其篇次</span>  
<span style="margin-left: 2em">如以牧民解附牧民篇下形𫝑解附形𫝑篇下之</span>  
<span style="margin-left: 2em">𩔖不一而足彌爲竄亂失眞此本爲萬厯壬午趙</span>  
<span style="margin-left: 2em">用賢所刊稱由宋本翻雕前有紹興己未張嵲後</span>  
<!-- 册3 葉712a　Page:文淵閣四庫全書_0003冊.djvu/183 -->
<span style="margin-left: 2em">跋云舛脫甚衆頗爲是正用賢序又云正其脫誤</span>  
<span style="margin-left: 2em">者逾三萬言則屢經㸃竄巳非劉向所校之舊然</span>  
<span style="margin-left: 2em">終逾於他氏所妄更者在近代猶善本也舊有房</span>  
<span style="margin-left: 2em">元齡註晁公武以爲尹知章所託然考唐書藝文</span>  
<span style="margin-left: 2em">志元齡注管子不著錄而所載有尹知章注管子</span>  
<span style="margin-left: 2em">三十巻則知章本未託名殆後人以知章人㣲元</span>  
<span style="margin-left: 2em">齡名重改題之以<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3271.svg?width=24" alt="四庫全書僻字第3271號（炫）" title="四庫全書僻字第3271號（炫）">俗耳案舊唐書知章綘州翼</span>  
<span style="margin-left: 2em">城人神龍初官太常博士睿宗卽位拜禮部員外</span>  
<span style="margin-left: 2em">郎轉國子博士有孝經注老子注今並不傳惟此</span>  
<!-- 册3 葉712b　Page:文淵閣四庫全書_0003冊.djvu/183 -->
<span style="margin-left: 2em">注藉元齡之名以存其文淺陋頗不足采然蔡絛</span>  
<span style="margin-left: 2em">鐵圍山叢談載蘇軾蘇轍同入省試有一題軾不</span>  
<span style="margin-left: 2em">得其出處轍以筆一卓而以口吹之軾因悟出管</span>  
<span style="margin-left: 2em">子註則宋時亦採以命題試士矣且古來無他注</span>  
<span style="margin-left: 2em">本明劉績所補注亦僅小有紏正未足相代故仍</span>  
<span style="margin-left: 2em">舊本錄之焉</span>  
管子補注二十四巻<sub class="note-yuan">編修勵守謙家藏本</sub>  
<span style="margin-left: 2em">明劉績撰績有三禮圖巳著錄管子舊註頗爲疎</span>  
<span style="margin-left: 2em">畧故宋張嵲跋其後曰管子書多古字如專作摶</span>  
<!-- 册3 葉713a　Page:文淵閣四庫全書_0003冊.djvu/183 -->
<span style="margin-left: 2em">忒作貣宥作侑况作兄釋作澤此類甚衆大匡載</span>  
<span style="margin-left: 2em">召忽語曰雖得天下吾不生也兄與我齊國之政</span>  
<span style="margin-left: 2em">也註乃謂召忽呼管仲爲兄曰澤命不渝注乃以</span>  
<span style="margin-left: 2em">爲恩澤之命不可徧舉黃震日抄亦曰管子注釋</span>  
<span style="margin-left: 2em">最多牴牾四傷之篇誤名百匿而以四傷名七法</span>  
<span style="margin-left: 2em">之篇幼官篇首章云若因夜虛守靜人物則皇其</span>  
<span style="margin-left: 2em">後方之圖本可覆也乃衍人物二字不知叅對以</span>  
<span style="margin-left: 2em">夜虛爲句守靜人物自爲句方以人物則皇爲句</span>  
<span style="margin-left: 2em">而曲爲之說曰聽候人物也幼官五圖以形生理</span>  
<!-- 册3 葉713b　Page:文淵閣四庫全書_0003冊.djvu/183 -->
<span style="margin-left: 2em">爲句而中央之註獨以形生屬上文明法篇以比</span>  
<span style="margin-left: 2em">周以相匿爲句而下又云忘主死交其後方之明</span>  
<span style="margin-left: 2em">法解可覆也乃以相爲匿是爲句而曲爲之說曰</span>  
<span style="margin-left: 2em">匿公是而不行也五法之章曰天下不患無財患</span>  
<span style="margin-left: 2em">無人以分之分如分地之利之分乃釋云可以分</span>  
<span style="margin-left: 2em">與財者賢人也立政之章曰道塗無行禽指人言</span>  
<span style="margin-left: 2em">之謂其爲能行之禽耳乃釋云無禽獸之行版法</span>  
<span style="margin-left: 2em">篇云悅在施愛有衆在廢私今因缺文而云悅在</span>  
<span style="margin-left: 2em">施有衆在廢私不成文矣云云其抉摘皆中理績</span>  
<!-- 册3 葉716a　Page:文淵閣四庫全書_0003冊.djvu/184 -->
<span style="margin-left: 2em">本之以作是註故於舊解頗有匡正皆附於原註</span>  
<span style="margin-left: 2em">之後以績按別之雖其循文詮解於訓詁亦罕所</span>  
<span style="margin-left: 2em">考訂而推求意義務求明愜較原註所得則巳多</span>  
<span style="margin-left: 2em">矣案明有兩劉績一爲山陰人字孟熙千頃堂書</span>  
<span style="margin-left: 2em">目載此書於績名下注江夏人則爲字用熙者無</span>  
<span style="margin-left: 2em">疑坊刻或題曰宋劉績誤也</span>  
鄧析子一巻<sub class="note-yuan">少詹事陸費墀家藏本</sub>  
<span style="margin-left: 2em">周鄧析撰析鄭人列子力命篇曰鄧析操兩可之</span>  
<span style="margin-left: 2em">說設無窮之詞子産執政作竹刑鄭國用之數難</span>  
<!-- 册3 葉716b　Page:文淵閣四庫全書_0003冊.djvu/184 -->
<span style="margin-left: 2em">子産之治子産屈之子産執而戮之俄而誅之劉</span>  
<span style="margin-left: 2em">歆奏上其書<sub class="note-yuan">案高似孫子畧誤以此奏爲劉向今據書錄解題改正</sub>則曰於</span>  
<span style="margin-left: 2em">春秋左氏傳昭公二十年而子産卒子太叔嗣爲</span>  
<span style="margin-left: 2em">政定公八年太叔卒駟歂嗣爲政明年乃殺鄧析</span>  
<span style="margin-left: 2em">而用其竹刑然則列子爲誤矣其書漢志作二篇</span>  
<span style="margin-left: 2em">今本仍分無厚轉辭二篇而併爲一巻然其文節</span>  
<span style="margin-left: 2em">次不相屬似亦掇拾之本也其言如天於人無厚</span>  
<span style="margin-left: 2em">君於民無厚父於子無厚兄於弟無厚𫝑者君之</span>  
<span style="margin-left: 2em">輿威者君之䇿則其旨同於申韓如令煩則民詐</span>  
<!-- 册3 葉717a　Page:文淵閣四庫全書_0003冊.djvu/184 -->
<span style="margin-left: 2em">政擾則民不定心欲安靜慮欲深遠則其旨同於</span>  
<span style="margin-left: 2em">黃老然其大旨主於𫝑統於尊事覈於實於法家</span>  
<span style="margin-left: 2em">爲近故竹刑爲鄭所用也至於聖人不死大盜不</span>  
<span style="margin-left: 2em">止一條其文與莊子同析遠在莊周以前不應預</span>  
<span style="margin-left: 2em">有勦說而莊子所載又不云鄧析之言或篇章殘</span>  
<span style="margin-left: 2em">缺後人摭莊子以足之歟</span>  
商子五巻<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">舊本題秦商鞅撰鞅事迹具史記鞅封於商號商</span>  
<span style="margin-left: 2em">君故漢志稱商君二十九篇三國志先主傳註亦</span>  
<!-- 册3 葉717b　Page:文淵閣四庫全書_0003冊.djvu/184 -->
<span style="margin-left: 2em">稱啇君書其稱商子則自隋志始也陳振孫書錄</span>  
<span style="margin-left: 2em">解題云漢志二十九篇今二十八篇已亡其一晁</span>  
<span style="margin-left: 2em">公武讀書志則云本二十九篇今亡者三篇讀書</span>  
<span style="margin-left: 2em">志成於紹興二十一年旣云已缺三篇書錄解題</span>  
<span style="margin-left: 2em">成於宋末乃反較晁本多二篇殆兩家所錄各據</span>  
<span style="margin-left: 2em">所見之本故多寡不同歟此本自更法至定分目</span>  
<span style="margin-left: 2em">凡二十有六似卽晁氏之本然其中第十六篇第</span>  
<span style="margin-left: 2em">二十一篇又皆有錄無書則併非宋本之舊矣史</span>  
<span style="margin-left: 2em">記稱讀鞅開塞書在今本爲第七篇文義甚明而</span>  
<!-- 册3 葉720a　Page:文淵閣四庫全書_0003冊.djvu/185 -->
<span style="margin-left: 2em">司馬貞作索隱乃妄爲之解爲晁公武所譏知其</span>  
<span style="margin-left: 2em">書唐代不甚行故貞不及睹又文獻通考引周氏</span>  
<span style="margin-left: 2em">渉筆以爲鞅書多附會後事擬取他詞非本所論</span>  
<span style="margin-left: 2em">著然周氏特據文臆斷未能確證其非今考史記</span>  
<span style="margin-left: 2em">稱秦孝公卒太子立公子䖍之徒告鞅欲反惠王</span>  
<span style="margin-left: 2em">乃車裂鞅以徇則孝公卒後鞅卽逃死不暇安得</span>  
<span style="margin-left: 2em">著書如爲平日所著則必在孝公之世又安得開</span>  
<span style="margin-left: 2em">巻第一篇卽稱孝公之諡殆法家者流掇鞅餘論</span>  
<span style="margin-left: 2em">以成是編猶管子卒於齊桓公前而書中屢稱桓</span>  
<!-- 册3 葉720b　Page:文淵閣四庫全書_0003冊.djvu/185 -->
<span style="margin-left: 2em">公耳諸子之書如是者多旣不得撰者之主名則</span>  
<span style="margin-left: 2em">亦姑從其舊仍題所託之人矣</span>  
韓子二十巻<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">周韓非撰漢書藝文志載韓子五十五篇張守節</span>  
<span style="margin-left: 2em">史記正義引阮孝緖七錄載韓子二十巻篇數巻</span>  
<span style="margin-left: 2em">數皆與今本相符惟王應麟漢藝文志考作五十</span>  
<span style="margin-left: 2em">六篇殆傳寫字誤也其注不知何人作考元至元</span>  
<span style="margin-left: 2em">三年何犿本稱舊有李瓚註鄙陋無取盡爲削去</span>  
<span style="margin-left: 2em">云云則註者當爲李瓚然瓚爲何代人犿未之言</span>  
<!-- 册3 葉721a　Page:文淵閣四庫全書_0003冊.djvu/185 -->
<span style="margin-left: 2em">王應麟玉海巳稱韓子註不知誰作諸書亦別無</span>  
<span style="margin-left: 2em">李瓚註韓子之文不知犿何所據也犿本僅五十</span>  
<span style="margin-left: 2em">三篇其序稱内佚姦劫一篇說林下一篇及内儲</span>  
<span style="margin-left: 2em">說下六㣲内似煩以下數章明萬厯十年趙用賢</span>  
<span style="margin-left: 2em">購得宋槧與犿本相校始知舊本六㣲篇之末尚</span>  
<span style="margin-left: 2em">有二十八條不止犿所云數章說林下篇之首尚</span>  
<span style="margin-left: 2em">有伯樂教二人相踶馬等十六章諸本佚脫其文</span>  
<span style="margin-left: 2em">以說林上篇田伯鼎好士章逕接此篇蟲有蚘章</span>  
<span style="margin-left: 2em">和氏篇之末自和雖獻璞而未美未爲王之害也</span>  
<!-- 册3 葉721b　Page:文淵閣四庫全書_0003冊.djvu/185 -->
<span style="margin-left: 2em">以下脫三百九十六字姦劫篇之首自我以淸廉</span>  
<span style="margin-left: 2em">事上以上脫四百六十字其脫葉適在兩篇之間</span>
