## 欽定四庫全書總目 卷十九　經部十九　禮類一

<!-- 册1 葉1552：整葉圖版，無文字記錄 -->
<!-- 册1 葉1553a　Page:文淵閣四庫全書_0001冊.djvu/438 -->
欽定四庫全書總目卷十九  
<span style="margin-left: 1em">經部十九</span>  
<span style="margin-left: 2em">禮類一</span>  
<span style="margin-left: 3em">古稱議禮如聚訟然儀禮難讀儒者罕通不能</span>  
<span style="margin-left: 3em">聚訟禮記輯自漢需某增某減具有主名亦無</span>  
<span style="margin-left: 3em">庸聚訟所辨論求勝者周禮一書而已考大司</span>  
<span style="margin-left: 3em">樂章先見於魏文侯時理不容僞河間獻王但</span>  
<span style="margin-left: 3em">言闕冬官一篇不言簡編失次則竄亂移補者</span>  
<span style="margin-left: 3em">亦妄三禮並立一從古六無可疑也鄭康成注</span>  
<!-- 册1 葉1553b　Page:文淵閣四庫全書_0001冊.djvu/438 -->
<span style="margin-left: 3em">賈公彦孔頴達疏於名物度數特詳宋儒攻擊</span>  
<span style="margin-left: 3em">僅摭其好引䜟緯一失至其訓詁則弗能踰越</span>  
<span style="margin-left: 3em">蓋得其節文乃可推制作之精意不比孝經論</span>  
<span style="margin-left: 3em">語可推尋文句而談本漢唐之注疏而佐以宋</span>  
<span style="margin-left: 3em">儒之義理亦無可疑也謹以類區分定爲六目</span>  
<span style="margin-left: 3em">曰周禮曰儀禮曰禮記曰三禮總義曰通禮曰</span>  
<span style="margin-left: 3em">雜禮書六目之中各以時代爲先後庶源流同</span>  
<span style="margin-left: 3em">異可比而考焉</span>  
周禮注疏四十二卷<sub class="note-yuan">内府藏本</sub>  
<!-- 册1 葉1556a　Page:文淵閣四庫全書_0001冊.djvu/439 -->
<span style="margin-left: 2em">漢鄭元注唐賈公彦疏元有易注巳著錄公彦洛</span>  
<span style="margin-left: 2em">州永年人永徽中官至太學博士事迹具舊唐書</span>  
<span style="margin-left: 2em">儒學傳周禮一書上自河間獻王於諸經之中其</span>  
<span style="margin-left: 2em">出最晚其眞僞亦紛如聚訟不可縷舉惟橫渠語</span>  
<span style="margin-left: 2em">錄曰周禮是的當之書然其間必有末世增入者</span>  
<span style="margin-left: 2em">鄭樵通志引孫處之言曰周公居攝六年之後書</span>  
<span style="margin-left: 2em">成歸豐而實未嘗行葢周公之爲周禮亦猶唐之</span>  
<span style="margin-left: 2em">顯慶開元禮預爲之以待他日之用其實未嘗行</span>  
<span style="margin-left: 2em">也惟其未經行故僅述大畧俟其臨事而損益之</span>  
<!-- 册1 葉1556b　Page:文淵閣四庫全書_0001冊.djvu/439 -->
<span style="margin-left: 2em">故建都之制不與召誥洛誥合封國之制不與武</span>  
<span style="margin-left: 2em">成孟子合設官之制不與周官合九畿之制不與</span>  
<span style="margin-left: 2em">禹貢合云云<sub class="note-yuan">案此條所云惟召誥洛誥武成孟子顯相舛異至禹貢乃唐虞之制周官</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">乃梅賾古文尚書王制乃漢文帝博士所追述皆不足以爲難其說蓋離合㕘半</sub>其說差</span>  
<span style="margin-left: 2em">爲近之然亦未盡也夫周禮作於周初而周事之</span>  
<span style="margin-left: 2em">可考者不過春秋以後其東遷以前三百餘年官</span>  
<span style="margin-left: 2em">制之沿革政典之損益除舊布新不知凡幾其初</span>  
<span style="margin-left: 2em">去成康未遠不過因其舊章稍爲改易而改易之</span>  
<span style="margin-left: 2em">人不皆周公也於是以後世之法竄入之其書遂</span>  
<!-- 册1 葉1557a　Page:文淵閣四庫全書_0001冊.djvu/439 -->
<span style="margin-left: 2em">雜其後去之愈遠時移勢變不可行者漸多其書</span>  
<span style="margin-left: 2em">遂廢此亦如後世律令條格率數十年而一修修</span>  
<span style="margin-left: 2em">則必有所附益特世近者可考年遠者無徵其增</span>  
<span style="margin-left: 2em">刪之迹遂靡所稽統以爲周公之舊耳迨乎法制</span>  
<span style="margin-left: 2em">旣更簡編猶在好古者留爲文獻故其書閱久而</span>  
<span style="margin-left: 2em">仍存此又如開元六典政和五禮在當代巳不行</span>  
<span style="margin-left: 2em">用而今日尚有傳本不足異也使其作僞何不全</span>  
<span style="margin-left: 2em">僞六官而必闕其一至以千金購之不得哉且作</span>  
<span style="margin-left: 2em">僞者必剽取舊文借眞者以實其贋古文尚書是</span>  
<!-- 册1 葉1557b　Page:文淵閣四庫全書_0001冊.djvu/439 -->
<span style="margin-left: 2em">也劉歆宗左傳而左傳所云禮經皆不見於周禮</span>  
<span style="margin-left: 2em">儀禮十七篇皆在七畧所載古經七十篇中禮記</span>  
<span style="margin-left: 2em">四十九篇亦在劉向所錄二百十四篇中而儀禮</span>  
<span style="margin-left: 2em">聘禮賔行饔餼之物禾米芻薪之數籩豆簠簋之</span>  
<span style="margin-left: 2em">實鉶壺鼎甕之列與掌客之文不同又大射禮天</span>  
<span style="margin-left: 2em">子諸侯侯數侯制與司射之文不同禮記雜記載</span>  
<span style="margin-left: 2em">子男執圭與典瑞之文不同禮器天子諸侯席數</span>  
<span style="margin-left: 2em">與司几筵之文不同如斯之類與二禮多相矛盾</span>  
<span style="margin-left: 2em">歆果贋託周公爲此書又何難牽就其文使與經</span>  
<!-- 册1 葉1560a　Page:文淵閣四庫全書_0001冊.djvu/440 -->
<span style="margin-left: 2em">傳相合以相證騐而必留此異同以啟後人之攻</span>  
<span style="margin-left: 2em">擊然則周禮一書不盡原文而非出依託可槪睹</span>  
<span style="margin-left: 2em">矣考工記稱鄭之刀又稱秦無廬鄭封於宣王時</span>  
<span style="margin-left: 2em">秦封於孝王時其非周公之舊典已無疑義南齊</span>  
<span style="margin-left: 2em">書稱文惠太子鎭雍州有盗發楚王冢𫉬竹簡書</span>  
<span style="margin-left: 2em">靑絲編簡廣數分長二尺有奇得十餘簡以示王</span>  
<span style="margin-left: 2em">僧䖍僧䖍曰是科斗書考工記則其爲秦以前書</span>  
<span style="margin-left: 2em">亦灼然可知雖不足以當冬官然百工爲九經之</span>  
<span style="margin-left: 2em">一共工爲九官之一先王原以制器爲大事存之</span>  
<!-- 册1 葉1560b　Page:文淵閣四庫全書_0001冊.djvu/440 -->
<span style="margin-left: 2em">尚稍見古制俞庭椿以下紛紛割裂五官均無知</span>  
<span style="margin-left: 2em">妄作耳鄭注隋志作十二卷賈疏文繁乃析爲五</span>  
<span style="margin-left: 2em">十卷新舊唐志並同今本四十二卷不知何人所</span>  
<span style="margin-left: 2em">併元于三禮之學本爲專門故所釋特精惟好引</span>  
<span style="margin-left: 2em">緯書是其一短歐陽修集有請校正五經剳子欲</span>  
<span style="margin-left: 2em">刪削其書然緯書不盡可據亦非盡不可據在審</span>  
<span style="margin-left: 2em">別其是非而已不必竄易古書也又好改經字亦</span>  
<span style="margin-left: 2em">其一失然所注但曰當作某耳尚不似北宋以後</span>  
<span style="margin-left: 2em">連篇累牘動稱錯簡則亦不必苛責於元矣公彦</span>  
<!-- 册1 葉1561a　Page:文淵閣四庫全書_0001冊.djvu/440 -->
<span style="margin-left: 2em">之疏亦極博核足以發揮鄭學朱子語錄稱五經</span>  
<span style="margin-left: 2em">疏中周禮疏最好蓋宋儒惟朱子深於禮故能知</span>  
<span style="margin-left: 2em">鄭賈之善云</span>  
周禮新義十六卷附考工記解二卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋王安石撰安石事蹟詳宋史本傳晁公武讀書</span>  
<span style="margin-left: 2em">志曰熙寧中置經義局撰三經義皆本王安石經</span>  
<span style="margin-left: 2em">說三經書詩周禮也新經毛詩義凡二十卷尚書</span>  
<span style="margin-left: 2em">義凡十三卷今並佚周禮新義本二十二卷明萬</span>  
<span style="margin-left: 2em">厯中重編内閣書目尚載其名故朱彞尊經義考</span>  
<!-- 册1 葉1561b　Page:文淵閣四庫全書_0001冊.djvu/440 -->
<span style="margin-left: 2em">不敢著其巳佚但注曰未見然外間實無傳本卽</span>  
<span style="margin-left: 2em">明以來内閣舊籍亦實無此書惟永樂大典中所</span>  
<span style="margin-left: 2em">載最夥蓋内閣書目據文淵閻書目文淵閣書目</span>  
<span style="margin-left: 2em">卽修永樂大典所徵之書其時尚有完帙故採之</span>  
<span style="margin-left: 2em">最詳也考蔡絛鐵圍山叢談曰王元澤奉詔爲三</span>  
<span style="margin-left: 2em">經義時王丞相介甫爲之提舉詩書蓋多出元澤</span>  
<span style="margin-left: 2em">及諸門弟子手周禮新義實丞相親爲之筆削者</span>  
<span style="margin-left: 2em">政和中有司上言天府所籍吳氏資多有王丞相</span>  
<span style="margin-left: 2em">文書於是朝廷悉藏諸秘閣用是吾得見之周禮</span>  
<!-- 册1 葉1564a　Page:文淵閣四庫全書_0001冊.djvu/441 -->
<span style="margin-left: 2em">新義筆跡如斜風細雨誠介甫親書云云然則三</span>  
<span style="margin-left: 2em">經義中惟周禮爲安石手著矣安石以周禮亂宋</span>  
<span style="margin-left: 2em">學者類能言之然周禮之不可行於後世微特人</span>  
<span style="margin-left: 2em">人知之安石亦未嘗不知也安石之意本以宋當</span>  
<span style="margin-left: 2em">積弱之後欲濟以富强而𢙢富强之說必爲儒者</span>  
<span style="margin-left: 2em">所排擊於是附會經義以鉗其口實非眞信周禮</span>  
<span style="margin-left: 2em">爲可行迨其後用之不得其人行之不得其道百</span>  
<span style="margin-left: 2em">弊叢生而宋以大壞其弊亦非眞緣周禮以致誤</span>  
<span style="margin-left: 2em">羅大經鶴林玉露詠安石放魚詩曰錯認蒼姬六</span>  
<!-- 册1 葉1564b　Page:文淵閣四庫全書_0001冊.djvu/441 -->
<span style="margin-left: 2em">典書中原從此變蕭疎是猶爲安石所紿未究其</span>  
<span style="margin-left: 2em">假借六藝之本懷也因是而攻周禮因是而攻安</span>  
<span style="margin-left: 2em">石所注之周禮是寛其影附之巧謀而科以迂腐</span>  
<span style="margin-left: 2em">之薄譴矣故安石怙權植黨之罪萬萬無可辭安</span>  
<span style="margin-left: 2em">石解經之說則與所立新法各爲一事程子取其</span>  
<span style="margin-left: 2em">易解朱子王應麟均取其尚書義所謂言各有當</span>  
<span style="margin-left: 2em">也今觀此書惟訓詁多用字說病其牽合其餘依</span>  
<span style="margin-left: 2em">經詮義如所解八則之治都鄙八統之馭萬民九</span>  
<span style="margin-left: 2em">兩之繫邦國者皆具有發明無所謂舞文害道之</span>  
<!-- 册1 葉1565a　Page:文淵閣四庫全書_0001冊.djvu/441 -->
<span style="margin-left: 2em">處故王昭禹林之奇王與之陳友仁等注周禮頗</span>  
<span style="margin-left: 2em">據其說</span>  
欽定周官義疏亦不廢採用又安可盡以人廢耶安石  
<span style="margin-left: 2em">神宗時所上五事剳子及神宗口錄載安石所引</span>  
<span style="margin-left: 2em">周官及楊時龜山集中所駁平頒興積一條其文</span>  
<span style="margin-left: 2em">皆在地官中今永樂大典闕地官夏官二卷其說</span>  
<span style="margin-left: 2em">遂不可考然所佚適屬其瑕纇則所存者益不必</span>  
<span style="margin-left: 2em">苛詆矣安石本未解考工記而永樂大典乃備載</span>  
<span style="margin-left: 2em">其說據晁氏讀書志蓋鄭宗顔輯安石字說爲之</span>  
<!-- 册1 葉1565b　Page:文淵閣四庫全書_0001冊.djvu/441 -->
<span style="margin-left: 2em">以補其闕今亦並錄其解備一家之書焉</span>  
周禮詳解四十卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">宋王昭禹撰陳振孫書錄解題曰昭禹未詳何等</span>  
<span style="margin-left: 2em">人近世爲舉子業者多用之其學皆宗王氏新說</span>  
<span style="margin-left: 2em">王與之作周禮訂義類編姓氏世次列於龜山楊</span>  
<span style="margin-left: 2em">時之後曰字光遠亦不詳其爵里當爲徽欽時人</span>  
<span style="margin-left: 2em">今按其書解惟王建國云業格于上下謂之王或</span>  
<span style="margin-left: 2em">而圍之謂之國解匪頒之式云散其所藏曰匪以</span>  
<span style="margin-left: 2em">等級之曰頒故匪從匸從非言其分而非藏也頒</span>  
<!-- 册1 葉1568a　Page:文淵閣四庫全書_0001冊.djvu/442 -->
<span style="margin-left: 2em">從分從自言自上而頒之下解圃曰園有衆甫謂</span>  
<span style="margin-left: 2em">之圃解鮑魚曰魚之鮮者包以致之解鱐曰魚之</span>  
<span style="margin-left: 2em">乾者肅以致之解司徒云於文反后爲司蓋后從</span>  
<span style="margin-left: 2em">一從厂從口則所以出命司反之則守令而巳從</span>  
<span style="margin-left: 2em">一則所以一衆司反之則分衆以治之而巳從厂</span>  
<span style="margin-left: 2em">則承上世之庇覆以君天下司反之則以君之爵</span>  
<span style="margin-left: 2em">爲執事之法而巳其附會穿鑿皆遵王氏字說蓋</span>  
<span style="margin-left: 2em">當時三經新義列在學官功令所懸故昭禹因之</span>  
<span style="margin-left: 2em">不改然其發明義㫖則有不盡同於王氏之學者</span>  
<!-- 册1 葉1568b　Page:文淵閣四庫全書_0001冊.djvu/442 -->
<span style="margin-left: 2em">如解泉府以國服爲之息云各以其所服國事賈</span>  
<span style="margin-left: 2em">物爲息若農以粟米工以器械皆以其所有也周</span>  
<span style="margin-left: 2em">之衰不能爲民正田制地稅斂無度又從而貸之</span>  
<span style="margin-left: 2em">則凶年饑歲無以爲償矣下無以償上之人又必</span>

<span style="margin-left: 2em">爲之永則謂揉兩曲木自兩旁合於前通車前三</span>

<span style="margin-left: 2em">分隧之一皆可謂之式式崇三尺三寸並式深處</span>  
<span style="margin-left: 2em">言之兩端與兩輢之植軹相接軍中望遠亦可一</span>  
<span style="margin-left: 2em">足履前式一足覆旁式左傳長勺之戰登軾而望</span>  
<span style="margin-left: 2em">是也若較在式上如何能登軾而望若較於隧三</span>  
<span style="margin-left: 2em">分之前橫架一木則在陰板之内車外不見式矣</span>  
<span style="margin-left: 2em">記如何云苟有車必見其式云云考鄭注曰兵車</span>  
<span style="margin-left: 2em">之式深尺四寸三分寸之二則經所云一在前者</span>  
<span style="margin-left: 2em">皆爲式凡一尺四寸有竒之地注始得云式深若</span>  
<span style="margin-left: 2em">僅於兩輢之中橫架一木名之曰式則一木前後</span>

<span style="margin-left: 2em">更不爲式注又何得以深淺度式乎孔疏謂橫架</span>  
<span style="margin-left: 2em">一木於車箱内葢未會鄭注式深二字之義又鄭</span>  
<span style="margin-left: 2em">注云較兩輢上出式者兩輢則兩箱板也上出式</span>  
<span style="margin-left: 2em">而度之以兩輢則兩較各在兩箱之上明矣故釋</span>  
<span style="margin-left: 2em">名曰較在箱上不云較在式上是其明證孔疏之</span>  
<span style="margin-left: 2em">誤顯然至於經文凡云揉者皆揉之使曲而希逸</span>
