## 欽定四庫全書總目 卷五十六　史部十二　詔令奏議類存目

<!-- 册2 葉972：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷五十六  
<span style="margin-left: 1em">史部十二</span>  
<span style="margin-left: 2em">詔令奏議類存目</span>  
火警或問一卷<sub class="note-yuan">左都御史張若淮家藏本</sub>  
<span style="margin-left: 2em">明世宗肅皇帝御製時大内東偏火帝詔戸禮二</span>  
<span style="margin-left: 2em">部及都察院命百官修省復製此文大畧謂火本</span>  
<span style="margin-left: 2em">非災異而人事不可不修並非惑於禍福事應之</span>  
<span style="margin-left: 2em">說前有帝所作自序後附修省勅諭六條案明史</span>  
<span style="margin-left: 2em">五行志宫中之火在嘉靖十年正月辛亥此本或</span>  
<!-- 册2 葉973b　Page:文淵閣四庫全書_0002冊.djvu/248 -->
<span style="margin-left: 2em">問末亦題嘉靖辛卯正月終旬與史相合而勅諭</span>  
<span style="margin-left: 2em">末乃作嘉靖九年十二月歲月俱誤疑傳抄之訛</span>  
<span style="margin-left: 2em">當以史文爲正也</span>  
<span style="margin-left: 4em">按此書爲世宗御製之文勅諭乃其附錄然</span>  
<span style="margin-left: 4em">宣示中外是亦詔令類矣故明堂從祀諸編</span>  
<span style="margin-left: 4em">著錄於故事此編無預典禮則附諸詔令焉</span>  
代言錄一卷<sub class="note-yuan">江西巡撫採進本</sub>  
<span style="margin-left: 2em">明楊士奇撰士奇有三朝聖諭錄已著錄是書乃</span>  
<span style="margin-left: 2em">其東里别集之一種所錄皆在内閣撰擬碑冊詔</span>  
<!-- 册2 葉976a　Page:文淵閣四庫全書_0002冊.djvu/249 -->
<span style="margin-left: 2em">誥之文自永樂四年至正統九年每篇末具標年</span>  
<span style="margin-left: 2em">月日核諸明實錄俱合惟上皇太后尊號詔標曰</span>  
<span style="margin-left: 2em">洪熙元年七月十五日而明宣宗實錄是詔實載</span>  
<span style="margin-left: 2em">在七月丁丑是月戊辰朔丁丑則初十日也又實</span>  
<span style="margin-left: 2em">錄載七月乙亥上奉冊寳尊母后張氏爲皇太后</span>  
<span style="margin-left: 2em">乙亥爲是月初八日未有初八日已上冊至十五</span>  
<span style="margin-left: 2em">日始下詔者又實錄載七月戊寅行在禮部奏恭</span>  
<span style="margin-left: 2em">上皇太后尊號巳詔告天下云云戊寅爲是月十</span>  
<span style="margin-left: 2em">一日於十一日云巳詔告天下則詔在十一日以</span>  
<!-- 册2 葉976b　Page:文淵閣四庫全書_0002冊.djvu/249 -->
<span style="margin-left: 2em">前無疑此書標十五日蓋傳寫之誤又洪熙元年</span>  
<span style="margin-left: 2em">六月十二日卽位詔欵有云原差去官養官員人</span>  
<span style="margin-left: 2em">等卽便回京毋致重擾軍民實錄載此篇毋致重</span>  
<span style="margin-left: 2em">擾軍民句作不許托故遲延則是書當爲士奇初</span>  
<span style="margin-left: 2em">稿臨時或更加潤飾實錄由定本錄之耳又如洪</span>  
<span style="margin-left: 2em">熙元年八月初六日諭吏部申明薦舉勅自中有</span>  
<span style="margin-left: 2em">亷潔公正句下尙有十五句而今本實錄載此篇</span>  
<span style="margin-left: 2em">皆脫之又如宣德二年十一月十五日皇子生詔</span>  
<span style="margin-left: 2em">第一條載大赦天下今實錄於第一條則僅載蠲</span>  
<!-- 册2 葉977a　Page:文淵閣四庫全書_0002冊.djvu/249 -->
<span style="margin-left: 2em">免稅糧鹽糧三分而大赦反載在第六此類文字</span>  
<span style="margin-left: 2em">異同頗可與實錄相㕘然其事則皆史所巳具也</span>  
諭對錄三十四卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">明張孚敬所奉世宗宻諭及其奏草也孚敬初名</span>  
<span style="margin-left: 2em">璁字秉用永嘉人正德辛巳進士厯官少師華蓋</span>  
<span style="margin-left: 2em">殿大學士諡文忠事蹟具明史本傳孚敬以議禮</span>  
<span style="margin-left: 2em">被遇六年而秉大政甚爲世所詬病而世宗始終</span>  
<span style="margin-left: 2em">眷禮不衰每稱少師蘿山而不名嘗諭孚敬朕有</span>  
<span style="margin-left: 2em">密諭毋泄朕有御筆悉親書又仿楊士奇故事賜</span>  
<!-- 册2 葉977b　Page:文淵閣四庫全書_0002冊.djvu/249 -->
<span style="margin-left: 2em">孚敬銀章二以便封奏前後所奉手勅凡三百八</span>  
<span style="margin-left: 2em">十一道因彚爲一書并奏對劄子皆隨事附之於</span>  
<span style="margin-left: 2em">後蓋孚敬旣没其孫汝紀汝經等所裒輯也<sub class="note-yuan">以上專集</sub></span>  
明詔制八卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明霍韜編韜有明良集已著錄是編載明代詔制</span>  
<span style="margin-left: 2em">始洪武元年終嘉靖十八年大抵皆典禮具文不</span>  
<span style="margin-left: 2em">足考一代之政令</span>  
明詔令二十一卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">不著編輯者名氏所載自太祖至嘉靖十八年止</span>  
<!-- 册2 葉980a　Page:文淵閣四庫全書_0002冊.djvu/250 -->
<span style="margin-left: 2em">蓋嘉靖時人所爲也考秦漢天子之語皆謂之詔</span>  
<span style="margin-left: 2em">宋以來以璽印頒天下之書乃謂之詔臣下面奉</span>  
<span style="margin-left: 2em">玉音謂之聖㫖是書若兼載聖㫖則所遺不可勝</span>  
<span style="margin-left: 2em">道若專載詔令則吳元年遇變省躬㫖授宋濓學</span>  
<span style="margin-left: 2em">士等㫖及正統中諭五府三法司等㫖皆不當載</span>  
<span style="margin-left: 2em">而又雜厠其間編次龎雜殊無義例</span>  
絲綸㨗要便覽一卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">不著編輯者名氏乃明萬厯天啟中内閣票㫖成</span>  
<span style="margin-left: 2em">式以曹司爲次分類標載蓋兩房中書舍人所抄</span>  
<!-- 册2 葉980b　Page:文淵閣四庫全書_0002冊.djvu/250 -->
<span style="margin-left: 2em">撮而成者末載秋審題本亦一時案牘之文<sub class="note-yuan">以上總集</sub></span>  
<span style="margin-left: 4em">案此編無類可歸以其爲當日王言之式附</span>  
<span style="margin-left: 4em">錄於詔令之末</span>  
<span style="margin-left: 1em">右詔令奏議類詔令之屬六部六十六卷皆附存目</span>  
田表聖奏議一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">宋田錫撰錫字表聖其先京兆人唐末徒蜀之洪</span>  
<span style="margin-left: 2em">雅登太平興國三年進士官至諫議大夫事迹具</span>  
<span style="margin-left: 2em">宋史本傳其奏議見於宋史藝文志者二卷已久</span>  
<span style="margin-left: 2em">散佚此本乃明給事中安磐所搜輯共得奏疏十</span>  
<!-- 册2 葉981a　Page:文淵閣四庫全書_0002冊.djvu/250 -->
<span style="margin-left: 2em">四篇附以錫所作箴序二篇本傳及墓誌銘二篇</span>  
<span style="margin-left: 2em">考錫所撰咸平集今尙有傳本凡是編所錄巳具</span>  
<span style="margin-left: 2em">載集中磐蓋未見其書故復爲裒輯焦竑國史經</span>  
<span style="margin-left: 2em">籍志載錫奏議一卷與宋史不合蓋亦僅據此本</span>  
<span style="margin-left: 2em">也</span>  
范文正公奏議二卷書牘一卷范忠宣公奏議二卷<sub class="note-yuan">浙江</sub>  
<sub class="note-yuan">巡撫採進本</sub>  
<span style="margin-left: 2em">明范惟一編惟一爲仲淹十六世孫官湖廣按察</span>  
<span style="margin-left: 2em">司僉事卷首題朱希周孫承恩文徵明陸師道同</span>  
<!-- 册2 葉981b　Page:文淵閣四庫全書_0002冊.djvu/250 -->
<span style="margin-left: 2em">校前後無序跋止於文正奏議前載韓琦舊序一</span>  
<span style="margin-left: 2em">篇</span>  
<span style="margin-left: 1em">國朝康熙中范時崇巡撫廣東往來吳中再謁祠宇</span>  
<span style="margin-left: 2em">因捐貲命主奉孫能濬校刊能濬後序云舊本忠</span>  
<span style="margin-left: 2em">宣集二十卷獨缺奏議明嘉靖中世孫惟一視學</span>  
<span style="margin-left: 2em">兩浙復續編文正忠宣奏議書牘命嚴州守韓叔</span>  
<span style="margin-left: 2em">陽梓行卽此本也按此本忠宣奏議其目錄標題</span>  
<span style="margin-left: 2em">編次前後與時崇本不合能濬後序中又云合家</span>  
<span style="margin-left: 2em">藏舊本細加校勘正其訛謬文集悉遵舊本摹刻</span>  
<!-- 册2 葉984a　Page:文淵閣四庫全書_0002冊.djvu/251 -->
<span style="margin-left: 2em">而忠宣奏議則考趙忠定奏議標目而次第其年</span>  
<span style="margin-left: 2em">月分爲二巻其前此續刻附奏中有前後簡編斷</span>  
<span style="margin-left: 2em">續錯亂者稍爲序次而條分諸目以便稽考云云</span>  
<span style="margin-left: 2em">是重刻之本也多所校定然忠宣奏議實賴此爲</span>  
<span style="margin-left: 2em">初刻故别存其目不没其經始之勤焉</span>  
李忠定奏議六十九卷附錄九卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋李綱撰綱有建炎時政記巳著錄案陳俊卿作</span>  
<span style="margin-left: 2em">綱梁溪集序稱其子秀之編其表章奏劄爲八十</span>  
<span style="margin-left: 2em">卷此本僅六十九卷巳非秀之之舊卷末附錄一</span>  
<!-- 册2 葉984b　Page:文淵閣四庫全書_0002冊.djvu/251 -->
<span style="margin-left: 2em">曰靖康傳信錄一曰建炎進退志一卽建炎時政</span>  
<span style="margin-left: 2em">記共爲三卷第四卷以下皆綱所爲制詔表劄疑</span>  
<span style="margin-left: 2em">卽宋史所云建炎制詔表劄集也俱巳編入梁谿</span>  
<span style="margin-left: 2em">集中故僅存其目不複錄焉</span>  
朱子奏議十五卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明朱吾弼編吾弼字諧卿號密林高安人萬厯已</span>  
<span style="margin-left: 2em">丑進士官至南京太僕寺卿事迹具明史本傳是</span>  
<span style="margin-left: 2em">編皆自晦菴集中抄出凡章奏十巻書狀劄子五</span>  
<span style="margin-left: 2em">巻朱子文集已家<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2959.svg?width=24" alt="四庫全書僻字第2959號（弦）" title="四庫全書僻字第2959號（弦）">戸誦此刻可謂屋下屋牀上</span>  
<!-- 册2 葉985a　Page:文淵閣四庫全書_0002冊.djvu/251 -->
<span style="margin-left: 2em">牀矣</span>  
奏對錄一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明楊士奇撰皆其正統初在内閣所上奏疏凡十</span>  
<span style="margin-left: 2em">九篇多關係軍國大計已載入東里別集中此其</span>  
<span style="margin-left: 2em">單行之本也</span>  
葉文莊奏疏四十卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明葉盛撰盛字與申崑山人正統乙丑進士官至</span>  
<span style="margin-left: 2em">吏部左侍郎諡文莊事迹具明史本傳盛初官兵</span>  
<span style="margin-left: 2em">科給事中有西垣奏草九卷出官山西㕘政協贊</span>  
<!-- 册2 葉985b　Page:文淵閣四庫全書_0002冊.djvu/251 -->
<span style="margin-left: 2em">軍務有邊奏存稿七卷巡撫兩廣有兩廣奏草十</span>  
<span style="margin-left: 2em">六卷巡撫宣府有上谷奏草八卷其子淇初併水</span>  
<span style="margin-left: 2em">東稿開封紀行稿菉竹堂涇東稿合爲九十卷刻</span>  
<span style="margin-left: 2em">於衡州此本則崇禎辛未其六世孫重華所刊也</span>  
兩廣奏草十六卷<sub class="note-yuan">江西巡撫採進本</sub>  
<span style="margin-left: 2em">明葉盛撰巳載入所著奏議中據卷首嘉靖辛亥</span>  
<span style="margin-left: 2em">張寰序稱盛著作頗多其子若孫巳刻之家塾獨</span>  
<span style="margin-left: 2em">兩廣奏議未有刻本至是始續成之云云葢初刻</span>  
<span style="margin-left: 2em">本自爲一帙後乃與他奏議合爲一編故又有此</span>  
<!-- 册2 葉988a　Page:文淵閣四庫全書_0002冊.djvu/252 -->
<span style="margin-left: 2em">別行之本傳於世也</span>  
王介菴奏稿六卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明王恕撰恕有玩易意見已著錄是編乃其官南</span>  
<span style="margin-left: 2em">京兵部尙書時所刻有成化乙巳程廷琪序又有</span>  
<span style="margin-left: 2em">陳公懋後序作於壬寅李東陽後序作於宏治壬</span>  
<span style="margin-left: 2em">子皆初刻也又有謝應徵序則嘉靖丁未揚州重</span>  
<span style="margin-left: 2em">刻所作又有程啟元序正德壬申三原重刻所作</span>  
<span style="margin-left: 2em">諸序皆不言篇數卷數程啟元序稱六卷亦據舊</span>  
<span style="margin-left: 2em">刻惟宏治壬戌楊循吉序稱東魯王公往使關中</span>  
<!-- 册2 葉988b　Page:文淵閣四庫全書_0002冊.djvu/252 -->
<span style="margin-left: 2em">得疏草二百餘篇又稱以余之居部下授而使編</span>
