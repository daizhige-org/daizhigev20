## 欽定四庫全書總目 卷一百六　子部十六　天文算法類

<!-- 册3 葉1112a　Page:文淵閣四庫全書_0003冊.djvu/283 -->
欽定四庫全書總目卷一百六  
<span style="margin-left: 1em">子部十六</span>  
<span style="margin-left: 2em">天文𮅕法𩔖</span>  
<span style="margin-left: 3em">三代上之制作𩔖非後世所及惟天文𮅕法則</span>  
<span style="margin-left: 3em">愈闡愈精容成造術顓頊立制而測星紀閏多</span>  
<span style="margin-left: 3em">述帝堯在古初巳修改漸密矣洛下閎以後利</span>  
<span style="margin-left: 3em">瑪竇以前變法不一泰西晩出頗異前規門戸</span>  
<span style="margin-left: 3em">搆爭亦如講學然分曹測驗具有實徵終不能</span>  
<span style="margin-left: 3em">指北爲南移昏作曉故攻新法者至</span>  
<!-- 册3 葉1112b　Page:文淵閣四庫全書_0003冊.djvu/283 -->
<span style="margin-left: 1em">國初而漸解焉</span>  
聖祖仁皇帝御製數理精藴諸書妙契天元精研化本於  
<span style="margin-left: 3em">中西兩法權衡歸一垂範億年海宇承流遞相</span>  
<span style="margin-left: 3em">推<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2973.svg?width=24" alt="四庫全書僻字第2973號（衍）" title="四庫全書僻字第2973號（衍）">一時如梅文𪔂等測量撰述亦具有成書</span>  
<span style="margin-left: 3em">故言天者至於</span>  
<span style="margin-left: 1em">本朝更無疑義今仰遵</span>  
聖訓考校諸家存古法以溯其源秉新制以究其變古來  
<span style="margin-left: 3em">疎密𨤲然具矣若夫占驗禨祥率多詭說鄭當</span>  
<span style="margin-left: 3em">再火裨竈先誣舊史各自爲𩔖今亦别入之術</span>  
<!-- 册3 葉1113a　Page:文淵閣四庫全書_0003冊.djvu/283 -->
<span style="margin-left: 3em">數家惟𮅕術天文相爲表裏明史藝文志以𮅕</span>  
<span style="margin-left: 3em">術入小學𩔖是古之𮅕術非今之𮅕術也今核</span>  
<span style="margin-left: 3em">其實與天文𩔖從焉</span>  
<span style="margin-left: 1em">周髀𮅕經二卷音義一卷<sub class="note-yuan">永樂大典本</sub></span>  
<span style="margin-left: 2em">案隋書經籍志天文𩔖首列周髀一卷趙嬰注又</span>  
<span style="margin-left: 2em">一卷甄鸞重述唐書藝文志李淳風釋周髀二卷</span>  
<span style="margin-left: 2em">與趙嬰甄鸞之注列之天文𩔖而厯𮅕𩔖中復列</span>  
<span style="margin-left: 2em">李淳風注周髀𮅕經二卷蓋一書重出也是書内</span>  
<span style="margin-left: 2em">稱周髀長八尺夏至之曰晷一尺六寸蓋髀者股</span>  
<!-- 册3 葉1113b　Page:文淵閣四庫全書_0003冊.djvu/283 -->
<span style="margin-left: 2em">也於周地立八尺之表以爲股其影爲勾故曰周</span>  
<span style="margin-left: 2em">髀其首章周公與商高問答實勾股之鼻祖故</span>  
御製數理精藴載在卷首而詳釋之稱爲成周六藝之遺  
<span style="margin-left: 2em">文榮方問於陳子以下徐光啟謂爲千古大愚今</span>  
<span style="margin-left: 2em">詳考其文惟論南北影差以地爲平遠復以平遠</span>  
<span style="margin-left: 2em">測天誠爲臆說然與本文巳絶不相𩔖疑後人傳</span>  
<span style="margin-left: 2em">說而誤入正文者如夏小正之經傳參合傅崧<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）"></span>  
<span style="margin-left: 2em">未訂以前使人不能讀也其本文之廣大精微者</span>  
<span style="margin-left: 2em">皆足以存古法之意開西法之源如書内以璇璣</span>  
<!-- 册3 葉1116a　Page:文淵閣四庫全書_0003冊.djvu/284 -->
<span style="margin-left: 2em">一晝夜環繞北極一周而過一度冬至夜半璇璣</span>  
<span style="margin-left: 2em">起北極下子位春分夜半起北極左卯位夏至夜</span>  
<span style="margin-left: 2em">半起北極上午位秋分夜半起北極右酉位是爲</span>  
<span style="margin-left: 2em">璇璣四游所極終古不變以七衡六間測日𨇠𤼵</span>  
<span style="margin-left: 2em">歛冬至日在外衡夏至在内衡春秋分在中衡當</span>  
<span style="margin-left: 2em">其冬至日在外衡間爲節氣亦終古不變古蓋天</span>  
<span style="margin-left: 2em">之學此其遺法蓋渾天如毬寫星象於外人自天</span>  
<span style="margin-left: 2em">外觀天蓋天如笠寫星象於内人自天内觀天笠</span>  
<span style="margin-left: 2em">形半圓有如張蓋故稱蓋天合地上地下兩半圓</span>  
<!-- 册3 葉1116b　Page:文淵閣四庫全書_0003冊.djvu/284 -->
<span style="margin-left: 2em">體卽天體之渾圓矣其法失傳巳久故自漢以迄</span>  
<span style="margin-left: 2em">元明皆主渾天明萬厯中歐邏巴人入中國始别</span>  
<span style="margin-left: 2em">立新法號爲精密然其言地圓卽周髀所謂地法</span>  
<span style="margin-left: 2em">覆槃滂沱四隤而下也其言南北里差卽周髀所</span>  
<span style="margin-left: 2em">謂北極左右夏有不釋之冰物有朝生暮穫中衡</span>  
<span style="margin-left: 2em">左右冬有不死之草五榖一歲再熟是爲寒暑推</span>  
<span style="margin-left: 2em">移隨南北不同之故春分至秋分極下常有日光</span>  
<span style="margin-left: 2em">秋分至春分極下常無日光是爲晝夜永短隨南</span>  
<span style="margin-left: 2em">北不同之故也其言東西里差卽周髀所謂東方</span>  
<!-- 册3 葉1117a　Page:文淵閣四庫全書_0003冊.djvu/284 -->
<span style="margin-left: 2em">日中西方夜半西方日中東方夜半晝夜易處如</span>  
<span style="margin-left: 2em">四時相反是爲節氣合朔如時早晚隨東西不同</span>  
<span style="margin-left: 2em">之故也又李之藻以西法製渾蓋通憲展晝短規</span>  
<span style="margin-left: 2em">使大於赤道規一同周髀之展半衡使大於中衡</span>  
<span style="margin-left: 2em">其新法𮅕書述第谷以前西法三百六十五日四</span>  
<span style="margin-left: 2em">分日之一每四歲之小餘成一日亦卽周髀所謂</span>  
<span style="margin-left: 2em">三百六十五日者三三百六十六日者一也西法</span>  
<span style="margin-left: 2em">多出於周髀此皆顯証特後來測騐增修愈推愈</span>  
<span style="margin-left: 2em">密耳明史厯志謂堯時宅西居昧谷疇人子弟散</span>  
<!-- 册3 葉1117b　Page:文淵閣四庫全書_0003冊.djvu/284 -->
<span style="margin-left: 2em">入遐方因而傳爲西學者固有由矣此書刻本脫</span>  
<span style="margin-left: 2em">誤多不可通今據永樂大典内所載詳加校訂補</span>  
<span style="margin-left: 2em">脫文一百四十七字改訛舛者一百一十三字刪</span>  
<span style="margin-left: 2em">其<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2973.svg?width=24" alt="四庫全書僻字第2973號（衍）" title="四庫全書僻字第2973號（衍）">複者十八字舊本相承題云漢趙君<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">注其</span>  
<span style="margin-left: 2em">自序稱爽以暗蔽注内屢稱爽或疑焉爽未之前</span>  
<span style="margin-left: 2em">聞蓋卽君<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">之名然則隋唐志之趙嬰殆即趙爽</span>  
<span style="margin-left: 2em">之訛歟注引靈憲乾象則其人在張衡劉洪後也</span>  
<span style="margin-left: 2em">舊有李藉音義别自爲卷今仍其舊書内凡爲圖</span>  
<span style="margin-left: 2em">有五而失傳者三訛舛者一謹據正文及注爲之</span>  
<!-- 册3 葉1120a　Page:文淵閣四庫全書_0003冊.djvu/285 -->
<span style="margin-left: 2em">補訂古者九數惟九章周髀二書流傳最古故訛</span>  
<span style="margin-left: 2em">誤亦特甚然溯委窮源得其端緖固術數家之鴻</span>  
<span style="margin-left: 2em">寳也</span>  
新儀象法要三卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋蘇頌撰頌字子容南安人徙居丹徒慶厯二年</span>  
<span style="margin-left: 2em">進士官至右僕射兼中書門下侍郞累爵趙郡公</span>  
<span style="margin-left: 2em">事蹟具宋史本傳是書爲重修渾儀而作事在元</span>  
<span style="margin-left: 2em">祐間而尤袤遂初堂書目稱爲紹聖儀象法要又</span>  
<span style="margin-left: 2em">藝文志有儀象法要一卷亦注云紹聖中編蓋其</span>  
<!-- 册3 葉1120b　Page:文淵閣四庫全書_0003冊.djvu/285 -->
<span style="margin-left: 2em">書成於紹聖初也案本傳稱時别製渾儀命頌提</span>  
<span style="margin-left: 2em">舉頌旣邃於律𮅕以吏部令史韓公亷有巧思奏</span>  
<span style="margin-left: 2em">用之授以古法爲臺三層上設渾儀中設渾象下</span>  
<span style="margin-left: 2em">設司辰贯以一機激水轉輪不假人力時至刻臨</span>  
<span style="margin-left: 2em">則司辰出告星辰𨇠度所次占候測驗不差晷刻</span>  
<span style="margin-left: 2em">晝夜晦明皆可推見前此未有也葉夣得石林燕</span>  
<span style="margin-left: 2em">語亦謂頌所修制造之精遠岀前古其學畧授冬</span>  
<span style="margin-left: 2em">官正袁惟幾今其法蘇氏子孫亦不傳云云案書</span>  
<span style="margin-left: 2em">中有官局生袁惟幾之名與燕語所記相合其說</span>  
<!-- 册3 葉1121a　Page:文淵閣四庫全書_0003冊.djvu/285 -->
<span style="margin-left: 2em">可信知宋時固甚重之矣書首列進狀一首上卷</span>  
<span style="margin-left: 2em">自渾儀至水趺共十七圖中卷自渾象至冬至曉</span>  
<span style="margin-left: 2em">中星圖共十八圖下卷自儀象臺至渾儀圭表共</span>  
<span style="margin-left: 2em">二十五圖圖後各有說蓋當時奉勅撰進者其列</span>  
<span style="margin-left: 2em">璣衡制度候視法式甚爲詳悉南宋以後流傳甚</span>  
<span style="margin-left: 2em">稀此本爲明錢曾所藏後有乾道壬辰九月九日</span>  
<span style="margin-left: 2em">吳興施元之刻本於三衢坐嘯齋字兩行蓋從宋</span>  
<span style="margin-left: 2em">槧影摹者元之字德初官至司諫嘗注蘇詩行世</span>  
<span style="margin-left: 2em">此書卷末天運輪等四圖及各條所附一本云云</span>  
<!-- 册3 葉1121b　Page:文淵閣四庫全書_0003冊.djvu/285 -->
<span style="margin-left: 2em">皆元之據别本補入校核殊精而曾所抄尤極工</span>  
<span style="margin-left: 2em">緻其撰讀書敏求記載入是書自稱圖様界畫不</span>  
<span style="margin-left: 2em">爽毫髪凡數月而後成楮墨精妙絶倫不數宋本</span>  
<span style="margin-left: 2em">良非誇語也我</span>  
<span style="margin-left: 1em">朝儀器精密夐絶千古頌所創造固無足輕重而一</span>  
<span style="margin-left: 2em">時講求制作之意頗有足備參考者且流傳秘冊</span>  
<span style="margin-left: 2em">閲數百年而摹繪如新是固宜爲寳貴矣</span>  
六經天文編二卷<sub class="note-yuan">直隷總督採進本</sub>  
<span style="margin-left: 2em">宋王應麟撰應麟有鄭氏周易注巳著錄是編裒</span>  
<!-- 册3 葉1124a　Page:文淵閣四庫全書_0003冊.djvu/286 -->
<span style="margin-left: 2em">六經之言天文者以易書詩所載爲上卷周禮禮</span>  
<span style="margin-left: 2em">記春秋所載爲下卷三代以上推歩之書不傳論</span>  
<span style="margin-left: 2em">者謂古法疎而今法密如歲差里差之辨皆聖人</span>  
<span style="margin-left: 2em">所未言晉虞喜始知歲差唐人作覆矩圖始知地</span>  
<span style="margin-left: 2em">有東西南北里差然堯典豳風月令左傳國語所</span>  
<span style="margin-left: 2em">言星辰前後巳相差一次是歲差之法可卽是例</span>  
<span style="margin-left: 2em">推周禮土圭之法日南景短日北景長日東景夕</span>  
<span style="margin-left: 2em">日西景朝是里差之法亦可卽是而見六經所載</span>  
<span style="margin-left: 2em">未始非推歩之根特古文簡約不能如後世推演</span>  
<!-- 册3 葉1124b　Page:文淵閣四庫全書_0003冊.djvu/286 -->
<span style="margin-left: 2em">詳密耳此編雖以天文爲名而不專主於星象凡</span>  
<span style="margin-left: 2em">陰陽五行風雨以及卦義悉彚集之採錄先儒經</span>  
<span style="margin-left: 2em">說爲多義有未備則旁渉史志以明之亦推歩家</span>  
<span style="margin-left: 2em">所當考證也宋史藝文志作六卷至正四明續志</span>  
<span style="margin-left: 2em">作二卷今此書分上下二編則二卷爲是</span>  
<span style="margin-left: 1em">國朝吉水李振裕補刋玉海序稱應麟著述逾三十</span>  
<span style="margin-left: 2em">種巳刻者玉海附詞學指南又有遺書十三種自</span>  
<span style="margin-left: 2em">詩考至通鑑答問共五十餘卷板皆朽蝕悉爲補</span>  
<span style="margin-left: 2em">刋之是編亦與焉此本前後無序跋𥿄墨甚舊蓋</span>  
<!-- 册3 葉1125a　Page:文淵閣四庫全書_0003冊.djvu/286 -->
<span style="margin-left: 2em">猶至元六年王俊孫所刋也</span>  
原本草象新書五卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">不著撰人名氏宋濓作序稱趙緣督先生所著先</span>  
<span style="margin-left: 2em">生鄱陽人𨼆遯自晦不知其名若字或曰名敬字</span>  
<span style="margin-left: 2em">子㳟或曰友欽弗能詳也王褘嘗刋定其書序稱</span>  
<span style="margin-left: 2em">名友某字子公其先於宋有屬籍攷宋史宗室世</span>  
<span style="margin-left: 2em">系表漢王房十二世以友字聯名書中稱歲䇿加</span>
