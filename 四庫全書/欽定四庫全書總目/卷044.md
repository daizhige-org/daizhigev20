## 欽定四庫全書總目 卷四十四　經部四十四　小學類存目二

欽定四庫全書總目卷四十四  
<span style="margin-left: 1em">經部四十四</span>  
<span style="margin-left: 2em">小學類存目二</span>  
韻經五卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">舊本題梁吳興沈約撰類宋會稽夏竦集古明宏</span>  
<span style="margin-left: 2em">農楊愼轉注江夏郭正域校前有正域自序曰近</span>  
<span style="margin-left: 2em">體詩惟宗沈韻今所傳韻非沈也唐禮部韻也故</span>  
<span style="margin-left: 2em">唐詩宗之沈韻上平有九咍十八痕下平有二十</span>  
<span style="margin-left: 2em">二凡上有十六混十九豏去有八祭十代十七焮</span>  
<!-- 册1 葉3669b　Page:文淵閣四庫全書_0001冊.djvu/967 -->
<span style="margin-left: 2em">入有十六昔而今韻無之其凡例又稱家藏有四</span>  
<span style="margin-left: 2em">聲韻乃約故本案梁書南史沈約傳並載約撰四</span>  
<span style="margin-left: 2em">聲譜隋志載其書一卷而唐志已不著錄觀陸法</span>  
<span style="margin-left: 2em">言切韻序厯述吕靜夏侯該陽休之周思言李季</span>  
<span style="margin-left: 2em">節杜臺卿六家之韻獨不及約書是隋開皇時其</span>  
<span style="margin-left: 2em">書已不顯唐李涪作刊誤但詬陸韻而不及沈書</span>  
<span style="margin-left: 2em">則僖宗時已佚矣正域何由於數百年後得其故</span>  
<span style="margin-left: 2em">本且沈韻雖不可見而其集猶存今以所用之韻</span>  
<span style="margin-left: 2em">一一排比鈎稽之惟東冬鍾三韻同用魚虞模三</span>  
<!-- 册1 葉3672a　Page:文淵閣四庫全書_0001冊.djvu/968 -->
<span style="margin-left: 2em">韻同用庚耕淸靑四韻同用而蒸登兩韻各獨用</span>  
<span style="margin-left: 2em">與廣韻異餘則四聲並同又安得如正域所云九</span>  
<span style="margin-left: 2em">咍之類其爲贋託殆不足辨至夏竦古文四聲五</span>  
<span style="margin-left: 2em">卷本采鐘鼎奇字分韻編次以便檢尋乃字書非</span>  
<span style="margin-left: 2em">韻書乃古文非今文正域乃稱夏竦集古尤爲乖</span>  
<span style="margin-left: 2em">迕觀其首列徐藏所作吳棫韻補序楊愼轉注古</span>  
<span style="margin-left: 2em">音畧自序而不及竦序知並未見其書而但以名</span>  
<span style="margin-left: 2em">勦說也王宏撰山志乃指此爲沈約眞本譏屠隆</span>  
<span style="margin-left: 2em">未見韻經誤指平水韻爲約書不亦傎乎又朱彝</span>  
<!-- 册1 葉3672b　Page:文淵閣四庫全書_0001冊.djvu/968 -->
<span style="margin-left: 2em">尊重刊廣韻序曰近有嶺外妄男子僞撰沈約之</span>  
<span style="margin-left: 2em">書信而不疑者有焉考王士禎居易錄記康熙庚</span>  
<span style="margin-left: 2em">午廣東香山縣監生楊錫震自言得沈約四聲譜</span>  
<span style="margin-left: 2em">古本於廬山僧今帾因合吳棫韻補而詳考音義</span>  
<span style="margin-left: 2em">博徵載籍爲古今詩韻注凡二百六十一卷赴通</span>  
<span style="margin-left: 2em">政司疏上之奉</span>  
㫖付内閣與毛奇齡所進古今通韻訂其同異彝尊所指  
<span style="margin-left: 2em">當卽其人今</span>  
<span style="margin-left: 1em">内府書目但有奇齡之書而錫震之書不錄未知其</span>  
<!-- 册1 葉3673a　Page:文淵閣四庫全書_0001冊.djvu/968 -->
<span style="margin-left: 2em">門目何如疑其所據卽正域此本也</span>  
書學正韻三十六卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">元楊桓撰桓旣著六書統六書㴑原又依韻編次</span>  
<span style="margin-left: 2em">是書兼以字母等韻各分標一二三四以辨其聲</span>  
<span style="margin-left: 2em">之高下然或有或缺體例不一所列之字兼存篆</span>  
<span style="margin-left: 2em">隷二體逐字之下注云統指統形統聲統意統注</span>  
<span style="margin-left: 2em">者見於六書統者也注云原指原形原聲原意原</span>  
<span style="margin-left: 2em">注者見於六體㴑原者也指卽指事形卽象形聲</span>  
<span style="margin-left: 2em">卽諧聲意卽會意注卽轉注省其文耳其所分韻</span>  
<!-- 册1 葉3673b　Page:文淵閣四庫全書_0001冊.djvu/968 -->
<span style="margin-left: 2em">目大槩因集韻之舊而稍有訂改如眞韻三等合</span>  
<span style="margin-left: 2em">口呼麔囷奫筠等字移入於諄諄韻四等開口呼</span>  
<span style="margin-left: 2em">趣字移入於眞則眞與諄一爲開口呼一爲合口</span>  
<span style="margin-left: 2em">呼兩不淆雜陸法言以魂痕次元後許敬宗等遂</span>  
<span style="margin-left: 2em">注三韻同用是書移痕魂於前與眞諄文欣爲一</span>  
<span style="margin-left: 2em">類移元於後與寒桓刪山先仙爲一類於古音以</span>  
<span style="margin-left: 2em">侈歛分二部者亦各從其類然一以今讀移舊部</span>  
<span style="margin-left: 2em">一以古音移今韻雖言之有故執之成理究不免</span>  
<span style="margin-left: 2em">變亂之嫌至於平聲併臻於眞少一韻目而入聲</span>  
<!-- 册1 葉3676a　Page:文淵閣四庫全書_0001冊.djvu/969 -->
<span style="margin-left: 2em">不併櫛於質且隱韻焮韻内二等開口呼ခ齔等</span>  
<span style="margin-left: 2em">字不知其卽臻櫛之上去聲是四聲一貫之故猶</span>  
<span style="margin-left: 2em">未盡知其亦好爲解事矣</span>  
蒙古字韻二卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">元朱宗文撰宗文字彦章信安人前有劉更序又</span>  
<span style="margin-left: 2em">稱爲朱巴顔葢宗文嘗充蒙古字學弟子故别以</span>  
<span style="margin-left: 2em">蒙古語命名也按元史釋老傳元初本用威烏爾</span>  
<span style="margin-left: 2em">字<sub class="note-yuan">按威烏爾原作畏吾兒今改正</sub>以達國言至世祖中統元年始</span>  
<span style="margin-left: 2em">命帝師製蒙古新字其字僅千餘其母凡四十有</span>  
<!-- 册1 葉3676b　Page:文淵閣四庫全書_0001冊.djvu/969 -->
<span style="margin-left: 2em">一其相關紐而成字者則有韻關之法其以二合</span>  
<span style="margin-left: 2em">三合四合而成字者則有語韻之法而大要以諧</span>  
<span style="margin-left: 2em">聲爲宗字成詔頒行天下又於州縣各設蒙古字</span>  
<span style="margin-left: 2em">學教授以教習之故當時頗有知其義者宗文以</span>  
<span style="margin-left: 2em">蒙古字韻字與聲合而諸家漢韻率多譌誤莫知</span>  
<span style="margin-left: 2em">取舍因重爲校正首列各本誤字及重入漢字次</span>  
<span style="margin-left: 2em">列總括變化之圖次字母三十六字次篆字母九</span>  
<span style="margin-left: 2em">十八字次則以各蒙古字分韻排列始一東迄十</span>  
<span style="margin-left: 2em">五麻皆上冠蒙古文下注漢文對音先平聲而附</span>  
<!-- 册1 葉3677a　Page:文淵閣四庫全書_0001冊.djvu/969 -->
<span style="margin-left: 2em">以上去入聲每一蒙古字以漢字音注自四五字</span>  
<span style="margin-left: 2em">至二三十字末附𮞉避字樣一百六十餘字葢文</span>  
<span style="margin-left: 2em">移案牘通行備檢之本也元代國書國語音譯久</span>  
<span style="margin-left: 2em">已傳訛宗文生於至大間雖自謂能通音譯而以</span>  
<span style="margin-left: 2em">南人隔膜之見比附推尋實多不能脗合卽如陶</span>  
<span style="margin-left: 2em">宗儀輟耕錄載元國字以可侯字爲首而是書又</span>  
<span style="margin-left: 2em">依韻會以見經堅乩字爲首其字母已不相合而</span>  
<span style="margin-left: 2em">元史旣稱有二合三合四合之法而此書乃用直</span>  
<span style="margin-left: 2em">對而不用切音甚至累數字以釋一音淸濁重輕</span>  
<!-- 册1 葉3677b　Page:文淵閣四庫全書_0001冊.djvu/969 -->
<span style="margin-left: 2em">毫無分别又字皆對音而不能翻譯成語觀元史</span>  
<span style="margin-left: 2em">及諸書所載蒙古字詔㫖行移皆能以國語聯屬</span>  
<span style="margin-left: 2em">成文是當日必别有翻譯之法而是書槩未之及</span>  
<span style="margin-left: 2em">遂致湮没而不可復考葢其時朝廷旣無頒行定</span>  
<span style="margin-left: 2em">式官司胥史輾轉傳鈔舛謬相仍觀於國姓之却</span>  
<span style="margin-left: 2em">特而訛作奇渥温載之史冊則其他錯互大槪可</span>  
<span style="margin-left: 2em">知且刊本久佚今所存者惟寫本其點畫旣非鈔</span>  
<span style="margin-left: 2em">胥所能知其舛誤亦非文士所能校不過彷彿鈎</span>  
<span style="margin-left: 2em">摹依稀形似尤不可據爲典要我</span>  
<!-- 册1 葉3680a　Page:文淵閣四庫全書_0001冊.djvu/970 -->
<span style="margin-left: 1em">國家同文盛治邁越古今</span>  
欽定元史蒙古國語解考訂精<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">凡相沿之蹖謬盡已  
<span style="margin-left: 2em">闡剔無遺傳譌之本竟付覆瓿可矣</span>  
正韻牋四卷<sub class="note-yuan">江西巡撫採進本</sub>  
<span style="margin-left: 2em">明楊時偉撰時偉有春秋編年舉要已著錄是書</span>  
<span style="margin-left: 2em">前有崇禎辛未自序大㫖以洪武正韻不行於當</span>  
<span style="margin-left: 2em">代故因其原本增注於下謂之補箋又取吳棫韻</span>  
<span style="margin-left: 2em">補陳第古韻攷諸書所據古書之音附於各韻之</span>  
<span style="margin-left: 2em">後謂之古音又取熊忠韻會舉要楊愼丹鉛錄諸</span>  
<!-- 册1 葉3680b　Page:文淵閣四庫全書_0001冊.djvu/970 -->
<span style="margin-left: 2em">書所收字增附於韻後謂之逸字其用意頗勤然</span>  
<span style="margin-left: 2em">洪武正韻分合舛誤窒礙難通雖以天子之尊傳</span>  
<span style="margin-left: 2em">國十餘世懸是書爲令甲而終不能使行於天下</span>  
<span style="margin-left: 2em">二百六七十年之中若存若亡無人置議時偉乃</span>  
<span style="margin-left: 2em">於舉世不用之中出奇立異冀以匹夫之力顚倒</span>  
<span style="margin-left: 2em">千古之是非抑亦難矣且所著古音雜取吳棫陳</span>  
<span style="margin-left: 2em">第二家不知其體例各别所收逸字不能究廣韻</span>  
<span style="margin-left: 2em">集韻之源僅據楊愼等之書尤爲疎畧所補箋亦</span>  
<span style="margin-left: 2em">皆轉輾稗販如日在木中爲東此許愼所引官溥</span>  
<!-- 册1 葉3681a　Page:文淵閣四庫全書_0001冊.djvu/970 -->
<span style="margin-left: 2em">說明載於說文而乃引鄭樵通志足知非根本之</span>  
<span style="margin-left: 2em">學矣</span>  
聲音文字通三十二卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明趙撝謙撰撝謙有六書本義已著錄是書乃所</span>  
<span style="margin-left: 2em">定韻譜也考皇極經世聲音唱和圖日月星辰凡</span>  
<span style="margin-left: 2em">一百六十聲爲體數去太陰少陰太柔少柔之體</span>  
<span style="margin-left: 2em">數四十八得一百一十二爲日月星辰之用數水</span>  
<span style="margin-left: 2em">火土石凡一百九十二音爲體數去太陽少陽太</span>  
<span style="margin-left: 2em">剛少剛之體數四十得一百五十二爲水火土石</span>  
<!-- 册1 葉3681b　Page:文淵閣四庫全書_0001冊.djvu/970 -->
<span style="margin-left: 2em">之用數撝謙此書則取音爲字母聲爲切韻各自</span>  
<span style="margin-left: 2em">相配而註所切之字於上凡有一音和以十聲蓋</span>  
<span style="margin-left: 2em">因邵子之圖而錯綜引伸之然以一卦配一音又</span>  
<span style="margin-left: 2em">以一卦配十聲使音與聲爲唱和卦與卦爲唱和</span>  
<span style="margin-left: 2em">欲於邵子經世圖之外增成新義而不知於聲音</span>  
<span style="margin-left: 2em">之道彌滋穿鑿殊無足取焦竑筆乘載撝謙殁後</span>  
<span style="margin-left: 2em">其門人柴廣敬以是書進於朝未及板行明史藝</span>  
<span style="margin-left: 2em">文志載是書爲一百卷此本尙存三十二卷葢别</span>  
<span style="margin-left: 2em">本之流傳者然卷首起自一之四亦殘缺之書不</span>  
<!-- 册1 葉3684a　Page:文淵閣四庫全書_0001冊.djvu/971 -->
<span style="margin-left: 2em">足取證以敗楮視之可矣</span>  
韻學集成十三卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">明章黼撰黼字道常嘉定人是書分部一準洪武</span>  
<span style="margin-left: 2em">正韻每部之中以平仄相從四聲具者九部三聲</span>  
<span style="margin-left: 2em">無人者十一部其隷字先後則從韻會舉要之例</span>  
<span style="margin-left: 2em">以字母爲序其分配五音以影曉二母從玉篇舊</span>  
<span style="margin-left: 2em">圖屬宫不從韻會舉要屬羽通喻二母從韻會舉</span>  
<span style="margin-left: 2em">要屬羽不從玉篇圖屬宫帮滂並明四母從玉篇</span>  
<span style="margin-left: 2em">屬宫不從韻會舉要屬羽非敷二母則以舊譜均</span>  
<!-- 册1 葉3684b　Page:文淵閣四庫全書_0001冊.djvu/971 -->
<span style="margin-left: 2em">誤屬宫而改爲屬徵其字多收篇海龍龕手鑑之</span>  
<span style="margin-left: 2em">怪體其音兼載中原音韻之北聲凡四萬三千餘</span>  
<span style="margin-left: 2em">字自記稱始於宣德壬子成於天順庚辰計其用</span>  
<span style="margin-left: 2em">力凡二十九年可謂專精於是然以正韻爲主根</span>
