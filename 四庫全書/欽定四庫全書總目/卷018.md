## 欽定四庫全書總目 卷十八　經部十八　詩類存目二

<!-- 册1 葉1512a　Page:文淵閣四庫全書_0001冊.djvu/428 -->
欽定四庫全書總目卷十八  
<span style="margin-left: 1em">經部十八</span>  
<span style="margin-left: 2em">詩類存目二</span>  
詩經朱傳翼三十卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 1em">國朝孫承澤撰承澤有尙書集解巳著錄承澤初附</span>  
<span style="margin-left: 2em">東林繼降闖賊終乃入於</span>  
<span style="margin-left: 1em">國朝自知爲當代所輕故末年講學惟假借朱子以</span>  
<span style="margin-left: 2em">爲重獨此編說詩則以小序集傳並列又雜引諸</span>  
<span style="margin-left: 2em">說之異同窺其大意似以集傳爲未愜而又不肯</span>  
<!-- 册1 葉1512b　Page:文淵閣四庫全書_0001冊.djvu/428 -->
<span style="margin-left: 2em">訟言故ခ頇摸棱不置論斷紛紜糅亂究莫名其</span>  
<span style="margin-left: 2em">指歸首鼠兩端斯之謂矣</span>  
詩說簡正錄十卷<sub class="note-yuan">直𨽻總督採進本</sub>  
<span style="margin-left: 1em">國朝提橋撰橋字景如號澹如居士河間人前明天</span>  
<span style="margin-left: 2em">啟壬戌進士入</span>  
<span style="margin-left: 1em">國朝官至刑部侍郎是編以詩經大全諸書卷帙浩</span>  
<span style="margin-left: 2em">博難以披尋因采擇諸說輯爲一編名曰簡正錄</span>  
<span style="margin-left: 2em">言其說簡而義正也每篇首列經文次摘採諸家</span>  
<span style="margin-left: 2em">之說融會訓釋又次附以巳見皆以通俗之語講</span>  
<!-- 册1 葉1513a　Page:文淵閣四庫全書_0001冊.djvu/428 -->
<span style="margin-left: 2em">解文義葢取便於初學而巳</span>  
詩問一卷<sub class="note-yuan">浙江朱彛尊家曝書亭藏本</sub>  
<span style="margin-left: 1em">國朝吳肅公撰肅公字雨若號街南宣城人是書大</span>  
<span style="margin-left: 2em">旨攻朱子詩集傳然亦不甚從小序往往皆臆揣</span>  
<span style="margin-left: 2em">武斷之說其中引世厯紀一條證出車爲文王詩</span>  
<span style="margin-left: 2em">又引竹書紀年一條證菀柳爲諸侯盟太室詩皆</span>  
<span style="margin-left: 2em">牽附雜說不足據以解經也</span>  
詩經傳說取裁十二卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 1em">國朝張能鱗撰能鱗字西山順天人順治丁亥進士</span>  
<!-- 册1 葉1513b　Page:文淵閣四庫全書_0001冊.djvu/428 -->
<span style="margin-left: 2em">官至四川按察使副使其書以豐坊僞詩傳爲主</span>  
<span style="margin-left: 2em">而旁採申培詩說及詩六帖以發明之宗旨先謬</span>  
<span style="margin-left: 2em">其餘亦不足深詰矣</span>  
毛詩日箋六卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 1em">國朝秦松齡撰松齡字留仙號對巖無錫人順治乙</span>  
<span style="margin-left: 2em">未進士改庶吉士以江南奏銷案罷歸康熙已未</span>  
<span style="margin-left: 2em">舉博學鴻詞官至左春坊左諭德是編以紫陽集</span>  
<span style="margin-left: 2em">傳宗孟子以意逆志之旨多不依小序因取歐蘇</span>  
<span style="margin-left: 2em">王吕程李輔嚴諸家以及明郝敬何楷近時顧炎</span>  
<!-- 册1 葉1516a　Page:文淵閣四庫全書_0001冊.djvu/429 -->
<span style="margin-left: 2em">武之言互相㕘核而斷以巳意不專主小序亦不</span>  
<span style="margin-left: 2em">專主集傳凡有疑義乃爲疏解亦不盡解全詩故</span>  
<span style="margin-left: 2em">曰日箋王士禎居易錄云秦宫諭所輯毛詩日箋</span>  
<span style="margin-left: 2em">所論與余夙昔之見頗同其所採取亦甚簡當然</span>  
<span style="margin-left: 2em">大旨多以意揣之不盡有所考証也</span>  
詩經疏畧八卷<sub class="note-yuan">河南巡撫採進本</sub>  
<span style="margin-left: 1em">國朝張沐撰沐有周易疏畧巳著錄其說以小序爲</span>  
<span style="margin-left: 2em">主而亦時有異同大扺調停前人之說而㕘以臆</span>  
<span style="margin-left: 2em">斷如平王之孫齊侯之子旣不用舊說又不用春</span>  
<!-- 册1 葉1516b　Page:文淵閣四庫全書_0001冊.djvu/429 -->
<span style="margin-left: 2em">秋王姬之說乃訓平爲等謂唐棣本不同於桃李</span>  
<span style="margin-left: 2em">而華如桃李王之孫本不齊於侯之子今觀其車</span>  
<span style="margin-left: 2em">服則等王之孫以齊於侯之子以附會序中不繫</span>  
<span style="margin-left: 2em">其夫下王后一等之說於經義殊爲乖刺亦何取</span>  
<span style="margin-left: 2em">乎宗小序也</span>  
詩經比興全義一卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 1em">國朝王鍾毅撰鍾毅字遠生華亭人順治中松江府</span>  
<span style="margin-left: 2em">學歲貢生是書據朱子詩傳發明比興之義每詩</span>  
<span style="margin-left: 2em">各標篇名而推求託物抒懷之意前有大意一篇</span>  
<!-- 册1 葉1517a　Page:文淵閣四庫全書_0001冊.djvu/429 -->
<span style="margin-left: 2em">篇末有云關雎之爲求賢菁莪棫樸之爲養士此</span>  
<span style="margin-left: 2em">等義非不佳然與集注全異功令所格不敢濫收</span>  
<span style="margin-left: 2em">云云葢專爲科舉作也</span>  
詩經惜陰錄二十卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 1em">國朝徐世沐撰世沐有周易惜陰錄巳著錄是書前</span>  
<span style="margin-left: 2em">有自記又有小引謂曾請正於李光地陸隴其每</span>  
<span style="margin-left: 2em">卷皆記其起草繕眞之年月葢亦苦志著述者然</span>  
<span style="margin-left: 2em">循文衍說於詩敎未得其要領也</span>  
白鷺洲主客說詩一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<!-- 册1 葉1517b　Page:文淵閣四庫全書_0001冊.djvu/429 -->
<span style="margin-left: 1em">國朝毛奇齡撰奇齡有仲氏易已著錄初施閏章爲</span>  
<span style="margin-left: 2em">江西㕘議延湖廣楊洪才講學於吉安之白鷺洲</span>  
<span style="margin-left: 2em">書院併續招奇齡往奇齡與洪才論詩不合及與</span>  
<span style="margin-left: 2em">閏章同官翰林重錄其向時所講毛詩諸條皆設</span>  
<span style="margin-left: 2em">爲甲乙問答故以主客爲名大旨洪才主朱子淫</span>  
<span style="margin-left: 2em">詩之說而奇齡則謂鄭風無淫詩洪才主朱子笙</span>  
<span style="margin-left: 2em">詩無詞之說而奇齡則謂笙詩之詞亡故是書所</span>  
<span style="margin-left: 2em">論惟此二事夫先王陳詩以觀民風本美刺兼舉</span>  
<span style="margin-left: 2em">以爲法戒旣他事有刺何爲獨不刺淫必以爲鄭</span>  
<!-- 册1 葉1520a　Page:文淵閣四庫全書_0001冊.djvu/430 -->
<span style="margin-left: 2em">風語語皆淫固非事理必以爲鄭風篇篇皆不淫</span>  
<span style="margin-left: 2em">亦豈事理哉且人心之所趨向形於詠歌不必實</span>  
<span style="margin-left: 2em">有其人其事六朝子夜讀曲諸歌唐人香奩諸集</span>  
<span style="margin-left: 2em">豈果淫者自述其醜亦豈果實見其男女會合代</span>  
<span style="margin-left: 2em">寫其狀不過人心佚蕩相率摹擬形容視爲佳話</span>  
<span style="margin-left: 2em">而讀者因知爲衰世之音推之古人諒亦如是此</span>  
<span style="margin-left: 2em">正採風之微旨亦安得槩以淫者必不自作一語</span>  
<span style="margin-left: 2em">遂謂三百篇内無一淫詩也至於笙詩之說未爲</span>  
<span style="margin-left: 2em">無理然併儀禮而詆爲僞抑又橫矣</span>  
<!-- 册1 葉1520b　Page:文淵閣四庫全書_0001冊.djvu/430 -->
國風省篇一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝毛奇齡撰皆其避讐出亡之時以意說詩之語</span>  
<span style="margin-left: 2em">後追憶而錄之其初設爲問答故名問答後去其</span>  
<span style="margin-left: 2em">問而存其答以其出於追憶故以省篇爲名凡二</span>  
<span style="margin-left: 2em">十六章所論或据他說或自爲斷制雖間有考證</span>  
<span style="margin-left: 2em">要於詩義未能盡合如以黍離爲念亂以雞鳴爲</span>  
<span style="margin-left: 2em">讒人皆憑臆見而失之者也以式微爲黎侯夫人</span>  
<span style="margin-left: 2em">作以衞武公爲殺兄皆據舊說而失之者也至於</span>  
<span style="margin-left: 2em">十畝之間諸篇李塨所作序目已記奇齡自悔之</span>  
<!-- 册1 葉1521a　Page:文淵閣四庫全書_0001冊.djvu/430 -->
<span style="margin-left: 2em">言矣</span>  
詩藴四卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝姜兆錫撰兆錫有周易本義述藴巳著錄是書</span>  
<span style="margin-left: 2em">一以朱子集傳爲宗力攻小序至以僞子貢詩傳</span>  
<span style="margin-left: 2em">僞申培詩說同類而譏未免主持太過於近代諸</span>  
<span style="margin-left: 2em">家之說頗取李光地詩所然惟合集傳者始采之</span>  
<span style="margin-left: 2em">稍有異同卽爲所汰至於木𤓰諸篇知不能全泯</span>  
<span style="margin-left: 2em">舊說則依違兩可於其間尤不免門戸之見矣</span>  
詩經集成三十卷<sub class="note-yuan">江蘇周厚堉家藏本</sub>  
<!-- 册1 葉1521b　Page:文淵閣四庫全書_0001冊.djvu/430 -->
<span style="margin-left: 1em">國朝趙燦英撰燦英字殿颺武進人是書成於康熙</span>  
<span style="margin-left: 2em">庚午大旨爲揣摩場屋之用故首列朱子集傳次</span>  
<span style="margin-left: 2em">敷衍語氣爲串講串講之後爲總解全如坊本高</span>  
<span style="margin-left: 2em">頭講章至總解之後益以近科鄉會試墨卷則益</span>  
<span style="margin-left: 2em">非說經之體矣</span>  
詩經詳說<sub class="note-yuan">無卷數　河南巡撫採進本</sub>  
<span style="margin-left: 1em">國朝冉覲祖撰覲祖有易經詳說已著錄是書以朱</span>  
<span style="margin-left: 2em">子集傳爲主仍採毛鄭孔及宋元以下諸儒之說</span>  
<span style="margin-left: 2em">附錄於下每章小序與集傳並列葢欲尊集傳而</span>  
<!-- 册1 葉1524a　Page:文淵閣四庫全書_0001冊.djvu/431 -->
<span style="margin-left: 2em">又不能盡棄序說欲從小序而又不敢顯悖傳文</span>  
<span style="margin-left: 2em">故其按語率依文講解往往摸棱間有自出新義</span>  
<span style="margin-left: 2em">者如鄭風有女同車謂男女同車爲必無之事改</span>  
<span style="margin-left: 2em">爲二女同車改溱洧爲夫婦偕遊之作又以豳風</span>  
<span style="margin-left: 2em">伐柯爲東人得遂室家之願歸美周公之詞考之</span>  
<span style="margin-left: 2em">古說又皆無所依據也</span>  
詩統說三十二卷<sub class="note-yuan">左都御史黃登賢家藏本</sub>  
<span style="margin-left: 1em">國朝黃叔琳撰叔琳有研北易抄巳著錄是編雜採</span>  
<span style="margin-left: 2em">諸家詩說分類抄錄所摭頗爲繁富而朱墨縱橫</span>  
<!-- 册1 葉1524b　Page:文淵閣四庫全書_0001冊.djvu/431 -->
<span style="margin-left: 2em">塗乙未定葢猶草創之本也前後無序䟦亦無目</span>  
<span style="margin-left: 2em">錄以其排纂之例推之十四卷以前皆總論詩之</span>  
<span style="margin-left: 2em">綱領十五卷乃依經文次第而論之不列經文惟</span>  
<span style="margin-left: 2em">集衆說故以統說爲名云</span>  
毛詩通義十四卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝方葇如撰葇如有周易通義巳著錄是書但列</span>  
<span style="margin-left: 2em">經文別無訓釋各章之下必引四書一兩句以証</span>  
<span style="margin-left: 2em">之如關雎章卽引君子之道造端乎夫婦葛覃章</span>  
<span style="margin-left: 2em">卽引夫人蠶繅以爲衣服之類至於墻有茨篇無</span>  
<!-- 册1 葉1525a　Page:文淵閣四庫全書_0001冊.djvu/431 -->
<span style="margin-left: 2em">可附會則謂宣姜所生如壽如文公如宋桓及許</span>  
<span style="margin-left: 2em">穆夫人皆有賢德引犁牛之子騂且角句殆於以</span>  
<span style="margin-left: 2em">經爲戲矣</span>  
詩經測義四卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝李鍾僑撰鍾僑字世邠安溪人康熙壬辰進士</span>  
<span style="margin-left: 2em">官翰林院編修降補國子監丞是編不載正文隨</span>  
<span style="margin-left: 2em">其所見各爲評論大旨以夫子未嘗刪詩特據所</span>  
<span style="margin-left: 2em">得編之而巳若謂三千刪爲三百則春秋時君卿</span>  
<span style="margin-left: 2em">大夫所賦多三百篇中所有且其人皆在夫子之</span>  
<!-- 册1 葉1525b　Page:文淵閣四庫全書_0001冊.djvu/431 -->
<span style="margin-left: 2em">前豈能預合聖人之意而去取之風雅正變之說</span>  
<span style="margin-left: 2em">亦難據楚茨以下瞻洛諸篇皆承平之作而列之</span>  
<span style="margin-left: 2em">於變平王之孫列在二南編詩不必以正變爲<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2634.svg?width=24" alt="四庫全書僻字第2634號（低）" title="四庫全書僻字第2634號（低）"></span>
