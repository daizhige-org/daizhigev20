## 欽定四庫全書總目 卷一百二十　子部三十　雜家類四

<!-- 册3 葉2389a　Page:文淵閣四庫全書_0003冊.djvu/602 -->
欽定四庫全書總目卷一百二十  
<span style="margin-left: 1em">子部三十</span>  
<span style="margin-left: 2em">雜家𩔖四</span>  
論衡三十卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">漢王充撰充字仲任上虞人自紀謂在縣爲掾功</span>  
<span style="margin-left: 2em">曹在都尉府位亦掾功曹在太守爲列掾五官功</span>  
<span style="margin-left: 2em">曹行事又稱永和三年徙家辟詣揚州部丹陽九</span>  
<span style="margin-left: 2em">江廬江復入爲治中章和二年罷州家居其書凡</span>  
<span style="margin-left: 2em">八十五篇而第四十四招致篇有錄無書實八十</span>  
<!-- 册3 葉2389b　Page:文淵閣四庫全書_0003冊.djvu/602 -->
<span style="margin-left: 2em">四篇考其自紀曰書雖文重所論百種案古太公</span>  
<span style="margin-left: 2em">望近董仲舒傳作書篇百有餘吾書亦纔出百而</span>  
<span style="margin-left: 2em">云太多然則原書實百餘篇此本目錄八十五篇</span>  
<span style="margin-left: 2em">已非其舊矣充書大旨詳於自紀一篇葢内傷時</span>  
<span style="margin-left: 2em">命之坎坷外疾世俗之虛僞故發憤著書其言多</span>  
<span style="margin-left: 2em">激刺孟問孔二篇至於奮其筆端以與聖賢相軋</span>  
<span style="margin-left: 2em">可謂誖矣又露才揚已好爲物先至於述其祖父</span>  
<span style="margin-left: 2em">頑狠以自表所長傎亦甚焉其他論辨如日月不</span>  
<span style="margin-left: 2em">圓諸說雖爲葛洪所駁載在晉志然大抵訂訛砭</span>  
<!-- 册3 葉2392a　Page:文淵閣四庫全書_0003冊.djvu/603 -->
<span style="margin-left: 2em">俗中理者多亦殊有禆於風教儲泳袪疑說謝應</span>  
<span style="margin-left: 2em">芳辨惑編不是過也至其文反覆詰難頗傷詞費</span>  
<span style="margin-left: 2em">則充所謂宅舍多土地不得小戸口衆簿籍不得</span>  
<span style="margin-left: 2em">少失實之事多虛華之語衆指實定宜辨爭之言</span>  
<span style="margin-left: 2em">安得約徑者固已自言之矣充所作别有譏俗書</span>  
<span style="margin-left: 2em">政務書晩年又作養性書今皆不傳惟此書存儒</span>  
<span style="margin-left: 2em">者頗病其蕪雜然終不能廢也高似孫子略曰袁</span>  
<span style="margin-left: 2em">崧後漢書載充作論衡中土未有傳者蔡邕入吳</span>  
<span style="margin-left: 2em">始見之以爲談助談助之言可以了此書矣其論</span>  
<!-- 册3 葉2392b　Page:文淵閣四庫全書_0003冊.djvu/603 -->
<span style="margin-left: 2em">可云允愜此所以攻之者衆而好之者終不絶歟</span>  
風俗通義十卷附錄一卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">漢應劭撰劭字仲遠汝南人嘗舉孝廉中平六年</span>  
<span style="margin-left: 2em">爲泰山太守事迹具後漢書本傳馬總意林稱爲</span>  
<span style="margin-left: 2em">三國時人不知何據也考隋書經籍志風俗通義</span>  
<span style="margin-left: 2em">三十一卷注云錄一卷應劭撰梁三十卷唐書藝</span>  
<span style="margin-left: 2em">交志應劭風俗通義三十卷崇文總目讀書志書</span>  
<span style="margin-left: 2em">錄解題皆作十卷與今本同明吳琯刻古今逸史</span>  
<span style="margin-left: 2em">又刪其半則更缺畧矣各卷皆有總題題各有散</span>  
<!-- 册3 葉2393a　Page:文淵閣四庫全書_0003冊.djvu/603 -->
<span style="margin-left: 2em">目總題後畧陳大意而散目先詳其事以謹按云</span>  
<span style="margin-left: 2em">云辨證得失皇霸爲目五正失爲目十一愆禮爲</span>  
<span style="margin-left: 2em">目九過譽爲目八十反爲目十音聲爲目二十有</span>  
<span style="margin-left: 2em">八窮通爲目十二祀典爲目十七怪神爲目十五</span>  
<span style="margin-left: 2em">山澤爲目十九其自序云謂之風俗通義言通於</span>  
<span style="margin-left: 2em">流俗之過謬而事該之於義理也後漢書本傳稱</span>  
<span style="margin-left: 2em">撰風俗通以辨物𩔖名號譏時俗嫌疑不知何以</span>  
<span style="margin-left: 2em">刪去義字或流俗省文如白虎通義之稱白虎通</span>  
<span style="margin-left: 2em">史家因之歟其書因事立論文詞淸辯可實博洽</span>  
<!-- 册3 葉2393b　Page:文淵閣四庫全書_0003冊.djvu/603 -->
<span style="margin-left: 2em">大致如王充論衡而叙述簡明則勝充書之冗漫</span>  
<span style="margin-left: 2em">多矣舊本屢經傳刻失於校讐頗有訛誤如十反</span>  
<span style="margin-left: 2em">𩔖中分范茂伯郅朗伯爲二事而佚其斷語窮通</span>  
<span style="margin-left: 2em">𩔖中孫卿一事有書而無錄怪神𩔖中城陽景王</span>  
<span style="margin-left: 2em">祠一條有錄而無書今並釐正又宋陳彭年等修</span>  
<span style="margin-left: 2em">廣韻王應麟作姓氏急就篇多引風俗通姓氏篇</span>  
<span style="margin-left: 2em">是此篇至宋末猶存今本無之不知何時散佚然</span>  
<span style="margin-left: 2em">考元大德丁未無錫儒學刊本前有李果序後有</span>  
<span style="margin-left: 2em">宋嘉定十三年丁黼䟦䟦稱余在餘杭借本於會</span>  
<!-- 册3 葉2396a　Page:文淵閣四庫全書_0003冊.djvu/604 -->
<span style="margin-left: 2em">稽陳正卿正卿葢得於中書徐淵子訛舛已甚殆</span>  
<span style="margin-left: 2em">不可讀愛其近古鈔錄藏之擕至中都得倌中本</span>  
<span style="margin-left: 2em">及孔復君寺丞木互加叅考始可句讀今刻之於</span>  
<span style="margin-left: 2em">䕫府好古者或得舊本從而增改是所望云則宋</span>  
<span style="margin-left: 2em">寧宗時之本已同今本不知王氏何以得見是篇</span>  
<span style="margin-left: 2em">或卽從廣韻注中輾轉授引歟永樂大典通字韻</span>  
<span style="margin-left: 2em">中尚載有風俗通姓氏一篇首題馬總意林字所</span>  
<span style="margin-left: 2em">載與廣韻註多同而不及廣韻註之詳葢馬總節</span>  
<span style="margin-left: 2em">本也然今木意林無此文當又屬佚脫今採附風</span>  
<!-- 册3 葉2396b　Page:文淵閣四庫全書_0003冊.djvu/604 -->
<span style="margin-left: 2em">俗通之末存梗槩焉</span>  
封氏聞見記十卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">唐封演撰演里貫未詳考封氏自西晉北魏以來</span>  
<span style="margin-left: 2em">世爲渤海蓚人然唐書宰相世系表中無演名疑</span>  
<span style="margin-left: 2em">其疎屬也書中石經一條稱天寳中爲太學生貢</span>  
<span style="margin-left: 2em">舉一條記其登第時張繟有千佛名經之戲然不</span>  
<span style="margin-left: 2em">云登第在何年佛圖澄碑一條記大厯中行縣至</span>  
<span style="margin-left: 2em">内邱則嘗刺邢州卷首結銜題朝散大夫檢校尚</span>  
<span style="margin-left: 2em">書吏部郞中兼御史中丞而尊號一條記貞元間</span>  
<!-- 册3 葉2397a　Page:文淵閣四庫全書_0003冊.djvu/604 -->
<span style="margin-left: 2em">事則德宗時終於是官也足書唐宋藝文志通志</span>  
<span style="margin-left: 2em">通攷皆作五卷書錄解題作二卷殆輾轉傳抄互</span>  
<span style="margin-left: 2em">有分合此本十卷未有元至正辛丑夏庭芝䟦又</span>  
<span style="margin-left: 2em">有吴峬朱良育孫允伽陸貽典四䟦良育䟦云自</span>  
<span style="margin-left: 2em">六卷至十卷友人唐子畏見借所抄近又於柳大</span>  
<span style="margin-left: 2em">中借鈔前五卷第七卷中全局俱欠只存末後一</span>  
<span style="margin-left: 2em">𥿄耳今攷目錄所列凡一百一條第一卷僅二條</span>  
<span style="margin-left: 2em">不盈兩𥿄亦似不完第三卷銓曹一條闕其末而</span>  
<span style="margin-left: 2em">風憲一條全佚不止闕第七卷第七卷中視物遠</span>  
<!-- 册3 葉2397b　Page:文淵閣四庫全書_0003冊.djvu/604 -->
<span style="margin-left: 2em">近一條海潮一條北方白虹一條西風則雨一條</span>  
<span style="margin-left: 2em">松柏西向一條皆全佚蜀無兔鴿一條佚其前半</span>  
<span style="margin-left: 2em">月桂子一條僅完其下石鼔一條<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2959.svg?width=24" alt="四庫全書僻字第2959號（弦）" title="四庫全書僻字第2959號（弦）">歌驛一條又</span>  
<span style="margin-left: 2em">闕高唐館一條亦完其下温湯一條又闕其末而</span>  
<span style="margin-left: 2em">目録此條之下註増字亦非僅存末一頁者中間</span>  
<span style="margin-left: 2em">又頗多闕字允伽䟦稱借秦酉巖本重校意其與</span>  
<span style="margin-left: 2em">朱本小異歟然稱朱䟦從秦本錄出則又不川解</span>  
<span style="margin-left: 2em">疑久無刊木逓相繕寫又非復朱氏之舊矣唐人</span>  
<span style="margin-left: 2em">小說多涉荒怪此書獨語必徵實前六卷多陳掌</span>  
<!-- 册3 葉2400a　Page:文淵閣四庫全書_0003冊.djvu/605 -->
<span style="margin-left: 2em">故七八兩卷多記古跡及雜論均足以資考證未</span>  
<span style="margin-left: 2em">二卷則全載當時士大夫軼事嘉言善行居多惟</span>  
<span style="margin-left: 2em">末附諧語數條而已其中音韻一條記唐韻部分</span>  
<span style="margin-left: 2em">爲陸法言之舊其同用獨用則許敬宗所定爲諸</span>  
<span style="margin-left: 2em">書之所未言文字一條論𨽻書不始程邈援水經</span>  
<span style="margin-left: 2em">註爲證明楊愼矜爲獨見者乃演之所已言又顏</span>  
<span style="margin-left: 2em">眞卿韻海鏡源世無傳本此書詳記其體例知元</span>  
<span style="margin-left: 2em">陰時夫韻府羣玉實源於此而周亮工書影稱眞</span>  
<span style="margin-left: 2em">卿取句首字不取句末字者其說爲杜撰欺人併</span>  
<!-- 册3 葉2400b　Page:文淵閣四庫全書_0003冊.djvu/605 -->
<span style="margin-left: 2em">知永樂大典列篆𨽻諸體於字下乃從此書竊取</span>  
<span style="margin-left: 2em">其式而諱所自來月中桂一條記桂子月中落一</span>  
<span style="margin-left: 2em">聯爲宋之問台州詩足證計有功唐詩紀事駱賓</span>  
<span style="margin-left: 2em">王爲僧之妄他如論金鷄露布鹵簿官銜石誌碑</span>  
<span style="margin-left: 2em">碣羊虎㧞河諸條亦皆原委詳明唐人說部自顏</span>  
<span style="margin-left: 2em">師古匡謬正俗李匡乂資暇集李涪刊誤之外固</span>  
<span style="margin-left: 2em">罕其比偶矣</span>  
尚書故實一卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">唐李綽撰綽仕履未詳考新唐書宰相世系表趙</span>  
<!-- 册3 葉2401a　Page:文淵閣四庫全書_0003冊.djvu/605 -->
<span style="margin-left: 2em">郡李氏南祖之後有名綽字肩孟者爲吏部侍郎</span>  
<span style="margin-left: 2em">紓之曾孫書中自稱趙郡人或卽其人歟宋史藝</span>  
<span style="margin-left: 2em">文志凡兩載之一見史部傳記𩔖一見子部小說</span>  
<span style="margin-left: 2em">𩔖而注其下云綽一作緯實一作事今按曾慥𩔖</span>  
<span style="margin-left: 2em">說所引亦明標李綽之名則作緯者悞矣自序稱</span>  
<span style="margin-left: 2em">賓護尚書張公三相盛門博物多聞綽避難圃田</span>  
<span style="margin-left: 2em">毎容侍話凡聆徵引必異尋常遂纂集尤異作此</span>  
<span style="margin-left: 2em">書葢皆據張尚書之所述也惟張尚書不著其名</span>  
<span style="margin-left: 2em">新唐書藝文志沿崇文總目之訛以張尚書爲卽</span>  
<!-- 册3 葉2401b　Page:文淵閣四庫全書_0003冊.djvu/605 -->
<span style="margin-left: 2em">延賞晁公武陳振孫已斥其誤然書中稱嘉貞爲</span>  
<span style="margin-left: 2em">四世祖又稱嘉祐爲高伯祖則所謂張尚書者當</span>  
<span style="margin-left: 2em">在彦遠天保彦修曼容諸兄弟中其文規次宗乃</span>  
<span style="margin-left: 2em">宏靖子於嘉貞爲曾孫不可稱高祖振孫乃皆以</span>  
<span style="margin-left: 2em">其不登八座爲疑亦非也觀其言賓護移知廣陵</span>  
<span style="margin-left: 2em">又言公除潞州旌節則必嘗爲揚州刺史昭義節</span>  
<span style="margin-left: 2em">度使者當以史於天保諸人下畧其官位遂致無</span>  
<span style="margin-left: 2em">可考耳其書雜記近事亦兼考舊聞如司馬承禎</span>  
<span style="margin-left: 2em">王谷盧元公尉遲迴韋卿材謝眞人淪落衣冠章</span>  
<!-- 册3 葉2404a　Page:文淵閣四庫全書_0003冊.djvu/606 -->
<span style="margin-left: 2em">仇兼瓊郭承嘏諸條雖頗涉語怪然如蘭亭叙入</span>  
<span style="margin-left: 2em">昭陵顧長康畫清夜遊西園圖謝赫李嗣眞評畫</span>  
<span style="margin-left: 2em">百衲琴戴顒刻佛像碧落碑狸骨帖寳章集靈芝</span>  
<span style="margin-left: 2em">殿佛教屬<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">宿冒黎生改金根車謝安無字碑鄭</span>  
<span style="margin-left: 2em">三絶顧况工畫諸軼事皆出此書而墓碑有圓空</span>
