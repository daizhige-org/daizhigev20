明太祖文集二十卷<sub class="note-yuan">兩江總督採進本</sub>

<span style="margin-left: 2em">事沈鈇仝校刋分十八類曰詔曰制曰誥曰書曰</span>  
<span style="margin-left: 2em">勅命曰䇿問曰勅問曰論曰樂章曰樂歌曰文曰</span>  
<span style="margin-left: 2em">碑曰記曰序曰說曰雜著曰祭文曰詩按太祖集</span>  
<span style="margin-left: 2em">初刻於洪武七年劉基及宋濂文集所載序文俱</span>  
<!-- 册4 葉1813b　Page:文淵閣四庫全書_0004冊.djvu/458 -->
<span style="margin-left: 2em">云五卷稱翰林學士樂韶鳳所編錄然黄虞稷千</span>  
<span style="margin-left: 2em">頃堂書目已不著錄所著錄者有太祖文集三十</span>  
<span style="margin-left: 2em">卷注曰甲集二卷乙集三卷丙集文十四卷詩一</span>  
<span style="margin-left: 2em">卷丁集十卷又太祖文集類編十二卷又太祖詩</span>  
<span style="margin-left: 2em">集五卷又太祖御製書稿三卷均與此本不符焦</span>  
<span style="margin-left: 2em">竑國史經籍志列太祖文集二十卷又三十卷此</span>  
<span style="margin-left: 2em">本卷數與竑所列前一本合當卽竑所著錄歟其</span>  
<span style="margin-left: 2em">刻在萬厯十四年編次不知出誰手目録之末有</span>  
<span style="margin-left: 2em">姚士觀等䟦語乃據舊本刻於中都亦未能詳考</span>  
<!-- 册4 葉1816a　Page:文淵閣四庫全書_0004冊.djvu/459 -->
<span style="margin-left: 2em">所自來也考朱彛尊明詩綜載有太祖神鳳操一</span>  
<span style="margin-left: 2em">首而集内無之則亦未爲賅備然所謂三十卷者</span>  
<span style="margin-left: 2em">今未見傳本其存佚均未可知近時諸家所藏弆</span>  
<span style="margin-left: 2em">大抵皆卽士觀等所刻今亦據以著錄存有明一</span>  
<span style="margin-left: 2em">代開國之著作焉</span>  
宋學士全集三十六卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明宋濂撰濂有篇海類編已著錄元末文章以吳</span>  
<span style="margin-left: 2em">萊柳貫黃溍爲一朝之後勁濂初從萊學旣又學</span>  
<span style="margin-left: 2em">於貫與溍其授受具有源流又早從聞人夢吉講</span>  
<!-- 册4 葉1816b　Page:文淵閣四庫全書_0004冊.djvu/459 -->
<span style="margin-left: 2em">貫五經其學問亦具有根柢明史濂本傳稱其自</span>  
<span style="margin-left: 2em">少至老未嘗一日去書卷於學無所不通爲文醇</span>  
<span style="margin-left: 2em">深演迤與古作者並在朝郊社宗廟山川百神之</span>  
<span style="margin-left: 2em">典朝會燕饗律厯衣冠之制四裔貢賦賞勞之儀</span>  
<span style="margin-left: 2em">旁及元勲巨卿碑記刻石之詞咸以委濓爲開國</span>  
<span style="margin-left: 2em">文臣之首士大夫造門乞文者後先相踵外國貢</span>  
<span style="margin-left: 2em">使亦知其名高麗安南日本至出兼金購其文集</span>  
<span style="margin-left: 2em">劉基傳中又稱所爲文章氣昌而竒與濂並爲一</span>  
<span style="margin-left: 2em">代之宗今觀二家之集濂文雍容渾穆如天閑良</span>  
<!-- 册4 葉1817a　Page:文淵閣四庫全書_0004冊.djvu/459 -->
<span style="margin-left: 2em">驥魚魚雅雅自中節度基文神鋒四出如千金駿</span>  
<span style="margin-left: 2em">足飛騰飄瞥驀澗注坡雖皆極天下之選而以德</span>  
<span style="margin-left: 2em">以力則畧有間矣方孝孺受業於濂努力繼之然</span>  
<span style="margin-left: 2em">較其品格亦終如蘇之與歐蓋基講經世之畧所</span>  
<span style="margin-left: 2em">學不及濂之醇孝孺自命太高意氣太盛所養不</span>  
<span style="margin-left: 2em">及濂之粹也</span>  
宋景濂未刻集二卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明宋濂撰濂集重刻於嘉靖中行世已久此本乃</span>  
<span style="margin-left: 1em">國朝順治乙未濂裔孫實頴得文徴明家所藏舊稿</span>  
<!-- 册4 葉1817b　Page:文淵閣四庫全書_0004冊.djvu/459 -->
<span style="margin-left: 2em">以示金壇蔣超超擇其中今本未載者得三十八</span>  
<span style="margin-left: 2em">篇編爲此集以補其遺今以韓叔陽刻本重勘其</span>  
<span style="margin-left: 2em">中䟦何道夫所著宣撫鄭公墓銘等十一篇皆今</span>  
<span style="margin-left: 2em">本所已載超蓋檢之未審其餘二十七篇則實屬</span>  
<span style="margin-left: 2em">佚文推究當日之意蓋或以元代功臣諸頌及誌</span>  
<span style="margin-left: 2em">銘諸篇大抵作於前朝至明不免有所諱或以尊</span>  
<span style="margin-left: 2em">崇二氏不免過當嫌於躭溺異學而隱之觀楊士</span>  
<span style="margin-left: 2em">竒東里集倪謙文僖集並用楊傑無爲集例凡爲</span>  
<span style="margin-left: 2em">二氏而作者皆别爲卷帙附綴末簡不散入各體</span>  
<!-- 册4 葉1820a　Page:文淵閣四庫全書_0004冊.djvu/460 -->
<span style="margin-left: 2em">之中則正德嘉靖以前士大夫之持論可大畧覩</span>  
<span style="margin-left: 2em">矣然古來操觚之士如韓愈之於高閑文暢持論</span>  
<span style="margin-left: 2em">終始謹嚴固其正也其餘若蘇黃諸集不入學𣲖</span>  
<span style="margin-left: 2em">者勿論至於胡寅眞德秀皆講學家所謂大儒致</span>  
<span style="margin-left: 2em">堂西山二集此類正復不少蓋文章一道隨事立</span>  
<span style="margin-left: 2em">言與訓詁經義排纂語錄其例小殊宋儒尚不能</span>  
<span style="margin-left: 2em">拘則濂作釋老之文又何必欲滅其迹歟</span>  
誠意伯文集二十卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明劉基撰基有國初禮賢錄已著錄其詩文雜著</span>  
<!-- 册4 葉1820b　Page:文淵閣四庫全書_0004冊.djvu/460 -->
<span style="margin-left: 2em">凡郁離子四卷覆瓿集十卷寫情集二卷春秋明</span>  
<span style="margin-left: 2em">經二卷犂眉集二卷本各自爲書成化中巡按浙</span>  
<span style="margin-left: 2em">江御史戴鱀等始合爲一帙而冠以基孫廌等所</span>  
<span style="margin-left: 2em">撰翊運錄蓋以中載詔旨制勅故列之卷首然其</span>  
<span style="margin-left: 2em">書究屬廌編用以編入卷數使此集標基之名而</span>  
<span style="margin-left: 2em">開卷乃他人之書殊乖體例今移綴是錄於末簡</span>  
<span style="margin-left: 2em">以正其訛餘十九卷則悉仍戴本之原次以存其</span>  
<span style="margin-left: 2em">舊基遭逢興運參預帷幄秘計深謀多所稗贊世</span>  
<span style="margin-left: 2em">遂謬謂爲前知凡䜟緯術數之說一切附會於基</span>  
<!-- 册4 葉1821a　Page:文淵閣四庫全書_0004冊.djvu/460 -->
<span style="margin-left: 2em">神怪謬妄無所不至方技家逓相熒惑百無一眞</span>  
<span style="margin-left: 2em">惟此一集尚眞出基手其詩沈鬱頓挫自成一家</span>  
<span style="margin-left: 2em">足與高啟相抗其文閎深肅括亦宋濂王禕之亞</span>  
<span style="margin-left: 2em">楊守陳序謂子房之䇿不見詞章元齡之文僅辦</span>  
<span style="margin-left: 2em">符檄未見樹開國之勲業而兼傳世之文章可謂</span>  
<span style="margin-left: 2em">千古人豪斯言允矣大抵其學問智畧如耶律楚</span>  
<span style="margin-left: 2em">材劉秉忠而文章則非二人所及也</span>  
鳳池吟稿十卷<sub class="note-yuan">浙江汪汝瑮家藏本</sub>  
<span style="margin-left: 2em">明汪廣洋撰廣洋字朝宗高郵人流寓太平元末</span>  
<!-- 册4 葉1821b　Page:文淵閣四庫全書_0004冊.djvu/460 -->
<span style="margin-left: 2em">舉進士太祖渡江召爲元師府令史官至右丞相</span>  
<span style="margin-left: 2em">封忠勤伯洪武十二年坐貶廣南於中途賜死事</span>  
<span style="margin-left: 2em">蹟具明史本傳廣洋有幹濟才屢叅政柄亦無他</span>  
<span style="margin-left: 2em">罪惡徒以初與楊憲同爲中書左右丞又與胡惟</span>  
<span style="margin-left: 2em">庸同爲左右丞相俱隱忍依違不能發其姦狀卒</span>  
<span style="margin-left: 2em">以黨誅蓋巧宦而適以巧敗故史稱其有負於爰</span>  
<span style="margin-left: 2em">立至於學問文章則史稱少師余闕淹通經史善</span>  
<span style="margin-left: 2em">篆𨽻工爲歌詩今觀是集大都淸剛典重一洗元</span>  
<span style="margin-left: 2em">人纎媚之習朱彛尊靜志居詩話嘗摘其五言之</span>  
<!-- 册4 葉1824a　Page:文淵閣四庫全書_0004冊.djvu/461 -->
<span style="margin-left: 2em">平沙誰戲馬落日自登臺湖水當門落松雲傍枕</span>  
<span style="margin-left: 2em">浮懷人當永夜看月上疎桐對客開春酒當門掃</span>  
<span style="margin-left: 2em">落花天垂芳草地漁唱夕陽村等句數十聯以爲</span>  
<span style="margin-left: 2em">可入唐人主客圖靜居北郭猶當遜之毋論孟載</span>  
<span style="margin-left: 2em">其論頗爲允愜雖當時爲宋濂諸人盛名所掩世</span>  
<span style="margin-left: 2em">不甚稱然觀其遺作究不愧一代開國之音也</span>  
陶學士集二十卷<sub class="note-yuan">浙江汪汝瑮家藏本</sub>  
<span style="margin-left: 2em">明陶安撰安字主靜當塗人元至正八年中浙江</span>  
<span style="margin-left: 2em">鄉試入明官至江西行省參知政事事蹟具明史</span>  
<!-- 册4 葉1824b　Page:文淵閣四庫全書_0004冊.djvu/461 -->
<span style="margin-left: 2em">本傳其詩一曰辭達集一曰知新近稿一曰黃崗</span>  
<span style="margin-left: 2em">寓稿一曰鶴沙小記一曰江行雜咏本各自爲集</span>  
<span style="margin-left: 2em">此本分體編次與所作賦詞共爲十卷其文亦十</span>  
<span style="margin-left: 2em">卷而送人之序引居其半或以安文章宿望人得</span>  
<span style="margin-left: 2em">其贈言以爲榮故求之者多耶又安以儒臣司著</span>  
<span style="margin-left: 2em">作於郊社宗廟典禮皆有奏議若明初分祭南北</span>  
<span style="margin-left: 2em">郊及四代各一廟之制皆定於安又刑律亦安所</span>  
<span style="margin-left: 2em">裁而集中均不載其文殆以朝廷公牘同署者不</span>  
<span style="margin-left: 2em">一人故不復列入私集也世言祝壽之序自歸有</span>  
<!-- 册4 葉1825a　Page:文淵閣四庫全書_0004冊.djvu/461 -->
<span style="margin-left: 2em">光始入集考此集已有二篇則不自有光始矣安</span>  
<span style="margin-left: 2em">聲價亞於宋濂然學術深醇其詞皆平正典實有</span>  
<span style="margin-left: 2em">先正遺風一代開國之初應運而生者其氣象固</span>  
<span style="margin-left: 2em">終不侔也</span>  
西隱集十卷<sub class="note-yuan">浙江汪汝瑮家藏本</sub>  
<span style="margin-left: 2em">明宋訥撰訥字仲敏滑縣人元至正中舉進士官</span>  
<span style="margin-left: 2em">鹽山知縣洪武十三年徴爲國子助教陞翰林學</span>  
<span style="margin-left: 2em">士文淵閣大學士遷國子祭酒卒正德中追諡文</span>  
<span style="margin-left: 2em">恪事蹟具明史本傳劉三吾撰訥墓誌稱所著西</span>  
<!-- 册4 葉1825b　Page:文淵閣四庫全書_0004冊.djvu/461 -->
<span style="margin-left: 2em">隱集十七卷而明史藝文志黄虞稷千頃堂書目</span>  
<span style="margin-left: 2em">俱作十卷此本有東萊劉師魯序稱其集初爲上</span>  
<span style="margin-left: 2em">海張趨所手錄滑人王崇之令上海從其後求得</span>  
<span style="margin-left: 2em">而刻之嵗久漫漶師魯因鳩工重刻蓋卽十卷之</span>  
<span style="margin-left: 2em">本豈張趨繕録之時又有所删併故與墓誌不合</span>  
<span style="margin-left: 2em">歟集前四卷爲賦詩後六卷爲雜文附以明太祖</span>  
<span style="margin-left: 2em">手勅四道及白雲茅屋賦二篇記一篇白雲茅屋</span>  
<span style="margin-left: 2em">者訥所築别墅之名也訥領成均冑子之任師道</span>  
<span style="margin-left: 2em">嚴正爲一時典型文章亦渾厚醇雅其奉勅製太</span>  
<!-- 册4 葉1828a　Page:文淵閣四庫全書_0004冊.djvu/462 -->
<span style="margin-left: 2em">學碑極爲太祖所賞今具載集中又有壬子嵗考</span>  
<span style="margin-left: 2em">試秋闈次北平詩及秋闈卽事諸詩壬子乃洪武</span>  
<span style="margin-left: 2em">六年蓋訥未仕之前已應聘爲北平考官而本傳</span>  
<span style="margin-left: 2em">墓誌均未之載其過元故官詩十九首尤纒綿悱</span>  
<span style="margin-left: 2em">惻有風人忠厚之遺朱彛尊靜志居詩話甚推其</span>  
<span style="margin-left: 2em">半船凉色潮生海兩岸秋風浪拍沙華表柱頭相</span>  
<span style="margin-left: 2em">語鶴秣陵江上獨歸鴻諸佳句云</span>
