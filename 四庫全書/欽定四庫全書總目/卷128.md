欽定四庫全書總目卷一百二十八  
<span style="margin-left: 1em">子部三十八</span>  
<span style="margin-left: 2em">雜家𩔖存目五</span>  
應菴任意錄十四卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明羅鶴撰鶴字子應號應菴泰和人是書計二百</span>  
<span style="margin-left: 2em">四十四條大意欲仿容齋隨筆學齋佔𠌫諸書而</span>  
<span style="margin-left: 2em">耳目頗隘不能盡有援据考證多據所聞見以意</span>  
<span style="margin-left: 2em">褒貶而已其持論有最偏駁者如赤龍合慶都生</span>  
<span style="margin-left: 2em">堯修已拆背生禹本緯書妄說皆反覆論辨以爲</span>  
<!-- 册3 葉3009b　Page:文淵閣四庫全書_0003冊.djvu/757 -->
<span style="margin-left: 2em">必然又引章氏家譜宏益記聞東林論易語尹氏</span>  
<span style="margin-left: 2em">性學指要趙說之心學淵源後跋胡氏大同論一</span>  
<span style="margin-left: 2em">切𤨏說文致周程諸儒皆以僧爲師至以鄕曲之</span>  
<span style="margin-left: 2em">私謂建文遜國之時楊士竒不當死難使務此小</span>  
<span style="margin-left: 2em">飾則不足以爲東里尤爲害義其謂吕后名雉高</span>  
<span style="margin-left: 2em">祖字之曰野鷄之𩔖杜撰故實又其小疵矣</span>  
路史二卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">舊本題靑藤山人撰靑藤山人徐渭别號也渭有</span>  
<span style="margin-left: 2em">筆元要㫖已著錄渭以才俊名一時然惟書畫有</span>  
<!-- 册3 葉3012a　Page:文淵閣四庫全書_0003冊.djvu/758 -->
<span style="margin-left: 2em">逸氣詩文巳么<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2959.svg?width=24" alt="四庫全書僻字第2959號（弦）" title="四庫全書僻字第2959號（弦）">側調不入正聲至考証之功益</span>  
<span style="margin-left: 2em">爲疎舛是編蓋其襍記之冊王士禎香祖筆記嘗</span>  
<span style="margin-left: 2em">議其不知隃麋爲漢縣而妄云唐時高麗貢墨以</span>  
<span style="margin-left: 2em">麋膠和松烟謂之隃麋又云中山酒中山兔毫並</span>  
<span style="margin-left: 2em">是應天府溧水縣非古中山亦出杜撰今考其書</span>  
<span style="margin-left: 2em">𤨏事多據事文𩔖聚訓詁多據洪武正韻故事多</span>  
<span style="margin-left: 2em">據十七史詳節頗爲弇陋甚至檀弓之髽指爲䘮</span>  
<span style="margin-left: 2em">冠月令之大酋指爲周禮以暨季江爲江季以寒</span>  
<span style="margin-left: 2em">具爲寒食之具種種臆談不可枚舉至云劉歆字</span>  
<!-- 册3 葉3012b　Page:文淵閣四庫全書_0003冊.djvu/758 -->
<span style="margin-left: 2em">子駿向之少子亦記爲異聞則更無謂矣</span>  
梅花草堂筆談十四卷二談六卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明張大復撰大復字元長崑山人是編爲其梅花</span>  
<span style="margin-left: 2em">草堂集中之一種據江南通志文苑傳乃其䘮明</span>  
<span style="margin-left: 2em">以後追憶而作也所記皆同社酬答之語間及鄕</span>  
<span style="margin-left: 2em">里𤨏事辭意纎佻無關考証第十三卷中有論孟</span>  
<span style="margin-left: 2em">解十二條以釋家語詮解聖經殊屬支離二談輕</span>  
<span style="margin-left: 2em">佻尤甚如云水滸傳何所不有却無破老一事<sub class="note-yuan">案美</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">男破老逸周書之文</sub>非闗缺䧟恰是酒肉漢本色如此以此</span>  
<!-- 册3 葉3013a　Page:文淵閣四庫全書_0003冊.djvu/758 -->
<span style="margin-left: 2em">益知作者之妙是何言歟</span>  
聞雁齋筆談六卷<sub class="note-yuan">浙江鮑士㳟家藏本</sub>  
<span style="margin-left: 2em">明張大復撰是編大抵欲仿蘇軾志林故多似古</span>  
<span style="margin-left: 2em">人襍帖短跋之格然所推重者李贄所規摹者屠</span>  
<span style="margin-left: 2em">隆也</span>  
河上楮談三卷<sub class="note-yuan">江西廵撫採進本</sub>  
<span style="margin-left: 2em">明朱孟震撰孟震字秉器新淦人隆慶戊辰進士</span>  
<span style="margin-left: 2em">官至右副都御史廵撫山西是書多述舊聞軼事</span>  
<span style="margin-left: 2em">間或評論詩文考證典籍亦頗喜談神怪其停雲</span>  
<!-- 册3 葉3013b　Page:文淵閣四庫全書_0003冊.djvu/758 -->
<span style="margin-left: 2em">小志一卷記當時文士頗詳所載詩篇多可採錄</span>  
<span style="margin-left: 2em">其論文宗王世貞推爲明代第一則當時耳目所</span>  
<span style="margin-left: 2em">染無足深怪其辨王禕吳雲事甚有典據而遜國</span>  
<span style="margin-left: 2em">一事則全沿史彬致身錄之訛引證愈多舛謬愈</span>  
<span style="margin-left: 2em">甚與所論元順帝出宋後事同一誤信之失其論</span>  
<span style="margin-left: 2em">史記訛字最<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">而前輩博雅一條不知淸江集之</span>  
<span style="margin-left: 2em">現存又誤以孔傳六帖爲三孔所作疎駁亦甚矣</span>  
汾上續談一卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">明朱孟震撰其體例與河上楮談同而所記多𤨏</span>  
<!-- 册3 葉3016a　Page:文淵閣四庫全書_0003冊.djvu/759 -->
<span style="margin-left: 2em">事惟安南國試錄一條叙述頗詳足資考證</span>  
浣水續談一卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">明朱孟震撰是編乃萬厯十三年孟震官四川按</span>  
<span style="margin-left: 2em">察使時所作故以浣水爲名浣水者浣花溪也其</span>  
<span style="margin-left: 2em">書襍撮而成徃徃不著時代亦不著出典如并州</span>  
<span style="margin-left: 2em">士族好爲可笑詩賦一條蓋顔氏家訓之原文而</span>  
<span style="margin-left: 2em">孟震筆之於已書儼如新事然則所謂誂撆邢魏</span>  
<span style="margin-left: 2em">諸公者不幾爲明代之邢魏乎惟松栢灘觀音寺</span>  
<span style="margin-left: 2em">一條考詢遺老繪畫地圖核其墳塔名氏師弟世</span>  
<!-- 册3 葉3016b　Page:文淵閣四庫全書_0003冊.djvu/759 -->
<span style="margin-left: 2em">系知所謂雪菴和尙者在有無疑似之間特爲明</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）"></span>  
游宦餘談一卷<sub class="note-yuan">江西廵撫採進本</sub>  
<span style="margin-left: 2em">明朱孟震撰自序稱生平宦轍殆徧九州因摭耳</span>  
<span style="margin-left: 2em">目所及撰成此書初分五卷後乃併爲一卷所錄</span>  
<span style="margin-left: 2em">多𤨏事末附西南夷風土記二十六條頗爲詳明</span>  
<span style="margin-left: 2em">然孟震序中自言未至滇雲則惟據傳聞書之恐</span>  
<span style="margin-left: 2em">亦未盡<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">實矣</span>  
黄帝祠額解一卷<sub class="note-yuan">兩江總督採進本</sub>  
<!-- 册3 葉3017a　Page:文淵閣四庫全書_0003冊.djvu/759 -->
<span style="margin-left: 2em">明李維楨撰維楨有史通評釋已著錄是書乃其</span>  
<span style="margin-left: 2em">奉詔謁黄帝陵見舊祠取𪔂湖之事額曰龍髯乃</span>  
<span style="margin-left: 2em">作是書以辨其不經謂騎龍卽乘六龍之義其實</span>  
<span style="margin-left: 2em">子華子已有是說無庸復贅又舉百家所言黄帝</span>  
<span style="margin-left: 2em">神靈諸事一一駁詰詞極辨博實亦司馬遷五帝</span>  
<span style="margin-left: 2em">本紀文不雅馴薦紳難言之緒論也</span>  
木几冗談一卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">明彭汝讓撰汝讓字欽之靑浦人是編乃劄記淸</span>  
<span style="margin-left: 2em">言儇佻殊甚蓋屠隆一𣲖也</span>  
<!-- 册3 葉3017b　Page:文淵閣四庫全書_0003冊.djvu/759 -->
說頤八卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明余懋學撰懋學字行之婺源人隆慶戊辰進士</span>  
<span style="margin-left: 2em">官至南京戸部右侍郎天啟中追諡恭穆事迹具</span>  
<span style="margin-left: 2em">明史本傳是書凡三百五十二則毎則徵引古事</span>  
<span style="margin-left: 2em">相𩔖或相反者二條撮爲四字標題而以論斷數</span>  
<span style="margin-left: 2em">語綴其末旁見側出頗得連珠遺意然引事不標</span>  
<span style="margin-left: 2em">出典置論亦多庸膚</span>  
留靑日札三十九卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">明田藝衡撰藝衡有大明同文集已著錄是書欲</span>  
<!-- 册3 葉3020a　Page:文淵閣四庫全書_0003冊.djvu/760 -->
<span style="margin-left: 2em">仿容齋隨筆夢溪筆談而所學不足以逮之故蕪</span>  
<span style="margin-left: 2em">襍特甚其中詩談初編二編各一卷玉笑零音一</span>  
<span style="margin-left: 2em">卷大統厯解三卷始天易一卷皆以所著别行之</span>  
<span style="margin-left: 2em">書編入以足卷帙尤可不必</span>  
玉笑零音一卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明田藝衡撰是書皆采取新竒故事緯以儷語凡</span>  
<span style="margin-left: 2em">一百二十八條其中如以堯舜之讓天下爲愛身</span>  
<span style="margin-left: 2em">不與朱均以天下爲愛子舜禹之受天下爲不知</span>  
<span style="margin-left: 2em">害鑄𪔂爲鎭厭之術金縢爲詛咒之媒皆紕繆之</span>  
<!-- 册3 葉3020b　Page:文淵閣四庫全書_0003冊.djvu/760 -->
<span style="margin-left: 2em">甚者已編入所著留靑日札中此乃其初出别行</span>  
<span style="margin-left: 2em">之本也</span>  
留留靑六卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">明徐懋升編懋升字元舉錢塘人初田藝衡作留</span>  
<span style="margin-left: 2em">靑日札駁雜頗甚懋升刪存六卷因以留留靑爲</span>  
<span style="margin-left: 2em">名標目已爲纎佻其所選錄亦未爲精審</span>  
天都載六卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">明馬大壯撰大壯字仲復徽州人羅汝芳之門人</span>  
<span style="margin-left: 2em">也嘗築天都館讀書因以名其所著大抵喜採異</span>  
<!-- 册3 葉3021a　Page:文淵閣四庫全書_0003冊.djvu/760 -->
<span style="margin-left: 2em">聞亦閒有考証而徃徃務求博引不核虚實如魚</span>  
<span style="margin-left: 2em">化爲人一條卽引捜神記孔子厄陳蔡時魚妖與</span>  
<span style="margin-left: 2em">子路鬬事爲證是豈可爲徵信乎又徃徃採自說</span>  
<span style="margin-left: 2em">部不據本書如夜郎王事自見後漢書西南夷傳</span>  
<span style="margin-left: 2em">而云小說稱夜郞王云云則亦襍錄之學耳</span>  
異林十卷<sub class="note-yuan">河南廵撫採進本</sub>  
<span style="margin-left: 2em">明支允堅撰允堅字子固號梅坡居士是編凡軼</span>  
<span style="margin-left: 2em">史隨筆二卷時事漫記三卷軼語考鏡三卷藝苑</span>  
<span style="margin-left: 2em">閒評二卷軼史隨筆論多𤨏屑時寓不遇之感而</span>  
<!-- 册3 葉3021b　Page:文淵閣四庫全書_0003冊.djvu/760 -->
<span style="margin-left: 2em">識趣頗卑如論劉穆之金柈貯㯽榔叚文昌金蓮</span>  
<span style="margin-left: 2em">花盆濯足之𩔖皆不勝企羡又論飛燕合德無損</span>  
<span style="margin-left: 2em">於漢妲己妺喜皆不白之𡨚殊爲偏僻至於薛嵩</span>  
<span style="margin-left: 2em">夢蝨報恩西王母論漢武帝語小說誣詞皆竟據</span>  
<span style="margin-left: 2em">爲實事尤不足取時事漫記多載委巷之談軼語</span>  
<span style="margin-left: 2em">考鏡掇拾餖飣如宋人二結之𩔖㸃竄列子而不</span>  
<span style="margin-left: 2em">竟其說不知何取藝苑閒評皆詩話之流而所見</span>  
<span style="margin-left: 2em">亦淺</span>  
宙合編八卷<sub class="note-yuan">福建廵撫採進本</sub>  
<!-- 册3 葉3024a　Page:文淵閣四庫全書_0003冊.djvu/761 -->
<span style="margin-left: 2em">明林兆珂撰兆珂有毛詩多識編已著錄是編乃</span>  
<span style="margin-left: 2em">其考証之文分爲六門一曰泰眞測徼皆談天地</span>  
<span style="margin-left: 2em">二曰珍駕提羽皆談經籍三曰墨兵微畫皆談史</span>  
<span style="margin-left: 2em">傳四曰議疇剽耳皆談世務五曰在鈞誦末皆論</span>  
<span style="margin-left: 2em">學問文章六曰說藪鬖髿皆談襍事明代說部大</span>  
<span style="margin-left: 2em">都撏撦斷爛游談無根兆珂又摭明人之說部而</span>
