## 欽定四庫全書總目 卷一百五十一　集部四　別集類四

<!-- 册4 葉264：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷一百五十一  
<span style="margin-left: 1em">集部四</span>  
<span style="margin-left: 2em">别集𩔖四</span>  
元氏長慶集六十卷補遺六卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">唐元稹撰稹事迹具唐書本傳考稹與白居易書</span>  
<span style="margin-left: 2em">稱河東李明府景儉在江陵時僻好僕詩章僕因</span>  
<span style="margin-left: 2em">撰成卷軸其中有㫖意可觀而詞近古往者爲古</span>  
<span style="margin-left: 2em">諷意亦可觀而流在樂府者爲樂諷詞雖近古而</span>  
<span style="margin-left: 2em">止於吟寫性情者爲古體詞實樂流而止於模𧰼</span>  
<!-- 册4 葉265b　Page:文淵閣四庫全書_0004冊.djvu/71 -->
<span style="margin-left: 2em">物色者爲新題樂府聲𫝑沿順屬對穩切者爲律</span>  
<span style="margin-left: 2em">詩仍以五七言爲兩體其中有稍存寄興與諷爲</span>  
<span style="margin-left: 2em">流者爲律諷又稱有悼亡詩數十首艶詩百餘首</span>  
<span style="margin-left: 2em">自十六時至元和七年有詩八百餘首成二十卷</span>  
<span style="margin-left: 2em">又稱昨巴南道中有詩五十一文書中得七年以</span>  
<span style="margin-left: 2em">後所爲向二百篇然則稹三十七歲之時巳有詩</span>  
<span style="margin-left: 2em">千餘首唐書本傳稱稹卒時年五十三其後十六</span>  
<span style="margin-left: 2em">年中又不知所作凡幾矣白居易作稹墓誌稱著</span>  
<span style="margin-left: 2em">文一百卷題曰元氏長慶集唐書藝文志又載有</span>  
<!-- 册4 葉268a　Page:文淵閣四庫全書_0004冊.djvu/72 -->
<span style="margin-left: 2em">小集十卷然原本已闕佚不傳此本爲宋宣和甲</span>  
<span style="margin-left: 2em">辰建安劉麟所傳明松江馬元調重刋自一卷至</span>  
<span style="margin-left: 2em">八卷前半爲古詩八卷後半至九卷爲傷悼詩十</span>  
<span style="margin-left: 2em">卷至二十二卷爲律詩二十三卷爲古樂府二十</span>  
<span style="margin-left: 2em">四卷至二十六卷爲新樂府二十七卷爲賦二十</span>  
<span style="margin-left: 2em">八卷爲䇿二十九卷至三十一卷爲書三十二卷</span>  
<span style="margin-left: 2em">至三十九卷爲表狀四十卷至五十卷爲制誥五</span>  
<span style="margin-left: 2em">十一卷爲序記五十二卷至五十八卷爲碑誌五</span>  
<span style="margin-left: 2em">十九卷至六十卷爲告祭文其卷帙與舊說不符</span>  
<!-- 册4 葉268b　Page:文淵閣四庫全書_0004冊.djvu/72 -->
<span style="margin-left: 2em">卽標目亦與自敘迥異不知爲何人所重編前有</span>  
<span style="margin-left: 2em">麟序稱稹文雖盛傳一時厥後浸以不顯惟嗜書</span>  
<span style="margin-left: 2em">者時時傳錄某先人嘗手自鈔寫謹募工刻行云</span>  
<span style="margin-left: 2em">云則麟及其父均未嘗有所增損葢在北宋卽僅</span>  
<span style="margin-left: 2em">有此殘本爾</span>  
白氏長慶集七十一卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">唐白居易撰居易有六帖巳著錄案錢曾讀書敏</span>  
<span style="margin-left: 2em">求記稱所見宋刻居易集兩本皆題爲白氏文集</span>  
<span style="margin-left: 2em">不名長慶集汪立名校刻香山詩集亦謂寶厯以</span>  
<!-- 册4 葉269a　Page:文淵閣四庫全書_0004冊.djvu/72 -->
<span style="margin-left: 2em">後之詩不應槪題曰長慶今考居易嘗自寫其集</span>  
<span style="margin-left: 2em">分置僧寺據所自記太和九年置東林寺者二千</span>  
<span style="margin-left: 2em">九百六十四首勒成六十卷開成元年置於聖善</span>  
<span style="margin-left: 2em">寺者三千二百五十五首勒成六十五卷開成四</span>  
<span style="margin-left: 2em">年置於蘇州南禪院者凡三千四百八十七首勒</span>  
<span style="margin-left: 2em">爲六十七卷皆題曰白氏文集開成五年置於香</span>  
<span style="margin-left: 2em">山寺者凡八百首合爲十卷則别題曰洛中集惟</span>  
<span style="margin-left: 2em">長慶四年元稹作白氏長慶集序稱盡徵其文手</span>  
<span style="margin-left: 2em">自排纂成五十卷二千一百九十一首又稱明年</span>  
<!-- 册4 葉269b　Page:文淵閣四庫全書_0004冊.djvu/72 -->
<span style="margin-left: 2em">當改元長慶訖於是因號曰白氏長慶集則長慶</span>  
<span style="margin-left: 2em">一集特穆宗甲辰以前之作曾及立名所辨不爲</span>  
<span style="margin-left: 2em">無據然唐志載白氏長慶集七十五卷宋志亦載</span>  
<span style="margin-left: 2em">白氏長慶集七十一卷而白氏文集之名轉不著</span>  
<span style="margin-left: 2em">錄又高斯得恥堂存稿有白氏長慶集序宋人目</span>  
<span style="margin-left: 2em">錄傳於今者晁公武讀書志尤袤遂初堂書目陳</span>  
<span style="margin-left: 2em">振孫書錄解題亦均作白氏長慶集則謂宋刻必</span>  
<span style="margin-left: 2em">作白氏文集亦未盡然况元稹之序本爲長慶集</span>  
<span style="margin-left: 2em">作而聖善寺文集記中載有居易自注稱元相公</span>  
<!-- 册4 葉272a　Page:文淵閣四庫全書_0004冊.djvu/73 -->
<span style="margin-left: 2em">先作集序并目錄一卷在外則長慶集序已移弁</span>  
<span style="margin-left: 2em">開成新作之目錄知寶厯以後之詩文均編爲續</span>  
<span style="margin-left: 2em">集襲其舊名矣未可遽以總題長慶爲非也其卷</span>  
<span style="margin-left: 2em">帙之數晁公武謂前集五十卷後集二十卷續集</span>  
<span style="margin-left: 2em">五卷今亡三卷則當有七十二卷陳振孫謂七十</span>  
<span style="margin-left: 2em">一卷之外又有外集一卷亦當有七十二卷而所</span>  
<span style="margin-left: 2em">標總數乃皆仍爲七十一卷與今本合則其故不</span>  
<span style="margin-left: 2em">可得詳至彭叔夏文苑英華辨證謂集中進士䇿</span>  
<span style="margin-left: 2em">問第二道俗本妄有所增又馮班才調集評亦稱</span>  
<!-- 册4 葉272b　Page:文淵閣四庫全書_0004冊.djvu/73 -->
<span style="margin-left: 2em">每卷首古調律詩格詩之目爲重刻改竄則今所</span>  
<span style="margin-left: 2em">行本巳迥非當日之舊矣</span>  
白香山詩集四十卷附錄年譜二卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 1em">國朝汪立名編立名有鐘鼎字源已著錄唐白居易</span>  
<span style="margin-left: 2em">長慶集詩文各半立名引宋祁之言謂居易長於</span>  
<span style="margin-left: 2em">詩而他文未能稱是因别刋其詩以成是集又據</span>  
<span style="margin-left: 2em">元稹序謂長慶時所作僅前五十卷其寶厯以後</span>  
<span style="margin-left: 2em">所作不應槪名以長慶<sub class="note-yuan">案立名此論未<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">巳詳辨於長慶集下</sub>因卽</span>  
<span style="margin-left: 2em">其歸老之地題曰香山參互衆本重加編次定爲</span>  
<!-- 册4 葉273a　Page:文淵閣四庫全書_0004冊.djvu/73 -->
<span style="margin-left: 2em">長慶集二十卷後集十七卷别集一卷又采摭諸</span>  
<span style="margin-left: 2em">書爲補遺二卷而以新定年譜一卷陳振孫舊本</span>  
<span style="margin-left: 2em">年譜一卷併元稹長慶集序一篇舊唐書本傳一</span>  
<span style="margin-left: 2em">篇冠於首復采諸書之有關居易詩者各箋注於</span>  
<span style="margin-left: 2em">其下居易集在東林寺者陸游入蜀記稱宋時已</span>  
<span style="margin-left: 2em">佚眞宗嘗令崇文院寫校包以斑竹帙送寺建炎</span>  
<span style="margin-left: 2em">中亦壞於兵其傳於世者錢曾所云宋本莫知存</span>  
<span style="margin-left: 2em">佚舊有明武定侯家刻本今亦罕見世所行者惟</span>  
<span style="margin-left: 2em">蘇州錢氏松江馬氏二本皆頗有顚倒訛舛胡震</span>  
<!-- 册4 葉273b　Page:文淵閣四庫全書_0004冊.djvu/73 -->
<span style="margin-left: 2em">亨唐音丁籖所錄又分體瑣屑往往以一題割隸</span>  
<span style="margin-left: 2em">二卷殊爲叢脞立名此本考證編排特爲精密其</span>  
<span style="margin-left: 2em">所箋釋雖不能篇篇皆備而引據典核亦勝於注</span>  
<span style="margin-left: 2em">書諸家漫衍支離徒溷耳目葢於諸刻中特爲善</span>  
<span style="margin-left: 2em">本其書成於康熙壬午朱<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">尊宋犖皆爲之序云</span>  
鮑溶詩集六卷外集一卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">唐鮑溶撰溶字德源元和四年進士其仕履未詳</span>  
<span style="margin-left: 2em">溶詩在後世不甚著然張爲作主客圖以溶爲博</span>  
<span style="margin-left: 2em">解宏㧞主以李羣玉爲上入室而爲與司馬退之</span>  
<!-- 册4 葉276a　Page:文淵閣四庫全書_0004冊.djvu/74 -->
<span style="margin-left: 2em">二人同居入室之列則當時固絶重之也其集宋</span>  
<span style="margin-left: 2em">史館舊本五卷訛題鮑防曾鞏始據唐文粹唐詩</span>  
<span style="margin-left: 2em">𩔖選考正之又以歐陽修本參校增多三十三篇</span>  
<span style="margin-left: 2em">合舊本共二百三十三篇𨤲爲六卷晁公武讀書</span>  
<span style="margin-left: 2em">志仍作五卷稱惟存一百九十三篇餘皆佚此本</span>  
<span style="margin-left: 2em">爲江南葉裕家所鈔首有曾鞏校上序今核所錄</span>  
<span style="margin-left: 2em">惟集外詩一卷與曾鞏新增三十三首之說合其</span>  
<span style="margin-left: 2em">正集比鞏序多一卷而詩止一百四十五首葢舊</span>  
<span style="margin-left: 2em">本殘缺傳寫者離析卷帙以足鞏序之數而忘外</span>  
<!-- 册4 葉276b　Page:文淵閣四庫全書_0004冊.djvu/74 -->
<span style="margin-left: 2em">集一卷本在六卷中也全唐詩所錄較此本多十</span>  
<span style="margin-left: 2em">六首較晁本多二首而較曾本尚少三十九首則</span>  
<span style="margin-left: 2em">其集之佚者多矣</span>  
樊川文集二十卷外集一卷别集一卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">唐杜牧撰牧字牧之京兆萬年人太和二年登進</span>  
<span style="margin-left: 2em">士第官至中書舍人事蹟附載新唐書杜佑傳内</span>  
<span style="margin-left: 2em">是集爲其甥裴延翰所編唐藝文志作二十卷晁</span>  
<span style="margin-left: 2em">氏讀書志又載外集一卷王士禎居易錄謂舊藏</span>  
<span style="margin-left: 2em">杜集止二十卷後見宋版本雕刻甚精而多數卷</span>  
<!-- 册4 葉277a　Page:文淵閣四庫全書_0004冊.djvu/74 -->
<span style="margin-left: 2em">考劉克莊後村詩話云樊川有續别集三卷十八</span>  
<span style="margin-left: 2em">九皆許渾詩牧仕宦不至南海而别集乃有南海</span>  
<span style="margin-left: 2em">府罷之作則宋本外集之外又有續别集三卷故</span>  
<span style="margin-left: 2em">士禎云然也此本僅附外集别集各一卷有裴延</span>  
<span style="margin-left: 2em">翰序又有宋熙寧六年田槪序較克莊所見别集</span>  
<span style="margin-left: 2em">尚少二卷而南海府罷之作不收焉則又經後人</span>  
<span style="margin-left: 2em">刪定非克莊所見本矣范攄雲溪友議曰先是李</span>  
<span style="margin-left: 2em">林宗杜牧言元白詩體舛雜而爲淸苦者見嗤因</span>  
<span style="margin-left: 2em">兹有恨牧又著論言近有元白者喜爲淫言媟語</span>  
<!-- 册4 葉277b　Page:文淵閣四庫全書_0004冊.djvu/74 -->
<span style="margin-left: 2em">鼓扇浮囂吾恨方在下位未能以法治之後村詩</span>  
<span style="margin-left: 2em">話因謂牧風情不淺如杜秋娘張好好諸詩<sub class="note-yuan">案杜秋詩</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">非艶體克莊此語殊誤</sub>靑樓薄倖之句街吏平安之報未知</span>  
<span style="margin-left: 2em">去元白幾何比之以燕伐燕其說良是新唐書亦</span>  
<span style="margin-left: 2em">引以論居易然考牧集無此論惟平盧軍節度巡</span>  
<span style="margin-left: 2em">官李戡墓誌述戡之言曰嘗痛自元和以來有元</span>  
<span style="margin-left: 2em">白詩者纎艶不逞非莊士雅人多爲其所破壞流</span>  
<span style="margin-left: 2em">於民間疏於屏壁子父女母交口教授淫言媟語</span>  
<span style="margin-left: 2em">冬寒夏𤍠八人肌骨不可除去吾無位不得用法</span>  
<!-- 册4 葉280a　Page:文淵閣四庫全書_0004冊.djvu/75 -->
<span style="margin-left: 2em">以治之欲使後代知有發憤者因集國朝以來𩔖</span>  
<span style="margin-left: 2em">於古詩得若干首編爲三卷目爲唐詩爲序以導</span>  
<span style="margin-left: 2em">其志云云然則此論乃戡之說非牧之說或牧嘗</span>  
<span style="margin-left: 2em">有是語及爲戡誌墓乃借以發之故攄以爲牧之</span>  
<span style="margin-left: 2em">言歟平心而論牧詩冶蕩甚於元白其風骨則實</span>  
<span style="margin-left: 2em">出元白上其古文縱横奥衍多切經世之務罪言</span>
