## 欽定四庫全書總目 卷四十八　史部四　編年類存目

欽定四庫全書總目卷四十八  
<span style="margin-left: 1em">史部四</span>  
<span style="margin-left: 2em">編年類存目</span>  
考定竹書十三卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝孫之騄撰之騄有尙書大傳已著錄是編以沈</span>  
<span style="margin-left: 2em">約所注竹書紀年未爲詳備因採摭諸書别爲之</span>  
<span style="margin-left: 2em">注然之騄愛博嗜奇多所徴引而不能考正眞僞</span>  
<span style="margin-left: 2em">如帝癸十年地震引華嚴合論大地有六種震動</span>  
<span style="margin-left: 2em">所謂遍動遍起遍涌遍震遍吼遍擊者爲說殊爲</span>  
<!-- 册2 葉325b　Page:文淵閣四庫全書_0002冊.djvu/86 -->
<span style="margin-left: 2em">蕪襍又劉知幾史通疑古篇中排詆舜禹以末世</span>  
<span style="margin-left: 2em">莽操心事推測聖人至爲乖謬而一槪引川漫無</span>  
<span style="margin-left: 2em">辨正沈約註出依託尙能知伊尹自立之誣太甲</span>  
<span style="margin-left: 2em">殺伊尹之妄之騄乃旁取異說以熒耳目云能補</span>  
<span style="margin-left: 2em">正沈注未見其然惟拾遺記商均暴天下之類辨</span>  
<span style="margin-left: 2em">别誣妄路史帝杼遷老王之類考訂訛謬間有數</span>  
<span style="margin-left: 2em">處可取耳至所補逸文採摭頗備然如晉幽公會</span>  
<span style="margin-left: 2em">魯季孫一條今本有之而註曰無又如湯十九年</span>  
<span style="margin-left: 2em">至二十四年皆書大旱葢作書者依託墨子湯五</span>  
<!-- 册2 葉328a　Page:文淵閣四庫全書_0002冊.djvu/87 -->
<span style="margin-left: 2em">年旱之文此本竟脫去二十一年大旱鑄金幣二</span>  
<span style="margin-left: 2em">條則亦不可盡據也</span>  
五代春秋二卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">宋尹洙撰洙字師魯河南人天聖二年進士授絳</span>  
<span style="margin-left: 2em">州正平主簿以薦爲館閣校勘累遷右司諫知渭</span>  
<span style="margin-left: 2em">州兼領涇原路經畧公事以爭永樂城事徙慶州</span>  
<span style="margin-left: 2em">復爲董士廉所訟貶崇信軍節度副使監均州酒</span>  
<span style="margin-left: 2em">稅卒事迹具宋史本傳考邵伯温聞見錄載歐陽</span>  
<span style="margin-left: 2em">修作五代史嘗約與洙分撰此書或卽作於是時</span>  
<!-- 册2 葉328b　Page:文淵閣四庫全書_0002冊.djvu/87 -->
<span style="margin-left: 2em">然體用編年與修書例異豈本約同撰而不果後</span>  
<span style="margin-left: 2em">乃自著此書歟所載始梁太祖開平元年甲子迄</span>  
<span style="margin-left: 2em">周顯德七年正月甲辰鄭樵通志藝文略作二卷</span>  
<span style="margin-left: 2em">與今本合趙希弁讀書附志則作五卷或别本流</span>  
<span style="margin-left: 2em">傳以一代爲一卷歟穆修春秋之學稱受之於洙</span>  
<span style="margin-left: 2em">然洙無說春秋之書惟此一編筆削頗爲不苟多</span>  
<span style="margin-left: 2em">得謹嚴之遺意知其春秋之學深矣已載入所作</span>  
<span style="margin-left: 2em">河南集中此葢其别行之本以初原自爲一書故</span>  
<span style="margin-left: 2em">仍存其目焉</span>  
<!-- 册2 葉329a　Page:文淵閣四庫全書_0002冊.djvu/87 -->
少微通鑑節要五十卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋江贄編贄字叔<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">崇安人政和中太史奏少微</span>  
<span style="margin-left: 2em">星見朝命舉遺逸之士有司以贄應詔贄辭不赴</span>  
<span style="margin-left: 2em">賜號少微先生是書取司馬光資治通鑑刪存大</span>  
<span style="margin-left: 2em">要然首尾賅貫究不及原書此本爲明正德中所</span>  
<span style="margin-left: 2em">刊前有武宗御製序考羅願鄂州小集末載王瓚</span>  
<span style="margin-left: 2em">月山錄跋結銜稱通鑑節要纂修官疑正德時又</span>  
<span style="margin-left: 2em">爲重修非復贄之舊本又明史李東陽傳稱東陽</span>  
<span style="margin-left: 2em">奉命編通鑑纂要旣成瑾令人摘其筆畫小疵除</span>  
<!-- 册2 葉329b　Page:文淵閣四庫全書_0002冊.djvu/87 -->
<span style="margin-left: 2em">謄錄官數人名欲因以及東陽東陽大窘屬焦芳</span>  
<span style="margin-left: 2em">與張綵爲解乃已又張元禎傳稱爲通鑑纂要副</span>  
<span style="margin-left: 2em">總裁纂要當卽節要葢史偶異文然則此書東陽</span>  
<span style="margin-left: 2em">及元禎所定也</span>  
續宋編年資治通鑑十八卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">舊本題朝散郞尙書禮部員外郞兼國史院編修</span>  
<span style="margin-left: 2em">官李燾經進考宋史藝文志及燾本傳惟載所著</span>  
<span style="margin-left: 2em">續通鑑長編無此書之名此本目錄末有武夷主</span>  
<span style="margin-left: 2em">奉劉深源校定一行亦不知爲何許人書中所記</span>  
<!-- 册2 葉332a　Page:文淵閣四庫全書_0002冊.djvu/88 -->
<span style="margin-left: 2em">皆北宋事迹體例與宋史全文約畧相似而闕漏</span>  
<span style="margin-left: 2em">殊甚葢亦當時麻沙坊本因燾有續通鑑長編託</span>  
<span style="margin-left: 2em">其名以售欺也</span>  
增節音註資治通鑑一百二十卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋陸唐老編唐老會稽人淳熙中進士第一故此</span>  
<span style="margin-left: 2em">書亦稱陸狀元通鑑皆於司馬光書内鈔其可備</span>  
<span style="margin-left: 2em">科舉䇿論之用者間有音註然淺陋頗甚亦寥寥</span>  
<span style="margin-left: 2em">不詳首有總例云學者未能徧曉出處則於詞賦</span>  
<span style="margin-left: 2em">一塲未敢引用足以見其大旨矣</span>  
<!-- 册2 葉332b　Page:文淵閣四庫全書_0002冊.djvu/88 -->
通鑑綱目測海三卷<sub class="note-yuan">江蘇廵撫採進本</sub>  
<span style="margin-left: 2em">元何中撰中字太虛一字餋正撫樂人事迹具元</span>  
<span style="margin-left: 2em">史儒學傳是書以糾通鑑綱目書法之同異卷末</span>  
<span style="margin-left: 2em">有大德丙午自跋曰朱子作綱目續春秋然其間</span>  
<span style="margin-left: 2em">書法可商畧者猶多間附己意緝成綱目測海三</span>  
<span style="margin-left: 2em">卷示兒輩云云葢不知綱目出趙師淵之手猶悞</span>  
<span style="margin-left: 2em">以爲朱子書也書中所列凡三例一辨胡呂二家</span>  
<span style="margin-left: 2em">所註如魏徙都大梁條胡氏謂魏王不恨不用孟</span>  
<span style="margin-left: 2em">子而恨不聽公叔之言中以爲徙都之後六年孟</span>  
<!-- 册2 葉333a　Page:文淵閣四庫全書_0002冊.djvu/88 -->
<span style="margin-left: 2em">子方至魏之類是也一發明二家所未註如秦人</span>  
<span style="margin-left: 2em">誅衛鞅條下中補註曰書秦人何鞅得罪於衆猶</span>  
<span style="margin-left: 2em">共誅之之類是也一乃糾正本書之訛異於全書</span>  
<span style="margin-left: 2em">之中不過十之二三耳其中如秦魏冉出其故君</span>  
<span style="margin-left: 2em">之妃歸于魏一條中謂諸侯之妻宜稱夫人不宜</span>  
<span style="margin-left: 2em">稱妃不知元妃孟子固左傳文也又漢元狩六年</span>  
<span style="margin-left: 2em">封三王一條中謂宜載誥䇿之詞不知綱目紀事</span>  
<span style="margin-left: 2em">之書非載文之書也又莽廢孺子一條中謂旣書</span>  
<span style="margin-left: 2em">始建國元年則不必書莽不知孺子廢而後成爲</span>  
<!-- 册2 葉333b　Page:文淵閣四庫全書_0002冊.djvu/88 -->
<span style="margin-left: 2em">始建國也又秦王世民殺太子建成一條中謂宜</span>  
<span style="margin-left: 2em">削秦王字此泥以爵字爲褒貶例也又張柬之等</span>  
<span style="margin-left: 2em">舉兵討武氏一條中謂多之亂二字不知書法在</span>  
<span style="margin-left: 2em">討字此二字刪之固可存之亦無害也又晉主重</span>  
<span style="margin-left: 2em">貴發大梁一條中謂宜書北遷不知朱子宋人避</span>  
<span style="margin-left: 2em">二帝北遷之事變其文也其他間有可取不過摭</span>  
<span style="margin-left: 2em">拾細碎不能深裨於史學綱目非無可糾如中此</span>  
<span style="margin-left: 2em">書尙未足以糾綱目也</span>  
通鑑綱目釋地糾繆六卷補註六卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<!-- 册2 葉336a　Page:文淵閣四庫全書_0002冊.djvu/89 -->
<span style="margin-left: 1em">國朝張庚撰庚字浦山秀水人是書以通鑑綱目集</span>  
<span style="margin-left: 2em">覽質實謬誤不少惟胡三省通鑑註頗屬精當可</span>  
<span style="margin-left: 2em">以正二書之謬又校以顧祖禹讀史方輿紀要及</span>  
<span style="margin-left: 2em">輿圖等書爲糾繆以正其失又爲補註以拾其遺</span>  
<span style="margin-left: 2em">用力頗爲勤摯然集覽質實之荒陋本不足與辨</span>  
<span style="margin-left: 2em">今旣與之辨矣則宜原原本本詳引諸書使沿革</span>  
<span style="margin-left: 2em">分合言言有據庻幾以有證之文破無根之論而</span>  
<span style="margin-left: 2em">所糾所補乃皆不著出典則終不能關其口也</span>  
帝王紀年纂要一卷<sub class="note-yuan">戸部尚書王際華家藏本</sub>  
<!-- 册2 葉336b　Page:文淵閣四庫全書_0002冊.djvu/89 -->
<span style="margin-left: 2em">元察罕撰明黃諫補察罕官至平章事事迹具元</span>  
<span style="margin-left: 2em">史本傳諫有從古正文已著錄其書本皇極經世</span>  
<span style="margin-left: 2em">爲準自太皥以下諸帝王各載其在位年數而畧</span>  
<span style="margin-left: 2em">述興廢大㫖於每代之前察罕成此書在皇慶元</span>  
<span style="margin-left: 2em">年嘗奏進於朝程鉅夫爲之序至明景泰中諫復</span>  
<span style="margin-left: 2em">爲續輯改原本每代下至延祐戊午若干年爲下</span>  
<span style="margin-left: 2em">至洪武戊申若干年并補入元代諸帝紀年然簡</span>  
<span style="margin-left: 2em">畧太甚不足以資考訂也</span>  
明本紀一卷<sub class="note-yuan">左都御史張若溎家藏本</sub>  
<!-- 册2 葉337a　Page:文淵閣四庫全書_0002冊.djvu/89 -->
<span style="margin-left: 2em">不著撰人名氏紀明太祖事蹟自起兵濠梁迄建</span>  
<span style="margin-left: 2em">國金陵皆分年排載頗爲詳備葢亦自實錄中摘</span>  
<span style="margin-left: 2em">出編次者惟自洪武三年正月以後並闕或草創</span>  
<span style="margin-left: 2em">未竟之本歟</span>  
世史正綱三十二卷<sub class="note-yuan">副都御史黄登賢家藏本</sub>  
<span style="margin-left: 2em">明邱濬撰濬有家禮儀節已著錄是書本明方孝</span>  
<span style="margin-left: 2em">孺釋統之意專明正統起秦始皇帝二十六年訖</span>  
<span style="margin-left: 2em">明洪武元年以著世變事始之所由於各條之下</span>  
<span style="margin-left: 2em">隨事附論然立說多偏駁不經如紀年干支之下</span>  
<!-- 册2 葉337b　Page:文淵閣四庫全書_0002冊.djvu/89 -->
<span style="margin-left: 2em">皆規以一圈中書國號至元代則加以黑圈迨至</span>  
<span style="margin-left: 2em">正十五年明太祖起兵則爲白圈其說以爲本之</span>  
<span style="margin-left: 2em">太極圖之陰陽至是天運轉而陽道復陰翳消也</span>  
<span style="margin-left: 2em">率臆妄作爲史家未有之變例可謂謬誕王士禎</span>  
<span style="margin-left: 2em">池北偶談稱其議論嚴正殊爲太過陶輔桑榆漫</span>  
<span style="margin-left: 2em">志稱其義嚴理到括盡幽隱深得麟經之旨胡應</span>  
<span style="margin-left: 2em">麟史學佔畢稱春秋之後有朱氏而綱目之後有</span>  
<span style="margin-left: 2em">邱氏更乖舛矣</span>  
通鑑綱目前編三卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<!-- 册2 葉340a　Page:文淵閣四庫全書_0002冊.djvu/90 -->
<span style="margin-left: 2em">明許誥撰誥自號函谷山人靈寶人吏部尚書進</span>  
<span style="margin-left: 2em">之子文淵閣大學士讚之兄兵部尚書論之弟宏</span>  
<span style="margin-left: 2em">治已未進士官至南京戸部尙書諡莊敏事迹附</span>  
<span style="margin-left: 2em">見明史許進傳是書以司馬光通鑑朱子綱目皆</span>  
<span style="margin-left: 2em">不<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">接春秋中間闕七十餘年之事金履祥通鑑</span>  
<span style="margin-left: 2em">前編書法又多舛迕乃重輯是編以訂訛補闕其</span>  
<span style="margin-left: 2em">中如辨宋昭公非周元孫魏文侯未弒晋幽公趙</span>  
<span style="margin-left: 2em">鞅趙無䘏之卒歲史記並誤亦小有考証而摹仿</span>  
<span style="margin-left: 2em">春秋過甚拘文牽義往往畫虎不成又或生例於</span>  
<!-- 册2 葉340b　Page:文淵閣四庫全書_0002冊.djvu/90 -->
<span style="margin-left: 2em">春秋之外如春秋書衛侯燬滅邢說者謂惡其滅</span>  
<span style="margin-left: 2em">同姓又或以爲因下衛侯燬卒之文而訛已非成</span>
