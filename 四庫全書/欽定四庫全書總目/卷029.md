## 欽定四庫全書總目 卷二十九　經部二十九　春秋類四

欽定四庫全書總目卷二十九  
<span style="margin-left: 1em">經部二十九</span>  
<span style="margin-left: 2em">春秋類四</span>  
日講春秋解義六十四卷  
<span style="margin-left: 2em">謹案是書爲</span>  
聖祖仁皇帝經筵舊稿  
世宗憲皇帝復加考論乃編次成帙說春秋者莫夥於兩  
<span style="margin-left: 2em">宋其爲進講而作者宋史藝文志有王葆春秋講</span>  
<span style="margin-left: 2em">義三卷今己散佚張廷式黄海集有春秋講義一</span>  
<!-- 册1 葉2325b　Page:文淵閣四庫全書_0001冊.djvu/631 -->
<span style="margin-left: 2em">卷永樂大典有戴溪春秋講義三卷大抵皆演繹</span>  
<span style="margin-left: 2em">經文指陳政理與章句之學迥殊是非惟崇政邇</span>  
<span style="margin-left: 2em">英奏御之體裁如是亦以統馭之柄在愼其賞罸</span>  
<span style="margin-left: 2em">賞罰之要在當其功罪而别嫌疑明是非定猶豫</span>  
<span style="margin-left: 2em">者則莫精於春秋聖人筆削之旨實在於是也故</span>  
<span style="margin-left: 2em">孟子曰春秋天子之事也公扈子曰有國者不可</span>  
<span style="margin-left: 2em">以不學春秋春秋國之鑑也董仲舒推演公羊之</span>  
<span style="margin-left: 2em">旨得二百三十二條作春秋决事十六篇其義葢</span>  
<span style="margin-left: 2em">有所受矣是編因宋儒進御舊體以闡發微言每</span>  
<!-- 册1 葉2328a　Page:文淵閣四庫全書_0001冊.djvu/632 -->
<span style="margin-left: 2em">條先列左氏之事迹而不取其浮夸次明公穀之</span>  
<span style="margin-left: 2em">義例而不取其穿鑿反覆演釋大旨歸本於王道</span>  
<span style="margin-left: 2em">允足明聖經之書法而探帝學之本原</span>  
聖祖仁皇帝  
世宗憲皇帝  
聖  
聖相承鄭重八明以成此一編豈非以經世之樞要具在  
<span style="margin-left: 2em">斯乎</span>  
欽定春秋傳說彚纂三十八卷  
<!-- 册1 葉2328b　Page:文淵閣四庫全書_0001冊.djvu/632 -->
<span style="margin-left: 2em">康熙三十八年奉</span>  
勅撰初胡安國作春秋傳張栻已頗有異議朱子編南軒  
<span style="margin-left: 2em">集存而不刪葢亦以栻說爲然至元延祐中復科</span>  
<span style="margin-left: 2em">舉法始以安國之傳懸爲功令而有明一代因之</span>  
<span style="margin-left: 2em">故元吳澄作俞臯春秋集傳序稱兼列胡氏以從</span>  
<span style="margin-left: 2em">時尙明馮夢龍作春秋大全凡例稱諸儒議論儘</span>  
<span style="margin-left: 2em">有勝胡傳者然業以胡傳爲宗自難並收以亂耳</span>  
<span style="margin-left: 2em">目豈非限於科律明知其悞而從之歟欽惟</span>  
聖祖仁皇帝道契天經  
<!-- 册1 葉2329a　Page:文淵閣四庫全書_0001冊.djvu/632 -->
心符聖義於尼山筆削  
洞鑒精微雖  
俯念士子久誦胡傳難以驟更仍綴於三傳之末而  
指授儒臣詳爲考證凡其中有乖經義者一一駁正多所  
<span style="margin-left: 2em">刊除至於先儒舊說世以不合胡傳擯棄弗習者</span>  
<span style="margin-left: 2em">亦一一採錄表章闡明古學葢以</span>  
聖人之德居  
天子之位故能蕩除門戸辨别是非挽數百年積重之勢  
<span style="margin-left: 2em">而反之於正也自時厥後能不爲胡傳所錮者如</span>  
<!-- 册1 葉2329b　Page:文淵閣四庫全書_0001冊.djvu/632 -->
<span style="margin-left: 2em">徐庭垣之春秋管窺焦袁熹之春秋闕如編響然</span>  
<span style="margin-left: 2em">並作不可殫數袞鉞之義遂皦若三光維風維草</span>  
<span style="margin-left: 2em">之效誠有自來矣<small>臣</small>等繕校之餘爲春秋幸尤爲</span>  
<span style="margin-left: 2em">天下萬世讀春秋者幸也</span>  
御纂春秋直解十五卷  
<span style="margin-left: 2em">乾隆二十三年奉</span>  
敇撰十二公爲十二卷莊公僖公襄公篇頁稍繁各析  
<span style="margin-left: 2em">一子卷實十五卷大旨在發明尼山本義而剷除</span>  
<span style="margin-left: 2em">種種迂曲之說故</span>  
<!-- 册1 葉2332a　Page:文淵閣四庫全書_0001冊.djvu/633 -->
<span style="margin-left: 1em">賜名曰直解冠以</span>  
<span style="margin-left: 1em">御製序文揭胡安國傳之傅會臆斷以明誥天下與</span>  
欽定春秋傳說彚纂宗旨同符考班彪之論春秋曰平易  
<span style="margin-left: 2em">正直春秋之義也王充之論春秋曰公羊榖梁之</span>  
<span style="margin-left: 2em">傳日月不具輒爲意使平常之事有怪異之說徑</span>  
<span style="margin-left: 2em">直之文有曲折之義非孔子之心蘇軾之論春秋</span>  
<span style="margin-left: 2em">曰春秋儒者本務然此書有妙用儒者罕能領會</span>  
<span style="margin-left: 2em">多求之繩約中乃近法家者流苛細繳繞竟亦何</span>  
<span style="margin-left: 2em">用朱子之論春秋亦曰聖人作春秋不過直書其</span>  
<!-- 册1 葉2332b　Page:文淵閣四庫全書_0001冊.djvu/633 -->
<span style="margin-left: 2em">事而善惡自見又曰春秋傳例多不可信聖人紀</span>  
<span style="margin-left: 2em">事安有許多義例然則聖經之法戒本共聞共見</span>  
<span style="margin-left: 2em">聖人之勸懲亦易知易從自啖助趙匡倡廢傳解</span>  
<span style="margin-left: 2em">經之說使人人各以臆見私相揣度務爲新奇以</span>  
<span style="margin-left: 2em">相勝而春秋以荒自孫復倡爲有貶無褒之說說</span>  
<span style="margin-left: 2em">春秋者必事事求其所以貶求其所以貶而不得</span>  
<span style="margin-left: 2em">則鍛錬周内以成其罪而春秋益荒俞汝言春秋</span>  
<span style="margin-left: 2em">平義序謂傳經之失不在於淺而在於深春秋尤</span>  
<span style="margin-left: 3em">甚可謂片言居要矣是編恭承</span>  
<!-- 册1 葉2333a　Page:文淵閣四庫全書_0001冊.djvu/633 -->
訓示務斟酌情理之平以求聖經之微意凡諸家所說  
<span style="margin-left: 2em">穿鑿破碎者悉斥不採而筆削大義愈以炳然學</span>  
<span style="margin-left: 2em">者恭讀</span>  
御纂春秋傳說彚纂以辨訂其是非復恭讀是編以融會  
<span style="margin-left: 2em">其精要春秋之學已更無餘藴矣</span>  
左傳杜解補正三卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 1em">國朝顧炎武撰炎武一名絳字寧人崑山人博極羣</span>  
<span style="margin-left: 2em">書精於考證</span>  
<span style="margin-left: 1em">國初稱學有根柢者以炎武爲最李光地嘗爲作小</span>  
<!-- 册1 葉2333b　Page:文淵閣四庫全書_0001冊.djvu/633 -->
<span style="margin-left: 2em">傳今載榕村集中是書以杜預左傳集解時有缺</span>  
<span style="margin-left: 2em">失而賈逵服䖍之注樂遜之春秋序義今又不傳</span>  
<span style="margin-left: 2em">於是博稽載籍作爲此書至邵寶左觿等書苟有</span>  
<span style="margin-left: 2em">合者亦皆采輯若室如懸罄取諸國語肉謂之羮</span>  
<span style="margin-left: 2em">取諸爾雅車之有輔取諸吕覽田祿其子取諸楚</span>  
<span style="margin-left: 2em">詞千畝原之在晉州取諸鄭康成祏爲廟主取諸</span>  
<span style="margin-left: 2em">說文石四爲鼓取諸王肅家語注祝其之爲萊蕪</span>  
<span style="margin-left: 2em">取之水經注凡此之類皆有根據其他推求文義</span>  
<span style="margin-left: 2em">研究詁訓亦多得左氏之意昔隋劉<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3271.svg?width=24" alt="四庫全書僻字第3271號（炫）" title="四庫全書僻字第3271號（炫）">作杜解規</span>  
<!-- 册1 葉2336a　Page:文淵閣四庫全書_0001冊.djvu/634 -->
<span style="margin-left: 2em">過其書不傳惟散見孔頴達正義中然孔疏之例</span>  
<span style="margin-left: 2em">務主一家故凡<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3271.svg?width=24" alt="四庫全書僻字第3271號（炫）" title="四庫全書僻字第3271號（炫）">所規皆遭排斥一字一句無不</span>  
<span style="margin-left: 2em">劉曲而杜直未協至公炎武甚重杜解而又能彌</span>  
<span style="margin-left: 2em">縫其闕失可謂掃除門戸能持是非之平矣近時</span>  
<span style="margin-left: 2em">惠棟作左傳補註糾正此書尨涼一條大司馬固</span>  
<span style="margin-left: 2em">一條文馬百駟一條使封人慮事一條遇艮之八</span>  
<span style="margin-left: 2em">一條豆區釡鍾一條然其中文馬之說究以炎武</span>  
<span style="margin-left: 2em">爲是棟又摘其引古春秋左氏說但舉漢書五行</span>  
<span style="margin-left: 2em">志之名又摘其禮爲鄰國闕一條用服䖍之說而</span>  
<!-- 册1 葉2336b　Page:文淵閣四庫全書_0001冊.djvu/634 -->
<span style="margin-left: 2em">不著所自案徵引佚書當以所載之書爲據棟引</span>  
<span style="margin-left: 2em">世本不標史記注引京相璠土地名不標水經注</span>  
<span style="margin-left: 2em">正體例之疎未可反譏炎武至服䖍一條當由偶</span>  
<span style="margin-left: 2em">忘出典棟注昭公二十九年賦晉國一鼓鐵證以</span>  
<span style="margin-left: 2em">王肅家語注亦明馮時可之說未標時可之名也</span>  
<span style="margin-left: 2em">是固不以掠美論矣</span>  
春秋稗疏二卷<sub class="note-yuan">湖南巡撫採進本</sub>  
<span style="margin-left: 1em">國朝王夫之撰夫之有周易稗疏已著錄是編論春</span>  
<span style="margin-left: 2em">秋書法及儀象典制之𩔖僅十之一而考證地理</span>  
<!-- 册1 葉2337a　Page:文淵閣四庫全書_0001冊.djvu/634 -->
<span style="margin-left: 2em">者居十之九其論書法謂閔公元年書季子仲孫</span>  
<span style="margin-left: 2em">高子皆不名乃閔公㓜弱聽國人之所爲故從國</span>  
<span style="margin-left: 2em">人之尊稱然考襄公之立實止四歲昭公之出亦</span>  
<span style="margin-left: 2em">非一年均未聞以君不與政書事或有變文何獨</span>  
<span style="margin-left: 2em">閔公見存反從國人立義其論春秋書戎皆指徐</span>  
<span style="margin-left: 2em">戎斥杜預陳留濟陽東有戎城之非且謂曹衛之</span>  
<span style="margin-left: 2em">間不應有戎證以費誓似乎近理然周之戎如今</span>  
<span style="margin-left: 2em">土司參錯於郡縣觀追戎濟西則去曹近而去徐</span>  
<span style="margin-left: 2em">遠至於凡伯聘魯歸周而戎伐之于楚丘則凡伯</span>  
<!-- 册1 葉2337b　Page:文淵閣四庫全書_0001冊.djvu/634 -->
<span style="margin-left: 2em">不涉徐方徐戎亦斷難越國安得謂曹衛之間戎</span>  
<span style="margin-left: 2em">不雜居如此之𩔖未免失之臆斷至以鸜鵒爲寒</span>  
<span style="margin-left: 2em">號蟲反斥埤雅之訛以延廐爲延袤其廐亦爲穿</span>  
<span style="margin-left: 2em">鑿杜註䣆亭在邵陵南不云卽在邵陵乃刪除南</span>  
<span style="margin-left: 2em">字而駁之尤爲文致其失然如莒人入向之向謂</span>  
<span style="margin-left: 2em">當從杜預在龍亢而駁水經注所引闞駰之說誤</span>  
<span style="margin-left: 2em">以邑名爲國名足以申杜注之義辨𣏌之東遷在</span>  
<span style="margin-left: 2em">春秋以前辨殺州吁于濮非陳地辨洮爲曹地非</span>  
<span style="margin-left: 2em">魯地音推小反不音他刀反辨貫字非貰字之誤</span>  
<!-- 册1 葉2340a　Page:文淵閣四庫全書_0001冊.djvu/635 -->
<span style="margin-left: 2em">辨厲卽賴國非隨縣之厲鄉辨踐土非鄭地辨翟</span>  
<span style="margin-left: 2em">泉周時不在王城之内辨莒魯之間有二鄆辨伸</span>  
<span style="margin-left: 2em">遂所卒之<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2618.svg?width=24" alt="四庫全書僻字第2618號（⿱乖一）" title="四庫全書僻字第2618號（⿱乖一）">非齊地辨次鄫之鄫非鄫國亦非鄭</span>  
<span style="margin-left: 2em">地辨春秋之祝其非漢之祝其皆足糾杜注之失</span>  
<span style="margin-left: 2em">據後漢郡國志謂郎在高平據括地志謂胡在郾</span>  
<span style="margin-left: 2em">城據漢書地理志謂重邱在平原據應劭漢書注</span>  
<span style="margin-left: 2em">謂陽在都陽皆足以補杜注之闕至於謂子糾爲</span>  
<span style="margin-left: 2em">齊襄公之子<sub class="note-yuan">案劉瑾詩集傳通釋解何彼穠矣篇亦以桓公爲襄公子然瑾由誤記與</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">夫之有所考辨者不冋</sub>謂魯襄公時頻月日食由於誤視暈</span>  
<!-- 册1 葉2340b　Page:文淵閣四庫全書_0001冊.djvu/635 -->
<span style="margin-left: 2em">珥亦足以備一解在近代說經之家尙頗有根柢</span>  
<span style="margin-left: 2em">其書向未刋行故子糾之說近時梁錫璵據爲新</span>  
<span style="margin-left: 2em">義翬不書族定姒非諡之說近時葉酉亦據爲新</span>  
<span style="margin-left: 2em">義殆皆未見其書也</span>  
春秋四傳糾正一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝俞汝言撰汝言字石吉秀水人前明諸生康熙</span>  
<span style="margin-left: 2em">丙辰汝言撰春秋平義始脫藁乃作此書以綜括</span>  
<span style="margin-left: 2em">其大㫖相傳其晚年失明口授而成之者也書中</span>
