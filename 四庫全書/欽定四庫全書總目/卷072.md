## 欽定四庫全書總目 卷七十二　史部二十八　地理類存目一

<!-- 册2 葉2172a　Page:文淵閣四庫全書_0002冊.djvu/548 -->
欽定四庫全書總目卷七十二  
<span style="margin-left: 1em">史部二十八</span>  
<span style="margin-left: 2em">地理類存目一</span>  
華陽宫記事一卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">宋僧祖秀撰祖秀蜀人靖康元年閏十一月汴京</span>  
<span style="margin-left: 2em">䧟時隨都人避兵艮岳因記其邱壑池館之勝叙</span>  
<span style="margin-left: 2em">述極詳末歸其過於朱勔梁師成而推原禍本於</span>  
<span style="margin-left: 2em">蔡京王偁東都事畧全載之此本蓋卽從偁書錄</span>  
<span style="margin-left: 2em">出也</span>  
<!-- 册2 葉2172b　Page:文淵閣四庫全書_0002冊.djvu/548 -->
艮嶽記一卷<sub class="note-yuan">編修汪如藻家藏本</sub>  
<span style="margin-left: 2em">宋張淏撰淏有㑹稽續志巳著錄是書取徽宗御</span>  
<span style="margin-left: 2em">製艮嶽記及蜀僧祖秀所作華陽宫記各摭其畧</span>  
<span style="margin-left: 2em">首叙朱勔擾民之事又稱越十年金人南侵臺榭</span>  
<span style="margin-left: 2em">宫室悉皆拆毁官不能禁其大意亦與祖秀同</span>  
故宫遺錄一卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">明蕭洵撰洵廬陵人洪武初爲工部郞中奉命毁</span>  
<span style="margin-left: 2em">元故宫因記其制度洵後爲湖州長興令欲刋未</span>  
<span style="margin-left: 2em">果其本歸於吕山高氏家洪武丙子松陵吳節從</span>  
<!-- 册2 葉2173a　Page:文淵閣四庫全書_0002冊.djvu/548 -->
<span style="margin-left: 2em">高氏鈔傳萬厯中武進趙琦美得之以張浙門家</span>  
<span style="margin-left: 2em">鈔本互校因行於世其書序次典核朱彛尊日下</span>  
<span style="margin-left: 2em">舊聞全載之故今不重錄焉</span>  
<span style="margin-left: 1em">右地理類宫殿䟽之屬三部三卷皆附存目</span>  
新定九域志十卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">此書與宋王存等所撰元豐九域志文並相同惟</span>  
<span style="margin-left: 2em">府州軍監縣下多出古蹟一門詳畧失宜視原書</span>  
<span style="margin-left: 2em">頗爲蕪雜蓋卽晁公武讀書志所云新本朱彛尊</span>  
<span style="margin-left: 2em">跋以爲是民間流行之書者也首卷四京及京東</span>  
<!-- 册2 葉2173b　Page:文淵閣四庫全書_0002冊.djvu/548 -->
<span style="margin-left: 2em">東路俱巳闕次卷亦有訛脫彛尊曾見崑山徐氏</span>  
<span style="margin-left: 2em">家藏宋槧本所紀闕文與此本同蓋卽從徐氏錄</span>  
<span style="margin-left: 2em">出者張淏雲谷雜記稱南渡後閩中刻九域志誤</span>  
<span style="margin-left: 2em">改睦州爲嚴州今檢毛晉家影鈔九域志舊本睦</span>  
<span style="margin-left: 2em">字未改而此本則巳作嚴州足知其出於南宋閩</span>  
<span style="margin-left: 2em">中刋本而古蹟一門當卽其時坊賈所增入矣王</span>  
<span style="margin-left: 2em">士禎居易錄載所見九域志與此本合而誤以爲</span>  
<span style="margin-left: 2em">卽元豐經進之書則亦未見王存原本也</span>  
厯代地理指掌圖一卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<!-- 册2 葉2176a　Page:文淵閣四庫全書_0002冊.djvu/549 -->
<span style="margin-left: 2em">舊本題宋蘇軾撰始自帝嚳迄於宋代爲圖凡四</span>  
<span style="margin-left: 2em">十有四前有序後有總論其序云據元豐九域志</span>  
<span style="margin-left: 2em">然書中乃有建炎二年改江寜爲建寜府紹興三</span>  
<span style="margin-left: 2em">十二年升洪州爲隆興府諸語案費衮梁溪漫志</span>  
<span style="margin-left: 2em">曰今世所傳地理指掌圖不知何人所作其考究</span>  
<span style="margin-left: 2em">精詳詮次有法上下數千百年一覽而盡非博學</span>  
<span style="margin-left: 2em">洽聞者不能爲自足以傳遠何必托之東坡其序</span>  
<span style="margin-left: 2em">亦云東坡所爲觀其文淺陋乃舉子對䇿手叚東</span>  
<span style="margin-left: 2em">坡安有此語最後有本朝陞改廢置州郡一圖乃</span>  
<!-- 册2 葉2176b　Page:文淵閣四庫全書_0002冊.djvu/549 -->
<span style="margin-left: 2em">有崇寜以後迄於建炎紹興所廢置者此豈出於</span>  
<span style="margin-left: 2em">東坡之手哉云云則此書之僞南宋人固巳言之</span>  
<span style="margin-left: 2em">而流傳刋本仍題軾名刋胡安國春秋傳者皆摘</span>  
<span style="margin-left: 2em">其列國一圖爲冠亦仍題曰東坡謬之甚矣其書</span>  
<span style="margin-left: 2em">雖簡明而踈畧殊甚費衮所稱殊爲過當亦不足</span>  
<span style="margin-left: 2em">據也</span>  
寰宇通衢一卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明洪武中官撰案黄虞稷千頃堂書目曰寰宇通</span>  
<span style="margin-left: 2em">衢一卷洪武二十七年九月書成先是太祖以輿</span>  
<!-- 册2 葉2177a　Page:文淵閣四庫全書_0002冊.djvu/549 -->
<span style="margin-left: 2em">地之廣不可無書以紀之乃命翰林儒臣以天下</span>  
<span style="margin-left: 2em">道里之數編類爲書其方隅之目有八所言皆與</span>  
<span style="margin-left: 2em">此本合</span>  
輿圖記叙二卷<sub class="note-yuan">江西廵撫採進本</sub>  
<span style="margin-left: 2em">明桂萼撰萼有桂文襄奏議巳著錄是編卽嘉靖</span>  
<span style="margin-left: 2em">八年爲大學士時所上首爲總圖次則兩京十三</span>  
<span style="margin-left: 2em">省名爲一圖附以四夷圖但畧具兵馬錢糧之總</span>  
<span style="margin-left: 2em">數併府州縣衛之名亦不具列所述利病亦皆敷</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2973.svg?width=24" alt="四庫全書僻字第2973號（衍）" title="四庫全書僻字第2973號（衍）">之詞其奏進䟽乃稱披此圖如祖宗之親厯地</span>  
<!-- 册2 葉2177b　Page:文淵閣四庫全書_0002冊.djvu/549 -->
<span style="margin-left: 2em">方者然世宗批荅亦稱其明白要切具見體國經</span>  
<span style="margin-left: 2em">濟皆不可解也</span>  
志畧十六卷<sub class="note-yuan">編修汪如藻家藏本</sub>  
<span style="margin-left: 2em">明廖世昭撰世昭福建懷安人正德丁丑進士官</span>  
<span style="margin-left: 2em">國子監博士是書首題南京兵部武庫司刋行蓋</span>  
<span style="margin-left: 2em">當時官本前載周禮職方氏九州全文其後每省</span>  
<span style="margin-left: 2em">爲一圖而終以四裔各畧載其沿革山川人物古</span>  
<span style="margin-left: 2em">蹟土産舛訛缺畧殊無可觀其四裔一卷傳聞附</span>  
<span style="margin-left: 2em">曾尤多失眞地志中之最劣者也</span>  
<!-- 册2 葉2180a　Page:文淵閣四庫全書_0002冊.djvu/550 -->
皇輿考十二卷<sub class="note-yuan">副都御史黄登賢家藏本</sub>  
<span style="margin-left: 2em">明張天復撰天復號内山山陰人嘉靖丁未進士</span>  
<span style="margin-left: 2em">官至雲南按察司副使事跡附見明史文苑傳其</span>  
<span style="margin-left: 2em">子元忭傳中是書取閩本志畧稍加潤飾其自序</span>  
<span style="margin-left: 2em">云文襄桂公輿地圖志宫諭念庵羅公廣輿圖司</span>  
<span style="margin-left: 2em">馬許公九邊論詞約而事該故徃徃引三家之說</span>  
<span style="margin-left: 2em">冠於篇端文襄桂公者桂萼念庵羅公者羅洪先</span>  
<span style="margin-left: 2em">司馬許公者許論也其大意在規明一統志之失</span>  
<span style="margin-left: 2em">但貪列人物依然挂一漏萬至若四至八到郡縣</span>  
<!-- 册2 葉2180b　Page:文淵閣四庫全書_0002冊.djvu/550 -->
<span style="margin-left: 2em">沿革皆畧而不詳未爲善本</span>  
圖註水陸路程途八卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">明黃汴撰汴不知何許人是書前列南北二京及</span>  
<span style="margin-left: 2em">各省路途後序道路分合里數遠近其山川夷險</span>  
<span style="margin-left: 2em">亦言之頗詳書成於隆慶四年而猶載廣東至安</span>  
<span style="margin-left: 2em">南驛路蓋未棄交趾以前所設舊站亦樂史太平</span>  
<span style="margin-left: 2em">寰宇記載燕雲十六州之例也</span>  
郡縣釋名二十六卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">明郭子章撰子章有蠙衣生易解巳著錄其書以</span>  
<!-- 册2 葉2181a　Page:文淵閣四庫全書_0002冊.djvu/550 -->
<span style="margin-left: 2em">郡縣地名一一詮釋其文義交義可通則畧爲訓</span>  
<span style="margin-left: 2em">詁如福州則云取百順之名永淸則云取邊境永</span>  
<span style="margin-left: 2em">淸之類皆固陋之甚至其不可解者則置而不言</span>  
<span style="margin-left: 2em">亦何取於釋名乎</span>  
目營小輯四卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">明陸化熙撰化熙有詩通巳著錄是書以十三省</span>  
<span style="margin-left: 2em">布政司爲綱而繫以所屬府州縣衛所凡土貢之</span>  
<span style="margin-left: 2em">宜鹽課之增損屯田之稅鈔悉隨地詮叙至太僕</span>  
<span style="margin-left: 2em">寺行太僕寺并各苑馬寺監馬數增耗及邊闗堡</span>  
<!-- 册2 葉2181b　Page:文淵閣四庫全書_0002冊.djvu/550 -->
<span style="margin-left: 2em">寨之廢置武弁員額駐屯之處多有明會典所未</span>  
<span style="margin-left: 2em">載者前有自序題辛酉仲夏辛酉爲天啟元年而</span>  
<span style="margin-left: 2em">書中永平府條下有天啟五年八月現在官兵十</span>  
<span style="margin-left: 2em">一萬七千八十六員名馬騾駝牛五萬三千八百</span>  
<span style="margin-left: 2em">五十二匹𨾏及所支月餉之數則序作於辛酉書</span>  
<span style="margin-left: 2em">成又在乙丑後矣其曰目營者自序謂取目若營</span>  
<span style="margin-left: 2em">四海之意蓋亦有志時務者也</span>  
輿地名勝志一百九十三卷<sub class="note-yuan">江蘇廵撫採進本</sub>  
<span style="margin-left: 2em">明曹學佺撰學佺有易經通論巳著錄學佺以博</span>  
<!-- 册2 葉2184a　Page:文淵閣四庫全書_0002冊.djvu/551 -->
<span style="margin-left: 2em">洽聞著述甚富是書則由雜采而成頗無倫次時</span>  
<span style="margin-left: 2em">亦舛訛又多不著出典未爲善本</span>  
今古輿地圖<sub class="note-yuan">無卷數　江蘇廵撫採進本</sub>  
<span style="margin-left: 2em">不著撰人名氏首列明一綂圖由明溯元層累而</span>  
<span style="margin-left: 2em">上至帝嚳九州凡爲圖五十又别爲古今區域總</span>  
<span style="margin-left: 2em">要厯代山名厯代水名辰次分野列國分野天象</span>  
<span style="margin-left: 2em">分野山河兩戒八圖共爲五十有八凡明郡縣用</span>  
<span style="margin-left: 2em">墨書而厯代沿革異同俱以五色筆界畫細註又</span>  
<span style="margin-left: 2em">各附說於圖中考錢曾讀書敏求記曰古今輿地</span>  
<!-- 册2 葉2184b　Page:文淵閣四庫全書_0002冊.djvu/551 -->
<span style="margin-left: 2em">圖二卷起帝嚳九州至元末羣雄悉以明朝區域</span>  
<span style="margin-left: 2em">爲總要復以朱界其間標舉厯代地理於上凡古</span>  
<span style="margin-left: 2em">今山水名及一行山河兩戒咸載焉據其所言與</span>  
<span style="margin-left: 2em">此本合惟曾云二卷此不分卷曾云起帝嚳九州</span>  
<span style="margin-left: 2em">至元末羣雄此起元末羣雄至帝嚳九州爲小異</span>  
<span style="margin-left: 2em">蓋此書本無卷數曾所藏蓋以篇頁稍繁分爲二</span>  
<span style="margin-left: 2em">冊故以二卷著錄又每頁各自爲圖不相聯屬裝</span>  
<span style="margin-left: 2em">潢者以時代先後叙之故始自帝嚳耳然書名今</span>  
<span style="margin-left: 2em">古不名古今是自後溯前之明證圖旁亦細註某</span>  
<!-- 册2 葉2185a　Page:文淵閣四庫全書_0002冊.djvu/551 -->
<span style="margin-left: 2em">圖第幾字則曾所藏本爲誤移其次序審矣其書</span>  
<span style="margin-left: 2em">於明代郡縣不能計里開方又不能上測經緯二</span>  
<span style="margin-left: 2em">度其方向皆在影響之間根柢先巳不<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">厯代沿</span>  
<span style="margin-left: 2em">革遂皆從之而移曾以謝莊左傳圖比之非其倫</span>  
<span style="margin-left: 2em">也</span>  
天下郡國利病書一百二十卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 1em">國朝顧炎武撰炎武有左傳杜解補正巳著錄是書</span>  
<span style="margin-left: 2em">蓋雜取天下府州縣志書及厯代奏䟽文集並明</span>  
<span style="margin-left: 2em">代實錄輯錄成編其中采掇舊文同異兼收間有</span>  
<!-- 册2 葉2185b　Page:文淵閣四庫全書_0002冊.djvu/551 -->
<span style="margin-left: 2em">矛盾之處編次亦絶無體例蓋未成之藁本也</span>
