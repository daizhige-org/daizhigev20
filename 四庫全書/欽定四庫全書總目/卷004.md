<span style="margin-left: 1em">經部四</span>  
<span style="margin-left: 2em">易類四</span>  
讀易私言一卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">元許衡撰衡字平仲河內人官至集賢殿大學士</span>  
<span style="margin-left: 2em">兼國子祭酒諡文正事迹具元史本傳其書論六</span>  
<span style="margin-left: 2em">爻之德位大㫖多發明繫詞傳同功異位柔危剛</span>  
<span style="margin-left: 2em">勝之義而又類聚各卦畫之居於六位者分别觀</span>  
<span style="margin-left: 2em">之葢健順動止人說陷麗其吉凶悔吝又視乎所</span>  
<!-- 册1 葉401b　Page:文淵閣四庫全書_0001冊.djvu/150 -->
<span style="margin-left: 2em">値之時而必以正且得中爲上孔子彖象傳每以</span>  
<span style="margin-left: 2em">當位不當位得中行中爲言衡所發明葢本斯㫖</span>  
<span style="margin-left: 2em">此書本在衡文集中元蘇天爵文類明劉昌中州</span>  
<span style="margin-left: 2em">文表皆載之</span>  
<span style="margin-left: 1em">國朝曹溶採入學海類編通志堂刋九經解遂從舊</span>  
<span style="margin-left: 2em">本收入而何焯校正九經解目錄以爲卽元李簡</span>  
<span style="margin-left: 2em">之書今考簡所撰學易記其書具在未嘗與此書</span>  
<span style="margin-left: 2em">相複且永樂大典所載亦作許衡則非簡書明甚</span>  
<span style="margin-left: 2em">焯之所校不知何以云然也</span>  
<!-- 册1 葉404a　Page:文淵閣四庫全書_0001冊.djvu/151 -->
易本義附錄纂疏十五卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">元胡一桂撰一桂字庭芳號雙湖婺源人景定甲</span>  
<span style="margin-left: 2em">子領鄉薦試禮部不第教授鄉里以終事迹具元</span>  
<span style="margin-left: 2em">史儒學傳是編以朱子本義爲宗取文集語錄之</span>  
<span style="margin-left: 2em">及於易者附之謂之附錄取諸儒易說之合於本</span>  
<span style="margin-left: 2em">義者纂之謂之纂疏其去取别裁惟以朱子爲宗</span>  
<span style="margin-left: 2em">元史稱其受易源流出於朱子殆以啟䝉翼傳及</span>  
<span style="margin-left: 2em">是書與陳櫟稱一桂此書於楊萬里易傳無半字</span>  
<span style="margin-left: 2em">及之今檢其所引櫟說信然葢宋末元初講學者</span>  
<!-- 册1 葉404b　Page:文淵閣四庫全書_0001冊.djvu/151 -->
<span style="margin-left: 2em">門戸最嚴而新安諸儒於授受源流辨别尤甚萬</span>  
<span style="margin-left: 2em">里易傳雖遠宗程子而早工吟咏與范成大陸游</span>  
<span style="margin-left: 2em">齊名不甚以講學爲事故雖甞薦朱子拒韓𠈁胄</span>  
<span style="margin-left: 2em">而慶元黨禁獨不列名一桂葢以詞人擯之未必</span>  
<span style="margin-left: 2em">盡以其書也</span>  
易學啟䝉翼傳四卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">元胡一桂撰一桂之父方平嘗作易學啟䝉通釋</span>  
<span style="margin-left: 2em">一桂更推闡而辨明之故曰翼傳自序稱去朱子</span>  
<span style="margin-left: 2em">纔百餘年而承學漸失如圖書已𨤲正矣復仍劉</span>  
<!-- 册1 葉405a　Page:文淵閣四庫全書_0001冊.djvu/151 -->
<span style="margin-left: 2em">牧之謬者有之卜筮之數灼如丹靑矣復祖尚元</span>  
<span style="margin-left: 2em">㫖者又有之因於本義附錄纂疏外復輯爲是書</span>  
<span style="margin-left: 2em">凡爲内篇者三一曰舉要以發詞變象占之義二</span>  
<span style="margin-left: 2em">曰明筮以考史傳卜筮卦占之法三曰辨疑以辨</span>  
<span style="margin-left: 2em">河圖洛書之同異皆發明朱子之說者也爲外篇</span>  
<span style="margin-left: 2em">者一則易緯候諸書以及京房飛候焦贑易林揚</span>  
<span style="margin-left: 2em">雄太元司馬光潛虛以至邵子皇極經世諸法亦</span>  
<span style="margin-left: 2em">附錄其槪以其皆易之支流故别之曰外大致與</span>  
<span style="margin-left: 2em">其父之書互相出入而方平主於明本㫖一桂主</span>  
<!-- 册1 葉405b　Page:文淵閣四庫全書_0001冊.djvu/151 -->
<span style="margin-left: 2em">於辨異學故體例各殊焉</span>  
易纂言十卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">元吳澄撰澄字幼淸號草廬崇仁人宋咸淳末舉</span>  
<span style="margin-left: 2em">進士不第入元以薦擢翰林應奉文字官至翰林</span>  
<span style="margin-left: 2em">學士卒諡文正事迹具元史本傳是書用吕祖謙</span>  
<span style="margin-left: 2em">古易本經文每卦先列卦變主爻每爻先列變爻</span>  
<span style="margin-left: 2em">次列象占十翼亦各分章數其訓解各附句下音</span>  
<span style="margin-left: 2em">釋考證則經附每卦之末傳附每章之末間有文</span>  
<span style="margin-left: 2em">義相因卽附辨於句下者偶一二見非通例也澄</span>  
<!-- 册1 葉408a　Page:文淵閣四庫全書_0001冊.djvu/152 -->
<span style="margin-left: 2em">於諸經好臆爲<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）">竄惟此書所改則有根據者爲</span>  
<span style="margin-left: 2em">多如師卦丈人吉改大人吉據崔憬所引子夏傳</span>  
<span style="margin-left: 2em">比卦比之匪人下增凶字據王肅本小畜卦輿說</span>  
<span style="margin-left: 2em">輻改輿說輹據許愼說文尚得載改尚德載據京</span>  
<span style="margin-left: 2em">房虞翻子夏本泰卦包荒改包巟據說文及虞翻</span>  
<span style="margin-left: 2em">本大畜卦曰閑輿衛改日閑輿衛從鄭元虞翻陸</span>  
<span style="margin-left: 2em">希聲本萃卦萃亨刪亨字從馬融鄭元虞翻陸績</span>  
<span style="margin-left: 2em">本困卦劓刖改臲ဂ據荀爽王肅陸績本鼎卦其</span>  
<span style="margin-left: 2em">形渥改其刑剭據鄭元本比彖比吉也刪也字據</span>  
<!-- 册1 葉408b　Page:文淵閣四庫全書_0001冊.djvu/152 -->
<span style="margin-left: 2em">王昭素本賁彖補剛柔交錯四字據王弼注震彖</span>  
<span style="margin-left: 2em">驚遠而懼邇也下補不喪𠤎鬯四字據王昭素所</span>  
<span style="margin-left: 2em">引徐氏本漸彖女歸吉也改女歸吉利貞據王肅</span>  
<span style="margin-left: 2em">本坤象履霜堅冰改初六履霜據魏志坎象樽酒</span>  
<span style="margin-left: 2em">簋貳刪貳字據陸德明釋文<sub class="note-yuan">案澄注明言舊本有貳字陸氏釋文無之</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">今世所行張弧陸希聲本皆同是傳文已刪去貳字徐氏通志堂本乃劖補刋板增入貳字是顧湄</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">等校正之時以不？爲誤也謹附訂於此</sub>繫辭上傳繫辭焉而明吉凶</span>  
<span style="margin-left: 2em">下補悔吝二字據虞翻本繫辭下傳何以守位曰</span>  
<span style="margin-left: 2em">仁改何以守位曰人據王肅本耒耨之利改耒耜</span>  
<!-- 册1 葉409a　Page:文淵閣四庫全書_0001冊.djvu/152 -->
<span style="margin-left: 2em">之利據王昭素本以濟不通下刪致遠以利天下</span>  
<span style="margin-left: 2em">六字據陸德明釋文序卦傳故受之以履下補履</span>  
<span style="margin-left: 2em">者禮也四字據韓康伯本皆援引古義具有源流</span>  
<span style="margin-left: 2em">不比師心變亂其餘亦多依傍胡瑗程子朱子諸</span>  
<span style="margin-left: 2em">說澄所自爲改正者不過數條而巳惟以繫辭傳</span>  
<span style="margin-left: 2em">中說上下經十六卦十八爻之文定爲錯簡移置</span>  
<span style="margin-left: 2em">於文言傳中則悍然臆斷不可以爲訓矣然其解</span>  
<span style="margin-left: 2em">釋經義詞簡理明融貫舊聞亦頗賅洽在元人說</span>  
<span style="margin-left: 2em">易諸家固終爲巨擘焉</span>  
<!-- 册1 葉409b　Page:文淵閣四庫全書_0001冊.djvu/152 -->
易纂言外翼八卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">元吳澄撰澄所著易纂言義例散見各卦中不相</span>  
<span style="margin-left: 2em">統貫卷首所陳卦畫亦粗具梗槪未及詳言因復</span>  
<span style="margin-left: 2em">作此書以暢明之纂言有通志堂刻本久行於世</span>  
<span style="margin-left: 2em">此書則傳本漸罕近遂散佚無存朱彝尊經義考</span>  
<span style="margin-left: 2em">云見明崑山葉氏書目載有四冊而亦未睹其書</span>  
<span style="margin-left: 2em">今惟永樂大典尚分載各韻之下考澄所作小序</span>  
<span style="margin-left: 2em">原書葢共十二篇一曰卦統以八經卦之純體合</span>  
<span style="margin-left: 2em">體者爲經六十四卦之雜體者爲緯乃上下經篇</span>  
<!-- 册1 葉412a　Page:文淵閣四庫全書_0001冊.djvu/153 -->
<span style="margin-left: 2em">之所由分二曰卦對以奇偶反易成二卦成上下</span>  
<span style="margin-left: 2em">篇相對三曰卦變言奇偶復生奇偶其用無窮四</span>  
<span style="margin-left: 2em">曰卦主因无妄傳而推之以明一經之義五曰變</span>  
<span style="margin-left: 2em">卦言剛柔交相變而一卦可爲六十四卦六曰互</span>  
<span style="margin-left: 2em">卦言中四爻復具二卦以爲一卦七曰象例凡經</span>  
<span style="margin-left: 2em">之取象皆類聚之以觀其通八曰占例言元亨利</span>  
<span style="margin-left: 2em">貞吉凶无咎其義皆本於天道九曰辭例乃象例</span>  
<span style="margin-left: 2em">占例所未備而可以互見者十曰變例言揲蓍四</span>  
<span style="margin-left: 2em">營十八變之法十一曰易原明河圖洛書先後天</span>  
<!-- 册1 葉412b　Page:文淵閣四庫全書_0001冊.djvu/153 -->
<span style="margin-left: 2em">圖十二曰易流備舉揚雄以下擬易之書今缺卦</span>  
<span style="margin-left: 2em">變變卦互卦三篇易流缺半篇易原疑亦不完然</span>  
<span style="margin-left: 2em">其餘尚首尾整齊無所遺失自唐定正義易遂以</span>  
<span style="margin-left: 2em">王弼爲宗象數之學久置不講澄爲纂言一夬於</span>  
<span style="margin-left: 2em">象史謂其能盡破傳注之穿鑿故言易者多宗之</span>  
<span style="margin-left: 2em">是編類聚區分以求其理之會通如卦統卦對二</span>  
<span style="margin-left: 2em">篇言經之所以𨤲爲上下乃程朱所未及象例諸</span>  
<span style="margin-left: 2em">篇闡明古義尤非元明諸儒空談妙悟者可比雖</span>  
<span style="margin-left: 2em">稍有殘缺而宏綱巨目尚可推尋謹依原目編次</span>  
<!-- 册1 葉413a　Page:文淵閣四庫全書_0001冊.djvu/153 -->
<span style="margin-left: 2em">析爲八卷俾與纂言相輔而行焉</span>  
易原奥義一卷周易原㫖六卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">元寶巴撰<sub class="note-yuan">案寶巴舊本作保八今改正</sub>寶巴字普菴色目人居</span>  
<span style="margin-left: 2em">於洛陽是書前有進太子牋結銜稱大中大夫前</span>  
<span style="margin-left: 2em">黃州路總管兼管内勸農事又有任士林序稱貳</span>  
<span style="margin-left: 2em">卿寶公不知其終於何官也牋末不題年月黃虞</span>  
<span style="margin-left: 2em">稷千頃堂書目稱舊有方回牟巘二序按回巘皆</span>  
<span style="margin-left: 2em">宋末舊人則寶巴爲元初人矣是書原分三種統</span>  
<span style="margin-left: 2em">名易體用本程子之說卽卦體以闡卦用也朱𢑴</span>  
<!-- 册1 葉413b　Page:文淵閣四庫全書_0001冊.djvu/153 -->
<span style="margin-left: 2em">尊經義考載易原奥義一卷存周易原㫖六卷存</span>  
<span style="margin-left: 2em">周易尚占三卷佚考陳繼儒彚秘笈中有周易尚</span>  
<span style="margin-left: 2em">占三卷書名與卷數並符書前又有大德丁未寶</span>  
<span style="margin-left: 2em">巴序人名亦合然序稱爲瑩蟾子李淸庵撰不云</span>  
<span style="margin-left: 2em">寶巴自作其書乃用錢代蓍之法以六爻配十二</span>  
<span style="margin-left: 2em">時五行六親六神合月建日辰以斷吉凶亦非尚</span>  
<span style="margin-left: 2em">占之本義序文鄙陋尤不類讀書人語葢方技家</span>  
<span style="margin-left: 2em">傳有是書與寶巴佚書其名偶合明人喜作僞本</span>  
<span style="margin-left: 2em">遂撰寶巴序文以影附之不知寶巴說易並根柢</span>  
<!-- 册1 葉416a　Page:文淵閣四庫全書_0001冊.djvu/154 -->
<span style="margin-left: 2em">於宋儒闡發義理無一字涉京焦䜟緯之說其肯</span>  
<span style="margin-left: 2em">以此書當古占法哉今辨明其妄别存目於術數</span>  
<span style="margin-left: 2em">類中而寶巴原書則仍以所存二種著錄庶闕而</span>  
<span style="margin-left: 2em">眞猶勝於全而僞焉</span>  
周易程朱傳義折衷三十三卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">元趙采撰采字德亮號隆齋潼川人其書用注疏</span>  
<span style="margin-left: 2em">本節錄程子易傅朱子本義之說益以語錄諸書</span>  
<span style="margin-left: 2em">列之於前而各以已說附於後所謂折衷也所注</span>  
<span style="margin-left: 2em">僅上下經殆以程子之傳不及繫辭以下與前有</span>
