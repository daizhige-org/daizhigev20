## 欽定四庫全書總目 卷一百九　子部十九　術數類二

<!-- 册3 葉1384a　Page:文淵閣四庫全書_0003冊.djvu/351 -->
欽定四庫全書總目卷一百九  
<span style="margin-left: 1em">子部十九</span>  
<span style="margin-left: 2em">術數𩔖二</span>  
宅經二卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">舊本題曰黄帝宅經案漢志形法家有宫宅地形</span>  
<span style="margin-left: 2em">二十卷則相宅之書較相墓爲古然隋志有宅吉</span>  
<span style="margin-left: 2em">凶論三卷相宅圖八卷舊唐志有五姓宅經二卷</span>  
<span style="margin-left: 2em">皆不云出黄帝是書葢依託也考書中稱黄帝二</span>  
<span style="margin-left: 2em">宅經及淮南子李淳風吕才等宅經二十有九種</span>  
<!-- 册3 葉1384b　Page:文淵閣四庫全書_0003冊.djvu/351 -->
<span style="margin-left: 2em">則作書之時本不僞稱黄帝特方技之流欲神其</span>  
<span style="margin-left: 2em">說詭題黄帝作耳其法分二十四路考尋休咎以</span>  
<span style="margin-left: 2em">八卦之位向乾坎艮震及辰爲陽巽離坤兌及戌</span>  
<span style="margin-left: 2em">爲陰陽以亥爲首巳爲尾陰以巳爲首亥爲尾而</span>  
<span style="margin-left: 2em">主於陰陽相得頗有義理文辭亦皆雅馴宋史藝</span>  
<span style="margin-left: 2em">文志五行類有相宅經一卷疑卽此書在術數之</span>  
<span style="margin-left: 2em">中猶最爲近古者矣</span>  
𦵏書一卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">舊本題晉郭璞撰璞有爾雅註巳著錄葬地之說</span>  
<!-- 册3 葉1385a　Page:文淵閣四庫全書_0003冊.djvu/351 -->
<span style="margin-left: 2em">莫知其所自來周官冡人墓大夫之職稱皆以族</span>  
<span style="margin-left: 2em">𦵏是三代以上𦵏不擇地之明證漢書藝文志形</span>  
<span style="margin-left: 2em">法家始以宫宅地形與相人相物之書並列則其</span>  
<span style="margin-left: 2em">術自漢始萌然尙未專言𦵏法也後漢書袁安傳</span>  
<span style="margin-left: 2em">載安父没訪求𦵏地道逢三書生指一處當世爲</span>  
<span style="margin-left: 2em">上公安從之故累世貴盛是其術盛傳於東漢以</span>  
<span style="margin-left: 2em">後其特以是擅名者則璞爲最著考璞本傳載璞</span>  
<span style="margin-left: 2em">從河東郭公受靑囊中書九卷遂洞天文五行卜</span>  
<span style="margin-left: 2em">筮之術璞門人趙載嘗竊靑囊書爲火所焚不言</span>  
<!-- 册3 葉1385b　Page:文淵閣四庫全書_0003冊.djvu/351 -->
<span style="margin-left: 2em">其嘗著𦵏書唐志有𦵏書地脈經一卷𦵏書五陰</span>  
<span style="margin-left: 2em">一卷又不言爲璞所作惟宋志載有璞𦵏書一卷</span>  
<span style="margin-left: 2em">是其書自宋始出其後方技之家競相粉飾遂有</span>  
<span style="margin-left: 2em">二十篇之多蔡元定病其蕪<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3439.svg?width=24" alt="四庫全書僻字第3439號（襍）" title="四庫全書僻字第3439號（襍）">爲刪去十二篇存</span>  
<span style="margin-left: 2em">其八篇吳澄又病蔡氏未盡藴奥擇至純者爲内</span>  
<span style="margin-left: 2em">篇精粗純駁相半者爲外篇粗駁當去而姑存者</span>  
<span style="margin-left: 2em">爲襍篇新喻劉則章親受之吳氏爲之註釋今此</span>  
<span style="margin-left: 2em">本所分内篇外篇雜篇葢猶吳氏之舊本至注之</span>  
<span style="margin-left: 2em">出於劉氏與否則不可考矣書中詞意簡質猶術</span>  
<!-- 册3 葉1388a　Page:文淵閣四庫全書_0003冊.djvu/352 -->
<span style="margin-left: 2em">士通文義者所作必以爲出自璞手則無可徵信</span>  
<span style="margin-left: 2em">或世見璞𦵏母曁陽卒遠水患故以是書歸之歟</span>  
<span style="margin-left: 2em">其中遺體受蔭之說使後世惑於禍福或稽留而</span>  
<span style="margin-left: 2em">不𦵏或遷徙而不恒巳深爲通儒所闢然如乘生</span>  
<span style="margin-left: 2em">氣一言其義頗精又所云𦵏者原其起乘其止乘</span>  
<span style="margin-left: 2em">風則散界水則止諸條亦多明白簡當王褘靑巖</span>  
<span style="margin-left: 2em">叢錄曰擇地以𦵏其術本於晉郭璞所著𦵏書二</span>  
<span style="margin-left: 2em">十篇多後人增以謬妄之說蔡元定嘗去其十二</span>  
<span style="margin-left: 2em">而存其八後世之爲其術者分爲二宗一曰宗廟</span>  
<!-- 册3 葉1388b　Page:文淵閣四庫全書_0003冊.djvu/352 -->
<span style="margin-left: 2em">之法始於閩中其源甚遠至宋王伋乃大行其爲</span>  
<span style="margin-left: 2em">說主於星卦陽山陽向陰山陰向不相乖錯純取</span>  
<span style="margin-left: 2em">八卦五星以定生尅之理其學浙中傳之而用之</span>  
<span style="margin-left: 2em">者甚鮮一曰江西之法肇於贑人楊筠松曾文迪</span>  
<span style="margin-left: 2em">及頼大有謝子逸輩尤精其學其爲說主於形𫝑</span>  
<span style="margin-left: 2em">原其所起卽其所止以定位向專指龍穴砂水之</span>  
<span style="margin-left: 2em">相配而他拘泥在所不論今大江以南無不遵之</span>  
<span style="margin-left: 2em">者二宗之說雖不相同然皆本於郭氏者也云云</span>  
<span style="margin-left: 2em">是後世言地學者皆以璞爲鼻祖故書雖依託終</span>  
<!-- 册3 葉1389a　Page:文淵閣四庫全書_0003冊.djvu/352 -->
<span style="margin-left: 2em">不得而廢歟據宋志本名𦵏書後來術家尊其說</span>  
<span style="margin-left: 2em">者改名𦵏經毛晉汲古閣刻本亦承其譌殊爲失</span>  
<span style="margin-left: 2em">考今仍題舊名以從其朔云</span>  
撼龍經一卷疑龍經一卷𦵏法倒杖一卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">舊本題唐楊筠松撰筠松不見於史傳惟陳振孫</span>  
<span style="margin-left: 2em">書錄解題載其名氏宋史藝文志則但稱爲楊救</span>  
<span style="margin-left: 2em">貧亦不詳其始末惟術家相傳以爲筠松名益竇</span>  
<span style="margin-left: 2em">州人掌靈臺地理官至金紫光祿大夫廣明中遇</span>  
<span style="margin-left: 2em">黄巢犯闕竊禁中玉函秘術以逃後徃來於䖍州</span>  
<!-- 册3 葉1389b　Page:文淵閣四庫全書_0003冊.djvu/352 -->
<span style="margin-left: 2em">無稽之談葢不是信也然其書乃爲世所盛傳撼</span>  
<span style="margin-left: 2em">龍經專言山龍脈絡形𫝑分貪狼巨門祿存文曲</span>  
<span style="margin-left: 2em">亷貞武曲破軍左輔右弼九星各爲之說疑龍經</span>  
<span style="margin-left: 2em">上篇言幹中尋枝以闗局水口爲主中篇論尋龍</span>  
<span style="margin-left: 2em">到頭看靣背朝迎之法下篇論結穴形𫝑附以疑</span>  
<span style="margin-left: 2em">龍十問以闡明其義𦵏法則專論<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）">穴有𠋣葢撞</span>  
<span style="margin-left: 2em">黏諸說倒杖分十二條卽上說而引伸之附二十</span>  
<span style="margin-left: 2em">四砂𦵏法亦臨穴時分寸毫𨤲之辨案陳振孫書</span>  
<span style="margin-left: 2em">錄解題有疑龍經一卷辨龍經一卷云吳炎錄以</span>  
<!-- 册3 葉1392a　Page:文淵閣四庫全書_0003冊.djvu/353 -->
<span style="margin-left: 2em">見遺皆無名氏是此書在宋並不題筠松所作今</span>  
<span style="margin-left: 2em">本不知何據而云然其撼龍之卽辨龍與否亦無</span>  
<span style="margin-left: 2em">可考證然相傳巳久所論山川之性情形𫝑頗能</span>  
<span style="margin-left: 2em">得其要領流傳不廢亦有以也舊本有李國木註</span>  
<span style="margin-left: 2em">併所附各圖庸陋淺俗了無可取今並加刋削不</span>  
<span style="margin-left: 2em">使與本文相溷焉</span>  
靑囊奥語一卷靑<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3615.svg?width=24" alt="四庫全書僻字第3615號（囊）" title="四庫全書僻字第3615號（囊）">序一卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">靑<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3615.svg?width=24" alt="四庫全書僻字第3615號（囊）" title="四庫全書僻字第3615號（囊）">奥語舊本題唐楊筠松撰其序則題筠松弟</span>  
<span style="margin-left: 2em">子曾文迪所作相傳文迪贑水人其父求巳先奔</span>  
<!-- 册3 葉1392b　Page:文淵閣四庫全書_0003冊.djvu/353 -->
<span style="margin-left: 2em">江南節制李司空辟行南康軍事文迪因得筠松</span>  
<span style="margin-left: 2em">之術後傳於陳摶是書卽其所授師說也案趙希</span>  
<span style="margin-left: 2em">弁讀書後志有靑<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3615.svg?width=24" alt="四庫全書僻字第3615號（囊）" title="四庫全書僻字第3615號（囊）">本㫖一卷云不記撰人演郭</span>  
<span style="margin-left: 2em">璞相墓經陳氏書錄解題有楊公遺訣曜金歌并</span>  
<span style="margin-left: 2em">三十六圖象一卷注云楊卽筠松也今是書以陰</span>  
<span style="margin-left: 2em">陽順逆九星化曜辨山水之貴賤吉凶未審與曜</span>  
<span style="margin-left: 2em">金歌爲一爲二惟鄭樵通志藝文畧别載有曾氏</span>  
<span style="margin-left: 2em">靑<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3615.svg?width=24" alt="四庫全書僻字第3615號（囊）" title="四庫全書僻字第3615號（囊）">子歌一卷又曾楊二家靑<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3615.svg?width=24" alt="四庫全書僻字第3615號（囊）" title="四庫全書僻字第3615號（囊）">經一卷或卽是</span>  
<span style="margin-left: 2em">書之原名歟其中多引而不𤼵之語如坤壬乙巨</span>  
<!-- 册3 葉1393a　Page:文淵閣四庫全書_0003冊.djvu/353 -->
<span style="margin-left: 2em">門從頭出一節厯來註家罕能詳其起例至序内</span>  
<span style="margin-left: 2em">二十四山分順逆一條則大㫖以木火金水分屬</span>  
<span style="margin-left: 2em">甲丙庚壬乙丁辛癸互起長生如甲木生於亥庫</span>  
<span style="margin-left: 2em">於未乙木生於午庫於戌之𩔖因以亥卯未寅午</span>  
<span style="margin-left: 2em">戌巳酉丑申子辰爲四局反覆<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2973.svg?width=24" alt="四庫全書僻字第2973號（衍）" title="四庫全書僻字第2973號（衍）">之得四十八局</span>  
<span style="margin-left: 2em">陽用左旋陰從右轉葢本之說卦陽順陰逆之例</span>  
<span style="margin-left: 2em">爲地學理氣家之權輿明人僞造之吳公教子書</span>  
<span style="margin-left: 2em">劉秉忠玉尺經葢卽竊其緒餘<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2973.svg?width=24" alt="四庫全書僻字第2973號（衍）" title="四庫全書僻字第2973號（衍）">爲圖局逮僧徹</span>  
<span style="margin-left: 2em">瑩作直指元眞專以三元水口隨地可以定向於</span>  
<!-- 册3 葉1393b　Page:文淵閣四庫全書_0003冊.djvu/353 -->
<span style="margin-left: 2em">是談地學者舍形法而言理氣剽竊傅會俱以是</span>  
<span style="margin-left: 2em">編爲口實然不以流派多岐併咎其剏法之始也</span>  
<span style="margin-left: 2em">舊本有註託名劉基李國木復加潤色蕪蔓殊甚</span>  
<span style="margin-left: 2em">又妄據僞玉尺經竄改原文尤爲誕妄今據舊本</span>  
<span style="margin-left: 2em">更正併削去其註以無滋淆惑焉</span>  
天玉經内傳三卷外編一卷<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">舊本題唐楊筠松撰考鄭樵通志藝文畧陳振孫</span>  
<span style="margin-left: 2em">書錄解題楊曾二家書無天玉經之名相傳楊氏</span>  
<span style="margin-left: 2em">師弟秘之不行於世至宋吳見誠遇異人始授以</span>  
<!-- 册3 葉1396a　Page:文淵閣四庫全書_0003冊.djvu/354 -->
<span style="margin-left: 2em">此經其子景鸞乃𤼵明其義然則是書亦至宋始</span>  
<span style="margin-left: 2em">出其爲筠松所撰與否更在影響之間矣特其流</span>  
<span style="margin-left: 2em">傳稍遠詞旨亦頗有義意故言理氣者至今宗之</span>  
<span style="margin-left: 2em">其眞僞可置勿論也内傳首言江東一卦江西一</span>  
<span style="margin-left: 2em">卦南北八神一卦術者罕通其說近時潘思榘作</span>  
<span style="margin-left: 2em">天玉經箋許清竒作天玉經註始推繹下文有父</span>  
<span style="margin-left: 2em">母三般卦又有天卦江東掌上尋之語疑所謂江</span>  
<span style="margin-left: 2em">東者卽天卦所謂江西者卽地卦所謂南北者卽</span>  
<span style="margin-left: 2em">父母卦大抵以甲丙庚壬四陽干左旋起長生者</span>  
<!-- 册3 葉1396b　Page:文淵閣四庫全書_0003冊.djvu/354 -->
<span style="margin-left: 2em">爲東卦陽數竒故曰天卦曰八神四一以乙丁辛</span>  
<span style="margin-left: 2em">癸四陰干右旋起長生者爲西卦陰數耦故曰地</span>  
<span style="margin-left: 2em">卦曰八神四二又以山家之坐向爲南北一卦由</span>  
<span style="margin-left: 2em">天地而及人故曰父母卦葢自神其說故爲隠奥</span>  
<span style="margin-left: 2em">之詞使人惝恍迷離驟不得其指要方技家之譎</span>  
<span style="margin-left: 2em">智徃徃如斯不獨此書爲然也外篇專言四經五</span>
