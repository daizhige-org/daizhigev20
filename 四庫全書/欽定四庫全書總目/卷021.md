## 欽定四庫全書總目 卷二十一　經部二十一　禮類三

<!-- 册1 葉1732：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷二十一  
<span style="margin-left: 1em">經部二十一</span>  
<span style="margin-left: 2em">禮類三</span>  
禮記正義六十三卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">漢鄭元註唐孔頴達疏隋書經籍志曰漢初河間</span>  
<span style="margin-left: 2em">獻王得仲尼弟子及後學者所記一百三十一篇</span>  
<span style="margin-left: 2em">獻之時無傳之者至劉向考校經籍檢得一百三</span>  
<span style="margin-left: 2em">十篇第而敘之又得明堂陰陽記三十三篇孔子</span>  
<span style="margin-left: 2em">三朝記七篇王史氏記二十一篇樂記二十三篇</span>  
<!-- 册1 葉1733b　Page:文淵閣四庫全書_0001冊.djvu/483 -->
<span style="margin-left: 2em">凡五種合二百十四篇戴德刪其煩重合而記之</span>  
<span style="margin-left: 2em">爲八十五篇謂之大戴記而戴聖又刪大戴之書</span>  
<span style="margin-left: 2em">爲四十六篇謂之小戴記漢末馬融遂傳小戴之</span>  
<span style="margin-left: 2em">學融又益月令一篇明堂位一篇樂記一篇合四</span>  
<span style="margin-left: 2em">十九篇云云其說不知所本今考後漢書橋元傳</span>  
<span style="margin-left: 2em">云七世祖仁撰禮記章句四十九篇號曰橋君學</span>  
<span style="margin-left: 2em">仁卽班固所謂小戴授梁人橋季卿者成帝時嘗</span>  
<span style="margin-left: 2em">官大鴻臚其時巳稱四十九篇無四十六篇之說</span>  
<span style="margin-left: 2em">又孔疏稱别錄禮記四十九篇樂記第十九四十</span>  
<!-- 册1 葉1736a　Page:文淵閣四庫全書_0001冊.djvu/484 -->
<span style="margin-left: 2em">九篇之首疏皆引鄭目錄鄭目錄之末必云此於</span>  
<span style="margin-left: 2em">劉向别錄屬某門月令目錄云此於别錄屬明堂</span>  
<span style="margin-left: 2em">陰陽記明堂位目錄云此於别錄屬明堂隂陽樂</span>  
<span style="margin-left: 2em">記目錄云此於别錄屬樂記葢十一篇今爲一篇</span>  
<span style="margin-left: 2em">則三篇皆劉向别錄所有安得以爲馬融所增疏</span>  
<span style="margin-left: 2em">又引元六藝論曰戴德傳記八十五篇則大戴禮</span>  
<span style="margin-left: 2em">是也戴聖傳禮四十九篇則此禮記是也元爲馬</span>  
<span style="margin-left: 2em">融弟子使三篇果融所增元不容不知豈有以四</span>  
<span style="margin-left: 2em">十九篇屬於戴聖之理况融所傳者乃周禮若小</span>  
<!-- 册1 葉1736b　Page:文淵閣四庫全書_0001冊.djvu/484 -->
<span style="margin-left: 2em">戴之學一授橋仁一授楊榮後傳其學者有劉佑</span>  
<span style="margin-left: 2em">高誘鄭元盧植融絶不豫其授受又何從而增三</span>  
<span style="margin-left: 2em">篇乎知今四十九篇實戴聖之原書隋志悞也元</span>  
<span style="margin-left: 2em">延祐中行科舉法定禮記用鄭元註故元儒說禮</span>  
<span style="margin-left: 2em">率有根據自明永樂中勅修禮記大全始廢鄭註</span>  
<span style="margin-left: 2em">改用陳澔集說禮學遂荒然研思古義之士好之</span>  
<span style="margin-left: 2em">者終不絶也爲之疏義者唐初尙存皇侃熊安生</span>  
<span style="margin-left: 2em">二家<sub class="note-yuan">案明北監本以皇侃爲皇甫侃以熊安生爲熊安二人姓名並悞足攸校刋之疎謹附訂</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">於此</sub>貞觀中勅孔頴達等修正義乃以皇氏爲本以</span>  
<!-- 册1 葉1737a　Page:文淵閣四庫全書_0001冊.djvu/484 -->
<span style="margin-left: 2em">熊氏補所未備頴達序稱熊則違背本經多引外</span>  
<span style="margin-left: 2em">義猶之楚而北行馬雖疾而去愈遠又欲釋經文</span>  
<span style="margin-left: 2em">惟聚難義猶治絲而棼之手雖繁而絲益亂也皇</span>  
<span style="margin-left: 2em">氏雖章句詳正微稍繁廣又旣遵鄭氏又時乖鄭</span>  
<span style="margin-left: 2em">義此是木落不歸其根狐死不首其邱皆二家之</span>  
<span style="margin-left: 2em">弊未爲得也故其書務伸鄭註未免有附會之處</span>  
<span style="margin-left: 2em">然採摭舊文詞富理博說禮之家鑽硏莫盡譬諸</span>  
<span style="margin-left: 2em">依山鑄銅煮海爲鹽卽衞湜之書尙不能窺其涯</span>  
<span style="margin-left: 2em">涘陳澔之流益如莛與楹矣</span>  
<!-- 册1 葉1737b　Page:文淵閣四庫全書_0001冊.djvu/484 -->
月令解十二卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋張虙撰虙慈溪人慶元丙辰進士官至國子祭</span>  
<span style="margin-left: 2em">酒是編乃虙端平初入講幄時所纂未及講竟以</span>  
<span style="margin-left: 2em">病歸家居時乃續完之表進於朝十二月各自爲</span>  
<span style="margin-left: 2em">卷奏稱每一月改則令以此一月進於御前可以</span>  
<span style="margin-left: 2em">裁成天地之道輔相天地之宜雖未免過膠古義</span>  
<span style="margin-left: 2em">不盡可見諸施行然辭義曉暢於順時出政之際</span>  
<span style="margin-left: 2em">皆三致意焉其用心有足取者月令於劉向别錄</span>  
<span style="margin-left: 2em">屬明堂陰陽記當卽漢書藝文志所云古明堂之</span>  
<!-- 册1 葉1740a　Page:文淵閣四庫全書_0001冊.djvu/485 -->
<span style="margin-left: 2em">遺事在明堂陰陽三十篇之内者吕氏春秋錄以</span>  
<span style="margin-left: 2em">分冠十二紀馬融賈逵蔡邕王肅孔晁張華皆以</span>  
<span style="margin-left: 2em">爲周公作鄭康成高誘以爲卽不韋作論者據漢</span>  
<span style="margin-left: 2em">書百官表言太尉爲秦官或又據國語晉有元尉</span>  
<span style="margin-left: 2em">輿尉之文謂尉之名不必起於秦然究不得因元</span>  
<span style="margin-left: 2em">尉輿尉遂斷三代必有太尉也意不韋採集舊文</span>  
<span style="margin-left: 2em">或附益以秦制歟今考其書古帝王發政施令之</span>  
<span style="margin-left: 2em">大端皆彰彰具存得其意而變通之未嘗非通經</span>  
<span style="margin-left: 2em">適用之一助至其言誤某令則致某災殆因洪範</span>  
<!-- 册1 葉1740b　Page:文淵閣四庫全書_0001冊.djvu/485 -->
<span style="margin-left: 2em">庶徴而推衍之遂爲漢儒陰陽五行之濫觴虙解</span>  
<span style="margin-left: 2em">皆未能駁正然列在禮經相沿已久亦不能獨爲</span>  
<span style="margin-left: 2em">虙咎也原書因隨月進御故凡解見孟月者仲月</span>  
<span style="margin-left: 2em">季月皆重見永樂大典所載各爲一編多刪其複</span>  
<span style="margin-left: 2em">於例爲協間有刪之不盡者今併汰除以歸畫一</span>  
<span style="margin-left: 2em">焉</span>  
禮記集說一百六十卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">宋衛湜撰湜字正叔吳郡人其書始作於開禧嘉</span>  
<span style="margin-left: 2em">定間自序言日編月削幾二十餘載而後成寶慶</span>  
<!-- 册1 葉1741a　Page:文淵閣四庫全書_0001冊.djvu/485 -->
<span style="margin-left: 2em">二年官武進令時表上於朝得擢<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">秘閣後終於</span>  
<span style="margin-left: 2em">朝散大夫<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">寶謨閣知袁州紹定辛卯趙善湘爲</span>  
<span style="margin-left: 2em">鋟板於江東漕院越九年湜復加校訂定爲此本</span>  
<span style="margin-left: 2em">自作前序後序又自作跋尾述其始末甚詳蓋首</span>  
<span style="margin-left: 2em">尾閱三十餘載故採摭羣言最爲賅博去取亦最</span>  
<span style="margin-left: 2em">爲精審自鄭注而下所取凡一百四十四家其他</span>  
<span style="margin-left: 2em">書之涉於禮記者所採錄不在此數焉今自鄭注</span>  
<span style="margin-left: 2em">孔疏而外原書無一存者朱彝尊經義考採摭亦</span>  
<span style="margin-left: 2em">最爲繁富而不知其書與不知其人者凡四十九</span>  
<!-- 册1 葉1741b　Page:文淵閣四庫全書_0001冊.djvu/485 -->
<span style="margin-left: 2em">家皆賴此書以傳亦可云禮家之淵海矣明初定</span>  
<span style="margin-left: 2em">制乃以陳澔注立於學官而湜注在若隱若顯間</span>  
<span style="margin-left: 2em">今</span>  
聖朝  
欽定禮記義疏取於湜書者特多豈非是非之公久必  
<span style="margin-left: 2em">論定乎又湜後序有云他人著書惟恐不出於巳</span>  
<span style="margin-left: 2em">予之此編惟恐不出於人後有達者毋襲此編所</span>  
<span style="margin-left: 2em">巳言没前人之善也其後慈谿黃震讀禮記日抄</span>  
<span style="margin-left: 2em">新安陳櫟禮記集義詳解皆取湜書刪節而附以</span>  
<!-- 册1 葉1744a　Page:文淵閣四庫全書_0001冊.djvu/486 -->
<span style="margin-left: 2em">巳見黃氏融滙諸家猶出姓名於下方<sub class="note-yuan">案此見黃氏日鈔</sub></span>  
<span style="margin-left: 2em">陳氏則不復標出<sub class="note-yuan">案櫟書今不傳此見定宇集中櫟所作自序</sub>卽此一</span>  
<span style="margin-left: 2em">節非惟其書可貴其用心之原亦殆非諸家所及</span>  
<span style="margin-left: 2em">矣</span>  
禮記纂言三十六卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">元吳澄撰澄有易纂言巳著錄案危素作澄年譜</span>  
<span style="margin-left: 2em">載至順三年澄年八十四留撫州郡學禮記纂言</span>  
<span style="margin-left: 2em">成而虞集行狀則稱成於至順四年卽澄卒之歲</span>  
<span style="margin-left: 2em">其言頗不相合然要爲澄晚年手定之本也其書</span>  
<!-- 册1 葉1744b　Page:文淵閣四庫全書_0001冊.djvu/486 -->
<span style="margin-left: 2em">每一卷爲一篇大㫖以戴記經文龎雜疑多錯簡</span>  
<span style="margin-left: 2em">故每一篇中其文皆以𩔖相從俾上下意義聯屬</span>  
<span style="margin-left: 2em">貫通而識其章句於左其三十六篇次第亦以𩔖</span>  
<span style="margin-left: 2em">相從凡通禮九篇䘮禮十一篇祭禮四篇通論十</span>  
<span style="margin-left: 2em">一篇各爲標目如通禮首曲禮則以少儀玉藻等</span>  
<span style="margin-left: 2em">篇附之皆非小戴之舊他如大學中庸依程朱別</span>  
<span style="margin-left: 2em">爲一書投壺奔䘮歸於儀禮冠儀等六篇别輯爲</span>  
<span style="margin-left: 2em">儀禮傳亦皆與古不同虞集稱其始終先後最爲</span>  
<span style="margin-left: 2em">精密先王之遺制聖賢之格言其僅存可考者旣</span>  
<!-- 册1 葉1745a　Page:文淵閣四庫全書_0001冊.djvu/486 -->
<span style="margin-left: 2em">表而存之各有所附而其糾紛固泥於專門名家</span>  
<span style="margin-left: 2em">之手者一旦各有條理無復餘蕴其推重甚至考</span>  
<span style="margin-left: 2em">漢書藝文志禮記本一百三十一篇戴德刪爲八</span>  
<span style="margin-left: 2em">十五戴聖刪爲四十九與易書詩春秋經聖人手</span>  
<span style="margin-left: 2em">定者固殊然舊唐書元行沖傳載行沖上𩔖禮義</span>  
<span style="margin-left: 2em">疏張說駁奏曰今之禮記厯代傳習著爲經教不</span>  
<span style="margin-left: 2em">可刋削魏孫炎始改舊本先儒所非竟不行用貞</span>  
<span style="margin-left: 2em">觀中魏徵因孫炎所修更加整比兼爲之註其書</span>  
<span style="margin-left: 2em">竟亦不行今行沖等解徴所著勒成一家然與先</span>  
<!-- 册1 葉1745b　Page:文淵閣四庫全書_0001冊.djvu/486 -->
<span style="margin-left: 2em">儒第乖章句隔絶若欲行用竊恐未可云云則古</span>  
<span style="margin-left: 2em">人屢經修緝迄不能變漢儒舊本唐以前儒風淳</span>  
<span style="margin-left: 2em">實不揺撼於新說此亦一徴澄復改併舊文儼然</span>  
<span style="margin-left: 2em">刪述恐亦不免僣聖之譏以其排比貫串頗有倫</span>  
<span style="margin-left: 2em">次所解亦時有發明較諸王栢刪詩尚爲有間故</span>  
<span style="margin-left: 2em">錄存之而附論其失如右</span>  
雲莊禮記集說十巻<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">元陳澔撰澔字可大都昌人雲莊其號也是書成</span>  
<span style="margin-left: 2em">於至治壬戌朱彝尊經義考作三十卷今本十卷</span>  
<!-- 册1 葉1748a　Page:文淵閣四庫全書_0001冊.djvu/487 -->
<span style="margin-left: 2em">坊賈所合併也初延祐科舉之制易書詩春秋皆</span>  
<span style="margin-left: 2em">以宋儒新說與古注疏相㕘惟禮記則專用古注</span>  
<span style="margin-left: 2em">疏葢其時老師宿儒猶有存者知禮不可以空言</span>  
<span style="margin-left: 2em">解也澔成是書又在延祐之後亦未爲儒者所稱</span>  
<span style="margin-left: 2em">明初始定禮記用澔註胡廣等修五經大全禮記</span>  
<span style="margin-left: 2em">亦以澔註爲主用以取士遂誦習相沿葢說禮記</span>  
<span style="margin-left: 2em">者漢唐莫善於鄭孔而鄭註簡奧孔疏典贍皆不</span>  
<span style="margin-left: 2em">似澔註之淺顯宋代莫善於衛湜而卷帙繁富亦</span>  
<span style="margin-left: 2em">不似澔註之簡便又南宋寶慶以後朱子之學大</span>

<span style="margin-left: 2em">盛稱朱子考定之本與履祥續作之注而不以創</span>  
<span style="margin-left: 2em">始稱崧卿葢講學家各尊所聞非公論也其中如</span>

<span style="margin-left: 2em">之辰繫於日十一月之於時日也萬物不通皆宜</span>

<span style="margin-left: 4em">今併移入四書以所解者四書之大學中庸</span>
