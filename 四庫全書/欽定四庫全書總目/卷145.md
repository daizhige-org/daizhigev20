## 欽定四庫全書總目 卷一百四十五　子部五十五　釋家類

<!-- 册3 葉4252a　Page:文淵閣四庫全書_0003冊.djvu/1068 -->
欽定四庫全書總目卷一百四十五  
<span style="margin-left: 1em">子部五十五</span>  
<span style="margin-left: 2em">釋家類</span>  
<span style="margin-left: 3em">梁阮孝緖作七錄以二氏之文別錄於末隋書</span>  
<span style="margin-left: 3em">遵用其例亦附於志末有部數卷數而無書名</span>  
<span style="margin-left: 3em">舊唐書以古無釋家遂併佛書於道家頗乖名</span>  
<span style="margin-left: 3em">實然惟錄諸家之書爲二氏作者而不錄二氏</span>  
<span style="margin-left: 3em">之經典則其義可從今錄二氏於子部未用阮</span>  
<span style="margin-left: 3em">孝緖例不錄經典用劉昫例也諸志皆道先於</span>  
<!-- 册3 葉4252b　Page:文淵閣四庫全書_0003冊.djvu/1068 -->
<span style="margin-left: 3em">釋然魏書已稱釋老志七錄舊目載於釋道宣</span>  
<span style="margin-left: 3em">廣宏明集者亦以釋先於道故今所敘錄以釋</span>  
<span style="margin-left: 3em">家居前焉</span>  
宏明集十四卷<sub class="note-yuan">兵部侍郞紀盷家藏本</sub>  
<span style="margin-left: 2em">梁釋僧祐編僧祐姓俞氏彭城下邳人初出家<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3951.svg?width=24" alt="四庫全書僻字第3951號（揚 --（『昜』上『旦』之『日』與『一』相連））" title="四庫全書僻字第3951號（揚 --（『昜』上『旦』之『日』與『一』相連））"></span>  
<span style="margin-left: 2em">都建初寺武帝時居鍾山定林寺唐書藝文志載</span>  
<span style="margin-left: 2em">僧祐宏明集十四卷此本卷數相符葢猶釋藏之</span>  
<span style="margin-left: 2em">舊末有僧祐後序而首無前序疑傳寫佚之所輯</span>  
<span style="margin-left: 2em">皆東漢以下至於梁代闡明佛法之文其學主於</span>  
<!-- 册3 葉4253a　Page:文淵閣四庫全書_0003冊.djvu/1068 -->
<span style="margin-left: 2em">戒律其說主於因果其大旨則主於抑周孔排黃</span>  
<span style="margin-left: 2em">老而獨伸釋氏之法夫天不言而自尊聖人之道</span>  
<span style="margin-left: 2em">不言而自信不待夸不待辨也恐人不尊不信而</span>  
<span style="margin-left: 2em">囂張其外以彌縫之是亦不足於中之明證矣然</span>  
<span style="margin-left: 2em">六代遺編流傳最古梁以前名流著作今無專集</span>  
<span style="margin-left: 2em">行世者頗賴以存終勝庸俗緇流所撰述就釋言</span>  
<span style="margin-left: 2em">釋猶彼教中雅馴之言也</span>  
廣宏明集三十卷<sub class="note-yuan">兵部侍郞紀昀家藏本</sub>  
<span style="margin-left: 2em">唐釋道宣撰道宣姓錢氏丹徒人隋末居終南白</span>  
<!-- 册3 葉4253b　Page:文淵閣四庫全書_0003冊.djvu/1068 -->
<span style="margin-left: 2em">泉寺又遷豐德寺淨業寺至唐高宗時乃卒持戒</span>  
<span style="margin-left: 2em">精苦釋家謂之宣律師唐志載廣宏明集三十卷</span>  
<span style="margin-left: 2em">與此本合然二十七卷以後每卷各分上下實三</span>  
<span style="margin-left: 2em">十四卷也其書續梁僧祐宏明集而體例小殊分</span>  
<span style="margin-left: 2em">爲十篇一曰歸正二曰辨惑三曰佛德四曰法義</span>  
<span style="margin-left: 2em">五曰僧行六曰慈濟七曰戒功八曰啟福九曰悔</span>  
<span style="margin-left: 2em">罪十曰統歸每篇各爲小序大旨排斥道教與僧</span>  
<span style="margin-left: 2em">祐書相同其中如魏書釋老志本於二氏神異各</span>  
<span style="margin-left: 2em">有紀錄雖同爲粉飾而無所抑<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3951.svg?width=24" alt="四庫全書僻字第3951號（揚 --（『昜』上『旦』之『日』與『一』相連））" title="四庫全書僻字第3951號（揚 --（『昜』上『旦』之『日』與『一』相連））">道宣乃於敘釋</span>  
<!-- 册3 葉4256a　Page:文淵閣四庫全書_0003冊.djvu/1069 -->
<span style="margin-left: 2em">氏者具載其全文敘道家者潛刪其靈蹟然則𡨚</span>  
<span style="margin-left: 2em">親無等猶爲最初之佛法迫其後世味漸深勝負</span>  
<span style="margin-left: 2em">互軋雖以叢林古德人天瞻禮如道宣者亦不免</span>  
<span style="margin-left: 2em">於門戸之見矣其書採摭浩博卷帙倍於僧祐如</span>  
<span style="margin-left: 2em">梁簡文帝被幽述志詩及連珠三首之類頗爲泛</span>  
<span style="margin-left: 2em">濫然道宣生隋唐之間古書多未散佚故墜簡遺</span>  
<span style="margin-left: 2em">文往往而在如阮孝緖七錄序文及其門目部分</span>  
<span style="margin-left: 2em">儒家久已失傳隋志僅存其說而此書第三卷内</span>  
<span style="margin-left: 2em">乃載其大綱尙可推尋崖畧是亦禮失求野之一</span>  
<!-- 册3 葉4256b　Page:文淵閣四庫全書_0003冊.djvu/1069 -->
<span style="margin-left: 2em">端不可謂無裨考證也神僧傳稱僧祐前身爲南</span>  
<span style="margin-left: 2em">齊剡溪隱嶽寺僧䕶道宣前身卽爲僧祐殆因道</span>  
<span style="margin-left: 2em">宣續僧祐之書故附會是說又稱道宣卒於乾封</span>  
<span style="margin-left: 2em">二年而書末有遊大慈恩寺詩乃題高宗之諡殊</span>  
<span style="margin-left: 2em">不可解又注曰一作唐太宗葢知其牴牾爲之遷</span>  
<span style="margin-left: 2em">就考雍錄載慈恩寺貞觀二十二年高宗在春宫</span>  
<span style="margin-left: 2em">時爲文德皇后立則太宗猶及見之然大慈恩之</span>  
<span style="margin-left: 2em">名可以出高宗之口不可以出太宗之口殆原本</span>  
<span style="margin-left: 2em">題爲御製後人誤改歟</span>  
<!-- 册3 葉4257a　Page:文淵閣四庫全書_0003冊.djvu/1069 -->
法苑珠林一百二十卷<sub class="note-yuan">大理寺卿陸錫熊家藏本</sub>  
<span style="margin-left: 2em">唐釋道世撰道世字元惲上都西明寺僧是書成</span>  
<span style="margin-left: 2em">於高宗總章元年朝散大夫蘭臺侍郞隴西李儼</span>  
<span style="margin-left: 2em">爲之序稱事總百篇勒成十帙此本乃一百二十</span>  
<span style="margin-left: 2em">卷葢百篇乃其總綱書中則約畧篇頁而分卷帙</span>  
<span style="margin-left: 2em">如千佛篇十惡篇則一篇分七八卷善友篇惡友</span>  
<span style="margin-left: 2em">篇擇交篇則兩三篇共一卷故書凡一百一十八</span>  
<span style="margin-left: 2em">卷而目錄二卷亦入卷數與陸德明經典釋文例</span>  
<span style="margin-left: 2em">同合之共爲百二十也毎篇各有述意如史傳之</span>  
<!-- 册3 葉4257b　Page:文淵閣四庫全書_0003冊.djvu/1069 -->
<span style="margin-left: 2em">序子目之首則或有述意或無述意爲例不一大</span>  
<span style="margin-left: 2em">旨以佛經故實分類編排推明罪福之由用生敬</span>  
<span style="margin-left: 2em">信之念葢佛法初興惟明因果曁達摩東邁始啟</span>  
<span style="margin-left: 2em">禪宗譬以六經之傳則因果如漢儒之訓詁雖專</span>  
<span style="margin-left: 2em">門授受株守師承而名物典故悉求依據其學核</span>  
<span style="margin-left: 2em">實而難誣禪宗如宋儒之義理雖覃思㝠會妙悟</span>  
<span style="margin-left: 2em">多方而擬議揣摩可以臆測其說憑虛而易騁故</span>  
<span style="margin-left: 2em">心印之教旣行天下咸避難趨易辨才無碍語錄</span>  
<span style="margin-left: 2em">日增而腹笥三藏之學在釋家亦幾乎絶響矣此</span>  
<!-- 册3 葉4260a　Page:文淵閣四庫全書_0003冊.djvu/1070 -->
<span style="margin-left: 2em">書作於唐初去古未遠在彼法之中猶爲引經據</span>  
<span style="margin-left: 2em">典雖其間荒唐悠謬之說與儒理牴牾而要與儒</span>  
<span style="margin-left: 2em">不相亂存之可考釋氏之掌故較後來侈談心性</span>  
<span style="margin-left: 2em">彌近理大亂眞者固尙有間矣</span>  
開元釋教錄二十卷<sub class="note-yuan">江西按察使王昶家藏本</sub>  
<span style="margin-left: 2em">唐釋智昇撰智昇開元中居長安西崇福寺是編</span>  
<span style="margin-left: 2em">以三藏經論編爲目錄不分門目但以譯人時代</span>  
<span style="margin-left: 2em">爲先後起漢明帝永平十年丁卯迄開元十八年</span>  
<span style="margin-left: 2em">庚午凡六百六十四載中間傳經緇素總一百七</span>  
<!-- 册3 葉4260b　Page:文淵閣四庫全書_0003冊.djvu/1070 -->
<span style="margin-left: 2em">十六人所出大小二乘三藏聖教及聖賢集傳併</span>  
<span style="margin-left: 2em">及失譯總二千二百七十八部合七千四十六卷</span>  
<span style="margin-left: 2em">分爲二錄一曰總括羣經錄皆先列譯人名氏次</span>  
<span style="margin-left: 2em">列所譯經名卷數及或存或佚末列小傳各詳其</span>  
<span style="margin-left: 2em">人之始末凡九卷其第十卷則載厯代佛經目錄</span>  
<span style="margin-left: 2em">凡古目錄二十五家僅存其名新目錄十六家具</span>  
<span style="margin-left: 2em">列其數首爲古經錄一卷謂爲秦始皇時釋利防</span>  
<span style="margin-left: 2em">等所齎其說恍惚無徴次爲舊經錄一卷稱爲劉</span>  
<span style="margin-left: 2em">向校書天祿閣所見葢依據向列仙傳序稱七十</span>  
<!-- 册3 葉4261a　Page:文淵閣四庫全書_0003冊.djvu/1070 -->
<span style="margin-left: 2em">二人巳見佛經之文至稱爲孔壁所藏則無庸置</span>  
<span style="margin-left: 2em">辨矣餘自漢時佛經目錄以後則固皆有實徴者</span>  
<span style="margin-left: 2em">也一曰別分乘藏錄凡爲七類一曰有譯有本二</span>  
<span style="margin-left: 2em">曰有譯無本三曰支𣲖別行四曰刪畧繁重五曰</span>  
<span style="margin-left: 2em">拾遺補闕六曰疑惑再譯七曰僞邪亂眞則各以</span>  
<span style="margin-left: 2em">經論類從州列部分與總錄一經一緯凡八卷其</span>  
<span style="margin-left: 2em">第十九卷則大乘經律論入藏目錄第二十卷則</span>  
<span style="margin-left: 2em">小乘經律論聖賢集傳入藏目錄也佛氏舊文兹</span>  
<span style="margin-left: 2em">爲大備亦兹爲最古所列諸傳尤足爲考證之資</span>  
<!-- 册3 葉4261b　Page:文淵閣四庫全書_0003冊.djvu/1070 -->
<span style="margin-left: 2em">朱𢑴尊作經義考號爲善本而核其體例多與此</span>  
<span style="margin-left: 2em">符或爲規仿或爲闇合均未可定然足見其爲緇</span>  
<span style="margin-left: 2em">流之中嫻於著作者矣考隋書載王儉七志以道</span>  
<span style="margin-left: 2em">佛附見合爲七門阮孝緖七錄則以佛錄第六道</span>  
<span style="margin-left: 2em">錄第七共爲七門隋志則於四部之末附載道經</span>  
<span style="margin-left: 2em">佛經之總數而不列其曰唐志以下頗載經曰而</span>  
<span style="margin-left: 2em">挂漏實多今於二氏之書皆擇體裁猶近儒書者</span>  
<span style="margin-left: 2em">畧存數家以備參考至經典敘目則惟錄此書及</span>  
<span style="margin-left: 2em">白雲霽道藏目錄以存梗槪亦猶隋志但列總數</span>  
<!-- 册3 葉4264a　Page:文淵閣四庫全書_0003冊.djvu/1071 -->
<span style="margin-left: 2em">之意云爾</span>  
宋高僧傳三十卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋釋贊寧撰贊寧有筍譜已著錄是書乃太平興</span>  
<span style="margin-left: 2em">國七年奉太宗勅旨編撰至端拱元年十月書成</span>  
<span style="margin-left: 2em">遣夭壽寺僧顯忠等於乾明節奉表上進有勅奬</span>  
<span style="margin-left: 2em">諭賜絹三十匹仍令僧錄司編入大藏而宋史藝</span>  
<span style="margin-left: 2em">文志不著錄葢史志於外教之書粗存梗槪不必</span>  
<span style="margin-left: 2em">求全於例當然亦於理當然也高僧傳之名起於</span>  
<span style="margin-left: 2em">梁釋惠敏分譯經義解兩門釋慧皎復加推擴分</span>  
<!-- 册3 葉4264b　Page:文淵閣四庫全書_0003冊.djvu/1071 -->
<span style="margin-left: 2em">立十科至唐釋道宣續高僧傳蒐輯彌博於是分</span>  
<span style="margin-left: 2em">譯經義解習禪明律䕶法感通遺身讀誦興福雜</span>  
<span style="margin-left: 2em">科十門所載迄唐貞觀而止贊寧此書葢又以續</span>  
<span style="margin-left: 2em">道宣之後故所錄始於唐高宗時門目亦一仍其</span>  
<span style="margin-left: 2em">舊凡正傳五百三十三人附見一百三十人傳後</span>  
<span style="margin-left: 2em">附以論斷於傳授源流最爲賅備中間如武后時</span>  
<span style="margin-left: 2em">人皆系之周朝殊乖史法又所載旣托始於唐而</span>  
<span style="margin-left: 2em">雜科篇中乃有劉宋元魏二人亦爲未明限斷然</span>  
<span style="margin-left: 2em">其於誄銘記志摭採不遺實稱詳博文格亦頗雅</span>  
<!-- 册3 葉4265a　Page:文淵閣四庫全書_0003冊.djvu/1071 -->
<span style="margin-left: 2em">贍考釋門之典故者固於兹有取焉</span>  
法藏碎金錄十卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋晁迥撰迥有昭德新編已著錄迥受學於王禹</span>  
<span style="margin-left: 2em">偁以文章典贍擅名而性躭禪悅喜究心於内典</span>  
<span style="margin-left: 2em">是編乃天聖五年退居昭德里所作皆融會佛理</span>  
<span style="margin-left: 2em">隨筆記載葢亦宗門語錄之𩔖其曰碎金取世說</span>
