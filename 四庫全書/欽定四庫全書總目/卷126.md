## 欽定四庫全書總目 卷一百二十六　子部三十六　雜家類存目三

<!-- 册3 葉2880：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷一百二十六  
<span style="margin-left: 1em">子部三十六</span>  
<span style="margin-left: 2em">雜家類存目三</span>  
事始一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">不著撰人名氏其書皆推原事物之始雜引經史</span>  
<span style="margin-left: 2em">如以太師始於吕望考之尚書箕子已先爲之則</span>  
<span style="margin-left: 2em">非周始也又如開府儀同三司謂始於漢代考漢</span>  
<span style="margin-left: 2em">建初二年使車騎將軍馬防班同三司同三司自</span>  
<span style="margin-left: 2em">此始延平元年鄧隲爲車𮪍將軍儀同三司儀同</span>  
<!-- 册3 葉2881b　Page:文淵閣四庫全書_0003冊.djvu/725 -->
<span style="margin-left: 2em">之號自此始而皆不云開府至魏黄權乃以車𮪍</span>  
<span style="margin-left: 2em">將軍開府儀同三司葢漢制惟三公開府至魏始</span>  
<span style="margin-left: 2em">有開府儀同三司之號是編混而一之皆失精審</span>  
<span style="margin-left: 2em">又如檀弓載乘邱之戰乃士有誄之始非自是而</span>  
<span style="margin-left: 2em">始有誄引爲誄始亦殊疎舛案郡齋讀書志載唐</span>  
<span style="margin-left: 2em">劉將孫事始三卷晁公武謂分二十六門與此本</span>  
<span style="margin-left: 2em">體例不合又載蜀馮鑑續事始十卷卷數尤不相</span>  
<span style="margin-left: 2em">應此本所引皆唐以前書疑後人抄撮類書中所</span>  
<span style="margin-left: 2em">引劉將孫書凑合成帙也</span>  
<!-- 册3 葉2884a　Page:文淵閣四庫全書_0003冊.djvu/726 -->
釋常談三卷<sub class="note-yuan">兵部侍郞紀昀家藏本</sub>  
<span style="margin-left: 2em">不著撰人名氏考陳振孫書錄解題曰續釋常談</span>  
<span style="margin-left: 2em">二卷秘書丞龔頥正養正撰<sub class="note-yuan">案王楙野客叢書作二十卷此葢誤脫十</sub></span>  
<span style="margin-left: 2em"><small>字</small>昔有釋常談一書不著名氏今故以續稱凡常</span>  
<span style="margin-left: 2em">言俗語皆著其所始然則此書之作在襲頥正之</span>  
<span style="margin-left: 2em">前當出北宋人手矣原序稱隨目註解總得二百</span>  
<span style="margin-left: 2em">事而此本僅一百二十六事殆後人病其冗濫有</span>  
<span style="margin-left: 2em">所刋除歟明謝肇淛文海披沙云釋常談一書作</span>  
<span style="margin-left: 2em">者不著名氏其中援引蕪陋極有可笑至以鵞爲</span>  
<!-- 册3 葉2884b　Page:文淵閣四庫全書_0003冊.djvu/726 -->
<span style="margin-left: 2em">右軍筯爲趙達盲爲小冠子夏癭爲智囊醉爲倒</span>  
<span style="margin-left: 2em">載覔食爲彈鋏五遷爲盤庚子死爲䘮明聾爲黈</span>  
<span style="margin-left: 2em">纊皆謬誤不經似村學究所爲其引<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3688.svg?width=24" alt="四庫全書僻字第3688號（負）" title="四庫全書僻字第3688號（負）">荆一叚尤</span>  
<span style="margin-left: 2em">似打鼓上場人語也云云今核其書如謂程普爲</span>  
<span style="margin-left: 2em">程據謂夫婦不睦爲參商謂戴帽爲張葢卸㡌爲</span>  
<span style="margin-left: 2em">傾葢謂鳯兮鳯兮爲孔子之語謂屣歩爲不乘鞍</span>  
<span style="margin-left: 2em">馬謂膏肓之疾爲晉悼公謂秦醫爲盧醫謂董宣</span>  
<span style="margin-left: 2em">封强項侯謂飮酒燭滅爲絶纓謂自稱巳善爲自</span>  
<span style="margin-left: 2em">媒齊東之語展卷皆是尙不止肇淛之所摘而災</span>  
<!-- 册3 葉2885a　Page:文淵閣四庫全書_0003冊.djvu/726 -->
<span style="margin-left: 2em">棃禍棗流傳五六百年亦事之不可理解者矣</span>  
别釋常談三卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">不著撰人名氏其中引中庸冠以禮記知爲宋人</span>  
<span style="margin-left: 2em">稱齊桓公爲威公知爲南宋人故所徵引如蘇軾</span>  
<span style="margin-left: 2em">東坡集蘇轍欒城集魏泰臨漢𨼆居詩話之𩔖皆</span>  
<span style="margin-left: 2em">至北宋而止也以先有釋常談續釋常談故以别</span>  
<span style="margin-left: 2em">釋爲名其淺陋鄙俚亦與二書相等摘之不可勝</span>  
<span style="margin-left: 2em">摘也</span>  
肻綮錄一卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<!-- 册3 葉2885b　Page:文淵閣四庫全書_0003冊.djvu/726 -->
<span style="margin-left: 2em">宋趙叔問撰叔問自號西𨼆老人其始末末詳以</span>  
<span style="margin-left: 2em">宋宗室聯名字推之蓋魏王廷美之裔也是書首</span>  
<span style="margin-left: 2em">辨俚俗字義於陸法言唐韻注中摘錄以備考證</span>  
<span style="margin-left: 2em">然唐韻爲孫愐作法言隋時人所著乃切韻非唐</span>  
<span style="margin-left: 2em">韻開卷先誤又謂孟子名應讀口箇切不知韓愈</span>  
<span style="margin-left: 2em">石鼓歌正押平聲其他辨証亦多說部習見之文</span>  
<span style="margin-left: 2em">無可采錄</span>  
古今考一卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">宋魏了翁撰了翁有周易要義已著錄是書前有</span>  
<!-- 册3 葉2888a　Page:文淵閣四庫全書_0003冊.djvu/727 -->
<span style="margin-left: 2em">自序稱卽漢紀隨文辨理作古今考然惟前二十</span>  
<span style="margin-left: 2em">餘頁摘漢書高帝紀中名物稱謂字義音釋略爲</span>  
<span style="margin-left: 2em">辨論與序相應自東坡胡麻賦以下皆雜記他事</span>  
<span style="margin-left: 2em">註曰以下雜識諸條附考方回所補了翁古今考</span>  
<span style="margin-left: 2em">仍以原書爲第一卷無此諸條知爲後人以篇頁</span>  
<span style="margin-left: 2em">寥寥不盈卷軸竄入他文以足之陳繼儒秘笈所</span>  
<span style="margin-left: 2em">載大抵此𩔖也</span>  
正朔考一卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">宋魏了翁撰其書力主周行夏時之說首舉豳風</span>  
<!-- 册3 葉2888b　Page:文淵閣四庫全書_0003冊.djvu/727 -->
<span style="margin-left: 2em">七月詩次考六經及先秦古書與厯代正史所書</span>  
<span style="margin-left: 2em">之月皆爲夏正而以改時改月爲世儒之臆說凡</span>  
<span style="margin-left: 2em">三篇考之周禮正歲正月並見於經所謂正歳者</span>  
<span style="margin-left: 2em">兼用建寅以便民所謂正月者則專用建子以頒</span>  
<span style="margin-left: 2em">朔故一王之制而兩正並行經典時有異文蓋緣</span>  
<span style="margin-left: 2em">於此了翁不考左傳王周正月之文及春王正月</span>  
<span style="margin-left: 2em">日南至之𩔖而摭其兼用之文爲周行夏時之證</span>  
<span style="margin-left: 2em">可謂知其一不知其二矣</span>  
讀書雜抄二卷<sub class="note-yuan">江蘇廵撫採進本</sub>  
<!-- 册3 葉2889a　Page:文淵閣四庫全書_0003冊.djvu/727 -->
<span style="margin-left: 2em">宋魏了翁撰其書多辨證經義之語若引左傳或</span>  
<span style="margin-left: 2em">濡馬褐以救之注褐馬衣遂謂馬有衣不知馬衣</span>  
<span style="margin-left: 2em">卽馬被具猶之宋人以馬被具爲馬甲耳非别有</span>  
<span style="margin-left: 2em">衣也春秋正義引服䖍說謂馬繁纓爲索帬豈古</span>  
<span style="margin-left: 2em">者馬亦别有帬耶此𩔖皆隨文生解不得經意其</span>  
<span style="margin-left: 2em">謂哉生魄當作霸霸魄二字有異昭爲韶音不始</span>  
<span style="margin-left: 2em">晉諱則皆有合於說文之㫖蓋隨筆劄記之書不</span>  
<span style="margin-left: 2em">及一一考證故不能一一精核也</span>  
搜采異聞集五卷<sub class="note-yuan">江蘇廵撫採進本</sub>  
<!-- 册3 葉2889b　Page:文淵閣四庫全書_0003冊.djvu/727 -->
<span style="margin-left: 2em">舊本題宋永亨撰諸家書目皆不載惟明商維濬</span>  
<span style="margin-left: 2em">稗海中刻之今考其文皆剽取洪邁容齋隨筆而</span>  
<span style="margin-left: 2em">顛倒其次序其中濮安王子宗綽藏書目錄一條</span>  
<span style="margin-left: 2em">尙未及改去忠宣公字又兄公一條亦未及改去</span>  
<span style="margin-left: 2em">余奉使金國字蓋明季士風浮僞喜以藏蓄異本</span>  
<span style="margin-left: 2em">爲名高其不能真得古書者徃徃贋作以<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3271.svg?width=24" alt="四庫全書僻字第3271號（炫）" title="四庫全書僻字第3271號（炫）">俗其</span>  
<span style="margin-left: 2em">不能自作者則又徃徃竄亂舊本被以新名如是</span>  
<span style="margin-left: 2em">者指不勝屈此特其一耳</span>  
續古今考九卷<sub class="note-yuan">兩江總督採進本</sub>  
<!-- 册3 葉2892a　Page:文淵閣四庫全書_0003冊.djvu/728 -->
<span style="margin-left: 2em">舊本題金元好問撰考好問著述存者有遺山集</span>  
<span style="margin-left: 2em">中州集續夷堅志佚者有壬辰雜編此外諸家著</span>  
<span style="margin-left: 2em">錄别無他書此編莫省所自來前有永樂四年解</span>  
<span style="margin-left: 2em">縉序詞意凡鄙殊不𩔖縉文其論晉書以十六國</span>  
<span style="margin-left: 2em">爲載記不若東都事畧以遼金夏爲附錄決非金</span>  
<span style="margin-left: 2em">人之言中間屢引困學紀聞文獻通考案王應麟</span>  
<span style="margin-left: 2em">生於宋寜宗嘉定十四年辛巳其作困學紀聞据</span>  
<span style="margin-left: 2em">袁桷序應麟時年五十餘歲當在咸淳末年好問</span>  
<span style="margin-left: 2em">卒於憲宗七年丁巳卽宋理宗寳祐五年是困學</span>  
<!-- 册3 葉2892b　Page:文淵閣四庫全書_0003冊.djvu/728 -->
<span style="margin-left: 2em">紀聞書成在其殁後二十年通考雖成於宋末元</span>  
<span style="margin-left: 2em">初其刋行於世則在元英宗至治二年在好問殁</span>  
<span style="margin-left: 2em">後又六十餘年皆不應預爲徵引至解論語有婦</span>  
<span style="margin-left: 2em">人焉引來集之樵書又引顧炎武語皆明末</span>  
<span style="margin-left: 1em">國初之人解中庸屋漏引陳司業之說今見陳祖范</span>  
<span style="margin-left: 2em">經咫中祖范薦舉經學</span>  
賜國子監司業銜事在乾隆十六年則此書直近時人  
<span style="margin-left: 2em">所爲本可不著於錄以其託名古人故存而辨之</span>  
<span style="margin-left: 2em">不使售欺焉</span>  
<!-- 册3 葉2893a　Page:文淵閣四庫全書_0003冊.djvu/728 -->
箐齋讀書錄二卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">明周洪謨撰洪謨有羣經辨疑錄已著錄是書卷</span>  
<span style="margin-left: 2em">首一行題南臯子述篇中皆自稱南臯子前有正</span>  
<span style="margin-left: 2em">德丁卯陳旦引詞云是文安先生精神心術所在</span>  
<span style="margin-left: 2em">羽翼經傳闡明意義最爲精切惜篇帙首尾俱未</span>  
<span style="margin-left: 2em">載姓氏恐歲久傳疑敢引其大畧於端今觀上卷</span>  
<span style="margin-left: 2em">中如黑水和夷諸辨頗見攷据三皇制器諸論則</span>  
<span style="margin-left: 2em">義甚平淺下卷辨論周正凡十餘條力主蔡氏改</span>  
<span style="margin-left: 2em">時不改月之說反詆孔鄭爲非極爲博辨至於僖</span>  
<!-- 册3 葉2893b　Page:文淵閣四庫全書_0003冊.djvu/728 -->
<span style="margin-left: 2em">公二年春正月日南至之文夏正必不可通則直</span>  
<span style="margin-left: 2em">斷以爲左氏妄意增改可謂不顧其安矣其他論</span>  
<span style="margin-left: 2em">伯牛非患癩之𩔖亦皆純以臆斷不足與辨也</span>  
兩山墨談十八卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明陳霆撰霆有唐餘紀傳已著錄是書考証古籍</span>  
<span style="margin-left: 2em">頗爲詳贍而持論每渉偏駁如據國語王子晉厲</span>  
<span style="margin-left: 2em">宣幽平之言謂周宣與厲幽平相等謂許衡姚樞</span>  
<span style="margin-left: 2em">不當仕元謂至正二十六年卽當削元之統皆乖</span>  
<span style="margin-left: 2em">謬殊甚又輕信小說如紅線蘇小妹之𩔖並引爲</span>  
<!-- 册3 葉2896a　Page:文淵閣四庫全書_0003冊.djvu/729 -->
<span style="margin-left: 2em">故實至於據政和縣志所載余應詩以元順帝爲</span>  
<span style="margin-left: 2em">瀛國公子益荒誕矣</span>  
灼薪劇談二卷<sub class="note-yuan">浙江鄭大節家藏本</sub>  
<span style="margin-left: 2em">明朱承爵撰承爵字子儋不知何許人其書作於</span>  
<span style="margin-left: 2em">正德癸酉因臘月大雪與朋友擁爐夜話錄而成</span>  
<span style="margin-left: 2em">編故以灼薪爲名然雜抄唐宋說部之文如余遊</span>  
<span style="margin-left: 2em">褒禪山一條全錄葉夢得避暑錄話而註其末曰</span>  
<span style="margin-left: 2em">余葉石林自謂也似乎節錄古書而彭淵材禁蛇</span>  
<span style="margin-left: 2em">開井一條全錄惠洪冷齋夜話惟改使余跋其書</span>  
<!-- 册3 葉2896b　Page:文淵閣四庫全書_0003冊.djvu/729 -->
<span style="margin-left: 2em">句爲使其宗跋其書又似乎冒爲巳語者殊不解</span>
