## 欽定四庫全書總目 卷十五　經部十五　詩類一

<!-- 册1 葉1281a　Page:文淵閣四庫全書_0001冊.djvu/370 -->
欽定四庫全書總目巻十五  
<span style="margin-left: 1em">經部十五</span>  
<span style="margin-left: 2em">詩𩔖一</span>  
<span style="margin-left: 3em">詩有四家毛氏獨傳唐以前無異論宋以後則</span>  
<span style="margin-left: 3em">衆說爭矣然攻漢學者意不盡在於經義務勝</span>  
<span style="margin-left: 3em">漢儒而巳伸漢學者意亦不盡在於經義憤宋</span>  
<span style="margin-left: 3em">儒之詆漢儒而巳各挾一不相下之心而又濟</span>  
<span style="margin-left: 3em">以不平之氣激而過當亦其勢然歟夫解春秋</span>  
<span style="margin-left: 3em">者惟公羊多駁其中高子沈子之說殆轉相附</span>  
<!-- 册1 葉1281b　Page:文淵閣四庫全書_0001冊.djvu/370 -->
<span style="margin-left: 3em">益要其大義數十傳自聖門者不能廢也詩序</span>  
<span style="margin-left: 3em">稱子夏而所引高子孟仲子乃戰國時人固後</span>  
<span style="margin-left: 3em">來攙續之明證卽成伯璵等所指篇首一句經</span>  
<span style="margin-left: 3em">師口授亦未必不失其眞然去古未遠必有所</span>  
<span style="margin-left: 3em">受意其眞贋相半亦近似公羊全信全疑均爲</span>  
<span style="margin-left: 3em">偏見今叅稽衆說務協其平苟不至程大昌之</span>  
<span style="margin-left: 3em">妄改舊文王柏之橫刪聖籍者論有可採並錄</span>  
<span style="margin-left: 3em">存之以消融數百年之門戸至於鳥獸草木之</span>  
<span style="margin-left: 3em">名訓詁聲音之學皆事須考証非可空談今所</span>  
<!-- 册1 葉1284a　Page:文淵閣四庫全書_0001冊.djvu/371 -->
<span style="margin-left: 2em">採輯則尊漢學者居多焉</span>  
詩序二巻<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">案詩序之說紛如聚訟以爲大序子夏作小序子</span>  
<span style="margin-left: 2em">夏毛公合作者鄭元詩譜也以爲子夏所序詩卽</span>  
<span style="margin-left: 2em">今毛詩者王肅家語注也以爲衛宏受學謝曼卿</span>  
<span style="margin-left: 2em">作詩序者後漢書儒林傳也以爲子夏所創毛公</span>  
<span style="margin-left: 2em">及衛宏又加潤益者隋書經籍志也以爲子夏不</span>  
<span style="margin-left: 2em">序詩者韓愈也以爲子夏惟裁初句以下出於毛</span>  
<span style="margin-left: 2em">公者成伯璵也以爲詩人所自製者王安石也以</span>  
<!-- 册1 葉1284b　Page:文淵閣四庫全書_0001冊.djvu/371 -->
<span style="margin-left: 2em">小序爲國史之舊文以大序爲孔子作者明道程</span>  
<span style="margin-left: 2em">子也以首句卽爲孔子所題者王得臣也以爲毛</span>  
<span style="margin-left: 2em">傳初行尚未有序其後門人互相傳授各記其師</span>  
<span style="margin-left: 2em">說者曹粹中也以爲村野妄人所作昌言排擊而</span>  
<span style="margin-left: 2em">不顧者則倡之者鄭樵王質和之者朱子也然樵</span>  
<span style="margin-left: 2em">所作詩辨妄一出周孚卽作非鄭樵詩辨妄一巻</span>  
<span style="margin-left: 2em">摘其四十二事攻之質所作詩總聞亦不甚行於</span>  
<span style="margin-left: 2em">世朱子同時如呂祖謙陳傅良葉適皆以同志之</span>  
<span style="margin-left: 2em">交各持異議黃震篤信朱學而所作日鈔亦申序</span>  
<!-- 册1 葉1285a　Page:文淵閣四庫全書_0001冊.djvu/371 -->
<span style="margin-left: 2em">說馬端臨作經籍考於他書無所考辨惟詩序一</span>  
<span style="margin-left: 2em">事反覆攻詰至數千言自元明以至今日越數百</span>  
<span style="margin-left: 2em">年儒者尚各分左右袒也豈非說經之家第一爭</span>  
<span style="margin-left: 2em">詬之端乎考鄭元之釋南陔曰子夏序詩篇義各</span>  
<span style="margin-left: 2em">編遭戰國至秦而南陔六詩亡毛公作傳各引其</span>  
<span style="margin-left: 2em">序冠之篇首故詩雖亡而義猶在也程大昌考古</span>  
<span style="margin-left: 2em">編亦曰今六序兩語之下明言有義無詞知其爲</span>  
<span style="margin-left: 2em">秦火之後見序而不見詩者所爲朱鶴齡毛詩通</span>  
<span style="margin-left: 2em">義序又舉宛丘篇序首句與毛傳異詞其說皆足</span>  
<!-- 册1 葉1285b　Page:文淵閣四庫全書_0001冊.djvu/371 -->
<span style="margin-left: 2em">爲小序首句原在毛前之明證邱光庭兼明書舉</span>  
<span style="margin-left: 2em">鄭風出其東門篇謂毛傳與序不符曹粹中放齋</span>  
<span style="margin-left: 2em">詩說亦舉召南羔羊曹風鳲鳩衛風君子偕老三</span>  
<span style="margin-left: 2em">篇謂傳意序意不相應序若出於毛安得自相違</span>  
<span style="margin-left: 2em">戾其說尤足爲續申之語出於毛後之明證觀蔡</span>  
<span style="margin-left: 2em">邕本治魯詩而所作獨斷載周頌三十一篇之序</span>  
<span style="margin-left: 2em">皆祗有首二句與毛序文有詳畧而大㫖畧同葢</span>  
<span style="margin-left: 2em">子夏五傳至孫卿孫卿授毛亨毛亨授毛萇是毛</span>  
<span style="margin-left: 2em">詩距孫卿再傳申培師浮邱伯浮邱伯師孫卿是</span>  
<!-- 册1 葉1288a　Page:文淵閣四庫全書_0001冊.djvu/372 -->
<span style="margin-left: 2em">魯詩距孫卿亦再傳故二家之序大同小異其爲</span>  
<span style="margin-left: 2em">孫卿以來遞相授受者可知其所授受祗首二句</span>  
<span style="margin-left: 2em">而以下出於各家之演說亦可知也且唐書藝文</span>  
<span style="margin-left: 2em">志稱韓詩⺊商序韓嬰注二十二巻是韓詩亦有</span>  
<span style="margin-left: 2em">序其序亦稱出子夏矣而韓詩遺說之傳於今者</span>  
<span style="margin-left: 2em">往往與毛迥異豈非傳其學者遞有增改之故哉</span>  
<span style="margin-left: 2em">今㕘考諸說定序首二句爲毛萇以前經師所傳</span>  
<span style="margin-left: 2em">以下續申之詞爲毛萇以下弟子所附仍錄冠詩</span>  
<span style="margin-left: 2em">部之首明淵源之有自併錄朱子之辨說著門戸</span>  
<!-- 册1 葉1288b　Page:文淵閣四庫全書_0001冊.djvu/372 -->
<span style="margin-left: 2em">所由分葢數百年朋黨之爭兹其發端矣隋志有</span>  
<span style="margin-left: 2em">顧歡毛詩集解叙義一巻雷次宗毛詩序義二巻</span>  
<span style="margin-left: 2em">劉<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3271.svg?width=24" alt="四庫全書僻字第3271號（炫）" title="四庫全書僻字第3271號（炫）">毛詩集小序一巻劉巘毛詩序義疏一巻<sub class="note-yuan">案序</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">叙二字互見葢史之駁文今仍其舊</sub>唐志則作⺊商詩序二巻今以</span>  
<span style="margin-left: 2em">朱子所辨其文較繁仍析爲二巻若其得失則諸</span>  
<span style="margin-left: 2em">家之論詳矣各具本書兹不復贅焉</span>  
毛詩正義四十巻<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">漢毛亨傳鄭元箋唐孔頴達疏案漢書藝文志毛</span>  
<span style="margin-left: 2em">詩二十九巻毛詩故訓傳三十巻然但稱毛公不</span>  
<!-- 册1 葉1289a　Page:文淵閣四庫全書_0001冊.djvu/372 -->
<span style="margin-left: 2em">著其名後漢書儒林傳始云趙人毛長傳詩是爲</span>  
<span style="margin-left: 2em">毛詩其長字不從艸隋唐經籍志載毛詩二十巻</span>  
<span style="margin-left: 2em">漢河間太守毛萇傳鄭氏箋於是詩傳始稱毛萇</span>  
<span style="margin-left: 2em">然鄭元詩譜曰魯人大毛公爲訓詁傳於其家河</span>  
<span style="margin-left: 2em">間獻王得而獻之以小毛公爲博士陸璣毛詩草</span>  
<span style="margin-left: 2em">木蟲魚疏亦云孔子刪詩授⺊商商爲之序以授</span>  
<span style="margin-left: 2em">魯人曾申申授魏人李克克授魯人孟仲子仲子</span>  
<span style="margin-left: 2em">授根牟子根牟子授趙人荀卿荀卿授魯國毛亨</span>  
<span style="margin-left: 2em">毛亨作訓詁傳以授趙國毛萇時人謂亨爲大毛</span>  
<!-- 册1 葉1289b　Page:文淵閣四庫全書_0001冊.djvu/372 -->
<span style="margin-left: 2em">公萇爲小毛公據是二書則作傳者乃毛亨非毛</span>  
<span style="margin-left: 2em">萇故孔氏正義亦云大毛公爲其傳由小毛公而</span>  
<span style="margin-left: 2em">題毛也隋志所云殊爲舛誤而流俗沿襲莫之能</span>  
<span style="margin-left: 2em">更朱彝尊經義考乃以毛詩二十九巻題毛亨撰</span>  
<span style="margin-left: 2em">註曰佚毛詩訓故傳三十巻題毛萇撰註曰存意</span>  
<span style="margin-left: 2em">主調停尤爲於古無據今叅稽衆說定作傳者爲</span>  
<span style="margin-left: 2em">毛亨以鄭氏後漢人陸氏三國吳人併傳授毛詩</span>  
<span style="margin-left: 2em">淵源有自所言必不誣也鄭氏發明毛義自命曰</span>  
<span style="margin-left: 2em">箋博物志曰毛公嘗爲北海郡守康成是此郡人</span>  
<!-- 册1 葉1292a　Page:文淵閣四庫全書_0001冊.djvu/373 -->
<span style="margin-left: 2em">故以爲敬推張華所言蓋以爲公府用記郡將用</span>  
<span style="margin-left: 2em">箋之意然康成生於漢末乃修敬於四百年前之</span>  
<span style="margin-left: 2em">太守殊無所取案說文曰箋表識書也鄭氏六藝</span>  
<span style="margin-left: 2em">論曰註詩宗毛爲主毛義若隱畧則更表明如有</span>  
<span style="margin-left: 2em">不同卽下巳意使可識别<sub class="note-yuan">案此論今佚此據正義所引</sub>然則康</span>  
<span style="margin-left: 2em">成特因毛傳而表識其傍如今人之簽記積而成</span>  
<span style="margin-left: 2em">帙故謂之箋無庸别曲說也自鄭箋旣行齊魯韓</span>  
<span style="margin-left: 2em">三家遂廢<sub class="note-yuan">案此陸德明經典釋文之說</sub>然箋與傳義亦有異同</span>  
<span style="margin-left: 2em">魏王肅作毛詩註毛詩義駮毛詩奏事毛詩問難</span>  
<!-- 册1 葉1292b　Page:文淵閣四庫全書_0001冊.djvu/373 -->
<span style="margin-left: 2em">諸書以申毛難鄭歐陽修引其釋衛風擊鼔五章</span>  
<span style="margin-left: 2em">謂鄭不如王<sub class="note-yuan">見詩本義</sub>王基又作毛詩駮以申鄭難王</span>  
<span style="margin-left: 2em">王應麟引其駁芣苢一條謂王不及鄭<sub class="note-yuan">見困學記聞亦載經</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">典釋文</sub>晉孫毓作毛詩異同評復申王說鄭統作難</span>  
<span style="margin-left: 2em">孫氏毛詩評又明鄭義<sub class="note-yuan">並見經典釋文</sub>袒分左右垂數百</span>  
<span style="margin-left: 2em">年至唐貞觀十六年命孔穎達等因鄭箋爲正義</span>  
<span style="margin-left: 2em">乃論歸一定無復岐途毛傳二十九巻隋志附以</span>  
<span style="margin-left: 2em">鄭箋作二十巻疑爲康成所併穎達等以疏文繁</span>  
<span style="margin-left: 2em">重又析爲四十巻其書以劉焯毛詩義疏劉<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3271.svg?width=24" alt="四庫全書僻字第3271號（炫）" title="四庫全書僻字第3271號（炫）">毛</span>  
<!-- 册1 葉1293a　Page:文淵閣四庫全書_0001冊.djvu/373 -->
<span style="margin-left: 2em">詩述義爲藁本故能融貫羣言包羅古義終唐之</span>  
<span style="margin-left: 2em">世人無異詞惟王讜唐語林記劉禹錫聽施士丐</span>  
<span style="margin-left: 2em">講毛詩所說維鵜在梁陟彼岵兮勿翦勿拜維北</span>  
<span style="margin-left: 2em">有斗四義稱毛未注然未嘗有所詆排也至宋鄭</span>  
<span style="margin-left: 2em">樵恃其才辯無故而發難端南渡諸儒始以掊擊</span>  
<span style="margin-left: 2em">毛鄭爲能事元延祐科舉條制詩雖兼用古註疏</span>  
<span style="margin-left: 2em">其時門戸巳成講學者迄不遵用沿及明代胡廣</span>  
<span style="margin-left: 2em">等竊劉瑾之書作詩經大全著爲令典於是專宗</span>  
<span style="margin-left: 2em">朱傳漢學遂亡然朱子從鄭樵之說不過攻小序</span>  
<!-- 册1 葉1293b　Page:文淵閣四庫全書_0001冊.djvu/373 -->
<span style="margin-left: 2em">耳至於詩中訓詁用毛鄭者居多後儒不考古書</span>  
<span style="margin-left: 2em">不知小序自小序傳箋自傳箋閧然佐鬭遂併毛</span>  
<span style="margin-left: 2em">鄭而棄之是非惟不知毛鄭爲何語殆併朱子之</span>  
<span style="margin-left: 2em">傳亦不辨爲何語矣我</span>  
<span style="margin-left: 1em">國家經學昌明一洗前明之固陋乾隆八年</span>  
皇上特命校刋十三經註疏  
頒布學宮鼓篋之儒皆駸駸乎研求古學今特錄其書  
<span style="margin-left: 2em">與小序同冠詩𩔖之首以昭六義淵源其來有自</span>  
<span style="margin-left: 2em">孔門師授端緒炳然終不能以他說掩也</span>  
<!-- 册1 葉1296a　Page:文淵閣四庫全書_0001冊.djvu/374 -->
毛詩草木鳥獸蟲魚疏二巻<sub class="note-yuan">通行本</sub>  
<span style="margin-left: 2em">吳陸璣撰明北監本詩正義全部所引皆作陸機</span>  
<span style="margin-left: 2em">考隋書經籍志毛詩草木蟲魚疏二巻注云烏程</span>  
<span style="margin-left: 2em">令吳郡陸璣撰陸德明經典釋文序錄陸璣毛詩</span>  
<span style="margin-left: 2em">草木鳥獸蟲魚疏二巻注云字元恪吳郡人吳太</span>  
<span style="margin-left: 2em">子中庻子烏程令資暇集亦辨璣字從玉則監本</span>
