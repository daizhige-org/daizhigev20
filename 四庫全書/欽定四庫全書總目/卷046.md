## 欽定四庫全書總目 卷四十六　史部二　正史類二、正史類存目

<!-- 册2 葉116a　Page:文淵閣四庫全書_0002冊.djvu/34 -->
欽定四庫全書總目卷四十六  
<span style="margin-left: 1em">史部二</span>  
<span style="margin-left: 2em">正史類二</span>  
南史八十卷<sub class="note-yuan">内府刊本</sub>  
<span style="margin-left: 2em">唐李延壽撰延壽事蹟附載新唐書令狐德棻傳</span>  
<span style="margin-left: 2em">延壽承其父大師之志爲北史南史而南史先成</span>  
<span style="margin-left: 2em">就正於令狐德棻其乖失者嘗爲改定宋人稱延</span>  
<span style="margin-left: 2em">壽之書刪煩補闕爲近世佳史顧炎武曰知錄又</span>  
<span style="margin-left: 2em">摘其李安民諸傳一事兩見爲紀載之疎以今考</span>  
<!-- 册2 葉116b　Page:文淵閣四庫全書_0002冊.djvu/34 -->
<span style="margin-left: 2em">之本紀刪其連綴諸臣事跡列傳則多刪詞賦意</span>  
<span style="margin-left: 2em">存簡要殊勝本書然宋齊梁陳四朝九錫之文符</span>  
<span style="margin-left: 2em">命之說告天之詞皆沿襲虛言無關實證而備書</span>  
<span style="margin-left: 2em">簡牘陳陳相因是芟削未盡也且合累朝之書勒</span>  
<span style="margin-left: 2em">爲通史發凡起例宜歸畫一今延壽於循吏儒林</span>  
<span style="margin-left: 2em">隱逸傳旣遞載四朝人物而文學一傳乃因宋書</span>  
<span style="margin-left: 2em">不立此目遂始於齊之邱靈鞠豈宋無文學乎孝</span>  
<span style="margin-left: 2em">義傳搜綴湮落以備闕文而蕭矯妻羊氏衛敬瑜</span>  
<span style="margin-left: 2em">妻王氏先後互載男女無別將謂史不當有列女</span>  
<!-- 册2 葉117a　Page:文淵閣四庫全書_0002冊.djvu/34 -->
<span style="margin-left: 2em">傳乎况北史謂周書無文苑傳遂取列傳中之庾</span>  
<span style="margin-left: 2em">信王褒入於文苑則宋之謝靈運顔延之何承天</span>  
<span style="margin-left: 2em">裴松之諸人何難移冠文苑之前北史謂魏隋有</span>  
<span style="margin-left: 2em">列女傳齊周並無此篇今又得趙氏陳氏附備列</span>  
<span style="margin-left: 2em">女則宛陵女子等十四人何難取補列女之闕書</span>  
<span style="margin-left: 2em">成一手而例出兩岐尤以矛陷盾萬萬無以自解</span>  
<span style="margin-left: 2em">者矣葢延壽當日專致力於北史南史不過因其</span>  
<span style="margin-left: 2em">舊文排纂刪潤故其減字節句每失本意間有所</span>  
<span style="margin-left: 2em">增益又緣飾爲多如宋路太后傳較宋書爲詳然</span>  
<!-- 册2 葉117b　Page:文淵閣四庫全書_0002冊.djvu/34 -->
<span style="margin-left: 2em">沈約修史工於詆毁前朝而不載路太后飮酒置</span>  
<span style="margin-left: 2em">毒之事當亦揆以前後恩慈不應存此異說也延</span>  
<span style="margin-left: 2em">壽采雜史爲實錄又豈可盡信哉然自宋畧齊春</span>  
<span style="margin-left: 2em">秋梁典諸書盡亡其備宋齊梁陳四史之㕘校者</span>  
<span style="margin-left: 2em">獨賴此書之存則亦何可竟廢也</span>  
北史一百卷<sub class="note-yuan">内府刊本</sub>  
<span style="margin-left: 2em">唐李延壽撰延壽表進其書稱本紀十二卷列傳</span>  
<span style="margin-left: 2em">八十八卷爲北史與今本卷數符合文獻通考作</span>  
<span style="margin-left: 2em">八十卷者誤也延壽旣與修隋書十志又世居北</span>  
<!-- 册2 葉120a　Page:文淵閣四庫全書_0002冊.djvu/35 -->
<span style="margin-left: 2em">土見聞較近㕘覈同異於北史用力獨深故叙事</span>  
<span style="margin-left: 2em">詳密首尾典贍如載元韶之姦利彭樂之勇敢郭</span>  
<span style="margin-left: 2em">琰沓龍超諸人之節義皆具見特筆出酈道元於</span>  
<span style="margin-left: 2em">酷吏附陸法和於藝術離合編次亦深有別裁視</span>  
<span style="margin-left: 2em">南史之多仍舊本者迥如兩手惟其以姓爲類分</span>  
<span style="margin-left: 2em">卷無法南史以王謝分支北史亦以崔盧繫派故</span>  
<span style="margin-left: 2em">家世族一例連書覽其姓名則同爲父子稽其朝</span>  
<span style="margin-left: 2em">代則各有君臣參錯混淆殆難辨別甚至長孫儉</span>  
<span style="margin-left: 2em">附長孫嵩傳薛道衡附薛辨傳遙遙華冑下逮雲</span>  
<!-- 册2 葉120b　Page:文淵閣四庫全書_0002冊.djvu/35 -->
<span style="margin-left: 2em">仍隔越抑又甚矣考延壽之敘次列傳先以魏宗</span>  
<span style="margin-left: 2em">室諸王次及魏臣又次以齊宗室及齊臣下逮周</span>  
<span style="margin-left: 2em">隋莫不皆然凡以勒一朝始末限斷分明乃獨於</span>  
<span style="margin-left: 2em">一二高門自亂其例深所未安至於楊素父子有</span>  
<span style="margin-left: 2em">闕隋室興亡以其系出宏農遂附見魏臣楊敷傳</span>  
<span style="margin-left: 2em">後又魏收及魏長賢諸人本非父子兄弟以其同</span>  
<span style="margin-left: 2em">爲魏姓遂合爲一卷尤爲舛迕觀延壽敘例凡累</span>  
<span style="margin-left: 2em">代相承者皆謂之家傳豈知家傳之體不當施於</span>  
<span style="margin-left: 2em">國史哉且南北史雖曰二書實通爲一家之著述</span>  
<!-- 册2 葉121a　Page:文淵閣四庫全書_0002冊.djvu/35 -->
<span style="margin-left: 2em">故延壽於裴蕴傳云祖之平父忌南史有傳王頒</span>  
<span style="margin-left: 2em">傳云父僧辨南史有傳卽互相貫通之㫖也乃南</span>  
<span style="margin-left: 2em">史旣有晉熙王昶傳矣北史復有劉昶傳南史旣</span>  
<span style="margin-left: 2em">有鄱陽王寶寅傳矣北史復有蕭寶寅傳南史旣</span>  
<span style="margin-left: 2em">有豫章王綜樂良王大圜傳矣北史復有蕭贊<sub class="note-yuan">蕭綜</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">入魏改名贊</sub>蕭大圜傳朱修之薛安都諸人南史則取</span>  
<span style="margin-left: 2em">諸宋書北史則取諸魏書不爲刪併殆專意北史</span>  
<span style="margin-left: 2em">無暇追刪南史以致有此誤乎然自宋以後魏書</span>  
<span style="margin-left: 2em">北齊書周書皆殘缺不全惟此書僅麥鐵杖傳有</span>  
<!-- 册2 葉121b　Page:文淵閣四庫全書_0002冊.djvu/35 -->
<span style="margin-left: 2em">闕文荀濟傳脫去數行其餘皆卷帙整齊始末完</span>  
<span style="margin-left: 2em">具徴北朝之故實者終以是書爲依據故雖八書</span>  
<span style="margin-left: 2em">具列而二史仍並行焉</span>  
舊唐書二百卷<sub class="note-yuan">内府刊本</sub>  
<span style="margin-left: 2em">晉劉昫等奉勅撰五代史記昫本傳不言昫撰此</span>  
<span style="margin-left: 2em">書史漏畧也自宋嘉祐後歐陽修宋祁等重撰新</span>  
<span style="margin-left: 2em">書此書遂廢然其本流傳不絶儒者表昫等之長</span>  
<span style="margin-left: 2em">以攻修祁等之短者亦不絶今觀所述大抵長慶</span>  
<span style="margin-left: 2em">以前本紀惟書大事簡而有體列傳敘述詳明贍</span>  
<!-- 册2 葉124a　Page:文淵閣四庫全書_0002冊.djvu/36 -->
<span style="margin-left: 2em">而不穢頗能存班范之舊法長慶以後本紀則詩</span>  
<span style="margin-left: 2em">話書序婚狀獄詞委悉具書語多支蔓<sub class="note-yuan">如文宗紀云上每誦</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">杜甫曲江行云江頭宫殿鎖千門細柳新蒲爲誰綠乃知天寶以前曲江四岸皆有行宫臺殿百司</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">廨署又云戸部侍郞判度支王彦威進所撰供軍圖畧其序云云武宗紀云右庶子呂讓進狀亡兄</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">温女太和七年嫁左衛兵曹蕭敏生二男開成三年敏心疾乖忤因而離婚今敏日愈却乞與臣姪</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">女配合又云御史臺奏據三司推勘吳湘獄謹具逐人罪狀如後揚州都虞候盧行立劉羣於會昌</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">二年五月十四日于阿顔家喫酒云云</sub>列傳則多敘官資曾無事實</span>  
<span style="margin-left: 2em">或但載寵遇不具首尾<sub class="note-yuan">如夏侯孜傳祇載厯官所至及責讓詔詞不及一事</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">朱朴傳祇載其相昭宗而不及其始末</sub>所謂繁畧不均者誠如宋人</span>  
<!-- 册2 葉124b　Page:文淵閣四庫全書_0002冊.djvu/36 -->
<span style="margin-left: 2em">之所譏按崇文總目初吳兢撰唐史自剏業訖於</span>  
<span style="margin-left: 2em">開元凡一百一十卷韋述因兢舊本更加筆削刊</span>  
<span style="margin-left: 2em">去酷吏傳爲紀志列傳一百十二卷至德乾元以</span>  
<span style="margin-left: 2em">後史官于休烈又增肅宗紀二卷史官令狐峘等</span>  
<span style="margin-left: 2em">復於紀志傳隨篇增輯而不加卷帙爲唐書一百</span>  
<span style="margin-left: 2em">三十卷是唐書舊稿實出吳兢雖衆手續增規模</span>  
<span style="margin-left: 2em">未改昫等用爲藍本故具有典型觀順宗紀論題</span>  
<span style="margin-left: 2em">史臣韓愈憲宗紀論題史臣蔣係此因仍前史之</span>  
<span style="margin-left: 2em">明證也至長慶以後史失其官無復善本昫等自</span>  
<!-- 册2 葉125a　Page:文淵閣四庫全書_0002冊.djvu/36 -->
<span style="margin-left: 2em">採雜說傳記排纂成之動乖體例良有由矣至於</span>  
<span style="margin-left: 2em">卷一百三十二旣有楊朝晟傳卷一百四十四復</span>  
<span style="margin-left: 2em">爲立傳蕭頴士旣附見於卷一百二復見於卷一</span>  
<span style="margin-left: 2em">百九十文苑傳宇文韶諫獵表旣見於卷六十二</span>  
<span style="margin-left: 2em">復見於卷六十四蔣乂諫張茂宗尚主疏旣見於</span>  
<span style="margin-left: 2em">卷一百四十一復見於卷一百四十九輿服志所</span>  
<span style="margin-left: 2em">載條議亦多同列傳之文葢李崧賈緯諸人各自</span>  
<span style="margin-left: 2em">編排不相參校昫掌領修之任曾未能鉤稽本末</span>  
<span style="margin-left: 2em">使首尾贯通舛漏之譏亦無以自解平心而論葢</span>  
<!-- 册2 葉125b　Page:文淵閣四庫全書_0002冊.djvu/36 -->
<span style="margin-left: 2em">瑕瑜不掩之作黨新書者必謂事事勝舊書黨舊</span>  
<span style="margin-left: 2em">書者又必謂事事勝新書皆偏見也我</span>  
皇上獨秉  
睿裁定於正史之中二書並列相輔而行誠千古至公  
<span style="margin-left: 2em">之道論史諸家可無庸復置一議矣</span>  
新唐書二百二十五卷<sub class="note-yuan">内府刊本</sub>  
<span style="margin-left: 2em">宋歐陽修宋祁等奉勅撰其監修者則曾公亮故</span>  
<span style="margin-left: 2em">書首進表以公亮爲首陳振孫書錄解題曰舊例</span>  
<span style="margin-left: 2em">修書止著官高一人名銜歐公曰宋公於我爲前</span>  
<!-- 册2 葉128a　Page:文淵閣四庫全書_0002冊.djvu/37 -->
<span style="margin-left: 2em">輩且於此書用力久何可没也遂於紀傳各著之</span>  
<span style="margin-left: 2em">宋公感其退遜故書中列傳題祁名本紀表志題</span>  
<span style="margin-left: 2em">修名然考隋書諸志巳有此例實不始於修與祁</span>  
<span style="margin-left: 2em">又宋史吕夏卿傳稱宰相世系表夏卿所撰而書</span>  
<span style="margin-left: 2em">中亦題修名則仍以官高者爲主特諸史多用一</span>  
<span style="margin-left: 2em">人此用二人爲異耳是書本以補正劉昫之舛漏</span>  
<span style="margin-left: 2em">自稱事增於前文省於舊劉安世元城語錄則謂</span>  
<span style="margin-left: 2em">事增文省正新書之失而未明其所以然今卽其</span>  
<span style="margin-left: 2em">說而推之史官記錄具載舊書今必欲廣所未備</span>  
<!-- 册2 葉128b　Page:文淵閣四庫全書_0002冊.djvu/37 -->
<span style="margin-left: 2em">勢必蒐及小說而至於猥雜唐代詞章體皆詳贍</span>  
<span style="margin-left: 2em">今必欲減其文句勢必變爲澁體而至於詰屈安</span>  
<span style="margin-left: 2em">世之言所謂中其病源者也若夫史漢本紀多載</span>  
<span style="margin-left: 2em">詔令古文簡質至多不過數行耳唐代王言率崇</span>  
<span style="margin-left: 2em">縟麗駢四儷六累牘連篇宋敏求所輯唐大詔令</span>  
<span style="margin-left: 2em">多至一百三十卷使盡登紀傳天下有是史體乎</span>  
<span style="margin-left: 2em">祁一例刊除事非得已過相訾議未見其然至於</span>  
<span style="margin-left: 2em">吕夏卿私撰兵志見晁氏讀書志宋祁别撰紀志</span>  
<span style="margin-left: 2em">見王得臣麈史則同局且私心不滿書甫頒行吳</span>  
<!-- 册2 葉129a　Page:文淵閣四庫全書_0002冊.djvu/37 -->
<span style="margin-left: 2em">縝糾謬卽踵之而出其所攻駁亦未嘗不切中其</span>  
<span style="margin-left: 2em">失然一代史書網羅浩博門分類别端緒紛拏出</span>  
<span style="margin-left: 2em">一手則精力難周出衆手則體裁互異爰從三史</span>  
<span style="margin-left: 2em">以逮八書牴牾參差均所不免不獨此書爲然吕</span>  
<span style="margin-left: 2em">宋之書未知優劣吳縝所糾存備考證則可因是</span>
