## 欽定四庫全書總目 卷一百十九　子部二十九　雜家類三

<!-- 册3 葉2324：整葉圖版，無文字記錄 -->
<!-- 册3 葉2325a　Page:文淵閣四庫全書_0003冊.djvu/586 -->
欽定四庫全書總目卷一百十九  
<span style="margin-left: 1em">子部二十九</span>  
<span style="margin-left: 2em">雜家𩔖三</span>  
目損齋筆記一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">元黃溍撰溍字晉卿金華人延祐二年賜同進士</span>  
<span style="margin-left: 2em">出身厯官翰林侍講學士中奉大夫知制詰同修</span>  
<span style="margin-left: 2em">國史同知經筵事謚文獻事蹟具元史本傳是書</span>  
<span style="margin-left: 2em">續通考作一卷危素行狀亦稱一卷與今本合書</span>  
<span style="margin-left: 2em">中皆考證經史子集異同得失其辨史十六則尤</span>  
<!-- 册3 葉2325b　Page:文淵閣四庫全書_0003冊.djvu/586 -->
<span style="margin-left: 2em">精於辨經如引史記沛公左司馬得泗州守壯殺</span>  
<span style="margin-left: 2em">之之文證顔師古漢書註之誤又引宋實錄李繼</span>  
<span style="margin-left: 2em">遷賜姓名不在眞宗時證僧文瑩湘山野錄之誤</span>  
<span style="margin-left: 2em">引据尤極明<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">非束書不觀而空談臆斷者也此</span>  
<span style="margin-left: 2em">本首有至正甲午宋濂序末有危素所作行狀及</span>  
<span style="margin-left: 2em">詔令移文博士傅泰謚議而末附以劉剛序葢附</span>  
<span style="margin-left: 2em">錄三篇卽剛所編入也惟卷首卷末均標云大明</span>  
<span style="margin-left: 2em">庚辰天順四年十三世孫叔善重刋今考行狀溍</span>  
<span style="margin-left: 2em">以至正十七年卒其時但有孫四人下距天順四</span>  
<!-- 册3 葉2328a　Page:文淵閣四庫全書_0003冊.djvu/587 -->
<span style="margin-left: 2em">年止一百三年不得遂有十三世孫然其子孫之</span>  
<span style="margin-left: 2em">詞世系又不應謬悞是則不可理解之事矣</span>  
丹鉛餘錄十七卷續錄十二卷摘錄十三卷總錄二十  
七卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明楊愼撰愼有檀弓叢訓已著錄愼博覽羣書喜</span>  
<span style="margin-left: 2em">爲雜著計其平生所叙錄不下二百餘種其考證</span>  
<span style="margin-left: 2em">諸書異同者則皆以丹鉛爲名顧其志攬茝微言</span>  
<span style="margin-left: 2em">曰古之罪人以丹書其籍魏志緣坐配没爲工樂</span>  
<span style="margin-left: 2em">雜戸者用赤𥿄爲籍其卷以鉛爲軸升庵名在尺</span>  
<!-- 册3 葉2328b　Page:文淵閣四庫全書_0003冊.djvu/587 -->
<span style="margin-left: 2em">籍故寄意於此也凡餘錄十七卷續錄十二卷閏</span>  
<span style="margin-left: 2em">錄九卷愼又自爲刪薙名曰摘錄刻於嘉靖丁未</span>  
<span style="margin-left: 2em">後其門人梁佐裒合諸錄爲一編刪除重複定爲</span>  
<span style="margin-left: 2em">二十八𩔖名曰總錄刻之上杭是編出而諸錄遂</span>  
<span style="margin-left: 2em">微然書帕之本校讐草率譌字如林又守土者多</span>  
<span style="margin-left: 2em">印以充餽遺𥿄墨裝潢皆取給於民民以爲困後</span>  
<span style="margin-left: 2em">竟毁之今所行者皆未毁前所印也又萬厯中四</span>  
<span style="margin-left: 2em">川巡撫張士佩重刋愼集以諸錄及談苑醍醐等</span>  
<span style="margin-left: 2em">書刪併爲四十一卷附於集後今亦與總錄並行</span>  
<!-- 册3 葉2329a　Page:文淵閣四庫全書_0003冊.djvu/587 -->
<span style="margin-left: 2em">此本惟有餘錄續錄摘錄而闕閏錄然有梁佐之</span>  
<span style="margin-left: 2em">總錄則閏錄亦在其中四本相輔而行以總錄補</span>  
<span style="margin-left: 2em">三錄之遺以三錄正總錄之誤仍然愼之完書也</span>  
<span style="margin-left: 2em">愼以博洽冠一時使其覃精研思網羅百代竭平</span>  
<span style="margin-left: 2em">生之力以成一書雖未必追蹤馬鄭亦未必遽在</span>  
<span style="margin-left: 2em">王應麟馬端臨下而取名太𢚩稍成卷帙卽付棗</span>  
<span style="margin-left: 2em">梨餖何爲編祗成雜學王世貞謂其工於證經而</span>  
<span style="margin-left: 2em">疎於解經詳於稗史而忽於正史詳於詩事而畧</span>  
<span style="margin-left: 2em">於詩旨求之宇宙之外而失之耳目之内亦<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">論</span>  
<!-- 册3 葉2329b　Page:文淵閣四庫全書_0003冊.djvu/587 -->
<span style="margin-left: 2em">也又好僞撰古書以證成已說睥睨一世謂無足</span>  
<span style="margin-left: 2em">以發其覆而不知陳耀文正楊之作已隨其後雖</span>  
<span style="margin-left: 2em">有意求瑕詆諆太過毋亦木腐蟲生有所以召之</span>  
<span style="margin-left: 2em">之道歟然漁獵旣富根柢終深故疎舛雖多而精</span>  
<span style="margin-left: 2em">華亦復不少求之於古可以位置鄭樵羅泌之間</span>  
<span style="margin-left: 2em">其在有明固鐵中錚錚者矣</span>  
譚苑醍醐九卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">明楊愼撰其書亦皆考證之語與丹鉛錄大致相</span>  
<span style="margin-left: 2em">出入而亦頗有異同首有嘉靖壬寅自序其名醍</span>  
<!-- 册3 葉2332a　Page:文淵閣四庫全書_0003冊.djvu/588 -->
<span style="margin-left: 2em">醐者謂從乳出酪從酪出酥從生酥出熟酥從熟</span>  
<span style="margin-left: 2em">酥出醍醐猶之精義入神非一蹴之力也所稱周</span>  
<span style="margin-left: 2em">八士爲南宫氏引逸周書南宫忽遷鹿臺之財南</span>  
<span style="margin-left: 2em">宫百達遷九鼎語謂南宫忽卽仲忽南宫百達卽</span>  
<span style="margin-left: 2em">伯達尙書所云南宫适卽伯适引據極爲<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">鑿又</span>  
<span style="margin-left: 2em">謂先天圖始於希夷後天圖續於康節葢希夷以</span>  
<span style="margin-left: 2em">授穆伯長穆伯長以授李挻之挺之之學授之康</span>  
<span style="margin-left: 2em">節其作後天圖見於邵伯温之序朱子所以不明</span>  
<span style="margin-left: 2em">言者非爲康節<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">以希夷恐後人議其流於神仙</span>  
<!-- 册3 葉2332b　Page:文淵閣四庫全書_0003冊.djvu/588 -->
<span style="margin-left: 2em">也其辨析亦最詳明又從毛傳解鄂不韡韡云鄂</span>  
<span style="margin-left: 2em">華苞也今文作蕚不華蒂也今文作跗謂華下有</span>  
<span style="margin-left: 2em">蕚蕚下有跗華蕚相覆而光明猶兄弟相順而榮</span>  
<span style="margin-left: 2em">顯可以辨集傳鄂然外見豈不韡韡之誤又據漢</span>  
<span style="margin-left: 2em">劉湛所書吕梁碑碑中序虞舜之世稱舜祖幕幕</span>  
<span style="margin-left: 2em">生窮蟬窮蟬生敬康敬康生喬牛喬牛生瞽䏂質</span>  
<span style="margin-left: 2em">之史記葢同而不言出自黃帝此可洗二女同姓</span>  
<span style="margin-left: 2em">尊卑爲婚之疑又他碑所載后稷生台璽台璽生</span>  
<span style="margin-left: 2em">叔均叔均而下數世始至不窋不窋下傅季厯猶</span>  
<!-- 册3 葉2333a　Page:文淵閣四庫全書_0003冊.djvu/588 -->
<span style="margin-left: 2em">十七世而司馬遷作周紀拘於十五王之說合二</span>  
<span style="margin-left: 2em">人爲一人又刪縮數人以合其數不知國語之言</span>  
<span style="margin-left: 2em">十五王皆指其賢而有聞者非謂后稷至武王千</span>  
<span style="margin-left: 2em">餘年而止十五世也又引水經注載諸葛亮表云</span>  
<span style="margin-left: 2em">臣遣虎歩監孟琰據武功水東司馬懿因渭水漲</span>  
<span style="margin-left: 2em">攻琰營臣作橋越水射之橋成遂馳去此諸葛遺</span>  
<span style="margin-left: 2em">事本傳不載者又辨李白爲蜀之彰明人厯引其</span>  
<span style="margin-left: 2em">上裴長史書與悲淸秋賦及諸詩句以證唐書稱</span>  
<span style="margin-left: 2em">白爲隴西人及唐宗室之非𩔖皆有據其餘考訂</span>  
<!-- 册3 葉2333b　Page:文淵閣四庫全書_0003冊.djvu/588 -->
<span style="margin-left: 2em">辨論亦多獲新解雖腹笥所陳或有誤記不免爲</span>  
<span style="margin-left: 2em">後人所摭拾要其大體終非儉腹所能辦也</span>  
藝彀三卷彀補三卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">明鄧伯羔撰伯羔有今易筌已著錄是書援据經</span>  
<span style="margin-left: 2em">籍考證頗爲詳贍雖多本舊文亦頗自出新意如</span>  
<span style="margin-left: 2em">疑漢有兩牟融辨出師表原有兩本皆爲有見引</span>  
<span style="margin-left: 2em">西京賦證澹淡爲兩字引唐六典證畊耕爲兩字</span>  
<span style="margin-left: 2em">於六書辨析亦精闢蘇氏檮杌之妄正邵子稱外</span>  
<span style="margin-left: 2em">臣之非尤能力持公論不附和門戸之局至續博</span>  
<!-- 册3 葉2336a　Page:文淵閣四庫全書_0003冊.djvu/589 -->
<span style="margin-left: 2em">物志本南宋李石所撰書中明出曾公亮王安石</span>  
<span style="margin-left: 2em">曾慥之名而疑爲唐人殊爲疎舛又据西溪叢語</span>  
<span style="margin-left: 2em">七修𩔖藁以落霞爲鳥名蟲名亦失別擇謂通考</span>  
<span style="margin-left: 2em">馬妖當收舞馬則迂謬彌甚然隆慶萬厯以後士</span>  
<span style="margin-left: 2em">大夫惟尙狂禪不復以稽古爲事是編廣徵博引</span>  
<span style="margin-left: 2em">足備參稽在爾時猶爲篤實之學矣</span>  
正楊四卷<sub class="note-yuan"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">𨽻總督採進本</sub>  
<span style="margin-left: 2em">明陳耀文撰耀文有經典稽疑已著錄是書凡一</span>  
<span style="margin-left: 2em">百五十條皆糾楊愼之訛成於隆慶己巳前有李</span>  
<!-- 册3 葉2336b　Page:文淵閣四庫全書_0003冊.djvu/589 -->
<span style="margin-left: 2em">蕟序及耀文自序愼於正德嘉靖之間以博學稱</span>  
<span style="margin-left: 2em">而所作丹鉛錄諸書不免瑕瑜並見眞僞互陳又</span>  
<span style="margin-left: 2em">晚謫永昌無書可檢惟憑記憶未免多疎耀文考</span>  
<span style="margin-left: 2em">正其非不使轉滋疑誤於學者不爲無功然釁起</span>  
<span style="margin-left: 2em">爭名語多攻訐醜詞惡謔無所不加雖古人挾怨</span>  
<span style="margin-left: 2em">搆爭如吳縝之糾新唐書者亦不至是殊<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2615.svg?width=24" alt="四庫全書僻字第2615號（垂）" title="四庫全書僻字第2615號（垂）">著作</span>  
<span style="margin-left: 2em">之體又書成之後王世貞頗有違言耀文復增益</span>  
<span style="margin-left: 2em">其書反唇辨難語同詬詈憤若㓂讐觀是書者取</span>  
<span style="margin-left: 2em">其博贍亦不可不戒其浮囂也朱國楨湧幢小品</span>  
<!-- 册3 葉2337a　Page:文淵閣四庫全書_0003冊.djvu/589 -->
<span style="margin-left: 2em">曰有丹鉛錄諸書便有正楊又有正正楊古人古</span>  
<span style="margin-left: 2em">事古字此書如彼彼書如此散見雜出各不相同</span>  
<span style="margin-left: 2em">見其一不見其二閧然糾駁不免爲前人所笑是</span>  
<span style="margin-left: 2em">亦善於解紛之說然博辨者固戒游詞精核者終</span>  
<span style="margin-left: 2em">歸定論國楨之病是書竟欲舉考證而廢之則又</span>  
<span style="margin-left: 2em">矯枉過<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">矣</span>  
疑耀七卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">舊本題明李贄撰贄有九正易因已著錄是編前</span>  
<span style="margin-left: 2em">有張萱序稱負笈數千里修謁其門迺裒一編見</span>  
<!-- 册3 葉2337b　Page:文淵閣四庫全書_0003冊.djvu/589 -->
<span style="margin-left: 2em">示屬以訂正戊申嵗以地官郎分務吳會登梓以</span>  
<span style="margin-left: 2em">傳云云案贄恃才妄誕敢以邪說誣民所作藏書</span>  
<span style="margin-left: 2em">至謂毋以孔夫子之是非是非我其他著作無一</span>  
<span style="margin-left: 2em">非往悖之詞而是編考證故實循循有法雖間倡</span>  
<span style="margin-left: 2em">儒佛歸一之說其言亦謹而不肆至云儒不必援</span>  
<span style="margin-left: 2em">佛佛不必援儒又云經典出六朝人潤色非其本</span>  
<span style="margin-left: 2em">眞且與贄論相反斷乎不出其手王士禎古夫于</span>
