## 欽定四庫全書總目 卷二　經部二　易類二

<!-- 册1 葉249a　Page:文淵閣四庫全書_0001冊.djvu/112 -->
欽定四庫全書總目卷二  
<span style="margin-left: 1em">經部二</span>  
<span style="margin-left: 2em">易類二</span>  
易數鈎隱圖三卷附遺論九事一卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">宋劉牧撰牧字長民其墓誌作字先之未詳孰是</span>  
<span style="margin-left: 2em">或有兩字也彭城人官至太常博士宋志載牧新</span>  
<span style="margin-left: 2em">注周易十一卷圖一卷晁公武讀書志則作圖三</span>  
<span style="margin-left: 2em">卷其注今不傳惟圖尚在卷數與晁氏本同漢儒</span>  
<span style="margin-left: 2em">言易多主象數至宋而象數之中復岐出圖書一</span>  
<!-- 册1 葉249b　Page:文淵閣四庫全書_0001冊.djvu/112 -->
<span style="margin-left: 2em">派牧在邵子之前其首倡者也牧之學出於种放</span>  
<span style="margin-left: 2em">放出於陳摶其源流與邵子之出於穆李者同而</span>  
<span style="margin-left: 2em">以九爲河圖十爲洛書則與邵異其學盛行於仁</span>  
<span style="margin-left: 2em">宗時黃黎獻作畧例隱訣吳秘作通神程大昌作</span>  
<span style="margin-left: 2em">易原皆發明牧說而葉昌齡則作圖義以駁之宋</span>  
<span style="margin-left: 2em">咸則作王劉易辨以攻之李覯復有刪定易圖論</span>  
<span style="margin-left: 2em">至蔡元定則以爲與孔安國劉歆所傳不合而以</span>  
<span style="margin-left: 2em">十爲河圖九爲洛書朱子從之著易學啟䝉自是</span>  
<span style="margin-left: 2em">以後若胡一桂董楷吳澄之書皆宗朱蔡牧之圖</span>  
<!-- 册1 葉252a　Page:文淵閣四庫全書_0001冊.djvu/113 -->
<span style="margin-left: 2em">幾於不傳此本爲通志堂所刊何焯以爲自道藏</span>  
<span style="margin-left: 2em">錄出今考道藏目錄實在洞眞部靈圖類雲字號</span>  
<span style="margin-left: 2em">中是卽圖書之學出於道家之一證錄而存之亦</span>  
<span style="margin-left: 2em">足廣異聞也南宋時劉敏士嘗刻於浙右漕司前</span>  
<span style="margin-left: 2em">有歐陽修序吳澄曰修不信河圖而有此序殆後</span>  
<span style="margin-left: 2em">人所僞爲而牧之後人誤信之者俞琰亦曰序文</span>  
<span style="margin-left: 2em">淺俚非修作其言有見故今據而削之其遺論九</span>  
<span style="margin-left: 2em">事一爲太皥受龍馬<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3688.svg?width=24" alt="四庫全書僻字第3688號（負）" title="四庫全書僻字第3688號（負）">圖二爲六十四卦推盪訣</span>  
<span style="margin-left: 2em">三爲大衍之數五十四爲八卦變六十四卦五爲</span>  
<!-- 册1 葉252b　Page:文淵閣四庫全書_0001冊.djvu/113 -->
<span style="margin-left: 2em">辨陰陽卦六爲復見天地之心七爲卦終九事八</span>  
<span style="margin-left: 2em">爲奇偶揲法九爲陰陽律吕圖以先儒之所未及</span>  
<span style="margin-left: 2em">故曰遺論本別爲一卷徐氏刻九經解附之鈎隱</span>  
<span style="margin-left: 2em">圖末今亦仍之焉</span>  
周易口義十二卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">宋倪天隱述其師胡瑗之說瑗字翼之泰州如臯</span>  
<span style="margin-left: 2em">人用范仲淹薦由布衣拜校書郞歴太常博士致</span>  
<span style="margin-left: 2em">仕歸事迹具宋史儒林傳天隱始末未詳葉祖洽</span>  
<span style="margin-left: 2em">作陳襄行狀稱襄有二妹一適進士倪天隱殆卽</span>  
<!-- 册1 葉253a　Page:文淵閣四庫全書_0001冊.djvu/113 -->
<span style="margin-left: 2em">其人董ခ嚴陵集載其桐廬縣令題名碑記一篇</span>  
<span style="margin-left: 2em">意其嘗官睦州也其說易以義理爲宗邵伯温聞</span>  
<span style="margin-left: 2em">見前錄記程子與謝湜書言讀易當先觀王弼胡</span>  
<span style="margin-left: 2em">瑗王安石三家三原劉紹攽周易詳說曰朱子謂</span>  
<span style="margin-left: 2em">程子之學源於周子然考之易傳無一語及太極</span>  
<span style="margin-left: 2em">於觀卦詞云予聞之胡翼之先生居上爲天下之</span>  
<span style="margin-left: 2em">表儀於大畜上九云予聞之胡先生曰天之衢亨</span>  
<span style="margin-left: 2em">誤加何字於夬九三云安定胡公移其文曰壯于</span>  
<span style="margin-left: 2em">頄有凶獨行遇雨若濡有愠君子夬夬无咎於漸</span>  
<!-- 册1 葉253b　Page:文淵閣四庫全書_0001冊.djvu/113 -->
<span style="margin-left: 2em">上九云安定胡公以陸爲逵考伊川年譜皇祐中</span>  
<span style="margin-left: 2em">游太學海陵胡翼之先生方主教道得先生試文</span>  
<span style="margin-left: 2em">大驚卽延見處以學職意其時必從而受業焉世</span>  
<span style="margin-left: 2em">知其從事濓溪不知其講易多本於翼之也其說</span>  
<span style="margin-left: 2em">爲前人所未及今核以程傳良然朱子語類亦稱</span>  
<span style="margin-left: 2em">胡安定易分曉正當則是書在宋時固以義理說</span>  
<span style="margin-left: 2em">易之宗也王得臣麈史曰安定胡翼之皇祐至和</span>  
<span style="margin-left: 2em">間國子直講朝廷命主太學時千餘士日講易是</span>  
<span style="margin-left: 2em">書殆卽是時所說宋志載瑗易解十卷周易口義</span>  
<!-- 册1 葉256a　Page:文淵閣四庫全書_0001冊.djvu/114 -->
<span style="margin-left: 2em">十卷朱<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">尊經義考引李振裕之說云瑗講授之</span>  
<span style="margin-left: 2em">餘欲著述而未逮其門人倪天隱述之以非其師</span>  
<span style="margin-left: 2em">手著故名曰口義後世或稱口義或稱易解實無</span>  
<span style="margin-left: 2em">二書也其說雖古無明文然考晁公武讀書志有</span>  
<span style="margin-left: 2em">云胡安定易傳葢門人倪天隱所纂非其自著故</span>  
<span style="margin-left: 2em">序首稱先生曰其說與口義合又列於易傳條下</span>  
<span style="margin-left: 2em">亦不另出口義一條然則易解口義爲一書明矣</span>  
<span style="margin-left: 2em">宋志葢誤分爲二也</span>  
温公易說六卷<sub class="note-yuan">永樂大典本</sub>  
<!-- 册1 葉256b　Page:文淵閣四庫全書_0001冊.djvu/114 -->
<span style="margin-left: 2em">宋司馬光撰考蘇軾撰光行狀載所作易說三卷</span>  
<span style="margin-left: 2em">注繫詞二卷宋史藝文志作易說一卷又三卷又</span>  
<span style="margin-left: 2em">繫詞說二卷晁公武讀書志云易說雜解易義無</span>  
<span style="margin-left: 2em">詮次未成書朱子語類又云嘗得温公易說於洛</span>  
<span style="margin-left: 2em">人范仲彪盡隨卦六二其後缺焉後數年好事者</span>  
<span style="margin-left: 2em">於北方互市得板本喜其復全是其書在宋時所</span>  
<span style="margin-left: 2em">傳本巳往往多寡互異其後乃并失其傳故朱<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）"></span>  
<span style="margin-left: 2em">尊經義考亦註爲巳佚今獨永樂大典中有之而</span>  
<span style="margin-left: 2em">所列實不止於隨卦似卽朱子所稱後得之本其</span>  
<!-- 册1 葉257a　Page:文淵閣四庫全書_0001冊.djvu/114 -->
<span style="margin-left: 2em">釋每卦或三四爻或一二爻且有全無說者惟繫</span>  
<span style="margin-left: 2em">詞差完備而說卦以下僅得二條亦與晁公武之</span>  
<span style="margin-left: 2em">言相合又以陳友文集傳精義馮椅易學胡一桂</span>  
<span style="margin-left: 2em">會通諸書所引光說核之一一具在知爲宋代原</span>  
<span style="margin-left: 2em">本無疑其解義多闕者葢光本撰次未成亦如所</span>  
<span style="margin-left: 2em">著潛虛轉以不完者爲眞本並非有所殘佚也光</span>  
<span style="margin-left: 2em">傳家集中有答韓秉國書謂王輔嗣以老莊解易</span>  
<span style="margin-left: 2em">非易之本㫖不足爲據葢其意在深闢虛無元渺</span>  
<span style="margin-left: 2em">之說故於古今事物之情狀無不貫徹疏通推闡</span>  
<!-- 册1 葉257b　Page:文淵閣四庫全書_0001冊.djvu/114 -->
<span style="margin-left: 2em">深至如解同人之彖曰君子樂與人同小人樂與</span>  
<span style="margin-left: 2em">人異君子同其遠小人同其近坎之大象曰水之</span>  
<span style="margin-left: 2em">流也習而不止以成大川人之學也習而不止以</span>  
<span style="margin-left: 2em">成大賢咸之九四曰心苟傾焉則物以其類應之</span>  
<span style="margin-left: 2em">故喜則不見其所可怒怒則不見其所可喜愛則</span>  
<span style="margin-left: 2em">不見其所可惡惡則不見其所可愛大都不襲先</span>  
<span style="margin-left: 2em">儒舊說而有德之言要如布帛菽粟之切於日用</span>  
<span style="margin-left: 2em">惜其沈湮旣久說易家竟不𫉬覩其書今幸際</span>  
聖朝表章典籍復得搜羅故簡裒次成編亦可知名賢  
<!-- 册1 葉260a　Page:文淵閣四庫全書_0001冊.djvu/115 -->
<span style="margin-left: 2em">著述其精意所在有不終冺没於來世者矣謹校</span>  
<span style="margin-left: 2em">勘釐訂畧仿宋史原目定爲六卷著於錄</span>  
橫渠易說三卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋張子撰宋志著錄作十卷今本惟上經一卷下</span>  
<span style="margin-left: 2em">經一卷繫辭傳以下至雜卦爲一卷末有總論十</span>  
<span style="margin-left: 2em">一則與宋志不合然書錄解題巳稱橫渠易說三</span>  
<span style="margin-left: 2em">卷則宋志誤也楊時喬周易古今文稱今本祇六</span>  
<span style="margin-left: 2em">十四卦無繫辭實未全之書則又時喬所見之本</span>  
<span style="margin-left: 2em">偶殘缺耳是書較程傳爲簡往往經文數十句中</span>  
<!-- 册1 葉260b　Page:文淵閣四庫全書_0001冊.djvu/115 -->
<span style="margin-left: 2em">一無所說末卷更不復全載經文載其有說者而</span>  
<span style="margin-left: 2em">巳董眞卿謂橫渠易說發明二程所未到處然考</span>  
<span style="margin-left: 2em">宋史張子卒於神宗時程子易傳序則作於哲宗</span>  
<span style="margin-left: 2em">元符二年其編次成書則在徽宗崇寧後張子不</span>  
<span style="margin-left: 2em">及見矣眞卿謂發明所未到非<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">論也其說乾彖</span>  
<span style="margin-left: 2em">用迎之不見其首隨之不見其後說文言用谷神</span>  
<span style="margin-left: 2em">字說鼓萬物而不與聖人同憂用天地不仁以萬</span>  
<span style="margin-left: 2em">物爲芻狗語皆借老子之言而實異其義非如魏</span>  
<span style="margin-left: 2em">晉人合老易爲一者也惟其解復卦后不省方以</span>  
<!-- 册1 葉261a　Page:文淵閣四庫全書_0001冊.djvu/115 -->
<span style="margin-left: 2em">后爲繼體守成之主以不省方爲富庶優暇不甚</span>  
<span style="margin-left: 2em">省事則於義頗屬未安此又不必以張子故而曲</span>  
<span style="margin-left: 2em">爲之詞矣</span>  
東坡易傳九卷<sub class="note-yuan">副都御史黃登賢家藏本</sub>  
<span style="margin-left: 2em">宋蘇軾撰是書一名毘陵易傳陸游老學庵筆記</span>  
<span style="margin-left: 2em">謂其書初遭元祐黨禁不敢顯題軾名故稱毘陵</span>  
<span style="margin-left: 2em">先生以軾終於常州故也蘇籕欒城遺言記蘇洵</span>  
<span style="margin-left: 2em">作易傳未成而卒屬二子述其志軾書先成轍乃</span>  
<span style="margin-left: 2em">送所解於軾今䝉卦猶是轍解則此書實蘇氏父</span>  
<!-- 册1 葉261b　Page:文淵閣四庫全書_0001冊.djvu/115 -->
<span style="margin-left: 2em">子兄弟合力爲之題曰軾撰要其成耳籕又稱洵</span>  
<span style="margin-left: 2em">晚歲讀易玩其爻象因得其剛柔遠近喜怒逆順</span>  
<span style="margin-left: 2em">之情故朱子謂其惟發明愛惡相攻情僞相感之</span>  
<span style="margin-left: 2em">義而議其粗疎胡一桂記晁說之之言謂軾作易</span>  
<span style="margin-left: 2em">傳自恨不知數學而其學又雜以禪故朱子作雜</span>  
<span style="margin-left: 2em">學辨以軾是書爲首然朱子所駁不過一十九條</span>  
<span style="margin-left: 2em">其中辨文義者四條又一條謂蘇說無病然有未</span>  
<span style="margin-left: 2em">盡其說者則朱子所不取者僅十四條未足以爲</span>  
<span style="margin-left: 2em">是書病况朱子語類又嘗謂其於物理上亦有看</span>  
<!-- 册1 葉264a　Page:文淵閣四庫全書_0001冊.djvu/116 -->
<span style="margin-left: 2em">得著處則亦未嘗竟廢之矣今觀其書如解乾卦</span>  
<span style="margin-left: 2em">彖傳性命之理諸條誠不免杳㝠恍惚淪於異學</span>  
<span style="margin-left: 2em">至其他推闡理勢言簡意明往往足以達難顯之</span>  
<span style="margin-left: 2em">情而深得曲譬之㫖葢大體近於王弼而弼之說</span>  
<span style="margin-left: 2em">惟暢元風軾之說多切人事其文詞博辨足資啟</span>  
<span style="margin-left: 2em">發又烏可一槪屏斥𫆀李衡作周易義海撮要丁</span>

<span style="margin-left: 2em">登嘉王榜進士紹興中官至左僕射兼修國史故</span>
