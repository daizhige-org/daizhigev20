易義隨記八卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 1em">國朝夏宗瀾撰宗瀾字起八江陰人由拔貢生薦授</span>  
<span style="margin-left: 2em">國子監助敎是編乃宗瀾恭讀</span>

<span style="margin-left: 2em">瀾方從楊名時於雲南以修周易折中時李光地</span>  
<span style="margin-left: 2em">爲總裁官而名時爲光地門人故㕘互以光地榕</span>

<span style="margin-left: 2em">錄之間凡問者皆宗瀾語答者皆名時語也</span>  
易卦劄記四卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 1em">國朝夏宗瀾撰是書惟解上下經不及繫辭以下前</span>  
<span style="margin-left: 2em">列易例舉要一篇讀易指要一篇其指要有曰要</span>  
<span style="margin-left: 2em">明易理須先將伏羲畫卦次序方位文王八卦方</span>  
<span style="margin-left: 2em">位及先後天方圓諸圖反覆記看令其曉然再說</span>

<span style="margin-left: 2em">外是矣</span>

程氏易通十四卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 1em">國朝程廷祚撰廷祚有大易擇言已著錄是書凡易</span>  
<span style="margin-left: 2em">學要論二卷周易正解十卷易學精義一卷又附</span>  
<span style="margin-left: 2em">錄占法訂誤一卷易通其總名也其要論盡去漢</span>  
<span style="margin-left: 2em">人爻變互體飛伏納甲諸法未免主持稍過然舉</span>  
<span style="margin-left: 2em">宋人河洛先天諸圖及乘承比應諸例掃而空之</span>  
<span style="margin-left: 2em">則實有芟除轇轕之功其正解則經傳之義疏不</span>  
<span style="margin-left: 2em">用今本亦不用古本以彖傳小象散入經文十翼</span>  
<span style="margin-left: 2em">併爲六翼頗嫌變亂而詮釋尙爲簡明其精義統</span>

<span style="margin-left: 2em">論義理通其說於道學畧如語錄之體其占法訂</span>  
<span style="margin-left: 2em">誤謂畫有奇偶九六而上下進退於初二三四五</span>  
<span style="margin-left: 2em">上之際所謂六爻發揮者易之變惟在於此之卦</span>  
<span style="margin-left: 2em">則所以識別動爻之用而所取仍在本卦故以洪</span>  
<span style="margin-left: 2em">範之說爲占法而以春秋内外傳所載爲附㑹變</span>  
<span style="margin-left: 2em">亂不與易應然箕子殷人未睹周易太卜掌三易</span>  
<span style="margin-left: 2em">之法則三易異占灼然可証左氏所紀其事或有</span>  
<span style="margin-left: 2em">附㑹其占法則當代所用卜史通行斷不至實無</span>  
<span style="margin-left: 2em">此法而憑虛自造是則信理黜數至於橋枉過直</span>

<span style="margin-left: 1em">國朝程廷祚撰此書葢其中年所作在大易擇言易</span>  
<span style="margin-left: 2em">通二書之前後多附入二書中然亦時有採取未</span>  
<span style="margin-left: 2em">盡者葢所見隨年而進故不一一盡執其舊說也</span>  
學易闡微四卷<sub class="note-yuan">福建巡撫採進本</sub>  
<span style="margin-left: 1em">國朝羅登標撰登標字子建寧化人康熙間舉人官</span>  
<span style="margin-left: 2em">松溪縣敎諭是書皆辨易中疑義凡爲論者七十</span>  
<span style="margin-left: 2em">四爲考者五爲解者三十三共一百十一篇多循</span>  
<!-- 册1 葉929b　Page:文淵閣四庫全書_0001冊.djvu/282 -->
<span style="margin-left: 2em">用前人之說其首卷第一篇論畫前有易不免膚</span>  
<span style="margin-left: 2em">詞卷三中以三百八十四爻割隷八卦於全卦之</span>  
<span style="margin-left: 2em">義反有未融至卷四中以六十四卦之五爻配歴</span>  
<span style="margin-left: 2em">代帝王解一篇亦屬掛一漏百其以恒五爻婦人</span>  
<span style="margin-left: 2em">吉夫子凶擬武后之幽囚太子竊弄神器尤爲悖</span>  
<span style="margin-left: 2em">理夫武后可稱婦人吉乎</span>  
讀易質疑二十卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝汪璲撰璲字文儀號黙庵休寧人其書置象數</span>  
<span style="margin-left: 2em">而專言理其凡例有云今說易之家謂易以道陰</span>  
<!-- 册1 葉932a　Page:文淵閣四庫全書_0001冊.djvu/283 -->
<span style="margin-left: 2em">陽務以圓妙幽𣺌籠罩影響如捕風如捉影無當</span>  
<span style="margin-left: 2em">實用故愚以爲學易當就平實切近處用功云云</span>  
<span style="margin-left: 2em">其宗㫖可見故隨文詮釋無所穿鑿而亦無所發</span>  
<span style="margin-left: 2em">明卷末雜卦一篇有錄無書疑裝緝者偶脫云</span>  
周易㑹緝<sub class="note-yuan">無卷數　山東巡撫採進本</sub>  
<span style="margin-left: 1em">國朝吳映撰映字沐曰晉江人其書大㫖皆宗朱子</span>  
<span style="margin-left: 2em">本義而折衷於𫎇引存疑諸書持論亦頗平實然</span>  
<span style="margin-left: 2em">取材太寡用意太拘尙未能深研精奥也</span>  
大易闡微錄十二卷<sub class="note-yuan">直隷總督採進本</sub>  
<!-- 册1 葉932b　Page:文淵閣四庫全書_0001冊.djvu/283 -->
<span style="margin-left: 1em">國朝劉琯撰琯字獻白棗强人先天之圖於周易之</span>  
<span style="margin-left: 2em">上別尊羲易其傳出自陳摶自㕘同契以外別無</span>  
<span style="margin-left: 2em">授受之<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">證故邵子之學朱子以爲易外別傳自</span>  
<span style="margin-left: 2em">元以來諸儒互有衍說亦遞相攻擊至</span>  
<span style="margin-left: 1em">國朝黃宗炎胡渭諸人始抉摘根源窮究依託渭書</span>  
<span style="margin-left: 2em">考究尤詳琯未覩黃胡二家之書不知其僞之已</span>  
<span style="margin-left: 2em">破故又因而推衍加以穿鑿如謂人之生虱人止</span>  
<span style="margin-left: 2em">一个而所生之虱个个有對又謂男女雖是二个</span>  
<span style="margin-left: 2em">合來仍是一个故男鰥女寡俗稱半个人其詞皆</span>

<span style="margin-left: 2em">不雅馴於月令天氣上升地氣下降閉塞成冬及</span>  
<span style="margin-left: 2em">周髀四遊之說攻駁尤甚大抵皆憑臆而談其敘</span>  
<span style="margin-left: 2em">跋皆自命甚高以爲聖賢所未發過矣</span>  
周易詳說十九卷<sub class="note-yuan">陜西巡撫採進本</sub>  
<span style="margin-left: 1em">國朝劉紹攽撰紹攽三原人是書大㫖以程傳爲宗</span>  
<span style="margin-left: 2em">與本義頗有同異於邵子先天之說亦不謂盡然</span>  
<span style="margin-left: 2em">不爲無見惟於漢儒舊訓掊擊過當頗近於傎其</span>  
<span style="margin-left: 2em">議論縱橫亦大抵隨文生義故往往自相矛盾如</span>  
<span style="margin-left: 2em">卷首論玩辭一條駁諸儒之失曰甚有釋傳與彖</span>  
<!-- 册1 葉933b　Page:文淵閣四庫全書_0001冊.djvu/283 -->
<span style="margin-left: 2em">傳不合釋象與爻不合無以自解則藉口有伏羲</span>  
<span style="margin-left: 2em">之易有周文之易有孔子之易云云至開卷元亨</span>  
<span style="margin-left: 2em">利貞一條又主大通而利正固之說謂王弼泥於</span>  
<span style="margin-left: 2em">穆姜之言以元亨利貞爲四德後多宗之殊不知</span>  
<span style="margin-left: 2em">文王有文王之易孔子有孔子之易彖辭彖傳不</span>  
<span style="margin-left: 2em">相率合者甚多云云是二說者使後人何所從乎</span>  
周易原始六卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝范咸撰咸字貞吉號九池錢塘人雍正癸卯進</span>  
<span style="margin-left: 2em">士官至監察御史其書惟解經文不及十翼大㫖</span>  
<!-- 册1 葉936a　Page:文淵閣四庫全書_0001冊.djvu/284 -->
<span style="margin-left: 2em">以理始於象象始於畫又以萬物始於陰陽象始</span>  
<span style="margin-left: 2em">於日月取繫辭陰陽之義配日月之語而總以陰</span>

<span style="margin-left: 2em">圈黑㸃依託圖書亦不以禪偈道經空標心性較</span>  
<span style="margin-left: 2em">明以來說易諸家頗爲篤實然其長在盡掃卮言</span>  
<span style="margin-left: 2em">其短亦在好生新意如謂元亨之元爲陽在下至</span>  
<span style="margin-left: 2em">於陰卦亦每稱元義有難通者亦曲伸其說又謂</span>  
<span style="margin-left: 2em">上經皆陽盛之卦下經皆陰盛之卦而上經有剝</span>  
<span style="margin-left: 2em">復下經有中孚大壯理有所格亦必强合其義是</span>

<span style="margin-left: 2em">中書科中書其書不釋十翼惟六十四卦每卦撰</span>  
<span style="margin-left: 2em">說一篇詮釋大意其大㫖欲以義理矯象數之失</span>  
<span style="margin-left: 2em">以平易救穿鑿之失以切實救支離泛濫之失而</span>  
<span style="margin-left: 2em">矯枉不免過直云</span>  
周易撥易堂解二十卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 1em">國朝劉斯組撰斯組字斗田新建人雍正甲辰舉人</span>  
<!-- 册1 葉937a　Page:文淵閣四庫全書_0001冊.djvu/284 -->
<span style="margin-left: 2em">官𣏌縣知縣是書前有記畧載梓此書時其壻夢</span>  
<span style="margin-left: 2em">二童歌詩曰不不不九六乾坤七四執黃農非古</span>  
<span style="margin-left: 2em">世非今理數𤓰分一太極又載著是書時其姪夢</span>  
<span style="margin-left: 2em">閣上有朱題撥易閣三字因以爲名其事頗涉幻</span>  
<span style="margin-left: 2em">杳似乎故神其說又謂撥字有發揮三才之義不</span>  
<span style="margin-left: 2em">知說文撥字在手部篆作ခ隷省作才非从才也</span>  
<span style="margin-left: 2em">其書首二卷皆圖說大抵因舊解而蔓衍之又謂</span>  
<span style="margin-left: 2em">論語中庸皆通於易卽陳際泰羣經輔易說之意</span>  
<span style="margin-left: 2em">六經一貫理自相通至於才辨縱橫隨心牽引如</span>  
<!-- 册1 葉937b　Page:文淵閣四庫全書_0001冊.djvu/284 -->
<span style="margin-left: 2em">解飛龍在天曰此則唐人所謂龍池躍龍龍已飛</span>  
<span style="margin-left: 2em">矣入天門開黃道艮闕亦具爻内讀易方解詩中</span>  
<span style="margin-left: 2em">寫龍德特全是豈詁經之體耶</span>  
周易摘抄五卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 1em">國朝顧昺撰昺號虛莊南滙人雍正甲辰舉人是編</span>  
<span style="margin-left: 2em">爲其三經解之一皆節錄</span>

<span style="margin-left: 2em">通論故曰摘抄間附已意亦罕所發明</span>  
學易大象要參四卷<sub class="note-yuan">編修林澍蕃家藏本</sub>  
<!-- 册1 葉940a　Page:文淵閣四庫全書_0001冊.djvu/285 -->
<span style="margin-left: 1em">國朝林贊龍撰贊龍字澤雲侯官人雍正丙午舉人</span>  
<span style="margin-left: 2em">是書以發明大象爲主六十四卦各爲一篇以上</span>  
<span style="margin-left: 2em">下經分二卷而冠以綱領六篇爲一卷一曰發凡</span>  
<span style="margin-left: 2em">二曰象例三曰義理象數四曰卦爻中相錯陰陽</span>  
<span style="margin-left: 2em">相應五曰憂患九德六曰大象有通於四書殿以</span>  
<span style="margin-left: 2em">附解二篇爲一卷一曰作易憂患解二曰雜卦傳</span>  
<span style="margin-left: 2em">解大㫖以大象上一句爲天地萬物之象下句爲</span>  
<span style="margin-left: 2em">人事以天象爲人事之則不言吉凶而言理義不</span>  
<span style="margin-left: 2em">言神聖而言君子以明人人可學故所闡發皆切</span>  
<!-- 册1 葉940b　Page:文淵閣四庫全書_0001冊.djvu/285 -->
<span style="margin-left: 2em">曰用其綱領有曰借易明理自夫子已然學以聚</span>  
<span style="margin-left: 2em">之問以辨之寛以居之仁以行之爲乾九二而言</span>  
<span style="margin-left: 2em">也而乾之九二豈有學問寛仁之義乎日月相推</span>  
<span style="margin-left: 2em">而明生焉寒暑相推而歲成焉爲咸九四而言也</span>
