欽定四庫全書總目卷五十五  
<span style="margin-left: 1em">史部十一</span>  
<span style="margin-left: 2em">詔令奏議𩔖</span>  
<span style="margin-left: 3em">記言記動二史分司起居注右史事也左史所</span>  
<span style="margin-left: 3em">錄蔑聞焉王言所敷惟詔令耳唐志史部初立</span>  
<span style="margin-left: 3em">此門黃虞稷千頃堂書目則移制誥於集部次</span>  
<span style="margin-left: 3em">於别集夫渙號明堂義無虛發治亂得失於是</span>  
<span style="margin-left: 3em">可稽此政事之樞機非僅文章𩔖也抑居詞賦</span>  
<span style="margin-left: 3em">於理爲褻尙書誓誥經有明徵今仍載史部從</span>  
<!-- 册2 葉869b　Page:文淵閣四庫全書_0002冊.djvu/222 -->
<span style="margin-left: 3em">古義也文獻通考始以奏議自爲一門亦居集</span>  
<span style="margin-left: 3em">末考漢志載奏事十八篇列戰國策史記之間</span>  
<span style="margin-left: 3em">附春秋末則論事之文當歸史部其證昭然今</span>  
<span style="margin-left: 3em">亦併改𨽻俾易與紀傳互考焉</span>  
太祖高皇帝聖訓四卷  
<span style="margin-left: 2em">康熙二十五年</span>  
聖祖仁皇帝恭編凡九十有二則分二十六門乾隆四年  
<span style="margin-left: 2em">我</span>  
皇上敬製序文  
<!-- 册2 葉872a　Page:文淵閣四庫全書_0002冊.djvu/223 -->
<span style="margin-left: 1em">宣付剞劂昭示萬方昔者有明末葉海水羣飛</span>  
景命有歸  
眞人首出亶聰明而應運錫智勇以匡時以遺甲一十三  
<span style="margin-left: 3em">人仗順興師</span>  
肇開鴻業  
威弧震疊妖孛熸芒仰溯  
臨御之日大抵秉旄執鉞者居多然而外播  
天聲内脩  
王政  
<!-- 册2 葉872b　Page:文淵閣四庫全書_0002冊.djvu/223 -->
經綸創造文武兼資凡一時  
指授開陳  
皇極敷言罔非彞訓黃帝七十戰而銘著於巾机成湯十  
<span style="margin-left: 3em">一征而義彰於誓誥以今方古厥道同符特以</span>  
<span style="margin-left: 2em">國初淳朴僅傳於故老舊臣之口故記載未詳</span>  
聖祖仁皇帝追維  
前烈敬勒鴻編昭千古之  
帝圖垂萬年之  
家法書所謂啓佑我後人咸以正無缺者  
<!-- 册2 葉873a　Page:文淵閣四庫全書_0002冊.djvu/223 -->
締造規模猶可仰窺而見焉  
太宗文皇帝聖訓六卷  
<span style="margin-left: 3em">順治末</span>  
世祖章皇帝編次未竟康熙二十六年  
聖祖仁皇帝續成凡一百一十一則分二十三門乾隆四  
<span style="margin-left: 3em">年</span>  
<span style="margin-left: 1em">皇上御製序文刊布惟我</span>  
太宗文皇帝纘承  
前緒益拓  
<!-- 册2 葉873b　Page:文淵閣四庫全書_0002冊.djvu/223 -->
鴻基因壘崇墉觀兵坶野  
威棱震耀旣遠邁成周至於敦敘羣倫正名百物禮樂大  
<span style="margin-left: 2em">備書契肇興則與軒帝膺圖外奮涿野之威而内</span>  
<span style="margin-left: 3em">肅合宫之典者後先同揆誠以</span>  
守成而兼  
創業  
奮武而並  
揆文蓋宰馭乎萬𩔖者其聰明睿智必超乎萬𩔖之上  
太祖有焉垂𥙿乎萬年者其制作精神必周乎萬年之後  
<!-- 册2 葉876a　Page:文淵閣四庫全書_0002冊.djvu/224 -->
太宗有焉稱  
天上  
諡尊以經天緯地之大名義所稱也  
豐功偉烈史臣珥筆巳恭紀  
琅函至於  
聖德所形  
聲律身度  
一舉一動效法乎乾坤  
一話一言表裏乎典誥者則恭傳  
<!-- 册2 葉876b　Page:文淵閣四庫全書_0002冊.djvu/224 -->
天語具載斯編於以上彰  
祖德下啓  
孫謀理珠囊而握金鏡誠億萬世之法守矣  
世祖章皇帝聖訓六卷  
<span style="margin-left: 3em">康熙二十六年</span>  
聖祖仁皇帝恭編凡一百一十三則分三十有二門乾隆  
<span style="margin-left: 3em">四年</span>  
<span style="margin-left: 1em">皇上御製序文刊布洪惟我</span>  
世祖章皇帝夙齡踐阼  
<!-- 册2 葉877a　Page:文淵閣四庫全書_0002冊.djvu/224 -->
定鼎燕京視帝堯起自唐封尙先五載然生而神靈幼而  
<span style="margin-left: 2em">徇齊長而敦敏則比德於黃軒是以</span>  
提挈天樞驅策羣力削平三蘖底定四瀛大同文軌建億  
<span style="margin-left: 2em">載之</span>  
丕基加以  
宵旰之餘始終典學  
御注孝經則操至德要道之原  
御纂内則衍義則昭篤近舉遠之本  
御製人臣儆心錄則振舉政典澄敘官方  
<!-- 册2 葉877b　Page:文淵閣四庫全書_0002冊.djvu/224 -->
御撰資政要覽則敦敘綱常砥礪世教凡聖賢之理藴無  
<span style="margin-left: 2em">不闡明凡帝王之治法無不講貫固已本心出治</span>  
<span style="margin-left: 2em">舉措咸宜至於</span>  
敎闡  
聖謨言爲世則亦出同綸綍寶並球圖夫天不可測測以  
<span style="margin-left: 2em">星辰之行地不可度度以山川之紀</span>  
聖不可知知以典籍之所傳  
堯誡湯銘貽留奕禩亦庶幾稍窺  
高厚之萬一矣  
<!-- 册2 葉880a　Page:文淵閣四庫全書_0002冊.djvu/225 -->
聖祖仁皇帝聖訓六十卷  
<span style="margin-left: 2em">雍正九年</span>  
世宗憲皇帝恭編乾隆六年  
皇上御製序文刊布凡三十二𩔖總一千九百餘則篇  
<span style="margin-left: 2em">帙視</span>  
列聖爲富葢  
聖祖仁皇帝道符  
帝縡  
命自  
<!-- 册2 葉880b　Page:文淵閣四庫全書_0002冊.djvu/225 -->
天申  
景祚延洪卜年久遠六甲五子首末循環與天運相始終  
<span style="margin-left: 2em">故</span>  
神功  
聖德史不勝書  
實錄數盈千卷而  
貽留大訓亦紀載獨繁伏考周易有曰日月得天而能久  
<span style="margin-left: 2em">照四時變化而能久行聖人久于其道而天下化</span>  
<span style="margin-left: 2em">成</span>  
<!-- 册2 葉881a　Page:文淵閣四庫全書_0002冊.djvu/225 -->
寶祚綿長故  
彝訓最爲詳備此誠帝王之盛軌也然其故有不止於此  
<span style="margin-left: 2em">者昔虞舜鳴韶鳳儀獸舞而臯陶颺拜猶期以愼</span>  
<span style="margin-left: 2em">憲省成慮其始勤而終情也使厯年久遠而暇豫</span>  
<span style="margin-left: 2em">之念或萌則怠氣所乘又安能於天下之事一一</span>  
<span style="margin-left: 3em">爲之衡量於在廷之臣一一爲之啓導今跽讀</span>  
聖謨所爲保泰而持盈謹小而愼微者六十一年如一日  
<span style="margin-left: 3em">然則</span>  
聖訓之獨多固在  
<!-- 册2 葉881b　Page:文淵閣四庫全書_0002冊.djvu/225 -->
享國之永亦在  
蒞政之勤矣周公告誡成王厯舉太戊武丁祖甲文王之  
<span style="margin-left: 3em">壽考而歸本於無逸</span>  
聖人之心固異世而同符也  
世宗憲皇帝聖訓三十六卷  
<span style="margin-left: 3em">乾隆五年</span>  
<span style="margin-left: 1em">皇上恭編</span>  
御製序文刊布分三十𩔖九百十六則卷帙亦極繁富  
<span style="margin-left: 3em">葢我</span>  
<!-- 册2 葉884a　Page:文淵閣四庫全書_0002冊.djvu/226 -->
世宗憲皇帝勵精圖治日昃不遑  
端拱九重而念周四海爲萬世永賴之計故理繁治劇而  
<span style="margin-left: 2em">不避其煩厪一夫不𫉬之心故慮遠防微而不遺</span>  
<span style="margin-left: 2em">於細所由都俞吁咈</span>  
誥誡特詳且癸卯  
踐阼以前侍  
聖祖仁皇帝之日長上則政教之條制刑賞之權衡聞之  
<span style="margin-left: 2em">最悉下則百度之利弊萬物之情僞知之最深故</span>  
睿照無遺如金鑑澄明物來畢肖隨時  
<!-- 册2 葉884b　Page:文淵閣四庫全書_0002冊.djvu/226 -->
誨示每泛應無窮而我  
皇上問視  
龍樓  
親聆  
綸綍亦二十餘載  
御極以後  
聖慕彌深追𫐠  
玉音始末尤能詳備十三年中之記錄積盈三十餘卷元  
<span style="margin-left: 2em">元本本有自來矣</span>  
<!-- 册2 葉885a　Page:文淵閣四庫全書_0002冊.djvu/226 -->
堯典禹謨流傳簡冊

<span style="margin-left: 2em">日月齊光也</span>  
世宗憲皇帝上諭八旗十三卷  
上諭旗務議覆十二卷  
諭行旗務奏議十三卷  
<span style="margin-left: 2em">雍正九年和碩莊親王允祿等奉</span>  
勅編凡三集共爲一書自康熙六十一年十一月十七日  
<span style="margin-left: 2em">以後所奉</span>  
<!-- 册2 葉885b　Page:文淵閣四庫全書_0002冊.djvu/226 -->

<span style="margin-left: 1em">國書漢書刊刻頒行伏考三代以上兵與民同體文</span>  
<span style="margin-left: 2em">與武亦不分途故凡其著名版籍者十六以下上</span>  
<span style="margin-left: 2em">所長六十以上上所養無事皆可合以訓練有事</span>  
<!-- 册2 葉888a　Page:文淵閣四庫全書_0002冊.djvu/227 -->
<span style="margin-left: 2em">卽人人可以荷戈而當時之將帥亦卽以卿大夫</span>  
<span style="margin-left: 2em">爲之未嘗治民而不治兵治兵而不治民也三代</span>  
<span style="margin-left: 2em">以下時異勢殊雖堯舜禹湯亦不能復行古法惟</span>  
<span style="margin-left: 2em">我</span>  
<span style="margin-left: 1em">國家八旗之制則古法猶存雖臂指相維統以軍律</span>  
<span style="margin-left: 2em">而其人如比閭族黨之相保民事具焉其官如郡</span>  
<span style="margin-left: 2em">國州縣之相𨽻吏事具焉故六職百司之政八旗</span>  
<span style="margin-left: 2em">無不備而科條案牘亦遂至劇至繁我</span>  
世宗憲皇帝深維根本之重  
<!-- 册2 葉888b　Page:文淵閣四庫全書_0002冊.djvu/227 -->
睿謨規畫鉅細咸周故宣於  
綸綍者特多猶慮纎毫之或遺也謀及卿士而議覆積而  
<span style="margin-left: 2em">成帙詢于芻蕘而奏議亦積而成帙葢</span>  
輦轂之側視聽至近  
籌度周詳  
咨詢周密猶若此然則萬方廣遠百度殷繁

世宗憲皇帝上諭内閣一百五十九卷  
<span style="margin-left: 2em">雍正七年</span>  
<!-- 册2 葉889a　Page:文淵閣四庫全書_0002冊.djvu/227 -->

御極之初止於是年以雍正九年告成  
皇上卽阼以後復  
命和碩和親王𢎞晝編次雍正八年至十三年  
上諭校正續刻補爲全書以乾隆六年告成原本皆以每  
<span style="margin-left: 2em">月别爲起訖不標卷數今恭依舊次釐爲一百五</span>  
<span style="margin-left: 2em">十九卷原本亦未題書名今恭繹</span>  
諭㫖由内閣  
<!-- 册2 葉889b　Page:文淵閣四庫全書_0002冊.djvu/227 -->
宣示者居多謹題曰  
上諭内閣以别於  
上諭八旗諸編焉伏考  
<span style="margin-left: 1em">國家舊制始置内三院後乃改置内閣以出納</span>  
綸音恭逢  
列聖膺圖  
乾綱獨握自增用奏摺以後皆  
高居紫極  
親御丹毫在廷之臣一詞莫贊卽  
<!-- 册2 葉892a　Page:文淵閣四庫全書_0002冊.djvu/228 -->
硃批諭㫖是也其題本由内閣票擬者遇事涉兩岐輙恭  
<span style="margin-left: 2em">繕雙簽以請無敢擅專至於</span>  
訓誥特頒則  
指授内<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">諸臣於  
<span style="margin-left: 1em">禁廷具草有纎微未達</span>  
聖意者必  
御筆塗乙添注亦罔敢以私意參其間  
鑒定之後降付内閣宣布中外而已更無由如前代宰輔  
<span style="margin-left: 2em">假批答以竊威福者此一百五十九卷名爲臣工</span>  
<!-- 册2 葉892b　Page:文淵閣四庫全書_0002冊.djvu/228 -->
<span style="margin-left: 2em">所繕錄實與</span>  
御札手勅無以異  
勵精宵旰之懷謹持魁柄之意萬世可伏讀而見之也我  
皇上御䟦程頤經筵劄子力斥其天下安危繫於宰相  
<span style="margin-left: 2em">之說誠所謂聰聽</span>  
彝訓<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2618.svg?width=24" alt="四庫全書僻字第2618號（⿱乖一）" title="四庫全書僻字第2618號（⿱乖一）">裕後昆者矣  
世宗憲皇帝硃批諭㫖三百六十卷  
<span style="margin-left: 2em">雍正十年奉</span>
