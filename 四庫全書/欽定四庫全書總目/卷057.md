## 欽定四庫全書總目 卷五十七　史部十三　傳記類一

<!-- 册2 葉1064：整葉圖版，無文字記錄 -->
<!-- 册2 葉1065a　Page:文淵閣四庫全書_0002冊.djvu/271 -->
欽定四庫全書總目卷五十七  
<span style="margin-left: 1em">史部十三</span>  
<span style="margin-left: 2em">傳記類一</span>  
<span style="margin-left: 3em">紀事始者稱傳記始黃帝此道家野言也究厥</span>  
<span style="margin-left: 3em">本源則晏子春秋是卽家傳孔子三朝記其記</span>  
<span style="margin-left: 3em">之權輿乎裴松之註三國志劉孝標註世說新</span>  
<span style="margin-left: 3em">語所引至繁葢魏晉以來作者彌夥諸家著錄</span>  
<span style="margin-left: 3em">體例相同其參錯混淆亦如一軌今略爲區別</span>  
<span style="margin-left: 3em">一曰聖賢如孔孟年譜之類二曰名人如魏鄭</span>  
<!-- 册2 葉1065b　Page:文淵閣四庫全書_0002冊.djvu/271 -->
<span style="margin-left: 3em">公諌錄之類三曰總錄如列女傳之類四曰雜</span>  
<span style="margin-left: 3em">錄如驂鸞錄之類其杜大圭碑傳琬琰集蘇天</span>  
<span style="margin-left: 3em">爵名臣事略諸書雖無傳記之名亦各核其實</span>  
<span style="margin-left: 3em">依類編入至安祿山黃巢劉豫諸書旣不能遽</span>  
<span style="margin-left: 3em">削其名亦未可薰蕕同器則從叛臣諸傳附載</span>  
<span style="margin-left: 3em">史末之例自爲一類謂之曰别錄</span>  
孔子編年五卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">舊本題宋胡舜陟撰考書首有紹興八年舜陟序</span>  
<span style="margin-left: 2em">乃自靜江罷歸之日命其子仔所撰非舜陟自作</span>  
<!-- 册2 葉1068a　Page:文淵閣四庫全書_0002冊.djvu/272 -->
<span style="margin-left: 2em">也舜陟字汝明績溪人大觀三年進士靖康間官</span>  
<span style="margin-left: 2em">侍御史南渡初知廬州有禦㓂功更厯數鎭最後</span>  
<span style="margin-left: 2em">爲廣西經略使欲爲秦檜父建祠高登不可因劾</span>  
<span style="margin-left: 2em">登以媚檜㑹以他事忤檜意亦逮治死於獄事蹟</span>  
<span style="margin-left: 2em">具宋史本傳仔字元任後流寓吳興嘗輯詩話行</span>  
<span style="margin-left: 2em">於世卽所謂苕溪漁隱者是也是書輯錄孔子言</span>  
<span style="margin-left: 2em">行以論語春秋三傳禮記家語史記諸家所載按</span>  
<span style="margin-left: 2em">歲編排體例亦如年譜其不曰年譜而曰編年尊</span>  
<span style="margin-left: 2em">聖人也自周秦之間䜟緯雜出一切詭異神怪之</span>  
<!-- 册2 葉1068b　Page:文淵閣四庫全書_0002冊.djvu/272 -->
<span style="margin-left: 2em">說率托諸孔子大抵誕謾不足信仔獨依据經傳</span>  
<span style="margin-left: 2em">補尋事實大㫖以論語爲主而附以他書其採掇</span>  
<span style="margin-left: 2em">頗爲審愼惟諸書紀錄聖言不能盡載其歲月仔</span>  
<span style="margin-left: 2em">旣限以編年不免時有牽合如左氏襄公二十一</span>  
<span style="margin-left: 2em">年鄭人游鄉校傳仲尼聞是語也云云杜預注謂</span>  
<span style="margin-left: 2em">仲尼於是十歲長而後聞之知孔子爲此言不當</span>  
<span style="margin-left: 2em">在是年也仔乃繫其事於十歲之下殊爲疎舛又</span>  
<span style="margin-left: 2em">禮記儒行篇對魯哀公云云則繫之六十八歲哀</span>  
<span style="margin-left: 2em">公問篇大禮何如云云則又繫之七十二歲不知</span>  
<!-- 册2 葉1069a　Page:文淵閣四庫全書_0002冊.djvu/272 -->
<span style="margin-left: 2em">何所據而云然此類尤失於穿鑿然由宋迄元明</span>  
<span style="margin-left: 2em">集聖蹟者其書日多亦猥雜日甚仔所論次猶爲</span>  
<span style="margin-left: 2em">近古故錄冠傳記之首以見濫觴所自焉</span>  
東家雜記二卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">宋孔傳撰傳字世文至聖四十七代孫建炎初隨</span>  
<span style="margin-left: 2em">孔端友南渡遂流寓衢州紹興中官至右朝議大</span>  
<span style="margin-left: 2em">夫知撫州軍州事兼管內勸農使封仙源縣閒國</span>  
<span style="margin-left: 2em">男是編成於紹興甲辰上卷分九類曰姓譜曰先</span>  
<span style="margin-left: 2em">聖誕辰諱日曰母顏氏曰娶元官氏曰追封諡號</span>  
<!-- 册2 葉1069b　Page:文淵閣四庫全書_0002冊.djvu/272 -->
<span style="margin-left: 2em">曰厯代崇封曰嗣襲封舜沿改曰改衍聖公曰鄉</span>  
<span style="margin-left: 2em">官下卷分十二類曰先聖廟曰手植檜曰杏壇曰</span>  
<span style="margin-left: 2em">後殿曰先聖小影曰廟栢曰廟中古碑曰本朝御</span>  
<span style="margin-left: 2em">製碑曰廟外古跡曰齊國公墓曰祖林古跡曰林</span>  
<span style="margin-left: 2em">中古碑其時去古未遠舊跡多存傳又生長仙源</span>  
<span style="margin-left: 2em">事皆目睹故所記特爲簡核前有孔子生年月日</span>  
<span style="margin-left: 2em">考異一篇末題淳祐十一年辛亥秋九月戊午朔</span>  
<span style="margin-left: 2em">去疾謹書末有南渡廟記一篇題寶祐二年二月</span>  
<span style="margin-left: 2em">甲子汝騰謹記二人宋宗室子故皆不署姓去疾</span>  
<!-- 册2 葉1072a　Page:文淵閣四庫全書_0002冊.djvu/273 -->
<span style="margin-left: 2em">稱舊有尹梅津跋此本無之而後有淳熙元年葉</span>  
<span style="margin-left: 2em">夢得跋蓋三篇皆重刻所續入也去疾考中厯駁</span>  
<span style="margin-left: 2em">諸家之誤而以爲春秋用夏正定孔子生於十月</span>  
<span style="margin-left: 2em">二十一日卒於四月十八日其說殊謬殆由是時</span>  
<span style="margin-left: 2em">理宗崇重道學胡安國傳方盛行故去疾據以爲</span>  
<span style="margin-left: 2em">說歟錢曾讀書敏求記曰壬戌冬日葉九來過芳</span>  
<span style="margin-left: 2em">草堂云有宋槧本東家雜記因假借繕寫此書爲</span>  
<span style="margin-left: 2em">先聖四十七代孫孔傳所編首列杏壇圖說記夫</span>  
<span style="margin-left: 2em">子車從出國東門因觀杏壇厯級而上顧弟子曰</span>  
<!-- 册2 葉1072b　Page:文淵閣四庫全書_0002冊.djvu/273 -->
<span style="margin-left: 2em">茲魯將臧文仲誓將之壇也覩物思人命琴而歌</span>  
<span style="margin-left: 2em">其歌曰寒暑往來春復秋夕陽西去水東流將軍</span>  
<span style="margin-left: 2em">戰馬今何在野草閑花滿地愁考諸家琴史俱失</span>  
<span style="margin-left: 2em">載附錄於此詳其語意未知果爲夫子之歌否也</span>  
<span style="margin-left: 2em">云云按此歌僞妄不辨而明曾乃語若存疑蓋其</span>  
<span style="margin-left: 2em">平生過尊宋本之失然曾云三卷此本實二卷曾</span>  
<span style="margin-left: 2em">云首列杏壇圖說此本杏壇爲下卷第三篇且有</span>  
<span style="margin-left: 2em">說無圖亦無此歌不知曾所見者又何本也其或</span>  
<span style="margin-left: 2em">誤記歟</span>  
<!-- 册2 葉1073a　Page:文淵閣四庫全書_0002冊.djvu/273 -->
<span style="margin-left: 1em">右傳記類聖賢之屬二部七巻皆文淵閣著錄</span>  
<span style="margin-left: 4em">案以上所錄皆聖蹟也以存目之中有諸賢</span>  
<span style="margin-left: 4em">之敘錄名統於一故總標曰聖賢</span>  
晏子春秋八卷<sub class="note-yuan">編修勵守謙家藏本</sub>  
<span style="margin-left: 2em">舊本題齊晏嬰撰晁公武讀書志嬰相景公此書</span>  
<span style="margin-left: 2em">著其行事及諫諍之言崇文總目謂後人採嬰行</span>  
<span style="margin-left: 2em">事爲之非嬰所撰然則是書所記乃唐人魏徵諫</span>  
<span style="margin-left: 2em">錄李絳論事集之流特失其編次者之姓名耳題</span>  
<span style="margin-left: 2em">爲嬰者依託也其中如王士禎池北偶談所摘齊</span>  
<!-- 册2 葉1073b　Page:文淵閣四庫全書_0002冊.djvu/273 -->
<span style="margin-left: 2em">景公圉人一事鄙倍荒唐殆同戯劇則妄人又有</span>  
<span style="margin-left: 2em">所<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2872.svg?width=24" alt="四庫全書僻字第2872號（竄）" title="四庫全書僻字第2872號（竄）">入非原本矣劉向班固俱列之儒家中惟柳</span>  
<span style="margin-left: 2em">宗元以爲墨子之徒有齊人者爲之其㫖多尚兼</span>  
<span style="margin-left: 2em">愛非厚葬久䘮者又往往言墨子聞其道而稱之</span>  
<span style="margin-left: 2em">薛季宣浪語集又以爲孔叢子詰墨諸條今皆見</span>  
<span style="margin-left: 2em">晏子書中則嬰之學實出於墨蓋嬰雖略在墨翟</span>  
<span style="margin-left: 2em">前而史角止魯實在惠公之時見呂氏春秋仲春</span>  
<span style="margin-left: 2em">記當染篇故嬰能先宗其說也其書自史記管晏</span>  
<span style="margin-left: 2em">列傳已稱爲晏子春秋故劉知幾史通稱晏子虞</span>  
<!-- 册2 葉1076a　Page:文淵閣四庫全書_0002冊.djvu/274 -->
<span style="margin-left: 2em">鄉吕氏陸賈其書篇第本無年月而亦謂之春秋</span>  
<span style="margin-left: 2em">然漢志惟作晏子隋志乃名春秋蓋二名兼行也</span>  
<span style="margin-left: 2em">漢志隋志皆作八篇至陳氏晁氏書目乃皆作十</span>  
<span style="margin-left: 2em">二卷蓋篇帙已多有更改矣此爲明李氏綿眇閣</span>  
<span style="margin-left: 2em">刻本內篇分諫上諫下問上問下雜上雜下六篇</span>  
<span style="margin-left: 2em">外篇分上下二篇與漢志八篇之數相合若世所</span>  
<span style="margin-left: 2em">傳烏程閔氏刻本以一事而內篇外篇複見所記</span>  
<span style="margin-left: 2em">大同小異者悉移而夾註內篇下殊爲變亂無緒</span>  
<span style="margin-left: 2em">今故仍從此本著錄庶幾猶略近古焉</span>  
<!-- 册2 葉1076b　Page:文淵閣四庫全書_0002冊.djvu/274 -->
<span style="margin-left: 4em">按晏子一書由後人摭其軼事爲之雖無傳</span>  
<span style="margin-left: 4em">記之名實傳記之祖也舊列子部今移入於</span>  
<span style="margin-left: 4em">此</span>  
魏鄭公諫錄五卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">唐王方慶撰方慶名綝以字行其先自丹陽徙咸</span>  
<span style="margin-left: 2em">陽武后時官至鸞臺侍郎同鳳閣鸞臺平章事終</span>  
<span style="margin-left: 2em">於太子左庶子封石泉縣公諡曰貞事蹟具新唐</span>  
<span style="margin-left: 2em">書本傳此書前題尚書吏部郎中蓋高宗時所居</span>  
<span style="margin-left: 2em">官本傳不載史文脫畧也傳稱方慶博學練朝章</span>  
<!-- 册2 葉1077a　Page:文淵閣四庫全書_0002冊.djvu/274 -->
<span style="margin-left: 2em">著書二百餘篇此乃所錄魏徵事蹟唐書㙯文志</span>  
<span style="margin-left: 2em">以爲魏徵諫事司馬光通鑑書目以爲魏元成故</span>  
<span style="margin-left: 2em">事標題互異惟洪邁容齋隨筆作魏鄭公諌錄與</span>  
<span style="margin-left: 2em">此相合方慶在武后時嘗以言悟主召還廬陵後</span>  
<span style="margin-left: 2em">建言不斥太子名以示復位之漸皆人所難能蓋</span>  
<span style="margin-left: 2em">亦思以伉直自見者故於徴諫爭之語摭錄最詳</span>  
<span style="margin-left: 2em">司馬光通鑑所記徵事多以是書爲依据其未經</span>  
<span style="margin-left: 2em">採錄者亦皆<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">實可信足與正史相參証元至順</span>  
<span style="margin-left: 2em">中翟思忠又嘗作續錄二卷世罕流傳明蘇州彭</span>  
<!-- 册2 葉1077b　Page:文淵閣四庫全書_0002冊.djvu/274 -->
<span style="margin-left: 2em">年採通鑑唐書補爲一巻今思忠所續錄二卷已</span>  
<span style="margin-left: 2em">於永樂大典內裒輯成編年書寥寥數條殊爲贅</span>  
<span style="margin-left: 2em">設今故刪年所補不復附綴此書之末焉</span>  
李相國論事集六卷<sub class="note-yuan">浙江孫仰曾家藏本</sub>  
<span style="margin-left: 2em">舊本題曰李深之文集唐李絳撰深之絳字也隴</span>  
<span style="margin-left: 2em">西人擢進士補渭南尉厯中書門下平章事事蹟</span>  
<span style="margin-left: 2em">具新唐書本傳今考其書乃唐史官蔣偕編絳奏</span>  
<span style="margin-left: 2em">議之文與論諫之事雖以集名實魏徵諫錄之類</span>  
<span style="margin-left: 2em">也前有大中五年偕自序稱今中執法夏侯公授</span>  
<!-- 册2 葉1080a　Page:文淵閣四庫全書_0002冊.djvu/275 -->
<span style="margin-left: 2em">余以公平生所論諫凡數十事其所爭皆磊磊有</span>  
<span style="margin-left: 2em">直臣風槪讀之令人激起忠義始自內廷終於罷</span>  
<span style="margin-left: 2em">相次成七篇著之東觀目爲李相國論事集云云</span>  
<span style="margin-left: 2em">其說本明此本標題殆後人傳寫所妄改歟偕序</span>  
<span style="margin-left: 2em">稱七篇今佚其一所存惟爲翰林學士時四十六</span>  
<span style="margin-left: 2em">事爲戸部侍郎時四事爲宰相時十五事共六十</span>  
<span style="margin-left: 2em">五條敘事朴拙頗乏文采謝狀賀表之類雜錄其</span>  
<span style="margin-left: 2em">間多與論諫無關又批答賀屏風一條宣示李栻</span>
