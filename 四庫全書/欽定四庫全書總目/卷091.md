## 欽定四庫全書總目 卷九十一　子部一　儒家類一

<!-- 册3 葉4：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷九十一  
<span style="margin-left: 1em">子部總敘</span>  
<span style="margin-left: 2em">自六經以外立說者皆子書也其初亦相淆自七</span>  
<span style="margin-left: 2em">畧區而列之名品乃定其初亦相軋自董仲舒别</span>  
<span style="margin-left: 2em">而白之醇駁乃分其中或佚不傳或傳而後莫爲</span>  
<span style="margin-left: 2em">繼或古無其目而今增古各爲𩔖而今合大都篇</span>  
<span style="margin-left: 2em">帙繁富可以自爲部分者儒家以外有兵家有法</span>  
<span style="margin-left: 2em">家有農家有醫家有天文𮅕法有術數有藝術有</span>  
<span style="margin-left: 2em">譜錄有雜家有𩔖書有小說家其别教則有釋家</span>  
<!-- 册3 葉5b　Page:文淵閣四庫全書_0003冊.djvu/6 -->
<span style="margin-left: 2em">有道家敘而次之凡十四𩔖儒家尙矣有文事者</span>  
<span style="margin-left: 2em">有武備故次之以兵家兵刑𩔖也唐虞無臯陶則</span>  
<span style="margin-left: 2em">㓂賊姦宄無所禁必不能風動時雍故次以法家</span>  
<span style="margin-left: 2em">民國之本也榖民之本也故次以農家本草經方</span>  
<span style="margin-left: 2em">技術之事也而生死繫焉神農黃帝以聖人爲天</span>  
<span style="margin-left: 2em">子尙親治之故次以醫家重民事者先授時授時</span>  
<span style="margin-left: 2em">本測候測候本積數故次以天文𮅕法以上六家</span>  
<span style="margin-left: 2em">皆治世者所有事也百家方技或有益或無益而</span>  
<span style="margin-left: 2em">其說久行理難竟廢故次以術數游藝亦學問之</span>  
<!-- 册3 葉8a　Page:文淵閣四庫全書_0003冊.djvu/7 -->
<span style="margin-left: 2em">餘事一技入神器或寓道故次以藝術以上二家</span>  
<span style="margin-left: 2em">皆小道之可觀者也詩取多識易稱制器博聞有</span>  
<span style="margin-left: 2em">取利用攸資故次以譜錄羣言岐出不名一𩔖總</span>  
<span style="margin-left: 2em">爲薈稡皆可采摭菁英故次以<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3439.svg?width=24" alt="四庫全書僻字第3439號（襍）" title="四庫全書僻字第3439號（襍）">家隸事分𩔖亦</span>  
<span style="margin-left: 2em">襍言也舊附於子部今從其例故次以𩔖書稗官</span>  
<span style="margin-left: 2em">所述其事末矣用廣見聞愈於博奕故次以小說</span>  
<span style="margin-left: 2em">家以上四家皆旁資參考者也二氏外學也故次</span>  
<span style="margin-left: 2em">以釋家道家終焉夫學者研理於經可以正天下</span>  
<span style="margin-left: 2em">之是非徴事於史可以明古今之成敗餘皆襍學</span>  
<!-- 册3 葉8b　Page:文淵閣四庫全書_0003冊.djvu/7 -->
<span style="margin-left: 2em">也然儒家木六藝之支流雖其間依草附木不能</span>  
<span style="margin-left: 2em">免門戸之私而數大儒明道立言炳然具在要可</span>  
<span style="margin-left: 2em">與經史旁叅其餘雖眞僞相雜醇疵互見然凡能</span>  
<span style="margin-left: 2em">自名一家者必有一節之足以自立卽其不合於</span>  
<span style="margin-left: 2em">聖人者存之亦可爲鑒戒雖有絲麻無棄菅蒯狂</span>  
<span style="margin-left: 2em">夫之言聖人擇焉在博收而愼取之爾</span>  
<span style="margin-left: 1em">子部一</span>  
<span style="margin-left: 2em">儒家𩔖一</span>  
<span style="margin-left: 3em">古之儒者立身行已誦法先王務以通經適用</span>  
<!-- 册3 葉9a　Page:文淵閣四庫全書_0003冊.djvu/7 -->
<span style="margin-left: 3em">而已無敢自命聖賢者王通教授河汾始摹擬</span>  
<span style="margin-left: 3em">尼山逓相標榜此亦世變之漸矣迨托克托等</span>  
<span style="margin-left: 3em">修宋史以道學儒林分爲兩傳而當時所謂道</span>  
<span style="margin-left: 3em">學者又自分二𣲖筆舌交攻自時厥後天下惟</span>  
<span style="margin-left: 3em">朱陸是爭門戸别而朋黨起恩讐報復蔓延者</span>  
<span style="margin-left: 3em">垂數百年明之末葉其禍遂及於宗社惟好名</span>  
<span style="margin-left: 3em">好勝之私心不能自克故相激而至是也聖門</span>  
<span style="margin-left: 3em">設教之意其果若是乎今所錄者大㫖以濂洛</span>  
<span style="margin-left: 3em">關閩爲宗而依附門牆藉詞衞道者則僅存其</span>  
<!-- 册3 葉9b　Page:文淵閣四庫全書_0003冊.djvu/7 -->
<span style="margin-left: 3em">目金谿姚江之𣲖亦不廢所長惟顯然以佛語</span>  
<span style="margin-left: 3em">解經者則斥人雜家凡以風示儒者無植黨無</span>  
<span style="margin-left: 3em">近名無大言而不慙無空談而鮮實則庶幾孔</span>  
<span style="margin-left: 3em">孟之正傳矣</span>  
孔子家語二十一卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">魏王肅註肅字子雍東海人官至中領軍散騎常</span>  
<span style="margin-left: 2em">侍事跡具三國志本𫝊是書肅自序云鄭氏學行</span>  
<span style="margin-left: 2em">五十載矣義理不安違錯者多是以奪而易之孔</span>  
<span style="margin-left: 2em">子二十二世孫有孔猛者家有其先人之書昔相</span>  
<!-- 册3 葉12a　Page:文淵閣四庫全書_0003冊.djvu/8 -->
<span style="margin-left: 2em">從學頃還家方取以來與子所論有若重規疊矩</span>  
<span style="margin-left: 2em">云云是此本自肅始傳也考漢書藝文志有孔子</span>  
<span style="margin-left: 2em">家語二十七卷顔師古注云非今所有家語禮樂</span>  
<span style="margin-left: 2em">記稱舜彈五<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2959.svg?width=24" alt="四庫全書僻字第2959號（弦）" title="四庫全書僻字第2959號（弦）">之琴以歌南風鄭注其詞未聞孔</span>  
<span style="margin-left: 2em">穎達疏載肅作聖證論引家語阜財解愠之詩以</span>  
<span style="margin-left: 2em">難康成又載馬昭之說謂家語王肅所增加非鄭</span>  
<span style="margin-left: 2em">所見故王柏家語考曰四十四篇之家語乃王肅</span>  
<span style="margin-left: 2em">自取左傳國語荀孟二戴記割裂織成之孔衍之</span>  
<span style="margin-left: 2em">序亦王肅自爲也獨史繩祖學齋佔畢日大戴一</span>  
<!-- 册3 葉12b　Page:文淵閣四庫全書_0003冊.djvu/8 -->
<span style="margin-left: 2em">書雖列之十四經然其書大抵雜取家語之書分</span>  
<span style="margin-left: 2em">析而爲篇目其公冠篇載成王冠祝辭内有先帝</span>  
<span style="margin-left: 2em">及陛下字周初豈曾有此家語止稱王字當以家</span>  
<span style="margin-left: 2em">語爲正云云今考陛下離顯先帝之光曜已下篇</span>  
<span style="margin-left: 2em">内已明云孝昭冠辭繩祖誤連爲祝雍之言殊未</span>  
<span style="margin-left: 2em">之考葢王肅襲取公冠篇爲冠頌巳誤合孝昭冠</span>  
<span style="margin-left: 2em">辭於成王冠辭故刪去先帝陛下字竄改王字家</span>  
<span style="margin-left: 2em">語襲大戴非大戴襲家語就此一條亦其明證其</span>  
<span style="margin-left: 2em">割裂他書亦往往類此反覆考證其出於肅手無</span>  
<!-- 册3 葉13a　Page:文淵閣四庫全書_0003冊.djvu/8 -->
<span style="margin-left: 2em">疑特其流傳旣久且遺文軼事往往多見於其中</span>  
<span style="margin-left: 2em">故自唐以來知其僞而不能廢也其書至明代傳</span>  
<span style="margin-left: 2em">本頗稀故何孟春所註家語自云未見王肅本王</span>  
<span style="margin-left: 2em">鏊震澤長語亦稱家語今本爲近世妄庸所刪削</span>  
<span style="margin-left: 2em">惟有王肅註者今本所無多具焉則亦僅見之也</span>  
<span style="margin-left: 2em">明代所傳凡二本閩徐𤊹家本中缺二十餘頁海</span>  
<span style="margin-left: 2em">虞毛晉家本稍異而首尾完全今徐本不知存佚</span>  
<span style="margin-left: 2em">此本則毛晉所校刋較之坊刻猶爲近古者矣</span>  
荀子二十卷<sub class="note-yuan">内府藏本</sub>  
<!-- 册3 葉13b　Page:文淵閣四庫全書_0003冊.djvu/8 -->
<span style="margin-left: 2em">周荀况撰况趙人嘗仕楚爲蘭陵令亦曰荀<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">漢</span>  
<span style="margin-left: 2em">人或稱曰孫<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">則以宣帝諱詢避嫌名也漢志儒</span>  
<span style="margin-left: 2em">家載荀<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">三十三篇王應麟考證謂當作三十二</span>  
<span style="margin-left: 2em">篇劉向校書序錄稱孫<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">書凡三百二十三篇以</span>  
<span style="margin-left: 2em">相校除重復二百九十篇定著三十三篇爲十二</span>  
<span style="margin-left: 2em">卷題日新書唐楊倞分易舊第編爲二十卷復爲</span>  
<span style="margin-left: 2em">之註更名荀子卽今本也考劉向序錄<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">以齊宣</span>  
<span style="margin-left: 2em">王時來游稷下後仕楚春申君死而<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">廢然史記</span>  
<span style="margin-left: 2em">六國年表載春申君之死上距宣王之末凡八十</span>  
<!-- 册3 葉16a　Page:文淵閣四庫全書_0003冊.djvu/9 -->
<span style="margin-left: 2em">七年史記稱<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">年五十始游齊則春申君死之年</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">年當一百三十七矣於理不近晁公武讀書志</span>  
<span style="margin-left: 2em">謂史記所云年五十爲年十五之訛意其或然宋</span>  
<span style="margin-left: 2em">濂荀子書後又以爲襄王時游稷下亦未詳所本</span>  
<span style="margin-left: 2em">總之戰國時人爾其生卒年月巳不可<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">考矣况</span>  
<span style="margin-left: 2em">之著書主於明周孔之教崇禮而勸學其中最爲</span>  
<span style="margin-left: 2em">口實者莫過於非十二子及性惡兩篇王應麟困</span>  
<span style="margin-left: 2em">學紀聞據韓詩外傳所引<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">但非十子而無子思</span>  
<span style="margin-left: 2em">孟子以今本爲其徒李斯等所增不知子思孟子</span>  
<!-- 册3 葉16b　Page:文淵閣四庫全書_0003冊.djvu/9 -->
<span style="margin-left: 2em">後來論定爲聖賢耳其在當時固亦<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">之曹偶是</span>  
<span style="margin-left: 2em">猶朱陸之相非不足訝也至其以性爲惡以善爲</span>  
<span style="margin-left: 2em">僞誠未免於理未融然<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">恐人恃性善之說任自</span>  
<span style="margin-left: 2em">然而廢學因言性不可恃當勉力於先王之教故</span>  
<span style="margin-left: 2em">其言曰凡性者天之所就也不可學不可事禮義</span>  
<span style="margin-left: 2em">者聖人之所生也人之所學而能所事而成者也</span>  
<span style="margin-left: 2em">不可學不可事而在人者謂之性可學而能可事</span>  
<span style="margin-left: 2em">而成之在人者謂之僞是性僞之分也其辨自僞</span>  
<span style="margin-left: 2em">字甚明楊倞註亦曰僞爲也凡非天性而人作爲</span>  
<!-- 册3 葉17a　Page:文淵閣四庫全書_0003冊.djvu/9 -->
<span style="margin-left: 2em">之者皆謂之僞故僞字人旁加爲亦會意字也其</span>  
<span style="margin-left: 2em">說亦合<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">本意後人昧於訓詁誤以爲眞僞之僞</span>  
<span style="margin-left: 2em">遂譁然掊擊謂<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">蔑視禮義如老莊之所言是非</span>  
<span style="margin-left: 2em">惟未睹其全書卽性惡一篇自篇首二句以外亦</span>  
<span style="margin-left: 2em">未竟讀矣平心而論<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">之學源出孔門在諸子之</span>  
<span style="margin-left: 2em">中最爲近正是其所長主持太甚詞義或至於過</span>
