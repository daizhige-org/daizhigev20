## 欽定四庫全書總目 卷二百　集部五十三　詞曲類存目

欽定四庫全書總目卷二百  
<span style="margin-left: 1em">集部五十三</span>  
<span style="margin-left: 2em">詞曲類存目</span>  
壽域詞一卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">宋杜安世撰安世字壽域京兆人黃昇花庵詞選</span>  
<span style="margin-left: 2em">又謂名壽域字安世未知孰是書錄解題載壽域</span>  
<span style="margin-left: 2em">詞一卷其事跡本末陳振孫巳謂未詳集内各調</span>  
<span style="margin-left: 2em">皆不載原題無可參考觀振孫列之張先詞後歐</span>  
<span style="margin-left: 2em">陽修詞前則北宋人也振孫稱其詞不甚工今核</span>  
<!-- 册5 葉1325b　Page:文淵閣四庫全書_0005冊.djvu/336 -->
<span style="margin-left: 2em">集中所載八十六闋往往失之淺俗字句尤多湊</span>  
<span style="margin-left: 2em">泊卽所載折紅梅一詞毛晉䟦指爲吳感作者通</span>  
<span style="margin-left: 2em">體皆剽竊柳永望梅詞未可謂之佳製振孫之言</span>  
<span style="margin-left: 2em">非過至菩薩蠻第二首乃南唐李後主詞鳳銜杯</span>  
<span style="margin-left: 2em">第二首乃晏殊詞惟結句增一空字爲小異晉皆</span>  
<span style="margin-left: 2em">未注晉所稱訴衷情一首見於花庵詞選者僅附</span>  
<span style="margin-left: 2em">載䟦中亦未補入集内字句訛脫尤不一而足首</span>  
<span style="margin-left: 2em">尾僅二十餘紙舛謬不可勝乙晉殆亦忽視其詞</span>  
<span style="margin-left: 2em">漫不一校耶</span>  
<!-- 册5 葉1328a　Page:文淵閣四庫全書_0005冊.djvu/337 -->
後山詞一卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">宋陳師道撰師道有後山叢談已著錄其詩餘一</span>  
<span style="margin-left: 2em">卷已附載集中考陳振孫書錄解題載後山詞一</span>  
<span style="margin-left: 2em">卷宋史藝文志則稱爲語業一卷而魏衍作師道</span>  
<span style="margin-left: 2em">集記但及叢談理究不及其詞知宋時本集外別</span>  
<span style="margin-left: 2em">行也胡仔漁隱叢話述師道自矜語謂於詞不減</span>  
<span style="margin-left: 2em">秦七黃九今觀其漁家傲詞有云擬作新詞酬帝</span>  
<span style="margin-left: 2em">力輕落筆黃秦去後無强敵云云自<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3688.svg?width=24" alt="四庫全書僻字第3688號（負）" title="四庫全書僻字第3688號（負）">良爲不淺</span>  
<span style="margin-left: 2em">然師道詩㝠心孤詣自是北宋巨擘至强囘筆端</span>  
<!-- 册5 葉1328b　Page:文淵閣四庫全書_0005冊.djvu/337 -->
<span style="margin-left: 2em">倚聲度曲則非所擅長如贈晁補之歌鬟之類殊</span>  
<span style="margin-left: 2em">不多見其詩話謂曾子開秦少游詩如詞而不自</span>  
<span style="margin-left: 2em">知詞如詩葢人各有能有不能固不必事事第一</span>  
<span style="margin-left: 2em">也</span>  
哄堂詞一卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">宋盧炳撰炳字叔陽其履貫未詳時代亦無可考</span>  
<span style="margin-left: 2em">陳振孫書錄解題列詞集九十二家而總注其後</span>  
<span style="margin-left: 2em">曰自南唐二主詞以下皆長沙書坊所刻號百家</span>  
<span style="margin-left: 2em">詞其最末一家爲郭應祥振孫稱嘉定間人則諸</span>  
<!-- 册5 葉1329a　Page:文淵閣四庫全書_0005冊.djvu/337 -->
<span style="margin-left: 2em">人皆在寧宗以前炳詞次序猶在侯寘詞後寘紹</span>  
<span style="margin-left: 2em">興中知建康則炳亦南渡後人集中有庚戌正月</span>  
<span style="margin-left: 2em">字庚戌爲建炎四年故集中諸詞多用周邦彥韻</span>  
<span style="margin-left: 2em">其時代適相接也其集書錄解題本作哄堂詞毛</span>  
<span style="margin-left: 2em">晉刊本則作烘堂按唐趙璘因話錄御史院合座</span>  
<span style="margin-left: 2em">俱笑謂之哄堂炳葢謙言博笑故以爲名若作烘</span>  
<span style="margin-left: 2em">堂於義無取知晉所刊爲誤炳葢嘗仕州縣故多</span>  
<span style="margin-left: 2em">同官倡和之詞然其同官無一知名士其頌祝諸</span>  
<span style="margin-left: 2em">作亦俱庸下至於武陵春之以老叶頭水龍吟之</span>  
<!-- 册5 葉1329b　Page:文淵閣四庫全書_0005冊.djvu/337 -->
<span style="margin-left: 2em">以斗奏叶表淸平樂之以皺叶好笑雖古韻木通</span>  
<span style="margin-left: 2em">而詞家無用古韻之例亦爲破格他若賀新郎之</span>  
<span style="margin-left: 2em">問天公底事敎幽獨待拉向錦屏曲玉圑兒之把</span>  
<span style="margin-left: 2em">不定紅生臉肉驀山溪之鞭寶馬閙竿隨簇著花</span>  
<span style="margin-left: 2em">藤轎皆鄙俚不文有乖雅調惟詠物諸作尙細膩</span>  
<span style="margin-left: 2em">熨貼間有可觀耳</span>  
近體樂府一卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">宋周必大撰必大有玉堂雜記已著錄此編凡詞</span>  
<span style="margin-left: 2em">十二闋已編入文忠集中此乃毛晉摘錄之本刻</span>  
<!-- 册5 葉1332a　Page:文淵閣四庫全書_0005冊.djvu/338 -->
<span style="margin-left: 2em">於六十家詞中者也題下所註甲子其可數者自</span>  
<span style="margin-left: 2em">丁亥至庚寅大約不出四歲中所作疑當周綸編</span>  
<span style="margin-left: 2em">次全集時已掇拾於散佚之餘非其完本矣</span>  
金谷遺音一卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">宋石孝友撰孝友字次仲南昌人乾道中進士其</span>  
<span style="margin-left: 2em">著作世不多見釣臺集載其七言絶句一首亦無</span>  
<span style="margin-left: 2em">可採錄其詞則至今猶傳書錄解題載孝友金谷</span>  
<span style="margin-left: 2em">遺音一卷與此本合其詞長調以端莊爲主小令</span>  
<span style="margin-left: 2em">以輕倩爲工而長調類多獻諛之作小令亦間近</span>  
<!-- 册5 葉1332b　Page:文淵閣四庫全書_0005冊.djvu/338 -->
<span style="margin-left: 2em">於俚俗毛晉䟦黃機詞恨草堂詩餘不載機及孝</span>  
<span style="margin-left: 2em">友一篇䟦孝友詞又獨稱其茶瓶兒惜奴嬌諸篇</span>  
<span style="margin-left: 2em">爲輕倩纎麗今考茶瓶兒結句云而今若没些兒</span>  
<span style="margin-left: 2em">事却枉了做人一世惜奴嬌前一闋云我已多情</span>  
<span style="margin-left: 2em">更撞著多情底你後一闋云𡨚家你敎我如何割</span>  
<span style="margin-left: 2em">捨𡨚家休直待敎人呪罵直是市井俚談而晉乃</span>  
<span style="margin-left: 2em">特激賞之反置其佳者於不論其爲顚倒更在草</span>  
<span style="margin-left: 2em">堂詩餘下矣又楊愼詞品極稱孝友多麗一闋此</span>  
<span style="margin-left: 2em">集不載詳考其詞乃張翥所作愼偶誤記今附辨</span>  
<!-- 册5 葉1333a　Page:文淵閣四庫全書_0005冊.djvu/338 -->
<span style="margin-left: 2em">於此不復据以補入焉</span>

<span style="margin-left: 2em">宋姜䕫撰䕫有絳帖平已著錄是集爲康熙甲午</span>  
<span style="margin-left: 2em">陳撰所刻附於詩集之後凡五十八闋較毛晉汲</span>  
<span style="margin-left: 2em">古閣本多二十四闋然其中多意爲刪竄非其舊</span>

<span style="margin-left: 2em">毛本有十六夜出四字憶王孫題下毛本有鄱陽</span>  
<!-- 册5 葉1333b　Page:文淵閣四庫全書_0005冊.djvu/338 -->

<span style="margin-left: 2em">又註促織二字鬲溪梅令毛本註曰仙吕調此本</span>  
<span style="margin-left: 2em">乃訛作高溪梅又訛註爲仙宫調湘月一首毛本</span>  
<span style="margin-left: 2em">題下註卽念奴嬌之鬲指聲也文義甚明此本乃</span>  
<span style="margin-left: 2em">以鬲指二字爲調名註曰一名湘月皆謬戾無理</span>  
<span style="margin-left: 2em">其中咏草<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3295.svg?width=24" alt="四庫全書僻字第3295號（㸃）" title="四庫全書僻字第3295號（㸃）">絳唇一闋撰䟦稱復見於逋翁集中</span>
