## 欽定四庫全書總目 卷五十四　史部十　雜史類存目三

<!-- 册2 葉805a　Page:文淵閣四庫全書_0002冊.djvu/206 -->
欽定四庫全書總目巻五十四  
<span style="margin-left: 1em">史部十</span>  
<span style="margin-left: 2em">雜史𩔖存目三</span>  
平播始末二巻<sub class="note-yuan">江西巡撫採進本</sub>  
<span style="margin-left: 2em">明郭子章撰子章有蠙衣生易解已著錄萬厯間</span>  
<span style="margin-left: 2em">播州宣慰使楊應龍叛子章方巡撫貴州被命與</span>  
<span style="margin-left: 2em">李化龍同討平之化龍有平播全書備錄前後進</span>  
<span style="margin-left: 2em">勦機宜子章亦嘗有黔記頗載其事晩年退休家</span>  
<span style="margin-left: 2em">居聞一二武弁造作平話<sub class="note-yuan">案永樂大典有平話一門所收至夥皆優人以</sub></span>  
<!-- 册2 葉805b　Page:文淵閣四庫全書_0002冊.djvu/206 -->
<span style="margin-left: 2em"><sub class="note-yuan">前代軼事衍爲俗語而口說之</sub>左袒化龍飾張功績多乖事實乃</span>  
<span style="margin-left: 2em">倣紀事本末之例以諸奏疏稍加詮次復爲此書</span>  
<span style="margin-left: 2em">以辨其誣</span>  
平播全書十五卷<sub class="note-yuan">副都御史黃登賢家藏本</sub>  
<span style="margin-left: 2em">明李化龍撰化龍字于田長垣人萬厯甲戌進士</span>  
<span style="margin-left: 2em">厯官兵部尙書諡襄毅事蹟具明史本傳播州楊</span>  
<span style="margin-left: 2em">氏自唐乾符中據有其地厯二十九世八百餘年</span>  
<span style="margin-left: 2em">萬厯初楊應龍爲宜慰使恃險作亂詔起化龍巡</span>  
<span style="margin-left: 2em">撫四川尋進總督四川湖廣貴州軍務進討平之</span>  
<!-- 册2 葉808a　Page:文淵閣四庫全書_0002冊.djvu/207 -->
<span style="margin-left: 2em">以其地置遵義平越二府因裒軍中前後文牘編</span>  
<span style="margin-left: 2em">爲是書前五巻爲進軍時奏疏六巻爲善後事宜</span>  
<span style="margin-left: 2em">奏疏七巻爲咨文八巻至十一巻爲牌票十二巻</span>  
<span style="margin-left: 2em">至十四巻爲書札十五巻爲評批爲祭文</span>  
<span style="margin-left: 4em">案此書雖載文而不紀事然其文全爲平定</span>  
<span style="margin-left: 4em">播州而作實具斯一事之始末其載文卽紀</span>  
<span style="margin-left: 4em">事也又雖冠以奏議而僅三之一不可入奏</span>  
<span style="margin-left: 4em">議雖出一人之手而大抵書記吏胥之所爲</span>  
<span style="margin-left: 4em">不可以入别集故從其本事入之雜史𩔖焉</span>  
<!-- 册2 葉808b　Page:文淵閣四庫全書_0002冊.djvu/207 -->
建文朝野彚編二十卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">明屠叔方撰叔方秀水人萬厯丁丑進士官至監</span>  
<span style="margin-left: 2em">察御史其書分遜國編年遜國列傳建文傳紀建</span>  
<span style="margin-left: 2em">文定論諸目葢雜採野史傳聞之說裒合成編大</span>  
<span style="margin-left: 2em">抵沿襲訛傳不爲信史至摭典故輯遺之謬說謂</span>  
<span style="margin-left: 2em">宣宗爲惠帝之子尤無忌憚矣</span>  
明祖四大法十二巻<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明陳棟如撰棟如字子極無錫人萬厯戊戌進士</span>  
<span style="margin-left: 2em">官至太僕寺少卿事迹附見明史馮應京傳是書</span>  
<!-- 册2 葉809a　Page:文淵閣四庫全書_0002冊.djvu/207 -->
<span style="margin-left: 2em">乃其自襄陽推官下獄釋歸時所輯以明太祖事</span>  
<span style="margin-left: 2em">實分心法治法祀法兵法四門皆於寶訓實錄中</span>  
<span style="margin-left: 2em">擇其有關政體者分條𩔖載葢本宋濂聖政記而</span>  
<span style="margin-left: 2em">擴充之然配𨽻多未切合詳畧亦往往失中不足</span>  
<span style="margin-left: 2em">以資檢核也</span>  
肅皇外史四十六巻<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明范守已撰守已字介儒洧川人萬厯甲戌進士</span>  
<span style="margin-left: 2em">官至按察司僉事是編紀明世宗一代朝政編年</span>  
<span style="margin-left: 2em">系月立綱分目頗見詳備而時近𤨏碎不合史體</span>  
<!-- 册2 葉809b　Page:文淵閣四庫全書_0002冊.djvu/207 -->
<span style="margin-left: 2em">當時南京書坊嘗刻其節本附雷禮大政記以行</span>  
<span style="margin-left: 2em">此則其全書也</span>  
聖典二十四巻<sub class="note-yuan">山東巡撫採進本</sub>  
<span style="margin-left: 2em">明朱睦㮮撰睦㮮有易學識遺已著錄是書紀太</span>  
<span style="margin-left: 2em">祖開國事蹟分八十一目仿貞觀政要之體視宋</span>  
<span style="margin-left: 2em">濓洪武聖政紀所載較詳</span>  
倭患考原二巻<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明黃俁卿撰自題曰閩人其始末未詳俁卿以嘉</span>  
<span style="margin-left: 2em">隆間福建瀕海郡縣嘗被倭患故爲是書以推其</span>  
<!-- 册2 葉812a　Page:文淵閣四庫全書_0002冊.djvu/208 -->
<span style="margin-left: 2em">致禍之由上卷溯洪武初年遣使通倭終萬厯初</span>  
<span style="margin-left: 2em">廣賊林鳳之亂下巻恤援朝鮮則紀宋應昌楊鎬</span>  
<span style="margin-left: 2em">東征事也巻末附以倭俗考其中所載閩事居多</span>  
<span style="margin-left: 2em">草野傳聞殊爲簡畧</span>  
典故紀聞十八巻<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">明余繼登撰繼登字世用號雲衢交河人萬厯丁</span>  
<span style="margin-left: 2em">丑進士官至禮部尙書諡文恪事蹟具明史本傳</span>  
<span style="margin-left: 2em">是編雜記前朝故事自洪武迄於隆慶然其帝曰</span>  
<span style="margin-left: 2em">云云之屬多屬空談大抵皆記注實錄潤色之詞</span>  
<!-- 册2 葉812b　Page:文淵閣四庫全書_0002冊.djvu/208 -->
<span style="margin-left: 2em">亦頗及𤨏屑雜事不盡關乎政要如太祖攻婺城</span>  
<span style="margin-left: 2em">時見五色雲無論其事眞僞總不在法戒之列又</span>  
<span style="margin-left: 2em">如成祖時靈邱民一産三男有司議給廪至八歲</span>  
<span style="margin-left: 2em">成祖命給至十歲亦細故不足毛舉也</span>  
使琉球錄二巻<sub class="note-yuan">浙江汪啓淑家藏本</sub>  
<span style="margin-left: 2em">明蕭崇業謝𤇍同撰崇業雲南臨安衞人隆慶辛</span>  
<span style="margin-left: 2em">未進士官至右僉都御史提督操江𤇍長樂人萬</span>  
<span style="margin-left: 2em">厯甲戌進士官至戸部尙書總督倉塲萬厯七年</span>  
<span style="margin-left: 2em">崇業爲戸科給事中𤇍爲行人司行人奉使往封</span>  
<!-- 册2 葉813a　Page:文淵閣四庫全書_0002冊.djvu/208 -->
<span style="margin-left: 2em">琉球國世子尙永爲中山王是年六月渡海抵其</span>  
<span style="margin-left: 2em">國十月還閩因記其行事儀節及琉球山川風俗</span>  
<span style="margin-left: 2em">爲此書大抵本嘉靖十三年陳侃四十年郭世霖</span>  
<span style="margin-left: 2em">二錄而稍潤益之明史藝文志載謝𤇍使琉球錄</span>  
<span style="margin-left: 2em">六巻此本止分上下二卷檢勘並無闕佚殆六字</span>  
<span style="margin-left: 2em">爲傳寫之誤歟</span>  
乙未私志一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明余寅撰案明有兩余寅其一字仲房歙縣人與</span>  
<span style="margin-left: 2em">徐渭沈明臣俱入胡宗憲幕中明史附見徐渭傳</span>  
<!-- 册2 葉813b　Page:文淵閣四庫全書_0002冊.djvu/208 -->
<span style="margin-left: 2em">中此余寅鄞縣人本字君房晩年改字僧杲萬厯</span>  
<span style="margin-left: 2em">庚辰進士官至太常寺少卿萬厯二十三年乙未</span>  
<span style="margin-left: 2em">冬帝以軍政失察貶科道官三十餘人九卿力諫</span>  
<span style="margin-left: 2em">不納旣而惡大學士陳于陛論救復命改謫遠方</span>  
<span style="margin-left: 2em">吏部尙書孫丕揚等再抗疏諫帝益怒盡除其名</span>  
<span style="margin-left: 2em">寅因作此書紀其本末及貶削諸臣姓名案明史</span>  
<span style="margin-left: 2em">陳于陛傳載此事作兩都言官而孫丕揚傳則作</span>  
<span style="margin-left: 2em">南京言官微有不同據寅所記乃北京科道耿隨</span>  
<span style="margin-left: 2em">龍等南京科道伍文煥等與于陛傳相合知丕揚</span>  
<!-- 册2 葉816a　Page:文淵閣四庫全書_0002冊.djvu/209 -->
<span style="margin-left: 2em">傳中南字以與兩字形似而訛也</span>  
馭倭錄九卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明王士騏撰士騏字冏伯太倉人尚書世貞子萬</span>  
<span style="margin-left: 2em">厯乙丑進士官至吏部員外郞坐妖書逮獄削籍</span>  
<span style="margin-left: 2em">明史文苑傳附載世貞傳末是編乃其爲兵部主</span>  
<span style="margin-left: 2em">事時採明一代倭冦事蹟起洪武元年訖萬厯二</span>  
<span style="margin-left: 2em">十四年凡當時所奉詔㫖及諸臣章奏並中外戰</span>  
<span style="margin-left: 2em">守方畧按年編紀本末頗具自序以爲薛浚考畧</span>  
<span style="margin-left: 2em">王文光補遺鄭若曾籌海圖編多取野史爲証往</span>  
<!-- 册2 葉816b　Page:文淵閣四庫全書_0002冊.djvu/209 -->
<span style="margin-left: 2em">往失眞故所錄皆就國史中拈出然當時奏報亦</span>  
<span style="margin-left: 2em">多掩敗爲功欺蔽𫎇飾國史所載正未必盡爲實</span>  
<span style="margin-left: 2em">錄也</span>  
建文書法儗五巻<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">明朱鷺撰鷺字白民吳縣人其書作於萬厯乙未</span>  
<span style="margin-left: 2em">詔復革除年號之時葢欲上之於朝以補國史故</span>  
<span style="margin-left: 2em">稱曰儗而署名自稱曰臣其書前編一卷紀惠帝</span>  
<span style="margin-left: 2em">初生至爲太孫時事正編二巻記惠帝在位四年</span>  
<span style="margin-left: 2em">事體例全倣朱子通鑑綱目附編二巻則雜錄明</span>  
<!-- 册2 葉817a　Page:文淵閣四庫全書_0002冊.djvu/209 -->
<span style="margin-left: 2em">人之論述巻首冠以頌聖德十條紀明厯朝恕待</span>  
<span style="margin-left: 2em">惠帝君臣之㫖述公論六條紀厯朝請復革除年</span>  
<span style="margin-left: 2em">號之奏章儗書法十六條則自敘其紀事之例其</span>  
<span style="margin-left: 2em">論惠帝之失惟在削宗藩變祖制持論未嘗不正</span>  
<span style="margin-left: 2em">惟行遯從亡尚沿舊說又成祖未卽位以前削帝</span>  
<span style="margin-left: 2em">稱王於義雖當然不宜出於明之臣子至序末題</span>  
<span style="margin-left: 2em">識一條稱萬厯甲午夢明太祖示以一朝表譜四</span>  
<span style="margin-left: 2em">金字次日具奏焚孝陵下復夢太祖召見則幾於</span>  
<span style="margin-left: 2em">妖言矣</span>  
<!-- 册2 葉817b　Page:文淵閣四庫全書_0002冊.djvu/209 -->
繩武編三十四巻<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">明吳瑞登撰瑞登有兩朝憲章錄已著錄是編成</span>  
<span style="margin-left: 2em">於萬厯壬辰以洪武至隆慶事迹分𩔖編輯其例</span>  
<span style="margin-left: 2em">一依眞德秀大學衍義凡四大綱一曰格致二曰</span>  
<span style="margin-left: 2em">誠正三曰修身四曰齊家爲目十有二又分子目</span>  
<span style="margin-left: 2em">五十然明自太祖開創之初已多過舉成祖簒立</span>  
<span style="margin-left: 2em">虐焰横扇英宗以下亦瑕多瑜少至世宗穆宗善</span>  
<span style="margin-left: 2em">政不及十之一稗政逾於十之九矣瑞登乃臚列</span>  
<span style="margin-left: 2em">虚詞使與古帝王嫓美雖臣子之體宜然然非事</span>  
<!-- 册2 葉820a　Page:文淵閣四庫全書_0002冊.djvu/210 -->
<span style="margin-left: 2em">實也至於法戒並存在德秀編錄前代史書自無</span>  
<span style="margin-left: 2em">不可瑞登乃舉厯朝之失昌言排擊孔子諱内之</span>  
<span style="margin-left: 2em">謂何是又併非臣子之體矣此所謂進退無據也</span>  
北樓日記二巻<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">不著撰人名氏考明史神宗本紀萬厯二十年寧</span>  
<span style="margin-left: 2em">夏致仕副總兵哱拜殺巡撫都御史党馨副使石</span>  
<span style="margin-left: 2em">繼芳據城反此書卽記其事北樓者寧夏鎭城樓</span>  
<span style="margin-left: 2em">賊所據以爲變者故以名編所載自正月己丑始</span>  
<span style="margin-left: 2em">亂至九月辛未平賊按日繫事頗爲詳悉其中月</span>  
<!-- 册2 葉820b　Page:文淵閣四庫全書_0002冊.djvu/210 -->
<span style="margin-left: 2em">日先後往往與史不合如賊聚衆殺馨縱獄囚焚</span>  
<span style="margin-left: 2em">案牘在二月戊申而史作三月戊辰總督魏學曾</span>  
<span style="margin-left: 2em">下檄安撫在二月壬子而史作三月壬申河套諸</span>
