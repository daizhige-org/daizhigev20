<span style="margin-left: 2em">順治十二年</span>

<span style="margin-left: 2em">治天下者治臣民而已矣使百官咸禔躬飭行以</span>  
<span style="margin-left: 2em">奉其職守萬姓咸講讓型仁以厚其風俗則唐虞</span>

世宗憲皇帝推繹  
聖謨以垂範奕世者也粤稽虞代命契爲司徒敬敷五教  
<span style="margin-left: 2em">當時必有誥誡之文今佚不可考周禮州長正月</span>  
<span style="margin-left: 2em">之吉各屬其州之民而讀法以考其德行道蓺而</span>  
<span style="margin-left: 2em">勸之糾其過惡而戒之又族師月吉則屬民而讀</span>  
<span style="margin-left: 2em">教法書其孝弟睦婣有學者其法今亦不傳然而</span>  
<span style="margin-left: 2em">聖帝明王膺作君作師之任其啟迪愚䝉必反覆</span>  
<!-- 册3 葉252b　Page:文淵閣四庫全書_0003冊.djvu/68 -->
<span style="margin-left: 2em">丁寧申以文告則其制章章可考故書稱皇極之</span>  
<span style="margin-left: 2em">敷言是𢑴是訓于帝其訓也惟是厯代以來如家</span>  
<span style="margin-left: 2em">訓世範之類率儒者私教於一家琴堂諭俗編之</span>  
<span style="margin-left: 2em">𩔖亦守令自行於一邑罕聞九重揮翰爲愚夫愚</span>  
<span style="margin-left: 2em">婦特撰一編獨明太祖所著資治通訓諸書具載</span>  
<span style="margin-left: 2em">永樂大典中而義或不醇詞或不雅世亦無述焉</span>  
<span style="margin-left: 2em">洪惟我</span>  
聖祖仁皇帝體  
天牖下民之意

<span style="margin-left: 2em">乾隆元年</span>

皇上取舊制各體文刪擇精要得二百六十則𨤲爲四  
<span style="margin-left: 2em">卷第一卷論帝王治化之要第二卷論天人性命</span>  
<span style="margin-left: 2em">之旨第三卷論禮樂法度之用第四卷論古今得</span>  
<span style="margin-left: 2em">失之迹考三代以前帝王訓誡多散見諸子百家</span>  
<span style="margin-left: 2em">中眞贋相叅不盡可據漢書所載黃帝以下諸目</span>  
<span style="margin-left: 2em">班固已注爲依託亦不足憑惟所載高帝八篇文</span>  
<span style="margin-left: 2em">帝十二篇爲帝王御製著錄儒家之始今其書不</span>

<span style="margin-left: 2em">作盛陳華藻而已帝王之學則必歸於傳心之要</span>  
<span style="margin-left: 2em">義儒生所論說高談性命而已帝王之學則必徴</span>  
<span style="margin-left: 2em">諸經世之實功故必以聖人之德居天子之位而</span>  
<span style="margin-left: 2em">後吐詞爲經足以垂萬世之訓也我</span>  
皇上亶聰首出念典彌勤紬繹舊聞發揮新得所謂爲  
<span style="margin-left: 2em">天地立心爲生民立命爲往聖繼絶學爲萬世開</span>  
<span style="margin-left: 2em">太平者具備於斯迄今太和翔洽</span>  
久道化成無逸作所之心與天行同其不息而百度修

<span style="margin-left: 2em">明八紘砥屬</span>  
天聲赫濯尤簡册之所未聞豈非内聖外王之道文經  
<span style="margin-left: 2em">武緯之原一一早握其樞要歟臣等校錄鴻編循</span>

<span style="margin-left: 2em">謹案是書爲順治十三年奉</span>  
勅所修至康熙二十一年告成  
<!-- 册3 葉257a　Page:文淵閣四庫全書_0003冊.djvu/69 -->

<span style="margin-left: 2em">衍義首冠以衍經之序述經之旨二篇不入卷數</span>  
<span style="margin-left: 2em">次衍至德之義以五常分五子目次衍要道之義</span>  
<span style="margin-left: 2em">以五倫分五子目次衍教所由生之義以禮樂政</span>  
<span style="margin-left: 2em">刑分四子目次天子之孝以愛親敬親爲綱愛親</span>  
<span style="margin-left: 2em">分子目十二敬親分子目十四次諸侯之孝分子</span>  
<span style="margin-left: 2em">目四次卿大夫之孝分子目五次士之孝分子目</span>  
<span style="margin-left: 2em">四次庶人之孝分子目三亦皆以愛親敬親爲首</span>  
<span style="margin-left: 2em">末二卷以大順之徴終焉大旨以一心一理推而</span>

<span style="margin-left: 2em">廣之貫通乎萬事萬物自上以及下篤近而舉遠</span>  
<span style="margin-left: 2em">源流本末無所不賅而於天子之孝推演尤詳凡</span>  
<span style="margin-left: 2em">例謂經稱先王以發端明是爲君天下之天子陳</span>  
<span style="margin-left: 2em">孝道也誠得孔曾授受之本旨矣眞德秀大學衍</span>

<span style="margin-left: 2em">順治十三年</span>  
世祖章皇帝御定冠以  
御製序文以禮記内則篇爲本援引經史諸書以佐證推  
<span style="margin-left: 2em">闡之分八綱三十二子目一曰孝之道分事舅姑</span>  
<span style="margin-left: 2em">事父母二子目二曰敬之道分事夫勸學佐忠贊</span>  
<span style="margin-left: 2em">廉重賢五子目三曰教之道分教子勉學訓忠三</span>  
<span style="margin-left: 2em">子目四曰禮之道分敬祭祀肅家政定變守貞殉</span>  
<span style="margin-left: 2em">節端好尙崇儉約謹言愼儀九子目五曰讓之道</span>  
<span style="margin-left: 2em">分崇謙退和妯娌睦宗族待外戚四子目六曰慈</span>

<span style="margin-left: 2em">之道分逮下慈㓜敦仁愛民宥過五子目七曰勤</span>  
<span style="margin-left: 2em">之道分女工飲食二子目八曰學之道分好學著</span>  
<span style="margin-left: 2em">書二子目考古西周盛運化起宫闈周南始關雎</span>  
<span style="margin-left: 2em">而桃夭漢廣丕變乎民風召南始鵲巢而采蘋采</span>  
<span style="margin-left: 2em">蘩具嫻乎禮教蓋正其家而天下正天下各正其</span>  
<span style="margin-left: 2em">家而風俗淳美民物泰平故先王治世必以内政</span>  
<span style="margin-left: 2em">爲本也此編出自</span>  
聖裁用以端人倫之始握風化之原疏通經義使知所遵  
<span style="margin-left: 2em">循引證史文使有所法戒用以修明閫教永著典</span>

<span style="margin-left: 3em">誡以下區區爝火之明又何足仰擬日月歟</span>

<span style="margin-left: 3em">康熙五十六年</span>  
聖祖仁皇帝御定初朱子門人陳淳撰性理字義熊剛大  
<span style="margin-left: 2em">又撰性理羣書性理之名由是而起明永樂中遂</span>  
<span style="margin-left: 2em">命胡廣等雜鈔宋儒之語湊泊成編名曰性理大</span>  
<span style="margin-left: 2em">全書與五經四書大全同頒於天下列在學官然</span>  
<span style="margin-left: 2em">廣等以斗筲下才濫膺編錄所纂五經四書大全</span>  
<!-- 册3 葉261b　Page:文淵閣四庫全書_0003冊.djvu/70 -->
<span style="margin-left: 2em">並剽竊坊刻講章改竄姓名苟充卷帙<sub class="note-yuan">語詳各本條下</sub>其</span>  
<span style="margin-left: 2em">性理大全書尤龎雜割裂徒以多爲貴無復體裁</span>  
<span style="margin-left: 3em">我</span>  
聖祖仁皇帝接唐虞之治統契孔孟之心傳原本六經  
權衡百氏凡宋儒論著於其見道之淺深立言之醇駁並  
<span style="margin-left: 2em">究知微曖坐照無遺病胡廣等所編徒博講學之</span>  
<span style="margin-left: 3em">名不過循聲之舉支離冗碎貽誤後來乃</span>  
命大學士李光地等刋正其書復  
親加𨤲定如蔡沈洪範數之𩔖旣斥之以防僣擬所附詩  
<!-- 册3 葉264a　Page:文淵閣四庫全書_0003冊.djvu/71 -->
<span style="margin-left: 2em">賦之𩔖亦削之以戒浮文其餘諸門皆精汰嚴收</span>  
<span style="margin-left: 2em">十分取一卷帙雖減於前而義藴之宏深别裁之</span>  
<span style="margin-left: 2em">精密以較原書司空圖所謂如礦出金也羣言淆</span>  
<span style="margin-left: 2em">亂折諸</span>  
聖豈不信歟  
御纂朱子全書六十六卷  
<span style="margin-left: 2em">康熙五十二年</span>

<span style="margin-left: 2em">於朱子咸淳中黎靖德刪除重複編爲一集尙得</span>

<span style="margin-left: 1em">國朝雷鋐撰鋐字貫一寧化人雍正癸丑進士官至</span>  
<span style="margin-left: 2em">副都御史是編乃其讀書劄記大旨惟以朱子爲</span>  
<span style="margin-left: 2em">宗然能不爭競門戸如巻一中一條云古人心最</span>

<span style="margin-left: 2em">耶其持論特平較諸講學之家侈談存理遏欲而</span>
