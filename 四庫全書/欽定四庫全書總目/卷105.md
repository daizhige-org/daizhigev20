<span style="margin-left: 1em">子部十五</span>  
<span style="margin-left: 2em">醫家𩔖存目</span>  
素問運氣圖括定局立成一卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明熊宗立撰宗立字道軒建陽人劉剡之門人也</span>  
<span style="margin-left: 2em"><sub class="note-yuan">剡永樂中人有四書通義巳著錄</sub>好講隂陽醫卜之術是書以素</span>  
<span style="margin-left: 2em">問五運六氣之說編爲歌辭又有天符歲會之說</span>  
<span style="margin-left: 2em">以人生年之甲子觀其得病之日氣運盛衰決其</span>  
<span style="margin-left: 2em">生死醫家未有用其法者葢本五運六氣以生尅</span>  
<!-- 册3 葉1017b　Page:文淵閣四庫全書_0003冊.djvu/259 -->
<span style="margin-left: 2em">制化推其王相休囚而巳初無所徵騐也</span>  
素問鈔補正十二卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">明丁瓚編瓉字㸃白鎭江人嘉靖丁丑進士官至</span>  
<span style="margin-left: 2em">温州府知府初滑壽著素問鈔歲久傳寫多訛瓚</span>  
<span style="margin-left: 2em">因其舊本重爲補正復兼采王冰原注以明之凡</span>  
<span style="margin-left: 2em">十二門悉依壽書舊例又以五運六氣主客圖并</span>  
<span style="margin-left: 2em">診家樞要附於後</span>  
續素問鈔九卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明汪機撰機有針灸問對巳著錄是編因滑壽素</span>  
<!-- 册3 葉1020a　Page:文淵閣四庫全書_0003冊.djvu/260 -->
<span style="margin-left: 2em">問鈔采王冰原註太畧因重爲補錄凡所增入以</span>  
<span style="margin-left: 2em">續字别之九卷之中分上中下三部上四卷中一</span>  
<span style="margin-left: 2em">卷下四卷其標目悉依滑氏之舊</span>  
素問註證𤼵微九卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">明馬蒔撰蒔字仲化會稽人其說據漢志内經十</span>  
<span style="margin-left: 2em">八篇之文以素問九卷靈樞九卷當之復引離合</span>  
<span style="margin-left: 2em">眞邪論中九鍼九篇因而九之之文定爲九九八</span>  
<span style="margin-left: 2em">十一篇以唐王冰分二十四卷爲誤殊非大㫖所</span>  
<span style="margin-left: 2em">闗其註亦無所𤼵明而於前人著述多所訾議過</span>  
<!-- 册3 葉1020b　Page:文淵閣四庫全書_0003冊.djvu/260 -->
<span style="margin-left: 2em">矣</span>  
素問懸解十三卷<sub class="note-yuan">編修周永年家藏本</sub>  
朝國朝黄元御撰元御有周易懸象巳著錄是書謂素  
<span style="margin-left: 2em">問八十一篇秦漢以後始著竹帛傳寫屢更不無</span>  
<span style="margin-left: 2em">錯亂因爲參互校正如本病論刺志論刺法論舊</span>  
<span style="margin-left: 2em">本皆謂巳亡元御則謂本病論在玉機眞藏論中</span>  
<span style="margin-left: 2em">刺志論則誤入診要經中論刺法論則誤入通評</span>  
<span style="margin-left: 2em">虚實論未嘗亡也又謂經絡論乃脾部論之後半</span>  
<span style="margin-left: 2em">篇脾部論乃十二正經經絡論之正文如此則三</span>  
<!-- 册3 葉1021a　Page:文淵閣四庫全書_0003冊.djvu/260 -->
<span style="margin-left: 2em">竒經與氣府論之前論正經後論竒經三脈無異</span>  
<span style="margin-left: 2em">故取以補闕仍復八十一篇之舊考言經文錯簡</span>  
<span style="margin-left: 2em">者起於劉向之校尙書<sub class="note-yuan">見漢書藝文志</sub>猶有古文可據也</span>  
<span style="margin-left: 2em">疑經文脫簡者始於鄭元之註玉藻<sub class="note-yuan">見禮記註</sub>然猶不</span>  
<span style="margin-left: 2em">敢移其次第至北宋以後始各以巳意改古書有</span>  
<span style="margin-left: 2em">所不通輙言錯簡六經遂幾無完本餘波所漸劉</span>  
<span style="margin-left: 2em">夢鵬以此法說楚詞迨元御此註併以此法說醫</span>  
<span style="margin-left: 2em">經而漢以來之舊帙無能免於㸃竄者矣揆諸古</span>  
<span style="margin-left: 2em">義殆恐不然其注則間有𤼵明如五運六氣之南</span>  
<!-- 册3 葉1021b　Page:文淵閣四庫全書_0003冊.djvu/260 -->
<span style="margin-left: 2em">政北政舊注以甲己爲南政其餘八千爲北政元</span>  
<span style="margin-left: 2em">御則謂天地之氣東西對待南北平分何南政之</span>  
<span style="margin-left: 2em">少而北政之多也一日之中天氣晝南而夜北一</span>  
<span style="margin-left: 2em">歲之中天氣夏南而冬北則十二年中三年在北</span>  
<span style="margin-left: 2em">三年在東三年在南三年在西在北則南面而布</span>  
<span style="margin-left: 2em">北方之政是謂北政天氣自北而南升在南則北</span>  
<span style="margin-left: 2em">面而布南方之政是謂南政天氣自南而北升則</span>  
<span style="margin-left: 2em">自卯而後天氣漸南總以南政統之自酉而後天</span>  
<span style="margin-left: 2em">氣漸北總以北政統之東西者左右之間氣故不</span>  
<!-- 册3 葉1024a　Page:文淵閣四庫全書_0003冊.djvu/261 -->
<span style="margin-left: 2em">可以言政此南北二極之義其論爲前人所未及</span>  
<span style="margin-left: 2em">然運氣之說特約舉天道之大凡不能執爲定譜</span>  
<span style="margin-left: 2em">以施治療則亦有如太極無極之爭耳</span>  
靈樞懸解九卷<sub class="note-yuan">編修周永年家藏本</sub>  
<span style="margin-left: 1em">國朝黄元御撰是書亦以錯簡爲說謂經别前十三</span>  
<span style="margin-left: 2em">叚爲正經後十五叚爲别經乃經别之所以命名</span>  
<span style="margin-left: 2em">而後十五叚却誤在經脈中標本而誤名衛氣四</span>  
<span style="margin-left: 2em">時氣大半誤入邪氣藏府病形論津液五别誤名</span>  
<span style="margin-left: 2em">五癃津液别此𩔖甚多乃研究素問比櫛其辭使</span>  
<!-- 册3 葉1024b　Page:文淵閣四庫全書_0003冊.djvu/261 -->
<span style="margin-left: 2em">之脈絡環通案靈樞晚出又非素問之比說者謂</span>  
<span style="margin-left: 2em">唐人剽取甲乙經爲之不應與古書一例錯簡也</span>  
圖註難經八卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">明張世賢撰世賢字天成寜波人正德中名醫也</span>  
<span style="margin-left: 2em">難經舊有吳吕廣唐楊德操諸家註宋嘉祐中丁</span>  
<span style="margin-left: 2em">德用始於文義𨼆奥者各爲之圖元滑壽作本義</span>  
<span style="margin-left: 2em">亦有數圖然皆不備世賢是編於八十一篇篇篇</span>  
<span style="margin-left: 2em">有圖凡註所累言不盡者可以披圖而解惟其中</span>  
<span style="margin-left: 2em">有文義顯然不必待圖始解者亦强足其數稍爲</span>  
<!-- 册3 葉1025a　Page:文淵閣四庫全書_0003冊.djvu/261 -->
<span style="margin-left: 2em">冗贅其註亦循文敷<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2973.svg?width=24" alt="四庫全書僻字第2973號（衍）" title="四庫全書僻字第2973號（衍）">未造深微</span>  
難經經釋二卷<sub class="note-yuan">江蘇廵撫採進本</sub>  
<span style="margin-left: 1em">國朝徐大椿撰大椿有神農本草經百種錄巳著錄</span>  
<span style="margin-left: 2em">是書以秦越人八十一難經有不合内經之㫖者</span>  
<span style="margin-left: 2em">援引經文以駁正之考難經漢藝文志不載隋志</span>  
<span style="margin-left: 2em">始著於錄雖未必越人之書然三國巳有吕博望</span>  
<span style="margin-left: 2em">註本而張機傷寒論平脈篇中所稱經說今在第</span>  
<span style="margin-left: 2em">五難中則亦後漢良醫之所爲厯代以來與靈樞</span>  
<span style="margin-left: 2em">素問並尊絶無異論大椿雖研究内經未必學出</span>  
<!-- 册3 葉1025b　Page:文淵閣四庫全書_0003冊.djvu/261 -->
<span style="margin-left: 2em">古人上遽相排斥未見其然况大椿所據者内經</span>  
<span style="margin-left: 2em">而素問全元起本巳佚其第七篇唐王冰始稱得</span>  
<span style="margin-left: 2em">舊本補之宋林億等校正巳稱其天元紀大論以</span>  
<span style="margin-left: 2em">下與素問餘篇絶不相通疑冰取陰陽大論以補</span>  
<span style="margin-left: 2em">所亡至刺法本病二論則冰本亦闕其間字句異</span>  
<span style="margin-left: 2em">同億等又復有校改註中題曰新校正皆是則素</span>  
<span style="margin-left: 2em">問巳爲後人所亂而難經反爲古本又滑壽難經</span>  
<span style="margin-left: 2em">本義列是書所引内經而今本無之者不止一條</span>  
<span style="margin-left: 2em">則當時所見之本與今亦不甚同卽有舛互亦宜</span>  
<!-- 册3 葉1028a　Page:文淵閣四庫全書_0003冊.djvu/262 -->
<span style="margin-left: 2em">兩存遽執以駁難經之誤是何異談六經者執開</span>  
<span style="margin-left: 2em">元改隷之本以駁漢博士𫆀</span>  
難經懸解二卷<sub class="note-yuan">編修周永年家藏本</sub>  
<span style="margin-left: 1em">國朝黄元御撰亦謂舊本有訛多所更定均所謂我</span>  
<span style="margin-left: 2em">用我法也</span>  
傷寒懸解十五卷<sub class="note-yuan">編修周永年家藏本</sub>  
<span style="margin-left: 1em">國朝黄元御撰是書大㫖謂漢張機因鍼灸刺法巳</span>  
<span style="margin-left: 2em">亡而著傷寒論以治外感之疾其理則岐黄越人</span>  
<span style="margin-left: 2em">之理其法則因岐黄越人之鍼刺而變通之立六</span>  
<!-- 册3 葉1028b　Page:文淵閣四庫全書_0003冊.djvu/262 -->
<span style="margin-left: 2em">經以治傷寒從六氣也製湯丸以療感傷守五味</span>  
<span style="margin-left: 2em">也凡脈法八十三章六經經證以及入府傳藏之</span>  
<span style="margin-left: 2em">裏證誤行汗吐下之壊病三百六十八章外感之</span>  
<span style="margin-left: 2em">𩔖證汗吐下宜忌八十六章共五百三十七章合</span>  
<span style="margin-left: 2em">百十三方自晉王叔和混𤍠病於傷寒後來坊本</span>  
<span style="margin-left: 2em">雜出又有傳經爲𤍠<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">中爲寒之說而傷寒亡矣</span>  
<span style="margin-left: 2em">且簡編亦多失次因爲解其脈法詳其經絡考其</span>  
<span style="margin-left: 2em">常變辨其宜忌凡舊文之訛亂者悉爲更定末載</span>  
<span style="margin-left: 2em">駁正叔和序例一卷以糾其失其持論甚高考傷</span>  
<!-- 册3 葉1029a　Page:文淵閣四庫全書_0003冊.djvu/262 -->
<span style="margin-left: 2em">寒論舊本經王叔和之編次巳亂其原次元御以</span>  
<span style="margin-left: 2em">爲錯簡較爲有據與所改素問靈樞難經出自獨</span>  
<span style="margin-left: 2em">斷者不同然果復張機之舊與否亦别無佐證也</span>  
傷寒說意十一卷<sub class="note-yuan">編修周永年家藏本</sub>  
<span style="margin-left: 1em">國朝黄元御撰元御旣作傷寒懸解謂論文簡奥非</span>  
<span style="margin-left: 2em">讀者所能遽曉乃會通大意復著此書以開示初</span>  
<span style="margin-left: 2em">學之門徑</span>  
金匱懸解二十二卷<sub class="note-yuan">編修周永年家藏本</sub>  
<span style="margin-left: 1em">國朝黄元御撰元御謂張機著金匱玉函經以治内</span>  
<!-- 册3 葉1029b　Page:文淵閣四庫全書_0003冊.djvu/262 -->
<span style="margin-left: 2em">傷襍病大㫖主於扶陽氣以爲運化之本自滋陰</span>  
<span style="margin-left: 2em">之說勝而陽自陰升陰由陽降之理迄無解者因</span>  
<span style="margin-left: 2em">推明其意以成此書於四診九候之法言之頗詳</span>  
長沙藥解四卷<sub class="note-yuan">編修周永年家藏本</sub>  
<span style="margin-left: 1em">國朝黄元御撰張機傷寒論共一百十三方金匱玉</span>  
<span style="margin-left: 2em">函經共一百七十五方合二書所用之藥共一百</span>  
<span style="margin-left: 2em">六十種元御各爲分析排纂以藥名藥性爲綱而</span>  
<span style="margin-left: 2em">以某方用此藥爲目各推其因證主療之意頗爲</span>  
<span style="margin-left: 2em">詳悉然藥有藥之性味此不易者也用藥有用藥</span>  
<!-- 册3 葉1032a　Page:文淵閣四庫全書_0003冊.djvu/263 -->
<span style="margin-left: 2em">之經緯此無定者也此當論方不容論藥但云某</span>  
<span style="margin-left: 2em">方有此藥爲某證而用某方有此藥又爲某證而</span>  
<span style="margin-left: 2em">用是猶求之於筌蹄也</span>  
圖註脈訣四卷附方一卷<sub class="note-yuan">浙江廵撫採進本</sub>  
<span style="margin-left: 2em">明張世賢撰是編因世傳王叔和脈訣而爲之圖</span>  
<span style="margin-left: 2em">註考晁公武讀書志曰脈經十卷晉王叔和撰唐</span>  
<span style="margin-left: 2em">甘伯宗名醫傳曰叔和西晉高平人博通經方精</span>  
<span style="margin-left: 2em">意審處尤好著述其書纂岐伯華陀等論脈要訣</span>  
<span style="margin-left: 2em">而成叙陰陽表裏辨三部九候分人迎氣口神門</span>
