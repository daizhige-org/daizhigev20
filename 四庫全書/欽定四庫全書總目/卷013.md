## 欽定四庫全書總目 卷十三　經部十三　書類存目一

<!-- 册1 葉1168a　Page:文淵閣四庫全書_0001冊.djvu/342 -->
欽定四庫全書總目卷十三  
<span style="margin-left: 1em">經部十三</span>  
<span style="margin-left: 2em">書類存目一</span>  
書古文訓十六卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋薛季宣撰季宣字士龍號艮齋永嘉人起居舍</span>  
<span style="margin-left: 2em">人徽言之子紹興二十九年年甫十七卽從荆南</span>  
<span style="margin-left: 2em">帥辟寫機宜文字調鄂州武昌令以王炎薦改知</span>  
<span style="margin-left: 2em">常熟縣入爲大理寺主簿進大理正知湖州乾道</span>  
<span style="margin-left: 2em">元年遷知常州未上卒然宋人多稱爲薛常州未</span>  
<!-- 册1 葉1168b　Page:文淵閣四庫全書_0001冊.djvu/342 -->
<span style="margin-left: 2em">之詳也事迹具宋史儒林傳是編所載經文皆以</span>  
<span style="margin-left: 2em">古文奇字書之案孔壁蝌蚪古文漢時巳佚無人</span>  
<span style="margin-left: 2em">見其書迹後漢書杜林傳稱林於西州得漆書古</span>  
<span style="margin-left: 2em">文尙書嘗寶愛之雖遭艱困握持不離身岀以示</span>  
<span style="margin-left: 2em">衛宏云云此言漆書古文之始又儒林傳曰扶風</span>  
<span style="margin-left: 2em">杜林傳古文尙書同郡賈逵爲之作訓馬融作傳</span>  
<span style="margin-left: 2em">鄭元作解云云今賈馬鄭之注俱不傳然考陸德</span>  
<span style="margin-left: 2em">明經典釋文叙錄稱馬鄭所注並伏生所誦非古</span>  
<span style="margin-left: 2em">文也隋書經籍志亦稱杜氏所傳與賈馬鄭三家</span>  
<!-- 册1 葉1169a　Page:文淵閣四庫全書_0001冊.djvu/342 -->
<span style="margin-left: 2em">所注惟二十九篇又雜以今文非孔舊本然則當</span>  
<span style="margin-left: 2em">時所謂古文巳非今本五十八篇之全矣郭忠恕</span>  
<span style="margin-left: 2em">作汗簡所引用有古尙書玉海載後周顯德六年</span>  
<span style="margin-left: 2em">郭忠恕定古文尙書刻板沈括夢溪筆談稱宋太</span>  
<span style="margin-left: 2em">宗得古文尙書改雲夢土作乂爲雲土夢作乂均</span>  
<span style="margin-left: 2em">不言所自晁武公讀書志稱古文尙書吕大防得</span>  
<span style="margin-left: 2em">本於宋次道王仲至家以核陸氏釋文雖有小異</span>  
<span style="margin-left: 2em">同而大體相類觀其作字奇古非字書傅會穿鑿</span>  
<span style="margin-left: 2em">者所能到學者考之可以見制字之本云云亦不</span>  
<!-- 册1 葉1169b　Page:文淵閣四庫全書_0001冊.djvu/342 -->
<span style="margin-left: 2em">言宋王之本何來考顔師古匡謬正俗引古文尙</span>  
<span style="margin-left: 2em">書戮作ခ誓作ဂ則唐初卽有此書又冊府元龜</span>  
<span style="margin-left: 2em">載天寶三載詔曰先王令範莫越於唐虞上古遺</span>  
<span style="margin-left: 2em">書實稱於訓誥雖百篇奥義前代或亡而六體奇</span>  
<span style="margin-left: 2em">文舊規猶在但以古先所制有異於當今傳寫寖</span>  
<span style="margin-left: 2em">訛有疑於後學永言刋革必在從宜尙書應是古</span>  
<span style="margin-left: 2em">體文字並依今字繕寫施行其舊本仍藏之書府</span>  
<span style="margin-left: 2em">云云是宋王二氏所傳宋太宗所得卽郭忠恕所</span>  
<span style="margin-left: 2em">見本忠恕所見卽唐内府本也然隋志稱晉世秘</span>  
<!-- 册1 葉1172a　Page:文淵閣四庫全書_0001冊.djvu/343 -->
<span style="margin-left: 2em">書所存有古文尙書經文今無有傳者是唐初古</span>  
<span style="margin-left: 2em">尙書已亡元宗時何以仍在秘府惟魏江式論書</span>  
<span style="margin-left: 2em">表中稱所撰古今文字四十篇採孔氏尙書五經</span>  
<span style="margin-left: 2em">音註籀篇爾雅等書似其時河北尙有傳本然經</span>  
<span style="margin-left: 2em">典釋文敘錄稱尙書之字本爲𨽻古旣是𨽻寫古</span>  
<span style="margin-left: 2em">文則不全爲古字今宋齊舊本及徐李等音所有</span>  
<span style="margin-left: 2em">古字蓋亦無幾穿鑿之徒務欲立異依傍字部改</span>  
<span style="margin-left: 2em">變經文疑惑後生不可承用是式所據者卽出此</span>  
<span style="margin-left: 2em">元宗秘府所藏正是本耳陸德明已先辨之何宋</span>  
<!-- 册1 葉1172b　Page:文淵閣四庫全書_0001冊.djvu/343 -->
<span style="margin-left: 2em">人又紛紛崇尙乎季宣此本又以古文筆畫改爲</span>  
<span style="margin-left: 2em">今體奇形怪態不可辨識較篆書之本尤爲駭俗</span>  
<span style="margin-left: 2em">其訓義亦無甚發明朱子語錄謂其惟於地名上</span>  
<span style="margin-left: 2em">用功頗中其病故雖宋人舊帙今亦無取焉</span>  
書疑九卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋王柏撰顧炎武日知錄稱爲元儒王柏考柏以</span>  
<span style="margin-left: 2em">度宗咸淳十年卒未嘗入元炎武偶誤也柏字會</span>  
<span style="margin-left: 2em">之號魯齋金華人受業於何基之門基黃榦弟子</span>  
<span style="margin-left: 2em">榦又朱子壻也故托克托等修宋史以朱子之故</span>  
<!-- 册1 葉1173a　Page:文淵閣四庫全書_0001冊.djvu/343 -->
<span style="margin-left: 2em">列柏於道學傳中然柏之學名岀朱子實則師心</span>  
<span style="margin-left: 2em">與朱子之謹嚴絶異此其辨論尙書之文也尙書</span>  
<span style="margin-left: 2em">一經疑古文者自吳棫朱子始<sub class="note-yuan">見朱子語錄</sub>併今文而</span>  
<span style="margin-left: 2em">疑之者自趙汝談始<sub class="note-yuan">見陳振孫書錄解題</sub>改定洪範自龔鼎</span>  
<span style="margin-left: 2em">臣始<sub class="note-yuan">見所作東原錄</sub>改定武成自劉敞始<sub class="note-yuan">見七經小傳</sub>其併全</span>  
<span style="margin-left: 2em">經而移易補綴之者則自柏始考漢書載劉向以</span>  
<span style="margin-left: 2em">中古文校歐陽大小夏侯三家經文酒誥脫簡一</span>  
<span style="margin-left: 2em">召誥脫簡二率簡二十五字者脫亦二十五字簡</span>  
<span style="margin-left: 2em">二十二字者脫亦二十二字文字異者七百有餘</span>  
<!-- 册1 葉1173b　Page:文淵閣四庫全書_0001冊.djvu/343 -->
<span style="margin-left: 2em">脫字數十云云此言脫簡之始也然向旣校知脫</span>  
<span style="margin-left: 2em">簡自必一一改正必不聽其仍前錯亂又惟言酒</span>  
<span style="margin-left: 2em">誥脫簡一召誥脫簡二則其餘併無脫簡可知亦</span>  
<span style="margin-left: 2em">非篇篇悉有顚倒且一簡或二十五字或二十二</span>  
<span style="margin-left: 2em">字具有明文則必無全脫一章一<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2728.svg?width=24" alt="四庫全書僻字第2728號（段 -- 𠭊 or 叚 ?）" title="四庫全書僻字第2728號（段 -- 𠭊 or 叚 ?）">之事而此二</span>  
<span style="margin-left: 2em">十餘字之中亦必無簡首恰得句首簡尾恰得句</span>  
<span style="margin-left: 2em">尾無一句割裂不完之事也柏作是書乃動以脫</span>  
<span style="margin-left: 2em">簡爲詞臆爲移補其併舜典於堯典刪除姚方興</span>  
<span style="margin-left: 2em">所撰二十八字合益稷於臯陶謨此有孔頴達正</span>  
<!-- 册1 葉1176a　Page:文淵閣四庫全書_0001冊.djvu/344 -->
<span style="margin-left: 2em">義可據者也以大禹謨臯陶謨爲夏書此有左傳</span>  
<span style="margin-left: 2em">可據者也以論語咨爾舜二十二字補舜讓於德</span>  
<span style="margin-left: 2em">弗嗣之下其爲堯典本文抑或爲他書所載如鬻</span>  
<span style="margin-left: 2em">子述帝王遺語之類巳不可知<sub class="note-yuan">案鬻子所述帝王遺語今本不載見</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">賈誼新書所引</sub>以孟子勞之來之二十二字補敬敷五教</span>  
<span style="margin-left: 2em">在寛之下則孟子明作堯言柏乃以爲舜語巳相</span>  
<span style="margin-left: 2em">矛盾然亦尙有論語孟子可據也至於堯典臯陶</span>  
<span style="margin-left: 2em">謨說命武成洪範多士多方立政八篇則純以意</span>  
<span style="margin-left: 2em">爲易置一槪託之於錯簡有割一兩節者有割一</span>  
<!-- 册1 葉1176b　Page:文淵閣四庫全書_0001冊.djvu/344 -->
<span style="margin-left: 2em">兩句者何脫簡若是之多而所脫之簡又若是之</span>  
<span style="margin-left: 2em">零星破碎長短參差其簡之長短廣狹字之行𣢾</span>  
<span style="margin-left: 2em">疎宻茫無一定也其爲師心杜撰竄亂聖經巳不</span>  
<span style="margin-left: 2em">辨而可知矣其所辨說如謂盤庚之言所欠者理</span>  
<span style="margin-left: 2em">明詞達又信泰誓序十有一年之說謂武王承祖</span>  
<span style="margin-left: 2em">父之餘慶藉友<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3771.svg?width=24" alt="四庫全書僻字第3771號（邦）" title="四庫全書僻字第3771號（邦）">之歸心氣焰旣張體貎且盛改</span>  
<span style="margin-left: 2em">元紀元視紂猶諸侯後世曲爲覆䕶反生荆棘又</span>  
<span style="margin-left: 2em">謂大誥寧王貽我大寶龜西土有大艱人亦不靖</span>  
<span style="margin-left: 2em">之語無異唐德宗奉天之難諉之於定數是排斥</span>  
<!-- 册1 葉1177a　Page:文淵閣四庫全書_0001冊.djvu/344 -->
<span style="margin-left: 2em">漢儒不巳併集矢於經文矣豈濓洛關閩諸儒立</span>  
<span style="margin-left: 2em">言<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2618.svg?width=24" alt="四庫全書僻字第2618號（⿱乖一）" title="四庫全書僻字第2618號（⿱乖一）">教之本㫖哉托克托等修宋史乃與其詩疑</span>  
<span style="margin-left: 2em">之說並特錄於本傳以爲美談何其寡識之甚乎</span>  
古洪範一卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋賀成大撰成大字季常爵里未詳其自序以爲</span>  
<span style="margin-left: 2em">洪範自三八政以下紊亂無次因援朱子大學分</span>  
<span style="margin-left: 2em">經傳之例每疇以禹之言爲經以箕子之言爲傳</span>  
<span style="margin-left: 2em">如五行一曰水至五曰土此禹之經也水曰潤下</span>  
<span style="margin-left: 2em">至稼穡作甘此箕子之傳也五事一曰貌至五日</span>  
<!-- 册1 葉1177b　Page:文淵閣四庫全書_0001冊.djvu/344 -->
<span style="margin-left: 2em">思爲禹之經貎曰恭至睿作聖爲箕子之傳三八</span>  
<span style="margin-left: 2em">政一曰食至八曰師爲經而移惟辟作福至民用</span>  
<span style="margin-left: 2em">僣忒爲傳五紀一曰歲至五曰厯數爲經而以王</span>  
<span style="margin-left: 2em">省惟歲至則以風雨爲傳五皇極則以皇建其有</span>  
<span style="margin-left: 2em">極一句爲經而以惟皇作極無偏無陂至以爲天</span>  
<span style="margin-left: 2em">下王爲傳三德則以一曰正直至三曰柔克爲經</span>  
<span style="margin-left: 2em">而以平康正直至高明柔克爲傳稽疑則以擇建</span>  
<span style="margin-left: 2em">立卜筮人至衍忒爲經而以立時人作卜筮至用</span>  
<span style="margin-left: 2em">作凶爲傳庶徵則以曰雨至曰時爲經而以五者</span>  
<!-- 册1 葉1180a　Page:文淵閣四庫全書_0001冊.djvu/345 -->
<span style="margin-left: 2em">來備至恒風若爲傳五福則以一曰福至五曰考</span>  
<span style="margin-left: 2em">終命爲經而移斂時五福至其作汝用咎爲傳六</span>  
<span style="margin-left: 2em">極則以一曰凶短折至六曰弱爲經而移惟時厥</span>  
<span style="margin-left: 2em">庻民於汝極錫汝保極一極備凶一極無凶凡厥</span>  
<span style="margin-left: 2em">庻民無有淫朋人無有比德不協于極不罹于咎</span>  
<span style="margin-left: 2em">無虐㷀獨而畏高明時人斯其惟皇之極爲傳顚</span>  
<span style="margin-left: 2em">倒錯亂純出臆斷而自以爲古洪範自伏生以後</span>  
<span style="margin-left: 2em">傳授厯厯可考何處有此古本乎</span>  
定正洪範二卷<sub class="note-yuan">内府藏本</sub>  
<!-- 册1 葉1180b　Page:文淵閣四庫全書_0001冊.djvu/345 -->
<span style="margin-left: 2em">元胡一中撰一中字允文諸曁人官紹興路參軍</span>  
<span style="margin-left: 2em">是編因王柏文及翁吳澄三家改定洪範之本而</span>  
<span style="margin-left: 2em">以巳意參酌之首爲圖說次考訂經文次爲雜說</span>  
<span style="margin-left: 2em">案河圖洛書名見繫詞不云有關於洪範漢書五</span>  
<span style="margin-left: 2em">行志始載劉歆之言稱禹治洪水錫洛書法而陳</span>  
<span style="margin-left: 2em">之洪範是也於是洛書始合於洪範然猶未及河</span>  
<span style="margin-left: 2em">圖一中又因歆有河圖洛書相爲經緯八卦九章</span>  
<span style="margin-left: 2em">相爲表裏之文遂以河圖洛書併合於洪範而又</span>  
<span style="margin-left: 2em">參以陳摶先天之說所列二十八圖大抵支離破</span>  
<!-- 册1 葉1181a　Page:文淵閣四庫全書_0001冊.djvu/345 -->
<span style="margin-left: 2em">碎至於無偏無黨亦以五行生尅立論尤爲無理</span>  
<span style="margin-left: 2em">其以九爲河圖十爲洛書沿用劉牧之說於彼法</span>  
<span style="margin-left: 2em">之中自生轇轕猶其小焉者矣且說旣穿鑿理多</span>  
<span style="margin-left: 2em">窒碍乃於必不可通者更遁爲錯簡之說以巧飾</span>
