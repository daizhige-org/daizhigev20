## 欽定四庫全書總目 卷二十二　經部二十二　禮類四

<!-- 册1 葉1801a　Page:文淵閣四庫全書_0001冊.djvu/500 -->
欽定四庫全書總目卷二十二  
<span style="margin-left: 1em">經部二十二</span>  
<span style="margin-left: 2em">禮類四</span>  
三禮圖集注二十卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">宋聶崇義撰崇義洛陽人周顯德中累官國子司</span>  
<span style="margin-left: 2em">業世宗詔崇義㕘定郊廟祭玉因取三禮舊圖凡</span>  
<span style="margin-left: 2em">得六本重加考訂宋初上於朝太祖覽而嘉之詔</span>  
<span style="margin-left: 2em">頒行考禮圖始於後漢侍中阮諶其後有梁正者</span>  
<span style="margin-left: 2em">題諶圖云陳留阮士信受學於頴川綦母君取其</span>  
<!-- 册1 葉1801b　Page:文淵閣四庫全書_0001冊.djvu/500 -->
<span style="margin-left: 2em">說爲圖三卷多不按禮文而引漢事與鄭君之文</span>  
<span style="margin-left: 2em">違錯正稱隋書經籍志列鄭元及阮諶等三禮圖</span>  
<span style="margin-left: 2em">九卷唐書藝文志有夏侯伏朗三禮圖十二卷張</span>  
<span style="margin-left: 2em">鎰三禮圖九卷崇文總目有梁正三禮圖九卷宋</span>  
<span style="margin-left: 2em">史載吏部尙書張昭等奏云四部書目内有三禮</span>  
<span style="margin-left: 2em">圖十二卷自開皇中勅禮部修撰其圖第一第二</span>  
<span style="margin-left: 2em">題云梁氏第十後題云鄭氏今書府有三禮圖亦</span>  
<span style="margin-left: 2em">題梁氏鄭氏則所謂六本者鄭元一阮諶二夏侯</span>  
<span style="margin-left: 2em">伏朗三張鎰四梁正五開皇所撰六也然勘驗鄭</span>  
<!-- 册1 葉1804a　Page:文淵閣四庫全書_0001冊.djvu/501 -->
<span style="margin-left: 2em">志元實未嘗爲圖殆習鄭氏學者作圖歸之鄭氏</span>  
<span style="margin-left: 2em">歟今考書中宫室車服等圖與鄭注多相違異卽</span>  
<span style="margin-left: 2em">如少牢饋食敦皆南首鄭注云敦有首者尊者器</span>  
<span style="margin-left: 2em">飾也飾葢象龜周之制飾器必以其類龜有上下</span>  
<span style="margin-left: 2em">甲此言敦之上下象龜上下甲葢者意擬之辭而</span>  
<span style="margin-left: 2em">是書敦與簠簋皆作小龜以爲葢頂是一器之微</span>  
<span style="margin-left: 2em">亦失鄭意沈括夢溪筆談譏其犧象尊黃目尊之</span>  
<span style="margin-left: 2em">誤歐陽修集古錄譏其簋圖與劉原甫所得眞古</span>  
<span style="margin-left: 2em">簋不同趙彦衛雲麓漫鈔譏其爵爲雀背承一器</span>  
<!-- 册1 葉1804b　Page:文淵閣四庫全書_0001冊.djvu/501 -->
<span style="margin-left: 2em">犧象尊作一器繪牛象林光朝亦譏之曰聶氏三</span>  
<span style="margin-left: 2em">禮圖全無來厯榖璧則畫穀蒲璧則畫蒲皆以意</span>  
<span style="margin-left: 2em">爲之不知榖璧止如今腰帶胯上粟文耳是宋代</span>  
<span style="margin-left: 2em">諸儒亦不以所圖爲然然其書抄撮諸家亦頗承</span>  
<span style="margin-left: 2em">舊式不盡出於杜撰淳熙中陳伯廣嘗爲重刻題</span>  
<span style="margin-left: 2em">其後云其圖度未必盡如古昔苟得而考之不猶</span>  
<span style="margin-left: 2em">愈於求諸野乎斯言允矣今姑仍其舊帙錄之以</span>  
<span style="margin-left: 2em">備一家之學此書世所行者爲通志堂刋本或一</span>  
<span style="margin-left: 2em">頁一圖或一頁數圖而以說附載圖四隙行欵㕘</span>  
<!-- 册1 葉1805a　Page:文淵閣四庫全書_0001冊.djvu/501 -->
<span style="margin-left: 2em">差尋覽未便惟</span>  
<span style="margin-left: 1em">内府所藏錢曾也是園影宋鈔本毎頁自爲一圖而</span>  
<span style="margin-left: 2em">說附於後較爲淸整易觀今依仿繕錄焉</span>  
三禮圖四卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">明劉績撰績字用熙號蘆泉江夏人宏治庚戌進</span>  
<span style="margin-left: 2em">士官至鎭江府知府是書所圖一本陸佃禮象陳</span>  
<span style="margin-left: 2em">祥道禮書林希逸考工記解諸書而取諸博古圖</span>  
<span style="margin-left: 2em">者爲尤多與舊圖大異考漢時去古未遠車服禮</span>  
<span style="margin-left: 2em">器猶有存者鄭康成圖雖非手撰要爲傳鄭學者</span>  
<!-- 册1 葉1805b　Page:文淵閣四庫全書_0001冊.djvu/501 -->
<span style="margin-left: 2em">所爲阮諶夏侯伏朗張鎰梁正亦皆五代前人其</span>  
<span style="margin-left: 2em">時儒風淳實尚不以鑿空臆斷相高聶崇義㕘考</span>  
<span style="margin-left: 2em">六本定爲一家之學雖踵謬沿訛在所不免而遞</span>  
<span style="margin-left: 2em">相祖述終有典型至宣和博古圖所載大半揣摩</span>  
<span style="margin-left: 2em">近似强命以名其間疎漏多端洪邁諸人已屢攻</span>  
<span style="margin-left: 2em">其失績以漢儒爲妄作而依據是圖殊爲顚倒然</span>  
<span style="margin-left: 2em">所採陸陳諸家之說如齊子尾送女器出於魏太</span>  
<span style="margin-left: 2em">和中犧尊純爲牛形王肅據以證鳳羽婆娑之誤</span>  
<span style="margin-left: 2em">齊景公器出晉永康中象尊純爲象形劉杳據以</span>  
<!-- 册1 葉1808a　Page:文淵閣四庫全書_0001冊.djvu/502 -->
<span style="margin-left: 2em">證象骨飾尊之非蒲璧刻文如蒲荏敷時榖璧如</span>  
<span style="margin-left: 2em">粟粒其器出於宋時沈括據以證蒲形禾形之謬</span>  
<span style="margin-left: 2em">此書並採用其說亦足以備一解至於宫室制度</span>  
<span style="margin-left: 2em">輿輪名物凡房序之位輢較之分亦皆一一分析</span>  
<span style="margin-left: 2em">不惟補崇義之闕且以拾希逸之遺其他珽荼曲</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">之屬增舊圖所未備者又七十餘事過而存之</span>  
<span style="margin-left: 2em">未始非兼收並蓄之義也</span>  
學禮質疑二卷<sub class="note-yuan">副都御史黃登賢家藏本</sub>  
<span style="margin-left: 1em">國朝萬斯大撰斯大有儀禮商巳著錄是書考辨古</span>  
<!-- 册1 葉1808b　Page:文淵閣四庫全書_0001冊.djvu/502 -->
<span style="margin-left: 2em">禮頗多新說如謂魯郊惟曰至一禮祈榖不名郊</span>  
<span style="margin-left: 2em">自魯僣行曰至之郊其君臣托於祈榖以輕其事</span>  
<span style="margin-left: 2em">後人不察郊與祈穀之分遂以魯爲祈榖見春秋</span>  
<span style="margin-left: 2em">不書祈榖遂以祈榖爲郊今考襄公七年傳孟獻</span>  
<span style="margin-left: 2em">子曰夫郊祀后稷以祈榖事欲蟄而郊郊而後耕</span>  
<span style="margin-left: 2em">桓公五年秋大雩左氏傳曰書不時也凡祀啟蟄</span>  
<span style="margin-left: 2em">而郊龍見而雩與孟獻子之言亦合斯大旣不信</span>  
<span style="margin-left: 2em">左氏又據詩序謂昊天有成命爲郊祀天地而不</span>  
<span style="margin-left: 2em">言祈榖遂立是說不知大戴禮公符篇載郊祀曰</span>  
<!-- 册1 葉1809a　Page:文淵閣四庫全書_0001冊.djvu/502 -->
<span style="margin-left: 2em">承天之神興甘風雨庶卉百穀莫不茂者則郊兼</span>  
<span style="margin-left: 2em">祈穀之明證家語雖出依託然皆綴緝舊文其郊</span>  
<span style="margin-left: 2em">問篇稱至於啟蟄之月則又祈榖於上帝王肅注</span>  
<span style="margin-left: 2em">曰啟蟄而郊郊而後耕與鄭杜二家尤爲契合斯</span>  
<span style="margin-left: 2em">大別爲創論非也斯大又謂大社祭地在北郊王</span>  
<span style="margin-left: 2em">社祈榖在國中今考五經通義大社在中門之外</span>  
<span style="margin-left: 2em">王社在籍田之中孔賈疏及通典俱宗其說又左</span>  
<span style="margin-left: 2em">傳閔公二年傳間於兩社爲公室輔杜預註周社</span>  
<span style="margin-left: 2em">亳社兩社之間朝廷執政所在頴達曰魯是周之</span>  
<!-- 册1 葉1809b　Page:文淵閣四庫全書_0001冊.djvu/502 -->
<span style="margin-left: 2em">諸侯故國社謂之周社則國社之所在爲朝廷執</span>  
<span style="margin-left: 2em">政之所在其爲中門内無疑諸侯之國社與天子</span>  
<span style="margin-left: 2em">之大社同也周書作雒篇曰乃設立丘兆於南郊</span>  
<span style="margin-left: 2em">以上帝配后稷日月星辰先王皆與食諸侯受命</span>  
<span style="margin-left: 2em">於周乃建大社於國中國中與南郊對舉則大社</span>  
<span style="margin-left: 2em">不在郊而在國可知斯大所云誤亦顯著斯大又</span>  
<span style="margin-left: 2em">謂士止爲小宗不得爲大宗以士無祖廟也今考</span>  
<span style="margin-left: 2em">喪服小記曰士不攝大夫士攝大夫惟宗子又荀</span>  
<span style="margin-left: 2em">子曰故王者天太祖諸侯不敢壞大夫士有常宗</span>  
<!-- 册1 葉1812a　Page:文淵閣四庫全書_0001冊.djvu/503 -->
<span style="margin-left: 2em">楊倞註曰繼別子之後爲族人所常宗百世不遷</span>  
<span style="margin-left: 2em">之大宗也據此則士亦得爲大宗明矣又喪服小</span>  
<span style="margin-left: 2em">記曰庶子不祭殤與無後者殤與無後者從祖祔</span>  
<span style="margin-left: 2em">食鄭元注曰宗子之無父無後者爲墠祭之孔頴</span>  
<span style="margin-left: 2em">達疏曰若宗子是士無曾祖廟故諸父無後者爲</span>  
<span style="margin-left: 2em">墠祭之又曾子問曰若宗子死告於墓而後祭於</span>  
<span style="margin-left: 2em">家鄭注曰祭於家容無廟也孔疏曰祭於家是容</span>  
<span style="margin-left: 2em">宗子無爵其家無廟而祭於庶子之家是且有無</span>  
<span style="margin-left: 2em">廟而爲宗子者矣今斯大謂有始祖廟乃得爲大</span>  
<!-- 册1 葉1812b　Page:文淵閣四庫全書_0001冊.djvu/503 -->
<span style="margin-left: 2em">宗充其說不特士不得爲大宗據祭法則大夫止</span>  
<span style="margin-left: 2em">有曾祖廟將大夫亦不得爲大宗乎斯大又變其</span>  
<span style="margin-left: 2em">說謂士大夫皆得有髙曾祖廟引大傳曰大夫有</span>  
<span style="margin-left: 2em">大事省於其君干祫及其高祖今考孔疏祫合也</span>  
<span style="margin-left: 2em">謂雖無廟而得與有廟者合祭大夫葢祫於曾祖</span>  
<span style="margin-left: 2em">廟而上及高祖上士則祫於祖廟而上及曾祖高</span>  
<span style="margin-left: 2em">祖中士則祫於禰廟而上及祖與曾祖高祖又安</span>  
<span style="margin-left: 2em">得援爲皆得有廟之証乎斯大又謂小記大夫士</span>  
<span style="margin-left: 2em">之妾祔於妾祖姑亡則中一以上而祔則祔於高</span>  
<!-- 册1 葉1813a　Page:文淵閣四庫全書_0001冊.djvu/503 -->
<span style="margin-left: 2em">祖姑是高祖有廟今考小記孔疏曰妾無廟爲壇</span>  
<span style="margin-left: 2em">祔之耳則妾雖祔於高祖之妾不必高祖有廟觀</span>  
<span style="margin-left: 2em">雜記父母之喪尚功衰而祔兄弟之殤孔疏其小</span>  
<span style="margin-left: 2em">功兄弟身及父是庶人不合立祖廟則曾孫嫡孫</span>  
<span style="margin-left: 2em">爲之立壇祔小功兄弟之長殤於從祖立神而祭</span>  
<span style="margin-left: 2em">不爲從祖立廟也又安得爲高祖之妾有廟乎凡</span>  
<span style="margin-left: 2em">此皆自立異說略無顯據其他若辨商周改月改</span>  
<span style="margin-left: 2em">時周詩周正及兄弟同昭穆皆極精<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">宗法十餘</span>  
<span style="margin-left: 2em">篇亦頗見推闡置其非而存其是亦未始非一家</span>  
<!-- 册1 葉1813b　Page:文淵閣四庫全書_0001冊.djvu/503 -->
<span style="margin-left: 2em">之學也</span>  
讀禮志疑六卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝陸隴其撰隴其有古文尚書考已著錄是編以</span>  
<span style="margin-left: 2em">三禮之書多由漢儒採輯而成其所載古今典禮</span>  
<span style="margin-left: 2em">自明堂淸廟吉凶軍賓嘉以及名物器數之㣲互</span>  
<span style="margin-left: 2em">相考校每多齟齬不合因取鄭孔諸家注疏折衷</span>  
<span style="margin-left: 2em">於朱子之書務得其中並旁及春秋律吕與夫天</span>  
<span style="margin-left: 2em">時人事可與禮經相發明者悉爲採入其有疑而</span>  
<span style="margin-left: 2em">未決者則仍闕之故曰讀禮志疑案禮經自經秦</span>  
<!-- 册1 葉1816a　Page:文淵閣四庫全書_0001冊.djvu/504 -->
<span style="margin-left: 2em">火雖多殘缺不完而漢代諸儒去古未遠其所訓</span>  
<span style="margin-left: 2em">釋大抵有所根據不同於以意揣求宋儒義理雖</span>  
<span style="margin-left: 2em">精而博考詳稽終不逮注疏家專門之學隴其覃</span>  
<span style="margin-left: 2em">思心性墨守程朱其造詣之醇誠近代儒林所罕</span>  
<span style="margin-left: 2em">見至於討論三禮究與古人之終身穿穴者有殊</span>  
<span style="margin-left: 2em">然孔疏篤信鄭注往往不免附㑹而陳澔集說尤</span>  
<span style="margin-left: 2em">爲弇陋隴其隨文糾正考核折衷其用意實非俗</span>  
<span style="margin-left: 2em">儒所能及如論孔疏月令引太史職鄭注中數曰</span>  
<span style="margin-left: 2em">歲朔數曰年並舉則分年歲單舉則可互稱又祥</span>

<span style="margin-left: 2em">渡紹興嘉泰諸年謂秦檜韓侂冑立廟而制終未</span>  
<span style="margin-left: 2em">定考宋龔鼎臣東原錄稱文彦博家廟不作七間</span>  
<span style="margin-left: 2em">乃用唐杜岐公家舊式則安得謂漢以後人臣無</span>  
<span style="margin-left: 2em">建廟之文其論後世不世爵世官今之宗子非古</span>

<span style="margin-left: 2em">宗子引阡陌不同於井田郡縣不同於封建爲證</span>  
<span style="margin-left: 2em">其說是也然井田廢而正供之義不廢封建廢而</span>  
<span style="margin-left: 2em">臂指相維之義不廢世官廢而宗子支子之義不</span>  
<span style="margin-left: 2em">廢漢書載當時詔令每稱賜天下爲父後者其時</span>  
<span style="margin-left: 2em">巳不世官而云爲父後則有不爲父後者可知今</span>  
<span style="margin-left: 2em">制父母在而子先卒者其長孫於祖父母之喪服</span>  
<span style="margin-left: 2em">斬衰三年卽宗子爲後之義灼然可推安能一舉</span>  
<span style="margin-left: 2em">而廢之使主祭之時但以行輩年歲爲序乎至於</span>  
<span style="margin-left: 2em">祭必以子一條謂祠堂合祭先代使宗子主四親</span>

<span style="margin-left: 2em">之祭致凡爲人子者不得祭父則所祭四親係他</span>  
<span style="margin-left: 2em">人之親並非已親所祭之父係他人之父並非已</span>  
<span style="margin-left: 2em">父措語尤乖皆不免於瑕纇葢其大意務通人情</span>  
<span style="margin-left: 2em">故不免有違古義然大致斟酌變通於古禮之必</span>  
<span style="margin-left: 2em">不可行及俗禮之誤託於古者剖析考證亦往往</span>
