## 欽定四庫全書總目 卷一百十　子部二十　術數類存目一

<!-- 册3 葉1484：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷一百十  
<span style="margin-left: 1em">子部二十</span>  
<span style="margin-left: 2em">術數𩔖存目一</span>  
正易心法一卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">舊本題宋麻衣道者撰凡四十二章章四句句四</span>  
<span style="margin-left: 2em">言又題希夷先生受併消息交獻通考載李潛序</span>  
<span style="margin-left: 2em">云得之廬山異人馬端臨註曰或云許堅又載張</span>  
<span style="margin-left: 2em">栻跋亦信爲陳搏所傳惟朱子語錄曰此書詞意</span>  
<span style="margin-left: 2em">凡近不類一二百年文字如所謂雷自天下而發</span>  
<!-- 册3 葉1485b　Page:文淵閣四庫全書_0003冊.djvu/376 -->
<span style="margin-left: 2em">山自天上而墜皆無理之妄談所謂一陽生於子</span>  
<span style="margin-left: 2em">月而應於卯月乃術家之小數所謂曲破體之乃</span>  
<span style="margin-left: 2em">成全體則爐火之末技所謂人間萬事悉是假合</span>  
<span style="margin-left: 2em">乃佛者之幻語必近年術數末流道聽塗說掇拾</span>  
<span style="margin-left: 2em">老佛醫卜諸說之陋者以成此書後二年守南康</span>  
<span style="margin-left: 2em">有前湘陰主簿戴師愈者求謁卽及麻衣易因復</span>  
<span style="margin-left: 2em">扣之宛然此老所作欲馳報敬夫敬夫巳下世時</span>  
<span style="margin-left: 2em">當塗守李侍郎壽翁雅好此書亟以書來日卽如</span>  
<span style="margin-left: 2em">君言斯人而能爲此書亦吾所願見幸爲津致之</span>  
<!-- 册3 葉1488a　Page:文淵閣四庫全書_0003冊.djvu/377 -->
<span style="margin-left: 2em">戴不久卽死而夀翁亦得請西歸矣又曰麻衣易</span>  
<span style="margin-left: 2em">是戴師愈所作太平州刋本第二跋卽其人也昨</span>  
<span style="margin-left: 2em">親見之甚稱此易以爲得之隠者問之不肯明言</span>  
<span style="margin-left: 2em">其人某適到其家見有一冊襍錄乃戴公自作其</span>  
<span style="margin-left: 2em">言皆與麻衣易說相𩔖及戴死其子弟將所謂易</span>  
<span style="margin-left: 2em">圖來看乃知眞戴所自作也觀此二則則是書之</span>  
<span style="margin-left: 2em">僞妄審矣</span>  
翼元十二卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋張行成撰行成有易通變巳著錄案行成進書</span>  
<!-- 册3 葉1488b　Page:文淵閣四庫全書_0003冊.djvu/377 -->
<span style="margin-left: 2em">狀曰始得邵氏書旣得司馬氏書潛思力索久乃</span>  
<span style="margin-left: 2em">貫通考之於易無所不合因著翼元十二卷以明</span>  
<span style="margin-left: 2em">揚雄之易又曰揚雄作太元義本連山自蓍言之</span>  
<span style="margin-left: 2em">易用七二極少陽也太元用三十三五六之合十</span>  
<span style="margin-left: 2em">一而三天也自𧰼言之周易體八用六天包地之</span>  
<span style="margin-left: 2em">數也太元體四用三地承天之數也云云葢所進</span>  
<span style="margin-left: 2em">七易之一也朱<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">尊經義考注云未見今檢永樂</span>  
<span style="margin-left: 2em">大典尙載其本然太元巳贅翼更蛇之足矣</span>  
太元别訓五卷<sub class="note-yuan">兩江總督採進本</sub>  
<!-- 册3 葉1489a　Page:文淵閣四庫全書_0003冊.djvu/377 -->
<span style="margin-left: 1em">國朝劉斯組撰斯組有撥易堂易解已著錄是編解</span>  
<span style="margin-left: 2em">釋揚雄太元各以韻語發揮其義意欲以奥崛配</span>  
<span style="margin-left: 2em">雄然原書詞意艱深所以待註註又僻澁使人不</span>  
<span style="margin-left: 2em">解是亦何取於註乎</span>  
皇極經世書𩔖要九卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋鍾過撰過字益齋廬陵人其書作於咸淳中吳</span>  
<span style="margin-left: 2em">應丑序云鍾君取邵子之書類之圖卽書書卽圖</span>  
<span style="margin-left: 2em">矣其𩔖之目曰道曰太極曰陰陽而以外篇之文</span>  
<span style="margin-left: 2em">分附之考皇極經世外篇本邵子門人所記故張</span>  
<!-- 册3 葉1489b　Page:文淵閣四庫全書_0003冊.djvu/377 -->
<span style="margin-left: 2em">行成亦别爲編次此書捃拾排纂初無所發明更</span>  
<span style="margin-left: 2em">不及行成之索隠矣</span>  
皇極經世節要<sub class="note-yuan">無卷數　浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">不著撰人名氏浙江遺書目錄題元周爽撰案朱</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">尊經義考載經世節要宋周奭著奭湘鄉人乾</span>  
<span style="margin-left: 2em">道間嘗與胡安國張栻游潛心於易云云則是周</span>  
<span style="margin-left: 2em">奭非周爽是宋人非元人也然書中推歩元會運</span>  
<span style="margin-left: 2em">世至於明嘉靖辛巳登極壬午改元則又非奭之</span>  
<span style="margin-left: 2em">舊本矣葢明人所附益也</span>  
<!-- 册3 葉1492a　Page:文淵閣四庫全書_0003冊.djvu/378 -->
皇極經世書說十八卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">明朱隠老撰隠老字子方號灊峯豐城人洪武中</span>  
<span style="margin-left: 2em">大學士朱善之父葢元末明初人也隠老以邵子</span>  
<span style="margin-left: 2em">皇極經世義趣深奥學者猝不能得其說因以巳</span>  
<span style="margin-left: 2em">意訓解凡邵子所未及者皆折衷而論定之若邵</span>  
<span style="margin-left: 2em">子所自爲說者則又姑取至淺近之理以爲之指</span>  
<span style="margin-left: 2em">示欲令讀者易得其津涯然邵子作此書其大旨</span>  
<span style="margin-left: 2em">主於推歩隠老乃多講義理而於數學罕所發明</span>  
<span style="margin-left: 2em">則仍未能得其綱領也</span>  
<!-- 册3 葉1492b　Page:文淵閣四庫全書_0003冊.djvu/378 -->
皇極經世書傳八卷<sub class="note-yuan">河南巡撫採進本</sub>  
<span style="margin-left: 2em">明黃畿撰畿字宗大香山人黃佐父也是書有佐</span>  
<span style="margin-left: 2em">附記曰皇極經世未有全書先君得諸道藏手自</span>  
<span style="margin-left: 2em">錄之今性理所載乃蔡西山指要非其全也祝泌</span>  
<span style="margin-left: 2em">氏鈐以泰爲元六十四卦皆用四爻與邵子異矣</span>  
<span style="margin-left: 2em">廖應淮元元集從之惟朱隠老始宗本旨爲之說</span>  
<span style="margin-left: 2em">然未盡也先君自成化乙巳隠居粤洲草堂始悟</span>  
<span style="margin-left: 2em">氣以六變體以四分用九則三十六宫用六則二</span>  
<span style="margin-left: 2em">十四閏聲音律吕圓唱方和而後乾坤坎離用焉</span>  
<!-- 册3 葉1493a　Page:文淵閣四庫全書_0003冊.djvu/378 -->
<span style="margin-left: 2em">天地萬物之理貫於一矣又稱凡所注釋有未備</span>  
<span style="margin-left: 2em">者佐附以膚見則推歩也年月日時分杪晝夜進</span>  
<span style="margin-left: 2em">退積成一元消長則命算工補其闕焉然則是書</span>  
<span style="margin-left: 2em">佐所續成也又稱畿有自序此本無之殆傳寫佚</span>  
<span style="margin-left: 2em">脫矣</span>  
皇極經世心易發微八卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">明楊向春撰向春字體元號野厓普洱人是書推</span>  
<span style="margin-left: 2em">衍皇極經世舊說立占卜之法惟論干支生尅五</span>  
<span style="margin-left: 2em">行制化葢方技家言非說易之書也自稱六卷而</span>  
<!-- 册3 葉1493b　Page:文淵閣四庫全書_0003冊.djvu/378 -->
<span style="margin-left: 2em">隆慶二年鄧世芳序稱八卷與此本合據世芳序</span>  
<span style="margin-left: 2em">是書一刻於大理再刻於京師及在武定又集前</span>  
<span style="margin-left: 2em">刻之未備者刻之葢自序乃初刻時作此則増定</span>  
<span style="margin-left: 2em">之本耳</span>  
皇極經世攷三卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 1em">國朝徐文靖撰文靖有禹貢會箋已著錄是編首列</span>  
<span style="margin-left: 2em">邵子起算之術括爲二圖一曰數皆不離於五圖</span>  
<span style="margin-left: 2em">一曰皇極經世一元圖皆櫽括王湜節要爲之末</span>  
<span style="margin-left: 2em">附三十六宫解引鄭康成乾鑿度注及黃帝素問</span>  
<!-- 册3 葉1496a　Page:文淵閣四庫全書_0003冊.djvu/379 -->
<span style="margin-left: 2em">太乙游九官之說爲證皆因論邵子之學偶及之</span>  
<span style="margin-left: 2em">其大旨則以竹書紀年駁經世紀年之誤上起唐</span>  
<span style="margin-left: 2em">堯甲子下迄秦始皇甲寅備列干支訂其同異考</span>  
<span style="margin-left: 2em">顧炎武日知錄備論自王莽以前古人不以甲子</span>  
<span style="margin-left: 2em">名歲厯引爾雅周禮注左傳史記吕氏春秋賈誼</span>  
<span style="margin-left: 2em">鵩賦漢書許愼說文考據甚明今本竹書不用歲</span>  
<span style="margin-left: 2em">陽歲名而如後世題甲子是卽明人作僞非汲冡</span>  
<span style="margin-left: 2em">舊文之證邵子之學無所不窺而所推帝王年數</span>  
<span style="margin-left: 2em">無不與竹書相左絶無一言之攷正是又今本晚</span>  
<!-- 册3 葉1496b　Page:文淵閣四庫全書_0003冊.djvu/379 -->
<span style="margin-left: 2em">出邵子未見之證乃文靖不以經世疑竹書而反</span>  
<span style="margin-left: 2em">以竹書攻經世葢文人愛竒嗜博不加詳攷遂至</span>  
<span style="margin-left: 2em">顛倒是非毛漸三墳自鄭樵之外宋以來人人知</span>  
<span style="margin-left: 2em">其僞而文靖乃據以作竹書前編其信竹書亦猶</span>  
<span style="margin-left: 2em">是矣</span>  
洪範九疇數解三卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">明熊宗立撰宗立有素問運氣圓括定局立成已</span>  
<span style="margin-left: 2em">著錄朱<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">尊經義考載是書作八卷與此本不符</span>  
<span style="margin-left: 2em">然<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">尊註曰未見恐傳聞訛異也初蔡沈作洪範</span>  
<!-- 册3 葉1497a　Page:文淵閣四庫全書_0003冊.djvu/379 -->
<span style="margin-left: 2em">九疇數未竟而卒今載於性理大全及永樂大典</span>  
<span style="margin-left: 2em">中者皆非完本故天台謝無楙序稱其享數弗遐</span>  
<span style="margin-left: 2em">釋數未備猶有遺恨宗立訓釋其書復因沈之法</span>  
<span style="margin-left: 2em">而廣之如沈書釋數之詞僅有潛之一數餘但虛</span>  
<span style="margin-left: 2em">標數曰字而並闕其文宗立皆一一補作又沈書</span>  
<span style="margin-left: 2em">以原沖從公中用分戎終九數爲九疇之綱宗立</span>  
<span style="margin-left: 2em">則因而重之各衍爲八十一數如焦贑易林以一</span>  
<span style="margin-left: 2em">卦衍六十四卦之例排定緝綴遂爲完書所註推</span>  
<span style="margin-left: 2em">闡易義曲相比附百方牽合使之成理亦頗能自</span>  
<!-- 册3 葉1497b　Page:文淵閣四庫全書_0003冊.djvu/379 -->
<span style="margin-left: 2em">申其說惟不註孰爲沈之原文孰爲宗立之續補</span>  
<span style="margin-left: 2em">體例龎襍茫無端緒非沈原書尙存幾不知是書</span>  
<span style="margin-left: 2em">爲誰作是亦自明以來刋古書者之積習矣</span>  
洪範圖解二卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">明韓邦奇撰邦奇有易學啟蒙意見已著錄是編</span>  
<span style="margin-left: 2em">因蔡沈洪範皇極内外篇復爲圖解於每疇所分</span>  
<span style="margin-left: 2em">之九字係以斷語俾占者易明其揲蓍之法與易</span>  
<span style="margin-left: 2em">之蓍卦相同所言休咎皆本於洪範亦與易𧰼相</span>  
<span style="margin-left: 2em">表裏葢萬物不離乎數而數不離乎竒偶故隨意</span>  
<!-- 册3 葉1500a　Page:文淵閣四庫全書_0003冊.djvu/380 -->
<span style="margin-left: 2em">牽合無不相通云</span>  
洪範皇極注四卷<sub class="note-yuan">江西巡撫採進本</sub>  
<span style="margin-left: 2em">明李經綸注</span>  
<span style="margin-left: 1em">國朝湯倓增注經綸有禮經類編已著錄倓號漫湖</span>  
<span style="margin-left: 2em">南豐人經綸先注此書名曰範數觀通倓又改此</span>  
<span style="margin-left: 2em">名凡書中稱漫湖日者皆倓說也其書首卷著揲</span>  
<span style="margin-left: 2em">法筮占說辨諸條以下則分内外篇末綴以範數</span>  
<span style="margin-left: 2em">之分而每卷皆系以圖葢專爲占筮而作朱<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">尊</span>
