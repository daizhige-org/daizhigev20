## 欽定四庫全書總目 卷一百九十七　集部五十　詩文評類存目

<!-- 册5 葉1017a　Page:文淵閣四庫全書_0005冊.djvu/259 -->
欽定四庫全書總目卷一百九十七  
<span style="margin-left: 1em">集部五十</span>  
<span style="margin-left: 2em">詩文評類存目</span>  
樂府古題要解二卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">舊本題唐吳兢𢰅兢有貞觀政要已著錄考崇文</span>  
<span style="margin-left: 2em">總目載古樂府古題要解共十二卷晁公武讀書</span>  
<span style="margin-left: 2em">志稱兢纂采漢魏以來古樂府詞凡十卷又於傳</span>  
<span style="margin-left: 2em">記及諸家文集中采樂府所起本義以釋解古題</span>  
<span style="margin-left: 2em">觀崇文總目稱二書共十二卷而讀書志稱古樂</span>  
<!-- 册5 葉1017b　Page:文淵閣四庫全書_0005冊.djvu/259 -->
<span style="margin-left: 2em">府十卷則所餘二卷爲樂府古題要解矣卷數與</span>  
<span style="margin-left: 2em">今本相合崇文總目又載樂府解題稱不著撰人</span>  
<span style="margin-left: 2em">名氏與吳兢所撰樂府古題頗同以江南曲爲首</span>  
<span style="margin-left: 2em">其後所解差異此本爲毛晉津逮秘書所刋後有</span>  
<span style="margin-left: 2em">晉跋稱今人以兢所撰與樂府解題混爲一書又</span>  
<span style="margin-left: 2em">稱太原郭氏諸叙中輙引樂府解題不及古題要</span>  
<span style="margin-left: 2em">解今考郭茂倩樂府詩集所引樂府解題自漢鐃</span>  
<span style="margin-left: 2em">歌上之囘篇始乃明題吳兢之名則混爲一書已</span>  
<span style="margin-left: 2em">不始於近代然茂倩所引其文則與此書全同不</span>  
<!-- 册5 葉1020a　Page:文淵閣四庫全書_0005冊.djvu/260 -->
<span style="margin-left: 2em">過偶刪一二句或增入樂府本詞一二句不應互</span>  
<span style="margin-left: 2em">相勦襲至此疑兢書久佚好事者因崇文總目有</span>  
<span style="margin-left: 2em">樂府解題與吳兢所撰樂府頗同語因捃拾郭茂</span>  
<span style="margin-left: 2em">倩所引樂府解題僞爲兢書而不知王堯臣等所</span>  
<span style="margin-left: 2em">謂與樂府頗同者乃指其解說古題體例相近非</span>  
<span style="margin-left: 2em">謂其文全同觀下文卽云以江南曲爲首其後所</span>  
<span style="margin-left: 2em">解差異是二書不同之明證安有兩家之書如出</span>  
<span style="margin-left: 2em">一口者乎且樂府自樂府雜詩自雜詩卷末乃載</span>  
<span style="margin-left: 2em">及建除諸體併及於字謎之類其爲捃拾以足兩</span>  
<!-- 册5 葉1020b　Page:文淵閣四庫全書_0005冊.djvu/260 -->
<span style="margin-left: 2em">卷之數灼然可知矣晉跋稱是書凡三本一得之</span>  
<span style="margin-left: 2em">廣山楊氏一得之錫山顔氏最後乃得一元板然</span>  
<span style="margin-left: 2em">則是書爲元人所贋造也</span>  
詩式一卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">舊本題唐釋皎然撰皎然有杼山集已著錄此本</span>  
<span style="margin-left: 2em">卽附載集末考陳振孫書錄解題載詩式五卷詩</span>  
<span style="margin-left: 2em">議一卷唐僧皎然撰以十九字括詩之體此本旣</span>  
<span style="margin-left: 2em">非五卷又一十九體乃末一條陳氏不應舉以槩</span>  
<span style="margin-left: 2em">全書陳氏又載正字王元擬皎然十九字一卷使</span>  
<!-- 册5 葉1021a　Page:文淵閣四庫全書_0005冊.djvu/260 -->
<span style="margin-left: 2em">僅如今本一條則不能擬爲一卷矣殊參差可疑</span>  
<span style="margin-left: 2em">又皎然與顏眞<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">同時乃天寳大厯間人而所引</span>  
<span style="margin-left: 2em">諸詩舉以爲例者有賀知章李白王昌齡相去甚</span>  
<span style="margin-left: 2em">近亦不應遽與古人並推疑原書散佚而好事者</span>  
<span style="margin-left: 2em">摭拾補之也何文煥詩話考索議其淈没條稱夏</span>  
<span style="margin-left: 2em">姬當壚似蕩而貞謂夏姬無當壚事當作文君不</span>  
<span style="margin-left: 2em">知此用辛延年羽林郎胡姬年十五春日獨當壚</span>  
<span style="margin-left: 2em">事特夏字誤姬字不誤不必改作文君且延年詩</span>  
<span style="margin-left: 2em">稱貽我靑銅鏡結我紅羅襦不惜紅羅裂何論輕</span>  
<!-- 册5 葉1021b　Page:文淵閣四庫全書_0005冊.djvu/260 -->
<span style="margin-left: 2em">賤軀所謂似蕩也又稱男兒愛後婦女子重前夫</span>  
<span style="margin-left: 2em">人生各有分貴賤不相逾多謝金吾子私愛徒區</span>  
<span style="margin-left: 2em">區所謂貞也若文君越禮安得曰似蕩而貞乎</span>  
詩法源流三卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">不著撰人名氏末有至治壬戌楊載舊序一篇稱</span>  
<span style="margin-left: 2em">少年遊浣花草堂見杜甫九世孫杜舉問所藏詩</span>  
<span style="margin-left: 2em">律舉言甫之詩法不傳諸子而傳其門人吳成鄒</span>  
<span style="margin-left: 2em">遂王恭舉得之於三子因以授載其說極爲𮎰誕</span>  
<span style="margin-left: 2em">所載凡五言律詩九首七言律詩四十三首各有</span>  
<!-- 册5 葉1024a　Page:文淵閣四庫全書_0005冊.djvu/261 -->
<span style="margin-left: 2em">吳成等註釋標立結上生下格拗句格牙鎭格節</span>  
<span style="margin-left: 2em">節生意格抑<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3951.svg?width=24" alt="四庫全書僻字第3951號（揚 --（『昜』上『旦』之『日』與『一』相連））" title="四庫全書僻字第3951號（揚 --（『昜』上『旦』之『日』與『一』相連））">格接頂格交股格纎腰格雙蹄格</span>  
<span style="margin-left: 2em">續腰格首尾互换格首尾相同格單蹄格應句格</span>  
<span style="margin-left: 2em">開合格開合變格疊字格句應句格敘事格歸題</span>  
<span style="margin-left: 2em">格續意格前多後少格前開後合格興兼比格興</span>  
<span style="margin-left: 2em">兼賦格比興格連珠格一意格變字格前實後虛</span>  
<span style="margin-left: 2em">格藏頭格先體後用格雙字起結格凡三十三格</span>  
<span style="margin-left: 2em">其謬陋殆不足辨楊載序俚拙萬狀亦必出僞託</span>  
<span style="margin-left: 2em">然其書乃作第三卷前二卷則一爲元人論詩之</span>  
<!-- 册5 葉1024b　Page:文淵閣四庫全書_0005冊.djvu/261 -->
<span style="margin-left: 2em">語分標傅若金等姓名一爲選錄漢魏晉詩題傅</span>  
<span style="margin-left: 2em">若川次舟編卷末又有嘉靖癸未邱道隆後序稱</span>  
<span style="margin-left: 2em">憲伯荆南王公用章取詩法源流增入古人論述</span>  
<span style="margin-left: 2em">與詩足法者𨤲爲三卷云云然則此書爲王用章</span>  
<span style="margin-left: 2em">所輯諸家著錄有作𫝊若金撰者當以開卷第一</span>  
<span style="margin-left: 2em">篇題若金名因而致誤耳</span>  
二南密㫖一卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">舊本題唐賈島撰案陳振孫書錄解題曰二南密</span>  
<span style="margin-left: 2em">㫖一卷唐賈島撰凡十五門恐亦依託此本端緒</span>  
<!-- 册5 葉1025a　Page:文淵閣四庫全書_0005冊.djvu/261 -->
<span style="margin-left: 2em">紛繁綱目混淆卷末忽總題一條云以上十五門</span>  
<span style="margin-left: 2em">不可妄傳卷中有總題一條云以上四十七門畧</span>  
<span style="margin-left: 2em">舉大綱是於陳氏所云十五門外增立四十七門</span>  
<span style="margin-left: 2em">已與書錄解題互異且所謂四十七門一十五門</span>  
<span style="margin-left: 2em">者輾轉推尋數皆不合亦不解其何故而議論𮎰</span>  
<span style="margin-left: 2em">謬詞意拙俚殆不可以名<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3313.svg?width=24" alt="四庫全書僻字第3313號（狀）" title="四庫全書僻字第3313號（狀）">如以盧綸月照何年</span>  
<span style="margin-left: 2em">樹花逢幾度春句爲大雅以錢起好風能自至明</span>  
<span style="margin-left: 2em">月不須期句爲小雅以衛風日居月諸胡迭而微</span>  
<span style="margin-left: 2em">句爲變大雅以綠衣黄裳句爲變小雅以召南林</span>  
<!-- 册5 葉1025b　Page:文淵閣四庫全書_0005冊.djvu/261 -->
<span style="margin-left: 2em">有樸遫野有死鹿句及鮑照申黜褒女進班去趙</span>  
<span style="margin-left: 2em">姬昇句錢起竹憐新雨後山愛夕陽時句爲南宗</span>  
<span style="margin-left: 2em">以衛風我心匪石不可轉也句左思吾愛段干木</span>  
<span style="margin-left: 2em">偃息藩魏君句盧綸詩誰知樵子徑得到葛洪家</span>  
<span style="margin-left: 2em">句爲北宗皆有如囈語其論總例物𧰼一門尤一</span>  
<span style="margin-left: 2em">字不通島爲唐代名人何至於此此殆又僞本之</span>  
<span style="margin-left: 2em">重儓矣</span>  
玉壺詩話一卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">舊本題宋釋文塋撰考宋史藝文志載玉壺淸話</span>  
<!-- 册5 葉1028a　Page:文淵閣四庫全書_0005冊.djvu/262 -->
<span style="margin-left: 2em">十卷今其書猶存已著於錄或題曰玉壺野史無</span>  
<span style="margin-left: 2em">所謂玉壺詩話者此本爲學海𩔖編所載僅寥寥</span>  
<span style="margin-left: 2em">數頁以玉壺淸話校之蓋書賈摘錄其有渉於詩</span>  
<span style="margin-left: 2em">者裒爲一卷詭立此名曹溶不及辨也</span>  
天厨禁臠三卷<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">宋釋惠洪撰惠洪有冷齋夜話已著錄是編皆標</span>  
<span style="margin-left: 2em">舉詩格而舉唐宋舊作爲式然所論多强立名目</span>  
<span style="margin-left: 2em">旁生支節如首列杜甫寒食對月詩爲偷春格而</span>  
<span style="margin-left: 2em">謂黄庭堅茶詞叠押四山字爲用此法則風馬牛</span>  
<!-- 册5 葉1028b　Page:文淵閣四庫全書_0005冊.djvu/262 -->
<span style="margin-left: 2em">不相及又如蘇軾芳草池塘惠連夢上林鴻雁子</span>  
<span style="margin-left: 2em"><img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">歸句黄庭堅平生幾兩<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2885.svg?width=24" alt="四庫全書僻字第2885號（𡲆）" title="四庫全書僻字第2885號（𡲆）">身後五車書句謂射</span>  
<span style="margin-left: 2em">雁得蘇武書無鴻字故改謝靈運春草池塘爲芳</span>  
<span style="margin-left: 2em">草五車書無身後字故改阮孚人生幾兩屐爲平</span>  
<span style="margin-left: 2em">生謂之用事補綴法亦自生妄見所論古詩押韻</span>  
<span style="margin-left: 2em">換韻之類尤茫然不知古法嚴羽滄浪詩話稱天</span>  
<span style="margin-left: 2em">厨禁臠最害事非虛語也</span>  
容齋詩話六卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">舊本題宋洪邁撰邁有史記法語已著錄此編諸</span>  
<!-- 册5 葉1029a　Page:文淵閣四庫全書_0005冊.djvu/262 -->
<span style="margin-left: 2em">家書目皆不載其名惟文淵閣書目有之永樂大</span>  
<span style="margin-left: 2em">典亦於詩字韻下全部收入則自宋元以來巳有</span>  
<span style="margin-left: 2em">此編今核其文蓋於邁容齋五筆之内各掇其論</span>  
<span style="margin-left: 2em">詩之語裒爲一編猶於玉壺淸話之中別鈔爲玉</span>  
<span style="margin-left: 2em">壺詩話耳以流傳已久姑存其目於此以備參考</span>  
<span style="margin-left: 2em">焉</span>  
容齋四六叢談一卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">舊本題宋洪邁撰亦於容齋五筆中掇其論四六</span>  
<span style="margin-left: 2em">之言別爲一卷疑與容齋詩話爲一手所輯所論</span>  
<!-- 册5 葉1029b　Page:文淵閣四庫全書_0005冊.djvu/262 -->
<span style="margin-left: 2em">較王銍四六話謝伋四六麈談特爲精核蓋邁初</span>  
<span style="margin-left: 2em">習詞科晩更内制於駢偶之文用力獨深故不同</span>  
<span style="margin-left: 2em">於勦說也</span>  
少陵詩格一卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">宋林越撰越有漢雋已著錄是編發明杜詩篇法</span>  
<span style="margin-left: 2em">穿鑿殊甚如秋興八首第一首爲接頂格謂江間</span>  
<span style="margin-left: 2em">波浪兼天湧爲巫峽之蕭森塞上風雲接地陰爲</span>  
<span style="margin-left: 2em">巫山之蕭森已牽合無理第二首爲交股格三首</span>  
<span style="margin-left: 2em">曰開合格四首曰雙蹄格五首曰續後格六首曰</span>  
<!-- 册5 葉1032a　Page:文淵閣四庫全書_0005冊.djvu/263 -->
<span style="margin-left: 2em">首尾互換格七首曰首尾相同格八首曰單蹄格</span>  
<span style="margin-left: 2em">隨意支配皆莫知其所自來後又有詠懷古蹟諸</span>  
<span style="margin-left: 2em">將諸詩亦間及他家每首皆標立格名種種杜撰</span>
