<span style="margin-left: 2em">宋李劉撰明孫雲翼箋釋劉字公甫崇仁人嘉定</span>  
<span style="margin-left: 2em">七年進士厯官寶章閣待制雲翼有橘山四六箋</span>  
<span style="margin-left: 2em">註已著録劉平生無他事可述惟以儷語爲專門</span>  
<span style="margin-left: 2em">所著有𩔖藁續𩔖藁梅亭四六今皆未見此本乃</span>  
<span style="margin-left: 2em">其門人羅逢吉所編以劉初年館何異家及在湖</span>

<span style="margin-left: 2em">南蜀中所作彚爲一集題曰標準葢門弟子尊師</span>  
<span style="margin-left: 2em">之詞也凡分七十一目共一千九十六首自六代</span>  
<span style="margin-left: 2em">以來箋啓卽多駢偶然其時文體皆然非以是别</span>  
<span style="margin-left: 2em">爲一格也至宋而歲時通候仕宦遷除吉凶慶吊</span>  
<span style="margin-left: 2em">無一事不用啓無一人不用啓其啓必以四六遂</span>  
<span style="margin-left: 2em">於四六之内別有專門南渡之始古法猶存孫覿</span>  
<span style="margin-left: 2em">汪藻諸人名篇不乏迨劉晚岀惟以流麗穩貼爲</span>  
<span style="margin-left: 2em">宗無復前人之典重沿波不返遂變爲𩔖書之外</span>  
<span style="margin-left: 2em">編公牘之副本而冗濫極矣然劉之所作頗爲隸</span>

<span style="margin-left: 2em">出交相諛佞以爲文章有格歸呈先祖乃不悅私</span>  
<span style="margin-left: 2em">意謂先祖八十有餘必是老拙曉不得文字顧首</span>  
<span style="margin-left: 2em">顧尾有間有架且造語俊爽皆與老拙不合也旣</span>

<span style="margin-left: 2em">不如此歐蘇不如此始知其非云云其持論獨異</span>  
<span style="margin-left: 2em">今觀其集雖當南渡後文體衰弱之餘未能盡除</span>  
<span style="margin-left: 2em">積習然其縱橫馳驟而一歸之於法度實有灝氣</span>  
<span style="margin-left: 2em">行乎其間非嘽緩之音所可比宜其與適代興矣</span>  
<span style="margin-left: 2em">讀書附志載所著篔窻初集三十卷續集三十八</span>

<span style="margin-left: 2em">人知邵陽宋史無傳其集亦不見於藝文志此本</span>
