## 欽定四庫全書總目 卷二十八　經部二十八　春秋類三

<!-- 册1 葉2240：整葉圖版，無文字記錄 -->

欽定四庫全書總目卷二十八  
<span style="margin-left: 1em">經部二十八</span>  
<span style="margin-left: 2em">春秋類三</span>  
春秋集傳釋義大成十二卷<sub class="note-yuan">內府藏本</sub>  
<span style="margin-left: 2em">元俞臯撰臯字心遠新安人初其鄉人趙良鈞宋</span>  
<span style="margin-left: 2em">末進士及第授修職郎廣德軍教授宋亡不仕以</span>  
<span style="margin-left: 2em">春秋教授鄉里臯從良鈞受學因以所傳著是書</span>  
<span style="margin-left: 2em">經文之下備列三傳其胡安國傳亦與同列吳澄</span>  
<span style="margin-left: 2em">序謂兼列胡氏以從時尙而四傳之名亦權輿於</span>  
<!-- 册1 葉2241b　Page:文淵閣四庫全書_0001冊.djvu/610 -->
<span style="margin-left: 2em">澄序中胡傳曰尊此其漸也然臯雖以四傳並列</span>  
<span style="margin-left: 2em">而於胡傳之過偏過激者實多所匡正澄序所謂</span>  
<span style="margin-left: 2em">玩經下之釋則四傳之是非不待辨而自明可謂</span>  
<span style="margin-left: 2em">專門而通者固亦持平之論矣觀臯自序稱所定</span>  
<span style="margin-left: 2em">十六例悉以程子傳爲宗又引程子所謂微詞隱</span>  
<span style="margin-left: 2em">義時措時宜於義不同而詞同事同而詞不同者</span>  
<span style="margin-left: 2em">反覆申明不可例拘之意又稱學者宜熟玩程傳</span>  
<span style="margin-left: 2em">均無一字及安國葢其師之學本出於程子特以</span>  
<span style="margin-left: 2em">程傳未有成書而胡傳方爲當代所傳習故取與</span>  
<!-- 册1 葉2244a　Page:文淵閣四庫全書_0001冊.djvu/611 -->
<span style="margin-left: 2em">三傳並論之統核全書其大㫖可以槪見固未嘗</span>  
<span style="margin-left: 2em">如明代諸人竟尊胡傳爲經也</span>  
春秋纂言十二卷總例七卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">元吳澄撰澄有易纂言已著錄是書采摭諸家傳</span>  
<span style="margin-left: 2em">注而間以巳意論斷之首爲總例凡分七綱八十</span>  
<span style="margin-left: 2em">一目其天道人紀二例澄所創作餘吉凶軍賓嘉</span>  
<span style="margin-left: 2em">五例則與宋張大亨春秋五禮例宗互相出入似</span>  
<span style="margin-left: 2em">乎蹈襲然澄非蹈襲人書者葢澄之學派兼出於</span>  
<span style="margin-left: 2em">金谿新安之間而大亨之學派則出於蘇氏澄殆</span>  
<!-- 册1 葉2244b　Page:文淵閣四庫全書_0001冊.djvu/611 -->
<span style="margin-left: 2em">以門戸不同未觀其書故與之闇合而不知也然</span>  
<span style="margin-left: 2em">其縷析條分則較大亨爲宻矣至於經文行𣢾多</span>  
<span style="margin-left: 2em">所割裂而經之闕文亦皆補以方空於體例殊爲</span>  
<span style="margin-left: 2em">未協葢澄於諸經率皆有所㸃竄不獨春秋爲然</span>  
<span style="margin-left: 2em">讀是書者取其長而置其所短可也明嘉靖中嘉</span>  
<span style="margin-left: 2em">興府知府蔣若愚嘗爲鋟木湛若水序之歲久散</span>  
<span style="margin-left: 2em">佚世罕傳本王士禎居易錄自云未見其書又云</span>  
<span style="margin-left: 2em">朱檢討曾見之吳郡陸醫其淸家是朱彞尊經義</span>  
<span style="margin-left: 2em">考之注存亦僅一睹此本爲兩淮所採進殆卽傳</span>  
<!-- 册1 葉2245a　Page:文淵閣四庫全書_0001冊.djvu/611 -->
<span style="margin-left: 2em">寫陸氏本歟久微而著固亦可寶之笈矣</span>  
春秋提綱十卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">舊本題鐵山先生陳則通撰不著爵里亦不著時</span>  
<span style="margin-left: 2em">代其始末未詳朱彞尊經義考列之劉莊孫後王</span>  
<span style="margin-left: 2em">申子前然則元人也是書綜論春秋大㫖分門凡</span>  
<span style="margin-left: 2em">四曰征伐曰朝聘曰盟會曰雜例每門中又區分</span>  
<span style="margin-left: 2em">其事以類相從題之曰例然大抵參校其事之始</span>  
<span style="margin-left: 2em">終而考究其成敗得失之由雖名曰例實非如他</span>  
<span style="margin-left: 2em">家之說春秋以書法爲例者故其言閎肆縱橫純</span>  
<!-- 册1 葉2245b　Page:文淵閣四庫全書_0001冊.djvu/611 -->
<span style="margin-left: 2em">爲史論之體葢說經家之别成一格者也其雜例</span>  
<span style="margin-left: 2em">門中論春秋爲用夏正猶堅守胡安國之說然安</span>  
<span style="margin-left: 2em">國解文公十四年有星孛于北斗解昭公十七年</span>  
<span style="margin-left: 2em">有星孛于大辰全襲董仲舒劉向之義則通災異</span>  
<span style="margin-left: 2em">例中獨深排漢儒事應之謬則所見固勝於安國</span>  
<span style="margin-left: 2em">矣</span>  
春秋諸國統紀一卷目錄一卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">元齊履謙撰履謙字伯恒大名人官至太史院使</span>  
<span style="margin-left: 2em">事迹具元史本傳此書乃其延祐丁巳爲國子司</span>  
<!-- 册1 葉2248a　Page:文淵閣四庫全書_0001冊.djvu/612 -->
<span style="margin-left: 2em">業時所作前有自序謂今之春秋葢聖人合二十</span>  
<span style="margin-left: 2em">國史記爲之自三傳專言褒貶於諸國分合與春</span>  
<span style="margin-left: 2em">秋所以爲春秋槩未之及故敘類此書以備諸家</span>  
<span style="margin-left: 2em">之闕凡二十有二篇首魯次周次宋次齊次晉次</span>  
<span style="margin-left: 2em">衛次蔡次陳次鄭次曹次秦次薛次𣏌次滕次莒</span>  
<span style="margin-left: 2em">次邾次許次宿次楚次吳自内魯尊周外各以五</span>  
<span style="margin-left: 2em">等之爵爲次其入春秋後降爵者則隨所降之爵</span>  
<span style="margin-left: 2em">列之而楚吳以僭王殿焉目錄謂此皆國史具在</span>  
<span style="margin-left: 2em">聖人據以作春秋者又以諸小國諸亡國釐爲二</span>  
<!-- 册1 葉2248b　Page:文淵閣四庫全書_0001冊.djvu/612 -->
<span style="margin-left: 2em">篇附錄於末目錄謂此無國史因二十國事所及</span>  
<span style="margin-left: 2em">而載者皆先於各國下列敘大勢與其排比之意</span>  
<span style="margin-left: 2em">題曰某國春秋統紀葢據墨子有百國春秋徐彦</span>  
<span style="margin-left: 2em">公羊疏有孔子求周史記得百二十國寶書之文</span>  
<span style="margin-left: 2em">故不主因魯史從赴告之義也案春秋如不據魯</span>  
<span style="margin-left: 2em">史不應以十二公紀年如不從赴告不應僖公以</span>  
<span style="margin-left: 2em">後晉事最詳僖公以前晉乃不載一事此葢掇拾</span>  
<span style="margin-left: 2em">雜說不考正經且魯史不紀周年内魯可也履謙</span>  
<span style="margin-left: 2em">分國編次而魯第一周第二不曰王人雖微加於</span>  
<!-- 册1 葉2249a　Page:文淵閣四庫全書_0001冊.djvu/612 -->
<span style="margin-left: 2em">諸侯之上乎况天王也至於隱公八年葬蔡宣公</span>  
<span style="margin-left: 2em">宣公十七年葬蔡文公並經有明文履謙漏此二</span>  
<span style="margin-left: 2em">條乃於桓公十七年葬蔡桓侯謂諸國皆僭稱公</span>  
<span style="margin-left: 2em">惟蔡仍舊章反引左傳爲證殊爲踈舛又經書桓</span>  
<span style="margin-left: 2em">公三年夫人姜氏至自齊六年九月丁卯子同生</span>  
<span style="margin-left: 2em">其事更無疑義穀梁傳疑故明之之說巳爲不核</span>  
<span style="margin-left: 2em">事實履謙乃竟以莊公爲齊侯之子尤爲乖謬以</span>  
<span style="margin-left: 2em">其排比經文頗易尋覽所論亦時有可采故錄存</span>  
<span style="margin-left: 2em">之吳澄序稱其縷數旁通務合書法間或求之太</span>  
<!-- 册1 葉2249b　Page:文淵閣四庫全書_0001冊.djvu/612 -->
<span style="margin-left: 2em">過要之不苟爲言葢瑕瑜不掩澄巳有微詞矣</span>  
春秋本義三十卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">元程端學撰端學字時叔號積齋慶元人至治元</span>  
<span style="margin-left: 2em">年舉進士第二官國子助教遷翰林國史院編修</span>  
<span style="margin-left: 2em">官事蹟附載元史儒學傳韓性傳中是書乃其在</span>  
<span style="margin-left: 2em">國學時所作所採自三傳而下凡　百七十六家</span>  
<span style="margin-left: 2em">卷首具列其目寧波府志及千頃堂書目均稱所</span>  
<span style="margin-left: 2em">採一百三十家未喻其故也首爲通論一篇問答</span>  
<span style="margin-left: 2em">一篇綱領一篇其下依經附說類次羣言間亦綴</span>  
<!-- 册1 葉2252a　Page:文淵閣四庫全書_0001冊.djvu/613 -->
<span style="margin-left: 2em">以案語左傳事迹卽參錯於衆說之巾體例頗爲</span>  
<span style="margin-left: 2em">糅雜其大㫖仍主常事不書有貶無褒之義故所</span>  
<span style="margin-left: 2em">徴引大抵孫復以後之說往往繳繞支離橫加推</span>  
<span style="margin-left: 2em">衍事事求其所以貶如經書紀履緰來逆女伯姬</span>  
<span style="margin-left: 2em">歸于紀此自直書其事舊無褒貶端學必謂履緰</span>  
<span style="margin-left: 2em">非命<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">紀不當使來迎魯亦不當聽其迎夫履緰</span>  
<span style="margin-left: 2em">爲命<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">固無明文其非命<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">又有何據乎紀叔姬</span>  
<span style="margin-left: 2em">之歸酅舊皆美其不以盛衰易志歸於夫族端學</span>  
<span style="margin-left: 2em">必以爲當歸魯而不當歸酅斯已刻矣乃復誣以</span>  
<!-- 册1 葉2252b　Page:文淵閣四庫全書_0001冊.djvu/613 -->
<span style="margin-left: 2em">失節於紀季此又何所據乎至於宋儒之駁左傳</span>  
<span style="margin-left: 2em">不過摘其與經相戻如經曰楚子麋卒而傳曰遇</span>  
<span style="margin-left: 2em">弑之類耳端學乃事事皆云未知信否則天下無</span>  
<span style="margin-left: 2em">可據之古書矣以其尚頗能糾正胡傳又所採一</span>  
<span style="margin-left: 2em">百七十六家其書佚者十之九此書猶畧見其梗</span>  
<span style="margin-left: 2em">槩姑錄之以備參考焉</span>  
春秋或問十卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">元程端學撰端學旣輯春秋本義復厯舉諸說得</span>  
<span style="margin-left: 2em">失以明去取之意因成此書葢與本義相輔而行</span>  
<!-- 册1 葉2253a　Page:文淵閣四庫全書_0001冊.djvu/613 -->
<span style="margin-left: 2em">者也其中最紕繆者莫過於堅執周用夏正一條</span>  
<span style="margin-left: 2em">反覆引譬至於一萬餘言無一不郢書燕說甚至</span>  
<span style="margin-left: 2em">於隱公元年不書卽位亦謂卽位當在前年十一</span>  
<span style="margin-left: 2em">月故正月不書以爲改正不改月之証其陋殆不</span>  
<span style="margin-left: 2em">足與辨然其他論說乃轉勝所作之本義葢本義</span>  
<span style="margin-left: 2em">由誤從孫復之說根柢先乖故每事必穿鑿其文</span>  
<span style="margin-left: 2em">務求聖人所以貶卽本條無可譏彈亦必旁引一</span>  
<span style="margin-left: 2em">事或旁引一人以當其罪遂至於支離轇轕多與</span>  
<span style="margin-left: 2em">經義相違此書則厯舉諸家各加抨擊雖過疑三</span>  
<!-- 册1 葉2253b　Page:文淵閣四庫全書_0001冊.djvu/613 -->
<span style="margin-left: 2em">傳未免乖方至於宋代諸儒一切深刻𤨏碎之談</span>  
<span style="margin-left: 2em">附會牽合之論轉能一舉而摧陷之然則本義之</span>  
<span style="margin-left: 2em">失失於芟除糾結之後又自生糾結耳若此書所</span>  
<span style="margin-left: 2em">辨訂則未嘗盡不中理也棄短取長固亦未可竟</span>  
<span style="margin-left: 2em">廢焉</span>  
春秋三傳辨疑二十卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">元程端學撰是書以攻駁三傳爲主凡端學以爲</span>  
<span style="margin-left: 2em">可疑者皆摘錄經文傳文而疏辨於下大抵先存</span>  
<span style="margin-left: 2em">一必欲廢傳之心而百計以求其瑕纇求之不得</span>  
<!-- 册1 葉2256a　Page:文淵閣四庫全書_0001冊.djvu/614 -->
<span style="margin-left: 2em">則以不可信一語槩之葢不信三傳之說創於啖</span>  
<span style="margin-left: 2em">助趙匡<sub class="note-yuan">按韓愈贈盧仝詩有春秋三傳束高閣獨抱遺經究終始之句仝與啖趙同時葢亦</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">宗二家之說者以所作春秋摘微巳佚故今據現存之書惟稱啖趙</sub>其後析爲三𣲖</span>  
<span style="margin-left: 2em">孫復尊王發微以下棄傳而不駁傳者也劉敞春</span>  
<span style="margin-left: 2em">秋權衡以下駁三傳之義例者也葉夢得春秋讞</span>  
<span style="margin-left: 2em">以下駁三傳之典故者也至於端學乃兼三𣲖而</span>  
<span style="margin-left: 2em">用之且併以左傳爲僞撰變本加厲罔顧其安至</span>
