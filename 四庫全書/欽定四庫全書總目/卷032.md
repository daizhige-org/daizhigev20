## 欽定四庫全書總目 卷三十二　經部三十二　孝經類、孝經類存目

<!-- 册1 葉2580a　Page:文淵閣四庫全書_0001冊.djvu/695 -->
欽定四庫全書總目卷三十二  
<span style="margin-left: 1em">經部三十二</span>  
<span style="margin-left: 2em">孝經類</span>  
<span style="margin-left: 3em">蔡邕明堂論引魏文侯孝經傳吕覽審微篇亦</span>  
<span style="margin-left: 3em">引孝經諸侯章則其來久矣然授受無緒故陳</span>  
<span style="margin-left: 3em">騤汪應辰皆疑其僞今觀其文去二戴所錄爲</span>  
<span style="margin-left: 3em">近要爲七十子徒之遺書使河間獻王採入一</span>  
<span style="margin-left: 3em">百三十一篇中則亦禮記之一篇與儒行緇衣</span>  
<span style="margin-left: 3em">轉從其類惟其各出别行稱孔子所作傳錄者</span>  
<!-- 册1 葉2580b　Page:文淵閣四庫全書_0001冊.djvu/695 -->
<span style="margin-left: 3em">又分章標目自名一經後儒遂以不類繫辭論</span>  
<span style="margin-left: 3em">語繩之亦有由矣中間孔鄭兩本互相勝負始</span>  
<span style="margin-left: 3em">以開元御註用今文遵制者從鄭後以朱子刊</span>  
<span style="margin-left: 3em">誤用古文講學者又轉而從孔要其文句小異</span>  
<span style="margin-left: 3em">義理不殊當以黃震之言爲定論<sub class="note-yuan">語見黄氏日鈔</sub>故今</span>  
<span style="margin-left: 3em">之所錄惟取其詞達理明有裨來學不復以今</span>  
<span style="margin-left: 3em">文古文區分門戸徒釀水火之爭蓋註經者明</span>  
<span style="margin-left: 3em">道之事非分明角勝之事也</span>  
古文孝經孔氏傳一卷附宋本古文孝經一卷<sub class="note-yuan">光祿寺<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">陸錫</sub>  
<!-- 册1 葉2581a　Page:文淵閣四庫全書_0001冊.djvu/695 -->
<sub class="note-yuan">熊家藏本</sub>  
<span style="margin-left: 2em">舊本題漢孔安國傳日本信陽太宰純音據卷末</span>  
<span style="margin-left: 2em">乾隆丙申歙縣鮑廷博新刊䟦稱其友汪翼滄附</span>  
<span style="margin-left: 2em">市舶至日本得於彼國之長﨑澳核其紀歲干支</span>  
<span style="margin-left: 2em">乃康熙十一年所刊前有太宰純序稱古書亡於</span>  
<span style="margin-left: 2em">中夏存於日本者頗多昔僧奝然適宋獻鄭注孝</span>  
<span style="margin-left: 2em">經一本今去其世七百餘年古書之散逸者亦不</span>  
<span style="margin-left: 2em">少而孔傳古文孝經全然尚存惟是經國人相傳</span>  
<span style="margin-left: 2em">之久不知厯幾人書寫是以文字訛謬魚魯不辨</span>  
<!-- 册1 葉2581b　Page:文淵閣四庫全書_0001冊.djvu/695 -->
<span style="margin-left: 2em">純旣以數本校讐且旁採他書所引苟有足徴者</span>  
<span style="margin-left: 2em">莫不㕘考十更裘葛乃成定本其經文與宋人所</span>  
<span style="margin-left: 2em">謂古文者亦不全同今不敢從彼改此傳中間有</span>  
<span style="margin-left: 2em">不成語雖疑其有誤然諸本皆同無所取正故姑</span>  
<span style="margin-left: 2em">傳疑以俟君子今文唐陸元朗嘗音之古文則否</span>  
<span style="margin-left: 2em">今因依陸氏音例並音經傳庶乎令讀者不誤其</span>  
<span style="margin-left: 2em">音云云考世傳海外之本别有所謂七經孟子考</span>  
<span style="margin-left: 2em">文者亦日本人所刊稱西條掌書記山井鼎輯東</span>  
<span style="margin-left: 2em">都講官物觀補遺中有古文孝經一卷亦云古文</span>  
<!-- 册1 葉2584a　Page:文淵閣四庫全書_0001冊.djvu/696 -->
<span style="margin-left: 2em">孔傳中華所不傳而其邦獨存又云其眞僞不可</span>  
<span style="margin-left: 2em">辨末學微賤不敢輒議云云則日本所傳原有是</span>  
<span style="margin-left: 2em">書非鮑氏新刊贋造此本核其文句與山井鼎等</span>  
<span style="margin-left: 2em">所考大抵相應惟山井鼎等稱每章題下有劉<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3271.svg?width=24" alt="四庫全書僻字第3271號（炫）" title="四庫全書僻字第3271號（炫）"></span>  
<span style="margin-left: 2em">直解其字極細寫之與注文麄細弗類又有引及</span>  
<span style="margin-left: 2em">邢昺正義者爲後人附錄此本無之爲少異耳其</span>  
<span style="margin-left: 2em">傳文雖證以論衡經典釋文唐會要所引亦頗相</span>  
<span style="margin-left: 2em">合然淺陋冗漫不類漢儒釋經之體併不類唐宋</span>  
<span style="margin-left: 2em">元以前人語殆市舶流通頗得中國書籍有桀𭶑</span>  
<!-- 册1 葉2584b　Page:文淵閣四庫全書_0001冊.djvu/696 -->
<span style="margin-left: 2em">知文義者摭諸書所引孔傳影附爲之以自誇圖</span>  
<span style="margin-left: 2em">籍之富歟考元王惲中堂事紀曰中統二年高麗</span>  
<span style="margin-left: 2em">世子植來朝宴於中書省問曰傳聞汝邦有古文</span>  
<span style="margin-left: 2em">尙書及海外異書答曰與中國書不殊高麗日本</span>  
<span style="margin-left: 2em">比隣相接海東經典大槩可知使果有之何以奝</span>  
<span style="margin-left: 2em">然不與鄭注並獻至今日而乃出足徵彼國之本</span>  
<span style="margin-left: 2em">出自宋元以後觀山井鼎亦疑之則其事固可知</span>  
<span style="margin-left: 2em">矣特以海外秘文人所樂覩使不實見其書終不</span>  
<span style="margin-left: 2em">知所謂古文孝經孔傳不過如此轉爲好古者之</span>  
<!-- 册1 葉2585a　Page:文淵閣四庫全書_0001冊.djvu/696 -->
<span style="margin-left: 2em">所惜故特錄存之而具列其始末如右</span>  
孝經正義三卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">唐元宗明皇帝御注宋邢昺疏案唐會要開元十</span>  
<span style="margin-left: 2em">年六月上注孝經頒天下及國子學天寶二年二</span>  
<span style="margin-left: 2em">月上重注亦頒天下舊唐書經籍志孝經一卷元</span>  
<span style="margin-left: 2em">宗注唐書藝文志今上孝經制㫖一卷注曰元宗</span>  
<span style="margin-left: 2em">其稱制㫖者猶梁武帝中庸義之稱制㫖實一書</span>  
<span style="margin-left: 2em">也趙明誠金石錄載明皇注孝經四卷陳振孫書</span>  
<span style="margin-left: 2em">錄解題亦稱家有此刻爲四大軸蓋天寶四載九</span>  
<!-- 册1 葉2585b　Page:文淵閣四庫全書_0001冊.djvu/696 -->
<span style="margin-left: 2em">月以御注刻石於太學謂之石臺孝經今尚存西</span>  
<span style="margin-left: 2em">安府學中爲碑凡四故拓本稱四卷耳元宗御製</span>  
<span style="margin-left: 2em">序末稱一章之中凡有數句一句之内義有兼明</span>  
<span style="margin-left: 2em">具載則文繁畧之則義闕今存於疏用廣發揮唐</span>  
<span style="margin-left: 2em">書元行冲傳稱元宗自注孝經詔行冲爲疏立於</span>  
<span style="margin-left: 2em">學官唐會要又載天寶五載詔孝經書疏雖粗發</span>  
<span style="margin-left: 2em">明未能該備今更敷暢以廣闕文令集賢院寫頒</span>  
<span style="margin-left: 2em">中外是注凡再修疏亦再修其疏唐志作二卷宋</span>  
<span style="margin-left: 2em">志則作三卷殆續增一卷歟宋咸平中邢昺所修</span>  
<!-- 册1 葉2588a　Page:文淵閣四庫全書_0001冊.djvu/697 -->
<span style="margin-left: 2em">之疏卽據行冲書爲藍本然孰爲舊文孰爲新說</span>  
<span style="margin-left: 2em">今已不可辨别矣孝經有今文古文二本今文稱</span>  
<span style="margin-left: 2em">鄭元注其說傳自荀昶而鄭志不載其名古文稱</span>  
<span style="margin-left: 2em">孔安國注其書出自劉<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3271.svg?width=24" alt="四庫全書僻字第3271號（炫）" title="四庫全書僻字第3271號（炫）">而隋書已言其僞至唐</span>  
<span style="margin-left: 2em">開元七年三月詔令羣儒質定右庶子劉知幾主</span>  
<span style="margin-left: 2em">古文立十二騐以駁鄭國子祭酒司馬貞主今文</span>  
<span style="margin-left: 2em">摘閨門章文句凡鄙庶人章割製舊文妄加子曰</span>  
<span style="margin-left: 2em">字及句中脫衣就功諸語以駁孔其文具載唐會</span>  
<span style="margin-left: 2em">要中厥後今文行而古文廢元熊禾作董鼎孝經</span>  
<!-- 册1 葉2588b　Page:文淵閣四庫全書_0001冊.djvu/697 -->
<span style="margin-left: 2em">大義序遂謂貞去閨門一章卒啟元宗無禮無度</span>  
<span style="margin-left: 2em">之禍明孫本作孝經辨疑併謂唐宫闡不肅貞削</span>  
<span style="margin-left: 2em">閨門一章乃爲國諱夫削閨門一章遂啟幸蜀之</span>  
<span style="margin-left: 2em">衅使當時行用古文果無天寶之亂乎唐宫闡不</span>  
<span style="margin-left: 2em">肅誠有之至於閨門章二十四字則絶與武韋不</span>  
<span style="margin-left: 2em">相涉指爲避諱不知所避何諱也況知幾與貞兩</span>  
<span style="margin-left: 2em">議並上會要載當時之詔乃鄭依舊行用孔注傳</span>  
<span style="margin-left: 2em">習者稀亦存繼絶之典是未因知幾而廢鄭亦未</span>  
<span style="margin-left: 2em">因貞而廢孔迨時閱三年乃有御注太學刻石署</span>  
<!-- 册1 葉2589a　Page:文淵閣四庫全書_0001冊.djvu/697 -->
<span style="margin-left: 2em">名者三十六人貞不預列御注旣行孔鄭兩家遂</span>  
<span style="margin-left: 2em">併廢亦未聞貞更建議廢孔也禾等徒以朱子刊</span>  
<span style="margin-left: 2em">誤偶用古文遂以不用古文爲大罪又不能知唐</span>  
<span style="margin-left: 2em">時典故徒聞中興書目有議者排毁古文遂廢之</span>  
<span style="margin-left: 2em">語遂沿其誤說憒憒然歸罪於貞不知以注而論</span>  
<span style="margin-left: 2em">則孔佚鄭亦佚孔佚罪貞鄭佚又罪誰乎以經而</span>  
<span style="margin-left: 2em">論則鄭存孔亦存古文並未因貞一議亡也貞又</span>  
<span style="margin-left: 2em">何罪焉今詳考源流明今文之立自元宗此注始</span>  
<span style="margin-left: 2em">元宗此注之立自宋詔邢昺等修此疏始衆說喧</span>  
<!-- 册1 葉2589b　Page:文淵閣四庫全書_0001冊.djvu/697 -->
<span style="margin-left: 2em">呶皆揣摩影響之談置之不論不議可矣</span>  
古文孝經指解一卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">不著編輯者名氏以宋司馬光范祖禹之說合爲</span>  
<span style="margin-left: 2em">一書案宋中興藝文志曰自唐明皇時議者排毁</span>  
<span style="margin-left: 2em">古文以閨門一章爲鄙俗而古文遂廢<sub class="note-yuan">按此說舛誤辨已見</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">孝經正義條下</sub>至司馬光始取古文爲指解又范祖禹進</span>  
<span style="margin-left: 2em">孝經說劄子曰仁宗朝司馬光在館閣爲古文指</span>  
<span style="margin-left: 2em">解表上之臣妄以所見又爲之說書錄解題載光</span>  
<span style="margin-left: 2em">書祖禹書各一卷此本殆以二書相因而作故合</span>  
<!-- 册1 葉2592a　Page:文淵閣四庫全書_0001冊.djvu/698 -->
<span style="margin-left: 2em">編也王應麟玉海載光書進於至和元年時爲殿</span>  
<span style="margin-left: 2em">中丞直秘閣與祖禹說小異然光集所載進表稱</span>  
<span style="margin-left: 2em">嘗撰古文孝經指解皇祐中獻於仁宗皇帝𥨸慮</span>  
<span style="margin-left: 2em">歲久不存今繕寫爲一卷上進云云則祖禹所說</span>  
<span style="margin-left: 2em">者初進之本應麟所說者重進之本耳孝經今文</span>  
<span style="margin-left: 2em">古文自隋志所載王劭劉<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3271.svg?width=24" alt="四庫全書僻字第3271號（炫）" title="四庫全書僻字第3271號（炫）">以來卽紛紛聚訟至</span>  
<span style="margin-left: 2em">今說經之家亦多遞相左右然所爭者不過字句</span>  
<span style="margin-left: 2em">之間觀光從古文而句下乃備載唐元宗今文之</span>  
<span style="margin-left: 2em">注使二本南轅北轍可移今文之注以注古文乎</span>  
<!-- 册1 葉2592b　Page:文淵閣四庫全書_0001冊.djvu/698 -->
<span style="margin-left: 2em">宋黃震日鈔有曰按孝經一爾古文今文特所傳</span>  
<span style="margin-left: 2em">微有不同如首章今文云仲尼居曾子侍古文則</span>  
<span style="margin-left: 2em">云仲尼閒居曾子侍坐今文云子曰先王有至德</span>  
<span style="margin-left: 2em">要道古文則曰子曰參先王有至德要道今文云</span>  
<span style="margin-left: 2em">夫孝德之本也教之所由生也古文則曰夫孝德</span>  
<span style="margin-left: 2em">之本教之所由生文之或増或減不過如此於大</span>  
<span style="margin-left: 2em">義固無不同至於分章之多寡今文三才章其政</span>  
<span style="margin-left: 2em">不嚴而治與先王見教之可以化民通爲一章古</span>  
<span style="margin-left: 2em">文則分爲二章今文聖治章第九其所因者本也</span>  
<!-- 册1 葉2593a　Page:文淵閣四庫全書_0001冊.djvu/698 -->
<span style="margin-left: 2em">與父子之道天性通爲一章古文則分爲二章不</span>  
<span style="margin-left: 2em">愛其親而愛他人者古文又分爲一章章句之分</span>  
<span style="margin-left: 2em">合率不過如此於大義亦無不同古文又云閨門</span>  
<span style="margin-left: 2em">之内具禮矣乎嚴父嚴兄妻子臣妾猶百姓徒役</span>  
<span style="margin-left: 2em">也此二十二字今文全無之而古文自爲一章與</span>  
<span style="margin-left: 2em">前之分章者三共增爲二十二所異者又不過如</span>  
<span style="margin-left: 2em">此非今文與古文各爲一書也其說可謂持平光</span>
