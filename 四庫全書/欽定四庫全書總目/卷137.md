## 欽定四庫全書總目 卷一百三十七　子部四十七　類書類存目一

<!-- 册3 葉3552a　Page:文淵閣四庫全書_0003冊.djvu/893 -->
欽定四庫全書總目卷一百三十七  
<span style="margin-left: 1em">子部四十七</span>  
<span style="margin-left: 2em">𩔖書𩔖存目一</span>  
聖賢羣輔錄二卷<sub class="note-yuan">山東巡撫採進本</sub>  
<span style="margin-left: 2em">一名四八目舊附載陶潛集中唐宋以來相沿引</span>  
<span style="margin-left: 2em">用承訛踵謬莫悟其非邇以編錄遺書始𫎇</span>  
睿鑒高深斷爲僞託<small>臣</small>等仰承  
聖訓詳悉推求乃知今本潛集爲北齊僕射陽休之編  
<span style="margin-left: 2em">休之序錄稱其集先有兩本一本六卷排比顚亂</span>  
<!-- 册3 葉3552b　Page:文淵閣四庫全書_0003冊.djvu/893 -->
<span style="margin-left: 2em">兼復闕少蕭統所撰八卷又少五孝傳及四八目</span>  
<span style="margin-left: 2em">今錄統所闕併序目等合爲十卷是五孝傳及四</span>  
<span style="margin-left: 2em">八目實休之所增蕭統舊本無是也統序稱深愛</span>  
<span style="margin-left: 2em">其文故加搜校則八卷以外不應更有佚篇其爲</span>  
<span style="margin-left: 2em">晚出僞書已無疑義且集中與子儼等疏稱子夏</span>  
<span style="margin-left: 2em">爲孔子四友而此錄四友乃爲顔囘子貢子路子</span>  
<span style="margin-left: 2em">張又五孝傳引孝乎惟孝友于兄弟之文句讀尙</span>  
<span style="margin-left: 2em">從包咸註知未見古文尙書而此錄四岳一條乃</span>  
<span style="margin-left: 2em">引孔安國傳其出兩手尤自顯然至書以聖賢羣</span>  
<!-- 册3 葉3553a　Page:文淵閣四庫全書_0003冊.djvu/893 -->
<span style="margin-left: 2em">輔爲名而魯三桓鄭七穆晉六<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">魏四友以及仕</span>  
<span style="margin-left: 2em">莽之唐林唐遵叛晉之王敦並列簡編名實相迕</span>  
<span style="margin-left: 2em">理乖風教亦决非潛之所爲昔宋庠校正斯集僅</span>  
<span style="margin-left: 2em">知八儒三墨二條爲後人所竄入而全書之贋竟</span>  
<span style="margin-left: 2em">不能明潛之受誣已逾千載今逢右文</span>  
聖世得以辨别而表章之使白璧無瑕流光奕葉是亦  
<span style="margin-left: 2em">潛之至幸矣</span>  
錦帶一卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">舊本題梁昭明太子撰陳振孫書錄解題又云梁</span>  
<!-- 册3 葉3553b　Page:文淵閣四庫全書_0003冊.djvu/893 -->
<span style="margin-left: 2em">元帝撰比事儷語在法帖中章草月儀之𩔖詳其</span>  
<span style="margin-left: 2em">毎篇自敘之詞皆山林之語非帝胄所宜言且詞</span>  
<span style="margin-left: 2em">氣不𩔖六朝亦復不𩔖唐格疑宋人按月令集爲</span>  
<span style="margin-left: 2em">駢句以備箋啟之用後來附會題爲統作耳今刻</span>  
<span style="margin-left: 2em">本昭明集中亦有之題曰十二月啟然昭明集乃</span>  
<span style="margin-left: 2em">後人所輯非其原本未可據以爲信也</span>  
錦帶補註一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">舊本題宋杜開撰其本較明人所刻多前序一篇</span>  
<span style="margin-left: 2em">不著撰人名氏詞旨頗鄙注文尤謬又出師古註</span>  
<!-- 册3 葉3556a　Page:文淵閣四庫全書_0003冊.djvu/894 -->
<span style="margin-left: 2em">杜詩之下如開卷註昭明太子四字曰姓蕭名普</span>  
<span style="margin-left: 2em">字子施昭明者號也殆目未睹史書者其他所引</span>  
<span style="margin-left: 2em">論語德不孤必有鄰君子以文會友詩中心藏之</span>  
<span style="margin-left: 2em">何日忘之等數條爲有根據餘則無一不出杜撰</span>  
<span style="margin-left: 2em">疑亦妄人依托也</span>  
𡻕華紀麗四卷<sub class="note-yuan">内府藏本</sub>  
<span style="margin-left: 2em">舊本題唐韓鄂撰考唐書宰相世系表載韓休之</span>  
<span style="margin-left: 2em">弟殿中丞倩倩之子河南兵曹參軍滌鄂乃滌之</span>  
<span style="margin-left: 2em">曾孫也其書以四時節候分門隸事各編爲駢句</span>  
<!-- 册3 葉3556b　Page:文淵閣四庫全書_0003冊.djvu/894 -->
<span style="margin-left: 2em">畧如北堂書鈔六帖之體唐志宋志皆列其名陳</span>  
<span style="margin-left: 2em">振孫書錄解題亦載之然久無傳本此本爲胡震</span>  
<span style="margin-left: 2em">亨秘冊函中所刻毛晉收其殘板以入津逮秘書</span>  
<span style="margin-left: 2em">者震亨䟦稱得之鄭曉家王士禎居易錄以爲卽</span>  
<span style="margin-left: 2em">震亨僞造按錢曾讀書敏求記云𡻕華紀麗舊抄</span>  
<span style="margin-left: 2em">卷終闕字數行又失去末葉後見章邱李中麓藏</span>  
<span style="margin-left: 2em">宋刻本脫落正同是此書<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3419.svg?width=24" alt="四庫全書僻字第3419號（確）" title="四庫全書僻字第3419號（確）">出宋本不由震亨之</span>  
<span style="margin-left: 2em">依托然書錄解題稱其采經史子傳𡻕時事𩔖聚</span>  
<span style="margin-left: 2em">而以儷句間之此本乃全作儷句已不相合又儷</span>  
<!-- 册3 葉3557a　Page:文淵閣四庫全書_0003冊.djvu/894 -->
<span style="margin-left: 2em">句拙陋殊甚所引書不過數十種而割裂餖飣往</span>  
<span style="margin-left: 2em">往不成文句且杜陽雜編蘇鶚所作鶚僖宗光啟</span>  
<span style="margin-left: 2em">中進士已届唐末摭言王定保所作定保昭宗光</span>  
<span style="margin-left: 2em">化三年進士已入五代鄂安得引二人之書至中</span>  
<span style="margin-left: 2em">引四時纂要一條考之唐志是書卽鄂所作鄂又</span>  
<span style="margin-left: 2em">何至自引已作况鄂旣唐人不應稱唐元宗及唐</span>  
<span style="margin-left: 2em">時均屬疑竇曾所云云正未可據爲定論也</span>  
標題補注𫎇求三卷<sub class="note-yuan">浙江鮑士恭家藏本</sub>  
<span style="margin-left: 2em">晉李瀚撰宋徐子光註書錄解題宋史藝文志皆</span>  
<!-- 册3 葉3557b　Page:文淵閣四庫全書_0003冊.djvu/894 -->
<span style="margin-left: 2em">作八卷今所行者凡二本一本二卷乃子光之原</span>  
<span style="margin-left: 2em">註已著於錄此本又分三卷凡子光註中陳振孫</span>  
<span style="margin-left: 2em">所謂兼及他人事者皆爲刪去而每句之下俱有</span>  
<span style="margin-left: 2em">評識二字如好賢循吏孝義廉介之𩔖卽所謂標</span>  
<span style="margin-left: 2em">題葢坊刻改竄之本不足取也</span>  
文選雙字𩔖要三卷<sub class="note-yuan">浙江汪啟淑家藏本</sub>  
<span style="margin-left: 2em">舊本題宋蘇易簡撰易簡有文房四譜已著錄是</span>  
<span style="margin-left: 2em">編取文選中藻麗之語分𩔖纂輯其中語出經史</span>  
<span style="margin-left: 2em">偶爲漢以來詞賦采用者亦卽以采用之篇註爲</span>  
<!-- 册3 葉3560a　Page:文淵閣四庫全書_0003冊.djvu/895 -->
<span style="margin-left: 2em">出典易備名臣不應荒陋至此陸游老學菴筆記</span>  
<span style="margin-left: 2em">稱宋初崇尙文選草必稱王孫梅必稱驛使月必</span>  
<span style="margin-left: 2em">稱望舒山水必稱淸暉方爲合格疑其時科舉之</span>  
<span style="margin-left: 2em">徒輯爲此書托易簡之名以行也</span>  
𩔖要一百卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">宋晏殊撰殊字同叔撫州臨川人景德初張知白</span>  
<span style="margin-left: 2em">以神童薦賜同進士岀身擢秘書省正字官至集</span>  
<span style="margin-left: 2em">賢殿學士同平章事兼樞宻使卒諡元獻事蹟具</span>  
<span style="margin-left: 2em">宋史本傳是編乃所作𩔖事之書體例畧如北堂</span>  
<!-- 册3 葉3560b　Page:文淵閣四庫全書_0003冊.djvu/895 -->
<span style="margin-left: 2em">書鈔白氏六帖而詳贍則過之葉夢得避暑錄話</span>  
<span style="margin-left: 2em">稱殊生平未嘗棄一𥿄雖封皮亦十百爲沓每讀</span>  
<span style="margin-left: 2em">書得一故事則批一封皮後批門𩔖命書吏傳寫</span>  
<span style="margin-left: 2em">卽今𩔖要也故所載皆從原書採掇不似他𩔖書</span>  
<span style="margin-left: 2em">互相剽竊輾轉傳訛然自宋代所傳名目卷帙已</span>  
<span style="margin-left: 2em">多互異歐陽修作殊神道碑稱類集古今爲集選</span>  
<span style="margin-left: 2em">二百卷曾鞏作序則稱上中下帙七十四篇惟宋</span>  
<span style="margin-left: 2em">史本傳稱一百卷與今本合據其四世孫知雅州</span>  
<span style="margin-left: 2em">袤進書原表則南渡後已多缺佚袤續加編錄於</span>  
<!-- 册3 葉3561a　Page:文淵閣四庫全書_0003冊.djvu/895 -->
<span style="margin-left: 2em">開禧二年上進故今書中有於篇目下題四世孫</span>  
<span style="margin-left: 2em">袤補闕者皆袤所增非殊之舊矣自明以來傳本</span>  
<span style="margin-left: 2em">甚罕惟浙江范氏天一閣所藏尙從宋本抄存而</span>  
<span style="margin-left: 2em">中間殘缺至四十三卷別有兩淮所進本僅存三</span>  
<span style="margin-left: 2em">十七卷門𩔖次第尤多顚倒且傳寫相沿訛謬脫</span>  
<span style="margin-left: 2em">落甚至不可句讀葢與太平御覽同爲宋代𩔖書</span>  
<span style="margin-left: 2em">之善本而其不可校正則較御覧爲更甚故今惟</span>  
<span style="margin-left: 2em">附存其目焉</span>  
春秋經傳𩔖對賦一卷<sub class="note-yuan">兩江總督採進本</sub>  
<!-- 册3 葉3561b　Page:文淵閣四庫全書_0003冊.djvu/895 -->
<span style="margin-left: 2em">宋徐晉<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">撰晉<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">里貫未詳自署稱將仕郞秘書</span>  
<span style="margin-left: 2em">省校書郞亦不知其始末也左傳文繁詞縟學者</span>  
<span style="margin-left: 2em">往往緯以儷語取便記誦見於宋史藝文志者有</span>  
<span style="margin-left: 2em">崔昇等十餘家今並亡佚惟此賦尙存凡一百五</span>  
<span style="margin-left: 2em">十韻一萬五千言屬對雖工而無當於義理其徵</span>  
<span style="margin-left: 2em">引亦多舛漏前有皇祐三年自序云首尾貫串十</span>  
<span style="margin-left: 2em">得八九殊未然也</span>  
<span style="margin-left: 1em">國朝高士奇嘗爲之注通志堂經解亦收之末有元</span>  
<span style="margin-left: 2em">至大戊申長沙區斗英一䟦稱江陰路總管太原</span>  
<!-- 册3 葉3564a　Page:文淵閣四庫全書_0003冊.djvu/896 -->
<span style="margin-left: 2em">趙嘉山得善本授郡庠俾鋟梓云</span>  
文選𩔖林十八卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">舊本題宋劉攽撰攽字貢父新喻人敞之弟也與</span>  
<span style="margin-left: 2em">敞同舉慶厯六年進士厯官秘書少監出知蔡州</span>  
<span style="margin-left: 2em">後終於中書舍人事蹟具宋史本傳是編取文選</span>  
<span style="margin-left: 2em">字句可供詞賦之用者分門標目共五百四十九</span>  
<span style="margin-left: 2em">𩔖然攽兄弟以文章學問與歐陽修蘇軾諸人馳</span>  
<span style="margin-left: 2em">騁上下未必爲此餖飣之學疑亦南宋時業詞科</span>  
<span style="margin-left: 2em">者所依托也</span>  
<!-- 册3 葉3564b　Page:文淵閣四庫全書_0003冊.djvu/896 -->
記室新書七十卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">舊本題宋方龜年編龜年莆田人景祐元年進士</span>  
<span style="margin-left: 2em">官至屯田郞中按宋史藝文志事𩔖門載方龜年</span>  
<span style="margin-left: 2em">羣書新語十一卷福建通志亦載之作十卷均無</span>  
<span style="margin-left: 2em">記室新書之名考世傳抄本翰苑新書有明<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3179.svg?width=24" alt="四庫全書僻字第3179號（沔）" title="四庫全書僻字第3179號（沔）">陽</span>  
<span style="margin-left: 2em">陳文燭序謂是宋人書抄自秘閣者無撰人姓氏</span>  
<span style="margin-left: 2em">凡分四集其別集十二卷卽此書之前十二卷其</span>  
<span style="margin-left: 2em">前集七十卷此書割去前十二卷以十三卷以下</span>  
<span style="margin-left: 2em">五十八卷續別集後仍足七十卷之數葢坊賈得</span>  
<!-- 册3 葉3565a　Page:文淵閣四庫全書_0003冊.djvu/896 -->
<span style="margin-left: 2em">殘缺翰苑新書併兩集爲一集改此名以售欺也</span>  
別本實賔錄一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">不著編輯者名氏卷首題曰蘇臺雲翁錄末誌正</span>  
<span style="margin-left: 2em">德五年五月望後蘇臺雲翁錄於西閣灣南之垂</span>
