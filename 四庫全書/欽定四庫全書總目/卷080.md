## 欽定四庫全書總目 卷八十　史部三十六　職官類存目

<!-- 册2 葉2660a　Page:文淵閣四庫全書_0002冊.djvu/670 -->
欽定四庫全書總目卷八十  
<span style="margin-left: 1em">史部三十六</span>  
<span style="margin-left: 2em">職官類存目</span>  
厯代銓政要畧一卷<sub class="note-yuan">編修程晉芳家藏本</sub>  
<span style="margin-left: 2em">舊本題宋楊億撰億字大年浦城人雍熙初年十</span>  
<span style="margin-left: 2em">一召試詩賦授秘書省正字淳化中命試翰林賜</span>  
<span style="margin-left: 2em">進士第天禧中官至工部侍郎翰林學士兼史館</span>  
<span style="margin-left: 2em">修撰卒諡曰文事蹟具宋史本傳此書宋史藝文</span>  
<span style="margin-left: 2em">志不著錄億本傳亦不載惟曹溶學海類編收之</span>  
<!-- 册2 葉2660b　Page:文淵閣四庫全書_0002冊.djvu/670 -->
<span style="margin-left: 2em">細核其文乃冊府元龜銓政一門總序也巳爲割</span>  
<span style="margin-left: 2em">裂作僞又億雖預修冊府元龜而據晁氏讀書志</span>  
<span style="margin-left: 2em">總其事者尚有王欽若同修者更有錢惟演等十</span>  
<span style="margin-left: 2em">五人作序者亦有李維等五人億於諸序不過奉</span>  
<span style="margin-left: 2em">勅㸃竄何所見而此序出億手此眞隨意支配者</span>  
<span style="margin-left: 2em">矣</span>  
太常沿革二卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">元任栻撰栻始末未詳此書乃其爲太常博士時</span>  
<span style="margin-left: 2em">所修前有危素序素時亦爲太常博士故也上卷</span>  
<!-- 册2 葉2661a　Page:文淵閣四庫全書_0002冊.djvu/670 -->
<span style="margin-left: 2em">志沿革下卷皆職官題名始自中統迄於至正所</span>  
<span style="margin-left: 2em">載當時奏牘文移皆從國語譯出未經修潤又案</span>  
<span style="margin-left: 2em">元太常集禮一書中載官屬職掌曰都監曰祭祠</span>  
<span style="margin-left: 2em">局曰鑾儀局曰法物庫曰神厨局皆有事於太廟</span>  
<span style="margin-left: 2em">之官而以署令一人丞一人統之此上下兩卷中</span>  
<span style="margin-left: 2em">俱未載及轉以典書附於卷末義例殊不可解危</span>  
<span style="margin-left: 2em">素序云寺升院院有正從二品之異其增損官吏</span>  
<span style="margin-left: 2em">祿秩弗同具載此書然大要巳具於元史矣</span>  
南臺備要二卷<sub class="note-yuan">永樂大典本</sub>  
<!-- 册2 葉2661b　Page:文淵閣四庫全書_0002冊.djvu/670 -->
<span style="margin-left: 2em">元劉孟保等撰前有江南行御史臺都事素元岱</span>  
<span style="margin-left: 2em">序稱至元十四年立行臺於維揚以式三省統諸</span>  
<span style="margin-left: 2em">道卽今江南諸道行御史臺之在集慶者也中臺</span>  
<span style="margin-left: 2em">嘗併其官屬除拜合爲一書刋布中外所謂憲臺</span>  
<span style="margin-left: 2em">通紀是巳至正癸未藁城董公守簡授湖廣行省</span>  
<span style="margin-left: 2em">中丞欲別爲載籍以便觀覽迺命掾屬劉孟保等</span>  
<span style="margin-left: 2em">披牘厯案稽覈故實裒集成編則此書乃補憲臺</span>  
<span style="margin-left: 2em">通紀之遺者也考憲臺通紀久巳散佚永樂大典</span>  
<span style="margin-left: 2em">亦僅存其卷首故不著於錄而惟存此書之目焉</span>  
<!-- 册2 葉2664a　Page:文淵閣四庫全書_0002冊.djvu/671 -->
官職㑹通二卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">明魏校撰校有周禮沿革傳巳著錄此書又敷衍</span>  
<span style="margin-left: 2em">其說以明之六部配周之六官其所屬官因以附</span>  
<span style="margin-left: 2em">焉僅有天官地官春官夏官四篇葢亦未成之稿</span>  
<span style="margin-left: 2em">每述一官必曰今欲正某官之職云云然言之則</span>  
<span style="margin-left: 2em">成理行之則必窒自漢以來未有以周禮致太平</span>  
<span style="margin-left: 2em">者也</span>  
南廱志二十四卷<sub class="note-yuan">浙江汪啓淑家藏本</sub>  
<span style="margin-left: 2em">明黄佐撰佐有泰泉鄉禮已著錄南都太學建於</span>  
<!-- 册2 葉2664b　Page:文淵閣四庫全書_0002冊.djvu/671 -->
<span style="margin-left: 2em">明太祖吳元年景泰中祭酒吳節嘗撰志一十八</span>  
<span style="margin-left: 2em">卷嘉靖初祭酒崔銑重纂未就佐得其遺牘因復</span>  
<span style="margin-left: 2em">加修訂以吳志爲本而增損成之凡事紀四職官</span>  
<span style="margin-left: 2em">表二雜考十二列傳六書法一凖史例頗爲詳備</span>  
<span style="margin-left: 2em">惟音樂考一門多泛論古樂皆佐一巳之見於太</span>  
<span style="margin-left: 2em">學制度無涉殊失限斷其第十八卷經籍考當時</span>  
<span style="margin-left: 2em">以委助敎梅鷟成之鷟學問淹貫故敘述亦具有</span>  
<span style="margin-left: 2em">本末書成於嘉靖二十二年而中有萬厯中事蓋</span>  
<span style="margin-left: 2em">後人隨時續添者也</span>  
<!-- 册2 葉2665a　Page:文淵閣四庫全書_0002冊.djvu/671 -->
䖍臺志十二卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明蕭根等撰根爵里未詳宏治甲寅汀漳盗起楚</span>  
<span style="margin-left: 2em">粤之不逞者和之於是設巡撫都御史治贛州以</span>  
<span style="margin-left: 2em">控制諸省至甲子罷置正德庚午盗攻武平縣乃</span>  
<span style="margin-left: 2em">復建焉嘉靖壬寅巡撫虞守愚命根等編𢰅䖍臺</span>  
<span style="margin-left: 2em">始末爲此書序次草創略備故事而巳贛州在陳</span>  
<span style="margin-left: 2em">以前曰南康至隋改爲䖍州宋紹興二十二年校</span>  
<span style="margin-left: 2em">書董德元上言䖍州號虎頭城非佳名廷議以䖍</span>  
<span style="margin-left: 2em">有䖍劉之義因改名贛州後人詞翰兼用古名然</span>  
<!-- 册2 葉2665b　Page:文淵閣四庫全書_0002冊.djvu/671 -->
<span style="margin-left: 2em">施於詩賦則可此記明代職官而用南宋以前之</span>  
<span style="margin-left: 2em">地名殊於體例未安且名䖍州時無御史臺於文</span>  
<span style="margin-left: 2em">義亦爲杜𢰅明人著述往往如斯糾之不可勝糾</span>  
<span style="margin-left: 2em">也</span>  
吕梁洪志一卷<sub class="note-yuan">戸部尚書王際華家藏本</sub>  
<span style="margin-left: 2em">明馮世雍撰世雍江夏人嘉靖癸未進士官工部</span>  
<span style="margin-left: 2em">主事明時運道自徐州泝吕梁洪入濟設洪夫以</span>  
<span style="margin-left: 2em">牽絻歲命工部屬官一員董其事謂之吕梁分司</span>  
<span style="margin-left: 2em">世雍嘗領其職因述前後建置始末及官署祠廟</span>  
<!-- 册2 葉2668a　Page:文淵閣四庫全書_0002冊.djvu/672 -->
<span style="margin-left: 2em">厯任姓氏以成斯志凡八篇篇首各有序末復繫</span>  
<span style="margin-left: 2em">以贊語</span>  
鄖臺志畧九卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明徐柱撰桂潛山人嘉靖乙未進士官鄖陽府知</span>  
<span style="margin-left: 2em">府先是成化初原傑撫定荆襄流民置鄖陽府設</span>  
<span style="margin-left: 2em">提督撫治一員鎭之嘉靖二十五年慈谿葉照以</span>  
<span style="margin-left: 2em">右副都御史領其任桂等輯比事略爲此書前二</span>  
<span style="margin-left: 2em">卷載建置輿地公𪠘官職後七卷爲劄奏政賦兵</span>  
<span style="margin-left: 2em">防著述所載有嘉靖以後事則金臺于湛等繼爲</span>  
<!-- 册2 葉2668b　Page:文淵閣四庫全書_0002冊.djvu/672 -->
<span style="margin-left: 2em">撫治又附益之也</span>  
䖍臺續志五卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">明陳燦撰燦里貫未詳官贛州府敎諭此書乃嘉</span>  
<span style="margin-left: 2em">靖中巡撫南贛等處右副都御史談愷屬燦等所</span>  
<span style="margin-left: 2em">輯紀宏治以後設官沿革及分地統轄之制以續</span>  
<span style="margin-left: 2em">蕭根之書首一卷爲輿圖考後四卷則編年紀事</span>  
<span style="margin-left: 2em">據其凡例稱於䖍臺志悉仍其舊凡所損益別爲</span>  
<span style="margin-left: 2em">一編葢祝舊志又稍變其例矣</span>  
南京太常寺志十三卷<sub class="note-yuan">浙江巡撫採進本</sub>
