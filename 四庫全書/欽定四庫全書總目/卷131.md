## 欽定四庫全書總目 卷一百三十一　子部四十一　雜家類存目八

<!-- 册3 葉3153a　Page:文淵閣四庫全書_0003冊.djvu/793 -->
欽定四庫全書總目卷一百三十一  
<span style="margin-left: 1em">子部四十一</span>  
<span style="margin-left: 2em">雜家𩔖存目八</span>  
帝皇龜鑑三十四卷<sub class="note-yuan">兩淮馬裕家藏本</sub>  
<span style="margin-left: 2em">舊本題宋王欽若撰欽若事迹具宋史本傳是書</span>  
<span style="margin-left: 2em">攷宋以來史志書目皆不著錄詳檢其文卽冊府</span>  
<span style="margin-left: 2em">元龜中帝王一部卷首欽若序卽原書之總𩔖也</span>  
<span style="margin-left: 2em">僞妄剽竊之書本不足辨而旣有傳本恐滋疑誤</span>  
<span style="margin-left: 2em">是以存而論之焉</span>  
<!-- 册3 葉3153b　Page:文淵閣四庫全書_0003冊.djvu/793 -->
徽言一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">宋司馬光編光手抄諸子史集精語置諸座右以</span>  
<span style="margin-left: 2em">自警自題其首云迂<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2727.svg?width=24" alt="四庫全書僻字第2727號（叟 -- 臾 ?）" title="四庫全書僻字第2727號（叟 -- 臾 ?）">年六十八葢元祐初爲相</span>  
<span style="margin-left: 2em">時也後有陳振孫䟦載光自題其末云余此書𩔖</span>  
<span style="margin-left: 2em">舉人抄書然舉子所抄獵其辭余所抄覈其意舉</span>  
<span style="margin-left: 2em">人志科名余志道德今是編已失其題末未知陳</span>  
<span style="margin-left: 2em">氏所載爲全文否又陳氏稱自國語以下六書今</span>  
<span style="margin-left: 2em">惟國語家語韓詩外傳孟子荀子五書疑有佚缺</span>  
<span style="margin-left: 2em">又毎條下間有題識數字者卷末又列所欲取書</span>  
<!-- 册3 葉3156a　Page:文淵閣四庫全書_0003冊.djvu/794 -->
<span style="margin-left: 2em">名二十二種葢未完之藁後人以光手書重之耳</span>  
卧遊錄一巻<sub class="note-yuan">江蘇巡撫採進本</sub>  
<span style="margin-left: 2em">舊本題朱吕祖謙撰祖謙有古周易已著錄是書</span>  
<span style="margin-left: 2em">前有嘉定九年王深源序後有嘉靖壬午顧元慶</span>  
<span style="margin-left: 2em">跋凡四十五則前二十一則全錄劉義慶世說新</span>  
<span style="margin-left: 2em">語次十八則全錄蘇軾襍著及陶潛集惟後二則</span>  
<span style="margin-left: 2em">不知爲誰語其言參差不倫了無取義祖謙必不</span>  
<span style="margin-left: 2em">如是之陋此本出陳繼儒普秘笈中殆明人依託</span>  
<span style="margin-left: 2em">也</span>  
<!-- 册3 葉3156b　Page:文淵閣四庫全書_0003冊.djvu/794 -->
經子法語二十四巻<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">宋洪邁撰邁有史記法語巳著錄邁兄弟並以詞</span>  
<span style="margin-left: 2em">科起家此書葢卽摘經子新穎字句以備程試之</span>  
<span style="margin-left: 2em">用者凡易一巻書二巻詩三巻周禮二巻禮記四</span>  
<span style="margin-left: 2em">巻儀禮公羊傳穀梁傳孟子荀子列子國語太元</span>  
<span style="margin-left: 2em">經各一巻莊子四巻體例畧如𩔖書但不分門目</span>  
<span style="margin-left: 2em">與經義絶不相渉朱<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2833.svg?width=24" alt="四庫全書僻字第2833號（𢑱）" title="四庫全書僻字第2833號（𢑱）">尊以易法語一巻詩法語</span>  
<span style="margin-left: 2em">一巻之𩔖散入經義考各門之中題曰未見未免</span>  
<span style="margin-left: 2em">失考矣</span>  
<!-- 册3 葉3157a　Page:文淵閣四庫全書_0003冊.djvu/794 -->
文苑英華鈔四卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 2em">宋高似孫編似孫有剡錄已著錄是編乃採摘文</span>  
<span style="margin-left: 2em">苑英華中典雅字句可供文章之用者仿洪邁經</span>  
<span style="margin-left: 2em">子法語之例鈔合成帙刻本仍以原目爲次不分</span>  
<span style="margin-left: 2em">卷數以似孫原序考之當時實分四卷也其中以</span>  
<span style="margin-left: 2em">諸本叅校如吕令開蓮峯賦別本皆作氣開秋爽</span>  
<span style="margin-left: 2em">此本作氣涵秋爽賈至早朝詩別本皆作共沐恩</span>  
<span style="margin-left: 2em">波鳳池上朝朝染翰侍君王此本作共沐恩波鳳</span>  
<span style="margin-left: 2em">池裏終朝黙黙侍君王李羣玉黃陵廟詩別本皆</span>  
<!-- 册3 葉3157b　Page:文淵閣四庫全書_0003冊.djvu/794 -->
<span style="margin-left: 2em">作𮞉風日暮吹芳芷此本作東風日暮吹香芷皆</span>  
<span style="margin-left: 2em">小有異同韓愈汴州東西水門記別本俱作請紀</span>  
<span style="margin-left: 2em">成績此本皆作請紀其成績又遂極其危句此本</span>  
<span style="margin-left: 2em">作遂持危亦皆韓集舉正韓文考異所未載其捜</span>  
<span style="margin-left: 2em">羅亦頗該洽自序謂周必大奉勅校文苑英華是</span>  
<span style="margin-left: 2em">書有助焉然摘錄不具首尾僅爲詞科餖飣之學</span>  
<span style="margin-left: 2em">爾</span>  
養生雜纂二十二卷附月覽二卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">宋周守忠撰守忠號㮤菴<sub class="note-yuan">案㮤古文松字</sub>不知何許人初</span>  
<!-- 册3 葉3160a　Page:文淵閣四庫全書_0003冊.djvu/795 -->
<span style="margin-left: 2em">以養生宜忌之事按月編錄名日月覽後於嘉定</span>  
<span style="margin-left: 2em">壬午又廣爲雜纂首爲總敘三篇次以事𩔖分爲</span>  
<span style="margin-left: 2em">十三部後人以月覽附刻於後共爲一書總題曰</span>  
<span style="margin-left: 2em">養生雜𩔖非其本名也</span>  
石屏新語二卷<sub class="note-yuan">浙江吳玉墀家藏本</sub>  
<span style="margin-left: 2em">舊題宋戴復古撰復古字式之天台黃巖人居南</span>  
<span style="margin-left: 2em">塘石屏山因以自號是編以石屏新語爲名則當</span>  
<span style="margin-left: 2em">爲復古所手著乃編中惟錄張詢古五代新說陳</span>  
<span style="margin-left: 2em">郁藏一話腴二種而多所刪節當是後人依託其</span>  
<!-- 册3 葉3160b　Page:文淵閣四庫全書_0003冊.djvu/795 -->
<span style="margin-left: 2em">名抄撮成帙也</span>  
補妬記八卷<sub class="note-yuan">浙江鄭大節家藏本</sub>  
<span style="margin-left: 2em">舊本題曰京兆王績編不著時代案晁公武讀書</span>  
<span style="margin-left: 2em">志載有此書一卷謂不知何人所輯陳振孫書錄</span>  
<span style="margin-left: 2em">解題亦有此書稱王績撰因古有宋虞氏妬記今</span>  
<span style="margin-left: 2em">不傳故補之其題名與此相合當卽振孫所見之</span>  
<span style="margin-left: 2em">本其書自一卷至六卷紀商周迄五季妬婦之事</span>  
<span style="margin-left: 2em">第七卷曰雜妬謂淫亂而妬及事渉神怪者第八</span>  
<span style="margin-left: 2em">卷曰總敘乃襍說文章自涼張續妬婦賦以下並</span>  
<!-- 册3 葉3161a　Page:文淵閣四庫全書_0003冊.djvu/795 -->
<span style="margin-left: 2em">闕故振孫所稱治妬二方已無之然振孫旣云古</span>  
<span style="margin-left: 2em">妬記不傳而書中又有採自妬記者不知何據殆</span>  
<span style="margin-left: 2em">於𩔖書剽取之至第七卷内宋仁宗尙楊二美人</span>  
<span style="margin-left: 2em">事乃注云見宋史則明人已有所附益非復宋代</span>  
<span style="margin-left: 2em">原書矣</span>  
古今藝苑談槩上集六卷下集六卷<sub class="note-yuan">兩江總督採進本</sub>  
<span style="margin-left: 2em">舊本題俞文豹撰案文豹宋人所著吹劍錄外集</span>  
<span style="margin-left: 2em">已著錄此編多引明代諸書葢僞託也書中襍采</span>  
<span style="margin-left: 2em">故實無所辨論毎條下各列書名而疎舛特甚如</span>  
<!-- 册3 葉3161b　Page:文淵閣四庫全書_0003冊.djvu/795 -->
<span style="margin-left: 2em">鄒忌妻妾事出戰國策而註曰十二國春秋列子</span>  
<span style="margin-left: 2em">攫金於市事末增吏大笑之四字當爲無知書賈</span>  
<span style="margin-left: 2em">抄撮說部僞立新名也</span>  
澄懷錄二卷<sub class="note-yuan">兩淮鹽政採進本</sub>  
<span style="margin-left: 2em">宋周宻撰宻有志雅堂襍鈔已著錄是書採唐宋</span>  
<span style="margin-left: 2em">諸人所紀登渉之勝與曠達之語彚爲一編皆節</span>  
<span style="margin-left: 2em">載原文而注書名其下亦世說新語之流別而稍</span>  
<span style="margin-left: 2em">變其體例者也明人喜摘錄清談目爲小品濫觴</span>  
<span style="margin-left: 2em">所自葢在此書矣</span>  
<!-- 册3 葉3164a　Page:文淵閣四庫全書_0003冊.djvu/796 -->
女教書四卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">元許熙載撰熙載字獻臣彰德相州人叅知政事</span>  
<span style="margin-left: 2em">有壬之父也是編集經書及先儒之言凡有闗於</span>  
<span style="margin-left: 2em">女教者分爲六篇曰内訓曰昏禮曰婦道曰母儀</span>  
<span style="margin-left: 2em">曰孝行曰貞節</span>  
景行錄一卷<sub class="note-yuan">浙江范懋柱家天一閣藏本</sub>  
<span style="margin-left: 2em">舊本題元史弼編弼字君佐自號紫微老人博野</span>  
<span style="margin-left: 2em">人官至福建行省平章政事封鄂國公事迹具元</span>  
<span style="margin-left: 2em">史本傳是編成於至元丁亥所錄格言百餘條多</span>  
<!-- 册3 葉3164b　Page:文淵閣四庫全書_0003冊.djvu/796 -->
<span style="margin-left: 2em">剽掇省心錄之語前有弼自序其詞潦倒可笑似</span>  
<span style="margin-left: 2em">出妄人所依託復有明瞿佑序稱宣德戊申侍太</span>  
<span style="margin-left: 2em">師英國公坐因問經史中警句可資觀覽而切於</span>  
<span style="margin-left: 2em">修省者謹寫一編拜獻以供淸暇之一顧末題門</span>  
<span style="margin-left: 2em">下士瞿佑手錄時年八十有二詞亦庸劣佑似不</span>  
<span style="margin-left: 2em">應至此考成化丙戌木訥作佑歸田詩話序雖有</span>  
<span style="margin-left: 2em">太師英國張公延爲西席之語然佑自序作於洪</span>  
<span style="margin-left: 2em">熙乙巳稱老與農圃爲徒亦竊歸田之號又稱輟</span>  
<span style="margin-left: 2em">耕隴上箕踞桑陰則洪熙時已返江南矣安得宣</span>  
<!-- 册3 葉3165a　Page:文淵閣四庫全書_0003冊.djvu/796 -->
<span style="margin-left: 2em">德戊申尙作客張輔家哉其爲假名於佑尤顯然</span>  
<span style="margin-left: 2em">矣後又有正德乙亥鎭遠侯顧士隆重刋序嘉靖</span>  
<span style="margin-left: 2em">甲午衡王重刋序葢皆因仍僞本不及考核耳</span>  
有官龜鑑十九卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">元蘇霖撰霖有書法鉤元已著錄是編採前人服</span>  
<span style="margin-left: 2em">官事迹彚爲一書凡分四十𩔖皆以四字標題如</span>  
<span style="margin-left: 2em">輔相君王贊翼皇儲之𩔖頗渉於俗且旣有陳善</span>  
<span style="margin-left: 2em">閉邪又有繩愆糾繆<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2711.svg?width=24" alt="四庫全書僻字第2711號（（⿺𠃊旨））" title="四庫全書僻字第2711號（（⿺𠃊旨））">言極諫之𩔖亦病於複體</span>  
<span style="margin-left: 2em">例殊爲猥雜所引諸書惟有元諸人言行採自家</span>  
<!-- 册3 葉3165b　Page:文淵閣四庫全書_0003冊.djvu/796 -->
<span style="margin-left: 2em">傳墓誌者問爲他書所未載其餘經史子集皆人</span>  
<span style="margin-left: 2em">所習見論斷尤罕所發明殊無可采也</span>  
忍經一卷<sub class="note-yuan">永樂大典本</sub>  
<span style="margin-left: 2em">元吳亮撰亮字明<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_2721.svg?width=24" alt="四庫全書僻字第2721號（卿）" title="四庫全書僻字第2721號（卿）">錢塘人前有馮寅序稱吳君</span>  
<span style="margin-left: 2em">精於經術吏事至元癸巳解海運元幕之任恬淡</span>  
<span style="margin-left: 2em">自居於纂述厯代帝王世系之暇思其平生行已</span>  
<span style="margin-left: 2em">惟一忍字會集羣書中格言大訓以爲一編所採</span>  
<span style="margin-left: 2em">皆習見之書葢姑以見意云爾</span>  
閒博錄一卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<!-- 册3 葉3168a　Page:文淵閣四庫全書_0003冊.djvu/797 -->
<span style="margin-left: 2em">不著撰人名氏諸家書目亦不著錄大都述先正</span>  
<span style="margin-left: 2em">格言及達觀保生之事卷中有一條稱吾鄉沈持</span>  
<span style="margin-left: 2em">要詹事今年已八十有三耳目聰明云云持要乃</span>  
<span style="margin-left: 2em">沈樞之字樞德淸人則此書似當爲宋南渡後湖</span>  
<span style="margin-left: 2em">州人所撰然書末復有二條一稱皇朝修經世大</span>  
<span style="margin-left: 2em">典云云一稱聖朝郊祀祝文天子以下止右丞相</span>  
<span style="margin-left: 2em">得預名云云經世大典成於元文宗至順二年据</span>  
<span style="margin-left: 2em">元史百官志專任右丞相亦自至順二年始則此</span>
