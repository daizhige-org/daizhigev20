<span style="margin-left: 1em">子部四十三</span>  
<span style="margin-left: 2em">雜家𩔖存目十</span>  
豐暇觀頤四卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 2em">不著撰人名氏有序三首一稱懶散道人一稱見</span>  
<span style="margin-left: 2em">廬主人一稱醉醒逸叟而卷首復題醉醒逸叟偶</span>  
<span style="margin-left: 2em">閱字詳其詞氣當是一人一題已丑一題辛卯一</span>  
<span style="margin-left: 2em">題癸已皆不著年號中引湯賓尹睡庵集考睡庵</span>  
<span style="margin-left: 2em">集序題萬厯庚戌則此書在是集之後已丑爲順</span>

<span style="margin-left: 2em">治六年辛卯爲順治八年癸巳爲順治十一年是</span>  
<span style="margin-left: 1em">國朝人矣其曰豐暇葢取謝靈運詩卧病豐暇豫之</span>  
<span style="margin-left: 2em">意皆雜引文集說部不分門目多放曠之言出入</span>  
<span style="margin-left: 2em">於佛老之間至於元帝垂訓之類亦登簡牘孰聞</span>  
<span style="margin-left: 2em">之而孰錄之乎</span>  
懿行編八卷<sub class="note-yuan">浙江巡撫採進本</sub>  
<span style="margin-left: 1em">國朝李瀅撰瀅字鏡石揚州興化人其書取諸史中</span>  
<span style="margin-left: 2em">嘉言懿行可爲法程者分𩔖標題紀事之後間爲</span>  
<span style="margin-left: 2em">論斷遠自上古近至明代凡二十九門毎條皆載</span>

<span style="margin-left: 2em">所採書名而於前人論斷亦節取一二</span>

<span style="margin-left: 1em">國朝項眞撰眞字不損秀水人前明諸生入</span>  
<span style="margin-left: 1em">國朝官景陵縣知縣是書摭拾成文漫無風旨雜引</span>  
<span style="margin-left: 2em">故實皆仍其原文今古不辨甚至以喬知之爲晉</span>  
<span style="margin-left: 2em">人疎陋可知矣</span>  
葉書一卷<sub class="note-yuan">安徽巡撫採進本</sub>  
<span style="margin-left: 1em">國朝黄生撰生有字詁已著錄是編皆錄載籍中新</span>  
<span style="margin-left: 2em">雋字句然所採多不倫葢亦從𩔖書摘抄以備文</span>

<span style="margin-left: 2em">進士</span>

<span style="margin-left: 2em">十二夫婦爲數十一兄弟爲數十六朋友爲數三</span>

<span style="margin-left: 2em">種一曰快書秘錄二曰廣快秘錄三曰明百家說</span>  
<span style="margin-left: 2em">皆雜錄前人之說四曰耕餘雜語爲寧陽張攀龍</span>  
<span style="margin-left: 2em">撰五曰譚韻新書摘王元禎湖海搜奇等書而成</span>  
<span style="margin-left: 2em">者六曰遺詩碎金則皆詩話也七曰三國問答爲</span>

<span style="margin-left: 2em">原本節錄之不足以言著書也</span>

<span style="margin-left: 2em">記内外篇二曰聞居擇言三曰小心齋劄記四曰</span>  
<span style="margin-left: 2em">南牖日箋五曰忠節語錄六曰嵗寒居答問七曰</span>

<span style="margin-left: 2em">舊本題</span>  
<span style="margin-left: 1em">國朝魏裔介撰其書亦鈔撮雜說而成卷一曰<img class="rare-char" src="https://commons.wikimedia.org/wiki/Special:FilePath/SKQS_3932.svg?width=24" alt="四庫全書僻字第3932號（鬼）" title="四庫全書僻字第3932號（鬼）">神</span>
